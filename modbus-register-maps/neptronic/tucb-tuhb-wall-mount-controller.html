Neptronic TUCB / TUHB Series universal wall-mount controller (Modbus RTU) Modbus register map

Updated 19 November 2026

Short answer

The TUCB and TUHB are Neptronic wall-mount controllers with built-in sensors, six binary and two analog outputs, for fan coils, heat pumps (with reversing valve and emergency heat options) and other unitary equipment. Over Modbus RTU they expose temperatures, humidity (TUHB), CO2, ramp demands, output states, mode, fan and setpoint control and the configuration registers.

This page lists 133 Modbus registers for the Neptronic TUCB / TUHB Series universal wall-mount controller (Modbus RTU) — 109 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Neptronic’s own free documentation (linked below) and checked against it.

Integration notes: Neptronic TUCB / TUHB Series universal wall-mount controller (Modbus RTU)

Integration in brief

Read holding registers with function 03 at the printed register index minus 40000 (40011 = address 11). Set the temperature unit for Modbus first, then use the mode, fan and setpoint registers for control.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is the controller's native protocol; set the address (1-246) and, if needed, a fixed baud rate and parity from the device menu or registers 0-2.

Byte order & addressing

  • The table prints a 4 prefix on a 0-based register index (40000 = address 0), not the 40001 Modicon convention.
  • Baud register holds baud/100 (384 = 38400); 0 means automatic baud detection.

Network setup

  • RS-485 two-wire, RTU. Supported baud rates 9600, 19200, 38400 and 57600; automatic baud detection is the default.
  • Parity/stop bits come from the communication-port register: 1 = none + 2 stop, 2 = even + 1 stop, 3 = odd + 1 stop.

Watch out for

  • Changing the Modbus temperature-unit bit changes the meaning of every temperature register at once.
  • Some registers only apply to models with a humidity, CO2 or other optional sensor.

Notes on this map

  • Every register is a 16-bit holding register; there are no 32-bit values.
  • Temperatures, setpoints and bands follow the Modbus temperature-unit bit of system option 1 (°C or °F); sensor readings and offsets are x100, setpoints and bands x10.
  • Do not apply the 40001 rule: in this guide 40000 is register 0.
  • Left out: the four ASCII product-name registers and register 40042 (all bits reserved).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Neptronic TUCB / TUHB Series universal wall-mount controller (Modbus RTU)

What Modbus registers does the Neptronic TUCB / TUHB Series universal wall-mount controller (Modbus RTU) have?

This map lists 133 registers: 133 holding registers. 109 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Neptronic TUCB / TUHB Series universal wall-mount controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. This older guide prints a "Register Index" with a 4 prefix starting at 40000. Its introduction places the device address at holding register index 0 and the baud rate at index 1, which the table shows as 40000 and 40001, so wire address = printed number - 40000 (not the usual 40001 rule).

What are the minimum Modbus registers to integrate the Neptronic TUCB / TUHB Series universal wall-mount controller (Modbus RTU)?

Start with HR 11 Internal temperature sensor reading (Internal (room) temperature x100); HR 14 Control temperature reading (Control temperature x100); HR 36 System mode status (System mode); HR 37 Fan speed selection by user (Fan speed); HR 38 Temperature setpoint in occupancy or day mode (Occupied setpoint x10); HR 23 Actual heating demand of ramp 1 (Heating demand ramp 1); HR 25 Actual cooling demand of ramp 1 (Cooling demand ramp 1); HR 9 System Status 1 (Status 1); HR 10 System Status 2 (Status 2 (alarms)); HR 39 System option 1 (System option 1 (bit 1 = Modbus temp unit)).

How do I enable Modbus control of the Neptronic TUCB / TUHB Series universal wall-mount controller (Modbus RTU)?

Modbus is the controller's native protocol; set the address (1-246) and, if needed, a fixed baud rate and parity from the device menu or registers 0-2.
