Integration notes: Intesis (HMS Networks) INMBSMID001I000 Midea AC to Modbus RTU gateway

Integration in brief

Set the Midea indoor-unit address in register 1210, then write 0-4 and poll 5, 10, 11 and 66. Write room temperature to 22 to make a Modbus-side sensor drive the unit.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step; register 7 = 1 disables the gateway. Register 1210 must hold the Midea address of the unit.

Byte order & addressing

  • Temperature scale depends on SW4.
  • With register 97 = 1 the gateway only forwards changed values, so cyclic rewrites do not override the remote.

Network setup

  • Default slave address 1, 9600 baud, 8N2 (8N1 auto-detected); change on SW3/SW4 and power-cycle.
  • External 12 V DC supply on V1/V2 required.
  • 120 ohm terminator on SW4.

Watch out for

  • The gateway must see the AC unit powered before it starts communicating.
  • DIP switch changes need a power cycle.

Notes on this map

  • Every register is a 16-bit unsigned holding register per the manual. The 'no value' marker (printed -32768, and in some rows as -32678, an apparent typo) is raw 0x8000 = 32768.
  • Temperatures follow SW4: x1 °C, x10 °C or °F. The register footnote calls x10 the default but the DIP-switch table marks x1 and Celsius as factory setting, so scale 1 / °C is used; with x10 set use 0.1.
  • Left out: machine threshold and custom setpoint-limit registers 1151-1156, because the manual gives their defaults in °C/°F but does not say whether they follow the SW4 x1/x10 setting.
  • Register 1210 must match the address of the indoor unit in the Midea system (0..63) before control works.
  • Error code list not reproduced; see manual section 7.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Intesis (HMS Networks) INMBSMID001I000 Midea AC to Modbus RTU gateway

What Modbus registers does the Intesis (HMS Networks) INMBSMID001I000 Midea AC to Modbus RTU gateway have?

This map lists 24 registers: 24 holding registers. 15 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Intesis (HMS Networks) INMBSMID001I000 Midea AC to Modbus RTU gateway Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables give a 'protocol address' (base 0) and a 'PLC address' (base 1); the protocol address is the wire address and is used for 'documented'.

What are the minimum Modbus registers to integrate the Intesis (HMS Networks) INMBSMID001I000 Midea AC to Modbus RTU gateway?

How do I enable Modbus control of the Intesis (HMS Networks) INMBSMID001I000 Midea AC to Modbus RTU gateway?

No enable step; register 7 = 1 disables the gateway. Register 1210 must hold the Midea address of the unit.
