RLE Technologies LD5200 leak detection controller (Modbus RTU / Modbus TCP slave) Modbus register map

Updated 17 November 2026

Short answer

The LD5200 monitors a water-sensing cable and reports where along the cable a leak is. As a Modbus slave on its EIA-485 ports (or Modbus over Ethernet) it gives leak, cable-break and contamination status, leak distance and current, cable resistances, virtual-zone alarms and the status of the slave panels it polls as a Modbus master. Thresholds and alarm delays are writable holding registers.

This page lists 47 Modbus registers for the RLE Technologies LD5200 leak detection controller (Modbus RTU / Modbus TCP slave) — 4 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from RLE Technologies’s own free documentation (linked below) and checked against it.

Integration notes: RLE Technologies LD5200 leak detection controller (Modbus RTU / Modbus TCP slave)

Integration in brief

Read input registers 30001-30011 with FC4: status bits for leak / cable break / contamination, leak distance and unit, leak current and cable data. Read 38001-38002 for the leak position as a float in meters.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set an EIA-485 port function to Modbus-Slave and give it a slave address (1-254, 0 = disabled) and baud rate in the Comm Port Settings menu (LCD) or the Modbus/EIA-485 web page. For Ethernet, set the Modbus/TCP/UDP slave unit identifier on the same page.

Byte order & addressing

  • RTU only on the serial ports, fixed 8 data bits, no parity, 1 stop bit; baud 9600 (default), 19200 or 38400.
  • As a slave the LD5200 accepts only one master.

Network setup

  • Three EIA-485 ports (TB5/TB6); port 2 can also be BACnet MS/TP or N2.
  • When the LD5200 is a master for distance-read panels, the first slave must use address 2, the next 3, and so on.

Watch out for

  • A missing end-of-line terminator on the sensing cable shows as a cable fault.

Notes on this map

  • Float word order: the guide labels 38001 as the float MSW and 38002 as the LSW, so the leak-location float is ABCD.
  • Only the first block of Modbus slave zones (2-16, registers 30012-30042) is listed. Later blocks cover 16 zones each: 30043 flags zones 17-32 with status/distance pairs from 30044, 30076 flags zones 33-48, and so on up to zone 128 at 30272/30273.
  • Holding registers 40003-40015 are spare.
  • Distance registers are in feet or meters depending on register 30003.
  • The guide calls the Ethernet option 'Modbus/TCP/UDP' with its own slave unit identifier (1-254); it does not list a separate map, so the same registers are assumed to apply over Ethernet. The TCP port is not given.
  • The leak trip range differs inside the guide: the Modbus table shows 25-295 uA, the LCD settings page says 25-175 uA.
  • Bit 15 of 30012 is labeled zone 16 although bit 0 is zone 2, so the bits of 30012 are not listed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the RLE Technologies LD5200 leak detection controller (Modbus RTU / Modbus TCP slave)

What Modbus registers does the RLE Technologies LD5200 leak detection controller (Modbus RTU / Modbus TCP slave) have?

This map lists 47 registers: 43 input registers, 4 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the RLE Technologies LD5200 leak detection controller (Modbus RTU / Modbus TCP slave) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. RLE says the start register is numbered from zero: 40001 = 0, 30001 = 0. So input register 30002 (leak distance) is wire address 1 with FC4, holding register 40016 is address 15 with FC3/FC6/FC16.

What byte order does the RLE Technologies LD5200 leak detection controller (Modbus RTU / Modbus TCP slave) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the RLE Technologies LD5200 leak detection controller (Modbus RTU / Modbus TCP slave)?

Start with IR 0 Status (Leak / cable break / contamination status); IR 1 Leak distance (Leak distance); IR 2 Distance units (Distance unit); IR 3 Leak current (Leak current); IR 8000 Leak location (float) (Leak location in meters (float)); IR 9 Virtual zone alarm status, zones 1-16 (Virtual zone alarms 1-16).

How do I enable Modbus control of the RLE Technologies LD5200 leak detection controller (Modbus RTU / Modbus TCP slave)?

Set an EIA-485 port function to Modbus-Slave and give it a slave address (1-254, 0 = disabled) and baud rate in the Comm Port Settings menu (LCD) or the Modbus/EIA-485 web page. For Ethernet, set the Modbus/TCP/UDP slave unit identifier on the same page.
