Short answer

The TCW260 is a Teracom Ethernet energy monitoring and logging module with 4 S0-capable digital inputs, 6 analog inputs (voltage or current-loop mode) and an RS-485 Modbus RTU master for up to 24 sensors. It builds up to 24 calculated channels with alarms, all of which are exposed over Modbus TCP.

Integration notes: Teracom TCW260 Ethernet energy monitoring module

Integration in brief

Enable Modbus TCP, then read the 24 channel results as floats from holding registers 19300-19347 and the alarm states from 22000-22023 with function 03.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP/IP is disabled by default. Enable it in the Modbus TCP/IP section of the web setup (standard port 502).

Byte order & addressing

  • Floats are high word first (ABCD).
  • Settings changed over Modbus are stored by writing 1 to Save configuration (PDU 24000), as the manual notes above its address table.

Network setup

  • The factory IP is 192.168.1.2; change it in the network settings, then enable Modbus TCP/IP.

Notes on this map

  • Word order: the manual says float registers are sent big-endian and its example response 41DD 4210 is given as 27.657, i.e. high word first (ABCD).
  • Strings are fixed-length UTF-8, zero padded; a 16-byte field spans 8 registers.
  • Registers come from the main address table and the full list in Appendix C; where both list an address it appears once.
  • Left out: the rows for analog input 6 multiplier and offset, which the manual prints at the same addresses as input 1 (14100, 14200), an apparent typo.
  • Left out: the 64 32-bit unsigned integer registers (Channel counter; Digital input close to open delay; Digital input counter init value; Digital input counter value; Digital input open to close delay; MB sensor counter). The manual states big-endian order only for floats and strings, so their word order is not documented.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Teracom TCW260 Ethernet energy monitoring module

What Modbus registers does the Teracom TCW260 Ethernet energy monitoring module have?

This map lists 942 registers: 4 discrete inputs, 938 holding registers. 832 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Teracom TCW260 Ethernet energy monitoring module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The address table prints PDU (wire) addresses in decimal. The manual's example frames use them directly (holding register 19300 = 0x4B64, discrete input 100 = 0x0064), so no offset is applied.

What byte order does the Teracom TCW260 Ethernet energy monitoring module use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Teracom TCW260 Ethernet energy monitoring module?

Start with DI 100 Digital input 1 (Digital input 1); HR 14400 Analog input 1 value (Analog input 1 value); HR 19300 Channel 1 value (Channel 1 value); HR 22000 Alarm 1 status (Alarm 1 status); HR 24000 Save configuration (Save configuration); HR 24002 HW error (Hardware error).

How do I enable Modbus control of the Teracom TCW260 Ethernet energy monitoring module?

Modbus TCP/IP is disabled by default. Enable it in the Modbus TCP/IP section of the web setup (standard port 502).

Where is the official Teracom TCW260 Ethernet energy monitoring module Modbus documentation?
