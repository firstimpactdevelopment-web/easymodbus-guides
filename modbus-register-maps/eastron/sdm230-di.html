Eastron SDM230-DI Modbus register map

Updated 16 October 2026

Short answer

The SDM230-DI is a single-phase, direct-connected (up to 100 A) DIN-rail energy meter with two digital inputs and an RS485 Modbus RTU port. Measurements, demand and energy totals are 32-bit IEEE floats in input registers (function 04); settings are held in holding registers (function 03 read, 16 write). This map covers the electrical values, import/export and resettable energy, demand, RS485 settings and the measurement-mode selector.

This page lists 41 Modbus registers for the Eastron SDM230-DI — 12 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Eastron’s own free documentation (linked below) and checked against it.

Integration notes: Eastron SDM230-DI

Integration in brief

Read two-register floats with function 04: voltage at 0x0000, current 0x0006, active power 0x000C, import/export kWh at 0x0048/0x004A. Write settings with function 16 after unlocking with the password in the KPPA register.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is always on at the RS485 terminals. To change key settings, write the password (default 1000) as a float to 40015 (KPPA) first; a read of 40015 returns 1 when unlocked.

Byte order & addressing

  • Settings such as address and baud code are 32-bit floats over two registers; DI filter time, reset, measurement mode, meter code, version and program number are single 16-bit registers.
  • Power factor carries a sign for current direction: positive for forward current, negative for reverse.

Network setup

  • Defaults: address 1, 9600 bps, 8 data bits, no parity, 1 stop bit.
  • Address 1-247; up to 64 meters per bus and 1000 m cable per the manual.
  • Comm settings can also be changed from the front-panel setup menu.

Watch out for

  • The Int64 energy and Int32 reading blocks (310001 onwards) are not mapped because their word order is not documented; use the float registers.

Notes on this map

  • Word order: the manual states that floats are sent big-endian with the first register holding the high 16 bits, and its example returns 42 70 00 00 for 60 minutes. All floats here are ABCD.
  • The input table footnote says total kWh/kVArh is import plus export; the measurement-mode register (463777) can change how the meter forms its total, so check that setting if totals look wrong.
  • Left out: Int64 energy (Wh / VArh, from 310001) and Int32 scaled readings (from 310251), because the manual states big-endian order only for floats.
  • Left out: DI-1/DI-2 counters (40770/40772) and serial number (464513), unsigned 32-bit values with no stated word order.
  • The reset register also lists a kWh reset code, but the code is blank in the manual, so only the demand (0000) and DI-count (0006) codes are given.
  • Demand footnote: the manual says the power-sum demand is calculated for 'import – export' (en dash) without saying whether that means net import minus export or both directions combined; check on a live meter if the sign matters.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Eastron SDM230-DI

What Modbus registers does the Eastron SDM230-DI have?

This map lists 41 registers: 26 input registers, 15 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Eastron SDM230-DI Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed Modicon style (30001, 40003, six-digit 463777...) next to the hex start address sent on the wire. Wire address = printed number minus 30001 / 40001 / 400001; the manual's example reads 40003 at start address 0x0002.

What byte order does the Eastron SDM230-DI use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Eastron SDM230-DI?

Start with IR 0 Voltage (Voltage); IR 6 Current (Current); IR 12 Active power (Active power); IR 30 Power factor (Power factor); IR 70 Frequency (Frequency); IR 72 Import active energy (Import kWh); IR 74 Export active energy (Export kWh).

How do I enable Modbus control of the Eastron SDM230-DI?

Modbus RTU is always on at the RS485 terminals. To change key settings, write the password (default 1000) as a float to 40015 (KPPA) first; a read of 40015 returns 1 when unlocked.
