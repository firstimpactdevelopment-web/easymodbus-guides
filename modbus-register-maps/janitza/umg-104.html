Short answer

The UMG 104 is a power analyser with four voltage and four current inputs and RS-485 / RS-232 serial ports, acting as a Modbus slave. Values are big-endian 32-bit floats that already include the CT/VT ratios. This map covers the 19000-19120 'frequently required readings' block, the fourth channel, consumed/delivered energy totals, digital I/O, the RS-485 address and energy reset commands.

Integration notes: Janitza UMG 104 power analyser (RS-485 Modbus RTU)

Integration in brief

Read holding registers (function 03) from 19000: the 122-register block gives volts, amps, power, CosPhi, frequency, energy and THD as big-endian floats. For all-tariff energy totals read 9851 (consumed) and 9863 (delivered).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The list holds the RS-485 Modbus device address at 10180 (read/write). It gives no menu path or other enable step.

Byte order & addressing

  • Addresses are used as printed (0-based).
  • Floats are ABCD; add 32768 to an address to get the same value little-endian.
  • Energy is in Wh and varh, not kWh.
  • Rotation field (19052) is a float: 1, 0 or -1.

Network setup

  • Use 8 data bits and no parity; the device transmits 2 stop bits (the master may use 1 or 2).
  • Set the CT/VT ratios at the device so the float values read in primary units.
  • Write 1 to 9997 / 9998 to clear the real / reactive energy counters.

Watch out for

  • 19068 is tariff 1 only; use 9851 for the consumed total.
  • Short-format copies elsewhere in the list ignore the CT/VT ratio.

Notes on this map

  • Byte order: the list says its addresses return data big-endian (high byte first, high word in the lower register = ABCD). Adding 32768 to an address returns the same value little-endian; that mirror block is not listed.
  • Data types in the list: short = signed 16-bit, int = signed 32-bit, uint = unsigned 32-bit, float = IEEE 754 32-bit. Float and integer values include the CT/VT ratios; short values do not.
  • 19068 in the frequently-read block is the consumed energy of tariff 1 (rate 1) only, so it is left out; the all-tariff consumed and delivered totals are taken from the energy table (9851 / 9863).
  • Transfer parameters (p. 5): 9600-115200 baud, 8 data bits, no parity, the UMG 104 sends 2 stop bits. The list does not give a default baud rate or device address.
  • Left out: RS-485 mode and baud rate (10182 / 10184), RS-232 settings and IP settings, because the list gives no value coding for them; the summed power factor at 1373, whose formula is printed as Psum3/Qsum3 (likely a typo); the SHORT copies of values; harmonics, min/max/mean blocks, monthly energy, tariffs 3/4 and comparators.
  • Left out: the CT/VT ratio rows 10032-10062. They are four-element arrays and every element is labelled 'L1, L2, L3', so which element belongs to which input is not clear from the list.

Questions about the Janitza UMG 104 power analyser (RS-485 Modbus RTU)

What Modbus registers does the Janitza UMG 104 power analyser (RS-485 Modbus RTU) have?

This map lists 69 registers: 69 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Janitza UMG 104 power analyser (RS-485 Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed as the protocol address and sent unchanged: 19000 is requested as 19000. The list starts at address 0 (real-time clock), which only fits 0-based numbering. In a 1-based or Modicon tool enter 19001 / 419001.

What byte order does the Janitza UMG 104 power analyser (RS-485 Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Janitza UMG 104 power analyser (RS-485 Modbus RTU)?

Start with HR 19000 Voltage L1-N (Voltage L1-N); HR 19012 Current L1 (Current L1); HR 19026 Real power total (Total real power); HR 19034 Apparent power total (Total apparent power); HR 19050 Frequency (Frequency); HR 9851 Real energy L1-L3, consumed (Consumed real energy, all tariffs); HR 9863 Real energy L1-L3, delivered (Delivered real energy, all tariffs).

How do I enable Modbus control of the Janitza UMG 104 power analyser (RS-485 Modbus RTU)?

The list holds the RS-485 Modbus device address at 10180 (read/write). It gives no menu path or other enable step.
