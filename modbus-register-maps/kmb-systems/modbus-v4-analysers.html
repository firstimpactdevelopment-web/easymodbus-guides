Short answer

KMB systems (Czech Republic) builds the SMC, SMY, SMZ, SML, PA and ARTIQ families of power meters and power-quality analysers. Firmware 4.x devices share one Modbus register map over RS-485 (Modbus RTU, auto-detected alongside KMB's own protocol) or Ethernet (Modbus TCP, port 502). This map covers the compact 19000-19121 block of the most-used values as IEEE floats with units, power factor, status and identification.

Integration notes: KMB systems SMC / SMY / SMZ / ARTIQ power analysers (Modbus manual v4.0)

Integration in brief

Read input registers (function 04) from 19000 for 27 floats: phase and line voltages, currents, P/Q/S per phase and total, CosPhi, frequency and phase order. Use function 03 on the same block if you want the averaged values.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP is on by default on Ethernet models (port 502, configurable with the TCP/IP settings). For RS-485 set the device address, baud rate and parity in the instrument (see its user manual); Modbus RTU is detected automatically.

Byte order & addressing

  • Addresses are 0-based PDU addresses.
  • Function 03 and 04 on the same address return average vs actual values.
  • Floats are big-endian.

Network setup

  • Device address 1-248 (0 and 249-255 reserved).
  • At least three Modbus TCP masters can connect at once; each must wait for a reply before the next request.

Watch out for

  • Multi-feeder devices answer feeder 2-12 data on extra Modbus addresses, not extra registers.
  • The instrument replies within 200 ms; set master timeouts accordingly.

Notes on this map

  • Encoding (2.3): multi-byte values are big-endian and 32/64-bit values run MSB to LSB across consecutive registers, so floats are ABCD. The modpoll example reads voltages around 236 V as big-endian floats.
  • Function 04 (input registers) returns actual 200 ms values; function 03 (holding registers) on the same addresses returns the averaged values set up in the instrument. Registers are listed here as input registers.
  • Left out: the energy rows of the 19000 block (19054-19108). Their unit column says Wh / VAh / varh while the block's introduction says the registers give total kWh/kvarh counts, so the unit is ambiguous. The 0x2000 energy block (64-bit doubles) has no unit stated, so it is left out as well.
  • Left out: the device number (528, printed only as '32b' with no signed/unsigned type), the detailed actual-data blocks 0x1100-0x13xx (no units printed), harmonics, archives, aggregated min/max blocks, RCM, PQ and NOVAR power-factor-controller registers, and the configuration/reset blocks.
  • Multi-feeder instruments use the device address for feeder 1 and mirror the map for feeders 2-12 at address (X-1) x 20 + base address; their base address is limited to 1-20.
  • Over RS-485 the device recognises Modbus RTU and KMB's own protocol automatically. The manual says KMB devices default to no parity; device address and baud must be set per the user manual.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the KMB systems SMC / SMY / SMZ / ARTIQ power analysers (Modbus manual v4.0)

What Modbus registers does the KMB systems SMC / SMY / SMZ / ARTIQ power analysers (Modbus manual v4.0) have?

This map lists 41 registers: 41 input registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the KMB systems SMC / SMY / SMZ / ARTIQ power analysers (Modbus manual v4.0) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed in decimal and hex as PDU (wire) addresses. The manual's modpoll examples use the -0 switch ('Modbus PDU addressing') with -r 528 for the device number and -r 4352 for the voltages, and a footnote says that without -0 every address would need +1.

What byte order does the KMB systems SMC / SMY / SMZ / ARTIQ power analysers (Modbus manual v4.0) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the KMB systems SMC / SMY / SMZ / ARTIQ power analysers (Modbus manual v4.0)?

Start with IR 19000 Voltage L1-N (Voltage L1-N); IR 19012 Current L1 (Current L1); IR 19026 Active power total (Total active power); IR 19034 Apparent power total (Total apparent power); IR 19050 Frequency (Frequency); IR 4864 Power factor total (Total power factor); IR 4097 Error code (Instrument error flags (0 = OK)).

How do I enable Modbus control of the KMB systems SMC / SMY / SMZ / ARTIQ power analysers (Modbus manual v4.0)?

Modbus TCP is on by default on Ethernet models (port 502, configurable with the TCP/IP settings). For RS-485 set the device address, baud rate and parity in the instrument (see its user manual); Modbus RTU is detected automatically.
