Short answer

Integration notes: Trane Series R RTHD water-cooled helical-rotary chiller (Symbio 800)

Integration in brief

Read the analog inputs as pairs of input registers (float, high word first) and the binary/multi-state points as single registers. Write the BAS setpoints and command points in the 4xxxx holding range.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

On the Symbio 800 web interface go to Installation > Identification and Communications > Protocol Configuration and select Modbus RTU or Modbus TCP (per Trane's Symbio 800 integration guides).

Byte order & addressing

  • Analog values are 32-bit floats occupying two registers; read both registers in one request.
  • 0xFFFF in a binary or multi-state register and NaN in an analog register mean the value is invalid or not present.

Network setup

  • The Modbus RTU address comes from the controller's rotary dials (1-247); address 000 disables Modbus RTU.
  • Modbus TCP uses Ethernet port 2; the rotary address is ignored for TCP.

Watch out for

  • Points not supported by the unit's configuration are absent; confirm the configuration dependencies before mapping.

Notes on this map

  • Register format table: analog points are 32-bit floats sent high word / high byte first (NaN = invalid); binary and multi-state points are unsigned 16-bit integers (0xFFFF = invalid).
  • Values are sent in the unit system ordered from the factory (I-P is the usual default, SI optional); the list names only the quantity, so temperature/pressure/flow units are left blank here.
  • Not every point exists on every unit: the controller builds its point set from the unit's configuration. Descriptions name the configuration a point depends on.
  • Register numbers are printed in 5-digit Modicon form (3xxxx input registers, 4xxxx holding registers) and converted here to wire addresses (30011 = input register 10).
  • Controller setup and the I-P/SI units statement come from Trane's Symbio 800 integration guide BAS-SVP047B-EN (Sept 2023, https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Integration/BAS-SVP047B-EN_09092023.pdf), which describes the same Symbio 800 controller.
  • Page 37 of the list, headed Modbus Binary Values, repeats the binary inputs 33011-33032; it is ignored here and the binary values are taken from page 38 (43011-43016).
  • Some Binary Value states are printed with text copied from other points (Base Loading Request '1 = Reduce Noise', pump requests '1 = Locked Out'); they are copied as printed.
  • The list skips 30109.
  • Trane publishes a separate points list for the older UC800 controller on the RTHD (BAS-PTS034A-EN); that register set is not this one.
  • Condenser/Evaporator Water Pump Request and Condenser Water Flow Status (33026-33028) are printed with the states 0 = Normal / 1 = In Alarm; copied as printed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Trane Series R RTHD water-cooled helical-rotary chiller (Symbio 800)

What Modbus registers does the Trane Series R RTHD water-cooled helical-rotary chiller (Symbio 800) have?

This map lists 275 registers: 263 input registers, 12 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Trane Series R RTHD water-cooled helical-rotary chiller (Symbio 800) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The list prints Modicon register numbers: 3xxxx are input registers and 4xxxx holding registers, so 30011 is input register address 10 and 42011 is holding register address 2010.

What byte order does the Trane Series R RTHD water-cooled helical-rotary chiller (Symbio 800) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Trane Series R RTHD water-cooled helical-rotary chiller (Symbio 800)?

Start with IR 10 Active Cool/Heat Setpoint Temperature (Active cool/heat setpoint); IR 18 Evaporator Leaving Water Temperature (Evaporator leaving water temperature); IR 16 Evaporator Entering Water Temperature (Evaporator entering water temperature); IR 26 Actual Running Capacity (Actual running capacity); IR 2010 Running Mode (Running mode); IR 3010 Run Enabled (Run enabled); IR 3016 Diagnostic Present (Diagnostic present); HR 10 Chilled Water Setpoint (Chilled water setpoint (BAS)); HR 2010 Chiller Mode Command BAS (BAS chiller mode command); HR 3010 Chiller Auto Stop Command BAS (Chiller auto/stop command); HR 3011 Reset Diagnostic (Reset diagnostic).

How do I enable Modbus control of the Trane Series R RTHD water-cooled helical-rotary chiller (Symbio 800)?

On the Symbio 800 web interface go to Installation > Identification and Communications > Protocol Configuration and select Modbus RTU or Modbus TCP (per Trane's Symbio 800 integration guides).

The source is Symbio 800 Integration Points List, BACnet/Modbus, Series R Model RTHD (BAS-PTS015A-EN), revision 2024-11-15, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Points%20List/BAS-PTS015A-EN_11152024.pdf.
