Short answer

The R-SG3 is a Seneca R-series converter for 4- or 6-wire strain-gauge load cells with two digital outputs. It serves Modbus TCP on one Ethernet port and Modbus RTU as a slave. This map covers net/gross/tare weight, status, the command register used for tare and calibration, thresholds and filter setup.

Integration notes: Seneca R-SG3 Ethernet load cell converter

Integration in brief

Poll net weight (63) and status (77); bit 4 of status says the weight is stable. Tare and calibration are done by writing codes to the command register at 79.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP and RTU are active by default; network settings are changed in the web server or Seneca's discovery tool. DIP switches 1-2 select normal operation, factory reset or web server disabled.

Byte order & addressing

  • Offsets are the wire addresses.
  • Floats are MSW first.
  • Bits 5-6 of the status register only drive the outputs when the output mode is 'from Modbus' (40033).

Network setup

  • Factory IP is 192.168.90.101; change it before adding a second unit.
  • Field tare: write 49914 to the command register with the empty platform loaded.

Watch out for

  • Tare taken with code 49594 lives in RAM and is lost at reboot; use 49914 to store it in flash.
  • Output mode codes in 40033 bits 8-11 (DO1) and 12-15 (DO2): 0 full scale, 1 threshold, 2 stable weight, 3 from Modbus, 4 threshold with hysteresis.
  • Filter level 7 hands control to the advanced filter registers.

Notes on this map

  • Every 32-bit row in the R-SG3 table marks the first register MSW and the second LSW, so the map uses ABCD.
  • Weight values are IEEE floats in the unit chosen at 40003.
  • Left out: the signed 32-bit integer weights (40070-40075), because the manual does not say how they are scaled; the analog output settings 40005 and 40022-40029, which apply to the Z-SG3 / ZE-SG3 only; the digital input register 40006, whose text is cut off in the table; reserved and password registers.
  • Factory settings in the R-SG3 web-server chapter: static IP 192.168.90.101, Modbus TCP port 502, RTU station address 1, 38400 baud, no parity, 1 stop bit (data bits are not listed for this model).
  • RW* registers live in flash and tolerate about 10,000 writes.
  • Left out: the raw 24-bit ADC readings (40092-40095), which are typed unsigned 32-bit but carry no MSW/LSW marking.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Seneca R-SG3 Ethernet load cell converter

What Modbus registers does the Seneca R-SG3 Ethernet load cell converter have?

This map lists 34 registers: 34 holding registers. 25 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seneca R-SG3 Ethernet load cell converter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The R-SG3 table prints the 4x number (40001) and a 0-based offset (0) on every row; the manual's numbering chapter says the offset is the 0-based address to put on the wire.

What byte order does the Seneca R-SG3 Ethernet load cell converter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Seneca R-SG3 Ethernet load cell converter?

Start with HR 63 Net weight (Net weight); HR 65 Gross weight (Gross weight); HR 67 Tare weight (Tare weight); HR 77 Status (Status (stable, full scale, negative)); HR 79 Command (Command register (tare, reboot)); HR 2 Measurement unit (Engineering unit in use).

How do I enable Modbus control of the Seneca R-SG3 Ethernet load cell converter?

Modbus TCP and RTU are active by default; network settings are changed in the web server or Seneca's discovery tool. DIP switches 1-2 select normal operation, factory reset or web server disabled.

Where is the official Seneca R-SG3 Ethernet load cell converter Modbus documentation?

The source is Series R I/O with protocol - User Manual (MI-00604-29-EN), revision 2026-09-03, published free by Seneca at https://www.seneca.it/media/6848135/mi00604-29-en.pdf.
