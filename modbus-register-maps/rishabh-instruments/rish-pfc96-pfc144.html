Rishabh Instruments RISH PFC 96 / PFC 144 automatic power factor controller Modbus register map

Updated 19 November 2026

Short answer

The RISH PFC 96 and PFC 144 are panel automatic power factor controllers that switch up to 12 capacitor banks while metering the line. Their RS-485 port speaks Modbus RTU and every value is an IEEE 754 float in two registers. This map covers the metering, demand, energy, max/min, THD, run-hour and per-bank kvar and switching-count registers (30001-30317) plus the main controller and communication settings.

This page lists 144 Modbus registers for the Rishabh Instruments RISH PFC 96 / PFC 144 automatic power factor controller — 33 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Rishabh Instruments’s own free documentation (linked below) and checked against it.

Integration notes: Rishabh Instruments RISH PFC 96 / PFC 144 automatic power factor controller

Integration in brief

Read 30001-30038 and 30071-30108 with FC04 for line values, demand and energy, and 30245-30317 for bank data, decoding each register pair as a big-endian float. Controller settings are floats in the 4X area written with FC16.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the RS-485 address and baud/parity in the controller's communication menu or via 40021/40019.

Byte order & addressing

  • Reading or writing half a float returns exception 02.
  • Settings marked WP are write-protected: send the basic password (40071) or, for advanced settings, the advanced password (40205) first if one is set.

Network setup

  • Default setup code 5 = 9600 bps, no parity, 2 stop bits; device address 1.

Watch out for

  • Capacitor discharge time (40129) must match the installed capacitors before banks are switched remotely.

Notes on this map

  • The data-format table states IEEE 754 floats, most significant byte first; the line-voltage example returns 43 6E FB 45. ABCD is the default and 40041 can reverse it.
  • Rows whose printed hex start address does not match their register number were left out (30169 and 30171 'old active import energy', and 40235 alarm relay status). The RTC date/time rows (30131, 30133) use a packed two-digit format and are also left out.
  • Left out: individual voltage/current harmonics (30321 onwards), alarm feature/set-point registers (Table 4), RTC set registers and display settings.
  • No unit column is printed, so units are left blank; energy follows 40005 (default kWh).
  • Register names drop the manual's superscript footnote markers (Imp = import, Exp = export, Ind = inductive, Cap = capacitive, OF = overflow).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Rishabh Instruments RISH PFC 96 / PFC 144 automatic power factor controller

What Modbus registers does the Rishabh Instruments RISH PFC 96 / PFC 144 automatic power factor controller have?

This map lists 144 registers: 110 input registers, 34 holding registers. 33 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Rishabh Instruments RISH PFC 96 / PFC 144 automatic power factor controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The interface definition prints 3X/4X numbers next to the hex start address (30001 = 00 00, 30071 = 00 46, 40019 = 00 12). Wire address = number - 30001 (FC04) or - 40001 (FC03/FC16); every row here was checked against its printed hex.

What byte order does the Rishabh Instruments RISH PFC 96 / PFC 144 automatic power factor controller use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Rishabh Instruments RISH PFC 96 / PFC 144 automatic power factor controller?

Start with IR 0 Line Voltage (Line voltage); IR 6 Line Current (Line current); IR 30 Power Factor (Power factor); IR 24 Reactive Power (Reactive power); IR 244 Difference to Power Factor (Difference to target power factor); IR 218 System Voltage THD % (Voltage THD).

How do I enable Modbus control of the Rishabh Instruments RISH PFC 96 / PFC 144 automatic power factor controller?

Set the RS-485 address and baud/parity in the controller's communication menu or via 40021/40019.

Where is the official Rishabh Instruments RISH PFC 96 / PFC 144 automatic power factor controller Modbus documentation?

The source is Power Factor Controller PFC 144 - PFC 96 Interface Definition (Version D), revision 2018-12, published free by Rishabh Instruments at https://rishabh.co.in/uploads/product/rish-pfc-12-228/PFC96_PFC144-Interface_Defination_REV_D1.pdf.
