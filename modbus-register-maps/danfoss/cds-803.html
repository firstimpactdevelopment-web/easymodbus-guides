Danfoss VLT Compressor Drive CDS 803 (Modbus RTU) Modbus register map

Updated 19 November 2026

Short answer

Danfoss's drive for variable-speed refrigeration and air-conditioning compressors. Its RS-485 port runs Modbus RTU: the FC-profile control and status words are coils 1-16 and 33-48, and every parameter is a holding register at ten times its parameter number. This map covers the control/status coils, compressor readouts, fault and warning words, and the communication and timeout parameters.

This page lists 79 Modbus registers for the Danfoss VLT Compressor Drive CDS 803 (Modbus RTU) — 33 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Danfoss’s own free documentation (linked below) and checked against it.

Integration notes: Danfoss VLT Compressor Drive CDS 803 (Modbus RTU)

Integration in brief

Set 8-30 = [2] Modbus RTU plus 8-31 address, 8-32 baud and 8-33 parity, keep 8-02 = FC port, then drive the compressor with the control-word coils (coil 11 data valid, coil 7 start) and read 16-13 frequency, 16-14 current, 16-10 power and 16-90 alarm word.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

8-30 Protocol = [2] Modbus RTU, 8-31 Address (1-247), 8-32 Baud Rate, 8-33 Parity/Stop Bits. 8-01 Control Site chooses digital inputs and/or control word; 8-02 Control Source must be FC Port; 8-50..8-56 decide how bus bits combine with digital inputs (most default to Logic OR).

Communication loss & watchdog

8-03 Control Timeout Time (0.1-200 s, default 20 s) and 8-04 Control Timeout Function (default Off; Freeze output, Stop, Jogging, Max. speed, Stop and trip, N2 override release) act when the control word is not updated in time.

Byte order & addressing

  • Parameter register = parameter number x 10, request address = that minus 1.
  • 32-bit values are high word first (ABCD).
  • CTW bit 10 (coil 11) must be 1 or the control word is ignored.
  • Coil 65 chooses whether parameter writes also go to EEPROM.

Network setup

  • Defaults: address 1, even parity with 1 stop bit; the protocol default is FC, so 8-30 must be changed to Modbus RTU.
  • The guides say the default baud rate depends on the protocol chosen in 8-30 and do not print the Modbus default, so set 8-32 explicitly (2400-115200).

Watch out for

  • Changing 8-30 Protocol may change the baud rate (8-32); re-check it after switching to Modbus.

Notes on this map

  • Parameter data (conversion index, data type) come from VLT Compressor Drive CDS 803 Programming Guide MG18P202, https://files.danfoss.com/download/Drives/MG18P202.pdf. Scale = 10^conversion index; the hour counters carry index 74 (factor 3600, i.e. hours expressed in seconds), so one count is one hour.
  • 32-bit values are high word first: the design guide reads 3-03 at registers 3030/3031 and gets 0016 E360 hex = 1500000 (1500.000 with conversion index -3).
  • 8-bit parameters (Uint8) are read and written as one 16-bit register. 16-34 Heatsink Temp (Int8) is left out because the sign extension in the 16-bit register is not stated.
  • Coils 17-32 (speed reference) and 49-64 (output frequency / feedback) carry 16-bit words bit by bit; they are not listed. REF/MAV use 4000 hex = 100 % of the reference range (two's complement for negative).
  • Alarm, warning and extended status words (16-90..16-94) are listed as raw UINT32; bit meanings are in the programming guide.
  • The two guides cover different software versions (1.20 and 2.0); check 15-43 Software Version on site.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Danfoss VLT Compressor Drive CDS 803 (Modbus RTU)

What Modbus registers does the Danfoss VLT Compressor Drive CDS 803 (Modbus RTU) have?

This map lists 79 registers: 28 coils, 51 holding registers. 33 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Danfoss VLT Compressor Drive CDS 803 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers derived from parameter numbers. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The design guide states coil 1 is sent as 0000 and holding register 40001 as 0000. A parameter's register is 10 x its parameter number (3-03 -> 3030), sent minus 1: the guide's example reads 3-03 at start address 0x0BD5 (3029). Coils are 1-based too (coil 65 is sent as 64).

What byte order does the Danfoss VLT Compressor Drive CDS 803 (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Danfoss VLT Compressor Drive CDS 803 (Modbus RTU)?

Start with CO 6 CTW bit 6: Ramp stop / start (CTW bit 6: ramp stop / start); CO 10 CTW bit 10: Data valid (CTW bit 10: data valid); CO 43 STW bit 11: Running (STW: running); HR 16129 16-13 Frequency (16-13 Frequency, 0.1 Hz); HR 16139 16-14 Motor current (16-14 Motor current, 0.01 A); HR 16099 16-10 Power [kW] (16-10 Power, 0.001 kW); HR 16899 16-90 Alarm Word (16-90 Alarm word).

How do I enable Modbus control of the Danfoss VLT Compressor Drive CDS 803 (Modbus RTU)?

8-30 Protocol = [2] Modbus RTU, 8-31 Address (1-247), 8-32 Baud Rate, 8-33 Parity/Stop Bits. 8-01 Control Site chooses digital inputs and/or control word; 8-02 Control Source must be FC Port; 8-50..8-56 decide how bus bits combine with digital inputs (most default to Logic OR).

What happens when the Danfoss VLT Compressor Drive CDS 803 (Modbus RTU) loses Modbus communication?

8-03 Control Timeout Time (0.1-200 s, default 20 s) and 8-04 Control Timeout Function (default Off; Freeze output, Stop, Jogging, Max. speed, Stop and trip, N2 override release) act when the control word is not updated in time.
