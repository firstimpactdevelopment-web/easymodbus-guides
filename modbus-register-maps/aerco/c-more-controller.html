AERCO C-More Boiler Controller (Benchmark / KC series) Modbus register map

Updated 16 October 2026

Short answer

The C-More controller on AERCO Benchmark and KC Series units is a Modbus RTU slave on RS-485, normally driven by an AERCO BMS/ACS or a third-party EMS. A master can monitor temperatures, firing rate, flame strength, run hours and status messages, and can control the unit either by writing a network setpoint (Remote Setpoint mode) or a firing rate (Direct Drive mode). Temperatures are transferred as 0-1000 counts that must be converted with AERCO's equations.

This page lists 57 Modbus registers for the AERCO C-More Boiler Controller (Benchmark / KC series) — 34 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from AERCO’s own free documentation (linked below) and checked against it.

Integration notes: AERCO C-More Boiler Controller (Benchmark / KC series)

Integration in brief

Give the C-More a Comm Address (1-127) in its Setup menu, set Boiler Mode to Remote Setpoint or Direct Drive and Remote Signal to Network, then write holding register 0 (setpoint counts) or 1 (fire rate %) at least every 10 seconds. Read input registers 1-16 for status, temperatures, fire rate and run hours.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Setup menu: Comm Address 1-127 (0, the default, disables Modbus). Configuration menu: Boiler Mode = Direct Drive or Remote Setpoint and Remote Signal = Network. Changing settings needs the right password level; register 2 holds the Modbus-port password and writes to protected registers fail with exception 02 until it matches.

Communication loss & watchdog

Fixed 10 s heartbeat: each received Net Direct Drive or Net Remote Setpoint write resets it. If it expires the controller shows MODBUS COMM FAULT and falls back to the Failsafe Mode in holding register 24 (Shutdown or Constant Setpoint).

Byte order & addressing

  • Temperatures are 0-1000 counts that need AERCO's conversion equations; they are not tenths of a degree.
  • Function code 16 (write multiple registers) is not supported and returns Illegal Function; write one register at a time with function 06.
  • A multi-register read (FC03/FC04) that includes any register the current password level cannot access fails as a whole with Illegal Data Address.
  • 32-bit counters are low word first.

Network setup

  • RS-485 2-wire with shield, RTU only, fixed 9600 baud on the C-More; up to 127 slaves (32 when driven by a BMS/ACS).
  • Terminate and bias only the last C-More on the bus: TERM, BIAS1 and BIAS2 DIP switches on the PMC board behind the front panel; that unit must stay powered for bias.
  • Address 0 is broadcast; a broadcast Net Direct Drive or Net Remote Setpoint sets all enabled slaves at once.

Watch out for

  • Do not write to registers marked Reserved.
  • Front-panel, RS-232 and Modbus changes are not interlocked; the last write wins.
  • AERCO recommends enabling Set Point Limiting and choosing the Failsafe Mode before handing control to Modbus.

Notes on this map

  • Temperature registers are raw counts (0-1000), not degrees, and are listed with scale 1 and units 'counts'. AERCO Table A-3 converts them with integer (floor) brackets: DEGREES_1 °F = floor((counts x 230 + 500) / 1000) + 20; DEGREES_2 °F = floor((counts x 330 + 500) / 1000) - 80; DEGREES_3 °F = floor((counts x 520 + 500) / 1000) + 40 (Celsius versions: x128 - 7, x183 - 62, x289 - 4). Because the result is rounded to whole degrees the conversion is a step function, not an exact scale/offset, so it is not encoded as one. Table A-4 gives the reverse (degrees to counts) for writes, e.g. DEGREES_1 counts = floor(((°F - 20) x 1000 + 115) / 230).
  • ABS_DEG_1 registers (prop band, min/max load adjust, setpoint limit band) are temperature differences in counts (published range 0-1000): °F = floor((counts x 230 + 500) / 1000) for counts >= 0 and floor((counts x 230 - 500) / 1000) for counts < 0. They are typed INT16 because the manual gives a negative-count formula; within the published range INT16 and UINT16 read the same.
  • Exhaust Temp (input 6) is printed as DEGREES_2 while Sensor Log Exhaust Temp (input 32, not listed) is DEGREES_3; check the conversion on site.
  • 32-bit counters (run cycles, run hours, fault-log cycle) are stored low word first (low word at the lower address), hence CDAB. The high word only ranges 0-15.
  • The Unit Status / message code list is Table A-2 in the manual even though the register table points to Table A-1.
  • Left out: reserved registers, the sensor-log and time-log history registers (28-43), the log pointers (68-70) and all BMS/BMS II/ACS registers (a separate controller covered in the same manual).

Questions about the AERCO C-More Boiler Controller (Benchmark / KC series)

What Modbus registers does the AERCO C-More Boiler Controller (Benchmark / KC series) have?

This map lists 57 registers: 23 input registers, 34 holding registers. 34 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the AERCO C-More Boiler Controller (Benchmark / KC series) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists generic Modbus data addresses in decimal and hex (e.g. Outlet Temp 2 (0x0002)) and states that BAS tools using 30001/40001 notation add 30001/40001 to them. The listed number is the wire address.

What byte order does the AERCO C-More Boiler Controller (Benchmark / KC series) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the AERCO C-More Boiler Controller (Benchmark / KC series)?

Start with HR 0 Net Remote Set Point (Network setpoint (Remote Setpoint mode)); HR 1 Net Direct Drive (Network fire rate (Direct Drive mode)); HR 12 Boiler Mode (Boiler mode); IR 1 Unit Status (Unit status); IR 2 Outlet Temp (Outlet temperature); IR 8 Fire Rate Out (Fire rate out); IR 15 Flame Strength (Flame strength); IR 0 Default Message Display Code (Status / fault message code).

How do I enable Modbus control of the AERCO C-More Boiler Controller (Benchmark / KC series)?

What happens when the AERCO C-More Boiler Controller (Benchmark / KC series) loses Modbus communication?
