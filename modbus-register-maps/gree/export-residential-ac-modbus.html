Short answer

On these Gree residential units the Modbus RTU slave lives in the indoor-unit controller or wired controller, so no extra module is needed. Holding registers carry on/off, mode, fan speed, setpoint, louvres, sleep and energy-saving limits plus indoor, return-air and outdoor temperatures; coils carry feature flags, locks and a long list of indoor, outdoor and inverter-drive fault bits. Up to 255 units can share one BMS line.

Integration notes: Gree Export residential split air conditioners (built-in Modbus on indoor unit / wired controller)

Integration in brief

Poll words 2-25 for on/off, mode, fan, setpoint and louvres and words 4, 49 and 82 for temperatures; read coils 17-236 for status and fault bits. Write word 2 (0xAA on / 0x55 off), 17, 19 and 20 to control the unit.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The Modbus interface is built into the indoor-unit controller or wired controller; each unit needs its own address (1-255) set before connecting the BMS. Power-cycle the unit after connecting the controller.

Byte order & addressing

  • On/off uses 0xAA and 0x55, not 1 and 0.
  • The two energy-saving flags (bits 32 and 33) must be set or cleared together.
  • A setpoint outside the active energy-saving limit is silently ignored; check by reading back.
  • Exception code 03 is returned for an out-of-range read (for example 128 words; the maximum is 127 per request).

Network setup

  • RS485, 9600 baud, 8 data bits, no parity, 1 stop bit.
  • Use twisted pair kept at least 15 cm from power cables; repeaters may be needed on long lines.
  • Match A to A and B to B; a constantly lit TX lamp on the converter points to swapped A/B.

Watch out for

  • Sleep is ignored in fan and auto modes.
  • The remote temperature shield is ignored in auto mode unless the unit allows setpoint adjustment in auto (bit 75).
  • Heating commands to cooling-only units (bit 177 = 1) do nothing.

Notes on this map

  • Gree does not host this protocol publicly; the link is the unaltered Gree PDF in the product-document store of the Finnish wholesaler Onninen (Kesko). No document number is printed; the date is the PDF creation date.
  • Registers are read with function 03 and written with 16; coils are read with 01 and written with 15. Points marked R in the table are read-only.
  • Only named points are listed; reserved words and bits are left out. Bits 237-239 have no name in the table and are left out.
  • Mode and swing values are printed in binary in the source (for example 001 = cooling, 1011 = swing positions 1-3); they are given here as decimal.
  • Left/right swing value 1100 (12) is printed only as '15 position'; the manual does not explain it, so the label is kept as printed.
  • The outdoor-ambient range is printed as -100 to 155 in whole degrees and is listed as a signed 16-bit value as the table states.
  • Several fault and status bits apply only to units that have that function (fresh-air valve, gate control, card switch, DRED).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Gree Export residential split air conditioners (built-in Modbus on indoor unit / wired controller)

What Modbus registers does the Gree Export residential split air conditioners (built-in Modbus on indoor unit / wired controller) have?

This map lists 113 registers: 97 coils, 16 holding registers. 28 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Gree Export residential split air conditioners (built-in Modbus on indoor unit / wired controller) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are words numbered from 0 and coils are bits numbered from 0 (Bit0 = Byte0.0). Word n is wire address n and Bit n is coil n. The example frames agree: reading ten bits from coil 5 sends start address 00 05, and reading two words from address 1 sends 00 01.

What are the minimum Modbus registers to integrate the Gree Export residential split air conditioners (built-in Modbus on indoor unit / wired controller)?

Start with HR 2 Unit On/Off (On/off); HR 17 Set mode (Mode); HR 19 Set fan speed (Fan speed); HR 20 Set temperature (Setpoint); HR 4 Ambient temperature (Room temperature); HR 49 Outdoor ambient temperature (Outdoor temperature); CO 151 Compressor status (Compressor running); CO 122 Communication failure with outdoor unit (Outdoor-unit communication fault).

How do I enable Modbus control of the Gree Export residential split air conditioners (built-in Modbus on indoor unit / wired controller)?

The Modbus interface is built into the indoor-unit controller or wired controller; each unit needs its own address (1-255) set before connecting the BMS. Power-cycle the unit after connecting the controller.
