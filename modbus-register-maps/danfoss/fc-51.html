Short answer

Danfoss's smallest VLT drive with Modbus RTU on the RS-485 terminals. Control and status run through coils (control word bits at coils 1-16, status bits at coils 33-48), and every parameter is a holding register at 10 x its parameter number. Integration notes: Danfoss VLT Micro Drive FC 51 (Modbus RTU)

Integration in brief

Set 8-30 = Modbus, 8-31 address, 8-32/8-33 baud and parity, keep 8-02 = FC RS485, then drive the unit with coils 1-16 (write coils 3, 4, 5, 7 and 11 = 1 to run) and the reference on coils 17-32. Read coils 33-48 for status and holding registers 16130/16140 for frequency and current.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set 8-30 Protocol = [2] Modbus RTU (takes effect only after the drive is powered off and on), 8-31 Address (1-247, factory 1), 8-32 baud (19200 is the default once Modbus is chosen) and 8-33 parity (factory even, 1 stop bit). 8-02 must stay [1] FC RS485 and 8-01 Control Site decides whether terminals, the control word or both act; 8-50 to 8-56 (factory Logic OR) set how bus and terminal commands combine.

Communication loss & watchdog

8-03 Control Word Timeout Time (0.1-6500 s, factory 1.0 s) with 8-04 Control Word Timeout Function: Off (factory), Freeze output, Stop, Jogging, Max. speed, or Stop and trip.

Byte order & addressing

  • Parameter register = 10 x parameter number, wire address = that minus 1 (16-13 -> 16129).
  • Control word bits are active-low for stops: coils 3-5 must be 1 (no DC brake, no coast, no quick stop) and coil 7 = 1 starts.
  • Coil 11 (data valid) must be 1 or the control word is ignored.

Network setup

  • Coil 65 = 1 makes parameter writes go to EEPROM as well as RAM; leave it 0 for cyclic writes.
  • Array parameters need holding register 9 (IND) set to the index first.

Watch out for

  • With factory 8-04 = Off the drive keeps running if the master stops polling.
  • Holding registers 50000-50210 (and 2810-2911) are described in the design guide alongside an instruction to set 8-30 = FC; use the coils for Modbus control.

Notes on this map

  • Parameter data (type, conversion index, defaults, option lists) come from the VLT Micro Drive FC 51 Programming Guide MG02C702 (12/2014, software 3.1x), https://assets.danfoss.com/documents/273489/AU361182403098en-000901.pdf, section 5.2 parameter lists. Conversion index -1 = x0.1, -2 = x0.01, -3 = x0.001, 0 = x1.
  • Left out: all 32-bit parameters (3-02, 3-03, 3-41, 3-42, 15-00 to 15-03, 16-01, 16-52, 16-90, 16-92, 16-94). The FC 51 guides only say they take 2 registers; the design guide's generic examples are inconsistent (3-14 at 3410, and a 3-03 read whose bytes 00 16 E3 60 are described as 000088B8 = 35 Hz), and Danfoss's general Modbus RTU instructions MG92B102 are written for software 6.4x and do not name the FC 51, so the word order is not settled for this drive.
  • The design guide's 32-bit example names 3-14 at registers 3410/3411; by the x10 rule 3-14 is register 3140, and the programming guide types 3-14 as Int16. Treat that example as a typo.
  • Uint8 parameters are read and written as one 16-bit register.
  • Section 8.11 lists CTW/REF at holding registers 50000/50010 and STW/MAV at 50200/50210 (and, from software 2.32, 2810/2811 and 2910/2911), but the same section says to set 8-30 = [0] FC, so their use with Modbus is unclear and they are not listed. Coils 1-16 carry the control word, 17-32 the bus reference (16-bit, 0x0-0xFFFF = -200 %..~200 %), 33-48 the status word and 49-64 output frequency (open loop) or feedback (closed loop); the reference and actual-value coil groups are not listed bit by bit.
  • Coil 15 (control word bit 14) is unused in the FC profile table and is not listed; status coils 37-39 and 45 are 'not used'.
  • Alarm and warning words (16-90/16-92) are 32-bit and left out for the word-order reason above; use status coil 36 (alarm) and 40 (warning) instead.
  • Left out: 16-05 and 16-15 (normalised percentages), 16-50/16-51 external and pulse references, text parameters (15-4x), the fault log arrays (15-30, need IND) and Smart Logic groups.

Questions about the Danfoss VLT Micro Drive FC 51 (Modbus RTU)

What Modbus registers does the Danfoss VLT Micro Drive FC 51 (Modbus RTU) have?

This map lists 60 registers: 28 coils, 32 holding registers. 28 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Danfoss VLT Micro Drive FC 51 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers derived from parameter numbers. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The design guide says Modbus addresses are referenced to 0: coil 1 is coil 0 on the wire and holding register 40001 is register 0. A parameter's register number is 10 x its parameter number (16-13 -> 16130; 3-12 is read in holding register 3120) and the request carries that number minus 1 (16-13 at address 16129). Coil n is address n - 1.

What are the minimum Modbus registers to integrate the Danfoss VLT Micro Drive FC 51 (Modbus RTU)?

Start with CO 6 CTW bit 6: ramp stop / start (Start (1) / ramp stop (0)); CO 10 CTW bit 10: data valid (Data valid - must be 1); CO 43 STW bit 11: running (Running status); CO 35 STW bit 3: alarm (Alarm status); CO 39 STW bit 7: warning (Warning status); HR 16129 16-13 Frequency (16-13 Frequency, 0.1 Hz); HR 16139 16-14 Motor Current (16-14 Motor current, 0.01 A); HR 8299 8-30 Protocol (8-30 Protocol).

How do I enable Modbus control of the Danfoss VLT Micro Drive FC 51 (Modbus RTU)?

Set 8-30 Protocol = [2] Modbus RTU (takes effect only after the drive is powered off and on), 8-31 Address (1-247, factory 1), 8-32 baud (19200 is the default once Modbus is chosen) and 8-33 parity (factory even, 1 stop bit). 8-02 must stay [1] FC RS485 and 8-01 Control Site decides whether terminals, the control word or both act; 8-50 to 8-56 (factory Logic OR) set how bus and terminal commands combine.

What happens when the Danfoss VLT Micro Drive FC 51 (Modbus RTU) loses Modbus communication?

8-03 Control Word Timeout Time (0.1-6500 s, factory 1.0 s) with 8-04 Control Word Timeout Function: Off (factory), Freeze output, Stop, Jogging, Max. speed, or Stop and trip.
