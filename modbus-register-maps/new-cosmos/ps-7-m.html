Short answer

The New Cosmos PS-7-M is a pump-type fixed gas detector whose base unit has RS-485 Modbus RTU and Ethernet Modbus TCP ports. All data are 16-bit holding registers: current gas concentration, full-scale code, a packed device status word with alarm and fault flags, alarm settings, test and maintenance mode controls and identity data. This map covers the main published registers.

Integration notes: New Cosmos Electric PS-7-M series extractive pump gas detector (Modbus RTU / TCP)

Integration in brief

Read 41039-41040 for concentration and full-scale code and 40516 for alarms and faults; check 40011 once for the unit. Write AL set values and modes at 40051-40055 when needed.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Turn the base unit power switch OFF, select RS485 or ETHERNET with the mode DIP switch and set the unit ID on the address DIP switches (binary, 1-254), then switch the power back on.

Byte order & addressing

  • Concentration has no sign in the register itself; read status bit 15.
  • Use relative (0-based) addresses on the wire: 41039 -> 1038.

Network setup

  • RS-485: up to 32 devices, 1.2 km at 9600 baud, built-in 120 ohm terminator switchable.
  • Modbus TCP: fixed port 502.

Watch out for

  • Reading or writing at 41321 and above returns an illegal address error.

Notes on this map

  • The guide is a New Cosmos document hosted by the US distributor DOD Technologies; New Cosmos does not offer it as a public download.
  • All registers are single 16-bit words. Strings carry two ASCII characters per register, first character in the high byte.
  • Gas concentration (41039) is an unsigned magnitude; status bit 15 (bit 7 of status byte 1) gives the sign (manual example: 5 with the sign bit set = -5 %). Its unit comes from register 40011 and its full scale from the F.S. code at 41040.
  • Device status 40516: status byte 1 is the high byte and status byte 2 the low byte (manual example 0x0302 = AL1 and AL2 active while in maintenance mode 2).
  • Left out: f-value and calibration gas code (ASCII), linear table X/Y pairs (two 8-bit values per register), 41284 Modbus setting change permit (meaning of the value not given), and the IP address/mask/gateway registers 41291-41299.
  • RS-485 settings are fixed: 9600 baud, 8 data bits, no parity, 1 stop bit. The unit ID (1-254) is set on DIP switches and is also the last octet of the IP address for Modbus TCP.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the New Cosmos Electric PS-7-M series extractive pump gas detector (Modbus RTU / TCP)

What Modbus registers does the New Cosmos Electric PS-7-M series extractive pump gas detector (Modbus RTU / TCP) have?

This map lists 30 registers: 30 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the New Cosmos Electric PS-7-M series extractive pump gas detector (Modbus RTU / TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table gives each register as a Modicon number (40001-41321) plus a relative address in hex that goes on the wire: 40001 = relative 0, 41039 = relative 0x40E (1038). The manual's examples read 41039 at relative address 1038.

What are the minimum Modbus registers to integrate the New Cosmos Electric PS-7-M series extractive pump gas detector (Modbus RTU / TCP)?

Start with HR 1038 Gas concentration (Gas concentration); HR 1039 F.S. code (Full-scale code); HR 515 Device status (Status: alarms, faults, sign); HR 10 Measurement unit code (Measurement unit code); HR 0 Flow rate (Pump flow rate).

How do I enable Modbus control of the New Cosmos Electric PS-7-M series extractive pump gas detector (Modbus RTU / TCP)?

Turn the base unit power switch OFF, select RS485 or ETHERNET with the mode DIP switch and set the unit ID on the address DIP switches (binary, 1-254), then switch the power back on.
