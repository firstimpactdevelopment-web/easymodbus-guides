Short answer

The PAHCMS000 kit connects a third-party air handler to LG Multi V or single-split outdoor units and controls discharge air temperature; a DDC can drive it over Modbus RTU on RS485 CH4. A coil switches the unit, holding registers set mode, capacity request and the cooling and heating discharge targets, and discrete inputs and input registers report unit and per-outdoor-unit (up to 4) run, compressor, defrost and error status, the error code and return/supply air temperatures.

This page lists 27 Modbus registers for the LG PAHCMS000 AHU Communication Kit, discharge-air control (Multi V DX kit, Modbus to DDC) — 5 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from LG’s own free documentation (linked below) and checked against it.

Integration notes: LG PAHCMS000 AHU Communication Kit, discharge-air control (Multi V DX kit, Modbus to DDC)

Integration in brief

With DIP SW1-1 ON (communication), write coil 00001 for on/off and holding registers 40001, 40003 and 40004 for mode and discharge targets; read 30011/30013 for air temperatures and 10001-10026 for unit and outdoor-unit status.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

DIP SW1-1 ON = controlled by DDC through Modbus or an LG central controller (OFF = contact signal, where Modbus control functions are unavailable). SW1-4 ON selects LG central communication over Modbus.

Byte order & addressing

  • Operation mode uses 0 = cooling, 2 = fan, 4 = heating.
  • The error code is a decimal number whose second digit is the module number.

Network setup

  • DDC central communication on RS485 CH4, 2-core 18-16 AWG, up to 1640 ft.
  • The main module address (1-247, needed with an LG central controller) is set with the Set/ESC buttons and the 7-segment display; the manual does not say whether it is also the Modbus slave ID for a DDC.

Watch out for

  • Control functions are not available when contact-signal control is selected (SW1-1 OFF).

Notes on this map

  • Access follows the function-code dots in the memory map: coil 00001 takes 01 and 05, discrete inputs 02 only, input registers 04 only, holding registers 03 and 06.
  • Reserved points are left out.
  • The manual does not print the RS485 serial settings for the DDC port; set them to match the kit (the R32 sister kit PAHCMR000 states 9600 bps, no parity, 1 stop bit, but that is a different manual).
  • Temperatures are sent multiplied by 10; the return/supply air range includes negative values, so they are listed as signed 16-bit.
  • For the capacity ratio behind register 40002 see the UI7 (0-10 V) capacity table in the manual.
  • An older revision of this manual (IM_AHU_Comm_Kit_PAHCMS000_5_18) is also hosted by LG.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the LG PAHCMS000 AHU Communication Kit, discharge-air control (Multi V DX kit, Modbus to DDC)

What Modbus registers does the LG PAHCMS000 AHU Communication Kit, discharge-air control (Multi V DX kit, Modbus to DDC) have?

This map lists 27 registers: 1 coil, 19 discrete inputs, 3 input registers, 4 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the LG PAHCMS000 AHU Communication Kit, discharge-air control (Multi V DX kit, Modbus to DDC) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Points are printed as 00001/10001/30001/40001-style registers, with a function-code table per block (01/05 coils 00001-00008, 02 inputs 10001-10030, 04 input registers 30001-30016, 03/06 holding registers 40001-40010). The wire address is the printed number minus the block base: 30011 is input register 10.

What are the minimum Modbus registers to integrate the LG PAHCMS000 AHU Communication Kit, discharge-air control (Multi V DX kit, Modbus to DDC)?

Start with CO 0 Operating On/Off (On/off); HR 0 Operation mode (Operation mode); HR 2 Cooling target temperature (Cooling discharge target); HR 3 Heating target temperature (Heating discharge target); IR 12 Supply air temperature (Supply air temperature); IR 0 Error code (Error code); DI 0 Error status (Error status); DI 2 Defrost status (Defrost status).

How do I enable Modbus control of the LG PAHCMS000 AHU Communication Kit, discharge-air control (Multi V DX kit, Modbus to DDC)?

DIP SW1-1 ON = controlled by DDC through Modbus or an LG central controller (OFF = contact signal, where Modbus control functions are unavailable). SW1-4 ON selects LG central communication over Modbus.
