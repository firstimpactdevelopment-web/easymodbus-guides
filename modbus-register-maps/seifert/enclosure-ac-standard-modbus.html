Seifert Systems Enclosure air conditioners (standard Modbus table) Modbus register map

Updated 17 November 2026

Short answer

Seifert enclosure air conditioners share one Modbus RTU holding-register table across their controller families. Setpoints and temperatures are signed 16-bit values in tenths of a degree, speeds are plain integers, and state, alarm, output and door-contact information are bit fields. Writing the enable-flags register switches the unit from its potentiometer setpoints to network setpoints.

This page lists 29 Modbus registers for the Seifert Systems Enclosure air conditioners (standard Modbus table) — 6 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Seifert Systems’s own free documentation (linked below) and checked against it.

Integration notes: Seifert Systems Enclosure air conditioners (standard Modbus table)

Integration in brief

Poll holding registers 0-27 with function 03. Set bit 0 of register 4 to use network setpoints, then write the setpoints (tenths of a degree) to registers 0-3.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Write register 4 (SET_ENABLE_FLAGS) with bit 0 set using function 06 so the controller uses Modbus setpoints instead of its potentiometers (not available on Carel-controller units).

Byte order & addressing

  • Register 4 cannot be written with function 16 (write multiple); use function 06.
  • Setting any undocumented bit in register 4 returns exception 03.

Network setup

  • Defaults: unit address 1, 19200 baud, 8 data bits, even parity, 1 stop bit.
  • To change the address write 0x0ADD to register 40, then the new address within 10 seconds.

Watch out for

  • Switching the temperature unit changes every temperature register; set it before writing setpoints.

Notes on this map

  • Source host: Seifert does not publish this table on its own site; the copy used is the Seifert document hosted by distributor AutomationDirect.
  • Every register is 16-bit. S = signed, U = unsigned; a factor of 10 means the raw value is tenths (send 315 for 31.5).
  • Temperatures are in Celsius unless EN_TEMP_UNIT (bit 11 of register 4) selects Fahrenheit, which changes both the Modbus values and the display.
  • The document has a per-register availability chart for Unit A (Carel controller), Unit B (Variable Speed controller) and Unit C (Seifert Standard controller); check it, as not every register exists on every unit.
  • Address 0xFF is a broadcast address the unit always answers; 0x00 and 0xFF cannot be set as the unit address.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Seifert Systems Enclosure air conditioners (standard Modbus table)

What Modbus registers does the Seifert Systems Enclosure air conditioners (standard Modbus table) have?

This map lists 29 registers: 29 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seifert Systems Enclosure air conditioners (standard Modbus table) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table numbers registers from 0 (cooling setpoint) to 27, plus 40 for the address register. A register numbered 0 can only be a protocol address, so the printed numbers are used as wire addresses.

What are the minimum Modbus registers to integrate the Seifert Systems Enclosure air conditioners (standard Modbus table)?

Start with HR 12 READ_CONTROL_SENSOR (Internal (control) temperature); HR 13 READ_STATE (Operating state); HR 14 READ_ALARM_STATUS (Alarm bits); HR 15 READ_OUTPUT_STATUS (Output status); HR 16 READ_CONTACT_STATUS (Door contacts); HR 0 SET_NETWORK_COOLING_SETPOINT (Network cooling setpoint); HR 4 SET_ENABLE_FLAGS (Enable flags (network setpoints)).

How do I enable Modbus control of the Seifert Systems Enclosure air conditioners (standard Modbus table)?

Write register 4 (SET_ENABLE_FLAGS) with bit 0 set using function 06 so the controller uses Modbus setpoints instead of its potentiometers (not available on Carel-controller units).

Where is the official Seifert Systems Enclosure air conditioners (standard Modbus table) Modbus documentation?
