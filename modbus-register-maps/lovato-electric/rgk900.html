Short answer

The RGK900 is one of Lovato's RGK genset controllers. It answers Modbus RTU and ASCII on its serial ports and Modbus TCP through the EXP1013 Ethernet module, and all measurements are 32-bit values read with function 04 (or 03). This map lists the electrical measurements, engine values, hour and start counters and energy totals that the protocol document marks for this model.

Integration notes: Lovato Electric RGK900 genset paralleling controller

Integration in brief

Read the 32-bit measures with function 04 (or 03), two registers each, high word first, at the table address minus one. Mode bits are in the 0F98H status copy.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the communication port (built-in serial or optical port, or an EXP expansion module) in the device setup menu; see the RGK instruction manual for the menu.

Byte order & addressing

  • Request one less than the printed hex address (0024H -> 0x0023).
  • At most 80 registers per request.

Network setup

  • Serial address, baud rate and protocol (RTU/ASCII) are set in the communication menu of the controller.

Watch out for

  • Powers are in W, var and VA with two decimals, not kW.

Notes on this map

  • Word order: the document's function 04 example decodes the reply 00 01 8D C0 as 101824, so the high word comes first (ABCD).
  • Scaling follows the unit column: V/100 means hundredths of a volt (scale 0.01), A/10000 is 0.0001 A, W/100 is 0.01 W, Hz/1000 is 0.001 Hz, kWh/10 is 0.1 kWh.
  • Only rows the table marks with the normal 'available' symbol for RGK900 are listed. Rows marked with the document's second symbol (no legend given) are left out.
  • Register 0F98H (wire 3991) is listed as a 2-word copy of the function 07 status. Bits 0-3 are OFF/reset, MAN, AUT and TEST mode in both of the document's bit lists; bits 4, 5 and 7 differ between them (function 07 table: error, engine start request, global alarm; 0F98H list on p. 16: alarm, engine running, global output), so the register carries no bit table here.
  • The 32-bit device global status at 2210H/2211H is not listed: it is printed as two 1-word rows, and for several models it carries the document's second symbol, which has no legend.
  • Left out: the per-phase minimum/maximum/average blocks from 0200H upward, the 0800H and 0A00H blocks, input/output/limit/remote-variable bit words (2100H-21D0H), the per-model alarm words (2200H up), GPS data, fuel consumption (mixed l/h or gal/h units), the auxiliary sensor value and the setup parameters (tables 5-8).
  • Left out: the commands table (mode change at 2F00H, key simulation at 2F0AH, remote variables at 4F00H). The address-minus-one rule is stated for reads; the document does not say whether it also applies to these write addresses.
  • Rows labelled 'Mains (Bus)' are the mains-side (or bus-side) measurements, as the document names them.
  • Also left out: counters CNT1-CNT8 (1D00H) and analog inputs/outputs (0F50H-0F6EH), whose units are user-set (UM1-UM8) and whose format is given only as 'long' with no sign.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lovato Electric RGK900 genset paralleling controller

What Modbus registers does the Lovato Electric RGK900 genset paralleling controller have?

This map lists 121 registers: 121 input registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lovato Electric RGK900 genset paralleling controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables print hex addresses (for example 0024H) and the document says the address in the query must be one lower than the table value. Its example reads mains L2 active power, listed at 0024H, with start address 00 23. 'address' here is already reduced by one.

What byte order does the Lovato Electric RGK900 genset paralleling controller use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lovato Electric RGK900 genset paralleling controller?

Start with IR 27 L1-L2 Voltage - Generator (Generator L1-L2 voltage); IR 91 Frequency - Generator (Generator frequency); IR 13 L1 Current (Phase L1 current); IR 111 Eqv. Active Power - Generator (Generator total active power); IR 3967 Engine working hours (Engine hours); IR 4007 Battery voltage (Battery voltage); IR 3991 Modbus Function 0x07 clone (Operating mode (status copy)); IR 21 L1-L2 Voltage - Mains (Bus) (Mains L1-L2 voltage).

How do I enable Modbus control of the Lovato Electric RGK900 genset paralleling controller?

Set the communication port (built-in serial or optical port, or an EXP expansion module) in the device setup menu; see the RGK instruction manual for the menu.
