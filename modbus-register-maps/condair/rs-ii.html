Short answer

The Condair RS is a resistive-heating steam humidifier with one or two cylinders. Its Integrated Controller is a Modbus RTU slave on RS-485 or a Modbus TCP server. This map covers per-cylinder status, safety chain, heating, valves and levels, capacities, demand, operating hours and service counters, plus two-channel setpoint and control registers.

Integration notes: Condair RS II resistive steam humidifier (Integrated Controller, Modbus RTU/TCP)

Integration in brief

Read input registers 2000-2030 (UInt16) and 2041-2072 (floats). Write channel 1 demand or humidity to holding 3007 (and channel 2 to 3008 for dual control).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Controls > Signal Settings: set Source = Modbus.

Communication loss & watchdog

When the demand or humidity signal comes from Modbus, it must be rewritten within 'Signal Timeout' (1-300 s, default 300 s); otherwise warning W35 is raised and the unit stops humidifying.

Byte order & addressing

  • The address column is the wire address; 32001 is address 2000.
  • Floats are two registers, MSR first by default.

Network setup

  • Menu > password 8808 > Network > Modbus Settings: set protocol (Modbus/RTU or Modbus/TCP), address, parity, baud rate and register sequence; the controller restarts after a protocol change.
  • For Modbus TCP set the IP parameters under Network > IP Settings (factory setting DHCP).

Watch out for

  • Cylinder B registers read meaningfully only on two-cylinder units.

Notes on this map

  • Input registers are read with function 04; holding registers with 03 and written with 06 or 16.
  • Floats use 'Register Sequence': MSR first (high register first, ABCD) is the factory setting; LSR first (CDAB) is the option. The map assumes the factory setting.
  • Factory serial settings: Modbus RTU, address 10, 19200 baud, even parity, 8 data bits, 1 stop bit. Modbus TCP uses port 502 and unit ID 255 (per the TCP technical data).
  • Units marked metric/imperial follow the controller's Metric/Imperial setting; the listed unit is the metric one.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Condair RS II resistive steam humidifier (Integrated Controller, Modbus RTU/TCP)

What Modbus registers does the Condair RS II resistive steam humidifier (Integrated Controller, Modbus RTU/TCP) have?

This map lists 59 registers: 47 input registers, 12 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Condair RS II resistive steam humidifier (Integrated Controller, Modbus RTU/TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print the 5-digit register (32001 = input register, 43001 = holding register) and the 0-based address beside it (2000 / 3000). The address column is what goes on the wire; the manual's own example: register 43004 = address 3003.

What byte order does the Condair RS II resistive steam humidifier (Integrated Controller, Modbus RTU/TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Condair RS II resistive steam humidifier (Integrated Controller, Modbus RTU/TCP)?

Start with IR 2000 Device Status Cyl. A (Status cylinder A); IR 2002 Maintenance and Error Status (Maintenance and error status); IR 2003 ErrorWarning Code (Error/warning code); IR 2047 Actual Hum. Capacity (Actual capacity); IR 2057 System Demand (System demand); HR 3007 Actual humidity or demand via Modbus CH1 (Demand/humidity via Modbus CH1).

How do I enable Modbus control of the Condair RS II resistive steam humidifier (Integrated Controller, Modbus RTU/TCP)?

Controls > Signal Settings: set Source = Modbus.

What happens when the Condair RS II resistive steam humidifier (Integrated Controller, Modbus RTU/TCP) loses Modbus communication?

When the demand or humidity signal comes from Modbus, it must be rewritten within 'Signal Timeout' (1-300 s, default 300 s); otherwise warning W35 is raised and the unit stops humidifying.
