Updated 17 November 2026

Short answer

Ecoforest's geothermal and air-source heat pumps expose the 'API HP Client' list over Modbus RTU on the BMS2 RS-485 port. Every value is a single 16-bit holding register with a fixed gain. This map covers status, alarms, compressor counters, humidity, service powers and the read/write BUS control and setpoint registers; temperature and pressure readings are left out because the manual does not state their sign.

This page lists 110 Modbus registers for the Ecoforest ecoGEO / ecoAIR heat pump (API HP24 Client, Modbus RTU) — 54 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Ecoforest’s own free documentation (linked below) and checked against it.

Integration notes: Ecoforest ecoGEO / ecoAIR heat pump (API HP24 Client, Modbus RTU)

Integration in brief

Enable BUS control in the installer menu, connect to BMS2 at 19200 baud, no parity, 2 stop bits, address 17, and poll the status and alarm registers 2030-2073 with function 03. Write 2700 to switch the heat pump and the 2705-2715 BUS-control flags before writing setpoints 2720-2759.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Installer menu > Installation > Remote control > BUS Control > enable. Check the BMS2 port settings (protocol 'MB Extended') in the same Remote control submenu. On the source manager BUS control is always on.

Byte order & addressing

  • All values are single 16-bit registers with a fixed gain (0.1 for temperatures, pressures, humidity and setpoints).
  • Counters over 999 are split: value = high part x 1000 + low part (2103/2104, 2105/2106).
  • BUS setpoints are clamped to their ranges and only apply when the matching BUS-control flag is set; the final setpoints in 2150-2164 show the result (not mapped here because their sign is not stated).
  • Date/time writes need the matching confirmation register (2695-2699) set to 1.

Network setup

  • RS-485 on the BMS2 port, 3-wire shielded twisted pair (Tx/Rx-, Tx/Rx+, GND).
  • Defaults: 19200 baud, no parity, 2 stop bits; address 17 for a heat pump, 15 supervisor, 14 source manager.
  • On ecoAIR outdoor units BMS2 links to the indoor unit, so an optional RS-485 card on the BMS port is needed for BUS access.
  • Supported functions: 03, 06, 16.

Watch out for

  • ecoAIR outdoor units serve this list only when configured as block slave or stand-alone.
  • Check the API version shown in the user menu (Information) matches HP24_Client; older software uses a different list.

Notes on this map

  • Ecoforest does not appear to host this manual publicly; the link is an unaltered copy of the Ecoforest manual on the TapHome integration site.
  • The manual calls every BUS register a 16-bit analog value but never states whether it is signed, and prints no range for the temperature, pressure, DT, superheat and final-setpoint readings. Those readings (2080-2102, 2130-2144, 2150-2164) are therefore left out, as are the cooling setpoints 2723 and 2731-2739 whose lower limit is only given as T_lim. Writable setpoints whose printed range is entirely positive are listed as UINT16 (identical decoding inside that range); only 2777/2778, printed as -99.9 to 99.9 kW, are INT16. Humidity 2170-2174 is listed as UINT16 because relative humidity cannot be negative.
  • Instantaneous powers 2186-2194 are left unscaled because their gain depends on register 2185 (W = 1, kW or MW = 0.1).
  • Left out: the energy-meter block 2200-2461 (gain depends on per-period unit registers) and e-MANAGER power readings 2501-2508, model-code digit registers 2010-2023 and software version letters 2007-2009, and the duplicate 'Zone n temperature' entries at 2175-2179 whose meaning differs from 2140-2144 but is not explained.
  • The heat pump status read (2045: 0 off, 1 on, 2 emergency) and the command register (2700: 1 off, 2 on, 3 emergency) use different codes; operation program likewise (2044 0-2, 2701 1-3).
  • Software older than AWD24 / WWD24 / WWC24 is not compatible with this register list.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Ecoforest ecoGEO / ecoAIR heat pump (API HP24 Client, Modbus RTU)

What Modbus registers does the Ecoforest ecoGEO / ecoAIR heat pump (API HP24 Client, Modbus RTU) have?

This map lists 110 registers: 110 holding registers. 54 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Ecoforest ecoGEO / ecoAIR heat pump (API HP24 Client, Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed in decimal and go on the wire unchanged: the manual's read example for outdoor temperature (address 2080) sends start register 08 20 hex, and the write example for heat pump status (2700) sends 0A 8C hex.

What are the minimum Modbus registers to integrate the Ecoforest ecoGEO / ecoAIR heat pump (API HP24 Client, Modbus RTU)?

Start with HR 2045 Heat pump status (Heat pump on/off/emergency); HR 2065 Alarm level (Alarm level); HR 2066 Lock alarm code (Lock alarm code); HR 2030 DHW production mode status (DHW production status); HR 2700 Heat pump status command (Switch heat pump); HR 2705 DHW BUS control (DHW setpoint by BUS flag); HR 2720 DHW setpoint (DHW setpoint by BUS).

How do I enable Modbus control of the Ecoforest ecoGEO / ecoAIR heat pump (API HP24 Client, Modbus RTU)?

Installer menu > Installation > Remote control > BUS Control > enable. Check the BMS2 port settings (protocol 'MB Extended') in the same Remote control submenu. On the source manager BUS control is always on.
