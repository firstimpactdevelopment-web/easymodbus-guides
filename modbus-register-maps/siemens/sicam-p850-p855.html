Short answer

SICAM P850 is a panel power monitoring device and P855 a class A power quality device, both with Ethernet Modbus TCP and an optional RS-485 Modbus RTU interface. All data sits in holding registers: measured values as IEEE floats and energy as floats and doubles. This map covers identity, instantaneous values, THD, flicker, load-profile values, total and per-phase energy and the tariff 1 energy values.

Integration notes: Siemens SICAM P850 / P855 power monitoring and PQ device

Integration in brief

Poll holding registers with FC 03: register 0201 (address 200) onward gives voltages, currents, power, power factor and frequency as big-endian floats; read total active energy import as a double at 4773 (address 4772).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP is configured in the device parameters (standard port 502 fixed, optional user port 503-65535, access rights full or read-only per port). The RS-485 Modbus RTU interface needs the serial option and its own address, baud and parity settings.

Communication loss & watchdog

Communication supervision time (default 600 x 100 ms = 60 s, 0 = off) for both TCP and RTU; Modbus TCP also has a keep-alive time (default 10 s).

Byte order & addressing

  • Register numbers are 1-based; subtract 1 for the address.
  • Floats and doubles are high word first.
  • Complex values must be read as a whole or the device returns exception 03.

Network setup

  • Modbus RTU defaults: address 1, 19200 baud, even parity with 1 stop bit (also odd, none with 1 stop bit, or none with 2 stop bits); baud 1200-115200.
  • Modbus TCP: up to 4 connections; with a user port, 2 on port 502 and 2 on the user port.

Watch out for

  • A port set to read-only access rejects writes.
  • Special NaN/Inf floats mark invalid values; handle them before logging.

Notes on this map

  • Word order: the manual states that for values larger than one register the lowest register holds the most significant byte (and Modbus TCP data is big-endian), so floats and doubles are high word first (ABCD).
  • Invalid or overflowed measured values are reported as special floats: 7F800000h = overflow/invalid, 7F800001h = not calculated (e.g. voltage below 15 % of rated), 7F800002h = value does not exist for the network type.
  • Left out: the indication registers (0101-0152), whose 2-bit value/quality layout is shown only in figures; the date/time registers; PQ aggregation, harmonics, PQ event and tariff counter blocks; the counter-pulse energy registers 0801-0846; tariffs 2-8 float32 and all float64 tariff values; the internal 1-cycle values 0281-0292.
  • The same register map applies to Modbus TCP and Modbus RTU.
  • Flicker values (0323-0357) have no unit.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Siemens SICAM P850 / P855 power monitoring and PQ device

What Modbus registers does the Siemens SICAM P850 / P855 power monitoring and PQ device have?

This map lists 179 registers: 179 holding registers. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Siemens SICAM P850 / P855 power monitoring and PQ device Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints 1-based register numbers (0201, 4761...) and states that the address in the message is register number - 1. Register 0201 (voltage a-N) is requested as address 200.

What byte order does the Siemens SICAM P850 / P855 power monitoring and PQ device use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Siemens SICAM P850 / P855 power monitoring and PQ device?

Start with HR 200 Voltage a-N (Voltage a-N); HR 208 Current a (Current a); HR 232 Active power (Total active power); HR 264 Power factor (Power factor); HR 274 Power frequency (Frequency); HR 4772 Active energy, import (float64) (Active energy import (double)); HR 4788 Active energy, export (float64) (Active energy export (double)).

How do I enable Modbus control of the Siemens SICAM P850 / P855 power monitoring and PQ device?

Modbus TCP is configured in the device parameters (standard port 502 fixed, optional user port 503-65535, access rights full or read-only per port). The RS-485 Modbus RTU interface needs the serial option and its own address, baud and parity settings.

What happens when the Siemens SICAM P850 / P855 power monitoring and PQ device loses Modbus communication?

Communication supervision time (default 600 x 100 ms = 60 s, 0 = off) for both TCP and RTU; Modbus TCP also has a keep-alive time (default 10 s).
