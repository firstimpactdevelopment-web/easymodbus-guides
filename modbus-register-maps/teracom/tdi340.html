Short answer

The TDI340 is a Teracom DIN-rail module with four isolated S0 inputs (IEC 62053-31) and a Modbus RTU RS-485 port. Each input has a 32-bit pulse counter in polling or edge mode, a scaled real value and an open/closed state, with optional debounce delays.

Integration notes: Teracom TDI340 4-channel S0 pulse counter with Modbus RTU

Integration in brief

Read the four 32-bit counters at PDU 210-217 (or real values at PDU 230-237) with function 03. Set each input's mode and edge first; edge mode is the factory default.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is the only interface and is always active; there is nothing to switch on. Factory settings are address 1, 19200 baud, 8E1.

Byte order & addressing

  • Baud rate and framing changes only take effect after the device is powered off and on again.
  • Word order for every 32-bit value is set by the Data order register (PDU 13); check it before blaming the scaling.

Network setup

  • Set unit ID (PDU 10), baud (PDU 11) and framing (PDU 12), then power-cycle the device.
  • Terminate both ends of the RS-485 bus with 120 ohm; the built-in resistor is enabled by wiring Term to RS485-. A daisy chain is recommended.

Notes on this map

  • Addresses are taken from the manual's PDU address column (0-based); the logical column adds 40001 for holding registers and 10001 for discrete inputs, as the manual states.
  • All 32-bit values follow the Data order register (PDU 13): 1 = most significant word first (factory default), 2 = least significant word first. The map shows the default, ABCD.
  • Left out: the 32-bit float/integer test-value registers (PDU 82-95), which only exist to check word order; the 16-bit test values are kept.
  • Input states are also readable as discrete inputs PDU 1-4 (logical 10002-10005), as the table prints them.
  • Debounce delays (0-65535 x 10 ms) only work while that input's counter is in polling mode.
  • A missing float returns NaN and a missing 32-bit integer -2147483648.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Teracom TDI340 4-channel S0 pulse counter with Modbus RTU

What Modbus registers does the Teracom TDI340 4-channel S0 pulse counter with Modbus RTU have?

This map lists 50 registers: 4 discrete inputs, 46 holding registers. 32 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Teracom TDI340 4-channel S0 pulse counter with Modbus RTU Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register table prints both a PDU (wire) address and a logical address (PDU + 40001 for holding registers). 'documented' holds the logical number; the PDU number is what goes in the request, e.g. logical 40101 = PDU 100.

What byte order does the Teracom TDI340 4-channel S0 pulse counter with Modbus RTU use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Teracom TDI340 4-channel S0 pulse counter with Modbus RTU?

Start with HR 210 Counter Input1 (32-bit) (Counter input 1); HR 212 Counter Input2 (32-bit) (Counter input 2); HR 230 Counter Input1 real value (Real value input 1); HR 200 All digital inputs (bitmask) (All input states); HR 110 Counter mode Input1 (Counter mode input 1); DI 1 Input1 (Input 1 state).

How do I enable Modbus control of the Teracom TDI340 4-channel S0 pulse counter with Modbus RTU?

Modbus RTU is the only interface and is always active; there is nothing to switch on. Factory settings are address 1, 19200 baud, 8E1.
