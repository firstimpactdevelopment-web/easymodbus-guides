Short answer

The 7SR10 is a compact non-directional overcurrent and earth-fault protection relay with an RS-485 port that can run IEC 60870-5-103, Modbus RTU or DNP3. Under Modbus, commands are coils, protection and status indications are discrete inputs, and measurands are input registers. This map covers the default point list: binary outputs, control commands, protection elements, voltages, currents, frequency, power factor, maximum demand, fault values, counters and status bit strings.

Integration notes: Siemens Reyrolle 7SR10 Argus overcurrent and earth-fault relay (Modbus RTU)

Integration in brief

Set COM1-RS485 Protocol to Modbus RTU and give the relay a station address, then read input registers (FC 04) from 30010 for voltages and 30064 for currents; values are 32-bit integers with 3 decimals, high word first. Protection pickups and trips are discrete inputs (FC 02); commands are coils (FC 05).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the Communications menu set COM1-RS485 Protocol = Modbus RTU (factory default is IEC 60870-5-103), then the station address (1-247), baud rate (default 19200) and parity (default even). Remote control needs the port mode to be Remote (default).

Byte order & addressing

  • Measurands are input registers (FC 04), not holding registers.
  • FP_32BITS_3DP values are integers: divide by 1000.
  • Bit strings put the first item in the least significant bit.

Network setup

  • RS-485 baud 75-38400 (default 19200), parity none/odd/even (default even).
  • The USB port can run the same protocol at the same time.

Watch out for

  • The 'Mult' column is not explained in the manual; check power readings against the relay display before using them.
  • Event records must be read as exactly 8 registers or the relay answers exception 2.

Notes on this map

  • Source host: this is the unaltered Siemens manual as hosted by RS Components; we did not find a public Siemens copy of this edition.
  • Word order: the manual states that 32-bit values are stored in two registers in big-endian format and shows FP_32BITS_3DP 123456 as 30001 = 0001h, 30002 = E240h, so high word first (ABCD).
  • FP_32BITS_3DP is a signed 32-bit integer carrying 3 decimal places (123.456 sent as 123456), so scale is 0.001. The manual's 'UINT32' and 'UINT16' are described as signed (two's complement), so they are listed as INT32 / INT16.
  • The point list is the factory default; it can be changed with the Communications Configuration Editor, and some points do not exist on every model.
  • Each point list row has a 'Mult' column that the manual does not explain. Numeric rows with Mult 1.000000 are listed (bit strings and the event counter, printed with Mult 0.000000, are also kept); rows with other Mult values (active/reactive/apparent power, max demand power, CB wear, S 3P max) are left out because their engineering scale cannot be settled from the manual.
  • Left out: the energy meter registers 30144-30150 (no unit printed), the 8-register event record at 30002 and the TIME_METER holding register 40001 (byte-packed structures, see pp. 35-36).
  • Units come from the point list description: 'xIn' / 'xInom' values are multiples of rated current, 'Degrees' values are phase angles.
  • Units are given only where the point list prints one; fault, maximum-demand and last-trip values have no unit in the list.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Siemens Reyrolle 7SR10 Argus overcurrent and earth-fault relay (Modbus RTU)

What Modbus registers does the Siemens Reyrolle 7SR10 Argus overcurrent and earth-fault relay (Modbus RTU) have?

This map lists 426 registers: 51 coils, 254 discrete inputs, 121 input registers. 51 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Siemens Reyrolle 7SR10 Argus overcurrent and earth-fault relay (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The point list uses Modicon numbers: coils 00001+, inputs 10001+, input registers 30001+. Subtract the block base for the wire address: coil 00001 = address 0, input 10001 = address 0, input register 30010 = address 9. The data-type section uses the same numbering (a float 'stored in registers 30001 and 30002').

What byte order does the Siemens Reyrolle 7SR10 Argus overcurrent and earth-fault relay (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Siemens Reyrolle 7SR10 Argus overcurrent and earth-fault relay (Modbus RTU)?

Start with IR 63 I Primary a (Primary current phase a); IR 65 I Primary b (Primary current phase b); IR 67 I Primary c (Primary current phase c); IR 59 Frequency (Frequency); DI 109 General Trip (General trip); CO 108 CB 1 (CB 1 control point).

How do I enable Modbus control of the Siemens Reyrolle 7SR10 Argus overcurrent and earth-fault relay (Modbus RTU)?

In the Communications menu set COM1-RS485 Protocol = Modbus RTU (factory default is IEC 60870-5-103), then the station address (1-247), baud rate (default 19200) and parity (default even). Remote control needs the port mode to be Remote (default).

Where is the official Siemens Reyrolle 7SR10 Argus overcurrent and earth-fault relay (Modbus RTU) Modbus documentation?

The source is Reyrolle 7SR10 Communication Protocols Manual (IEC 60870-5-103, Modbus RTU, DNP3) (C53000-L7040-C002-7), revision 2025-11. Siemens doesn't publish it on its own website, so this map was re-typed from a free copy at https://docs.rs-online.com/a9fe/A700000016195318.pdf. It may be an older revision, so check it against the live unit.
