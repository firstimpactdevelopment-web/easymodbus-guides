Short answer

The SunSaver Duo is a PWM solar charge controller that charges two separate batteries. Via its RJ-11 MeterBus port and Morningstar's MSC adapter it speaks Modbus RTU: both battery voltages and charge currents, solar voltage, duty cycles, charge setpoints in use, state and fault bits, plus EEPROM custom settings and a few coils.

Integration notes: Morningstar SunSaver Duo dual-battery PWM charge controller (Modbus RTU via MeterBus)

Integration in brief

Through the MSC adapter at 9600 8N2, ID 1, read 0x0000-0x0010 for both battery voltages, solar voltage and charge currents, and 0x0108-0x0110 for state, faults and battery states.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The meter port auto-detects Meterbus or Modbus; connect the MSC adapter and poll. Coil 0x00F1 switches the port back to Meterbus for a remote meter.

Byte order & addressing

  • Both FC 0x03 and FC 0x04 are supported for reading.
  • EEPROM values that need updating are saved once every 24 hours; coil 0x0016 forces it.

Network setup

  • Serial: 9600 baud, 8 data bits, no parity, 2 stop bits, no flow control.

Watch out for

  • The RJ-11 port is MeterBus, not RS-485; Morningstar's MSC adapter is needed.

Notes on this map

  • Left out: the 32-bit hourmeter and amp-hour counters (0x0013-0x001A). The register table puts the HI word first, but the spec's own two-word example reads the hourmeter LO word at 0x0013 and HI at 0x0014, and the revision history says the HI/LO addresses were swapped in an earlier version. The word order cannot be settled from the document.
  • Left out: the 'reset amp-hours' coil, because the table gives 0x0010 and the definitions page gives 0x0017 (which is also the min/max reset coil).
  • Scaling formulas (n / 1800 for battery voltages, n / 1032 for solar voltage, n / 673 for currents, 0-417 = 0-100 % for duty/priority) are converted to multipliers.
  • Left out: the pre-scaled temperatures at 0x0100-0x0105 (F and C copies), because the spec gives no data type or signedness for them and sub-zero readings are expected.
  • Only the 'DIP off' custom voltages are listed for each battery; the 'DIP on' set (0xE00C-0xE011, 0xE018-0xE01D) follows the same layout. The two ID registers 0xE000/0xE001 are not listed because the table and the definitions disagree on which range belongs to which ID.
  • Battery detect registers follow the register table (0x010F, 0x0110); the definitions page repeats the battery-state addresses for them, which looks like a copy error.
  • Any EEPROM write (FC 0x06) sets an 'EEPROM changed' fault that needs a controller reset.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Morningstar SunSaver Duo dual-battery PWM charge controller (Modbus RTU via MeterBus)

What Modbus registers does the Morningstar SunSaver Duo dual-battery PWM charge controller (Modbus RTU via MeterBus) have?

This map lists 52 registers: 5 coils, 47 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Morningstar SunSaver Duo dual-battery PWM charge controller (Modbus RTU via MeterBus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The hex PDU address in Morningstar's table is the wire address; the spec says all listed addresses are request-PDU addresses, and its example reads battery 1 voltage at 0x0000 (0x5CD0 = 23760 / 1800 = 13.20 V).

What are the minimum Modbus registers to integrate the Morningstar SunSaver Duo dual-battery PWM charge controller (Modbus RTU via MeterBus)?

Start with HR 0 vb1 - battery 1 voltage (Battery 1 voltage); HR 1 vb2 - battery 2 voltage (Battery 2 voltage); HR 3 ia1 - charge current battery 1 (Charge current battery 1); HR 4 ia2 - charge current battery 2 (Charge current battery 2); HR 264 state - controller state (Controller state); HR 265 faults - fault bitfield (Fault bitfield).

How do I enable Modbus control of the Morningstar SunSaver Duo dual-battery PWM charge controller (Modbus RTU via MeterBus)?

The meter port auto-detects Meterbus or Modbus; connect the MSC adapter and poll. Coil 0x00F1 switches the port back to Meterbus for a remote meter.
