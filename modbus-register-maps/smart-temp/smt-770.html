Integration notes: Smart Temp SMT-770 thermostat with EC-02 module (Modbus RTU)

Integration in brief

Read 40354 for the room temperature shown on the display and 40318 for the active setpoint; write mode (40002), fan (40003) and setpoints (40005/40006 or 40015 depending on DIP mode).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the thermostat address in the installer menu (item AD, default 7); 9600 8N1 by default. A paired EC-02 copies address and baud from the thermostat.

Communication loss & watchdog

Coil override (40062) falls back to thermostat control after about 5 minutes without Modbus or after a power loss; refresh it at least every 4 minutes.

Byte order & addressing

  • Celsius setpoints are (raw - 20) / 2.
  • Registers 40350/40354 are (raw - 400) / 10.

Network setup

  • Only the last device on the bus gets the EOL resistor; with a paired EC-02, terminate at the EC-02, not the thermostat.
  • Up to 32 thermostats per segment.

Watch out for

  • Writes that conflict with the DIP-switch mode are silently ignored.
  • Changing baud (40060) or parity (40068) over Modbus drops the device off the current network.

Notes on this map

  • This copy is hosted by the distributor Reece; it is the Smart Temp SMT-770 / EC-02 Communications Addendum, version 4.6.
  • Set temperatures in Celsius mode are stored as (°C x 2) + 20, so value = raw x 0.5 - 10; in Fahrenheit mode the raw value is °F directly. The map shows the Celsius scaling; check 40029.
  • Left out: 40310/40313/40316 room and outside-air temperatures, whose Celsius formula is printed two ways (subtract 20 or subtract 80); register 4021 (security PIN, address misprinted); the second 40318 row (heating set temperature, duplicate address); the TT temperature 40356, whose label says °F while its range is in °C; schedule registers 40513 upward.
  • Many registers only act in particular DIP-switch modes (DIP 6/8 select manual, two-setpoint, commercial or residential programmable). Writing values that conflict with the DIP settings is ignored.
  • Factory Modbus address is 7. The addendum warns that writing unlisted registers can corrupt the thermostat setup.
  • The addendum prints 40318 twice (active set temperature, then heating set temperature after 40319). This map keeps the first, in-sequence 40318 as the active setpoint; confirm on site.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Smart Temp SMT-770 thermostat with EC-02 module (Modbus RTU)

What Modbus registers does the Smart Temp SMT-770 thermostat with EC-02 module (Modbus RTU) have?

This map lists 35 registers: 5 coils, 30 holding registers. 25 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Smart Temp SMT-770 thermostat with EC-02 module (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Coils are printed 00001-00005 and holding registers 40002 upward (Modicon references); subtract 1 (coils) or 40001 (holding registers) for the wire address.

What are the minimum Modbus registers to integrate the Smart Temp SMT-770 thermostat with EC-02 module (Modbus RTU)?

Start with HR 353 Displayed room temperature (Room temperature (0.1 °C)); HR 317 Active set temperature (Active setpoint); HR 1 Thermostat mode (Thermostat mode); HR 2 Fan mode (Fan mode); HR 14 Single set point (manual mode) (Single setpoint (manual mode)); CO 0 G1 relay (G1 fan relay).

How do I enable Modbus control of the Smart Temp SMT-770 thermostat with EC-02 module (Modbus RTU)?

Set the thermostat address in the installer menu (item AD, default 7); 9600 8N1 by default. A paired EC-02 copies address and baud from the thermostat.

What happens when the Smart Temp SMT-770 thermostat with EC-02 module (Modbus RTU) loses Modbus communication?

Coil override (40062) falls back to thermostat control after about 5 minutes without Modbus or after a power loss; refresh it at least every 4 minutes.
