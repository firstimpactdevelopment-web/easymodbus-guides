Short answer

The Datamanager publishes each Fronius Sensor Card as its own Modbus device (unit ID 245 for Solar Net address 0, up to 247). After the common block it carries SunSpec irradiance model 302, back-of-module temperature model 303 and base meteorological model 307. This map covers the identification block, irradiance, both temperature inputs and wind speed.

Integration notes: Fronius Fronius Sensor Card via Datamanager (SunSpec 302/303/307)

Integration in brief

Enable Modbus on the Datamanager and poll the sensor card at unit ID 245 + its Solar Net address. Read 40072 for irradiance and 40079-40086 for temperatures and wind speed.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

RegisterNameTypeWhyAccess
HR 40069Irradiance IDUINT16Model ID 302 confirms the layoutRead
HR 40071GHIUINT16Global horizontal irradianceRead
HR 40078TmpBOMINT16Module temperature (sensor 1)Read
HR 40082TmpAmbINT16Ambient temperature (sensor 2)Read
HR 40085WndSpdINT16Wind speedRead

Enable Modbus control & writes

In the Datamanager web interface open Settings > Modbus and set data output to tcp (or rtu). The sensor card must be connected to the Datamanager via Solar Net.

Byte order & addressing

  • The sensor card is a separate Modbus device: unit ID = 245 + Solar Net address (0-2 -> 245-247).
  • Unlike the inverter and meter models, the sensor card layout does not change between float and int+SF.

Network setup

  • Sensor card Solar Net address 0 -> unit ID 245, 1 -> 246, 2 -> 247.

Watch out for

  • Points marked not supported (humidity, pressure, wind direction and others) still exist in the block; ignore them.

Notes on this map

  • Register table from Fronius' official XLSX in the Modbus SunSpec maps ZIP; the unit-ID rule comes from the PDF.
  • The XLSX gives a fixed scale factor of -1 for the temperatures (raw x 0.1); GHI and wind speed have no scale factor and are used as read.
  • Left out: the 32-bit SID (40001-40002, word order not stated) and every point the XLSX marks not supported (POAI, DFI, DNI, OTI, the second TmpBOM at 40080, RH, pressure, wind direction, rain, snow, precipitation type, electric field, surface and soil wetness).
  • Changelog 1.1.5-0 notes that TmpAmb (40083) is mapped to temperature sensor 2 and the second TmpBOM register is not supported.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Fronius Fronius Sensor Card via Datamanager (SunSpec 302/303/307)

What Modbus registers does the Fronius Fronius Sensor Card via Datamanager (SunSpec 302/303/307) have?

This map lists 20 registers: 20 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Fronius Fronius Sensor Card via Datamanager (SunSpec 302/303/307) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Fronius numbers registers from 1 (SunSpec base register 40001) and tells you to request the register number minus one, so register 40072 is read at wire address 40071. The manual's RTU example reads register 40005 with address bytes 9C 44 (40004).

What are the minimum Modbus registers to integrate the Fronius Fronius Sensor Card via Datamanager (SunSpec 302/303/307)?

Start with HR 40069 Irradiance ID (Model ID 302 confirms the layout); HR 40071 GHI (Global horizontal irradiance); HR 40078 TmpBOM (Module temperature (sensor 1)); HR 40082 TmpAmb (Ambient temperature (sensor 2)); HR 40085 WndSpd (Wind speed).

How do I enable Modbus control of the Fronius Fronius Sensor Card via Datamanager (SunSpec 302/303/307)?

In the Datamanager web interface open Settings > Modbus and set data output to tcp (or rtu). The sensor card must be connected to the Datamanager via Solar Net.
