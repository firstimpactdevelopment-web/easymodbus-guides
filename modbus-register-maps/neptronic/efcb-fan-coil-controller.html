Short answer

The EFCB is a Neptronic fan coil unit controller that pairs with a TFL/TDF digital room sensor and talks Modbus RTU on RS-485. Everything is in one holding-register table: sensor readings, heating/cooling/fan demands, relay and analog output states, mode, fan speed and setpoints, plus the full configuration set for outputs, inputs, humidity and CO2 options.

This page lists 171 Modbus registers for the Neptronic EFCB Series networkable fan coil controller (Modbus RTU) — 135 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Neptronic’s own free documentation (linked below) and checked against it.

Integration notes: Neptronic EFCB Series networkable fan coil controller (Modbus RTU)

Integration in brief

Read holding registers with function 03 at the wire address shown in the guide's Protocol Address column (Modicon 40001 = address 0). Set the temperature unit for Modbus first, then use the mode, fan and setpoint registers for control.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is the controller's native protocol; set the address (1-246) and, if needed, a fixed baud rate and parity from the device menu or registers 0-2.

Byte order & addressing

  • The guide prints both the 0-based protocol address and the 40001-style notation, so there is no off-by-one guesswork.
  • Baud register holds baud/100 (384 = 38400); 0 means automatic baud detection.

Network setup

  • RS-485 two-wire, RTU. Supported baud rates 9600, 19200, 38400 and 57600; automatic baud detection is the default.
  • Parity/stop bits come from the communication-port register: 1 = none + 2 stop, 2 = even + 1 stop, 3 = odd + 1 stop.

Watch out for

  • Changing the Modbus temperature-unit bit changes the meaning of every temperature register at once.
  • Some registers only apply to models with a humidity, CO2 or other optional sensor.

Notes on this map

  • Every register is a 16-bit holding register (function 03 to read, 06 or 16 to write); there are no 32-bit values.
  • Temperatures, setpoints, bands and offsets are reported in °C or °F according to the "temperature unit in Modbus" bit of the system-options register; scaling is x100 for sensor readings and offsets and x10 for setpoints and bands, as listed per register.
  • Register 0 packs the Neptronic product ID in the high byte and the Modbus address in the low byte.
  • Left out: the four product-name registers (two ASCII characters each, byte order not spelled out) and every register the guide marks Reserved.
  • Register 40151 (labelled humidity deadband but with a signed ±5 %RH range that reads like an offset) is left out; 40150 carries the humidity deadband setting.
  • Register 40128 (DO3 mode) is split across a page break in the guide; its option list is the same 1-8 list printed for DO1, DO2 and DO4.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Neptronic EFCB Series networkable fan coil controller (Modbus RTU)

What Modbus registers does the Neptronic EFCB Series networkable fan coil controller (Modbus RTU) have?

This map lists 171 registers: 171 holding registers. 135 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Neptronic EFCB Series networkable fan coil controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row prints both the protocol (wire) address, starting at 0, and the 40001-style notation; e.g. 40046 is protocol address 45. The documented field holds the 4xxxx notation.

What are the minimum Modbus registers to integrate the Neptronic EFCB Series networkable fan coil controller (Modbus RTU)?

Start with HR 11 Internal temperature sensor reading (Internal (room) temperature x100); HR 14 Control temperature reading (Control temperature x100); HR 45 System mode status (System mode); HR 46 Fan speed selection by user (Fan speed); HR 47 Temperature setpoint in occupancy or day mode (Occupied setpoint x10); HR 24 Actual heating demand (Heating demand); HR 26 Actual cooling demand (Cooling demand); HR 9 System Status 1 (Status 1 (fault, filter, changeover)); HR 10 System Status 2 (Status 2 (alarms)); HR 48 System options1 (System options 1 (bit 1 = Modbus temp unit)).

How do I enable Modbus control of the Neptronic EFCB Series networkable fan coil controller (Modbus RTU)?

Modbus is the controller's native protocol; set the address (1-246) and, if needed, a fixed baud rate and parity from the device menu or registers 0-2.
