Short answer

The Z-4RTD2-SI reads four RTD sensors (PT100, PT500, PT1000, NI100, NI120, NI1000, CU50, CU100) in 2, 3 or 4-wire mode and serves them over Modbus RTU. Each channel is available as a scaled 16-bit integer and as a float. This map covers measurements, error flags, serial settings, per-channel configuration, fault values, offsets and the command register.

This page lists 27 Modbus registers for the Seneca Z-4RTD2-SI 4-channel RTD input module (Modbus RTU) — 16 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Seneca’s own free documentation (linked below) and checked against it.

Integration notes: Seneca Z-4RTD2-SI 4-channel RTD input module (Modbus RTU)

Integration in brief

Read holding registers 1-13 (function 03): error flags, four scaled integers and four floats. Check the burnout and out-of-range bits in register 1 before trusting a value.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is always on. Station address and parity are in register 34, baud rate in 35; write 51792 to register 47 to save configuration and 52428 to reboot.

Byte order & addressing

  • Offset is the wire address.
  • Float word order can be flipped by Configuration 2 bit 15.

Network setup

  • Set sensor type, wiring and speed per channel in registers 36-39, then save (51792 to register 47).

Watch out for

  • Integer scaling changes when a channel is switched to resistance mode.
  • While a USB cable is plugged in, the RS-485 port is disabled; unplug USB to restore it.

Notes on this map

  • All values are holding registers.
  • Floats are printed MSW at the lower address (ABCD); bit 15 of Configuration 2 (offset 40) switches them to LSW first. The manual does not state the factory value of that bit, so confirm it reads 0 before trusting ABCD. The manual also lists a word-swapped copy at +1000 (e.g. 41007); not included here.
  • The 16-bit measures are °C/10 in temperature mode. In resistance mode they are Ohm/100 for PT100/NI100/NI120/CU50/CU100 and Ohm/10 for PT500/PT1000/NI1000, so the listed 0.1 scale only fits temperature mode.
  • RW* registers are in flash (about 10,000 writes).
  • The manual does not give factory defaults for address or baud rate.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Seneca Z-4RTD2-SI 4-channel RTD input module (Modbus RTU)

What Modbus registers does the Seneca Z-4RTD2-SI 4-channel RTD input module (Modbus RTU) have?

This map lists 27 registers: 27 holding registers. 16 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seneca Z-4RTD2-SI 4-channel RTD input module (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table prints the 4x number (40003) and the 0-based offset (2). The offset is the wire address.

What byte order does the Seneca Z-4RTD2-SI 4-channel RTD input module (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Seneca Z-4RTD2-SI 4-channel RTD input module (Modbus RTU)?

Start with HR 1 Errors (Error / burnout flags); HR 6 Channel 1 measure (float) (Channel 1 float); HR 8 Channel 2 measure (float) (Channel 2 float); HR 10 Channel 3 measure (float) (Channel 3 float); HR 12 Channel 4 measure (float) (Channel 4 float); HR 2 Channel 1 measure (16-bit) (Channel 1 integer).

How do I enable Modbus control of the Seneca Z-4RTD2-SI 4-channel RTD input module (Modbus RTU)?

Modbus RTU is always on. Station address and parity are in register 34, baud rate in 35; write 51792 to register 47 to save configuration and 52428 to reboot.
