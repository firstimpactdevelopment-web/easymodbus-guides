Short answer

Interface that plugs into the S21 connector of a Daikin split / room air conditioner and exposes it as a Modbus RTU slave when its address is 1 or higher. Holding registers set setpoint, fan, mode, louvre, on/off, forced thermo-off and local limits; input registers report fault state, fault code, return-air and coil temperatures.

Integration notes: Realtime Control Systems RTD-RA Modbus interface for Daikin room air conditioners

Integration in brief

Set an address of 1..63 on SW1 so the unit becomes a Modbus slave, then write H0001-H0005 and poll I0121-I0131. H0010 decides whether the IR remote stays usable.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus slave mode is active whenever the SW1 address is 1 or higher; address 0 selects stand-alone mode. Closing input S2 in slave mode selects clone mode, which disables Modbus control.

Communication loss & watchdog

Optional via SW1: with no holding-register write for 120 s the unit is switched on with its current settings and local control is unlocked or left as is, depending on the switch.

Byte order & addressing

  • Readback temperatures above 32767 are negative: subtract 65536 then divide by 100.
  • Repeated identical writes in Last Touch mode override the user's remote; use On Change (3) for cyclic writers.

Network setup

  • 9600 baud, no parity, 1 stop bit by default.
  • Address on SW1 (0..63; 0 = stand-alone).
  • RS485 3-wire: DB(+), DA(-), GND, daisy-chained.

Watch out for

  • Supported setpoint range and number of fan speeds vary by indoor unit model.

Notes on this map

  • All registers are 16 bits. Readback temperatures are signed and x100; setpoint and limits are whole °C.
  • Fault codes pack two ASCII characters (high byte, low byte). Daikin code table is published separately by Realtime Controls.
  • Function codes 03, 04, 06 and 16 supported, 1..10 registers per request.
  • With the SW1 address set to 0 the RTD-RA runs stand-alone (inputs S1/S2 control it) and is not a Modbus slave.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Realtime Control Systems RTD-RA Modbus interface for Daikin room air conditioners

What Modbus registers does the Realtime Control Systems RTD-RA Modbus interface for Daikin room air conditioners have?

This map lists 17 registers: 5 input registers, 12 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Realtime Control Systems RTD-RA Modbus interface for Daikin room air conditioners Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register base 0: H0005 is holding register wire address 5 and I0123 is input register wire address 123.
