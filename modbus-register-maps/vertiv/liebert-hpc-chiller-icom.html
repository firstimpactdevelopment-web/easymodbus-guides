Short answer

The Liebert HPC is an air-cooled chiller family (with optional free cooling) for data-centre chilled-water loops. With a Liebert IntelliSlot Modbus card the iCOM controller is a Modbus slave. This map covers compressor states, head pressures and run hours for up to four compressors, condenser fan speeds, supply/return fluid temperatures and setpoints, free cooling, pumps, system on/off and status, and the alarm bits.

This page lists 151 Modbus registers for the Vertiv Liebert HPC chiller with iCOM v4 (IntelliSlot Modbus) — 30 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Vertiv’s own free documentation (linked below) and checked against it.

Integration notes: Vertiv Liebert HPC chiller with iCOM v4 (IntelliSlot Modbus)

Integration in brief

Read 30483-30511 for status, fluid temperatures and utilisation, and the discrete inputs for compressor, condenser, pump and system alarms. Write 40487 to switch the chiller on/off and 40424 for the supply fluid setpoint (tenths of deg C).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Liebert IntelliSlot card the guide lists for the unit's controller (for iCOM v4 units: IS-485L for Modbus 485, IS-IPBML for Modbus IP / BACnet IP) and set its Modbus address and line speed on the card.

Byte order & addressing

  • Modicon numbering: subtract 40001 / 30001 / 10001 for the wire address.
  • The same point names repeat for compressors 1-4 and condensers 1-4; the register name here is prefixed with the group heading from the guide.

Network setup

  • RS-485 (2-wire) RTU settings for the IntelliSlot 485 card: 9600, 19200 or 38400 baud, 8 data bits, no parity, 1 stop bit.
  • Each unit needs a unique Modbus slave address on the RS-485 line.
  • For Modbus IP, use the IntelliSlot Modbus IP / BACnet IP card listed for the unit's controller in the guide's compatibility table.

Watch out for

  • Several fluid setpoints and alarm thresholds (e.g. 40426, 40430, 40434, 40615-40621) are printed without a scale, unlike setpoint 1 (40424, x / 10). They are listed as printed; check one against the unit display before writing.
  • Discrete inputs 10033, 10214 and 10234 are printed as a second 'Compressor Low Suction Pressure' for the same compressor; transcribed as printed.

Notes on this map

  • Source: Emerson Network Power / Liebert reference guide SL-28170 (Rev 9). Vertiv does not host this guide publicly; the linked copy is the unaltered PDF on the Contemporary Controls support site.
  • Scale column: 'x / 10' means the raw value is tenths (scale 0.1); '-' or blank means no scaling. Some temperature setpoints are printed without a scale while similar points use x / 10; they are transcribed exactly as printed.
  • Most temperatures exist twice: once in deg C and once in deg F at a different register. Only the deg C registers are listed here.
  • Points that the guide lists with both an input register (3xxxx) and a holding register (4xxxx) are the writable settings; we list the holding register (read/write). The same value can also be read at the matching 3xxxx input register (same offset).
  • Signedness is not stated in the guide. Temperature values are listed as INT16 (they can be below zero); everything else as UINT16.
  • Points that take two registers (date/time and schedule start/stop times, 32-bit values) are left out because the guide does not state their word order.
  • Event/alarm discrete inputs read 1 while the event is active ('Active on Alarm').
  • Points marked in the guide as iCOM_SC100-only (compressors 3 and 4, condensers 3 and 4, customer inputs 3 and 4) are not present on SC31 units.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Vertiv Liebert HPC chiller with iCOM v4 (IntelliSlot Modbus)

What Modbus registers does the Vertiv Liebert HPC chiller with iCOM v4 (IntelliSlot Modbus) have?

This map lists 151 registers: 83 discrete inputs, 38 input registers, 30 holding registers. 30 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vertiv Liebert HPC chiller with iCOM v4 (IntelliSlot Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints Modicon-style numbers: discrete inputs 1xxxx, input registers 3xxxx, holding registers 4xxxx. Its RTU example asks for holding register 40051 with start offset 50 (0x0032), so subtract 10001 / 30001 / 40001 to get the wire address. Coils are printed as plain numbers on the same scale as the discrete inputs (coil 25 sits beside status 10025), so coil n is wire address n-1.

What are the minimum Modbus registers to integrate the Vertiv Liebert HPC chiller with iCOM v4 (IntelliSlot Modbus)?

Start with HR 486 System Info: System On/Off Control (System on/off control); IR 483 System Info: System Operating State (System operating state); IR 482 System Info: System Status (System status); IR 492 System Operations: Supply Fluid Temperature (Supply fluid temperature); IR 490 System Operations: Return Fluid Temperature (Return fluid temperature); HR 423 Supply (Outlet) Fluid: Supply Fluid Temp Set Point 1 (Supply fluid temperature setpoint 1); IR 504 System Operations: Compressor Utilization (Compressor utilisation); IR 505 System Operations: Ambient Air Temperature (Ambient air temperature); HR 514 System Event Acknowledge/Reset (Acknowledge / reset events).

How do I enable Modbus control of the Vertiv Liebert HPC chiller with iCOM v4 (IntelliSlot Modbus)?

Fit the Liebert IntelliSlot card the guide lists for the unit's controller (for iCOM v4 units: IS-485L for Modbus 485, IS-IPBML for Modbus IP / BACnet IP) and set its Modbus address and line speed on the card.

Where is the official Vertiv Liebert HPC chiller with iCOM v4 (IntelliSlot Modbus) Modbus documentation?

The source is Liebert IntelliSlot Modbus 485, Modbus IP and BACnet IP Reference Guide (SL-28170 Rev 9), revision 10-12 (printed as SL-28170_REV9_10-12). Vertiv doesn't publish it on its own website, so this map was re-typed from a free copy at https://ccontrols.com/support/dp/Liebert.pdf. It may be an older revision, so check it against the live unit.
