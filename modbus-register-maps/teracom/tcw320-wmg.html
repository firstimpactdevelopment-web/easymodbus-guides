Teracom TCW320x-WMG 1-Wire to Modbus gateway Modbus register map

Updated 19 November 2026

Short answer

The TCW320x-WMG is a Teracom gateway that reads up to 20 Teracom 1-Wire sensors (or DS18B20 probes) and publishes their readings on a fixed Modbus map over RS-485 RTU and Modbus TCP. Each sensor slot holds up to two float parameters; the map also has the serial settings, word-order switch and identity strings.

This page lists 52 Modbus registers for the Teracom TCW320x-WMG 1-Wire to Modbus gateway — 4 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Teracom’s own free documentation (linked below) and checked against it.

Integration notes: Teracom TCW320x-WMG 1-Wire to Modbus gateway

Integration in brief

Read the sensor parameters as floats from PDU 1010 onward with function 03, over RS-485 or Modbus TCP. Lock sensor positions in the web interface so slots do not move.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP is enabled or disabled on the Modbus page of the web interface (default port 502); the RTU slave address, baud and parity are set there too and apply after saving.

Byte order & addressing

  • Word order of every float is set by PDU 13.
  • The web Modbus page shows data bits and stop bits but does not let you change them (factory default 8 data, 1 stop).
  • Baud rate and framing written to PDU 11-12 only take effect after a power cycle.

Network setup

  • Factory network defaults: Ethernet variant 192.168.1.2; Wi-Fi variant in AP mode at 192.168.4.1.
  • Set RTU address/baud/parity on the Modbus page and save.

Watch out for

  • A missing or failed sensor reads NaN.

Notes on this map

  • 32-bit values follow the Data order register (PDU 13): 1 = most significant word first (default), 2 = least significant word first. The map shows the default, ABCD.
  • Sensor slot n uses PDU 1000 + 10n for parameter 1 and +2 for parameter 2; the unit depends on the sensor type found in that slot.
  • Left out: the 32-bit float/integer test-value registers (PDU 82-95).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Teracom TCW320x-WMG 1-Wire to Modbus gateway

What Modbus registers does the Teracom TCW320x-WMG 1-Wire to Modbus gateway have?

This map lists 52 registers: 52 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Teracom TCW320x-WMG 1-Wire to Modbus gateway Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints PDU (zero-based) addresses only and says so in its addressing section; send them as printed.

What byte order does the Teracom TCW320x-WMG 1-Wire to Modbus gateway use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Teracom TCW320x-WMG 1-Wire to Modbus gateway?

Start with HR 1010 Sensor 1 Parameter 1 (Sensor 1 parameter 1); HR 1012 Sensor 1 Parameter 2 (Sensor 1 parameter 2); HR 1020 Sensor 2 Parameter 1 (Sensor 2 parameter 1); HR 13 Data order (Word order); HR 14 Device code (Device code check).

How do I enable Modbus control of the Teracom TCW320x-WMG 1-Wire to Modbus gateway?

Modbus TCP is enabled or disabled on the Modbus page of the web interface (default port 502); the RTU slave address, baud and parity are set there too and apply after saving.

Where is the official Teracom TCW320x-WMG 1-Wire to Modbus gateway Modbus documentation?

The source is TCW320E-WMG / TCW320W-WMG User Manual (Revision R1.0), revision 2026-10, published free by Teracom at https://www.teracomsystems.com/download/tcw320x-wmg-1-wire-to-modbus-gateway-user-manual/.
