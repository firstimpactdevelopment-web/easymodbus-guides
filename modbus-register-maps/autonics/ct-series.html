Integration notes: Autonics CT series programmable counter / timer (Modbus RTU)

Integration in brief

Read input registers 301001-301013 in one FC04 request for LED status, present value and presets; write presets at 400001-400006 and use coil 0 (FC05 FF00) to reset.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set communication writing [COmW] (400156) to Enabled to allow Modbus writes; address, speed, parity and stop bits are in the communication group (also on the front panel).

Byte order & addressing

  • 32-bit values are low word first.
  • The bracketed hex number is the wire address; the 6-digit number is a reference only.

Network setup

  • Address 1..127, 2400-38400 bps, parity and stop bits set in the communication group.
  • Response waiting time 5..99 ms (RSwT).

Watch out for

  • Writing counter/timer group settings resets the count.

Notes on this map

  • Autonics does not offer a static public link to this manual (downloads go through its website); this is the unaltered Autonics document hosted by the distributor AutomationDirect.
  • Word order: the manual states that for two-word data the upper data sits at the higher address, e.g. 301004 = present value low word and 301005 = high word (CDAB).
  • Present and preset values are display counts; apply the decimal point from 400058 (counter) or the time range from 400102 (timer) yourself.
  • Changing counter or timer group parameters over Modbus resets the current value; preset and communication changes keep it.
  • Left out: prescale decimal point, prescale value and start value (400060-400064) and the time-range code table, whose printed layout is too garbled to transcribe reliably.
  • Broadcast commands are not supported. Autonics recommends FC06 over FC16 for PLC/HMI writes.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Autonics CT series programmable counter / timer (Modbus RTU)

What Modbus registers does the Autonics CT series programmable counter / timer (Modbus RTU) have?

This map lists 53 registers: 5 coils, 5 discrete inputs, 13 input registers, 30 holding registers. 32 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Autonics CT series programmable counter / timer (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row prints a 6-digit reference (000001/100001/300001/400001 style) followed by the hex protocol address in brackets, e.g. 301004 (03EB); the bracketed hex value is the wire address.

What byte order does the Autonics CT series programmable counter / timer (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Autonics CT series programmable counter / timer (Modbus RTU)?

Start with IR 1003 Present value of counter/timer (Present value); IR 1000 LED display status (Output/LED status); HR 0 PRESET2 (PRESET) setting value (PRESET2 setpoint); HR 2 PRESET1 setting value (PRESET1 setpoint); CO 0 Reset (Reset); IR 1005 Display unit (Decimal point / time range).

How do I enable Modbus control of the Autonics CT series programmable counter / timer (Modbus RTU)?

Set communication writing [COmW] (400156) to Enabled to allow Modbus writes; address, speed, parity and stop bits are in the communication group (also on the front panel).

Where is the official Autonics CT series programmable counter / timer (Modbus RTU) Modbus documentation?

The source is User Manual for Communication - Counters/Timers CT Series (MCC-CTC1-V1.3-EN). Autonics doesn't publish it on its own website, so this map was re-typed from a free copy at https://cdn.automationdirect.com/static/manuals/autonics/autonicscommmanual.pdf. It may be an older revision, so check it against the live unit.
