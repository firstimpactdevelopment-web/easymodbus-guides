Short answer

Danfoss's compact drive with a built-in RS-485 port. In Modbus RTU mode the FC-profile control word, bus reference, status word and main actual value sit at holding registers 50000-50210, and every parameter is reachable at ten times its parameter number (PNU). This map covers the control block, the speed limits and ramp-up time, the fault/warning words and the communication and watchdog settings.

This page lists 29 Modbus registers for the Danfoss iC2-Micro frequency converter (Modbus RTU) — 16 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Danfoss’s own free documentation (linked below) and checked against it.

Integration notes: Danfoss iC2-Micro frequency converter (Modbus RTU)

Integration in brief

Set P 10.1.1 = [2] Modbus RTU with the address, baud and parity in P 10.1.2-10.1.4, keep P 5.5.1.2 Control Source = FC Port, then write CTW to 50000 (bit 10 = 1) and the reference to 50010 and poll 50200/50210. Readouts sit at PNU x 10 (minus 1 on the wire), 32-bit values high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

P 10.1.1 Protocol = [2] Modbus RTU ([26] emulates the VLT Micro Drive FC 51 parameter format), P 10.1.2 address 1-247, P 10.1.3 baud, P 10.1.4 parity. P 5.5.1.1 Control Place Selection decides whether digital inputs, the control word or both are used; P 5.5.1.2 Control Source must be FC Port. STW bit 9 must be 1 (not local) for bus control.

Communication loss & watchdog

P 5.2.16 Watchdog Response (default Off; Freeze output, Stop, Jogging, Max. speed, Stop and trip, Qstop and trip, set-up select, Trip) runs when no telegram arrives within P 5.2.17 Watchdog Delay (0.5-6000.0 s, default 1.0 s).

Byte order & addressing

  • Parameter register = PNU x 10, request address = that minus 1.
  • 32-bit values are high word first (ABCD).
  • CTW bit 10 (data valid) must be 1 or the control word is ignored.
  • Coil 65 chooses whether parameter writes also go to EEPROM.

Network setup

  • Defaults: address 1, 9600 baud, even parity, 1 stop bit (protocol default is FC, not Modbus).
  • Modbus address range 1-247; 0 is broadcast (no response).

Watch out for

  • REF and MAV are percentages of the reference range (4000h = 100%), not Hz.
  • The guide does not list a conversion factor for most readouts, so this map leaves motor current, power and frequency parameters out; use MAV for output speed.

Notes on this map

  • 32-bit parameters are high word first: the guide reads P 5.5.3.3 at registers 3030/3031 and gets 0000 88B8 hex = 35000 = 35.000 Hz.
  • The guide gives a conversion factor only for a few parameters (P 5.8.3 and P 5.8.2 = 0.1 Hz, P 5.5.4.2 = 0.01 s, P 5.5.3.3 = 0.001 by its 35.000 Hz read example); its parameter tables list no conversion index per parameter. Readouts and settings whose factor the guide does not state (motor current, voltage, power, frequency, DC-link voltage, thermal loads, torque, reference/feedback readouts, ramp-down time, watchdog delay, hour and kWh counters) are left out rather than inferred from the decimals shown in the ranges, which are not always consistent (P 10.1.6 prints default 0.010 with range 1-500).
  • 8-bit parameters (uint8) are read as one 16-bit register. The int8 heatsink temperature (P 2.1.9) is left out because the sign extension in the register is not stated.
  • P 5.5.3.3 Reference Maximum is in the unit chosen in P 5.5.3.2 (default Hz), with 3 decimals per the guide's read example.
  • The guide's text example says P 5.5.3.11 is PNU 341 and 32-bit, but its parameter table gives PNU 314, int16 (and PNU 341 is Ramp 1 Accel. Time). P 5.5.3.11 is not listed here.
  • Array parameters (fault log, preset references, active fault list) use holding register 9 (40009) as the index pointer; set it before reading the array element.
  • Fault/warning word bit meanings and fault numbers are in the guide's troubleshooting chapter and are not reproduced here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Danfoss iC2-Micro frequency converter (Modbus RTU)

What Modbus registers does the Danfoss iC2-Micro frequency converter (Modbus RTU) have?

This map lists 29 registers: 1 coil, 28 holding registers. 16 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Danfoss iC2-Micro frequency converter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers derived from parameter numbers. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed 1-based (40001 is sent as 0000). A parameter's register is 10 x its parameter number (PNU), sent minus 1: P 5.5.3.3 (PNU 303) is register 3030, read at address 3029 (0x0BD5) in the guide's own example. CTW 50000, REF 50010, STW 50200 and MAV 50210 follow the same minus-1 rule. Coil 65 is sent as 64.

What byte order does the Danfoss iC2-Micro frequency converter (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Danfoss iC2-Micro frequency converter (Modbus RTU)?

Start with HR 49999 Control word (CTW) (CTW: start/stop/reset); HR 50009 Bus reference (REF) (REF: speed reference, 4000h = 100%); HR 50199 Status word (STW) (STW: ready/running/trip/warning); HR 50209 Main actual value (MAV) (MAV: output frequency, 4000h = 100%); HR 16899 P 5.1.1 Fault Word 1 (P 5.1.1 Fault word 1); HR 16919 P 5.1.4 Warning Word 1 (P 5.1.4 Warning word 1); HR 18549 P 5.1.11 Active Fault Number (P 5.1.11 Active fault number).

How do I enable Modbus control of the Danfoss iC2-Micro frequency converter (Modbus RTU)?

P 10.1.1 Protocol = [2] Modbus RTU ([26] emulates the VLT Micro Drive FC 51 parameter format), P 10.1.2 address 1-247, P 10.1.3 baud, P 10.1.4 parity. P 5.5.1.1 Control Place Selection decides whether digital inputs, the control word or both are used; P 5.5.1.2 Control Source must be FC Port. STW bit 9 must be 1 (not local) for bus control.

What happens when the Danfoss iC2-Micro frequency converter (Modbus RTU) loses Modbus communication?

P 5.2.16 Watchdog Response (default Off; Freeze output, Stop, Jogging, Max. speed, Stop and trip, Qstop and trip, set-up select, Trip) runs when no telegram arrives within P 5.2.17 Watchdog Delay (0.5-6000.0 s, default 1.0 s).
