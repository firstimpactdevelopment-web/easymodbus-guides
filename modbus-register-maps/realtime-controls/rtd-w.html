Short answer

Small Modbus RTU slave that joins the P1/P2 bus of Daikin Altherma HT hydroboxes and small inverter chillers. Holding registers set leaving-water and room setpoints, mode, on/off, domestic hot water and quiet mode; input registers return group status, temperatures x100, pump and compressor state, run hours and per-PCB data.

Integration notes: Realtime Control Systems RTD-W Modbus interface for Daikin Altherma HT hydrobox and small inverter chillers

Integration in brief

Set the Modbus address on SW1, wire DB/DA/GND, set H0008 to External or Changeover, then write H0001-H0006 for setpoints, mode and on/off and poll I0020-I0078 for status.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

H0008 = 1 (External) or 3 (Changeover, default) lets Modbus switch the unit; 2 (Local) ignores Modbus on/off.

Communication loss & watchdog

If P1/P2 communication is lost for one minute the RTD raises an alarm on the fault relay R2; an RS485 communication timeout is also shown on the LEDs.

Byte order & addressing

  • Temperatures in input registers are x100 and signed; setpoints in holding registers are whole °C.
  • Read at most 10 registers per request.

Network setup

  • RS485 D-Bus: DB(+), DA(-) and common GND, daisy chain only, up to 500 m without repeaters.
  • Factory serial settings 9600 baud, no parity, 1 stop bit.
  • Power 15..24 V DC, e.g. from X9A on the A3P board.

Watch out for

  • The RTD-W works as a SUB controller: a BRC21 must be configured as MAIN on the P1/P2 bus.

Notes on this map

  • The source is the French edition of the Realtime Control Systems installation instructions, from a Sonepar (distributor) file host. The maker's own site (realtime-controls.co.uk) was offline and no Daikin-hosted copy was found, so the link is marked unofficial.
  • All values are 16-bit unless stated. Temperatures marked 'x100' are signed: raw 2150 = 21.50 °C, raw 65036 = -5.00 °C. Holding-register setpoints are printed in whole °C with no x100 marking and are listed at scale 1.
  • Fault codes are in the 'RTD ASCII' format described in the RTD-NET instructions (two characters packed high byte / low byte).
  • Supported function codes: 03 and 04 (1..10 registers), 06, and 16 (1..10 registers).
  • Only PCB 01 of the per-PCB block is listed. For PCB xx add (xx-1) x 100 (PCB 02 leaving water = I0223).
  • The pump run-hour counter is 32-bit unsigned: the manual's data-type table says R holds the high word and R+1 the low word.
  • Control fields that the connected unit does not support read 32767 and ignore writes.
  • Sensor-input mirror registers I10001..I10006 are left out: their printed range (0..1) and values (0 / 100) disagree.
  • The Modbus address is 0..63 on SW1.3..SW1.8. Baud and parity can be changed from the defaults if needed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Realtime Control Systems RTD-W Modbus interface for Daikin Altherma HT hydrobox and small inverter chillers

What Modbus registers does the Realtime Control Systems RTD-W Modbus interface for Daikin Altherma HT hydrobox and small inverter chillers have?

This map lists 37 registers: 25 input registers, 12 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Realtime Control Systems RTD-W Modbus interface for Daikin Altherma HT hydrobox and small inverter chillers Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual states register base 0 and writes H0010 / I0010 for holding / input register 10, so the number after H or I is the wire address. Per-PCB input registers are numbered xx00..xx99 with xx = PCB 01..16; this file lists PCB 01 (I0122..I0147).

What byte order does the Realtime Control Systems RTD-W Modbus interface for Daikin Altherma HT hydrobox and small inverter chillers use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Realtime Control Systems RTD-W Modbus interface for Daikin Altherma HT hydrobox and small inverter chillers?

Start with HR 4 Space heating/cooling Modbus on/off (Space heating/cooling on/off); HR 3 Operating mode (Heating or cooling); HR 1 Leaving water setpoint, heating (Heating leaving water setpoint); HR 8 Control source for mode and on/off (Who may switch the unit); IR 23 Group average leaving water temperature (Leaving water temperature (x100)); IR 21 Group error (Group error); IR 22 Group error code (Error code); IR 20 P1P2 PCB count (Units found on P1/P2).

How do I enable Modbus control of the Realtime Control Systems RTD-W Modbus interface for Daikin Altherma HT hydrobox and small inverter chillers?
