Short answer

The Decision-Maker MPAC controllers are Kohler automatic transfer switch controllers sharing one Modbus map. It gives source A (1) and source B (2) voltages and frequencies, load current, contactor position and source availability, transition mode, time-delay status, accessory and I/O states, transfer statistics and write-only test and manual-operation commands. This map covers the monitoring block, nominal ratings, transition mode, I/O and accessory status, maintenance counters and the command registers.

This page lists 48 Modbus registers for the Kohler Decision-Maker MPAC 750/1200/1500 ATS controller — 10 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Kohler’s own free documentation (linked below) and checked against it.

Integration notes: Kohler Decision-Maker MPAC 750/1200/1500 ATS controller

Integration in brief

Poll 400001-400019 in one FC 03 read for contactor position, source availability, both sources' voltages and frequencies and load current. Use 401350 bit commands for remote tests and peak shave, and 401312-401319 for transfer statistics.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In SiteTech or on the controller enable Modbus (Modbus Server Port 0 / Modbus Server TCP), set the Modbus slave address (1-247) and baud rate (9600, 19200 or 57600), and for TCP the unit ID, IP address, subnet mask and gateway.

Byte order & addressing

  • Counters in 401300-401311 are high word first, unlike the LSW-first LONG type used by Kohler generator controllers.
  • 400045 packs source 1 rotation in bits 8-9 and source 2 rotation in bits 0-1.

Network setup

  • Parity (none) and stop bits (1) are fixed.
  • Register 409999 identifies the model: 23 = MPAC 1500, 27 = MPAC 1200, 26 = MPAC 750.

Watch out for

  • The general exception table caps reads at 50 registers and writes at 16.
  • Bit 7 of 401350 forces the switch to OFF; use with care on a live load.

Notes on this map

  • Factory communication settings: 19200 baud, no parity, 1 stop bit (parity and stop bits are not adjustable), Modbus TCP unit ID 2; the serial slave address is listed with default 0, so set it before use.
  • The 2-register history counters (401300-401311) are stated as most significant word first, so they are ABCD. 401012 (duration of last outage, 2 words) has no stated word order and is left out.
  • The guide puts 400039-400058 (including the transition override at 400039 and transition/operation modes at 400057) in its distributor-password setup group and says to send the data register and the password (400040, 400058) in the same request. Factory settings and calibration are also password protected and not listed.
  • Left out: synchronizing settings, time delays and trip points, I/O module events, expansion board states, accessory setup, load control, exerciser, common alarms, ATS strings, network/UART configuration, clock/DST, packed date fields, event history, current-based load control, prime power and min/max logging.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Kohler Decision-Maker MPAC 750/1200/1500 ATS controller

What Modbus registers does the Kohler Decision-Maker MPAC 750/1200/1500 ATS controller have?

This map lists 48 registers: 48 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Kohler Decision-Maker MPAC 750/1200/1500 ATS controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. This section prints 6-digit holding-register references starting at 400001, so 400001 is wire address 0 and 401350 is wire address 1349.

What byte order does the Kohler Decision-Maker MPAC 750/1200/1500 ATS controller use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Kohler Decision-Maker MPAC 750/1200/1500 ATS controller?

Start with HR 0 System Overview (Contactor position and source availability); HR 7 Source A L1-L2 Voltage (Source A L1-L2 voltage); HR 10 Source B L1-L2 Voltage (Source B L1-L2 voltage); HR 13 Source A Frequency (Source A frequency); HR 14 Source B Frequency (Source B frequency); HR 15 Current L1 (Load current L1); HR 741 Accessory Status (Accessory status (tests, peak shave)).

How do I enable Modbus control of the Kohler Decision-Maker MPAC 750/1200/1500 ATS controller?

In SiteTech or on the controller enable Modbus (Modbus Server Port 0 / Modbus Server TCP), set the Modbus slave address (1-247) and baud rate (9600, 19200 or 57600), and for TCP the unit ID, IP address, subnet mask and gateway.

Where is the official Kohler Decision-Maker MPAC 750/1200/1500 ATS controller Modbus documentation?

The source is Modbus Communications Protocol Operation (generator set, transfer switch and power monitor controllers) (TP-6113 12/21p), revision 2021-12, published free by Kohler at https://resources.kohler.com/power/kohler/industrial/pdf/tp6113.pdf.
