Toshiba BMS-IFMB0UEW-E Modbus RTU interface for ESTIA air-to-water heat pumps Modbus register map

Updated 19 November 2026

Short answer

The BMS-IFMB0UEW-E clips onto the AB remote-controller bus (AW-LINK or TU2C-LINK) of a Toshiba ESTIA hydro unit and answers as a Modbus RTU slave. Everything is a signed 16-bit holding register: zone and hot-water on/off, mode, setpoints, the special functions (auto temp, night setback, boost, frost protection, anti-bacteria), alarm status and code, sensor temperatures, running-hour counters, the setpoint limits and the interface's own configuration.

This page lists 56 Modbus registers for the Toshiba BMS-IFMB0UEW-E Modbus RTU interface for ESTIA air-to-water heat pumps — 12 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Toshiba’s own free documentation (linked below) and checked against it.

Integration notes: Toshiba BMS-IFMB0UEW-E Modbus RTU interface for ESTIA air-to-water heat pumps

Integration in brief

Connect the interface to the hydro unit's AB terminals (TB07 on 4/5 Series, TB04 on R32 1 Series) and to RS-485, then poll 40001-40025 with function 3 and write single registers with function 6.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step: set the hydro unit type (S1), slave address and baud rate (S3) and temperature format/termination (S4) on the interface's DIP switches; the values can also be read over Modbus.

Byte order & addressing

  • Function 16 is accepted but only with a length of 1; write one register per request.
  • Temperature reads of 0x8000 mean no sensor or a sensor error.
  • Temperatures are whole degrees unless DIP S4 bit 1 is ON, so the same register reads 45 or 450 depending on the switch.

Network setup

  • Serial format is 8 data bits, no parity, 2 stop bits (8N1-compatible); baud 2400/4800/9600 (default)/19200 via DIP S3.
  • Slave address 1-63 via DIP S3 (default 1).
  • Only one remote controller (header) may stay on the AB bus; a sub remote controller cannot be connected.
  • The AB bus between interface and hydro unit is unpolarised and limited to 50 m; RS-485 is polarised (A+, B-), up to 500 m, with 120 ohm termination at each end (on-board resistor via S4 bit 4).

Watch out for

  • Setting zone temperatures from Modbus may still give lower water temperatures, depending on the remote controller's FC/DN settings.

Notes on this map

  • Toshiba does not appear to host this manual publicly; the link is an unaltered copy of Toshiba Carrier Air-Conditioning Europe's manual on the Dutch distributor Intercool's download centre.
  • The manual states every register is a 16-bit signed holding register, so all entries are INT16 (the bit field 40066 is shown as BITMAP16).
  • Temperature scale is chosen by DIP switch S4 bit 1: whole degrees (x1, default) or decidegrees (x10). A further S4 switch selects Celsius (default) or Fahrenheit. The files' scale of 1 matches the default; set scale 0.1 if S4 bit 1 is ON.
  • The manual marks per register which of R32 1 Series, 5 Series and 4 Series supports it. Every listed register is marked for all three, except 40018 (not on 4 Series) and 40066 (R32 1 Series only).
  • The check-code list (section 6) maps alarm-code numbers to remote-controller codes such as A01 or E03; it is not copied here because the extracted table rows do not line up reliably.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Toshiba BMS-IFMB0UEW-E Modbus RTU interface for ESTIA air-to-water heat pumps

What Modbus registers does the Toshiba BMS-IFMB0UEW-E Modbus RTU interface for ESTIA air-to-water heat pumps have?

This map lists 56 registers: 56 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Toshiba BMS-IFMB0UEW-E Modbus RTU interface for ESTIA air-to-water heat pumps Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual gives the rule directly: start address in the request = printed register number - 40001. So 40001 is wire address 0 and 40201 is wire address 200.

What are the minimum Modbus registers to integrate the Toshiba BMS-IFMB0UEW-E Modbus RTU interface for ESTIA air-to-water heat pumps?

Start with HR 0 Zone1/2 ON/OFF setting/monitor (Zones on/off); HR 1 HOT WATER On/Off (Hot water on/off); HR 2 Zone1/Zone2 operation mode setting/monitor (Heat/cool mode); HR 3 Zone1 temperature setting (Zone 1 setpoint); HR 5 HOT WATER temperature setting (Hot water setpoint); HR 11 Alarm status (Alarm status); HR 12 Alarm code (Alarm code); HR 18 Outside temperature (Outside temperature); HR 22 Water outlet temperature (Water outlet temperature).

How do I enable Modbus control of the Toshiba BMS-IFMB0UEW-E Modbus RTU interface for ESTIA air-to-water heat pumps?

No enable step: set the hydro unit type (S1), slave address and baud rate (S3) and temperature format/termination (S4) on the interface's DIP switches; the values can also be read over Modbus.
