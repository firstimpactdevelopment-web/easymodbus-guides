Short answer

The PowerXL DC1 talks Modbus RTU on its RJ45 RS-485 socket. Eaton numbers every value by an ID: a small process-data block (command, speed reference, status/fault word, speed, current) plus parameter IDs. Every value is a single 16-bit register with an implied decimal point. This map covers the process data and the communication settings.

Integration notes: Eaton PowerXL DC1 compact drive (Modbus RTU)

Integration in brief

Write the speed reference to ID 2 and the command word to ID 1 (bit 0 = run), then read IDs 6-8 for status, speed and current. The control-source parameter must select Modbus first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set P-12 = 3 (Modbus control) or 4 (Modbus control with Modbus ramp times). DI1 must be held high (enable) when running from Modbus. Drive address, baud rate and comms timeout are sub-settings of P-36; parity is P-56.

Communication loss & watchdog

P-36 sub-setting 'Modbus RTU0 COM Timeout': 0 = no action, 1-4 = trip after 30 ms / 100 ms / 1 s / 3 s, 5-8 = ramp to stop after 30 ms / 100 ms / 1 s / 3 s. A Modbus timeout shows fault 50 (Sc-FO1).

Byte order & addressing

  • Register = ID - 1 on the wire; tools with a +1 offset take the ID directly.
  • Function codes 03, 06, 16 and 23 only; at most 11 registers per read.
  • The high byte of ID 6 is a fault number, not flags.

Network setup

  • P-36 holds the drive address (1-63, default 1), baud rate (9.6-115.2 kbit/s) and the comms timeout.
  • P-56 sets parity/stop bits; section 2.3.2 gives the default as no parity, 1 stop bit, 8 data bits.
  • The RS-485 link is on the RJ45 socket.

Watch out for

  • Without the DI1/STO enable the drive reports 'Stop' and will not run from Modbus.
  • Set bit 2 of the command word to reset a fault.

Notes on this map

  • Every value is one 16-bit register; the decimal point is implied (a displayed 0.3 A is sent as 3).
  • The manual does not state signedness for the process data; they are typed UINT16 because their ranges are non-negative (direction is a status bit).
  • Output power (ID 10) is left out: the summary table gives scale 1 but the detailed text says one decimal (53 = 5.3 kW). The power (ID 13) and voltage range (ID 14) words are left out because their meaning depends on the drive's kW/HP setting.
  • Fault numbers in the high byte of ID 6 for the DC1 (decimal, as printed in table 11): 0 no-Flt (no fault), 1 OI-b brake overcurrent, 2 OL-br brake resistor overload, 3 O-I output overcurrent, 4 I.t-trP motor overload, 5 PS-trp hardware overcurrent, 6 O.Volt DC overvoltage, 7 U.Volt DC undervoltage, 8 O-t heatsink overtemperature, 9 U-t undertemperature, 10 P-dEf defaults loaded, 11 E-trip external fault, 12 SC-ObS keypad/PC comms error, 13 FlT-dc DC ripple too high, 14 P-LOss input phase loss, 16 Th-flt heatsink thermistor fault, 17 dAtA-F memory error, 18 4-20 F analog input out of range, 19 dAtA-E memory error, 21 F-Ptc motor PTC, 22 FAn-F fan fault, 23 O-hEAt ambient too hot, 26 OUt-F output fault, 40-44 AtF-01..05 motor identification failed, 49 Out-Ph motor phase lost, 50 Sc-FO1 Modbus timeout, 51 Sc-FO2 CANopen timeout. The 'Stop' display (enable signal missing) is listed without a number and is not a fault.
  • Left out: f-max/f-min and the fixed frequencies (the table scales them as 3000 = 50.0 Hz, i.e. 60 counts per Hz); register 164 (P-36), which packs the address in the low byte, baud in bits 8-11 and timeout in bits 12-15; the analog-input registers 20/21 (scale 4096 = 100 % but range printed 0-1000); serial number words 29-32; run-hour words 25-28.
  • Left out: heatsink temperature (24); its range starts at -10 °C but the data-format cell is blank, so signedness is not stated.

Questions about the Eaton PowerXL DC1 compact drive (Modbus RTU)

What Modbus registers does the Eaton PowerXL DC1 compact drive (Modbus RTU) have?

This map lists 19 registers: 19 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Eaton PowerXL DC1 compact drive (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual numbers registers from ID 1. Its frame examples read status ID 6 with start address 0005h and write command ID 1 to address 0000h, so ID n is wire address n-1.

What are the minimum Modbus registers to integrate the Eaton PowerXL DC1 compact drive (Modbus RTU)?

Start with HR 0 Fieldbus command (Run/stop/reset command word); HR 1 Fieldbus speed reference (Speed reference (0.1 Hz)); HR 5 Status and fault word (Status bits and fault number); HR 6 Actual speed (Actual frequency); HR 7 Motor current (Motor current); HR 139 Local process data source (Control source must select Modbus).

How do I enable Modbus control of the Eaton PowerXL DC1 compact drive (Modbus RTU)?

Set P-12 = 3 (Modbus control) or 4 (Modbus control with Modbus ramp times). DI1 must be held high (enable) when running from Modbus. Drive address, baud rate and comms timeout are sub-settings of P-36; parity is P-56.

What happens when the Eaton PowerXL DC1 compact drive (Modbus RTU) loses Modbus communication?

P-36 sub-setting 'Modbus RTU0 COM Timeout': 0 = no action, 1-4 = trip after 30 ms / 100 ms / 1 s / 3 s, 5-8 = ramp to stop after 30 ms / 100 ms / 1 s / 3 s. A Modbus timeout shows fault 50 (Sc-FO1).
