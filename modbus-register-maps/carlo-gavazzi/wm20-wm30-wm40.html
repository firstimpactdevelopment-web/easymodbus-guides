Short answer

The WM20, WM30 and WM40 are Carlo Gavazzi's modular panel power analyzers. Unlike the smaller CG meters, live values are IEEE-754 floats (in base units) and energies are 64-bit counters in Wh/varh, both sent low word first. This map covers per-phase and system voltage, current, power, PF, frequency, asymmetry, phase sequence, total/partial/tariff energy, identification, RS485 settings and energy reset commands.

This page lists 79 Modbus registers for the Carlo Gavazzi WM20 / WM30 / WM40 power analyzers — 12 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Carlo Gavazzi’s own free documentation (linked below) and checked against it.

Integration notes: Carlo Gavazzi WM20 / WM30 / WM40 power analyzers

Integration in brief

Read input registers 0050h-008Fh as floats (low word first) for live values and 0500h-051Fh as UINT64 Wh/varh counters (least significant word first).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit an RS485 (or Ethernet) communication module. Change RS485 address/baud/parity in 1130h-1132h, then write 1 to 3052h (or power-cycle) to apply.

Byte order & addressing

  • Floats are low word first (CDAB).
  • 64-bit energy counters are least significant word first and in Wh/varh.
  • Up to 125 registers per read; functions 03/04 equivalent; 06 and 10h for writes.

Network setup

  • Terminate the last instrument and the host; above 1000 m use a line amplifier.
  • WM20/WM30 RS485 baud options: 9600, 19200, 38400, 115200; parity none/odd/even.

Watch out for

  • New RS485 settings take effect only after the update command 3052h or a power cycle.

Notes on this map

  • Float word order: the document lists the frame bytes as float bits 15-8, 7-0, 31-24, 23-16, i.e. low word first with MSB-first bytes (CDAB).
  • Integer word order: UINT16/UINT64 are MSB-first inside a word and LSW first across words (p. 10). Under this library's 64-bit convention CDAB means least significant word first with all four words reversed, which is exactly what the document describes: words arrive W0 (least) to W3 (most).
  • Float units are not printed separately; the variable names (V, A, W, VA, var, Hz, %) are the engineering units, so no scaling is applied.
  • Energy counters are in Wh / varh (not kWh); divide by 1000 for kWh.
  • Tariff energies (0524h-0583h) are WM40 only; RS485 settings at 1130h-1132h are documented for WM30 and WM20 only (WM40 uses a different communication module table, not mapped here).
  • Left out: the hour counter (0520h), whose value packs hours x100 plus minutes in the remainder rather than a plain scale; K-factor, temperature, analogue-input and the model-dependent 'A' rows at 0090h-009Ah, which overlap by model; odd/even THD, TDD, max/min/demand blocks; harmonic tables; module and alarm configuration; clock; record-file and special-register (42h) functions.
  • Removed on verification: total THD floats (00A0h-00B0h). The table names them 'THD tot ...' without any unit, and the document never says whether the float is a percentage or a ratio, so the scaling is ambiguous. (Asymmetry rows 008Ah/008Ch print '%' in the name and are kept.)

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Carlo Gavazzi WM20 / WM30 / WM40 power analyzers

What Modbus registers does the Carlo Gavazzi WM20 / WM30 / WM40 power analyzers have?

This map lists 79 registers: 67 input registers, 12 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Carlo Gavazzi WM20 / WM30 / WM40 power analyzers Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as a 6-digit Modicon number for function 04 (3xxxxx; first digit becomes 4 for function 03) beside the hex physical address placed in the frame. Wire address = physical address (300081 / 0050h is address 0x50). Setup and command rows are written with 06/10h and are listed as holding registers.

What byte order does the Carlo Gavazzi WM20 / WM30 / WM40 power analyzers use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Carlo Gavazzi WM20 / WM30 / WM40 power analyzers?

Start with IR 80 V L1-N (V L1-N (float)); IR 96 A L1 (A L1 (float)); IR 110 W system (W system (float)); IR 134 PF system (PF system); IR 136 Frequency (Frequency); IR 1280 Total kWh(+) (Total kWh(+) in Wh); IR 1288 Total kWh(-) (Total kWh(-) in Wh); IR 11 Carlo Gavazzi identification code (Model ID (WM20/30/40)).

How do I enable Modbus control of the Carlo Gavazzi WM20 / WM30 / WM40 power analyzers?

Fit an RS485 (or Ethernet) communication module. Change RS485 address/baud/parity in 1130h-1132h, then write 1 to 3052h (or power-cycle) to apply.
