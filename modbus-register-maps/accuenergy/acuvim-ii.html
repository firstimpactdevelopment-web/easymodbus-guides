Accuenergy Acuvim II Series Modbus register map

Updated 16 October 2026

Short answer

The Acuvim II is a panel-mount multifunction power and energy meter with an RS485 Modbus RTU port, plus optional expansion modules (second RS485, Ethernet with Modbus TCP, I/O). All data lives in holding registers addressed by hex number: system settings and status as 16-bit words, live readings as 32-bit floats from 4000H, energy as 32-bit integers from 4048H, THD as scaled 16-bit values. Relays and digital inputs on I/O modules use coil and discrete-input functions.

This page lists 102 Modbus registers for the Accuenergy Acuvim II Series — 48 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Accuenergy’s own free documentation (linked below) and checked against it.

Integration notes: Accuenergy Acuvim II Series

Integration in brief

Poll 4000H-403BH with function 03 (30 floats, high word first) for frequency, voltages, currents, power and PF, and 4048H-4059H for energy counters. Set Basic Parameter Mode 101DH = 1 so floats are already primary values.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Channel 1 must be set to Modbus (0FFEH = 0) from the front panel or software. Writable registers are changed with function 10H; relays on I/O modules are switched with function 05.

Byte order & addressing

  • All register data is read with function 03; the manual lists no function 04. Relays use functions 01/05 and digital inputs function 02.
  • Float readings are secondary-mode values unless Basic Parameter Mode 101DH is set to 1 (Primary); the default is Secondary.
  • Energy registers are integers scaled by the energy display mode, not floats.
  • A single 10H write may not span two register regions.

Network setup

  • Channel 1 defaults: address 1, 19200 bps, no parity with 1 stop bit (parity code 3).
  • When channel 2 uses the Ethernet module, the manual says to set channel 2 to 38400 bps and None1 parity.
  • Set wiring type (1003H/1004H), CT1/CT2 and PT ratios to match the installation before relying on readings.

Watch out for

  • System status flags (102EH) must be cleared after reading or new alarm/SOE records are not stored properly.
  • Writing 1 to Clear energy (1016H) erases the energy counters.

Notes on this map

  • Word order: the manual's read example returns frequency 50.00 Hz as 42 48 00 00 and voltages as 42 C7 CC CD, high word first; dword values are defined as high word first (Rx = high word x 65536 + low word). All 32-bit values here are ABCD.
  • IMPORTANT - primary vs secondary: Basic Parameter Mode (101DH) controls the real-time float block (4000H-4047H and 4600H-4605H). Its default is 0 = Secondary. Only with 101DH = 1 do the registers hold primary values, and only then are the scales and units in this map correct for voltage, current, power and demand. In secondary mode the manual gives primary voltage = value x PT1/PT2, current = value x CT1/CT2, power = value x (PT1/PT2) x (CT1/CT2) / 1000 (kW, kvar, kVA). For 333 mV, Rogowski (100 mV/50 Hz) and 80/100/200 mA CT options the manual says to use CT2 = 1 in that calculation, so the raw current value is then not a secondary-side ampere reading. This map cannot express a ratio taken from other registers, and PT1 is not mapped (see below), so set 101DH = 1 before using these registers. Frequency, power factor, unbalance and load type are the same in both modes.
  • Power, reactive power, apparent power and power demand floats are divided by 1000 to give kW, kvar and kVA (primary mode), so scale 0.001 is used with those units.
  • Energy scale depends on Energy Display Mode (1019H), default 0 = Primary: the energy table gives Rx/10 for primary mode, and the worked write example (0A9D4089H = 17807783.3 kWh) matches. Mode 1 (Secondary) is Rx/1000. Mode 2 is labelled 'Primary in 0.01kWh' in the settings table but grouped with Rx/1000 in the energy table and shown as 1 Wh resolution on the display menu, so its resolution is unclear. Scale 0.1 in this map is valid only with 1019H = 0, and each energy register says so.
  • Left out: Reactive and apparent power demand (4044H/4046H), because the table gives them each other's formula and unit.
  • Left out: channel 1/2 baud rate (1002H, 102FH): listed as 16-bit words with a 2400-115200 range, which cannot fit a word, so the encoding is unclear.
  • Left out: PT1 (1005H-1006H) and PT2 (1007H) because their decimal ranges (50.0 ...) are not matched by a stated scale.
  • The 0FFEH protocol register lists '2: BACnet MS/TP' in the table but its note says 1 selects BACnet, so only 0 = Modbus is given.
  • Not covered: 100 ms metering block (3000H), max/min, harmonics per order, sequence components, TOU, alarms, data logs, I/O module settings and SunSpec registers.
  • When writing with function 10H, one command may only modify one register region (system parameters, status, clock, alarm settings, I/O settings, logs).
  • Left out: net active and net reactive energy (4052H, 4056H). The table types them 'int32', but the manual's data-type section defines only word, int, dword (high word first) and float, so the signed 32-bit encoding and word order are not stated.

Questions about the Accuenergy Acuvim II Series

What Modbus registers does the Accuenergy Acuvim II Series have?

This map lists 102 registers: 2 coils, 4 discrete inputs, 96 holding registers. 48 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Accuenergy Acuvim II Series Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists each register as a hex address (e.g. 4000H) with its decimal equivalent (16384); that number is sent on the wire unchanged. Its example query for frequency uses start address 40 00H.

What byte order does the Accuenergy Acuvim II Series use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Accuenergy Acuvim II Series?

Start with HR 16384 Frequency (Frequency); HR 16386 Phase 1 voltage (Phase 1 voltage); HR 16402 Phase A current (Phase A current); HR 16418 Total system power (Total system power); HR 16442 Total power factor (Total power factor); HR 16456 Import active energy (Import active energy); HR 16458 Export active energy (Export active energy); HR 4125 Basic parameter mode (Primary/secondary mode for float readings).

How do I enable Modbus control of the Accuenergy Acuvim II Series?

Channel 1 must be set to Modbus (0FFEH = 0) from the front panel or software. Writable registers are changed with function 10H; relays on I/O modules are switched with function 05.
