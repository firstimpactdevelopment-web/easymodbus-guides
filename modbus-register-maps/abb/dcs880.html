ABB DCS880 DC drive (embedded Modbus RTU) Modbus register map

Updated 17 November 2026

Short answer

ABB's thyristor DC drive for armature and field control of DC motors. The control board's XD2D RS-485 port can run Modbus RTU, which puts a control word, two references, a status word and two actual values in the first six holding registers and maps every parameter to a holding register worked out from its group and index. This map covers that cyclic block plus the main armature, field, mains and power signals, the active fault codes and the comm-loss settings, all in 16-bit form.

This page lists 26 Modbus registers for the ABB DCS880 DC drive (embedded Modbus RTU) — 6 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ABB’s own free documentation (linked below) and checked against it.

Integration notes: ABB DCS880 DC drive (embedded Modbus RTU)

Integration in brief

Set 58.01 = Modbus RTU plus node, baud and parity, validate with 58.06 = Refresh settings, then set 06.08 Main control word source = EFB, 20.01 Command location = Main control word and the speed reference source to EFB reference 1. Write the control word and REF1 at 400001/400002 and poll the status word and actuals at 400004-400006.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

58.01 Protocol enable = Modbus RTU (disables the device-to-device link on XD2D). Set 58.03 Node address, 58.04 Baud rate and 58.05 Parity, then 58.06 Communication control = Refresh settings (or reboot). For control set 06.08 Main control word source = EFB, 20.01 Command location = Main control word, and 22.11/22.12 (speed) or 26.11/26.12 (torque) to EFB reference 1 or 2. Save fieldbus parameter writes with 96.16 Parameter save manually = Save.

Communication loss & watchdog

58.14 Communication loss action (No action / Fault / Last speed / Speed reference safe / Fault always / Warning), 58.16 Communication loss time (0-32.5 s, default 0.3 s) and 58.15 Communication loss mode (any message, or only CW/reference writes, resets the timer). Loss gives fault 6681 or warning A7CE.

Byte order & addressing

  • The control word is edge-triggered: bit 0 must go 0 to 1 for On and bit 3 must go 0 to 1 for Run.
  • Bit 10 Remote command must be 1 or the control word and references are ignored (bits 0-2 still act).
  • For holding registers the supported function-code table lists FC 03, FC 06, FC 0x16 (mask write) and FC 0x17 (read/write multiple); FC 16 is not in the list.
  • The drive handles 10 registers per 10 ms, so long block reads add response delay (about 22 ms for 20 registers).

Network setup

  • RS-485 on terminal XD2D of the control board; see the DCS880 hardware manual 3ADW000462 for termination.
  • Defaults: node 1, 19.2 kbit/s, 8 data bits, even parity, 1 stop bit.
  • Changes to group 58 take effect after 58.06 = Refresh settings or a reboot.

Watch out for

  • Coils mirror the control word bits and discrete inputs the status word bits plus DI states, but both tables number from 00001 without a 0/1-based statement, so they are not listed.

Notes on this map

  • Source host: ABB lists this manual as 3ADW000474, but its public library returns 'not available' for that number and no other ABB-hosted copy was found; this is a copy of the ABB document hosted by a US distributor.
  • Registers 400001-400006 are the defaults of 58.101-58.106 Data I/O 1-6 and can be re-pointed; Data I/O 7-24 (400007-400024) are user-selected and not listed.
  • Only 16-bit parameter registers are listed. The manual describes a 32-bit block (420000 + 200 x group + 2 x index, word order set by 58.34, default LO-HI) but prints only 16-bit (FbEq16) scaling, so no 32-bit registers are included.
  • Speed and torque signals (01.01-01.06, 01.17, 01.18) use 46.02 / 46.04 scaling, which depends on drive setup, so they are left out. References and actual values in the cyclic block are left unscaled for the same reason.
  • The manual's error-code register table is headed 400090-400100 but its rows are numbered 89-94, so those registers are left out.
  • 58.14 Communication loss action defaults to No action in the parameter list; the setup table shows Fault as the value to use for fieldbus control.
  • 01.24 follows 96.02 Unit selection (kW or hp); the unit shown assumes kW.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ABB DCS880 DC drive (embedded Modbus RTU)

What Modbus registers does the ABB DCS880 DC drive (embedded Modbus RTU) have?

This map lists 26 registers: 26 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB DCS880 DC drive (embedded Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual uses 6-digit holding register references 400001-465536, so 400001 is wire address 0. With 58.33 = Mode 0 (default) a 16-bit parameter gg.ii sits at 400000 + 100 x gg + ii, e.g. 01.21 -> 400121 = wire 120. Masters limited to 5 digits can reach 400001-409999 as 40001-49999.

What are the minimum Modbus registers to integrate the ABB DCS880 DC drive (embedded Modbus RTU)?

Start with HR 0 Control word (CW) (Control word: on/run/reset); HR 1 Reference 1 (REF1) (Reference 1 (speed reference)); HR 3 Status word (SW) (Status word: ready/running/fault); HR 4 Actual value 1 (ACT1) (Actual value 1); HR 109 01.10 Motor current in A (01.10 Motor current in A); HR 120 01.21 Armature voltage in V (01.21 Armature voltage, 0.1 V); HR 128 01.29 M1 field current in A (01.29 Field current, 0.1 A); HR 400 04.01 Tripping fault (04.01 Tripping fault code).
