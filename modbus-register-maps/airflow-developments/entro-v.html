Short answer

The Entro-V is a heat recovery ventilation unit whose control board acts as a Modbus RTU slave on RS-485. Only function 03 (read) and 06 (write single) are supported and every point is a single 16-bit register. The map covers on/off, fan speed stages and mode, temperatures and sensor values, output and input states, the set point and the alarm code.

Integration notes: Airflow Developments Entro-V heat recovery unit controller (Basic / Digital controller, Modbus RTU)

Integration in brief

Wire RS-485 to the MODBUS connector on the control board, poll address 1 at 9600 8N1 with FC03, and use FC06 to write. Start/stop with ID 1, set fan stages with IDs 101/102 and the set point with ID 128; watch ID 2 for faults.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is built into the control board. Slave address (ID 153), link speed (ID 154, 0 = 9600) and frame type (ID 155, 0 = N81 RTU) are service-level parameters in the full list.

Byte order & addressing

  • Only FC03 and FC06 are supported: no FC04, no FC16 multi-register writes.
  • IDs are 0-based wire addresses.
  • Fan speed stage values run 0 = Low, 1 = Mid, 2 = High, 3 = Stop.

Network setup

  • Defaults: address 1, 9600 baud, no parity, 8 data bits, 1 stop bit.
  • Fit a 120 ohm terminating resistor at each end of a long RS-485 line, as the manual advises.
  • Avoid duplicate addresses when several units share the bus.

Watch out for

  • The link to the digital controller panel uses its own Modbus address parameters (IDs 235/236), separate from the BMS slave address (ID 153).

Notes on this map

  • Airflow does not host this manual as a direct PDF on airflow.com that we could find; this copy sits in Airflow's product listing on the SpecifiedBy library and is the unaltered Airflow document (Airflow Developments Ltd footer).
  • Registers listed here are those in section 9.4 'Modbus Register List' (the IDs flagged for Modbus in the full parameter list). The full list on pp. 28-32 has more IDs (service settings, I/O assignment, timers); they are not flagged as Modbus points and are left out.
  • Temperatures have a -40 to 80 °C range with multiplier 0.1, so they are treated as signed 16-bit; the manual does not spell out the signed encoding.
  • The CO2 register (30) is printed with multiplier 0.1 and unit ppm; check against a known reading before relying on it.
  • Alarm code values come from the fault code list (Part III, p. 25).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Airflow Developments Entro-V heat recovery unit controller (Basic / Digital controller, Modbus RTU)

What Modbus registers does the Airflow Developments Entro-V heat recovery unit controller (Basic / Digital controller, Modbus RTU) have?

This map lists 34 registers: 34 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Airflow Developments Entro-V heat recovery unit controller (Basic / Digital controller, Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register list's ID column is the wire address. The manual's example frame reads the '2nd register' with register ID bytes 0x00 0x02, and the list starts at ID 0 (program version), so use the ID unchanged in the request.

What are the minimum Modbus registers to integrate the Airflow Developments Entro-V heat recovery unit controller (Basic / Digital controller, Modbus RTU)?

Start with HR 1 Unit on/off (Unit on/off); HR 2 Alarm code (Alarm code); HR 101 Fresh air fan speed stage (Fresh air fan speed stage); HR 102 Exhaust air fan speed stage (Exhaust air fan speed stage); HR 22 Supply air temperature (Supply air temperature); HR 20 Outdoor air temperature (Outdoor air temperature); HR 21 Return air temperature (Return air temperature); HR 128 Set temperature (Set temperature).

How do I enable Modbus control of the Airflow Developments Entro-V heat recovery unit controller (Basic / Digital controller, Modbus RTU)?

Modbus is built into the control board. Slave address (ID 153), link speed (ID 154, 0 = 9600) and frame type (ID 155, 0 = N81 RTU) are service-level parameters in the full list.
