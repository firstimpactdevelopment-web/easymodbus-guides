Short answer

The SGC 120 Mk II is DEIF's second-generation single genset controller with RS-485 Modbus RTU. Values can be read as holding registers (function 03) or input registers (function 04) at the same addresses. This map covers the 16-bit generator, mains, load and engine readings, run-time counters, the packed I/O and genset-status words and the mode-change command.

This page lists 53 Modbus registers for the DEIF SGC 120 Mk II Single Genset Controller — 1 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from DEIF’s own free documentation (linked below) and checked against it.

Integration notes: DEIF SGC 120 Mk II Single Genset Controller

Integration in brief

Poll holding registers 1-64 with function 03 (or 04) for live values and the DG status word for running/fault state. Write 2 (START), 1 (STOP) or 4 (AUTO) to register 0 with function 16.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the RS-485 communication mode to Modbus in the controller's communication menu and give it a server ID; see the user manual.

Byte order & addressing

  • Function 16 uses its own small write map: register 0 takes one mode key code at a time, 1 sets the DTC parent specifier. Reading those same numbers returns measurements instead.
  • Functions 03 and 04 return the same data.

Network setup

  • RS-485 server ID, baud rate and parity are set in the controller menu (see the user manual).

Watch out for

  • Phase frequencies are labelled R, Y, B (L1, L2, L3).

Notes on this map

  • Scaling values in the table (0.1, 0.01) are used as multipliers here even though the column header reads 10^-x; the values only make sense as multipliers, and the first-generation SGC tables use the same numbers as plain multipliers.
  • Left out: the energy counters 39-50 (listed as FLOAT32 CDAB but also with a 0.1 scaling, which leaves it unclear whether the float is already in kWh) and the run-hours overflow word at 60. Percentage load (30) is left out because its unit is printed as kW.
  • Left out: the alarm-state words 65-76. The table repeats the same bit range under different alarm words (for example two alarm groups both on register 68), so the layout cannot be read with certainty.
  • Word 77 packs inputs A-I at table bits 16 down to 8 and outputs A-F at bits 7 down to 2. Word 78 packs, from table bit 1 up: common notification, common warning, common electric trip, common shutdown, gen available, fail to start, stopped with fault, stopped normally, DG running, load on DG, load on mains, operation mode (bits 12-14: 100 manual, 101 auto, 110 scheduler), mains healthy, SGC mode (bit 16). The table numbers bits 1-16 without saying whether bit 1 is the least significant bit, so the words are listed whole.
  • Also not listed: the packed time-stamp bytes, the CPCB IV+, EGR and DTC blocks and the J1939 values passed through from the engine ECU.
  • See the user manual 4189341364 for wiring and the RS485 menu: https://deif-cdn-umbraco.azureedge.net/media/pf3dpmxu/sgc-120-mk-ii-user-manual-4189341364-uk.pdf

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the DEIF SGC 120 Mk II Single Genset Controller

What Modbus registers does the DEIF SGC 120 Mk II Single Genset Controller have?

This map lists 53 registers: 53 holding registers. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the DEIF SGC 120 Mk II Single Genset Controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables print plain register numbers starting at 0 (register 0 is the protocol revision / mode command), with no 4xxxx prefix, so the printed number is the request address. The same numbers work with function 03 and function 04.

What are the minimum Modbus registers to integrate the DEIF SGC 120 Mk II Single Genset Controller?

Start with HR 1 Generator L1-N voltage (Generator L1-N voltage); HR 7 Generator R frequency (Generator frequency); HR 23 Load L1 current (Load L1 current); HR 29 Load total power (Total kW); HR 56 Battery voltage (Battery voltage); HR 78 DG status word (Genset status flags); HR 0 Protocol revision (read) / DG mode command (write) (Mode-change command).

How do I enable Modbus control of the DEIF SGC 120 Mk II Single Genset Controller?

Set the RS-485 communication mode to Modbus in the controller's communication menu and give it a server ID; see the user manual.

Where is the official DEIF SGC 120 Mk II Single Genset Controller Modbus documentation?

The source is SGC 120 Mk II Modbus tables (4189341403 rev. C), published free by DEIF at https://deif-cdn-umbraco.azureedge.net/media/hbwholpu/sgc-120-mk-ii-modbus-tables-4189341403-uk.xlsx.
