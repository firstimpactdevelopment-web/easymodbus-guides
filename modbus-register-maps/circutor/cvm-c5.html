Circutor CVM-C5 Modbus register map

Updated 17 November 2026

Short answer

The CVM-C5 is a compact panel power analyzer from Circutor with an RS-485 Modbus RTU port. Every measured value is a 32-bit integer in two registers with fixed scaling (V x10, mA, Hz x10, % x10), read with function 03 or 04, each with instantaneous, maximum and minimum copies. This map covers voltages, currents, reactive and apparent power, frequency, THD, demand and the two-tariff energy counters plus the tariff selector.

This page lists 108 Modbus registers for the Circutor CVM-C5 — 1 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Circutor’s own free documentation (linked below) and checked against it.

Integration notes: Circutor CVM-C5

Integration in brief

Read with function 04 from 0x00 in two-register steps (maximum 20 variables / 40 registers per frame). Values are 32-bit integers, high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is the only protocol. Set peripheral number, speed, parity and stop bits in the setup menu (sections 4.6.18-4.6.23).

Byte order & addressing

  • The active tariff is selected by writing 0 or 1 to register 0x1388 with function 10.
  • Each measurement has maximum and minimum copies at separate addresses.

Network setup

  • Default: peripheral number 1, 9600 baud, no parity, 8 data bits, 1 stop bit.
  • Speeds 1200-19200 baud; data bits fixed at 8.

Watch out for

  • Limit each read to 20 variables (40 registers).

Notes on this map

  • Word order: the manual's example response gives register 1 = 0000 and register 2 = 084D for 212.5 V, so 32-bit values are high word first (ABCD). The manual states all parameters are 32 bits long.
  • Left out: active power, signed reactive power, power factor and cos phi (per phase and three-phase), because the manual does not state whether those Modbus values are signed.
  • Left out: the 'Maximum demand' register at 44-45, whose unit is printed as W/VA/mA, so its unit depends on the selected demand variable.
  • Left out: apparent energy (consumed and generated) because the units column prints kVAh for one and VAh for the other; CO2, cost and hours per tariff.
  • Energy counters are per tariff only (T1 and T2); there is no total register.
  • Frequency is scaled x10 on this model (not x100 as on the CVM-C10).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Circutor CVM-C5

What Modbus registers does the Circutor CVM-C5 have?

This map lists 108 registers: 107 input registers, 1 holding register. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Circutor CVM-C5 Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. All Modbus addresses in the manual are hexadecimal wire addresses. The manual's example reads L1-L2 voltage at initial register 2A and receives 0000 084D = 212.5 V, which matches the table entry 2A-2B with V x10 scaling.

What byte order does the Circutor CVM-C5 use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Circutor CVM-C5?

Start with IR 0 L1 phase-neutral voltage (L1 phase-neutral voltage (V x10)); IR 2 L1 current (L1 current (mA)); IR 66 Three-phase apparent power (Three-phase apparent power); IR 40 Frequency (Frequency (Hz x10)); IR 60 Active energy tariff 1 (Active energy tariff 1); IR 108 Active energy tariff 2 (Active energy tariff 2).

How do I enable Modbus control of the Circutor CVM-C5?

Modbus RTU is the only protocol. Set peripheral number, speed, parity and stop bits in the setup menu (sections 4.6.18-4.6.23).

Where is the official Circutor CVM-C5 Modbus documentation?

The source is CVM-C5 Instruction Manual (M026B01-03), published free by Circutor at https://docs.circutor.com/docs/M026B01-03.pdf.
