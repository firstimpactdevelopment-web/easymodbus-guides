Short answer

CONDUCTOR W4 is the Swegon room controller for rooms with measured supply and extract airflow plus waterborne cooling and heating, with optional CO2 control. This map covers its alarms, sensor temperatures, damper and valve outputs, airflow level settings in l/s, CO2 control limits, PI tuning and a 39xx commissioning block. Temperature setpoints and the measured airflow, pressure and CO2 readings are left out because the manual gives no scaling for them.

Integration notes: Swegon CONDUCTOR W4 room controller (airflow and water, Modbus RTU)

Integration in brief

Read 3x0028-3x0030 (temperatures x10), 3x0022 (application state) and 3x0055/3x0056 (damper positions); write 4x0002 for state and 4x0036/4x0042/4x0043 for airflow levels in l/s. Temperature setpoints, measured airflows and CO2 are not in this map because the manual gives no scaling for them.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the BMS address, baud, parity and stop bits in system parameters P_101-P_104 from the room unit (service level).

Byte order & addressing

  • Reference numbers use the 0x/1x/3x/4x prefix; subtract 1 inside each table.
  • The 4x39xx block (commissioning status, flow sensor settings, zero calibration) sits far above the normal parameter range.

Network setup

  • RS-485, Modbus RTU; the controller is a slave on the BMS bus.
  • Changes to the BMS parameters are made from the CONDUCTOR room unit.

Watch out for

  • Many values only matter in a given application state (manual, economy, night cool, timer); check 3x0022 before writing.
  • Register numbering differs between the W1, W3 and W4 tables; use the table for the exact model and software.

Notes on this map

  • Addresses are printed in Modicon form (0x coils, 1x discrete inputs, 3x input registers, 4x holding registers); wire address = number - 1 within each table.
  • Sensor temperatures and battery voltage carry an explicit 1:10 scaling. Room temperature (3x0060), changeover temperature (3x0061) and the room-unit setpoint/flow readings (3x0031/3x0032) give a unit but no scaling, so they are left out.
  • Left out: every temperature setpoint in the holding table (4x0021-4x0030, including the two 'TC/TH Not used' rows, and manual temperature 4x0063). The table gives °C ranges but no scaling, while the input temperatures are marked 1:10, so the raw format is not settled.
  • Also left out: the 16-register component name (ASCII byte order not given), application ID, serial number, software version and boot-year registers (no format given), and every Not used row.
  • BMS port settings are menu parameters P_101 (address 1-247), P_102 (baud 9.6/19.2/38.4 k), P_103 (parity odd/even/none) and P_104 (stop bits).
  • Left out: 4x3911 commissioning command (packs air and water states into the two bytes; the value list is cut off in the manual).
  • Also left out: the measured airflows (3x0057-3x0059), duct pressures (3x0034-3x0036) and room CO2 (3x0062), which carry only a unit (l/s, Pa, ppm) with no range or scaling; PID outputs 3x0049-3x0052 (signed -100 to 100 % range, signed format never stated); and the commissioning read-backs 4x3921-4x3924 and 4x3940, which give no unit or format.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Swegon CONDUCTOR W4 room controller (airflow and water, Modbus RTU)

What Modbus registers does the Swegon CONDUCTOR W4 room controller (airflow and water, Modbus RTU) have?

This map lists 119 registers: 4 coils, 48 discrete inputs, 28 input registers, 39 holding registers. 43 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Swegon CONDUCTOR W4 room controller (airflow and water, Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print 0x/1x/3x/4x reference numbers; subtract 1 for the wire address in each table (4x3921 = holding register 3920).

What are the minimum Modbus registers to integrate the Swegon CONDUCTOR W4 room controller (airflow and water, Modbus RTU)?

Start with IR 27 Temp sensor regulator (Regulator temperature sensor x10); IR 28 Temp sensor RU1 (Room unit 1 temperature x10); IR 21 Application state (Application state); HR 1 Application transition (Application transition (state request)); IR 54 SA Damper pos. (Supply air damper position); IR 55 EA Damper pos (Extract air damper position); HR 35 Normal flow SA1 (Normal supply airflow SA1); DI 5 Active alarms (Active alarms).

How do I enable Modbus control of the Swegon CONDUCTOR W4 room controller (airflow and water, Modbus RTU)?

Set the BMS address, baud, parity and stop bits in system parameters P_101-P_104 from the room unit (service level).
