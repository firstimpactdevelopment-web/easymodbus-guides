Schneider Electric PowerTag Energy wireless sensors via PowerTag Link gateway (Modbus TCP) Modbus register map

Updated 19 November 2026

Short answer

PowerTag Energy sensors clip onto breakers and report over radio to a PowerTag Link gateway, which serves each sensor as its own Modbus TCP server address (1-247). Every sensor exposes the same register block: currents, voltages, power and power factor as big-endian floats, and energy counters as 64-bit integers in Wh. Which registers a sensor fills depends on its type (63 A, M250/M630, F160/Rope).

This page lists 83 Modbus registers for the Schneider Electric PowerTag Energy wireless sensors via PowerTag Link gateway (Modbus TCP) — 20 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Schneider Electric’s own free documentation (linked below) and checked against it.

Integration notes: Schneider Electric PowerTag Energy wireless sensors via PowerTag Link gateway (Modbus TCP)

Integration in brief

Connect to the gateway on TCP port 502, use each sensor's Modbus address as the unit ID, and read 3000-3110 (floats) plus the 64-bit energy registers 3204-3212.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP is on by default on the gateway. The gateway gives each paired wireless device a Modbus address (1-247), which can be changed on its web pages.

Byte order & addressing

  • Unit ID selects the sensor, not the gateway; 255 addresses the gateway itself.
  • Energy is in Wh/VARh/VAh as signed 64-bit integers.
  • Not every register is filled by every sensor type.

Network setup

  • The gateway takes its IP address by DHCP by default; a static IPv4 address can be set on its web pages.
  • Check or edit each wireless device's Modbus address in that device's parameters on the web pages.

Watch out for

  • The gateway flags a communication-loss alarm when it hears nothing from a device for 6 times that device's communication period.
  • The guide lists two misprinted hex addresses; trust the decimal register numbers.

Notes on this map

  • The guide says 32-bit and 64-bit values are big-endian: most significant word first.
  • Read a sensor by using its Modbus server address (set per wireless device on the gateway web pages, 1-247). The gateway's own identification registers answer on server address 255.
  • Invalid or unavailable values read 0xFFC00000 (floats) or 0x8000000000000000 (64-bit energy).
  • Each register's description says which sensor types fill it: PowerTag 63 = A9MEM152x/154x/156x/157x, M250/M630 = LV43402x, F160/Rope = A9MEM1580/A9MEM159x.
  • Left out: the 'set partial counter' write registers (3260, 3268, 3276, 3284, 3292), demand timestamps (DATETIME), the PowerTag control-module, HeatTag, load-monitoring, configuration, diagnostic and synthesis-table registers.
  • Schneider's function code 100-4 (read scattered registers) is also accepted for most float registers; this map uses plain function 03.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Schneider Electric PowerTag Energy wireless sensors via PowerTag Link gateway (Modbus TCP)

What Modbus registers does the Schneider Electric PowerTag Energy wireless sensors via PowerTag Link gateway (Modbus TCP) have?

This map lists 83 registers: 83 holding registers. 20 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Schneider Electric PowerTag Energy wireless sensors via PowerTag Link gateway (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints register numbers in decimal and addresses in hex, with address = register - 1 (register 3000 is address 0x0BB7). Two hex cells in the table are misprinted (register 3228 shown as 0x09CB, register 5193 as 0x1488); wire addresses here follow the register-minus-one rule.

What byte order does the Schneider Electric PowerTag Energy wireless sensors via PowerTag Link gateway (Modbus TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Schneider Electric PowerTag Energy wireless sensors via PowerTag Link gateway (Modbus TCP)?

Start with HR 2999 RMS current on phase A (Phase A current); HR 3027 RMS phase-to-neutral voltage A-N (Phase A-N voltage); HR 3059 Total active power (Total active power); HR 3083 Total power factor (Total power factor); HR 3203 Total active energy delivered + received (non-resettable) (Total active energy (not resettable)); HR 3211 Total active energy received (non-resettable) (Total active energy received).

How do I enable Modbus control of the Schneider Electric PowerTag Energy wireless sensors via PowerTag Link gateway (Modbus TCP)?

Modbus TCP is on by default on the gateway. The gateway gives each paired wireless device a Modbus address (1-247), which can be changed on its web pages.
