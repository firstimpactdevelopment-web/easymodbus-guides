Short answer

The Optyma iCO2 gateway exposes Danfoss's CO2 condensing units to a supervisor over RS-485 Modbus RTU. All values are single 16-bit holding registers addressed by PNU. This map covers the main switch, suction setpoint, day/night clock, high/receiver/suction pressures, temperatures, fan and compressor speed, valve openings and status.

This page lists 36 Modbus registers for the Danfoss Optyma iCO2 gateway (OP-MPAM015 / OP-MPAM005) — 7 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Danfoss’s own free documentation (linked below) and checked against it.

Integration notes: Danfoss Optyma iCO2 gateway (OP-MPAM015 / OP-MPAM005)

Integration in brief

Read the pressures, temperatures and speeds with function 03 and use the summary alarm and control state for status. Write r12 Main switch and r23 suction setpoint with function 06.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the slave address with parameter o03 on the MMILDS display.

Byte order & addressing

  • Request PNU - 1 on the wire (PNU 100 = address 99).
  • Every value is one 16-bit holding register; one decimal in the list means the raw value is x10, two decimals x100.

Network setup

  • Set the slave address with o03 on the MMILDS display.
  • Line settings: even parity, 8 data bits, 1 stop bit; the baud rate switches automatically between 19200 and 38400.

Watch out for

  • The list remarks 'MBP CDU-ECU can receive only' against r23 Suction pressure setpoint; check the unit variant before relying on writes to it.
  • Writes are also accepted by broadcast (address 0).

Notes on this map

  • Scale follows the 'Decimals' column: 1 decimal = value x10 on the wire (127 = 12.7), 2 decimals = x100. The SW version row has no decimals entry and is left unscaled.
  • The list header says all values are in °C / bar(g), while the unit column prints °C/°F and bar/PSI. Units here follow the header.
  • The alarm list (PNU 20000-20021) is left out: its PDF layout does not pair each alarm code with a PNU unambiguously.
  • Baud rate switches automatically between 19200 and 38400; even parity, 8 data bits, 1 stop bit.
  • Signedness is not printed; registers with negative minimums are listed as INT16.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Danfoss Optyma iCO2 gateway (OP-MPAM015 / OP-MPAM005)

What Modbus registers does the Danfoss Optyma iCO2 gateway (OP-MPAM015 / OP-MPAM005) have?

This map lists 36 registers: 36 holding registers. 7 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Danfoss Optyma iCO2 gateway (OP-MPAM015 / OP-MPAM005) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide states every PNU is the register address plus 1: PNU 100 is requested as 0x63 (99).

What are the minimum Modbus registers to integrate the Danfoss Optyma iCO2 gateway (OP-MPAM015 / OP-MPAM005)?

Start with HR 116 r12 Main switch (Main switch); HR 99 r23 Ts Ref (Suction setpoint); HR 10029 u01 Pc bar (High pressure); HR 10035 U23 Po (Suction pressure); HR 10037 U25 T Ambient (Ambient temperature); HR 10028 u 52 CompCap% (Compressor speed %); HR 2540 EKC Error (Summary alarm); HR 2006 Ctrl. State (Control state).

How do I enable Modbus control of the Danfoss Optyma iCO2 gateway (OP-MPAM015 / OP-MPAM005)?

Set the slave address with parameter o03 on the MMILDS display.
