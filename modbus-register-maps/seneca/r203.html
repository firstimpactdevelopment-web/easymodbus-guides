Short answer

The Seneca R203 is a DIN-rail three-phase network analyzer with harmonic analysis, digital I/O and a data logger. It serves Modbus TCP on Ethernet and Modbus RTU on RS-485 from one holding-register table. This map covers identity and status, instantaneous electrical values, THD, fundamentals, 64-bit energy counters, system values and the two pulse counters.

This page lists 88 Modbus registers for the Seneca R203 three-phase power analyzer (Ethernet + RS-485) — 33 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Seneca’s own free documentation (linked below) and checked against it.

Integration notes: Seneca R203 three-phase power analyzer (Ethernet + RS-485)

Integration in brief

Read the instantaneous float block 100-187 in one or two requests, and the three-phase 64-bit energy totals at 1878-1905. Status at 17 flags reversed CTs and wiring errors during commissioning.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The Modbus TCP server and RTU slave are active by default. Network and serial parameters are set with the Easy Setup 2 software or the web server.

Communication loss & watchdog

The manual documents a Modbus TCP connection timeout (default 60 s) that closes idle client connections; no output watchdog is described.

Byte order & addressing

  • Table offsets are the wire addresses; 4x numbers are offset + 40001.
  • 32-bit floats are MSW first and 64-bit energies MMSW first as printed in the tables.

Network setup

  • Factory IP is 192.168.90.101: change it before putting a second unit on the same network.
  • RS-485 defaults to 38400 baud, 8 data bits, no parity, 1 stop bit; the manual does not print a default RTU station address.

Watch out for

  • Check status bits 7-12 after wiring: reversed CTs and voltage/current mismatches are flagged there.
  • Power sign follows the quadrant convention: negative active power means generation.

Notes on this map

  • Only function codes 03, 06 and 16 are supported; everything is a holding register.
  • Every 32-bit row is marked MSW at the lower address and every 64-bit energy is marked MMSW first, so the map uses ABCD. The manual says the two words can be swapped when reading; this map follows the order printed in the tables.
  • Energy totals are in Wh / VARh / VAh as unsigned or signed 64-bit integers as printed.
  • Left out: the per-harmonic voltage and current tables, the averaged and min/max values from 41497 upward, and the L1 net active energy (41843), which is typed UNSIGNED64 while its L2/L3 siblings are SIGNED64.
  • Left out: the per-phase apparent energy rows 41867-41878, whose register name says reactive energy while the description says apparent energy.
  • Factory network settings: static IP 192.168.90.101, gateway 192.168.90.1, Modbus TCP port 502, TCP station address 1; RS-485 38400 baud 8N1.
  • RW* registers live in flash and tolerate about 10,000 writes.
  • Left out: the demand averaging time (45075), typed 32-bit but printed as a single row with no MSW/LSW marking.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Seneca R203 three-phase power analyzer (Ethernet + RS-485)

What Modbus registers does the Seneca R203 three-phase power analyzer (Ethernet + RS-485) have?

This map lists 88 registers: 88 holding registers. 33 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seneca R203 three-phase power analyzer (Ethernet + RS-485) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each table row prints the 4x number (40001) beside a 0-based ADDRESS OFFSET (0); the manual's addressing chapter says the offset is the 0-based address. Request the offset on the wire.

What byte order does the Seneca R203 three-phase power analyzer (Ethernet + RS-485) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Seneca R203 three-phase power analyzer (Ethernet + RS-485)?

Start with HR 100 Voltage L1-L2 (Line voltage L1-L2); HR 106 Current L1 (Current L1); HR 168 Active power total (Total active power); HR 174 Power factor total (Total power factor); HR 144 Frequency L1 (Frequency); HR 1878 Active energy imported total (Imported active energy total); HR 1882 Active energy exported total (Exported active energy total); HR 17 Status (Status and wiring error flags).

How do I enable Modbus control of the Seneca R203 three-phase power analyzer (Ethernet + RS-485)?

The Modbus TCP server and RTU slave are active by default. Network and serial parameters are set with the Easy Setup 2 software or the web server.

What happens when the Seneca R203 three-phase power analyzer (Ethernet + RS-485) loses Modbus communication?

The manual documents a Modbus TCP connection timeout (default 60 s) that closes idle client connections; no output watchdog is described.
