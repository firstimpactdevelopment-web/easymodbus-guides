Short answer

The SGxL family are signal conditioners that turn DC, thermocouple or RTD inputs into analog output signals, with an RS-485 Modbus RTU port. Every item is a signed 16-bit register. The map covers input and output range settings, filtering, manual output, communication settings, the measured input, output value and the status word.

Integration notes: Shinko Technos SGxL signal conditioner series (Modbus RTU)

Integration in brief

Wire RS-485, set the instrument number on the keypad (default 1, 38400 bps, 8 bits odd parity), then read input value 00B0H, output value 00B1H and status 00B2H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is always on. Set instrument number, speed, data bit/parity, stop bit and response delay in Communication setting mode, then choose Save.

Byte order & addressing

  • Serial RS-485 and the console (USB tool cable) cannot be used together; unplug the tool cable for Modbus.
  • Writing communication settings over the bus takes effect on the unit; update the master to match.

Network setup

  • Factory defaults: instrument number 1, 38400 bps, 8 data bits, odd parity, 1 stop bit, 10 ms response delay.
  • Speeds 9600, 19200 or 38400 bps; up to 31 units on one line.

Watch out for

  • Exception 18 (12H) is returned while the keypad is in setting mode.
  • Non-volatile memory is good for about one million writes; 0002H is the exception and is not stored.

Notes on this map

  • Output 2 items (0040H-0050H) are left out: the manual marks them as console-software data that cannot be used.
  • Input type codes are not listed here because the code table changes with model and input group (pp. 15-16).
  • 0001H-0002H accept single-register function 03/06 only; 0010H-0084H also accept function 10H; read-only items accept 03 or 04.
  • All data are 16-bit two's complement and values with a decimal point are sent without it.
  • Multi-Display character registers 0070H-0077H are omitted (front-panel label characters).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Shinko Technos SGxL signal conditioner series (Modbus RTU)

What Modbus registers does the Shinko Technos SGxL signal conditioner series (Modbus RTU) have?

This map lists 46 registers: 46 holding registers. 41 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos SGxL signal conditioner series (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are listed as hex data items (0001H) that go into the request unchanged. The manual adds that the matching Modicon holding-register number is the item in decimal plus 40001 (0001H = 40002).

What are the minimum Modbus registers to integrate the Shinko Technos SGxL signal conditioner series (Modbus RTU)?

Start with HR 176 Input value (Measured input value); HR 177 Output 1 output value (Output 1 value); HR 178 Status flag (Over/underscale and mode status); HR 19 Decimal point place (Input decimal point); HR 20 Output 0% value (Input value at 0% output); HR 21 Output 100% value (Input value at 100% output).

How do I enable Modbus control of the Shinko Technos SGxL signal conditioner series (Modbus RTU)?

Modbus RTU is always on. Set instrument number, speed, data bit/parity, stop bit and response delay in Communication setting mode, then choose Save.

Where is the official Shinko Technos SGxL signal conditioner series (Modbus RTU) Modbus documentation?

The source is Communication Instruction Manual SGxL (No. SGxL1CE3), revision 2022-03, published free by Shinko Technos at https://shinko-technos.co.jp/e/manual/english/SGxL1CE3.pdf.
