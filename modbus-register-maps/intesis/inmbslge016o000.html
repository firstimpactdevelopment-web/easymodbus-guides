Short answer

Multi-unit Modbus server on the LG PI485 bus. Each configured indoor unit (AC, ventilation, DX kit or air-to-water) gets a 100-register block with control, temperatures, status and a 32-bit energy counter; registers 0..18 send commands to all units. Modbus RTU and Modbus TCP run together.

Integration notes: Intesis (HMS Networks) INMBSLGE016O000 LG VRF to Modbus RTU / TCP gateway (16 / 64 indoor units)

Integration in brief

Add the units in Intesis MAPS, send the project, then poll each IU x 100 block. Write on/off, mode, fan and setpoint (tenths) per unit or use registers 0..18 for building-wide commands.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Units must be configured in MAPS; their index there decides the register block.

Byte order & addressing

  • All registers are 16-bit signed except the 32-bit energy counter (high word first).
  • Read with FC03 or FC04; write with FC06 or FC16.
  • Undefined addresses in the 0..20000 poll range read back 0; the manual also says invalid addresses return a Modbus exception code.

Network setup

  • All Modbus settings (RTU slave number, baud 1200..115200, parity, stop bits, RS-485 or RS-232, TCP port, IP) are set with the Intesis MAPS tool over the USB console port or Ethernet.
  • Factory IP is 192.168.100.246 with DHCP enabled.
  • Modbus RTU and Modbus TCP can be used at the same time.
  • Port B carries Modbus RTU on B1, B2 and B3 (SGND). The manual prints the B1/B2 polarity both ways in two sections, so check the terminal label. A DIP switch enables 120 ohm termination and bias.
  • Port A connects to the LG PI485 bus: A3 = BUS B, A4 = BUS A.

Watch out for

  • Mode codes depend on unit type: DX and air-to-water units accept only 0 Auto, 1 Heat and 4 Cool.

Notes on this map

  • Only unit index 1 is listed. For index IU add (IU-1) x 100 (IU 2 on/off = 200).
  • All registers are 16-bit signed except Accumulated Power Consumption (IU*100+29), which the manual footnotes as 32-bit unsigned in standard Modbus big-endian (MSB/LSB) format; it is listed as UINT32 high word first and spans IU*100+29 and +30.
  • Humidity (IU*100+17) is left out: its value column repeats '0-Off, 1-On', so its scale and unit are not given.
  • Temperatures are tenths of °C or °F per the 'LG Temperature Units' MAPS setting; °C shown.
  • Registers 7 and 8 are left out: the manual names them 'On / Off for VENT and DX (all units)' but their value text reads 'Set Fan Speed Auto / Low' (the same as registers 12 and 13), so their action is unclear.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious.
