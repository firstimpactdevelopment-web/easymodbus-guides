Updated 19 November 2026

Short answer

The WXT530 series are compact Vaisala weather transmitters that measure wind, pressure, temperature, humidity, rain and (WXT536) external inputs. From firmware 3.85 the RS-485 user port can run Modbus RTU. All values are 16-bit integers with a scale factor; this map covers the configuration holding registers and the instant, min, max and average input registers in metric and imperial units.

This page lists 96 Modbus registers for the Vaisala WXT530 series weather transmitters (Modbus RTU) — 11 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Vaisala’s own free documentation (linked below) and checked against it.

Integration notes: Vaisala WXT530 series weather transmitters (Modbus RTU)

Integration in brief

Read input registers 11-51 (function 04) for the metric weather values; divide by the scale factor. Holding registers 1-11 hold the configuration.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Order with the RS-485 Modbus option (order code WXT53XU...), or on an existing unit with firmware 3.85 or newer switch from CLI to Modbus with Vaisala Configuration Tool 2.62+ or the service-port command ?XU,M=M!.

Byte order & addressing

  • Register numbers start at 1; subtract 1 for the wire address.
  • Precipitation counters saturate; write 0x3247 to holding register 8 to reset them.

Network setup

  • Factory Modbus settings: address 1, 19200 baud, 8 data bits, even parity, 1 stop bit on the RS-485 user port.
  • Change the address in holding register 10; baud, parity and stop bits can only be changed in CLI mode (?XU command), then switch back to Modbus.

Watch out for

  • The RS-232 service port always uses CLI and cannot be used at the same time as the Modbus user port.
  • Writing 0x0F to holding register 11 drops the unit out of Modbus mode.
  • Switching between CLI and Modbus mode resets the accumulated precipitation values; moving an old unit to Modbus also rolls settings back to defaults.
  • Firmware updates are only possible in CLI mode.

Notes on this map

  • Holding registers 1-11 hold configuration and functions (read with function 03, write with function 16); measurements and device status are input registers (function 04).
  • Every value is a single 16-bit register; there are no 32-bit values.
  • Values are stored as value x scaling factor; divide the raw value by the listed factor. Signed values read 32767 when invalid or unavailable, unsigned values 65535.
  • Available quantities depend on the model; input registers 3-8 tell which parameters and sensors are present (high/low byte 00 = available, 07 = not available).
  • Do not poll faster than the update interval of the value (for example 1 min for averages).
  • Tipping bucket rain gauges and level sensors are not supported over Modbus.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Vaisala WXT530 series weather transmitters (Modbus RTU)

What Modbus registers does the Vaisala WXT530 series weather transmitters (Modbus RTU) have?

This map lists 96 registers: 85 input registers, 11 holding registers. 11 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vaisala WXT530 series weather transmitters (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every register table prints both the 1-based register number and the hex address (register 1 = 0x0000), and the text refers to holding register number 10 as 0x0009; the hex address is what goes on the wire.

What are the minimum Modbus registers to integrate the Vaisala WXT530 series weather transmitters (Modbus RTU)?

Start with IR 31 Air temperature instant (Air temperature); IR 10 Relative humidity instant (Relative humidity); IR 14 Relative air pressure instant (Relative pressure); IR 42 Wind speed instant (Wind speed); IR 18 Wind direction instant (Wind direction); IR 50 Precipitation intensity (Rain intensity).

How do I enable Modbus control of the Vaisala WXT530 series weather transmitters (Modbus RTU)?

Order with the RS-485 Modbus option (order code WXT53XU...), or on an existing unit with firmware 3.85 or newer switch from CLI to Modbus with Vaisala Configuration Tool 2.62+ or the service-port command ?XU,M=M!.

Where is the official Vaisala WXT530 series weather transmitters (Modbus RTU) Modbus documentation?
