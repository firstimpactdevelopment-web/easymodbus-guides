Short answer

Grundfos DDA diaphragm dosing pumps expose one Modbus register map whether they talk through the built-in SoftCIM ports (DDA model C) or a CIM module in a CIU 900. Control registers start/stop the pump, pick the operating mode and write setpoints such as the manual dosing rate and batch volume; status and measurement registers report the actual mode, fault and warning codes, dosing capacity, backpressure, total volume and tank level. 32-bit values are split into HI/LO register pairs.

Integration notes: Grundfos SMART Digital DDA dosing pump (SoftCIM, CIM 200 / CIM 500)

Integration in brief

Turn on Bus/Cloud control in the pump (HMI or Grundfos GO), then write 00101 bit 0 = 1 (RemoteAccessReq), choose the mode in 00105, write the setpoint (e.g. 00106-00107 in 0.1 ml/h) and send 00104 = 0 to start. Watch 00201 bit 0 to confirm remote control and poll 00204/00217/00218 for running, fault and warning.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the pump HMI or the Grundfos GO app set Settings > Communication > Bus/Cloud control = On. Then set 00101 bit 0 (RemoteAccessReq) = 1; without it all control bits are ignored. Relays and the analog output answer Modbus only when their function is set to Bus control in the pump.

Communication loss & watchdog

A fixed 10 s communication watchdog is switched on the first time Bus/Cloud control is enabled; it can be turned off or on with 00102 bit 2 (persistent). If Modbus traffic stops for more than 10 s the pump stops dosing and raises alarm 15; it resumes when communication returns.

Byte order & addressing

  • Register numbers are 1-based: 00101 goes out as address 100.
  • Commands in 00103 act on a rising edge; with AutoAckControlBits (00005) = 0 you must write the bit back to 0 before the next command.
  • ReqStop cannot stop the pump while it is de-aerating.

Network setup

  • DDA model C (SoftCIM RTU): in Grundfos GO, Settings > Communication > RS485 AYB: protocol Modbus RTU, address 1-247, 9600/19200/38400 baud, parity and stop bits; the M12 port needs a termination plug at the line end.
  • DDA model C (SoftCIM TCP): Settings > Communication > Ethernet RJ45: Ethernet On, protocol Modbus TCP, DHCP or static IP, TCP port (default 502).
  • CIM 200: the slave address is set in the pump menu (its hex rotary switches are not used with DDA). SW4/SW5 select 9600 (OFF/ON), 19200 (OFF/OFF, default), 38400 (ON/OFF) or software-defined (ON/ON); SW3 OFF = even parity 1 stop, ON = no parity 2 stop; SW1+SW2 ON = 150 ohm termination in.
  • CIM 500: set the rotary switch to Modbus TCP and set the IP in its web server (default 192.168.1.100, user admin); the Modbus TCP IP must differ from the web server IP.

Watch out for

  • If Bus/Cloud control is not enabled in the pump, 00201 bit 0 stays 0 and no write takes effect.
  • With Bus/Cloud control on, settings can no longer be changed from the pump HMI or GO app.
  • Measured capacity and pressure read nothing useful unless FlowControl (00102 bit 1) is enabled.

Notes on this map

  • Every block can be read with function 03 or 04 (same data); this map lists them as holding registers. Coils are not supported.
  • 32-bit values are register pairs named ...HI at the lower address and ...LO at the next. The profile's own troubleshooting sections (10.1.5 and 10.2, pp. 31-32) give the rule value = HI x 65536 + LO, so the high word comes first (ABCD).
  • The profile says counters and scaled values are unsigned integers unless stated otherwise; no register here is marked signed.
  • Left out: RTC set/read registers 00117-00122 and 00220-00225 (one BCD byte per register, no matching data type here); WarningBits 00219 (the profile lists 'Byte 1' and 'Byte 2' without saying which is the low byte); DosingPressureMax 00301 (scale column just says 'Bar'); PulseInputFrequency 00309 (unit printed as 'Hz/min'); RunTime 00321-00322 (no unit) and OperatingHours 00323-00324 (named hours but scaled in seconds); PropDosingTargetConcentration 00336-00337 (its LO register carries the wrong name); tank low-limit and process-flow sensor settings 00340-00346; alarm simulation block 00701 onward; GENIbus counters 00021-00028.
  • FaultCode and WarningCode hold one event code each; only one alarm can be shown at a time. Event codes 210, 211, 35, 208, 36, 37, 17 and 169 need FlowControl enabled.
  • Not every setting exists on every pump: for example Timer mode is DDA XL only, while HMI batch, proportional dosing, minimum-pressure monitoring and max. capacity are DDA model C only (see the overview table on pp. 20-21).
  • The defaults above are the CIM 200's (19200 baud, even parity, 1 stop bit). The built-in SoftCIM Modbus RTU port on DDA model C defaults to 9600 baud; its parity and stop bits are set in the pump HMI or GO app.

Questions about the Grundfos SMART Digital DDA dosing pump (SoftCIM, CIM 200 / CIM 500)

What Modbus registers does the Grundfos SMART Digital DDA dosing pump (SoftCIM, CIM 200 / CIM 500) have?

This map lists 58 registers: 58 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Grundfos SMART Digital DDA dosing pump (SoftCIM, CIM 200 / CIM 500) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as 5-digit numbers from 00001. The profile says register X is sent as X-1 in the telegram (its example: 00115 SetOutputRelays goes out as 00114), so 00101 is wire address 100.

What byte order does the Grundfos SMART Digital DDA dosing pump (SoftCIM, CIM 200 / CIM 500) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Grundfos SMART Digital DDA dosing pump (SoftCIM, CIM 200 / CIM 500)?

Start with HR 100 Mode/state settings (Remote access request bit); HR 103 ReqStartStop (Start/stop request); HR 104 OperatingMode (Operating mode); HR 105 SetSetpointManual (Manual dosing setpoint); HR 200 Actual mode/state settings (Remote access confirmed); HR 203 Miscellaneous status (Running / warning / fault bits); HR 216 FaultCode (Fault code); HR 217 WarningCode (Warning code); HR 305 MeasuredDosingCapacity (Measured dosing capacity); HR 311 VolumeTotal (Total dosed volume).

How do I enable Modbus control of the Grundfos SMART Digital DDA dosing pump (SoftCIM, CIM 200 / CIM 500)?

What happens when the Grundfos SMART Digital DDA dosing pump (SoftCIM, CIM 200 / CIM 500) loses Modbus communication?

A fixed 10 s communication watchdog is switched on the first time Bus/Cloud control is enabled; it can be turned off or on with 00102 bit 2 (persistent). If Modbus traffic stops for more than 10 s the pump stops dosing and raises alarm 15; it resumes when communication returns.
