Short answer

The FC series are PID controllers with seven set value memories and a simple 7-step program mode. On the C (RS-232C) or C5 (RS-485) option they can speak Modbus ASCII, one 16-bit holding register per request. The map covers the seven memory blocks of SV, PID, alarm and output limits, step times, general settings, PV, MV and the status word.

Integration notes: Shinko Technos FC series digital indicating controller (C/C5 option, Modbus ASCII)

Integration in brief

Select Modbus ASCII as the protocol on the keypad and give each unit an instrument number; then read PV 0099H, OUT1 MV 009AH and status 009EH one register at a time with function 03, and write SV memory 1 at 0000H with function 06.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Requires the C (RS-232C) or C5 (RS-485) option on a Modbus-capable model. Set instrument number, communication speed and Communication protocol = Modbus ASCII on the keypad; none of these can be changed over the bus.

Byte order & addressing

  • Modbus ASCII with 7 data bits, even parity, 1 stop bit; RTU masters will not talk to it.
  • Only one register per request.

Network setup

  • Factory defaults: instrument number 0, 9600 bps, Shinko protocol.
  • Speeds 2400, 4800, 9600 or 19200 bps, selected on the keypad.
  • On RS-485 fit a terminator at the far end of the line.

Watch out for

  • Send A3/A4 type before the alarm value: changing the type resets the value to 0.
  • AT Perform/Cancel returns an exception during PI or ON/OFF action, or if it repeats the current state.
  • EEPROM write life is about one million writes; avoid cyclic writes.

Notes on this map

  • Modbus ASCII only (no RTU). Function 03 reads exactly one register and function 06 writes one; multi-register reads are not supported.
  • All data are 16-bit two's complement. Values with a decimal point are sent as whole numbers without it; PV-type values (PV, SV, alarm values, SV and scaling limits) follow the decimal point place (0078H).
  • The Modbus addresses differ from the Shinko-protocol data items for the same setting (PV is 0080H in Shinko protocol but 0099H in Modbus).
  • Units of PID times, cycles and MV are not printed in the command table.
  • Items marked for certain models still accept writes on other models but do nothing.
  • The manual is inconsistent about address 0: the Modbus section says a unit set to 0 answers normally (no broadcast), while the general notes say broadcast commands get no reply.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Shinko Technos FC series digital indicating controller (C/C5 option, Modbus ASCII)

What Modbus registers does the Shinko Technos FC series digital indicating controller (C/C5 option, Modbus ASCII) have?

This map lists 160 registers: 160 holding registers. 153 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos FC series digital indicating controller (C/C5 option, Modbus ASCII) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed as hex (0000H) and go into the request unchanged; the manual's example frames read SV memory 1 at address 0000H and PV at 0099H.

What are the minimum Modbus registers to integrate the Shinko Technos FC series digital indicating controller (C/C5 option, Modbus ASCII)?

Start with HR 153 PV (Process value); HR 0 SV memory 1 (SV memory 1); HR 105 SV memory number / step number (Active SV memory / step); HR 154 OUT1 MV (OUT1 manipulated value); HR 158 Status flag (Output, alarm and over/underscale status); HR 120 Decimal point place (Decimal point for scaling).

How do I enable Modbus control of the Shinko Technos FC series digital indicating controller (C/C5 option, Modbus ASCII)?

Requires the C (RS-232C) or C5 (RS-485) option on a Modbus-capable model. Set instrument number, communication speed and Communication protocol = Modbus ASCII on the keypad; none of these can be changed over the bus.

Where is the official Shinko Technos FC series digital indicating controller (C/C5 option, Modbus ASCII) Modbus documentation?

The source is Communication Instruction Manual FC series (C, C5) (No.FC1CE11), revision 2006-12, published free by Shinko Technos at https://shinko-technos.co.jp/e/manual/english/FC1CE11.pdf.
