Integration notes: Vaisala HMDW110 series humidity and temperature transmitters with TMI110 (Modbus RTU)

Integration in brief

Read holding registers 1-4 for RH and temperature (CDAB floats); 9-10 adds dew point. Register 513 reads 1 when no error is active.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Order the transmitter with the factory-activated Modbus RTU option, or set the start-up serial mode to Modbus with the smode command on the service port.

Byte order & addressing

  • Floats are low word first (CDAB); pick "word-swapped" float in masters that default to high word first.
  • Read or write each 32-bit value in one transaction.

Network setup

  • Defaults: address 240, 19200 baud, no parity, 8 data bits, 2 stop bits, response delay 0.
  • Change address and serial settings with registers 1537-1541 or with Vaisala Insight; restart for bit rate and parity changes.

Watch out for

  • Use the test registers (7937 on) to confirm float format and addressing before trusting readings.

Notes on this map

  • All registers are holding registers: read with function 03, write with function 16.
  • 32-bit floats put the least significant word at the listed register (CDAB). The guide states this and its worked read and write examples confirm it.
  • Unavailable measurement data reads as a quiet NaN rather than an exception.
  • TMI110 lists only the temperature register (3); the full measurement table covers the HMD, HMW and HMS humidity models.
  • Left out: error code (516) and security hash (518). They are 32-bit integers, and this guide only states the word order for 32-bit floats.
  • Bit rate and parity changes (1538, 1539) take effect after a restart (register 1542). Modbus output needs 9600 baud or higher.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Vaisala HMDW110 series humidity and temperature transmitters with TMI110 (Modbus RTU)

What Modbus registers does the Vaisala HMDW110 series humidity and temperature transmitters with TMI110 (Modbus RTU) have?

This map lists 16 registers: 16 holding registers. 7 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vaisala HMDW110 series humidity and temperature transmitters with TMI110 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide numbers registers in decimal starting at 1 and also prints the 0-based hex address used in the request; register number 1 is address 0x0000 on the wire.

What byte order does the Vaisala HMDW110 series humidity and temperature transmitters with TMI110 (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Vaisala HMDW110 series humidity and temperature transmitters with TMI110 (Modbus RTU)?

Start with HR 0 Relative humidity (Relative humidity); HR 2 Temperature (Temperature); HR 8 Dew/frost point temperature (Dew point); HR 512 Device status (Device status).

How do I enable Modbus control of the Vaisala HMDW110 series humidity and temperature transmitters with TMI110 (Modbus RTU)?

Order the transmitter with the factory-activated Modbus RTU option, or set the start-up serial mode to Modbus with the smode command on the service port.

Where is the official Vaisala HMDW110 series humidity and temperature transmitters with TMI110 (Modbus RTU) Modbus documentation?
