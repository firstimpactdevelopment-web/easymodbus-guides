Short answer

The V7 and its NEMA 4X twin V74X are Yaskawa's legacy compact drives with built-in Modbus RTU. Commands go to hex registers 0001h, 0002h and 0009h, status, fault and monitors are read from 0020h-003Dh, and parameters n001-n179 sit at 0101h-01B3h. This map covers the command and monitor registers with published units, and the run/reference source and Modbus setup parameters.

Integration notes: Yaskawa V7 / V74X compact drive (legacy) - Modbus RTU

Integration in brief

Set n153 (address), n154 (baud) and n155 (parity), then n003 = 2 and n004 = 6 to take run and reference from Modbus. Write 0001h/0002h and poll 0020h-0031h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

n153 slave address 1-31 (default 0), n154 baud (default 2 = 9600), n155 parity (default 2 = none). n003 = 2 and n004 = 6 select built-in Modbus RTU for run/stop and frequency reference. n157 = 0 for 2-wire RS-485.

Communication loss & watchdog

n151 selects the time-out response: 0 coast (default), 1 ramp with n020, 2 ramp with n022, 3 continue with alarm, 4 disabled. 002Ch bit F shows a communication timeout.

Byte order & addressing

  • Registers and addresses are hex.
  • 1-8 registers per 03h read.
  • Parameter writes (0101h-01B3h) go to an off-line area until 0 is written to 0910h (ACCEPT) or 0900h (ENTER, about 100,000 writes).
  • Network digital inputs are ORed with the physical terminals.

Network setup

  • Modbus is available on the keypad RJ-45 jack or the R+/R-/S+/S- terminals.
  • Slave address 1-20h (1-32) per the protocol chapter; n153 accepts 0-31.
  • Baud 2400-19200.

Watch out for

  • Factory default n153 = 0 means the drive does not answer reads until an address is set.

Notes on this map

  • n153 defaults to 0, so a factory-fresh drive has no valid Modbus slave address; set n153 to 1-31 first. The defaults block shows the printed parameter defaults (n153 = 0, n154 = 2 = 9600, n155 = 2 = none).
  • Left out because the sign is not stated: 002Fh frequency reference bias, 0032h torque monitor, 0037h output power, 0038h-003Ah PID feedback/input/output.
  • Frequency registers follow n152 (default 0 = 0.1 Hz) and are left unscaled.
  • The CM091/CM092 Modbus TCP/IP option card uses a different command layout (Table 4.5) that is not covered here.
  • Broadcast (slave 0): 0001h bit 0 run, bit 1 reverse, bit 4 external fault, bit 5 fault reset; 0002h fixed at 30000 = 100 % of n011.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Yaskawa V7 / V74X compact drive (legacy) - Modbus RTU

What Modbus registers does the Yaskawa V7 / V74X compact drive (legacy) - Modbus RTU have?

This map lists 26 registers: 26 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yaskawa V7 / V74X compact drive (legacy) - Modbus RTU Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are hex and go on the wire unchanged: the read example asks for starting register 00h 20h (0020h-0023h). Parameter nXXX lives at its hex address in Table 4.4 (n003 = 0103h, n153 = 0199h); ENTER/ACCEPT are printed as 900/910.

What are the minimum Modbus registers to integrate the Yaskawa V7 / V74X compact drive (legacy) - Modbus RTU?

How do I enable Modbus control of the Yaskawa V7 / V74X compact drive (legacy) - Modbus RTU?
