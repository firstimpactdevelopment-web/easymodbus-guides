Yokogawa UTAdvanced UT35A-L limit controller Modbus register map

Updated 17 November 2026

Short answer

The UT35A-L is a high/low limit controller in Yokogawa's UTAdvanced family that trips an output relay when the PV passes its limit setpoint. Its D registers map one-to-one onto Modbus holding registers. This map covers the process monitoring block: PV, limit setpoint, exceed and relay status, alarms, latches, exceed duration time and PV peak value.

This page lists 16 Modbus registers for the Yokogawa UTAdvanced UT35A-L limit controller — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Yokogawa’s own free documentation (linked below) and checked against it.

Integration notes: Yokogawa UTAdvanced UT35A-L limit controller

Integration in brief

Use the factory Modbus RTU setting, then read D2001-D2008 for errors, PV, limit setpoint and the exceed/relay status bits.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the communication setup parameters PSL, BPS, PRI, STP, DLN and ADR on the keypad (factory protocol is Modbus RTU).

Byte order & addressing

  • Wire address = D number - 1 (D2003 = 07D2H).

Network setup

  • Factory defaults: Modbus RTU, 19200 bps, even parity, 1 stop bit, 8 data bits, address 1.

Watch out for

  • Reading undefined (blank) D registers is not allowed and can upset the unit.

Notes on this map

  • All registers are 16-bit and read-only in this block (D2001-D2100).
  • PV is sent without its decimal point; the position follows the input's decimal point setting.
  • Alarm setpoints and setup parameters (D2501 onward) are not included in this map.
  • Current SP group registers (D2101-D2200) are not included.

Questions about the Yokogawa UTAdvanced UT35A-L limit controller

What Modbus registers does the Yokogawa UTAdvanced UT35A-L limit controller have?

This map lists 16 registers: 16 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yokogawa UTAdvanced UT35A-L limit controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists D register numbers; the Modbus reference is the D number with D replaced by 4 (D2003 = 42003) and the wire address is that minus 40001, as printed in the H No. column (07D2H).

What are the minimum Modbus registers to integrate the Yokogawa UTAdvanced UT35A-L limit controller?

Start with HR 2002 PV_L1 measured value (PV (D2003)); HR 2001 PV1.E_L1 PV input error status (PV input error flags (D2002)); HR 2003 CSP_L1 control (limit) setpoint (Limit setpoint (D2004)); HR 2007 MOD_L1 operation status (Exceeded / output relay (D2008)); HR 2010 ALM_L1 alarm 1-3 status (Alarm status (D2011)); HR 2036 ALO_L1 alarm output 1-3 status (Alarm output status (D2037)).

How do I enable Modbus control of the Yokogawa UTAdvanced UT35A-L limit controller?

Set the communication setup parameters PSL, BPS, PRI, STP, DLN and ADR on the keypad (factory protocol is Modbus RTU).

Where is the official Yokogawa UTAdvanced UT35A-L limit controller Modbus documentation?

The source is UTAdvanced Series Communication Interface (RS-485, Ethernet) User's Manual (IM 05P07A01-01EN 13th Edition), revision 2026-03, published free by Yokogawa at https://web-material3.yokogawa.com/IM05P07A01-01EN.pdf.
