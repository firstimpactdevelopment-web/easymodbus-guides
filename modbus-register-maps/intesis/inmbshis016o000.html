Short answer

Multi-unit Modbus server for Hisense VRF systems (H-Link bus). Every configured indoor unit gets a 100-register block with control, temperatures and status, each outdoor unit gets a 25-register block, and low addresses hold 'all units' commands. Modbus RTU and Modbus TCP work together.

Integration notes: Intesis (HMS Networks) INMBSHIS016O000 Hisense VRF to Modbus RTU / TCP gateway (16 / 64 indoor units)

Integration in brief

Add the indoor units in Intesis MAPS, send the configuration, then poll each unit block from Ui x 100. Write on/off, mode, fan and setpoint (tenths of °C) in the same block.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Indoor units must be configured in MAPS; their index there decides the register block.

Byte order & addressing

  • Every register is a 16-bit signed integer; there are no 32-bit values (unless stated in this file).
  • Read with FC03 or FC04; write with FC06 or FC16.
  • Undefined addresses in the 0..20000 poll range read back 0; the manual also says invalid addresses return a Modbus exception code.
  • Registers 0..20 are broadcast commands to every unit and are write-only.

Network setup

  • All Modbus settings (RTU slave number, baud 1200..115200, parity, stop bits, RS-485 or RS-232, TCP port, IP) are set with the Intesis MAPS tool over the USB console port or Ethernet.
  • Factory IP is 192.168.100.246 with DHCP enabled.
  • Modbus RTU and Modbus TCP can be used at the same time.
  • Port B carries Modbus RTU on B1, B2 and B3 (SGND). The manual prints the B1/B2 polarity both ways in two sections, so check the terminal label. A DIP switch enables 120 ohm termination and bias.

Watch out for

  • The block number is the MAPS unit index, not the H-Link refrigerant/unit address.

Notes on this map

  • Only indoor index 1 and outdoor address 1 are listed. For index Ui add (Ui-1) x 100 (Ui 2 on/off = 200); for outdoor OU add (OU-1) x 25.
  • Outdoor discharge and suction pressure (OU*25+10000+6 / +7) are left out: the manual labels them '(x10 °C)' but gives a range in MPa, so the unit and scale are unclear.
  • Outdoor temperature, frequency and current carry no x10 marker in the manual, so they are listed at scale 1 as printed.
  • Fan speed (Ui*100+2) prints '3-High, 3-High+', a duplicate code; only 0..2 are decoded. The broadcast registers 10 and 11 set High and High+ separately.
  • The manual spells the communication-status value 'Not Exit'; read as 'not existing'.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Intesis (HMS Networks) INMBSHIS016O000 Hisense VRF to Modbus RTU / TCP gateway (16 / 64 indoor units)

What Modbus registers does the Intesis (HMS Networks) INMBSHIS016O000 Hisense VRF to Modbus RTU / TCP gateway (16 / 64 indoor units) have?

This map lists 55 registers: 55 holding registers. 32 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Intesis (HMS Networks) INMBSHIS016O000 Hisense VRF to Modbus RTU / TCP gateway (16 / 64 indoor units) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual states formula results are link-layer addresses with the first register at 0, so they are wire addresses. Indoor unit index Ui (1..64, from the MAPS Units Configuration tab) uses Ui x 100 + offset; outdoor unit address OU (1..64) uses OU x 25 + 10000 + offset. This file lists Ui = 1 (100..127) and OU = 1 (10025..10030).

What are the minimum Modbus registers to integrate the Intesis (HMS Networks) INMBSHIS016O000 Hisense VRF to Modbus RTU / TCP gateway (16 / 64 indoor units)?

Start with HR 100 IU on/off (Indoor unit on/off); HR 101 IU operation mode (Operation mode); HR 104 IU temperature setpoint (Setpoint (x10)); HR 106 IU inlet (return) temperature (Return air temperature (x10)); HR 110 IU unit error code (Error code); HR 113 IU communication status (Unit present / communicating); HR 125 IU operation condition (Thermo on/off / alarm state); HR 10025 OU communication error (Outdoor unit communication error).
