SmartGen HGM6100N / HGM6100CAN Series Modbus register map

Updated 16 October 2026

Short answer

SmartGen's HGM6100N family are single-genset auto-start (HGM6110) and AMF (HGM6120) controllers. The RS485 port is a Modbus RTU slave with fixed register tables: status and alarm bits as coils (FC01), measurements and run counters as holding registers (FC03), and remote control as single-coil writes (FC05). This map covers the common status/alarm coils, the electrical and engine measurements, genset state codes, counters and the remote start/stop/mode/breaker commands.

This page lists 145 Modbus registers for the SmartGen HGM6100N / HGM6100CAN Series — 7 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from SmartGen’s own free documentation (linked below) and checked against it.

Integration notes: SmartGen HGM6100N / HGM6100CAN Series

Integration in brief

Wire to RS485 A/B, set the controller's Module Address, then poll holding registers 0000-0054 with FC03 and coils 0000-0081 with FC01. Remote commands are single FC05 writes of FF00 to coils 0000-0006, the same addresses that read back as status bits.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set a unique Module Address (1-254, default 1) from the front-panel parameter menu (default password 0318); the new setting applies once saved. Baud rate (2400/4800/9600/19200/115200, default 9600) and parity (none/odd/even, default none) are also controller settings.

Byte order & addressing

  • Remote command coils are written with FF00 and each command is sent once only; they act as one-shot commands, not latched states.
  • Coils 0-6 mean different things for read (FC01) and write (FC05).
  • Run hours, start count and energy are split into a high part and a 0-9999 low part combined as high x 10000 + low, not as a 32-bit word pair.
  • Supported function codes are 01, 03, 05 and 06 only. Read at most 120 registers per request.

Network setup

  • Use 120 Ω shielded twisted pair, shield grounded at one end only.
  • The controller has an internal 120 Ω terminator that is enabled by default in its settings; disable it on units that are not at the end of the bus.
  • Default: address 1, 9600 bps, 8 data bits, no parity, 1 stop bit; allow at least 200 ms response timeout.
  • Up to 32 controllers per RS485 segment, 1000 m at 9600 bps.

Watch out for

  • This controller starts a real engine. Confirm the genset is safe to run and local staff are informed before writing coils 0-6; a write to coil 0 is a start command even though the same address reads as Common Alarm.
  • HGM6120 coils 5/6 are named close/open keys and the document does not say how the controller chooses between closing and opening; a write while the breaker is closed may open it and drop the load. Read Gen On-load (coil 7) / Mains On-load (coil 6) first.
  • After a remote stop, check the mode coils 40-43 and send Remote Auto (coil 3) if the set must stay ready for automatic operation.

Notes on this map

  • Coil addresses 0-6 are shared: FC01 reads return status bits, while an FC05 write of FF00 to the same address issues a remote command (start, stop, test, auto, manual, breaker). Each entry names both meanings; the write meaning is in capitals.
  • HGM6110 (auto start) and HGM6120 (AMF) differ at command coils 5 and 6; HGM6100N and HGM6100CAN differ at several status coils (54, 62, 63, 70, 71, 79). Both meanings are given in the names.
  • The FC05 table describes the command value as '00FFH', but the worked example frame sends FF 00 (high byte FF), which is also the standard Modbus ON value; use FF00.
  • Left out: mains and gen frequency (0006, 0013). The table prints ratio 0.1 Hz, but NOTE 1 uses frequency with ratio 0.01 Hz as its worked example, so the scale is contradictory.
  • Left out: the state delay registers (0035, 0037, 0039, 0041) and Load Output Percentage (0055), because no ratio is printed for them.
  • Left out: the 32-bit current and power registers at 0206-0217 and 2500-2511. The document says value = high part x 65536 + low part but never says which address holds the high part, so the word order is not established. The 16-bit versions (0014-0016, 0026-0028) are included.
  • Left out: ECU-only (HGM6100CAN) engine data 0032-0033 and 0056-0219 (J1939 values, DM1/DM2 fault codes, aftertreatment indicators) and the HGM6100N fuel-level logging block 0098-0114.
  • A reading of 32766 means no valid data (the controller shows ###).
  • Water temperature, oil pressure and fuel level are documented as unsigned, so negative coolant temperatures cannot be represented as documented.
  • The ATS running status (0038) has no value table in the document; only the raw code is available.

Questions about the SmartGen HGM6100N / HGM6100CAN Series

What Modbus registers does the SmartGen HGM6100N / HGM6100CAN Series have?

This map lists 145 registers: 81 coils, 64 holding registers. 7 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the SmartGen HGM6100N / HGM6100CAN Series Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print a decimal 'Modbus Address' (used here as the wire address) next to a 'PLC Address' (1-based: coils 0001.., holding registers 40001..). The document's own example reads battery voltage at Modbus address 0024 with start address 0x0018, which confirms the Modbus Address column is the 0-based PDU address.

What are the minimum Modbus registers to integrate the SmartGen HGM6100N / HGM6100CAN Series?

Start with CO 0 Common Alarm (read) / WRITE = REMOTE START ENGINE (Common alarm (read) / remote start (write)); CO 41 Auto Mode (Auto mode active); HR 34 Controller Running Status (Genset running state); HR 7 Gen UA (Generator phase A voltage); HR 14 A Phase Current (Phase A current); HR 26 Active Power (Total active power); HR 23 Engine Speed (Engine speed); HR 24 Battery Voltage (Battery voltage).

How do I enable Modbus control of the SmartGen HGM6100N / HGM6100CAN Series?

Set a unique Module Address (1-254, default 1) from the front-panel parameter menu (default password 0318); the new setting applies once saved. Baud rate (2400/4800/9600/19200/115200, default 9600) and parity (none/odd/even, default none) are also controller settings.

Where is the official SmartGen HGM6100N / HGM6100CAN Series Modbus documentation?

The source is HGM6100N/HGM6100CAN Genset Controller Communication Protocol, revision 2025-07-01 (v1.7), published free by SmartGen at https://www.smartgen.cn/yun/data/download/HGM6100N_HGM6100CAN_Protocol_en.pdf.
