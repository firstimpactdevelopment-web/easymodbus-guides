Short answer

Small Modbus RTU slave that joins a Daikin P1/P2 remote-controller bus and controls up to 16 indoor units as one group. Holding registers carry setpoint, fan, mode, louvre and on/off plus keypad lock modes and limits; input registers return group and per-unit temperatures, faults, filter and defrost state.

Integration notes: Realtime Control Systems RTD-NET Modbus interface for Daikin VRV / Sky Air

Integration in brief

Set the slave address on SW1, wire DB/DA/GND, then write H0001-H0005 for setpoint, fan, mode, louvre and on/off and poll I0020-I0035 for group status. Use the update registers to decide whether the wall controller stays usable.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step: holding-register writes act on the group straight away. The update registers (H0010-H0015) choose Last Touch (default), Central (locks keypad buttons), Local or On Change behaviour.

Communication loss & watchdog

Optional, set by a SW1 DIP switch: if no holding-register write arrives for 120 s all units are switched on with their current settings, and remote controllers are either unlocked or left as they are depending on the switch.

Byte order & addressing

  • Temperatures above 32767 are negative: subtract 65536, then divide by 100.
  • In Last Touch mode a master that rewrites the same value every scan overrides the wall controller; use On Change (3) if your master writes cyclically.
  • Coil and per-unit thermo readings exist only when the RTD is the P1/P2 MAIN controller.

Network setup

  • 9600 baud, no parity, 1 stop bit by default (other rates available on request from the maker).
  • Slave address 0..63 on SW1.
  • Daisy-chain DB(+), DA(-) and GND; no star or ring wiring; up to 500 m without repeaters.
  • Power 15-24 V DC from the indoor unit PCB (X18A/X35A) or a separate supply.

Watch out for

  • Infra-red BRC receivers must be set to SUB when the RTD is MAIN.
  • If the P1/P2 bus is not found within 1 minute the RTD raises an alarm on its fault output.

Notes on this map

  • Every register is 16 bits. Temperatures in input registers are signed and multiplied by 100; setpoint and setpoint limits are whole °C (16..32).
  • Only unit 1 of the per-unit block is listed. For unit n add (n-1) x 100 to each address (e.g. unit 2 return air = 223).
  • Fanspeed inhibit (H0022) is listed without bit meanings: the manual's fan inhibit table (Low 2, High 13) does not follow the powers-of-two pattern of the mode and louvre tables, so it is not decoded here.
  • Fault codes are two ASCII characters packed high byte / low byte (e.g. 16697 = 'A9'). The full Daikin code table is published by Realtime Controls separately.
  • Function codes 03, 04, 06 and 16 are supported, 1..10 registers per request.
  • The Modbus slave address is set 0..63 on DIP switch SW1.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Realtime Control Systems RTD-NET Modbus interface for Daikin VRV / Sky Air

What Modbus registers does the Realtime Control Systems RTD-NET Modbus interface for Daikin VRV / Sky Air have?

This map lists 37 registers: 19 input registers, 18 holding registers. 18 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Realtime Control Systems RTD-NET Modbus interface for Daikin VRV / Sky Air Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual states register base 0 and writes registers as H0010 / I0010 meaning wire address 10. Per-unit input registers are numbered unit x 100 + offset (unit 1 = 0120..0132, unit 16 = 1620..1632).

What are the minimum Modbus registers to integrate the Realtime Control Systems RTD-NET Modbus interface for Daikin VRV / Sky Air?

Start with HR 5 OnOff (Group on/off); HR 3 Mode (Mode); HR 1 Setpoint (Setpoint); HR 2 Fanspeed (Fan speed); IR 23 Return Air Average (Average return air); IR 21 Is Fault (group) (Any unit faulted); IR 22 Fault Code (group) (Fault code); IR 20 Unit Count (Units found).

How do I enable Modbus control of the Realtime Control Systems RTD-NET Modbus interface for Daikin VRV / Sky Air?

No enable step: holding-register writes act on the group straight away. The update registers (H0010-H0015) choose Last Touch (default), Central (locks keypad buttons), Local or On Change behaviour.

What happens when the Realtime Control Systems RTD-NET Modbus interface for Daikin VRV / Sky Air loses Modbus communication?

Optional, set by a SW1 DIP switch: if no holding-register write arrives for 120 s all units are switched on with their current settings, and remote controllers are either unlocked or left as they are depending on the switch.
