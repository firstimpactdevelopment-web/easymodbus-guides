Huawei SmartLogger plant data logger (Modbus TCP) Modbus register map

Updated 17 November 2026

Short answer

The SmartLogger is Huawei's plant data logger. Over Modbus TCP it answers for itself with logical device ID 0 and reaches inverters, power meters and environment monitors behind it by their RS485 addresses. This map covers the SmartLogger's own registers: clock, power on/off and transfer trip, active and reactive power adjustment, plant totals for power, current, voltage and energy, plant status, scheduling modes and targets, capacity values, DI status and alarm bit words.

This page lists 70 Modbus registers for the Huawei SmartLogger plant data logger (Modbus TCP) — 25 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Huawei’s own free documentation (linked below) and checked against it.

Integration notes: Huawei SmartLogger plant data logger (Modbus TCP)

Integration in brief

Connect over Modbus TCP and read plant totals with logical device ID 0: active power at 40525, input power at 40521 and daily/total yield at 40562/40560. Limit the total output of all inverters by writing 40420 (kW x 10) or 40428 (% x 10).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The document does not describe how to enable Modbus TCP.

Byte order & addressing

  • Logical device ID 0 addresses the SmartLogger itself; other IDs reach connected devices.
  • Gains are divisors (10, 100, 1000).
  • Several 'Plant status' registers are used only in specific Chinese regions (Qinghai, Xinjiang, Ningxia); pick the one your site uses.

Network setup

  • Modbus TCP on port 502.
  • Function codes: 03 read, 06 write single, 10 write multiple, 2B device identification.

Watch out for

  • Power on/off registers act on all inverters at once.
  • Out-of-range power adjustment values are discarded.

Notes on this map

  • Huawei hosts this document only behind a support-site login; the copy linked is a forum upload of the unaltered Huawei PDF.
  • Data encoding is big-endian for addresses and data (leftmost byte first), so 32- and 64-bit values are read high word first (ABCD).
  • Gain is a divisor: a value with gain 10 in kW is read as raw / 10 kW.
  • RO registers accept only function 03; WO registers accept only 06/16; RW accept all three.
  • Left out: City (40002, no coding given), Reserved (40608), Device operation (40725, mixed ESN + command block), the reactive scheduling target (40742) whose gain is 10 or 1000 depending on mode, Japanese-utility communication registers 41942-41949 (gain marked N/A), current error during scanning (42150), and the power meter, weather station and remapped register sections.
  • Alarm info 3 (50002, certificate alarms) appears only in the alarm table, so it is not listed.
  • The document gives Modbus TCP port 502.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Huawei SmartLogger plant data logger (Modbus TCP)

What Modbus registers does the Huawei SmartLogger plant data logger (Modbus TCP) have?

This map lists 70 registers: 70 holding registers. 25 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Huawei SmartLogger plant data logger (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are sent as printed: the read example requests register 32306 with address bytes 7E 32. In Modbus TCP the SmartLogger's own registers use logical device ID 0.

What byte order does the Huawei SmartLogger plant data logger (Modbus TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Huawei SmartLogger plant data logger (Modbus TCP)?

Start with HR 40525 Active power (Plant active power); HR 40521 Input power (Plant input power); HR 40560 Total energy yield (E-Total) (Total energy yield); HR 40562 Daily energy yield (E-Daily) (Daily energy yield); HR 40428 Active power adjustment by percentage (Active power limit in %); HR 40737 Active power control mode (Active power control mode).
