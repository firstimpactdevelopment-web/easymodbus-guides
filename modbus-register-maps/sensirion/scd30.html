Short answer

The SCD30 is an NDIR CO2 module with on-board humidity and temperature sensing. With the SEL pin tied to VDD it speaks Modbus RTU (UART level) at a fixed address and baud rate. Measurements are big-endian IEEE-754 floats; configuration commands are single 16-bit register writes.

This page lists 13 Modbus registers for the Sensirion SCD30 CO2, humidity and temperature sensor module — 8 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Sensirion’s own free documentation (linked below) and checked against it.

Integration notes: Sensirion SCD30 CO2, humidity and temperature sensor module

Integration in brief

Write 0 (or the ambient pressure in mbar) to 0x0036 once to start measuring; the setting survives power cycles. Then poll 0x0027 for data ready and read six registers from 0x0028 for CO2, temperature and humidity.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Pull the SEL pin to VDD during power-up to select Modbus instead of I2C.

Byte order & addressing

  • Address 0x61 and 19200 8N1 are fixed.
  • The manual's read example fetches all six measurement registers from 0x0028 in one request (CO2, temperature, humidity, each high word first).

Network setup

  • Power up with SEL high, connect TX/RX through a suitable transceiver, then send the start command.

Watch out for

  • Continuous measurement and ASC states are stored in non-volatile memory and resume after power-up.

Notes on this map

  • The read-measurement example returns 43 DB 8C 2E (439 ppm), 41 D9 E7 FF (27.2 °C) and 42 43 3A 1B (48.8 %RH), and the document states the values are big-endian floats, so all three are high word first.
  • The sensor accepts function codes 3, 4 and 6 only; there is no multi-register write.
  • The Modbus address 0x61 (97) and 19200 8N1 are fixed in this document; no command to change them is listed.
  • The UART pins are at logic level; an RS-485 transceiver is needed to put the module on a bus.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Sensirion SCD30 CO2, humidity and temperature sensor module

What Modbus registers does the Sensirion SCD30 CO2, humidity and temperature sensor module have?

This map lists 13 registers: 13 holding registers. 8 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Sensirion SCD30 CO2, humidity and temperature sensor module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are given in hex exactly as they appear in the request frames (for example 0x61 0x03 0x00 0x28 reads from 0x0028), so they are wire addresses.

What byte order does the Sensirion SCD30 CO2, humidity and temperature sensor module use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Sensirion SCD30 CO2, humidity and temperature sensor module?

Start with HR 54 Start continuous measurement (Start continuous measurement); HR 39 Data ready status (Data ready); HR 40 CO2 concentration (CO2); HR 42 Temperature (Temperature); HR 44 Relative humidity (Humidity).

How do I enable Modbus control of the Sensirion SCD30 CO2, humidity and temperature sensor module?

Pull the SEL pin to VDD during power-up to select Modbus instead of I2C.
