Seneca Z-10-D-IN 10-channel digital input / counter module (HW2) Modbus register map

Updated 17 November 2026

Short answer

The Z-10-D-IN reads ten digital inputs and counts pulses on each, with counters kept in non-volatile FeRAM. Over RS-485 Modbus RTU it exposes input states, 16- and 32-bit counters, and per-input period, frequency and high time.

This page lists 55 Modbus registers for the Seneca Z-10-D-IN 10-channel digital input / counter module (HW2) — 21 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Seneca’s own free documentation (linked below) and checked against it.

Integration notes: Seneca Z-10-D-IN 10-channel digital input / counter module (HW2)

Integration in brief

Read 40002 for input states and 40101-40120 (wire 100-119) for the ten 32-bit counters, high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Supported functions are 3, 6 and 16; address and baud come from the DIP switches, or from EEPROM when all are OFF.

Byte order & addressing

  • Counters 1-8 also appear as 16-bit values at 40003-40010; the full 32-bit copies are at 40101 on.

Network setup

  • Write 1 to 40022 to save R/W settings to EEPROM, 2 to reset.

Watch out for

  • Older firmware lacks the full 32-bit counter area.

Notes on this map

  • 32-bit counters are marked MSW at the lower address and LSW at the next, so they are high word first (ABCD).
  • Left out: 40015 overflow flags, the measure A/B registers 40016-40018, the filter and IN9/IN10 mode registers 40019-40020, and 40021 (address and baud packed with DIP-switch dependent meaning), because their bit layouts did not extract cleanly.
  • Counters marked RW** can be written to preset them.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Seneca Z-10-D-IN 10-channel digital input / counter module (HW2)

What Modbus registers does the Seneca Z-10-D-IN 10-channel digital input / counter module (HW2) have?

This map lists 55 registers: 55 holding registers. 21 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seneca Z-10-D-IN 10-channel digital input / counter module (HW2) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual states that the first register (offset 0) is 40001 and prints both columns.

What byte order does the Seneca Z-10-D-IN 10-channel digital input / counter module (HW2) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Seneca Z-10-D-IN 10-channel digital input / counter module (HW2)?

Start with HR 1 Input states (Input states); HR 100 Counter 1 (full 32-bit) (Counter 1); HR 102 Counter 2 (full 32-bit) (Counter 2); HR 130 IN1 frequency (IN1 frequency); HR 21 Command (Command).

How do I enable Modbus control of the Seneca Z-10-D-IN 10-channel digital input / counter module (HW2)?

Supported functions are 3, 6 and 16; address and baud come from the DIP switches, or from EEPROM when all are OFF.

Where is the official Seneca Z-10-D-IN 10-channel digital input / counter module (HW2) Modbus documentation?

The source is Z-10-D-IN HW2 User Manual (MI00253-10-EN), published free by Seneca at https://www.seneca.it/media/4184/mi00253-10-en.pdf.
