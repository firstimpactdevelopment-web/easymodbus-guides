Short answer

Current-generation air-cooled scroll chiller with two circuits and up to three scroll compressors per circuit. Its BAS module (BACnet IP, BACnet MS/TP or Modbus RTU) exposes everything as 16-bit holding registers: water and refrigerant temperatures and pressures, enable/mode/setpoint/capacity-limit commands, status enums, alarm index and module registers, and run-hour/start counters.

Integration notes: Daikin Applied Trailblazer AGZ-F air-cooled scroll chiller (MicroTech controller)

Integration in brief

Plug in the BAS module, set BAS Network Protocol = Modbus with address, baud, parity and stop bits on the HMI, cycle power, then set Control Source = BAS. Poll with function 03; use 9 to enable, 35 for the chilled-water setpoint, 38 for capacity limit and 5/28-30 for alarms.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

On the HMI (Manager password 2526): Configuration > BAS Configuration > BAS Module Connected = Yes, then cycle power; Protocol tab BAS Network Protocol = Modbus and set units; Settings tab Address, Baud Rate, Parity and Modbus Stop Bits; cycle power again. Finally Configuration > Commission > Control Source = BAS, otherwise enable, setpoint, mode, capacity-limit and clear-alarm writes are ignored.

Byte order & addressing

  • Printed register numbers are 1-based without the 4xxxx prefix: subtract 1 for the wire address.
  • 32-bit counters are high word first (ABCD) - unlike older MicroTech chillers (ED 15121), which are low word first.
  • Most analog values are x10 and follow the English/Metric setting; the multiplier does not change.
  • Each alarm class has four registers: index (28-30) plus module type, module ID and payload (2001-2009).

Network setup

  • Address 0-247 (default 1); baud 9600/19200/38400/57600/76800 (default 19200); parity Even/Odd/None (default None); stop bits 1 or 2 (default 1).
  • RS-485 lands on the module's 'J3 Disp' 4-pin connector, using only + and -. End-of-line and bias resistors are field-supplied.
  • The same module also does BACnet IP and MS/TP; one protocol is active, chosen by BAS Network Protocol (default None/LON).

Watch out for

  • Nothing answers until BAS Module Connected = Yes and the panel has been power-cycled.
  • Control Source = Local or Remote Switch silently ignores network commands; register 1 shows Local/Remote.
  • The cool setpoint low limit is 39.9 °F unless the unit is set up for glycol.

Notes on this map

  • Network setup and parameter ranges come from the companion manual IM 1283-1, BACnet and Modbus Chiller Unit Controller (Mar 2024), pp. 36-39: https://tahoeweb.daikinapplied.com/api/general/DownloadDocumentByName/media/IM1283-1.pdf/
  • ED 19131 is shared with WMT and WMC-E centrifugal chillers. Only points that Table 5 marks in the AGZ-F column are listed.
  • Two-register counters: the document's worked example (99900 = 0x0001863C stored as 74 = 0x0001, 75 = 0x863C) puts the high word first, so they are ABCD. This is the opposite of the older MicroTech chillers in ED 15121.
  • The document never defines 'x 10'. Its ranges and defaults ('Default: 100% x 10', '14.9-70.0°F x 10') only make sense as raw = value x 10, so those registers use scale 0.1.
  • Signedness is not stated. Temperatures and refrigerant pressures are INT16 because their published ranges go negative (the shared pressure rows include sub-atmospheric R-1233zd(E) ranges); counters, percentages and enums are UINT16.
  • Units follow the HMI 'BAS Measurement Units' setting, readable at register 316 (English default). Units shown are English (°F, psi); Metric uses °C and kPa with the same multiplier.
  • Discharge temperature: AGZ-F has one sensor per circuit; the table lists it under Circuit 1 Compressor 1 (68) and Circuit 2 Compressor 1 (107), which are mapped. Register 81 (Circuit 1 Compressor 2) is left out. Suction temperature uses the per-circuit registers 1990/1974.
  • Units (316) shows 'RW Holding Register' in the data-type column but 'R' in the access column; it is listed read-only (change it at the HMI).
  • Condenser refrigerant pressure (39/43): the Modbus table gives the R-32 Metric range as 0-2827 kPa x10, but 700 psi is about 4826 kPa (the BACnet table's figure). Metric readings above 3276.7 kPa would not fit the signed register, so read pressures with BAS Measurement Units = English.
  • Left out: points not marked for AGZ-F (compressor current/voltage/power/RLA, condenser water points, flow rates, liquid line temperature, heat-recovery temperatures, heat setpoint). Alarm index meanings (pp. 32-33) are not reproduced; the module-type value list (Tables 30-32) is the same for all three classes.

Questions about the Daikin Applied Trailblazer AGZ-F air-cooled scroll chiller (MicroTech controller)

What Modbus registers does the Daikin Applied Trailblazer AGZ-F air-cooled scroll chiller (MicroTech controller) have?

This map lists 63 registers: 63 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Daikin Applied Trailblazer AGZ-F air-cooled scroll chiller (MicroTech controller) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. ED 19131 prints holding registers without the 4xxxx prefix (register 8 = 40008) and states the module is zero-based: 40002 is sent as 0001. Wire address = printed number - 1.

What byte order does the Daikin Applied Trailblazer AGZ-F air-cooled scroll chiller (MicroTech controller) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.
