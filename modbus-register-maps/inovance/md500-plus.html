Inovance MD500-PLUS series AC drive Modbus register map

Updated 19 November 2026

Short answer

Inovance's general-purpose vector drive for asynchronous and permanent-magnet motors. With the MD38TX1 RS-485 card it acts as a Modbus RTU slave. Speed goes to 1000H as a signed percentage of maximum frequency, run commands to 2000H, status and fault codes come from 3000H and 8000H, and every parameter has its own hex address (F/A groups at FxxxH/AxxxH, U0 monitors at 70xxH). This map covers the control block, the core U0 monitors with their data types and units, and the FD communication parameters.

This page lists 55 Modbus registers for the Inovance MD500-PLUS series AC drive — 17 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Inovance’s own free documentation (linked below) and checked against it.

Integration notes: Inovance MD500-PLUS series AC drive

Integration in brief

Fit the MD38TX1 card, set F0-02 = 2 and F0-03 = 9, then write a signed percentage of F0-10 to 1000H (10000 = 100.00 %) and a run code to 2000H. Poll 3000H for run state, 8000H for faults and 7000H-7006H for frequency, voltage, current, power and torque.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

RS-485 needs the MD38TX1 extension card. F0-02 = 2 accepts run commands over communication; F0-03 = 9 makes 1000H the main frequency. FD-00..FD-02 set baud, data format and address.

Communication loss & watchdog

FD-04 sets a Modbus timeout (0.0 s = off); when messages stop for longer the drive reports a communication fault (Err16).

Byte order & addressing

  • 1000H is a percentage, not Hz: 10000 = +100.00 % of F0-10, negative values reverse.
  • Default serial format is 8-N-2 (FD-01 = 0).
  • To change F-group parameters without wearing the EEPROM, replace the leading F with 0 (F3-12 -> 030CH); A-group uses 4x. Those RAM addresses are write-only.

Network setup

  • FD-02 address (default 1), FD-00 baud (default 5 = 9600 bit/s), FD-01 data format (default 0 = 8-N-2).
  • Restore defaults over Modbus by writing the user password to 1F00H, then 1 to 1F01H within 30 s.

Watch out for

  • Reads longer than 12 registers, or reads that cross the end of a parameter group, return an error.
  • No reply is sent for a frame with a CRC error.

Notes on this map

  • Every register is one 16-bit word. Scales come from the 'Basic Unit' column of Table 1-1; signedness comes from the data type printed in each U0 parameter description.
  • Left out: U0-14 (unit printed differently in the two tables), U0-22/U0-23, U0-32/U0-33/U0-36/U0-38 (position/debug values) and everything from U0-58 on, because Table 1-1 and the parameter descriptions give different addresses for those rows (e.g. U0-59 at 0x7035 vs 0x703B).
  • The 1000H-1020H 'stop/run parameter' block is listed without units, so it is left out; read the U0 group instead.
  • F9-14 holds the same fault code as 8000H; the guide prints the 8000H codes in hex (001AH = 26).
  • Function codes: 03H read, 06H write, 10H multi-write; up to 12 consecutive registers per request, and a request must not run past the end of a parameter group.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Inovance MD500-PLUS series AC drive

What Modbus registers does the Inovance MD500-PLUS series AC drive have?

This map lists 55 registers: 55 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Inovance MD500-PLUS series AC drive Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are hex and go on the wire unchanged: the guide's reverse-run example is 01 06 20 00 00 02, writing 2 to 2000H. Parameter addresses are the group code (F0-FE, A0-AC, 70 for U0) followed by the parameter number in hex (F3-12 = 0xF30C).

What are the minimum Modbus registers to integrate the Inovance MD500-PLUS series AC drive?

Start with HR 8192 Control command (Run / stop / reset command); HR 4096 Communication reference (Speed reference as % of max frequency); HR 12288 AC drive state (Forward / reverse / stopped); HR 32768 AC drive fault (Fault code); HR 28672 U0-00 Running frequency (Running frequency); HR 28676 U0-04 Output current (Output current); HR 28674 U0-02 Bus voltage (DC bus voltage).

How do I enable Modbus control of the Inovance MD500-PLUS series AC drive?

RS-485 needs the MD38TX1 extension card. F0-02 = 2 accepts run commands over communication; F0-03 = 9 makes 1000H the main frequency. FD-00..FD-02 set baud, data format and address.

What happens when the Inovance MD500-PLUS series AC drive loses Modbus communication?

FD-04 sets a Modbus timeout (0.0 s = off); when messages stop for longer the drive reports a communication fault (Err16).

Where is the official Inovance MD500-PLUS series AC drive Modbus documentation?
