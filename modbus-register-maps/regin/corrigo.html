Regin Corrigo ventilation controller (ventilation application 3.6) Modbus register map

Updated 24 October 2026

Short answer

The Regin Corrigo is a pre-programmed air handling unit controller whose ventilation application is reachable over EXOline, Modbus and BACnet. As a Modbus slave it publishes temperatures, pressures, flows and humidity as input registers, setpoints and manual/auto modes as holding registers, and alarm and I/O states as discrete inputs. Every value is a single 16-bit register; real values are sent multiplied by 10, except air flow (factor 1) and time settings (factor 100).

This page lists 134 Modbus registers for the Regin Corrigo ventilation controller (ventilation application 3.6) — 45 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Regin’s own free documentation (linked below) and checked against it.

Integration notes: Regin Corrigo ventilation controller (ventilation application 3.6)

Integration in brief

Connect the Corrigo as a Modbus slave, read input registers 30001-30024 for temperatures and pressures and discrete inputs 10184-10186 for sum alarms, and command the unit through holding register 40368 (Manual off / reduced / normal / Auto) plus the setpoints at 40001-40037.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the Modbus slave address and line settings on the Corrigo display or with E tool. Defaults are slave address 1, 9600 baud, 8 data bits, no parity, 1 stop bit, RTU. Only signals that have a default value in the list can be written.

Byte order & addressing

  • Every value is one 16-bit register; Real values are x10 (air flow x1, time settings x100).
  • At most 47 registers can be read in one request.
  • Leave at least 3.5 character times (about 4 ms at 9600 bps) between messages.
  • Enumerations start at 0 on Modbus but at 1 on BACnet for the same point.
  • Extract and exhaust temperature variable names are swapped relative to the air they measure.

Network setup

  • Supported function codes: 1, 2, 3, 4, 5, 6, 15 and 16.
  • RTU framing only (word length 8); the manual lists baud rates from 150 to 9600.
  • BACnet/IP and MS/TP are separate options, disabled by default; they are not needed for Modbus.

Watch out for

  • To override an output, first set its mode register to Manual, then write the matching manual-output register.
  • Configuration registers 40474-40478 (control mode, fan, heating, cooling and exchanger type) change how the whole unit runs; treat them as read-only outside commissioning.
  • Air flow setpoints and readings are m3/h with no scaling, unlike every other Real value.

Notes on this map

  • Scaling: the manual says Real (R) signals are multiplied by 10, time-setting signals by 100 and air flow signals by 1; Integer, Index and Logic signals are not scaled. Scale 0.1 is applied to every Real register here except the air flows.
  • Signedness is not stated per register. Real and Integer values are listed as INT16 because temperatures and offsets can be negative; Index (enumeration) values are UINT16. A x10 value in INT16 cannot exceed 3276.7, so very high pressures or CO2 readings may not fit.
  • Extract/exhaust naming is swapped inside the controller: 30009 (variable ExhaustAirTemp) is extract air from the room, and 30020 (variable ExtractAirTemp) is exhaust air leaving the unit. Names here follow the measured air, as the manual's own notes do.
  • Enumerations are the Modbus values. The same points over BACnet start at 1 instead of 0 (e.g. run state Stopped is 0 on Modbus, 1 on BACnet).
  • Left out: the per-alarm status registers (30071 onward). In the 3.6 list the value legend (0 Not used, 1 Normal, 2 Blocked, 3 Acknowledge) is printed in the rows of alarms 2-5, which hides those alarms' names, and the full legend only appears in the older 3.2 list. Use the alarm discrete inputs (10033 onward, 0 = no alarm, 1 = alarm) instead.
  • Left out: fan running-hour counters (30004/30005) and accumulated fan energy (30275/30279), because a x10 16-bit value overflows quickly and the manual gives no rollover or energy unit.
  • Left out: weekly schedules (40040-40263, HH.MM x100), holiday dates, PID tuning, alarm delays, I/O assignment indexes, expansion-unit I/O, the real-time clock and the slave-drive tables in chapter 7.
  • Printing errors in the source: the UAI3 and DO3 assignment registers are printed as 3040 and 3066 instead of 30040 and 30066 (neither is included here).
  • Transport: the manual describes RTU framing only. It names Modbus TCP just as one possible physical layer in a general paragraph, so TCP is not listed here.
  • Terminology: the manual's introduction defines 'exhaust' and 'extract' the opposite way round from the register descriptions; the descriptions here follow the register rows and the 3.2 list, where point 9 is the extract (room return) air and point 20 the exhaust air.

Questions about the Regin Corrigo ventilation controller (ventilation application 3.6)

What Modbus registers does the Regin Corrigo ventilation controller (ventilation application 3.6) have?

This map lists 134 registers: 2 coils, 47 discrete inputs, 42 input registers, 43 holding registers. 45 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Regin Corrigo ventilation controller (ventilation application 3.6) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The 3.6 list prints Modicon reference numbers (00001 coils, 10001 discrete inputs, 30001 input registers, 40001 holding registers), and every table starts at 1; the older 3.2 list prints the same points as bare numbers starting at 1 (e.g. 9 for 30009). We apply the standard Modicon rule (subtract the table base and 1), so Outdoor temperature 30001 is input register 0 on the wire. The manual never states the offset in words; the only worked example is a test-tool screenshot that reads AO1 (30054) by entering point address 54, which matches a tool that numbers points from 1. Confirm on site by reading the outdoor or supply temperature.

What are the minimum Modbus registers to integrate the Regin Corrigo ventilation controller (ventilation application 3.6)?

Start with HR 367 Air handler operating mode (Air handler operating mode (manual/auto command)); HR 0 Supply air setpoint (Supply air setpoint); IR 2 Unit run state (Unit run state); IR 6 Supply air temperature (Supply air temperature); IR 0 Outdoor temperature (Outdoor temperature); IR 8 Extract air temperature (Extract air temperature); DI 183 Sum alarm (Sum alarm); CO 2 Acknowledge all alarms (Acknowledge all alarms).

How do I enable Modbus control of the Regin Corrigo ventilation controller (ventilation application 3.6)?

Set the Modbus slave address and line settings on the Corrigo display or with E tool. Defaults are slave address 1, 9600 baud, 8 data bits, no parity, 1 stop bit, RTU. Only signals that have a default value in the list can be written.
