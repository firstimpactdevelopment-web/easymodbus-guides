ABB EQ meter A43 / A44 (Modbus RTU) Modbus register map

Updated 17 November 2026

Short answer

The A43 and A44 are the top-line three-phase DIN-rail meters of ABB's EQ family. With the RS-485 port set to Modbus they answer function 3/6/16 requests on holding registers whose hex numbers go on the wire as printed. This map covers total, tariff, per-phase and resettable energy, instantaneous values, I/O states and pulse counters, identification, CT/VT settings, reset commands and the DMTME-compatible block.

This page lists 182 Modbus registers for the ABB EQ meter A43 / A44 (Modbus RTU) — 33 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ABB’s own free documentation (linked below) and checked against it.

Integration notes: ABB EQ meter A43 / A44 (Modbus RTU)

Integration in brief

Select Modbus for the RS-485 port in the meter's settings menu, then read holding registers with function 3 at the hex addresses as printed (0x5000 for total active import). Multi-register values are high word first; energies are 64-bit with 2 decimals.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the meter's settings menu open the RS-485 communication page, choose Modbus (instead of EQ-Bus), then set baud rate, address and parity.

Byte order & addressing

  • Addresses are hex wire addresses; no 40001 or minus-1 offset.
  • Readable range is 0x1000-0x8EFF; reads outside it return exception 2.
  • Unsupported quantities return FFFF / 7FFF... instead of an exception.
  • Writes to a listed-but-unsupported register are silently ignored; read back to confirm.

Network setup

  • Modbus address 1-247.
  • Baud 1200, 2400, 4800, 9600, 19200, 38400, 57600 or 115200.
  • Parity None, Odd or Even.
  • Function codes 3, 6 and 16; broadcast works with 6 and 16.

Watch out for

  • Modbus runs only on the RS-485 port; the IR side speaks M-Bus or EQ-Bus.
  • In transformer-connected meters (A44) the energy registers hold primary values: the CT/VT ratios at 0x8C04-0x8C0A are already applied.

Notes on this map

  • Addresses are hex wire addresses. All data is in holding registers: read with function 3 (up to 125 registers), write with 6 or 16.
  • Multi-register values put the most significant byte in the high byte of the lowest register, so 32-bit and 64-bit values are ABCD.
  • Quantities a given article does not measure still answer, filled with FFFF (unsigned) or the largest positive value (signed).
  • Left out: resettable reactive import/export (5534, 5538 hex). The manual prints kWh as their unit, so the unit cannot be taken from the table as printed.
  • Instantaneous power registers are signed 32-bit with 2 decimals (about +/-21 MW maximum); the DMTME block at 0x1000 gives whole watts for larger systems.
  • Left out: date/time and power-outage time (packed byte fields), the 64-bit error/information/warning/alarm flag strings, harmonics arrays, load-profile resets, DST start/end packed fields, the DMTME energy rows printed as 'Wh*100' / 'VArh*100', the DMTME CT/VT ratio rows, and the selector-based log and load-profile readout.
  • I/O registers exist only on articles with matching inputs/outputs; steel-type (A43/A44 1xx-xxx) variants hold import registers only.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ABB EQ meter A43 / A44 (Modbus RTU)

What Modbus registers does the ABB EQ meter A43 / A44 (Modbus RTU) have?

This map lists 182 registers: 182 holding registers. 33 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB EQ meter A43 / A44 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every start register is printed in hex exactly as sent on the bus; the manual says not to subtract 40000 or 1. 5000 hex = 20480 decimal. The example request frame reads 0x5000 with function 3.

What byte order does the ABB EQ meter A43 / A44 (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ABB EQ meter A43 / A44 (Modbus RTU)?

Start with HR 20480 Active import energy (Total active import energy (0.01 kWh)); HR 20484 Active export energy (Total active export energy); HR 23296 Voltage L1-N (Voltage L1-N); HR 23308 Current L1 (Current L1); HR 23316 Active power Total (Total active power (signed, 0.01 W)); HR 23340 Frequency (Frequency); HR 23354 Power factor Total (Total power factor); HR 35072 Serial number (Serial number, quick comms check).

How do I enable Modbus control of the ABB EQ meter A43 / A44 (Modbus RTU)?

In the meter's settings menu open the RS-485 communication page, choose Modbus (instead of EQ-Bus), then set baud rate, address and parity.
