Accuenergy Acuvim-L Series Modbus register map

Updated 16 October 2026

Short answer

The Acuvim-L is a panel-mount multifunction power and energy meter with RS485 Modbus RTU and optional expansion modules (Ethernet with Modbus TCP, I/O). All register data is in holding registers at hex addresses: settings and status as 16-bit words, real-time readings as 32-bit floats from 2180H, energy as scaled 32-bit integers from 2080H and THD as scaled 16-bit values. Relays and digital inputs on I/O modules use coil and discrete-input functions.

This page lists 112 Modbus registers for the Accuenergy Acuvim-L Series — 55 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Accuenergy’s own free documentation (linked below) and checked against it.

Integration notes: Accuenergy Acuvim-L Series

Integration in brief

Read the floats at 2180H-21D3H with function 03 (high word first) for voltage, current, power, PF and demand, and the uint32 energy counters from 2080H. Set Basic Parameter Mode 101DH = 1 so floats are already primary values.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Channel 1 must be set to Modbus (0FFEH = 0, the default). Writable registers are changed with function 10H; relays on an I/O module are switched with function 05.

Byte order & addressing

  • All register data is read with function 03; the manual lists no function 04. Relays use functions 01/05 and digital inputs function 02.
  • Float readings are secondary-mode values unless Basic Parameter Mode 101DH is set to 1 (Primary); the default is Secondary.
  • Energy counters are integers whose resolution follows the energy display mode.

Network setup

  • Channel 1 defaults: address 1, 19200 bps, no parity with 1 stop bit (parity code 3).
  • Set wiring type (1003H/1004H) and CT/PT ratios to match the installation before relying on readings.

Watch out for

  • System status flags (102EH) should be cleared after reading or new alarm/SOE records may not be stored.
  • Writing 1 to Clear energy (1016H) erases the energy counters.

Notes on this map

  • Word order: the read example returns frequency 50.00 Hz as 42 48 00 00 (high word first) and dword values are defined as high word first. All 32-bit values here are ABCD.
  • IMPORTANT - primary vs secondary: Basic Parameter Mode (101DH) controls the real-time float block (Table 6-19, 2180H-21D3H). Its default is 0 = Secondary. Only with 101DH = 1 do the registers hold primary values, and only then are the scales and units in this map correct for voltage, current, power and demand. In secondary mode the manual gives primary voltage = value x PT1/PT2, current = value x CT1/CT2, power = value x (PT1/PT2) x (CT1/CT2) / 1000 (kW, kvar, kVA). For 333 mV and Rogowski (100 mV/50 Hz, 120 mV/60 Hz) CT options the manual says to use CT2 = 1 in that calculation, so the raw current value is then not a secondary-side ampere reading. This map cannot express a ratio taken from other registers, and PT1/PT2 are not mapped (see below), so set 101DH = 1 before using these registers. Frequency, power factor, unbalance and load type are the same in both modes.
  • Power, reactive power, apparent power and power demand floats are divided by 1000 to give kW, kvar and kVA (primary mode), so scale 0.001 is used with those units.
  • Energy scale depends on Energy Display Mode (1019H). The manual states the default is 'Primary 0.1 Mode' (register value 0, 'Primary in kWh'), for which the energy table gives Rx/10; scale 0.1 in this map is valid only in that mode and each energy register says so. Secondary mode (1) is Rx/1000. Mode 2 is labelled 'Primary in 0.01kWh' in the settings table but 'Primary 0.001 Mode' (Rx/1000) in the energy table, so its resolution is unclear.
  • The manual's worked examples read the 4000H block (frequency at 4000H, energy at 4048H), but the v4 address tables list real-time floats at 3000H and 2180H and energy at 2080H. This map uses the tabulated 2180H/2080H addresses.
  • Left out: net active/reactive/apparent energy (2086H, 2096H, 20A6H), typed uint32 but with a signed range; reactive and apparent power demand (21C8H/21CAH), whose formulas and units are swapped in the table.
  • Left out: channel 1/2 baud rate (1002H, 102FH) and PT1/PT2 (1005H-1007H), whose encodings in a 16-bit word are not explained.
  • Not covered: 3000H basic block (duplicates 2180H), harmonics by order, max/min, TOU, alarms, logs and I/O module settings.
  • The channel 1 protocol register (0FFEH) lists 2 = BACnet MS/TP in the table, but the note under the table says 1 selects BACnet, so only 0 = Modbus is given.
  • The energy table prints apparent-energy units as kVA; they are given here as kVAh.
  • The address-block discrepancy above has not been checked on a meter: the worked examples and the historical-log section use 4000H (frequency) and 4002H (phase A voltage), while the register tables give 2180H/2080H. If 2180H returns an exception on older firmware, compare with the Acuvim II map.

Questions about the Accuenergy Acuvim-L Series

What Modbus registers does the Accuenergy Acuvim-L Series have?

This map lists 112 registers: 2 coils, 4 discrete inputs, 106 holding registers. 55 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Accuenergy Acuvim-L Series Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each register is listed by hex address (e.g. 2180H) with its decimal value (8576); that number goes on the wire unchanged, as in the manual's query example with start address 40 00H.

What byte order does the Accuenergy Acuvim-L Series use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Accuenergy Acuvim-L Series?

Start with HR 8576 Frequency (Frequency); HR 8578 Phase 1 voltage (Phase 1 voltage); HR 8594 Phase A current (Phase A current); HR 8614 Total system power (Total system power); HR 8638 Total power factor (Total power factor); HR 8320 Import active energy (Import active energy); HR 8322 Export active energy (Export active energy); HR 4125 Basic parameter mode (Primary/secondary mode for float readings).

How do I enable Modbus control of the Accuenergy Acuvim-L Series?

Channel 1 must be set to Modbus (0FFEH = 0, the default). Writable registers are changed with function 10H; relays on an I/O module are switched with function 05.
