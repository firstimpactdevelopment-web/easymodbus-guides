Short answer

Procon protocol converter that plugs into the CN105/CN92 connector of one Mitsubishi Electric split indoor unit and serves Modbus RTU or BACnet MS/TP on RS-485. For Air-To-Air units it exposes mode, setpoint, fan, vane and on/off, room temperature and fault code, the BMS room-sensor setpoint offset and deadband auto-changeover settings.

Integration notes: Mitsubishi Electric MelcoBEMS MINI (A1M) gateway for Air-To-Air split units

Integration in brief

Set DIP 7 ON for Modbus RTU, choose the slave ID on DIP 1-5 and set DIP 6 ON for 9600 / no parity. Write mode, setpoint, fan, vane and on/off at holding 0-3 and 7, and poll room temperature (8) and fault code (12).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

DIP 7 ON = Modbus RTU (OFF = BACnet MS/TP).

Byte order & addressing

  • Node address on DIP 1-5 (1-30, binary); all ON = address from holding 4; all OFF = address 1.
  • DIP 6 ON = 9600 baud, no parity; OFF = holding 5 and 6. Data bits 8 and stop bits 1 are fixed.
  • Setting the BMS room temperature to 0 °C turns the setpoint offset feature off.

Network setup

  • Plug the flying lead into CN105/CN92 on the indoor unit PCB; it is powered from there (12 V DC).
  • Use one A1M per indoor unit if the fault register is used; with MXZ multi-splits one A1M per indoor unit is required.

Watch out for

  • The RS-485 ACK LED flashes on valid Modbus or BACnet traffic; if it stays lit without flashing, check the RS-485 wiring and the protocol / baud / parity settings.

Notes on this map

  • This file covers only the Air-To-Air tables (section 11). The same manual has Lossnay tables (section 13); the Air-To-Water tables are in a separate register-table document.
  • Input values and the coil are mirrored as read-only holding registers for BMSs that only read holding registers. There are no discrete inputs for Air-To-Air systems.
  • BMS room temperature is given signed (40016) and unsigned (40017). Deadband setpoints (40019/40020) are whole °C, unlike the x10 setpoint and temperatures.
  • Holding 4 and 5 serve as the Modbus slave ID / baud rate or the BACnet station ID / baud rate, depending on the protocol chosen on DIP 7.
  • The BACnet device instance is a 32-bit value: the manual names 272 the most significant and 273 the least significant 16 bits, so it is listed as UINT32 high word first.
  • Fault codes other than 8000 / 0x8000 and 6999 / 0x6999 are the indoor unit's own codes.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Mitsubishi Electric MelcoBEMS MINI (A1M) gateway for Air-To-Air split units

What Modbus registers does the Mitsubishi Electric MelcoBEMS MINI (A1M) gateway for Air-To-Air split units have?

This map lists 33 registers: 1 coil, 7 input registers, 25 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Mitsubishi Electric MelcoBEMS MINI (A1M) gateway for Air-To-Air split units Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every row prints a 0-based 'Address' next to the Modicon address (40001 = holding 0, 30001 = input 0, 00001 = coil 0). The 0-based address is the wire address.

What byte order does the Mitsubishi Electric MelcoBEMS MINI (A1M) gateway for Air-To-Air split units use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Mitsubishi Electric MelcoBEMS MINI (A1M) gateway for Air-To-Air split units?

Start with HR 7 Drive On/Off (On/off); HR 0 Drive mode (Mode); HR 1 Temperature setpoint (Setpoint (x10)); HR 2 Fan speed (Fan speed); HR 8 Room temperature (Room temperature (x10)); HR 12 Fault code (decimal) (Fault code (8000 = none)).

How do I enable Modbus control of the Mitsubishi Electric MelcoBEMS MINI (A1M) gateway for Air-To-Air split units?
