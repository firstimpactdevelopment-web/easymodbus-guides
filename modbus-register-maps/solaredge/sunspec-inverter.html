SolarEdge SolarEdge inverters (SunSpec logging) Modbus register map

Updated 16 October 2026

Short answer

SolarEdge inverters expose a read-only SunSpec map: the common block at 40000, inverter model 101/102/103 at 40069, and up to three SolarEdge-connected meter blocks after it. Every measurement is an integer paired with a signed power-of-ten scale-factor register. This map covers identity and the 16-bit inverter AC/DC measurements, operating state and the 16-bit vendor status code, plus meter 1 currents, voltages, frequency and power; 32-bit registers are left out because the note contradicts itself on their word order.

This page lists 77 Modbus registers for the SolarEdge SolarEdge inverters (SunSpec logging) — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from SolarEdge’s own free documentation (linked below) and checked against it.

Integration notes: SolarEdge SolarEdge inverters (SunSpec logging)

Integration in brief

Enable Modbus TCP (LAN only) or set RS485-1 to the SunSpec (Non-SE Logger) protocol, then read 40069-40108 with function 03 at unit ID 1. Check that 40069 reads 101, 102 or 103 to confirm the addressing, then decode each value with its scale-factor register.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

SolarEdge Go / SetApp: Commissioning > Site Communication > Modbus TCP > Enable (port 1502 by default), or RS485-1 > Protocol > SunSpec (Non-SE Logger) with a unique Device ID 1-247. LCD inverters: Communication > LAN Conf > Modbus TCP (port 502 by default), or the RS485-1 Conf menu. Modbus TCP is off from the factory.

Communication loss & watchdog

No SunSpec communication watchdog is described. The note gives a 2-minute idle time for the Modbus TCP server and advises sending a request within that window to keep the connection open.

Byte order & addressing

  • Off-by-one trap: the note prints both columns. Request 40000 (base 0) for the SunSpec marker; a tool that subtracts 1 from 40001-style numbers must start from the base-1 column, never from the base-0 one, or every register is one late and SFs are misread.
  • Every value has its own scale-factor register (raw x 10^SF); SFs can change, so read them together with the values.
  • 32-bit values (SunS marker, lifetime energy, meter energy counters, Vendor4 status, meter events) are not listed: the note says big-endian in one place and little-endian word order in another. Reading 40000-40001 on site (0x5375 0x6E53 = high word first) shows which applies before you decode any 32-bit value.
  • On Synergy three-phase inverters model 160 sits at 40121 and the meter blocks move by +50 or +70 registers.

Network setup

  • TCP: LAN cable only (Wi-Fi is not supported for Modbus TCP); the inverter on Ethernet answers at unit ID 1; default port 1502 on SolarEdge Go/SetApp units and 502 on LCD units, both configurable.
  • RTU: RS485, 115200 bps 8N1 by default, adjustable 9600-115200 bps; each inverter needs a unique Device ID 1-247 and the logger's ID must differ from all of them.
  • A follower inverter cannot talk to a SolarEdge leader and a third-party logger on the same RS485 bus; use the second RS485 port or a Commercial Gateway.
  • After enabling TCP the LCD status shows Init for about 10 s before Ready.

Watch out for

  • Only one Modbus TCP client and only one Modbus leader (RTU or TCP) are supported at a time - a second logger or home-automation integration will lock out the first.
  • Unsupported registers return the SunSpec NOT_IMPLEMENTED value; unsupported meter accumulators may read 0.
  • Appendix B quotes read/write response times under 0.5 s, measured on three-phase commercial SetApp inverters (firmware 4.13.5xx and later).

Notes on this map

  • All registers are read with function 03; the note describes this SunSpec map as read-only monitoring data.
  • Value = raw x 10^SF, where SF is the signed int16 named in scale_factor_ref. Read a value and its SF in the same request so they belong to the same sample.
  • Word order: the meter section of the note says registers are big-endian with the most significant part first, but Appendix A states, for communicating with SolarEdge devices in general, that 32-bit values use little-endian word order (with a big-endian copy at +0x800). The appendix does not limit that statement to the proprietary registers, so every 32-bit register is left out: C_SunSpec_ID 40000, I_AC_Energy_WH 40093, I_Status_Vendor4 40119, meter 1 real-energy counters 40226-40240, apparent-energy totals 40243/40251 and M_Events 40293. Their scale-factor registers (40095, 40242, 40259) are kept.
  • I_AC_Energy_WH_SF (40095) is typed uint16 in this note although SunSpec scale factors are signed int16; the published type is kept. Its energy register is not listed (see word order).
  • The note attaches a footnote to I_AC_VoltageAN/BN/CN reading 'Supported only in split-phase configurations'; the same footnote marker also appears on the status table. These registers may be unimplemented on some grid setups.
  • On the inverter table the footnote 'use this field for versions up to 3.19.XX' is attached to I_Status_Vendor (40108) and also to I_AC_PF and I_AC_PF_SF (40091-40092).
  • Left out: Multiple MPPT extension model 160 (from 40121, Synergy three-phase inverters only, firmware 4.13+). On Synergy units it occupies the addresses where meter 1 sits on other inverters, and the meter blocks move by +50 (2-unit) or +70 (3-unit).
  • Left out: meter line-to-line voltages 40199-40202 (the note says SolarEdge meters do not report L-L voltage over SunSpec), per-phase meter VA/var/PF, per-phase apparent energies and the reactive-energy quadrant counters 40260-40292.
  • Meters 2 and 3 repeat the meter 1 layout at base 40295 and 40469 (base 0, default). Only enabled meters are readable and they are packed in order, so if meters 1 and 3 are enabled, meter 3 appears in the meter 2 slot.
  • The meter overview text mentions DID 4 or 5, while the register table lists 201-204; the table values are used here.
  • Active/reactive power control (curtailment) is documented in SolarEdge's separate Power Control document and is not part of this map.

Questions about the SolarEdge SolarEdge inverters (SunSpec logging)

What Modbus registers does the SolarEdge SolarEdge inverters (SunSpec logging) have?

This map lists 77 registers: 77 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the SolarEdge SolarEdge inverters (SunSpec logging) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The source prints two columns for every register: 'base 0' (Modbus protocol address) and 'base 1' (PLC address). 'documented' holds the base-0 value, which goes on the wire unchanged: the SunSpec marker is requested at 40000, and the same register is listed as 40001 in the base-1 column.

What are the minimum Modbus registers to integrate the SolarEdge SolarEdge inverters (SunSpec logging)?

Start with HR 40069 C_SunSpec_DID (Inverter model ID (101/102/103) - proves the addressing is right); HR 40083 I_AC_Power (AC output power); HR 40084 I_AC_Power_SF (AC power scale factor); HR 40085 I_AC_Frequency (Grid frequency); HR 40086 I_AC_Frequency_SF (Frequency scale factor); HR 40107 I_Status (Operating state); HR 40206 Meter 1 M_AC_Power (Meter 1 total real power (grid import/export)); HR 40210 Meter 1 M_AC_Power_SF (Meter 1 power scale factor).

How do I enable Modbus control of the SolarEdge SolarEdge inverters (SunSpec logging)?

SolarEdge Go / SetApp: Commissioning > Site Communication > Modbus TCP > Enable (port 1502 by default), or RS485-1 > Protocol > SunSpec (Non-SE Logger) with a unique Device ID 1-247. LCD inverters: Communication > LAN Conf > Modbus TCP (port 502 by default), or the RS485-1 Conf menu. Modbus TCP is off from the factory.

What happens when the SolarEdge SolarEdge inverters (SunSpec logging) loses Modbus communication?

No SunSpec communication watchdog is described. The note gives a 2-minute idle time for the Modbus TCP server and advises sending a request within that window to keep the connection open.
