Integration notes: Trane Agility water-cooled centrifugal chiller (Symbio 800)

Integration in brief

Read the analog inputs as pairs of input registers (float, high word first) and the binary/multi-state points as single registers. Write the BAS setpoints and command points in the 4xxxx holding range.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

On the Symbio 800 web interface (USB connection) go to Installation > Identification and Communications > Protocol Configuration and select Modbus RTU or Modbus TCP; for TCP set the IP address on the IP Configuration tab.

Byte order & addressing

  • Analog values are 32-bit floats in two consecutive registers, high word first.
  • 0xFFFF in a binary or multi-state register and NaN in an analog register mean the value is invalid.

Network setup

  • The Modbus RTU address comes from the controller's rotary dials (001-247); 000 disables Modbus RTU. A change takes effect without a power cycle.
  • Modbus TCP uses Ethernet port 1 (port 2 is reserved for the optional touch screen); the rotary address is not used for TCP and the Wi-Fi module does not support Modbus TCP.

Watch out for

  • Points not supported by the unit's configuration are absent; confirm the configuration dependencies before mapping.

Notes on this map

  • Register format table: analog points are 32-bit floats sent high word / high byte first (NaN = invalid); binary and multi-state points are unsigned 16-bit integers (0xFFFF = invalid).
  • Values are sent in the unit system ordered from the factory (I-P is the usual default, SI optional); the list names only the quantity, so temperature/pressure/flow units are left blank here.
  • Not every point exists on every unit: the controller builds its point set from the unit's configuration. Descriptions name the configuration a point depends on.
  • Register numbers are printed in 5-digit Modicon form (3xxxx input registers, 4xxxx holding registers) and converted here to wire addresses (30011 = input register 10).
  • Agility integration guide BAS-SVP047B-EN (Sept 2023, https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Integration/BAS-SVP047B-EN_09092023.pdf) gives the same register format and the Modbus RTU/TCP setup steps used in the integration block.
  • Left out: AI-10173 to AI-10184 (registers 30157-30168). The list numbers these 32-bit floats one register apart, which cannot be right for two-register values, so their true addresses are unclear.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. What Modbus registers does the Trane Agility water-cooled centrifugal chiller (Symbio 800) have?

Are the Trane Agility water-cooled centrifugal chiller (Symbio 800) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The list prints Modicon register numbers: 3xxxx are input registers and 4xxxx holding registers, so 30011 is input register address 10 and 42011 is holding register address 2010.

What byte order does the Trane Agility water-cooled centrifugal chiller (Symbio 800) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.
