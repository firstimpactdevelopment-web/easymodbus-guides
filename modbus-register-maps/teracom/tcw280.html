Teracom TCW280 Ethernet analog output module Modbus register map

Updated 19 November 2026

Short answer

The TCW280 is a Teracom Ethernet module with 2 isolated analog outputs (0-5/0-10 V or 0-20/4-20/0-24 mA), 4 open-drain digital outputs with ON/OFF or PWM mode and 2 relays. Over Modbus TCP the relays and digital outputs are coils, and modes, ranges, setpoints and alarms are holding registers.

This page lists 62 Modbus registers for the Teracom TCW280 Ethernet analog output module — 57 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Teracom’s own free documentation (linked below) and checked against it.

Integration notes: Teracom TCW280 Ethernet analog output module

Integration in brief

Enable Modbus TCP, set each analog output's mode and range (holding 18200/18300), then write the output value as a float to holding 18500/18502 with function 16.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP is off by default. Turn it on in the Modbus TCP/IP settings of the web interface (default port 502).

Byte order & addressing

  • Floats are high word first (ABCD).

Network setup

  • The factory IP is 192.168.1.2 (web login admin/admin); change it in the network settings, then enable Modbus TCP/IP.

Notes on this map

  • Word order: the manual says float registers are sent big-endian and its example response 3FA0 0000 is given as 1.25, i.e. high word first (ABCD).
  • Strings are fixed-length UTF-8, zero padded; 64-byte fields span 32 registers.
  • Left out: Save configuration, Restart device and HW error (PDU 50000-50002), whose data size column is empty in this manual.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Teracom TCW280 Ethernet analog output module

What Modbus registers does the Teracom TCW280 Ethernet analog output module have?

This map lists 62 registers: 6 coils, 56 holding registers. 57 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Teracom TCW280 Ethernet analog output module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The address table prints PDU (wire) addresses in decimal. The manual's example frames use them directly (coil 100 = 0x0064, holding register 500 = 0x01F4), so no offset is applied.

What byte order does the Teracom TCW280 Ethernet analog output module use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Teracom TCW280 Ethernet analog output module?

Start with CO 100 Relay 1 (Relay 1); HR 18500 Analog out 1 value (Analog output 1 value); HR 18200 Analog out 1 mode (Analog output 1 mode); HR 18300 Analog out 1 range (Analog output 1 range); HR 18600 Analog out 1 alarm (Analog output 1 alarm); HR 16700 Digital out 1 state (Digital output 1 state).

How do I enable Modbus control of the Teracom TCW280 Ethernet analog output module?

Modbus TCP is off by default. Turn it on in the Modbus TCP/IP settings of the web interface (default port 502).

Where is the official Teracom TCW280 Ethernet analog output module Modbus documentation?

The source is TCW280 User manual (TCW280_R1.8), revision 2026-10, published free by Teracom at https://www.teracomsystems.com/download/analog-output-module-tcw280-user-manual/.
