Integration notes: JUMO ecoLine O-DO digital optical dissolved oxygen sensor (Modbus RTU)

Integration in brief

Write the compensation values (93-98), write 7 to register 1, wait 300 ms, poll register 82 until no 3-bit field equals 7, then read 83-90 as ABCD floats.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is the sensor's native interface; set the address with JUMO DSM software.

Byte order & addressing

  • Floats are high word first (ABCD).
  • No Modbus requests are allowed for 300 ms after a start command; requests during that window are ignored.

Network setup

  • 9600 baud, 8 data bits, no parity, 1 stop bit; address 1-247.
  • Wire A/B on M12 pins 5/4; the sensor needs +5 V on pin 1.

Watch out for

  • Resend the compensation values after every power-up; they are not stored.

Notes on this map

  • Floats are IEEE 754 sent high word first (ABCD); the worked example returns 41 CA 66 66 = 25.3 °C for start address 0x0053.
  • Measurements are triggered: write a start command to register 1, wait at least 300 ms without any Modbus traffic, poll the status word at 82 until no field reads 7, then read the values.
  • Integers are unsigned 16-bit, high byte first.
  • Each 3-bit field: 0 OK, 1 OK but outside sensor spec, 2 OK with reduced accuracy, 3 OK (reserved), 4 failed outside spec, 5 failed (membrane cap missing or damaged), 6 failed (reserved), 7 not yet complete.
  • Only the values requested by the start command are valid after a cycle; ignore the others.
  • Compensation values are not saved in the sensor; the master must write them before measuring if they differ from the defaults. Whether the sensor uses its own or the written temperature is chosen in JUMO DSM software.
  • The membrane is rated for about 1 million measurements, so do not trigger faster than needed.
  • The document gives the address range 1-247 but does not state a factory default address.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the JUMO ecoLine O-DO digital optical dissolved oxygen sensor (Modbus RTU)

What Modbus registers does the JUMO ecoLine O-DO digital optical dissolved oxygen sensor (Modbus RTU) have?

This map lists 9 registers: 9 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the JUMO ecoLine O-DO digital optical dissolved oxygen sensor (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables list the Modbus PDU address in decimal and hex; the value goes into the request unchanged (the example reads the temperature at start address 0x0053).

What byte order does the JUMO ecoLine O-DO digital optical dissolved oxygen sensor (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the JUMO ecoLine O-DO digital optical dissolved oxygen sensor (Modbus RTU)?

Start with HR 1 Start measuring operation (Start a measurement); HR 82 Measuring operation status (Measurement status); HR 83 Temperature (Temperature); HR 85 Oxygen saturation (O2 saturation); HR 87 Oxygen concentration (O2 mg/l).

How do I enable Modbus control of the JUMO ecoLine O-DO digital optical dissolved oxygen sensor (Modbus RTU)?

Modbus RTU is the sensor's native interface; set the address with JUMO DSM software.
