Short answer

The E7 is Yaskawa's legacy HVAC fan/pump drive with a built-in RS-422/485 port that speaks Memobus/Modbus RTU (or Metasys N2 / APOGEE FLN). All registers are hex: commands at 0001h-000Fh, detailed fault and alarm words from 0010h, status from 0020h, U1/U2/U3 monitors from 0040h, and every parameter at its own address. This map covers the command block, all status/fault words, the main monitors with their published units, and the b1/H5 communication parameters.

Integration notes: Yaskawa E7 HVAC drive (CIMR-E7U) - Modbus RTU

Integration in brief

Set H5-08 = 0, H5-01..H5-03 at the keypad and power-cycle; set b1-01 = 2 and b1-02 = 2 to take reference and run from Modbus. Write 0001h/0002h together with function 10h and poll 0020h-002Dh plus 0042h-0046h.

Enable Modbus control & writes

H5-08 = 0 selects Memobus/Modbus (1 = Metasys N2, 2 = APOGEE FLN). Set H5-01 (default 1Fh), H5-02 (default 3 = 9600) and H5-03 (default none) and cycle power. b1-01 = 2 and b1-02 = 2 hand reference and run to serial communications.

Communication loss & watchdog

H5-05 = 1 (default) enables CE detection after H5-09 (default 2.0 s); H5-04 sets the reaction: 0 ramp, 1 coast, 2 fast-stop, 3 alarm only (default), 4 run at d1-04. 002Ch bit F flags a comm timeout.

Byte order & addressing

  • Registers and the slave address are hex.
  • Function codes 03h, 06h, 08h and 10h; the parameter manual allows 1-8 registers per read.
  • Serial parameter writes go to RAM; write 0 to 0900h (ENTER) to keep them over power loss (100,000 write limit). Run-locked parameters need 0910h (ACCEPT).
  • Network multi-function inputs are ORed with the terminals.

Network setup

  • RS-485: jumper S+ to R+ and S- to R-; up to 31 drives.
  • Slave address 1-20h (1-32), default 1Fh; 0 is broadcast.
  • 8 data bits, 1 stop bit; 1200-19200 baud.

Watch out for

  • H5-08 must be 0; an E7 left on N2 or FLN will not answer Modbus.
  • Fault trace values are not stored for CPF00/CPF01/CPF03, UV1 and UV2.

Notes on this map

  • 0040h/0041h frequency monitors are printed as 'Units 0.01Hz' in TM.E7.11, but the E7 user manual (TM.E7.01) says frequency monitor units change with o1-03; they are left unscaled here. 0002h frequency reference likewise depends on the display-unit setting.
  • Left out because the sign is not stated: 0028h/0032h torque, 0047h/0033h output power, 0063h-0065h PID input/output/setpoint, 0068h heatsink temperature, 0051h Iq, and 0038h-003Ah PID levels (no units printed in TM.E7.11).
  • 0011h operator status and 0012h OPE bits and 0013h product code are not included.
  • Fault code numbers for U2-01/U3-01 are not tabulated in TM.E7.11, so no value list is given.
  • Broadcast (slave 0): 0001h bit 0 run, bit 1 reverse, bits 5/6 multi-function inputs S3/S4, bits C-E S5-S7 (enabled by 000Fh bits C-E); 0002h frequency reference fixed at 30000 = 100 % of maximum frequency.
  • The register map comes from TM.E7.11; the E7 user manual TM.E7.01 Appendix D gives the same data-table layout.
  • From the free E7 user manual TM.E7.01 (Appendix D, https://www.yaskawa.com/delegate/getAttachment?documentId=TM.E7.01&cmd=documents&documentName=TM.E7.01.pdf): 8 data bits and 1 stop bit, up to 31 slaves, ENTER/RAM-only registers 0900H/0910H, and no fault trace for CPF00, CPF01, CPF03, UV1 and UV2.

Questions about the Yaskawa E7 HVAC drive (CIMR-E7U) - Modbus RTU

What Modbus registers does the Yaskawa E7 HVAC drive (CIMR-E7U) - Modbus RTU have?

This map lists 66 registers: 66 holding registers. 21 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yaskawa E7 HVAC drive (CIMR-E7U) - Modbus RTU Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. All addresses are hex and go into the request unchanged: the manual's read example sets starting register 00h 20h to read 0020h-0023h. Parameters use the hex address in the parameter table (b1-01 = 0180h, H5-01 = 0425h). ENTER/ACCEPT are printed as 900/910, i.e. 0900h/0910h.

What are the minimum Modbus registers to integrate the Yaskawa E7 HVAC drive (CIMR-E7U) - Modbus RTU?

Start with HR 1 Command (Run/stop, direction, reset); HR 2 Frequency reference (Frequency reference); HR 32 Inverter status (0020h) (Run/ready/fault); HR 33 Fault contents (summary) (Fault summary); HR 44 Inverter status (002Ch) (Status incl. comm timeout); HR 65 Output frequency (U1-02) (Output frequency); HR 66 Output current (U1-03) (Output current); HR 128 Current fault (U2-01) (Current fault code).

How do I enable Modbus control of the Yaskawa E7 HVAC drive (CIMR-E7U) - Modbus RTU?

H5-08 = 0 selects Memobus/Modbus (1 = Metasys N2, 2 = APOGEE FLN). Set H5-01 (default 1Fh), H5-02 (default 3 = 9600) and H5-03 (default none) and cycle power. b1-01 = 2 and b1-02 = 2 hand reference and run to serial communications.

What happens when the Yaskawa E7 HVAC drive (CIMR-E7U) - Modbus RTU loses Modbus communication?

H5-05 = 1 (default) enables CE detection after H5-09 (default 2.0 s); H5-04 sets the reaction: 0 ramp, 1 coast, 2 fast-stop, 3 alarm only (default), 4 run at d1-04. 002Ch bit F flags a comm timeout.
