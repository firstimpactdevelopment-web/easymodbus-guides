Grundfos E-pumps (MAGNA3, TPE, CRE, CUE) via CIM 200 / CIM 500 Modbus register map

Updated 16 October 2026

Short answer

Grundfos exposes its electronically controlled pumps over Modbus through a plug-in CIM 200 (RTU) or CIM 500 (Modbus TCP) module, a CIU box, or the SoftCIM port on newer MGE motors. All pump types share one functional profile: a control block (remote/start/stop, control mode, setpoint), a status block and a measurement block. This map covers the module configuration and watchdog, control and status words, alarm/warning codes and the live measurements; many measurements exist only on certain motor generations or with an extra sensor.

This page lists 102 Modbus registers for the Grundfos E-pumps (MAGNA3, TPE, CRE, CUE) via CIM 200 / CIM 500 — 20 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Grundfos’s own free documentation (linked below) and checked against it.

Integration notes: Grundfos E-pumps (MAGNA3, TPE, CRE, CUE) via CIM 200 / CIM 500

Integration in brief

Set the CIM 200 address on the two hex rotary switches (or the CIM 500 to Modbus TCP), then write control register 00101 = 3 (remote + start) and the setpoint to 00104 in 0.01 % steps. Poll 00201 for on/alarm/warning bits, 00205/00206 for codes and 00301 onwards for head, flow, speed and power.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Bus control requires bit 0 (RemoteAccessReq) of 00101 = 1; then bit 1 starts (1) or stops (0) the pump. OperationMode 00103 only takes effect while the pump is commanded on (OnOffReq = 1).

Communication loss & watchdog

Register 00012 sets a comm-loss timeout of 5-3600 s (0 = disabled, the default). Any valid telegram feeds it; on timeout the pump returns to Local mode.

Byte order & addressing

  • Register numbers are 1-based: 00104 is wire address 103.
  • Temperatures are in 0.01 K, not degrees C.
  • ResetAlarm (00101 bit 2) acts on a rising edge; with AutoAckControlBits (00005) = 0 you must clear the bit yourself before the next reset.
  • The setpoint is a percentage of the configured sensor range (closed loop) or of nominal frequency (open loop), not an engineering value.
  • The manual's 'stop' telegram example shows value 0x03 in the frame but 0x0001 in the text; 0x0001 (remote, off) is the stop command per the bit definitions.

Network setup

  • CIM 200: set the slave address (1-247) on hex rotary switches SW6 (high nibble) and SW7 (low nibble).
  • CIM 200 baud via SW4/SW5: OFF/ON = 9600, OFF/OFF = 19200 (default), ON/OFF = 38400, ON/ON = software-defined (registers 00003/00004/00009/00010).
  • CIM 200 parity via SW3: OFF = even parity, 1 stop bit (default); ON = no parity, 2 stop bits.
  • CIM 200 line termination (120 ohm) via SW1 and SW2, both ON = terminated; default is not terminated. Switch changes take effect immediately.
  • CIM 500: set the protocol rotary switch to the Modbus TCP position, then set the Modbus TCP IP address in the web server (default web server 192.168.1.100, user admin). The Modbus TCP IP must differ from the web server IP; port 502 is always active.
  • SoftCIM (MGE with FM310/311/110): configure address, baud, parity, stop bits and watchdog in Grundfos GO under Settings > Communication > RS485 AYB.

Watch out for

  • Register 00002 is shown as RESERVED in the table but returns 'RegisterOffset' in the manual's example; leave it at 0.
  • SoftCIM cannot be used while a CIM module is fitted in the same MGE motor; set the AYB port to GENIbus in that case.
  • Restart the CIM/CIU after changing the pump's sensor configuration so measurement scaling is updated.
  • Unit ID is ignored by the CIM 500 on Modbus TCP.

Notes on this map

  • All blocks can be read with function code 03 or 04; this map lists them as holding registers. Configuration and control registers are written with 06 or 16.
  • 32-bit values are split into HI and LO registers with HI at the lower address; the manual gives value = HI x 65536 + LO, so word order is ABCD.
  • Temperatures are published in 0.01 K (kelvin); subtract 273.15 to get degrees C.
  • InletPressure (00315) carries a -1.000 bar offset; FeedTankLevel (00317) and StorageTankLevel (00350) carry a -100 m offset. These are applied via offset.
  • A raw value of 0xFFFF in the measurement block means 'not available' (sensor missing or pump type does not support it). Many measurements need MGE model G/H/K, CUE or an external sensor; see the availability table on pp. 23-24.
  • Left out: FeedbackSensorMin/Max (00210/00211) because the manual gives no scaling; Conductivity, pH and Turbidity (00363-00365) because the published units look inconsistent; user registers 00751-00800 (free storage). Also left out: SetMaxFlowLimit (00106), because the manual says it is written in 0.01 m³/h while its read-back register MaxFlowLimit (00345) is listed in 0.1 m³/h; the write scale is not certain.
  • SoftCIM Modbus RTU and CIM 200 support the same registers unless noted. In the configuration block, 00001, 00003, 00004, 00009 and 00010 apply to the CIM 200 only (not CIM 500), and 00001 is not supported by SoftCIM; 00005 and 00012 apply to both CIM 200 and CIM 500.
  • Alarm and warning code lists are shared; not every code applies to every pump type.

Questions about the Grundfos E-pumps (MAGNA3, TPE, CRE, CUE) via CIM 200 / CIM 500

What Modbus registers does the Grundfos E-pumps (MAGNA3, TPE, CRE, CUE) via CIM 200 / CIM 500 have?

This map lists 102 registers: 102 holding registers. 20 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Grundfos E-pumps (MAGNA3, TPE, CRE, CUE) via CIM 200 / CIM 500 Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as 5-digit register numbers (00104 = Setpoint). The manual's telegram examples address register X as X-1 on the wire, e.g. Setpoint 00104 is written at address 0x0067 (103).

What byte order does the Grundfos E-pumps (MAGNA3, TPE, CRE, CUE) via CIM 200 / CIM 500 use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Grundfos E-pumps (MAGNA3, TPE, CRE, CUE) via CIM 200 / CIM 500?

Start with HR 100 ControlRegister (Remote/start/stop/reset command word); HR 101 ControlMode (Control mode); HR 103 Setpoint (Setpoint, 0.01 %); HR 200 PumpStatus (Status bits (on, running, alarm, warning, remote)); HR 204 AlarmCode (Alarm code); HR 300 Head (Head); HR 301 VolumeFlow (Flow); HR 303 Speed (Speed); HR 311 Power (Power (32-bit)); HR 11 Watchdog (Comm watchdog timeout).

How do I enable Modbus control of the Grundfos E-pumps (MAGNA3, TPE, CRE, CUE) via CIM 200 / CIM 500?

Bus control requires bit 0 (RemoteAccessReq) of 00101 = 1; then bit 1 starts (1) or stops (0) the pump. OperationMode 00103 only takes effect while the pump is commanded on (OnOffReq = 1).

What happens when the Grundfos E-pumps (MAGNA3, TPE, CRE, CUE) via CIM 200 / CIM 500 loses Modbus communication?

Register 00012 sets a comm-loss timeout of 5-3600 s (0 = disabled, the default). Any valid telegram feeds it; on timeout the pump returns to Local mode.
