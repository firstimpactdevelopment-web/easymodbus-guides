Danfoss VLT Midi Drive FC 280 (Modbus RTU) Modbus register map

Updated 17 November 2026

Short answer

The FC 280 is Danfoss's compact general-purpose (Midi) drive with a built-in RS-485 port that can run Modbus RTU. Control and status words are exchanged as coils (control bits 1-16, status bits 33-48), and every drive parameter is a holding register at ten times its parameter number. This map lists the control/status coils, the communication parameters, the main readouts and the alarm/warning words.

This page lists 89 Modbus registers for the Danfoss VLT Midi Drive FC 280 (Modbus RTU) — 31 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Danfoss’s own free documentation (linked below) and checked against it.

Integration notes: Danfoss VLT Midi Drive FC 280 (Modbus RTU)

Integration in brief

Set 8-30 = Modbus RTU and the port settings, make sure 8-02 is FC port, then write the 16 control bits (coils 1-16) and the reference (coils 17-32) with function 15 and read status coils 33-48. Read readouts from the 16-xx registers at parameter number x 10, minus 1 on the wire.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

8-30 Protocol = [2] Modbus RTU, 8-31 Address 1-247, 8-32 Baud Rate (2400-115200, default 9600), 8-33 Parity/Stop Bits (even parity, 1 stop bit by default). 8-02 Control Source must be [1] FC port and 8-10 should be [0] FC profile and 8-01 Control Site decides whether digital inputs, the control word or both are used.

Communication loss & watchdog

8-03 Control Timeout Time (0.5-6000 s, default 1 s) and 8-04 Control Timeout Function (default Off; Freeze output, Stop, Jogging, Max. speed, Stop and trip) act when the control word stops being updated.

Byte order & addressing

  • Control word bit 10 (coil 11) must be 1 or the drive ignores the control word.
  • Parameter writes go to RAM only unless coil 65 is 1.

Network setup

  • 8-35 Minimum Response Delay can be raised for slow masters or converters.
  • Array parameters need the index written to holding register 9 first.

Watch out for

  • Register numbers in the manual are 1-based; subtract 1 in the request.

Notes on this map

  • 32-bit values are high word first: the design guide's example reads 3-03 at registers 3030/3031 and gets 0x0016 0xE360, and its preset-multiple example writes 1-24 = 738 (7.38 A) as 0x0000 0x02E2.
  • Scale comes from each parameter's conversion index in the programming guide (-1 = x0.1, -2 = x0.01, -3 = x0.001, 0 = x1). Indices 74, 75, 67 and 100 have factors 3600, 3600000, 1/60 and 1 relative to SI units, so 15-00/15-01 arrive in hours, 15-02 in kWh, 16-57 in RPM and 16-34/16-39 in °C (scale 1).
  • Left out: 16-05 Main Actual Value [%] (normalised N2), 16-09 Custom Readout, 16-62/16-64 analog inputs (unit not given), 16-66 Digital Output (text), 16-67/16-68 pulse inputs and 16-69 pulse output (unit not given), 16-20 Motor Angle, text and array parameters.
  • The design guide for this drive lists no 50000/50200 control registers; bus control uses coils 1-16 (control word), 17-32 (16-bit speed reference, 4000h = 100 %, negative in two's complement), 33-48 (status word) and 49-64 (output frequency, or feedback in closed loop).
  • Uint8 parameters are read and written as one 16-bit register.
  • Bit-by-bit coil names follow the FC profile tables; coil 15 has no function and STW coils 37-39 and 45 are unused.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Danfoss VLT Midi Drive FC 280 (Modbus RTU)

What Modbus registers does the Danfoss VLT Midi Drive FC 280 (Modbus RTU) have?

This map lists 89 registers: 28 coils, 61 holding registers. 31 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Danfoss VLT Midi Drive FC 280 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers derived from parameter numbers. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Coils and registers are numbered from 1 and sent minus 1 (coil 65 = address 64, register 40001 = address 0). A parameter's register is 10 x its parameter number (16-13 -> 16130) and the request uses that minus 1; the design guide reads 3-03 (register 3030) at register address 3029.

What byte order does the Danfoss VLT Midi Drive FC 280 (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Danfoss VLT Midi Drive FC 280 (Modbus RTU)?

Start with CO 6 CTW bit 6 (coil 7) (CTW bit 6: start / ramp stop); CO 10 CTW bit 10 (coil 11) (CTW bit 10: data valid); CO 43 STW bit 11 (coil 44) (Running); CO 35 STW bit 3 (coil 36) (Alarm); HR 16129 16-13 Frequency (16-13 Frequency); HR 16139 16-14 Motor current (16-14 Motor current); HR 16899 16-90 Alarm word (16-90 Alarm word).

How do I enable Modbus control of the Danfoss VLT Midi Drive FC 280 (Modbus RTU)?

8-30 Protocol = [2] Modbus RTU, 8-31 Address 1-247, 8-32 Baud Rate (2400-115200, default 9600), 8-33 Parity/Stop Bits (even parity, 1 stop bit by default). 8-02 Control Source must be [1] FC port and 8-10 should be [0] FC profile and 8-01 Control Site decides whether digital inputs, the control word or both are used.

What happens when the Danfoss VLT Midi Drive FC 280 (Modbus RTU) loses Modbus communication?

8-03 Control Timeout Time (0.5-6000 s, default 1 s) and 8-04 Control Timeout Function (default Off; Freeze output, Stop, Jogging, Max. speed, Stop and trip) act when the control word stops being updated.
