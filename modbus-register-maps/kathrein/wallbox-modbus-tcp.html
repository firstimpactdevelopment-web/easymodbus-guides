Short answer

Integration notes: KATHREIN KATHREIN Wallbox (Modbus TCP server)

Integration in brief

Enable the Modbus server in easyOperate, write 0x8000 to 0x00A0 to take EMS control, then write the charging current in mA to 0x00A2 (0 pauses). Read 0x0060 for state, 0x0066 for granted power and 0x0069 for session energy.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The Modbus server is switched on or off in the easyOperate configuration panel; it is disabled by factory default. EMS control itself is enabled by writing 0x8000 to 0x00A0.

Communication loss & watchdog

If 0x00A3 is set above 0, each setpoint write restarts a timer of that many seconds; when it runs out the wallbox charges with the fallback current in 0x00A5 (default 6000 mA) on the lines in 0x00A4. The default 0 disables the timeout.

Byte order & addressing

  • Current setpoints are in milliamps, not amps or tenths of amps.
  • Writing 0xFFFF to 0x00A2 cancels the charge; 0 only pauses it.
  • The unit ID is ignored today, but 0 is recommended for future firmware.

Network setup

  • Connect to the wallbox IP address on TCP port 502.
  • Use unit ID 0.

Watch out for

  • Meter values (0x0030 on) are floats with no stated word order; check against the display before using them.

Notes on this map

  • KATHREIN does not host this register mapping publicly; the linked copy is the unaltered release 1.1 document posted on the Symcon community forum.
  • Word order: the data-type table says integer types are stored big-endian with the most significant register first, so UINT32 and UINT64 values are high word first (ABCD).
  • Left out: the meter block 0x0030-0x005C (voltages, currents, powers, power factors, total energy). These are FLOAT32 values and the document only says they follow IEEE 754; the integer word-order rule is not stated for floats.
  • Left out: tariff registers 0x006B-0x006D and the reserved BINARY blocks, which the document marks as reserved for future use.
  • Only holding registers are answered: read with function 03, write with 06 or 16.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the KATHREIN KATHREIN Wallbox (Modbus TCP server)

What Modbus registers does the KATHREIN KATHREIN Wallbox (Modbus TCP server) have?

This map lists 22 registers: 22 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the KATHREIN KATHREIN Wallbox (Modbus TCP server) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed in hex and go on the wire unchanged. The table starts with register 0x0000 (mapping version), which cannot exist in 1-based numbering, so the printed numbers are protocol addresses: 0x00A2 is requested as 162 decimal.

What byte order does the KATHREIN KATHREIN Wallbox (Modbus TCP server) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the KATHREIN KATHREIN Wallbox (Modbus TCP server)?

Start with HR 160 EMS-Control: Control-Register (Enable EMS control); HR 162 EMS-Control: Setpoint Charging Current (Charging current setpoint (mA)); HR 163 EMS-Control: Timeout Period (Setpoint timeout); HR 165 EMS-Control: Timeout Fallback Current (Fallback current after timeout); HR 96 EVSE: Status (EVSE status); HR 97 EVSE: Error-State (Error flags); HR 102 EVSE: Granted Power (Granted power); HR 105 Charging: Energy (Session energy).

How do I enable Modbus control of the KATHREIN KATHREIN Wallbox (Modbus TCP server)?

The Modbus server is switched on or off in the easyOperate configuration panel; it is disabled by factory default. EMS control itself is enabled by writing 0x8000 to 0x00A0.
