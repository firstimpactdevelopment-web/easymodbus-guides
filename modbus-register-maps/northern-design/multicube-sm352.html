Northern Design multicube modular meter, SM352 sub-metering slave (Modbus RTU) Modbus register map

Updated 17 November 2026

Short answer

The multicube is a modular sub-metering system: one master display unit plus up to ten SM352 modules, each holding two three-phase meters. Every slave meter answers on its own Modbus RTU ID and carries the same register set, which is the one listed here (energy, instantaneous values, THD, setup and tariff totals). The master unit's concentrator tables that summarise all slaves are not covered.

This page lists 81 Modbus registers for the Northern Design multicube modular meter, SM352 sub-metering slave (Modbus RTU) — 17 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Northern Design’s own free documentation (linked below) and checked against it.

Integration notes: Northern Design multicube modular meter, SM352 sub-metering slave (Modbus RTU)

Integration in brief

Address each SM352 half by its own Modbus ID (master ID + 1, + 2, ...). Read the K scale registers 2837-2840 and eScale 513 once, then poll 2816-2836 and 514-519 with function 03; up to 128 registers fit in one read.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the RTU485 communications module. Set the master display unit's Modbus ID in its programming menu; it then gives each slave meter the next IDs in sequence.

Byte order & addressing

  • One multicube can use up to 21 IDs (master + 20 slave meters). Leave a gap that large between master IDs when several systems share a bus.
  • Scale exponents are offset by 3: value = raw x 10^(K-3).

Network setup

  • RS-485 half duplex, two wires plus 0 V; 4800, 9600 or 19200 baud.
  • Replies take up to 250 ms; wait at least 10 ms after a reply before the next request.

Watch out for

  • System and per-phase energy registers are writable; a write changes billing totals.
  • A slave set to three-phase returns zero in single-phase registers, and the other way round.

Notes on this map

  • Northern Design does not host this manual publicly; the link is an unaltered copy on a distributor's file host.
  • 32-bit values are LONG = 65536 x high word + low word, with the high word at the lower address (ABCD).
  • Energy values are the LCD digits with no decimal point. Scale them with eScale (513): factor = 10^(eScale-6) kWh, e.g. eScale 5 gives x0.1. Instantaneous values use value = raw x 10^(K-3) with K from 2837-2840. Both are listed here with scale 1 and no unit, so the map shows raw counts.
  • The manual titles tariff table 17 'single phase' but its rows are system totals and its note says three-phase totals; table 16 (per-phase tariff energy, 4096-4191) is left out.
  • Left out: current demand periods 1-3 and power demand periods 1-3 (3594-3596, 3598-3600) because no unit is printed, the load-name ASCII registers (7170-7190), the amalgamated tables 30/31 (copies) and all master display unit tables (concentrator copies, logging and tariff structures).
  • The serial number at 7168 is printed as a high word / low word pair; it is listed as UINT32 high word first like the other LONG values.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Northern Design multicube modular meter, SM352 sub-metering slave (Modbus RTU)

What Modbus registers does the Northern Design multicube modular meter, SM352 sub-metering slave (Modbus RTU) have?

This map lists 81 registers: 81 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Northern Design multicube modular meter, SM352 sub-metering slave (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print a 0-based data address beside the Modicon register (512 = 40513). The data address goes on the wire. Each table starts at a multiple of 256, so the table number is the high byte of the address (table 11 = 2816).

What byte order does the Northern Design multicube modular meter, SM352 sub-metering slave (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Northern Design multicube modular meter, SM352 sub-metering slave (Modbus RTU)?

Start with HR 2840 Power scale Kp (Power scale Kp); HR 2837 Amps scale Ki (Amps scale Ki); HR 2816 System kW (System kW (raw)); HR 2822 Phase 1 amps (Phase 1 amps (raw)); HR 2821 Phase 1 volts (Phase 1 volts (raw)); HR 2819 System PF (System power factor); HR 513 eScale (Energy exponent eScale); HR 514 System kWh (System kWh).

How do I enable Modbus control of the Northern Design multicube modular meter, SM352 sub-metering slave (Modbus RTU)?

Fit the RTU485 communications module. Set the master display unit's Modbus ID in its programming menu; it then gives each slave meter the next IDs in sequence.
