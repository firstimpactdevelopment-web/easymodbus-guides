Integration notes: Autonics TK series PID temperature controller (Modbus RTU)

Integration in brief

Read 301001-301008 with FC04 for PV, decimal point, SV and MV; write the setpoint to 400001 and use coil 0 for run/stop. Check 301002 to place the decimal point.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Communication write (400224) must be Enabled (default) for Modbus writes.

Byte order & addressing

  • PV reports 31000 for sensor open, 30000 / -30000 for over/under range.
  • The bracketed hex is the wire address.

Network setup

  • Address 1..99 (default 1), 2400-38400 bps (default 9600), parity none, 2 stop bits.

Watch out for

  • Display values carry no fixed scale; Temp.L input types report one decimal place, so always apply the decimal point from 301002.

Notes on this map

  • Autonics does not publish a static public link to this manual; this is the unaltered Autonics document hosted by distributor AutomationDirect.
  • PV, SV, alarm limits and multi-SV values are signed display counts whose decimal point depends on the input type; read 301002 (decimal point) and scale accordingly. They are listed with scale 1.
  • Default communication settings (address 1, 9600 bps, no parity, 2 stop bits, writes enabled) are the defaults printed in the communication parameter rows.
  • Left out: hysteresis, dead band, OFF offset, input correction, scaling and alarm-mode registers whose scale depends on the input range, plus the input-type code table.
  • Registers 400301-400330 are the user-parameter group (copies of chosen parameters).
  • Left out: heater current monitoring input register 301008, because the manual prints only the display range 0.0..50.0 and not the raw value scaling.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Autonics TK series PID temperature controller (Modbus RTU)

What Modbus registers does the Autonics TK series PID temperature controller (Modbus RTU) have?

This map lists 62 registers: 2 coils, 14 discrete inputs, 12 input registers, 34 holding registers. 36 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Autonics TK series PID temperature controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Rows print a 6-digit reference (000001/100001/300001/400001 style) and the hex protocol address in brackets, e.g. 301001 (03E8); the bracketed hex value is the wire address.

What are the minimum Modbus registers to integrate the Autonics TK series PID temperature controller (Modbus RTU)?

Start with IR 1000 PV (present value) (Process value); IR 1001 Decimal point location (Decimal point); IR 1003 SV setting value (Active setpoint); IR 1004 Heating side MV (Heating output %); HR 0 SV set value (Write setpoint); CO 0 RUN/STOP (Run/stop).

How do I enable Modbus control of the Autonics TK series PID temperature controller (Modbus RTU)?

Communication write (400224) must be Enabled (default) for Modbus writes.

Where is the official Autonics TK series PID temperature controller (Modbus RTU) Modbus documentation?

The source is TK Series Communication Manual (Simultaneous Heating & Cooling Output PID Temperature Controllers) (MCT-TKC1-V2.2-EN). Autonics doesn't publish it on its own website, so this map was re-typed from a free copy at https://cdn.automationdirect.com/static/manuals/autonics/autonicstkcommunicationsmanual.pdf. It may be an older revision, so check it against the live unit.
