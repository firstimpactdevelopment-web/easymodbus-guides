Short answer

The SINEAX CAM is a Swiss universal measurement device for heavy-current networks with plug-in I/O modules. With the Modbus/TCP bus card it publishes its measurements as holding registers (mostly IEEE 754 floats), relay and digital output states as coils and digital inputs as discrete inputs. This map covers firmware info, the full instantaneous value block, THD/TDD, symmetrical components, analog inputs and the I/O states.

This page lists 108 Modbus registers for the Camille Bauer Metrawatt SINEAX CAM universal measurement device (Modbus/TCP) — 16 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Camille Bauer Metrawatt’s own free documentation (linked below) and checked against it.

Integration notes: Camille Bauer Metrawatt SINEAX CAM universal measurement device (Modbus/TCP)

Integration in brief

Connect to TCP port 502 and read 40100-40187 in one FC3 request: 44 floats with voltage, current, power, frequency and power factor, low word first. THD/TDD sit in 40190-40196 as tenths of a percent.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Assign IP address, mask and gateway with the CB-Manager software (factory IP 192.168.1.101). The Modbus/TCP port can be changed there, but 502 is always supported.

Byte order & addressing

  • Floats are low word first (CDAB).
  • Use FC 0x10 / 0x0F for writes; single-write function codes are not implemented.
  • The manual's TCP examples use unit ID 0xFF since the IP address selects the device.

Network setup

  • At least 5 simultaneous Modbus/TCP clients are supported.
  • Up to two NTP servers can be set in CB-Manager for clock synchronisation (port 123).

Watch out for

  • Several blocks only exist from a given analysis firmware version (1.32, 1.37, 1.39); read FV_OUTPUT at 40007 first.
  • Register 40016 (CFG_DIGIO) is writable and changes module I/O direction; do not write it by accident.

Notes on this map

  • Host: this copy is hosted on api-usa.com, not on a Camille Bauer site; no public copy was found on camillebauer.com.
  • Float word order: the manual says the first register holds bits 0-15 and the second bits 16-31, and its U1N example reads 0xE878 then 0x436B (= 234.908 V). That is low word first, CDAB.
  • Power units: the manual does not print units for P, Q, S (only V and A are given, in the system-analysis table and the U1N example), so units are left blank here; check against the device display.
  • Left out: every UINT32 / TIME value (energy meters 41400-41482, logic-function words 43917-43923, timestamps 40096-40098 and min/max times), because the document gives no word order for 32-bit integers. Energy meters also need a scaling exponent whose register is not listed for the standard meters.
  • Left out: min/max floats 40584-40666, harmonics 40200-40493 (UINT16 x 0.1 %, same scale as THD), mean values 41030-41322 (meaning depends on configuration) and parameter blocks.
  • Availability depends on the connection type (single phase, split phase, 3-wire, 4-wire); registers that do not apply read 0.
  • Function codes 0x05 and 0x06 (single coil/register write) and 0x04 (input registers) are not implemented; use 0x0F and 0x10.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Camille Bauer Metrawatt SINEAX CAM universal measurement device (Modbus/TCP)

What Modbus registers does the Camille Bauer Metrawatt SINEAX CAM universal measurement device (Modbus/TCP) have?

This map lists 108 registers: 16 coils, 12 discrete inputs, 80 holding registers. 16 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Camille Bauer Metrawatt SINEAX CAM universal measurement device (Modbus/TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed 4xxxx and coils/inputs 0xxxx/1xxxx. The manual's own example: U1N at 40102 is sent as address 101 (0x65). Coil 1 is address 0, discrete input 10003 is address 2.

What byte order does the Camille Bauer Metrawatt SINEAX CAM universal measurement device (Modbus/TCP) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Camille Bauer Metrawatt SINEAX CAM universal measurement device (Modbus/TCP)?

Start with HR 101 U1N (Voltage L1-N); HR 117 I1 (Current L1); HR 133 P (Active power system); HR 157 F (Frequency); HR 159 PF (Power factor system); HR 190 THD_U1X (Voltage THD phase 1).

How do I enable Modbus control of the Camille Bauer Metrawatt SINEAX CAM universal measurement device (Modbus/TCP)?

Assign IP address, mask and gateway with the CB-Manager software (factory IP 192.168.1.101). The Modbus/TCP port can be changed there, but 502 is always supported.
