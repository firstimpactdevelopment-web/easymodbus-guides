Integration notes: Airzone Aidoo Pro Modbus control for air-to-water heat pumps

Integration in brief

Set the Aidoo output to Modbus and the slave ID in the Airzone Cloud app, connect RS-485 at 19200 8E1, then use registers 0, 3, 9, 11 and 12 for on/off, mode, DHW and setpoints, and poll 46-48 and 7-8 for water temperatures and errors.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the Airzone Cloud app: Airtools > advanced configuration via Bluetooth > Integration > output Modbus, set the Modbus ID.

Byte order & addressing

  • Mode codes start at 1 (1 Auto, 2 Cool, 3 Heat, 4 Fan, 5 Dry).
  • Energy counters are low word first (CDAB).

Network setup

  • Factory serial settings 19200 baud, 8 data bits, even parity, 1 stop bit.
  • Slave address default 1.

Watch out for

  • Register 13 bit 0 tells whether a DHW tank is configured.

Notes on this map

  • Distributor copy: airzonecontrol.com answers automated requests with a bot check (not bypassed) and no other Airzone-hosted copy was found; this multilingual PDF carries Airzone's own layout and address.
  • 32-bit energy counters are low word first: the manual's example (1) 0x1215, (2) 0x0001 = 0x00011215 = 70165 kWh, so CDAB.
  • ACS in the manual means domestic hot water (DHW). C1 / C2 are water circuits 1 and 2.
  • The manual does not state signed or unsigned for 16-bit values; the remaining registers are listed as UINT16 because their normal values are not negative.
  • External (outdoor) temperature (35) and outdoor heat exchanger temperature (39) are left out: these routinely go below 0 °C and the manual gives no sign convention for 16-bit values.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Airzone Aidoo Pro Modbus control for air-to-water heat pumps

What Modbus registers does the Airzone Aidoo Pro Modbus control for air-to-water heat pumps have?

This map lists 80 registers: 80 holding registers. 13 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Airzone Aidoo Pro Modbus control for air-to-water heat pumps Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are numbered from 0 (unit on/off is register 0) and the command description puts this number in the 'register address' field, so the printed number is the wire address.

What byte order does the Airzone Aidoo Pro Modbus control for air-to-water heat pumps use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Airzone Aidoo Pro Modbus control for air-to-water heat pumps?

Start with HR 0 Unit status on/off (On/off); HR 3 Mode (Mode); HR 11 Water setpoint circuit 1 (Water setpoint circuit 1 (x10)); HR 9 DHW (ACS) unit on/off (DHW on/off); HR 12 DHW (ACS) setpoint (DHW setpoint (x10)); HR 46 Water out temperature (Water out temperature (x10)); HR 48 DHW tank temperature (DHW tank temperature (x10)); HR 7 Unit error code part 1 (Error code (ASCII)).

How do I enable Modbus control of the Airzone Aidoo Pro Modbus control for air-to-water heat pumps?

In the Airzone Cloud app: Airtools > advanced configuration via Bluetooth > Integration > output Modbus, set the Modbus ID.
