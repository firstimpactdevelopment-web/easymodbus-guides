Short answer

LS Electric's general-purpose variable frequency drive with a built-in RS-485 port that speaks Modbus RTU or the LS INV 485 protocol. Monitoring sits in the S100 common area at 0h0300-0h037F, run/stop and frequency commands at 0h0380-0h03DF, and every keypad parameter has its own address per group (dr = 0h1100, CM = 0h1700, Pr = 0h1B00). This map covers the S100 common area, the trip/warning bit words, and the parameters needed to put the drive under Modbus control.

Integration notes: LS Electric LSLV-S100 AC drive (built-in RS-485 Modbus RTU)

Integration in brief

Set CM.01-CM.04 to match the master, set dr.06 = 3 (Int 485) and dr.07 = 6 (Int 485), then write 0h0380 (frequency, 0.01 Hz) and 0h0382 (0003h forward, 0001h reverse, 0000h stop). Poll 0h0305, 0h0310, 0h0311, 0h0315 and the trip words 0h0330-0h0334. Remember every printed address is sent minus 1.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

CM.01 station ID (1-250, default 1), CM.02 = 0 Modbus-RTU (default), CM.03 baud (default 3 = 9600), CM.04 frame (default 0 = 8N1), CM.05 response delay (default 5 ms). For control set dr.06 Cmd Source = 3 (Int 485) and dr.07 Freq Ref Src = 6 (Int 485); on the 7-segment keypad these are the drv and Frq codes. Virtual inputs: assign functions in CM.70-CM.77 and set bits in 0h0385.

Communication loss & watchdog

Pr.12 Lost Cmd Mode (0 none by default, 1 free-run, 2 decelerate with Pr.07, 3 hold average input, 4 hold average output, 5 run at Pr.14) acts when communication has been lost for longer than Pr.13 Lost Cmd Time (0.1-120 s, default 1.0 s). Relay 1 can signal it with OU.31 = 13 (Lost Command); 0h0332 bit 2 and 0h0334 bit 3 flag it.

Byte order & addressing

  • Wire address = printed address - 1 (manual example: 0x1103 is sent as 0x1102). 0h0300 is read at 0x02FF.
  • Supported functions: 03, 04, 06 and 16 (0x10). Exception 06 means slave busy.
  • 0h0382 bits 2 and 3 act on a 0 -> 1 edge: write the bit back to 0 before the next reset or free-run stop.
  • Values changed over communication are lost at power-off unless saved: write 0h03E0 = 0 then 1 (a 1 -> 0 change does nothing). Setting CNF.48 = 1 on the LCD keypad also saves them.
  • An older iG5A-compatible block also exists at 0h0000-0h001B; this map does not use it because the manual's minus-1 rule cannot reach its first address 0h0000.

Network setup

  • Wire RS-485 to control terminals S+, S- and SG; connect SG to the master's signal ground.
  • Turn the RS-485 terminating resistor on with switch SW4 on the control board (factory setting Off) at the drive at each end of the line.
  • Up to 16 drives per line, 1,200 m maximum (700 m recommended), shielded twisted pair 0.75 mm2.
  • Baud 1200-115200 bps; frames 8N1, 8N2, 8E1 or 8O1.

Watch out for

  • Factory dr.06 = 1 (Fx/Rx-1 terminals) and dr.07 = 0 (Keypad-1): network run and frequency commands do nothing until both are changed.
  • When registering control items in CM.51 onward (read/written at 0h0110+), put the frequency and run command entries last in the frame.
  • 0h0386 digital output control only moves outputs whose OU.31/OU.33 function is None.
  • If every value looks shifted by one register, the master is already applying the -1 itself; read 0h0300 (inverter model) and expect 0006h.

Notes on this map

  • Direct PDF from LS Electric's Solution Square CDN: https://sftpssqblobcdn.blob.core.windows.net/prod/largefile/document/17912520084750/S100_Manual_English_V4.3.pdf (V4.3, listed on the document page with update date 2026-10-06).
  • Left out because the sign is not stated and the values can go negative: 0h0317 output torque, 0h0318/0h0319 and 0h0388/0h0389 PID reference/feedback, 0h0390-0h0395 torque reference/limits/bias, 0h0324-0h032B analog inputs and outputs (V1 can be bipolar), and 0h032D module temperature.
  • Left out: 0h032E/0h032F energy (0.1 kWh and MWh registers; how they combine is not described) and the parameter-group registers other than those needed for setup.
  • 0h0305 and 0h0306 hold packed 4-bit and 8-bit fields rather than single flags; the 'bits' entries name the lowest bit of each field.
  • Pr.13 Lost Cmd Time (0h1B0D, 0.1-120 s) is not included because its register scaling is not printed; set it on the keypad.
  • The frequency command registers (0h0005, 0h0380) are never stored, even with parameter save; to keep a frequency through a power cycle set dr.07 = 1 (Keypad-1), write dr.01 at 0h1101 and save with 0h03E0.
  • The iS5/iP5A/iV5/iG5A-compatible area (0h0000-0h001B: command frequency 0h0005, operation command 0h0006, status 0h000E and so on) is left out: the manual starts that area at 0h0000, which cannot exist under the minus-1 rule shown in its only example frame, so the offset for that legacy area is not settled by the manual. Use the S100 area at 0h0300+ instead.
  • The manual prints a scale of '0' for 0h0312 output rpm, 0h0313 feedback speed and the 0h0340-0h0345 time counters; this map reads that as zero decimal places (whole rpm, days, minutes).
  • CM.04 option 1 (D8/PN/S2, two stop bits) appears in the chapter 7 parameter description but not in the CM group function table.

Questions about the LS Electric LSLV-S100 AC drive (built-in RS-485 Modbus RTU)

What Modbus registers does the LS Electric LSLV-S100 AC drive (built-in RS-485 Modbus RTU) have?

This map lists 48 registers: 48 holding registers. 21 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the LS Electric LSLV-S100 AC drive (built-in RS-485 Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints communication addresses in hex (0h0300, 0h1103). Its only Modbus-RTU worked example writes Acc time (0x1103) and Dec time (0x1104) with starting address 0x1102, labelled 'Starting Address -1 (0x1103-1)', and the CRCs printed for that request (0x1202) and response (0xE534) are the correct CRCs for 0x1102, so the wire address is the printed address minus 1: 0h0380 frequency command is sent as 0x037F. The protocol text only says the starting address is the communication address; this map follows the worked frame. The manual states no different rule per area.

What are the minimum Modbus registers to integrate the LS Electric LSLV-S100 AC drive (built-in RS-485 Modbus RTU)?

Start with HR 897 Operation command (0h0382 operation command (run/stop/direction/reset)); HR 895 Frequency command (0h0380 frequency command, 0.01 Hz); HR 772 Inverter operation state (0h0305 operation state (ready/warning/fault, accel/decel, direction)); HR 784 Output frequency (0h0311 output frequency); HR 783 Output current (0h0310 output current); HR 788 DC link voltage (0h0315 DC link voltage); HR 815 Latch type trip information 1 (0h0330 latch trip flags); HR 819 Warning information (0h0334 warning flags).
