Short answer

The SMVector is a Lenze AC Tech inverter (models up to 10 HP in this guide). The ESVZAR0 option module adds Modbus RTU on RS-485. Registers 1-99 are network control and status (control word, status word, frequencies, load, fault, run-hour counters, network speed/PID/torque commands); every drive parameter Pxxx is also readable as register xxx.

Integration notes: Lenze SMVector drive with ESVZAR0 RS-485 Modbus module

Integration in brief

Set P400 = 2, address/baud/format in P410-P412, then read #23-#29 for status, frequencies, load and fault. To run from the network: assert a terminal set to NET ENABLE, write 0 to #48 to unlock #1 (or the P194 password to also unlock #44), then write control bits to #1 and the speed to #44.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

P400 = 2 (Modbus RTU); P410 address, P411 baud, P412 format. For control set one of P121-P123 to 09 (NET ENABLE) and close that TB-13 input, and P100 to 00, 01, 03 or 04. Use P101 = 06 or bits 12-15 of #1 to make the network the speed reference.

Communication loss & watchdog

Once controls are unlocked via #48, P425 (0-300 s, default 10.0 s) sets the message time-out and P426 the action (default trip fault). Any read keeps it alive.

Byte order & addressing

  • Function codes 03 and 04 are identical; FC16 only writes one register.
  • Only one action bit per write to #1, except stop/quick stop/inhibit; otherwise exception 04.
  • Writing #1 with bit 1 (lock security) ends network control and stops the drive if P100 = 3.
  • Broadcast is not supported.

Network setup

  • RS-485 on the ESVZAR0 terminal block; terminate the end of the network.
  • Default 9600 baud, 8 data bits, no parity, 2 stop bits, address 1.

Watch out for

  • If P494 does not show 1.01, 1.10 or 1.30, Lenze warns not to write any register with this map.
  • Writes are ignored unless the NET ENABLE terminal is configured and closed.

Notes on this map

  • Host: copy hosted by Precision Electric (a Lenze AC Tech distributor); a search did not find this guide as a direct download on lenze.com.
  • Scaling: values are sent in internal units, value x 10^DP; e.g. 34.3 Hz is sent as 343. Frequencies, torque, PID and analog output are one-decimal values (scale 0.1). PID values (37-39, 41, 45) are signed.
  • Word order: registers #60/#61 and #64/#65 are low word first; the guide's example shows run-time hours 0x12345678 read as 5678h then 1234h (CDAB).
  • Left out: motor voltage #30 and total kWh #32/#33 (scaling defers to the drive manual), and the 32-bit registers #511/#540/#541 (high word first per the guide, but its #540 example frame uses the address of #511). Parameters #100-399 and #500-599 follow the SMV operating instructions (SV01) and are not listed.
  • Present fault codes (high byte of #29): 0 no fault, 1 TMP output, 2 output transistor, 3 ground, 4 high drive temperature, 5 flying start, 6 high DC bus, 7 low DC bus, 8 thermal overload, 9 OEM, 10 illegal setup, 11 dynamic brake over-temperature, 12 single phase, 13 external, 14 control, 15 start error, 16 incompatibility, 17 internal 1 (EPM), 18 internal 2, 19 internal 3, 20/21 internal 5, 22 internal 6, 23 internal 7, 24 internal 8, 25 internal 9, 26 personality, 27 AD offset, 28 remote keypad lost, 29 assertion level, 30 internal 4, 31 internal 0, 32 follower lost, 33 ISO comm, 34 SPI time-out, 35 invalid message received, 36 network time-out.
  • Run status codes (low byte of #26): 0 fault lockout, 1 fault, 2 start pending, 3 IDE not done, 4 inhibit, 5 stop, 6 lower transistors on, 7 run IDE, 8 run, 9 accel, 10 decel, 11 decel override, 12 DC brake, 13 flying restart, 14 slow current limit, 15 fast current limit, 16 sleep.
  • Usually only one register per read; exceptions are #24 (6 registers #24-29) and the 2-register counters. FC16 writes only one register.
  • Left out: network PID setpoint command #45. Table 5 marks it read-only, but section 8.3 says to write it; the access is unclear.

Questions about the Lenze SMVector drive with ESVZAR0 RS-485 Modbus module

What Modbus registers does the Lenze SMVector drive with ESVZAR0 RS-485 Modbus module have?

This map lists 33 registers: 33 holding registers. 15 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lenze SMVector drive with ESVZAR0 RS-485 Modbus module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers derived from parameter numbers. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Lenze numbers registers by drive register #, and Modbus 4X/3X register = drive register + 1. The drive register # is the wire address: the guide's example reads #60 with start address 0x003C. Drive parameter Pxxx is register #xxx (P103 = #103).

What byte order does the Lenze SMVector drive with ESVZAR0 RS-485 Modbus module use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lenze SMVector drive with ESVZAR0 RS-485 Modbus module?

Start with HR 1 Drive control (Control word: start/stop/direction); HR 48 Unlock controls (Unlock controls); HR 44 Network speed command (Network speed command); HR 23 Drive status (Status word); HR 25 Actual frequency (Actual frequency); HR 29 Present fault (high byte) / commanded direction (low byte) (Present fault).

How do I enable Modbus control of the Lenze SMVector drive with ESVZAR0 RS-485 Modbus module?

What happens when the Lenze SMVector drive with ESVZAR0 RS-485 Modbus module loses Modbus communication?
