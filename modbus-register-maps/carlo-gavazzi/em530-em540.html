Updated 28 October 2026

Short answer

The EM530 and EM540 are Carlo Gavazzi's three-phase DIN-rail energy meters (EM530 CT-connected, EM540 direct-connected). The S1 versions talk Modbus RTU on RS485; live values and energy totals are 32-bit integers sent low word first with fixed weights, and functions 03 and 04 return the same data. This map covers volts, amps, powers, PF, frequency, THD, demand, total/partial/phase/tariff energy, run hours, identity, setup, serial settings and resets.

Integration notes: Carlo Gavazzi EM530 / EM540 three-phase energy meters (RS485 Modbus)

Integration in brief

Read input registers 0000h-0033h (function 04 or 03) for live values and 0034h-005Dh for energy, in blocks of up to 20 registers. Decode INT32 low word first and apply the fixed weights: V, W, VA, var and kWh x0.1, A and PF x0.001, Hz x0.1.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Only the S1 versions have the RS485 Modbus port. Set address, baud, parity and stop bits from the front menu or registers 2000h-2003h.

Byte order & addressing

  • INT32 values are low word first (CDAB).
  • PF at 002Eh-0031h is signed by power direction; the lead/lag sign is in the separate PF rows at 0072h-0075h.
  • Exported energy (kWh(-)) counting depends on measurement mode (1103h); on MID models the mode is fixed by the part number (PFA/PFB/PFC).

Network setup

  • Defaults: address 1, 9600 baud, no parity, 1 stop bit.
  • Baud 9600-115200; parity none or even.
  • Terminate both bus ends with 120 ohm; on the meter, bridge B+ to T on the last unit. Use a repeater beyond 1000 m or more than 160 instruments on one bus.

Watch out for

  • Reset registers always read 0; writing 1 runs the command.
  • Total-counter reset (4003h) and CT changes are blocked on MID versions.
  • Reading an unlisted address returns an illegal-data-address exception, so do not read across gaps.

Notes on this map

  • Word order: section 3.1 says bytes are MSB first inside each word and INT32/UINT32/UINT64 values are sent LSW first, so every 32-bit value here is CDAB.
  • Functions 03 and 04 return the same data; configuration rows are listed as holding registers because they are written with 06/10.
  • Left out: the INT64 Wh/varh energy block at 0500h-0533h, because the data-format section states word order for INT32, UINT32 and UINT64 but not INT64. The INT32 kWh x0.1 registers carry the same totals.
  • Left out: the energy offset registers (4100h-4214h), factory reset (4020h), alarm and pulse-output settings, display/screen-saver pages and the configurable name, to keep the map to what an integrator needs.
  • Left out: table 4.2 (00F6h onward), which repeats the same values grouped by phase.
  • The identification code is printed at 000Bh (300012), which is also the high word of V L3-L1 (000Ah-000Bh). The document lists both and says the ID table is read one word at a time; read 000Bh on its own to get the model code.
  • Rows printed as 'n.a.' or 'not available, value = 0' are skipped.
  • The revision history inside the PDF ends at Rev. 1.3 dated 3 June 2021 while the cover says 13 February 2024; the cover date is used.
  • The frame tables show 1-20 registers per read while the text says up to 125; keep read blocks to 20 registers to be safe.
  • Table 4.12 prints Modicon 304357 for both 1104h and 1105h; the physical address 1105h is used for the wrong-connection status (304357 is the Modicon number of 1104h).

Questions about the Carlo Gavazzi EM530 / EM540 three-phase energy meters (RS485 Modbus)

What Modbus registers does the Carlo Gavazzi EM530 / EM540 three-phase energy meters (RS485 Modbus) have?

This map lists 109 registers: 92 input registers, 17 holding registers. 16 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Carlo Gavazzi EM530 / EM540 three-phase energy meters (RS485 Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row shows a 6-digit Modicon number for function 04 (3xxxxx; swap the leading 3 for 4 with function 03) and the hex physical address that goes in the frame. Wire address = physical address: 300001 / 0000h is address 0.

What byte order does the Carlo Gavazzi EM530 / EM540 three-phase energy meters (RS485 Modbus) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Carlo Gavazzi EM530 / EM540 three-phase energy meters (RS485 Modbus)?

Start with IR 0 V L1-N (V L1-N); IR 12 A L1 (A L1); IR 40 W sys (W sys); IR 49 PF sys (PF sys); IR 51 Hz (Frequency); IR 52 kWh (+) TOT (kWh(+) total); IR 78 kWh (-) TOT (kWh(-) total); IR 11 Carlo Gavazzi identification code (Model check).

How do I enable Modbus control of the Carlo Gavazzi EM530 / EM540 three-phase energy meters (RS485 Modbus)?

Only the S1 versions have the RS485 Modbus port. Set address, baud, parity and stop bits from the front menu or registers 2000h-2003h.
