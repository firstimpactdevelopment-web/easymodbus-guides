Short answer

The R-4RTD-8DIDO is a Seneca R-series remote I/O with four RTD temperature inputs and eight digital channels that can be inputs or outputs, plus eight 32-bit counters. It serves Modbus TCP on a two-port Ethernet switch and Modbus RTU on RS-485. This map covers temperatures, resistances, engineering values, status flags, digital I/O and counters.

This page lists 50 Modbus registers for the Seneca R-4RTD-8DIDO Ethernet I/O (4 RTD inputs, 8 digital I/O) — 18 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Seneca’s own free documentation (linked below) and checked against it.

Integration notes: Seneca R-4RTD-8DIDO Ethernet I/O (4 RTD inputs, 8 digital I/O)

Integration in brief

Read holding registers 29-55 in one block: status flags, digital I/O, then temperature, resistance and engineering floats. Counters live high at 1843-1858.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

  • Check the burnout bits before trusting a temperature.

Notes on this map

  • The protocol page lists function codes 01, 03, 05, 06, 15 and 16; the tables also give the digital inputs as 1x input status read with function 02. Modbus RTU runs on RS-485 and Modbus TCP serves up to 8 clients.
  • 32-bit values are printed MSW at the lower address (ABCD).
  • Factory settings from the manual: static IP 192.168.90.101/24, gateway 192.168.90.1, Modbus TCP port 502, station address 1; RS-485 38400 baud, 8 data bits, no parity, 1 stop bit, address 1.
  • RW* registers are stored in flash and survive about 10,000 writes.
  • Temperature floats are in the unit chosen per channel in the web server (°C, K, °F or Ohm).
  • Left out: the signed 16-bit temperature copies at 40057-40060, because the table gives no scale for them.
  • The table prints the reserved range as 40014..40029 / offset 13..39; the offset end looks like a typo and is not used here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Seneca R-4RTD-8DIDO Ethernet I/O (4 RTD inputs, 8 digital I/O)

What Modbus registers does the Seneca R-4RTD-8DIDO Ethernet I/O (4 RTD inputs, 8 digital I/O) have?

This map lists 50 registers: 8 coils, 8 discrete inputs, 34 holding registers. 18 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seneca R-4RTD-8DIDO Ethernet I/O (4 RTD inputs, 8 digital I/O) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Holding-register tables print the 4x number (40001) and the 0-based offset (0); coils print 1 / offset 0 and discrete inputs 10001 / offset 0. The offset is the wire address.

What byte order does the Seneca R-4RTD-8DIDO Ethernet I/O (4 RTD inputs, 8 digital I/O) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Seneca R-4RTD-8DIDO Ethernet I/O (4 RTD inputs, 8 digital I/O)?

Start with HR 29 Status (Over-range / burnout flags); HR 32 RTD1 temperature (RTD1 temperature); HR 34 RTD2 temperature (RTD2 temperature); HR 36 RTD3 temperature (RTD3 temperature); HR 38 RTD4 temperature (RTD4 temperature); HR 31 Digital inputs (Digital inputs).

How do I enable Modbus control of the Seneca R-4RTD-8DIDO Ethernet I/O (4 RTD inputs, 8 digital I/O)?

Modbus TCP server and RTU slave are on by default; configure through the web server or Seneca Discovery Device.

What happens when the Seneca R-4RTD-8DIDO Ethernet I/O (4 RTD inputs, 8 digital I/O) loses Modbus communication?

Per the web-server chapter, digital outputs have an optional watchdog (default disabled, timeout default 100 s) on Modbus traffic or on output writes.
