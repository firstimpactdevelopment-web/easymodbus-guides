Short answer

The InRow ACRD60x and ACRC60x are in-row cooling units for data-centre rows and contained aisles. Their controller answers Modbus RTU and Modbus TCP with everything in holding registers. This map covers the cooling-group values (output, demand, setpoints, airflow), the unit's operating mode, supply/return/rack-inlet temperatures, humidity, fan speed, chilled-water and refrigerant readings, compressor VFD data, run hours, service settings, thresholds and 80-plus alarm flags.

Integration notes: APC (Schneider Electric) InRow ACRD60x / ACRC60x cooling units (Modbus register map 990-5786)

Integration in brief

Read the unit operating mode (1206, ENUM) and the supply/return air temperatures (1225, 1227), rack inlet temperatures (1238-1243) and fan speed (1235), which are UINT32 values in tenths, high word first. Write the group cool setpoint at 1023 (tenths of deg C, two registers with function 16).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Not described in the register map.

Byte order & addressing

  • The decimal 'Absolute Starting Register Number' is the wire address; the Modicon column is that number plus 40001.
  • Every UINT32/INT32 takes two registers, most-significant word first; write them with function code 16.
  • Temperatures such as supply and rack-inlet are listed as UINT32 even though they are in tenths of deg C.

Network setup

  • Both Modbus RTU (serial) and Modbus TCP are supported per the map; the serial settings and unit ID are not listed in this document.

Watch out for

  • A single large read can take 2 s or more; if requests time out, read fewer registers at a time or raise the timeout.
  • Reading before the controller has data ready returns an invalid-address error.

Notes on this map

  • The map gives every block twice: a US-units copy (deg F, CFM, ft; Group Data at 0-72, Unit Data at 128-352) and a metric copy 1000 registers higher (deg C, L/s, m). Only the metric copy, the alarm block (512-598) and the Modbus counters are listed here; for US units subtract 1000 from the address.
  • Per the map: 32-bit values (UINT32, INT32) are big-endian, most-significant word first; signed values and ENUMs are two's complement 16-bit; strings carry two characters per register, high byte first.
  • '(Tenths)' values are scaled 0.1 and '(Hundredths)' values 0.01.
  • Reads use function code 3 or 4; writes use function code 16, or 6 for single-register points.
  • Reading a single reserved/undefined register returns an exception; a block read that starts on a valid register returns zeros for undefined ones. Reserved rows and the raw VFD alarm/warning status streams (1278, 1280) are left out.
  • The map prints no date; 2017-03 is the PDF's own creation date (2017-03-08).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the APC (Schneider Electric) InRow ACRD60x / ACRC60x cooling units (Modbus register map 990-5786)

What Modbus registers does the APC (Schneider Electric) InRow ACRD60x / ACRC60x cooling units (Modbus register map 990-5786) have?

This map lists 216 registers: 216 holding registers. 53 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the APC (Schneider Electric) InRow ACRD60x / ACRC60x cooling units (Modbus register map 990-5786) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map prints three columns: the Modicon number (40001 style), the absolute register in hex and the absolute register in decimal. The notes state that absolute register 0 is Modicon 40001 and is address zero on the wire, so the decimal column is the wire address (e.g. 41226 = wire 1225).

What byte order does the APC (Schneider Electric) InRow ACRD60x / ACRC60x cooling units (Modbus register map 990-5786) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the APC (Schneider Electric) InRow ACRD60x / ACRC60x cooling units (Modbus register map 990-5786)?

Start with HR 1206 Operating Mode (Operating mode); HR 1225 Supply Air Temperature (Supply air temperature); HR 1227 Return Air Temperature (Return air temperature); HR 1238 Rack Inlet Temperature 1 (Rack inlet temperature 1); HR 1235 Fan Speed (Fan speed); HR 1023 Group: Cool Setpoint (Group cool setpoint); HR 1000 Group: Overall Status (Overall status); HR 512 Internal Communication Error (First alarm flag (alarm block starts here)).
