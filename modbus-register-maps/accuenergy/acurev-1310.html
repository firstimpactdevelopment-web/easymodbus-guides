Accuenergy AcuRev 1310 series DIN-rail power meter Modbus register map

Updated 17 November 2026

Short answer

The AcuRev 1310 series are Accuenergy's DIN-rail power and energy meters with an RS-485 port that speaks Modbus RTU (or BACnet MS/TP). This map covers the float real-time block (currents, voltages, frequency, power, power factor, phase angles), the demand and neutral/residual block, per-phase and per-tariff energy counters, the meter status words and the dual-source energy feature. The SunSpec mirror blocks, peak-demand timestamps, monthly history and max/min logs in the same workbook are not repeated.

This page lists 150 Modbus registers for the Accuenergy AcuRev 1310 series DIN-rail power meter — 96 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Accuenergy’s own free documentation (linked below) and checked against it.

Integration notes: Accuenergy AcuRev 1310 series DIN-rail power meter

Integration in brief

Read the float block 2000H-2045H (8192-8261) for live values and the Int32 energy block 2046H-2085H for kWh-type counters; everything is big-endian, high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the Modbus address and serial (or network) parameters on the meter; the workbook does not list the factory communication defaults.

Byte order & addressing

  • Energy counters are signed Int32 even though import/export totals only count up; net counters can go negative.
  • Load type is a float holding an ASCII code (67, 76 or 82).

Network setup

  • See the AcuRev 1310 user manual for the front-panel communication settings.

Watch out for

  • Energy registers are writable; a mistaken write with function 16 overwrites the counter.

Notes on this map

  • The Data Types sheet states high byte first within a register and the high-order register first for 32-bit values, so floats and 32-bit counters are ABCD.
  • Energy counters are 32-bit integers in Wh, varh or VAh as labelled (revision 1.1 added these units); they can be written (function 16) to preset them.
  • Function codes per block: 03 to read, 16 to write energy, dual-source settings and commands.
  • Left out: the SunSpec blocks at 1000H and C350H (scaled duplicates of the same values), monthly energy history, peak-demand values with 6-byte timestamps, demand-reset/unseal/event records, max/min logs, and the dual-source change log records (packed timestamps).
  • Register 0100H returns a wiring-check result code; the code list is referenced in the maker's map but not reproduced here.
  • Transport and the 1312/1313/1314 model names come from the AcuRev 1310 user manual (https://www.accuenergy.com/wp-content/uploads/AcuRev-1310-User-Manual.pdf): Modbus RTU (factory default) or BACnet MS/TP on the built-in RS-485 port; no Modbus TCP.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Accuenergy AcuRev 1310 series DIN-rail power meter

What Modbus registers does the Accuenergy AcuRev 1310 series DIN-rail power meter have?

This map lists 150 registers: 150 holding registers. 96 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Accuenergy AcuRev 1310 series DIN-rail power meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The workbook states that its addresses are 0-based Modbus PDU addresses and prints each as hex and decimal (2000H = 8192). Request the decimal value as given.

What byte order does the Accuenergy AcuRev 1310 series DIN-rail power meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Accuenergy AcuRev 1310 series DIN-rail power meter?

Start with HR 8194 Phase A Current (Phase A current); HR 8202 Phase A Voltage (Phase A voltage); HR 8216 Frequency (Frequency); HR 8218 Total Active Power (Total active power); HR 8242 Power Factor (Total power factor); HR 8270 Total Active Energy Imported (Total active energy imported); HR 8262 Total Active Energy Exported (Total active energy exported).

How do I enable Modbus control of the Accuenergy AcuRev 1310 series DIN-rail power meter?

Set the Modbus address and serial (or network) parameters on the meter; the workbook does not list the factory communication defaults.
