Rishabh Instruments RISH Delta Power NX multifunction power meter Modbus register map

Updated 19 November 2026

Short answer

The RISH Delta Power NX is a 96 x 96 mm multifunction meter that measures voltage, current, power, power factor, frequency and demand (no energy counters) on 1-phase and 3-phase networks, with an RS-485 Modbus RTU port. Every value is an IEEE 754 float in two registers: measurements are input registers (FC04) from 30001, mirrored as holding registers at 40001+, and setup parameters sit at 46003-46085. This map covers the measured values, demands, run/on hours and the setup block.

This page lists 89 Modbus registers for the Rishabh Instruments RISH Delta Power NX multifunction power meter — 22 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Rishabh Instruments’s own free documentation (linked below) and checked against it.

Integration notes: Rishabh Instruments RISH Delta Power NX multifunction power meter

Integration in brief

Read 30001-30072 (and the demand block 30083-30106) with FC04 and decode each register pair as a big-endian float. Settings are floats at 46003+ written with FC16.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the Modbus address (46047, default 1) and Comsetup code (46045, default 8 = 9600 8N1) from the front panel or over Modbus.

Byte order & addressing

  • Setup values are floats too: system type 3 reads back as 40 40 00 00.
  • Reading or writing half a float returns exception 02.
  • If a password is set, write it to 46033 before changing setup registers.

Network setup

  • Comsetup (46045) packs baud 4800-57600, parity and stop bits into one code; see the value list.

Watch out for

  • Per-phase PF and line-to-line voltages are only valid for the wiring types noted in each description.

Notes on this map

  • The data-format table states IEEE 754 floats, most significant byte first; the Volts 3 example returns 43 5B 41 21 (219.25 V), so ABCD is the default. 46049 can switch to reversed order.
  • Every 3X value can also be read with FC03 at the number plus 10000; only the 3X copies are listed.
  • The register table has no unit column, so units are left blank.
  • Left out: the min/max history from 31301 and the user-assignable registers. Demand time (46015) is printed as seconds in Table 4 and minutes in the explanation, so no unit is given.
  • Up to 40 parameters (80 registers) per read request.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Rishabh Instruments RISH Delta Power NX multifunction power meter

What Modbus registers does the Rishabh Instruments RISH Delta Power NX multifunction power meter have?

This map lists 89 registers: 66 input registers, 23 holding registers. 22 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Rishabh Instruments RISH Delta Power NX multifunction power meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints 3X/4X register numbers. Wire address = number - 30001 (FC04) or - 40001 (FC03/FC16): the Volts 3 example (30005) starts at 00 04 and the system-type example (46003) starts at 17 72 (6002).

What byte order does the Rishabh Instruments RISH Delta Power NX multifunction power meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Rishabh Instruments RISH Delta Power NX multifunction power meter?

Start with IR 0 V1 (Voltage L1); IR 6 I1 (Current L1); IR 52 Watt sum (Total active power); IR 62 PF average (Average power factor); IR 70 System frequency (Frequency).

How do I enable Modbus control of the Rishabh Instruments RISH Delta Power NX multifunction power meter?

Set the Modbus address (46047, default 1) and Comsetup code (46045, default 8 = 9600 8N1) from the front panel or over Modbus.
