Short answer

The PCC 1301 and PowerCommand 1.x are Cummins genset controls with a two-wire RS-485 Modbus RTU slave port. The map gives switch position, operating state, active fault, alternator voltages, currents, kVA and frequency, engine data, Modbus start/stop and E-stop, and the basic genset setup parameters. Settings changed over Modbus are kept only after a save command.

This page lists 49 Modbus registers for the Cummins PCC 1301 / PowerCommand 1.1 / 1.2 genset control (Modbus RTU) — 17 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Cummins’s own free documentation (linked below) and checked against it.

Integration notes: Cummins PCC 1301 / PowerCommand 1.1 / 1.2 genset control (Modbus RTU)

Integration in brief

Poll 40010/40011 for switch position and state, 40012/40013 for the active fault, 40018-40044 for alternator values and 40061-40069 for engine data. Remote start/stop is 40300 (1 = start) and remote E-stop 40302.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The section gives no enable parameter; the RS-485 port is on TB2-3 (+), TB2-4 (-) and TB2-1 (shield). Writing 40004 = 1 (save adjustments) stores the written settings in non-volatile memory.

Byte order & addressing

  • Up to 40 contiguous registers per read or write.
  • Gaps in the register list are unused addresses.

Network setup

  • Wire the two-wire RS-485 bus to TB2-3/TB2-4 with the shield on TB2-1.
  • Address and baud settings are not given in this section; set them at the control (see the control's service manual).

Watch out for

  • Older control software may not support all registers.

Notes on this map

  • Cummins does not host this document publicly; the link is a copy on an integrator's site (Control Concepts). A dealer site lists a newer Issue 26 (2020) that could not be downloaded here; registers may have been added since Issue 7.
  • Only section 1 (PCC 1301 / PowerCommand 1.x) is covered. PowerCommand 2.x/3.x, DMC and MCM3320 use other register maps in the same document.
  • Engine runtime is split over 40070 (named high byte) and 40071 (named low byte), 1 s units. Section 1 does not give a combining rule, so they are listed as two separate words; section 2 of the same document uses value = high x 65536 + low for its 32-bit pairs.
  • 40059 is printed as 'phase a' a second time; it sits between phase A (40058) and phase C (40060).
  • Coolant temperature (40064) is printed as unsigned 0.1 °C and engine speed (40068) as 0.1 rpm; transcribed as printed.
  • The NFPA 110 and extended annunciation bit maps (40016/40017) are in section 4, Tables 4-1/4-2. Those tables label bit 0 as the MSB and bit 15 as the LSB, while the MCM3320 section of the same document calls bit 15 the most significant, so the bit positions are not expanded here.
  • Left out: the governor/AVR tuning, model/serial number characters, metering calibration and configurable I/O settings (43014-43090).
  • Not every control software version supports every register; an unsupported register may simply not answer while others do.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Cummins PCC 1301 / PowerCommand 1.1 / 1.2 genset control (Modbus RTU)

What Modbus registers does the Cummins PCC 1301 / PowerCommand 1.1 / 1.2 genset control (Modbus RTU) have?

This map lists 49 registers: 49 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Cummins PCC 1301 / PowerCommand 1.1 / 1.2 genset control (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as Modicon 4xxxx holding-register numbers; 40011 is wire address 10.

What are the minimum Modbus registers to integrate the Cummins PCC 1301 / PowerCommand 1.1 / 1.2 genset control (Modbus RTU)?

Start with HR 9 Run/off/auto switch position (Switch position); HR 10 Genset operating state (Operating state); HR 11 Fault code (Active fault code); HR 12 Fault type (Fault type); HR 25 Current phase A (Phase A current); HR 43 Alternator frequency (Frequency); HR 299 Genset start/stop via Modbus (Start/stop command).

How do I enable Modbus control of the Cummins PCC 1301 / PowerCommand 1.1 / 1.2 genset control (Modbus RTU)?

The section gives no enable parameter; the RS-485 port is on TB2-3 (+), TB2-4 (-) and TB2-1 (shield). Writing 40004 = 1 (save adjustments) stores the written settings in non-volatile memory.
