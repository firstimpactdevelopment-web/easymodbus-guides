Short answer

The Z-4AI converts four ±10 V / ±20 mA single-ended inputs to normalized 16-bit values readable over RS-485 Modbus RTU. Everything is in single 16-bit holding registers: comms settings, per-channel filters and scaling, the four measurements and, from firmware 737, channel differences.

This page lists 34 Modbus registers for the Seneca Z-4AI 4-channel analog input module — 24 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Seneca’s own free documentation (linked below) and checked against it.

Integration notes: Seneca Z-4AI 4-channel analog input module

Integration in brief

Read holding registers 40017-40020 (wire 16-19) for the four normalized inputs and 40016 for over/underflow bits.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set address and baud with the SW1 DIP switches, or set all address switches OFF to use the values stored in 40002/40003.

Byte order & addressing

  • 40002 packs baud code and address into one register.
  • Input type must match the SW2 DIP switch for each channel.

Network setup

  • SW1 switches 9-10 enable the RS-485 terminator.
  • Write bit 7 of 40016 to store settings in EEPROM.

Watch out for

  • Difference registers 40055-40058 exist only from firmware revision 737.

Notes on this map

  • All registers are single 16-bit words; there are no 32-bit values.
  • Address 1 and 38400 baud are the EEPROM defaults, used only when the address DIP switches are all OFF; otherwise DIP switches set address (1-63) and baud (9600-57600).
  • Bit 0 of 40003 selects Z-4AI-0 compatibility, in which the measurement is fixed to 0-10000.
  • Left out: 40036, labelled 'Errors' but printed with the same parity/delay/sampling bit list as 40003, so its real content is unclear.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Seneca Z-4AI 4-channel analog input module

What Modbus registers does the Seneca Z-4AI 4-channel analog input module have?

This map lists 34 registers: 34 holding registers. 24 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seneca Z-4AI 4-channel analog input module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table prints both the 4x number and the offset (40001 = offset 0); the offset is the wire address.

What are the minimum Modbus registers to integrate the Seneca Z-4AI 4-channel analog input module?

Start with HR 16 IN1 normalized value (IN1); HR 17 IN2 normalized value (IN2); HR 18 IN3 normalized value (IN3); HR 19 IN4 normalized value (IN4); HR 15 Status (Status and over/underflow).

How do I enable Modbus control of the Seneca Z-4AI 4-channel analog input module?

Set address and baud with the SW1 DIP switches, or set all address switches OFF to use the values stored in 40002/40003.

Where is the official Seneca Z-4AI 4-channel analog input module Modbus documentation?

The source is Z-4AI User Manual (MI002572-E), published free by Seneca at https://www.seneca.it/media/1329/mi00257-2-en.pdf.
