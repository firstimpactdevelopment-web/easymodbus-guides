Short answer

Single-phase DIN-rail energy meters from Rishabh in direct-connected (ED), CT-connected (EC) and RJ12 CT (ER) versions; the Modbus variants have an RS-485 port speaking Modbus RTU. Every measured value is an IEEE 754 float in two registers, readable as input registers from 30001 or as holding registers at the same offset from 40001. This map covers voltage, current, power, PF, frequency, demands, total/tariff/partial energies and the main setup registers.

Integration notes: Rishabh Instruments RISH ED11XX / EC11XX / ER11XX single-phase DIN-rail energy meters

Integration in brief

Read 30001-30038 for instantaneous values and 30107-30142 for energies with FC04 (or FC03 at 40001+) and decode each register pair as a big-endian float.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Only the x1 (Modbus) variants have RS-485. Set address and baud/parity from the front-panel setup (address 001 and 9600 baud, no parity by default; check stop bits, see notes) or via 46025/46027.

Byte order & addressing

  • Setup values are floats too: total energy formula 1 reads back as 3F 80 00 00.
  • Reading or writing half a float returns exception 02.

Network setup

  • Comsetup (46027) codes 0-19 pack baud 2400-38400, parity and stop bits.

Watch out for

  • Changing CT settings on EC/ER models locks after a countdown (46021); plan CT changes during commissioning.

Notes on this map

  • The data-format table states IEEE 754 floats, most significant byte first. The voltage example returns 43 66 00 00 (230 V) and the current example 40 A0 00 00 (5 A), so word order is ABCD.
  • Every 3X value is also a 4X holding register at the same offset (30001 -> 40001); only the 3X copies are listed.
  • Left out: parameter 42 (printed with the same name as 43), parameter 108 'Partial Active Import Energy' (unit printed as Wh, unlike its kWh siblings), the 'long energy' Table 5 (30513-30655, format not described) and the user-assignable registers (31025-31051).
  • Units are as printed (Volts -> V, Amp -> A). Energy overflow counts increase each time the matching energy passes 99999.999.
  • Up to 40 parameters per read request.
  • Table 4 prints 'Total Apparent Energy' (and its overflow count) twice in each block: at 30123/30125 and again at 30139/30141 (same for T1 30159/30161 vs 30175/30177, T2 30195/30197 vs 30211/30213, partial 30231/30233 vs 30247/30249). The first copy of each pair is left out because its real meaning is unclear; the second copy sits where the long-energy Table 5 puts total apparent energy.
  • Default stop bits are not settled: the front-panel section gives nonE1 (no parity, 1 stop) but Table 6 prints Comsetup default 9 (9600, no parity, 2 stop). Both agree on 9600 baud and no parity. Some setup rows also differ between ED and EC/ER models; only the clearly described rows are listed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Rishabh Instruments RISH ED11XX / EC11XX / ER11XX single-phase DIN-rail energy meters

What Modbus registers does the Rishabh Instruments RISH ED11XX / EC11XX / ER11XX single-phase DIN-rail energy meters have?

This map lists 84 registers: 79 input registers, 5 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Rishabh Instruments RISH ED11XX / EC11XX / ER11XX single-phase DIN-rail energy meters Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Table 4 prints 3X and 4X numbers next to the hex start address (30001 = 00 00, 30071 = 00 46). Wire address = number - 30001 (FC04) or - 40001 (FC03); every row was checked against the printed hex and parameter number. The setup example reads 46007 at 17 76.

What byte order does the Rishabh Instruments RISH ED11XX / EC11XX / ER11XX single-phase DIN-rail energy meters use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Rishabh Instruments RISH ED11XX / EC11XX / ER11XX single-phase DIN-rail energy meters?

Start with IR 0 Voltage (Voltage); IR 6 Current (Current); IR 12 Active Power (Active power); IR 30 Power Factor (Power factor); IR 70 Frequency (Frequency); IR 108 Active Import Energy (Active import energy (kWh)).

How do I enable Modbus control of the Rishabh Instruments RISH ED11XX / EC11XX / ER11XX single-phase DIN-rail energy meters?

Only the x1 (Modbus) variants have RS-485. Set address and baud/parity from the front-panel setup (address 001 and 9600 baud, no parity by default; check stop bits, see notes) or via 46025/46027.
