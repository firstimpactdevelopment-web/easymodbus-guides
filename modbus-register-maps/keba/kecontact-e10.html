KEBA KeContact E10 smart energy meter (Modbus) Modbus register map

Updated 17 November 2026

Short answer

The KeContact E10 is KEBA's three-phase smart energy meter for home energy management with its wallboxes. It answers Modbus with holding registers only: instantaneous power, current, voltage, power factor and frequency, 64-bit energy counters per phase, a fast block for current/voltage/power, a plug-and-play identity block, a SunSpec common + meter (203) model, and a few configuration, identify and restart registers.

This page lists 184 Modbus registers for the KEBA KeContact E10 smart energy meter (Modbus) — 17 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from KEBA’s own free documentation (linked below) and checked against it.

Integration notes: KEBA KeContact E10 smart energy meter (Modbus)

Integration in brief

Read the 64-bit energy counters at 512 (import) and 516 (export) and the per-phase power/current/voltage block 0-147, or use the SunSpec meter model at 40070 if your system speaks SunSpec. All values are big-endian, high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU baud rate is set in register 258 (0 = 9600 ... 5 = 115200). IP address, subnet mask and DHCP are in registers 259-267 and take effect after a restart.

Byte order & addressing

  • Read all registers of a multi-register value in one request.
  • Writing 1 to register 268 locks all configuration and the restart register; plan the configuration first.

Network setup

  • Registers 61613/61614 make the meter blink for identification on site.

Watch out for

  • Power values are split into + (import) and - (export) registers, both unsigned, rather than one signed value.

Notes on this map

  • Multi-register values are most significant word first: the description sheet says the lower address holds the most significant bits and gives a uint32 example (0x0023 then 0x0044). 64-bit energy counters follow the same rule.
  • Engineering values: power in 0.1 W/var/VA steps, current and voltage in 0.001 A/V, power factor in 0.001, frequency in 0.001 Hz, energy in 0.1 Wh/varh/VAh.
  • SunSpec values use scale-factor registers that KEBA says can change at run time; always read the scale factor with the value.
  • All data is read with function 03 (read holding registers); configuration registers accept 06 and 16.
  • Static IP and subnet mask take one octet per register (4 registers each); network changes take effect after a restart (61615).
  • In the SunSpec block the list shows 0x8000 (SunSpec 'not implemented') for total current 40072 and the average voltages 40077/40081, 0x8000 for the reactive-energy scale factor 40174, and 0 for the var-hour quadrant counters; use the per-phase values and the native energy counters instead.
  • Reading an address that is not in the list returns exception 02. Reserved gaps are not listed.
  • Bus settings other than the baud-rate code (register 258) are not given in the list, so defaults are left empty.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the KEBA KeContact E10 smart energy meter (Modbus)

What Modbus registers does the KEBA KeContact E10 smart energy meter (Modbus) have?

This map lists 184 registers: 184 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the KEBA KeContact E10 smart energy meter (Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The list gives start addresses, not register numbers: the first block starts at address 0 and the SunSpec block at 40000. The sheet itself warns that SunSpec register 40001 is read at address 40000.

What byte order does the KEBA KeContact E10 smart energy meter (Modbus) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the KEBA KeContact E10 smart energy meter (Modbus)?

Start with HR 0 Active power+ (Active power import (total)); HR 2 Active power- (Active power export (total)); HR 60 Current (L1) (Current L1); HR 62 Voltage (L1) (Voltage L1); HR 26 Supply frequency (Frequency); HR 512 Active energy+ (Active energy import); HR 516 Active energy- (Active energy export).

How do I enable Modbus control of the KEBA KeContact E10 smart energy meter (Modbus)?

Modbus RTU baud rate is set in register 258 (0 = 9600 ... 5 = 115200). IP address, subnet mask and DHCP are in registers 259-267 and take effect after a restart.
