APC Symmetra PX 250/500 kW Modbus register map

Updated 17 November 2026

Short answer

The Symmetra PX 250/500 kW publishes a large Modbus map through its AP9635 network card, over RTU or TCP. Status and alarm registers at 40001 onward are bit fields; measurements (battery, input, bypass, output per phase, load, energy, temperatures, operating modes and component lifetimes) are 16- or 32-bit holding registers from 44097 onward, with documented multiply/divide scaling.

This page lists 156 Modbus registers for the APC Symmetra PX 250/500 kW — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from APC’s own free documentation (linked below) and checked against it.

Integration notes: APC Symmetra PX 250/500 kW

Integration in brief

Read the status/alarm block from 0 and the measurement blocks from 0x1100 (battery), 0x1200 (input), 0x1300 (bypass), 0x1400 (output) and 0x1500 (system) with function 03 or 04.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Enable Modbus (serial RTU or TCP) on the AP9635 Network Management Card; see its user's guide.

Byte order & addressing

  • Status bits are only consistent within one register; do not combine bits across registers.
  • Frequencies, PF, crest factor and % load use a 0.1 scale.

Network setup

  • Serial/TCP parameters and unit ID are configured on the AP9635 card.

Watch out for

  • Some registers were added in later firmware (sypx512, sypx515, sypx516) and may be missing on older firmware.

Notes on this map

  • Source host: this is the APC document as republished by integrator Control Concepts (ccontrols.com); APC's own download links refuse automated requests.
  • Word order: note 2 says INT32/UINT32 have the most significant word in n+0, so 32-bit values are ABCD. Note 3: function codes 3 and 4 are both supported.
  • Strings are two characters per register, high byte first, without a null terminator.
  • Left out: rows whose multiply and divide columns disagree (the parallel-system %-load registers show multiply 1 but divide 10), rows with no data type, and per-module lifetime registers for frames 1-3 (frame 0 kept as the pattern).
  • Accessing an undefined range returns an illegal-data-address error. Detailed comms settings are in the AP9635 user's guide.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the APC Symmetra PX 250/500 kW

What Modbus registers does the APC Symmetra PX 250/500 kW have?

This map lists 156 registers: 156 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the APC Symmetra PX 250/500 kW Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row shows the Modicon number, the absolute address in hex and decimal; note 12 says absolute address 0 is register 40001 and address zero on the wire.

What byte order does the APC Symmetra PX 250/500 kW use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the APC Symmetra PX 250/500 kW?

Start with HR 0 UPS Status (UPS status bits (on battery, bypass, alarms)); HR 4354 Runtime remaining (Runtime remaining); HR 4358 Estimated charge % (Battery charge %); HR 5145 Total Percent load (Total output load %); HR 5143 Total active power (output) (Total output active power); HR 5378 UPS Mode Operation mode of the UPS (UPS operating mode).

How do I enable Modbus control of the APC Symmetra PX 250/500 kW?

Enable Modbus (serial RTU or TCP) on the AP9635 Network Management Card; see its user's guide.
