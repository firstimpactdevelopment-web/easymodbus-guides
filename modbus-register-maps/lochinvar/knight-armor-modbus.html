Updated 16 October 2026

Short answer

Lochinvar's Knight, Armor, Wall Mount, FTXL, Shield and related boilers and water heaters speak Modbus RTU through an optional RS-485 communication board configured with DIP switches. A BAS can enable the unit, send a modulation rate or setpoint command, and supply tank, outdoor and system temperatures, with a configuration word telling the appliance which values to take from the BAS. Read-only data covers outlet/inlet/flue temperatures, firing rate, pump speeds, cascade power and status, blocking and lockout codes.

This page lists 43 Modbus registers for the Lochinvar Knight / Armor / Wall Mount boilers (ModBus communication board) — 11 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lochinvar’s own free documentation (linked below) and checked against it.

Integration notes: Lochinvar Knight / Armor / Wall Mount boilers (ModBus communication board)

Integration in brief

Set the board address, baud and parity on its DIP switches, put the boiler control in ModBus mode, then write the configuration word 40001 followed by the command registers. For a simple enable, write 40001 = 0x0001 and 40002 = 0x0001; for a modulation or setpoint command also set bit 2 (40001 = 0x0005) and write 40003. Monitor 30009-30016.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the boiler installer menu go to CONTROL MODES and set ModBus to ACTIVE, then pick the control mode (enable only, enable + rate/setpoint, rate only, DHW). Set BMS TYPE to POWER or SETPOINT for rate commands. Re-send the configuration word in 40001 before each command.

Communication loss & watchdog

MODBUS T/O in the CONTROL MODES menu, 5-120 s (default 10 s): if BAS-supplied temperatures or the 0-10 V value are not refreshed in time the boiler falls back to its own sensors. Enable-type commands must be refreshed at least every 4 minutes or the boiler reverts to its own inputs.

Byte order & addressing

  • Modicon addressing: 40001 is holding register 0 on the wire.
  • Temperatures are passed as degrees C x 10 (the manual's examples: 267 = 26.7 C, 683 = 68.3 C); the map assumes DIP switch 8 is OFF (Celsius).
  • A rate command is a plain percentage (0-100). To command a temperature setpoint via 40003 the value is the 0-10 V equivalent percentage, interpolated from the BMS setpoint-at-low/high-voltage parameters, not degrees.
  • The lockout code changes during normal operation; only trust it when the status code (30014) reads 40.

Network setup

  • DIP switches 1-7 set the Modbus address (binary weights 1-64, maximum 127).
  • DIP switch 8: OFF = Celsius, ON = Fahrenheit.
  • DIP switch 9: OFF = 9600 baud, ON = 19200 baud.
  • DIP switch 10: OFF = no parity with 2 stop bits, ON = even parity with 1 stop bit.
  • RTU only; use 120 ohm termination at the ends of the RS-485 run.
  • For cascades, a board on the leader alone gives total cascade data; fit a board to each unit to see individual temperatures.

Watch out for

  • Writing commands without setting the matching bit in 40001 has no effect; the boiler keeps using its own inputs.
  • Board LED D7 shows faults: 1.5 s on / 0.5 s off means no Modbus communication, 0.5 s on / 1.5 s off means no communication with the burner control.

Notes on this map

  • Temperatures: the manual's conversion section says the appliance passes temperatures in degrees C multiplied by 10 (worked examples: outdoor 26.7 C sent as 267; outlet 683 read as 68.3 C). Scale 0.1 is applied to every temperature register.
  • Removed: System/Cascade Setpoint (30004), Outlet Setpoint (30008) and Tank Setpoint (40004). The memory map gives these a 0.5 C resolution while the conversion section says all temperature data is degrees C x 10, and the worked examples only cover other registers (outdoor temperature and outlet temperature). Because the scaling of these three is not settled by the document, they are left out.
  • Signed types: registers whose published minimum is negative (inlet, flue, tank, outdoor, supply/return temperatures) are listed as INT16; the manual itself only says '16-bit word'.
  • Dip switch 8 on the communication board selects degrees C (OFF) or F (ON) for the display/data; units here assume C (switch OFF), matching the manual's tables and conversion examples.
  • Holding register 40002 'Coils' has no bit list: the manual's tables write 0x0001 to enable the unit but 0x0008 for the tank thermostat, which does not match the tank thermostat being coil 00005. Write only the exact values from the manual's control-mode tables.
  • Input registers 30001-30003 are packed copies of the discrete inputs; the bit-to-input order is not stated, so they are listed as UINT16. Use the discrete inputs instead.
  • The same manual also covers AWH and KBX appliances (pp. 30-33) with similar holding-register use; this map follows the main memory map on pp. 13-14.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Lochinvar Knight / Armor / Wall Mount boilers (ModBus communication board)

What Modbus registers does the Lochinvar Knight / Armor / Wall Mount boilers (ModBus communication board) have?

This map lists 43 registers: 4 coils, 18 discrete inputs, 14 input registers, 7 holding registers. 11 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lochinvar Knight / Armor / Wall Mount boilers (ModBus communication board) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed Modicon-style (00001 coils, 10001 discrete inputs, 30001 input registers, 40001 holding registers). Subtract the table base and 1 for the wire address, e.g. Outlet Temperature 30009 is input register 8.

What are the minimum Modbus registers to integrate the Lochinvar Knight / Armor / Wall Mount boilers (ModBus communication board)?

Start with HR 0 Configuration (Configuration bits: which values come from the BAS); HR 1 Coils (Enable / thermostat command word); HR 2 0-10 Volt Input / Rate Command / Setpoint Command (Rate (%) or setpoint command); IR 8 Outlet Temperature (Outlet temperature); IR 9 Inlet Temperature (Inlet temperature); IR 11 Firing Rate (Firing rate); IR 13 Boiler Status Code (Status code); IR 15 Boiler Lockout Code (Lockout code).
