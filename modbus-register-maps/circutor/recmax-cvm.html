Circutor RECmax-CVM Modbus register map

Updated 19 November 2026

Short answer

The RECmax-CVM combines an earth-leakage breaker that recloses on its own with a three-phase power analyzer. Its RS-485 port speaks Modbus RTU. Measurements are 32-bit integers in register pairs with fixed scaling, the leakage and reclosing counters are single registers, and setup lives in blocks around 0x2710 and 0xC360. This map covers voltages, currents, reactive and apparent power, THD, demand, energies, leakage data, status words, setup and reset commands; transformation ratios are left out.

Integration notes: Circutor RECmax-CVM

Integration in brief

Poll the block from 0x0000 with function 04 (at most 20 variables, 40 registers, per frame), then read the leakage registers C392-C399. All 32-bit values are high word first with fixed scale.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is the standard protocol (Protocol register 0x2742 = 0). Set the peripheral number from the front panel (hold PROG for more than 3 s) or register 0x2743, and speed and framing with 0x2744-0x2747; reset the device for Modbus setup changes to apply.

Byte order & addressing

  • A frame may carry at most 20 variables (40 registers).
  • Energies come both as a single Wh/varh counter and as a whole-unit plus remainder pair; use the pair for large totals.
  • Reset commands are coils written with function 05 and FF00.
  • The trip/reset register C3AC operates the breaker remotely; treat it as a control point.

Network setup

  • Defaults from the setup tables: peripheral number 1, 19200 baud, no parity, 8 data bits, 1 stop bit.
  • Only 9600 and 19200 baud are offered.
  • Up to 32 devices per RS-485 bus, 1200 m maximum.

Watch out for

  • Writing C3AC = 1 trips the breaker and cuts the load.

Notes on this map

  • Word order: the read example returns register 1 = 0000 and register 2 = 084D for 212.5 V, so 32-bit values are high word first (ABCD).
  • Left out: active power (per phase and three-phase), power factor, cos phi and the kW maximum demand. The device measures in four quadrants but the manual never says whether these Modbus values are signed, so their type cannot be fixed from the document.
  • Voltages, currents, reactive and apparent powers, frequency, THD, demand values and energies are non-negative and are typed UINT32.
  • Left out: minimum values, most maximum values, harmonics tables (0x1F4-0x367), CO2 and cost registers, digital output programming (0x2B0C-0x2B15), model and serial-number registers (type not stated) and the input-status word at C38F, whose bit list starts at bit 1 and ends with an unlabeled bit 9, so the bit positions are not certain.
  • Measurement, energy and protection variables accept functions 03 and 04. Setup registers are listed as holding registers; the manual names function 0x10 for most of them, but for the number of quadrants (2B24), the POSITIVE SAFE OUTPUT function (C363) and enable reclosing (C391) it lists only function 04, so those are marked read-only.
  • Setup changes take effect only after the device is reset, and an out-of-range value is replaced by the default without an error.
  • Left out: the transformation ratios (2710-2714). The manual gives their addresses but no units, ranges or encoding, so the current secondary in particular could be a code rather than amps.
  • Left out: the delete-energy (834) and delete-max/min (838) coils. Table 27 puts max/min deletion at 838, but the function 05 write example uses 0834 for the same action, so the two addresses contradict each other.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Circutor RECmax-CVM

What Modbus registers does the Circutor RECmax-CVM have?

This map lists 100 registers: 3 coils, 77 input registers, 20 holding registers. 20 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Circutor RECmax-CVM Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints every Modbus address in hexadecimal and they are the wire addresses. Its read example asks for initial register 0000 to get L1 phase voltage and receives 0000 084D (2125 = 212.5 V), which confirms the offset and the x10 voltage scale.

What byte order does the Circutor RECmax-CVM use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Circutor RECmax-CVM?

Start with IR 0 Phase voltage L1 (L1 phase voltage (V x10)); IR 2 Current L1 (L1 current (mA)); IR 66 Three-phase apparent power (Three-phase apparent power); IR 40 Frequency (Frequency (Hz x10)); IR 60 Consumed active energy III (Consumed active energy); IR 50071 Leakage current (Earth leakage current (mA)); IR 50066 Total reclosing operations (Total reclosing operations); IR 50064 Relay output status (Relay status).

How do I enable Modbus control of the Circutor RECmax-CVM?

Modbus RTU is the standard protocol (Protocol register 0x2742 = 0). Set the peripheral number from the front panel (hold PROG for more than 3 s) or register 0x2743, and speed and framing with 0x2744-0x2747; reset the device for Modbus setup changes to apply.
