Short answer

The GDA 4022 is a two-channel gas detection controller whose isolated RS-485 port runs as a Modbus RTU slave by default. Gas concentrations are input registers, alarm states and the system fault are coils, and configuration (gas type, units, alarm behaviour, location names, mA outputs) sits in holding registers. All values are 16-bit, signed unless the document says otherwise.

This page lists 29 Modbus registers for the Gas Detection Australia GDA 4022 — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Gas Detection Australia’s own free documentation (linked below) and checked against it.

Integration notes: Gas Detection Australia GDA 4022

Integration in brief

Read input registers 0-1 (function 04) for concentrations, coils 100-400 (function 01) for alarms and fault, and holding registers 200/201 once to learn the units.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The RS-485 port is a Modbus slave in the factory configuration; no enable step is needed.

Byte order & addressing

  • The controller normally answers within 20 ms; keep at least 3.5 characters (>3.7 ms) between frames.

Network setup

  • Fixed serial format: 9600 baud, 8 data bits, no parity, 1 stop bit.
  • Fit termination at both bus ends for runs over 30 m or noisy sites; enable master bias resistors if communication is unreliable.

Watch out for

  • Ring or star wiring is not recommended for the RS-485 bus.

Notes on this map

  • Coils are read with function 01, holding registers with 03 and the concentrations with 04, as listed in the table's function-code column.
  • The document says all integers are signed unless stated, so registers are typed INT16.
  • Left out: sensor range, scale, alarm thresholds, hysteresis, mA output mode/scaling/update period and value/status display mode. The range/threshold formulas (value x 10 to a power taken from the scale register) are not legible in the published PDF text.
  • Concentration readings are raw; the document says the value is x10 when the gas range is % LEL or % Vol, so use the units register (40201/40202) to pick the divisor.
  • Documented addresses use the legacy (Modicon-style) column; coils use 0xxxx numbers.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Gas Detection Australia GDA 4022

What Modbus registers does the Gas Detection Australia GDA 4022 have?

This map lists 29 registers: 7 coils, 2 input registers, 20 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Gas Detection Australia GDA 4022 Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table gives three columns per register: the physical (wire) address, the 1-based offset and the legacy Modicon address, e.g. physical 00000 = offset 00001 = 30001. Wire addresses here are the physical column; 'documented' shows the legacy number.

What are the minimum Modbus registers to integrate the Gas Detection Australia GDA 4022?

Start with IR 0 Sensor 1 concentration (Sensor 1 concentration); IR 1 Sensor 2 concentration (Sensor 2 concentration); CO 100 Sensor 1 alarm 1 (Sensor 1 alarm 1); CO 400 System fault (System fault); HR 200 Sensor 1 units of concentration (Sensor 1 units (sets the x10 rule)); HR 100 Sensor 1 gas type (Sensor 1 gas type).

How do I enable Modbus control of the Gas Detection Australia GDA 4022?

The RS-485 port is a Modbus slave in the factory configuration; no enable step is needed.
