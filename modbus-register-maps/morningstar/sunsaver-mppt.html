Short answer

The SunSaver MPPT is a Morningstar MPPT solar charge controller with a load output. It speaks Modbus RTU on its RJ-11 meter port through Morningstar's MSC adapter (MeterBus to RS-232). RAM registers give battery, array and load readings, charge and load state and fault bitfields; EEPROM registers hold the charge setpoints and LO-first copies of the Ah and hour counters; coils force load/charge disconnect and clear counters.

This page lists 56 Modbus registers for the Morningstar SunSaver MPPT solar charge controller (Modbus RTU via MeterBus) — 21 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Morningstar’s own free documentation (linked below) and checked against it.

Integration notes: Morningstar SunSaver MPPT solar charge controller (Modbus RTU via MeterBus)

Integration in brief

Connect through the Morningstar MSC adapter at 9600 8N2, ID 1. Read 0x0008-0x0014 for live data; multiply raw voltages by 100/32768 and currents by 79.16/32768. Use coils 0x0001/0x0002 to switch the load or charger off remotely.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the comm DIP switch (switch 4, reported as bit 3 of register 0x0025) to MODBUS protocol instead of Meterbus, and connect via the MSC RS-232 adapter.

Byte order & addressing

  • Every analog value needs its own formula-derived multiplier; there are no floats.
  • Any EEPROM write sets an 'EEPROM changed' fault; reset the controller (coil 0x00FF) to clear it. Writes are not verified.

Network setup

  • Serial: 9600 baud, 8 data bits, no parity, 2 stop bits, no flow control.
  • Modbus ID is stored in EEPROM at 0xE034 (1-247).

Watch out for

  • The MeterBus port is not RS-485; a Morningstar adapter is required.

Notes on this map

  • Scaling: Morningstar gives formulas such as n x 100 x 2^-15; these are converted to a single multiplier (e.g. 100/32768 = 0.0030517578125 for voltages, 79.16/32768 for currents, 989.5/65536 for power, 96.667/32768 for Vb_ref). The manual's example: 0x0F96 = 3990 x 100 / 32768 = 12.18 V.
  • Word order: the RAM table names each 32-bit pair HI word then LO word (e.g. hourmeter_HI 0x0021, hourmeter_LO 0x0022), but the spec's own two-word example reads the hourmeter LO word at the lower address. Because the document contradicts itself, the RAM 32-bit values (Ah counters 0x0015-0x0020, hourmeter 0x0021, alarm 0x0023 and daily alarm 0x0031) are left out. The EEPROM read-only copies are printed LO word first (Ehourmeter_LO 0xE040, Ehourmeter_HI 0xE041), which matches the example, so those are listed as CDAB.
  • The two-word example uses addresses 0x0025/0x0026 for the hourmeter, which do not match the table (0x0021/0x0022).
  • Both Read Holding (0x03) and Read Input (0x04) are supported; registers are listed as holding registers. EEPROM is written with Write Single Register (0x06) only.
  • Alarm bitfield bits (32-bit value at 0x0023, not listed): 0 RTS open, 1 RTS shorted, 2 RTS disconnected, 3 Ths open, 4 Ths shorted, 5 SSMPPT hot, 6 current limit, 7 current offset, 10 uncalibrated, 11 RTS miswire, 14 miswire, 15 FET open, 16 P12, 17 high Va current limit.
  • Not listed: bank-2 charge settings (0xE00D-0xE017), LED thresholds, the data logger (0x8000-0x81FF) and the remaining EEPROM timers.
  • Voltages and currents are listed as unsigned raw values; temperatures are signed (-128 to +127).

Questions about the Morningstar SunSaver MPPT solar charge controller (Modbus RTU via MeterBus)

What Modbus registers does the Morningstar SunSaver MPPT solar charge controller (Modbus RTU via MeterBus) have?

This map lists 56 registers: 8 coils, 48 holding registers. 21 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Morningstar SunSaver MPPT solar charge controller (Modbus RTU via MeterBus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Morningstar prints a PDU address (hex, goes on the wire as-is) and a logical address (PDU + 1). The manual states all listed addresses are request-PDU addresses; its scaling example reads battery voltage at 0x0008.

What byte order does the Morningstar SunSaver MPPT solar charge controller (Modbus RTU via MeterBus) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Morningstar SunSaver MPPT solar charge controller (Modbus RTU via MeterBus)?

Start with HR 8 Adc_vb_f - battery voltage (Battery voltage); HR 9 Adc_va_f - array voltage (Array voltage); HR 11 Adc_ic_f - charging current (Charging current); HR 17 Charge state (Charge state); HR 18 Array fault bitfield (Array faults); HR 39 Power_out - charge output power (Charge output power); CO 1 Load disconnect (Remote load disconnect).

How do I enable Modbus control of the Morningstar SunSaver MPPT solar charge controller (Modbus RTU via MeterBus)?

Set the comm DIP switch (switch 4, reported as bit 3 of register 0x0025) to MODBUS protocol instead of Meterbus, and connect via the MSC RS-232 adapter.
