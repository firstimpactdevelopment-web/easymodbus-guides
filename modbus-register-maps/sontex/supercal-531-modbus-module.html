Sontex Supercal 531 / Superstatic 440 / 449 with Modbus EIA-485 module Modbus register map

Updated 17 November 2026

Short answer

Sontex's Supercal 531 integrator and the Superstatic 440/449 heat and cooling meters take an optional RS-485 plug-in module that makes them a Modbus RTU or ASCII slave. Settings and the clock are holding registers, meter values are input registers and error flags are discrete inputs. This map covers the settings block, device information, error flags and the IEEE-754 float copies of energy, volume, pulse inputs, power, flow and temperatures, including the Set-Day stored values.

This page lists 79 Modbus registers for the Sontex Supercal 531 / Superstatic 440 / 449 with Modbus EIA-485 module — 17 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Sontex’s own free documentation (linked below) and checked against it.

Integration notes: Sontex Supercal 531 / Superstatic 440 / 449 with Modbus EIA-485 module

Integration in brief

Fit the Modbus module, wire D0/D1/Common, and poll input registers with function 04 using low-word-first floats: energy 30103, volume 30303, power 30703, flow 30713 and temperatures 30723/30725/30733, plus their unit codes. Discrete inputs 10001-10016 report meter errors.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The integrator detects the module automatically once it is plugged into a module slot; no setting is needed. Baud rate is set with DIP switch S2 (default 19200), bias and termination with DIP switch S1.

Byte order & addressing

  • 32-bit values are low word first (CDAB) even though the tables say '(h-l)'.
  • Each float block has a unit register two registers before the value; read it once to know whether energy is kWh, MWh or GJ.

Network setup

  • Defaults: address 1, RTU, 19200 baud, 8 data bits, even parity, 1 stop bit.
  • Address, parity, stop bits and RTU/ASCII can be changed over Modbus by writing 40017 (password) through the wanted register in one telegram; the module then reboots and is silent for 30-60 s. Do not power it down for 90-120 s.
  • If settings are changed with Prog531/449 over the optical port, the module must be power-cycled (wait 15 s, power off at least 10 s) before they take effect.
  • In ASCII mode with no parity the module uses 2 stop bits automatically.

Watch out for

  • The module needs integrator firmware 3.7 or later.
  • The module is powered from the integrator's mains supply board or an external 12 VDC / 150 mA supply; without that supply it will not answer.

Notes on this map

  • This is an unaltered Sontex manual hosted by the Swiss distributor NeoVac; Sontex keeps its own copy behind a login-only extranet and does not host it publicly.
  • Word order: the tables label 32-bit values '(h-l)' but every table footer says Sontex uses l-h ordering, and the word-swapping example (p. 10) puts the low word in the first register (30723) and the high word in the next (30724). The ModScan example also uses 'least significant register first'. All 32-bit values here are therefore CDAB.
  • Units of the float values follow the unit-code register at the start of each block (e.g. 30101 energy: 18 Wh, 19 kWh, 146 MWh, 126 MJ, 226 GJ, 20 BTU).
  • Left out: the 'long data point' integer copies (30201-30220, 30401-30420, 30601-30618, 30801-30834). Their value must be divided by 10 to the power of a separate Decimals register (0-3), which cannot be expressed as a fixed scale. The float copies carry the same quantities.
  • Left out: monthly logs 31001-33266 (32 stored months per quantity, 2 registers each, floats from 31003 and longs from 31203), which are long arrays rather than single points.
  • 40020 Flow control is printed as 'MB_RTU=0, MB_RTU=1' (presumably RTU/ASCII, but the source does not say), so no enum is given. 32-bit integers are given as UINT32 because the source does not mark them signed (it marks signed values explicitly elsewhere).
  • The same document also covers the BACnet MS/TP module; that part is not used here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Sontex Supercal 531 / Superstatic 440 / 449 with Modbus EIA-485 module

What Modbus registers does the Sontex Supercal 531 / Superstatic 440 / 449 with Modbus EIA-485 module have?

This map lists 79 registers: 16 discrete inputs, 46 input registers, 17 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Sontex Supercal 531 / Superstatic 440 / 449 with Modbus EIA-485 module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual says register numbering starts at 1, which is physical address 0 in the telegram, and prints Modicon-style references: 40011 is holding wire address 10, 30103 is input wire address 102, 10001 is discrete input 0. Its own Modbus Poll / ModScan screenshots use the same 30713/30103 references.

What byte order does the Sontex Supercal 531 / Superstatic 440 / 449 with Modbus EIA-485 module use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Sontex Supercal 531 / Superstatic 440 / 449 with Modbus EIA-485 module?

Start with IR 100 Energy unit (float block) (Energy unit code); IR 102 Energy totalizer heating (Energy totalizer (float)); IR 302 Volume (Volume (float)); IR 702 Power (Power (float)); IR 712 Flow (Flow (float)); IR 722 High temperature (High temperature); IR 724 Low temperature (Low temperature); DI 2 Error status: flow (Flow error flag).

How do I enable Modbus control of the Sontex Supercal 531 / Superstatic 440 / 449 with Modbus EIA-485 module?

The integrator detects the module automatically once it is plugged into a module slot; no setting is needed. Baud rate is set with DIP switch S2 (default 19200), bias and termination with DIP switch S1.

Where is the official Sontex Supercal 531 / Superstatic 440 / 449 with Modbus EIA-485 module Modbus documentation?

The source is Modbus EIA-485 Module for Supercal 531 and Superstatic 440/449 - Instructions for Use (0531P217 V05), revision 2019-09. Sontex doesn't publish it on its own website, so this map was re-typed from a free copy at https://www.neovac.ch/downloadcenter/document-a9b1ddfb-1182-446f-b1b9-132bdb729345.pdf. It may be an older revision, so check it against the live unit.
