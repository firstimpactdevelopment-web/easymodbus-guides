Short answer

Eubank EAH and EGH packaged wall-mount air conditioners (an AirX brand sold alongside Marvair) carry an electronic control board with two RJ11 Modbus RTU ports. Over Modbus the board accepts thermostat calls, reports switch, relay and sensor states and an alarm word, and exposes fan-speed, economizer and calibration settings.

This page lists 71 Modbus registers for the Eubank EAH / EGH wall-mount air conditioner control board (Modbus RTU) — 34 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Eubank’s own free documentation (linked below) and checked against it.

Integration notes: Eubank EAH / EGH wall-mount air conditioner control board (Modbus RTU)

Integration in brief

Set coil 17 = 1 (communicating mode; the map says it mirrors parameter P22), then drive the unit with the Y1/Y2/G/W2/humidity/O call coils (0-4, 24). Read temperatures, relay states, pressure switches and the alarm word (input register 18) to monitor it.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set menu item 23 (T'STAT Select) to C for a communicating thermostat via Modbus, or write coil 17 = 1 (the Modbus map says coil 17 reads and changes 'P22', the thermostat-type setting). The Modbus ID (item 24, 1-99, default 1) and baud (item 25: 9.6 or 19 = 9600/19200) are set in the board configuration menu.

Communication loss & watchdog

Register 8 / configuration item 26 sets the Modbus timeout (1-60 min, default 10). After that long without Modbus traffic the board falls back to hardware thermostat calls.

Byte order & addressing

  • Only single-coil (05) and single-register (06) writes are accepted.
  • Register reads are documented with function 04 only, including the writable ones.
  • Temperature value 255 means no sensor or a failed sensor.

Network setup

  • Default slave ID 1, 19200 baud, 8 data bits, no parity, 1 stop bit.
  • The board has two RJ11 Modbus ports wired in parallel; both carry the same bus.

Watch out for

  • Until the thermostat type is C (menu item 23, or coil 17 = 1) the board keeps following its hardwired thermostat inputs.
  • After the Modbus timeout with no traffic the board switches back to its hardware thermostat inputs, so poll faster than the timeout.

Notes on this map

  • The manual prints two columns: a zero-based 'packet register ID' (used as the address here) and a one-based reference ID. Coils and registers each start at zero-based ID 0.
  • Bit points: the board reads all of them with function 02 and writes the RW ones with function 05 (single coil only, no function 15). Coils and discrete inputs share one address space. RW bits are listed as coils, read-only bits as discrete inputs.
  • Registers: the board reads them with function 04 and writes RW ones with function 06 (single register only, no function 16). RW registers are listed as holding registers so they can be written; the manual only documents reading them with function 04 at the same address. Whether function 01/03 reads work is not stated.
  • Writes to read-only points return an error.
  • Calibration registers hold 0-18 with 9 = no correction; the applied correction is the value minus 9.
  • Heat and cool set points (registers 0-1) are writable but marked 'not currently used, for future use'.
  • Anti-short-cycle timers count in 0.5 s steps (scale 0.5).
  • This AC table runs to register 40 (head pressure cutout, fan-only speed); unlike the Marvair MAH AC manual it has no register 41. IFM Y1/Y2 speeds are 40-100 (default 60) and alarm bit 0 is 'freeze sensor fault'.
  • The configuration section gives the Modbus ID range as 1-99 in the table; the default is 1.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Eubank EAH / EGH wall-mount air conditioner control board (Modbus RTU)

What Modbus registers does the Eubank EAH / EGH wall-mount air conditioner control board (Modbus RTU) have?

This map lists 71 registers: 10 coils, 20 discrete inputs, 17 input registers, 24 holding registers. 34 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Eubank EAH / EGH wall-mount air conditioner control board (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map prints a zero-based packet ID next to a one-based reference ID (1, 2, 3...). The zero-based ID is the wire address.

What are the minimum Modbus registers to integrate the Eubank EAH / EGH wall-mount air conditioner control board (Modbus RTU)?

Start with CO 17 Communicating thermostat mode (Communicating (Modbus) thermostat mode); CO 0 Y1 compressor call (Y1 cooling call); CO 3 G fan call (G fan call); DI 13 Compressor 1 relay output (Compressor 1 relay state); IR 18 Alarm status (Alarm status bits); IR 14 P1 temperature (P1 temperature); IR 27 Outdoor temperature (Outdoor temperature); HR 8 Modbus timeout (Modbus timeout (minutes)).

How do I enable Modbus control of the Eubank EAH / EGH wall-mount air conditioner control board (Modbus RTU)?

Set menu item 23 (T'STAT Select) to C for a communicating thermostat via Modbus, or write coil 17 = 1 (the Modbus map says coil 17 reads and changes 'P22', the thermostat-type setting). The Modbus ID (item 24, 1-99, default 1) and baud (item 25: 9.6 or 19 = 9600/19200) are set in the board configuration menu.

What happens when the Eubank EAH / EGH wall-mount air conditioner control board (Modbus RTU) loses Modbus communication?

Register 8 / configuration item 26 sets the Modbus timeout (1-60 min, default 10). After that long without Modbus traffic the board falls back to hardware thermostat calls.
