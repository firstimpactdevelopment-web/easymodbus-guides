AutomationDirect GS1 series AC drive Modbus register map

Updated 17 November 2026

Short answer

The GS1 is an AutomationDirect AC drive with a built-in RS-485 port running Modbus ASCII or RTU. Drive parameters P0.00-P9.xx map to holding registers (parameter group x 256 + number), and read-only status registers at 2100h report fault code, run state, frequencies, voltages and load. This map covers the status block and the P9 serial control parameters used to run the drive over Modbus.

This page lists 22 Modbus registers for the AutomationDirect GS1 series AC drive — 11 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from AutomationDirect’s own free documentation (linked below) and checked against it.

Integration notes: AutomationDirect GS1 series AC drive

Integration in brief

Set P9.02 to an RTU mode, P3.00 to serial operation and P4.00 = 5 for serial frequency source, then write speed (P9.26, x10) and run (P9.27). Monitor Status Monitor 1/2 and output frequency at 2100h-2103h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set P3.00 (source of operation) to 3 or 4 and P4.00 (source of frequency) to 5 for serial control, as referenced in Status Monitor 2; set P9.00-P9.02 for address, baud and protocol from the keypad.

Communication loss & watchdog

P9.04 enables communication time-out detection, P9.05 sets the time (0.1-60.0 s) and P9.03 selects the reaction (keep running, ramp stop, coast stop).

Byte order & addressing

  • Factory protocol is Modbus ASCII, not RTU.
  • Speed reference has an implied decimal: write 600 for 60.0 Hz.
  • Hex addresses are wire addresses: 091Ah = 2330 decimal = 42331 Modicon.

Network setup

  • P9.00 address (default 1), P9.01 baud (default 9600), P9.02 protocol/format.
  • Writes to P0-P8 parameters can be grouped through the block transfer parameters P9.11 onward.

Watch out for

  • Some faults only show in Status Monitor 1 after a hard trip; warnings may not appear there.

Notes on this map

  • AutomationDirect's own manual chapter (cdn.automationdirect.com).
  • Parameter-to-register rule: Px.yy is at hex x*256 + yy (e.g. P9.26 = 091Ah = 42331); the full list is in the chapter's parameter address tables. Only the P9 communication/control parameters are included here.
  • Status values marked XXX.X in the manual carry one implied decimal (scale 0.1).
  • Scale Frequency is split into low word (2108h) and high word (2109h), so it is listed as a 32-bit value with the low word first (CDAB); its unit depends on P8.01.
  • P9.05 (communication time-out, 0.1-60.0 s) is left out because its raw encoding is not stated in this chapter.
  • The factory protocol (P9.02 = 0) is Modbus ASCII 7N2; set 3, 4 or 5 for RTU.
  • Speed reference scaling: the manual's example frame 01 10 09 1B 00 02 04 02 58 00 01 writes 0258h (600) for 60 Hz. That frame starts at 091Bh although the parameter table and the CLICK example put P9.26 at 091Ah (42331); the table address is used here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the AutomationDirect GS1 series AC drive

What Modbus registers does the AutomationDirect GS1 series AC drive have?

This map lists 22 registers: 22 holding registers. 11 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the AutomationDirect GS1 series AC drive Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists each register in hex and as a Modicon number: hex 0000h = 40001, 2100h = 48449. The hex value is the wire address. CLICK PLCs need a six-digit form (402331 instead of 42331).

What byte order does the AutomationDirect GS1 series AC drive use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the AutomationDirect GS1 series AC drive?

Start with HR 2330 P9.26 Serial Comm Speed Reference (Speed reference); HR 2331 P9.27 Serial Comm RUN Command (Run/stop); HR 2332 P9.28 Serial Comm Direction Command (Direction); HR 8448 Status Monitor 1 (Fault code); HR 8449 Status Monitor 2 (Run state bits); HR 8451 Output Frequency H (Output frequency).

How do I enable Modbus control of the AutomationDirect GS1 series AC drive?

Set P3.00 (source of operation) to 3 or 4 and P4.00 (source of frequency) to 5 for serial control, as referenced in Status Monitor 2; set P9.00-P9.02 for address, baud and protocol from the keypad.

What happens when the AutomationDirect GS1 series AC drive loses Modbus communication?

P9.04 enables communication time-out detection, P9.05 sets the time (0.1-60.0 s) and P9.03 selects the reaction (keep running, ramp stop, coast stop).

Where is the official AutomationDirect GS1 series AC drive Modbus documentation?

The source is GS1 Series AC Drives User Manual - Chapter 5: Communications (GS1-M 3rd Ed., Rev.B (chapter 5)), published free by AutomationDirect at https://cdn.automationdirect.com/static/manuals/gs1m/ch5.pdf.
