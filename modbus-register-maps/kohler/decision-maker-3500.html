Short answer

The Decision-Maker 3500 is a Kohler generator set controller whose map also carries bus, synchronizing and generator management data. Its Modbus RTU map reports generator and bus electrical values as percentages of the set's ratings, engine data, run-time counters, genset state and master switch position, plus event logs and configuration. This map covers the electrical, engine, run-time, rating and status registers.

This page lists 67 Modbus registers for the Kohler Decision-Maker 3500 generator set controller — 5 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Kohler’s own free documentation (linked below) and checked against it.

Integration notes: Kohler Decision-Maker 3500 generator set controller

Integration in brief

Read 400001-400039 for generator electrical values and 400059-400076 for engine data, then multiply the percentages by the ratings at 400105-400109 to get volts, amps and kW. Watch 400652 for genset state and 400653 for the master switch position.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Use Kohler SiteTech to set the Modbus address (1-247, unique per unit) and baud rate (9600, 19200, 38400 or 57600) on the controller.

Byte order & addressing

  • Electrical values are percent of rating, not engineering units.
  • Counters use LW/HW register pairs (low word first).
  • 0xFFC0 in any register means unsupported in this application.

Network setup

  • Serial format is 8 data bits, no parity, 1 stop bit.
  • Read 409999 = 49 to confirm the controller type.

Watch out for

  • Maximum 50 registers per read and 16 per write; do not start a block read on an undefined register.

Notes on this map

  • Generator and bus voltages, currents and powers are reported as percent of the set's rated values (x100), not volts, amps or kW. Rated current is at 400108 and the kW rating at 400109; the rated voltage is the system voltage at 400105.
  • 32-bit UDINT counters are split into an LW register followed by an HW register, so they are listed CDAB.
  • Left out: 400087-400088 (the low word is labelled controller total operation time while the high word is labelled unloaded hours), per-phase reactive and apparent power, phase angles, speed/voltage bias, the voltage/resistance/digital channel configuration blocks, time delays, protective relay and synchronizer settings, load management, generator management, event logs and the ID strings.
  • Invalid-data flags: 0xFFC0 = register not supported in this application; 0x7FE0-0x7FFF = supported but the value is unknown (for example ECM sensors with the ECM unpowered).
  • Registers marked in the manual as needing firmware 1.4 or later return errors on older firmware.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Kohler Decision-Maker 3500 generator set controller

What Modbus registers does the Kohler Decision-Maker 3500 generator set controller have?

This map lists 67 registers: 67 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Kohler Decision-Maker 3500 generator set controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints 6-digit holding-register references (400001 = first holding register; 409999 is register 49999 in 5-digit form), so 400001 is wire address 0 and 400652 is wire address 651.

What byte order does the Kohler Decision-Maker 3500 generator set controller use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Kohler Decision-Maker 3500 generator set controller?

Start with HR 3 Generator Voltage L-L Average (Generator L-L average voltage, % of rated); HR 11 Generator Current Average (Generator average current, % of rated); HR 12 Generator Frequency (Generator frequency); HR 16 Generator Total Real Power (Total real power, % of rated kW); HR 60 Engine Speed (Engine speed); HR 61 Battery Voltage (Battery voltage); HR 651 Status (Genset state); HR 652 Master Switch Position (Master switch position).

How do I enable Modbus control of the Kohler Decision-Maker 3500 generator set controller?

Use Kohler SiteTech to set the Modbus address (1-247, unique per unit) and baud rate (9600, 19200, 38400 or 57600) on the controller.

Where is the official Kohler Decision-Maker 3500 generator set controller Modbus documentation?

The source is Modbus Communications Protocol Operation (generator set, transfer switch and power monitor controllers) (TP-6113 12/21p), revision 2021-12, published free by Kohler at https://resources.kohler.com/power/kohler/industrial/pdf/tp6113.pdf.
