Short answer

The Alber MPM-100 and BDS monitor stationary battery strings: cell voltages, intercell and intertier resistances, string voltage, currents, temperatures and alarms. They speak Modbus ASCII (7 data bits, 2 stop bits, 9600 baud) with functions 03 and 16; values are 16-bit integers with power-of-two scaling. This map covers representative cell voltage and resistance registers, overall voltage, time-to-go, system status, the firmware command register and configuration basics.

Integration notes: Vertiv (Alber) Alber MPM-100 and BDS series battery monitors (Modbus ASCII)

Integration in brief

Poll with Modbus ASCII function 03 at 9600 baud, 7 data bits, no parity, 2 stop bits; read cell voltages from 0000H and string values from 0400H, applying the power-of-two scaling.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus ASCII is the monitor's native protocol; set the master to ASCII mode.

Byte order & addressing

  • ASCII framing with 7 data bits and 2 stop bits.
  • Power-of-two scaling on voltages and resistances.
  • Temperatures are sign-magnitude, not two's complement.

Network setup

  • 9600 baud, 7 data bits, no parity, 2 stop bits.
  • MPM address 01H; BDS string n = address n.

Watch out for

  • Alarm reset and tests are commands written to 41542 (data address 0605H).

Notes on this map

  • Left out: discharge time (41026), the battery amp-hour rows (41818-41825) and amp-hours remaining #1-#4 (41137, 41139, 41141, 41143). All are marked '(High - Low)' and the list does not explain whether that means two registers or a split value, so size or encoding is not settled.
  • Scaling comes from the data transformation table: overall voltage / 2^4, cell voltage / 2^10, intertier resistance x 10^3 / 2^11, intercell resistance x 10^3 / 2^13. Scales are written here as decimals (0.0625, 0.0009765625, 0.48828125, 0.1220703125).
  • Left out: currents (scaled by the shunt value or a float-current constant), internal cell resistance (model-dependent RConstant), and temperatures, which use sign-and-magnitude encoding (bit 15 = negative) divided by 128 or by 45 depending on DCM/MPM firmware.
  • Only the first, second and last cell voltage and the first/last intercell rows are listed; the rest follow at one register per cell.
  • Device address: MPM is 01H; BDS strings 1-16 are 01H-10H.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Vertiv (Alber) Alber MPM-100 and BDS series battery monitors (Modbus ASCII)

What Modbus registers does the Vertiv (Alber) Alber MPM-100 and BDS series battery monitors (Modbus ASCII) have?

This map lists 19 registers: 19 holding registers. 2 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vertiv (Alber) Alber MPM-100 and BDS series battery monitors (Modbus ASCII) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row gives a 4xxxx reference and the hex data address used in the frame: Cell Voltage 1 is reference 40001 at data address 0000H, overall voltage is 41025 at 0400H. Wire address = reference - 40001.

What are the minimum Modbus registers to integrate the Vertiv (Alber) Alber MPM-100 and BDS series battery monitors (Modbus ASCII)?

Start with HR 0 Cell voltage 1 (Cell voltage 1); HR 1024 Overall voltage (Overall string voltage); HR 1135 Time-to-go #1 (Time-to-go); HR 1540 System status (System status bits); HR 1152 Alarm type of first current alarm (First active alarm).

How do I enable Modbus control of the Vertiv (Alber) Alber MPM-100 and BDS series battery monitors (Modbus ASCII)?

Modbus ASCII is the monitor's native protocol; set the master to ASCII mode.
