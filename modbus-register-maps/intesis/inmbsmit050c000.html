Integration notes: Intesis (HMS Networks) INMBSMIT050C000 / INMBSMIT100C000 Mitsubishi Electric City Multi centralised controller to Modbus gateway

Integration in brief

Point the gateway at the centralised controller(s) in Intesis MAPS, import the groups, send the project, then poll each group's 100-register block for on/off, mode, fan, vane and errors.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The centralised controller XML interface must be active (it may need a licence from Mitsubishi Electric) and the groups must be configured in MAPS (unit type per group).

Byte order & addressing

  • Every register is a 16-bit signed integer; there are no 32-bit values (unless stated in this file).
  • Read with FC03 or FC04; write with FC06 or FC16.
  • Undefined addresses in the 0..20000 poll range read back 0; the manual also says invalid addresses return a Modbus exception code.
  • Controller command registers (cc x 30 + 1..25) are write-only broadcasts to every group of that controller.

Network setup

  • All Modbus settings (RTU slave number, baud 1200..115200, parity, stop bits, RS-485 or RS-232, TCP port, IP) are set with the Intesis MAPS tool over the USB console port or Ethernet.
  • Factory IP is 192.168.100.246 with DHCP enabled.
  • Modbus RTU and Modbus TCP can be used at the same time.
  • Port B carries Modbus RTU on B1, B2 and B3 (SGND). The manual prints the B1/B2 polarity both ways in two sections, so check the terminal label. The gateway has built-in bias and termination; do not add another resistor at its end of the bus.
  • The centralised controller(s) must be reachable over Ethernet from the gateway.

Watch out for

  • Some permission registers only work when MAPS 'Old Model Compatibility' is set to New model; setback control needs EB-50GU or AE-200 and newer.

Notes on this map

  • Only controller 0 and its group 1 are listed. Group g on controller cc: add ((cc x 50) + g - 1) x 100 (cc 0 group 2 on/off = 200; cc 1 group 1 = 5100). Controller 1 signals: add 30.
  • All temperature registers are left out (all-group setpoint cc x 30 + 25, group setpoint +4, ambient +5, setpoint restrictions +21..+26, multiple setpoints +27..+31, outdoor temperature +35): setpoints are printed as whole '°C' yet with half-degree ranges such as 4.5..35 °C, and ambient is printed '°C/x10°C' with a 0.0..99.9 range, so the scale cannot be fixed from the document.
  • Mode, fan and setpoint registers have different meanings for Lossnay (LC), ATW booster/HEX and CEh heat-pump groups; only indoor-unit (IC) codes are decoded. Lossnay mode: 0 LC Auto, 1 Heat Recovery, 2 Bypass. ATW/HWHP mode: 0 Hot water, 1 Heating, 2 Heating Eco, 3 Anti-freeze, 4 Cooling.
  • The IC fan-speed value list is printed as '0-Auto, 1-Low, 2-Mid-1, 3-Mid-2, 2-Mid2, 3-Mid1, 4-High', which assigns 2 and 3 twice; only 0, 1 and 4 are decoded. The Lossnay fan list is equally garbled and is not decoded.
  • Which registers exist depends on the unit type selected in MAPS (IC, LC, FU, BU, WH, CEh); the manual's applicability matrix is not reproduced.
  • Brightness and occupancy (+33 / +34) carry the same 'Setpoint Type = Multiple Setpoint' availability note as the setpoint rows in the manual.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. What Modbus registers does the Intesis (HMS Networks) INMBSMIT050C000 / INMBSMIT100C000 Mitsubishi Electric City Multi centralised controller to Modbus gateway have?

Are the Intesis (HMS Networks) INMBSMIT050C000 / INMBSMIT100C000 Mitsubishi Electric City Multi centralised controller to Modbus gateway Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual states formula results are link-layer addresses with the first register at 0. Controller signals: cc x 30 + signal; group signals: ((cc x 50) + g) x 100 + signal, with cc = 0 or 1 and g = group 1..50. This file lists cc = 0 (0..24) and cc 0 group 1 (100..137).
