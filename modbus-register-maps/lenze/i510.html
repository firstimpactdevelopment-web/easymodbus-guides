Lenze i510 cabinet inverter 0.25-2.2 kW (Modbus RTU) Modbus register map

Updated 17 November 2026

Short answer

Lenze's i510 is a compact cabinet frequency inverter whose Modbus/CANopen control unit acts as a Modbus RTU slave. Besides 24 freely mappable registers, it has fixed blocks: status data from 42001 and control data from 42101. This map covers those predefined registers: AC drive control and status words, frequency setpoint and actual frequency, drive status, error code, motor voltage and current, apparent power, temperatures, DC bus and torque.

This page lists 17 Modbus registers for the Lenze i510 cabinet inverter 0.25-2.2 kW (Modbus RTU) — 6 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lenze’s own free documentation (linked below) and checked against it.

Integration notes: Lenze i510 cabinet inverter 0.25-2.2 kW (Modbus RTU)

Integration in brief

Set the front selector to Modbus, activate the network (0x2631:037 = TRUE) and make the network the setpoint source (0x2860:001 = 5). Write 0x0061 to 42101 (run forward + control and reference from network) and the frequency to 42102 in 0.01 Hz; read 42001-42011 for status and measurements.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the Modbus/CANopen selector on the inverter front to Modbus. Set 0x2631:037 (PAR 400/037) Activate network = TRUE and 0x2860:001 (PAR 201/001) = 5 Network. Set node address 0x2321:001 (1-247, default 1), baud 0x2321:002 and data format 0x2321:003 (both default Automatic), then restart Modbus communication (0x2320 = 1) or power-cycle.

Communication loss & watchdog

0x2858:002 Time-out (0.0-300.0 s, default 2.0 s) with 0x2858:001 Response to time-out (default Error).

Byte order & addressing

  • Register 42101 is sent as address 2100 (0x0834).
  • The frequency setpoint and actual frequency are unsigned; direction comes from control word bits 0/1 and status bits 2/3.
  • With automatic baud rate or data format detection the first 5-10 messages after power-up are lost.
  • Digital input DI1 is 'Start enable' by default and must be high for the drive to start.

Network setup

  • Baud 2400-115200 or automatic; data format 8E1, 8O1, 8N2 or automatic.
  • A minimum response delay can be set in 0x2321:004 (0-1000 ms).

Watch out for

  • The manual's example: writing 0x0061 to 42101 on node 1 starts the drive if DI1 is high.
  • MOD-ERR LED blinking = communication error; MOD-RUN and MOD-ERR flickering = automatic baud detection still running.

Notes on this map

  • This copy is hosted by the US distributor Precision Electric and is the unaltered Lenze commissioning manual; Lenze's own copy sits in its download portal and was not found as a direct public link.
  • Data types and scaling come from the parameter attribute list (data type and network factor: the integer read is divided by the factor, e.g. factor 10 -> scale 0.1).
  • Apparent power 42008/42009 is a 32-bit signed value; the register table states 42008 = high word and 42009 = low word (ABCD), factor 1000 (kW as printed).
  • Left out: 42012 digital inputs (0x60FD is a 32-bit parameter but only one register is assigned, so which half is sent is unclear); 42103 and 42104, because the register table gives 42103 as NETWordIN2 with address 0x4008:003 (which the attribute list calls NETWordIN3) and repeats 0x400B:001 for 42104.
  • The 24 freely mappable registers (0x232B:1-24, internal register numbers from 2500 shown in 0x232C) are not listed; their content depends on configuration.
  • Only function codes 3, 6, 16 and 23 are supported; all data are holding registers. Data are big-endian (most significant byte first).

Questions about the Lenze i510 cabinet inverter 0.25-2.2 kW (Modbus RTU)

What Modbus registers does the Lenze i510 cabinet inverter 0.25-2.2 kW (Modbus RTU) have?

This map lists 17 registers: 17 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lenze i510 cabinet inverter 0.25-2.2 kW (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual states all data are 4X registers numbered from 1 but addressed from 0, so register 40001 is address 0; its example writes register 42101 to address 2100 (0x0834). So 42001 = wire 2000 and 42101 = wire 2100.

What byte order does the Lenze i510 cabinet inverter 0.25-2.2 kW (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lenze i510 cabinet inverter 0.25-2.2 kW (Modbus RTU)?

Start with HR 2100 AC Drive control word (0x400B:001) (AC Drive control word (start/stop/reset)); HR 2101 Network setpoint frequency (0x400B:005) (Frequency setpoint, 0.01 Hz); HR 2000 AC Drive status word (0x400C:001) (AC Drive status word); HR 2001 Actual frequency (0x400C:006) (Actual frequency, 0.01 Hz); HR 2002 Error code (0x603F) (Error code); HR 2005 Actual motor current (0x2D88) (Motor current, 0.1 A); HR 2010 DC-bus voltage (0x2D87) (DC-bus voltage).

How do I enable Modbus control of the Lenze i510 cabinet inverter 0.25-2.2 kW (Modbus RTU)?

Set the Modbus/CANopen selector on the inverter front to Modbus. Set 0x2631:037 (PAR 400/037) Activate network = TRUE and 0x2860:001 (PAR 201/001) = 5 Network. Set node address 0x2321:001 (1-247, default 1), baud 0x2321:002 and data format 0x2321:003 (both default Automatic), then restart Modbus communication (0x2320 = 1) or power-cycle.

What happens when the Lenze i510 cabinet inverter 0.25-2.2 kW (Modbus RTU) loses Modbus communication?

0x2858:002 Time-out (0.0-300.0 s, default 2.0 s) with 0x2858:001 Response to time-out (default Error).
