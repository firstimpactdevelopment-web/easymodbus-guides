Short answer

WebMaster controllers manage cooling tower and boiler water chemistry. The Modbus TCP/IP option makes the controller a Modbus TCP server on port 502 with read (FC3) and write (FC6/FC16) of holding registers. This map covers the header strings, the live sensor, analog input, digital input and analog output values, and the writable alarm set points of the four direct sensor inputs.

Integration notes: Walchem WebMaster / WebMaster ONE (WM1) Modbus TCP/IP option

Integration in brief

Connect to port 502 with unit ID 1, read holding registers with FC3 in blocks of up to 125, and decode floats as CDAB. Poll no faster than every 4 seconds; set points are written as 2-register CDAB floats with FC16.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The Modbus TCP/IP option must be installed/enabled on the WebMaster; set point writes need software v14 or higher.

Communication loss & watchdog

An idle TCP connection is closed after 1 minute of inactivity; up to 10 connections are accepted.

Byte order & addressing

  • Addresses are 1-based: subtract 1.
  • Floats are word-swapped (CDAB).
  • Unit ID 0 is treated as broadcast and gets no reply.

Network setup

  • Network settings are configured through the WebMaster browser interface.
  • Read up to 125 registers per request.

Watch out for

  • Data refreshes every 4 seconds; faster polling only returns the same values.
  • Modbus RTU is not supported; serial masters need a TCP gateway.

Notes on this map

  • Floats use Walchem's 'float inverse' format: the two words are swapped, so 5000.0 (0x459C4000) arrives as 0x4000 0x459C - low word first (CDAB).
  • Digital input states are single bits: the manual's 'register/bit' notation counts bits 1-16 from the least significant bit, so '/1' is bit 0 and '/9' is bit 8 here.
  • Left out: the status, relay hand-off-auto and relay output state registers (2002-2144). The manual calls them 32-bit integers but lists a size of 1 word and an example that reads 1 register, so the register that holds the value is unclear.
  • Left out: the bit-packed alarm registers (1001-1058); several alarm rows share registers with different bit positions per hardware variant and could not be transcribed reliably.
  • Left out: analog input, digital input, analog output and relay set points (20001+, 20881+, 23601+, relay tables) - their meaning depends on the configured input/output type.
  • Values only exist for hardware that is installed; e.g. analog inputs need the analog input card and DI_A..DI_F depend on the controller variant.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Walchem WebMaster / WebMaster ONE (WM1) Modbus TCP/IP option

What Modbus registers does the Walchem WebMaster / WebMaster ONE (WM1) Modbus TCP/IP option have?

This map lists 128 registers: 128 holding registers. 40 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Walchem WebMaster / WebMaster ONE (WM1) Modbus TCP/IP option Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Sections 4.5.1 and 4.6.1 state that the published addresses are 1-based and the packet is 0-based; subtract 1 on the wire (sensor 1 calibrated value 3001 / 43001 is wire address 3000).

What byte order does the Walchem WebMaster / WebMaster ONE (WM1) Modbus TCP/IP option use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Walchem WebMaster / WebMaster ONE (WM1) Modbus TCP/IP option?

Start with HR 3000 Sensor input 1 calibrated value (Sensor input 1 calibrated value); HR 3002 Sensor input 2 calibrated value (Sensor input 2 calibrated value); HR 3048 Sensor input 1 temperature calibrated value (Sensor input 1 temperature); HR 3096 Analog input 1 scaled value (Analog input 1 scaled value); HR 3321 Digital input states (3322) (Digital input states (DI_C / DI_1)); HR 20642 Sensor input 1 low alarm (Sensor input 1 low alarm set point); HR 20644 Sensor input 1 high alarm (Sensor input 1 high alarm set point).

How do I enable Modbus control of the Walchem WebMaster / WebMaster ONE (WM1) Modbus TCP/IP option?

The Modbus TCP/IP option must be installed/enabled on the WebMaster; set point writes need software v14 or higher.

What happens when the Walchem WebMaster / WebMaster ONE (WM1) Modbus TCP/IP option loses Modbus communication?

An idle TCP connection is closed after 1 minute of inactivity; up to 10 connections are accepted.
