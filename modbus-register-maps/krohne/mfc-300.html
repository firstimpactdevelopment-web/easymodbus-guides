Short answer

The MFC 300 is a KROHNE signal converter for Coriolis mass flowmeters. With the Modbus option it is an RS-485 Modbus RTU slave. This map covers mass and volume flow, density, temperature, concentration and diagnosis floats, the double-float counters, counter and calibration parameters, serial settings and the control coils.

Integration notes: KROHNE MFC 300 Coriolis mass flow converter (Modbus RTU)

Integration in brief

Read input registers 30000-30027 (function 04) for flow, density and temperature floats and 30050-30061 for the double-float counters. Use coils 3000-3005 to start, stop and reset counters.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set address, baud rate, parity, data format and stop bits in converter menu C6.8.

Byte order & addressing

  • Protocol addresses are sent as printed.
  • Temperature is in kelvin.
  • Counters are 64-bit doubles.

Network setup

  • Defaults 19200 baud, even parity, 1 stop bit, address 1.
  • Bus termination and biasing are off by default; set jumpers X5/X6 on the Modbus board to enable them.

Watch out for

  • New calibration values take effect after a warm start (coil 1001).

Notes on this map

  • Data format is selectable in converter menu C6.8; the default is Big Endian, which section 6.2 defines as MSB first, so floats and doubles are listed ABCD. The register table for 50004 pairs the labels the other way round (see below), so check one known value (for example 30000 at zero flow, or the baud rate at 50000) before trusting a new installation.
  • Left out: the data-format register 50004, because its printed coding contradicts itself (0 = Little Endian 'MSB first', 1 = Big Endian 'LSB first'); set data format at the converter menu instead.
  • Left out: long status sensor/device (30062 / 30064, byte[4]) because their bits are not defined here.
  • Counter 3 and its parameters exist only on converters with the IO2 option; writing to a missing counter returns an error.
  • Factory serial settings: address 1, 19200 baud, even parity, 1 stop bit.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the KROHNE MFC 300 Coriolis mass flow converter (Modbus RTU)

What Modbus registers does the KROHNE MFC 300 Coriolis mass flow converter (Modbus RTU) have?

This map lists 68 registers: 13 coils, 18 input registers, 37 holding registers. 50 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the KROHNE MFC 300 Coriolis mass flow converter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists protocol addresses that go into the request unchanged: input register 30006 is requested as start address 30006 (0x7536).

What byte order does the KROHNE MFC 300 Coriolis mass flow converter (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the KROHNE MFC 300 Coriolis mass flow converter (Modbus RTU)?

Start with IR 30004 Mass flow (Mass flow); IR 30002 Volume flow (Volume flow); IR 30008 Density (Density); IR 30006 Temperature (Temperature); IR 30050 Counter 1 (Counter 1).

How do I enable Modbus control of the KROHNE MFC 300 Coriolis mass flow converter (Modbus RTU)?

Set address, baud rate, parity, data format and stop bits in converter menu C6.8.
