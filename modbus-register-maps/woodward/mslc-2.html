Woodward MSLC-2 Master Synchronizer and Load Control Modbus register map

Updated 17 November 2026

Short answer

The MSLC-2 sits at the utility tie or bus breaker of a DSLC-2 generator plant: it synchronises the plant bus to the utility and runs import/export, base-load and process control for the DSLC-2 units. It is a Modbus RTU slave on RS-485 and a Modbus/TCP slave on Ethernet. Measurements and states come from data protocol 5200 at Modicon 450001; interface setpoints and remote discrete-input commands are parameters. This map covers system A/B frequencies and phase angle, 32-bit system A power, voltage and current, energy, control modes, flags, alarms, relays and inputs.

This page lists 69 Modbus registers for the Woodward MSLC-2 Master Synchronizer and Load Control — 6 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Woodward’s own free documentation (linked below) and checked against it.

Integration notes: Woodward MSLC-2 Master Synchronizer and Load Control

Integration in brief

Block-read up to 128 holding registers from wire address 50000 for frequencies, phase angle, modes, flags and alarms, and from 50100 for 32-bit system A power, voltages and currents. Release functions to the interface in 7645, switch them in 7644, and write setpoints to 7640-7642 and 7780.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

RS-485 (serial interface 2): Modbus slave ID 3188 (default 1; 0 disables Modbus), baud 3170 (default 19.2 kBd), parity 3171 (default none), stop bits 3172 (default one). Network A/B Modbus/TCP slave IDs are 5351/5451 (default 255).

Communication loss & watchdog

No timeout parameter is given. After an interface connection loss the discrete-input states stay as they were; energising DI 22 'Modbus reset' hands all functions back to hardware control and clears the control bits.

Byte order & addressing

  • Some PLCs need the address shifted by one; the manual notes 450001 may become bus address 50000.
  • 32-bit parameters such as 7642 and 7780 are written as two registers in one request, high word first.

Network setup

  • Network A default IP 192.168.0.33 and network B default 192.168.1.33 (parameters 5330-5333 / 5430-5433); Woodward recommends the MSLC-2 device number (33-48) as the last octet.
  • RS-485 reply delay is parameter 3189 (0.00-2.55 s).

Watch out for

  • Releasing Run/Permissive to the interface lets the PLC close the utility tie breaker through synchronisation; test carefully.
  • CB Aux and Modbus reset stay hardware controlled even when released in 7645.

Notes on this map

  • The 5200 table states size (16/32 bit) and format (signed / bit array) for each value. The shared DSLC-2/MSLC-2 Modbus chapter says 32-bit values are sent high word at the lower address, so 32-bit values are ABCD.
  • System A is the utility / mains side and system B the plant bus side as used throughout the MSLC-2 manual.
  • Left out: the 16-bit power, voltage and current values at 50011-50031 (scaled by exponent registers 50001-50003; use the 32-bit block from 50100), values with only a range instead of a multiplier (AI4-AI6, process and PF references, ASA/CBS numbers) and unnamed bits.
  • Load and reactive load control mode enums are printed for both MSLC-2 and DSLC-2; only the MSLC-2 meanings are listed here.
  • Interface setpoints need no password but only take effect when their setpoint-source parameter (7634, 7635, 7783, 7784) is set to Interface.
  • Bits of 7644/7645 in manual order 01-16: Check, Permissive, Run, CB Aux, Voltage raise, Voltage lower, Base load, Utility unload, Ramp pause, Setpoint raise, Setpoint lower, Process, Imp./Exp. control, Modbus reset, System update, N/A. The manual does not say whether bit 01 is the least significant bit.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Woodward MSLC-2 Master Synchronizer and Load Control

What Modbus registers does the Woodward MSLC-2 Master Synchronizer and Load Control have?

This map lists 69 registers: 69 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Woodward MSLC-2 Master Synchronizer and Load Control Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The 5200 table prints both the bus address (50000) and the Modicon address (450001); this map records and sends the bus address. Parameters use Modicon 40000 + (parameter ID + 1), so parameter 7642 is Modicon 47643 = wire address 7642. The manual's ModScan32 screenshot for parameter 7642 uses address 7643 (1-based), which confirms this; its worked example prints '407642', a typo that does not follow the rule.

What byte order does the Woodward MSLC-2 Master Synchronizer and Load Control use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Woodward MSLC-2 Master Synchronizer and Load Control?

Start with HR 50010 System A frequency (System A (utility) frequency); HR 50023 System B frequency (System B (bus) frequency); HR 50032 Phase Angle System A / System B (Phase angle A / B); HR 50056 Sync Control State (Synchronizer state); HR 50057 Load Control Mode (Load control mode); HR 50075 Alarms 1 (Alarms 1); HR 50100 Total System A power (Total system A power (32-bit)); HR 50156 P Sum (P sum).

How do I enable Modbus control of the Woodward MSLC-2 Master Synchronizer and Load Control?

RS-485 (serial interface 2): Modbus slave ID 3188 (default 1; 0 disables Modbus), baud 3170 (default 19.2 kBd), parity 3171 (default none), stop bits 3172 (default one). Network A/B Modbus/TCP slave IDs are 5351/5451 (default 255).

What happens when the Woodward MSLC-2 Master Synchronizer and Load Control loses Modbus communication?

No timeout parameter is given. After an interface connection loss the discrete-input states stay as they were; energising DI 22 'Modbus reset' hands all functions back to hardware control and clears the control bits.
