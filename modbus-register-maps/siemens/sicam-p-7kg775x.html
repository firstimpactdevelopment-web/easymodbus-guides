Short answer

SICAM P is a panel power meter and power-quality monitor with an RS-485 Modbus slave (RTU or ASCII) on a 9-pin D-sub socket. Every measured value occupies two holding registers and is sent as an IEEE float by default. This map covers device identity, the format switch, time sync, binary I/O and command bits, all measured values, the 5th-19th and 2nd/3rd/21st harmonics, energy values, alarm counters and analog I/O.

Integration notes: Siemens SICAM P power meter (Modbus RTU/ASCII)

Integration in brief

Set the Modbus address, baud and parity on the device, then read holding registers (FC 03) from 40201 (wire 200) in float format. Values come as big-endian floats, two registers each; keep 40050 at 0 unless you want scaled integers.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The Modbus serial interface is a hardware variant of the meter. Slave address (1-247), baud, parity and RTU/ASCII mode are set in the device parameters (on the device or with SICAM P PAR).

Byte order & addressing

  • Modicon numbering: subtract 40001 for the wire address.
  • Floats are high word first (ABCD).
  • Register 40050 switches all measured values between float and 16-bit integer; the setting survives power-off.
  • Max 125 registers per read in RTU (60 in ASCII).

Network setup

  • Slave address 1-247; 300-115200 baud; parity even/odd/none in RTU (even/odd only in ASCII per the technical data); always 1 stop bit.
  • RS-485 on a 9-pin D-sub: pin 3 = A, pin 8 = B, pin 5 = GND, pin 6 = +5 V for termination.
  • Up to 32 devices per segment without repeaters.

Watch out for

  • Writing a read-only register returns exception 03, not 02.
  • Switch binary outputs by read-modify-write of 40129; only outputs with no assigned function can be controlled.
  • Time sync (40065-40068) must be written with FC 16 as a broadcast.

Notes on this map

  • Word order: the manual says the lower register of a multi-register value holds the most significant byte, so floats and the unsigned-long alarm counters are high word first (ABCD).
  • All float registers assume the default float format (40050 = 0). In integer format only the first register of each pair is used and the value must be multiplied by a range-dependent factor (table 5-1, which depends on the measuring ranges and CT/VT setup); that mode is not mapped.
  • Energy values are listed with data type 'measured value', so in float mode they are floats in Wh/varh/VAh.
  • Bits 2-5 of 40129 are BO3-BO6, but which output each bit drives depends on which RO/BO modules are fitted in slots A and B (four layouts in the manual); check the table on pp. 24-25 for your hardware.
  • Only rows printed individually are listed for harmonic block 2. The 4th-20th harmonic voltages (40512-40612) and currents (40632-40732) are printed only as ranges, so they are left out.
  • The harmonic currents of block 1 (5th-19th) are in A; the harmonic currents of block 2 (2nd, 3rd, 21st) are printed in %.
  • Left out: serial number 40020-40030 (the printed range is 11 registers for a 20-character string), and the limit-value group parameters 41000-41209 (packed byte fields; needs the full table on pp. 36-42).
  • Analog inputs AI_A12 to AI_D34 depend on fitted AI modules; on 7KG775x only slot A. Only AO_A12/AO_A34 (40967/40969) are writable.
  • Broadcast (address 0) is accepted for FC 06 and FC 16 writes, not for reads.

Questions about the Siemens SICAM P power meter (Modbus RTU/ASCII)

What Modbus registers does the Siemens SICAM P power meter (Modbus RTU/ASCII) have?

This map lists 164 registers: 164 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Siemens SICAM P power meter (Modbus RTU/ASCII) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints Modicon holding-register numbers (40001, 40201...). Subtract 40001 for the wire address: 40201 (voltage L1-N) is requested as address 200. Bit-coded registers are printed as 'register / 2^n', meaning bit n of that register.

What byte order does the Siemens SICAM P power meter (Modbus RTU/ASCII) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Siemens SICAM P power meter (Modbus RTU/ASCII)?

Start with HR 200 Voltage UL1-N (Voltage L1-N); HR 208 Current IL1 (Current L1); HR 232 Active power P total (Total active power); HR 264 Power factor total (Total power factor); HR 274 Frequency (Frequency); HR 822 Active energy total (Total active energy); HR 49 Measured value format (Measured value format (float/integer)).

How do I enable Modbus control of the Siemens SICAM P power meter (Modbus RTU/ASCII)?

The Modbus serial interface is a hardware variant of the meter. Slave address (1-247), baud, parity and RTU/ASCII mode are set in the device parameters (on the device or with SICAM P PAR).
