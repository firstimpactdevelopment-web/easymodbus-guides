Short answer

The Lovato FFL700DP and FFL800DP are diesel engine fire pump controllers (EN 12845). They speak Modbus RTU, ASCII or TCP on the built-in RS-485, the optical port and, on FFL800DP, expansion modules. This map covers mains voltage, engine speed, hours, engine temperatures, oil pressure, fuel level, battery voltages, the alarm words, I/O states, the global status word and the reset/save commands.

This page lists 32 Modbus registers for the Lovato Electric FFL700DP / FFL800DP diesel engine fire pump controllers — 4 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lovato Electric’s own free documentation (linked below) and checked against it.

Integration notes: Lovato Electric FFL700DP / FFL800DP diesel engine fire pump controllers

Integration in brief

Read the alarm words 2200h-2205h and the global status 2210h for supervision, plus engine speed, battery voltages and fuel level. Subtract one from every table address.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In SETUP, menu M17 (communication), set node address, port speed, data format, stop bits and protocol for the port in use; port 1 is the built-in RS-485.

Byte order & addressing

  • Table addresses are one above the wire address.
  • 32-bit values are high word first.
  • Function 06 writes only to addresses above 1000h.

Network setup

  • Defaults: node 01, 9600 baud, 8 data bits, no parity, 1 stop bit, Modbus RTU.
  • Up to 3 communication ports can be configured (n = 1...3).

Watch out for

  • The example frame in the document labels the battery A register as 'number of switching alarms of breaker 1'; the address (0F0Eh sent as 0F 0D) and the value (12.07 VDC) are battery A.

Notes on this map

  • Measures and status words are read with function 03 or 04 (same data) and are listed as input registers. Commands use function 06.
  • Function 06 writes only to addresses above 1000h.
  • Word order: the example answer 00 00 04 B7 decodes to 1207 = 12.07 VDC (battery A, VDC/100), so 32-bit values are high word first (ABCD). The example's own wording calls the register 'number of switching alarms of breaker 1', a leftover from another product; the address and value match battery A.
  • Temperatures, oil pressure, fuel level and water reserve are printed with alternative units (°C / °F, bar / psi, % / l / gal); the protocol document does not say which one applies, so check the unit set on the controller (see its operating manual).
  • Left out: the LIM1-8 limit words and CNT1-8 counters (user-defined), and the front-panel key simulation at 2F0Ah (its Italian and English key tables disagree).
  • Ethernet (EXP1013T) defaults: IP 192.168.1.1, IP port 1001.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lovato Electric FFL700DP / FFL800DP diesel engine fire pump controllers

What Modbus registers does the Lovato Electric FFL700DP / FFL800DP diesel engine fire pump controllers have?

This map lists 32 registers: 28 input registers, 4 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lovato Electric FFL700DP / FFL800DP diesel engine fire pump controllers Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables print hex addresses one above the request address; the document says to subtract one, and its example reads battery A voltage (table 0F0Eh) by sending 0F 0D. Addresses here are already reduced by one.

What byte order does the Lovato Electric FFL700DP / FFL800DP diesel engine fire pump controllers use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lovato Electric FFL700DP / FFL800DP diesel engine fire pump controllers?

Start with IR 8719 Device global status (Global status (MAN/AUT, alarm, engine started)); IR 8703 Alarms A01-A16 (Alarms A01-A16); IR 8704 Alarms A17-A32 (Alarms A17-A32 (failure to start)); IR 5 Engine speed (Engine speed); IR 3853 Battery A voltage (Battery A voltage); IR 4003 Fuel level (Fuel level).

How do I enable Modbus control of the Lovato Electric FFL700DP / FFL800DP diesel engine fire pump controllers?

In SETUP, menu M17 (communication), set node address, port speed, data format, stop bits and protocol for the port in use; port 1 is the built-in RS-485.
