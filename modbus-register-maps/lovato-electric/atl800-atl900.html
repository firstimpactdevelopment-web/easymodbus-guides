Short answer

The ATL800 and ATL900 are Lovato's automatic transfer switch controllers for two (ATL800) or three (ATL900) sources. They talk Modbus RTU, ASCII and TCP through the optical port and EXP expansion modules. This map covers line voltages, frequencies, currents and powers, operating-time and operation counters, alarm and status words, and the mode, breaker and generator commands.

Integration notes: Lovato Electric ATL800 / ATL900 automatic transfer switch controllers

Integration in brief

Read 32-bit measures with function 04 at the table address minus one, high word first. 207Ch gives the mode and global alarm; write 2F00h (sent as 0x2EFF) to change mode, and 1C00h to open or close breakers.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Configure the port in setup menu M10 (node address P10.n.01, speed P10.n.02, data format P10.n.03, stop bits P10.n.04, protocol P10.n.05; IP settings for EXP1013).

Byte order & addressing

  • Every address, read or write, is sent one lower than printed.
  • Commands use function 06.

Network setup

  • Up to three communication ports (n = 1-3) can be set in menu M10.
  • Defaults: node 01, 9600 baud, 8 bits no parity, 1 stop bit, Modbus-RTU; Ethernet (EXP1013) default IP 192.168.1.1, IP port 1001.

Watch out for

  • Line voltages are whole volts (no decimals).
  • The default Modbus TCP port is 1001, not 502.

Notes on this map

  • Word order: the read example returns 00 00 00 0A for a count of 10, so the high word comes first (ABCD).
  • Units as printed: line voltages are whole volts, frequency Hz/10, battery VDC/10, currents A/10000, powers kW, kvar and kVA /10000, power factor /10000.
  • Alarm bits at 9Ah (32-bit): bit 0 A01 battery voltage low, 1 A02 battery high, 2 A03 BRK1 timeout, 3 A04 BRK2 timeout, 4 A05 BRK3 timeout, 5-7 A06-A08 phase sequence lines 1-3, 8 A09 load not powered timeout, 9 A10 local battery charger, 10-12 A11-A13 genset battery chargers, 13 A14 emergency, 14-16 A15-A17 breaker trips, 17-19 A18-A20 breakers withdrawn, 20-22 A21-A23 genset not available, 23-25 A24-A26 maintenance hours, 26-28 A27-A29 maintenance operations, 29 A30 auxiliary voltage breaker, 30 A31 non-priority load breaker timeout, 31 A32 TB1 timeout. At 9Ch: bits 0-6 A33-A39 (tie and non-priority breakers), bits 7-14 user alarms UA1-UA8.
  • Left out: maintenance hours and operations-to-maintenance (units differ between lines), minimum/maximum battery voltage (unit printed as V while the live value is VDC/10), generic counters and analog I/O (user-defined units), digital I/O bit words, display-message and LED words, the 32-bit device global status at 2210h, remote variables, key simulation, and the setup parameters.
  • LINE2 status words are printed at 2176h/2177h while LINE1 is at 2074h/2075h; they are listed exactly as printed.
  • Input function status is left out: Table 3 lists it at 2078h, but the bit table for it says to read address 2178h, so the address is not settled.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lovato Electric ATL800 / ATL900 automatic transfer switch controllers

What Modbus registers does the Lovato Electric ATL800 / ATL900 automatic transfer switch controllers have?

This map lists 114 registers: 111 input registers, 3 holding registers. 3 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lovato Electric ATL800 / ATL900 automatic transfer switch controllers Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables print hex addresses (for example 3Ah) and the document says to send one less. Its read example asks for 3Ah with start address 00 39, and its write example sends 2F03h as 2F02h. 'address' here is already reduced by one.

What byte order does the Lovato Electric ATL800 / ATL900 automatic transfer switch controllers use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lovato Electric ATL800 / ATL900 automatic transfer switch controllers?

Start with IR 1 Voltage of LINE1 L1-N (LINE1 L1-N voltage); IR 13 Voltage of LINE2 L1-N (LINE2 L1-N voltage); IR 25 Frequency of LINE1 (LINE1 frequency); IR 8308 LINE1 breaker status (LINE1 breaker status); IR 8315 Controller general status (Mode and global alarm); IR 153 Alarm bits A01-A32 (Alarm bits); HR 12031 Operating mode change (Mode change).

How do I enable Modbus control of the Lovato Electric ATL800 / ATL900 automatic transfer switch controllers?

Configure the port in setup menu M10 (node address P10.n.01, speed P10.n.02, data format P10.n.03, stop bits P10.n.04, protocol P10.n.05; IP settings for EXP1013).

Where is the official Lovato Electric ATL800 / ATL900 automatic transfer switch controllers Modbus documentation?
