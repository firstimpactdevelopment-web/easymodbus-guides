Short answer

Bonfiglioli's ACTIVE and ACTIVE Cube inverters speak Modbus RTU or ASCII through a CM-232 or CM-485 communication module. As on the Agile, the register address is the parameter number plus the data set number in the top 4 bits, and 32-bit parameters are read as two registers at one parameter address. This map covers the control and status words, RAM references, error and warning readouts and the module's Modbus settings.

Integration notes: Bonfiglioli ACTIVE / ACTIVE Cube inverter with CM-232 / CM-485 (Modbus RTU/ASCII)

Integration in brief

Set 395 = 2 (Modbus RTU), baud 10 and parity 1375, address 1376, reset the inverter, then 412 = 1. Write 484 (2 registers, 0.01 Hz) and step control word 410 through 0x0006, 0x0007, 0x000F; poll 411 and 260.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The CM module ships in VABus (395 = 0): set 395 = 2 (RTU) or 3 (ASCII) with the keypad or VPlus. Baud rate 10 (factory 19200) applies only after a reset (parameter 34 = 123) or mains off/on. For parity 1375 (factory even) the manual contradicts itself (reset needed in 5.2.1, immediate in 5.2.2), so reset after changing it. Address 1376 (factory 1) applies at once. Set 412 = 1 for control-word operation; the hardware release (STOA/STOB on ACU, S1IND on ACT) plus a Start Right/Left input are still needed.

Communication loss & watchdog

413 RS232/RS485 watchdog timer, 0-10000 s (factory 0 = off). When it expires the inverter trips with F2010 Watchdog RS232/RS485.

Byte order & addressing

  • Address = parameter number + 0x1000 x data set. Data set 0 writes all four EEPROM sets; data sets 5-9 write RAM only (set + 5). Control word 410 and references 484/524 always use data set 0.
  • 32-bit values are high word first and are read as 2 registers at one parameter number.
  • Reading or writing a 32-bit parameter with function 3/16 needs ACU firmware 5.1.12 or later; on ACT the manual says this is still in preparation, so use functions 100/101 there.
  • Picking the wrong protocol in 395 cuts off the CM port; fix it with the keypad or VPlus.

Network setup

  • CM-485 has a termination switch; switch it on only at the two ends of the bus.
  • Recommended cable lengths for CM-485: 1200 m at 19200, 300 m at 115200 baud.

Watch out for

  • A write error blocks further writes until register 11 is read.
  • A baud rate change does nothing until the inverter is reset; reset after a parity change too.

Notes on this map

  • Word order comes from the manual's 32-bit write examples (44.50 Hz to parameter 482 sends 00 00 11 62; an out-of-range value sends 00 03 0D 40): high word first.
  • A 32-bit parameter occupies one parameter number: request 2 registers starting at that number.
  • Values with decimals are sent as integers; the scale for 484 and 524 follows their two-decimal ranges.
  • The data set of 410, 484 and 524 is always zero; they are RAM values and are not written to EEPROM.
  • Parameters stored in four data sets return error 9 in register 11 when read with data set 0 and the sets differ; register 11 must be read before the next write is accepted.
  • In control via remote contacts (412 = 2) the control word bits act as virtual digital inputs (bit 0 = STOA+STOB on ACU, S1IND on ACT); a software-only release is not possible.
  • Left out: 282/283 reference bus/ramp frequency (data type not stated) and 392 (selection list not given).
  • Application warnings 274 exist on ACU only; on ACT bit 15 of 270 is the V-belt warning instead.
  • Function codes 3/16 for 32-bit values need ACU firmware 5.1.12 or later; ACT must use functions 100/101 (same high-word-first layout in the manual's examples).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Bonfiglioli ACTIVE / ACTIVE Cube inverter with CM-232 / CM-485 (Modbus RTU/ASCII)

What Modbus registers does the Bonfiglioli ACTIVE / ACTIVE Cube inverter with CM-232 / CM-485 (Modbus RTU/ASCII) have?

This map lists 16 registers: 16 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Bonfiglioli ACTIVE / ACTIVE Cube inverter with CM-232 / CM-485 (Modbus RTU/ASCII) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The start address field carries the parameter number (0-1599) in bits 0-11 and the data set (0-9) in bits 12-15, sent as-is: parameter 481 in data set 1 is 0x11E1, in data set 0 it is 0x01E1 (= 481). This map lists data set 0 addresses (parameter number). For another data set add 0x1000 x data set (data set 2 of parameter 372 = 0x2174).

What byte order does the Bonfiglioli ACTIVE / ACTIVE Cube inverter with CM-232 / CM-485 (Modbus RTU/ASCII) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.
