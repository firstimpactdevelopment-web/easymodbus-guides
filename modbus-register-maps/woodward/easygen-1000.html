Short answer

The easYgen-1000 is Woodward's genset controller for single units and AMF duty. On RS-485 it is a Modbus RTU slave: the visualization telegram (protocol 4003) is block-read from Modicon 450001, and control word 1 at parameter 503 starts, stops and acknowledges the set. This map covers generator and mains voltages, currents and frequency, energy and hours counters, status and alarm words, a few J1939 engine values and the remote-control word.

Integration notes: Woodward easYgen-1000 Series genset controller (Modbus RTU)

Integration in brief

Block-read up to 128 holding registers from wire address 50000 (Modicon 450001) for measurements, status and alarms. To start or stop the set, write 0 and then the start (bit 0) or stop (bit 1) bit to parameter 503; acknowledge with two rising edges of bit 4.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Select the Modbus protocol on the serial interface and set the Modbus slave ID (0-255) and reply delay (0-1000 ms) in the controller. For remote start/stop the LogicsManager must use command variable 04.13; see application manual 37394. Parameter writes need the code level 2 password for that interface (parameter 10401 for serial interface 1).

Communication loss & watchdog

Interface watchdogs exist but are disabled by default; they are described in the device manual, not in this document.

Byte order & addressing

  • Start, stop and acknowledge react only to a rising edge: write 0 first, then the bit.
  • Acknowledge must be sent twice: the first edge silences the horn, the second clears faults that are gone.
  • Some PLCs and tools offset addresses by one; the manual notes 450001 may become bus address 50000.

Network setup

  • RS-485 half or full duplex is supported. Set the baud rate, parity and stop bits in the controller's serial interface menu to match the master.

Watch out for

  • Writing control word 1 can start or stop the engine; make sure the site is safe first.
  • Bits 2 and 3 of control word 1 must always be 0.

Notes on this map

  • 32-bit values are listed as a High word row followed by a Low word row, so the high word sits at the lower address (ABCD).
  • The telegram prints units and resolution but no signed/unsigned type. Voltages, currents, frequency, energy and hours cannot be negative, so the unsigned type here reads them correctly either way.
  • Left out: generator and mains real power, reactive power and power factor (words 10, 13, 50, 53, 56, 59, 61-65), because the telegram does not say whether they are signed and they can go negative; analog inputs T1/T2 (no scaling given); hours/days until maintenance; the system state bits 0-5 of word 34, whose labels sit between two bit rows; diagnostic (DM1/DM2) SPN/FMT words and most J1939 engine values.
  • Words 112-168 come from an engine ECU over J1939 and only hold data when one is connected and configured.
  • Parameters (configuration range 40001-450000) are read or written one at a time with a length that matches the parameter data type; the full parameter list is in configuration manual 37391, not this document.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Woodward easYgen-1000 Series genset controller (Modbus RTU)

What Modbus registers does the Woodward easYgen-1000 Series genset controller (Modbus RTU) have?

This map lists 49 registers: 49 holding registers. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Woodward easYgen-1000 Series genset controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual uses Modicon numbers. Telegram word No. n is Modicon 450000 + n; the manual says 450001 may become bus address 50000, so word n is wire address 49999 + n. Parameters use Modicon 40000 + (parameter ID + 1), so control word 1 (parameter 503) is 40504 = wire address 503.

What byte order does the Woodward easYgen-1000 Series genset controller (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.
