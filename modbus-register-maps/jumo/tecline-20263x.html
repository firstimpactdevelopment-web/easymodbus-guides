Short answer

JUMO tecLine sensors are amperometric membrane sensors for free and total chlorine, chlorine dioxide, ozone, hydrogen peroxide, peracetic acid and bromine, with a built-in RS-485 Modbus RTU interface. Integration notes: JUMO tecLine digital disinfection sensors (Cl2, TC, ClO2/O3, H2O2/PAA, Br, Cl2 OM) (Modbus RTU)

Integration in brief

Read 6 registers from 0x0000 (function 03) for concentration, cell current and temperature as CDAB floats; read 0x0200 once for the unit.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

HR 0ConcentrationFLOAT32 CDABConcentrationRead
HR 4TemperatureFLOAT32 CDABTemperatureRead

Enable Modbus control & writes

Modbus RTU is the native interface; change address and serial format with JUMO DSM software or registers 0x0400-0x0402.

Byte order & addressing

  • Floats are low word first (CDAB).
  • Only RTU mode is supported.

Network setup

  • M12 pins: 2 = +24 V, 3 = GND, 4 = RS-485 B, 5 = RS-485 A.
  • Check the type-specific default address before commissioning several sensors on one bus.

Watch out for

  • Sensors ship uncalibrated; a calibration only becomes active when the date/time stamp is written.
  • Replace the membrane/electrolyte when the slope falls below 30 % of the nominal slope (0x030A).

Notes on this map

  • Copy hosted by the Australian distributor Onetemp; JUMO does not offer a public direct link to this document. The file is the unaltered JUMO interface description.
  • Floats are sent low word first (CDAB): the guide says the bytes come as 3-4-1-2, and its temperature example returns BA 2F 41 C0 = 24.09 °C.
  • Default slave address depends on type: 20 Cl2, 30 TC, 50 O3, 80 ClO2, 60 H2O2, 70 PAA, 90 Br, 100 Cl2 OM. Default serial format reads 38400 baud, none parity, 1 stop bit in the settings table.
  • Left out: the calibration date/time stamps (0x020A and history), which are unsigned 32-bit integers with no stated word order; writing the stamp at 0x020A is what activates a new calibration, so use JUMO DSM software or test word order first.
  • Left out: history entry 3, because the table prints the same addresses (0x0212/0x0214) as entry 0.
  • Unit code 1 is printed as an unreadable symbol in the table and is left out of the enum.
  • Function 03 and 04 both read all parameters; writes use 06 or 16.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the JUMO tecLine digital disinfection sensors (Cl2, TC, ClO2/O3, H2O2/PAA, Br, Cl2 OM) (Modbus RTU)

What Modbus registers does the JUMO tecLine digital disinfection sensors (Cl2, TC, ClO2/O3, H2O2/PAA, Br, Cl2 OM) (Modbus RTU) have?

This map lists 24 registers: 24 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the JUMO tecLine digital disinfection sensors (Cl2, TC, ClO2/O3, H2O2/PAA, Br, Cl2 OM) (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed in hex and sent unchanged; the example reads the temperature with start address 0x0004.

What byte order does the JUMO tecLine digital disinfection sensors (Cl2, TC, ClO2/O3, H2O2/PAA, Br, Cl2 OM) (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the JUMO tecLine digital disinfection sensors (Cl2, TC, ClO2/O3, H2O2/PAA, Br, Cl2 OM) (Modbus RTU)?

Start with HR 0 Concentration (Concentration); HR 4 Temperature (Temperature); HR 2 Cell current (Cell current (for calibration)); HR 512 Unit (Unit code).

How do I enable Modbus control of the JUMO tecLine digital disinfection sensors (Cl2, TC, ClO2/O3, H2O2/PAA, Br, Cl2 OM) (Modbus RTU)?

Modbus RTU is the native interface; change address and serial format with JUMO DSM software or registers 0x0400-0x0402.
