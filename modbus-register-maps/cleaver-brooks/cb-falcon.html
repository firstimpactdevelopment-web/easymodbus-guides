Short answer

The CB Falcon boiler control is a Modbus RTU slave on its two RS-485 ports. All data are 16-bit holding registers; this map covers the system and burner status block: digital I/O, limits, temperatures, setpoints, burner state, lockout and alarm codes, and sensor states.

This page lists 33 Modbus registers for the Cleaver-Brooks CB Falcon hydronic / steam boiler control — 1 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Cleaver-Brooks’s own free documentation (linked below) and checked against it.

Integration notes: Cleaver-Brooks CB Falcon hydronic / steam boiler control

Integration in brief

Poll holding registers 0x0000-0x0034 with FC03 (up to 125 per read) for I/O, temperatures, setpoints, burner status and lockout code; temperatures are 0.1 °C. The Remote STAT register (0x002A) can create a heat demand.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Use the MB1 or MB2 RS-485 port; the Falcon answers on a single Modbus address.

Byte order & addressing

  • Temperatures are always Celsius x10.
  • 0x8FFF = sensor not configured.
  • Variable-length items must be read on their own.

Network setup

  • RTU 38400 8N1 per the manual.
  • Writes: up to 20 registers; reads: up to 125.

Watch out for

  • Reading 0x0000 clears it, so a second master will miss change flags.

Notes on this map

  • Source is a copy of the Cleaver-Brooks manual hosted by Contemporary Controls; Cleaver-Brooks did not turn up a public copy in two searches.
  • Serial format per Table 2: RTU, 38400 bps, 8 data bits, no parity, 1 stop bit.
  • Temperatures are in 0.1 °C regardless of the display unit setting; 0x8FFF means the sensor is not configured. The manual types them as U16 while giving a range down to -40 °C and does not say how values below zero are coded. They are listed as UINT16 for boiler water, flue and setpoint values, which sit above 0 °C in service; treat any sub-zero reading with care. The S5 sensor temperature (0x000D) is left out because S5 is often an outdoor sensor where sub-zero values are routine.
  • Left out: firing rate and other rate registers, whose unit (0.1 % or RPM) is chosen by the top bit; every 32-bit counter (cycle counts, run times), because the manual does not state their word order; the configuration change and extended status change registers; 4-20 mA inputs; and everything from 0x0035 on (CH/DHW/pump status, configuration, lead-lag, lockout history, alert log).
  • Status change (0x0000) clears itself when read, so only one master should poll it.
  • Writes need a password login in the Password register (0x00B1) for protected parameters; register 0x0013 shows the current write access.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Cleaver-Brooks CB Falcon hydronic / steam boiler control

What Modbus registers does the Cleaver-Brooks CB Falcon hydronic / steam boiler control have?

This map lists 33 registers: 33 holding registers. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Cleaver-Brooks CB Falcon hydronic / steam boiler control Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Table 4 lists each register as a hex address and its decimal equivalent, starting at 0000 (Status change). These are the protocol addresses: register 0x0022 (decimal 34) is sent as 34.

What are the minimum Modbus registers to integrate the Cleaver-Brooks CB Falcon hydronic / steam boiler control?

Start with HR 32 Burner control status (Burner control status); HR 34 Lockout code (Lockout code); HR 35 Alarm reason (Alarm reason); HR 7 Outlet temperature (Outlet temperature); HR 16 Active CH setpoint (Active CH setpoint); HR 2 Digital I/O (Digital I/O); HR 42 Remote STAT (Remote STAT demand).

How do I enable Modbus control of the Cleaver-Brooks CB Falcon hydronic / steam boiler control?

Use the MB1 or MB2 RS-485 port; the Falcon answers on a single Modbus address.
