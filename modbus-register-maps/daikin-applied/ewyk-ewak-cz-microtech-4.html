Integration notes: Daikin Applied EWAK-CZ / EWYK-CZ air-cooled chiller and heat pump (MicroTech 4, ICARO software)

Integration in brief

Fit a POL902 module, set its address and serial settings at the keypad, then poll holding registers. Read Unit Status (col 15) and leaving water temperature (col 17); enable with col 9, choose Cool/Heat with col 34 and send setpoints to cols 35/37 in tenths of °C.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Power off, plug the POL902 module onto the controller's extension bus, power on, check the BUS LED is steady green, then enter the service password and set the Modbus parameters under Main menu > Commissioning > Modbus.

Byte order & addressing

  • Addresses are Modicon-style: subtract 1 from the guide's column value.
  • Tenths (0,1) apply to temperatures, percentages and the current limit.
  • Unit and circuit alarms are bit-packed words; register 299 is Unit Alarm Word 1 and 295 is Word 5 (descending order).

Network setup

  • POL902 defaults per port: address 1, parity None, 2 stop bits, 19200 baud, 5 ms response delay; port T2 is passive by default.
  • BSP LED green = module and controller talking; BUS LED green = Modbus traffic, red = communication interrupted.

Watch out for

  • Never leave Clear Alarms - Network (col 10) written to Clear; the guide warns that a continuous clear can be hazardous.
  • Operation mode values 1, 4 and 5 are marked Not Used on this range; use 2 (Cool) or 3 (Heat).

Notes on this map

  • The integration list's 'Offset' column holds 1 for enums and 0,1 for temperatures, percentages and the current limit; it is a multiplier (0,1 = tenths), so it is used as scale here.
  • Temperatures are shown in °C; register 47 switches the unit system between Metric and Imperial.
  • The W access letter is taken as read/write.
  • Left out: the three 'UNSIGNED DOUBLE WORD' run-hour counters (102 evaporator pump 1, 323 and 423 compressor run hours) because the guide does not say which word is high.
  • Left out: DHW Standby Mode (95), whose type and offset columns are not filled in properly (MV_red / DHWStandbyMode), and the Reserved registers 279, 290, 291.
  • Alarm words are single 16-bit registers (the printed 0...4294967295 range is not meaningful for one word). Only bits with a named alarm are listed; the annex marks which bits apply to the SIC, SPLIT, R454C and R290 variants.
  • Compressor starts registers are single words although the printed range is 0-9,999,999.
  • Bit numbering in the alarm words is confirmed by the guide's worked example: Unit Alarm Word #1 = 17,408 (0100 0100 0000 0000) means bits 10 and 14 are active.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Daikin Applied EWAK-CZ / EWYK-CZ air-cooled chiller and heat pump (MicroTech 4, ICARO software)

What Modbus registers does the Daikin Applied EWAK-CZ / EWYK-CZ air-cooled chiller and heat pump (MicroTech 4, ICARO software) have?

This map lists 92 registers: 92 holding registers. 29 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Daikin Applied EWAK-CZ / EWYK-CZ air-cooled chiller and heat pump (MicroTech 4, ICARO software) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide says all variables are holding registers 'addressed 4xxxx' with the number in its Address column (1 = 40001), the same rule as Daikin Applied's other MicroTech 4 Modbus guides. Wire address = column value - 1.

What are the minimum Modbus registers to integrate the Daikin Applied EWAK-CZ / EWYK-CZ air-cooled chiller and heat pump (MicroTech 4, ICARO software)?

Start with HR 0 Local/Network Source (Local/Network source); HR 14 Unit Status (Unit status); HR 16 Evaporator Leaving Water Temperature (Leaving water temperature); HR 12 Actual Capacity (Actual capacity); HR 8 Unit Enable Setpoint - Network (Network enable command); HR 33 Operation Mode Setpoint - Network (Operation mode command); HR 34 Cool Setpoint - Network (Cool setpoint command); HR 36 Heat Setpoint - Network (Heat setpoint command); HR 4 Unit General Alarm (Unit general alarm).

How do I enable Modbus control of the Daikin Applied EWAK-CZ / EWYK-CZ air-cooled chiller and heat pump (MicroTech 4, ICARO software)?
