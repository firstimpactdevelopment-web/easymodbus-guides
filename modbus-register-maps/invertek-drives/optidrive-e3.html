Short answer

Invertek's compact general purpose variable frequency drive with Modbus RTU on the front RJ45 port. Registers 1-4 take the control word, frequency setpoint, PI setpoint and ramp time; registers 7-24 and 2001-2016 report status, output values, I/O and the trip code. Parameters P-04 to P-60 sit at register 128 + parameter number. This map covers the control and monitoring block plus the command-source parameter.

Integration notes: Invertek Drives Optidrive E3 IP20 (built-in Modbus RTU)

Integration in brief

Set P-12 = 3 (or 4 to write ramp times in register 4), keep digital input 1 closed as the hardware enable, then write register 1 = 1 to run and register 2 with the frequency x10. Poll 2001 for status, 2002-2004 for speed, current and power, and 2016 for the trip code.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set P-12 = 3 (Modbus with internal ramps) or 4 (ramps from register 4). Set the drive address, baud rate and watchdog in P-36 indexes 1-3 (factory address 1, 115.2 kbps). An enable signal on digital input 1 is still required in Modbus mode. P-14 must hold the access code (P-37, factory 101) to reach parameters above P-14.

Communication loss & watchdog

P-36 index 3 sets the communication-loss time: 0 disables it, or 30, 100, 1000 or 3000 ms (factory 3000 ms with trip). A 't' suffix trips the drive (fault 50, Modbus comms loss); the other suffix coast-stops without tripping. P-63 decides whether any valid telegram (0, standard) or only telegrams for this node (1, advanced) reset the timer.

Byte order & addressing

  • Register numbers are 1-based: subtract 1 for the wire address.
  • Only 8-N-1 framing is listed; the factory baud rate is 115200.
  • Parameter registers are 128 + parameter number, not the parameter number itself.

Network setup

  • Wire RS485- to RJ45 pin 7, RS485+ to pin 8 and 0 V common to pin 3; pins 4/5 are the PC/keypad port.
  • Use twisted pair for RS485+/-, connect 0 V common across all devices, and terminate the shield at the controller only.
  • The RJ45 port is not Ethernet: do not plug it into a network switch.

Watch out for

  • With the factory P-63 = 0, telegrams for other nodes also keep the watchdog alive.
  • After an over current or overload trip (codes 3, 4, 15) a reset is refused until the built-in delay has elapsed.

Notes on this map

  • Left out: register 6 (drive status / error code) because the guide contradicts itself on which byte holds the error code (the table says low byte, the bit table puts status in bits 0-7 and the trip code in the high byte). Use register 2001 (status) and 2016 (trip code) instead.
  • Parameter registers P-04 to P-60 (128 + parameter number) are left out apart from P-12: the guide says some use internal scaling without stating it. P-36 (address, baud, watchdog) has three sub-indexes and no stated register layout.
  • The guide does not state signedness for most registers. Values with a 0-n range are typed UINT16; torque (+/-200 %) and motor output speed (status bit 13 = negative speed) are typed INT16.
  • Function code 16 (write multiple) is accepted for registers 1-4 only; 03 and 06 work on all registers.
  • The E3 IP66 Indoor guide (82-E3MAN-IN V2.00) lists only registers 1-24 with slightly different register-6 wording; this map follows the IP20 guide.
  • Register 3 scaling is given only as 0-4096 = 0-100.0 %, so it is kept raw.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Invertek Drives Optidrive E3 IP20 (built-in Modbus RTU)

What Modbus registers does the Invertek Drives Optidrive E3 IP20 (built-in Modbus RTU) have?

This map lists 29 registers: 29 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Invertek Drives Optidrive E3 IP20 (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide numbers registers from 1 and tells zero-based masters to subtract 1, so register 1 (control word) is wire address 0 and register 2001 is address 2000. Parameter registers are 128 + parameter number (P-12 = register 140 = address 139).

What are the minimum Modbus registers to integrate the Invertek Drives Optidrive E3 IP20 (built-in Modbus RTU)?

Start with HR 0 Control word (Control word: run, reset, coast stop); HR 1 Frequency setpoint (Frequency setpoint, 0.1 Hz); HR 2000 Status word 2 (Status word 2); HR 2001 Motor output speed (Motor output speed, 0.1 Hz); HR 2002 Motor output current (Motor output current, 0.1 A); HR 2003 Motor output power (Motor output power, 0.1 kW); HR 2015 Trip code (Trip code); HR 139 P-12 Primary command source (P-12 command source).

How do I enable Modbus control of the Invertek Drives Optidrive E3 IP20 (built-in Modbus RTU)?
