ABB PSE softstarter (internal Modbus RTU) Modbus register map

Updated 17 November 2026

Short answer

ABB's compact PSE softstarters can be controlled over Modbus RTU through a small adaptor on their fieldbus port. Status comes as discrete inputs or one status word, measurements (currents, frequency, power factor, starts, run time) as 16-bit registers, and the motor is started and stopped through coils or a control word. Start/stop and protection settings are directly readable and writable as one register each. This map covers the full published register set.

This page lists 67 Modbus registers for the ABB PSE softstarter (internal Modbus RTU) — 29 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ABB’s own free documentation (linked below) and checked against it.

Integration notes: ABB PSE softstarter (internal Modbus RTU)

Integration in brief

Set Fieldbus interface type = Modbus RTU and Fieldbus control = On on the softstarter, then write the control word 0400h with bit 5 (auto mode) and bit 2 (start), and poll 0300h status, 0202h-0204h phase currents and 2000h diagnostics.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

On the softstarter set Fieldbus interface type = internal Modbus RTU, Fieldbus control = On (Off for monitoring only), the internal Modbus RTU baud rate (9.6-76.8 kbaud) and frame format (8O1, 8E1, 8N2, 8N1), and the Fieldbus address (1-247).

Communication loss & watchdog

301Ch Internal Modbus RTU timeout (0.5-60.0 s, default 0.5 s) with 3019h Fieldbus fault reaction (Trip or Switch to local). A loss shows as fault EF40 and diagnostic bit 'Fieldbus fault'.

Byte order & addressing

  • Addresses are hex protocol addresses sent as-is.
  • Stop has priority over start, and both are ignored unless auto mode is set in exactly one place (coil 0105h or control word bit 5).
  • The default comm timeout is only 0.5 s, so the master must poll continuously.

Network setup

  • The Modbus RTU adaptor plugs into the PSE fieldbus connector; fit termination at both line ends.
  • After writing 4064h (baud) the master must switch to the new rate to keep talking.

Watch out for

  • Parameter writes fail while the motor is ramping; read 2003h for the reason and the parameter number.
  • The motor may start unexpectedly when switching between fieldbus and hardwired control if a start signal is present.

Notes on this map

  • This copy is hosted by the US distributor Precision Electric; it is the unaltered ABB document (ABB footer, document ID 1SFC132367M0201 Rev B). ABB's online library did not return a copy for this document ID.
  • All values are 16-bit. Read-only data blocks (status word, analog inputs, diagnostics, Modbus diagnostics) answer both function 03 and 04; they are listed as input registers here. The digital input telegram answers function 01 or 02 and is listed as discrete inputs; the output coils can be read back with 01/02.
  • Scaling follows the manual's 'Value = 1 => ...' column: power factor 100 = 1, number of starts 1 = 100 starts, run time 1 = 10 h.
  • Defaults: unit_id 255 is the parameter-list default of 3017h Fieldbus address (the manual's examples use 47); baud 19200 and 8E1 are the defaults of 301Dh/301Eh.
  • Parameters 3016h-301Eh are read-only over Modbus; set them on the softstarter. 4064h lets the master change the baud rate.
  • Left out: 2001h and 2002h (all bits reserved), the identification strings at 4000h-4017h (vendor, product code, revision, URL, product name; byte order of the text is not stated) and the reserved blocks. Function 43 (2Bh) Read Device Identification is also supported.
  • Start/stop can come from coils 0101h/0102h (with auto mode on coil 0105h) or from bits 1/2 of the control word (with auto mode in bit 5). Setting auto mode in both places makes the device ignore start/stop.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ABB PSE softstarter (internal Modbus RTU)

What Modbus registers does the ABB PSE softstarter (internal Modbus RTU) have?

This map lists 67 registers: 5 coils, 9 discrete inputs, 20 input registers, 33 holding registers. 29 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB PSE softstarter (internal Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. All addresses are printed as hex protocol addresses and go on the wire unchanged; the manual's example frames send 0000h (coils), 0100h, 0202h, 2000h and 3007h exactly as listed. So 0202h is requested as 514 decimal.

What are the minimum Modbus registers to integrate the ABB PSE softstarter (internal Modbus RTU)?

Start with HR 1024 Control word (Control word: start/stop/auto mode/reset); IR 768 Status word (Status word: running, fault, ready); IR 514 Phase current L1 (Phase current L1); IR 512 Motor current in % of Ie (Motor current in % of Ie); IR 513 Thermal load (Thermal load); IR 8192 Diagnostic word 1 (Diagnostic word (faults/protections)).

How do I enable Modbus control of the ABB PSE softstarter (internal Modbus RTU)?

On the softstarter set Fieldbus interface type = internal Modbus RTU, Fieldbus control = On (Off for monitoring only), the internal Modbus RTU baud rate (9.6-76.8 kbaud) and frame format (8O1, 8E1, 8N2, 8N1), and the Fieldbus address (1-247).

What happens when the ABB PSE softstarter (internal Modbus RTU) loses Modbus communication?

301Ch Internal Modbus RTU timeout (0.5-60.0 s, default 0.5 s) with 3019h Fieldbus fault reaction (Trip or Switch to local). A loss shows as fault EF40 and diagnostic bit 'Fieldbus fault'.

Where is the official ABB PSE softstarter (internal Modbus RTU) Modbus documentation?
