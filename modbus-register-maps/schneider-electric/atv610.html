Integration notes: Schneider Electric Easy Altivar ATV610 (embedded Modbus serial)

Integration in brief

Set Add (6001) to 1-247 and restart the drive, set FR1 to Modbus (164) with CHCF = SIM, then write CMD (8501) = 0006h followed by 000Fh with a non-zero LFR (8502, 0.1 Hz) or LFRD (8602, rpm). Poll ETA (3201), RFR (3202), HMIS (3240) and LFT (7121).

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set [Modbus Address] Add (logical 6001) to 1-247; the factory value 0 (OFF) means the drive does not answer. Speed and format default to 19200 baud, 8-E-1 (tbr 6003, tFO 6004). A new Modbus address takes effect only after the drive is restarted. For combined CiA402 control use [Control Mode] CHCF = [Not separ.] SIM and set [Ref Freq 1 Config] FR1 = Modbus (164); for separate mode use CHCF = SEP with Cd1 = Modbus.

Communication loss & watchdog

[ModbusTimeout] ttO (6005), 0.1-30 s, factory 10 s. If no valid Modbus frame arrives within ttO on a monitored channel, the drive raises [Modbus Com Interruption] SLF1 and reacts per SLL (7010): factory freewheel stop, or ignore, configured stop, fallback speed LFF (7080), speed maintained, ramp stop, fast stop or DC injection.

Byte order & addressing

  • Addresses are decimal logical numbers sent as-is (3201 = 0x0C81); do not subtract 1 or add 40001.
  • CiA402 sequence: 0006h (shutdown) -> Ready to switch on, then 000Fh (enable operation) to run; 0007h disables operation, 0000h disables voltage, 0002h quick stop, 0080h rising edge resets a fault.
  • Mask ETA with 006Fh to read the state: 0040h switch on disabled, 0021h ready to switch on, 0023h switched on, 0027h operation enabled, 0007h quick stop active, 0008h/0028h fault.
  • CMD bit 11 is reverse direction by default ([Reverse Assign] rrS = C111); bits 12-15 can be assigned to functions (C112-C115).

Network setup

  • Set Add, tbr and tFO in the [Communication] COM- / [Comm parameters] CMP- / [Modbus SL] MSL- / [Modbus Fieldbus] Md1- menu, then restart the drive so the new address is used.
  • RS-485 trunk: shielded twisted pair plus a common conductor; each line terminator is 120 ohm in series with 1 nF; the master supplies bus polarization.
  • Write CMD and the reference at least once so the Modbus channel becomes active and monitored.

Watch out for

  • Factory Add = OFF: a brand-new drive is silent on the bus.
  • Configuration parameters (R/WS) are refused while the motor is running.
  • CMI bit 1 (save to EEPROM) clears itself, but if CMI is written cyclically the master must write it back to 0; EEPROM life is about 100,000 writes.

Notes on this map

  • Second source: Easy Altivar ATV610 Modbus Manual EAV64395.03 (10/2024), https://download.schneider-electric.com/files?p_Doc_Ref=EAV64395 - addressing examples (read W3102 at 0C1E hex, write W9001 at 2329 hex), settings, the CiA402 sequence and the CMD/ETA bit layout.
  • Every register in this map is a single 16-bit word; 32-bit values in the parameter file (e.g. run/power-on time counters) are left out because neither document states their word order.
  • LFR (8502) and RFR (3202) are 0.1 Hz only while CMI bit 9 = 0; with bit 9 = 1 they become a signed value where 32767 = tFr. The parameter file states this in the CMI bit 9 description.
  • LCR (3204) is left unscaled: the parameter file says 'refer to programming manual', where the current step depends on the drive rating.
  • ACC/DEC (9001/9002) are raw values; their resolution follows INR (9020): 0 = 0.01 s, 1 = 0.1 s, 2 = 1 s.
  • Energy is split into 0-999 registers per decade: motor energy = OC4 TWh + OC3 GWh + OC2 MWh + OC1 kWh + OC0 Wh; input energy likewise with IC0-IC4.
  • Value lists for HMIS, LFT/DP0-DP3, LALR, FR1 (PSA list), CD1, TBR and the stop/fault reactions are copied from the Enumerations sheet.
  • Registers shown as RW that the file lists as R/WS can only be written while the drive is not running.
  • Left out: NCR, ITH, AI physical values, PID feedback/reference and SPD because their unit is 'refer to programming manual'; option-card and function-block parameters.

Questions about the Schneider Electric Easy Altivar ATV610 (embedded Modbus serial)

What Modbus registers does the Schneider Electric Easy Altivar ATV610 (embedded Modbus serial) have?

This map lists 70 registers: 70 holding registers. 38 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Schneider Electric Easy Altivar ATV610 (embedded Modbus serial) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The parameter file gives each logical address in hex and decimal (16#0C81 = 3201); the decimal value goes into the request unchanged. The Modbus serial manual's example reads W3102-W3105 by sending start address 0C1E hex (= 3102) and writes W9001 at 2329 hex, so there is no 40001 offset and no minus 1.

What are the minimum Modbus registers to integrate the Schneider Electric Easy Altivar ATV610 (embedded Modbus serial)?

Start with HR 8501 CMD - Command register (CMD: CiA402 run/stop/reset); HR 8502 LFR - Reference frequency (LFR: frequency reference, 0.1 Hz); HR 3201 ETA - Status Register (ETA: CiA402 status word); HR 3202 RFR - Motor frequency (RFR: output frequency, 0.1 Hz); HR 3204 LCR - Motor current (LCR: motor current (raw)); HR 3240 HMIS - Device state (HMIS: drive state code); HR 7121 LFT - Last error occurred (LFT: last fault code); HR 3209 THD - Drive thermal state (THD: drive thermal state).

How do I enable Modbus control of the Schneider Electric Easy Altivar ATV610 (embedded Modbus serial)?

Set [Modbus Address] Add (logical 6001) to 1-247; the factory value 0 (OFF) means the drive does not answer. Speed and format default to 19200 baud, 8-E-1 (tbr 6003, tFO 6004). A new Modbus address takes effect only after the drive is restarted. For combined CiA402 control use [Control Mode] CHCF = [Not separ.] SIM and set [Ref Freq 1 Config] FR1 = Modbus (164); for separate mode use CHCF = SEP with Cd1 = Modbus.

What happens when the Schneider Electric Easy Altivar ATV610 (embedded Modbus serial) loses Modbus communication?

[ModbusTimeout] ttO (6005), 0.1-30 s, factory 10 s. If no valid Modbus frame arrives within ttO on a monitored channel, the drive raises [Modbus Com Interruption] SLF1 and reacts per SLL (7010): factory freewheel stop, or ignore, configured stop, fallback speed LFF (7080), speed maintained, ramp stop, fast stop or DC injection.
