Short answer

The Z-D-IN is a DIN-rail module with five digital inputs, each feeding a counter, on an RS-485 Modbus RTU port. Address and baud rate come from DIP switches or from EEPROM. This map covers input states, the five counters (IN5 can run as a 32-bit counter), filter, configuration flags and the save/reset command register.

This page lists 16 Modbus registers for the Seneca Z-D-IN 5-channel digital input / counter module (Modbus RTU) — 14 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Seneca’s own free documentation (linked below) and checked against it.

Integration notes: Seneca Z-D-IN 5-channel digital input / counter module (Modbus RTU)

Integration in brief

Read holding registers 0-6 (function 03) for the input states and the five counters. Write a counter register to preset or clear it.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is always on. DIP switches 3-8 set the address (all off = take address and baud from EEPROM), 1-2 the baud rate, 9-10 the RS-485 terminator.

Byte order & addressing

  • Offset address is the wire address.
  • The 32-bit IN5 counter is LSW first.

Network setup

  • Default 38400 8N1, address 1.
  • After writing the filter or flags, set bit 0 of register 10 to save to EEPROM.

Watch out for

  • Overflow flags in register 1 stay set until written back to 0.

Notes on this map

  • All registers are holding registers; functions 03, 06 and 16 are supported.
  • The only 32-bit value, the IN5 32-bit counter, is stored LSW at 40019 and MSW at 40020 (CDAB), as printed in the table.
  • Register 40010 holds node address and baud rate together. Its bit description is self-contradictory (it gives bits 0-7 to both the baud code and the node address), so it is left out; set these with the DIP switches or Easy Setup.
  • R/W(*) registers (40008-40010) only reach EEPROM after bit 0 of the command register (40011) is set.
  • Default serial settings from the manual: 38400 baud, 8 data bits, no parity, 1 stop bit, address 1.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Seneca Z-D-IN 5-channel digital input / counter module (Modbus RTU)

What Modbus registers does the Seneca Z-D-IN 5-channel digital input / counter module (Modbus RTU) have?

This map lists 16 registers: 16 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seneca Z-D-IN 5-channel digital input / counter module (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table prints both the Modbus address (40001 = first register) and the offset address (0). The offset is what goes on the wire.

What byte order does the Seneca Z-D-IN 5-channel digital input / counter module (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Seneca Z-D-IN 5-channel digital input / counter module (Modbus RTU)?

Start with HR 1 Input status and counter overflows (Input states and overflow flags); HR 2 Counter 1 (Counter 1); HR 3 Counter 2 (Counter 2); HR 4 Counter 3 (Counter 3); HR 5 Counter 4 (Counter 4); HR 6 Counter 5 (16-bit mode) (Counter 5).

How do I enable Modbus control of the Seneca Z-D-IN 5-channel digital input / counter module (Modbus RTU)?

Modbus RTU is always on. DIP switches 3-8 set the address (all off = take address and baud from EEPROM), 1-2 the baud rate, 9-10 the RS-485 terminator.

Where is the official Seneca Z-D-IN 5-channel digital input / counter module (Modbus RTU) Modbus documentation?

The source is User Manual Z-D-IN (MI00252-3-EN), revision 2022-01-13, published free by Seneca at https://www.seneca.it/media/2495/mi00252-3-en.pdf.
