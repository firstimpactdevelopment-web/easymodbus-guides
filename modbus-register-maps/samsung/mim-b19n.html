Updated 17 November 2026

Short answer

The MIM-B19N links one Samsung outdoor system (up to 4 modular outdoor units) and up to 48 indoor units, hydro units, AHU kits, ERVs, chillers or FCUs on the R1/R2 bus to a Modbus RTU master. Each indoor unit gets a fixed 50-register block. This map covers the module status registers and the indoor-unit block: on/off, mode, fan speed, setpoints, room and water temperatures, errors, ventilation and hot-water functions. Addresses are given for indoor unit 0.

This page lists 34 Modbus registers for the Samsung MIM-B19N Modbus interface module (DVM / EHS / indoor units) — 21 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Samsung’s own free documentation (linked below) and checked against it.

Integration notes: Samsung MIM-B19N Modbus interface module (DVM / EHS / indoor units)

Integration in brief

Set the module address with the DIP/rotary switches, connect RS-485 at 9600 8E1, wait until bits 0-2 of an indoor unit's communication status (50 + n*50) read 7, then read and write its 50-register block.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the Modbus address (1-247) as the sum of the ON DIP switches plus the rotary switch value, connect R1/R2 to the outdoor unit, and give every indoor unit an address 0-47. Reset the module after changing indoor unit addresses or the central-control option.

Byte order & addressing

  • Per-unit blocks: address = 50 + indoor address x 50 + offset.
  • Temperatures are x10 integers.
  • Holding values update only after the indoor unit reports a change.

Network setup

  • Fixed serial format: 9600 bps, 8 data bits, even parity, 1 stop bit.
  • RS-485 2-wire, up to 1000 m; DC 12 V supply.

Watch out for

  • Leave at least 10 ms after each response before the next request.
  • Repeated identical writes are sent to the unit each time; write only when a change is needed.
  • After power-up all registers read 0 until tracking of the outdoor/indoor units completes.

Notes on this map

  • Source host: the unaltered Samsung manual hosted by a UK distributor; we did not find a public Samsung copy.
  • All values are single 16-bit registers, big-endian. Temperatures are Celsius x10; the manual's ranges go down to -41 °C, so they are listed as signed.
  • The manual marks each point R, W or R/W per unit type (indoor, HE/HT/EHS, AHU kit, ERV, ERV+, chiller, FCU, FCU kit). Read-only points are listed as input registers (FC 04) and writable points as holding registers (FC 03/06/16); the module supports both read functions but the manual does not say which table each read-only point lives in, so try FC 03 if FC 04 is refused.
  • Access shown is the widest across unit types; a point marked '-' for a unit type does not apply to it (e.g. water temperatures only for HE/HT/EHS and chillers, ventilation only for ERV).
  • Left out: the MCC chiller error-information registers (+26/+27, packed bytes) and the reserved ranges.
  • Any write to a holding register is always forwarded to the indoor unit as a command, even if the value is unchanged.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Samsung MIM-B19N Modbus interface module (DVM / EHS / indoor units)

What Modbus registers does the Samsung MIM-B19N Modbus interface module (DVM / EHS / indoor units) have?

This map lists 34 registers: 13 input registers, 21 holding registers. 21 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Samsung MIM-B19N Modbus interface module (DVM / EHS / indoor units) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table prints both a 1-based register number and the Modbus PDU address; the PDU address is used. Indoor unit n (0-47) occupies PDU addresses 50 + n*50 + k. This map lists indoor unit 0 (addresses 50-81); add 50 per unit, e.g. indoor unit 3 on/off = 50 + 150 + 2 = 202.

What are the minimum Modbus registers to integrate the Samsung MIM-B19N Modbus interface module (DVM / EHS / indoor units)?

Start with IR 50 Communication status (Indoor unit 0 communication status); HR 52 Air conditioner on/off (Indoor unit 0 on/off); HR 53 Air conditioner mode (Indoor unit 0 mode); HR 58 Set temperature (Indoor unit 0 set temperature); IR 59 Room temperature (Indoor unit 0 room temperature); IR 63 Integrated indoor unit error code (Indoor unit 0 error code); IR 0 Modbus interface module error status (Module error status).

How do I enable Modbus control of the Samsung MIM-B19N Modbus interface module (DVM / EHS / indoor units)?

Set the Modbus address (1-247) as the sum of the ON DIP switches plus the rotary switch value, connect R1/R2 to the outdoor unit, and give every indoor unit an address 0-47. Reset the module after changing indoor unit addresses or the central-control option.
