Short answer

Packaged rooftop unit whose MicroTech 4 controller speaks Modbus RTU through a plug-on RS-485 module. Everything is a 16-bit holding register: air and refrigerant temperatures, pressures, capacities, setpoints, occupancy and application-mode commands, network enables, status enums and alarm numbers. Values use English or Metric units per a controller setting.

Integration notes: Daikin Applied Rebel / Rebel Applied rooftop (MicroTech 4 controller)

Integration in brief

Set address/baud/parity on the controller HMI (BMS Communication / Modbus Set-Up), apply and cycle power, then read holding registers with function 03. Check register 261 first to know if values are English or Metric, and use 251/252 for occupancy, 249 for application mode and 138-141 for setpoints.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

A Modbus RTU communication module must be fitted. Network address and baud are set only from the HMI (password 2526, BMS Communication / Modbus Set-Up), then 'Apply Changes' and cycle power. Application mode has no effect unless the HMI Control Mode is Auto. Register 264 (Unit Local/Network Control) must read Network (0), set at the HMI, for most network writes to apply.

Communication loss & watchdog

The module's Com LED Timeout (0-3600 s, default 3 s) only turns the bus LED red when the client stops polling; no control fallback on comms loss is documented. Network temperature/RH inputs fall back to local sensors when the network value is unreliable.

Byte order & addressing

  • Printed register numbers are 1-based without the 4xxxx prefix: subtract 1 for the wire address.
  • All values follow the English/Metric setting (register 261); the multiplier stays the same.
  • Writable registers are shown as 'W' in the document but are readable too.
  • Enable registers 162/164/166 use -1 as 'not network-controlled'.

Network setup

  • Address 1-247 (default 1), baud 4800/9600/19200/38400 (default 38400), parity Even/Odd/None (default None), two stop bits Yes/No (default Yes).
  • Load resistor (termination) is a software setting on the module (default No); set Yes at the ends of the segment.
  • Response delay default 5 ms; increase only for slow clients.
  • Network parameters revert to defaults after a controller software field upgrade.

Watch out for

  • Writing Emergency Override (register 255) = Off stops the unit until it is written back to Normal.
  • Current State (252) only acts when Occupancy Mode (251) is Auto.
  • Many points exist only with options (power monitoring, refrigerant monitoring, energy recovery, expansion module).

Notes on this map

  • Network settings (defaults 38400 bps, no parity, 2 stop bits, address 1) come from the companion manual IM 1374-1-1, Modbus RTU Communication Module for MicroTech 4 Rebel and Rebel Applied (Feb 2026): https://tahoeweb.daikinapplied.com/api/general/DownloadDocumentByName/media/IM%201374-1%20MicroTech%20Rebel%20Applied%20Modbus%20Comm%20Manual%200219.pdf
  • The document marks writable registers 'W' and defines that as read-write; they are listed as RW.
  • The document never defines 'x 10' / 'x 100' / 'x 1000'. The only reading consistent with its decimal ranges and defaults (for example '72°F x 10', '-45.6-121.1°C x 10') is raw = value x factor, so scales are 0.1 / 0.01 / 0.001.
  • Units follow register 261 / the module's 'Unit Support' setting (default English). Units shown here are the English ones (°F, psi, in. w.c.); in Metric the same registers carry °C, kPa and Pa with the same multiplier.
  • Signedness is not stated. A register is INT16 only when its published English or Metric range includes negative values (or an enum uses -1); every other register is UINT16. Each kept register's range was checked to fit its type after scaling in both unit systems.
  • The network 'invalid' value for space/outdoor temperature inputs is printed as 621.8 °F / 327.7 °C x10; the raw number is not stated.
  • Left out: every two-register value (energy and power totals 80-115, airflow setpoints 175-176 and 187-190, run-hour counters 191-236) because the document never states the word order for multi-register numbers.
  • Left out: single-register airflows 29, 30 and 172 ('0-60000 cfm x 10' cannot fit in 16 bits), building static pressure 9 (x10 on a ±0.249 in. range is unclear), return fan DSP setpoint 134, exhaust plenum setpoint 135 and OAT 128 (no multiplier printed), and duplicate/unnamed rows (133, 169, 171, 178, 180, 182, 183, 258, 283-287, 292).
  • Left out: air-quality sensors 31-38, circuit 3 points 63-73, generic I/O 300-349 (expansion module) and most configuration enums 353-376. Alarm number meanings (pp. 25-37) are not reproduced.
  • Left out because the '% x 10' multiplier cannot be trusted: this revision shows a mechanical '%' -> '% x 10' edit (register 15 reads '0-100% x 10 x 10', notes read '100% x 10 outdoor air' and 'held at 0% x 10', an alarm text reads '5% x 10' and the ASCII appendix lists '% x 10' for character 37). Every percent register is therefore ambiguous between raw 0-100 and 0-1000: 10, 11, 15, 18, 25, 27, 125, 126, 144, 145, 149-153, 163, 165, 167, 168, 174 and 186.
  • Left out: maximum purge time 184 ('0-300 Min x 10'), because the same edit also produced 'Min x 10' text (Unit State value 4 reads 'Min x 10DAT').
  • Left out: filter pressure 21 (the table cell spans registers 21-23, and '0-1250 Pa x 100' cannot fit 16 bits in Metric) and building static pressure setpoint 137 ('-62.2-62.2 Pa x 1000' cannot fit a signed 16-bit register in Metric). Also not mapped: exhaust air plenum static pressure 24 and Remote Setpoint Source 270/271, power monitor reset 272.
  • Unit State (260) value 4 is printed 'Min x 10DAT', an artefact of the same edit; it is listed with the printed text.
  • The data-bits setting is not stated in ED 19133-2 or IM 1374-1, so it is left null.

Questions about the Daikin Applied Rebel / Rebel Applied rooftop (MicroTech 4 controller)

What Modbus registers does the Daikin Applied Rebel / Rebel Applied rooftop (MicroTech 4 controller) have?

This map lists 112 registers: 112 holding registers. 35 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Daikin Applied Rebel / Rebel Applied rooftop (MicroTech 4 controller) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The protocol document prints holding registers without the 4xxxx prefix (register 8 = 40008) and states that register number 1 is sent as index 0 in the PDU. Wire address = printed number - 1.
