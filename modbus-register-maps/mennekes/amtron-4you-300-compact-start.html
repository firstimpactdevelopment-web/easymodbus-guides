Short answer

These MENNEKES home wallboxes become a Modbus RTU slave ('satellite') on RS-485 when DIP switches S1-4 and S1-5 are on, so an energy manager can control them. Data can be read as holding or input registers. This map covers identity, EVSE and CP state, configured current limits, per-phase current, voltage and power, session and lifetime energy, error codes and the control registers: heartbeat, charging release, current limit, phase switching and lock.

Integration notes: MENNEKES AMTRON 4You 300 / Compact 2.0s / Start 2.0s (Modbus RTU)

Integration in brief

Every 10 s or faster, write 0x55AA to 0x0D00 (heartbeat); write 1 to 0x0D05 (release) and the current limit as a float to 0x0302 with function 16. Read 0x0100 (EVSE state), 0x0E00 (error), 0x0512 (power) and 0x0B02 (session energy).

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set DIP switches S1-4 and S1-5 to ON and reboot; the wallbox then runs as a Modbus satellite at address 50 (10-50 can be set with the MENNEKES configuration tool).

Communication loss & watchdog

The energy manager must write 0x55AA to 0x0D00 at least every 10 s. What happens when it stops depends on 0x030E: 0 keeps charging with the last values received, 1 pauses charging, 6-32 charges at that fallback current. With no fallback active and no EV connected, the wallbox goes to error state (code 200 = energy manager not available); 0x0E01 shows when the fallback is active.

Byte order & addressing

  • 0x0302 = 0 means unlimited, not stop; to pause, write a value between 0.01 and 5.99 A.
  • Floats and uint32 values need function 16 for writes; function 6 is only for single-register values.
  • Requested Phases (0x0D04) is ignored unless 0x030C reads 2 (phase-switch capable hardware, 11 kW models).

Network setup

  • RS-485: Modbus A = +, B = -.
  • Default 57600 baud, 8 data bits, no parity, 2 stop bits; other rates from 9600 to 57600 baud and 8E1 / 8O1 framing can be chosen with the MENNEKES configuration tool.

Watch out for

  • After a reboot or communication error the wallbox needs 0x0D00, 0x0D05 and 0x0302 written again before it returns to idle and charges.
  • MENNEKES recommends changing the current no faster than every 5 s and avoiding frequent pauses; some EVs (e.g. Fiat 500e) need the current set to 0 before a phase change.

Notes on this map

  • The specification states 'Byte and Word Order: Big Endian', so float32 and uint32 values have the high word first (ABCD). Float values are in engineering units with no scaling.
  • Each register lists the register-layout version that introduced it (v01.00-v01.03); registers added in a later layout may be missing on older firmware (0x0114, 0x0D19 and 0x001B arrived with v01.03).
  • Charging current energy manager (0x0302): 0 means no limit and the wallbox signals its maximum (16 or 32 A); 0.01-5.99 A pauses charging; 6 A and up is a limit, clipped to the wallbox's own maximum.
  • Error codes 2300-2305 (over/undervoltage on L1-L3, with voltage detection active) are also listed in the source alongside the codes given under values.
  • Function codes per the source: read 0x03 or 0x04; write single register 0x06 only for 1-register values, write multiple 0x10 for floats (e.g. 0x0302).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Are the MENNEKES AMTRON 4You 300 / Compact 2.0s / Start 2.0s (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed in hex and go on the wire unchanged. The specification gives no example frame, but its table starts at register 0x0000 (Modbus version), which cannot exist in 1-based numbering, so the printed numbers are protocol addresses. So 0x0302 is requested as 770 decimal.

What byte order does the MENNEKES AMTRON 4You 300 / Compact 2.0s / Start 2.0s (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.
