Short answer

The RISH ML 1400/1410 is a 96 x 96 panel meter that measures up to 12 load circuits from 4 voltage inputs. Every measured value is a 32-bit IEEE float available in both the 3X and 4X tables. Integration notes: Rishabh Instruments RISH ML 1400 / ML 1410 Multiload Monitor (Modbus RTU)

Integration in brief

Read the 12 channel currents and powers with function 04 from wire 12 and 36 as ABCD floats; voltages start at wire 0 and frequency is at wire 1468.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set address, baud rate and parity in the meter's communication parameter screen (or the RS485 setup and node address registers).

Byte order & addressing

  • Every value is a 2-register float, even settings.
  • Printed decimal addresses have typos on one page; trust the hex column.

Network setup

  • RS-485, 4800-57600 bps, up to 32 meters per segment.
  • Allow 300 ms response time before retrying.

Watch out for

  • Broadcast (address 0) is not supported.
  • Energy unit and divisor are configurable; check them before scaling energies.

Notes on this map

  • Floats are sent most significant byte first by default; the example reply 43 5B 41 21 decodes to 219.254 V, so ABCD. Writing 2141.0 to the word-order register (46011) in reversed order switches the meter to CDAB for all floats.
  • Each value is in both the 3X table (function 04) and the 4X table (function 03); only the 3X copy is listed.
  • Table 1 prints the wrong decimal 3X/4X numbers for parameters 66-84: parameter 66 is printed one lower (30130, hex 0082) and parameters 67-84 two lower (e.g. 30131 for Angle channel 1, hex 0084). The hex column runs 2 x (parameter - 1) without a break and matches both section 3.1 example frames (Voltage L2 at 00 02, W channel 2 at 00 26), so this map uses the hex address.
  • Energy, demand and overflow-count registers are left out: the energy unit (Wh/kWh/MWh) and divisor are user settings (46091 and related), so a fixed unit cannot be given.
  • Settings registers in Table 3 are also floats; only address, RS485 code and word order are listed. Writes need function 16 with both registers.
  • Channel quantities depend on the channel mode (3P4W, 3P3W, 1P2W, RCM, NC) set for each channel group.
  • Reading part of a float returns exception 02. Keep each request to 120 parameters (240 registers) or fewer.
  • The user-assignable register illustration near the end of section 3 shows parameter addresses 2 higher than Table 1 (e.g. Voltage L2 as 0x0004). The 3.1 example frames and their decoded replies agree with Table 1, so Table 1 is used.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Rishabh Instruments RISH ML 1400 / ML 1410 Multiload Monitor (Modbus RTU)

What Modbus registers does the Rishabh Instruments RISH ML 1400 / ML 1410 Multiload Monitor (Modbus RTU) have?

This map lists 82 registers: 79 input registers, 3 holding registers. 3 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Rishabh Instruments RISH ML 1400 / ML 1410 Multiload Monitor (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Table 1 prints 30001/40001-style numbers plus a hex start-address column. The manual's example reads Voltage L2 (30003, parameter 2) at start address 00 02 and W channel 2 (40039, parameter 20) at 00 26, so subtract 30001 or 40001. Where the printed decimal and the hex column disagree (parameters 66-84), this map follows the hex column, which matches the rule wire = 2 x (parameter - 1).

What byte order does the Rishabh Instruments RISH ML 1400 / ML 1410 Multiload Monitor (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Rishabh Instruments RISH ML 1400 / ML 1410 Multiload Monitor (Modbus RTU)?

Start with IR 0 Voltage L1 (Voltage L1); IR 12 Current channel 1 (Current channel 1); IR 36 W channel 1 (W channel 1); IR 108 PF channel 1 (PF channel 1); IR 1468 Frequency (Frequency).

How do I enable Modbus control of the Rishabh Instruments RISH ML 1400 / ML 1410 Multiload Monitor (Modbus RTU)?

Set address, baud rate and parity in the meter's communication parameter screen (or the RS485 setup and node address registers).
