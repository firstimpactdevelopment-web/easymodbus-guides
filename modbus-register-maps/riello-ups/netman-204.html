Short answer

NetMan 204 is Riello UPS's Ethernet card. Besides SNMP and BACnet it serves a fixed Modbus TCP table on port 502 with UPS state bits, input/bypass/output measurements, battery data, nominal ratings and a small command block. This map covers that whole published UPS table.

Integration notes: Riello UPS NetMan 204 network card (UPS Modbus TCP map)

Integration in brief

Enable Modbus on the card's MODBus/BACNET page, then poll holding registers 11-63 (addresses) over TCP port 502 for measurements and read discrete inputs 0-63 for the state flags. Treat 0xFFFF as 'not available'.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Log in to the card's web page as admin, open the MODBus/BACNET configuration and tick Enable MODBUS. Modbus is not one of the services active from the factory.

Byte order & addressing

  • Register numbers are 1-based; subtract 1 for the wire address.
  • Total output energy is 32-bit with the low word first (registers 59 then 60).
  • Unavailable measurements return 0xFFFF rather than an exception.
  • Commands: write the code to address 112, then read address 116 for the result (code, code+100 if refused, 0 if invalid).

Network setup

  • Factory default is DHCP. Holding the reset button about 10 s until the LED is solid red reboots the card on static 192.168.0.204 / 255.255.0.0 temporarily.
  • Allow about 2 minutes after power-up or reboot before the card answers.
  • Modbus TCP listens on port 502.

Watch out for

  • The same table is used for every Riello UPS family, so many registers stay 0xFFFF on single-phase units.
  • No Modbus unit ID is documented.

Notes on this map

  • Function codes 1/2 read the state bits, 3/4 read all registers (the same table either way, listed here as holding registers), and 6/16 write only the command registers.
  • State bits are listed as discrete inputs at their bit addresses (bit number minus 1). The manual gives bit numbers, not the bit position inside registers 1-4, so the register words themselves are not decoded here.
  • Left out because the manual does not say whether they are signed: battery current (51), negative battery voltage (50), internal UPS temperature (62) and sensor temperatures (63, 64).
  • Special flag registers 121-128 (Sentry 'SENTR' status codes) are not decoded; the manual points to each UPS manual for them.
  • Gaps in the table (e.g. 9-11, 19-21, 45-47) are reserved. Any measurement the connected UPS does not provide reads 0xFFFF.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Riello UPS NetMan 204 network card (UPS Modbus TCP map)

What Modbus registers does the Riello UPS NetMan 204 network card (UPS Modbus TCP map) have?

This map lists 61 registers: 16 discrete inputs, 45 holding registers. 3 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Riello UPS NetMan 204 network card (UPS Modbus TCP map) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables print both a register NUMBER and an ADDRESS column, and a footnote says register n is sent as n-1 (e.g. register 12, input voltage V1, is address 11). State bits likewise: bit number n is bit address n-1. This map uses the ADDRESS column.

What byte order does the Riello UPS NetMan 204 network card (UPS Modbus TCP map) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Riello UPS NetMan 204 network card (UPS Modbus TCP map)?

Start with DI 13 Battery working (Running on battery); DI 12 Battery low (Battery low); DI 31 UPS failure (UPS failure); DI 63 Communication lost with UPS (Card lost the UPS); HR 51 Remaining battery capacity (Remaining battery capacity); HR 53 Remaining back-up time (Remaining back-up time); HR 37 Load phase L1 (Load phase L1); HR 11 Input mains star voltage V1 (Input voltage V1).

How do I enable Modbus control of the Riello UPS NetMan 204 network card (UPS Modbus TCP map)?

Log in to the card's web page as admin, open the MODBus/BACNET configuration and tick Enable MODBUS. Modbus is not one of the services active from the factory.
