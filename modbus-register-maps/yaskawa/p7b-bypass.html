Short answer

The P7B is a P7 fan/pump drive packaged with a bypass contactor panel and HAND/OFF/AUTO switch. Modbus RTU is served by the drive itself (option V, native protocol) using the same hex register layout as the P7, except that 0001H bits 0/1 are run/stop and direction. This map covers the Appendix D reference and monitor data and the Enter commands.

This page lists 25 Modbus registers for the Yaskawa P7B drive/bypass (legacy) - Modbus RTU — 9 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Yaskawa’s own free documentation (linked below) and checked against it.

Integration notes: Yaskawa P7B drive/bypass (legacy) - Modbus RTU

Integration in brief

Put the HAND/OFF/AUTO switch in AUTO, set H5-01..H5-03 at the keypad and power-cycle, set the drive's reference and run source to serial, then write 0001H/0002H with function 10H and poll 0020H-002DH.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set H5-01 (default 1F hex), H5-02 (default 3 = 9600) and H5-03 (default none) and cycle power. The HAND/OFF/AUTO switch must be in AUTO for serial run/stop and speed control; OFF overrides a serial run command. For monitoring only, just the H5 parameters are needed.

Communication loss & watchdog

H5-05 = 1 enables CE detection after the H5-09 time; H5-04 sets the reaction. 002CH bit F shows a comm time-out.

Byte order & addressing

  • Registers are hex and 0-based.
  • Function codes 03H, 06H, 08H and 10H.
  • 0001H bit 0 is run/stop and bit 1 is direction, unlike the stand-alone P7 (bit 0 forward, bit 1 reverse).
  • Parameter writes need 0 written to 0900H (EEPROM) or 0910H (RAM).

Network setup

  • Drive terminals S+, S-, R+, R-; for RS-485 jumper S+ to R+ and S- to R-. Up to 31 drives.
  • Terminating resistor: DIP switch S1-1 on the drive terminal board, ON only at the end of the line.
  • 8 data bits, 1 stop bit; 1200-19200 baud.

Watch out for

  • The OFF position of the HAND/OFF/AUTO switch takes precedence over a serial run command.

Notes on this map

  • TM.P7B.01 does not print Modbus addresses for parameters (b1, H5) or the U monitors, so only the Appendix D data-table registers are included; set H5 at the keypad.
  • 0023H/0024H are listed raw: U1-01/U1-02 units change with o1-03 and the data table gives no resolution.
  • Left out because the manual prints no units or resolution: 0025H output voltage, 0026H output current, 0027H output power, 0028H torque reference and 0031H DC bus voltage.
  • The Enter command text in TM.P7B.01 names registers 0900H or 0901H but its table lists 0900H and 0910H; the table addresses are used here.
  • Broadcast (address 0) accepts only 0001H and 0002H (30000 = 100 %).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Yaskawa P7B drive/bypass (legacy) - Modbus RTU

What Modbus registers does the Yaskawa P7B drive/bypass (legacy) - Modbus RTU have?

This map lists 25 registers: 25 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yaskawa P7B drive/bypass (legacy) - Modbus RTU Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are hex and are sent unchanged: the 03H example reads starting address 00 20 (drive status) and the 10H example writes from 00 01.

How do I enable Modbus control of the Yaskawa P7B drive/bypass (legacy) - Modbus RTU?
