Short answer

The Bosch Control Air 5600 is a BACnet-native DDC controller for water-to-air heat pumps whose EIA-485 port can also run Modbus RTU or N2. The integration points list gives each point a BACnet object and a Modbus register. This map holds the binary commands, alarm and status bits and the mode registers; the floating-point temperatures and setpoints are left out.

Integration notes: Bosch Control Air 5600 water-to-air heat pump controller (Modbus RTU, standard software)

Integration in brief

Set the BAS port to Modbus and EIA-485, address the controller with the rotary dials, then poll discrete input 10002 (unit in alarm) and the UPM alarm bits, read the mode registers (30059/30060) and command occupancy with coil 00001.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Communications jumper in the top (EIA-485) position; BAS Port Settings DIP switches SW3/SW4 select Modbus and SW1/SW2 the baud (9.6, 19.2, 38.4 or 76.8 kbps). The Applications Manual gives the switch table.

Byte order & addressing

  • All analog values are floats with an unstated word order, so only the binary and signed points are listed here.
  • Runtime and UPM reset coils are momentary: write 1, then 0.

Network setup

  • Rotary dials (tens/ones) set the address up to 99; the controller only reads them at power-up.
  • Parity, stop bits and default address are not stated in the documents.

Watch out for

  • Occupancy command (coil 00001) defaults to unoccupied, which keeps the unit off until the BAS sets it.
  • Coil 00006 (BAS loop enable) must be 1 for heating/cooling.

Notes on this map

  • Left out: every point typed 'Holding Register (Float)' or 'Input Register (Float)' (setpoints, temperatures, configuration values, demand percentages). They are IEEE floats over two registers, and neither the points list nor the Control Air 5600 Applications Manual states the word order.
  • Also left out: row 39 'Cooling Demand Percentage' (type cell cut to 'Holding', probably float) and rows 18-19 (Equipment Touch selections with no register).
  • The 'Signed' multi-state registers are treated as one 16-bit signed register each.
  • Row 91 (Compressor 1 Runtime, discrete input 10006) carries the fan-mode text in the source; its states are not given here. Compressor 2 runtime (10007) is 1 = run-time timer expired.
  • Some state texts are printed the opposite way to their neighbours (10015 economizer cooling 0 = On, 10005 circulation pump 0 = running); they are copied as printed.
  • The same register list appears as section 13 of the Control Air 5600 Applications Manual BTC 761601101 C (01.2026), which also covers the DIP switches and rotary address: https://www.bosch-homecomfort.com/us/media/country_pool/documents/application-manual/controls/control_air_5600_applications_manual_01.2026.pdf

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Bosch Control Air 5600 water-to-air heat pump controller (Modbus RTU, standard software)

What Modbus registers does the Bosch Control Air 5600 water-to-air heat pump controller (Modbus RTU, standard software) have?

This map lists 86 registers: 12 coils, 70 discrete inputs, 2 input registers, 2 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Bosch Control Air 5600 water-to-air heat pump controller (Modbus RTU, standard software) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed Modicon style: coils 00001 up, discrete inputs 10001 up, input registers 30001 up, holding registers 40001 up. Subtract the base (and 1) for the wire address, e.g. discrete input 10013 = wire 12.

What are the minimum Modbus registers to integrate the Bosch Control Air 5600 water-to-air heat pump controller (Modbus RTU, standard software)?

Start with CO 0 Occupancy Command (BAS) (BAS occupancy command); DI 1 Alarm Status (Unit in alarm); DI 7 Comp Stage1 Output Cmd (Compressor stage 1 output); DI 34 UPM Safety - High Pressure Alarm (UPM high-pressure alarm); IR 59 Zone Mode Status (Zone mode status); HR 123 Set Zone Mode (Set zone mode); CO 5 BAS Loop Enable/Disable (BAS loop enable (heat/cool allowed)).

How do I enable Modbus control of the Bosch Control Air 5600 water-to-air heat pump controller (Modbus RTU, standard software)?

Communications jumper in the top (EIA-485) position; BAS Port Settings DIP switches SW3/SW4 select Modbus and SW1/SW2 the baud (9.6, 19.2, 38.4 or 76.8 kbps). The Applications Manual gives the switch table.
