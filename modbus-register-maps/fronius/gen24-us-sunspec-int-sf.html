Short answer

The US GEN24 map carries the same SunSpec models as the rest-of-world map (common, inverter 101/103, nameplate, settings, status, controls, MPPT 160, storage 124) and then the IEEE 1547-2018 information models 701-713. This map covers the 16-bit values and controls of models 1-124 plus the AC measurement (701), capacity ratings (702), enter-service (703), AC controls (704) and storage capacity (713) blocks; the voltage/frequency trip and curve models 705-712 are left out.

Integration notes: Fronius Primo GEN24 Plus / Symo GEN24 Plus US (SunSpec int+SF with 700-series models)

Integration in brief

Enable the Modbus TCP server in the inverter web UI with int+SF and Allow Control, then poll unit ID 1. Live data is in models 103 (40070-40109) and 701; power limits can be written either through model 123 or the IEEE 1547 controls in model 704.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Inverter web interface > Communication > Modbus: choose TCP Server and/or RTU Server, set SunSpec Model Type int+SF, and activate 'Allow Control' for power, power factor, reactive power and battery commands.

Communication loss & watchdog

Model 123 controls have *_RvrtTms fallback timers (0-28800 s) that restart with every Modbus message; model 124 has InOutWRte_RvrtTms. Model 704 holds reversion setpoints (the *Rvrt registers) that apply when its reversion timer expires; those timers are 32-bit and not included here.

Byte order & addressing

  • Off-by-one: SunSpec registers are numbered from 40001; request number minus one.
  • Switching float/int+SF changes the address of every model after the inverter model.
  • Battery power appears as MPPT inputs 3 (charge) and 4 (discharge).

Network setup

  • TCP: inverter unit ID is always 1; port 502 or 1502 selectable in the web UI.
  • RTU: set Inverter address (1-247, factory 1), baud and parity in the web UI.

Watch out for

  • Query sequentially (at most 2 requests in parallel) with a response timeout of at least 1 s.
  • After changing a value of an active mode, re-write the matching enable register with 1.

Notes on this map

  • Register table from Fronius' official XLSX 'Gen24_Primo_Symo_Inverter_Register_Map_Int&SF_storage_US.xlsx' in gen24-modbus-api-external-docs.zip; changelog 1.2.4-0 says the US files add the 7xx series. Behaviour and settings from the PDF.
  • Models 1-124 sit at the same addresses as in the rest-of-world storage map; the 7xx models start at 40370 and the end block is at 41890.
  • Word order: neither the PDF nor the XLSX states the order of 32/64-bit values, so every 32/64-bit point is left out (SID, WH, event fields, ActWh, StActCtl, Tms, MPPT DCWH/Tms, and the 32-bit points of models 701-713 such as frequency, energy counters and timers).
  • Left out: inverter-model DCA/DCV (40097-40100), every point the XLSX marks not supported, and the trip/curve models 705-712 (volt-var, volt-watt, LV/HV/LF/HF trip, frequency droop, watt-var).
  • Many scale factors are auto-scaled: read each value and its SF in the same request. Unsupported values read int16 0x8000, uint16/enum16 0xFFFF.
  • Ranges marked 'may vary based on inverter configuration or country setup' (voltage ratings, power factor limits, enter-service thresholds) are installation dependent.

Questions about the Fronius Primo GEN24 Plus / Symo GEN24 Plus US (SunSpec int+SF with 700-series models)

What Modbus registers does the Fronius Primo GEN24 Plus / Symo GEN24 Plus US (SunSpec int+SF with 700-series models) have?

This map lists 236 registers: 236 holding registers. 43 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Fronius Primo GEN24 Plus / Symo GEN24 Plus US (SunSpec int+SF with 700-series models) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Fronius numbers SunSpec registers from 40001 and says to send the register number minus one: register 40001 is read at address 40000 (0x9C40). The manual's RTU example reads register 40005 (Mn) with address bytes 9C 44 (40004).

What are the minimum Modbus registers to integrate the Fronius Primo GEN24 Plus / Symo GEN24 Plus US (SunSpec int+SF with 700-series models)?

Start with HR 40069 Inverter ID (Inverter model ID (101/103) - confirms int+SF layout); HR 40083 W (AC power); HR 40084 W_SF (AC power scale factor); HR 40107 St (Operating state); HR 40351 ChaState (Battery state of charge); HR 40365 ChaState_SF (SoC scale factor); HR 40232 WMaxLimPct (Active power limit % (model 123)); HR 40236 WMaxLim_Ena (Enable the power limit); HR 40609 WMaxLimPctEna (IEEE 1547 active power limit enable (model 704)).

How do I enable Modbus control of the Fronius Primo GEN24 Plus / Symo GEN24 Plus US (SunSpec int+SF with 700-series models)?

Inverter web interface > Communication > Modbus: choose TCP Server and/or RTU Server, set SunSpec Model Type int+SF, and activate 'Allow Control' for power, power factor, reactive power and battery commands.

What happens when the Fronius Primo GEN24 Plus / Symo GEN24 Plus US (SunSpec int+SF with 700-series models) loses Modbus communication?

Model 123 controls have *_RvrtTms fallback timers (0-28800 s) that restart with every Modbus message; model 124 has InOutWRte_RvrtTms. Model 704 holds reversion setpoints (the *Rvrt registers) that apply when its reversion timer expires; those timers are 32-bit and not included here.
