Short answer

Liquid-to-liquid coolant distribution unit that moves heat from a direct-to-chip server loop (TCS) to facility water (FWS) using two variable-speed pumps and a control valve. Modbus TCP exposes one block of 16-bit holding registers: pressures, flows, temperatures, pump and valve values, setpoints, sensor range states and packed status and error words.

Integration notes: Trane TCDU coolant distribution unit (data-centre liquid cooling)

Integration in brief

Connect to the TCDU's Telemetry Control RJ45 with Modbus TCP on port 503 (not 502) and read holding registers 40001-40096. Setpoints sit in 40046-40062 and the control word in 40092.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP is served on the RJ45 port labelled Telemetry Control (also used for data-log download and the REST API). The port takes a DHCP address by default; a fixed IP is set by logging into the internal IOT2050 module over SSH, editing the connection with nmtui and rebooting it.

Byte order & addressing

  • TCP port is 503, not the usual 502.
  • All values are signed 16-bit with fixed decimal multipliers; there are no 32-bit registers, so each pump's energy is split into a kWh register and an MWh register.

Network setup

  • Find the unit's IP on the DHCP server, or set a fixed IP on the IOT2050 module (service port P1-X1, default 192.168.2.40; credentials are supplied separately by Trane).
  • Point the client at port 503; the manual does not state a unit ID.

Watch out for

  • Several status bits are active-low (E-stop, safety relay, leak detection, inverter state): 1 means normal.
  • Register 40001 counts 1-255 continuously; use it to confirm the link is alive.

Notes on this map

  • Every register is a signed 16-bit value (data type 'INT 16'). The 'Multiplier' column is the factor applied before sending (x10 means 25.3 °C is sent as 253), so scales here are 0.1 / 0.01. The manual's REST API table states the same read scales (x0.1 for temperature, percent and kW, x0.01 for pressure).
  • Pressure units are bar gauge as printed ('barg'); flow is litres per minute ('LPM').
  • The 23 'State' registers (40065-40087) are described only as 'per enumeration range state below', but no state table follows in this revision; their codes are left blank.
  • The threshold pointer block (40088-40090) needs an index-to-threshold table that the register list does not include, and the threshold value's multiplier is printed as 'Varies'.
  • Left out: spare and reserved registers (40019-40022, 40050, 40064, 40097-40101) and FWS dT limiting setpoint 40063 (printed with no multiplier, unit or description).
  • TCS Pump 2 Pressure (40025) carries the description of pump 1 in the source; the register name says pump 2 and is used here.
  • Register numbers are printed from 40001 in 5-digit Modicon form; the manual gives no separate offset statement, so 40001 is taken as wire address 0.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Trane TCDU coolant distribution unit (data-centre liquid cooling)

What Modbus registers does the Trane TCDU coolant distribution unit (data-centre liquid cooling) have?

This map lists 89 registers: 89 holding registers. 20 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Trane TCDU coolant distribution unit (data-centre liquid cooling) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register list prints Modicon holding registers starting at 40001, so 40001 is wire address 0 and 40049 is wire address 48.

What are the minimum Modbus registers to integrate the Trane TCDU coolant distribution unit (data-centre liquid cooling)?

Start with HR 1 Summarized fault / common fault (Common fault summary); HR 31 TCS supply temperature (TCS supply temperature); HR 32 TCS return temperature (TCS return temperature); HR 29 TCS flow rate 1 (TCS flow rate); HR 36 TCS cooling (TCS cooling kW); HR 12 FWS input temperature (FWS supply temperature); HR 48 TCS supply temperature setpoint (TCS supply temperature setpoint); HR 90 System status bits (System status bits); HR 0 Modbus comm check counter (Heartbeat counter).

How do I enable Modbus control of the Trane TCDU coolant distribution unit (data-centre liquid cooling)?

Modbus TCP is served on the RJ45 port labelled Telemetry Control (also used for data-log download and the REST API). The port takes a DHCP address by default; a fixed IP is set by logging into the internal IOT2050 module over SSH, editing the connection with nmtui and rebooting it.
