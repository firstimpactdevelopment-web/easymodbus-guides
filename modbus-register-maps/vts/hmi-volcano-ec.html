VTS HMI-VOLCANO EC controller for VOLCANO air heaters Modbus register map

Updated 17 November 2026

Short answer

The HMI-VOLCANO EC is the room controller for VTS VOLCANO EC fan heaters, which can run in heating or cooling mode. Over Modbus RTU a BMS can switch it on and off, choose heating or cooling, set the fan output and room setpoint, edit the weekly schedule and read the room temperature, schedule state and output states.

This page lists 49 Modbus registers for the VTS HMI-VOLCANO EC controller for VOLCANO air heaters — 39 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from VTS’s own free documentation (linked below) and checked against it.

Integration notes: VTS HMI-VOLCANO EC controller for VOLCANO air heaters

Integration in brief

Switch the unit with coil 2, select heating/cooling with holding 21, set the room setpoint (0.01 °C) in holding 23 and fan output % in holding 22; read the room temperature from input register 0.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is always active on the RS485 terminals (J3 A/B); change baud, parity and address through holding registers 0-2 (the device restarts after each change).

Byte order & addressing

  • Setpoints are rounded to 0.5 °C and schedule times to 15 minutes.
  • Parity is written as the ASCII code of 'e', 'o' or 'n'; 'n' uses 2 stop bits.
  • Writing a setpoint below MIN or above MAX is refused.

Network setup

  • RS485 on terminal block J3 (A, B, ground).
  • Default 9600 baud, even parity, address 1.

Watch out for

  • A sensor fault reads -32768 (shown as 327.68 when treated as unsigned).

Notes on this map

  • Holding registers 0-3 (baud, parity, address, sensor correction) must be written one per message; a multi-register write that includes them is refused.
  • Temperatures are in 0.01 °C (value / 100). When the controller is set to °F, temperature registers are in °F with the same scale.
  • Left out: coils 5 and 6 (temperature unit and clock format) and holding register 40 (fan regulation mode), which appear only in the default-value table and not in the register tables.
  • Defaults per the default-value table: 9600 baud (960), even parity, address 1, setpoint 22.00 °C, ECO 18.00 °C.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the VTS HMI-VOLCANO EC controller for VOLCANO air heaters

What Modbus registers does the VTS HMI-VOLCANO EC controller for VOLCANO air heaters have?

This map lists 49 registers: 5 coils, 2 discrete inputs, 2 input registers, 40 holding registers. 39 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the VTS HMI-VOLCANO EC controller for VOLCANO air heaters Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every table gives the address 'for PDU' in decimal and hex (first register 0 = 0x0000), so that address goes on the wire unchanged. The function-code examples count registers from 1 instead (register 108 is requested as 0x006B = 107), which matches: PDU address = register number - 1. This map uses the 'for PDU' column.

What are the minimum Modbus registers to integrate the VTS HMI-VOLCANO EC controller for VOLCANO air heaters?

Start with CO 2 MB_ADDR_POWER_ON_OFF (On/off); HR 21 MB_ADDR_ZONE_MODE (Heating/cooling); HR 23 MB_ADDR_ZONE_TEMPERATURE_TARGET (Room setpoint); HR 22 MB_ADDR_ZONE_FAN_SPEED (Fan output %); IR 0 MB_ADDR_ZONE_TEMPERATURE_ACTUAL (Room temperature); IR 1 MB_ADDR_ZONE_ACTUAL_PROGRAM_STATE (Schedule state); HR 19 MB_ADDR_ZONE_PROGRAM (Continuous or schedule).

How do I enable Modbus control of the VTS HMI-VOLCANO EC controller for VOLCANO air heaters?

Modbus RTU is always active on the RS485 terminals (J3 A/B); change baud, parity and address through holding registers 0-2 (the device restarts after each change).
