Short answer

The Liebert CRV is a row-based precision cooling unit that sits between IT racks. Through a Liebert IntelliSlot Modbus card its iCOM v4 controller is a Modbus RTU / TCP slave. The map covers supply and return air temperatures, dew point and humidity, remote rack sensors, setpoints and alarm thresholds, fan speed and capacity, condenser data, system on/off and status, and the event bits.

This page lists 176 Modbus registers for the Vertiv Liebert CRV in-row cooling unit with iCOM v4 (IntelliSlot Modbus) — 41 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Vertiv’s own free documentation (linked below) and checked against it.

Integration notes: Vertiv Liebert CRV in-row cooling unit with iCOM v4 (IntelliSlot Modbus)

Integration in brief

Read 30385-30395 for air temperatures, 30474-30477 for status and 30451-30455 for fan and capacity. Write 40478 to switch the unit on/off and 40397 for the air temperature setpoint in tenths of deg C.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Liebert IntelliSlot card the guide lists for the unit's controller (for iCOM v4 units: IS-485L for Modbus 485, IS-IPBML for Modbus IP / BACnet IP) and set its Modbus address and line speed on the card.

Communication loss & watchdog

Holding register 40448 'BMS Timeout Period' (minutes) sets how long the unit waits for BMS communication before a timeout event; the resulting action is not described in this guide.

Byte order & addressing

  • Modicon numbering: subtract 40001 / 30001 / 10001 for the wire address.
  • On/off is a holding register here (40478), not a coil.
  • Low-noise-mode day selections (40494, 40495) are bit masks: bit 0 Monday ... bit 6 Sunday.

Network setup

  • RS-485 (2-wire) RTU settings for the IntelliSlot 485 card: 9600, 19200 or 38400 baud, 8 data bits, no parity, 1 stop bit.
  • Each unit needs a unique Modbus slave address on the RS-485 line.
  • For Modbus IP, use the IntelliSlot Modbus IP / BACnet IP card listed for the unit's controller in the guide's compatibility table.

Watch out for

  • Humidity setpoint and humidification/dehumidification bands (40413-40415) are whole %RH, while the humidity dead band and thresholds (40416-40418) are tenths.

Notes on this map

  • Source: Emerson Network Power / Liebert reference guide SL-28170 (Rev 9). Vertiv does not host this guide publicly; the linked copy is the unaltered PDF on the Contemporary Controls support site.
  • Scale column: 'x / 10' means the raw value is tenths (scale 0.1); '-' or blank means no scaling. Some temperature setpoints are printed without a scale while similar points use x / 10; they are transcribed exactly as printed.
  • Most temperatures exist twice: once in deg C and once in deg F at a different register. Only the deg C registers are listed here.
  • Points that the guide lists with both an input register (3xxxx) and a holding register (4xxxx) are the writable settings; we list the holding register (read/write). The same value can also be read at the matching 3xxxx input register (same offset).
  • Signedness is not stated in the guide. Temperature values are listed as INT16 (they can be below zero); everything else as UINT16.
  • Points that take two registers (date/time and schedule start/stop times, 32-bit values) are left out because the guide does not state their word order.
  • Event/alarm discrete inputs read 1 while the event is active ('Active on Alarm').
  • Event acknowledge/reset (40500) is a holding register only; write 2 to reset or 4 to acknowledge, per the guide.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Vertiv Liebert CRV in-row cooling unit with iCOM v4 (IntelliSlot Modbus)

What Modbus registers does the Vertiv Liebert CRV in-row cooling unit with iCOM v4 (IntelliSlot Modbus) have?

This map lists 176 registers: 91 discrete inputs, 44 input registers, 41 holding registers. 41 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vertiv Liebert CRV in-row cooling unit with iCOM v4 (IntelliSlot Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints Modicon-style numbers: discrete inputs 1xxxx, input registers 3xxxx, holding registers 4xxxx. Its RTU example asks for holding register 40051 with start offset 50 (0x0032), so subtract 10001 / 30001 / 40001 to get the wire address. Coils are printed as plain numbers on the same scale as the discrete inputs (coil 25 sits beside status 10025), so coil n is wire address n-1.

What are the minimum Modbus registers to integrate the Vertiv Liebert CRV in-row cooling unit with iCOM v4 (IntelliSlot Modbus)?

Start with HR 477 System On/Off Control (System on/off control); IR 474 System Operating State (System operating state); IR 473 System Status (System status); IR 384 Supply Air Temperature (Supply air temperature); IR 386 Return Air Temperature (Return air temperature); IR 411 Return Humidity (Return humidity); HR 396 Air Temperature Set Point (Air temperature setpoint); IR 450 Fan Speed (Fan speed); HR 499 System Event Acknowledge/Reset (Acknowledge / reset events).

How do I enable Modbus control of the Vertiv Liebert CRV in-row cooling unit with iCOM v4 (IntelliSlot Modbus)?

Fit the Liebert IntelliSlot card the guide lists for the unit's controller (for iCOM v4 units: IS-485L for Modbus 485, IS-IPBML for Modbus IP / BACnet IP) and set its Modbus address and line speed on the card.

What happens when the Vertiv Liebert CRV in-row cooling unit with iCOM v4 (IntelliSlot Modbus) loses Modbus communication?

Holding register 40448 'BMS Timeout Period' (minutes) sets how long the unit waits for BMS communication before a timeout event; the resulting action is not described in this guide.
