Short answer

The DMG7000-DMG9000 are Lovato's 96x96 panel power analyzers. They answer Modbus RTU, ASCII or TCP depending on the communication port used, and EXS4 Easy Branch current modules on the same channel appear as extra Modbus nodes. Measurements are fixed-point 32-bit integers sent high word first. This map covers voltages, currents, powers, power factor, frequency, unbalance, THD, max demand, hour counter, I/O status, the real-time clock and the reset, tariff and remote-variable commands.

This page lists 58 Modbus registers for the Lovato Electric DMG7000 / DMG7500 / DMG8000 / DMG9000 power analyzers — 10 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lovato Electric’s own free documentation (linked below) and checked against it.

Integration notes: Lovato Electric DMG7000 / DMG7500 / DMG8000 / DMG9000 power analyzers

Integration in brief

Read the measurement block with function 04 (or 03) starting at wire address 1 (printed 0x0002) and decode each pair as a 32-bit integer, high word first, applying the printed divisor. Remember to subtract 1 from every printed address.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus runs on the meter's communication port; the protocol variant (RTU, ASCII or TCP) follows the port in use. Set the node address in parameter P07.n.01 on the DMG and P20.n.05 for each Easy Branch measuring point.

Byte order & addressing

  • Printed addresses are one above the wire address (0x0002 is requested as 0x0001).
  • All 32-bit values are high word first (ABCD).
  • Writing 5 to 0x2F03 saves and reboots the meter with no Modbus reply; do not treat the timeout as a failure.
  • Remote variables are switched by writing 0xAA (on) or 0xBB (off) to their own register.

Network setup

  • Default node address is 1; Easy Branch points follow as 2, 3, 4...
  • Up to 120 registers per read; one TCP client per physical port.

Watch out for

  • Energy counters are not in this map; their 4-register 'Long' format is ambiguous in the manual.
  • DMG9000-only rows (V4, I4, earth current, power quality) return errors or zero on the smaller models.

Notes on this map

  • Byte and word order are big endian (high word first), so every 2-register value is ABCD.
  • Measurement registers are read with function 03 or 04 (same data); they are listed as input registers. At most 120 registers per request; Modbus TCP accepts one connection per physical port.
  • Scale is the divisor printed in the Unit column: V/100 = 0.01 V, A/10000 = 0.0001 A, kW/100000 = 0.00001 kW (0.01 W), Hz/1000, PF /10000, %/100.
  • Several power rows carry a '(1)' marker in the Unit column, but no footnote text for it appears in the English/Polish, English/Chinese or English/Russian editions. The printed scale is used here; confirm power readings against the front display at commissioning.
  • Left out: all energy counters (0x1B20-0x1CFC). The table gives them 4 registers each but labels the format 'Unsigned Long' / 'Signed Long', which normally means 32 bits, so the bit width cannot be decoded with certainty.
  • Left out: alarm, PLC, limit and remote-variable status blocks (0x2120-0x2140, 0x4F00 read), which are 40-bit fields across 3 registers without a stated word arrangement; min/max/average copies, harmonic spectra, angles, crest and k-factors, analogue inputs, counters and the DMG9000 power-quality statistics.
  • Left out: parameter setup through menu/submenu/parameter selector registers (0x5000-0x5004); the example frames use addresses one lower than the table, as noted under addressing.
  • Function 0x11 (report slave ID) returns a model code: 0x70 DMG7000, 0x75 DMG7500, 0x80 DMG8000, 0x90 DMG9000, 0x40 EXS4.
  • EXS4 Easy Branch measuring points answer on their own node numbers (by default the DMG is node 1 and branch points take 2, 3, ...), with the subset of registers the manual marks as available for EXS4.
  • Verifier: all seven example frames in the parameter-setup section carry valid CRCs, so the minus-one rule is taken from genuine frames (0x5000->4FFF, 0x5001->5000, 0x5002->5001, 0x5004->5003, 0x2F03->2F02).
  • Verifier: the energy-counter width is not settled anywhere in the document - no 64-bit statement and no example frame for the 4-register rows, and total export energy is even typed 'Signed Long' - so they stay out.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Lovato Electric DMG7000 / DMG7500 / DMG8000 / DMG9000 power analyzers

What Modbus registers does the Lovato Electric DMG7000 / DMG7500 / DMG8000 / DMG9000 power analyzers have?

This map lists 58 registers: 48 input registers, 10 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lovato Electric DMG7000 / DMG7500 / DMG8000 / DMG9000 power analyzers Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables print hex register numbers that are one higher than the address sent on the wire. The manual's own example frames prove it: the table puts 'parameter value' at 0x5004, 'save to flash' at 0x2F03 and 'menu select' at 0x5000, and the example requests send 50 03, 2F 02 and 4F FF. So subtract 1: L1 voltage, printed 0x0002, is requested at address 0x0001. The same rule is applied to every register here.

What byte order does the Lovato Electric DMG7000 / DMG7500 / DMG8000 / DMG9000 power analyzers use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lovato Electric DMG7000 / DMG7500 / DMG8000 / DMG9000 power analyzers?

Start with IR 1 L1 phase voltage (L1 phase voltage (V/100)); IR 7 L1 current (L1 current (A/10000)); IR 57 Total active power (Total active power (kW/100000, signed)); IR 63 Total power factor (Total power factor); IR 49 Frequency (Frequency); IR 83 THD voltage L1 (THD voltage L1); IR 2615 Max demand active power total (Max demand active power).

How do I enable Modbus control of the Lovato Electric DMG7000 / DMG7500 / DMG8000 / DMG9000 power analyzers?
