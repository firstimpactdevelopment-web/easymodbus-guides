Shinko Technos ACS2 digital indicating controller (C5, C5W options) Modbus register map

Updated 17 November 2026

Short answer

The ACS2 is a Shinko PID temperature controller with SV memories, program control and several PID modes. With the C5/C5W option it speaks Shinko protocol, Modbus RTU or MC protocol on RS485; all items are 16-bit holding registers. This map covers SV memories, input setup, EV1 alarm handling, control mode and key function settings, and the full read block from 03E8H (PV, MV, SV, status, error and heater current).

This page lists 47 Modbus registers for the Shinko Technos ACS2 digital indicating controller (C5, C5W options) — 31 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Shinko Technos’s own free documentation (linked below) and checked against it.

Integration notes: Shinko Technos ACS2 digital indicating controller (C5, C5W options)

Integration in brief

In the Communication setting group choose MODBUS RTU, an 8-bit data format and a non-zero instrument number. Poll PV 03E8H, OUT1 MV 03E9H, status 03ECH/03EDH and errors 03F5H; write SV1 at 0001H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Requires the C5 or C5W option. In RUN mode step through the setting groups to the Communication setting group and enter it (keys shown on p. 4), set Communication protocol to MODBUS RTU mode, then instrument number, speed, data bit/parity and stop bit.

Byte order & addressing

  • Factory data format is 7 bits/Even; Modbus RTU needs an 8-bit choice.
  • Instrument number defaults to 0, the Modbus broadcast address; set 1-95.
  • Modbus ASCII is not offered on this model; protocols are Shinko, MODBUS RTU, MC protocol and SVTC.

Network setup

  • Factory defaults: Shinko protocol, instrument 0, 9600 bps, 7 bits/Even.
  • Speeds 9600 to 115200 bps.

Watch out for

  • Data clear (00D8H) also resets communication settings, so the unit may stop answering with the current master settings.

Notes on this map

  • Only a subset of the setting table is mapped: PID terms, EV2/EV3, output and many other setting items on pp. 22-27 are left out, as are program pattern commands (section 7.1.3 onward).
  • All data are 16-bit two's complement. Items marked 'decimal point ignored' are whole numbers; apply the decimal point of the input range.
  • Error status flag (03F5H): the manual states 0 = normal, 1 = error only for bit 11; the other bits are listed without a polarity legend.
  • Writing data clear (00D8H) restores factory settings including communication settings; not mapped here.

Questions about the Shinko Technos ACS2 digital indicating controller (C5, C5W options)

What Modbus registers does the Shinko Technos ACS2 digital indicating controller (C5, C5W options) have?

This map lists 47 registers: 47 holding registers. 31 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos ACS2 digital indicating controller (C5, C5W options) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are listed as hex data items (0001H) that go into the request unchanged. The manual adds that the matching Modicon holding-register number is the item in decimal plus 40001 (0001H = 40002).

What are the minimum Modbus registers to integrate the Shinko Technos ACS2 digital indicating controller (C5, C5W options)?

Start with HR 1000 PV (Process value); HR 1 SV1 setting (Set value SV1); HR 1001 OUT1 MV (OUT1 manipulated value); HR 1004 Status flag 1 (Output and alarm status); HR 1013 Error status flag (Error status); HR 1005 Status flag 2 (Run mode status).

How do I enable Modbus control of the Shinko Technos ACS2 digital indicating controller (C5, C5W options)?

Requires the C5 or C5W option. In RUN mode step through the setting groups to the Communication setting group and enter it (keys shown on p. 4), set Communication protocol to MODBUS RTU mode, then instrument number, speed, data bit/parity and stop bit.

Where is the official Shinko Technos ACS2 digital indicating controller (C5, C5W options) Modbus documentation?

The source is Communication Instruction Manual ACS2 (C5W, C5) (No. ACS2CE3), revision 2026-08, published free by Shinko Technos at https://shinko-technos.co.jp/e/manual/english/ACS2CE3.pdf.
