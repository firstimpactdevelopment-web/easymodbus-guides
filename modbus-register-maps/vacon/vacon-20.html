Integration notes: Vacon VACON 20 AC drive (built-in Modbus RTU)

Integration in brief

Set P2.2 = 1 (Modbus), the address and baud in P2.3/P2.4, P2.1 = 1 (fieldbus control place) and P3.3 = 3 (fieldbus reference). Then write 2001 = 1 (run) with 2003 = speed in 0.01 % of the min-max range, and poll 2101 status, 2103 actual speed and 2105-2111.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the system menu set P2.2 Fieldbus protocol = 1 (Modbus), P2.3 slave address (factory 1), P2.4 baud rate (factory 9600) and P2.6 parity (factory none, which uses 2 stop bits). Then set P2.1 = 1 so the fieldbus is the control place and P3.3 = 3 for a fieldbus frequency reference.

Communication loss & watchdog

P2.7 Communication time out (ID 814): 0 = not used, otherwise 1-255 s (factory 10 s).

Byte order & addressing

  • IDs map to Modicon 4xxxx (and 3xxxx) references: wire address = ID - 1.
  • With parity None the drive uses 2 stop bits; with even or odd parity it uses 1.
  • Speed reference and actual speed are 0.01 % of the range between minimum and maximum frequency, not of maximum frequency.

Network setup

  • RS-485 A/B are I/O terminals A and B; the built-in 120 ohm termination is switched by the right-hand DIP switch above the I/O terminals (off by default).
  • The built-in Modbus is only used when no fieldbus option board is fitted.

Watch out for

  • Multi-register reads must cover consecutive IDs, at most 11 per request.
  • The Loc/Rem button (or local control) moves the control place to the keypad, away from the fieldbus.

Notes on this map

  • Process data out 2-8 (2105-2111) are assignable with P10.2-P10.8; the scale and units listed are the manual's values for the factory content.
  • Register 2104 (P10.1, default frequency reference) is left out because the manual gives no scale for it; 2002/2102 general control and status words are left out because their bit table does not extract cleanly; 2004-2011 input words are application-assignable (P10.9, PID, analog output, aux control word).
  • Monitoring IDs V1.x (e.g. output frequency ID 1, motor current ID 3) are readable by ID but the manual gives only units, not the Modbus resolution, so they are not listed.
  • Up to 11 consecutive IDs can be read in one request.
  • Supported functions: 03, 04, 06 and 16; broadcast only for writes.

Questions about the Vacon VACON 20 AC drive (built-in Modbus RTU)

What Modbus registers does the Vacon VACON 20 AC drive (built-in Modbus RTU) have?

This map lists 18 registers: 18 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vacon VACON 20 AC drive (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints each process data item as two Modicon references, e.g. 32101/42101 for ID 2101 (input register or holding register), and says some PLC drivers need 1 subtracted from the ID. So ID n is holding register 4xxxx = 40000 + n, wire address n - 1 (status word 2101 -> address 2100; P2.1 ID 172 -> address 171). The same data can also be read with function 04 as input registers.

What are the minimum Modbus registers to integrate the Vacon VACON 20 AC drive (built-in Modbus RTU)?

Start with HR 2000 FB Control word (FB control word); HR 2002 FB Speed reference (Speed reference, 0.01 %); HR 2100 FB Status word (FB status word); HR 2102 FB Actual speed (Actual speed, 0.01 %); HR 2104 Process data out 2 (default output frequency) (Output frequency (default), 0.01 Hz); HR 2108 Process data out 6 (default motor current) (Motor current (default), 0.01 A); HR 171 P2.1 Remote control place 1 selection (P2.1 control place).

How do I enable Modbus control of the Vacon VACON 20 AC drive (built-in Modbus RTU)?

In the system menu set P2.2 Fieldbus protocol = 1 (Modbus), P2.3 slave address (factory 1), P2.4 baud rate (factory 9600) and P2.6 parity (factory none, which uses 2 stop bits). Then set P2.1 = 1 so the fieldbus is the control place and P3.3 = 3 for a fieldbus frequency reference.

What happens when the Vacon VACON 20 AC drive (built-in Modbus RTU) loses Modbus communication?

P2.7 Communication time out (ID 814): 0 = not used, otherwise 1-255 s (factory 10 s).
