ABB M4M 20 / M4M 30 network analyzer Modbus register map

Updated 16 October 2026

Short answer

The M4M 20 and M4M 30 are ABB panel-mount network analyzers available with an RS-485 Modbus RTU or an Ethernet Modbus TCP port. All data sits in holding registers at hex addresses that are sent on the wire unchanged, with 64-bit energy and 32-bit instantaneous values high word first. This map covers total, tariff and per-phase energy, real-time electrical values, THD summaries, device info, transformer ratios and the RTU/TCP communication settings.

This page lists 152 Modbus registers for the ABB M4M 20 / M4M 30 network analyzer — 26 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ABB’s own free documentation (linked below) and checked against it.

Integration notes: ABB M4M 20 / M4M 30 network analyzer

Integration in brief

Read holding registers with function 3 at the hex address from the map (for example 0x5B02 for phase voltage L1). Energy is 4 registers at 0.01 kWh; voltages, currents and powers are 2 registers, high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is built in on the Modbus RTU and Ethernet (Modbus TCP) versions; set address, baud rate and parity (RTU) or DHCP/IP/port (TCP) on the device or through registers 8CEB-8CF6.

Byte order & addressing

  • Hex wire addresses; no 40001 offset.
  • Writes to unsupported but writable registers are not rejected; read back to confirm.
  • Parity register encoding is 0 = odd, 1 = even, 2 = none.
  • IP address, mask and gateway are packed into one UINT32 as 0xAABBCCDD.

Network setup

  • RTU: 3-wire RS-485 (A, B, common), line topology, 120 ohm termination at both ends, max 700 m.
  • RTU address 1-247; baud 9600-115200.
  • TCP: default port 502; the M4M 30 Ethernet has two RJ45 ports for daisy-chaining.

Watch out for

  • Tariff energy, CT neutral ratio and unbalance exist only on M4M 30.
  • CT ratio registers are not used on Rogowski versions.

Notes on this map

  • Byte/word order and addressing rules come from the companion 'Communication protocol - Modbus manual, M4M network analyzers' 2CSG445050D0201 v1.05 (https://search.abb.com/library/Download.aspx?DocumentID=2CSG445050D0201&LanguageCode=en&DocumentPartId=&Action=Launch), section 3: multi-register values are most significant byte first in the lowest register (ABCD).
  • Only function codes 3, 6 and 16 are supported. Readable range per the manual is 0x1000-0x8EFF, 1-125 registers per read; quantities missing on a variant return FFFF (unsigned) or 7FFF... (signed) instead of an exception.
  • Instantaneous power registers are signed 32-bit at 0.01 W, so they saturate near +/-21 MW. Map v1.3 added whole-watt ('Scaler 1') power registers from CB1Ah onward (real-time) and CC24h onward (max/min), available from FW P1.3.10.0; they are not included here.
  • The map prints the apparent energy unit as 'kVA'; these are energy accumulators and are listed as kVAh.
  • Left out: 5024/5034 (CO2 and currency equivalents of imported energy) because the map gives their unit as kg/kWh and Currency/kWh with 'conversion factor' wording, which leaves the meaning ambiguous.
  • Left out: Error/Information/Warning/Alarm flag blocks (8A13-8A28, 64 bits each) whose bit meanings are not tabulated with the register rows; average/min/max values and their timestamps; individual harmonic orders; historical/log/load-profile header and data blocks; OBIS-coded alarm, pulse and tariff configuration groups; Slave ID (8911), Date Time (8A00) and Day of week (8A03), which have no plain data type in the map.
  • Removed on verification: outputs 1-6 (6300h-6305h), input status 1-6 (6308h-630Dh), input counters 1-6 (6318h-632Ch), product type number ID (8910h) and LED source (8CE4h). The map leaves their Data Type cell empty and the companion Modbus manual (2CSG445050D0201, sections 11.1 and 14) does not state a type either, so they are not published. Bluetooth enable (8EFCh) is typed 'Unsigned' in the map and is kept.
  • Unbalance registers 6200/6202 were swapped in map v1.3N; this file follows the v1.3O labels.
  • Rows marked 'M4M 30 only' or 'I/O versions' return the invalid marker on other variants.

Questions about the ABB M4M 20 / M4M 30 network analyzer

What Modbus registers does the ABB M4M 20 / M4M 30 network analyzer have?

This map lists 152 registers: 152 holding registers. 26 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB M4M 20 / M4M 30 network analyzer Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map gives each start register in hex (and decimal) exactly as sent on the bus; 5B02 is wire address 0x5B02 = 23298. The manual's example frame reads phase voltage L1 at 0x5B02 with function 3.

What byte order does the ABB M4M 20 / M4M 30 network analyzer use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ABB M4M 20 / M4M 30 network analyzer?

Start with HR 20480 Active energy import (Total active import energy); HR 20484 Active energy export (Total active export energy); HR 23298 Phase voltage L1 (Phase voltage L1); HR 23312 Current L1 (Current L1); HR 23322 Active power total (Total active power); HR 23346 Frequency (Frequency); HR 23360 Power factor total (Total power factor); HR 35168 Type designation (Type designation (ASCII), confirms the variant).

How do I enable Modbus control of the ABB M4M 20 / M4M 30 network analyzer?

Modbus is built in on the Modbus RTU and Ethernet (Modbus TCP) versions; set address, baud rate and parity (RTU) or DHCP/IP/port (TCP) on the device or through registers 8CEB-8CF6.
