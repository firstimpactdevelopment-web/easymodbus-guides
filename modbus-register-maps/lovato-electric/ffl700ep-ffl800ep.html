Short answer

The FFL700EP and FFL800EP are Lovato controllers for electric fire pumps built to EN 12845. They speak Modbus RTU, ASCII or TCP on the optical port, the built-in RS-485 and, on FFL800EP, EXP1012T/EXP1013T modules. This map covers the supply voltages, currents, active powers and power factors, frequency and asymmetry, working hours, the alarm words, I/O states, the global status word and the save/reset/command registers.

This page lists 43 Modbus registers for the Lovato Electric FFL700EP / FFL800EP electric fire pump controllers — 4 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lovato Electric’s own free documentation (linked below) and checked against it.

Integration notes: Lovato Electric FFL700EP / FFL800EP electric fire pump controllers

Integration in brief

Read the alarm words 2200h-2203h and the global status 2210h for supervision, plus currents, voltages and frequency for motor monitoring. Subtract one from every table address.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In SETUP menu M11 (communication) set P11.n.01 node address, .02 baud rate, .03 data format, .04 stop bits and .05 protocol for port n; port 1 is the built-in RS-485.

Byte order & addressing

  • Table addresses are one above the wire address.
  • 32-bit values are high word first.

Network setup

  • Defaults: node 01, 9600 baud, 8 data bits, no parity, 1 stop bit, Modbus RTU.
  • EXP1013T Ethernet module: default IP 192.168.1.1, IP port 1001 (P11.n.06-P11.n.08).

Watch out for

  • The document's read example names water temperature at 0F0Ah while Table 2 lists it at 0F0Eh; that register is left out of this map.
  • Function 06 writes are accepted only on addresses above 1000h.

Notes on this map

  • Measures and status words are read with function 03 or 04 (same data) and are listed as input registers. Commands use function 06.
  • Word order: the example answer 00 00 09 EC decodes to 2540 = 25.40 °C, so 32-bit values are high word first (ABCD).
  • The example says it reads water temperature with start address 0F 09 (table 0F0Ah), but Table 2 lists water temperature at 0F0Eh. Because of that mismatch the water temperature register is left out; the minus-one rule itself is stated in the text.
  • Scales are the divisors printed in the unit column (V/100, A/10000, W/10, var/10, VA/10, PF/10000, Hz/1000). Phase-to-phase asymmetry is printed %/10 while the other asymmetries are %/100.
  • Left out: L1-L3 reactive and apparent powers (same pattern at 001Ah-0024h), max/min equivalent phase-to-phase voltage, LIM1-8 words, CNT1-8 counters, analog inputs/outputs (no units printed) and the key simulation at 2F0Ah.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lovato Electric FFL700EP / FFL800EP electric fire pump controllers

What Modbus registers does the Lovato Electric FFL700EP / FFL800EP electric fire pump controllers have?

This map lists 43 registers: 39 input registers, 4 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lovato Electric FFL700EP / FFL800EP electric fire pump controllers Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The document states that the address in a request is the table address decreased by one (Modbus standard). Addresses here are the table value minus one.

What byte order does the Lovato Electric FFL700EP / FFL800EP electric fire pump controllers use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lovato Electric FFL700EP / FFL800EP electric fire pump controllers?

Start with IR 8719 Device global status (Global status (mode, pump running, mains failure)); IR 8703 Alarms A01-A16 (Alarms A01-A16); IR 8704 Alarms A17-A32 (Alarms A17-A32); IR 7 L1 phase current (L1 current); IR 13 L1-L2 voltage (L1-L2 voltage); IR 57 Frequency (Frequency).

How do I enable Modbus control of the Lovato Electric FFL700EP / FFL800EP electric fire pump controllers?

In SETUP menu M11 (communication) set P11.n.01 node address, .02 baud rate, .03 data format, .04 stop bits and .05 protocol for port n; port 1 is the built-in RS-485.
