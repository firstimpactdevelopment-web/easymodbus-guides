Short answer

The Lovato ADXL is a soft starter for three-phase motors. With the optional EXC1042 RS-485 board it answers Modbus RTU or ASCII (the addendum also lists Modbus TCP as a protocol choice). This map covers voltage, currents, powers, power factor, frequency, torque, thermal status, thyristor temperature, I/O bits, the start/stop commands, the command register and the parameter-access selectors.

This page lists 32 Modbus registers for the Lovato Electric ADXL soft starters (Modbus RTU / ASCII / TCP) — 8 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lovato Electric’s own free documentation (linked below) and checked against it.

Integration notes: Lovato Electric ADXL soft starters (Modbus RTU / ASCII / TCP)

Integration in brief

Fit the EXC1042 RS-485 board, set P08 serial parameters, then read currents (08h-0Dh), total power (3Ah), thermal status (FB0h) and thyristor temperature (FB2h) as big-endian 32-bit values. Start and stop with a 1 written to 1002h and 1003h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Install the EXC1042 RS-485 communication board, then in menu 01-SETUP > P08 COMMUNICATION set node address (08.01), baud rate (08.02), data format (08.03), stop bits (08.04) and protocol (08.05).

Byte order & addressing

  • Table addresses are one above the wire address.
  • 32-bit values are high word first.
  • Phase active powers are kW/100000 but total active power is kW/10000.

Network setup

  • Defaults: node 1, 9600 baud, 8 data bits, no parity, 1 stop bit, Modbus RTU.
  • Data format choices: 8 bit none/odd/even and 7 bit odd/even.

Watch out for

  • Without the EXC1042 board the soft starter has no Modbus port.
  • Only function 06 is listed for writes; function 16 is not among the supported functions.

Notes on this map

  • Measurements are read with function 03 or 04 (same data); they are listed as input registers. Commands and parameters are written with function 06 only (no function 16 is listed).
  • Word order: the read example returns 00 00 01 10 for a thyristor temperature of 27.2 °C (272 x 0.1), so the high word comes first (ABCD).
  • Scales are the divisors printed in the unit column: V/100, A/10000, kW/100000 for phase powers but kW/10000 for total power, PF/10000, Hz/1000, %/10, °C/10.
  • Left out: the status register F84h (printed as 2 words but 'Unsigned integer', so its width is unclear) and the total active energy at 1B20h (4 words labelled 'Unsigned long'). Function 07 (read exception status) returns a status byte with start/stop input, block, alarm, motor running and bypass bits.
  • Left out: the 28-register event description text at 5032h (read via the pointer at 5030h).
  • Parameter access: write the menu (5000h), sub-menu (5001h) and parameter number (5002h), then read or write the value at table address 5004h (wire 5003h); write 5 to 2F03h to save and reboot. 5004h is not listed as a register because the document prints no data format for it. The document recommends a reboot (5 to 2F03h) after commands C11-C14.
  • Only one communication port can be configured (menu P08).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lovato Electric ADXL soft starters (Modbus RTU / ASCII / TCP)

What Modbus registers does the Lovato Electric ADXL soft starters (Modbus RTU / ASCII / TCP) have?

This map lists 32 registers: 24 input registers, 8 holding registers. 8 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lovato Electric ADXL soft starters (Modbus RTU / ASCII / TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables print hex addresses one higher than the address sent on the wire; the document says to subtract one, and its example reads thyristor temperature (table 0FB2h) by sending 0F B1. Write example: parameter menu 5000h is sent as 4F FF. Addresses here are already reduced by one.

What byte order does the Lovato Electric ADXL soft starters (Modbus RTU / ASCII / TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lovato Electric ADXL soft starters (Modbus RTU / ASCII / TCP)?

Start with IR 7 L1 current (L1 current); IR 57 Total active power (Total active power); IR 4015 Motor thermal status (Motor thermal status); IR 4017 Thyristor temperature (Thyristor temperature); IR 3967 Motor hour meter (Motor hours (seconds)); HR 4097 Motor start command (Start command); HR 4098 Motor stop command (Stop command).

How do I enable Modbus control of the Lovato Electric ADXL soft starters (Modbus RTU / ASCII / TCP)?

Install the EXC1042 RS-485 communication board, then in menu 01-SETUP > P08 COMMUNICATION set node address (08.01), baud rate (08.02), data format (08.03), stop bits (08.04) and protocol (08.05).
