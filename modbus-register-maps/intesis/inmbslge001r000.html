Short answer

Modbus RTU server that sits on the 3-wire remote-controller bus of an LG indoor unit, alongside or instead of the LG wired remote. Holding registers cover on/off, mode, fan, vanes, setpoint, room temperature, compressor status and run hours, alarm and error code, and window-contact / virtual-temperature features.

Integration notes: Intesis (HMS Networks) INMBSLGE001R000 LG AC to Modbus RTU gateway

Integration in brief

Decide the BYR-bus role first (SW1: slave next to an LG wired remote, master if there is none), set address and baud on SW3/SW4, power-cycle, then poll holding registers 0-11 with function 03 and write with 06.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step; register 7 (gateway disablement) must be 0 for commands to reach the unit.

Byte order & addressing

  • Temperature scale depends on DIP SW4 and the manual is inconsistent about the factory default.
  • 8-N-2 by default; 8-N-1 is auto-detected.

Network setup

  • SW1: BYR-bus role (slave by default, needs an LG wired remote as master) and LG error type.
  • SW3: slave address; SW3/SW4: baud (9600 default).
  • SW4: x1/x10, °C/°F and 120 Ω termination.
  • DIP changes need a power cycle; the gateway only talks once the AC unit is powered.

Watch out for

  • With the factory slave setting and no LG wired remote on the bus, the gateway will not communicate with the unit.
  • Writing register 22 starts virtual temperature: the gateway offsets the unit setpoint, so the LG remote may show a different setpoint than register 4.

Notes on this map

  • Every register is documented as a 16-bit unsigned holding register and no temperature range in the manual goes below zero, so temperatures are UINT16. The 'no value' marker the manual writes as -32768 is raw 0x8000 (32768) and is listed as an enum entry.
  • Temperature registers depend on DIP SW4: x1 °C, x10 °C (decidegrees) or °F (no °F x10). The register-table footnote calls x10 the default, but the SW4 table and the quick-start page (all other switches off) give x1 °C as the factory setting, so scale 1 / °C is used. Read SW4 position 1-2 on site: if x10 is set use scale 0.1; if °F is set the values are whole °F.
  • Error code enum (LG codes) not reproduced; see manual section 7.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Intesis (HMS Networks) INMBSLGE001R000 LG AC to Modbus RTU gateway

What Modbus registers does the Intesis (HMS Networks) INMBSLGE001R000 LG AC to Modbus RTU gateway have?

This map lists 32 registers: 32 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Intesis (HMS Networks) INMBSLGE001R000 LG AC to Modbus RTU gateway Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables give a 'protocol address' (base 0) and a 'PLC address' (base 1); the protocol address is the wire address and is used for 'documented'.

What are the minimum Modbus registers to integrate the Intesis (HMS Networks) INMBSLGE001R000 LG AC to Modbus RTU gateway?

Start with HR 0 AC unit On/Off (On/off); HR 1 AC unit mode (Mode); HR 2 AC unit fan speed (Fan speed); HR 4 AC unit temperature setpoint (Setpoint); HR 5 AC unit temperature reference (Room temperature); HR 11 Error code (Error code); HR 53 Compressor status (Compressor status).

How do I enable Modbus control of the Intesis (HMS Networks) INMBSLGE001R000 LG AC to Modbus RTU gateway?

No enable step; register 7 (gateway disablement) must be 0 for commands to reach the unit.
