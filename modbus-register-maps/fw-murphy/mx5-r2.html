Short answer

The MX5-R2 is FW Murphy's I/O and communications expansion module for Centurion controllers, with 24 digital inputs, 10 analog inputs, a magnetic pickup, 16 digital outputs and 4 analog outputs. In Standard IO mode it is a Modbus RTU server on two RS-485 ports and RS-232 and a Modbus TCP server on Ethernet, all using one holding-register table. This map covers the whole published table.

Integration notes: FW Murphy Interchange Comm Control Module MX5-R2 (Standard IO mode)

Integration in brief

Poll holding registers 400021-400038 for inputs, write 400061 and 400047-400050 for outputs, and set 400073 plus the comm-failure registers so outputs go to a safe state if the client stops polling.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Standard IO mode is the default (COP LED code 4,2). To reload it: power up with DIP 5-8 closed and DIP 2 open, 1/3/4 closed. DIP 5-8 closed with 1-4 closed loads factory defaults (baud, Ethernet, channel configuration).

Communication loss & watchdog

Register 400073 sets a communication timeout in seconds; when no client talks on any port for that time, outputs go to the states in 400064 and 400069-400072. Pulse mode is also cancelled on comm loss.

Byte order & addressing

  • Supported functions: 03, 06 and 16 only; invalid addresses return an exception.
  • Polarity registers pack two inputs: high byte = odd channel, low byte = even channel.
  • The firmware checksum is split MSW (400009) then LSW (400010).

Network setup

  • RS-485: A (+) on terminals 61/62, B (-) on 80/81; twisted shielded pair, 120 ohm.
  • Serial default 9600 baud, up to 115.2k via 400085; set the RTU client timeout to at least 400 ms.
  • Ethernet default 192.168.0.100 / 255.255.255.0, gateway 0.0.0.0; change via 465197-465217.

Watch out for

  • In Rockwell IO mode the Ethernet ports speak EtherNet/IP (CIP) only, not Modbus TCP.
  • DIP switches 5-8 double as address switches; the special functions only act when they are closed at power-up.

Notes on this map

  • Analog inputs: the register notes call them signed 16-bit counts, but the table gives full scale as 32768 = 5 V or 25 mA while the text says 32767 = 24 mA (4 mA = 5243, 20 mA = 26214). They are left as raw INT16 counts; calibrate against the stated 4-20 mA counts.
  • The 400090-400097 polarity rows reuse the DI1-DI8 byte labels in the table; this map labels them by the register's channel pair (DI9-DI24).
  • Factory-use registers 400002-400004, 400051-400052, 400084 and 400098-400115 are left out.
  • Default serial framing: the module answers with 1 stop bit at addresses 1-31 and 2 stop bits at 32-239; parity is not stated.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the FW Murphy Interchange Comm Control Module MX5-R2 (Standard IO mode)

What Modbus registers does the FW Murphy Interchange Comm Control Module MX5-R2 (Standard IO mode) have?

This map lists 127 registers: 127 holding registers. 89 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the FW Murphy Interchange Comm Control Module MX5-R2 (Standard IO mode) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed in 6-digit Modicon form (400001 = holding register 1). Wire address = number - 400001, e.g. digital inputs 400021 = address 20 and IP address 465197 = address 65196.

What byte order does the FW Murphy Interchange Comm Control Module MX5-R2 (Standard IO mode) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.
