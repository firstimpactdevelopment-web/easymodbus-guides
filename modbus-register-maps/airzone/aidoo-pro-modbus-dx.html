Short answer

Aidoo Pro is a small Airzone interface for an air-conditioning unit that can serve Modbus RTU on RS-485 to a BMS. The direct-expansion map gives on/off, mode, setpoint, fan, louvres, room and refrigerant-circuit temperatures, pressures, current, error codes and 32-bit energy counters.

Integration notes: Airzone Aidoo Pro Modbus control for direct-expansion (split / VRF) air conditioners

Integration in brief

Set the Aidoo output to Modbus and the slave ID in the Airzone Cloud app, connect RS-485 at 19200 8E1, then use registers 0-4 for on/off, setpoint (x10), mode and fan and poll 2, 7-8 and 55 for room temperature and errors.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the Airzone Cloud app: Airtools > advanced configuration via Bluetooth > Integration > output Modbus, set the Modbus ID.

Byte order & addressing

  • Mode codes start at 1 (1 Auto, 2 Cool, 3 Heat, 4 Fan, 5 Dry).
  • Fan speed can be set as a percentage (register 4) or a step number (register 54).
  • Energy counters are low word first (CDAB).

Network setup

  • Factory serial settings 19200 baud, 8 data bits, even parity, 1 stop bit, half duplex.
  • Slave address default 1.

Watch out for

  • The manual footnotes that the local temperature (register 2) must be greater than 0.

Notes on this map

  • Distributor copy: airzonecontrol.com answers automated requests with a bot check (not bypassed) and no other Airzone-hosted copy was found; this multilingual PDF carries Airzone's own layout and address.
  • 32-bit energy counters span two registers with the low word first: the manual's worked example reads (1) 0x1215 and (2) 0x0001 as 0x00011215 = 70165 kWh, so CDAB.
  • The manual does not state signed or unsigned for 16-bit values; the remaining registers are listed as UINT16 because their normal values are not negative.
  • The Modbus slave address is set in the Airzone Cloud app (Airtools > Integration > Modbus) or via register 56.
  • Function codes 03, 04, 06 and 16 are supported.
  • External (outdoor) temperature (35) and outdoor heat exchanger temperature (39) are left out: these routinely go below 0 °C and the manual gives no sign convention for 16-bit values.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Airzone Aidoo Pro Modbus control for direct-expansion (split / VRF) air conditioners

What Modbus registers does the Airzone Aidoo Pro Modbus control for direct-expansion (split / VRF) air conditioners have?

This map lists 52 registers: 52 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Airzone Aidoo Pro Modbus control for direct-expansion (split / VRF) air conditioners Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are numbered from 0 (unit on/off is register 0) and the command description puts this number in the 'register address' field, so the printed number is the wire address.

What byte order does the Airzone Aidoo Pro Modbus control for direct-expansion (split / VRF) air conditioners use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Airzone Aidoo Pro Modbus control for direct-expansion (split / VRF) air conditioners?

Start with HR 0 Unit status on/off (On/off); HR 3 Mode (Mode); HR 1 Setpoint (Setpoint (x10)); HR 4 Fan speed (percentage) (Fan speed); HR 2 Local (room) temperature (Room temperature (x10)); HR 7 Unit error code part 1 (Error code (ASCII)); HR 14 Available modes (Modes the unit supports).

How do I enable Modbus control of the Airzone Aidoo Pro Modbus control for direct-expansion (split / VRF) air conditioners?

In the Airzone Cloud app: Airtools > advanced configuration via Bluetooth > Integration > output Modbus, set the Modbus ID.
