Integration notes: Red Lion PAX2C temperature/process PID controller (Modbus RTU/ASCII)

Integration in brief

Read registers 1-8 in one request (wire 0-7) for process value, min/max, setpoints, deviation and output power. Write setpoint 1 at wire 4 and switch auto/manual at wire 17.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the comms type register (1702) to Modbus RTU or ASCII, set baud, data bits, parity and address in 1703-1706, then write 1 to 1710 to load the new settings.

Byte order & addressing

  • Factory comms type is Modbus ASCII, not RTU.
  • Display-unit values carry no decimal point.

Network setup

  • Default address 247, 38400 baud, 8 data bits, no parity.
  • Write 1 to register 1710 after changing serial registers.

Watch out for

  • Output power can only be written in manual mode.
  • Digital outputs can only be forced through register 29 when their MMR bit (register 30) is set.

Notes on this map

  • Red Lion's site hosts only the older Ver 1.5 table (PAX2C8H8V, marked reference only); this file uses the unaltered Ver 2.0 table (LP0905F) from a distributor's file host.
  • Registers can be read as holding (4x) or input (3x) registers; they are listed as holding registers.
  • Values marked 1 = 1 display unit are the displayed digits without the decimal point; apply the controller's decimal point setting yourself.
  • The only 32-bit value listed (segment time remaining) is printed as a Hi word register followed by a Lo word register, so it is ABCD.
  • Factory serial settings: Modbus ASCII (type 2), 38400 baud, 8 data bits, no parity, address 247. Stop bits are not given in the table.
  • Serial setting changes (1701-1709) take effect only after writing 1 to register 1710, and the master must then switch to the new settings.
  • Do not power the unit down while parameters are being written; the table warns this can corrupt non-volatile memory.
  • Profile definitions (5001 and up), the A/B parameter lists, input/output configuration and FlexCard registers are documented in the table but left out.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Red Lion PAX2C temperature/process PID controller (Modbus RTU/ASCII)

What Modbus registers does the Red Lion PAX2C temperature/process PID controller (Modbus RTU/ASCII) have?

This map lists 64 registers: 64 holding registers. 51 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Red Lion PAX2C temperature/process PID controller (Modbus RTU/ASCII) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are numbered from 1; the table's own example reads register 2 with start address 00 01, and its notes refer to 41701-41710 for registers 1701-1710. Request register N at wire address N-1.

What byte order does the Red Lion PAX2C temperature/process PID controller (Modbus RTU/ASCII) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Red Lion PAX2C temperature/process PID controller (Modbus RTU/ASCII)?

Start with HR 0 Input process value (Process value); HR 3 Active setpoint value (Active setpoint); HR 4 Setpoint 1 value (Setpoint 1 (write)); HR 7 Output power (Output power); HR 17 Control mode (Auto/manual control mode); HR 25 Alarm (1-16) status register (Alarm status bits).

How do I enable Modbus control of the Red Lion PAX2C temperature/process PID controller (Modbus RTU/ASCII)?

Set the comms type register (1702) to Modbus RTU or ASCII, set baud, data bits, parity and address in 1703-1706, then write 1 to 1710 to load the new settings.
