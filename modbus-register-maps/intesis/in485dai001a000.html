Short answer

This Intesis gateway connects a Daikin Altherma 3 air-to-water heat pump to an RS-485 bus as a Modbus RTU server (or BACnet MS/TP device, chosen by DIP switch). All points are single 16-bit registers: on/off, heat/cool mode, zone, room and DHW setpoints with limits, water and outdoor temperatures, compressor and pump status and hours, flow, error codes and gateway diagnostics.

Integration notes: Intesis (HMS Networks) IN485DAI001A000 Daikin Altherma 3 air-to-water to Modbus RTU / BACnet MS/TP gateway

Integration in brief

Set SW1 position 5 ON for Modbus RTU, choose the baud on SW1 6-8 and the address on SW2 1-6, power-cycle, then read with function 03 or 04 (max 50 registers per request) and write one register at a time.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

DIP switch SW1 position 5 ON selects Modbus RTU (default). All settings are DIP switches and only apply after a power cycle.

Byte order & addressing

  • Function 16 is accepted but must write only one register per request.
  • Registers read 0x8000 (-32768) until the unit has reported.
  • Temperature scale and unit depend on SW2 positions 7 and 8.

Network setup

  • Default 2400 bps, 8 data bits, no parity, 2 stop bits; 8-N-1 is detected automatically.
  • Modbus address 1-63 on SW2 positions 1-6.
  • SW3 position 1 ON adds the 120 ohm terminator; positions 2-3 ON add bus polarization.

Watch out for

  • If the gateway ignores writes, check that Modbus control lock (119) is 0.
  • Operating time (116) counts only when compressor or pump registers are active.

Notes on this map

  • Temperatures follow DIP switch SW2: position 7 OFF = whole degrees (x1, default), ON = tenths (x10, 19.2 = 192); position 8 OFF = °C (default), ON = °F. Units and scale here are for the defaults; use scale 0.1 if you set x10.
  • Every register starts at 0x8000 (-32768) until the gateway has data, so temperatures are typed signed 16-bit.
  • An invalid write resets a temperature register to its initial value; other registers keep their old value.
  • Room 1 unit-limit registers (205-208) are left out to keep the map short; they report the Altherma's absolute room setpoint limits.
  • The manual's baud-rate table prints 38500 bps for value 5; the physical-layer section lists 38400, which is used here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious.
