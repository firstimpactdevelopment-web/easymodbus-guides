Short answer

The Liquiline CM44x is Endress+Hauser's multichannel transmitter for Memosens pH, ORP, conductivity, oxygen, turbidity and similar sensors. With the Modbus option it exposes 16 configurable analog and 8 digital device variables, 4 analog and 8 digital write-back variables, diagnostics and per-sensor information blocks. This map covers those common blocks, with the sensor block shown for sensor 1.

Integration notes: Endress+Hauser Liquiline CM44x multichannel transmitter (Modbus RS485 / TCP)

Integration in brief

Assign the measured values you need to AI 1-16 in the transmitter menu, then read registers 0-63 (value, status, unit for each AI) with function 03 or 04 and decode floats as CDAB. Check each status byte is 0 before using the value.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Menu Setup/General settings/Extended setup/Modbus/Settings: bus address (default 247, or set by the module's address switch), RTU/ASCII, baud (default 19200), parity (default even, 1 stop bit), byte order and watchdog. For TCP set the IP under .../Ethernet/Settings (DHCP by default) and use port 502. Assign sources to the device variables under Setup/Outputs.

Communication loss & watchdog

Modbus watchdog default 5 s (0-999 s, 0 = off), set in the Modbus settings menu. If no valid request arrives in that time the device raises diagnostic S969 and lights the red BF LED until the next valid request.

Byte order & addressing

  • Floats are CDAB at the factory byte order but 32-bit integers and strings are most-significant-byte first.
  • A hardware address set on the module's address switch overrides the menu address.

Network setup

  • RS-485 termination is set on the module; input register 941 reports whether it is on.
  • The 485/ETH module has a service switch that forces IP 192.168.1.212/24 while it is on.

Watch out for

  • Values written to AO/DO are ignored unless their status register is written as 0 (good) in the same transfer.
  • Up to 125 registers per read and 120 per write.

Notes on this map

  • Word order depends on the device's Byte order setting. At the factory default 1-0-3-2 a FLOAT is sent mantissa-low word first and sign/exponent word second, i.e. CDAB, which is what this file uses.
  • The guide says every data type longer than 2 bytes other than FLOAT is sent like a string, most significant byte first at the default setting, so UNSIGNED32 values are listed as ABCD.
  • UNSIGNED8 values occupy one full register.
  • The AI/DI device variables carry whatever source is assigned to them in the transmitter menu (Setup/Outputs/Modbus); their unit code (table 7.1) tells what the value is. Units are therefore blank here.
  • Status bytes: 0 good, 1 uncertain, 2 bad, 3 not assigned. AO and DO values written by the PLC are used only when their status is written as 0.
  • Sensor blocks repeat per channel: sensor N uses registers N000-N999 (sensor 1 = 1000-1999). Only sensor 1 is listed; add (N-1) x 1000 for the others.
  • DATETIME fields (7 bytes in 4 registers, packed date/time) are left out because the format is a packed structure, not a plain number.
  • Current output values 96-110 are labelled in ampere in the table although the names say mA; check scaling against the analog output on site.
  • A parameter has to be read or written in full; reading half of a FLOAT or string returns a slave-device-failure exception.
  • The guide says function codes 03 and 04 return the same data, but it also gives separate input and holding tables that reuse the same numbers: diagnostics (input) and configuration (holding) both start at 500, and the sensor block (input) and sensor setup (holding) both start at X000. Because the guide does not settle which content a read returns at those numbers, every register that sits on such a clash is left out: the whole configuration block 500-736 (communication settings, byte order, watchdog, device tag, PID setpoints) and input registers 500-521, 594-625, 690-737 and sensor X000-X018.
  • Timestamps (UNSIGNED32) count seconds since 1 January 1970.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Endress+Hauser Liquiline CM44x multichannel transmitter (Modbus RS485 / TCP)

What Modbus registers does the Endress+Hauser Liquiline CM44x multichannel transmitter (Modbus RS485 / TCP) have?

This map lists 221 registers: 97 input registers, 124 holding registers. 28 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Endress+Hauser Liquiline CM44x multichannel transmitter (Modbus RS485 / TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide states that its register numbers start at 0 exactly as sent on the wire, and that Modicon-style PLCs must add 1. So AI 1 value (register 0) is 40001 in Modicon terms.

What byte order does the Endress+Hauser Liquiline CM44x multichannel transmitter (Modbus RS485 / TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)) and CDAB (low word first (word-swapped)). Each register's order is in the Order column.

What are the minimum Modbus registers to integrate the Endress+Hauser Liquiline CM44x multichannel transmitter (Modbus RS485 / TCP)?

Start with HR 0 MODBUS_AI_1_VALUE (AI 1 value (e.g. main measured value)); HR 2 MODBUS_AI_1_STATUS (AI 1 status); HR 3 MODBUS_AI_1_UNIT (AI 1 unit code); HR 4 MODBUS_AI_2_VALUE (AI 2 value (e.g. temperature)); HR 6 MODBUS_AI_2_STATUS (AI 2 status); HR 112 MODBUS_DI_1_VALUE (DI 1 value (e.g. limit contact)).

How do I enable Modbus control of the Endress+Hauser Liquiline CM44x multichannel transmitter (Modbus RS485 / TCP)?

Menu Setup/General settings/Extended setup/Modbus/Settings: bus address (default 247, or set by the module's address switch), RTU/ASCII, baud (default 19200), parity (default even, 1 stop bit), byte order and watchdog. For TCP set the IP under .../Ethernet/Settings (DHCP by default) and use port 502. Assign sources to the device variables under Setup/Outputs.

What happens when the Endress+Hauser Liquiline CM44x multichannel transmitter (Modbus RS485 / TCP) loses Modbus communication?

Modbus watchdog default 5 s (0-999 s, 0 = off), set in the Modbus settings menu. If no valid request arrives in that time the device raises diagnostic S969 and lights the red BF LED until the next valid request.
