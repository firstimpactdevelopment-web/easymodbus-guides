Short answer

The M-7080 and M-7080B are RS-485 remote I/O modules that count pulses or measure frequency on two inputs and drive two digital outputs. In Modbus RTU mode the 32-bit counts sit in holding registers as low/high word pairs, and configuration flags are coils. This map covers the count/frequency values, maximum and preset values, input thresholds, outputs and counter control.

This page lists 24 Modbus registers for the ICP DAS M-7080 / M-7080B 2-channel counter/frequency module (Modbus RTU) — 20 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ICP DAS’s own free documentation (linked below) and checked against it.

Integration notes: ICP DAS M-7080 / M-7080B 2-channel counter/frequency module (Modbus RTU)

Integration in brief

Read holding registers 0-3 for both 32-bit counts (low word first). Start or stop each counter with coils 00135/00136 and drive the outputs with coils 00001/00002.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The module must be in Modbus RTU mode (ICP DAS modules also speak DCON); see the module's user manual for switching protocol.

Byte order & addressing

  • 32-bit values are low word first (CDAB).
  • Counters are started by default (coils 00135/00136 default 1).

Network setup

  • Voltage trigger levels are in 0.1 V steps (factory 0.8 V low, 2.4 V high).

Watch out for

  • On the M-7080B, writing the preset registers 40097-40100 with type code 52 also loads them into the counters.

Notes on this map

  • Each 32-bit value is listed as a low word followed by a high word, so read two registers and treat them as low word first (CDAB).
  • Whether channel values are counts or frequency depends on the module type code, which this table does not map; frequency units are not stated.
  • The M-7080B table has no set-to-preset coils (00133/00134); on the M-7080B, writing the preset registers with type code 52 also loads them into the counters.
  • The M-7080 counter-mode coils 00145/00146 need firmware 0A24 or later and are left out, as are the module name, address and baud registers not printed for these models.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ICP DAS M-7080 / M-7080B 2-channel counter/frequency module (Modbus RTU)

What Modbus registers does the ICP DAS M-7080 / M-7080B 2-channel counter/frequency module (Modbus RTU) have?

This map lists 24 registers: 14 coils, 10 holding registers. 20 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ICP DAS M-7080 / M-7080B 2-channel counter/frequency module (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table is titled 'M-7000 Address Mapping (Base 1)': 00001 coils, 10001 discrete inputs, 30001 input registers, 40001 holding registers. Subtract the table base for the wire address (40001 = holding register 0).

What byte order does the ICP DAS M-7080 / M-7080B 2-channel counter/frequency module (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ICP DAS M-7080 / M-7080B 2-channel counter/frequency module (Modbus RTU)?

Start with HR 0 Counter/frequency value channel 0 (Channel 0 count/frequency); HR 2 Counter/frequency value channel 1 (Channel 1 count/frequency); CO 64 Overflow flag of counter 0 (Counter 0 overflow); CO 134 Start/stop counter 0 (Start/stop counter 0); CO 0 DO 0 (DO 0).

How do I enable Modbus control of the ICP DAS M-7080 / M-7080B 2-channel counter/frequency module (Modbus RTU)?

The module must be in Modbus RTU mode (ICP DAS modules also speak DCON); see the module's user manual for switching protocol.

Where is the official ICP DAS M-7080 / M-7080B 2-channel counter/frequency module (Modbus RTU) Modbus documentation?

The source is M-7000 Series Address Mapping Table (V1.18), revision 2025-09, published free by ICP DAS at https://www.icpdas.com/en/download/file.php?num=19906.
