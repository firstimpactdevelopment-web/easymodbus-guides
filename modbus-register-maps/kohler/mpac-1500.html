Short answer

The MPAC 1500 is a Kohler automatic transfer switch controller. Its Modbus map gives normal (N) and emergency (E) source voltages and frequencies, load current, contactor position and source availability, transition mode, time-delay status, accessory and I/O states, transfer statistics and write-only test and manual-operation commands. This map covers the monitoring block, nominal ratings, transition mode, I/O and accessory status, maintenance counters and the command registers.

Integration notes: Kohler MPAC 1500 automatic transfer switch controller

Integration in brief

Poll 40001-40019 in one FC 03 read for contactor position, source availability, both sources' voltages and frequencies and load current. Use 41350 bit commands for remote tests and peak shave, and 41312-41319 for transfer statistics.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

On the controller's communications setup enable Modbus Server Port 1/Port 2 (serial) or Modbus Server TCP (Ethernet), set each port's address (1-247) and baud rate (9600, 19200 or 57600), and for TCP the unit ID, IP address and subnet mask.

Byte order & addressing

  • Each serial port needs its own Modbus address.
  • Counters in 41300-41311 are high word first, unlike the LSW-first LONG type used by Kohler generator controllers.
  • 40045 packs the normal-source rotation in the high byte and the emergency-source rotation in the low byte.

Network setup

  • Serial format is 8 data bits, no parity, 1 stop bit.
  • Register 49999 returns 23 (0x17) for the MPAC 1500.

Watch out for

  • The general exception table caps reads at 50 registers and writes at 16.
  • Bit 7 of 41350 forces the switch to OFF; use with care on a live load.

Notes on this map

  • Serial port 1 defaults to Modbus address 1 and port 2 to address 2; Modbus TCP uses unit ID 3 from the factory.
  • The 2-register maintenance counters (41300-41311) are stated as most significant word first, so they are ABCD. 41012-41013 (duration of last outage) is a 2-word value without a stated word order and is left out.
  • 40057 (transition mode) is in the guide's distributor-password group: the guide says to send the data register and the password (40058) in the same request. 40042 has its own password register at 40040. Calibration and factory settings also need the distributor-level password and are not listed.
  • Left out: synchronizing settings, time delays and trip points (40059-40107), programmable I/O event-code assignments, expansion board states, accessory setup, exerciser, common alarms, customer strings, clock/DST registers, packed date fields and the event history.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Kohler MPAC 1500 automatic transfer switch controller

What Modbus registers does the Kohler MPAC 1500 automatic transfer switch controller have?

This map lists 48 registers: 48 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Kohler MPAC 1500 automatic transfer switch controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. This section prints 5-digit holding-register references starting at 40001, so 40001 is wire address 0 and 41350 is wire address 1349.

What byte order does the Kohler MPAC 1500 automatic transfer switch controller use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Kohler MPAC 1500 automatic transfer switch controller?

Start with HR 0 System Overview (Contactor position and source availability); HR 7 Source N L1-L2 Voltage (Normal source L1-L2 voltage); HR 10 Source E L1-L2 Voltage (Emergency source L1-L2 voltage); HR 13 Source N Frequency (Normal source frequency); HR 14 Source E Frequency (Emergency source frequency); HR 15 Current L1 (Load current L1); HR 741 Accessory Status (Accessory status (tests, peak shave)).

How do I enable Modbus control of the Kohler MPAC 1500 automatic transfer switch controller?

On the controller's communications setup enable Modbus Server Port 1/Port 2 (serial) or Modbus Server TCP (Ethernet), set each port's address (1-247) and baud rate (9600, 19200 or 57600), and for TCP the unit ID, IP address and subnet mask.

Where is the official Kohler MPAC 1500 automatic transfer switch controller Modbus documentation?

The source is Modbus Communications Protocol Operation (generator set, transfer switch and power monitor controllers) (TP-6113 12/21p), revision 2021-12, published free by Kohler at https://resources.kohler.com/power/kohler/industrial/pdf/tp6113.pdf.
