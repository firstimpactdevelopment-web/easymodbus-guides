DEIF AGC-4 Automatic Genset Controller Modbus register map

Updated 19 November 2026

Short answer

The AGC-4 is DEIF's paralleling and power-management genset controller. Modbus RTU runs on option H2 (RS-485) or H9 (RS-232), and Modbus TCP on the option N Ethernet card. This map covers the genset-variant AC measurements, energy and hour counters, DC supply readings, the running-mode flags, the status flags and the control command words used for remote start, stop, breaker and mode commands.

This page lists 159 Modbus registers for the DEIF AGC-4 Automatic Genset Controller — 19 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from DEIF’s own free documentation (linked below) and checked against it.

Integration notes: DEIF AGC-4 Automatic Genset Controller

Integration in brief

Read input registers 501-527 and 538 with function 04 for generator values, 567-568 for DC supply, and 1019 for the active mode. Send commands by writing a word to holding register 5 or 6 with bit 0 set together with the command bit.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit option H2 (RS-485), H9 (RS-232) or option N (Ethernet). Serial settings are in parameters 7500-7520, listed in the AGC-4 parameter list 4189340688.

Byte order & addressing

  • A command word is only accepted when bit 0 is also 1; write e.g. 0x0003 to holding 5 for remote start.
  • Addresses 0-499 on function 04 are a user-configurable copy area, not fixed data.

Network setup

  • Option H2 RS-485: 9600 or 19200 bit/s, 8 data bits, no parity, 1 stop bit.
  • Option N: set the card's IP address with the option N configuration software; Modbus TCP port 502.

Watch out for

  • Most AC values are scaled x1 (whole volts, amps, kW); check the scaling column before assuming tenths.

Notes on this map

  • The source is an Excel workbook. Each row has a scaling exponent x; the value is raw x 10^-x, so x=2 is scale 0.01. Units are as printed.
  • 32-bit values: the tables mark every 32-bit register with data format ABCD (high word at the lower address); DEIF's AGC 150 Modbus server manual (4189341435, section 3.4) uses the same notation with that meaning.
  • Only rows marked for the DG (genset) application are listed. Mains and BTB controllers reuse the same addresses for mains or bus A values.
  • Left out: the configurable area 0-499 (contents set by the Modbus configurator), analogue and multi-input readings (meaning depends on configuration), CIO module inputs, alarm bits, EIC engine data, DAVR data, power-management data and the 208 command-flag coils. They are all in the workbook.
  • Parameters are read and written through address areas plus the parameter's USW address (for example holding 4000-5999 'values used'); see the Option H2/H9 document 4189341180.
  • Control command bit words read back 0; the live state of the command words can be read on input registers 642-655 (not listed).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the DEIF AGC-4 Automatic Genset Controller

What Modbus registers does the DEIF AGC-4 Automatic Genset Controller have?

This map lists 159 registers: 37 discrete inputs, 103 input registers, 19 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the DEIF AGC-4 Automatic Genset Controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables give a 'Modbus address' that goes straight into the request, and also a 6-digit PLC address that is one higher (input register 501 = PLC 300502). Request 501 on the wire for generator voltage L1-L2.

What byte order does the DEIF AGC-4 Automatic Genset Controller use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the DEIF AGC-4 Automatic Genset Controller?

Start with IR 501 Generator voltage L1-L2 (Generator voltage L1-L2); IR 507 Generator frequency L1 (Generator frequency); IR 513 Generator current L1 (Generator current L1); IR 519 Generator power (Generator active power); IR 536 Generator Export, active energy counter, total (Exported kWh total); IR 554 Absolute running hours (Absolute running hours); IR 1019 Mode flags word 1019 (Active mode); HR 5 Control command word 5 (Remote start/stop and breaker commands).

How do I enable Modbus control of the DEIF AGC-4 Automatic Genset Controller?

Fit option H2 (RS-485), H9 (RS-232) or option N (Ethernet). Serial settings are in parameters 7500-7520, listed in the AGC-4 parameter list 4189340688.
