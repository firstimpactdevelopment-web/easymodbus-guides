Circutor CVM-E3-MINI Modbus register map

Updated 17 November 2026

Short answer

The CVM-E3-MINI is a compact DIN-rail three-phase power analyzer from Circutor with an RS-485 port for Modbus RTU or BACnet. It exposes two parallel Modbus maps; this file uses Map 2, which follows the CVM-C10 layout shifted by 0x1000. Values are 32-bit integers with fixed scaling (V x10, mA, Hz x100) read with function 03/04. Included: voltages, currents, reactive and apparent power, THD, demand, total energies, status words, setup registers and reset commands.

This page lists 104 Modbus registers for the Circutor CVM-E3-MINI — 21 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Circutor’s own free documentation (linked below) and checked against it.

Integration notes: Circutor CVM-E3-MINI

Integration in brief

Read the Map 2 block from 0x1000 with function 04, at most 20 variables (40 registers) per frame. Each value is a 32-bit integer, high word first, scaled as listed.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set Protocol (0x2742) to Modbus (the default), then peripheral number, baud and framing from the display setup or registers 0x2743-0x2747. Reset or exit setup to apply.

Byte order & addressing

  • Firmware v2.xx needs a master timeout of at least 200 ms and at least 100 ms between frames.
  • Energy is split into a whole-unit register and a remainder (Wh/varh/VAh) register.
  • Reset commands use function 05 with value FF00.

Network setup

  • Defaults: peripheral number 1, 19200 baud, no parity, 8 data bits, 1 stop bit.
  • Baud rates 9600 and 19200; 38400-115200 only on firmware v2.xx.
  • Voltage ratio is limited to 1000 and voltage ratio x current ratio to 300000.

Watch out for

  • Two maps return the same data at different addresses; make sure the master uses Map 2 (0x1000 range) for measurement and energy values.

Notes on this map

  • Word order: the manual's read example returns register 1 = 0000, register 2 = 084D for 212.5 V, so 32-bit values are high word first (ABCD).
  • Map 1 (CVM-MINI compatible addresses) is not listed; the manual recommends Map 2 for new integrations. Map 1 also contains printing errors (e.g. min average current printed 106-417, frequency scale x10 vs x100).
  • Left out: active power, reactive power (signed), power factor and cos phi, and kW maximum demand. The document does not say whether the Modbus values are signed, so the data type cannot be fixed.
  • Left out: per-tariff and per-phase energies, harmonics, CO2/cost, alarm and pulse programming, password and BACnet registers; all are in tables 62-79 of the manual.
  • Left out: the 'Generated apparent energy (VAh)' total, whose address is misprinted (10FE-10EF).
  • Configuration changes made over Modbus apply only after a device reset; the ratio registers must be written as one group.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Circutor CVM-E3-MINI

What Modbus registers does the Circutor CVM-E3-MINI have?

This map lists 104 registers: 7 coils, 83 input registers, 14 holding registers. 21 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Circutor CVM-E3-MINI Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. All addresses in the manual are hexadecimal wire addresses. Its function 04 example reads L1 voltage at 0000 (Map 1) and gets 0000 084D = 212.5 V. Map 2 adds 0x1000 to the CVM-C10 addresses, so L1 voltage is 0x1000 here.

What byte order does the Circutor CVM-E3-MINI use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Circutor CVM-E3-MINI?

Start with IR 4096 L1 Phase voltage (L1 phase voltage (V x10)); IR 4098 L1 Current (L1 current (mA)); IR 4150 Three-phase Apparent power (Three-phase apparent power); IR 4156 L1 Frequency (Frequency (Hz x100)); IR 4316 Total consumed active energy III (kWh) (Total consumed active energy kWh); IR 2001 Power status (Power status (consumed/generated)).

How do I enable Modbus control of the Circutor CVM-E3-MINI?

Set Protocol (0x2742) to Modbus (the default), then peripheral number, baud and framing from the display setup or registers 0x2743-0x2747. Reset or exit setup to apply.
