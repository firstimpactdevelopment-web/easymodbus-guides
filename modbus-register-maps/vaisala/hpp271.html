Short answer

Integration notes: Vaisala HPP271 hydrogen peroxide probe (Modbus RTU)

Integration in brief

Read holding registers 1-16 for H2O2, dew point and water concentration (CDAB floats); check 513 and 529 for reading validity.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Digital (RS-485 Modbus) or analog output is chosen at power-up by pin 5 of the M12 connector: leave pin 5 floating for Modbus, tie it to ground for analog. Power-cycle after changing it.

Byte order & addressing

  • Floats and 32-bit integers are low word first (CDAB); pick "word-swapped" in masters that default to high word first.
  • Read or write each 32-bit value in one transaction.

Network setup

  • Defaults: address 240, 19200 baud, no parity, 8 data bits, 2 stop bits.
  • Change address, bit rate, parity/stop bits and response delay with registers 1537-1540; writing 1 to 1541 restarts the probe.

Watch out for

  • Use the test registers (7937 reads -12345, 7938 reads -123.45) to confirm float format and addressing before trusting readings.
  • After starting a purge by writing 1 to 1283, only read that register until the purge has finished.

Notes on this map

  • All registers are holding registers: read with function 03, write with function 16.
  • 32-bit floats and 32-bit integers put the least significant word at the listed register (CDAB). The guide states this and its worked read example confirms it.
  • Unavailable data reads as quiet NaN (float) or 0x8000 (16-bit integer) rather than an exception.
  • Left out: the restore-factory-settings register, because the guide prints its number (7937) and hex address (1E00) inconsistently and 7937 is also the signed-integer test register.
  • Clipping and error-limit registers for the analog outputs (1801-1807, 2057-2063) and the service agreement block (2817-2846) are left out.
  • Status code registers 514 and 516 are 32-bit values and follow the low-word-first rule the guide gives for 32-bit integers.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Vaisala HPP271 hydrogen peroxide probe (Modbus RTU)

What Modbus registers does the Vaisala HPP271 hydrogen peroxide probe (Modbus RTU) have?

This map lists 44 registers: 44 holding registers. 28 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vaisala HPP271 hydrogen peroxide probe (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide numbers registers in decimal starting at 1 and also prints the 0-based hex address used in the request; register number 1 is address 0x0000 on the wire.

What byte order does the Vaisala HPP271 hydrogen peroxide probe (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Vaisala HPP271 hydrogen peroxide probe (Modbus RTU)?

Start with HR 0 H2O2 concentration by volume (H2O2 ppm); HR 10 H2O+H2O2 dew point (H2O+H2O2 dew point); HR 512 Device status (Device status); HR 528 H2O2 concentration status (H2O2 reading status); HR 546 Sensor vitality (Sensor vitality).

How do I enable Modbus control of the Vaisala HPP271 hydrogen peroxide probe (Modbus RTU)?

Digital (RS-485 Modbus) or analog output is chosen at power-up by pin 5 of the M12 connector: leave pin 5 floating for Modbus, tie it to ground for analog. Power-cycle after changing it.
