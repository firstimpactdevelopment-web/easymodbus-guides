Short answer

ATI's D12 (explosion-proof) and F12 (NEMA 4X) gas transmitters can carry a Modbus RTU option on RS-232 or RS-485. Everything sits in holding registers: a block at 40033-40052 gives fault and status words, gas concentration, temperature and loop current, and settings or calibrations are run by loading parameters and writing a subroutine number to 40001.

This page lists 29 Modbus registers for the Analytical Technology (ATI) D12 / F12 gas transmitter (H10, catalytic bead, wet H2S sensors) Modbus interface — 14 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Analytical Technology (ATI)’s own free documentation (linked below) and checked against it.

Integration notes: Analytical Technology (ATI) D12 / F12 gas transmitter (H10, catalytic bead, wet H2S sensors) Modbus interface

Integration in brief

Read holding registers 40035-40048 (address 34, 14 registers) in one FC03 request: faults, status, concentration, %FS, temperature and blanked readings, with floats low word first. Use subroutine 31 (with the alarm bits in 40003) to reset latched alarms.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is a factory-installed option. Set slave address on the transmitter at Menu > Setup > Modbus and baud/parity at Menu > Setup > System > Commun.

Byte order & addressing

  • Floats and longs are CDAB.
  • FC01/02/04 return zeros rather than exceptions.
  • Report Slave ID returns 1100.

Network setup

  • Defaults: address 1, 9600 baud, N,8,1.
  • Baud can be 300-28.8k; parity options N81, N82, E81, O81.

Watch out for

  • The transmitter answers within about 250 ms, so poll no faster than about 3 times a second.
  • D12 units with IR sensors use a different register table.

Notes on this map

  • Source is a copy hosted by the Danish distributor Loewener; ATI does not host this Modbus manual publicly as far as two searches showed. It is the unaltered ATI document (Rev G, Aug 2007).
  • 32-bit values (REAL and LONG) are low word first (CDAB): the manual's example puts 0x4000 in 40003 and 0x459C in 40004 for 5000.0, and says only the register order, not the bytes, has to be swapped.
  • Only registers 40001-40014 can be written; writing above 40014 returns exception 02. Settings and calibrations are changed through subroutines: load 40003-40006 (a float parameter fills two of them, low word first), write the number to 40001, then read 40002 for the result.
  • The table lists 'LDATA' long parameters as type REAL, which conflicts with their name; they are left out. The raw ADC registers 40053-40069, gain/offset internals 40071-40083 (except range 40073), and the internal ADC words 40088 on are also left out.
  • The manual's own table header for 40015 (listen-only) gives no value coding, so it is not listed.
  • Concentration units depend on the fitted sensor (ppm, %LEL and so on); the transmitter shows them on its display.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Analytical Technology (ATI) D12 / F12 gas transmitter (H10, catalytic bead, wet H2S sensors) Modbus interface

What Modbus registers does the Analytical Technology (ATI) D12 / F12 gas transmitter (H10, catalytic bead, wet H2S sensors) Modbus interface have?

This map lists 29 registers: 29 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Analytical Technology (ATI) D12 / F12 gas transmitter (H10, catalytic bead, wet H2S sensors) Modbus interface Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual numbers holding registers 40001-40999 and states address = register number - 40001 (e.g. 40043 is sent as 42 / 0x2A).

What byte order does the Analytical Technology (ATI) D12 / F12 gas transmitter (H10, catalytic bead, wet H2S sensors) Modbus interface use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Analytical Technology (ATI) D12 / F12 gas transmitter (H10, catalytic bead, wet H2S sensors) Modbus interface?

How do I enable Modbus control of the Analytical Technology (ATI) D12 / F12 gas transmitter (H10, catalytic bead, wet H2S sensors) Modbus interface?
