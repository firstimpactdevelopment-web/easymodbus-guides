Short answer

The 7M.38 is Finder's three-phase MID energy meter for DIN rail. The RS485 version speaks Modbus RTU and offers the same measurements twice: as packed integer formats and as IEEE 754 floats. This map uses the float block (voltages, currents, powers, power factor, THD, frequency, energy counters) plus identification, status, tariff, reset and serial-port registers.

Integration notes: Finder 7M.38 three-phase energy meter (Modbus RS485)

Integration in brief

Read input registers with function 04 and decode the IEEE 754 float block, high word first: subtract 30000 from the printed number (Pt at 32490 is wire 2490). Energy comes as floats in Wh/varh at 32752 onward.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU runs on the RS485 serial versions (7M.38.8.400.XXXX). Port 1 address, baud, stop bits and parity sit in registers 40202-40205; writing settings needs the access level raised first by writing the user password to 40001 (function 16), then save with operator command 40012 = 1.

Byte order & addressing

  • The memory reference is 30000/40000, not 30001/40001: printed 30107 is wire address 107.
  • Floats and 32-bit integers are high word first (ABCD).
  • The integer measurement registers use a packed exponent format; use the float block for SCADA.

Network setup

  • Modbus address 1-247; baud code range 1-7 (2400 to 115200 - code 0, 1200 baud, is listed but outside the allowed min/max); parity none/odd/even; 1 or 2 stop bits; 8 data bits only.
  • The operator command register 40012 saves (1) or aborts (2) pending setting changes and can restart the instrument (3).

Watch out for

  • Which energy counter is import and which is export depends on the counter configuration registers; verify against the display before billing.
  • Read 30099 for the maximum number of registers the meter accepts per request.

Notes on this map

  • Wire address = printed number - 30000 (input registers) or - 40000 (holding registers); see the 30107 / 0x006B example in the document.
  • T_float is IEEE 754 single precision sent high word first; the document's example stores 123.45 as 42F6 E666, so floats are ABCD. T3 (signed 32-bit) is also high word first.
  • Measurements at 30105-30190 refresh once per second; the integer energy counters every 40 ms.
  • Left out: the integer measurement block (30105-30175 and the 355xx-357xx average/max/min copies). It uses Finder types T5/T6/T7, which pack a signed decade exponent in the top byte and the value in the low 24 bits (or sign flags for power factor); that needs custom decoding rather than a plain integer with a fixed scale. Use the float block instead.
  • Left out: integer energy counters 30406-30445 ('mantissa x EXP(exponent register)') because the document does not define the EXP operation, and the '1000 x energy counter' block, because the intro text places it at 30426-30441 while the table lists it at 30462-30501.
  • Left out: a second float copy of counters n1-n4 at 32638-32645 that has no function code printed; the ENERGY block at 32752-32759 is used.
  • Energy counters n1-n4 are non-resettable, counters 1-16 are user counters that can be reset via 40031. What each counter integrates (active/reactive/apparent, which phase, which quadrants = import or export) is set in the counter's parameter and configuration registers (40421 onward); the document does not list factory assignments, so check them on the meter.
  • Left out: CAP/IND power factor floats (32562-32569) because the sign convention is not explained, alarm flag words, logic functions, data logger, LCD, Ethernet/WiFi/M-Bus settings and the alarm/pulse-output configuration groups.
  • The 7M.24 single-phase meter uses a separate, shorter table in the same document and is not covered here.
  • Verifier: the document does not name a specific order code for the RS485 version; it only says '7M.38.8.400.XXXX with serial communication'. The 0212 alias comes from Finder's catalogue, not this PDF.

Questions about the Finder 7M.38 three-phase energy meter (Modbus RS485)

What Modbus registers does the Finder 7M.38 three-phase energy meter (Modbus RS485) have?

This map lists 72 registers: 59 input registers, 13 holding registers. 13 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Finder 7M.38 three-phase energy meter (Modbus RS485) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as 3xxxx (input, function 04) and 4xxxx (holding, functions 03/06/16), and the document gives 30000 / 40000 as the memory reference - not 30001. Its request example reads U1 (30107) by sending start address 0x006B = 107. So the wire address is the printed number minus 30000 or 40000: Pt float 32490 is input register 2490.

What byte order does the Finder 7M.38 three-phase energy meter (Modbus RS485) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Finder 7M.38 three-phase energy meter (Modbus RS485)?

Start with IR 2500 U1 (U1 voltage (float, V)); IR 2516 I1 (I1 current (float, A)); IR 2490 Active power total (Pt) (Total active power (float, W)); IR 2496 Power factor total (PFt) (Total power factor); IR 2498 Frequency (Frequency); IR 2752 Energy counter n1 (Energy counter n1 (float, Wh)); IR 2756 Energy counter n3 (Energy counter n3 (float, Wh)).

How do I enable Modbus control of the Finder 7M.38 three-phase energy meter (Modbus RS485)?
