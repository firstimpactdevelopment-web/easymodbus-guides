Short answer

The RISH Master 3440 is a 96 x 96 mm panel multifunction meter (class 0.2S) that measures voltage, current, power, power factor, frequency, harmonics and energy on 3-phase 4-wire, 3-phase 3-wire or single-phase networks. Its RS-485 port speaks Modbus RTU and every reading is a 32-bit IEEE float in two registers. This map covers per-phase and system parameters, energies, demands, THD and hour counters (Table 1), plus the main setup registers (system type, CT/PT ratios, demand period, communication and word-order settings).

This page lists 290 Modbus registers for the Rishabh Instruments RISH Master 3440 (class 0.2S) multifunction meter — 13 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Rishabh Instruments’s own free documentation (linked below) and checked against it.

Integration notes: Rishabh Instruments RISH Master 3440 (class 0.2S) multifunction meter

Integration in brief

Read measured values with FC04 (or FC03 at the 4X copies) in pairs of registers and decode them as ABCD floats. Settings are floats too and are written with FC16.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU on RS-485 is built in; set the slave address, baud rate and parity from the meter's setup menu or the RS-485 setup register.

Byte order & addressing

  • Each parameter is two registers; reading or writing only half of a float returns an Illegal Data Address exception.
  • Addresses are Modicon-style: subtract 30001 or 40001 for the wire address.
  • Limit each read to 40 parameters (80 registers) or less.

Network setup

  • Slave address range 1-247; broadcast (address 0) is not supported.
  • Allow about 200 ms for the meter to answer before retrying.

Watch out for

  • If a password lock is set, write the valid password to the Password register before changing any 4X setting; a wrong password returns exception code 2.

Notes on this map

  • Measured values are IEEE-754 32-bit floats in two registers. The manual's example responses (e.g. data bytes 43 5B 41 21 for a current reading) put the most significant register first, so ABCD is the default order.
  • Register 46041 (Word Order) can switch the meter to reversed register order; the manual says to write 2141.0 to it and the meter detects which order was used. If floats look wrong, check this setting.
  • Every measured value is also readable as a holding register (FC03) at the 4X address printed next to it in the manual; this map lists the 3X (input register, FC04) copies only.
  • Rows whose printed hex address does not match the decimal 3X/4X address in the manual were left out rather than guessed.
  • Left out: the 32-bit integer energy tables (their integer word order is not demonstrated in the manual), user-assignable registers and data-log blocks.
  • Where the register table has no unit column, units are left blank; energy registers follow the energy unit (Wh/kWh/MWh) configured on the meter, and 'OF' / overflow registers count roll-overs of the matching energy register.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Rishabh Instruments RISH Master 3440 (class 0.2S) multifunction meter

What Modbus registers does the Rishabh Instruments RISH Master 3440 (class 0.2S) multifunction meter have?

This map lists 290 registers: 276 input registers, 14 holding registers. 13 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Rishabh Instruments RISH Master 3440 (class 0.2S) multifunction meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints 30001/40001-style addresses next to the hex start address actually sent (30001 = 0x0000). Wire address = printed number - 30001 (input registers) or - 40001 (holding registers); every value here was cross-checked against the printed hex address.

What byte order does the Rishabh Instruments RISH Master 3440 (class 0.2S) multifunction meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Rishabh Instruments RISH Master 3440 (class 0.2S) multifunction meter?

Start with IR 0 V1 (Voltage L1); IR 6 I1 (Current L1); IR 52 Watt Sum (Total active power (Watt Sum)); IR 70 Freq (Frequency); IR 62 PF Avg (Average power factor); IR 72 Wh import (Active energy import (Wh import)).

How do I enable Modbus control of the Rishabh Instruments RISH Master 3440 (class 0.2S) multifunction meter?

Modbus RTU on RS-485 is built in; set the slave address, baud rate and parity from the meter's setup menu or the RS-485 setup register.
