Short answer

The MP 204 is Grundfos's electronic motor protector for single- and three-phase pump motors. A CIU communication box talks GENIbus to the MP 204 and presents it as a Modbus slave, with blocks for CIU settings, CIU status, one control register, protector status and measured data. The map covers start/stop and trip commands, alarm and warning codes, phase voltages and currents, power factor, power, energy, run hours, start counters and insulation resistance.

Integration notes: Grundfos MP 204 motor protector with CIU 200 / CIU 500 (Modbus)

Integration in brief

Set the CIU 200 slave address on the two hex switches, keep 19200 8E1, then poll 00201-00208 for status and alarm, and 00301-00354 for measurements. Start, stop and trip the pump through ControlRegister 00101.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The MP 204 needs no setting for remote control; configure it with the R100, Grundfos GO or PC Tool first, then connect the CIU. OnOffReq (bit 2 of 00101) starts and stops the motor; the device acts on the last command from Modbus, remote or buttons.

Byte order & addressing

  • Reset and trip bits act on a rising edge. With AutoAckControlBits = 1 (default) the CIU clears them itself; with 0 you must clear them and watch 00208.
  • Data block values are unsigned unless stated; 0xFFFF means not available.

Network setup

  • CIU 200: address on rotary switches SW6/SW7 (hex, high and low nibble), speed on SW4/SW5 (9600, 19200 default, 38400, or software-defined), parity on SW3 (even/1 stop default, or none/2 stop), termination on SW1/SW2.
  • CIU 500: Modbus TCP on port 502.

Watch out for

  • Changing RegisterOffset (00002) moves every register above 00100; leave it at 0.
  • Single-phase motors report different meanings in the L1-L3 voltage and current registers (neutral, main winding, auxiliary winding).

Notes on this map

  • All registers can be read with function 03 or 04 (the same data is in both tables); they are listed here as holding registers. Control and configuration registers are written with 06 or 16.
  • 32-bit values are split into HI and LO registers with the HI (high-order) part at the lower address, so they are ABCD.
  • A raw value of 65535 (0xFFFF) means 'not available'. Several values exist only for 1-phase or only for 3-phase motors, or need the optional sensors (Tempcon, Pt100).
  • Motor temperatures are given in 0.01 K as printed; the manual does not say whether an offset of 273.15 applies, so no offset is set here.
  • Left out: CIU 250-only registers (GSM real-time clock 00080-00097, GeneralStatus/PIN bits 00029, GSM battery 00033, NoDataActivityTimeout 00008, GSM signal and IP address 00236-00239) and the free user registers 00751-00800.
  • Software-defined parity and stop-bit defaults (none / 1 stop bit) apply only in software-defined mode; the DIP-switch default is even parity, 1 stop bit.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Grundfos MP 204 motor protector with CIU 200 / CIU 500 (Modbus)

What Modbus registers does the Grundfos MP 204 motor protector with CIU 200 / CIU 500 (Modbus) have?

This map lists 74 registers: 74 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Grundfos MP 204 motor protector with CIU 200 / CIU 500 (Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as 5-digit register numbers; the telegram examples address register X as X-1 (ControlRegister 00101 is written at address 0x0064). The RegisterOffset register 00002 shifts every address above 00100 if it is changed from its default 0.

What byte order does the Grundfos MP 204 motor protector with CIU 200 / CIU 500 (Modbus) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Grundfos MP 204 motor protector with CIU 200 / CIU 500 (Modbus)?

Start with HR 100 ControlRegister (Start/stop, trip and reset commands); HR 200 StatusRegister (Running, ready and fault flags); HR 201 OperatingMode (Operating mode); HR 203 AlarmCode (Alarm code); HR 204 WarningBits1 (Active warnings); HR 311 LineCurrentMean (Mean line current); HR 327 Power (Power consumption); HR 329 Energy (Energy counter).

How do I enable Modbus control of the Grundfos MP 204 motor protector with CIU 200 / CIU 500 (Modbus)?

The MP 204 needs no setting for remote control; configure it with the R100, Grundfos GO or PC Tool first, then connect the CIU. OnOffReq (bit 2 of 00101) starts and stops the motor; the device acts on the last command from Modbus, remote or buttons.
