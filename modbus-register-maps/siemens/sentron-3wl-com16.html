Short answer

SENTRON WL breakers talk Modbus RTU through the COM16 module. Data is grouped in register blocks: the high byte of the register number is the block (data set) number, e.g. block 94 at 0x5E01 holds the live measured values. This map covers the 16-bit and 32-bit measured values of block 94, the min/max blocks 72-76, the counters of block 91 and a few overview values of block 51.

Integration notes: Siemens SENTRON WL (3WL) air circuit breaker with COM16 Modbus module

Integration in brief

Read the live values of block 94 with function 03 at the printed number minus 1: phase currents L1-L3 are printed 0x5E06-0x5E08 (wire 0x5E05-0x5E07), total active power 0x5E16 and frequency 0x5E36. Min/max values sit in blocks 72-76 and switching/trip counters in block 91.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus runs through the COM16 module. Its address, baud rate and parity are in block 160 (printed 0xA003 high byte for the address, 0xA019 for baud rate and parity). Without a bridge on the COM16 WriteEnable input, switching, trip reset, parameter changes and counter resets are blocked; setting the system time and resetting min/max values are still allowed.

Byte order & addressing

  • Register numbers are block-based: high byte = block number, low byte = 1-based register in the block.
  • Several registers pack two 8-bit values; read the whole word and split it.

Network setup

  • Factory settings: address 126, 19200 baud, no parity; the module also runs an automatic baud search at start-up.
  • Change the Modbus address, baud rate and parity in block 160 if needed.

Watch out for

  • Values from the metering function read as unavailable on breakers without it; check the property bytes.

Notes on this map

  • Scaling in the tables is a power-of-ten exponent applied at the master (e.g. frequency -2 means x 0.01); it is converted to a plain multiplier here.
  • The data-format chapter says all Modbus RTU data is sent in Motorola (big-endian) format; 32-bit 'unsigned long' values (energies, runtime meter) are mapped high word first.
  • Units follow the manual's default unit table (A, V, kW, kVA, kvar, Hz, s); energies carry the unit printed in their name.
  • Left out: byte-packed values (one register holding two 8-bit items, e.g. unbalance %, THD, form/peak factor, temperatures), 64-bit time stamps, logs, harmonics, format-coded status words and all property bytes.
  • Voltage, power, energy, power factor and frequency need the breaker's metering function or metering function PLUS; currents come from the electronic trip unit (ETU).
  • The value buffer area is read with function 03 and written with 16; basic type data, control bytes and status bits use functions 04, 01/05/15 and 02.
  • SENTRON 3VL moulded-case breakers use different data areas (section 8.8) and are not covered by this map.
  • The kWh/kvarh energy registers of block 94 (0x5E3B-0x5E41) have no scaling entry in the table and are left out; the MWh/Mvarh versions are included.
  • Byte order inside a register is high byte first in the function 03/04 examples; the function 16 system-time example labels its bytes differently, but that only concerns byte-packed values, which are left out here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Siemens SENTRON WL (3WL) air circuit breaker with COM16 Modbus module

What Modbus registers does the Siemens SENTRON WL (3WL) air circuit breaker with COM16 Modbus module have?

This map lists 100 registers: 100 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Siemens SENTRON WL (3WL) air circuit breaker with COM16 Modbus module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register-block tables print 1-based register numbers in decimal and hex, where the high byte is the block number (block 94 starts at 0x5E01). The manual's write example for block 68 sends start address 0x4402 for the system time, which the block 68 table lists at 0x4403, so the wire address is the printed number minus 1.

What byte order does the Siemens SENTRON WL (3WL) air circuit breaker with COM16 Modbus module use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Siemens SENTRON WL (3WL) air circuit breaker with COM16 Modbus module?

Start with HR 24069 Current in phase L1 (Phase L1 current); HR 24072 Mean current value over the three phases (Average current); HR 24082 Mean value of phase-to-phase voltage (Average L-L voltage); HR 24085 Total active power (Total active power); HR 24113 Mean value of the power factor (Mean power factor); HR 24117 Frequency (Frequency); HR 24105 Active energy in normal direction (Active energy, MWh).

How do I enable Modbus control of the Siemens SENTRON WL (3WL) air circuit breaker with COM16 Modbus module?

Modbus runs through the COM16 module. Its address, baud rate and parity are in block 160 (printed 0xA003 high byte for the address, 0xA019 for baud rate and parity). Without a bridge on the COM16 WriteEnable input, switching, trip reset, parameter changes and counter resets are blocked; setting the system time and resetting min/max values are still allowed.
