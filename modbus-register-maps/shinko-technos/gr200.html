Shinko Technos GR200 paperless recorder (Modbus RTU / Modbus TCP) Modbus register map

Updated 17 November 2026

Short answer

The GR200 is an up-to-18-channel paperless recorder. It is a Modbus RTU slave on RS-485 and also answers Modbus TCP on port 502 over Ethernet. This map covers the read-only measured values and channel status for all 18 channels plus the per-channel range, scaling and decimal point settings needed to interpret them.

This page lists 145 Modbus registers for the Shinko Technos GR200 paperless recorder (Modbus RTU / Modbus TCP) — 108 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Shinko Technos’s own free documentation (linked below) and checked against it.

Integration notes: Shinko Technos GR200 paperless recorder (Modbus RTU / Modbus TCP)

Integration in brief

Read input registers 30101-30118 for the measured values and 30131-30148 for channel status in one block each with function 04, and read each channel's decimal point setting once with function 03.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set MODBUS Station No. (0-255; 0 stops communication), speed and parity on the front panel. For Modbus TCP (port 502) also turn the MODBUS TCP/IP function ON (factory OFF) and cycle power.

Byte order & addressing

  • Out-of-range readings come back as 32767 (over), -32767 (under) or -32768 (burnout/error); check the status registers.
  • The recorder accepts written values outside the setting range without complaint.

Network setup

  • Factory defaults: station 1, 19200 bps, odd parity, 8 data bits, 1 stop bit (8 bits and 1 stop bit are fixed). Up to 31 units per RS-485 line.

Watch out for

  • A read is limited to 64 registers per message.

Notes on this map

  • Long (2-register) values such as totalizer counts and totalizing times are left out: the manual says one value spans two registers but never states which word comes first.
  • Channel setting blocks are 64 registers apart: CH1 starts at 40001, CH2 at 40065 ... CH18 at 41089.
  • Holding registers are read with function 03 and written with 10H; the map lists no single-register write (06).
  • Tags, colours, totalizer, alarm, display and network settings are omitted; the manual's Table 2 and Table 5 code lists are not reproduced.
  • Measured values carry no decimal point; place it from the channel's decimal point setting.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Shinko Technos GR200 paperless recorder (Modbus RTU / Modbus TCP)

What Modbus registers does the Shinko Technos GR200 paperless recorder (Modbus RTU / Modbus TCP) have?

This map lists 145 registers: 37 input registers, 108 holding registers. 108 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos GR200 paperless recorder (Modbus RTU / Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as 30xxx/40xxx numbers; the manual says the address in the message is the lower four digits minus 1 (40003 is sent as 0002). The manual's example reads CH2 measured value (30102) at relative address 0065H.

What are the minimum Modbus registers to integrate the Shinko Technos GR200 paperless recorder (Modbus RTU / Modbus TCP)?

Start with IR 100 CH1 measured value (CH1 measured value); IR 130 CH1 status (CH1 status); HR 17 CH1 decimal point (CH1 decimal point); HR 15 CH1 engineering start (CH1 engineering start); HR 16 CH1 engineering end (CH1 engineering end); IR 85 Memory card utilization (Memory card utilization).

How do I enable Modbus control of the Shinko Technos GR200 paperless recorder (Modbus RTU / Modbus TCP)?

Set MODBUS Station No. (0-255; 0 stops communication), speed and parity on the front panel. For Modbus TCP (port 502) also turn the MODBUS TCP/IP function ON (factory OFF) and cycle power.
