Short answer

The DCRL3, DCRL5 and DCRL8 are Lovato automatic power factor controllers (the register table covers up to 14 steps). They speak Modbus RTU and ASCII, and the DCRL8 also Modbus TCP, on the optical port or EXP10xx expansion modules. This map covers voltage, current, power factor, powers, alarm bits, step timers and counters, harmonics and the mode, step and reset commands.

This page lists 28 Modbus registers for the Lovato Electric DCRL3 / DCRL5 / DCRL8 power factor controllers — 6 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lovato Electric’s own free documentation (linked below) and checked against it.

Integration notes: Lovato Electric DCRL3 / DCRL5 / DCRL8 power factor controllers

Integration in brief

Read voltage (04h), current (06h), actual power factor (14h) and the alarm bits (16h) with function 04, subtracting one from each table address. Switch AUT/MAN by writing 1 or 2 to 3000h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Use the optical port or fit an EXP1012 RS-485 (or EXP1013 Ethernet on DCRL8) module, then set node address, speed, data format, stop bits and protocol in the setup menu.

Byte order & addressing

  • Table addresses are one above the wire address.
  • 32-bit values are high word first.
  • Some 'signed' values use a sign bit (bit 31) instead of two's complement.

Network setup

  • Defaults: node 01, 9600 baud, 8 data bits, no parity, 1 stop bit, Modbus RTU.
  • Ethernet (DCRL8 + EXP1013): default IP 192.168.1.1, port 1001.
  • Maximum data field is 80 registers.

Watch out for

  • Parameter changes made through 5002h/5004h only take effect after writing 5 to 2F03h (store to EEPROM).

Notes on this map

  • Measures are read with function 03 or 04 (same data) and are listed as input registers. Commands use function 06.
  • Word order: the RTU example returns 00 00 00 1C for 28 °C and the ASCII example 00 00 01 3D for 317 V, so 32-bit values are high word first (ABCD).
  • The RTU example says the panel temperature is at table address 0Eh but sends 00 2D in the frame; the document's written rule (subtract one) and the ASCII example (voltage) are followed here.
  • Left out: cos-phi (02h; bit 31 is the sign and bit 30 the inductive/capacitive flag, no scale printed), and delta-kvar, panel temperature and max temperature (marked sign in bit 31, i.e. sign-magnitude, not two's complement).
  • Left out: output status (10h; no bit legend), THDV at 2008h (no format printed), apparent energy and parameter values (read via 5002h/5004h with lengths given in the operating manual).
  • Intermediate steps follow the printed patterns: insertion times 200h + 2 x (step-1), counts 2020h + (step-1), residual power 2040h + (step-1); only steps 1 and 14 are listed.
  • Left out: the command-menu register 2FF0h. The English text says its C01-C09 functions are mapped to single bits and several can run at once, but the table lists plain values 00h-08h, so the write format is unclear.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lovato Electric DCRL3 / DCRL5 / DCRL8 power factor controllers

What Modbus registers does the Lovato Electric DCRL3 / DCRL5 / DCRL8 power factor controllers have?

This map lists 28 registers: 22 input registers, 6 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lovato Electric DCRL3 / DCRL5 / DCRL8 power factor controllers Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The document states that, as in the Modbus standard, the address in a request is the table address minus one; its function 04 example (registers 10h-17h requested with start 00 0F) and ASCII example (table 04h sent as 00 03) agree. Addresses here are already reduced by one.

What byte order does the Lovato Electric DCRL3 / DCRL5 / DCRL8 power factor controllers use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lovato Electric DCRL3 / DCRL5 / DCRL8 power factor controllers?

Start with IR 3 Voltage (Voltage); IR 5 Current (Current); IR 19 Actual power factor (Actual power factor); IR 21 Error bits (Alarm bits); IR 51 Reactive power (Reactive power); HR 12287 Operating mode change (AUT/MAN mode).

How do I enable Modbus control of the Lovato Electric DCRL3 / DCRL5 / DCRL8 power factor controllers?

Use the optical port or fit an EXP1012 RS-485 (or EXP1013 Ethernet on DCRL8) module, then set node address, speed, data format, stop bits and protocol in the setup menu.
