Grundfos Booster systems (Hydro MPC, Hydro Multi-E, Multi-B) via CIM 200 / CIM 500 Modbus register map

Updated 16 October 2026

Short answer

Grundfos multi-pump booster sets and twin-head pumps share one Modbus functional profile, reached through a CIM 200 (RTU) or CIM 500 (Modbus TCP) module or the SoftCIM port on GENIECON and newer MGE pumps. The map covers system start/stop, control mode and setpoint, per-pump force start/stop, system status and alarm codes, system measurements and a status/data block for each of up to six pumps. Which registers are live depends on the booster type and installed sensors.

This page lists 127 Modbus registers for the Grundfos Booster systems (Hydro MPC, Hydro Multi-E, Multi-B) via CIM 200 / CIM 500 — 23 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Grundfos’s own free documentation (linked below) and checked against it.

Integration notes: Grundfos Booster systems (Hydro MPC, Hydro Multi-E, Multi-B) via CIM 200 / CIM 500

Integration in brief

Address the CIM (rotary switches on the CIM 200, IP on the CIM 500), enable bus control in the controller if it is an MPC/GENIECON/DDD, then write 00101 = 3 to take remote control and start, and 00104 for the setpoint in 0.01 %. Poll 00201 for on/alarm/warning, 00205 for the alarm code, 00301/00302 for pressure and flow and 00209/00210 for per-pump running and alarm bits.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set 00101 bit 0 (RemoteAccessReq) = 1 and bit 1 (OnOffReq) to start/stop. For Hydro MPC, GENIECON and DDD you must also set the controller's control source to 'From bus' (Settings > Secondary functions > Control source). With a CIM in more than one pump of a Multi-E/TPED, control registers must be written to every pump head.

Communication loss & watchdog

Register 00012 sets a comm-loss timeout of 5-3600 s (0 = disabled, default). On timeout the booster returns to Local mode.

Byte order & addressing

  • Register numbers are 1-based: 00104 is wire address 103.
  • Temperatures are in 0.01 K; HeatDiffTemp is in 0.01 °C.
  • Pump block power is scaled 10 W per count, unlike the system power register (1 W, 32-bit).
  • ResetAlarm acts on a rising edge; if AutoAckControlBits (00005) = 0, clear the bit before the next reset.

Network setup

  • CIM 200: address on hex rotary switches SW6/SW7; baud on SW4/SW5 (default 19200); parity on SW3 (default even, 1 stop bit); termination via SW1/SW2.
  • CIM 500: set the protocol rotary switch to Modbus TCP and configure the Modbus TCP IP address in the module web server.
  • Hydro MPC / GENIECON / DDD: select 'From bus' as control source in the controller HMI before expecting Modbus commands to act.

Watch out for

  • Many measurements return 0xFFFF on a given booster type because the sensor or function is not present.
  • Hydro Multi-E model G can only run in auto-control and OpenLoopMax; several pump-block values are unavailable on model G.

Notes on this map

  • All blocks can be read with function code 03 or 04; listed here as holding registers. Control and configuration registers are written with 06 or 16.
  • 32-bit values are HI/LO register pairs with HI at the lower address; the manual combines them as HI x 65536 + LO (ABCD).
  • Temperatures are in 0.01 K (kelvin) except HeatDiffTemp (00369), which is published in 0.01 °C.
  • A raw value of 0xFFFF means 'not available'. Many registers apply only to particular booster types or need a sensor; see the support columns in the manual.
  • Pump blocks repeat every 10 registers: pump 1 at 00401, pump 2 at 00411 ... pump 6 at 00451. Pump power is in 10 W steps. Pilot and backup pump blocks (00461, 00471) and Pump-x energy for pilot/backup were left out.
  • Left out: tank-filling limits (00111-00114, 00215-00219), DDD remote-sensor setpoints and fieldbus sensor block (00119-00128, 00146-00156), manual pump speeds (00136-00143), PI tuning registers 00144/00145 and 00231/00232 (offset/scaling not clear enough), FeedbackSensorMin/Max (00221/00222, no scaling given), analog input values/units (00224-00230, 00376-00382, scaling depends on an enum), flow measurements 1-3 and remote/differential pressures not listed above, and the DDD logged sensor data. Alarm simulation registers were also omitted.
  • AlarmCode 00205 lists booster-system codes; when the alarm comes from an individual pump the pump's own Grundfos code is reported (see the E-pump code list).

Questions about the Grundfos Booster systems (Hydro MPC, Hydro Multi-E, Multi-B) via CIM 200 / CIM 500

What Modbus registers does the Grundfos Booster systems (Hydro MPC, Hydro Multi-E, Multi-B) via CIM 200 / CIM 500 have?

This map lists 127 registers: 127 holding registers. 23 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Grundfos Booster systems (Hydro MPC, Hydro Multi-E, Multi-B) via CIM 200 / CIM 500 Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as 5-digit register numbers; the manual states register X is addressed as X-1 in the telegram (setpoint 00104 is sent as 00103).

What byte order does the Grundfos Booster systems (Hydro MPC, Hydro Multi-E, Multi-B) via CIM 200 / CIM 500 use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Grundfos Booster systems (Hydro MPC, Hydro Multi-E, Multi-B) via CIM 200 / CIM 500?

Start with HR 100 ControlRegister (Remote/start/stop/reset command word); HR 103 Setpoint (Setpoint, 0.01 %); HR 200 SystemStatus (System status bits); HR 204 AlarmCode (System alarm code); HR 208 PumpsRunning (Pumps running); HR 209 PumpsAlarm (Pumps in alarm); HR 300 Head (System head/pressure); HR 301 VolumeFlow (System flow); HR 311 Power (System power (32-bit)).

How do I enable Modbus control of the Grundfos Booster systems (Hydro MPC, Hydro Multi-E, Multi-B) via CIM 200 / CIM 500?

Set 00101 bit 0 (RemoteAccessReq) = 1 and bit 1 (OnOffReq) to start/stop. For Hydro MPC, GENIECON and DDD you must also set the controller's control source to 'From bus' (Settings > Secondary functions > Control source). With a CIM in more than one pump of a Multi-E/TPED, control registers must be written to every pump head.

What happens when the Grundfos Booster systems (Hydro MPC, Hydro Multi-E, Multi-B) via CIM 200 / CIM 500 loses Modbus communication?

Register 00012 sets a comm-loss timeout of 5-3600 s (0 = disabled, default). On timeout the booster returns to Local mode.
