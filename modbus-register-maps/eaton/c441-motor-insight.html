Short answer

Motor Insight is Eaton's voltage and current monitoring motor protection relay. The C441 Ethernet module serves its data over Modbus TCP and RS-485 Modbus RTU together with its own I/O and network settings. This map covers the adapter I/O and comms registers, the motor measurements and trip/warning words (300-336), the command register and the protection settings (400-446).

Integration notes: Eaton C441 Motor Insight motor protection relay (via C441 Ethernet module)

Integration in brief

Read 300-315 for currents, voltages, power and thermal pile, and 330-332 for trip and warning bits. Write command codes to 400 (e.g. 0xAA reset relay) and settings to 403-446. Comm-loss behaviour is set with 440/441 and 251-254.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP is served by the C441 Ethernet module; the IP is set by DHCP, NV memory or the DIP switches (register 143 shows the method; 192.168.1.254 is the restore address). Remote motor control also depends on the comm idle/loss settings 251-254.

Communication loss & watchdog

Register 110 (Modbus TCP) and 159 (serial) set a com timeout in ms (0 = off); 251-254 choose whether the motor stops or holds on comm idle or loss, and 111-114 set the adapter relays' fault and idle states.

Byte order & addressing

  • Register numbers are 1-based; subtract 1 on the wire.
  • Coil numbers in the manual are bit views of registers (coil = 16 x (register - 1) + bit + 1), not separate data.

Network setup

  • Serial port settings live in 160-163 (mode, baud, address, parity/stop) where the table lists them.
  • On a C441R/C441T the RS-485 port is an extra Modbus RTU/ASCII monitoring port that serves the same register map.

Watch out for

  • Several values change scale with hardware or a scale register; check the notes before trusting raw numbers.

Notes on this map

  • Source is a distributor copy (precision-elec.com) of Eaton manual MN04200002E dated August 2012. Eaton lists a later edition (January 2016) at eaton.com, which could not be downloaded from this machine; check it for changes.
  • The tables print 1-based Modbus register numbers: the production/consumption-list note says field inputs register 1 is register address 0 (address = register number - 1).
  • All registers listed are single 16-bit words. Multi-word items (32-bit adapter serial number at 7, firmware/hardware revision at 9/11, IP addresses 144-154, MAC address 156) have no stated word order or layout and are left out. Signedness is not stated; values are typed unsigned.
  • The same map is served over Modbus TCP and over the adapter's RS-485 Modbus RTU port; functions 01/02/03/04/05/06/15/16/23 and 43/14 are supported. Coil numbers in the manual are bit views of the same registers and are not listed here.
  • Registers 1000-4000 are a user-configurable production/consumption list (custom register block); not expanded here.
  • Current registers 300-303 are 0.1 A on 90 A models and on 9 A models with external CTs, and 0.01 A on 9 A models without CTs; motor power 308 is 0.1 kW with external CTs and 0.01 kW otherwise. They are left unscaled here; apply the factor that matches the hardware.
  • Fault code 315 heads a fault queue: read as a list, faults run newest first. The table's next entry is 325.
  • CT multiplier 403: 90 A units 1-4 conductor passes; 9 A units 1-2 passes or 3 = 150:5, 4 = 300:5, 5 = 600:5 CTs.
  • Register 401 (Motor Control) has no description in the manual and is left out.
  • Defaults are those printed for the C441R/C441T serial monitoring port (address 1, 19.2k, even parity, 1 stop bit, RTU); data bits and the Modbus TCP port are not stated.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Eaton C441 Motor Insight motor protection relay (via C441 Ethernet module)

What Modbus registers does the Eaton C441 Motor Insight motor protection relay (via C441 Ethernet module) have?

This map lists 89 registers: 89 holding registers. 57 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Eaton C441 Motor Insight motor protection relay (via C441 Ethernet module) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print register numbers starting at 1; the manual states that the Modbus register address is the register number minus 1 (field inputs, register 1, is address 0).

What are the minimum Modbus registers to integrate the Eaton C441 Motor Insight motor protection relay (via C441 Ethernet module)?

Start with HR 299 Current I1 (Phase A current); HR 302 Current average (Average current); HR 306 Voltage average (Average voltage); HR 307 Motor power (Motor power); HR 313 Thermal pile (Thermal pile); HR 329 Trip reason (Trip reason bits); HR 331 Warning / alarm indications (Warning bits); HR 399 Command register (Command register (reset relay etc.)).

How do I enable Modbus control of the Eaton C441 Motor Insight motor protection relay (via C441 Ethernet module)?

Modbus TCP is served by the C441 Ethernet module; the IP is set by DHCP, NV memory or the DIP switches (register 143 shows the method; 192.168.1.254 is the restore address). Remote motor control also depends on the comm idle/loss settings 251-254.

What happens when the Eaton C441 Motor Insight motor protection relay (via C441 Ethernet module) loses Modbus communication?

Register 110 (Modbus TCP) and 159 (serial) set a com timeout in ms (0 = off); 251-254 choose whether the motor stops or holds on comm idle or loss, and 111-114 set the adapter relays' fault and idle states.
