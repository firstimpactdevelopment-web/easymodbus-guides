Short answer

The Promag 400 is Endress+Hauser's electromagnetic flowmeter family (D, L and W sensors). Its Modbus RS485 interface exposes every operating-menu parameter at a fixed register. This map lists the values an integrator needs: volume and mass flow, conductivity, three totalizers with their controls, units, diagnostics and the Modbus settings.

Integration notes: Endress+Hauser Proline Promag 400 electromagnetic flowmeter (Modbus RS485)

Integration in brief

Set bus address, baud rate and parity on the device, then read volume flow (register 3874, wire 3873) and totalizer 1 (register 2610, wire 2609) with function 03 or 04 as CDAB floats. Reset totalizers by writing to the totalizer control registers.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus settings are under Expert > Communication > Modbus configuration. Writing over the bus can be limited with the Fieldbus writing access parameter (Read + write or Read only).

Byte order & addressing

  • Floats default to CDAB because of the 1-0-3-2 byte order; the order is selectable on the device.
  • Failure mode (register 4920) chooses whether measured values go to NaN or hold the last valid value during a fault.

Network setup

  • Factory settings: address 247, 19200 baud, Even parity, RTU.
  • Telegram delay (default 6 ms) can be raised for slow masters.

Watch out for

  • Writing parameters cyclically wears out the EEPROM.
  • Flow and totalizer values are sent in the units set in the unit registers, so changing a unit on the device changes what the numbers mean.

Notes on this map

  • This is an integrator subset of a parameter manual that gives a register for every menu item; display, sensor-adjustment, I/O and web-server parameters are left out.
  • Float word order follows the Byte order parameter (register 4915). At the factory setting 1-0-3-2 the bytes go out as byte 1, byte 0, byte 3, byte 2, with byte 3 holding the sign and exponent, which is CDAB. If you change Byte order, the word order of every float changes with it.
  • Integer parameters are 2 bytes; the manual does not say signed or unsigned, so they are listed as UINT16 (all values shown are positive codes).
  • Every value can be read with function 03 or 04 and written with 06 or 16, so it is listed here as a holding register.
  • The parity picklist codes for the no-parity options disagree between the parameter description (2 = None/1 stop bit) and the register table (2 = None/2 stop bits), so only 0 = Even and 1 = Odd are given.
  • The diagnostic registers return an integer only; the manual does not list the coding, so read the meaning from the device display or operating manual.
  • String parameters (device tag, serial number, firmware version, order code) and the scan list (5001-5016, data read back at 5051-5081) are left out because their packing depends on the byte-order setting.
  • Writes to non-volatile parameters go to EEPROM, which the manual limits to about one million writes; do not write setpoints cyclically.
  • The data-bit and stop-bit count for the Even/Odd parity settings is not stated in this manual, so those defaults are left blank.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Endress+Hauser Proline Promag 400 electromagnetic flowmeter (Modbus RS485)

What Modbus registers does the Endress+Hauser Proline Promag 400 electromagnetic flowmeter (Modbus RS485) have?

This map lists 53 registers: 53 holding registers. 33 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Endress+Hauser Proline Promag 400 electromagnetic flowmeter (Modbus RS485) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are printed in the Modbus Application Protocol form, which the manual equates with Modicon 3XXXX/4XXXX numbers (mass flow 2007 = 32007), and the scan-list parameter says register addresses are 1-based. So subtract 1 for the wire address: volume flow 3874 is requested at 3873.

What byte order does the Endress+Hauser Proline Promag 400 electromagnetic flowmeter (Modbus RS485) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Endress+Hauser Proline Promag 400 electromagnetic flowmeter (Modbus RS485)?

Start with HR 3873 Volume flow (Volume flow); HR 3875 Mass flow (Mass flow); HR 2609 Totalizer 1 value (Totalizer 1 value); HR 2102 Volume flow unit (Volume flow unit code); HR 2731 Actual diagnostics (Active diagnostic); HR 2607 Control totalizer 1 (Totalizer 1 control (reset/hold)).

How do I enable Modbus control of the Endress+Hauser Proline Promag 400 electromagnetic flowmeter (Modbus RS485)?

Modbus settings are under Expert > Communication > Modbus configuration. Writing over the bus can be limited with the Fieldbus writing access parameter (Read + write or Read only).
