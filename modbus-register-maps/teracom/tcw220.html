Teracom TCW220 Ethernet data logger Modbus register map

Updated 19 November 2026

Short answer

The TCW220 is a Teracom Ethernet data logger with 2 analog inputs, 2 dry-contact inputs, 2 relays and a 1-Wire bus for up to 8 Teracom sensors. Over Modbus TCP it serves relays as coils, inputs as discrete inputs, and readings, limits and alarm flags as holding registers.

This page lists 178 Modbus registers for the Teracom TCW220 Ethernet data logger — 113 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Teracom’s own free documentation (linked below) and checked against it.

Integration notes: Teracom TCW220 Ethernet data logger

Integration in brief

Enable Modbus TCP, then switch relays as coils 100-101, read inputs as discrete inputs 100-101 and read analog and 1-Wire floats from holding registers 17500+ and 19800+.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP/IP is disabled by default. Enable it on the services page of the web interface (standard port 502).

Byte order & addressing

  • Floats are high word first (ABCD).
  • PDU 50000 reports whether settings are saved (0 = unsaved, 1 = saved).

Network setup

  • The factory IP is 192.168.1.2; change it in the network settings, then enable Modbus TCP/IP.

Notes on this map

  • Word order: the manual says float registers are sent big-endian and its example response 41BD 0655 decodes to 23.628, i.e. high word first (ABCD).
  • Strings are fixed-length UTF-8, zero padded; 64-byte fields span 32 registers.
  • 1-Wire sensor values (S11..S82) are floats whose unit comes from the matching dimension string; each sensor has two value slots (Sx1, Sx2).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Teracom TCW220 Ethernet data logger

What Modbus registers does the Teracom TCW220 Ethernet data logger have?

This map lists 178 registers: 2 coils, 2 discrete inputs, 174 holding registers. 113 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Teracom TCW220 Ethernet data logger Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The address table prints PDU (wire) addresses in decimal. The manual's example frame reads register 19800 as 0x4D58 on the wire, so no offset is applied.

What byte order does the Teracom TCW220 Ethernet data logger use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Teracom TCW220 Ethernet data logger?

Start with CO 100 Relay 1 (Relay 1); DI 100 Digital input 1 (Digital input 1); HR 17500 Analog input 1 value (Analog input 1); HR 19800 Sensor 1, S11 value (Sensor 1 first value); HR 20000 Sensor 1, S11 alarm status (Sensor 1 alarm); HR 50003 HW error (Hardware error).

How do I enable Modbus control of the Teracom TCW220 Ethernet data logger?

Modbus TCP/IP is disabled by default. Enable it on the services page of the web interface (standard port 502).

Where is the official Teracom TCW220 Ethernet data logger Modbus documentation?

The source is TCW220 User manual (Revision R4.24), revision 2026-09, published free by Teracom at https://www.teracomsystems.com/download/ethernet-data-logger-tcw220-user-manual/.
