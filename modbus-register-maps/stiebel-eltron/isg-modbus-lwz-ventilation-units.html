Updated 17 November 2026

Short answer

Stiebel Eltron's LWZ integral units combine ventilation with heat recovery, an exhaust-air heat pump and DHW. Over Modbus they are reached through the Internet Service Gateway (ISG) with the Modbus TCP/IP extension, which serves single 16-bit registers with fixed scaling per data type. The map covers system values (input registers 1-33), operating mode, heating/DHW/cooling setpoints and fan stages (holding 1001-1027), status flags (2001-2005), heat, energy and runtime counters (3001-3032) and the shared SG Ready registers.

Integration notes: Stiebel Eltron Integral ventilation units LWZ / LWA via ISG Modbus TCP/IP

Integration in brief

Poll the ISG on TCP port 502, unit ID 1. Read input registers (FC 04) for temperatures, fan speeds, status flags 2001 and fault status 2002; write holding registers (FC 06/16) for operating mode 1001, room/DHW setpoints and the ventilation stages 1018-1021. Subtract 1 from every printed register number.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The ISG web or ISG plus needs the Modbus TCP/IP software extension and, for the ISG web, the Basic service package. With an integral ventilation unit connected, check for it in SERVICEWELT under DIAGNOSIS > BUS SUBSCRIBER > ISG; if Modbus TCP/IP is not listed, update the ISG firmware or contact Stiebel Eltron service.

Byte order & addressing

  • All points are 16-bit; totals use paired kWh/MWh registers.
  • Operating mode codes are not contiguous: 11 = automatic, 14 = manual.
  • Faults cannot be acknowledged over Modbus, only in SERVICEWELT.
  • The Modbus interface cannot run alongside other ISG software interfaces (read-only use with EMI excepted).

Network setup

  • Default ISG IP 192.168.0.126 on a direct PC link; DHCP behind a router. Change it on the Profile tab in SERVICEWELT.
  • Unit ID fixed at 1, port 502.

Watch out for

  • Do not run the ISG on the same CAN bus as a DCo-aktiv GSM module.

Notes on this map

  • Stiebel Eltron does not host this software documentation publicly (its own download path returns 404). The linked copy is a retailer mirror of the unchanged Stiebel Eltron document with one shop cover page added in front.
  • Data types: type 2 = signed, value x 0.1; type 6 = unsigned, x 1; type 7 = signed, value x 0.01; type 8 = unsigned 0-255, x 1. Unavailable objects return 32768 (0x8000).
  • For LWZ units the controller reports -60 for a missing or open sensor lead and -50 for a shorted sensor lead.
  • Energy totals are split into a kWh register (0-999) and an MWh register: total = MWh x 1000 + kWh.
  • Rows marked '(x)' in the table apply only to the listed sub-models (LWZ 504, units with cooling, units with solar, LWZ 304/404/504/Trend); this is noted in the descriptions. Registers 18 and 19 (supply air fan) are listed for LWZ only, not LWA.
  • Left out: extract air temperature (23) and extract air dew point (24), because they are typed as signed x 0.1 values but given a 0-65535 range; BUS-STATUS (2003), typed unsigned but coded with negative values.
  • Holding registers 1016-1027 sit on a continuation page without a repeated table header in the English section; their values were checked against the German table.
  • SG Ready on/off (4001): the language tables of the same document disagree on the coding (German and Italian: 0 = off, 1 = on; English: 0 = on, 1 = off). No value labels are given here; test on site which code switches the function on.
  • WPM-managed heat pumps use another register set: see stiebel-eltron/isg-modbus-wpm-heat-pumps.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Stiebel Eltron Integral ventilation units LWZ / LWA via ISG Modbus TCP/IP

What Modbus registers does the Stiebel Eltron Integral ventilation units LWZ / LWA via ISG Modbus TCP/IP have?

This map lists 99 registers: 69 input registers, 30 holding registers. 30 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Stiebel Eltron Integral ventilation units LWZ / LWA via ISG Modbus TCP/IP Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The document states that ISG addressing is 1-based (its example: register 30501 is reached as address 501 with function code 04), so subtract one from the printed register number: outside temperature, printed 7, is requested at input register address 6. The document also warns that, depending on the configuration, an offset of 1 may have to be allowed for; confirm with outside temperature against the unit display.

What are the minimum Modbus registers to integrate the Stiebel Eltron Integral ventilation units LWZ / LWA via ISG Modbus TCP/IP?

Start with IR 6 Outside temperature (Outside temperature (offset check)); IR 15 Actual DHW temperature (Actual DHW temperature); IR 0 Actual room T HC1 (Actual room temperature HC1); IR 2000 Operating status (Operating status flags); IR 2001 Fault status (Fault status); HR 1000 Operating mode (Operating mode); HR 1001 Room temperature day HC1 (Day room setpoint HC1); HR 1017 Day stage (Ventilation day stage).

How do I enable Modbus control of the Stiebel Eltron Integral ventilation units LWZ / LWA via ISG Modbus TCP/IP?

The ISG web or ISG plus needs the Modbus TCP/IP software extension and, for the ISG web, the Basic service package. With an integral ventilation unit connected, check for it in SERVICEWELT under DIAGNOSIS > BUS SUBSCRIBER > ISG; if Modbus TCP/IP is not listed, update the ISG firmware or contact Stiebel Eltron service.
