Short answer

The SJ-P1 high-function inverter answers Modbus RTU on its RS485 terminals. Coils carry run/stop, direction, reset and the input/output terminals; holding registers carry the dA/db/dC monitors, trip history, RS485 frequency, torque and PID commands and every parameter. This map lists the control set, main monitors, trip monitor 1 and the CF communication parameters.

Integration notes: Hitachi SJ-P1 series inverter (Modbus RTU, firmware Ver. 2.00)

Integration in brief

Set CF-01 to CF-04 for the serial line and CF-08 to Modbus-RTU, then AA101 = 08 and AA111 = 03. Write the signed frequency to 10502/10503, run and stop with coil 1, and poll dA-01, dA-02, dA-40 and the trip monitor.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Select Modbus-RTU with CF-08, then set AA101 = 08 (speed from RS485) and AA111 = 03 (run command from RS485). Coils 1 and 2 only act when AA111 = 03.

Communication loss & watchdog

CF-06 sets the communication timeout (0.00-100.00 s); when it expires error E041 is raised, and CF-05 picks the action (trip, trip after stop, ignore, free-run stop or deceleration stop).

Byte order & addressing

  • Wire address is the printed number minus 1.
  • Two-register values are high word first.
  • Register numbers changed between firmware Ver. 1.xx and 2.00; check the firmware with dC-50 before using this map.

Network setup

  • CF-01 baud (03-10 = 2400-115200 bps), CF-02 station 1-247, CF-03 parity, CF-04 stop bits; CF-07 adds a reply delay.
  • One request handles at most 32 coils or 16 registers; a coil read of 0 or more than 32 coils returns exception 03h.

Watch out for

  • The [NDc] output signal can be assigned to an output terminal to flag a communication loss.

Notes on this map

  • Two-register values are printed as (High) then (Low) register; the guide's read example returns 60.00 Hz as 0000h then 1770h, so the high word comes first (ABCD).
  • This register layout is for firmware Ver. 2.00. The guide lists items whose register number or range changed from Ver. 1.xx (for example dA-04 was one unsigned register in Ver. 1.xx).
  • Only a working subset is listed. Later trip monitors repeat the trip monitor 1 block every 20 registers (trip monitor 2 at 1021, 3 at 1041 ...). The full parameter list is in chapter 14.6.
  • AA101/AA111 are listed without full value tables; the guide states 08 = RS485 for AA101 and 03 = RS485 for AA111. CF-08 (communication method) is left out because its printed codes (00-02) and register range (1-3) disagree.
  • Monitor and setting ranges assume CF-11 register data selection = 00 (A, V). With 01 (%), current and voltage items read as % of rating.
  • The single-register input/output power monitors (dA-30, dA-34) are left out: their printed resolution changes with drive size and is given in kWh for a power value.

Questions about the Hitachi SJ-P1 series inverter (Modbus RTU, firmware Ver. 2.00)

What Modbus registers does the Hitachi SJ-P1 series inverter (Modbus RTU, firmware Ver. 2.00) have?

This map lists 90 registers: 31 coils, 59 holding registers. 34 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Hitachi SJ-P1 series inverter (Modbus RTU, firmware Ver. 2.00) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints register and coil numbers in decimal and hex and says the start number in the frame is the number minus 1; its examples read trip monitor 1 (register 03E9h) with start 03E8h and write coil 1 with start 0000h. So wire address = printed number - 1.

What byte order does the Hitachi SJ-P1 series inverter (Modbus RTU, firmware Ver. 2.00) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Hitachi SJ-P1 series inverter (Modbus RTU, firmware Ver. 2.00)?

Start with CO 0 Operation command (Run/stop); CO 3 Trip reset [RS] (Trip reset); HR 10501 RS485 set frequency (RS485 set frequency); HR 10000 Output frequency monitor (dA-01) (Output frequency); HR 10001 Output current monitor (dA-02) (Output current); HR 10039 DC voltage monitor (dA-40) (DC bus voltage); HR 1000 Trip monitor 1 factor (Latest trip factor); CO 22 Inverter operation ready (Inverter ready).

How do I enable Modbus control of the Hitachi SJ-P1 series inverter (Modbus RTU, firmware Ver. 2.00)?

Select Modbus-RTU with CF-08, then set AA101 = 08 (speed from RS485) and AA111 = 03 (run command from RS485). Coils 1 and 2 only act when AA111 = 03.

What happens when the Hitachi SJ-P1 series inverter (Modbus RTU, firmware Ver. 2.00) loses Modbus communication?

CF-06 sets the communication timeout (0.00-100.00 s); when it expires error E041 is raised, and CF-05 picks the action (trip, trip after stop, ignore, free-run stop or deceleration stop).
