Short answer

Panel-mounted power and energy meter from the Trumeter APM family. Function code 4 input registers return 44 measurements as 32-bit floats (per-phase voltages, currents, powers, angles, power factor, THD, max load, totals and energy); function code 1 coils report ten alarm states.

Integration notes: Trumeter APM Power meter (APM-PWR) Modbus map

Integration in brief

Read input registers 0-87 with FC04 as 44 big-endian floats, and coils 0-9 with FC01 for alarm states.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Notes on this map

  • Word order: the page states the floats use two 16-bit words with the most significant word sent first, and each word high byte first (ABCD).
  • Values are the displayed values in whatever unit the meter is configured for (e.g. 415 for V or 8.7 for kVA), so units are not fixed here; check the meter's unit configuration.
  • Serial settings and default address are not given on this page; set them in the meter's configuration menu.
  • Transport is listed as RTU on the basis that the APM is an RS-485 panel meter; the page itself does not name the physical layer.
  • Unsupported functions return exception 1 and unknown addresses exception 2.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Trumeter APM Power meter (APM-PWR) Modbus map

What Modbus registers does the Trumeter APM Power meter (APM-PWR) Modbus map have?

This map lists 54 registers: 10 coils, 44 input registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Trumeter APM Power meter (APM-PWR) Modbus map Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table lists a parameter number and an 'Address' that starts at 0 (frequency at address 0, L1-L2 voltage at 2); the address column is used directly as the wire address.

What byte order does the Trumeter APM Power meter (APM-PWR) Modbus map use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Trumeter APM Power meter (APM-PWR) Modbus map?

Start with IR 0 Frequency (Frequency); IR 4 L1 to N Voltage (L1-N voltage); IR 6 L1 Current (L1 current); IR 80 Total Active Power (Total active power); IR 74 Active Energy (Active energy); IR 86 All phase power factor (Power factor); CO 0 Alarm 1 status (Alarm 1).

How do I enable Modbus control of the Trumeter APM Power meter (APM-PWR) Modbus map?
