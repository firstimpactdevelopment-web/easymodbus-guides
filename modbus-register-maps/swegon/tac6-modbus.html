Swegon TAC6 controller (Global units) Modbus register map

Short answer

TAC6 is the newer controller of Swegon/Global heat recovery units. All data is in signed 16-bit holding registers: identification, working mode and speed, fan flows, pressures and RPM, temperatures T1-T8, input/output states, run and maintenance hours, alarm bitmaps and the Modbus control block for speed, airflows, bypass, boost and fire alarm. This map lists the registers an integrator needs, not every setup parameter.

This page lists 93 Modbus registers for the Swegon TAC6 controller (Global units) — 19 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Swegon’s own free documentation (linked below) and checked against it.

Integration notes: Swegon TAC6 controller (Global units)

Integration in brief

Connect over Modbus TCP (port 502, unit ID 1). Set 40200 = 1 and write 0-3 to 40201 for stop/I/II/III, or set 40200 = 3 and write supply/exhaust flows to 40204/40205. Read 40052/40053 for mode and speed, 40155-40162 for temperatures and 40300-40304 for alarms; write 1 to 40250 to reset alarms.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the TAC6 Modbus satellite (SAT WIFI-ETHERNET for Modbus TCP) and set 40200 to give Modbus control of the speed or airflows.

Byte order & addressing

  • Only holding registers are used (FC 03, 06, 16).
  • All registers are signed 16-bit.
  • 32-bit values are low word first (CDAB).

Network setup

  • Use unit ID 1 in Modbus TCP requests; the SAT WIFI-ETHERNET accepts only that address because it is not a gateway to RTU.
  • Default satellite IP is 192.168.1.1/255.255.255.0; set DHCP or a fixed IP from the TACtouch advanced menu or TACsimulator, then reset the control board.
  • At most 3 TCP clients can connect at once.

Watch out for

  • Writing EEPROM-backed setup values often wears out the memory.

Notes on this map

  • Addressing and word order come from Swegon's French manual 'TAC6 + MODBUS TCP/IP' (050325, 2023-07-14), which is written for TAC6 boards in GLOBAL/ESENSA units; the register table itself does not repeat them.
  • The TAC6 TCP/IP manual states that all values are signed and that 32-bit values are sent low word first, then high word (Val32 = HIGH x 65536 + LOW), so 32-bit registers here are INT32 CDAB. When writing a 32-bit value, write the low word first; the value updates when the high word arrives.
  • Only a selection is listed: the general info, visualization, control and alarm blocks plus the working mode, flow ratio and Modbus address setup registers. Setup, advanced setup and time-table registers (40400-41xxx) are left out; see the source table.
  • The TAC6 TCP/IP manual says setup parameters are stored in EEPROM rated for about 1,000,000 write cycles; the TAC6 table does not mark which registers these are, so do not write setup values cyclically.
  • Flow values are m³/h or % of maximum torque depending on the working mode (CA vs TQ); 40055 gives the unit of 40054.
  • The TAC6 table does not give where each probe T1-T8 sits in the unit. The digital input/output bitmaps differ from TAC5.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Swegon TAC6 controller (Global units)

What Modbus registers does the Swegon TAC6 controller (Global units) have?

This map lists 93 registers: 93 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Swegon TAC6 controller (Global units) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table prints 4xxxx registers. Swegon's TAC6 + Modbus TCP/IP manual (French) says the leading 4 is only a type prefix and that document numbering is one-based while the address sent is zero-based (register 41001 is sent as 1000). So 40201 is holding register 200 on the wire.

What byte order does the Swegon TAC6 controller (Global units) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Swegon TAC6 controller (Global units)?

Start with HR 199 Control master (Control master); HR 200 Speed selection via Modbus (Speed via Modbus); HR 51 Current working mode (Current working mode); HR 52 Current speed (Current speed); HR 154 Temperature T1 (Temperature T1); HR 158 Temperature T5 (Temperature T5); HR 299 Alarms 1 (Alarm bitmap 1); HR 249 Reset (Alarm reset).

How do I enable Modbus control of the Swegon TAC6 controller (Global units)?

Fit the TAC6 Modbus satellite (SAT WIFI-ETHERNET for Modbus TCP) and set 40200 to give Modbus control of the speed or airflows.
