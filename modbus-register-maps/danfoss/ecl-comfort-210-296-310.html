Short answer

The ECL Comfort 210/296/310 is Danfoss's electronic heating controller for district heating substations, heating circuits and DHW, run by a plug-in application key. Every parameter has a parameter number (PNU), and the Modbus register is the PNU minus one. This map covers circuit modes and status, sensor temperatures, the main room and DHW setpoints, alarms, output status and override, the clock, communication settings and M-bus energy meter 1.

This page lists 131 Modbus registers for the Danfoss ECL Comfort 210 / 296 / 310 heating controller (Modbus RTU / TCP) — 40 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Danfoss’s own free documentation (linked below) and checked against it.

Integration notes: Danfoss ECL Comfort 210 / 296 / 310 heating controller (Modbus RTU / TCP)

Integration in brief

Read circuit status (PNU 4211, wire 4210), sensor temperatures (PNU 10201 and up, wire 10200 and up, value/100) and the comfort setpoint (PNU 11180, wire 11179, value/10) with function 03 or 04. Change the mode by writing PNU 4201 (wire 4200) and setpoints with function 06 only.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step: Modbus is always active. Set the Modbus address (PNU 38) and RS-485 baud rate (PNU 39). All three models have the USB service port and RS-485 Modbus RTU (galvanically isolated on the 296/310); Modbus/TCP is on the ECL 296/310 only.

Byte order & addressing

  • Register = PNU - 1.
  • Only FC03/FC04/FC06; no multi-register write.
  • Address 254 is a service address for single-controller links (USB, TCP).

Network setup

  • RS-485 default: address 1, 38400 baud, 8 data bits, Even parity, 1 stop bit.
  • Bias is off by default (PNU 2049); Danfoss suggests biasing at the master.
  • Modbus/TCP on port 502 (ECL 296/310).

Watch out for

  • Baud and address changes take effect immediately, so you lose the link when you write them.
  • Parameter availability and sensor meaning depend on the installed application key (e.g. A266.1); a non-existing PNU returns exception 2.
  • Write the holiday mode after its start and end dates.

Notes on this map

  • All values are 16-bit integers that must be scaled per parameter. The guide warns that scales in its PNU list are guidelines and can change with the application; check the application key instructions for the parameters you write.
  • The guide does not say whether integers are signed. Temperatures (sensors, setpoints) are listed as INT16 because outdoor temperatures go below zero; codes and counts as UINT16.
  • Sensor S2 example: raw 0x0860 = 2144 = 21.44 °C (scale 100). Setpoint example: 200 = 20.0 °C (scale 10).
  • Application parameters live at 11xxx (circuit 1), 12xxx (circuit 2), 13xxx (circuit 3); add 1000 per circuit. Only circuits 1 and 2 setpoints are listed.
  • M-bus energy meter values use two PNUs with the high word in the first one (serial example 0x00A7, 0xFEE3 = 11009763), so 32-bit values are ABCD. Meters 2-5 start at PNU 6050, 6100, 6150, 6200 with the same offsets. Energy meter type 4 uses a different layout and is not listed.
  • Only function codes 03 and 04 (read) and 06 (write single) are supported; function 16 is not, so write one register at a time. Up to 123 PNUs can be read in one request.
  • Output bitmask PNUs 3998 (high word) and 3999 (low word) are left out because the guide's bit table does not say which bits sit in which word; use the per-output status PNUs 4000-4018 instead.
  • Manual output states can only be set on the display or ECA 30/31, not over Modbus. Override only applies when the controller is not in manual mode.
  • Holiday programs (10700-10839), weekly schedules (3110-3975), heat-curve points and the anti-bacteria settings are documented in the guide but left out to keep the map short.
  • The operating status reads 0 (setback) whenever the circuit mode is above 3.
  • Modbus/TCP connections are closed by the controller after about 75 seconds without traffic.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Danfoss ECL Comfort 210 / 296 / 310 heating controller (Modbus RTU / TCP)

What Modbus registers does the Danfoss ECL Comfort 210 / 296 / 310 heating controller (Modbus RTU / TCP) have?

This map lists 131 registers: 131 holding registers. 40 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Danfoss ECL Comfort 210 / 296 / 310 heating controller (Modbus RTU / TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide lists parameter numbers (PNU) and states the register address is PNU-1; its frame example reads comfort setpoint PNU 11180 at 0x2BAB (11179). So request PNU minus 1 on the wire.

What byte order does the Danfoss ECL Comfort 210 / 296 / 310 heating controller (Modbus RTU / TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Danfoss ECL Comfort 210 / 296 / 310 heating controller (Modbus RTU / TCP)?

Start with HR 10200 Raw sensor S1 (Sensor S1 (meaning depends on the application key)); HR 10202 Raw sensor S3 (Sensor S3 (meaning depends on the application key)); HR 4200 Circuit 1 mode (Circuit 1 mode (write to change)); HR 4210 Circuit 1 status (Circuit 1 status); HR 11179 Circuit 1 comfort room setpoint (Circuit 1 comfort room setpoint); HR 1024 Alarm field 1 (alarms 1-16) (Alarm bits 1-16); HR 6013 Energy meter 1 accumulated energy (Energy meter 1 accumulated energy).

How do I enable Modbus control of the Danfoss ECL Comfort 210 / 296 / 310 heating controller (Modbus RTU / TCP)?

No enable step: Modbus is always active. Set the Modbus address (PNU 38) and RS-485 baud rate (PNU 39). All three models have the USB service port and RS-485 Modbus RTU (galvanically isolated on the 296/310); Modbus/TCP is on the ECL 296/310 only.
