Short answer

FRENIC-HVAC and FRENIC-AQUA drives for fans and pumps speak Modbus RTU on their RS-485 port. Every function code (F, E, H, y, S, M ...) is a holding register found by a fixed group/number rule; the S codes carry frequency, run and PID commands and the M codes carry monitors, status words and alarm history. This map lists the communication command and monitor codes and the link settings.

Integration notes: Fuji Electric FRENIC-HVAC / FRENIC-AQUA inverters (RS-485 Modbus RTU)

Integration in brief

Set y10 = 0 (Modbus RTU), y01 address and y04/y06 serial settings, and H30 = 3 so frequency and run commands come from RS-485. Write S05 (Hz) or S01 (p.u.) for speed and S06 bit 0/1 for run forward/reverse; poll M09, M11, M14 and M16.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Select Modbus RTU with y10 = 0 and set H30 (communications link function) so the frequency and/or run command come from RS-485 (3 = both from the RJ-45 port). If a digital input is assigned to LE (enable communications link), it must be ON.

Communication loss & watchdog

y08 sets a no-response detection time (0 = off, 1-60 s); y02/y03 choose whether the drive trips at once, after a timer, or keeps running.

Byte order & addressing

  • Addresses are function-code based: wire address = group code x 256 + number (for example H30 = 4 x 256 + 30 = 1054).
  • Reads are limited to 50 words and do not cross a function code group; unused codes read as 0.
  • Reading S codes returns the last value written over comms, not the live command; read the M codes for the live value.
  • Alarm reset through S06 needs bit 15 set then cleared; S14 = 1 resets in one write.
  • S14 = 1 resets an alarm even when H30, y98, y99 or the LE terminal block the link; S06 bit 15 only works when the link is enabled.

Network setup

  • y01 station address 1-247, y04 baud (0-4 = 2400-38400 bps), y06 parity (stop bits follow parity in Modbus RTU), data length fixed at 8 bits.
  • y09 adds a response interval (0.00-1.00 s) for slow masters.

Watch out for

  • If S01 is not 0 it overrides S05; write 0 to S01 when using S05.
  • Writing an alarm reset while a run command is still set restarts the drive immediately.

Notes on this map

  • All function code data are single 16-bit words; no 32-bit values are used in this map.
  • Per-unit values (S01, S12, S13, M01, M06, M68, M72, M73) use +/-20000 = 100 % or maximum frequency; convert with the drive's maximum frequency (F03).
  • M09 output frequency is unsigned over Modbus RTU (0.00-655.35 Hz); the signed range in the table applies to the Fuji general-purpose inverter protocol.
  • Codes marked not supported on HVAC/AQUA in the manual (torque and flux commands, motor temperature M22) are left out.
  • Accel/decel times (F07/F08, S08/S09) use Fuji's packed floating-point format [12] and are not listed.
  • M14 bit 6 (TL, torque limiting) is left out: the bit table lists it, but the bit diagram of format 16 shows bit 6 as unused (0).
  • M86 uses alarm-history format 41: the low byte is the light alarm code and the high byte counts consecutive repeats of the same alarm.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Fuji Electric FRENIC-HVAC / FRENIC-AQUA inverters (RS-485 Modbus RTU)

What Modbus registers does the Fuji Electric FRENIC-HVAC / FRENIC-AQUA inverters (RS-485 Modbus RTU) have?

This map lists 53 registers: 53 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Fuji Electric FRENIC-HVAC / FRENIC-AQUA inverters (RS-485 Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers derived from parameter numbers. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each function code is a holding register at 40000 + group code x 256 + number (manual Table 3.2: F=0, E=1, H=4, S=7, M=8, y=14). In the frame the high byte is the group code and the low byte the number, so the wire address is group x 256 + number; the manual's examples send 08 06 for M06 and 07 01 for S01.

What are the minimum Modbus registers to integrate the Fuji Electric FRENIC-HVAC / FRENIC-AQUA inverters (RS-485 Modbus RTU)?

Start with HR 1797 Frequency reference (0.01 Hz) (S05 frequency command); HR 1798 Operation command (S06 run command); HR 1806 Alarm reset command (S14 alarm reset); HR 2057 Output frequency (M09 output frequency); HR 2059 Output current (effective) (M11 output current); HR 2062 Operation status (M14 status); HR 2064 Latest alarm code (M16 latest alarm); HR 1054 Communications link function (mode selection) (H30 link mode).

How do I enable Modbus control of the Fuji Electric FRENIC-HVAC / FRENIC-AQUA inverters (RS-485 Modbus RTU)?

Select Modbus RTU with y10 = 0 and set H30 (communications link function) so the frequency and/or run command come from RS-485 (3 = both from the RJ-45 port). If a digital input is assigned to LE (enable communications link), it must be ON.

What happens when the Fuji Electric FRENIC-HVAC / FRENIC-AQUA inverters (RS-485 Modbus RTU) loses Modbus communication?

y08 sets a no-response detection time (0 = off, 1-60 s); y02/y03 choose whether the drive trips at once, after a timer, or keeps running.
