Schneider Electric Conext Core XC Series grid-tie PV inverter (0G-XC-BB) Modbus register map

Updated 17 November 2026

Short answer

The Conext Core XC is a grid-tied three-phase PV inverter with an RS-485 Modbus RTU port. All values are 16-bit integers with a fixed multiplier, read with function 03 and written with function 16. This map covers the read-only monitoring block (0x1700-0x1828), ratings and grid-code settings, the main power-limit and remote enable/disable controls, Modbus port settings and the log-reading registers.

This page lists 125 Modbus registers for the Schneider Electric Conext Core XC Series grid-tie PV inverter (0G-XC-BB) — 24 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Schneider Electric’s own free documentation (linked below) and checked against it.

Integration notes: Schneider Electric Conext Core XC Series grid-tie PV inverter (0G-XC-BB)

Integration in brief

Poll 0x1700-0x1828 with function 03 for state, grid voltages and currents, active/reactive power and PV values (all 16-bit, divide by the listed factor). To control power, set Parameter Control Station (0xE0E0) to 2 = Modbus, then write the active power limit at 0xFA19 with function 16.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

On the front panel go to 2 Language, Time, Interface > Comm. Interface > Parameter Control Station and select panel control to set the Modbus address and baud rate, then power-cycle with QF2. For writes, set register 0xE0E0 to 2 (Modbus).

Byte order & addressing

  • Addresses are hex and zero based; a master that counts from 1 must add one.
  • Only function codes 03, 16, 08 (sub-function 00) and 43 are supported; there is no FC06 single-register write.
  • Changing the Modbus unit ID (0xE0E1 commit, 0x8003) needs a system reset before it takes effect.

Network setup

  • Default RS-485 settings: 19200 baud, 8 data bits, even parity, 1 stop bit; all inverters on one bus must use the same settings.
  • Do not use 57600 baud if the Vigilohm IM400 is installed (it only supports 38400).

Watch out for

  • Reading an unmapped address returns 0xFFFF with no exception, so a wrong address can look like a valid value.
  • Leaving Logger Mode (0x4705) in any read mode stops data logging; set it back to 0.

Notes on this map

  • Scale: the document gives units as 'unit/xN', meaning divide the raw value by N; this is converted to scale = 1/N.
  • Left out: the 32-bit items (kWh Energy Produced 0x0802-0x0803, Energy Today 0x0804-0x0805, Operating Hours 0x081E-0x081F and Time 0xFA21-0xFA22) because the note does not state their word order; the text product designation, assembly and serial number blocks (0x1-0x1D, typed uchar8); and the log buffer registers.
  • Only a selection of the writable registers in Table 18 is included (enable/disable, power and phase-current limits, power reference source, MPPT voltage window, port settings and a few grid-support switches). The many grid-code thresholds and delays are left out.
  • Registers flagged ** in the note can be written while the inverter is enabled; the rest need the inverter disabled.
  • Unmapped addresses inside a block read 0xFFFF without an error; writing one returns an illegal address exception.
  • The note's Table 20/21 for the optional Vigilohm IM400 insulation monitor is a separate device and is not part of this map.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Schneider Electric Conext Core XC Series grid-tie PV inverter (0G-XC-BB)

What Modbus registers does the Schneider Electric Conext Core XC Series grid-tie PV inverter (0G-XC-BB) have?

This map lists 125 registers: 125 holding registers. 24 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Schneider Electric Conext Core XC Series grid-tie PV inverter (0G-XC-BB) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The application note says register addresses are zero based, printed in hex, and go straight into the request's address field. A master that wants register numbers must convert to decimal and add 1.

What are the minimum Modbus registers to integrate the Schneider Electric Conext Core XC Series grid-tie PV inverter (0G-XC-BB)?

Start with HR 5888 Operational Mode State (Operating mode and state); HR 6142 Active Power (Active power, kW x10); HR 6145 PV Power (PV power); HR 6136 Grid Voltage V12 (Grid voltage V12); HR 6146 Grid Frequency (Grid frequency); HR 6184 Alarm Code (Active alarm code); HR 57568 Parameter Control Station (Hand settings control to Modbus); HR 64025 User Active Power Limit (User active power limit).

How do I enable Modbus control of the Schneider Electric Conext Core XC Series grid-tie PV inverter (0G-XC-BB)?

On the front panel go to 2 Language, Time, Interface > Comm. Interface > Parameter Control Station and select panel control to set the Modbus address and baud rate, then power-cycle with QF2. For writes, set register 0xE0E0 to 2 (Modbus).
