Integration notes: Intesis (HMS Networks) INMBSTOS001R000 Toshiba AC to Modbus RTU gateway

Integration in brief

Leave SW1 at the defaults for plain control (gateway is AB-bus master), set address and baud on SW3/SW4, power-cycle, then poll holding registers 0-11 with function 03 and write with 06. Select RAV or VRF on SW1 only if you need the 4000+ diagnostics.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step; register 7 (gateway disablement) must be 0 for commands to reach the unit.

Byte order & addressing

  • Diagnostic addresses are per indoor unit: (IU - 1) * 25 + 4000 + offset.
  • Register 5 reads the Modbus-supplied temperature (reg 22) when one is valid, and is offset ±0.5 °C by mode.
  • 8-N-2 by default; 8-N-1 is auto-detected.

Network setup

  • SW1: indoor unit type (default 'not specified'; RAV / VRF SMMS / VRF SHRM enable diagnostics) and AB-bus role (master by default; slave if a Toshiba remote is the header).
  • SW3: slave address; SW3/SW4: baud (9600 default).
  • SW4: x1/x10, °C/°F and 120 Ω termination.
  • DIP changes need a power cycle.

Watch out for

  • Writes made while the gateway is still initialising are not applied; some registers read undetermined values until start-up completes.
  • Error code 65535 means the gateway lost the indoor unit.

Notes on this map

  • Every register is documented as a 16-bit unsigned holding register and no temperature range in the manual goes below zero, so temperatures are UINT16. The 'no value' marker the manual writes as -32768 is raw 0x8000 (32768) and is listed as an enum entry. Temperature registers depend on DIP SW4: x1 °C, x10 °C (decidegrees) or °F (no °F x10). The register-table footnote calls x10 the default, but the SW4 table and the quick-start page (all other switches off) give x1 °C as the factory setting, so scale 1 / °C is used. Read SW4 position 1-2 on site: if x10 is set use scale 0.1; if °F is set the values are whole °F.
  • Advanced diagnostic temperatures (4010-4012, 4016, 4021) are printed as 'x1 °C' and kept as UINT16 per the manual; the manual never says how a sub-zero value would be encoded.
  • Left out: indoor fan-coil temperatures TCJ, TC2 and TC1 (4013-4015). Coil temperatures can fall below 0 °C and the manual gives no signed encoding for these unsigned registers.
  • Left out because the printed scale is ambiguous: indoor PMV opening ('x1, x10 Pulses', 4018) and running hours indoor fan ('x100 hours', 4019).
  • Left out: outdoor-unit diagnostic blocks for VRF-SMMSi (4200+), VRF-SHRM/SMMS and RAV systems. They mix 'x10 A', 'X100 MPa', 'x10 RPS' and 'x100 hours' notations whose direction (multiply or divide) is not defined, and outdoor temperatures can go below zero with no signedness stated.
  • Advanced registers are only populated when SW1 selects a unit type other than the default; the Priority column (0 start-up, 1 high, 2 low) sets how often each is refreshed, tuned with register 4451.
  • Error code enum (Toshiba codes) not reproduced; see manual section 7.
  • Register 5 is marked R/W in the register table but described as read-only in the temperature section; it is listed read-only here. Use register 22 to supply an external temperature.
  • Default slave address: the quick-start page and register 15 range (1..63) give 1, while the SW3 table labels the all-off position (address 0) as default. Unit ID 1 is listed; check SW3 on site.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Intesis (HMS Networks) INMBSTOS001R000 Toshiba AC to Modbus RTU gateway

What Modbus registers does the Intesis (HMS Networks) INMBSTOS001R000 Toshiba AC to Modbus RTU gateway have?

This map lists 36 registers: 36 holding registers. 13 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Intesis (HMS Networks) INMBSTOS001R000 Toshiba AC to Modbus RTU gateway Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables give a 'protocol address' (base 0) and a 'PLC address' (base 1); the protocol address is the wire address. Per-indoor-unit diagnostics are printed as a formula, (IU - 1) * 25 + 4000 + n; this file lists IU 1 only (4000-4021, without 4013-4015 and 4018-4019). For IU 2 add 25, and so on.

How do I enable Modbus control of the Intesis (HMS Networks) INMBSTOS001R000 Toshiba AC to Modbus RTU gateway?
