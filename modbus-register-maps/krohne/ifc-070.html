Short answer

The IFC 070 is KROHNE's battery-powered electromagnetic water meter converter, with an optional mains (FlexPower) supply and an RS-485 Modbus RTU add-on. Flow, totalizers, pressure and temperature are offered three times: as doubles, floats and integers. This map covers the double and float banks, the integer litre counters, alarms, coil commands and the Modbus settings.

Integration notes: KROHNE IFC 070 signal converter (Modbus)

Integration in brief

Read the double bank 3000-3071 or the float bank 4000-4035 in one request each. Keep the data format at big endian so multi-register values decode high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The Modbus add-on is configured in the local menu: slave address (default 1), baud rate (default 9600), parity (default even), stop bits, data format (default big endian), transmission delay and reception interval.

Byte order & addressing

  • Addresses are protocol addresses (0-based).
  • Changing the data format register flips byte and/or word order for every multi-register value.
  • Reading an alarm-state register acknowledges the alarm.

Network setup

  • Default RTU settings: address 1, 9600 baud, even parity, 1 stop bit.
  • On battery-powered units the bus is not isolated and is limited to about 100 m without termination.

Watch out for

  • On battery units Modbus may be off after a mains loss (8007 default off) or listening only at the reception interval: a master that polls at random times gets no answer.
  • Setting writes stay pending until coil 1002 (Apply changes) is set.

Notes on this map

  • This copy is hosted by the distributor Instrumart; it is KROHNE document 4005415902 (AD IFC 070 Modbus R02).
  • Word order: the data-format setting (8004) offers little endian, big endian (default) and two mixed-endian modes, and the data encoding page says the most significant byte of any multi-byte quantity is sent first. In the default big-endian mode, 32- and 64-bit values are therefore ABCD (highest word first). If the data format is changed, the order changes too.
  • The register banks can be read with function 03 or 04 and written with 16; coils with 01/02 and 05. The register section says every address can be read with any function code, so the coil addresses also read as unsigned integers.
  • Left out: integer-format flow speed (5000), pressure (5014), temperature (5016, 5032) and battery capacity (5026/5028), because the manual gives no scaling for these integer values; the measurement-settings block 6000-6027, whose printed layout is too jumbled to tie each code to its address; and the string/array identity registers other than the serial numbers.
  • Settings registers marked R/W* only accept writes after unlocking with the access-control register 9998 and with the special write option enabled; changes are held until 'Apply changes' (coil 1002).
  • To save battery the Modbus interface can be switched off when mains power is lost (default off) and can be set to listen only at a reception interval.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the KROHNE IFC 070 signal converter (Modbus)

What Modbus registers does the KROHNE IFC 070 signal converter (Modbus) have?

This map lists 78 registers: 21 coils, 57 holding registers. 23 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the KROHNE IFC 070 signal converter (Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables list the Modbus protocol (data) address, which goes on the wire unchanged: flow speed at 3000 is requested as 3000. In a 1-based or Modicon tool add 1 (3001 / 43001).

What byte order does the KROHNE IFC 070 signal converter (Modbus) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the KROHNE IFC 070 signal converter (Modbus)?

Start with HR 4002 Volume flow (float) (Volume flow (float)); HR 4008 Total volume counter (float) (Total volume counter (float)); HR 3016 Total volume counter (Total volume counter (double precision)); HR 4022 Error/warning states (32-bit) (Error and warning bits); HR 4028 Battery remaining (float) (Battery remaining); HR 4030 Flow direction (32-bit) (Flow direction).

How do I enable Modbus control of the KROHNE IFC 070 signal converter (Modbus)?

The Modbus add-on is configured in the local menu: slave address (default 1), baud rate (default 9600), parity (default even), stop bits, data format (default big endian), transmission delay and reception interval.

Where is the official KROHNE IFC 070 signal converter (Modbus) Modbus documentation?
