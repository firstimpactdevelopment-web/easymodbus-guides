Integration notes: Yaskawa iQpump605 intelligent pump controller (MEMOBUS/Modbus RTU)

Integration in brief

Set H5-01..H5-03, then b1-01 = 2 and b1-02 = 2 so the frequency reference and Run come from Modbus. Write 0001H (run bits) and 0002H (frequency reference) with function 10H and poll 0020H, 0021H and 002CH.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set H5-01 node address (default 1FH), H5-02 speed (default 3 = 9600 bps) and H5-03 parity (default 0 = none), then power-cycle or set H5-20 = 1. For control set b1-01 = 2 and b1-02 = 2 (b1-02 = 8 combines AUTO command with serial run). H5-12 decides whether 0001H bits 0/1 are FWD/REV run or Run plus direction.

Communication loss & watchdog

H5-05 = 1 (default) enables CE detection; H5-09 sets the timeout (0.0-10.0 s, default 2.0 s) and H5-04 the reaction (0 ramp, 1 coast, 2 fast stop, 3 alarm only - default, 4 run at the H5-34 go-to frequency, with H5-35 as an optional timeout). Drive status 2 (002CH) bit F shows a timeout.

Byte order & addressing

  • Registers are hex and 0-based: 0020H is sent as 00 20.
  • No function 06H; use 10H.
  • Parameter writes need the Enter command unless H5-11 = 1.

Network setup

  • RS-485 is on the control terminal block; 8 data bits and 1 stop bit are fixed; up to 31 drives per line.
  • Set DIP switch S2 ON only at the last drive on the line.
  • H5-01 = 0 makes the drive ignore Modbus.

Watch out for

  • The EEPROM Enter command (0900H) is limited to about 100,000 writes; use 0910H for frequent changes.
  • Network inputs in 0001H are ORed with the physical terminals.

Notes on this map

  • Frequency registers 0002H, 0023H and 0024H use the units chosen in o1-03, so they are left unscaled.
  • Left out: 0025H output voltage (unit switched by H5-10), 0026H output current, 0027H output power and 0028H/0032H torque reference (unit/sign not fixed for every model), 003EH/003FH output frequency in r/min or 0.01 % (sign not stated), 15FFH (named PID setpoint in one row and PID feedback in another), the U-monitor, fault-trace and fault-history blocks from 0040H and the option/extended registers 15C0H-15DFH.
  • Supported function codes are 03H, 08H, 10H, 5AH and 67H (non-consecutive read/write); there is no 06H, so use 10H even for a single register.
  • With H5-11 = 0, parameters written over Modbus take effect only after the Enter command (0900H or 0910H). Command registers do not need Enter.

Questions about the Yaskawa iQpump605 intelligent pump controller (MEMOBUS/Modbus RTU)

What Modbus registers does the Yaskawa iQpump605 intelligent pump controller (MEMOBUS/Modbus RTU) have?

This map lists 39 registers: 39 holding registers. 24 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yaskawa iQpump605 intelligent pump controller (MEMOBUS/Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are hex and are sent unchanged: the manual's read example (Table 6.7) asks slave 2 for starting register 0020H as bytes 00 20. Parameters use the hex number printed under each parameter (H5-01 = 0425H).
