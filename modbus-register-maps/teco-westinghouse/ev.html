Short answer

The EV is a legacy TECO-Westinghouse micro inverter that speaks Modbus RTU or ASCII through an RS-485 option card. The run command and frequency go to 00E6H/00E7H, status, fault code and monitors are read from 00EFH-00F8H, and each F/C parameter has its own register listed in section 6. This map covers the command and monitor data.

Integration notes: TECO-Westinghouse EV micro inverter (Modbus RTU/ASCII)

Integration in brief

Fit the RS-485 option card, set the follower address and serial settings on the drive, then write 00E6H (run bits) and 00E7H (frequency) and poll 00EFH-00F6H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Install the RS-485 option card and set address and communication parameters per the EV drive manual.

Byte order & addressing

  • Registers are hex.
  • Functions 03H, 06H, 08H and 10H; maximum frame 80 bytes.
  • Follower addresses 01H-FEH.
  • Parameter registers in section 6 are not in parameter order (e.g. F07 = 0008H, F08 = 0007H).

Network setup

  • RS-485 via the option card terminals RSA/RSB; 120 ohm, 1/4 W terminators at both ends.

Watch out for

  • Unused bits read as 0; registers marked not used are read-only.

Notes on this map

  • 00E7H frequency command has no printed scale; the 06H example labels the write '60.0 Hz' but sends 1770H (6000), so it is left unscaled. The 00F2H/00F3H monitors are 100 = 1 Hz.
  • Left out: 00F9H/00FAH AIN values (footnote *1 not explained) and the remote-keypad registers.
  • The section 6 table maps every F and C parameter to an individual hex register; those are not expanded here.
  • Communication setup parameters (address, baud, protocol) are not named in this manual; see the EV drive manual.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the TECO-Westinghouse EV micro inverter (Modbus RTU/ASCII)

What Modbus registers does the TECO-Westinghouse EV micro inverter (Modbus RTU/ASCII) have?

This map lists 12 registers: 12 holding registers. 2 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the TECO-Westinghouse EV micro inverter (Modbus RTU/ASCII) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are hex and sent unchanged: the 03H example reads start address 00 F2 (frequency command monitor) and gets 1770H. Parameters use the register table in section 6 (e.g. F01 = 0001H, C00 = 0064H), which is not sequential.

What are the minimum Modbus registers to integrate the TECO-Westinghouse EV micro inverter (Modbus RTU/ASCII)?

Start with HR 230 Operation command (Run/stop, direction, reset); HR 231 Frequency command (Frequency command); HR 239 Operation state (Operation state); HR 240 Fault description (Fault code); HR 243 Output frequency (Output frequency); HR 246 Output current (Output current).

How do I enable Modbus control of the TECO-Westinghouse EV micro inverter (Modbus RTU/ASCII)?

Install the RS-485 option card and set address and communication parameters per the EV drive manual.

Where is the official TECO-Westinghouse EV micro inverter (Modbus RTU/ASCII) Modbus documentation?

The source is EV Inverter Series: Modbus Communication Manual, published free by TECO-Westinghouse at https://tecowestinghouse.com/PDF/ev_modbus_manual.pdf.
