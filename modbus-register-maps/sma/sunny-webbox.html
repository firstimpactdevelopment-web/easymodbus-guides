Updated 17 November 2026

Short answer

Legacy SMA plant data logger that exposes its connected SMA inverters and sensors over Modbus TCP. Unit ID 1 is the gateway with the table that maps each detected device to a Modbus unit ID; unit ID 2 holds plant-wide values such as total and daily yield, plant AC power and plant time. Per-device data sit under unit IDs 3-247 (see the separate common-device map).

This page lists 23 Modbus registers for the SMA Sunny WebBox Modbus gateway (plant and gateway unit IDs 1-2) — 4 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from SMA’s own free documentation (linked below) and checked against it.

Integration notes: SMA Sunny WebBox Modbus gateway (plant and gateway unit IDs 1-2)

Integration in brief

Enable Modbus in the WebBox web UI, run plant detection, then read plant totals from unit ID 2 and look up each device's unit ID in the unit-1 assignment table before polling devices on unit IDs 3-247.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Log in to the WebBox as installer, Settings > Network, set 'Use Modbus' to Yes (default off), optionally change the port, Save. Activating Modbus assigns unit IDs to the devices already detected.

Byte order & addressing

  • Devices detected later get unit ID 255 and cannot be reached until you assign them a unit ID 3-247 (gateway table or Data > Devices > Modbus page).
  • Reading a block that contains undefined registers returns NaN for those; a block with no defined register gives an exception.

Network setup

  • Modbus TCP only, factory port 502.
  • Unit ID 1 = gateway, 2 = plant, 3-247 = devices.
  • Keep requests at least 10 s apart and 30 registers or less per transfer.

Watch out for

  • SMA recommends about 25 devices per WebBox (max 50).
  • Values from Sunny Central inverter families reach the WebBox Modbus interface with a typical delay of 8-10 s.

Notes on this map

  • Word order: the manual's data-type figures put bits 31..16 in the first register and bits 15..0 in the second (64-bit: bits 63..48 first), and data are sent big-endian, so 32/64-bit values are high word first (ABCD).
  • Format to scale: FIX0 = x1, FIX1 = x0.1, FIX2 = x0.01, FIX3 = x0.001, TEMP = one decimal (x0.1), DT = UTC seconds since 1970-01-01, Duration = seconds.
  • NaN (no value): U16 0xFFFF, S16 0x8000, U32 0xFFFFFFFF, S32 0x80000000, U64 0xFFFFFFFFFFFFFFFF.
  • Multi-register values must be read in one request. SMA recommends at least 10 s between data requests and no more than 30 registers per transfer.
  • Unit ID 1 answers 30001/30003/30007/30057 and the assignment table; unit ID 2 answers the same four plus the plant values. Both are listed once here.
  • Only assignment slots 1 and 2 are listed. Slot n starts at 42109 + 4 x (n-1) (Device-ID, 2-register serial number, Unit ID); the table runs to slot 245 at 43085-43088.
  • To change a device's unit ID, write the slot's Device-ID, serial number and Unit ID registers as one block with FC16; only the Unit ID register is writable. Never assign the same unit ID twice.
  • Time-zone code list (section 7.6) is not reproduced.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the SMA Sunny WebBox Modbus gateway (plant and gateway unit IDs 1-2)

What Modbus registers does the SMA Sunny WebBox Modbus gateway (plant and gateway unit IDs 1-2) have?

This map lists 23 registers: 15 input registers, 8 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the SMA Sunny WebBox Modbus gateway (plant and gateway unit IDs 1-2) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The assignment tables give 'ADR (DEC)', the decimal Modbus register address, which is sent unchanged in the request (the manual's gateway example reads device 1 at 42109). 30xxx entries are read-only values, 40xxx entries are writable parameters; the WebBox accepts FC03 and FC04 for reads.

What byte order does the SMA Sunny WebBox Modbus gateway (plant and gateway unit IDs 1-2) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the SMA Sunny WebBox Modbus gateway (plant and gateway unit IDs 1-2)?

Start with IR 30775 Plant AC active power, all phases [Pac] (Plant AC power); IR 30513 Plant total yield [E-Total] (Plant total energy); IR 30517 Plant day yield [E-heute] (Plant day energy); IR 30193 Plant time (UTC) [SerTm] (Plant time); HR 42112 Device 1: Unit ID (Unit ID of device slot 1); IR 30007 Modbus data change counter (Profile change counter).

How do I enable Modbus control of the SMA Sunny WebBox Modbus gateway (plant and gateway unit IDs 1-2)?

Log in to the WebBox as installer, Settings > Network, set 'Use Modbus' to Yes (default off), optionally change the port, Save. Activating Modbus assigns unit IDs to the devices already detected.
