Integration notes: Endress+Hauser Proline Prosonic Flow W 400 ultrasonic flowmeter (Modbus RS485)

Integration in brief

Read volume flow (wire 2006) and totalizer 1 (wire 2609) as CDAB floats with function 03 or 04; check actual diagnostics (wire 2731) and signal strength for clamp-on health. Reset totalizers through the totalizer control registers.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus settings are under Expert > Communication > Modbus configuration. Fieldbus writing access (register 6807) must be Read + write for Modbus writes.

Byte order & addressing

  • Floats default to CDAB (byte order 1-0-3-2), selectable on the device.
  • Failure mode 4920 chooses NaN or last valid value for measured values during a fault.

Network setup

  • Factory settings: address 247, 19200 baud, Even parity, RTU.
  • Telegram delay can be raised for slow masters.

Watch out for

  • Values are sent in the units set in the unit registers; read the unit registers at start-up.
  • Clamp-on accuracy depends on the pipe and sensor setup done on the device; check signal strength and acceptance rate if values look wrong.

Notes on this map

  • Integrator subset of a parameter manual that lists a register for every menu item; installation (pipe/sensor), I/O, display, WLAN and web-server parameters are left out.
  • Float word order follows the Byte order parameter (register 4915). The factory setting 1-0-3-2 sends byte 1, byte 0, byte 3, byte 2, byte 3 being sign and exponent, so floats are CDAB. Changing Byte order changes every float.
  • Integer parameters are 2 bytes and listed as UINT16; the manual does not state signedness and all codes shown are positive.
  • All parameters read with function 03 or 04 and write with 06 or 16; they are listed as holding registers.
  • The no-parity picklist codes differ between the parameter description (2 = None/1 stop bit) and the register table (2 = None/2 stop bits), so only Even (0) and Odd (1) are given.
  • The diagnostic registers return an integer whose coding the manual does not list.
  • String parameters (tag, serial number, firmware, order code) and the scan list (5001-5016) are left out because their packing depends on the byte order setting.
  • Velocity unit sits at register 2600, right next to the totalizer 1 block (2601 and up); do not confuse them.
  • Non-volatile writes go to EEPROM; avoid cyclic writes.
  • The data-bit and stop-bit count for the Even/Odd parity settings is not stated in this manual, so those defaults are left blank.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Endress+Hauser Proline Prosonic Flow W 400 ultrasonic flowmeter (Modbus RS485)

What Modbus registers does the Endress+Hauser Proline Prosonic Flow W 400 ultrasonic flowmeter (Modbus RS485) have?

This map lists 60 registers: 60 holding registers. 35 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Endress+Hauser Proline Prosonic Flow W 400 ultrasonic flowmeter (Modbus RS485) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints registers in the Modbus Application Protocol form and equates them with Modicon 3XXXX/4XXXX numbers (its own example: 2007 = 32007); the scan-list parameter calls register addresses 1-based. Subtract 1 on the wire: volume flow at register 2007 is requested at 2006.

What byte order does the Endress+Hauser Proline Prosonic Flow W 400 ultrasonic flowmeter (Modbus RS485) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Endress+Hauser Proline Prosonic Flow W 400 ultrasonic flowmeter (Modbus RS485)?

Start with HR 2006 Volume flow (Volume flow); HR 2014 Flow velocity (Flow velocity); HR 2609 Totalizer 1 value (Totalizer 1 value); HR 2102 Volume flow unit (Volume flow unit code); HR 4958 Signal strength (Signal strength); HR 2731 Actual diagnostics (Active diagnostic); HR 2607 Totalizer 1 control (Totalizer 1 control).

How do I enable Modbus control of the Endress+Hauser Proline Prosonic Flow W 400 ultrasonic flowmeter (Modbus RS485)?

Modbus settings are under Expert > Communication > Modbus configuration. Fieldbus writing access (register 6807) must be Read + write for Modbus writes.
