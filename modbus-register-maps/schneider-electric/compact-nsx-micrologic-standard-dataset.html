Short answer

MicroLogic trip units in ComPact NSX breakers are read over Modbus through an IFM serial interface or an IFE Ethernet interface. Schneider publishes a 'standard dataset' at registers 32000-32341 that gathers breaker status, trip causes, currents, voltages, power, energy, demand and power factor in one block. Floats and 64-bit energies are big-endian; values are already in engineering units.

Integration notes: Schneider Electric ComPact NSX MicroLogic trip unit, standard dataset (IFM / IFE interface)

Integration in brief

Read the dataset with function 03 in three requests, as the guide does: 32000-32123, 32124-32241 and 32340 onward. Breaker status is at 32001, currents from 32028, voltages from 32056, power from 32072, energy from 32096, power factor at 32206-32213.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit an IFM (RS-485 Modbus) or IFE (Ethernet) interface and connect it to the trip unit over the ULP cord. No enable step is needed to read the dataset; remote control needs the locking pad open and the command interface.

Byte order & addressing

  • IFE always answers on unit ID 255.
  • In Auto-Speed mode the IFM uses one stop bit with even/odd parity and two stop bits with no parity.
  • Voltage, power and energy registers need an E (or P/H) trip unit; type A units only fill currents.

Network setup

  • IFM: set the Modbus address on the two rotary switches; leave Auto-Speed on and send at least 25 frames so it can lock onto baud and parity.
  • IFE: set its IP address; the Modbus unit ID is fixed at 255.

Watch out for

  • Changing baud or parity after auto-detection needs an IFM power cycle.
  • Check the validity register before trusting a status bit.

Notes on this map

  • The guide states INT32/INT64 values are big-endian (most significant register first) and decodes total active energy 32096-32099 that way. Its FLOAT32 readout example (registers 32028-32029 returning 0x440A 0xC000 = 555 A) shows floats are high word first too.
  • Each description says which trip units fill the register: NSX A/E (ComPact NSX MicroLogic types A and E), NT/NW/NS A/E/P/H, and MTZ (the X column).
  • Bit registers come in pairs: the even register holds a validity bit for each bit of the odd register that follows.
  • Left out: IO module status words 32003/32005, pre-alarm and user-alarm words 32017-32023, and 32186 (maximum earth-leakage current), whose unit is printed as V.
  • IFE: the server address is 255 (fixed). IFM: the address comes from the two rotary switches; baud and parity are auto-detected by default. With Auto-Speed off, 4800-38400 baud and even/odd/none parity can be set in EcoStruxure Power Commission. The guide gives no fixed default and no TCP port.
  • One read is limited to 125 registers; the guide reads the dataset in three requests (32000-32123, 32124-32241, 32340-32435). Do not split a 64-bit energy across two reads.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Schneider Electric ComPact NSX MicroLogic trip unit, standard dataset (IFM / IFE interface)

What Modbus registers does the Schneider Electric ComPact NSX MicroLogic trip unit, standard dataset (IFM / IFE interface) have?

This map lists 98 registers: 98 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Schneider Electric ComPact NSX MicroLogic trip unit, standard dataset (IFM / IFE interface) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide lists a hex address and a decimal register for every row, with register = address + 1 (register 32028 = 0x7D1B). Its readout example requests 0x7D1B for register 32028.

What byte order does the Schneider Electric ComPact NSX MicroLogic trip unit, standard dataset (IFM / IFE interface) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Schneider Electric ComPact NSX MicroLogic trip unit, standard dataset (IFM / IFE interface)?

Start with HR 32000 Circuit breaker status (Open/closed/tripped status); HR 32006 Tripping cause, standard protections (Trip cause); HR 32027 RMS current phase 1 (Phase 1 current); HR 32055 Voltage V12 (Voltage V12); HR 32077 Total active power (Total active power); HR 32095 Total active energy (Total active energy); HR 32211 Total power factor (Total power factor).

How do I enable Modbus control of the Schneider Electric ComPact NSX MicroLogic trip unit, standard dataset (IFM / IFE interface)?

Fit an IFM (RS-485 Modbus) or IFE (Ethernet) interface and connect it to the trip unit over the ULP cord. No enable step is needed to read the dataset; remote control needs the locking pad open and the command interface.
