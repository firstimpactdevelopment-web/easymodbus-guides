Short answer

The TSV300 is a Teracom 4-channel true-RMS voltage transducer (0-264 VAC or up to 370 VDC) with Modbus RTU over RS-485. It gives AC and DC readings with min/max as 32-bit floats and as 32-bit signed integers x1000.

This page lists 74 Modbus registers for the Teracom TSV300 AC/DC voltage transducer with Modbus RTU — 21 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Teracom’s own free documentation (linked below) and checked against it.

Integration notes: Teracom TSV300 AC/DC voltage transducer with Modbus RTU

Integration in brief

Read the AC floats at PDU 100-107 or DC floats at PDU 500-507 with function 03; the x1000 int32 blocks suit masters without float support.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is the only interface and is always active; there is nothing to switch on. Factory settings are address 1, 19200 baud, 8E1.

Byte order & addressing

  • Baud rate and framing changes only take effect after the device is powered off and on again.
  • Word order for every 32-bit value is set by the Data order register (PDU 13); check it before blaming the scaling.

Network setup

  • Set unit ID (PDU 10), baud (PDU 11) and framing (PDU 12), then power-cycle the device.
  • Terminate both ends of the RS-485 bus with 120 ohm; the built-in resistor is enabled by wiring Term to RS485-. A daisy chain is recommended.

Notes on this map

  • Addresses are taken from the manual's PDU address column (0-based); the logical column is the same number plus 40001, the holding-register offset the manual states.
  • All 32-bit values follow the Data order register (PDU 13): 1 = most significant word first (factory default), 2 = least significant word first. The map shows the default, ABCD.
  • Left out: the 32-bit float/integer test-value registers (PDU 82-95), which only exist to check word order; the 16-bit test values are kept.
  • AC blocks start at PDU 100 (float) and 150 (x1000 int32); DC blocks at PDU 500 and 550. Min/max registers start as NaN after a reset and track readings from then on.
  • A missing reading returns NaN (float) or -2147483648 (int32).
  • The manual lists function codes 3 and 6 for the float multiplier/offset registers; a 2-register write normally needs function 16.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Teracom TSV300 AC/DC voltage transducer with Modbus RTU

What Modbus registers does the Teracom TSV300 AC/DC voltage transducer with Modbus RTU have?

This map lists 74 registers: 74 holding registers. 21 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Teracom TSV300 AC/DC voltage transducer with Modbus RTU Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register table prints both a PDU (wire) address and a logical address (PDU + 40001 for holding registers). 'documented' holds the logical number; the PDU number is what goes in the request, e.g. logical 40101 = PDU 100.

What byte order does the Teracom TSV300 AC/DC voltage transducer with Modbus RTU use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Teracom TSV300 AC/DC voltage transducer with Modbus RTU?

Start with HR 100 Input AC voltage 1 (AC voltage input 1); HR 102 Input AC voltage 2 (AC voltage input 2); HR 500 Input DC voltage 1 (DC voltage input 1); HR 150 Input AC voltage 1 x 1000 (AC voltage 1 x1000 (int32)); HR 1000 Reset min and max values (Reset min/max).

How do I enable Modbus control of the Teracom TSV300 AC/DC voltage transducer with Modbus RTU?

Modbus RTU is the only interface and is always active; there is nothing to switch on. Factory settings are address 1, 19200 baud, 8E1.

Where is the official Teracom TSV300 AC/DC voltage transducer with Modbus RTU Modbus documentation?

The source is TSV300 User manual (Revision R1.4), revision 2026-10, published free by Teracom at https://www.teracomsystems.com/download/tsv300-ac-voltage-transducer-with-modbus-rtu-interface/.
