Kohler Decision-Maker 550 generator set controller (application code 2.10+) Modbus register map

Updated 17 November 2026

Short answer

The Decision-Maker 550 is a Kohler generator set controller. It answers Modbus RTU directly with a holding-register map of generator electrical output, engine status from the ECM or local senders, run-time and maintenance counters, system setpoints, remote timed-run commands and a 16-word system event stack. This map covers the electrical and engine blocks, master switch and mode status, run-time counters, key system settings and the remote functions.

This page lists 63 Modbus registers for the Kohler Decision-Maker 550 generator set controller (application code 2.10+) — 8 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Kohler’s own free documentation (linked below) and checked against it.

Integration notes: Kohler Decision-Maker 550 generator set controller (application code 2.10+)

Integration in brief

Read 400001-400028 for generator output and 400033-400047 for engine data in one or two FC 03 requests, check 400079/400080 for switch position and programming mode, and use 401306/401307 for remote timed starts once the controller is in remote programming mode.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

On the controller set the network address (unique per unit) and the baud rate (9600 or 19200) in the communications menu. Writes require the controller's programming mode to be Remote; otherwise writes are rejected with exception 01.

Byte order & addressing

  • The exception table caps reads at 50 registers (section 1.3 says 100) and writes at 16; do not read past the end of a block or start a read at an undefined register.
  • 32-bit LONG counters are low word first.
  • Byte-packed fields (day|month, hr|min, min|sec) put the first item in the high byte.

Network setup

  • Serial format is 8 data bits, no parity, 1 stop bit.
  • Register 409999 returns device ID 20 for the 550.

Watch out for

  • Writes to system parameters are rejected unless the generator set is in OFF or AUTO.
  • A timed-run start is refused while a timed run is already active.

Notes on this map

  • Data types follow the manual's definitions: WORD = 16-bit unsigned, SWORD = 16-bit signed, LONG = 32-bit unsigned with the least significant word first, so LONG registers are listed CDAB.
  • Oil, fuel and coolant pressures and temperatures follow 400139 Metric Units: kPa and °C when metric, psi and °F otherwise. The units shown assume metric.
  • The ECM status row is printed as 40048 while its neighbours use 6-digit 4000xx references; it sits between 400047 and 400049 and is treated as 400048.
  • Left out: user-calibrated analog inputs 1-7, DDEC-only values, the 2-word date fields (byte-packed day|month), maintenance date/time fields, time-delay and protective setpoints, analog/digital input setup, relay driver definitions, event history, strings and the defined common faults.
  • Only system event word 1 is listed; the stack runs 401500-401515 (events 0-255) and must be read as one 16-register block.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Kohler Decision-Maker 550 generator set controller (application code 2.10+)

What Modbus registers does the Kohler Decision-Maker 550 generator set controller (application code 2.10+) have?

This map lists 63 registers: 63 holding registers. 8 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Kohler Decision-Maker 550 generator set controller (application code 2.10+) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints 6-digit holding-register references (400001 = first holding register, 409999 = register 49999 in 5-digit form), so 400001 is wire address 0 and 401306 is wire address 1305.

What byte order does the Kohler Decision-Maker 550 generator set controller (application code 2.10+) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Kohler Decision-Maker 550 generator set controller (application code 2.10+)?

Start with HR 0 L1-L2 Voltage (L1-L2 voltage); HR 6 L1 Current (L1 current); HR 9 Frequency (Frequency); HR 10 Total kW (Total kW); HR 34 Engine Speed (Engine speed); HR 35 Local Battery Voltage (Battery voltage); HR 78 Master Switch Position (Master switch position); HR 1499 System Events word 1 (events 0-15) (System event stack word 1).

How do I enable Modbus control of the Kohler Decision-Maker 550 generator set controller (application code 2.10+)?

On the controller set the network address (unique per unit) and the baud rate (9600 or 19200) in the communications menu. Writes require the controller's programming mode to be Remote; otherwise writes are rejected with exception 01.
