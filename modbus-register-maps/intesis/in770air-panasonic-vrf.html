Integration notes: Intesis (HMS Networks) IN770AIR***O000 700 Series Air Gateway, Panasonic application (Modbus)

Integration in brief

Pick the Panasonic application and the Modbus interface in Intesis MAPS, discover or add the units, send the project, then read and write each unit's block.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The gateway must be configured with Intesis MAPS (Panasonic 770 project template, Modbus selected) and the project sent to it; the unit numbers used in the address formulas are the indoor / outdoor unit addresses.

Byte order & addressing

  • Writes accept FC06 (single register) only.
  • Trigger (T) registers act when 1 is written and are not meant to be read.

Network setup

  • All Modbus settings (RTU or TCP, slave address, baud, parity) are made with the Intesis MAPS tool; the manual gives no factory serial settings.
  • On first power-up DHCP is tried for 30 seconds, then the gateway falls back to 192.168.100.246.
  • Modbus RTU uses the EIA-485 port (A+, B-); bias and 120 ohm termination are on DIP switch block SW A.

Watch out for

  • The line number (1 or 2) moves the whole indoor and outdoor map by 10000.

Notes on this map

  • For indoor unit n add (n-1) x 100, for outdoor unit n add (n-1) x 25, and add 10000 for line 2.
  • The all-unit temperature setpoint is printed at address 14, which is already the 'fan speed Low (all units)' address; it is left out.
  • Compressor 1..3 operation time (outdoor +4..+6) are left out: a 0..16777215 h range does not fit the single register listed.
  • One manual covers the three licence sizes of the same hardware: IN770AIRXXSO000 (4 indoor / 4 outdoor units), IN770AIR00SO000 (16 / 16) and IN770AIR00MO000 (64 indoor / 30 outdoor). The brand application is chosen in Intesis MAPS.
  • The manual gives no data type for the registers; values whose printed range goes below zero are listed as INT16, the rest as UINT16.
  • The consumption registers (yesterday / today / total, also per heat and cool) are left out: each takes two addresses, but the manual gives neither the word order nor a fixed unit (Wh or kWh is chosen in MAPS).
  • Reads use FC03 or FC04; writes use FC06 only. 'T' (trigger) registers act when 1 is written.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Intesis (HMS Networks) IN770AIR***O000 700 Series Air Gateway, Panasonic application (Modbus)

What Modbus registers does the Intesis (HMS Networks) IN770AIR***O000 700 Series Air Gateway, Panasonic application (Modbus) have?

This map lists 58 registers: 58 holding registers. 39 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Intesis (HMS Networks) IN770AIR***O000 700 Series Air Gateway, Panasonic application (Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Occupancy registers start at address 0, so printed addresses are wire addresses. Indoor unit n (1..64) on line L uses n x 100 + (L-1) x 10000 + offset; outdoor unit n (1..31) uses n x 25 + (L-1) x 10000 + 7000 + offset. This file lists line 1, indoor 1 (100..129) and outdoor 1 (7025..7028).

What are the minimum Modbus registers to integrate the Intesis (HMS Networks) IN770AIR***O000 700 Series Air Gateway, Panasonic application (Modbus)?

Start with HR 100 IU on/off (On/off); HR 101 IU operation mode (Mode); HR 102 IU fan speed (Fan speed); HR 104 IU temperature setpoint (Setpoint (x10)); HR 105 IU AC ambient temperature (Room temperature (x10)); HR 119 IU unit error code (Error code); HR 122 IU communication error (Communication error); HR 7025 OU communication error (Outdoor unit communication error).

How do I enable Modbus control of the Intesis (HMS Networks) IN770AIR***O000 700 Series Air Gateway, Panasonic application (Modbus)?

The gateway must be configured with Intesis MAPS (Panasonic 770 project template, Modbus selected) and the project sent to it; the unit numbers used in the address formulas are the indoor / outdoor unit addresses.
