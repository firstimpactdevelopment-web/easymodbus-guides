Novus N20K48 modular process controller (Modbus RTU) Modbus register map

Updated 17 November 2026

Short answer

The Novus N20K48 is a modular PID temperature and process controller with optional RS-485 Modbus RTU. All registers are 16-bit holding registers covering identity, input configuration, control, tuning, timers, alarms and ramp/soak programs. This map covers the setpoint, process variable, output, run/auto modes, input setup, tuning and alarm setpoints.

This page lists 38 Modbus registers for the Novus N20K48 modular process controller (Modbus RTU) — 33 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Novus’s own free documentation (linked below) and checked against it.

Integration notes: Novus N20K48 modular process controller (Modbus RTU)

Integration in brief

Poll 200-202 for setpoint, PV and output power. Write 200 to change the setpoint, 214 to run/stop control and 213 for manual/automatic.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the RS-485 option and set address and serial parameters on the controller.

Byte order & addressing

  • Addresses are 0-based.
  • Temperature PV is x10 regardless of the decimal-point setting.

Network setup

  • Up to 247 controllers on one RS-485 line; terminals 3 (D1/D+/B), 2 (D0/D-/A), 1 (GND).

Watch out for

  • Setpoint writes are limited to SPLL/SPHL (220/221).

Notes on this map

  • This copy is hosted on a reseller's Shopify store; it is the Novus N20K48 Communication Protocol V1.0x document.
  • Function codes 03, 05, 06 and 16 are supported; the manual says all registers are 16-bit integers. Signed types are used where a published range goes negative.
  • Scaling: the PV of a temperature input is always the value times 10, whatever INPUT_DPPO says; for linear inputs, PV and setpoint decimals follow INPUT_DPPO (279). Setpoint-type registers are listed unscaled because the manual does not say whether the x10 rule also applies to them.
  • Left out: AI_DIAG (88) and the status words, whose bit numbering (printed from bit 1) is not tied to bit 0 in the text; serial-number, Bluetooth name and ramp/soak program registers; dual-word input limits 78-81 and 103-106, whose word order is not stated.
  • Serial settings are made at the controller; the protocol document gives no defaults.
  • Addressing rests on the register table starting at address 0 with a real register (INFO_ID); the document has no request-frame example.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Novus N20K48 modular process controller (Modbus RTU)

What Modbus registers does the Novus N20K48 modular process controller (Modbus RTU) have?

This map lists 38 registers: 38 holding registers. 33 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Novus N20K48 modular process controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register table lists addresses from 0 (INFO_ID), which only fits 0-based protocol addresses; send the printed number unchanged. Add 1 (or 40001) for a 1-based or Modicon tool.

What are the minimum Modbus registers to integrate the Novus N20K48 modular process controller (Modbus RTU)?

Start with HR 201 CTRL_PV1 process variable (Process variable); HR 200 CTRL_SP control setpoint (Setpoint); HR 202 CTRL_MV1 control output power (Output power 0.1 %); HR 214 CTRL_RUN run (Run control); HR 213 CTRL_AUTO control mode (Manual/automatic); HR 279 INPUT_DPPO decimal point position (Decimal point position).

How do I enable Modbus control of the Novus N20K48 modular process controller (Modbus RTU)?

Fit the RS-485 option and set address and serial parameters on the controller.
