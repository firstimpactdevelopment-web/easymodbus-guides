Short answer

SIMOCODE pro V Modbus is a motor management and protection system whose basic unit has a built-in RS-485 Modbus RTU slave. Its data sets are mapped into one bit memory area (coils/discrete inputs) and one register memory area. This map covers the cyclic command and monitoring bits, motor currents, voltages and power, statistics and the device diagnostic bits.

This page lists 258 Modbus registers for the Siemens SIMOCODE pro V Modbus RTU basic unit — 14 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Siemens’s own free documentation (linked below) and checked against it.

Integration notes: Siemens SIMOCODE pro V Modbus RTU basic unit

Integration in brief

Set the address (default 126) and baud (default 19200), then read holding registers 0x0806-0x081D for currents, voltages and power, and discrete inputs 0x1C08 onward for status. Control the motor through coils 0x0000-0x0002 (ON<, OFF, ON> in the default process image).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the Modbus address with the addressing plug (DIP switches 1-247, press TEST/RESET) or in SIMOCODE ES (Parameter > Modbus), together with baud rate, port configuration (8E1/8O1/8N2/8N1) and wait time. Remote control over the bus needs the operating mode Remote (mode selector S1 = 1 and S2 = 1).

Communication loss & watchdog

Watchdog / watchdog time in the Modbus parameters: if no valid read or write arrives within the time, the unit restarts its baud search (auto baud) and, with Bus monitoring enabled, raises 'Fault - bus'. 'PLC/PCS monitoring' raises 'Fault - PLC/PCS' when its input (normally cyclic receive bit 0.7) drops in Remote mode.

Byte order & addressing

  • Addresses are hex offsets sent as-is.
  • D words are big-endian, high word first.
  • Currents are percent of the set current Is, not amps.

Network setup

  • Default address 126, default baud 19200; 300-57600 baud or auto (4.8-57.6 kbps, needs the watchdog on).
  • RS-485 via terminals A/B/SPE or the 9-pin sub-D (alternatives, not both).
  • Port configuration 8E1, 8O1, 8N2 or 8N1.

Watch out for

  • Coil writes accept only 0x0000 and 0xFF00.
  • A writable bit block cannot be written across read-only bits.
  • Auto baud detection works only with the watchdog enabled.

Notes on this map

  • Word order: the manual says data longer than one byte is stored big-endian (figure 4-1), so the D word values (power, operating hours, starts, energy) are high word first (ABCD).
  • Function codes 03 and 04 return the same register data, and 01 and 02 the same bit data; registers are listed as holding registers and read-only bits as discrete inputs.
  • The coil and input-bit assignments shown are the factory defaults of the process image; they can be reassigned in SIMOCODE ES.
  • Each diagnostic register 0x1C00-0x1C0F also holds 16 of the diagnostic bits (bit address = 0x1C00 + 16 x register offset + bit). Only the bit addresses are listed, because the manual's FC 01 example confirms them.
  • Left out: byte-packed values (thermal motor model, phase unbalance and cos phi in 0x0802-0x0803, permissible starts in 0x0C02), AM1 inputs, TM1 temperatures 1-3 and EM+ currents (no unit printed), error/event memory, trace data, I&M records and the device parameters from 0x4180 (parameter writes need the full tables on pp. 58-77).
  • Several operating-hour values are counted in seconds (unit 1 s) even though their name says hours.
  • The FC 03 example on p. 27 prints the start address of the currents as 0x07 although the text says 0x0807; the table address 0x0807 is used here.
  • Max per request: 2000 bits, 125 registers; the command image accepts at most 2 registers / 16 coils per access and measured values 16 registers.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Siemens SIMOCODE pro V Modbus RTU basic unit

What Modbus registers does the Siemens SIMOCODE pro V Modbus RTU basic unit have?

This map lists 258 registers: 8 coils, 210 discrete inputs, 40 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Siemens SIMOCODE pro V Modbus RTU basic unit Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed as hex offsets and sent unchanged as the start address. The manual's examples read device status bits with start address 0x1C08 (FC 01) and write the cooling-down period at 0x419A (FC 06). In a 1-based tool add 1 (0x0807 = 2055 -> 42056).

What byte order does the Siemens SIMOCODE pro V Modbus RTU basic unit use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Siemens SIMOCODE pro V Modbus RTU basic unit?

Start with HR 2055 Current I_L1 (Current L1 (% of Is)); HR 2054 Max. current I_max (Max. phase current); HR 2074 Active power P (Active power); DI 7176 Status - group fault (Group fault); DI 7186 Status - Off (Status Off); CO 2 Cyclic receive bit 0.2 (Command ON> (default)); CO 1 Cyclic receive bit 0.1 (Command OFF (default)).

How do I enable Modbus control of the Siemens SIMOCODE pro V Modbus RTU basic unit?

Set the Modbus address with the addressing plug (DIP switches 1-247, press TEST/RESET) or in SIMOCODE ES (Parameter > Modbus), together with baud rate, port configuration (8E1/8O1/8N2/8N1) and wait time. Remote control over the bus needs the operating mode Remote (mode selector S1 = 1 and S2 = 1).

What happens when the Siemens SIMOCODE pro V Modbus RTU basic unit loses Modbus communication?

Watchdog / watchdog time in the Modbus parameters: if no valid read or write arrives within the time, the unit restarts its baud search (auto baud) and, with Bus monitoring enabled, raises 'Fault - bus'. 'PLC/PCS monitoring' raises 'Fault - PLC/PCS' when its input (normally cyclic receive bit 0.7) drops in Remote mode.
