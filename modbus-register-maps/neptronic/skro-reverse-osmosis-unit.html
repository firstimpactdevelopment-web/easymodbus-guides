Short answer

The SKRO is Neptronic's reverse osmosis unit that feeds purified water to its humidifiers. The Modbus RTU module exposes holding registers for inlet, permeate and concentrate pressures, the TDS reading, flow settings, motor and valve states, level floats, warnings, the operating state and an enumerated system alarm, plus a power on/off and request register.

This page lists 50 Modbus registers for the Neptronic SKRO reverse osmosis water treatment unit (Modbus communication module) — 20 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Neptronic’s own free documentation (linked below) and checked against it.

Integration notes: Neptronic SKRO reverse osmosis water treatment unit (Modbus communication module)

Integration in brief

Read State (15061), System Alarm (15062), the three pressures (6000-6002) and TDS (6003); switch the unit with System Power State (15000) and send resets or a fast flush through Request (15060).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Modbus communication module and set the address from the device menu or register 0.

Communication loss & watchdog

Network Timeout Failsafe (12025) reads 0 = OK / 1 = Timeout and Modbus Network Timeout (12026) is an Off/On setting; the timeout delay itself (6030/6031, 30-600 s) spans two registers and is not listed. The guide does not describe what the unit does on timeout.

Byte order & addressing

  • All points are holding registers (FC03/06/16 only).
  • Auto baud detection is the default.

Network setup

  • RS-485 two-wire, RTU mode, 9600-57600 baud or auto.
  • Parity / stop bits via register 2 (default no parity, 2 stop bits).

Watch out for

  • Warnings 12064-12070 are separate 0/1 registers; the System Alarm code in 15062 is the main fault.

Notes on this map

  • Only function codes 03, 06 and 16 are supported; binary points are 16-bit holding registers holding 0 or 1.
  • A 'Scale N' data type with 'Value x N' means raw = engineering value x N; this map stores the multiplier 1/N.
  • Units follow Modbus Server Units (15002): 0 metric, 1 imperial.
  • Left out because they span two registers with no stated word order: Modbus TCP keep-alive (6016/6017), Network Timeout Delay (6030/6031), Run Time (6265/6266) and On Time (6267/6268).
  • Left out because the scale column and the 'Value x' text disagree: Regulator Pressure 6269 (Scale 1 vs x100), Pump On Fast Flush Delay 6270 (Scale 1 vs x10) and Idle Drain Time 6271 (Scale 1 vs x11).
  • Product name (3-6) and database version (16000-16015) ASCII registers are left out; 12000-12002 and 12027-12062 are printed as reserved ranges.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Neptronic SKRO reverse osmosis water treatment unit (Modbus communication module)

What Modbus registers does the Neptronic SKRO reverse osmosis water treatment unit (Modbus communication module) have?

This map lists 50 registers: 50 holding registers. 20 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Neptronic SKRO reverse osmosis water treatment unit (Modbus communication module) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide states addresses follow the Protocol Address (base 0, add 1 for a PLC) and prints the convention notation (base 400001) next to each, e.g. 6000 / 406001. The protocol address is the wire address.

What are the minimum Modbus registers to integrate the Neptronic SKRO reverse osmosis water treatment unit (Modbus communication module)?

Start with HR 15061 State (Operating state); HR 15062 System Alarm (System alarm); HR 15000 System Power State (Power on/off); HR 6000 Inlet Pressure (Inlet pressure); HR 6001 Permeate Pressure (Permeate pressure); HR 6003 TDS Sensor (TDS); HR 15060 Request (Reset / fast flush request).

How do I enable Modbus control of the Neptronic SKRO reverse osmosis water treatment unit (Modbus communication module)?

Fit the Modbus communication module and set the address from the device menu or register 0.

What happens when the Neptronic SKRO reverse osmosis water treatment unit (Modbus communication module) loses Modbus communication?

Network Timeout Failsafe (12025) reads 0 = OK / 1 = Timeout and Modbus Network Timeout (12026) is an Off/On setting; the timeout delay itself (6030/6031, 30-600 s) spans two registers and is not listed. The guide does not describe what the unit does on timeout.
