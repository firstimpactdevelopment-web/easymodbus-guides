Short answer

The R-16DI-8DO is a Seneca R-series remote I/O with 16 digital inputs, each with a 32-bit counter and pulse timing, and 8 digital outputs. It serves Modbus TCP on two Ethernet ports and Modbus RTU on RS-485. This map covers the input and output words, counters and counter reset, low/high time and period floats, integer frequencies, and the coil/discrete-input views.

Integration notes: Seneca R-16DI-8DO Ethernet I/O (16 digital inputs, 8 digital outputs)

Integration in brief

Read holding register 20 for all 16 inputs and write 22 for the 8 outputs (or use coils 32-39). Counters are 32-bit LSW-first pairs from 102; reset any of them through register 100 or coils 100-115.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP server and RTU slave are on by default; configure through the web server or Seneca Discovery Device.

Communication loss & watchdog

Per the web-server chapter, an optional digital-output watchdog (default disabled, timeout default 5 s) sends the outputs to their fail state when no Modbus, USB or P2P traffic arrives within the timeout.

Byte order & addressing

  • Offset is the wire address.
  • 32-bit values are LSW first on this model.

Network setup

  • Factory IP is 192.168.90.101; change it before adding a second unit.

Watch out for

  • Do not assume sibling R-series word order; this model's table is LSW first.

Notes on this map

  • The protocol page lists function codes 01, 03, 05, 06, 15 and 16; the tables also give the digital inputs as 1x input status read with function 02. Modbus RTU runs on RS-485 and Modbus TCP serves up to 8 clients.
  • Unlike some sibling R-series products, this table marks every 32-bit pair LSW first (counter 1 LSW at 40103, MSW at 40104), so counters and floats are CDAB.
  • Factory settings from the manual: static IP 192.168.90.101/24, gateway 192.168.90.1, Modbus TCP port 502, station address 1; RS-485 38400 baud, 8 data bits, no parity, 1 stop bit, address 1.
  • Left out: the command register 40017 (codes not listed for this product); the 32-bit integer low/high/period copies at 40201-40296, whose unit is printed as [ms*10] and is unclear; the consecutive copy block from 48001 (it repeats the values with integer timing in 50 us steps); float frequencies at 48331+.
  • Coils 1-16 in the coil table mirror the inputs read-only and are not listed; use discrete inputs 10001-10016.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Seneca R-16DI-8DO Ethernet I/O (16 digital inputs, 8 digital outputs)

What Modbus registers does the Seneca R-16DI-8DO Ethernet I/O (16 digital inputs, 8 digital outputs) have?

This map lists 125 registers: 24 coils, 16 discrete inputs, 85 holding registers. 42 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seneca R-16DI-8DO Ethernet I/O (16 digital inputs, 8 digital outputs) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Holding-register tables print the 4x number (40001) and the 0-based offset (0); coils print 1 / offset 0 and discrete inputs 10001 / offset 0. The offset is the wire address.

What byte order does the Seneca R-16DI-8DO Ethernet I/O (16 digital inputs, 8 digital outputs) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Seneca R-16DI-8DO Ethernet I/O (16 digital inputs, 8 digital outputs)?

Start with HR 20 Digital inputs (Digital inputs); HR 22 Digital outputs (Digital outputs); HR 102 Counter 1 (Counter 1); HR 100 Counter reset (Counter reset bits); HR 528 Input 1 period (Input 1 period).

How do I enable Modbus control of the Seneca R-16DI-8DO Ethernet I/O (16 digital inputs, 8 digital outputs)?

Modbus TCP server and RTU slave are on by default; configure through the web server or Seneca Discovery Device.

What happens when the Seneca R-16DI-8DO Ethernet I/O (16 digital inputs, 8 digital outputs) loses Modbus communication?

Per the web-server chapter, an optional digital-output watchdog (default disabled, timeout default 5 s) sends the outputs to their fail state when no Modbus, USB or P2P traffic arrives within the timeout.
