Neptronic TSUB Series universal wall-mount controller (Modbus RTU) Modbus register map

Updated 19 November 2026

Short answer

The TSUB is a Neptronic wall-mount room controller with built-in sensing and configurable analog, binary and universal I/O for fan coils and similar terminal HVAC equipment. Over Modbus RTU it exposes room and external temperatures, humidity, CO2 and pressure readings, heating/cooling ramp demands, output states, mode, fan and setpoint control, VFD and 6-way-valve settings, and its configuration registers.

This page lists 157 Modbus registers for the Neptronic TSUB Series universal wall-mount controller (Modbus RTU) — 126 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Neptronic’s own free documentation (linked below) and checked against it.

Integration notes: Neptronic TSUB Series universal wall-mount controller (Modbus RTU)

Integration in brief

Read holding registers with function 03 at the wire address shown in the guide's Protocol Address column (Modicon 40001 = address 0). Set the temperature unit for Modbus first, then use the mode, fan and setpoint registers for control.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is the controller's native protocol; set the address (1-246) and, if needed, a fixed baud rate and parity from the device menu or registers 0-2.

Byte order & addressing

  • The guide prints both the 0-based protocol address and the 40001-style notation, so there is no off-by-one guesswork.
  • Baud register holds baud/100 (384 = 38400); 0 means automatic baud detection.

Network setup

  • RS-485 two-wire, RTU. Supported baud rates 9600, 19200, 38400 and 57600; automatic baud detection is the default.
  • Parity/stop bits come from the communication-port register: 1 = none + 2 stop, 2 = even + 1 stop, 3 = odd + 1 stop.

Watch out for

  • Changing the Modbus temperature-unit bit changes the meaning of every temperature register at once.
  • Some registers only apply to models with a humidity, CO2 or other optional sensor.

Notes on this map

  • Every register is a 16-bit holding register (function 03 to read, 06 or 16 to write); there are no 32-bit values.
  • Temperatures, setpoints, bands and offsets are reported in °C or °F according to the "temperature unit in Modbus" bit of the system-options register; scaling is x100 for sensor readings and offsets and x10 for setpoints and bands, as listed per register.
  • Register 0 packs the Neptronic product ID in the high byte and the Modbus address in the low byte.
  • Left out: the four product-name registers (two ASCII characters each, byte order not spelled out) and every register the guide marks Reserved.
  • Left out: the pulse output values 40187-40191 and the delta-temperature registers 40192-40193 (not carried into this map); 40100 (analog output 3 ramp), whose option list sits next to a printed Scale 10 that makes no sense for a list; and 40183 (floating output BO3/BO7), whose data-type column says Scale 10 while the range text says Value x 1.
  • The guide's remarks next to the system-mode values point at register numbers that do not match the table; only the value list is kept.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Neptronic TSUB Series universal wall-mount controller (Modbus RTU)

What Modbus registers does the Neptronic TSUB Series universal wall-mount controller (Modbus RTU) have?

This map lists 157 registers: 157 holding registers. 126 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Neptronic TSUB Series universal wall-mount controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row prints both the protocol (wire) address, starting at 0, and the 40001-style notation; e.g. 40046 is protocol address 45. The documented field holds the 4xxxx notation.

What are the minimum Modbus registers to integrate the Neptronic TSUB Series universal wall-mount controller (Modbus RTU)?

Start with HR 11 Internal temperature sensor reading (Internal (room) temperature x100); HR 14 Control temperature reading (Control temperature x100); HR 41 System mode status (System mode); HR 42 Fan speed selection by user (Fan speed); HR 43 Temperature setpoint in occupancy or day mode (Occupied setpoint x10); HR 26 Actual heating demand of ramp 1 (Heating demand ramp 1); HR 28 Actual cooling demand of ramp 1 (Cooling demand ramp 1); HR 9 System Status 1 (Status 1); HR 10 System Status 2 (Status 2 (alarms)); HR 44 System option1 (System option 1 (bit 1 = Modbus temp unit)).

How do I enable Modbus control of the Neptronic TSUB Series universal wall-mount controller (Modbus RTU)?

Modbus is the controller's native protocol; set the address (1-246) and, if needed, a fixed baud rate and parity from the device menu or registers 0-2.

Where is the official Neptronic TSUB Series universal wall-mount controller (Modbus RTU) Modbus documentation?

The source is TSUB Series Universal Wall-Mount Controller Modbus Communication Module User Guide (TSUB-Modbus Guide-250829 (V1.13)), revision 2025-08-29, published free by Neptronic at https://www.neptronic.com/controls/PDF/2025/TSUB-Modbus%20Guide-250829%20(V1.13).pdf.
