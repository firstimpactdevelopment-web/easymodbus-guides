Short answer

ABB's compact general purpose variable frequency drive with a built-in RS-485 port that speaks Modbus RTU. The first six holding registers carry the control word, two references, status word and two actual values; every parameter is also a holding register derived from its group and index. Integration notes: ABB ACS480 general purpose drive (embedded Modbus RTU)

Integration in brief

Enable Modbus RTU in group 58, point the start/stop and reference sources at the embedded fieldbus, then write the ABB Drives control word and Reference 1 at 400001/400002 and poll the status word and actual values at 400004-400006. Read further monitoring values straight from their parameter registers (400000 + 100*group + index).

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set 58.01 Protocol enable = Modbus RTU, then 58.03 node address, 58.04 baud and 58.05 parity, and apply them with 58.06 Communication control = Refresh settings (or power-cycle). For control set 20.01 Ext1 commands (and 20.06 for EXT2) = Embedded fieldbus and the reference source, e.g. 22.11 Ext1 speed ref1 or 28.11 Ext1 frequency ref1 = EFB ref1. Every start/stop control-word value in the manual sets bit 10 (REMOTE_CMD); the manual's own description of that bit is truncated. Save parameter writes permanently with 96.07 Parameter save manually.

Communication loss & watchdog

58.14 Communication loss action (No action / Fault / Last speed / Speed ref safe / Fault always / Warning) with 58.16 Communication loss time (0.0-6000.0 s, not listed here) and 58.15 Communication loss mode (any message, or only control word/reference writes, resets the timer). A loss trips 6681 EFB comm loss or warns A7CE; 'Speed ref safe' runs at 22.41/28.41. There is a 30 s boot-up delay before monitoring starts.

Byte order & addressing

  • Addresses are 6-digit Modicon references: 400001 = wire 0. 32-bit parameter registers start at 420000 and cannot be reached with 5-digit (4xxxx) addressing.
  • 32-bit values in this map are listed CDAB, which assumes 58.34 Word order = LO-HI (the default: low word first). If 58.34 is set to HI-LO, read them as ABCD.
  • References and actual values are signed 16-bit with 20000 = the 46.01/46.02 scaling value, not engineering units.
  • Only the lower 16 bits of the drive's 32-bit control/status words are visible at 400001/400004.
  • Start (manual's sequence): write 0x0476 (1142) to 400001; once status bit 0 (RDY_ON) is 1, write 0x0477 (1143, ready/stopped) and then 0x047F (1151) to run. Stop: 0x0477 (1143) stops per 21.03 Stop mode; 0x047E (1150) forces an OFF1 ramp stop. Fault reset: rising edge of control-word bit 7.

Network setup

  • Wire the RS-485 link per the drive's hardware manual; the control unit has switches for bus termination and bias resistors.
  • Defaults: node 1, 19.2 kbit/s, 8 data bits, even parity, 1 stop bit (58.03-58.05); baud can also be set to Autodetect.
  • Changes to group 58 take effect only after 58.06 = Refresh settings or a control-unit reboot.
  • 58.07 Communication diagnostics flags wiring (A/B swap), parity, baud and addressing errors; 58.08-58.12 count packets and errors.

Watch out for

  • If a start command is ignored, read 06.18 Start inhibit status word on the panel (for example a missing run enable or STO).
  • If 96.78 Legacy Modbus mapping is enabled the drive looks like an ACS550 and this map no longer applies.
  • Exception 04h means the request was rejected by the drive; read 400092 Error code for the reason (e.g. limit exceeded).

Notes on this map

  • Registers 400001-400006 are the factory defaults of Data I/O 1-6 (58.101-58.106) and can be re-pointed; 400007-400014 are user-selectable via 58.107-58.114 and are not listed.
  • Control and status word bits are shown for the ABB Drives profile (58.25 = 0, default). With the DCU profile (58.25 = 5) the words are passed through unconverted with a different bit layout (bit 0 STOP, bit 1 START, bit 2 REVERSE, bit 4 RESET...).
  • Reference/actual registers are signed 16-bit; 20000 corresponds to the value of 46.01 Speed scaling or 46.02 Frequency scaling (46.03 torque, 46.04 power), so their engineering value depends on drive settings and is left unscaled here.
  • 32-bit registers use 58.34 Word order; the default LO-HI sends the low word first (CDAB). If 58.34 is set to HI-LO the order becomes ABCD. Within each register the high byte is sent first.
  • 16-bit parameter scaling is the manual's FbEq16 column (e.g. '10 = 1 V' -> scale 0.1); 32-bit scaling is the FbEq32 column in the Additional parameter data chapter. Parameters whose 16-bit scaling is 'See par. 46.xx' (01.01 speed, 01.06 frequency, 01.07 current, 01.10 torque, 01.14 power, 01.72-01.74 phase currents) are listed only in their 32-bit form.
  • Left out: 06.xx control/status/inhibit words (bit lists not re-checked for this drive), 01.50-01.53 hour/day kWh logs, group 46 scaling parameters and configuration parameters other than the comm-loss settings.
  • Coils (CW bits) and discrete inputs (SW bits, DI status) also exist but are omitted: the manual's wording on how their references map to wire addresses is ambiguous.
  • If 96.78 Legacy Modbus mapping (ACS550/ACx550 compatibility) is enabled, the register layout changes and this map no longer applies.
  • 58.16 Communication loss time is left out: the ACS480 manual gives its 16-bit scaling as '1 = 1' over a 0.0-6000.0 s range without saying whether the integer is whole or tenth seconds.
  • The EFB setup table shows 58.14 = Fault, 58.15 = Cw / Ref1 / Ref2 and 58.16 = 3.0 s as defaults, while the parameter list shows 58.14 = No action, 58.15 = Any message and 58.16 = 30.0 s. Read them back from the drive.
  • The register table on p. 571 says 400003 and 400004 are re-pointed with 58.102; by the parameter list they belong to 58.103 and 58.104.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the ABB ACS480 general purpose drive (embedded Modbus RTU)

What Modbus registers does the ABB ACS480 general purpose drive (embedded Modbus RTU) have?

This map lists 52 registers: 52 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB ACS480 general purpose drive (embedded Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints holding registers as 6-digit references and maps 400001-465536 onto the 65536-register address field, so 400001 = wire address 0 (its setup table also pairs the parameter range with addresses 100-65535). Masters limited to 5 digits can use 40001-49999 for 400001-409999; 32-bit parameter registers (420000+) need 6-digit or raw addressing. With 58.33 Addressing mode = Mode 0 (default) a 16-bit parameter gg.ii sits at 400000 + 100*gg + ii (e.g. 01.11 -> 400111, wire 110) and a 32-bit copy at 420000 + 200*gg + 2*ii (e.g. 01.07 -> 420214, wire 20213). Mode 1 uses 400000 + 256*gg + ii and Mode 2 uses 400000 + 512*gg + 2*ii; this map assumes Mode 0. All 32-bit registers are listed CDAB, which assumes 58.34 Word order = LO-HI, the default.

What byte order does the ABB ACS480 general purpose drive (embedded Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ABB ACS480 general purpose drive (embedded Modbus RTU)?

Start with HR 0 Control word (EFB CW) (Control word: start/stop/reset); HR 1 Reference 1 (EFB Ref1) (Reference 1 (speed/frequency setpoint, 20000 = 46.01/46.02)); HR 3 Status word (EFB SW) (Status word: ready/running/fault/remote); HR 4 Actual value 1 (EFB Act1) (Actual value 1 (speed/frequency feedback)); HR 110 01.11 DC voltage (01.11 DC voltage); HR 400 04.01 Tripping fault (04.01 Tripping fault code); HR 20211 01.06 Output frequency (32-bit) (01.06 Output frequency, 0.01 Hz (32-bit)); HR 20213 01.07 Motor current (32-bit) (01.07 Motor current, 0.01 A (32-bit)).
