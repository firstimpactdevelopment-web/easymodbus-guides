Short answer

The PCB1 is a ramp/soak program controller with 10 patterns of 10 steps, 10 PID blocks and three event outputs. On RS-485 it speaks Shinko protocol or Modbus ASCII/RTU; every item is a signed 16-bit holding register. The map covers all pattern, event, wait and PID-block items, engineering settings, run/hold/advance commands and the read-only monitor block.

Integration notes: Shinko Technos PCB1 programmable controller (C5W/C5 option)

Integration in brief

Select MODBUS RTU mode in Engineering setting mode 1 and give the unit a non-zero instrument number; then poll PV 9000H, current step SV 9003H, pattern/step 9005H and status 900AH-900BH, and start/stop with 8001H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Requires the C5W or C5 option. In Engineering setting mode 1 (down + MODE for about 3 s) set Communication protocol to MODBUS RTU (or ASCII), then instrument number, speed, data bit/parity and stop bit. These can only be set on the keypad.

Byte order & addressing

  • The manual's Modicon example writes 2100H as 42101, treating the hex digits as decimal; its example frames send 2100H itself as the PDU address (CRCs check), so use the hex data item directly.
  • Instrument number 0 is the Modbus broadcast address; give each unit 1-95.
  • The USB console cable and RS-485 cannot be used at the same time.

Network setup

  • Factory defaults: Shinko protocol, instrument number 0, 9600 bps, 7 bits/even parity, 1 stop bit, 10 ms response delay.
  • For Modbus RTU choose an 8-bit data format (8 bits/no, even or odd parity).
  • Do not fit a terminator; the unit has built-in pull-up/pull-down resistors.

Watch out for

  • HOLD and ADVANCE return exception 17 (11H) while the program is stopped.
  • Exception 18 (12H) is returned while the keypad is in setting mode.
  • Non-volatile memory takes about one million writes; avoid cyclic writes of settings.

Notes on this map

  • Addresses with a pattern or block number follow the manual's digit scheme: 2p00H (pattern p = 1-A), 3p00H, 5p00H, and 4k12H-4k16H for PID block k = 1-A. Step n of a pattern uses 2p00H + (n-1) x 3.
  • The manual's PCD-33A compatible command set (section 7.2, 0001H-00A3H) is not repeated here; see the pcd-33a map for that layout.
  • All data are 16-bit two's complement; values with a decimal point are sent as whole numbers.
  • Units of PID times and limits are not printed in the command table.
  • Changing an EV allocation clears that event's alarm value-0, hysteresis, delay and energized settings.

Questions about the Shinko Technos PCB1 programmable controller (C5W/C5 option)

What Modbus registers does the Shinko Technos PCB1 programmable controller (C5W/C5 option) have?

This map lists 678 registers: 678 holding registers. 664 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos PCB1 programmable controller (C5W/C5 option) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Data items are hex (9000H) and are sent unchanged as the Modbus holding-register address. The manual says the Modicon number is the data item plus 40001. The RTU examples read PV at 9000H and write pattern 1 step 1 SV at 2100H (CRCs A90AH and 83E1H checked).

What are the minimum Modbus registers to integrate the Shinko Technos PCB1 programmable controller (C5W/C5 option)?

Start with HR 36864 PV (Process value); HR 36867 Current step SV (Current step SV); HR 36869 Current pattern and step (Running pattern and step); HR 36875 Current unit status (Run/hold/wait status); HR 36874 Status flag (Output, alarm and over/underscale flags); HR 32769 Program control RUN/STOP (Program RUN/STOP); HR 32768 Pattern number for operation (Pattern to run); HR 28675 Decimal point place (Decimal point for scaling).

How do I enable Modbus control of the Shinko Technos PCB1 programmable controller (C5W/C5 option)?

Requires the C5W or C5 option. In Engineering setting mode 1 (down + MODE for about 3 s) set Communication protocol to MODBUS RTU (or ASCII), then instrument number, speed, data bit/parity and stop bit. These can only be set on the keypad.

Where is the official Shinko Technos PCB1 programmable controller (C5W/C5 option) Modbus documentation?

The source is Communication Instruction Manual PCB1 (C5W, C5) (No. PCB1CE3), revision 2019-09, published free by Shinko Technos at https://shinko-technos.co.jp/e/manual/english/PCB1CE3.pdf.
