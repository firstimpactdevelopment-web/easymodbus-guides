Short answer

The TCW210-TH is a Teracom Ethernet data logger for up to eight temperature or temperature/humidity sensors on 1-Wire or Modbus RTU. Over Modbus TCP it serves each sensor's values, raw values, limits, trim settings and alarm flags as holding registers.

This page lists 239 Modbus registers for the Teracom TCW210-TH temperature and humidity data logger — 132 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Teracom’s own free documentation (linked below) and checked against it.

Integration notes: Teracom TCW210-TH temperature and humidity data logger

Integration in brief

Enable Modbus TCP, then read sensor values as floats from holding registers 19800 onward (two registers per value) with function 03.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

RegisterNameTypeWhyAccess
HR 19800Sensor 1, S11 valueFLOAT32 ABCDSensor 1 first valueRead
HR 19802Sensor 1, S12 valueFLOAT32 ABCDSensor 1 second valueRead
HR 20000Sensor 1, S11 alarm statusUINT16Sensor 1 first value alarmRead
HR 50002Temperature unitUINT16Temperature unitRead/write
HR 50003HW errorUINT16Hardware errorRead/write

Enable Modbus control & writes

Modbus TCP/IP is disabled by default. Enable it on the services page of the web interface (standard port 502).

Byte order & addressing

  • Floats are high word first (ABCD).
  • PDU 50000 reports whether settings are saved (0 = unsaved, 1 = saved).

Network setup

  • The factory IP is 192.168.1.2; change it in the network settings, then enable Modbus TCP/IP.

Notes on this map

  • Word order: the manual says float registers are sent big-endian and its example response 41BD 0655 decodes to 23.628, i.e. high word first (ABCD).
  • Strings are fixed-length UTF-8, zero padded; 64-byte fields span 32 registers.
  • Each of the 8 sensors has three value slots (Sx1..Sx3), each with dimension, limits, multiplier, offset, value, raw value and alarm status.
  • Left out: 'Number of installed sensors' (PDU 18000), listed only as '16-bit Integer' without saying signed or unsigned.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Teracom TCW210-TH temperature and humidity data logger

What Modbus registers does the Teracom TCW210-TH temperature and humidity data logger have?

This map lists 239 registers: 239 holding registers. 132 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Teracom TCW210-TH temperature and humidity data logger Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The address table prints PDU (wire) addresses in decimal. The manual's example frame reads register 19800 as 0x4D58 on the wire, so no offset is applied.

What byte order does the Teracom TCW210-TH temperature and humidity data logger use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Teracom TCW210-TH temperature and humidity data logger?

Start with HR 19800 Sensor 1, S11 value (Sensor 1 first value); HR 19802 Sensor 1, S12 value (Sensor 1 second value); HR 20000 Sensor 1, S11 alarm status (Sensor 1 first value alarm); HR 50002 Temperature unit (Temperature unit); HR 50003 HW error (Hardware error).

How do I enable Modbus control of the Teracom TCW210-TH temperature and humidity data logger?

Modbus TCP/IP is disabled by default. Enable it on the services page of the web interface (standard port 502).

Where is the official Teracom TCW210-TH temperature and humidity data logger Modbus documentation?

The source is TCW210-TH User manual (Revision R1.26), revision 2026-10, published free by Teracom at https://www.teracomsystems.com/download/temperature-humidity-data-logger-tcw210-th-user-manual/.
