Short answer

The PCD-33A is a 9-pattern, 9-step ramp/soak temperature controller. With the C5 option it speaks Shinko protocol or Modbus ASCII/RTU on RS-485, one 16-bit holding register per request. The map covers every pattern/step SV, time and wait flag, per-pattern wait, alarm and time-signal values, PID and alarm settings, run/stop and advance commands, PV, MV, current SV, running pattern/step and status.

Integration notes: Shinko Technos PCD-33A programmable controller (C5 option)

Integration in brief

Select Modbus RTU (or ASCII) in Auxiliary function setting mode 1, set instrument number and speed, then read PV 0080H, current SV 0083H, running pattern/step 0085H and status 0086H; start and stop the program with 0042H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Requires the C5 option. Choose the Modbus protocol, instrument number and speed in Auxiliary function setting mode 1 on the keypad.

Byte order & addressing

  • Modbus is not available through Shinko's IF-300-C5 converter; use a generic RS-232C/RS-485 converter.
  • Slave address range 0-95; address 0 is broadcast (no reply).

Network setup

  • Speeds 2400, 4800, 9600 (default) or 19200 bps; data 7 or 8 bits, parity even/odd/none, 1 or 2 stop bits.
  • Do not add a terminator: the unit has built-in pull-up/pull-down resistors.

Watch out for

  • Changing an alarm action type resets that alarm's values; send the type first.
  • Exception 17 (11H) means the item cannot be set in the present state; 18 (12H) means the keypad is in setting mode.

Notes on this map

  • Pattern/step addresses follow the manual's 1xx0H scheme: 1000H + pattern x 100H + step x 10H + item (SV 0, time 1, wait 2); per-pattern items are 1p13H-1p17H. The RTU example reads pattern 1 step 1 SV at 1110H.
  • Scaling high/low limit (002CH, 002DH) and decimal point place (002EH) are listed without a Shinko or Modbus command code in the table, so they are left out; set the decimal point on the keypad.
  • Function 03 reads one register and 06 writes one; the number of data is fixed at 1.
  • Values with a decimal point are sent as whole numbers. Units of PID times, step times and MV are not printed in the table.
  • A value changed over the bus does not drag related values with it (e.g. lowering SV high limit leaves step SVs as they were).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Shinko Technos PCD-33A programmable controller (C5 option)

What Modbus registers does the Shinko Technos PCD-33A programmable controller (C5 option) have?

This map lists 329 registers: 329 holding registers. 321 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos PCD-33A programmable controller (C5 option) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Data items are printed as hex (0080H, 1110H) and go into the request unchanged, as the manual's RTU example frames show (PV read at 0080H). The RTU example reads pattern 1 step 1 SV at 1110H (CRC 80F3H checked).

What are the minimum Modbus registers to integrate the Shinko Technos PCD-33A programmable controller (C5 option)?

Start with HR 128 PV (Process value); HR 131 Current SV (Current program SV); HR 133 Running pattern and step (Running pattern and step); HR 134 Instrument status (Run, alarm and error status); HR 66 Program run Perform/Stop (Run/stop the program); HR 63 Running pattern number (Select pattern to run); HR 4368 P1 step 1 SV (Pattern 1 step 1 SV).

How do I enable Modbus control of the Shinko Technos PCD-33A programmable controller (C5 option)?

Requires the C5 option. Choose the Modbus protocol, instrument number and speed in Auxiliary function setting mode 1 on the keypad.

Where is the official Shinko Technos PCD-33A programmable controller (C5 option) Modbus documentation?

The source is Communication Instruction Manual PCD-33A (C5, SVTC) (No.PCD3CE1), revision 2003-02, published free by Shinko Technos at https://shinko-technos.co.jp/e/manual/english/PCD3CE2.pdf.
