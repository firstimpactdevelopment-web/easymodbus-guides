Novelan Novelan heat pump controller via Novelan GLT (Modbus TCP) Modbus register map

Updated 19 November 2026

Short answer

With the GLT licence active, the Novelan heating and heat pump controller is a Modbus TCP slave on port 502 at the controller's own IP address. Discrete inputs show utility block, smart-grid and compressor/heater states; input registers give temperatures, pressures, running hours, plant status, faults, output and 32-bit heat and energy counters; coils reset faults and force pumps on; holding registers take outdoor temperature, setpoints, operating modes, smart-grid state and heating-curve settings.

This page lists 95 Modbus registers for the Novelan Novelan heat pump controller via Novelan GLT (Modbus TCP) — 37 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Novelan’s own free documentation (linked below) and checked against it.

Integration notes: Novelan Novelan heat pump controller via Novelan GLT (Modbus TCP)

Integration in brief

License GLT with the supplied USB dongle, then poll input registers 0-59 and discrete inputs 0-7 over Modbus TCP and write holding registers 0-23 for outdoor temperature, setpoints and modes.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Configure GLT with the Novelan GLT Tool, then insert the supplied USB dongle in the controller's USB port to unlock GLT permanently (otherwise only a test phase runs). Check Service > Informationen > GLT on the controller.

Byte order & addressing

  • To stop forcing a value, write a value outside its limits (holding registers) or 0 (coils); otherwise the written value stays in force.
  • Only the currently active fault is shown in input register 46.

Network setup

  • Modbus TCP uses the controller's IP address and port 502; set the IP under Service > Systemsteuerung (DHCP server, DHCP client or fixed IP).

Watch out for

  • Controllers with software older than the Modbus TCP versions listed can only use BACnet/IP.

Notes on this map

  • ait-deutschland / Novelan do not appear to host this manual publicly; the link is an unaltered copy of the manufacturer's PDF posted on the ioBroker forum.
  • The manual calls all registers integer values without stating signedness. Temperatures and the holding offset 23 are listed as INT16 because the holding outdoor temperature accepts -200 (= -20.0 °C) and the offset -50; the input-register temperatures have no printed range, so negative readings assume two's complement.
  • 'Auflösung 10' means tenths (scale 0.1) and 'Auflösung 100' hundredths (scale 0.01). Heat and energy counters are printed in 'kW/h' and are taken as kWh.
  • Each 32-bit counter is split into High and Low registers; the manual says to shift High 16 bits left and add Low, with High at the lower ID, so they are listed as UINT32 high word first.
  • Data points marked * in the manual exist only on units with LIN and/or Modbus components; greyed points need a comfort/extension or ventilation board. Values for points not visible on the controller display are invalid.
  • Discrete inputs exist only for IDs 0-7. Coil 1 is reserved and left out.
  • Coils read 0 = off and 1 = on. Writing 1 forces the output on; writing 0 hands it back to automatic control.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Novelan Novelan heat pump controller via Novelan GLT (Modbus TCP)

What Modbus registers does the Novelan Novelan heat pump controller via Novelan GLT (Modbus TCP) have?

This map lists 95 registers: 13 coils, 8 discrete inputs, 50 input registers, 24 holding registers. 37 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Novelan Novelan heat pump controller via Novelan GLT (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual warns that registers are 0-based: the printed ID is the wire address (input register 0 = mean outdoor temperature, holding register 0 = outdoor temperature).

What byte order does the Novelan Novelan heat pump controller via Novelan GLT (Modbus TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Novelan Novelan heat pump controller via Novelan GLT (Modbus TCP)?

Start with IR 37 Anlagenstatus (Plant status); IR 0 Mitteltemperatur (Mean outdoor temperature); IR 1 Vorlauftemperatur (Flow temperature); IR 2 Rücklauftemperatur (Return temperature); IR 4 Trinkwarmwassertemperatur (Hot water temperature); IR 46 Fehlerspeicher (Active fault); HR 1 Rücklauf-Temperatur Soll (Return temperature setpoint); HR 7 Betriebsart Heizung (Heating mode); HR 14 Smart Grid (Smart grid state); CO 0 Fehlerreset (Fault reset).

How do I enable Modbus control of the Novelan Novelan heat pump controller via Novelan GLT (Modbus TCP)?

Configure GLT with the Novelan GLT Tool, then insert the supplied USB dongle in the controller's USB port to unlock GLT permanently (otherwise only a test phase runs). Check Service > Informationen > GLT on the controller.
