Short answer

Danfoss's HVAC variable frequency drive with a built-in RS-485 port that can run Modbus RTU. Control word, bus reference, status word and main actual value sit at fixed holding registers 50000-50210, and every drive parameter is a holding register at ten times its parameter number. This map covers the control block, the communication and comm-loss parameters, and the main 15-xx/16-xx readouts whose conversion index is published.

Integration notes: Danfoss VLT HVAC Drive FC 102 (Modbus RTU)

Integration in brief

Set 8-30 to Modbus RTU and power-cycle, make sure 8-02 points at the FC port and the drive is not in local/Hand control, then write the control word to 50000 and the reference to 50010 and poll 50200/50210. Read readouts from the 16-xx registers at parameter number x 10 (minus 1 on the wire).

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set 8-30 Protocol = [2] Modbus RTU (effective only after powering the drive off and on), 8-31 Address, 8-32 FC Port Baud Rate and 8-33 Parity/Stop Bits. Control word source 8-02 must be [1] FC port; 8-01 Control Site chooses digital and/or control word; 8-50..8-56 decide how bus bits combine with digital inputs (8-50, 8-55 and 8-56 default to Logic OR). STW bit 9 must read 1 (not in local operation) for bus control, and CTW bit 10 (data valid) must be 1.

Communication loss & watchdog

8-03 Control Word Timeout Time (0.5-18000 s, 0.1 s units) and 8-04 Control Word Timeout Function (default Off; options include Freeze output, Stop, Jogging, Max. speed, Stop and trip, set-up switching, Warning only). A valid control word restarts the timer. 8-05 decides what happens after communication returns from a set-up-switching timeout, and 8-06 resets that timeout when 8-05 = Hold set-up.

Byte order & addressing

  • Parameter register = parameter number x 10, request address = that minus 1 (16-13 -> 16130 -> address 16129).
  • 32-bit values are high word first (ABCD).
  • REF/MAV use 4000h = 100% of the 3-02..3-03 reference range, negative values in two's complement.
  • CTW bit 10 must be 1 or the whole control word is ignored. Derived from the bit table (these words are not printed in the manual): bits 2, 3, 4, 5, 6 and 10 set = 047Ch runs on the ramp; clearing bit 6 (043Ch) ramps to stop; bit 7 resets on its rising edge.
  • Uint8 parameters still occupy a full 16-bit register.

Network setup

  • RS-485 on the control terminals of the built-in FC port; set address 1-247 for Modbus RTU in 8-31.
  • Parity default is even with 1 stop bit (8-33); baud is chosen in 8-32 (2400-115200).
  • 8-35 Minimum Response Delay can be raised for slow masters or converters.
  • Array parameters need the index written to holding register 9 before the read or write.

Watch out for

  • Parameter writes go to RAM only unless coil 65 is set to 1; RAM changes are lost at power-down.
  • If 8-02 was changed to an option slot (e.g. after a fieldbus option was fitted), Modbus control words on the FC port are ignored.
  • Pressing [Stop/Reset] on the keypad or selecting local in 3-13 Reference Site blocks bus control (STW bit 9 = 0).

Notes on this map

  • Scaling comes from each parameter's conversion index in the programming guide: -1 = x0.1, -2 = x0.01, -3 = x0.001, 0 = x1, 1 = x10. The 4.x guide's conversion table gives indices 67, 74, 75 and 100 the factors 1/60, 3600, 3600000 and 1 relative to SI units, so the transferred integer is already in RPM, hours, kWh and degC respectively (scale 1).
  • 3-02/3-03 conversion index -3 is printed in the 7.61 guide and agrees with the design guide example (0016E360h = 1500000 = 1500.000 RPM). Programming data source: VLT HVAC Drive FC 102 Programming Guide, software 7.61, AU430028034214en-001901 (2024.10), https://assets.danfoss.com/documents/435027/AU430028034214en-001901.pdf.
  • 32-bit parameters occupy two registers, high word first: the manual's example reads 3-03 at registers 3030/3031 and returns 0016E360h = 1500000 = 1500.000 RPM.
  • 8-bit parameters (Uint8) are read and written as one 16-bit register.
  • REF and MAV are signed 16-bit values where 16384 (4000h) = 100%; with 3-00 = min-max the range runs from 3-02 (0%) to 3-03 (100%), with -max..+max it runs from -3-03 to +3-03.
  • Left out: 16-26 Power Filtered [kW] (conversion index 0 on a kW parameter; the 7.61 guide gives W as the base unit for 16-10, so 16-26's raw unit could be W or kW and is not stated), 16-23 Motor Shaft Power (index 1 with no stated base unit); 16-05 Main Actual Value [%] and 16-15 Frequency [%] (normalised N2 type); 15-30..15-33 alarm log arrays (need the IND pointer in register 9); text parameters. 16-10 Power [kW] is included because the 7.61 guide states its fieldbus value is in 10 W steps (index 1, base unit W).
  • Alarm/warning/extended status words (16-90..16-95) are listed as raw UINT32; their bit meanings are in the programming guide's troubleshooting tables.
  • Coils 1-16 / 17-32 / 33-48 / 49-64 mirror CTW, REF, STW and MAV bit by bit; only coil 65 (parameter write control) is listed separately.
  • The design guide's 3-14 example prints registers 3410/3411; by the x10 rule 3-14 is 3140/3141, so treat that example as a typo.
  • FC 202 / FC 302 use the same scheme but have their own programming guides; this file only claims FC 102.

Questions about the Danfoss VLT HVAC Drive FC 102 (Modbus RTU)

What Modbus registers does the Danfoss VLT HVAC Drive FC 102 (Modbus RTU) have?

This map lists 51 registers: 1 coil, 50 holding registers. 18 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Danfoss VLT HVAC Drive FC 102 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers derived from parameter numbers. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed 1-based. A parameter's register number is 10 x its parameter number (3-03 -> 3030, 16-13 -> 16130) and the request carries that number minus 1 (3-03 is read at address 3029 = 0x0BD5, per the manual's own example). The fixed process registers CTW 50000, REF 50010, STW 50200 and MAV 50210 follow the same minus-1 rule (CTW = address 49999). Coils are also numbered from 1 (coil 65 = address 64).

What byte order does the Danfoss VLT HVAC Drive FC 102 (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Danfoss VLT HVAC Drive FC 102 (Modbus RTU)?

Start with HR 49999 Control word (CTW) (CTW: start/stop/reset); HR 50009 Bus reference (REF) (REF: speed reference, 4000h = 100%); HR 50199 Status word (STW) (STW: ready/running/trip/warning); HR 16129 16-13 Frequency (16-13 Frequency, 0.1 Hz); HR 16139 16-14 Motor current (16-14 Motor current, 0.01 A); HR 16099 16-10 Power [kW] (16-10 Power, 10 W steps (0.01 kW)); HR 16899 16-90 Alarm Word (16-90 Alarm word); HR 15019 15-02 kWh Counter (15-02 kWh counter).
