Datakom D-300 / D-500 / D-700 genset controllers Modbus register map

Updated 28 October 2026

Short answer

Datakom's D-series units control a single genset (D-300, D-500) or a synchronising genset (D-700) and expose Modbus RTU on RS-485/RS-232 and Modbus TCP on Ethernet or GPRS. Everything sits in holding registers read with function 3. This map covers the 16-bit live values (frequencies, battery and charge voltages, oil pressure, fuel level, rpm), the operating status and mode, the shutdown and warning alarm bits, the function flags and the pushbutton-simulation register used for remote start/stop; all 32-bit values are left out (see notes).

This page lists 29 Modbus registers for the Datakom D-300 / D-500 / D-700 genset controllers — 1 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Datakom’s own free documentation (linked below) and checked against it.

Integration notes: Datakom D-300 / D-500 / D-700 genset controllers

Integration in brief

Read 10604 (operation status), 10605 (mode) and the summary flags at 11558 with function 3, then 10338-10341 for frequencies and battery voltage. Remote control is done by writing a single bit to 8193 to simulate a panel key (Stop, Run/Manual, Auto, Test).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set a Modbus slave address (1-240). For RS-485 set 'RS-485 Enable' to 1 and pick a baud rate; for Ethernet set 'Ethernet Enable' to 1, the Modbus TCP port (usually 502) and the IP, gateway and subnet; the first User IP Mask should be 255.255.255.0.

Byte order & addressing

  • Only functions 3, 6 and 16 are supported; status bits are read from holding registers.
  • A read returns at most 16 registers; asking for more silently returns only the first 16.
  • Writing a read-only register returns exception code 10 (write protection).
  • Addresses are decimal and used as-is; do not add 40001 or subtract 1.

Network setup

  • Serial: 8 data bits, no parity, 1 stop bit, RTU mode, baud 2400-115200 selectable.
  • Every unit on one RS-485 line needs its own slave address; over TCP keep the default address 1 unless the gateway needs otherwise.
  • For GPRS the manual says to use Modbus TCP port 80.

Watch out for

  • These controllers start a real engine and operate the mains and genset breakers. Make sure the set and switchgear are safe before simulating Run, Test, GCB or MCB key presses.
  • The pushbutton register mimics a key press; check 10605 afterwards and press Auto again if the set must stay ready for a mains failure.

Notes on this map

  • Left out: every 32-bit value (all phase voltages, currents and powers at 10240-10327, average voltage and current at 10377-10384, the run/crank/hour/energy counters at 10616-10647 and 11569-11581, GPS position and the multi-genset totals). The manual contradicts itself on word order: one paragraph says the least significant register comes first, the next says the high-order 16 bits are in the first register. Until Datakom settles it, those registers are not listed.
  • Left out: the power factor registers (10328-10335 and 11376). The table prints a x10 coefficient for them, which would give power factor in steps of 0.1 and looks doubtful; they are omitted rather than published with a possibly wrong scale.
  • COEFF. in the manual is how many times larger the raw value is than the real one: x10 means divide by 10 (scale 0.1), x100 means divide by 100 (scale 0.01).
  • Left out: the engine, oil, canopy and ambient temperature registers (10362, 10364-10366 and the _2 copies at 10368 and 10370-10372). The manual gives them only as '16bit' in tenths of a degree C and never says whether they are signed, so readings below zero cannot be decoded with certainty.
  • Alarm and flag arrays are packed with alarm/flag 0 in bit 0 of the first register. The shutdown array is 10504-10519, loaddump 10520-10535 and warning 10536-10551; only the words holding the named engine and genset alarms are listed (words 1-3 are digital-input and expansion-input alarms, words 5-6 ambient-temperature and sender alarms). The loaddump array uses the same bit layout as the other two.
  • The function-flag array is 224 bits at 11555-11568. Page 15 of the manual repeats a corrupted copy of the counter table that wrongly reuses address 11555; the first table on the page (flags at 11555, counters from 11569) is the consistent one.
  • 8193 lists a x10 coefficient but is a bit field; the coefficient is ignored. Writing 14536 to 8210 forces a hard reset of the unit and is deliberately not listed.
  • Also not listed: the harmonic-analysis and scope-meter block (8194, 10386-10503), analog input ohm values, the LCD buffer and LED, output and expansion status bits.

Questions about the Datakom D-300 / D-500 / D-700 genset controllers

What Modbus registers does the Datakom D-300 / D-500 / D-700 genset controllers have?

This map lists 29 registers: 29 holding registers. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Datakom D-300 / D-500 / D-700 genset controllers Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register tables print decimal addresses and they go on the wire unchanged. The manual's read example asks for 16 registers 'starting from address 20h (32 decimal)' with the frame 01 03 00 20 00 10, and its write example puts register 40h in the frame as 00 40. So 10338 (mains frequency) is requested as 10338, with no 40001 offset and no minus 1.

What are the minimum Modbus registers to integrate the Datakom D-300 / D-500 / D-700 genset controllers?

Start with HR 10604 Unit operation status (Genset sequence state); HR 10605 Unit mode (STOP / RUN / AUTO / TEST mode); HR 11558 Function flags 48-63 (Shutdown, loaddump and warning summary flags); HR 11557 Function flags 32-47 (Mains fail and engine running flags); HR 10339 Genset frequency (Genset frequency); HR 10341 Battery voltage (Battery voltage); HR 10376 Engine rpm (Engine speed); HR 8193 Pushbutton simulation (Remote key presses).

How do I enable Modbus control of the Datakom D-300 / D-500 / D-700 genset controllers?

Set a Modbus slave address (1-240). For RS-485 set 'RS-485 Enable' to 1 and pick a baud rate; for Ethernet set 'Ethernet Enable' to 1, the Modbus TCP port (usually 502) and the IP, gateway and subnet; the first User IP Mask should be 255.255.255.0.
