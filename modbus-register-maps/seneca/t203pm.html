Short answer

The T203PM is a DIN-rail transducer that measures true-RMS AC or DC voltage and current on one phase and works out power, energy, power factor, frequency and THD. It answers Modbus RTU on RS-485 (and on USB for setup). This map covers the float measurement block, min/max values, scaled integer copies, the 64-bit energy counters, the command register and the analog/digital output setup.

Integration notes: Seneca T203PM single-phase AC/DC power meter (Modbus RTU)

Integration in brief

Read holding registers 104-125 (function 03) in one block for volts, amps, powers, energies, frequency, PF and THD as ABCD floats. Use the 64-bit counters at 181/185/189 when you need exact energy totals.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU slave is always on. Slave ID is register 2 and serial format register 81; the maker recommends its Easy Setup 2 software for configuration.

Byte order & addressing

  • 0-based offset is the wire address; tables also print 4x numbers.
  • Add 1000 to an address for the word-swapped copy of a 32-bit value.
  • Energy counters count in tenths of Wh.

Network setup

  • Set the slave ID (offset 2) and the stop bit / parity / baud word (offset 81). The command register (offset 4) accepts 49600 (write to flash) and 49568 (reboot); the manual does not say whether a reboot is needed for new serial settings.
  • Set AC or DC measuring with offset 82.

Watch out for

  • While a USB cable is plugged in, the RS-485 port stops answering; unplug USB to restore it.
  • To preset energy counters, first write 49616 to the command register, write the counters, then write 49617.

Notes on this map

  • Only function codes 03, 06 and 16 are supported; every value, including measurements, is a holding register.
  • 32-bit values are MSW in the lower register (ABCD) and 64-bit counters are MMSW first (ABCD). The manual says adding 1000 to an address gives the same 32-bit value word-swapped (e.g. current at 41107); that mirror block is not listed here.
  • Integer copies are scaled as printed: V/10, A/10, W/10, Hz/10, PF/1000, THD/10; energy counters are Wh/10 (varh/10, VAh/10).
  • The table marks the command register (40005) RO, but the manual's procedures write commands to it, so it is listed as RW.
  • Registers marked RW* are stored in flash and survive about 10,000 writes.
  • Left out: reserved registers and the integer min/max copies (40197-40218); the float min/max block covers the same values.
  • The manual does not state factory defaults for address, baud rate or parity.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Seneca T203PM single-phase AC/DC power meter (Modbus RTU)

What Modbus registers does the Seneca T203PM single-phase AC/DC power meter (Modbus RTU) have?

This map lists 61 registers: 61 holding registers. 23 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seneca T203PM single-phase AC/DC power meter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table prints both the 4x number (40002) and the 0-based offset (1). The offset is the wire address: 40002 is sent as 1.

What byte order does the Seneca T203PM single-phase AC/DC power meter (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Seneca T203PM single-phase AC/DC power meter (Modbus RTU)?

Start with HR 104 RMS voltage (RMS voltage); HR 106 RMS current (RMS current); HR 108 Active power (Active power); HR 114 Active energy (Active energy); HR 120 Frequency (Frequency); HR 122 Power factor (Power factor); HR 181 Active energy counter (Active energy counter, Wh/10).

How do I enable Modbus control of the Seneca T203PM single-phase AC/DC power meter (Modbus RTU)?

Modbus RTU slave is always on. Slave ID is register 2 and serial format register 81; the maker recommends its Easy Setup 2 software for configuration.
