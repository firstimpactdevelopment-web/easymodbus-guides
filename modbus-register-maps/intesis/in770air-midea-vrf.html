Integration notes: Intesis (HMS Networks) IN770AIR***O000 700 Series Air Gateway, Midea application (Modbus)

Integration in brief

Pick the Midea application and the Modbus interface in Intesis MAPS, discover or add the units, send the project, then read and write each unit's block.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The units must be set up in Intesis MAPS; the unit index used in the formulas is the one shown on the Signals tab.

Byte order & addressing

  • Writes accept FC06 (single register) only.
  • All-unit (T) registers are trigger-only commands.

Network setup

  • All Modbus settings (RTU or TCP, slave address, baud, parity) are made with the Intesis MAPS tool; the manual gives no factory serial settings.
  • On first power-up DHCP is tried for 30 seconds, then the gateway falls back to 192.168.100.246.
  • Modbus RTU uses the EIA-485 port (A+, B-); bias and 120 ohm termination are on DIP switch block SW A.

Watch out for

  • The unit index n is the one shown in the Unit column of the MAPS Signals tab.

Notes on this map

  • For unit index n add (n-1) x 100 to the listed indoor addresses (unit 2 on/off = 200).
  • Mode codes in the per-unit block (0 Heat, 1 Cool, 2 Fan, 3 Dry, 4 Auto) differ from the order of the all-unit mode commands.
  • Outdoor unit registers are only available when the indoor unit is a Midea V8 system.
  • One manual covers the three licence sizes of the same hardware: IN770AIRXXSO000 (up to 4 indoor units), IN770AIR00SO000 (16) and IN770AIR00MO000 (64). The brand application is chosen in Intesis MAPS.
  • The manual states no data type for any register. INT16 is used only where it prints a negative range (room temperature); everything else is listed as UINT16.
  • The consumption registers (yesterday / today / total, also per heat and cool) are left out: each takes two addresses, but the manual gives no word order, and the unit is printed as Wh/kWh (selectable).
  • Reads use FC03 or FC04; writes use FC06 only. 'T' registers are trigger-only: write the printed value (1, or the setpoint / speed) to send the command.
  • Addressing: the manual has no addressing statement or example frame; 0-based is taken from the global On register printed at Modbus address 0 (no 1-based scheme has a register 0), with no overlap against the unit blocks.
  • Temperature ranges are printed in both °C and °F; the manual's Modbus section does not say how the unit is chosen. °C is listed here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Intesis (HMS Networks) IN770AIR***O000 700 Series Air Gateway, Midea application (Modbus)

What Modbus registers does the Intesis (HMS Networks) IN770AIR***O000 700 Series Air Gateway, Midea application (Modbus) have?

This map lists 38 registers: 38 holding registers. 33 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Intesis (HMS Networks) IN770AIR***O000 700 Series Air Gateway, Midea application (Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual states no address base and gives no example frame; the first all-unit register is printed at Modbus address 0 and nothing in the tables contradicts that, so printed addresses are taken as wire addresses. Unit index n (1..N, as shown in MAPS) uses n x 100 + offset; outdoor index n uses n x 10000 + offset. This file lists unit 1 (100..134) and outdoor unit 1 (10000..10001).
