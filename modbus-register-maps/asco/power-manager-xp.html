Short answer

The Power Manager Xp is ASCO's metering module for 7000 Series transfer switches. Over Modbus RTU it reports per-phase voltage, current, kW, kvar, kVA and power factor, frequency, demand, separate energy totals for the normal and emergency sources, digital I/O and switch position, all as holding registers.

This page lists 62 Modbus registers for the ASCO Power Manager Xp power meter for transfer switches (Modbus RTU) — 7 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ASCO’s own free documentation (linked below) and checked against it.

Integration notes: ASCO Power Manager Xp power meter for transfer switches (Modbus RTU)

Integration in brief

Read 40011-40026 for voltage and current, 40031-40046 for power and power factor, and the LO/HO energy pairs from 40051 (normal source) and 40071 (emergency source).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The 485 port (J1) protocol, baud rate and address are configuration registers 40208-40210 (writable with FC06).

Byte order & addressing

  • RTU only, 8 data bits, no parity, 1 stop bit; maximum 64 bytes per packet.
  • Energy pairs are low word first.

Network setup

  • Device address 1-247; 0 is broadcast.

Watch out for

  • Only the listed address ranges are supported; keep block reads inside them (e.g. skip undefined 40027-40030).

Notes on this map

  • Host: copy hosted by Contemporary Controls. Schneider Electric lists a newer revision (381339-221Q) on se.com behind a bot check; it was not opened.
  • Energy registers are 32-bit pairs printed as 'LO word' then 'HO word' with a signed range (-1,999,999,999 to +1,999,999,999), so they are INT32, low word first (CDAB).
  • Power factor is published as (value) x 100; frequency as Hz x 100.
  • Readable addresses (wire, decimal): 11-26, 31-48, 51-64, 71-84, 87-94, 96-125, 127-128, 130-137, 149-159.
  • Duplicate copies of total kW/kvar/kVA/PF/frequency at 40087-40101 and 40130-40132 and the configuration block 40200-40215 (system type, PT/CT ratios, port settings) are mostly not listed; their coding is described on pp. 6-8 of the document.
  • Switch position register 40096 is printed as '0:norm & 1:emer.' for main and auxiliary; the bit layout is not stated.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ASCO Power Manager Xp power meter for transfer switches (Modbus RTU)

What Modbus registers does the ASCO Power Manager Xp power meter for transfer switches (Modbus RTU) have?

This map lists 62 registers: 62 holding registers. 7 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ASCO Power Manager Xp power meter for transfer switches (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. ASCO says the address sent is the map address minus 40001. The read example asks for IA-IAVE at 40021 with start address 0x0014 (20).

What byte order does the ASCO Power Manager Xp power meter for transfer switches (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ASCO Power Manager Xp power meter for transfer switches (Modbus RTU)?

Start with HR 17 VL AVE - average L-L voltage (VL AVE average L-L voltage); HR 23 I AVE - average current (Average current); HR 33 kW T - total active power (Total kW); HR 41 Pf T - total power factor (Total power factor); HR 50 Normal kWh import (Normal kWh import); HR 92 Frequency (phase A) (Frequency).

How do I enable Modbus control of the ASCO Power Manager Xp power meter for transfer switches (Modbus RTU)?

The 485 port (J1) protocol, baud rate and address are configuration registers 40208-40210 (writable with FC06).

Where is the official ASCO Power Manager Xp power meter for transfer switches (Modbus RTU) Modbus documentation?
