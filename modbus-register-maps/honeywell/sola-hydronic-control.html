Short answer

SOLA is Honeywell's integrated burner and hydronic control used by many boiler OEMs. Its RS-485 Modbus RTU port exposes everything as 16-bit holding registers, with digital signals packed into bit-map registers. This map covers the status area: change flags, digital I/O, limits, demand source, temperatures, firing rate, flame signal, burner control status and lockout codes, sensor states, CH/DHW/lead-lag status and pump status.

Integration notes: Honeywell SOLA hydronic boiler control (Modbus interface)

Integration in brief

Connect to the SOLA's 3-pin RS-485 Modbus port (38400 8N1) and read holding registers with FC 03 from address 0. Temperatures are 0.1 °C integers; burner status is at 32, lockout code at 34.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Use one of the SOLA's RS-485 Modbus ports (MB1 or MB2); the control answers to a single Modbus address. Register writes are limited by the access level shown in register 19 (none, installer, OEM or all).

Byte order & addressing

  • Addresses are 0-based; add 40001 for 4xxxx tools.
  • Status-change registers 0, 1 and 23 clear when read.
  • Digital signals are bits inside holding registers, not coils.

Network setup

  • RS-485 terminals: 1 = Data+ (a), 2 = Data- (b), 3 = common.
  • Fixed format: 38400 bps, 8 data bits, no parity, 1 stop bit.

Watch out for

  • OEM boilers may disable or relabel some SOLA functions; confirm with the boiler maker's documentation.
  • 0x8FFF in a temperature register means that function is not enabled; 0x7FFF and 0x8000-0x8500 are sensor fault codes.

Notes on this map

  • Source host: Honeywell's specification as hosted by Contemporary Controls (a Honeywell integration partner); Honeywell does not host it publicly that we could find.
  • All temperatures are in 0.1 °C regardless of the display unit setting. The specification lists these registers as U16 even though the range is -40 to 130 °C; check how sub-zero values arrive on site. A temperature that does not apply (function not enabled) reads 0x8FFF; sensor faults replace the reading with the codes in table 4 of the source (0x7FFF, 0x8000-0x8500).
  • Firing-rate type registers carry either RPM or a 0.1 % value; the most significant bit tells which (0 = RPM, 1 = %), as set by the modulation output parameter (register 192).
  • Left out: the 32-bit statistics counters (128-147); the specification says 32-bit items use two consecutive registers but does not state the word order. Also left out: configuration registers above 173, alert/lockout history, lead-lag slave tables and the variable-length data items.
  • Pump status coding depends on application build (before/after 1600); see tables 13-14 in the source.
  • Up to 125 registers per read and 20 per write; variable-length items must be read on their own.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Honeywell SOLA hydronic boiler control (Modbus interface)

What Modbus registers does the Honeywell SOLA hydronic boiler control (Modbus interface) have?

This map lists 140 registers: 140 holding registers. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Honeywell SOLA hydronic boiler control (Modbus interface) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The specification says register addresses start at 0 per the Modbus specification; add 40001 to the decimal address for traditional 4xxxx numbering. Register 7 (outlet temperature) is requested as address 7 (40008).

What are the minimum Modbus registers to integrate the Honeywell SOLA hydronic boiler control (Modbus interface)?

Start with HR 7 Outlet (S3S4) or Outlet limit (S3) sensor (Outlet temperature); HR 8 Firing rate (Firing rate); HR 10 Flame signal (Flame signal); HR 32 Burner control status (Burner control status); HR 34 Lockout code (Lockout code); HR 6 Demand source (Demand source); HR 16 Active CH setpoint (Active CH setpoint).

How do I enable Modbus control of the Honeywell SOLA hydronic boiler control (Modbus interface)?

Use one of the SOLA's RS-485 Modbus ports (MB1 or MB2); the control answers to a single Modbus address. Register writes are limited by the access level shown in register 19 (none, installer, OEM or all).
