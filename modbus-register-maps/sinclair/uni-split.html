Short answer

Sinclair's UNI SPLIT DC inverter indoor units have a Modbus RTU slave built into the indoor controller, so no separate gateway is needed; up to 255 units share one RS-485 line. Settings and analog values are 16-bit words (holding registers) and flags are coils. This map covers on/off, mode, fan, setpoint, swing, temperatures, remote locks and shields, feature flags, and the indoor, outdoor and inverter-drive fault bits.

Integration notes: Sinclair UNI SPLIT DC inverter indoor units (integrated Modbus RTU)

Integration in brief

Set the indoor unit to PC/Modbus address mode on the wired controller, then poll holding registers 0-83 with function 03 and coils 0-215 with function 01. Control by writing words 2, 17, 19 and 20 with function 16.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The Modbus interface is built into the indoor unit controller. Select the address mode and set the unit address on the wired controller (see the unit's service manual).

Byte order & addressing

  • Writes must use function 16 (registers) or 15 (coils); function 06/05 are not listed.
  • On/off uses 0xAA (on) and 0x55 (off), not 1/0.
  • The BMS and the unit's own controls act equally: the most recent command wins.

Network setup

  • RS-485 at 9600 baud, 8 data bits, no parity, 1 stop bit.
  • Up to 255 indoor units per RS-485 port; use another port for more.
  • Use twisted pair and keep it at least 15 cm from power cables.

Watch out for

  • Exception 04 means the Modbus module can't reach the air conditioner, including right after power-up.
  • Heating commands are ignored on cooling-only units (check coil 177).

Notes on this map

  • All values are 16-bit words or single bits; there are no 32-bit values.
  • Function codes listed: 01 read coils, 03 read registers, 0F write coils and 10 write registers. Single-write codes 05 and 06 are not listed.
  • Reserved words and bits are left out, as are a few bits printed with no name (for example Bit125 and Bits 201-204 and 207, which have no value meaning).
  • When energy saving is active in cooling (or heating), a remote setpoint below the cooling lower limit (or above the heating upper limit) is ignored. The two energy-saving bits (32 and 33) must be set or cleared together.
  • After power-up, the module answers with exception 04 until it has valid data from the unit; 04 later means the module has lost contact with the air conditioner.
  • Several fault bits are printed with '1: yes 0: on', which reads as a typo for '0: no'; they are given here as 1 = fault.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Sinclair UNI SPLIT DC inverter indoor units (integrated Modbus RTU)

What Modbus registers does the Sinclair UNI SPLIT DC inverter indoor units (integrated Modbus RTU) have?

This map lists 115 registers: 97 coils, 18 holding registers. 31 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Sinclair UNI SPLIT DC inverter indoor units (integrated Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Word and bit addresses start at 0 and go on the wire unchanged: 'Word 20' is holding register address 20 and 'Bit17' is coil address 17. The manual's read example (start address 00 01 for words 1-2) confirms the numbering.

What are the minimum Modbus registers to integrate the Sinclair UNI SPLIT DC inverter indoor units (integrated Modbus RTU)?

Start with HR 2 Unit on/off (Unit on/off (0xAA on, 0x55 off)); HR 4 Ambient temperature (Ambient temperature); HR 17 Set mode (Mode); HR 19 Set fan speed (Fan speed); HR 20 Set temperature (Setpoint); CO 151 Compressor status (Compressor running); CO 122 Comms failure with ODU (ODU communication failure).

How do I enable Modbus control of the Sinclair UNI SPLIT DC inverter indoor units (integrated Modbus RTU)?

The Modbus interface is built into the indoor unit controller. Select the address mode and set the unit address on the wired controller (see the unit's service manual).

Where is the official Sinclair UNI SPLIT DC inverter indoor units (integrated Modbus RTU) Modbus documentation?

The source is User's manual UNI SPLIT Modbus, published free by Sinclair at https://www.sinclair-solutions.com/files/user-manual-en/accessories/sinclair-um-uni-split-modbus-protocol-en.pdf.
