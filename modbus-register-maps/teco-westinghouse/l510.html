Short answer

The L510 is TECO-Westinghouse's micro inverter; with its RS-485 option card it speaks Modbus RTU or ASCII. Run/stop and frequency are written to hex registers 2501H/2502H, status and monitors are read from 2520H-252FH, and each parameter nn-mm has its own register (group in the high byte, number in the low byte). This map covers the command and monitor tables.

Integration notes: TECO-Westinghouse L510 inverter (Modbus RTU/ASCII)

Integration in brief

Fit the RS-485 option card, set node address and serial settings and select communication as run/frequency source in the L510 parameters, then write 2501H and 2502H and poll 2520H-2527H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Install the RS-485 option card, then set the node address, communication parameters and run/frequency source at the keypad (parameter numbers are in the L510 manual, not this addendum).

Byte order & addressing

  • Registers are hex: 2520H is sent as 25 20.
  • Functions 03H, 06H, 08H and 10H; maximum frame 80 bytes.
  • Node addresses 01H-FEH; 00H is broadcast.
  • Write 0 to unused bits and never write reserved registers.

Network setup

  • RS-485 via the L510 option card, S+ / S-.
  • Up to 31 inverters per network; 120 ohm terminators at both ends.

Watch out for

  • Exception codes: 01 function, 02 register number, 03 number, 04 data setting error.
  • Inverter response time is about 10 ms.

Notes on this map

  • The addendum does not name the drive parameters for node address, baud rate, parity or remote run/frequency source; set those per the L510 instruction manual.
  • 2502H frequency command has no scale in the command table, so it is left unscaled (the read-back 2523H uses 100 = 1 Hz).
  • 2521H is a code table (0-40), mapped as an enum.
  • Left out: 252BH PID input (sign not stated) and 252CH/252DH AVI/ACI inputs (footnote *1 not explained). 2526H is labelled 'DC voltage command' in the table.
  • The parameter register rule (group high byte, number low byte, hex) is not expanded into individual registers.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the TECO-Westinghouse L510 inverter (Modbus RTU/ASCII)

What Modbus registers does the TECO-Westinghouse L510 inverter (Modbus RTU/ASCII) have?

This map lists 12 registers: 12 holding registers. 2 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the TECO-Westinghouse L510 inverter (Modbus RTU/ASCII) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are hex and sent unchanged: the 06H example writes start register 01 02 (0102H) and the 03H example reads 01 23 (0123H). Parameters map as group in the high byte and number in the low byte, e.g. 00-10 = 000AH, 01-17 = 0111H.

What are the minimum Modbus registers to integrate the TECO-Westinghouse L510 inverter (Modbus RTU/ASCII)?

Start with HR 9473 Operation signal (Run/stop, direction, reset); HR 9474 Frequency command (Frequency command); HR 9504 State signal (Run/ready/fault status); HR 9505 Error description (Error code); HR 9508 Output frequency (Output frequency); HR 9511 Output current (Output current).

How do I enable Modbus control of the TECO-Westinghouse L510 inverter (Modbus RTU/ASCII)?

Install the RS-485 option card, then set the node address, communication parameters and run/frequency source at the keypad (parameter numbers are in the L510 manual, not this addendum).

Where is the official TECO-Westinghouse L510 inverter (Modbus RTU/ASCII) Modbus documentation?

The source is L510 Communication Addendum Modbus RTU/ASCII (DOCUMENT-TECO-L510-AC001 Ver01), revision 2015-06, published free by TECO-Westinghouse at https://tecowestinghouse.com/PDF/L510_comm_addendum.pdf.
