Short answer

The Procon MelcoBEMS MINI (A1M+) is an RS-485 Modbus gateway; its air-to-water (ATW) register tables carry separate applicability columns for the commercial units: CAHV and CRHV heat pumps, QAHV CO2 heat pumps and EAHV / EACV e-series chillers. This map lists the holding registers ticked for those units: on/off, operating mode, water setpoint, capacity mode and ratio, outdoor temperature from the BMS, water inlet/outlet, evaporating, condensing and brine temperatures, compressor frequencies, run states of up to 32 modules, pumps, energy counters and model information.

This page lists 131 Modbus registers for the Mitsubishi Electric MelcoBEMS MINI (A1M+) gateway for CAHV / CRHV / QAHV heat pumps and EAHV / EACV e-series chillers — 14 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Mitsubishi Electric’s own free documentation (linked below) and checked against it.

Integration notes: Mitsubishi Electric MelcoBEMS MINI (A1M+) gateway for CAHV / CRHV / QAHV heat pumps and EAHV / EACV e-series chillers

Integration in brief

Read 40014 to confirm an ATW system and 40010 / 40013 for faults. Switch with 40026 and choose the mode with 40027 on the master unit; write the water setpoint at 40053 (x100) and read water outlet / inlet temperatures at 40102 / 40104.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step is described in the register tables; set the gateway's address, baud rate and parity (40005-40007) to match the BMS. See the MelcoBEMS MINI (A1M+) installation instructions.

Byte order & addressing

  • Holding registers are read with FC 03 and written with FC 06 or 16; rows marked READ ONLY cannot be written.
  • Baud codes 0 and 4 both mean 9600.

Network setup

  • Each A1M+ reads the unit it is connected to; the slave columns show what a gateway on a slave unit can read. Wiring and DIP settings are in the separate A1M+ installation instructions.

Watch out for

  • Run-time hours are split: 40137 holds 0-99 h and 40138 the hundreds (x100 h); total = 40138 x 100 + 40137.
  • Energy counters 40235-40250 are 0.01 kWh in one register, so they top out at 655.35 kWh; the tables do not say what happens after that.

Notes on this map

  • Only holding registers ticked for at least one of CAHV master/slave, CRHV master/slave, QAHV master or EAHV/EACV master/slave are listed; each description names the units it applies to (m/s = master and slave). The FTC (Ecodan) part of the same tables is a separate file in this library.
  • Several addresses carry a different name for the commercial units than for FTC (e.g. 40102 'Water Outlet Temperature' instead of 'Flow Temperature', 40031 'Thermo-off Temperature' on QAHV); the commercial name is used here.
  • Temperatures are x100 (0.01 °C) except outdoor temperatures 40051 and 40100 (x10). Every signed temperature has an unsigned twin at the next address; only the signed versions are listed.
  • Ticks shown in brackets with note #18 (slave units on 40026, 40027, 40049, 40050) are read-only values.
  • Setting water temperature (40053) range per the notes: CAHV +30 to +65 °C, CRHV +25 to +65 °C, QAHV +40 to +90 °C, EAHV +30 to +55 °C heating and +5 to +25 °C cooling. Outdoor temperature by BMS (40051): -30 to +50 °C.
  • Model notes: on CAHV 2013 models Stop and Cooling modes are not supported (CRHV 2013: also Legionella); EAHV 2015 models do not support Stop, Hot Water, No-Voltage Contact and Legionella modes; Emergency/Test Run are not supported on CAHV/CRHV 2013 and EAHV 2015; MRC prohibit bit 4 is not supported on those models; capacity mode is not supported on CAHV 2013; values marked #1 read 0 on CAHV/CRHV 2013 models.
  • Left out: 40114 (printed '(signed)' but with the unsigned note **), and the input register, coil and discrete input tables, which repeat the same data.
  • The MRC Prohibit register must not be written to Shizuoka-designed models (note ††).

Questions about the Mitsubishi Electric MelcoBEMS MINI (A1M+) gateway for CAHV / CRHV / QAHV heat pumps and EAHV / EACV e-series chillers

What Modbus registers does the Mitsubishi Electric MelcoBEMS MINI (A1M+) gateway for CAHV / CRHV / QAHV heat pumps and EAHV / EACV e-series chillers have?

This map lists 131 registers: 131 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Mitsubishi Electric MelcoBEMS MINI (A1M+) gateway for CAHV / CRHV / QAHV heat pumps and EAHV / EACV e-series chillers Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every row gives a protocol 'Addr' and a Modicon address (Addr 25 = 40026). The Addr value is the wire address.
