ComAp InteliGen4 200 Modbus register map

Updated 16 October 2026

Short answer

ComAp's InteliGen4 200 is a gen-set controller for multiple-set (MINT) and single parallel-to-mains (SPtM) applications. Its Modbus RTU and Modbus TCP map is generated per configuration, so values and setpoints must be exported from InteliConfig for each controller. This page covers only the registers ComAp fixes in every controller: the command interface used to start/stop the engine, reset faults and operate breakers, the password and error registers, the alarm list count, and the remote-control data registers.

This page lists 10 Modbus registers for the ComAp InteliGen4 200 — 7 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ComAp’s own free documentation (linked below) and checked against it.

Integration notes: ComAp InteliGen4 200

Integration in brief

Export the configuration-specific Modbus table from InteliConfig for measurements. For control, write the password to 4211 if required, then write the 32-bit argument to 4207-4208 and the command code to 4209 (or all three in one FC16 write), and read 4207-4208 to confirm.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

RS485 on board: set RS485 Mode to MODBUS (default is Direct) and set RS485 Modbus Speed and RS485 Modbus Mode. CM-RS232-485 module: set COM1 Mode or COM2 Mode to MODBUS plus the matching speed. Ethernet (CM3-Ethernet module required): set MODBUS Server to ENABLED (default disabled). Modbus Server Address (1-247, default 1) sets the unit ID.

Communication loss & watchdog

No control watchdog is documented. On Modbus TCP the controller closes a client socket that has been silent longer than MODBUS Client Inactivity Timeout (0-600 s, default 60 s).

Byte order & addressing

  • Most of the register map is configuration-dependent; two controllers with different configurations or firmware have different maps.
  • 32-bit registers are high word first (ABCD).
  • Reading an address inside a multi-register object returns exception 02; error 04 details are in 4205-4206.
  • Command and argument can be sent as one FC16 write of three registers starting at 4207, or as FC16 (argument) followed by FC06 (code).

Network setup

  • RS485 Modbus: 9600 bps default (9600-115200), 8N1 default (8N2 and 8E1 selectable), unit ID from Modbus Server Address.
  • Modbus TCP: port 502, up to 2 clients at once, needs the CM3-Ethernet module; can run alongside web and direct Ethernet / AirGate connections.
  • Use Modbus TCP only on a closed private network; the guide warns it has no authentication or encryption.

Watch out for

  • Engine start, stop, fault reset and breaker commands act on a real gen-set and switchgear. Disconnect remote control before maintenance and make sure the site is safe before writing 4209.
  • Write the argument and code exactly as listed: a different argument with code 1 or 2 is a different action. A refused command (for example when the controller is not in MAN) returns 0x00000002 in 4207-4208.
  • Engine start/stop, fault and horn reset and the GCB/MCB toggle commands behave like the front-panel buttons; a toggle acts on whatever state the breaker is in, so prefer the explicit on/off arguments.
  • Do not use setpoints for continuous regulation or rewrite them rapidly; ComAp asks for the RemoteControl registers (5000/5001/5200) to be used instead.

Notes on this map

  • Everything else (measurements, binary I/O, setpoints) is placed by the controller configuration and must be exported from InteliConfig; the guide's examples show such exported addresses but they are not fixed and are not listed here.
  • 32-bit values are high word first: the guide maps byte 3 (MSB) to the first register, and its engine-start example sends argument 0x01FE0000 as 01FE then 0000.
  • Command arguments (write to 4207-4208, then code to 4209): code 1 with 0x01FE0000 = engine start, 0x02FD0000 = engine stop, 0x08F70000 = fault reset, 0x04FB0000 = horn reset. Code 2 with 0x11EE0000 = GCB toggle, 0x11EF0000 = GCB on, 0x11F00000 = GCB off, 0x12ED0000 = MCB toggle, 0x12EE0000 = MCB on, 0x12EF0000 = MCB off.
  • A successful command returns a fixed value in 4207-4208 (e.g. 0x000001FF after engine start); 0x00000001 means invalid argument and 0x00000002 means refused (wrong mode, breaker cannot be closed now, etc.).
  • User buttons 1-16: code 0x47 (buttons 1-8) or 0x48 (buttons 9-16) with argument 0x00nn0000, where nn = 10 x button number for PULSE, +1 for TOGGLE, +2 for ON, +3 for OFF (e.g. button 1 PULSE = 0x000A0000, button 16 OFF = 0x00A30000; table on p. 206). The button setpoint must be in COMMAND mode.
  • Left out: RTC time and date (4200-4203, BCD-coded pairs), the 16 alarm-list records at 4215-4646 (27-register structures holding level, status and a UTF-8 text), and RemoteControlBin_1..16 at 5210-5225 (no data type given).
  • The reserved-register table prints '4010' for the 'Not implemented' row between 4209 and 4211; from its position this is 4210.
  • The same reserved-register scheme appears in other ComAp controller guides, but only the InteliGen4 200 guide was checked for this page.

Questions about the ComAp InteliGen4 200

What Modbus registers does the ComAp InteliGen4 200 have?

This map lists 10 registers: 10 holding registers. 7 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ComAp InteliGen4 200 Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints 'register addresses' that go straight into the request: its engine-start example writes register 4207 as 0x106F. It sometimes also gives the Modicon number (44208 for address 4207). Reserved registers can be read with FC03 or FC04 and written with FC06 or FC16.

What byte order does the ComAp InteliGen4 200 use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ComAp InteliGen4 200?

Start with HR 4207 Command Argument / Return Value (Command argument / result); HR 4209 Command Code (Command code); HR 4211 Password (Password for protected commands); HR 4205 Last Application Error (Error detail after exception 04); HR 4214 Alarm List Item Count (Number of active alarm list entries); HR 5000 RemoteControl2B 1 (Remote analog value into PLC logic).

How do I enable Modbus control of the ComAp InteliGen4 200?

RS485 on board: set RS485 Mode to MODBUS (default is Direct) and set RS485 Modbus Speed and RS485 Modbus Mode. CM-RS232-485 module: set COM1 Mode or COM2 Mode to MODBUS plus the matching speed. Ethernet (CM3-Ethernet module required): set MODBUS Server to ENABLED (default disabled). Modbus Server Address (1-247, default 1) sets the unit ID.

What happens when the ComAp InteliGen4 200 loses Modbus communication?

No control watchdog is documented. On Modbus TCP the controller closes a client socket that has been silent longer than MODBUS Client Inactivity Timeout (0-600 s, default 60 s).
