Short answer

The Nilan CTS602 is the controller in Nilan's residential and light-commercial ventilation units and compact heat pumps (ventilation, heat recovery, hot water and optional central heating). Its RS-485 port COM1 is a Modbus RTU slave at fixed 19200 8E1. Input registers give temperatures T0-T18 (x0.01 °C), humidity, CO2, digital inputs, alarm list, run and control states, fan steps and differential-pressure flows; holding registers carry on/off, operation mode, ventilation step, temperature setpoint, hot water and central heating settings, outputs and the clock.

Integration notes: Nilan CTS602 controller with HMI350T panel (Modbus version 23)

Integration in brief

Connect to COM1 (CN7 pins 2/3/6) at 19200 8E1, slave 30. Read input registers 200-222 for temperatures and air quality, 1000-1002 for run/mode/state and 400 for alarms; command the unit with holding registers 1001 (on/off), 1002 (mode), 1003 (ventilation step) and 1004 (temperature setpoint, x0.01 °C).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step: the CTS602 always answers on COM1. Only the node address can be changed (holding register 50 or the panel); speed and framing are fixed.

Byte order & addressing

  • Only function codes 03, 04 and 16 are supported; single-register write (06) is not, so write with function 16.
  • Temperatures are x0.01, not x0.1.
  • Packet size is limited to 255 bytes.

Network setup

  • COM1 on connector CN7: pin 2 = Data+ (A), pin 3 = Data- (B), pin 6 = ground. COM2 (pins 4/5) is the user panel bus.
  • Terminate both bus ends with 120 ohm; there is no opto-isolation on the CTS602, so all nodes need a common ground.
  • Up to 200 m of shielded twisted pair; default node address 30, selectable 1-247.

Watch out for

  • Holding register 1007 can restore factory defaults (1) or a backup; do not write it casually.
  • Mode 4 (Service) in 1002 is read-only; service functions are selected through 1005.

Notes on this map

  • Nilan does not host this protocol description at a public URL we could find (its manuals say it can be downloaded from the Nilan website, but no direct link turned up). The linked copy, hosted by the home-automation vendor TapHome in its 'manufacturer' folder, is the unchanged Nilan document 52173104.
  • Scale column: '100' means the raw value is divided by 100 (e.g. temperatures and % values with two decimals). Registers without a scale are whole numbers.
  • Signedness is not stated per register; temperatures and temperature settings are typed INT16 because they can be negative (the list shows ranges down to -40.00 °C), everything else UINT16.
  • Left out: software version text registers (1-3, two ASCII characters each), suction/discharge pressure (219/220, no scale given), registers scaled by 60 (1503, 4018) whose unit is unclear, user-function temperature/offset (604/605 and their user-function-2 copies 614/615) and fan-scaling (4098/4099) which have no scale, the pressure-control P/I settings (2300-2304), the alarm log detail block (3050-3074), week-program editing registers (4030-4036) and the menu-open flag (2002).
  • Enumerations are only given where the list prints the full value set; several holding registers in the display section (e.g. 4003-4005, 4012, 4013, 4020, 4021, 4041, 4108-4112) are listed without their complete value lists and are left without values.
  • Some holding-register descriptions in the source are in Danish (2300-2327 'Trin n tilluft/fraluft' = step n supply/extract air flow or pressure, 1209 heat source select); they are translated in the names here.
  • The document does not mark which holding registers are read-only; the output registers 100-206 and the clock 300-305 report states rather than commands.
  • All input registers can also be read as holding registers with function 03 at address + 10000 (read only).
  • External fire alarm auto reset (holding 4040) is left without value labels: the printed table shows codes 0-2, but the cell is cut off and the document's text layer holds a further code 3 that is not visible.

Questions about the Nilan CTS602 controller with HMI350T panel (Modbus version 23)

What Modbus registers does the Nilan CTS602 controller with HMI350T panel (Modbus version 23) have?

This map lists 262 registers: 97 input registers, 165 holding registers. 165 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Nilan CTS602 controller with HMI350T panel (Modbus version 23) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Nilan lists the addresses exactly as sent in the Modbus request, without the 30001/40001 global offset: reading input register 100 with function 04 is global address 30101. Use the printed number directly as the wire address.

What are the minimum Modbus registers to integrate the Nilan CTS602 controller with HMI350T panel (Modbus version 23)?

Start with HR 1001 User on / off select (equal to ON/OFF keys) (On/off); HR 1002 User operation mode select (Operation mode); HR 1003 User ventilation step select (Ventilation step); HR 1004 User temperature setpoint (Temperature setpoint); IR 1002 Actual control state (Actual control state); IR 208 Outdoor temperature (Outdoor temperature); IR 203 Room exhaust temperature (Room exhaust temperature); IR 400 Alarm state bit mask (Alarm status).

How do I enable Modbus control of the Nilan CTS602 controller with HMI350T panel (Modbus version 23)?

No enable step: the CTS602 always answers on COM1. Only the node address can be changed (holding register 50 or the panel); speed and framing are fixed.
