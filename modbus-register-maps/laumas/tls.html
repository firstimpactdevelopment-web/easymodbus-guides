Laumas TLS weight transmitter with analog output (Modbus RTU) Modbus register map

Updated 17 November 2026

Short answer

The TLS is a single-channel load-cell transmitter with an analog output and RS-485. With the port set to Modbus RTU it gives gross, net and peak weight, a status word, two inputs and two outputs, two setpoints and the analog-output span as holding registers. Tare, zero, calibration and EEPROM saves are triggered by writing codes to one command register.

This page lists 20 Modbus registers for the Laumas TLS weight transmitter with analog output (Modbus RTU) — 9 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Laumas’s own free documentation (linked below) and checked against it.

Integration notes: Laumas TLS weight transmitter with analog output (Modbus RTU)

Integration in brief

Set the serial port to Modbus RTU, then read 40007-40013 with FC3: status word, gross, net and peak weight. Use the status sign bits and the division index (40014) to get the real value. Write 7, 9 and 8 to 40006 for tare on, tare off and zero.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the serial communication menu choose the Modbus RTU protocol (communication is disabled by default), then set address (1-99, default 1), baud (default 9600), parity (default none) and stop bits (default 1).

Byte order & addressing

  • Only FC3 and FC16 are supported; write single registers with FC16.
  • Maximum 32 registers per request.
  • A settable reply delay (0-200 ms) in the serial menu slows responses.

Network setup

  • RS-485: if the line is over 100 m or runs above 9600 baud, close the two RS-485 termination jumpers (120 ohm) on the furthest instruments.
  • Broadcast writes (address 0) are executed without reply.

Watch out for

  • Outputs can be written only when configured for PLC control in the outputs menu.
  • Changing the theoretical full scale or the sensitivity resets weight-based settings such as setpoints and hysteresis to their defaults.

Notes on this map

  • Host: this copy is hosted by Massload, not by Laumas; a search did not turn up a public copy on laumas.com.
  • Word order: 32-bit values are H/L pairs, high word at the lower address. The read example returns gross 4000 as 0x0000 0x0FA0 at 40008-40009 and the -56 calibration example is 0xFFFF 0xFFC8 at 40037-40038, so ABCD is documented.
  • Weights carry no sign and no decimal point: apply status bits 7-9 for the sign and the division index for decimals. Divisions/units register 40014: low byte = division index (0-18: 100, 50, 20, 10, 5, 2, 1 with 0 decimals; 0.5, 0.2, 0.1 with 1; 0.05, 0.02, 0.01 with 2; 0.005, 0.002, 0.001 with 3; 0.0005, 0.0002, 0.0001 with 4); high byte = unit index (0 kg, 1 g, 2 t, 3 lb, 4 N, 5 l, 6 bar, 7 atm, 8 pieces, 9 N m, 10 kg m, 11 other).
  • Left out: Hysteresis 1 (40021-40022) because its access column is blank in the table; display coefficient 40015-40016 because the manual does not give its scaling for Modbus; exchange registers 40124-40131 whose use is not described.
  • Command codes 1, 6, 20, 98 and 131 appear in the list with their name printed as display symbols that do not extract; they are not listed.
  • Setpoints, hysteresis and analog-span values are written to RAM; send command 99 to keep them after power-off. EEPROM allows about 100000 writes.
  • The manual says the calibration sample weight is a signed 32-bit number; it does not state signedness for setpoints, hysteresis or the analog-output weights, which are typed INT32 here (this only matters for negative values).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Laumas TLS weight transmitter with analog output (Modbus RTU)

What Modbus registers does the Laumas TLS weight transmitter with analog output (Modbus RTU) have?

This map lists 20 registers: 20 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Laumas TLS weight transmitter with analog output (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints registers as 40001-40131 and says to subtract 40001 for 0-based clients (40028 -> 27). Its read example asks for start address 0x0007 to read gross weight at 40008, which confirms it.

What byte order does the Laumas TLS weight transmitter with analog output (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Laumas TLS weight transmitter with analog output (Modbus RTU)?

Start with HR 6 Status register (Status word); HR 7 Gross weight (Gross weight); HR 9 Net weight (Net weight); HR 13 Divisions and units of measure (Division index for decimals); HR 5 Command register (Command register); HR 24 Inputs (Digital inputs).

How do I enable Modbus control of the Laumas TLS weight transmitter with analog output (Modbus RTU)?

In the serial communication menu choose the Modbus RTU protocol (communication is disabled by default), then set address (1-99, default 1), baud (default 9600), parity (default none) and stop bits (default 1).
