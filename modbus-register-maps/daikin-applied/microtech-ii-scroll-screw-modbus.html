Short answer

Older McQuay scroll and screw chillers (and the ACZ condensing unit) whose MicroTech II controller takes a plug-in Modbus RTU module. The map is a fixed set of coils and 16-bit holding registers: start/stop, setpoints, water and refrigerant values, per-compressor data via a selector, run hours and a 16-word alarm bitmap. Descriptions name the models a point exists on.

This page lists 52 Modbus registers for the Daikin Applied MicroTech II scroll and screw chillers AGZ/ACZ/WGZ/AGS/WGS (Modbus module) — 7 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Daikin Applied’s own free documentation (linked below) and checked against it.

Integration notes: Daikin Applied MicroTech II scroll and screw chillers AGZ/ACZ/WGZ/AGS/WGS (Modbus module)

Integration in brief

Read the shaded minimum points (status, water temperatures, capacity, alarm coil) and write Chiller Enable (coil 2) and Cool Setpoint (40002) once the unit's setpoint source is switched to the network.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set Unit Setpoint screen 1 Source = Keypad, select Modbus as the protocol on the model-specific menu screen (the ED lists the screen number and password for AGZ-A/B, ACZ-A/B, AGS-B/C, WGS and WGZ), confirm operation on the BAS, then set Source = Network.

Byte order & addressing

  • Per-compressor values are multiplexed: write Compressor Select (40161) before reading them.
  • Compressor run hours are sent divided by 10.

Network setup

  • Set the protocol to Modbus at the keypad; the ID number (Modbus address 1-247) and baud rate only appear after that.
  • Modbus RTU over RS-485 through the plug-in Modbus Communication Module.

Watch out for

  • Network control needs the unit's setpoint/control source switched to Network/BAS at the unit.
  • Shutdown faults cannot be cleared over the network; reset them at the chiller panel.

Notes on this map

  • Every analog value is one 16-bit holding register in English units (°F, psi gauge, gpm). 'x 10' in the units column means the value is sent times ten, so the scale is 0.1. Temperatures and pressures have signed ranges (for example -40 to 244 °F, -3276.8 to 3276.7 psi) and are typed INT16; counters and percentages are UINT16.
  • Compressor Run Hours (40175) is printed as 'hours/10' with the note that the returned value must be multiplied by 10.
  • Per-compressor registers (40015-40036, 40174, 40175) return the compressor chosen in Compressor Select (40161). Write the selector first, then read.
  • Left out: Chiller Mode Output, printed as data type 'Coil' with index 40148 (type and index disagree), and Oil Feed Pressure 40033, printed 'psi' without the 'x 10' that every other pressure carries.
  • Coil 3 is printed for both 'Chiller On Off' and 'Run Enabled' (both tagged D2); it is listed once.
  • Active Alarms: 16 holding registers 40130-40145, one bit per alarm (Table 3 assigns no alarm to 40145, so it is not listed). Alarm n sits in register 40130 + n div 16, bit n mod 16 (alarm 1 = 40130 bit 1, alarm 16 = 40131 bit 0), as printed in Table 3. Which alarms a model raises varies by model, circuit count and options (Table 3 footnotes); the bit names here are not filtered by model.
  • The unit's protocol, Modbus ID number (1-247) and baud rate are set at the keypad; the companion manual IM 743-1, MicroTech II Chiller Unit Controller Modbus Communication Module (May 2005, https://tahoeweb.daikinapplied.com/api/general/DownloadDocumentByName/media/IM743-1.pdf), covers module installation and those settings but gives no default baud rate.
  • Point availability follows Table 2: a description ending 'Models: ...' lists the only models that have that point; all others exist on all five. Capacity Limit Output/Setpoint and Chiller Limited apply to dual-circuit AGZ/ACZ units only where Table 2 marks them with an asterisk (AGZ: limit output, limit setpoint, limited; ACZ: limit output, limited).
  • Only flow loss can be cleared from the network on these models.
  • Serial format is fixed at 8 data bits, no parity, 1 or 2 stop bits, 1200-19200 bps, RTU only (p. 6).
  • Alarm 144 (Re-Start Fault Circuit 4) is printed with bit 0 but a blank register cell; it is placed in 40139 by the numbering rule.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Daikin Applied MicroTech II scroll and screw chillers AGZ/ACZ/WGZ/AGS/WGS (Modbus module)

What Modbus registers does the Daikin Applied MicroTech II scroll and screw chillers AGZ/ACZ/WGZ/AGS/WGS (Modbus module) have?

This map lists 52 registers: 10 coils, 42 holding registers. 7 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Daikin Applied MicroTech II scroll and screw chillers AGZ/ACZ/WGZ/AGS/WGS (Modbus module) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The document states that data element 1 is sent as index 0 in the PDU. Holding registers are printed in 4xxxx form (Cool Setpoint 40002 = wire address 1) and coils as plain element numbers (Chiller Enable coil 2 = wire address 1). The point tags confirm it: Active Setpoint 40003 is tagged A2 and Chiller Enable coil 2 is tagged D1.

What are the minimum Modbus registers to integrate the Daikin Applied MicroTech II scroll and screw chillers AGZ/ACZ/WGZ/AGS/WGS (Modbus module)?

Start with HR 146 Chiller Status (Chiller status); HR 6 Evaporator Leaving Water Temperature for Unit (Evaporator leaving water temperature); HR 10 Actual Capacity (Actual capacity); HR 3 Capacity Limit Setpoint (Capacity limit setpoint); CO 1 Chiller Enable (Chiller enable (start/stop)); CO 3 Alarm Digital Output (Alarm present); CO 24 Clear Alarms (Clear alarms); HR 129 Active Alarms word 1 (alarms 1-15) (Alarm word 1).

How do I enable Modbus control of the Daikin Applied MicroTech II scroll and screw chillers AGZ/ACZ/WGZ/AGS/WGS (Modbus module)?

Set Unit Setpoint screen 1 Source = Keypad, select Modbus as the protocol on the model-specific menu screen (the ED lists the screen number and password for AGZ-A/B, ACZ-A/B, AGS-B/C, WGS and WGZ), confirm operation on the BAS, then set Source = Network.
