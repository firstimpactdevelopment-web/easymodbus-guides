Integration notes: Realtime Control Systems RTD-LT/CA Modbus interface for Daikin Altherma LT (split, CA) air-to-water heat pumps

Integration in brief

Set the address on SW1, wire DB/DA/GND, pick update mode 3 (send on change) if the BMS writes repeatedly, then write H0001-H0013 and poll I0021-I0051 plus the energy counters.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable switch; the update-mode register (+200) decides whether Modbus writes, the remote controller or both win.

Communication loss & watchdog

If P1/P2 communication is not restored within one minute the RTD raises an alarm on the fault relay.

Byte order & addressing

  • Writing the same value repeatedly in 'last keypress' mode overrides user changes at the controller; use update mode 3.
  • Changing weather-dependent mode (H0053 / H0063) resets the P1/P2 bus; the controller and the RTD show busy until the reset ends.
  • Read at most 10 registers per request.

Network setup

  • RS485 D-Bus: DB(+), DA(-) and GND, daisy chain only.
  • Factory serial settings 9600 baud, no parity, 1 stop bit.
  • Power 15..24 V DC SELV.

Watch out for

  • The RTD works as SUB: an EKRUCAL1 must be configured as MAIN.

Notes on this map

  • The source is the French edition of the Realtime Control Systems installation instructions, from a Sonepar (distributor) file host. The maker's own site (realtime-controls.co.uk) was offline and no Daikin-hosted copy was found, so the link is marked unofficial.
  • All values are 16-bit unless stated. Temperatures marked 'x100' are signed: raw 2150 = 21.50 °C, raw 65036 = -5.00 °C. Holding-register setpoints are printed in whole °C with no x100 marking and are listed at scale 1.
  • Fault codes are in the 'RTD ASCII' format described in the RTD-NET instructions (two characters packed high byte / low byte).
  • Supported function codes: 03 and 04 (1..10 registers), 06, and 16 (1..10 registers).
  • 32-bit counters (energy, run hours) are unsigned with the high word in the lower register, as both the data-type table and the register tables state.
  • Special values: 32767 = register not implemented, 32768 = function not available, 32769 = waiting for a value from the unit.
  • Each control register has an update-mode register at +200 (H0201 for H0001 and so on); only H0201 is listed.
  • Min/max setpoint registers for multizone (I0303/I0304, I0403/I0404) and DHW boost (I0306/I0406) follow the same pattern and are not listed.
  • In Sequencer mode the map changes to the RTD-W map; this file does not cover Sequencer mode.
  • Modbus address 0..63 on SW1 (0..15 in Smart Grid mode).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Realtime Control Systems RTD-LT/CA Modbus interface for Daikin Altherma LT (split, CA) air-to-water heat pumps

What Modbus registers does the Realtime Control Systems RTD-LT/CA Modbus interface for Daikin Altherma LT (split, CA) air-to-water heat pumps have?

This map lists 72 registers: 49 input registers, 23 holding registers. 23 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Realtime Control Systems RTD-LT/CA Modbus interface for Daikin Altherma LT (split, CA) air-to-water heat pumps Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual states register base 0 and writes H0010 / I0010 for holding / input register 10, so the number after H or I is the wire address. 32-bit values use two consecutive registers, high word first.

What byte order does the Realtime Control Systems RTD-LT/CA Modbus interface for Daikin Altherma LT (split, CA) air-to-water heat pumps use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Realtime Control Systems RTD-LT/CA Modbus interface for Daikin Altherma LT (split, CA) air-to-water heat pumps?

Start with HR 4 Space heating/cooling on/off (Space heating/cooling on/off); HR 3 Operating mode (Mode); HR 1 Main zone leaving water setpoint, heating (Heating LWT setpoint); HR 12 DHW reheat on/off (DHW reheat on/off); IR 40 Leaving water temperature (Leaving water temperature (x100)); IR 44 Outdoor air temperature (Outdoor temperature (x100)); IR 21 Unit error (Unit error); IR 62 Total energy consumed (Total energy consumed (UINT32)).

How do I enable Modbus control of the Realtime Control Systems RTD-LT/CA Modbus interface for Daikin Altherma LT (split, CA) air-to-water heat pumps?

No enable switch; the update-mode register (+200) decides whether Modbus writes, the remote controller or both win.

What happens when the Realtime Control Systems RTD-LT/CA Modbus interface for Daikin Altherma LT (split, CA) air-to-water heat pumps loses Modbus communication?

If P1/P2 communication is not restored within one minute the RTD raises an alarm on the fault relay.
