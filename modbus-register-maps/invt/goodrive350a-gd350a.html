Short answer

INVT's high-performance vector drive with option-card slots for fieldbuses, encoders and I/O. The built-in RS-485 port speaks Modbus RTU. Commands and setpoints go to the 2000H block, status and fault words sit at 2100H-2103H, monitors at 3000H onwards, and each function parameter has its own hex address. This map covers that block plus the run-source, P14 serial and fault parameters.

Integration notes: INVT Goodrive350A (GD350A) high-performance multifunction VFD

Integration in brief

Set P00.01 = 2 and P00.02 = 0 so run commands come from Modbus, and P00.06 = 8 so the speed reference does too. Write the frequency to 2001H in 0.01 Hz and a run/stop code to 2000H, then poll 2100H, 2102H and 3000H-3004H.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

P00.01 = 2 gives the run command to communication; P00.02 = 0 picks Modbus as that channel. P00.06 (A frequency source) = 8 makes 2001H the speed reference. P09.00 must select Modbus before 2002H/2003H act as PID reference/feedback. P14.00-P14.02 set address, baud and format.

Communication loss & watchdog

P14.04 sets a bus-silence timeout (0.0 s = off). When it runs out the drive raises CE (fault 18) and P14.05 decides whether it coasts, keeps running or stops with its stop mode.

Byte order & addressing

  • Parameter Pxx.yy sits at hex register (xx << 8) | yy: P14.01 = 0E01H, P07.27 = 071BH.
  • Setting the top bit of a parameter address (for example 8007H for P00.07) writes RAM only and spares the EEPROM; those aliases cannot be read.
  • Scaled values follow the decimals printed in the parameter list or address table (one decimal = x10, two decimals = x100), per the manual's fieldbus-scale section. Registers with a negative printed range are typed INT16 here.

Network setup

  • P14.00 slave address (default 1), P14.01 baud (default 4 = 19200 bps), P14.02 format (default 1 = E,8,1 RTU).
  • Read with function 03H; write with 06H or 10H.

Watch out for

  • Frequent parameter writes wear the EEPROM; use the RAM alias (address + 8000H) for values that change often.
  • Some parameters cannot be changed while the drive runs; the drive answers with exception 08H.

Notes on this map

  • Every register is a single 16-bit word; there are no 32-bit values in this map.
  • Any function parameter can be read or written at (group << 8) | index; only the parameters an integrator needs most are listed here.
  • 3016H (identification code) and 5000H (fault code) are printed without range or unit, so they are left out; 2102H and 2103H carry the same information.
  • 300FH, 3010H and 3011H (reserved AI4 and pulse inputs printed with a mixed kHz/0.01 Hz unit) are left out.
  • P00.02 values other than 0 select option cards; only 0 (Modbus/Modbus TCP) is listed.
  • 300DH/300EH (AI2/AI3) are left out: the address table prints AI2 as 0.00-10.00 V and AI3 as -10.00-10.00 V, but P17.20 prints AI2 as -10.00-10.00 V, so signedness is unclear.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the INVT Goodrive350A (GD350A) high-performance multifunction VFD

What Modbus registers does the INVT Goodrive350A (GD350A) high-performance multifunction VFD have?

This map lists 47 registers: 47 holding registers. 25 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the INVT Goodrive350A (GD350A) high-performance multifunction VFD Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed in hex and go on the wire unchanged. Parameter P00.00 sits at 0000H and the manual's example frames carry the address bytes directly (reading state word 2100H is sent as 01 03 21 00 00 01).

What are the minimum Modbus registers to integrate the INVT Goodrive350A (GD350A) high-performance multifunction VFD?

Start with HR 8192 Communication control command (Run / stop / fault reset command); HR 8193 Communication frequency setting (Speed reference in 0.01 Hz); HR 8448 VFD status word 1 (Running / stopped / fault state); HR 8450 VFD fault code (Active fault code); HR 12288 Running frequency (Output frequency); HR 12292 Output current (Output current); HR 12290 Bus voltage (DC bus voltage).

How do I enable Modbus control of the INVT Goodrive350A (GD350A) high-performance multifunction VFD?

P00.01 = 2 gives the run command to communication; P00.02 = 0 picks Modbus as that channel. P00.06 (A frequency source) = 8 makes 2001H the speed reference. P09.00 must select Modbus before 2002H/2003H act as PID reference/feedback. P14.00-P14.02 set address, baud and format.

What happens when the INVT Goodrive350A (GD350A) high-performance multifunction VFD loses Modbus communication?

P14.04 sets a bus-silence timeout (0.0 s = off). When it runs out the drive raises CE (fault 18) and P14.05 decides whether it coasts, keeps running or stops with its stop mode.
