Short answer

The CM500 is a CO2 sensor and controller with an RS-485 port that speaks Modbus RTU using FC03 reads and FC06 writes. Readings are single 16-bit registers. The shared register sheet also lists other gas, particulate and RTC registers that only answer on units fitted with those sensors.

Integration notes: CO2Meter CM500 CO2 sensor / controller (RS-485 Modbus RTU)

Integration in brief

Poll 19200 8N1 at address 104 (0x68) with FC03 and read register 0x14 for CO2 in ppm. Change address, baud or parity with FC06 and power-cycle the sensor.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is the RS-485 interface's protocol; no enable step is described.

Byte order & addressing

  • Only FC03 and FC06 are supported.
  • Baud and parity changes need a power cycle.

Network setup

  • Defaults: 19200 baud, 8 data bits, no parity, 1 stop bit.

Watch out for

  • Address 250 (0xFA) is broadcast; do not assign it to a sensor.

Notes on this map

  • The sheet is served from a Shopify file CDN (cdn.shopify.com) used by CO2Meter's store, not from a CO2Meter-branded host, so it is marked unofficial.
  • Note 1 on page 2 says the CO2 start address is 0x0B, but the register table and both example frames use 0x14; 0x14 is used here.
  • Default slave address is printed as 0x068 (104). The examples use 0xFA, which the sheet reserves for broadcast.
  • Left out: O2, ambient temperature, barometer, RH, dew point and battery voltage (12H, 19H-1DH). The sheet only shows display formats such as 'xx.xx%', not the register scaling.
  • Writable RTC registers (78H-7BH) are left out because their layout is not described.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the CO2Meter CM500 CO2 sensor / controller (RS-485 Modbus RTU)

What Modbus registers does the CO2Meter CM500 CO2 sensor / controller (RS-485 Modbus RTU) have?

This map lists 13 registers: 13 holding registers. 3 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the CO2Meter CM500 CO2 sensor / controller (RS-485 Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are listed as hex addresses sent unchanged in the request; the examples read CO2 with start address 0x0014 (table row 14H).

What are the minimum Modbus registers to integrate the CO2Meter CM500 CO2 sensor / controller (RS-485 Modbus RTU)?

Start with HR 20 CO2 (CO2 ppm); HR 0 Slave address (Slave address); HR 1 Baud rate (Baud rate code); HR 2 UART parity / framing (Parity code).

How do I enable Modbus control of the CO2Meter CM500 CO2 sensor / controller (RS-485 Modbus RTU)?

Modbus RTU is the RS-485 interface's protocol; no enable step is described.

Where is the official CO2Meter CM500 CO2 sensor / controller (RS-485 Modbus RTU) Modbus documentation?
