Short answer

The SKH4 is Neptronic's high-pressure atomizing humidifier with up to six spray stages and six zones. Its Modbus RTU module puts everything in holding registers: input signal voltages, scaled readings (room and supply RH, temperatures, water temperature, pump pressure), set points and PID terms, zone demands, binary inputs and relay states as 0/1 registers, and enumerated profile, source, state and alarm registers.

Integration notes: Neptronic SKH4 high-pressure atomizer humidifier (Modbus communication module)

Integration in brief

Read State (15017), System Alarm (15018), Room RH (6006), Power Output (6001) and Pressure (6025). For BAS control, set Control Profile (15006) and Control Demand Source (15013) to a network option, then write Control Network Demand (6049) or Room RH Network Reading (6033).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Modbus communication module, set the address from the device menu or register 0, and pick a network control profile (15006) and sources (15009-15015) when the BAS should supply readings or demand.

Byte order & addressing

  • All points, binary ones included, are holding registers (FC03/06/16 only).
  • Auto baud detection is the default; after two or more bad frames in one second at a given rate the device moves to the next rate.

Network setup

  • RS-485 two-wire, RTU mode, 9600-57600 baud or auto baud detection.
  • Device address 1-246 per the requirements text (the register row says 1-247); set in the device menu or register 0.
  • Parity / stop bits via register 2 or the Modbus Comport Config menu item (default no parity, 2 stop bits).

Watch out for

  • Many timers and counters are split over several registers with no word order given, so they are not in this map.
  • Readings switch between metric and imperial with register 15001.

Notes on this map

  • Only function codes 03, 06 and 16 are supported, so binary points (inputs, relays, flags) are 16-bit holding registers holding 0 or 1.
  • A 'Scale N' data type with 'Value x N' means raw = engineering value x N; this map stores the multiplier 1/N.
  • Temperature and capacity units follow Modbus Server Units (15001): 0 metric, 1 imperial.
  • Left out because the guide contradicts itself: 2003 Water Temperature Signal (Scale 1 vs Value x 1000); 6005, 6009 and 6013 bias registers (unsigned with a negative range, Scale 10 vs example x100); 6031 Power Output Feedback and 6032 Motor Speed (Scale 100 vs Value x 10); 6176-6187 depress times and drain flows (Scale 10 vs Value x 1).
  • Left out because they span two or four registers with no stated word order: every row printed with a (0)/(1)/(2)/(3) suffix, including run, on, idle and service times, cycle counts, drain volumes, Room Temperature Setpoint 6058, Room Temperature Demand Proportional Gain 6062, Modbus TCP keep-alive 6076, Demand Low Dead Band 6085, Network Timeout 6087, the RH proportional bands 6089/6091, Zone D/F humidity 6106/6113 and Control Signal 2009.
  • Product name ASCII registers 3-6 are left out.
  • The guide prints holding register 40672 next to protocol address 6071 (a typo for 406072); the protocol-base column is used.
  • Water Temperature Bias (6093) is marked read-only and Pressure Sensor Signal (2004) writable, as printed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Neptronic SKH4 high-pressure atomizer humidifier (Modbus communication module)

What Modbus registers does the Neptronic SKH4 high-pressure atomizer humidifier (Modbus communication module) have?

This map lists 250 registers: 250 holding registers. 177 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Neptronic SKH4 high-pressure atomizer humidifier (Modbus communication module) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide says register addresses follow the protocol base (base 0, add 1 for a PLC) and also prints the six-digit holding register (base 400001) beside each one, e.g. 6006 / 406007. The protocol-base number is the wire address.

What are the minimum Modbus registers to integrate the Neptronic SKH4 high-pressure atomizer humidifier (Modbus communication module)?

Start with HR 15017 State (Operating state); HR 15018 System Alarm (System alarm); HR 6006 Room RH (Room RH); HR 6034 Room RH Setpoint (Room RH set point); HR 6001 Power Output (Power output); HR 6025 Pressure (Pump pressure); HR 6049 Control Network Demand (Network demand); HR 15006 Control Profile (Control profile).

How do I enable Modbus control of the Neptronic SKH4 high-pressure atomizer humidifier (Modbus communication module)?

Fit the Modbus communication module, set the address from the device menu or register 0, and pick a network control profile (15006) and sources (15009-15015) when the BAS should supply readings or demand.
