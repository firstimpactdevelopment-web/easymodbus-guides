Integration notes: Acromag BusWorks XT1211-000 / XT1221-000 8-channel differential analog input (Modbus TCP)

Integration in brief

Read input registers 0-7 for the eight channels and convert counts to engineering units from the configured range (30000 = 100 %). Watch register 8 to confirm fresh data.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

RegisterNameTypeWhyAccess
IR 0CH 00 dataINT16Channel 0Read
IR 1CH 01 dataINT16Channel 1Read
IR 7CH 07 dataINT16Channel 7Read
IR 8Heart beatUINT16HeartbeatRead

Enable Modbus control & writes

Modbus TCP needs no enabling; set the IP address (default static 192.168.1.100) and channel ranges with the USB configuration software before connecting to the network.

Byte order & addressing

  • Values are normalized counts (30000 or 20000 = 100 %), not volts or milliamps.

Network setup

  • Configure IP address, input ranges and averaging over USB before connecting to the network.

Watch out for

  • Use a USB isolator when configuring with grounded inputs connected, or a ground loop can shift readings.

Notes on this map

  • Channel values are normalized counts, not engineering units: bipolar ranges read -30000 to +30000 for -100 % to +100 %, unipolar ranges 0-30000; with legacy support enabled the span is 20000 instead. The range is chosen per channel in the USB software (XT1211: ±20 mA, 0-20 mA, 0-11.17 mA, 4-20 mA; XT1221: ±10 V, ±5 V, 0-10 V, 0-5 V).
  • The map prints the Modicon reference and a 0-based address column; the address column is sent on the wire.
  • There are no configuration registers: ranges, averaging and IP settings are set only with the USB configuration software.
  • The Unit ID is ignored and echoed back in Modbus TCP.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Acromag BusWorks XT1211-000 / XT1221-000 8-channel differential analog input (Modbus TCP)

What Modbus registers does the Acromag BusWorks XT1211-000 / XT1221-000 8-channel differential analog input (Modbus TCP) have?

This map lists 9 registers: 9 input registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Acromag BusWorks XT1211-000 / XT1221-000 8-channel differential analog input (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register map prints both the reference (00001, 10001, 30001, 40001) and the 0-based address column; the address column is what goes on the wire.

What are the minimum Modbus registers to integrate the Acromag BusWorks XT1211-000 / XT1221-000 8-channel differential analog input (Modbus TCP)?

Start with IR 0 CH 00 data (Channel 0); IR 1 CH 01 data (Channel 1); IR 7 CH 07 data (Channel 7); IR 8 Heart beat (Heartbeat).

How do I enable Modbus control of the Acromag BusWorks XT1211-000 / XT1221-000 8-channel differential analog input (Modbus TCP)?

Modbus TCP needs no enabling; set the IP address (default static 192.168.1.100) and channel ranges with the USB configuration software before connecting to the network.
