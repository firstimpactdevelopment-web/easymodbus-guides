Updated 17 November 2026

Short answer

Stiebel Eltron heat pumps are not polled directly: the Internet Service Gateway (ISG) with the paid Modbus TCP/IP extension acts as a Modbus TCP server for the WPM heat pump manager behind it. All data points are single 16-bit registers with a fixed scaling per data type. This map covers the WPM system values (input registers 501-608), the writable operating mode and setpoints (holding 1501-1521), status flags and output states (2501-2547), heat and energy counters per system and per heat pump (3501-3655), and the shared SG Ready registers (4001-4003, 5001-5002).

Integration notes: Stiebel Eltron Heat pumps with WPM controller via ISG Modbus TCP/IP (WPMsystem, WPM 3, WPM 3i)

Integration in brief

Connect a Modbus TCP master to the ISG on port 502, unit ID 1, and read input registers with FC 04 and holding registers with FC 03/06/16. Remember the 1-based numbering: wire address = printed number - 1. Read outside temperature (507), flow/return (515/516), DHW actual/set (522/523), status flags (2501) and fault status (2504); write the operating mode (1501) and comfort/ECO setpoints (1502-1511).

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The ISG web or ISG plus needs the Modbus TCP/IP software extension and, for the ISG web, the Basic service package. With a WPM connected, check for the extension in SERVICEWELT under DIAGNOSIS > SYSTEM > ISG; if Modbus TCP/IP is not listed, update the ISG firmware or contact Stiebel Eltron service.

Byte order & addressing

  • All values are single 16-bit registers; there are no 32-bit values in this map. Totals are spread over a kWh and an MWh register.
  • Faults can only be acknowledged in SERVICEWELT, not over Modbus.
  • The Modbus interface cannot be combined with other ISG software interfaces, except read-only use alongside the EMI energy management extension.
  • Change either the operating mode or the setpoints of a mode over Modbus and leave the other fixed, so new setpoints take effect immediately.

Network setup

  • Default ISG address 192.168.0.126 when connected straight to a PC; behind a router it takes a DHCP address. Set the IP under the Profile tab in SERVICEWELT.
  • Unit ID is fixed at 1; TCP port 502.
  • Test with outside temperature against the controller display to confirm the 1-register offset.

Watch out for

  • An ISG must not share a CAN bus with a DCo-aktiv GSM module; communication to the WPM can fail.
  • 1520 = 1 is a full factory reset of the system; all settings are lost.

Notes on this map

  • Stiebel Eltron does not host this software documentation publicly (its own download path for it returns 404). The linked copy is a retailer mirror: the multilingual Stiebel Eltron document unchanged, with one shop cover page added in front, so PDF page numbers are one higher than the printed page numbers.
  • Data types from the document: type 2 = signed, value x 0.1 (temperatures, most pressures and flows); type 6 = unsigned 0-65535, x 1; type 7 = signed, value x 0.01; type 8 = unsigned 0-255, x 1. Write by sending the engineering value divided by the same factor (20.3 °C -> 203).
  • Unavailable objects return 32768 (0x8000). Not every object exists on every controller; the WPMsystem / WPM 3 / WPM 3i columns are noted in descriptions where a register is not listed for all three.
  • Energy counters are split into a kWh register (0-999) and an MWh register: total = MWh x 1000 + kWh. Day counters are single kWh registers.
  • Registers 524-527 and 532 (cooling and external heat source temperatures) are printed with the unit K in both the German and English tables; they are kept as published.
  • Left out: BUS-STATUS (2505) because it is typed as unsigned 0-65535 while its codes are negative (-1 to -4).
  • SG Ready on/off (4001): the language tables of the same document disagree on the coding (German and Italian: 0 = off, 1 = on; English: 0 = on, 1 = off). No value labels are given here; test on site which code switches the function on.
  • Holding register 1508 (fixed value operation) accepts 20-70 °C; writing 0x9000 turns the function off. The document says this works on WPMsystem, WPM 3 from software 39005 and WPM 3i from software 39106; older software can only activate and adjust it.
  • Integral ventilation units (LWZ/LWA) use a different register set and are mapped separately (stiebel-eltron/isg-modbus-lwz-ventilation-units).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Stiebel Eltron Heat pumps with WPM controller via ISG Modbus TCP/IP (WPMsystem, WPM 3, WPM 3i)

What Modbus registers does the Stiebel Eltron Heat pumps with WPM controller via ISG Modbus TCP/IP (WPMsystem, WPM 3, WPM 3i) have?

This map lists 335 registers: 311 input registers, 24 holding registers. 24 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Stiebel Eltron Heat pumps with WPM controller via ISG Modbus TCP/IP (WPMsystem, WPM 3, WPM 3i) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The document states that ISG addressing is 1-based and gives the example that register 30501 is reached as address 501 with function code 04, so the wire address is the printed number minus one: outside temperature, printed 507, is requested at input register address 506. The document also warns that, depending on the configuration, an offset of 1 may have to be allowed for, so check outside temperature against the controller display first.

What are the minimum Modbus registers to integrate the Stiebel Eltron Heat pumps with WPM controller via ISG Modbus TCP/IP (WPMsystem, WPM 3, WPM 3i)?

Start with IR 506 Outside temperature (Outside temperature (check offset)); IR 514 Actual flow temperature (Actual flow temperature); IR 521 Actual DHW temperature (Actual DHW temperature); IR 2500 Operating status (Operating status flags); IR 2503 Fault status (Fault status); HR 1500 Operating mode (Operating mode); HR 1501 Comfort temperature HC 1 (Comfort temperature HC 1); HR 1509 Comfort temperature DHW (Comfort DHW setpoint); IR 3502 VD HEATING TOTAL MWh heat all HPs (Total compressor heating heat, MWh part).

How do I enable Modbus control of the Stiebel Eltron Heat pumps with WPM controller via ISG Modbus TCP/IP (WPMsystem, WPM 3, WPM 3i)?

The ISG web or ISG plus needs the Modbus TCP/IP software extension and, for the ISG web, the Basic service package. With a WPM connected, check for the extension in SERVICEWELT under DIAGNOSIS > SYSTEM > ISG; if Modbus TCP/IP is not listed, update the ISG firmware or contact Stiebel Eltron service.
