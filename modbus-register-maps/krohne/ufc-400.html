KROHNE UFC 400 ultrasonic flow converter (Modbus RTU) Modbus register map

Updated 17 November 2026

Short answer

The UFC 400 is KROHNE's signal converter for ultrasonic flowmeters. With the Modbus option it is an RS-485 Modbus RTU slave. This map covers flow velocity, volume and mass flow, sound velocity, gain and SNR (overall and per path), NAMUR NE 107 status bytes, the totalisers, process input parameters, serial settings and the control coils.

This page lists 89 Modbus registers for the KROHNE UFC 400 ultrasonic flow converter (Modbus RTU) — 49 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from KROHNE’s own free documentation (linked below) and checked against it.

Integration notes: KROHNE UFC 400 ultrasonic flow converter (Modbus RTU)

Integration in brief

Read input registers 30000-30015 (function 04) for flow and acoustic values and 30500-30507 for their NE 107 status bytes. Totalisers are doubles at 32000/32004.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set slave address, baud rate, parity, data format, delay and stop bits in display menu C5.8.

Byte order & addressing

  • Protocol addresses are sent as printed.
  • Write holding registers with FC16, then apply with coil 1002.
  • Pipe temperature is entered in kelvin.

Network setup

  • Defaults: address 1, 19200 bps, even parity, 1 stop bit, Big Endian.

Watch out for

  • Discrete input 10001 = 1 means written changes are still pending.

Notes on this map

  • This is an unaltered copy of the KROHNE document hosted by distributor Instrumart; no public KROHNE URL for this revision was found in the time available.
  • Data representation (pp. 9-10): 16-bit values are MSB first; 32- and 64-bit values follow the 'Register Format' setting (holding 50006). Big Endian, the default, puts the most significant word in the first register (ABCD); the manual's Little Endian diagram keeps bytes in order inside each register but reverses the registers (CDAB).
  • Holding registers are written with function 16 (0x10). Configuration changes take effect only after 'Apply Changes' (coil 1002).
  • Totaliser 3 registers are footnoted in the manual as available only on signal converters with the 'modular carrier'.
  • Left out: NE 107 status groups (39004, Long), diagnostics selectors 41002/41003 (long code lists), NE 107 event-group signal registers 52000+, and device identification via function 43.
  • Byte-type parameters each occupy one register and are listed as UINT16.
  • Left out: transmission delay 50002 (Float), because the table gives its unit as ms while the range is printed as 0...0.04.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the KROHNE UFC 400 ultrasonic flow converter (Modbus RTU)

What Modbus registers does the KROHNE UFC 400 ultrasonic flow converter (Modbus RTU) have?

This map lists 89 registers: 12 coils, 1 discrete input, 39 input registers, 37 holding registers. 49 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the KROHNE UFC 400 ultrasonic flow converter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists protocol addresses that go into the request unchanged: input register 30006 is requested as 30006 (0x7536); each row also prints the hex value. Register numbers, if a tool wants them, are the address + 1.

What byte order does the KROHNE UFC 400 ultrasonic flow converter (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the KROHNE UFC 400 ultrasonic flow converter (Modbus RTU)?

Start with IR 30002 Volume flow (Volume flow); IR 30000 Flow velocity (Flow velocity); IR 30006 Velocity of sound (Velocity of sound); IR 30501 NE 107 status of volume flow (Volume flow status); IR 32000 Totaliser 1 value (double) (Totaliser 1); IR 39100 NE 107 device status (Device status).

How do I enable Modbus control of the KROHNE UFC 400 ultrasonic flow converter (Modbus RTU)?

Set slave address, baud rate, parity, data format, delay and stop bits in display menu C5.8.

Where is the official KROHNE UFC 400 ultrasonic flow converter (Modbus RTU) Modbus documentation?

The source is UFC 400 Supplementary instructions - Signal converter for ultrasonic flowmeters - Description of Modbus interface (4002744801 R01), revision 2013-05. KROHNE doesn't publish it on its own website, so this map was re-typed from a free copy at https://core.instrumart.com/assets/Krohne-UFC-400-Modbus-Manual.pdf. It may be an older revision, so check it against the live unit.
