Integration notes: Lumel NMID08 / NMID09 / NMID10 single-phase energy meter

Integration in brief

Poll input registers 0x00-0x1F with function 04 for voltage, current, powers and power factor, then 0x6C and 0x70 for import/export energy. Each value is a float in two registers, high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is always on in the Modbus versions; set address, baud rate and parity/stop bits in the front-panel setup menu.

Byte order & addressing

  • Read two registers per value and never start a read in the middle of a float (exception 02).
  • Keep one request to 40 parameters (80 registers) or fewer.

Network setup

  • Factory settings: address 1, 9600 baud, no parity, 1 stop bit (nonE1).
  • Parity choices are nonE1, nonE2, EVEn and odd.
  • Broadcast address 0 is not supported.

Watch out for

  • Energy needs the overflow counter for very large totals.

Notes on this map

  • Format is stated as 4 bytes per parameter, IEEE-754 float, most significant byte first; the example frames return 43 66 00 00 for 230 V and 40 A0 00 00 for 5 A, which settles high word first.
  • The same values sit in the 4X (holding register) area at the same addresses; this map lists the 3X copy only.
  • Left out: hex 0x54, which the table labels 'var Exp./Cap Max Demand' exactly like 0x56; the long-energy table 5 (0x200 on), because its data format is not spelled out; the 4X setup table 6 and the user-assignable area from 0x400.
  • Energy registers count up to 99999.999 and the matching overflow register counts the roll-overs.
  • Table 4 uses the label 'Total Apparent Energy' twice (0x7A/0x7C and 0x8A/0x8C), and likewise for the T1, T2 and partial groups; both copies are listed as printed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lumel NMID08 / NMID09 / NMID10 single-phase energy meter

What Modbus registers does the Lumel NMID08 / NMID09 / NMID10 single-phase energy meter have?

This map lists 88 registers: 88 input registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lumel NMID08 / NMID09 / NMID10 single-phase energy meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The measurement table prints Modicon numbers (30001) next to the hex start address (00 00). The hex column is the wire address, so 30001 is register 0 and power factor 30031 is 0x1E.

What byte order does the Lumel NMID08 / NMID09 / NMID10 single-phase energy meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lumel NMID08 / NMID09 / NMID10 single-phase energy meter?

Start with IR 0 Voltage (Voltage); IR 6 Current (Current); IR 12 Active Power (Active power); IR 30 Power Factor (Power factor); IR 70 Frequency (Frequency); IR 108 Active Import Energy (Active import energy); IR 112 Active Export Energy (Active export energy).

How do I enable Modbus control of the Lumel NMID08 / NMID09 / NMID10 single-phase energy meter?

Modbus is always on in the Modbus versions; set address, baud rate and parity/stop bits in the front-panel setup menu.

Where is the official Lumel NMID08 / NMID09 / NMID10 single-phase energy meter Modbus documentation?

The source is NMID08, NMID09, NMID10 DIN rail mount single phase energy meter - User Manual, published free by Lumel at https://www.lumel.com.pl/resources/Pliki%20do%20pobrania/liczniki%20energii/NMID08_NMID09_NMID10_user_manual.pdf.
