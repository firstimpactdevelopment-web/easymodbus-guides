Integration notes: Intesis (HMS Networks) INMBSMHI128O000 / INMBSMHI048O000 Mitsubishi Heavy Industries Superlink to Modbus gateway

Integration in brief

Enable the indoor units in LinkBoxMB, set the SLK selector (New = Superlink-II, Old = Superlink-I), then poll each unit's 20-register block. Write single registers (FC06) for on/off, mode, setpoint and fan.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Each indoor unit must be enabled in the LinkBoxMB Devices list and the configuration file sent to the gateway.

Communication loss & watchdog

A per-unit communication-error signal is raised when a unit stops answering within the 'Timeout response' set in LinkBoxMB (2000..10000 ms).

Byte order & addressing

  • Printed addresses are 1-based: subtract 1 for the wire address.
  • Only FC06 is supported for writes (no FC16).
  • Mode codes differ from most other Intesis maps: 0 = Cool, 1 = Heat, 2 = Fan, 3 = Auto, 4 = Dry.

Network setup

  • Configure Modbus (TCP and/or RTU, RS-485 on C1 or RS-232 on C2, baud 1200..38400, parity, slave number) in LinkBoxMB over the console port.
  • Superlink connects to the A-B terminals (no polarity), max 1000 m, no loop wiring.
  • Set the SLK selector to NEW for Superlink-II systems or OLD for Superlink-I.

Watch out for

  • With SC-SL2NA / SC-SL3NA central controllers present, unconnected indoor units must be deregistered and the remote lock rights adjusted (see manual section 1).

Notes on this map

  • Only indoor unit address 0 is listed. For unit address n add n x 20 to each wire address (unit 127 on/off: printed 2542, wire 2541).
  • The manual says registers are 2-byte big-endian values but does not say signed or unsigned; all listed values are non-negative, so UINT16 is used.
  • Temperatures are whole °C (no x10).
  • Writes must use function 06 (single register). Reads use 03 or 04. A poll range containing an invalid address returns an exception.
  • Error code numbers match MHI remote-controller E codes (value 40 = E40 high pressure); full table on p. 26 of the manual.
  • INMBSMHI048O000 serves unit addresses 00..47 only.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Intesis (HMS Networks) INMBSMHI128O000 / INMBSMHI048O000 Mitsubishi Heavy Industries Superlink to Modbus gateway

What Modbus registers does the Intesis (HMS Networks) INMBSMHI128O000 / INMBSMHI048O000 Mitsubishi Heavy Industries Superlink to Modbus gateway have?

This map lists 20 registers: 20 holding registers. 13 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Intesis (HMS Networks) INMBSMHI128O000 / INMBSMHI048O000 Mitsubishi Heavy Industries Superlink to Modbus gateway Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables say 'base addr is 1': printed register 1 is wire address 0. Indoor unit with Superlink address n (0..127) uses printed n x 20 + 1 .. n x 20 + 14, so wire n x 20 + 0..13. This file lists unit address 0 (printed 1..14, wire 0..13) and the all-unit block (printed 2995..3000).

What are the minimum Modbus registers to integrate the Intesis (HMS Networks) INMBSMHI128O000 / INMBSMHI048O000 Mitsubishi Heavy Industries Superlink to Modbus gateway?

Start with HR 0 IU communication status (Unit communication status); HR 1 IU on/off (On/off); HR 2 IU operation mode (Mode); HR 3 IU setpoint temperature (Setpoint (°C)); HR 4 IU fan speed (Fan speed); HR 7 IU room temperature (Room temperature (°C)); HR 9 IU error code (Error code); HR 2994 Hardware communication status (Gateway hardware communication status).

How do I enable Modbus control of the Intesis (HMS Networks) INMBSMHI128O000 / INMBSMHI048O000 Mitsubishi Heavy Industries Superlink to Modbus gateway?

Each indoor unit must be enabled in the LinkBoxMB Devices list and the configuration file sent to the gateway.

What happens when the Intesis (HMS Networks) INMBSMHI128O000 / INMBSMHI048O000 Mitsubishi Heavy Industries Superlink to Modbus gateway loses Modbus communication?
