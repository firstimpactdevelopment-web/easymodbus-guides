RLE Technologies Falcon F200 environment and leak monitoring appliance (Modbus TCP) Modbus register map

Updated 17 November 2026

Short answer

The Falcon F200 is a small monitoring appliance for data rooms: up to four external temperature/humidity sensors, a leak-detection cable input and eight digital inputs. It is a Modbus TCP server only. All values are 16-bit holding registers: temperatures in hundredths of a degree (C and F copies), humidity in %RH, leak and cable status flags and digital input states and alarms.

This page lists 71 Modbus registers for the RLE Technologies Falcon F200 environment and leak monitoring appliance (Modbus TCP) — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from RLE Technologies’s own free documentation (linked below) and checked against it.

Integration notes: RLE Technologies Falcon F200 environment and leak monitoring appliance (Modbus TCP)

Integration in brief

Poll the F200 over Modbus TCP with FC3. Read 40071-40073 for leak, missing cable and cable break, 40010/40013 for sensor 1 temperature and humidity, and 40004/40005 for digital input alarm and state bitfields.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The guide only says the F200 acts as a Modbus TCP server; it does not describe enabling or configuring Modbus.

Byte order & addressing

  • Digital input alarm registers 40090-40097 stay 0 unless the input's notification option in the web interface is set to something other than Disabled.

Watch out for

  • Each external sensor has its own fixed block of registers; 40006 reports whether sensors are connected.

Notes on this map

  • Temperature registers are 'Celsius x 100' or 'Fahrenheit x 100' with range 0-65535 (unsigned as published), so 2150 = 21.50 °C. The guide does not say how sub-zero temperatures are reported.
  • Humidity is published as '% Relative Humidity' with no multiplier; scale 1 is used.
  • Only 16-bit registers exist; no word-order question arises.
  • The guide gives no unit ID or TCP port.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the RLE Technologies Falcon F200 environment and leak monitoring appliance (Modbus TCP)

What Modbus registers does the RLE Technologies Falcon F200 environment and leak monitoring appliance (Modbus TCP) have?

This map lists 71 registers: 71 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the RLE Technologies Falcon F200 environment and leak monitoring appliance (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. RLE prints every register in 4xxxx form ('Read Output Registers', read with FC3). Under the Modicon convention 40010 is wire address 9. The guide has no example frame that confirms the offset.

What are the minimum Modbus registers to integrate the RLE Technologies Falcon F200 environment and leak monitoring appliance (Modbus TCP)?

Start with HR 70 Leak detected (Leak detected); HR 72 Cable break alarm (Cable break); HR 71 No sensing cable connected (No sensing cable connected); HR 9 Sensor 1 temperature (Sensor 1 temperature (°C x 100)); HR 12 Sensor 1 humidity (Sensor 1 humidity); HR 3 Digital input alarm status (all inputs) (Digital input alarm bitfield).
