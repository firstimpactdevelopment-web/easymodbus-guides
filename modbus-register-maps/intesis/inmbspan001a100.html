Short answer

This Intesis interface connects to a Panasonic Aquarea hydro unit and presents it as a Modbus RTU server. All points are single 16-bit holding registers: system on/off and operating mode, zone setpoints and actual temperatures, DHW tank on/off and setpoint, water temperatures, present power draw, error code, unit configuration, and requests such as powerful, quiet and sterilisation. Some registers apply only to newer K/L/M series units.

Integration notes: Intesis (HMS Networks) INMBSPAN001A100 Panasonic Aquarea H/J/K/L/M air-to-water to Modbus RTU gateway

Integration in brief

Connect the gateway to the Aquarea hydro unit and the RS-485 bus, set the address on SW3 P1-P6 (default 1), then read holding registers with function 03 and write single registers with function 06: register 0 for on/off, 4 for mode, 12 and 33 for zone and tank setpoints.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No software enable. Set the address and baud on the DIP switches with the gateway unpowered; it is powered by the Aquarea unit.

Byte order & addressing

  • Function 16 works only with a quantity of one register.
  • Factory serial setting is 9600 baud, 8-N-2; 8-N-1 is detected automatically.
  • Temperature scale and unit change with DIP switch SW4.
  • Register 70 reads 1 (error) until the gateway has communicated with the Aquarea unit.

Network setup

  • SW3 P1-P6: Modbus address in binary (P1 = least significant bit).
  • SW3 P7-P8 plus SW4 P3: baud rate (9600 default).
  • SW4 P1 = x1/x10, P2 = °C/°F, P4 = 120 ohm termination.
  • Switch the gateway off (power down the Aquarea) before changing DIP switches.

Watch out for

  • Zone 1/Zone 2 on/off (register 9) only applies when two zones are configured.
  • Many registers from 105 upward exist only on K, L or M series units.

Notes on this map

  • The download link's file name says v1-0-0 but the PDF it serves is version 1.0.2 dated 2026-02-04; the addresses here are from 1.0.2.
  • Temperatures follow DIP switch SW4: P1 ON = tenths of a degree (x10, Celsius only), P2 ON = Fahrenheit; both OFF (factory) = whole °C. Units and scale here are for the default; use scale 0.1 if x10 is set.
  • Temperature ranges go below zero (-127 to 127 °C), so temperatures are typed signed 16-bit. Invalid readings are 0x8000 on signed registers and 0xFFFF on unsigned ones.
  • What register 12/13 (zone setpoint) and 14/15 (actual) mean depends on zone setup (83/84), setting mode (16/17) and operating mode (4): room, water, water shift or pool; see the table on p. 30.
  • For registers whose values are range-checked, an out-of-range write is moved to the nearest limit (writing 6 to a 0-5 register applies 5).
  • Left out: the 32-bit energy totals 120-131 and 366-373 (two registers each, word order not stated); compressor total on time 184-185 (split into MSB/LSB registers with a 24-bit range, packing not stated); the compensation-curve, bivalent, SG Ready capacity and M-series-only settings (150-438) - read them from the manual if needed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Are the Intesis (HMS Networks) INMBSPAN001A100 Panasonic Aquarea H/J/K/L/M air-to-water to Modbus RTU gateway Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire).
