Short answer

The OLCT 700 and OLCT 710 FP are Oldham-branded versions of the Teledyne 700-series smart catalytic bead combustible gas detectors. Next to the 4-20 mA loop they answer Modbus RTU on RS-485 with 22 holding registers: range, gas reading, span level, sensor life, fault bits, loop current, supply voltage, model-specific diagnostics, calibration command and gas/units text. This map covers all of them except temperature.

Integration notes: Teledyne Oldham Simtronics OLCT 700 / OLCT 710 FP catalytic bead combustible gas detector (RS-485 Modbus)

Integration in brief

Give each sensor its own serial ID from the magnetic-switch menu, wire RS-485 at 9600 8N1 and poll holding registers 0-9 with function 03; read 40005 for faults.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The manual describes no separate enable step; set a unique serial ID in Program Mode (Set Serial ID).

Byte order & addressing

  • Register numbers start at 40000 = wire address 0.
  • The text names function 03 as the only supported code, but the register table lists function 06 for writing the R/W registers.
  • Text characters are low byte first.

Network setup

  • 9600 baud, 8 data bits, no parity, 1 stop bit.
  • Serial ID is entered in hexadecimal (01, 02 ... 0A ...).

Watch out for

  • Bit 14 of the fault register is set while the sensor is in calibration.

Notes on this map

  • All registers are single 16-bit holding registers; the manual shares one table across FP, IR and TP detectors and model register 40006 tells them apart. Registers 40011-40014 change meaning with the model; only the FP detector meanings are given here.
  • The manual footnote on reading scale refers to Low Range, which the FP detector does not have; the reading is taken as whole units.
  • Range, reading and span level are in the units of the notation string (PPM, PPB or %).
  • Register 40010 (temperature, °C) is left out: the manual gives no data type, so it is unclear how readings below 0 °C are coded.
  • The notation string stores the first character in the low byte of each register (low byte, high byte, ...), the reverse of the usual Modbus string order.
  • Bit 13 of the fault register is reserved.
  • Default serial ID is 01; it is set in the sensor menu (Set Serial ID) in hexadecimal.
  • The manual prints device type 8 as "OLCT 700/710 Detector"; the register layout is the same as the Teledyne Detcon 700 series.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Teledyne Oldham Simtronics OLCT 700 / OLCT 710 FP catalytic bead combustible gas detector (RS-485 Modbus)

What Modbus registers does the Teledyne Oldham Simtronics OLCT 700 / OLCT 710 FP catalytic bead combustible gas detector (RS-485 Modbus) have?

This map lists 16 registers: 16 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Teledyne Oldham Simtronics OLCT 700 / OLCT 710 FP catalytic bead combustible gas detector (RS-485 Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints registers as 40000-40021, starting at 40000, so the digits after the leading 4 are the 0-based wire address: 40000 (device type) is address 0 and 40002 (gas reading) is address 2. Only function 03 reads them; writable ones use function 06.

How do I enable Modbus control of the Teledyne Oldham Simtronics OLCT 700 / OLCT 710 FP catalytic bead combustible gas detector (RS-485 Modbus)?
