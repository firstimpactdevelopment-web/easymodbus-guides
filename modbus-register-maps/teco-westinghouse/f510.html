Short answer

The F510 is TECO-Westinghouse's HVAC fan and pump inverter; its RS-485 port supports Modbus RTU/ASCII as well as BACnet MS/TP and Metasys N2. Run/stop and frequency (0.01 Hz) are written to 2501H/2502H, and status, fault and warning codes and monitors are read from 2520H-252FH. Each parameter nn-mm has its own register, with the group in the high byte and the number in the low byte.

Integration notes: TECO-Westinghouse F510 HVAC fan/pump inverter (Modbus RTU/ASCII)

Integration in brief

Set the RS-485 protocol to Modbus, the node address and serial parameters, and select communication as run/frequency source, then write 2501H and 2502H (0.01 Hz) and poll 2520H-2528H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Select Modbus as the communication protocol (the port also does BACnet and Metasys N2), then set node address, serial settings and run/frequency source at the keypad per the F510 manual.

Byte order & addressing

  • Registers are hex.
  • Functions 03H, 06H, 08H and 10H; maximum frame 80 bytes.
  • Node addresses 01H-FEH; 00H is broadcast.
  • Write 0 to unused bits and never write reserved registers.

Network setup

  • RS-485 on CN6: S+ / S- per the CN6 pin-out.
  • The addendum shows 120 ohm terminators on p. 1-1 but says 220 ohm in Appendix A; up to 31 inverters.

Watch out for

  • Exception codes: 01 function, 02 register number, 03 number, 04 data setting error.
  • Inverter response time is about 10 ms.

Notes on this map

  • Unlike the A510/E510 Compact addenda, the F510 monitor table prints no units for 2523H, 2524H, 2526H and 2527H, so they are listed raw.
  • The addendum does not name the drive parameters for node address, baud rate, parity or run/frequency source; set those per the F510 manual.
  • 2521H (faults) and 2528H (warnings) are code tables, mapped as enums.
  • Left out: 2507H DO, 2529H digital output state (no bit list), 252CH/252DH analog inputs (no unit).
  • Parameter 12-00 is 32-bit (2510H high word, 2511H low word) and is not listed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the TECO-Westinghouse F510 HVAC fan/pump inverter (Modbus RTU/ASCII)

What Modbus registers does the TECO-Westinghouse F510 HVAC fan/pump inverter (Modbus RTU/ASCII) have?

This map lists 15 registers: 15 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the TECO-Westinghouse F510 HVAC fan/pump inverter (Modbus RTU/ASCII) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are hex and sent unchanged (2520H is sent as 25 20). Parameters map group to the high byte and number to the low byte, except 12-00 which is 32-bit at 2510H (high word) / 2511H (low word).

What are the minimum Modbus registers to integrate the TECO-Westinghouse F510 HVAC fan/pump inverter (Modbus RTU/ASCII)?

Start with HR 9473 Operation signal (Run/stop, direction, reset); HR 9474 Frequency command (Frequency command 0.01 Hz); HR 9504 State signal (Status bits); HR 9505 Error description (Fault code); HR 9508 Output frequency (Output frequency); HR 9512 Warning description (Warning code).

How do I enable Modbus control of the TECO-Westinghouse F510 HVAC fan/pump inverter (Modbus RTU/ASCII)?

Select Modbus as the communication protocol (the port also does BACnet and Metasys N2), then set node address, serial settings and run/frequency source at the keypad per the F510 manual.

Where is the official TECO-Westinghouse F510 HVAC fan/pump inverter (Modbus RTU/ASCII) Modbus documentation?
