Crompton Instruments Integra 1530 / 1560 / 1580 Modbus register map

Updated 19 November 2026

Short answer

The Integra 1530, 1560 and 1580 are Crompton Instruments panel digital meters. With the RS485 option they act as a Modbus RTU slave. Every value, readings and settings alike, is an IEEE-754 float in two registers: readings are input registers (function 04) and settings are holding registers (functions 03 and 16).

This page lists 83 Modbus registers for the Crompton Instruments Integra 1530 / 1560 / 1580 — 24 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Crompton Instruments’s own free documentation (linked below) and checked against it.

Integration notes: Crompton Instruments Integra 1530 / 1560 / 1580

Integration in brief

Read input registers with function 04 in two-register pairs; floats come high word first unless the Register Order setting was changed. Total power is at wire address 52 (30053), frequency at 70 and import energy at 72.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU exists only on meters built with the RS485 option. Settings marked password-protected need the password written to 40025 first; writing it again, or a power cycle, locks them again.

Byte order & addressing

  • Every value, settings included, is a two-register float; write settings with function 16.
  • Register Order (40041) is set by writing 2141.0 in the word order the meter should use from then on.
  • One request may cover at most 40 parameters; more returns an exception.

Network setup

  • Address range 1-247; broadcast address 0 is not supported.
  • Baud 2400, 4800, 9600 or 19200 with even, odd or no parity, chosen by the RS485 set-up code (40019).
  • Two-wire RS485 with 120 ohm termination at both ends of a line; up to 32 nodes and 1200 m.
  • Allow up to 150 ms for the meter to start replying.

Watch out for

  • An RS485 set-up code not in the table can leave the meter unreachable; the guide recommends the front panel or the Integra configurator for comms changes.
  • Demand Time and Energy Reset accept only 0; any other value returns an error.

Notes on this map

  • Source host: a copy served by Control Concepts (ccontrols.com), an integrator. TE Connectivity's document site refused automated requests and no public TE copy was found, so the unofficial flag is set.
  • Word order: the guide says floats go most significant register first by default (ABCD). Writing 2141.0 to Register Order (40041) using the other order switches the meter to low word first for all float traffic.
  • Volts 1 (parameter 1, wire address 0) has a blank row in the printed input table, so it is left out even though the numbering pattern implies it.
  • The energy registers (Wh, varh, VAh) carry no unit in the table; the set-up text calls the counters kWh and kvarh, so compare a reading with the front panel before scaling.
  • Phase rows return zero when the wiring system does not have that phase; the table marks which rows apply to 3-phase 4-wire, 3-phase 3-wire, 1-phase 3-wire and 1-phase 2-wire.
  • Left out: the analogue output 3 and 4 holding registers (40345 onward). Their printed register numbers and hex addresses disagree and several rows are duplicated. Outputs 3 and 4 exist on the 1560/1580 only.
  • Holding registers not in the table are reserved for the maker; do not write them.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Crompton Instruments Integra 1530 / 1560 / 1580

What Modbus registers does the Crompton Instruments Integra 1530 / 1560 / 1580 have?

This map lists 83 registers: 52 input registers, 31 holding registers. 24 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Crompton Instruments Integra 1530 / 1560 / 1580 Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print 30001/40001-style register numbers next to the hex start address used on the wire, e.g. Current 1 = 30007 = 0x0006 (the guide's own read example uses start 0006). Wire address = printed number minus 30001 or 40001, which also equals 2 x (parameter number - 1).

What byte order does the Crompton Instruments Integra 1530 / 1560 / 1580 use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Crompton Instruments Integra 1530 / 1560 / 1580?

Start with IR 6 Current 1 (Phase 1 current); IR 42 Volts Ave (Average phase voltage); IR 52 Watts Sum (Total active power); IR 62 Power Factor Ave (Average power factor); IR 70 Frequency (Frequency); IR 72 Wh Import (Imported active energy); HR 40 Register Order (Register order).

How do I enable Modbus control of the Crompton Instruments Integra 1530 / 1560 / 1580?

Modbus RTU exists only on meters built with the RS485 option. Settings marked password-protected need the password written to 40025 first; writing it again, or a power cycle, locks them again.

Where is the official Crompton Instruments Integra 1530 / 1560 / 1580 Modbus documentation?

The source is Crompton Integra 1530, 1560, 1580 Communications Guide (Integra Comms Issue 1), revision 2006-01. Crompton Instruments doesn't publish it on its own website, so this map was re-typed from a free copy at https://arccontrol.ccontrols.com/support/dp/Integra15xx.pdf. It may be an older revision, so check it against the live unit.
