VTS CO2-SENS-D-MODRTU Modbus register map

Updated 17 November 2026

Short answer

A duct-mounted CO2 transducer from VTS with a 0-5/0-10 V output and an RS-485 Modbus RTU interface. The measurement, sensor status and a fixed test value sit in the first three holding registers; configuration is done by writing a password, command and parameter into three registers. All registers are plain 16-bit values read with function 03.

This page lists 8 Modbus registers for the VTS CO2-SENS-D-MODRTU — 3 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from VTS’s own free documentation (linked below) and checked against it.

Integration notes: VTS CO2-SENS-D-MODRTU

Integration in brief

Read three holding registers from 0x0000 with function 03: CO2 in ppm, status, and the 1000 test value. Check status is 1 before trusting the reading.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

RegisterNameTypeWhyAccess
HR 0VALUE_REG (CO2 concentration)UINT16CO2 concentration in ppmRead
HR 1STATUS_REGUINT16Sensor status / warm-upRead
HR 2TEST_VAL_REGUINT16Fixed 1000 test value for comms checkRead
HR 11DEV_ID_REG (device identification)BITMAP16Device identificationRead

Enable Modbus control & writes

Modbus RTU is always active. To change settings write password 1234, command and parameter to 0x0003-0x0005 in one function 16 write, or write command and parameter first and the password last.

Byte order & addressing

  • An invalid or out-of-range parameter makes COMMAND_REG read 0xEEEE instead of executing.
  • Status reads 3 (warm up) for the first 3 minutes after power-on.

Network setup

  • Left DIP switch: switch 1 = 120 ohm termination, 2 = analogue range 0-5 V or 0-10 V, 3-4 = parity/stop bits or 'use software settings', 5-6 = baud 2400-19200.
  • Right DIP switch sets the address in binary (switch 1 = +1 ... switch 8 = +128).
  • DIP switch changes are read only at start-up: press RESET or cycle power after changing them.

Watch out for

  • The DIP switches only offer 2400-19200 baud; 38400-115200 can only be set through the command registers.

Notes on this map

  • All registers are 16-bit; there are no 32-bit values in this map.
  • Command parameters: 1 = address 1-247 (default 1); 2 = baud code 24/48/96/192/384/576/1152 for 2400-115200 bit/s (default 192 = 19200); 3 = parity 0 none (default), 1 even, 2 odd; 4 = stop bits 1 (default) or 2; 5 = ABClogic 0 off (default) / 1 on; 6 = 1 software reset of device, 2 reset of sensor module.
  • The defaults above are the software-configuration defaults from the command table. The DIP switches can override baud rate, parity and address; their factory positions are marked in bold in the manual and could not be confirmed from the text.
  • Reserved registers 0x0006-0x000A read 0 and are not listed. Reading any address not in the map returns exception 02.
  • The manual lists functions 03, 06 and 16 only; use function 03 (read holding registers) for all reads.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the VTS CO2-SENS-D-MODRTU

What Modbus registers does the VTS CO2-SENS-D-MODRTU have?

This map lists 8 registers: 8 holding registers. 3 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the VTS CO2-SENS-D-MODRTU Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register map lists addresses in hex from 0x0000, and the DEV_ID description gives 'addr=11=0x000B', so the printed value is the wire address.

What are the minimum Modbus registers to integrate the VTS CO2-SENS-D-MODRTU?

Start with HR 0 VALUE_REG (CO2 concentration) (CO2 concentration in ppm); HR 1 STATUS_REG (Sensor status / warm-up); HR 2 TEST_VAL_REG (Fixed 1000 test value for comms check); HR 11 DEV_ID_REG (device identification) (Device identification).

How do I enable Modbus control of the VTS CO2-SENS-D-MODRTU?

Modbus RTU is always active. To change settings write password 1234, command and parameter to 0x0003-0x0005 in one function 16 write, or write command and parameter first and the password last.
