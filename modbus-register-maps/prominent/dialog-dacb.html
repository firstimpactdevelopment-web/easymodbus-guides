Short answer

The diaLog DACb is ProMinent's multi-parameter measuring and control controller with up to three measuring and control channels plus a calculated (mathematic) channel. With the Modbus RTU option it is an RS-485 or RS-232 slave. This map covers the measured values, setpoints, status, warning and error words per channel, output states, device information, stop/pause commands, the per-channel control configuration (setpoints, limits, PID terms) and calibration values.

Integration notes: ProMinent DULCOMETER diaLog DACb multi-parameter controller (Modbus RTU)

Integration in brief

Read holding registers (function 03) from PDU 99: each channel block gives the measured value and setpoint as floats followed by status, warnings and the 32-bit error words. Check the endian test value at PDU 197 first. Writes use function 06 for single registers and 16 for floats.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the slave address, baud rate, serial format, interface mode and termination in SETUP > BUS configuration (access code needed). Bus control parameters are used when bit 15 of the channel configuration word is set.

Byte order & addressing

  • Register numbers are 1-based; subtract 1 for the PDU address.
  • 32-bit values are high word first (ABCD).
  • Byte-sized parameters use only the low 8 bits of the register; write the top 8 bits as 0.
  • If one register in a multi-register write raises an exception, the rest of that write is ignored.

Network setup

  • Factory settings: RS-485, slave address 1, 19200 baud, 8 data bits, odd parity, 1 stop bit; termination off.
  • Turn on active termination in the menu when the controller is the last device on the RS-485 line.
  • With no parity, 2 stop bits are required.

Watch out for

  • Keep responses short at low baud rates: the manual warns that replies over about 100 bytes at 9600 baud (200 at 19200) may be corrupted.
  • Read-only registers answer only to function 03.

Notes on this map

  • 32-bit values (FLOAT32 and UINT32) put bits 31-16 in the first register and bits 15-0 in the second, so the word order is ABCD; bytes are sent high byte first. Register 198 (PDU 197) always reads 0xAABBCCDD as a check.
  • Measured value, setpoint, limits and Xp are floats in whatever unit the channel is configured for (pH, mV, ppm and so on); the manual does not list units for them.
  • Left out: Pump relay 4 (register 139), because its printed PDU address (hex 90) does not match register 139 (which would be hex 8A); the identity-code registers 150-161, because their text encoding is not described; the math-channel error registers 130/131, which the manual marks as reserved for later use; and channel 1 'Additive basic load' (215), printed as UINT16 although its range is -100 to +100 % (channels 2 and 3 are INT16).
  • Channel 1 temperature is printed as INT16 and the other channels' temperature as UINT16; both are in 0.1 °C steps and are listed exactly as printed.
  • Configuration word bits 3-6 (channels 1 and 2 only, valid only when bit 15 = 1) hold the control type: 0 off, 1 manual, 2 P one-way increase, 3 P one-way decrease, 4 P two-way standard, 5 P two-way dead zone, 6 PID one-way increase, 7 PID one-way decrease, 8 PID two-way standard, 9 PID two-way dead zone.
  • Left out: registers 291 and 293, which the manual labels 'Slope Channel 1' and 'Zero point Channel 1' a second time (probably channel 3).
  • The text of section 1.7 calls the byte-order test register 'Register 199', but the register table prints it as register 198 (PDU hex C5); the table value is used here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the ProMinent DULCOMETER diaLog DACb multi-parameter controller (Modbus RTU)

What Modbus registers does the ProMinent DULCOMETER diaLog DACb multi-parameter controller (Modbus RTU) have?

This map lists 95 registers: 95 holding registers. 47 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ProMinent DULCOMETER diaLog DACb multi-parameter controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints a decimal 'Register' number plus the hex PDU address; the PDU address is the register minus 1 (register 100 is requested at PDU address 99, hex 63). The 'address' field here is the PDU address.

What byte order does the ProMinent DULCOMETER diaLog DACb multi-parameter controller (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ProMinent DULCOMETER diaLog DACb multi-parameter controller (Modbus RTU)?

Start with HR 99 Ch1 measured value (Channel 1 measured value); HR 103 Ch1 actual setpoint (Channel 1 setpoint); HR 106 Ch1 status (Channel 1 status); HR 108 Ch1 existing errors (Channel 1 existing errors); HR 112 Ch2 measured value (Channel 2 measured value); HR 197 Endian test value (Endian test (0xAABBCCDD)); HR 199 Ch1 stop (Channel 1 stop command).

How do I enable Modbus control of the ProMinent DULCOMETER diaLog DACb multi-parameter controller (Modbus RTU)?
