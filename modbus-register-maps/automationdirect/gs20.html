Short answer

The DURApulse GS20 and GS20X are AutomationDirect's compact and NEMA 4X general-purpose drives with a built-in RS-485 Modbus RTU/ASCII port. Control goes through command words at 2000h-2002h and status is read from 2100h upward; every parameter Pxx.yy is also a register. This map covers the command and status words, frequency, voltages, the main serial setup parameters and the block-transfer registers.

This page lists 34 Modbus registers for the AutomationDirect DURApulse GS20 / GS20X AC drive — 23 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from AutomationDirect’s own free documentation (linked below) and checked against it.

Integration notes: AutomationDirect DURApulse GS20 / GS20X AC drive

Integration in brief

Set the drive's run source and frequency source to RS-485, then write 2000h (run/stop/direction) and 2001h (frequency in 0.01 Hz) in one function-16 write. Poll 2100h-2106h for fault, state and frequency.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set P09.00 address and P09.04 protocol (codes 12-17 are RTU), then select RS-485 as the frequency reference (P00.20 = 1 in Remote/Auto or P00.30 = 1 in Local/Hand, per the manual's note) and as the run-command source (see chapter 4).

Communication loss & watchdog

P09.03 COM1 time-out detection (0.0-100.0 s, factory 0.0) sets the loss timeout; P09.02 selects warn, ramp-stop, coast-stop or no action on loss.

Byte order & addressing

  • Hex addresses are the wire addresses.
  • 2000h-2002h are write-only command words.
  • If the RS-485 frequency reference exceeds P01.00, the drive runs at maximum output frequency.

Network setup

  • Use P09.04 to pick RTU framing (e.g. 13 = 8N2 RTU); all nodes must match.

Watch out for

  • Block transfer registers P09.11-P09.26 let one read/write reach scattered parameters: write the target address (e.g. 8448 for 2100h) into a block-transfer slot.
  • Run command bits are a 2-bit code, not independent flags.

Notes on this map

  • AutomationDirect's own manual chapter (cdn.automationdirect.com).
  • Parameter-to-register rule: Pxx.yy is at hex xx*256 + yy (P09.00 = 0900h = 42305; the block-transfer example P02.22 = 0216h). Only selected P09 communication parameters are listed; the rest are in chapter 4.
  • Values printed as XXX.XX carry two implied decimals (scale 0.01) and XXX.X one (scale 0.1).
  • Left out: output current (2104h), whose decimal places shift with the current and depend on 211Fh; output torque (210Bh), because its sign handling is not stated; P09.01 baud rate, P09.03 time-out and P09.09 response delay, whose raw encodings of decimal values are not given in this chapter.
  • The P09.02-P09.04 rows of the summary table print the defaults out of line, so their factory defaults are not given here; the manual says P09.04 selects mode, data bits, parity and stop bits.
  • Up to 12 words can be read in one request (function 03).
  • Control word 1 (2000h): bits 1-0 = 01 stop, 10 run, 11 jog + run; bits 5-4 = 01 forward, 10 reverse, 11 change direction; bits 7-6 accel/decel set; bits 11-8 multi-step speed; bit 12 enables bits 6-11; bits 14-13 = 01 keypad, 10 per P00.21, 11 change operation source.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the AutomationDirect DURApulse GS20 / GS20X AC drive

What Modbus registers does the AutomationDirect DURApulse GS20 / GS20X AC drive have?

This map lists 34 registers: 34 holding registers. 23 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the AutomationDirect DURApulse GS20 / GS20X AC drive Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are listed in hex with the matching Modicon number (2000h = 48193, 2100h = 48449, 0900h = 42305). The hex value is the wire address; the manual's RTU examples send 21 02 to read 2102h and 20 00 to write 2000h.

What are the minimum Modbus registers to integrate the AutomationDirect DURApulse GS20 / GS20X AC drive?

Start with HR 8192 Control word 1 (Run/stop/direction command); HR 8193 Frequency command (Frequency command 0.01 Hz); HR 8448 Status monitor 1 (Warning/error code); HR 8449 Status monitor 2 (Drive state); HR 8451 Output frequency (Output frequency); HR 8453 DC bus voltage (DC bus voltage).

How do I enable Modbus control of the AutomationDirect DURApulse GS20 / GS20X AC drive?

Set P09.00 address and P09.04 protocol (codes 12-17 are RTU), then select RS-485 as the frequency reference (P00.20 = 1 in Remote/Auto or P00.30 = 1 in Local/Hand, per the manual's note) and as the run-command source (see chapter 4).

What happens when the AutomationDirect DURApulse GS20 / GS20X AC drive loses Modbus communication?

P09.03 COM1 time-out detection (0.0-100.0 s, factory 0.0) sets the loss timeout; P09.02 selects warn, ramp-stop, coast-stop or no action on loss.

Where is the official AutomationDirect DURApulse GS20 / GS20X AC drive Modbus documentation?

The source is DURApulse GS20 & GS20X Drive User Manual - Chapter 5: Serial Communications (GS20-M 1st Edition, Rev. F (chapter 5)), published free by AutomationDirect at https://cdn.automationdirect.com/static/manuals/gs20m/ch5.pdf.
