Short answer

The PR122DC and PR123DC are the DC versions of ABB's Emax trip units. With the PR120/D-M module they talk Modbus RTU: pole currents, DC voltage, power and energy are input registers, and commands such as open, close and trip reset are written to two holding registers. 32-bit values are sent low word first.

Integration notes: ABB SACE Emax DC PR122DC / PR123DC trip units with PR120/D-M (Modbus RTU)

Integration in brief

Read input registers 200-225 for currents, voltage, power and energy, and 101/107 for breaker state and trips. Open, close or reset with a function-16 write of command type and parameter to registers 0-1.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the PR120/D-M module and set the external bus address, baud and protocol on the trip unit. Remote mode (state 2 bit 9) is needed for open/close commands.

Byte order & addressing

  • 32-bit values are low word first.
  • Measures are input registers (function 4).
  • Commands always need function 16 with both registers.

Network setup

  • Set the external-bus address (1-247), baud (9600/19200), addressing type and frame format (E,8,1 / O,8,1 / N,8,2 / N,8,1) on the trip unit.

Watch out for

  • Slave ID register 700 tells PR122DC (0x59) from PR123DC (0x58).

Notes on this map

  • The document states 4-byte values are sent with the low word at the lower address (LOW-HIGH), bytes within a word high first, so 32-bit registers are CDAB.
  • External bus settings: 9600 or 19200 baud, address 1-247, Standard or ABB addressing, E,8,1 / O,8,1 / N,8,2 / N,8,1. The document does not state the external-bus factory values.
  • IB, IB_2, ground current, voltage, power and energy are PR123DC only.
  • Left out: state words other than 2 and 8, statistics, history, logger and parameter areas.
  • Over the external bus, commands are accepted only in Remote mode (state 2 bit 9).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ABB SACE Emax DC PR122DC / PR123DC trip units with PR120/D-M (Modbus RTU)

What Modbus registers does the ABB SACE Emax DC PR122DC / PR123DC trip units with PR120/D-M (Modbus RTU) have?

This map lists 18 registers: 16 input registers, 2 holding registers. 2 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB SACE Emax DC PR122DC / PR123DC trip units with PR120/D-M (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map gives relative addresses on 30001 (input registers, function 4) and 40001 (holding registers) bases; its example says run-time measures at offset 200 are 30201, relative address 200, which is the wire address with 'Standard' addressing.

What byte order does the ABB SACE Emax DC PR122DC / PR123DC trip units with PR120/D-M (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ABB SACE Emax DC PR122DC / PR123DC trip units with PR120/D-M (Modbus RTU)?

Start with IR 101 State 2 - flags (CB open/closed, tripped, remote); IR 107 State 8 - latched trips (Which protection tripped); IR 203 IA current (Pole A current); IR 217 DC voltage (DC voltage); IR 218 Total active power (Total active power); HR 0 Command type (Commands).

How do I enable Modbus control of the ABB SACE Emax DC PR122DC / PR123DC trip units with PR120/D-M (Modbus RTU)?

Fit the PR120/D-M module and set the external bus address, baud and protocol on the trip unit. Remote mode (state 2 bit 9) is needed for open/close commands.
