Lovato Electric ATL610 automatic transfer switch controller Modbus register map

Updated 19 November 2026

Short answer

The ATL610 is Lovato's two-line automatic transfer switch controller for mains/mains or mains/generator changeover. It speaks Modbus RTU, ASCII or TCP through its optical port or plug-in USB, RS-232, RS-485 and Ethernet modules. This map covers both lines' voltages and frequencies, battery voltage, run-time and operation counters, the 32-bit alarm word, line and breaker status words, controller status, and the mode, breaker, generator and reset commands.

This page lists 48 Modbus registers for the Lovato Electric ATL610 automatic transfer switch controller — 9 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lovato Electric’s own free documentation (linked below) and checked against it.

Integration notes: Lovato Electric ATL610 automatic transfer switch controller

Integration in brief

Read LINE 1/LINE 2 voltages (02h-18h), frequencies (1Ah/1Ch), the alarm word (40h) and the line, breaker and controller status words (2074h-207Ch) with function 04, subtracting one from each table address. Change mode by writing 0/1/2 to 2F00h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit an EXP1012 (RS-485) or EXP1013 (Ethernet) module, or use the optical port, then set menu M08 for that port: node address P08.n.01, speed .02, data format .03, stop bits .04, protocol .05 and, for Ethernet, IP address/mask/port .06-.08.

Byte order & addressing

  • Table addresses are one above the wire address.
  • 32-bit values are high word first.
  • Function 06 writes only to addresses above 1000h.

Network setup

  • Defaults: node 01, 9600 baud, 8 data bits, no parity, 1 stop bit, Modbus RTU.
  • Ethernet module defaults: IP 192.168.1.1, IP port 1001 (not 502), server mode.
  • Two communication ports can be configured (n = 1 or 2).
  • Maximum data field is 80 registers.

Watch out for

  • The Modbus TCP port defaults to 1001, so set the master accordingly or change P08.n.08.

Notes on this map

  • Measures and status words are read with function 03 or 04 (same data) and are listed as input registers. Commands are written with function 06; function 06 only works on addresses above 1000h.
  • Word order: the RTU example returns 00 00 00 07 for 7 switching alarms, so the high word comes first (ABCD).
  • Units as printed: voltages in whole volts, frequency Hz/10, battery VDC/10, times in seconds.
  • The ASCII example in the document calls the register at 0Ch an 'L3 current', which does not match the ATL610 table (0Ch is LINE 1 L3-L1 voltage); the label looks copied from another product. Its frame (00 0B for 0Ch) still follows the minus-one rule.
  • Left out: minimum/maximum battery voltage (printed in V while the live value is VDC/10), maintenance hours and operations-to-maintenance (unit 'nr' with no clear meaning), generic counters CNT1-4 and LIM bits (user-defined), the 2-word device global status at 2210h ('Unsigned integer' over 2 words), and the real-time clock registers.
  • Left out because the document contradicts itself: digital outputs status (table says 2140h, bit legend says 2072h) and input functions status (table says 2078h with 2 words, legend says 2178h). The two 'Frontal LED status' words 207Eh/207Fh have no bit legend.
  • Remote variables REM1-REM8 are at 4F00h-4F07h (only REM1 and REM2 listed): write AAh to set, BBh to clear.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lovato Electric ATL610 automatic transfer switch controller

What Modbus registers does the Lovato Electric ATL610 automatic transfer switch controller have?

This map lists 48 registers: 39 input registers, 9 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lovato Electric ATL610 automatic transfer switch controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables print hex addresses one higher than the address in the request; the document says the query address must be decreased by one, its RTU example reads breaker 1 switching alarms (table 3Ah) by sending 00 39, and the event-log examples show 5030h - 1 = 502Fh. Addresses here are already reduced by one.

What byte order does the Lovato Electric ATL610 automatic transfer switch controller use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lovato Electric ATL610 automatic transfer switch controller?

Start with IR 7 LINE 1 voltage L1-L2 (LINE 1 L1-L2 voltage); IR 19 LINE 2 voltage L1-L2 (LINE 2 L1-L2 voltage); IR 63 Alarms (Alarm bits); IR 8307 LINE 1 voltage status (LINE 1 voltage status); IR 8308 LINE 1 breaker status (LINE 1 breaker status); IR 8315 Controller general status (Controller mode and global alarm); HR 12031 Operating mode change (Mode change OFF/MAN/AUT).

How do I enable Modbus control of the Lovato Electric ATL610 automatic transfer switch controller?

Fit an EXP1012 (RS-485) or EXP1013 (Ethernet) module, or use the optical port, then set menu M08 for that port: node address P08.n.01, speed .02, data format .03, stop bits .04, protocol .05 and, for Ethernet, IP address/mask/port .06-.08.

Where is the official Lovato Electric ATL610 automatic transfer switch controller Modbus documentation?
