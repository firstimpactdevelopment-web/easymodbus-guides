Short answer

Vapor-logic 5 is the previous-generation DriSteem humidifier controller (electric, GTS gas, XT electrode, STS steam-to-steam and high-pressure systems). Modbus RTU is standard. Its point list is close to Vapor-logic 6 but not identical: input registers for humidity, dew point, demand and output, holding registers for run mode, set points, fieldbus demand and PID, discrete inputs that also report the fill and drain valves, and coils for every alarm and message.

This page lists 107 Modbus registers for the DriSteem Vapor-logic 5 humidifier controller (Modbus RTU) — 72 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from DriSteem’s own free documentation (linked below) and checked against it.

Integration notes: DriSteem Vapor-logic 5 humidifier controller (Modbus RTU)

Integration in brief

Enable Modbus in the Communications setup and poll input registers 0-10 for humidity, demand and output. To command the unit write Run_mode (40001) and a set point (40002) or fieldbus demand (40006).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Setup menu > Communications > Modbus: Modbus enabled = Yes, Modbus address (default 99) and baud rate (default 9600).

Byte order & addressing

  • Printed numbers are Modicon-style: subtract one for the wire address.
  • Units switch between I-P and SI with the unit setting; there are no decimal places.

Network setup

  • Wire the RS-485 bus to terminal P7 on the Vapor-logic board (+ to +, - to -), set address and baud in Setup > Communications, then cycle power.

Watch out for

  • The map differs from Vapor-logic 6 (e.g. DI-8/DI-9 report fill and drain valves here); use the list matching the controller version.

Notes on this map

  • The PDF sits on the CloudFront host that holds DriSteem public documents (historical-literature folder); the document is the DriSteem IOM.
  • Note 1 of the table states 16-bit input and holding registers and single-bit discrete inputs and coils; its stated ranges (IR1-IR11, HR1-HR10, DI1-DI9, DV1-DV50) are narrower than the rows actually listed, and all listed rows are included.
  • No scale is printed, so values are whole numbers in the units shown, except Water_until_ADS / Water_until_service, which the table gives in units of 100 lbs or 100 kg.
  • Units follow the controller's I-P or SI setting. Temperatures are typed INT16 because their ranges go below zero; signedness is not stated.
  • The set points HR-2 to HR-4 are marked Write in this version (they are RW in Vapor-logic 6).
  • The description column prints 'Reserved' beside coils DV-1 / DV-2.
  • Several numbers carry different meanings on GTS, XT, STS and high-pressure (HPS) systems; both meanings are given.
  • Serial framing (parity, data and stop bits) is not stated in the manual.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the DriSteem Vapor-logic 5 humidifier controller (Modbus RTU)

What Modbus registers does the DriSteem Vapor-logic 5 humidifier controller (Modbus RTU) have?

This map lists 107 registers: 60 coils, 15 discrete inputs, 17 input registers, 15 holding registers. 72 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the DriSteem Vapor-logic 5 humidifier controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Points are printed as IR-1 / 30001, HR-1 / 40001, DI-1 / 10001 and coil DV-1 / 1. These are one-based Modicon numbers: subtract one for the wire address (30001 -> input register 0, coil 1 -> coil 0).

What are the minimum Modbus registers to integrate the DriSteem Vapor-logic 5 humidifier controller (Modbus RTU)?

Start with IR 0 Space_RH (Space RH); IR 8 Steam_output_percent (Steam output %); IR 4 Steam_demand_percent (Steam demand %); HR 0 Run_mode (Run mode); HR 1 Space_RH_set_point (Space RH set point); HR 5 Fieldbus_demand_% (Fieldbus demand %); CO 2 Active_manually_cleared_alarms_exist (Manually cleared alarms exist); CO 3 Clear_all_faults (Clear all faults).

How do I enable Modbus control of the DriSteem Vapor-logic 5 humidifier controller (Modbus RTU)?

Setup menu > Communications > Modbus: Modbus enabled = Yes, Modbus address (default 99) and baud rate (default 9600).
