Short answer

The Neptronic SKG4 is a gas-fired steam humidifier built from up to four burner modules. Its Modbus RTU module exposes holding registers only: signal voltages, room and supply RH, per-module chimney, water and ambient temperatures, fan feedback, demand and maximum output, PID and boiler settings, per-module inputs and valve states as 0/1 registers, and module state, request and alarm codes.

Integration notes: Neptronic SKG4 gas-fired steam humidifier (Modbus communication module)

Integration in brief

Read Room RH (6005), Humidity Demand (6054), System Power Output (6055) and each module's State and Alarm (15015-15026). For BAS control set Control Profile (15004) and Demand Source (15011) to network options and write Humidity Control Network Demand (6052) within the Network Timeout.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Modbus communication module, set the address in the device menu (or register 0) and pick network profile and sources (15004-15012) if the BAS supplies readings or demand.

Communication loss & watchdog

Network Timeout (6158, 1-900 s, default 900 s): network-supplied values must be refreshed within this time; Network Control State (12051) shows a fault.

Byte order & addressing

  • All points, binary ones included, are holding registers (FC03/06/16 only).
  • Default framing is no parity with 2 stop bits.

Network setup

  • RS-485 two-wire, RTU; 9600-57600 baud or auto baud detection.
  • Parity/stop bits via register 2 or the Modbus Comport Config menu item.

Watch out for

  • Module 2-4 registers only respond meaningfully on units with that many burner modules.
  • System Mode (15034) chooses parallel, sequential or hybrid staging of modules.

Notes on this map

  • Only function codes 03, 06 and 16 are supported, so binary points (inputs, relays, flags) are 16-bit holding registers holding 0 or 1.
  • 'Scale N' with 'Value x N' means the raw value is the engineering value times N; this map stores the multiplier 1/N.
  • Temperature and capacity units follow Modbus Server Units (415001): 0 metric, 1 imperial.
  • The guide text calls automatic baud detection the default, while register 1 lists 19200 as its default value; the baud default is left blank here.
  • Default unit address is not stated; it is set from the device menu or register 0.
  • Left out: product name ASCII registers 3-6; Room RH Bias 6008 (a bias printed with a 0-100 % range and 100 % default); module water levels 6018/6023/6028/6033 (Scale 10 but 'Value x 100' example); Boiler Idle Temperature Setpoint 6155 (scale and example disagree); Humidity Demand Low Dead Band 6162-6163 and the ignition counters 6164-6179, and all run/on/service time and calibration counters, which span two or four registers with no stated word order.
  • Module 1-4 Drain Valve (12056-12059) are printed with 0 = On, 1 = Off, the reverse of the other valve points; copied as printed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Neptronic SKG4 gas-fired steam humidifier (Modbus communication module)

What Modbus registers does the Neptronic SKG4 gas-fired steam humidifier (Modbus communication module) have?

This map lists 245 registers: 245 holding registers. 87 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Neptronic SKG4 gas-fired steam humidifier (Modbus communication module) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints a protocol-base (0-based) address and a six-digit holding register (base 400001) side by side, e.g. 6005 / 406006. The protocol-base number is the wire address.

What are the minimum Modbus registers to integrate the Neptronic SKG4 gas-fired steam humidifier (Modbus communication module)?

Start with HR 6005 Room RH (Room RH); HR 6039 Room RH Setpoint (Room RH set point); HR 6054 Humidity Demand (Humidity demand); HR 6055 System Power Output (System power output); HR 15015 Module 1 State (Module 1 state); HR 15017 Module 1 Alarm (Module 1 alarm); HR 15014 System Power State (System on/off); HR 6052 Humidity Control Network Demand (Network demand).

How do I enable Modbus control of the Neptronic SKG4 gas-fired steam humidifier (Modbus communication module)?

Fit the Modbus communication module, set the address in the device menu (or register 0) and pick network profile and sources (15004-15012) if the BAS supplies readings or demand.

What happens when the Neptronic SKG4 gas-fired steam humidifier (Modbus communication module) loses Modbus communication?

Network Timeout (6158, 1-900 s, default 900 s): network-supplied values must be refreshed within this time; Network Control State (12051) shows a fault.
