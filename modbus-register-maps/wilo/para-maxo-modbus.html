Wilo Para MAXO (built-in Modbus RTU) Modbus register map

Updated 16 October 2026

Short answer

The Wilo Para MAXO is a high-efficiency OEM circulator (used inside boilers and heat pumps) with Modbus RTU on its signal cable. A master switches the pump on/off, picks constant speed or constant/variable differential pressure, and writes a relative duty point in 0.5 % steps; a bus command timer can drop the pump to preset fallback values on comm loss. Read-only data covers pressure, calculated flow, power, energy, run hours, speed, status bits and the Wilo error code.

This page lists 28 Modbus registers for the Wilo Para MAXO (built-in Modbus RTU) — 10 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Wilo’s own free documentation (linked below) and checked against it.

Integration notes: Wilo Para MAXO (built-in Modbus RTU)

Integration in brief

Talk to address 101 at 19200 8E1 by default. Write H 42 (control mode), then H 1 (duty point, 200 = 100 %) and H 40 = 1 to run; read I 200/I 400 for set and actual duty point, I 1/I 2/I 4 for pressure, flow and power, and I 404/I 940 for status and errors.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step is documented: the pump accepts Modbus writes directly. Use Bus Command Timer (H 300) = MANUAL to allow both local and bus operation (last write wins).

Communication loss & watchdog

Fallback emulation (guide p. 23): set H 400 (20-65534 s, default 300 s), the fallback on/off H 404 and the fallback duty point H 402, then write H 300 = 6 (SET_PRESET) and keep rewriting it before the timeout. If it lapses the pump runs on the preset values. The fallback control mode register H 403 is not listed here because Wilo's documents give conflicting codes for it.

Byte order & addressing

  • Register numbers are already wire addresses (0-based); do not subtract 1.
  • Duty point is in 0.5 % steps: 200 = 100 % of the mode's reference (max head or max speed from I 206).
  • After changing the control mode (H 42), write H 1 = 0 first and then the new duty point so the active duty point refreshes.
  • Writes below the minimum output (I 204) are clamped to it.
  • Input register I 402 (Pump Command active) shows bit 3 as a static 1 described as needed 'for write access', while the guide's examples write H 40 = 1 (bit 0 only). Follow the guide's values and confirm with I 402.

Network setup

  • Signal cable: core 1 (brown) = Data+ / D1 / B(+), core 3 (black) = Data- / D0 / A(-), core 2 (blue/grey) = common.
  • Terminate both bus ends with 120-150 ohm; no line polarization is needed on the Wilo side.
  • Change address, baud and frame via H 61440, H 61441 and H 61442 (default 101, 19200, 8E1).

Watch out for

  • Wilo numbers registers from zero, unlike the usual 1-based Modbus register numbering; a tool that adds or subtracts 1 will hit the wrong register.
  • Calculated flow is an estimate; do not use it for closed-loop control.

Notes on this map

  • The register list is Wilo's public HTML datapoint list (Wilo's media CDN, reached from the short link qr.wilo.com/para-maxo-Modbus-registers printed in Wilo's own guide). Addressing, communication defaults (address 101, 19200 baud, 8E1), the duty-point worked examples and the fallback procedure come from Wilo's 'OEM Technical guide Wilo-Para MAXO Modbus Communication Protocol' V01.01 (2025-02-13), https://cms.media.wilo.com/cdndoc/wilo698135/9854564/wilo698135.pdf, pp. 5, 8, 11, 17-25. That PDF carries a notice that it is Wilo property and may not be copied or extracted without Wilo's written acceptance; only re-keyed facts are used here and the PDF is linked, not re-hosted.
  • Scale: physical value = raw x scale as listed in the datapoint list (e.g. Pressure raw x 10 = cm H2O, Operation Time raw x 10 = h, Flow raw x 0.1 = m³/h, duty point raw x 0.5 = %).
  • Duty point is relative: the engineering value at 100 % is published in input register 206 ('duty point 100 % value', a 32-bit REAL). Head or speed = duty point % x that value / 100.
  • Left out because the 32-bit word order is not stated: duty point 100 % value (I 206, REAL), Heartbeat Count (I 500, UDINT), Vendor ID (I 702, DWORD) and parameter block acknowledge (61694, DWORD).
  • Flow error value: the datapoint list gives 9999, the technical guide's warning cites 65535; treat both as invalid.
  • Removed where Wilo's documents disagree: Bus Command Timer Time remain (I 504: UINT, scale 1 in the datapoint list but UDINT, scale 2 in the guide); Application Version (I 700: WORD in the guide and older list, UDINT in the current list); Control Function preset (H 403: the list codes the modes 1/3/4 but the guide's fallback section codes them 1/2/3). Flow min-pres-value (I 25) is left out because the current list's support reference does not include Para MAXO.
  • Speed (I 7) is INT in the current datapoint list and UINT in the guide and the older list; it is typed INT16 here. Real pump speeds are far below 32768 rpm, so both readings agree.
  • The control-mode lists (H 42, I 10) also include 140 = Gen_UsrDfd for Para MAXO in the current datapoint list; the guide only describes 1, 3 and 4.

Questions about the Wilo Para MAXO (built-in Modbus RTU)

What Modbus registers does the Wilo Para MAXO (built-in Modbus RTU) have?

This map lists 28 registers: 18 input registers, 10 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Wilo Para MAXO (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Wilo register numbers start at zero and equal the request address (Wilo's Para MAXO Modbus technical guide states this explicitly), so Flow 'I 2' is input register address 2 on the wire.

What are the minimum Modbus registers to integrate the Wilo Para MAXO (built-in Modbus RTU)?

Start with HR 40 Pump Command in (Pump on/off); HR 42 Control Function (Control mode); HR 1 duty point (rel.) (Duty point (setpoint), 0.5 % steps); IR 404 Operation Status (Operation status bits); IR 940 Warning/Error Message (Wilo error code); IR 4 power input (Electrical power); IR 7 Speed (Speed); IR 2 Flow (calculated) (Calculated flow).

How do I enable Modbus control of the Wilo Para MAXO (built-in Modbus RTU)?

No enable step is documented: the pump accepts Modbus writes directly. Use Bus Command Timer (H 300) = MANUAL to allow both local and bus operation (last write wins).

What happens when the Wilo Para MAXO (built-in Modbus RTU) loses Modbus communication?

Fallback emulation (guide p. 23): set H 400 (20-65534 s, default 300 s), the fallback on/off H 404 and the fallback duty point H 402, then write H 300 = 6 (SET_PRESET) and keep rewriting it before the timeout. If it lapses the pump runs on the preset values. The fallback control mode register H 403 is not listed here because Wilo's documents give conflicting codes for it.
