Short answer

The AEGIS II is a ProMinent DULCOMETER controller. Its COM module, fitted in module slot 3, adds a read-only Modbus RTU slave port on RS-485. Every 32-bit value is published twice, once low word first and once high word first; this map uses the high-word-first copy (registers 901-1123) and covers the input readings A-Z, relay and pulse outputs, alarm levels, totalisers, on/off setpoints and the input, output and system state words.

This page lists 124 Modbus registers for the ProMinent DULCOMETER AEGIS II controller (Modbus RTU slave) — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ProMinent’s own free documentation (linked below) and checked against it.

Integration notes: ProMinent DULCOMETER AEGIS II controller (Modbus RTU slave)

Integration in brief

Poll holding registers (function 03) in the 901-1123 block, at most once per second. Inputs A-N are the sensor readings as high-word-first floats; the state words tell you whether each input and output is enabled, alarmed or interlocked.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the COM module in module slot 3 and set the slave address, baud rate and parity at MENU > System > Communications. Connect the master to XB21/XB22 (the XB1 port is the module's own master port for a Pyxis ST-500 probe).

Byte order & addressing

  • Two copies of every value: 501-723 low word first, 901-1123 high word first. Pick one and stay with it.
  • Register numbers are 1-based; subtract 1 for the PDU address.
  • Read-only: function 03 only.

Network setup

  • Defaults: slave address 10, 19200 baud, 8 data bits, even parity, 1 stop bit.
  • Termination for the slave port is set with jumper XT2 on the COM module.
  • With no parity, 2 stop bits are required.

Watch out for

  • Poll no faster than once per second.
  • Disabled inputs, alarms and outputs read 0 rather than an error.

Notes on this map

  • The manual publishes each 32-bit value twice: registers 501-723 carry bits 15-0 in the first register (low word first, CDAB) and registers 901-1123 carry bits 31-16 first (ABCD). Only the ABCD copy is listed; the CDAB copy is the same layout 400 registers lower.
  • 16-bit state registers for inputs A-Z also appear in both blocks (679-704 and 1079-1104).
  • All values are read-only; any write, or a read of an unlisted register, returns an exception. The manual asks for no more than one query per second.
  • Readings are floats in the user units configured for each input; the manual gives no units.
  • Left out: the P7 control-state row, whose printed PDU address (1110) clashes with R4 while its register is 1117; PDU 1116 is likely but not stated.
  • Inputs K-N, W-Z and the 'phantom' values depend on the AEGIS II configuration and plug-in modules.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ProMinent DULCOMETER AEGIS II controller (Modbus RTU slave)

What Modbus registers does the ProMinent DULCOMETER AEGIS II controller (Modbus RTU slave) have?

This map lists 124 registers: 124 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ProMinent DULCOMETER AEGIS II controller (Modbus RTU slave) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row gives a decimal 'Register' and its PDU address; the PDU address is the register minus 1 (ProMinent register 100 is fetched at PDU 99). Here 'address' is the PDU address, e.g. input A in the high-word-first block is register 901, PDU 900.

What byte order does the ProMinent DULCOMETER AEGIS II controller (Modbus RTU slave) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ProMinent DULCOMETER AEGIS II controller (Modbus RTU slave)?

Start with HR 900 A - Serial sensor 1 value (Input A (serial sensor 1)); HR 904 C - Module slot 1 value 1 (Input C (module slot 1 value 1)); HR 912 G - 4-20 mA input value (Input G (4-20 mA input)); HR 1078 A - State (Input A state); HR 1104 R1 - Control state (R1 control state); HR 1122 System state (System state).

How do I enable Modbus control of the ProMinent DULCOMETER AEGIS II controller (Modbus RTU slave)?

Fit the COM module in module slot 3 and set the slave address, baud rate and parity at MENU > System > Communications. Connect the master to XB21/XB22 (the XB1 port is the module's own master port for a Pyxis ST-500 probe).
