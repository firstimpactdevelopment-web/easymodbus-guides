Short answer

ICP DAS tM modules are small DIN-rail RS-485 I/O modules that speak DCON or Modbus RTU. The DIO models covered here give digital outputs as coils, digital inputs as discrete inputs, 16-bit input counters, latch bits and module settings. Only the channels a model actually has respond.

Integration notes: ICP DAS tM series digital I/O modules tM-P4C4, tM-C8, tM-P8 (Modbus RTU)

Integration in brief

Switch the module to Modbus RTU, then read inputs with function 02 from wire 32 and drive outputs with function 05 at wire 0-7. Counters are on function 04 from wire 0.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Factory default is already Modbus RTU, address 1, 9600 bps. Coil 00257 switches between DCON and Modbus; address and baud changes are made with the DCON utility or function 70.

Communication loss & watchdog

Host watchdog: enable with coil 00261, timeout 0-255 x 0.1 s in 40489. On timeout the outputs go to their safe values (00129-00136); clear the timeout status with coil 00270.

Byte order & addressing

  • No function 06/16: use 05/15 for coils; settings registers are read only over standard Modbus.
  • Inputs can be read as coils (00033+) or discrete inputs (10033+).

Network setup

  • Address 1-247 and baud/parity are module settings (40485/40486); use the DCON utility, function 70 or INIT mode to change them.
  • RS-485.

Watch out for

  • Each model accepts only the channel addresses listed for it in the function-code sections.
  • Counters are 16-bit with a maximum of 65535.
  • After a host watchdog timeout the outputs hold their safe values and ignore DO writes until the timeout status (coil 00270) is cleared; the status survives a power cycle.

Notes on this map

  • Channels are listed 0-7. tM-P4C4 has DO0-DO3 and DI0-DI3, tM-C8 has DO0-DO7 only, tM-P8 has DI0-DI7 only; each function-code section lists only the channel addresses valid for each model.
  • Supported function codes are 01, 02, 03, 04, 05, 15 and 70 (module settings). There is no 06 or 16, so the holding registers 40485-40492, although marked R/W in the table, cannot be written with standard Modbus writes; they are listed as read only. Change settings with the DCON utility or function 70.
  • Counters are 16-bit (maximum 65535) and can be read with function 03 or 04.
  • DI latch values are listed as coils (00065-00072 high, 00097-00104 low) because function 01 accepts 0x0040/0x0060 while function 02 accepts only 0x0020-0x003F; the table's 10065/10097 copies are not listed. Latched DO values (00073-00080, 00105-00112) are left out.
  • Firmware version and module name (40481-40484, low word first) are left out because their encoding is not described.
  • In INIT mode (INIT switch) the module starts at address 00, 9600 bps, DCON protocol, for recovery.
  • The address table marks the safe-value, power-on-value and settings coils R/W, but the function 05/15 sections list only the DO channels, 0x0107 and 0x0200+ as valid outputs. If a write to a settings coil is refused, use the DCON utility or function 70.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ICP DAS tM series digital I/O modules tM-P4C4, tM-C8, tM-P8 (Modbus RTU)

What Modbus registers does the ICP DAS tM series digital I/O modules tM-P4C4, tM-C8, tM-P8 (Modbus RTU) have?

This map lists 94 registers: 65 coils, 8 discrete inputs, 8 input registers, 13 holding registers. 40 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ICP DAS tM series digital I/O modules tM-P4C4, tM-C8, tM-P8 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The address table uses Modicon numbers (00001, 10033, 30001, 40481). The function-code sections give the matching wire addresses: DO readback starts at 0x0000 (00001), DI at 0x0020 (00033/10033), latch clear at 0x0107 (00264) and counter clear at 0x0200 (00513). Subtract 1 from the 5-digit number.

What are the minimum Modbus registers to integrate the ICP DAS tM series digital I/O modules tM-P4C4, tM-C8, tM-P8 (Modbus RTU)?

Start with CO 0 DO0 output (DO0 output); DI 32 DI0 input (DI0 input); IR 0 DI0 counter (DI0 counter); CO 512 Clear DI0 counter (Clear DI0 counter); CO 260 Host watchdog enable (Host watchdog enable); CO 269 Host watchdog timeout status (Host watchdog timeout status).

How do I enable Modbus control of the ICP DAS tM series digital I/O modules tM-P4C4, tM-C8, tM-P8 (Modbus RTU)?

Factory default is already Modbus RTU, address 1, 9600 bps. Coil 00257 switches between DCON and Modbus; address and baud changes are made with the DCON utility or function 70.

What happens when the ICP DAS tM series digital I/O modules tM-P4C4, tM-C8, tM-P8 (Modbus RTU) loses Modbus communication?

Host watchdog: enable with coil 00261, timeout 0-255 x 0.1 s in 40489. On timeout the outputs go to their safe values (00129-00136); clear the timeout status with coil 00270.
