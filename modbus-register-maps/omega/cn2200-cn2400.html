Short answer

The CN2200 and CN2400 are Omega panel-mount PID temperature and process controllers. Every parameter has a 16-bit Modbus address, and a second 'IEEE region' gives the same parameter as a full-resolution 32-bit float. This map lists the loop values in the IEEE region (so no decimal-point scaling is needed) and the mode selectors and status words as plain 16-bit registers.

Integration notes: Omega CN2200 / CN2400 series temperature and process controllers (Modbus RTU)

Integration in brief

Read PV, target setpoint and output as one 6-register block from 8002h (function 03), decode as ABCD floats, and write a new setpoint with function 16 to 8004h. Use 273 for auto/manual and 74 for alarm and sensor-break flags.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Comms hardware must be fitted: on the CN2400 the plug-in H module sets RS-232/422/485, while CN2200 comms is fixed when ordered. Set the slave address with Addr in the Cms list.

Byte order & addressing

  • Two address spaces: plain 16-bit (scaled by display resolution) and IEEE floats at 2 x address + 8000h.
  • Function 06 is refused in the IEEE region; use function 16.

Network setup

  • Set the address in the Cms list (1-254) and match baud/parity on the master.
  • RTU only, 8 data bits, 1 stop bit.

Watch out for

  • Reading an unconfigured parameter returns an undefined value, not an exception.
  • The handbook's manual-mode example selects manual (273 = 1) before changing output power at 3.
  • Keep reads to 32 words on a CN2200 (125 on a CN2400).

Notes on this map

  • Float parameters (PV, setpoints, output, alarm setpoints) are listed only in the IEEE region. In the normal 16-bit region their scaling depends on the controller's integer/full-resolution setting and the display decimal point, which the master must know, so those 16-bit forms are left out.
  • IEEE floats are sent with bits 31-24 first in the lower address (example 1.001 = 3F 80 20 C5), i.e. ABCD. Both words must be read or written in one request.
  • The IEEE region only accepts function 03/04 reads and function 16 writes; function 06 is rejected there. Start IEEE reads at even addresses.
  • Summary output status word (75): bit 8 is Tune active on CN2400 but Load fail on CN2200; bit 11 is DC control module fault on CN2400 but SSR fail on CN2200; bit 12 is programmer segment sync on CN2400 but New alarm on CN2200; bit 14 is IP1 fault on CN2400 and reserved on CN2200. Only the common bits are listed.
  • Configuration parameters are read only unless the controller is in configuration mode. A function 06 write to a read-only or unconfigured parameter is rejected, but a function 16 block whose only value lands on an unconfigured address looks successful and the value is discarded.
  • The slave address (1-254) is the Addr parameter in the Cms list. Parity can be None, Odd or Even and every unit uses 1 stop bit; the handbook gives no factory defaults and only RTU mode is supported.
  • Alarm hysteresis, PID times and other parameters are documented in the handbook but not listed; use address x 2 + 8000h to read any of them as a float.
  • One read can return at most 125 words on a CN2400 and 32 words on a CN2200.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Omega CN2200 / CN2400 series temperature and process controllers (Modbus RTU)

What Modbus registers does the Omega CN2200 / CN2400 series temperature and process controllers (Modbus RTU) have?

This map lists 29 registers: 29 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Omega CN2200 / CN2400 series temperature and process controllers (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The handbook's addresses go on the wire as printed: its example reads PV and setpoint starting at address 0001. For the float form of any parameter use address x 2 + 8000h, e.g. target setpoint 2 -> 8004h (32772).

What byte order does the Omega CN2200 / CN2400 series temperature and process controllers (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Omega CN2200 / CN2400 series temperature and process controllers (Modbus RTU)?

Start with HR 32770 Process variable (Process variable (float)); HR 32772 Target setpoint (Target setpoint (float, write with FC16)); HR 32774 Output power (Output power (float)); HR 32778 Working setpoint (Working setpoint (float, read only)); HR 273 Auto/manual select (Auto/manual); HR 74 Fast status byte (Alarm and sensor-break flags).

How do I enable Modbus control of the Omega CN2200 / CN2400 series temperature and process controllers (Modbus RTU)?

Comms hardware must be fitted: on the CN2400 the plug-in H module sets RS-232/422/485, while CN2200 comms is fixed when ordered. Set the slave address with Addr in the Cms list.

Where is the official Omega CN2200 / CN2400 series temperature and process controllers (Modbus RTU) Modbus documentation?

The source is Series CN2200 and CN2400 Modbus and Digital Communications Handbook, published free by Omega at https://assets.dwyeromega.com/manuals/M3372.pdf.
