Short answer

The Lovato VT1 is an AC drive whose RS-485 port supports Modbus RTU/ASCII and BACnet MS/TP. Over Modbus a master writes a command word and frequency reference and reads a block of monitor registers. This map covers the command word, frequency command, status and fault code, terminal status, output frequency, voltage, current, power, PID values, analog inputs and drive temperature.

This page lists 17 Modbus registers for the Lovato Electric VT1 series variable speed drives (Modbus RTU / ASCII) — 2 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lovato Electric’s own free documentation (linked below) and checked against it.

Integration notes: Lovato Electric VT1 series variable speed drives (Modbus RTU / ASCII)

Integration in brief

Write the frequency reference (wire 0x2502) and set bit 0 of the command word (wire 0x2501) to run; a single function 16 write of two registers at 0x2501 does both. Read status, fault code and output values from the block starting at wire 0x2520.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Wire the drive's RS-485 port and select Modbus RTU or ASCII, the slave address and the run/frequency command source on the drive keypad; those parameter numbers are in the VT1 instruction manual, not in this protocol document.

Communication loss & watchdog

A lost connection shows Err6 on the drive; the reaction to an external abnormality written via command bit 2 follows parameter 07-09.

Byte order & addressing

  • Table addresses are one above the wire address.
  • Exception codes are 51h-55h, not the usual 01h-04h.
  • Reads and block writes may not cross register groups.

Network setup

  • Set slave address, baud rate and data format on the drive before connecting; the protocol document does not list defaults.
  • Maximum frame length is 80 bytes.
  • Terminate each end of the RS-485 line with a 120 ohm resistor.

Watch out for

  • Do not write to the reserved word at table 2501H (wire 0x2500).

Notes on this map

  • All registers are 16-bit holding registers: read with 03, write with 06 or 16. Reads and multi-writes must stay within one register group; at most 37 registers per RTU read and 35 per RTU write.
  • Offset: the doc has no wording on it, but its three example frames all send the table number minus one (see addressing note), so that rule is applied to every register.
  • Scales as printed: frequencies 100 = 1 Hz, voltage 10 = 1 V, current 10 = 1 A, power 10 = 1 kW, PID 10 = 1 %, temperature 10 = 1 °C, AVI/ACI 1000 = 10 V.
  • Left out: the drive parameters. The manual says parameter gg-nn sits at register GGnnH (e.g. 08-03 at 0803H) but gives no example frame for it, so it is not clear whether that number also needs the minus-one shift.
  • The AVI and ACI rows carry a footnote mark (*1) whose text is not printed in the document; check the analog scaling against the drive display.
  • Write 0 to unused bits of the command word and never write to the reserved register 2501H (table numbering).
  • Error responses carry codes 51h-55h (function, address, data amount, data range, writing mode) rather than the standard 01-04.
  • Bit 2 of the command word is not a fault flag: setting it tells the drive about an external abnormality and makes it stop as set in 07-09 and show EFO; otherwise a communication loss shows Err6.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lovato Electric VT1 series variable speed drives (Modbus RTU / ASCII)

What Modbus registers does the Lovato Electric VT1 series variable speed drives (Modbus RTU / ASCII) have?

This map lists 17 registers: 17 holding registers. 2 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lovato Electric VT1 series variable speed drives (Modbus RTU / ASCII) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register tables print hex numbers one above the wire address, as all three example frames show: reading the frequency command (table 2524H) sends 25 23; writing 60.0 Hz to the frequency command (table 2503H) sends 25 02; a two-register write of run command + frequency (table 2502H-2503H) starts at 25 01. Addresses here are the table value minus one.

What are the minimum Modbus registers to integrate the Lovato Electric VT1 series variable speed drives (Modbus RTU / ASCII)?

Start with HR 9473 Command word (Command word (run/stop, reset)); HR 9474 Frequency command (Frequency reference); HR 9504 Drive status (Drive status); HR 9505 Fault code (Fault code); HR 9508 Output frequency (Output frequency); HR 9511 Output current (Output current).

How do I enable Modbus control of the Lovato Electric VT1 series variable speed drives (Modbus RTU / ASCII)?

Wire the drive's RS-485 port and select Modbus RTU or ASCII, the slave address and the run/frequency command source on the drive keypad; those parameter numbers are in the VT1 instruction manual, not in this protocol document.

What happens when the Lovato Electric VT1 series variable speed drives (Modbus RTU / ASCII) loses Modbus communication?

A lost connection shows Err6 on the drive; the reaction to an external abnormality written via command bit 2 follows parameter 07-09.
