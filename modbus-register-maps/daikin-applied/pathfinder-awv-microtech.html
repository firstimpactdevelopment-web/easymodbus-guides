Daikin Applied Pathfinder AWV air-cooled screw chiller (MicroTech controller) Modbus register map

Updated 25 October 2026

Short answer

Air-cooled screw chiller with two refrigerant circuits, each with a variable-speed screw compressor. The MicroTech controller speaks Modbus RTU through a plug-on RS-485 module, and every point is a 16-bit holding register: water and refrigerant temperatures, pressures, compressor amps/volts/kW, enable and setpoint commands, status enums, alarm indexes and run-hour counters. Values follow an English/Metric setting.

This page lists 96 Modbus registers for the Daikin Applied Pathfinder AWV air-cooled screw chiller (MicroTech controller) — 17 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Daikin Applied’s own free documentation (linked below) and checked against it.

Integration notes: Daikin Applied Pathfinder AWV air-cooled screw chiller (MicroTech controller)

Integration in brief

Fit the Modbus module, set address and baud at the keypad (Modbus Setup), apply so the controller reboots, then poll holding registers with function 03. Read 1 (Local/Remote) and 316 (Units) first; use 9 to enable, 35 for the chilled-water setpoint, 38 for capacity limit, and 5 plus 28-33 for alarms.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

A Modbus communication module must be attached to the unit controller. Set Network Address and Baud Rate at the keypad (password 5321, View/Set Unit > Modbus Setup), then Apply Changes = Yes to reboot the controller. Chiller Local/Remote (register 1) must read Remote (0) - it can only be changed at the keypad - or enable, mode, setpoint, capacity-limit and clear-alarm writes are ignored.

Communication loss & watchdog

The module's Com LED Timeout (0-3600 s, default 3 s) only turns the BUS LED red when the master stops polling; no control fallback on communication loss is documented. Enable, mode and clear-alarm commands have a Null value that falls back to Disable / Cool / Normal when nothing writes them.

Byte order & addressing

  • Printed register numbers are 1-based without the 4xxxx prefix: subtract 1 for the wire address.
  • 32-bit run-hour counters are low word first (CDAB).
  • Most analog values are x10 and follow the English/Metric Units register (316); the multiplier does not change with units.
  • Alarm codes carry the alarm index in the high byte; the low byte holds circuit (bits 5-7), compressor (bits 2-4) and level (bits 0-1: 1 warning, 2 problem, 3 fault).
  • Many diagnostic registers (800s, 1100s, 1800s-1900s) exist only with newer AWV application code.

Network setup

  • Address 1-247 (default 1); baud 4800/9600/19200/38400 (default 38400); parity Even/Odd/None (default None); Two Stop Bits Yes/No (default Yes).
  • RS-485 is 3-wire (+, -, REF) shielded twisted pair, daisy-chained. The module's Load Resistor setting (default No) switches in termination; set Yes only on the first or last device.
  • Response Delay defaults to 5 ms; raise it only for slow masters.
  • Network parameters revert to defaults after an application software field upgrade - recheck them.

Watch out for

  • Writes are silently ignored while register 1 reads Local (1).
  • Chiller Mode Setpoint only matters when Available Modes at the keypad is not Cool Only.
  • Some manual-reset lockouts (low evaporator pressure, high condenser pressure, freeze) cannot be cleared from the network.
  • Compressor voltage is not available on AWV units with a Turboscrew compressor.

Notes on this map

  • Network settings (address 1, 38400 bps, parity None, two stop bits, response delay, Com LED timeout) are from the companion manual IM 969-7, MicroTech Chiller Unit Controller Modbus Communication Module (Oct 2023): https://tahoeweb.daikinapplied.com/api/general/DownloadDocumentByName/media/Daikin_Applied_IM_969-7_MT_Chiller_Modbus_Comm_Manual.pdf/
  • ED 15121 is shared by AGZ, AMZ, AWS, ADS, WME-B and WWV/TWV chillers. Only points that Table 3 marks in the AWV column are listed, and only the 'Compressor 1' slots of circuits 1 and 2 (the other compressor slots in the tables belong to multi-compressor models).
  • Two-register counters: the document's worked example (run hours 99900 = 0x0001863C stored as 74 = 0x863C, 75 = 0x0001) puts the low word in the lower register, so they are CDAB.
  • Strings: two ASCII characters per register, leftmost character in the lowest register and in the high byte (Figure 1 example: 0x3235 = '25').
  • The document never defines 'x 10'. Its ranges and defaults (for example 'Default: 43.88°F x 10', '0-100% x 10') only make sense as raw = value x 10, so those registers use scale 0.1.
  • Signedness is not stated. A register is INT16 when its published English or Metric range goes negative; otherwise UINT16. Condenser pressure is UINT16 because 4826 kPa x10 does not fit a signed register.
  • Units follow register 316 (English default). Units shown are the English ones (°F, psi); in Metric the same registers carry °C and kPa with the same multiplier.
  • Left out: Circuit 1 evaporator saturated refrigerant temperature (42), because ED 15121-13 prints its range without the 'x 10' that the other circuits' copies carry, so its scaling is not settled.
  • Left out: HMI Unit Status (1107) and Circuit HMI Status (1108/1109), because the document lists only text abbreviations, no numeric values.
  • Left out: points Table 3 does not mark for AWV (chiller current 25, condenser water points, flow rates, heat-recovery temperatures, heat setpoint, extra compressor slots) and the individual per-alarm registers (pp. 33-40). Alarm text for each index/code is in the document.
  • The Waterside Economizer Enable Setpoint default is printed as 'Disable (1)' although 1 = Enable in the same cell; the value list is copied as printed. Register 1854 is listed read-only (its data-type column says RO although the access column says R/W).
  • Total kW (27) is marked RW in the data-type column but R in the access column; it is listed read-only.

Questions about the Daikin Applied Pathfinder AWV air-cooled screw chiller (MicroTech controller)

What Modbus registers does the Daikin Applied Pathfinder AWV air-cooled screw chiller (MicroTech controller) have?

This map lists 96 registers: 96 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Daikin Applied Pathfinder AWV air-cooled screw chiller (MicroTech controller) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. ED 15121 prints holding registers without the 4xxxx prefix (register 8 = 40008) and states the module is zero-based: register 40003 goes out as 0002 in the PDU. Wire address = printed number - 1.

What byte order does the Daikin Applied Pathfinder AWV air-cooled screw chiller (MicroTech controller) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Daikin Applied Pathfinder AWV air-cooled screw chiller (MicroTech controller)?

Start with HR 0 Chiller Local/Remote (Local/Remote - network commands only work in Remote); HR 14 Chiller Status (Chiller status); HR 16 Evaporator Leaving Fluid Temperature (Leaving chilled water temperature); HR 12 Actual Capacity (Actual capacity); HR 8 Chiller Enable Setpoint (Network enable command); HR 34 Cool Setpoint - Network (Cooling setpoint command); HR 37 Capacity Limit Setpoint - Network (Capacity limit command); HR 4 Alarm Digital Output (Any alarm active); HR 29 Fault Alarm Index (Active fault index); HR 315 Units (English/Metric) (English/Metric flag).

How do I enable Modbus control of the Daikin Applied Pathfinder AWV air-cooled screw chiller (MicroTech controller)?

A Modbus communication module must be attached to the unit controller. Set Network Address and Baud Rate at the keypad (password 5321, View/Set Unit > Modbus Setup), then Apply Changes = Yes to reboot the controller. Chiller Local/Remote (register 1) must read Remote (0) - it can only be changed at the keypad - or enable, mode, setpoint, capacity-limit and clear-alarm writes are ignored.

What happens when the Daikin Applied Pathfinder AWV air-cooled screw chiller (MicroTech controller) loses Modbus communication?

The module's Com LED Timeout (0-3600 s, default 3 s) only turns the BUS LED red when the master stops polling; no control fallback on communication loss is documented. Enable, mode and clear-alarm commands have a Null value that falls back to Disable / Cool / Normal when nothing writes them.
