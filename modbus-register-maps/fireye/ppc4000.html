Updated 17 November 2026

Short answer

The PPC4000 is Fireye's parallel positioning fuel/air ratio control for burners. It is a Modbus RTU slave with holding registers only: a read-only block of status, counters, positions, raw sensor values and lockout history, and a small read/write block for burner on/off, low fire, lead/lag, auto/manual and manual modulation rate.

This page lists 76 Modbus registers for the Fireye PPC4000 parallel positioning burner control (Modbus RTU) — 5 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Fireye’s own free documentation (linked below) and checked against it.

Integration notes: Fireye PPC4000 parallel positioning burner control (Modbus RTU)

Integration in brief

Poll the PPC4000 with FC03 at 8N1 and the baud rate chosen on the control (4800-57600). Read operational state, modulation rate and the active error; write 1/0 with FC06 to 41002 to turn the burner on or off.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is available on PPC4000 units with engineering code EC08 or later; the baud rate is selected in the PPC4000 menu.

Byte order & addressing

  • Only FC03 (read) and FC06 (write single) are used.
  • Register numbers are Modicon-style; subtract 40001.
  • 32-bit counters are upper word first.

Network setup

  • Serial format is fixed at 8 data bits, no parity, 1 stop bit; baud 4800-57600 is menu selectable.
  • Set the slave address on the PPC4000.

Watch out for

  • Manual modulation rate (41018) has no effect until auto/manual (41005) is set to manual.

Notes on this map

  • Fireye's own copy of this bulletin was not reachable (the later MOD-4001-NXF4000_PPC4000 link on fireye.com returns 404); this copy is served by a controls distributor and is the unaltered Fireye bulletin.
  • The three 32-bit counters are listed as an upper-16-bit register followed by a lower-16-bit register, so they read as ABCD UINT32.
  • VFD positions are 0-1000 in tenths of a degree, so scale 0.1 gives degrees; servo positions and set point/alarm values have no stated scaling and are raw.
  • Raw sensor conversion from the bulletin: value = ((raw / calibration constant - 0.2) / 0.8) * range + offset, using 40052 as the calibration constant and the range/offset of the fitted sensor (e.g. TS350: range 318, offset 32). Sensors 4 and 5 are raw only.
  • Lockout history: only fault 1 (most recent) is listed; faults 2-10 follow at 40200-40253 in six-register groups with the same layout.
  • O2 probe status and temperature registers (40036-40039) are left out; their meaning is in the separate O2 probe manual.
  • Error codes are listed in a separate Fireye publication; this bulletin does not explain the operational state numbers 0-16.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Fireye PPC4000 parallel positioning burner control (Modbus RTU)

What Modbus registers does the Fireye PPC4000 parallel positioning burner control (Modbus RTU) have?

This map lists 76 registers: 76 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Fireye PPC4000 parallel positioning burner control (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The bulletin prints holding register numbers from 40001 next to the message address actually sent (40001 = address 00, 41002 = 1001). Subtract 40001 for the wire address.

What byte order does the Fireye PPC4000 parallel positioning burner control (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Fireye PPC4000 parallel positioning burner control (Modbus RTU)?

Start with HR 0 Operational state (Operational state); HR 8 Current modulation rate (Modulation rate); HR 191 Current active error number (Active error number); HR 4 Burner on minutes (Burner on minutes); HR 1001 Burner control on/off (Burner on/off command); HR 1004 Burner control auto/manual (Auto/manual); HR 1017 Manual modulation rate (Manual modulation rate).

How do I enable Modbus control of the Fireye PPC4000 parallel positioning burner control (Modbus RTU)?

Modbus is available on PPC4000 units with engineering code EC08 or later; the baud rate is selected in the PPC4000 menu.

Where is the official Fireye PPC4000 parallel positioning burner control (Modbus RTU) Modbus documentation?

The source is PPC4000 Modbus Communications (MOD-4001), revision 2012-09-13. Fireye doesn't publish it on its own website, so this map was re-typed from a free copy at https://www.ccontrols.com/support/dp/MOD-4001.pdf. It may be an older revision, so check it against the live unit.
