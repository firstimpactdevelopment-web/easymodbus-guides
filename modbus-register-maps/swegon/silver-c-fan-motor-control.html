Swegon SILVER C fan motor control (RX/PX/CX/SD, generation E/F) Modbus register map

Updated 17 November 2026

Short answer

Each supply or extract fan in a SILVER C air handler has its own motor controller with a Modbus RTU slave port. Over it a master can start and stop the fan, give a speed setpoint in percent, reset alarms and read speed, current, power, temperatures, run time and an energy log. Configuration values such as ramp times, I/O module functions and the serial settings are holding registers.

This page lists 106 Modbus registers for the Swegon SILVER C fan motor control (RX/PX/CX/SD, generation E/F) — 46 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Swegon’s own free documentation (linked below) and checked against it.

Integration notes: Swegon SILVER C fan motor control (RX/PX/CX/SD, generation E/F)

Integration in brief

Set coil 7 (Control) to 0 so speed comes from Modbus, write the speed setpoint in 0.01 % to holding register 0 and switch the motor with coil 0. Poll input registers 3-8 for output, speed, temperature, voltage, current and power, and discrete inputs 0-27 for alarms.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Communication settings are changed with the TBLZ-4-75 hand-held terminal (or the matching holding registers). Coil 7 selects whether speed follows Modbus or the 0-10 V input. Coil 18 can lock the configuration against Modbus writes.

Communication loss & watchdog

Comm. timeout 0-240 s, factory 10 s (holding register 21). What the fan does on timeout is not described.

Byte order & addressing

  • Factory slave address is 54 decimal (0x36); the addressing pins on connector A/B select 54-57 so several fan controllers share one bus.
  • Coils are written with FC05 using 0xFF00 for ON.
  • Factory serial setting is 38400 baud, no parity, 1 stop bit; the alternative factory setting is 115200, even parity.

Network setup

  • Connect to terminals Bus A / Bus B / GND or to RJ12 connector A or B; connector C is the master port for external sensors.
  • Use the hand-held terminal to change address, baud rate, parity and timeout.

Watch out for

  • Do not use RJ12 connector C for the BMS; it is a master port.
  • Speed and limit registers change units between EC (rpm) and FC (0.01 Hz) configurations.

Notes on this map

  • Scales and units are for the EC configuration. In the FC configuration speed values (3x0005, 4x0002, 4x0003) are in 0.01 Hz instead of rpm; this is said in the description of those registers.
  • Discrete inputs 26 and 27 are printed with a 0x prefix (0x0027, 0x0028) inside the discrete-input table; they are kept as discrete inputs at the printed addresses.
  • Left out: 3x0014 config file variant (two ASCII characters), 3x0019 AOC SW variant (no range or unit), the product name characters 3x2004-3x2012 (the address column switches between decimal and hex there), 4x0033/4x0034 relay configuration and 4x0037 analog input 2 (option tables mostly TBD / N/A).
  • Run time is split into minutes (0-1439) and days; energy is split into Wh, kWh and MWh parts. Add the parts yourself.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Swegon SILVER C fan motor control (RX/PX/CX/SD, generation E/F)

What Modbus registers does the Swegon SILVER C fan motor control (RX/PX/CX/SD, generation E/F) have?

This map lists 106 registers: 16 coils, 26 discrete inputs, 34 input registers, 30 holding registers. 46 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Swegon SILVER C fan motor control (RX/PX/CX/SD, generation E/F) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every table prints the reference (0x0001, 1x0001, 3x0001, 4x0001) and the protocol address next to it; the address column is the reference number minus 1 (4x0001 = address 0). The address column is used here.

What are the minimum Modbus registers to integrate the Swegon SILVER C fan motor control (RX/PX/CX/SD, generation E/F)?

Start with CO 0 Motor ON/OFF (Motor on/off); CO 7 Control (Speed source Modbus or 0-10 V); HR 0 Setpoint / PrcSet (Speed setpoint 0.01 %); IR 3 PrcOut (Actual output %); IR 4 RPMOut (Actual speed); IR 8 Power In (Input power W); DI 10 Internal Stop (Internal stop alarm); CO 1 Reset Alarms (Alarm reset).

How do I enable Modbus control of the Swegon SILVER C fan motor control (RX/PX/CX/SD, generation E/F)?

Communication settings are changed with the TBLZ-4-75 hand-held terminal (or the matching holding registers). Coil 7 selects whether speed follows Modbus or the 0-10 V input. Coil 18 can lock the configuration against Modbus writes.

What happens when the Swegon SILVER C fan motor control (RX/PX/CX/SD, generation E/F) loses Modbus communication?

Comm. timeout 0-240 s, factory 10 s (holding register 21). What the fan does on timeout is not described.
