Short answer

The s-MEXT-G00 is a Mitsubishi Electric direct-expansion close-control unit for computer rooms (6-44 kW). With the Modbus serial board fitted, its controller exposes Boolean variables as coils and analogue/integer variables as holding registers over RS-485 Modbus RTU. This map covers unit status and on/off, setpoints, room/delivery/outside temperatures, humidity, pressures, fan and damper positions, operating mode, run hours and the electrical readings.

This page lists 68 Modbus registers for the Mitsubishi Electric s-MEXT-G00 computer room air conditioner (ME28 relC) — 10 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Mitsubishi Electric’s own free documentation (linked below) and checked against it.

Integration notes: Mitsubishi Electric s-MEXT-G00 computer room air conditioner (ME28 relC)

Integration in brief

Read unit status and alarm coils, room/delivery temperature, humidity and operating mode; write the on/off coil and the cold/hot setpoints (x10).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Modbus serial board, then in the User menu (User password) set P30.01 Enable supervision = Y, P30.02 BMS address, P30.03 protocol = Modbus and P30.04 baud rate. Set P30.05 On/Off by BMS = Y so the on/off coil works.

Byte order & addressing

  • Numbering starts at 1: coil 002 is wire address 1 and register 40002 is wire address 1 (subtract 40001).
  • Integer variables sit 128 registers above their software address.

Network setup

  • Up to 200 units on one network; polling time grows with the number of units.
  • Line settings are fixed at 8 data bits, no parity, 2 stop bits.

Watch out for

  • A probe in alarm reads -999 (-99.9 after scaling); a probe or parameter that is not configured reads -888.

Notes on this map

  • Scale: the manual's conversion factors are 'Value x10' for writes and 'Value/10' for reads, so those registers hold tenths (scale 0.1); 'Value x1' registers are unscaled.
  • Analogue (type A) variables are listed as INT16 because the manual documents negative sentinel values (-999 probe alarm, -888 not configured); integer (type I) variables are listed as UINT16 since none carry negative ranges. The manual does not state signedness explicitly.
  • Flow OUT = read only, IN = written by the BMS; rows listing both are read-write. Coil 038 is IN only (write).
  • Run hours are split into a 'thousands' and a 'units' register.
  • Serial settings per the manual: 8 data bits, 2 stop bits, no parity (fixed); baud selectable 1200-19200 in the user menu (P30.04); unit ID 001-200.
  • Addresses not listed in the database must not be used, per the manual.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Mitsubishi Electric s-MEXT-G00 computer room air conditioner (ME28 relC)

What Modbus registers does the Mitsubishi Electric s-MEXT-G00 computer room air conditioner (ME28 relC) have?

This map lists 68 registers: 6 coils, 62 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Mitsubishi Electric s-MEXT-G00 computer room air conditioner (ME28 relC) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The interface database prints coils as 001-184 and registers as 40001-40257 and states the start address is 1, not 0. So coil 002 is wire address 1 and register 40002 is wire address 1. Integer ('whole') variables start at 40129 (software address + 128).

What are the minimum Modbus registers to integrate the Mitsubishi Electric s-MEXT-G00 computer room air conditioner (ME28 relC)?

Start with CO 1 Unit status (Unit status); CO 2 Presence of alarm (Alarm present); CO 8 On/Off command by supervisor (On/off command); HR 1 Cold temperature setpoint (Cold temperature setpoint); HR 6 Room temperature (Room temperature); HR 21 Ambient humidity (Ambient humidity); HR 142 Unit operating mode (Unit operating mode); HR 160 Active alarm code (with greater priority) (Active alarm code).

How do I enable Modbus control of the Mitsubishi Electric s-MEXT-G00 computer room air conditioner (ME28 relC)?
