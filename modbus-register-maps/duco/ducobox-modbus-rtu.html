Short answer

Duco residential and light-commercial ventilation systems expose each network component (the DucoBox itself, control valves, sensors, user controls, window ventilators) as a Modbus 'node'. Registers are numbered node x 10 + parameter, with up to ten 16-bit input (read) and ten holding (write) parameters per node. This map lists the DucoBox master node (node 1, registers 10-19): system status, ventilation level and power, plus the system override, auto min/max and action registers.

Integration notes: Duco DucoBox ventilation units / IQ unit (Modbus RTU, master node)

Integration in brief

Read input 11-12 for the system status and ventilation level. Control either with holding 10 (target %, -1 to release) or holding 19 (Action, simulates a button press so user controls stay in step).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Communication Print option (DucoBox) or use the IQ unit's built-in port; set the Modbus address in the display menu or Duco Network Tool.

Byte order & addressing

  • Addresses are node x 10 + parameter; read node numbers from the Duco Network Tool.
  • If the master reads values shifted by one register, set RegOffs = 1 in the Duco display menu.

Network setup

  • Default serial settings 9600 baud, 8 data bits, no parity, 1 stop bit; change in the display menu.

Watch out for

  • A target value left set overrides the zone and user controls no longer show the true setting; write -1 to release it.

Notes on this map

  • Only the DucoBox master node (node 1) is listed because every other component's registers depend on the node number the installer's network assigns. For any component, input and holding register = node x 10 + parameter (parameter 0-9).
  • Common per-component parameters (from the sheet): input 0 type of module, 1 status, 2 ventilation position %, 9 localisation number; holding 0 target value % (-1 = off), 9 action. Sensor nodes add indoor temperature (°C x 10), CO2 (ppm) or RH (% x 100) in the input block.
  • Input register Status values differ from the Action values (manual low is 4 in Status but 2 in Action).
  • Target value (holding 10) is typed INT16 because -1 turns the override off.
  • All registers are 16-bit. Supported functions: 03, 04, 06, 16.
  • The Modbus slave address is set in the display menu or the Duco Network Tool; its default is not stated in this sheet.

Questions about the Duco DucoBox ventilation units / IQ unit (Modbus RTU, master node)

What Modbus registers does the Duco DucoBox ventilation units / IQ unit (Modbus RTU, master node) have?

This map lists 11 registers: 7 input registers, 4 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Duco DucoBox ventilation units / IQ unit (Modbus RTU, master node) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Duco numbers registers as node number followed by parameter number (node 1 parameter 0 = 10, node 7 parameter 2 = 72). The sheet says its implementation follows the official Modbus specification, so the printed number is the address sent on the wire; masters that subtract one (reading 19 for 20) can be compensated with the RegOffs parameter set to 1.

What are the minimum Modbus registers to integrate the Duco DucoBox ventilation units / IQ unit (Modbus RTU, master node)?

Start with IR 11 Status (System status); IR 12 Ventilation position (Ventilation level %); IR 13 Current power (Current power); HR 10 Target value (Target value override); HR 19 Action (Action (manual/auto)); HR 15 Auto min. (Auto minimum).

How do I enable Modbus control of the Duco DucoBox ventilation units / IQ unit (Modbus RTU, master node)?

Fit the Communication Print option (DucoBox) or use the IQ unit's built-in port; set the Modbus address in the display menu or Duco Network Tool.
