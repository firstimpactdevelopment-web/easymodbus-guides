Short answer

Invertek's HVAC/pump variable frequency drive with Modbus RTU on its built-in RJ45 RS-485 port (the same port also offers BACnet MS/TP). Registers 1-4 take the control word, speed reference and ramp time; registers 6-35 report status, fault code, output values, I/O, energy and run time; and parameters P1-xx to P5-xx sit at register = parameter number (P1-01 = 101). This map covers the control/monitor block and the P1/P5 parameters a Modbus integration needs.

Integration notes: Invertek Drives Optidrive Eco (built-in Modbus RTU)

Integration in brief

Put the drive in fieldbus control with P1-12 = 4, then write register 1 (control word) and register 2 (speed in 0.1 Hz) and poll registers 6-11 for status, fault code, frequency, current, torque and power. Subtract 1 from every register number the guide prints.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set P1-14 = 101 to open the extended parameter groups, then set P5-01 node address (1-63; P5-16 for higher addresses), P5-03 baud rate and P5-04 data format, and set P1-12 = 4 (Fieldbus control) so registers 1-2 can run the drive. The hardware ENABLE input must be present before a start command from the fieldbus is accepted. With P1-12 = 6 the port runs BACnet MS/TP instead of Modbus.

Communication loss & watchdog

P5-05 Communications loss timeout (0.0-5.0 s, default 1.0 s, 0 disables) with P5-06 action: 0 trip and coast, 1 ramp then trip, 2 ramp only, 3 run at preset speed 4. A timeout trips fault 50 (Built-in Modbus RTU communication timeout).

Byte order & addressing

  • Register numbers in the guide are 1-based: subtract 1 for the wire address (register 1 = address 0, P1-01 = register 101 = address 100).
  • Only function codes 03, 06 and 16 are supported, and 16 (write multiple) works for registers 1-4 only - write parameters one at a time with 06.
  • Register 6 holds status in the low byte and the fault code in the high byte; mask and shift rather than reading it as one number.
  • Fault reset (control word bit 2) must be set back to 0 after the fault clears.

Network setup

  • Wire to the RJ45 port: pin 7 = RS485-, pin 8 = RS485+, pin 3 = 0 V common. Connect the 0 V common across all devices; it is not an Ethernet port.
  • Use shielded twisted pair (120 ohm), terminate the end of the network with 120 ohm, and ground the shield at the controller only.
  • Defaults: address 1 (P5-01), 115.2 kbps (P5-03), no parity / 1 stop bit (P5-04 'n-1'). Baud choices include 9.6, 19.2, 38.4, 57.6, 76.8 and 115.2 kbps.
  • P5-15 adds an extra reply delay in characters for slow masters.

Watch out for

  • If P1-12 is not 4, writes to registers 1-2 do not control the drive; registers 6-24 can still be read in any mode.
  • P1-01/P1-02 change to rpm once P1-10 Motor rated speed is set to the nameplate rpm.
  • Register 3 is reserved on the Eco; there is no torque reference register.
  • P0-49 counts Modbus RTU communication errors - read it on the keypad when diagnosing a noisy bus.

Notes on this map

  • Register 6 packs two bytes: the low byte is the 8-bit status word, the high byte the fault code. Read the register, then take (value >> 8) for the fault number; 0 means no fault.
  • The guide does not say whether the output values are signed. Frequency, torque, power, analog levels and temperature are typed INT16 here: every value in their documented ranges is below 32768, so INT16 and UINT16 decode identically, and INT16 is also right if the drive sends a negative value.
  • Parameter registers follow the guide's rule: register number = parameter number, and a parameter shown with one decimal place is sent x10 (the guide's example: P1-01 = 500 means 50.0 Hz). When P1-10 Motor rated speed is non-zero, P1-01/P1-02 are in rpm instead and the decimal handling for rpm is not stated.
  • The guide says P5-01 (drive address), P5-03 (baud rate) and P5-04 (data format) are not accessible over Modbus, so they are not listed; P5-16 (alternative Modbus address) is left out for the same reason.
  • The register-4 text says ramp control needs 'P5-08 = 1', but the introduction and the P5-07 parameter description both put Fieldbus Ramp Control in P5-07; this map follows P5-07.
  • Left out: register 22 pre-ramp speed reference (units not stated), registers 30-33 kWh/MWh meters (resolution not stated, and the guide labels both the resettable and non-resettable pairs as P0-26/P0-27), register 35 run time minutes and seconds (packing not stated), register 3 (reserved), P1-08 motor current and P1-11 boost (decimal places not stated).
  • P1-12 values 1 and 2 are both printed as 'Keypad control - uni-directional' in this guide edition.
  • The P5-05 text refers to 'P5-07' for the loss action; the action itself is P5-06.

Questions about the Invertek Drives Optidrive Eco (built-in Modbus RTU)

What Modbus registers does the Invertek Drives Optidrive Eco (built-in Modbus RTU) have?

This map lists 27 registers: 27 holding registers. 16 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Invertek Drives Optidrive Eco (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide numbers registers from 1 and says masters that count from 0 must subtract 1, so register 1 (control word) is wire address 0 and register 6 (status) is address 5. Parameters use register = parameter number (P1-01 = register 101 = address 100; P5-05 = 505 = address 504).

What are the minimum Modbus registers to integrate the Invertek Drives Optidrive Eco (built-in Modbus RTU)?

Start with HR 0 Command control word (Control word: run/stop, fault reset); HR 1 Command speed reference (Speed reference, 0.1 Hz); HR 5 Error code / drive status (Status bits (low byte) + fault code (high byte)); HR 6 Output frequency (Output frequency, 0.1 Hz); HR 7 Output current (Output current, 0.1 A); HR 9 Output power (Output power, 0.01 kW); HR 22 DC link voltage (DC bus voltage); HR 111 P1-12 Primary command source (P1-12 command source (must be 4)); HR 33 Running time - hours (Total run time, hours).

How do I enable Modbus control of the Invertek Drives Optidrive Eco (built-in Modbus RTU)?

Set P1-14 = 101 to open the extended parameter groups, then set P5-01 node address (1-63; P5-16 for higher addresses), P5-03 baud rate and P5-04 data format, and set P1-12 = 4 (Fieldbus control) so registers 1-2 can run the drive. The hardware ENABLE input must be present before a start command from the fieldbus is accepted. With P1-12 = 6 the port runs BACnet MS/TP instead of Modbus.

What happens when the Invertek Drives Optidrive Eco (built-in Modbus RTU) loses Modbus communication?

P5-05 Communications loss timeout (0.0-5.0 s, default 1.0 s, 0 disables) with P5-06 action: 0 trip and coast, 1 ramp then trip, 2 ramp only, 3 run at preset speed 4. A timeout trips fault 50 (Built-in Modbus RTU communication timeout).
