Short answer

The JCx-33A series are PID temperature controllers sharing one command set. With the C5 option they speak Shinko protocol, Modbus ASCII or Modbus RTU on RS485, and every item is a signed 16-bit holding register. The map covers SV and limits, PID, alarm, heater burnout and loop break settings, auto/manual and output OFF, PV, MV and the status word.

This page lists 50 Modbus registers for the Shinko Technos JCS-33A / JCM-33A / JCR-33A / JCD-33A digital indicating controller (C5 option) — 46 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Shinko Technos’s own free documentation (linked below) and checked against it.

Integration notes: Shinko Technos JCS-33A / JCM-33A / JCR-33A / JCD-33A digital indicating controller (C5 option)

Integration in brief

Set Communication protocol to Modbus RTU in Auxiliary function setting mode 1 and give the unit a non-zero instrument number; then poll PV 0080H, OUT1 MV 0081H and status 0085H and write SV1 at 0001H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Requires the C5 option. Enter Auxiliary function setting mode 1 by holding the key pair shown on p. 2 for about 3 s, press the advance key 4 times to reach Communication protocol, and choose Modbus RTU; then set instrument number, speed, parity and stop bit.

Byte order & addressing

  • Instrument number defaults to 0, the Modbus broadcast address; set 1-95.
  • Send alarm type before alarm value and input type before other settings, because changing them resets dependent values.

Network setup

  • Factory defaults: Shinko protocol, instrument 0, 9600 bps, even parity, 1 stop bit.
  • Speeds 2400, 4800, 9600, 19200 bps; no terminator needed, the unit has built-in pull-up/pull-down resistors.

Watch out for

  • Clearing the key-change flag during keypad setting mode returns exception 18 (12H).

Notes on this map

  • All data are 16-bit two's complement. Values with a decimal point are sent as whole numbers; apply the decimal point place (001AH).
  • Units of PID times, cycles and MV are not printed in the command table.
  • PID values are updated after AT ends; read them once status bit 11 returns to 0.
  • Protocol, instrument number, speed, parity and stop bit are keypad-only settings.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Shinko Technos JCS-33A / JCM-33A / JCR-33A / JCD-33A digital indicating controller (C5 option)

What Modbus registers does the Shinko Technos JCS-33A / JCM-33A / JCR-33A / JCD-33A digital indicating controller (C5 option) have?

This map lists 50 registers: 50 holding registers. 46 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos JCS-33A / JCM-33A / JCR-33A / JCD-33A digital indicating controller (C5 option) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are listed as hex data items (0001H) that go into the request unchanged. The manual adds that the matching Modicon holding-register number is the item in decimal plus 40001 (0001H = 40002).

What are the minimum Modbus registers to integrate the Shinko Technos JCS-33A / JCM-33A / JCR-33A / JCD-33A digital indicating controller (C5 option)?

Start with HR 128 PV (Process value); HR 1 SV1 (Set value SV1); HR 129 OUT1 MV (OUT1 manipulated value); HR 133 Status flag (Output, alarm and error status); HR 55 Control output OFF (Control output OFF); HR 26 Decimal point place (Decimal point for scaling).

How do I enable Modbus control of the Shinko Technos JCS-33A / JCM-33A / JCR-33A / JCD-33A digital indicating controller (C5 option)?

Requires the C5 option. Enter Auxiliary function setting mode 1 by holding the key pair shown on p. 2 for about 3 s, press the advance key 4 times to reach Communication protocol, and choose Modbus RTU; then set instrument number, speed, parity and stop bit.
