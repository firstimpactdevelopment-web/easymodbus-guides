Short answer

The MelcoBEMS MINI (A1M+) is a Procon-built RS-485 Modbus RTU gateway for Mitsubishi Electric units, documented by Mitsubishi Electric UK. With an Ecodan FTC controller it exposes on/off, zone modes, tank and zone setpoints, temperatures, heater and pump states and energy totals. This map lists the holding registers that the register tables mark as applicable to FTC4, FTC5 or FTC6.

Integration notes: Mitsubishi Electric MelcoBEMS MINI (A1M+) gateway for Ecodan FTC4/FTC5/FTC6 air-to-water systems

Integration in brief

Connect the A1M+ to the FTC controller as described in its installation instructions and to the BMS RS-485 line, then read 40014 to confirm an ATW system is detected and 40010 for faults. Switch the system with 40026, set the tank and zone targets at 40031/40055/40057, and poll flow, return, tank and room temperatures from 40094-40118.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step is described in the register tables; the gateway answers once it is powered from the unit and its Modbus address, baud rate and parity (40005-40007) match the master. See the separate MelcoBEMS MINI installation instructions.

Byte order & addressing

  • Temperatures are x100 for most points but x10 for outdoor ambient (40100) and DHW temperature drop (40092).
  • Each signed temperature has an unsigned twin one address higher for masters that cannot handle negative values.
  • Baud-rate code 0 and code 4 both mean 9600 in the table.
  • Holding registers support FC 03, FC 06 and FC 16; registers marked READ ONLY cannot be written.

Network setup

  • Set the Modbus address (1-247), baud rate and parity in 40005-40007 to match the BMS.
  • Energy values (40283-40299) are reported as a kWh part plus a Wh part (x10 Wh); add them for the full reading.

Watch out for

  • Value 0x6999 (hex register) or 6999 (decimal register) means the gateway cannot talk to the heat pump controller, not a heat pump fault.
  • Operating mode register 40027 is not marked for FTC units; use the zone A/C mode registers 40029/40030 and DHW mode 40028 instead.

Notes on this map

  • Only holding registers ticked for FTC4, FTC5 or FTC6 are listed. Registers marked FTC5/FTC6 only (or read-only on FTC4) say so in their description. CAHV/CRHV/QAHV/EAHV-only registers (operating mode 40027, capacity control, outdoor temperature by BMS, setting water temperature, brine and condensing temperatures, electric energy 1-16) are left out.
  • Most temperatures exist twice: a signed version (x100, 0x8000 = -327.68 °C) and an unsigned version at the next address that never returns a negative. Only the signed versions are listed; the unsigned twin is at address + 1.
  • The gateway also exposes the same data as input registers, coils and discrete inputs; their read-only holding-register copies are what is listed here.
  • Left out: 40073 Status Of Heating, 40270-40272 model profile/capacity rows and the slave heat-pump frequency/run-time rows, because the extracted table text for those rows runs together and could not be matched to a single register with certainty; also the FTC6-only block 40343-40430 (date/time, software version, hybrid boiler settings, error status 1-39).
  • The register tables do not state the gateway's factory slave ID, baud rate or parity, so the defaults are left empty; they are set via registers 40005-40007 or the installation instructions.
  • Note in the source: the MRC Prohibit command must not be written to Shizuoka-designed models.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Are the Mitsubishi Electric MelcoBEMS MINI (A1M+) gateway for Ecodan FTC4/FTC5/FTC6 air-to-water systems Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every row gives both a protocol 'Addr' and a Modicon address (e.g. Addr 4 = 40005). The Addr value is what goes on the wire, so Modicon 40005 is wire address 4.
