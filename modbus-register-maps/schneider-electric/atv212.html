Schneider Electric Altivar 212 (embedded Modbus RTU) Modbus register map

Updated 25 October 2026

Short answer

Schneider Electric's HVAC variable frequency drive for fans and pumps, with Modbus RTU built in on two RS-485 ports: an RJ45 socket and an open-style screw terminal. Parameters are addressed by their hexadecimal communication numbers (Fd00, FA01, F802...) sent unchanged as the register address, and the drive reads or writes only one register per request. This map covers command word 1 and 2, frequency and speed references, relay and analog output control, the status words, output frequency, current, voltage and power monitors, trip and alarm codes with trip history, I/O states, and the Modbus and control-source settings.

This page lists 55 Modbus registers for the Schneider Electric Altivar 212 (embedded Modbus RTU) — 25 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Schneider Electric’s own free documentation (linked below) and checked against it.

Integration notes: Schneider Electric Altivar 212 (embedded Modbus RTU)

Integration in brief

Give the drive a unique F802 address (factory 1), make sure F807 points at the port you are wired to, then either set CMOd = 2 and FMOd = 4 (drive stopped) or keep them and set bits 15/14 in FA00. Write FA01 in 0.01 Hz and FA00 = 0400h (run forward) or C400h (run forward with command and reference priority). Poll Fd00, Fd01, FE03 and FC90 one register at a time.

Enable Modbus control & writes

All communication settings are in [PROGRAMMING MENU] > [COMMUNICATION MENU] COM. F807 chooses which port may command the drive: 0 = RJ45, 1 = open-style terminal (factory). On the open-style port also set F829 = 1 (Modbus RTU, factory). F802 is the address for both ports (0 disables). Full network control: CMOd = 2 (Communication) and FMOd = 4 (Serial com ref.), changed only while stopped. Alternatively leave CMOd/FMOd on terminals and set FA00 bit 15 (commands) and bit 14 (reference) to take priority over the bus; the LOC/REM key and a logic input set to function 48 (Forced local) can still take control back.

Communication loss & watchdog

F803 [Com. time out], 0-100 s, factory 3 s (0 disables). The timer starts at the first valid frame addressed to the drive and is restarted by any request (read, write or identification). F851 lists the reactions 0 ramp stop and hand control back to CMOd/FMOd (LonWorks board only), 1 ignore, 2 ramp stop, 3 freewheel and 4 trip Err5 (RJ45) or Err8 (network port, factory). The programming manual adds that on Modbus only setting 1 is honoured and every other setting trips in Err5/Err8, so on Modbus expect either no reaction (1) or a trip. Detection is active when CMOd = 2 or FMOd = 4.

Byte order & addressing

  • Function 03 reads exactly one register per request (quantity 1); asking for 2 at Fd00 returns exception 03. The only multi-register read is the indirect block at 16#1875 (quantity 1-5).
  • Function 16 writes exactly one register (or the 2-register indirect block at 16#1870). Supported functions are 03, 06, 16 and 43/14 only - no FC04.
  • Addresses are the hex communication numbers sent as-is: Fd00 -> 0xFD00 (64768), F802 -> 0x0802 (2050). Don't add 40001 and don't subtract 1.
  • FA00 examples: 0400h run forward, 0600h run reverse when CMOd/FMOd are on serial; C400h / C600h run with communication priority regardless of CMOd/FMOd. Bit 13 resets a fault.
  • Frequency values are 0.01 Hz: 6000 = 60.00 Hz, 8000 = 80.00 Hz.
  • The drive transmits 2 stop bits and accepts 1 or 2, so masters set to 1 or 2 stop bits both work. Baud and parity changes need a power cycle.
  • Read Device Identification (43/14) reports the vendor as 'Télémécanique', the catalog number (e.g. ATV212H075M3X) and the control software version as 4 ASCII digits.

Network setup

  • RJ45 port: pin 4 = D1 (B), pin 5 = D0 (A), pin 2 = common, pin 7 = 10 V supply for a converter or the graphic display; pins 1, 3, 6, 8 not connected.
  • Open-style terminal: B (+), A (-), GND (common), SCR (shield); two wires per cage are allowed for daisy chaining.
  • Set switch SW103 to Term to connect the built-in 120 ohm terminator at a bus end (switch only with power off).
  • Set F802 (address), then F800/F801 (RJ45) or F820/F821 (open style) for baud and parity; factory is 19200 bps, even parity. Cycle power so baud/parity take effect.
  • Check traffic on the keypad monitor [Mdb com stat], which shows Rx/Tx activity for each port.

Watch out for

  • F807 defaults to the open-style port. A master on the RJ45 socket can read but its run commands and reference are ignored until F807 = 0.
  • Output current and voltages are percentages, not amps or volts.
  • FA00/FA01 are not retained: after a power loss the drive comes back with no communication priority and a zero reference until the master writes them again.
  • CMOd and FMOd can only be changed while the drive is stopped; a write while running returns exception 04.
  • F803 = 0 or F851 = 1 disables communication-loss protection; use only for commissioning.

Notes on this map

  • Second source: Altivar 212 Programming Manual S1A53838 rev 04 (06/2025), https://download.schneider-electric.com/files?p_Doc_Ref=S1A53838 - used for the F207 value list (p. 88), parameters that can only be changed while stopped (p. 41), the CMOd/FMOd notes and the F851/F829 remarks (pp. 87, 148-149), and the keypad meaning of the percent monitors (pp. 20-22).
  • Every register is one 16-bit word; the map has no 32-bit values. The manual gives no signed/unsigned type and no ranges for the monitors. The ones kept (frequencies, speed, current, voltages, loads, input power) are magnitudes with no negative case in the manual's descriptions (direction is a separate status bit) and are typed UINT16; the writable registers have ranges from 0 upward.
  • Output current FE03, DC bus voltage FE04 and output voltage FE05 are in 0.01 % steps, not amps or volts. The Modbus manual does not state the 100 % base. On the keypad, current in % is relative to the drive's rated output current and voltage in % to 200 V (240 V class) or 400 V (480 V class) (programming manual p. 20).
  • Monitors marked 'value before trip' in the manual's description column (FE02, FE05, FE15, FE16, FE22, FE26, FE27, FE29) are kept with that wording; Fd00, Fd06 and Fd07 are tagged as current values, and FE03, FE04 and FE90 carry no tag.
  • FA00, FA01, FA13, FA20, FA50 and FA51 live in RAM only: they return to 0 at power-off, reset or factory setting, so the priority bits and reference must be rewritten after a power cycle.
  • Left out: torque FE18, torque current FE20, exciting current FE21 and output power FE30, because they can plausibly be negative and the manual gives no signedness; input/output energy FE76/FE77 (1 Wh in a 16-bit word while the keypad shows kWh per F749, unclear) and run-time counters FE14/FE80 (manual says 0.01 h, keypad says 0.01 = 1 hour, conflicting).
  • Left out: ACC (address 9) because the Modbus manual's worked example gives both 0.1 s and 0.01 s as its unit; other drive parameters (FH, UL, LL, motor data) because the Modbus manual does not print their addresses and the current programming manual has no address column.
  • Left out: FE06/FE07 (I/O at last trip; FE07's decimal address is misprinted as 65030), Fd42/Fd49 trip copies FE42/FE49, FA49 damper feedback (address not printed), drive model code F805/FB05 (two different codes printed) and LI selection F112 (long function list).
  • Trip codes Err1 (speed reference alarm) and CFI2 (download transfer fault) have no numeric code in the manual and are not in the value list.
  • Indirect blocks: after setting F875-F879 (power cycle), one FC03 read at 16#1875 with quantity 1-5 returns those monitors in order; after setting F870/F871, one FC16 write of 2 registers at 16#1870 writes both items. These block addresses only accept those exact request shapes.

Questions about the Schneider Electric Altivar 212 (embedded Modbus RTU)

What Modbus registers does the Schneider Electric Altivar 212 (embedded Modbus RTU) have?

This map lists 55 registers: 55 holding registers. 25 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Schneider Electric Altivar 212 (embedded Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each parameter's communication number is its register address in hex: Fd00 is 16#FD00 = 64768, FA01 is 16#FA01 = 64001, and F802 is 16#0802 = 2050 (the leading F of Fxxx parameters is not part of the address). The manual prints both forms, and its example frame reads output frequency with starting address FD 00, so the address goes on the wire unchanged, with no 40001 offset and no minus 1.

What are the minimum Modbus registers to integrate the Schneider Electric Altivar 212 (embedded Modbus RTU)?

Start with HR 64000 FA00 - Command word 1 (FA00: run/stop/reset and priority bits); HR 64001 FA01 - Frequency reference from comm. (FA01: frequency reference, 0.01 Hz); HR 64768 Fd00 - Output frequency (Fd00: output frequency, 0.01 Hz); HR 64769 Fd01 - Status word (Fd01: status word); HR 65027 FE03 - Output current (FE03: output current, 0.01 %); HR 64656 FC90 - Trip code (FC90: present trip code); HR 64657 FC91 - Alarm code (FC91: alarm flags); HR 2129 F851 - Com. fault setting (F851: reaction to comm loss).

How do I enable Modbus control of the Schneider Electric Altivar 212 (embedded Modbus RTU)?

All communication settings are in [PROGRAMMING MENU] > [COMMUNICATION MENU] COM. F807 chooses which port may command the drive: 0 = RJ45, 1 = open-style terminal (factory). On the open-style port also set F829 = 1 (Modbus RTU, factory). F802 is the address for both ports (0 disables). Full network control: CMOd = 2 (Communication) and FMOd = 4 (Serial com ref.), changed only while stopped. Alternatively leave CMOd/FMOd on terminals and set FA00 bit 15 (commands) and bit 14 (reference) to take priority over the bus; the LOC/REM key and a logic input set to function 48 (Forced local) can still take control back.

What happens when the Schneider Electric Altivar 212 (embedded Modbus RTU) loses Modbus communication?

F803 [Com. time out], 0-100 s, factory 3 s (0 disables). The timer starts at the first valid frame addressed to the drive and is restarted by any request (read, write or identification). F851 lists the reactions 0 ramp stop and hand control back to CMOd/FMOd (LonWorks board only), 1 ignore, 2 ramp stop, 3 freewheel and 4 trip Err5 (RJ45) or Err8 (network port, factory). The programming manual adds that on Modbus only setting 1 is honoured and every other setting trips in Err5/Err8, so on Modbus expect either no reaction (1) or a trip. Detection is active when CMOd = 2 or FMOd = 4.
