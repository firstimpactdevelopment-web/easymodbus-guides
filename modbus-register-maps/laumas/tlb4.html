Laumas TLB4 four-channel weight transmitter (Modbus RTU / Modbus TCP) Modbus register map

Updated 17 November 2026

Short answer

The TLB4 is a DIN-rail weight transmitter for up to four load cells. Over Modbus RTU (or the Modbus/TCP version, which uses the same register list) it exposes gross, net and peak weight, a status word, digital I/O, setpoints and calibration values as holding registers, and takes commands (tare, zero, save) through a single command register. This map lists the directly addressed registers; settings reached through the exchange registers are left out.

Integration notes: Laumas TLB4 four-channel weight transmitter (Modbus RTU / Modbus TCP)

Integration in brief

Read 40007-40013 in one FC3 request: status word, then gross, net and peak weight as 32-bit H/L pairs. Apply the sign bits from the status word and the decimals from the division index. Write 7 / 9 / 8 to the command register 40006 for tare on, tare off and zero.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Select Modbus RTU in the instrument's serial communication menu and set address, baud, parity and stop bits there. The Modbus/TCP version gets its IP address from the Lantronix DeviceInstaller tool and listens on port 502.

Byte order & addressing

  • Only FC3 and FC16 are supported; use FC16 even for a single register (the manual's examples write with FC16).
  • At most 32 registers per request.
  • Weights carry no sign: check SR1 bits 7 (gross), 8 (net), 9 (peak).
  • Setpoints and some values are written to EEPROM (limited to about 100000 writes); setpoints themselves stay in RAM until command 99.

Network setup

  • Set the RS-485 address (1-99), baud rate, parity and stop bits in the instrument's serial communication setting menu.
  • For Modbus/TCP use port 502; the register set is identical to RTU.

Watch out for

  • Broadcast (address 0) writes are executed with no reply; broadcast reads are ignored.
  • Setpoints and hysteresis values are set to zero if the calibration is changed significantly.

Notes on this map

  • Host: this copy is hosted by AutomationDirect, not by Laumas; a short search did not find the same protocols manual as a direct download on laumas.com.
  • Word order: every 32-bit value is an H/L register pair with the high word at the lower address. The manual's read example returns gross weight 4000 as 0x0000 0x0FA0 at 40008-40009, so ABCD is documented.
  • Weights (GW, NW, PW) are positive magnitudes with the decimals implied by the division setting (DU low byte); the sign comes from SR1 bits 7-9. The manual says the calibration weight CALW is a signed 32-bit number (two's complement for negatives). It does not state signedness for setpoints, hysteresis, analog weights or preset tare; they are typed INT32 here, which only matters for negative values.
  • Left out: exchange registers 40051-40064 (R1/W1, EXC, AEXC). The list prints them as fourteen single registers while the other fieldbuses describe R1/W1 and EXC/AEXC as 4-byte values, and the exact register split for Modbus is not stated.
  • Parameters such as filter, sensitivity, full scale and zero tracking are reached by writing W1 and sending a 65xx command to CMDR; they are not listed because they go through the exchange registers.
  • Program type matters: peak weight, display coefficient, setpoints and CMDOUT are BASE program features; instrument status IS is LOAD program only.
  • Serial settings (baud, parity, address 1-99) are set from the instrument's own menu; the protocols manual does not give factory values.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Laumas TLB4 four-channel weight transmitter (Modbus RTU / Modbus TCP)

What Modbus registers does the Laumas TLB4 four-channel weight transmitter (Modbus RTU / Modbus TCP) have?

This map lists 25 registers: 25 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Laumas TLB4 four-channel weight transmitter (Modbus RTU / Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed 40001-40074. Laumas says to subtract 40001 for a 0-based client (40028 -> 27). The manual's read example asks for start address 0x0007 to read gross weight at 40008, confirming the offset.

What byte order does the Laumas TLB4 four-channel weight transmitter (Modbus RTU / Modbus TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Laumas TLB4 four-channel weight transmitter (Modbus RTU / Modbus TCP)?

Start with HR 6 Status register (SR1) (Status: stability, sign and load-cell errors); HR 7 Gross weight (GW) (Gross weight); HR 9 Net weight (NW) (Net weight); HR 13 Divisions and units of measure (DU) (Division index for the implied decimals); HR 5 Command register (CMDR) (Command register for tare / zero); HR 16 Digital inputs (INS) (Digital inputs).

How do I enable Modbus control of the Laumas TLB4 four-channel weight transmitter (Modbus RTU / Modbus TCP)?

Select Modbus RTU in the instrument's serial communication menu and set address, baud, parity and stop bits there. The Modbus/TCP version gets its IP address from the Lantronix DeviceInstaller tool and listens on port 502.
