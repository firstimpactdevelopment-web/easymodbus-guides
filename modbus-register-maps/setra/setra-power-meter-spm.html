Setra Systems Setra Power Meter (SPM) multi-circuit power meter Modbus register map

Updated 17 November 2026

Short answer

The Setra Power Meter is a multi-circuit meter with two voltage inputs and up to 48 configurable loads, each with three phases of CT inputs, reachable over Modbus RTU or Modbus TCP. Values are 32-bit floats and unsigned integers, most significant byte first. This map covers device identity and settings, both voltage inputs (voltages, angles, THD, frequency, service type) and the full Load 1 block with its three phases; Loads 2-48 repeat the same layout at higher addresses.

This page lists 132 Modbus registers for the Setra Systems Setra Power Meter (SPM) multi-circuit power meter — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Setra Systems’s own free documentation (linked below) and checked against it.

Integration notes: Setra Systems Setra Power Meter (SPM) multi-circuit power meter

Integration in brief

Read input registers with function 04: voltages from absolute 104, Load 1 totals from 324-369 and phases from 404, decoding floats high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Byte order & addressing

  • Floats are ABCD.
  • Register numbers are 30000 + address, not 30001 + address.

Network setup

  • Check Total Loads (86) and each load's and phase's 'enabled' row to see which blocks hold live data.

Watch out for

  • Disabled loads and phases still have registers; check their 'enabled' rows.

Notes on this map

  • Word order: every block of uint32/float32 values is headed 'Data Format: Big-Endian (high byte first, or most significant byte first)'. That describes the 32-bit values themselves, so the most significant byte, and with it the high word, comes first in the lower register: ABCD.
  • Loads 2-48 follow the Load 1 layout in later blocks (Load 2 starts at absolute 580); they are not repeated here.
  • Left out: 'id' identifier rows, pulse counts and scalers (user-configurable units), the Modbus slave address row, the date/time string and reserved rows.
  • Input registers (function 04) are implied by the 3xxxx register numbers.
  • Left out: the kVAh+ and kVAh- rows (total and per phase). Their names say apparent energy but the unit column prints kilo-volt-amperes-reactive-hour, so the unit is not settled.
  • Addressing: the 'Absolute Address' column starts at 0 for the first register (Device_Name), so it is used as the wire address; the 'Modbus Register' column is that number plus 30000.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Setra Systems Setra Power Meter (SPM) multi-circuit power meter

What Modbus registers does the Setra Systems Setra Power Meter (SPM) multi-circuit power meter have?

This map lists 132 registers: 132 input registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Setra Systems Setra Power Meter (SPM) multi-circuit power meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row gives an 'Absolute Address' and a 'Modbus Register'. The list starts at absolute address 0 (Device_Name, register 30000), and every register number is 30000 + the absolute address, so the absolute address is the wire address for an input-register read: Vin1 L1-N is absolute 104 (register 30104).

What byte order does the Setra Systems Setra Power Meter (SPM) multi-circuit power meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Setra Systems Setra Power Meter (SPM) multi-circuit power meter?

Start with IR 104 Vin1_L1-N (Vin1 L1-N voltage); IR 128 Vin1_Freq (Frequency); IR 324 Load 1 total_kWh (Load 1 net kWh); IR 352 Load 1 total_amperage (Load 1 total current); IR 354 Load 1 total_kW (Load 1 total kW); IR 360 Load 1 total_aPF (Load 1 power factor).

How do I enable Modbus control of the Setra Systems Setra Power Meter (SPM) multi-circuit power meter?

The list does not describe setup. It shows the meter can run Modbus TCP (the slave address row reads 0 in that mode) as well as a serial slave address.
