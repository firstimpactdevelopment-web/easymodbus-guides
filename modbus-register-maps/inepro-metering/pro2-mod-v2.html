Short answer

The PRO2-Mod is inepro's single-phase MID DIN-rail energy meter with an RS485 Modbus RTU port (this is the older PRO line, not the 2026 PRO1/PRO2 template). Every measurement is an IEEE 754 float, high word first, read with function 03 from hex blocks 4000h (setup), 5000h (live values) and 6000h (energy). The map covers voltage, current, power, power factor, frequency, total/tariff energy and the writable ID, baud, parity, S0, tariff and combination-code settings.

Integration notes: inepro Metering PRO2-Mod single-phase energy meter (PRO2 series, manual 2.18-6)

Integration in brief

Wire RS485 to terminals 10 and 11, poll unit 1 at 9600 baud 8E1 with function 03 and decode each value as a high-word-first float. Live values sit at 5000h-502Bh, energy at 6000h-604Ah.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is on the -Mod version only. Set the ID in Program mode 2 and baud/parity in Program mode 3 (4-digit password, default 0000), or over Modbus at 4003h/4004h/4011h.

Byte order & addressing

  • Addresses are hex: 5012h is decimal 20498 on the wire.
  • Floats are ABCD (high word first).
  • Power is in kW/kvar/kVA, not W.
  • Default parity is even (8E1), not 8N1.

Network setup

  • RS485 on terminals 10 and 11; defaults Modbus ID 1, 9600 baud, 8 data bits, even parity, 1 stop bit.
  • Baud can be lowered to 4800, 2400 or 1200; parity can be none or odd; data and stop bits are fixed.
  • Fit a 120 ohm / 0.25 W resistor across the RS485 terminals at the meter when testing through an RS485 converter.

Watch out for

  • Program mode 3 settings (S0, combination code, baud, parity, power-down counter) need the display password (default 0000).
  • Total active energy (6000h) follows the combination code; read forward (600Ch) and reverse (6018h) for import and export.

Notes on this map

  • The PDF is inepro's own user manual (hosted on inepro's website CDN).
  • The register map is shared with the PRO380; rows marked '*PRO380 only' (L2/L3 values, per-phase energy, CT ratio/mode, L2/L3 current direction and quadrants) are left out of this single-phase file.
  • 'Float ABCD' = IEEE 754 32-bit float, high word first. 'Signed' rows are 16-bit integers.
  • Units are as printed: power in kW, kvar and kVA (not W), energy in kWh and kvarh.
  • Left out: serial number, meter code, checksum and active status word (typed HEX with no decoding), LCD cycle time (HEX; the write example 0025 for 25 s suggests BCD), current direction (ASCII) and error code 4015h (no code list given).
  • Baud rate (4004h) is written as the plain number, e.g. 2580h = 9600. The Modbus section allows 1200, 2400, 4800 and 9600.
  • Combination code 11 is marked PRO380 only and is left out of the value list.
  • The day-counter write row prints function 06 and length 1, but its example frame writes 2 registers with function 16; it is listed here as a 2-register float.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the inepro Metering PRO2-Mod single-phase energy meter (PRO2 series, manual 2.18-6)

What Modbus registers does the inepro Metering PRO2-Mod single-phase energy meter (PRO2 series, manual 2.18-6) have?

This map lists 40 registers: 40 holding registers. 8 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the inepro Metering PRO2-Mod single-phase energy meter (PRO2 series, manual 2.18-6) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map prints hex addresses that go into the request unchanged; the manual's example frames are 01 06 4003 000A (set Modbus ID) and 01 06 6048 0002 (set tariff). So 5012h (total active power) is wire address 20498. Do not enter the hex numbers as decimal.

What byte order does the inepro Metering PRO2-Mod single-phase energy meter (PRO2 series, manual 2.18-6) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the inepro Metering PRO2-Mod single-phase energy meter (PRO2 series, manual 2.18-6)?

Start with HR 20480 Voltage (Voltage); HR 20490 Current (Current); HR 20498 Total active power (Total active power (kW)); HR 20522 Power factor (Power factor); HR 20488 Grid frequency (Grid frequency); HR 24588 Forward active energy (Forward (import) active energy); HR 24600 Reverse active energy (Reverse (export) active energy).

How do I enable Modbus control of the inepro Metering PRO2-Mod single-phase energy meter (PRO2 series, manual 2.18-6)?

Modbus is on the -Mod version only. Set the ID in Program mode 2 and baud/parity in Program mode 3 (4-digit password, default 0000), or over Modbus at 4003h/4004h/4011h.
