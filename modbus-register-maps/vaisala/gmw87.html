Integration notes: Vaisala GMW87 CO2 and temperature wall transmitter (Modbus RTU)

Integration in brief

Read holding registers 1-2 for CO2 as a CDAB float, or 257 as an integer. Status 513 is 0 when the device is OK.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the Modbus address, bit rate and parity with the DIP switches on the transmitter board before power-up.

Byte order & addressing

  • Floats are low word first (CDAB); pick "word-swapped" float in masters that default to high word first.
  • Read each 32-bit value in one transaction.

Network setup

  • Address (1-247), bit rate (4800, 9600, 19200, 38400, 57600, 76800 or 115200) and parity (None or Even) are set with DIP switches on the component board; the guide gives no factory default.
  • 1 and 2 stop bits are both accepted automatically.
  • Up to 8 transmitters per RS-485 line; turn on the 120 ohm termination DIP switch only on the last device if the bus has no other terminator.

Watch out for

  • With all address switches off (address 0) the transmitter is offline and never answers.
  • Use the test registers (7937, 7938) to confirm float format and addressing before trusting readings.

Notes on this map

  • All registers are holding registers read with function 03; the guide lists no write function code.
  • 32-bit floats and 32-bit integers put the least significant word at the listed register (CDAB). The guide states this and its worked read example confirms it.
  • Unavailable data reads as quiet NaN (float) or 0x8000 (16-bit integer) rather than an exception.
  • Only GMW87 has the RS-485 Modbus interface; the other GMW80 models are analog.
  • The temperature value is the internal device temperature, not a specified room measurement.
  • Left out: error code register 514, a 32-bit integer meant for Vaisala support; the guide states the word order only for 32-bit floats.
  • Left out: text string test register 7940, because the guide does not give its length in registers.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Vaisala GMW87 CO2 and temperature wall transmitter (Modbus RTU)

What Modbus registers does the Vaisala GMW87 CO2 and temperature wall transmitter (Modbus RTU) have?

This map lists 9 registers: 9 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vaisala GMW87 CO2 and temperature wall transmitter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide numbers registers in decimal starting at 1 and also prints the 0-based hex address used in the request; register number 1 is address 0x0000 on the wire.

What byte order does the Vaisala GMW87 CO2 and temperature wall transmitter (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Vaisala GMW87 CO2 and temperature wall transmitter (Modbus RTU)?

Start with HR 0 Measured CO2 (CO2 ppm); HR 256 Measured CO2 (integer) (CO2 ppm (integer)); HR 512 Device status (Device status); HR 519 CO2 measurement status (CO2 measurement status).

How do I enable Modbus control of the Vaisala GMW87 CO2 and temperature wall transmitter (Modbus RTU)?

Set the Modbus address, bit rate and parity with the DIP switches on the transmitter board before power-up.

Where is the official Vaisala GMW87 CO2 and temperature wall transmitter (Modbus RTU) Modbus documentation?

The source is GMW80 Series User Guide (M211748EN-H), revision 2021-10, published free by Vaisala at https://docs.vaisala.com/r/M211748EN-H/en-US.
