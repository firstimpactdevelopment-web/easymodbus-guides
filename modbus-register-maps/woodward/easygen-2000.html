Updated 17 November 2026

Short answer

The easYgen-2000 series (2200/2300/2500) is Woodward's genset controller for single and paralleled sets. It is a Modbus RTU slave: data protocol 5100 is block-read from Modicon 450001, and parameters 503-510 take remote start/stop, acknowledge and interface setpoints. This map covers voltages, currents, frequencies, energy and hours, the operating state, control and alarm bit words, J1939 speed/pressure/hours and the remote-control parameters.

Integration notes: Woodward easYgen-2000 Series genset controller (easYgen-2200 / 2300 / 2500)

Integration in brief

Block-read up to 128 holding registers from wire address 50000. Start or stop by writing 0 and then bit 0 (start) or bit 1 (stop) to parameter 503; acknowledge with two rising edges of bit 4.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Enable Modbus on the serial interface and set its slave ID and baud in the controller's interface parameters. Include 04.13 Remote request in the LogicsManager start condition for remote starts.

Byte order & addressing

  • Commands act on rising edges: write 0, then the bit.
  • 32-bit parameters (507, 510) are written as two registers in one request, high word first; 507 overlaps 508 and 510 overlaps 511, so never block-write across them.

Network setup

  • Block reads of 1-128 registers are allowed in the visualization range.

Watch out for

  • Writing parameter 503 can start or stop the engine; coordinate with site staff.

Notes on this map

  • In the 5100 table, values occupying data bytes 3-6 are 32-bit (two registers); the others are 16-bit. The manual states 32-bit Modbus values go high word first (interface setpoint examples), so ABCD.
  • The 5100 table does not say whether values are signed. Values that cannot be negative (voltages, currents, frequencies, energy, hours, speed, pressures, levels) are listed as unsigned, which reads them correctly either way. Left out for that reason: generator/mains real and reactive power, power factors, temperatures, engine torque, hours until maintenance and the active power / PF setpoint readbacks.
  • Also left out: analog inputs/outputs (scaling 'changeable' or no sign), J1939 DM1/DM2 SPN entries and lamp words, and ECU-specific stop codes. The 5101 protocol (without J1939) is not covered.
  • Remote start/stop needs the LogicsManager start request to include 04.13 Remote request. Interface setpoints only act when the AnalogManager source (05.06, 05.12, 05.03, 05.09) points at the interface value; no password is needed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Woodward easYgen-2000 Series genset controller (easYgen-2200 / 2300 / 2500)

What Modbus registers does the Woodward easYgen-2000 Series genset controller (easYgen-2200 / 2300 / 2500) have?

This map lists 71 registers: 71 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Woodward easYgen-2000 Series genset controller (easYgen-2200 / 2300 / 2500) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The 5100 table prints the Modicon address (450001) and a start address one lower (450000); the manual says 450001 may become bus address 50000, so the wire address is the Modicon number minus 400001. Parameters use Modicon 40000 + (parameter ID + 1): parameter 503 is 40504 = wire address 503. The manual says some PC tools need a shift of one (504).

What byte order does the Woodward easYgen-2000 Series genset controller (easYgen-2200 / 2300 / 2500) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Woodward easYgen-2000 Series genset controller (easYgen-2200 / 2300 / 2500)?

Start with HR 50002 Control mode (Control mode AUTO/STOP/MANUAL); HR 50018 Operation mode / status (Operating state); HR 50045 Alarm classes latched (Latched alarm classes); HR 50006 Gen. frequency (Generator frequency); HR 50052 Gen. voltage L1-L2 (Generator voltage L1-L2); HR 50034 Gen. current 1 (Generator current 1); HR 50021 Battery voltage (Battery voltage); HR 503 Remote control word 1 (Remote start / stop / acknowledge).

How do I enable Modbus control of the Woodward easYgen-2000 Series genset controller (easYgen-2200 / 2300 / 2500)?

Enable Modbus on the serial interface and set its slave ID and baud in the controller's interface parameters. Include 04.13 Remote request in the LogicsManager start condition for remote starts.
