Short answer

Microprocessor-controlled hot-water mixing/recirculation valve that blends hot and cold water to a setpoint, with high/low alerts, an over-temperature error and a thermal-disinfection cycle. Over Modbus RTU it exposes holding registers for setpoint, status, outlet and inlet temperatures (0.1 °C), error codes, alarm limits, disinfection commands and an error log.

Integration notes: Armstrong International Brain DRV25 / DRV40 / DRV80 digital recirculation valve (Modbus RTU)

Integration in brief

Wire the DRV's RS-485 port at 9600 8N1, then read registers 4 (status), 6 (outlet temperature) and 8 (error code). Write the setpoint to register 1 in tenths of °C; set register 4 to Off before changing configuration registers 400-411 and back to On afterwards.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is fixed at 9600 bps, no parity, 8 data bits, 1 stop bit. Set the unit address (1-31, read back in register 0) before connecting to the network: on DRV40/80 with the DRV Programming Software through the CN3 port (valve Off), on DRV25 with the SAGE mobile app over Bluetooth. The same software switches the CN2 network port from SAGE BS to Modbus.

Byte order & addressing

  • Disinfection needs registers 23, 401 and 402 set up, then 0x6172 to 306 and 0x5452 to 307 within 10 seconds; writes out of order are rejected.
  • DRV25: fit the CN10 jumper to switch in the end-of-line termination resistor if long cables or reflections make communication unreliable.

Network setup

  • Function codes 03, 06 and 16 only.
  • Modbus is 9600 bps only (BACnet supports higher rates).
  • Use Cat5 twisted pair in a daisy chain; do not wire the valves in a star.

Watch out for

  • An over-temperature error drives the valve full cold and stays latched until power is cycled.
  • Abort (308) while the cycle is at full hot sends the valve full cold and shows Error Temp until power is cycled.

Notes on this map

  • Armstrong International (hot-water group) is a different company from Armstrong Fluid Technology (pumps).
  • Addressing: resolved as 0-based because the table includes a real register 0 (Unit Address), which only exists in 0-based numbering; the guide gives no example frame.
  • Temperatures are listed as '0.1 Deg C' and are used with scale 0.1. Signedness is not stated; they are typed UINT16 (hot-water temperatures). Offset Temperature (407, 0.1 Deg C, R/W) is left out because an offset can be negative and the guide does not say whether it is signed.
  • Left out: all two-part 'Long' values (serial number 106-107, manufacture date 108-109, commissioning date 116-117, operation count 121-122, on time 123-124, unused hours 128-129, disinfection dates 156-157, clock 288-289 and the error log dates), because the guide does not say which half is high; the 16-register Valve Identity/Location string (139-154), because character order is not stated; and register 114, printed with two conflicting rows.
  • The DRV25/DRV40/DRV80 support columns in the table are graphical marks and are not reproduced; some registers (alerts, relay) apply only to DRV40/80.
  • Allow at least 5 s between a write and the next read.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Armstrong International Brain DRV25 / DRV40 / DRV80 digital recirculation valve (Modbus RTU)

What Modbus registers does the Armstrong International Brain DRV25 / DRV40 / DRV80 digital recirculation valve (Modbus RTU) have?

This map lists 46 registers: 46 holding registers. 23 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Armstrong International Brain DRV25 / DRV40 / DRV80 digital recirculation valve (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. IOM-776 lists plain register numbers starting at 0 (Unit Address is register 0) and supports function codes 03, 06 and 16. A register numbered 0 can only be a protocol (PDU) address, so the listed numbers are used as wire addresses.

What are the minimum Modbus registers to integrate the Armstrong International Brain DRV25 / DRV40 / DRV80 digital recirculation valve (Modbus RTU)?

Start with HR 6 Valve Outlet Temperature (Outlet (blended) temperature); HR 1 Setpoint Temperature (Setpoint); HR 4 Valve Status (Valve status / on-off-full cold); HR 8 Valve Error Code (Active error code); HR 10 Hot Inlet Temperature (Hot inlet temperature); HR 11 Cold Inlet Temperature (Cold inlet temperature).
