Short answer

The PM180 expertmeter is SATEC's high-performance power quality analyzer with serial, Ethernet and expandable I/O. Its 32-bit register set carries 1-second phase and total values, demands and energy counters as integers, low word first. This map covers volts, amps, power, PF, THD, frequency, unbalance, present demands, energy totals, digital I/O, basic wiring/CT/PT setup, COM1 settings, password and clear commands.

This page lists 129 Modbus registers for the SATEC PM180 expertmeter high performance analyzer — 13 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from SATEC’s own free documentation (linked below) and checked against it.

Integration notes: SATEC PM180 expertmeter high performance analyzer

Integration in brief

Read 13952 onward (phase values) and 14336 onward (totals) with function 03; decode 32-bit integers low word first. Energy totals start at 14720; check the energy decimal places setting (46258) before scaling.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the port protocol, address and baud for COM1 at 46448-46452 (or from the front panel/PAS); Modbus/TCP runs on the Ethernet port.

Byte order & addressing

  • 32-bit values are low word first (CDAB).
  • Voltage and power units change from 0.1 V / 1 W to 1 V / 1 kW when a PT ratio above 1 is set.
  • Energy resolution depends on 46258.

Network setup

  • Set wiring mode, PT ratio and CT primary at 46208-46213 first.
  • Write the 8-digit password to 44378 if protection is on.

Watch out for

  • Changing the PT ratio from 1 changes the meaning of every voltage and power register.

Notes on this map

  • Addressing: the guide says to add 40001 to a register address to get the Modicon holding-register number (400001 above 9999), so printed addresses are 0-based wire addresses.
  • Word order: 32-bit values are sent with the low-order word in the first (even) register and the high-order word in the second, so they are CDAB here.
  • Units U1 (voltage) and U3 (power) depend on the PT ratio: with PT ratio = 1 they are 0.1 V and 0.001 kW/kvar/kVA (the scales used here); with PT ratio > 1 they become 1 V and 1 kW/kvar/kVA. U2 (current) is always 0.01 A.
  • Function 04 can be used the same way as function 03.
  • Energy registers use unit U5, set by 'number of energy decimal places' (46258, 0-3, default 0). The scale here (1 kWh/kvarh/kVAh) is for the default; with 1, 2 or 3 decimals use 0.1, 0.01 or 0.001.
  • The Total Energies block header prints 14720-14741, but its rows run to +42,43 (kvarh Q4 at 14762); the per-row offsets are used here.
  • V4 voltage (14476) uses unit U4 (V4 PT ratio) and is left out.
  • Left out: 16-bit scaled registers, 1/2-cycle, 0.2-second and 3-second values, low/high phase values, harmonics and interharmonics, IEEE 519 statistics, min/max logs, billing/TOU, setpoints, files and COM2-COM5 settings.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the SATEC PM180 expertmeter high performance analyzer

What Modbus registers does the SATEC PM180 expertmeter high performance analyzer have?

This map lists 129 registers: 129 holding registers. 13 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the SATEC PM180 expertmeter high performance analyzer Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide numbers registers from 0 and says to add 40001 (or 400001 above 9999) to get Modicon holding-register numbers, so the printed address is the wire address: 13952 is requested as 13952 (Modicon 413953).

What byte order does the SATEC PM180 expertmeter high performance analyzer use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the SATEC PM180 expertmeter high performance analyzer?

Start with HR 13952 V1 voltage (V1 voltage); HR 13958 I1 current (I1 current); HR 14336 Total kW (Total kW); HR 14342 Total PF (Total PF); HR 14468 Frequency (Frequency); HR 14720 kWh import (kWh import); HR 14722 kWh export (kWh export).

How do I enable Modbus control of the SATEC PM180 expertmeter high performance analyzer?

Set the port protocol, address and baud for COM1 at 46448-46452 (or from the front panel/PAS); Modbus/TCP runs on the Ethernet port.
