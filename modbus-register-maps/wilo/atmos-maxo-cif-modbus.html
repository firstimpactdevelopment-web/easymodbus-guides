Wilo Atmos MAXO with CIF module Modbus RTU Modbus register map

Updated 17 November 2026

Short answer

The Wilo Atmos MAXO gets Modbus RTU through Wilo's plug-in CIF module. A master switches the pump on/off with the pump command word, selects the control mode and writes a relative duty point in 0.5 % steps; a bus command timer can fall back to preset values when communication stops. Read-only data covers head, flow, power, energy, speed, temperatures and status/error words. This map keeps only the points Wilo marks as supported on the Atmos MAXO.

This page lists 36 Modbus registers for the Wilo Atmos MAXO with CIF module Modbus RTU — 10 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Wilo’s own free documentation (linked below) and checked against it.

Integration notes: Wilo Atmos MAXO with CIF module Modbus RTU

Integration in brief

Set bus address, baud (parameter A) and frame (parameter C) in the pump menu, then write the control mode (H 42), the duty point (H 1) and the pump command (H 40). Poll status (I 404 if present), error code (I 940) and the measured values in the I 1-I 10 block.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Plug in the CIF module Modbus RTU and set the bus address (menu <5.2.3.0>), baud rate (parameter A, <5.2.4.0>: 5 = 9600, 6 = 19200, 7 = 38400 ...) and frame (parameter C, <5.2.5.0>: 2 = 8N1, 3 = 8N2, 6 = 8E1, 10 = 8O1). OFF as bus address disables the interface.

Communication loss & watchdog

The bus command timer (H 300, timeout in H 400 where supported) can switch the pump to the preset command, mode and duty point (H 402-405) when the master stops refreshing it.

Byte order & addressing

  • Register numbers are raw wire addresses; do not subtract 1.
  • Duty points are in 0.5 % steps (200 = 100 %).
  • Unsupported control-mode values are ignored by the pump.

Network setup

  • Where a setpointSignalSource register is listed, select IF-Module (value 1) as the setpoint source if the duty point should come from the bus.
  • Terminate the RS-485 line at both ends.

Watch out for

  • Temperatures are in kelvin.
  • Last write wins between the bus, the pump display and other remote controls.

Notes on this map

  • Source is Wilo's public HTML functional description for the CIF module Modbus RTU, which marks every register and every enumeration/bit value with the pump families that support it. Only registers, values and bits marked for Atmos MAXO are kept here; values and bits not listed are not supported on this pump. Facts are re-keyed and the document is linked, not re-hosted.
  • 32-bit values (REAL = FLOAT32, UDINT = UINT32) are stored with the most significant 16 bits at the base address (ABCD), as stated in section 6.1.4.
  • Scale: engineering value = raw x scale from Wilo's list (e.g. pressure x 10 = cm H2O, operation time x 10 = h, flow x 0.1 = m3/h, duty point x 0.5 = %, temperatures x 0.1 = K).
  • Temperatures are in kelvin with scale 0.1 (raw 2932 = 293.2 K, about 20 °C).
  • Error values: an unavailable reading returns the largest positive value of its data type (65535 for UINT, 32767 for INT).
  • Flow (input register 2): Wilo lists it twice with the same address, type and scale; up to module 6.00 its error value is 9999, from 6.01 it is 65535.
  • Module-version requirements from the list are noted in descriptions ('Module 3.01+' etc.); registers without a note exist from module version 1.00.
  • Left out: identification registers (700-750: BCD software revisions, vendor ID, UUID, article number), system time (502), energy-meter start timestamps (306/310), the double-pump total runtime (9) and 'pressure max-pres-value' (212, ambiguous between live and maximum pressure).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Wilo Atmos MAXO with CIF module Modbus RTU

What Modbus registers does the Wilo Atmos MAXO with CIF module Modbus RTU have?

This map lists 36 registers: 26 input registers, 10 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Wilo Atmos MAXO with CIF module Modbus RTU Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Wilo states that all register addresses are raw addresses as sent on the bus; its example frame 01 04 02 BC 00 01 reads input register 700 (0x02BC). Masters that count registers from 1 must add 1.

What byte order does the Wilo Atmos MAXO with CIF module Modbus RTU use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Wilo Atmos MAXO with CIF module Modbus RTU?

Start with HR 40 Pump Command in (On/off command (bit 3 = 1 when writing, if listed)); HR 42 controlFunction (Control mode); HR 1 dutyPointRel (Setpoint (duty point, 0.5 % steps)); IR 404 Operation Status (Operation status flags); IR 940 warning/errorMessage (Active warning/error code); IR 1 pressure (Actual pressure); IR 2 flow (Flow); IR 4 powerInput (Power input).

How do I enable Modbus control of the Wilo Atmos MAXO with CIF module Modbus RTU?

Plug in the CIF module Modbus RTU and set the bus address (menu <5.2.3.0>), baud rate (parameter A, <5.2.4.0>: 5 = 9600, 6 = 19200, 7 = 38400 ...) and frame (parameter C, <5.2.5.0>: 2 = 8N1, 3 = 8N2, 6 = 8E1, 10 = 8O1). OFF as bus address disables the interface.

What happens when the Wilo Atmos MAXO with CIF module Modbus RTU loses Modbus communication?

The bus command timer (H 300, timeout in H 400 where supported) can switch the pump to the preset command, mode and duty point (H 402-405) when the master stops refreshing it.
