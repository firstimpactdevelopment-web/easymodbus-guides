Short answer

The Cube and Rail IP meters are Northern Design three-phase meters with a built-in Ethernet port and a Modbus TCP server on port 502. The manual recommends polling the read-only amalgamated data table, which packs energy, volts, amps, power, power factor, demand and the scale exponents into one block of integers. Energy counters are also in a writable 32-bit table.

This page lists 64 Modbus registers for the Northern Design Cube & Rail IP Meter (Ethernet, Modbus TCP) — 8 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Northern Design’s own free documentation (linked below) and checked against it.

Integration notes: Northern Design Cube & Rail IP Meter (Ethernet, Modbus TCP)

Integration in brief

Connect to port 502 and read the amalgamated table 7680-7737 with function 03 (split into requests your client accepts). Read the scale exponents at 7733-7737 first, then apply raw x 10^(K-3) to each instantaneous value and 10^(Ke-6) to the energy counts.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The manual describes no enable step: the Modbus TCP server answers on port 502 at the meter's IP address. By default the meter takes its IP settings from DHCP and falls back to 192.168.1.127 if none is found; the address can also be set on the front panel or the Network Settings web page.

Byte order & addressing

  • The amalgamated tables refresh once per second; polling faster gains nothing.
  • Scale registers are exponents offset by 3 (raw x 10^(K-3)), not plain multipliers.
  • Only functions 3, 4 and 6 are implemented; clients that write with function 16 will be refused.

Network setup

  • Port 502. The meter uses DHCP by default (fallback 192.168.1.127, mask 255.255.255.0); a static address can be set on the front panel or the Network Settings web page.
  • The manual covers V2 IP meters only; check the rear label for 'IP.Ver: V2'.

Watch out for

  • The energy counters at 514-529 are writable; a stray write changes the stored totals.
  • The amalgamated tables are read only; write energy presets through the 512-529 block instead.

Notes on this map

  • Northern Design does not host this manual publicly; the link is a copy on a distributor's file host (the same host used for the Cube 350 and multicube manuals).
  • 32-bit values: every energy row is printed as a High Word at the lower address followed by the Low Word, so ABCD.
  • Instantaneous values are signed integers of the displayed digits. Real value = raw x 10^(K-3) with K = Ki (7733), Kvp (7734), Kvl (7735) or Kp (7736); demand power rows use Kp + 1. These rows are listed with scale 1 and no unit. Frequency (500 = 50.00), power factor (1000 = 1.000) have fixed printed scales.
  • Energy counts: kWh = raw x 10^(Ke-6) and Wh = raw x 10^(Ke-3). The manual's formula names register 40516, but its worked example shows the 40515-40516 pair is meant. Ke is at 513 and also at 7737.
  • The data type of the Ki/Kvp/Kvl/Kp/Ke registers is not printed; they are small positive exponents (the example gives 1 to 4), listed as UINT16.
  • Row 7684 is printed only as 'Kvarh' without saying inductive or capacitive.
  • Left out: amalgamated data table 2 (5632-5672). Several of its rows are marked Read/Write while the table note says the whole table is read only, and most rows give no data format.
  • The TCP server supports functions 3, 4 and 6 only (no function 16).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Northern Design Cube & Rail IP Meter (Ethernet, Modbus TCP)

What Modbus registers does the Northern Design Cube & Rail IP Meter (Ethernet, Modbus TCP) have?

This map lists 64 registers: 64 holding registers. 8 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Northern Design Cube & Rail IP Meter (Ethernet, Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print a 0-based data address next to the Modicon register number (7680 = 47681). The data address is what goes on the wire: request 7680 to read 47681.

What byte order does the Northern Design Cube & Rail IP Meter (Ethernet, Modbus TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Northern Design Cube & Rail IP Meter (Ethernet, Modbus TCP)?

Start with HR 7736 Power Scale Kp (Power scale Kp); HR 7705 System kW (System kW (raw)); HR 7691 Phase 1 Volts (Phase 1 volts (raw)); HR 7688 Phase 1 Amps (Phase 1 amps (raw)); HR 7697 Frequency (Frequency); HR 7701 System PF (System power factor); HR 7737 Energy Scale Ke (Energy scale Ke); HR 7680 kWh (kWh counter).

How do I enable Modbus control of the Northern Design Cube & Rail IP Meter (Ethernet, Modbus TCP)?

The manual describes no enable step: the Modbus TCP server answers on port 502 at the meter's IP address. By default the meter takes its IP settings from DHCP and falls back to 192.168.1.127 if none is found; the address can also be set on the front panel or the Network Settings web page.
