Short answer

Integration notes: Teracom TSM400-4-CP Modbus CO2 and barometric pressure sensor

Integration in brief

Read CO2 and pressure as floats at PDU 106-109 with function 03, or as plain 16-bit values at PDU 603-604.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is the only interface and is always active; there is nothing to switch on. Factory settings are address 1, 19200 baud, 8E1.

Byte order & addressing

  • Baud rate and framing changes only take effect after the device is powered off and on again.
  • Word order for every 32-bit value is set by the Data order register (PDU 13); check it before blaming the scaling.

Network setup

  • Set unit ID (PDU 10), baud (PDU 11) and framing (PDU 12), then power-cycle the device.
  • Terminate both ends of the RS-485 bus with 120 ohm; the built-in resistor is enabled by shorting the RS485- and TERM terminals. A daisy chain is recommended.

Notes on this map

  • Addresses are taken from the manual's PDU address column (0-based); the logical column is the same number plus 40001, the holding-register offset the manual states.
  • All 32-bit values follow the Data order register (PDU 13): 1 = most significant word first (factory default), 2 = least significant word first. The map shows the default, ABCD.
  • Left out: the 32-bit float/integer test-value registers (PDU 82-95), which only exist to check word order; the 16-bit test values are kept.
  • The mmHg x100 pressure in the integer block is split into a high word and a low word (PDU 704/705); they are listed as two 16-bit registers as the manual does. Combine as high x 65536 + low, then divide by 100.
  • CO2 automatic self-calibration is switched by PDU 2002 (0 = off, 1 = on); it assumes the sensor sees about 400 ppm fresh air at least weekly.
  • Readings can be trimmed with the multiplier and offset floats near PDU 2115: corrected = measured x multiplier + offset.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Teracom TSM400-4-CP Modbus CO2 and barometric pressure sensor

What Modbus registers does the Teracom TSM400-4-CP Modbus CO2 and barometric pressure sensor have?

This map lists 24 registers: 24 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Teracom TSM400-4-CP Modbus CO2 and barometric pressure sensor Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register table prints both a PDU (wire) address and a logical address (PDU + 40001 for holding registers). 'documented' holds the logical number; the PDU number is what goes in the request, e.g. logical 40101 = PDU 100.

What byte order does the Teracom TSM400-4-CP Modbus CO2 and barometric pressure sensor use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Teracom TSM400-4-CP Modbus CO2 and barometric pressure sensor?

Start with HR 106 CO2, ppm (CO2 ppm (float)); HR 108 Pressure, hPa (Pressure hPa (float)); HR 603 CO2, ppm (CO2 ppm (uint16)); HR 604 Pressure, hPa (Pressure hPa (uint16)); HR 2002 Automatic self-calibration (ASC) (CO2 self-calibration on/off).

How do I enable Modbus control of the Teracom TSM400-4-CP Modbus CO2 and barometric pressure sensor?

Modbus RTU is the only interface and is always active; there is nothing to switch on. Factory settings are address 1, 19200 baud, 8E1.

Where is the official Teracom TSM400-4-CP Modbus CO2 and barometric pressure sensor Modbus documentation?

The source is TSM400-4-CP User manual (TSM400-4-CP-R1.9), revision 2026-10, published free by Teracom at https://www.teracomsystems.com/download/tsm400-4-cp-modbus-co2-and-pressure-sensor/.
