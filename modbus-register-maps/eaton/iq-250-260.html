Eaton IQ 250 / IQ 260 Electronic Power Meter Modbus register map

Updated 16 October 2026

Short answer

The IQ 250 and IQ 260 are panel-mount multifunction power meters with a serial COM2 port (Modbus RTU, Modbus ASCII or DNP) and optional plug-in cards, including a network card for Modbus TCP. Everything sits in holding registers: live readings and demand values are IEEE floats in primary units, while status, THD and angles are 16-bit integers. This map covers identification, primary readings, demand, maximum demand, phase angles, status, THD, reset commands and the CT/PT and COM2 settings.

This page lists 97 Modbus registers for the Eaton IQ 250 / IQ 260 Electronic Power Meter — 19 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Eaton’s own free documentation (linked below) and checked against it.

Integration notes: Eaton IQ 250 / IQ 260 Electronic Power Meter

Integration in brief

Poll holding registers 999-1028 (wire) with function 03 to get voltages, currents, totals, PF and frequency as big-endian floats in primary units; read the demand block at 1999 and the status word at 4500. Settings changes need a password-protected privileged session and settings-update mode.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Reads need no enabling. To change settings: write the password to Open Privileged Command Session (21002), then Initiate Programmable Settings Update (21003), write the settings, use the checksum registers 21004/21005 (writing 21005 saves the settings to non-volatile memory), then write Terminate (21007), which restarts the meter. Reset commands (20000, 20001) take the password directly.

Byte order & addressing

  • Holding registers only; the map has no input registers.
  • 32-bit values are high word first (ABCD).
  • The printed decimal register is one higher than the wire address; the printed hex column is the wire address.
  • Per-phase power and power factor read zero unless the hookup is wye.
  • Registers not in the map read 0 and accept writes that do nothing.

Network setup

  • Set the COM2 address, baud rate and protocol from the front panel or Eaton's configuration software; over Modbus they live in 30026-30027 and can only be written in settings-update mode.
  • COM2 baud choices in the map: 9600, 19200, 38400 or 57600.

Watch out for

  • Meter Data readings are 0 until the first measurements are ready and while the meter is in settings-update mode (measurement state 'off').
  • Reset energy after changing the Power & Energy Format register, as the map advises.
  • A THD register reading raw 10000 means THD is unavailable (low signal, delta voltage, or model).

Notes on this map

  • Word order: the map's data-format preface says that for 32-bit integers and floats the lower-addressed register holds the high-order half, and its worked float example (C4E1 then 1DB9 = -1800.929) confirms it. All 32-bit values here are ABCD.
  • Eaton publishes this map on its Power Xpert Meter 2000 product page under a file name that also mentions the PXM 2000, but the document text itself only names the IQ 250/260. This entry is therefore limited to the IQ 250/260.
  • Left out: the integer Readings Block (registers 279-305). Its scale and decimal-point position come from the programmable settings, so a fixed scale cannot be given. Use the float Primary Readings Block instead.
  • Left out: every energy counter (Primary Energy Block 1500-1571, Uncompensated energy 3032-3103 and the secondary-block energy 40022-40061). They are signed or unsigned 32-bit integers whose implied decimal point and unit/kilo/mega multiplier depend on the Power & Energy Format register (30006), which the schema cannot express as a fixed scale. Read 30006 and apply its energy scale and decimal digits yourself if you need them.
  • Left out: the secondary readings block 40002-40073. These values use offset formulas such as 150 x (raw - 2047) / 2047 that do not fit a simple scale and offset.
  • Left out: short-term and minimum/maximum blocks other than the maximum demand values, timestamped min/max blocks, option-card blocks, log setup and log retrieval blocks, TSTAMP registers (three-register date/time) and the limit setpoints.
  • Map typo, not used here: in the Short Term Primary Maximum block, Volts C-N Maximum is printed with hex 232F-2320 against decimal 8992-8993; the decimal column implies hex 231F.
  • Values marked 'M' in the source range column mean a 1,000,000 multiplier on the range only; the floats themselves are in plain volts, amps, watts, VARs and VAs.
  • Command registers always read 0. If a password is wrong the meter still answers normally but does nothing; with passwords disabled the password is 5555.

Questions about the Eaton IQ 250 / IQ 260 Electronic Power Meter

What Modbus registers does the Eaton IQ 250 / IQ 260 Electronic Power Meter have?

This map lists 97 registers: 97 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Eaton IQ 250 / IQ 260 Electronic Power Meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each map row prints a hex address and a decimal register. The hex column is the wire address; the decimal column is one higher (the map's own example: serial number at hex 0008 = register 9, entered as 40009 in a SCADA tool). Here 'documented' is the decimal register and address = decimal minus 1.

What byte order does the Eaton IQ 250 / IQ 260 Electronic Power Meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Eaton IQ 250 / IQ 260 Electronic Power Meter?

Start with HR 999 Volts A-N (Volts A-N); HR 1011 Amps A (Amps A); HR 1017 Watts, 3-Ph total (Total watts); HR 1023 Power Factor, 3-Ph total (Total power factor); HR 1025 Frequency (Frequency); HR 2005 Positive Watts, 3-Ph, Average (Positive watt demand); HR 4500 Meter Status (Meter status (measurement state)).

How do I enable Modbus control of the Eaton IQ 250 / IQ 260 Electronic Power Meter?

Reads need no enabling. To change settings: write the password to Open Privileged Command Session (21002), then Initiate Programmable Settings Update (21003), write the settings, use the checksum registers 21004/21005 (writing 21005 saves the settings to non-volatile memory), then write Terminate (21007), which restarts the meter. Reset commands (20000, 20001) take the password directly.
