Integration notes: JUMO ecoLine NTU digital turbidity sensor (Modbus RTU)

Integration in brief

Write 3 (NTU) or 5 (FNU) to register 1, wait 300 ms, poll register 82 until no 3-bit field equals 7, then read 83-88 as ABCD floats.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is the sensor's native interface; set the address with JUMO DSM software.

Byte order & addressing

  • Floats are high word first (ABCD).
  • No Modbus requests are allowed for 300 ms after a start command.

Network setup

  • 9600 baud, 8 data bits, no parity, 1 stop bit; address 1-247.
  • Wire A/B on M12 pins 5/4; the sensor needs +5 V on pin 1.

Watch out for

  • Strong ambient light makes readings fail (status 5) or lose accuracy (status 2).

Notes on this map

  • Floats are IEEE 754 sent high word first (ABCD); the worked example returns 41 CA 66 66 = 25.3 °C for start address 0x0053.
  • Measurements are triggered: write a start command to register 1, wait at least 300 ms without any Modbus traffic, poll the status word at 82 until no field reads 7, then read the values.
  • Integers are unsigned 16-bit, high byte first.
  • Each 3-bit field: 0 OK, 1 OK but outside sensor spec, 2 OK with reduced accuracy, 3 OK (reserved), 4 failed outside spec, 5 failed (too much extraneous light), 6 failed (reserved), 7 not yet complete.
  • The status table names the third field FTU while the value table uses FNU; both refer to the formazin nephelometric reading.
  • The NTU step-by-step text mentions a start value of 31, but the address table lists only 1, 3 and 5; this map follows the table.
  • The document gives the address range 1-247 but does not state a factory default address.

Questions about the JUMO ecoLine NTU digital turbidity sensor (Modbus RTU)

What Modbus registers does the JUMO ecoLine NTU digital turbidity sensor (Modbus RTU) have?

This map lists 5 registers: 5 holding registers. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the JUMO ecoLine NTU digital turbidity sensor (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables list the Modbus PDU address in decimal and hex; the value goes into the request unchanged (the example reads the temperature at start address 0x0053).

What byte order does the JUMO ecoLine NTU digital turbidity sensor (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the JUMO ecoLine NTU digital turbidity sensor (Modbus RTU)?

Start with HR 1 Start measuring operation (Start a measurement); HR 82 Measuring operation status (Measurement status); HR 83 Temperature (Temperature); HR 85 Turbidity (Turbidity NTU).

How do I enable Modbus control of the JUMO ecoLine NTU digital turbidity sensor (Modbus RTU)?

Modbus RTU is the sensor's native interface; set the address with JUMO DSM software.
