Short answer

Yaskawa's FP605 fan and pump drive packaged with a bypass contactor board. The bypass board's RS-485 port speaks MEMOBUS/Modbus RTU (or N2, P1, BACnet). Drive command and monitor registers start at 0001H and 0020H, and the bypass adds its own command word and digital I/O registers at 8400H-8403H. This map covers drive and bypass control, status, fault bits and the b1/H5/Z3-12 setup parameters.

Integration notes: Yaskawa FP605 enclosed bypass (MEMOBUS/Modbus RTU)

Integration in brief

Set H5-08 = 0, H5-01..H5-03 and cycle power (or H5-20 = 1); set b1-01 = 2 and b1-02 = 2 for serial reference and run. Write 0001H and 0002H with function 10H, use 8400H for drive/bypass selection and emergency override, and poll 0020H, 0021H and 002CH.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

H5-08 = 0 selects Modbus (default 3 = BACnet). Set H5-01 address (default 1FH), H5-02 speed (default 3 = 9600 bps), H5-03 parity (default 0 = none), then cycle power or set H5-20 = 1. Set b1-01 = 2 and b1-02 = 2 for serial control; Z3-12 = 1 lets 0001H bits 4-B and 8402H drive the digital inputs.

Communication loss & watchdog

H5-05 = 1 (default) enables CE detection after H5-09 (0.0-10.0 s, default 2.0 s); H5-04 sets the reaction (0 ramp, 1 coast, 2 fast stop, 3 alarm only - default, 4 run at H5-34 with H5-35 as an optional timeout). Drive status 2 (002CH) bit F shows a timeout.

Byte order & addressing

  • Registers are hex and 0-based: 0020H is sent as 00 20.
  • No function 06H; use 10H.
  • 8403H bits only act on outputs whose Z2-xx function is 99 (not used).

Network setup

  • RS-485 on bypass terminal TB3; 8 data bits fixed.
  • Enable the RS-485 termination resistor (bypass board DIP switch, see the switch table) only on the bypass at the end of the line.

Watch out for

  • Out of the box the bypass talks BACnet (H5-08 = 3), not Modbus.
  • With Z3-12 = 0 (default) the network digital-input bits are ignored.

Notes on this map

  • H5-08 defaults to 3 (BACnet) on this package; it must be set to 0 for Modbus.
  • Frequency registers 0002H, 0023H and 0024H use the units chosen in o1-03, so they are left unscaled.
  • Left out: 0007H/0008H analog outputs, 0025H output voltage (unit switched by H5-10), 0026H/0027H output current and power, 002DH and later monitors not checked row by row, the U-monitor, fault-trace and fault-description blocks from 0040H, 15FFH (no unit given), the clock registers 3004H-3030H and emergency-override registers 3A93H-3A96H.
  • The command table prints run bits 0/1 with both meanings (forward run / run and reverse run / reverse) without naming the selecting parameter; on the drive this is H5-12, which is not in the bypass H5 list.
  • Supported function codes are 03H, 08H, 10H, 5AH and 67H; there is no 06H, so use 10H even for a single register.
  • With H5-11 = 0 (default), parameter writes take effect only after the Enter command (0900H or 0910H).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Yaskawa FP605 enclosed bypass (MEMOBUS/Modbus RTU)

What Modbus registers does the Yaskawa FP605 enclosed bypass (MEMOBUS/Modbus RTU) have?

This map lists 35 registers: 35 holding registers. 26 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yaskawa FP605 enclosed bypass (MEMOBUS/Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are hex and are sent unchanged: the manual's read example asks for starting register 0020H as bytes 00 20. Parameters use the hex number printed under each parameter (H5-01 = 0425H, Z3-12 = 850BH).

What are the minimum Modbus registers to integrate the Yaskawa FP605 enclosed bypass (MEMOBUS/Modbus RTU)?

Start with HR 1 Run command / drive MFDI command (Run/stop, direction, fault reset); HR 2 Frequency reference (Frequency reference (o1-03 units)); HR 33792 Bypass command word (Bypass command word (drive/bypass select)); HR 32 Drive status 1 (Drive/bypass status 1); HR 33 Fault description 1 (Fault description 1); HR 36 U1-02 Output frequency (U1-02 output frequency); HR 44 Drive status 2 (Drive status 2 incl. comm timeout).

How do I enable Modbus control of the Yaskawa FP605 enclosed bypass (MEMOBUS/Modbus RTU)?

H5-08 = 0 selects Modbus (default 3 = BACnet). Set H5-01 address (default 1FH), H5-02 speed (default 3 = 9600 bps), H5-03 parity (default 0 = none), then cycle power or set H5-20 = 1. Set b1-01 = 2 and b1-02 = 2 for serial control; Z3-12 = 1 lets 0001H bits 4-B and 8402H drive the digital inputs.

What happens when the Yaskawa FP605 enclosed bypass (MEMOBUS/Modbus RTU) loses Modbus communication?

H5-05 = 1 (default) enables CE detection after H5-09 (0.0-10.0 s, default 2.0 s); H5-04 sets the reaction (0 ramp, 1 coast, 2 fast stop, 3 alarm only - default, 4 run at H5-34 with H5-35 as an optional timeout). Drive status 2 (002CH) bit F shows a timeout.
