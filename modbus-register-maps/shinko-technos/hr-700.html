Shinko Technos HR-700 hybrid recorder (Modbus RTU, firmware 4.00+) Modbus register map

Updated 17 November 2026

Short answer

The HR-700 is a hybrid chart recorder with a Modbus map for up to six channels. From firmware 4.00 it offers Modbus RTU on RS-485/RS-232C alongside Shinko's original protocol. Input registers carry the clock, recording status, per-channel alarm flags, measured values as scaled integers and as IEEE floats, and unit text; holding registers carry recording commands and channel, alarm and communication settings.

This page lists 240 Modbus registers for the Shinko Technos HR-700 hybrid recorder (Modbus RTU, firmware 4.00+) — 196 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Shinko Technos’s own free documentation (linked below) and checked against it.

Integration notes: Shinko Technos HR-700 hybrid recorder (Modbus RTU, firmware 4.00+)

Integration in brief

Set Communication protocol to Modbus RTU with 8-bit data, then read input registers 30107-30130 for the six channels (integer plus decimal point, or IEEE float) and 30101-30106 for alarm flags; start and stop recording by writing AA01H/AA00H to 40101.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Needs body firmware 4.00 or later. Set Communication protocol to Modbus RTU and data length to 8 bit in the recorder's communication settings (also exposed at 40973 and 40976).

Byte order & addressing

  • 7-bit data length does not work with Modbus RTU.
  • Out-of-range integer readings return 8181H (minus side) or 7E7EH (plus side).
  • Clock set must be one 7-register write starting at 40111.

Network setup

  • Slave address 1-247 per the overview table (host address setting 40971 allows 1-32); speeds 1200-38400 bps; parity none/even/odd; 1 or 2 stop bits.

Watch out for

  • Function 06 writes one register and 10H up to 123; reads are limited to 123 registers.

Notes on this map

  • Measurement floats (30119-30130) are documented high-order word first, so ABCD.
  • The holding-register float copies of scaling range and alarm set values (e.g. 40251-40262) are left out: the manual says IEEE but does not state their word order.
  • Channel setup blocks repeat every 100 registers: CH1 40201, CH2 40301 ... CH6 40701. Tag, unit and partial-compression items are omitted.
  • Parameter writes take effect only after writing AA01H to Save the settings (40104); operation commands act at once.
  • Engineering parameters (40901-40970), print text and comment areas are omitted.
  • Factory communication defaults are not stated in this manual.

Questions about the Shinko Technos HR-700 hybrid recorder (Modbus RTU, firmware 4.00+)

What Modbus registers does the Shinko Technos HR-700 hybrid recorder (Modbus RTU, firmware 4.00+) have?

This map lists 240 registers: 44 input registers, 196 holding registers. 196 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos HR-700 hybrid recorder (Modbus RTU, firmware 4.00+) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map prints Modicon numbers (30001, 40101) next to a hex relative address; 30001 and 40001 are relative address 0, so subtract 30001 or 40001 to get the wire address. The manual's function 04 example reads relative address 0032H, which is 30051 (clock year).

What byte order does the Shinko Technos HR-700 hybrid recorder (Modbus RTU, firmware 4.00+) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Shinko Technos HR-700 hybrid recorder (Modbus RTU, firmware 4.00+)?

Start with IR 118 CH1 measurement (float) (CH1 measured value (float)); IR 106 CH1 measurement (integer) (CH1 measured value (integer)); IR 112 CH1 decimal point position (CH1 decimal point); IR 100 CH1 channel status (CH1 alarm flags); IR 56 Recording status (Recording status); HR 100 Recording start/stop (Recording start/stop command); HR 103 Save the settings (Save settings command).

How do I enable Modbus control of the Shinko Technos HR-700 hybrid recorder (Modbus RTU, firmware 4.00+)?

Needs body firmware 4.00 or later. Set Communication protocol to Modbus RTU and data length to 8 bit in the recorder's communication settings (also exposed at 40973 and 40976).

Where is the official Shinko Technos HR-700 hybrid recorder (Modbus RTU, firmware 4.00+) Modbus documentation?

The source is HR-700 Hybrid Recorder Communication Command Manual (No. HR7CE4), revision 2018-05, published free by Shinko Technos at https://shinko-technos.co.jp/e/manual/english/HR7CE4.pdf.
