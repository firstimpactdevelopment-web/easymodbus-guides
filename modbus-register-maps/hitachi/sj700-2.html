Short answer

The SJ700-2 is Hitachi's general-purpose sensorless-vector inverter with a built-in RS485 port that speaks Hitachi ASCII or Modbus RTU. Commands and status flags are coils, the frequency reference and monitors are holding registers, and 32-bit values are split into high and low registers. This map covers the run and terminal coils, status coils, frequency command, key d-monitors and accel/decel times.

This page lists 70 Modbus registers for the Hitachi SJ700-2 series inverter (Modbus RTU) — 18 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Hitachi’s own free documentation (linked below) and checked against it.

Integration notes: Hitachi SJ700-2 series inverter (Modbus RTU)

Integration in brief

Set A001 = 03 and A002 = 03, write the frequency to registers 0001h-0002h (wire 0-1, 0.01 Hz) and run with coil 0001h (wire 0). Read output frequency at 1001h-1002h and current at 1003h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set C079 (communication mode) to Modbus-RTU, C071 speed, C072 node address, C074 parity, C075 stop bits and C078 wait time on the keypad; set A001 = 03 and A002 = 03 to take frequency and run commands over the network.

Communication loss & watchdog

C077 sets the reception timeout (0.00-99.99 s) and C076 picks the action after a timeout (trip, decelerate and trip, ignore, free-run stop, or decelerate and stop); the NDc output (coil 0033h) signals the disconnection.

Byte order & addressing

  • Requests use the printed number minus 1.
  • 32-bit values are high word first.

Network setup

  • RS485 on terminal block TM2 (SP, SN); use RP-SN to enable the terminating resistor.
  • 2400-19200 bps, 8 data bits in Modbus-RTU mode, up to 32 inverters.

Watch out for

  • The physical intelligent input terminals override the input coils.
  • Register writes are lost at power-off unless 1 is written to 0900h to store them in EEPROM.

Notes on this map

  • 32-bit values are two registers labelled (high) then (low), so ABCD.
  • The trip-monitoring block 0010h-004Eh (trip counter, six trip records, programming error code) is documented but not included in this map.
  • Inverter status A (0003h) is left out because its value list is cut off in the table, and cumulative RUN time (1015h) because its 0.1 resolution has no unit printed.
  • Cumulative power (1013h) is listed raw with 0.1 resolution as printed; the manual gives the value as input power divided by the b079 display gain, so no fixed unit is assigned.
  • Function-mode parameter registers (1201h and up) are documented in the manual but not listed here.
  • Communication error coils 004Ah-004Eh stay set until an error reset.
  • Coil 0013h is left out: the table names it RUN (running) but its setting column reads 1 = tripping, 0 = normal.
  • Coil 0049h (data writing in progress) is left out: the Enter-command note points to coil 001Ah for that flag, while the coil table puts OTQ at 001Ah and data writing at 0049h.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Hitachi SJ700-2 series inverter (Modbus RTU)

What Modbus registers does the Hitachi SJ700-2 series inverter (Modbus RTU) have?

This map lists 70 registers: 41 coils, 29 holding registers. 18 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Hitachi SJ700-2 series inverter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Coil and register numbers are printed in hex (0001h). The manual says the starting number in a request is 1 less than the coil or register number, e.g. reading coils from 0007h sends 00 06. So wire address = printed number - 1.

What byte order does the Hitachi SJ700-2 series inverter (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Hitachi SJ700-2 series inverter (Modbus RTU)?

Start with CO 0 Operation command (Run/stop command); CO 1 Rotation direction command (Direction command); HR 0 Frequency source setting (F001) (Frequency command (F001)); HR 4096 Output frequency (d001) (Output frequency); HR 4098 Output current (d002) (Output current); HR 3 Inverter status B (Inverter status B (run/trip)).

How do I enable Modbus control of the Hitachi SJ700-2 series inverter (Modbus RTU)?

Set C079 (communication mode) to Modbus-RTU, C071 speed, C072 node address, C074 parity, C075 stop bits and C078 wait time on the keypad; set A001 = 03 and A002 = 03 to take frequency and run commands over the network.

What happens when the Hitachi SJ700-2 series inverter (Modbus RTU) loses Modbus communication?

C077 sets the reception timeout (0.00-99.99 s) and C076 picks the action after a timeout (trip, decelerate and trip, ignore, free-run stop, or decelerate and stop); the NDc output (coil 0033h) signals the disconnection.
