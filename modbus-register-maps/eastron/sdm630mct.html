Eastron SDM630MCT Modbus register map

Updated 28 October 2026

Short answer

The SDM630MCT is Eastron's three-phase, CT-connected (1 A / 5 A CT secondary) DIN-rail multifunction meter with an RS485 Modbus RTU port. Every value is a 32-bit IEEE-754 float, high register first: live readings and energy in input registers (function 04) and settings in holding registers (function 03 read, 16 write). This map covers the full input table plus the demand, wiring, RS485, CT/PT ratio, pulse and reset settings.

This page lists 109 Modbus registers for the Eastron SDM630MCT — 12 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Eastron’s own free documentation (linked below) and checked against it.

Integration notes: Eastron SDM630MCT

Integration in brief

Use function 04 from 30001 (wire 0) in blocks of up to 60 registers; every value is a big-endian float. Settings are floats in holding registers written with function 16, one parameter per message; system type and CT/PT ratios need the password written to 40025 first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

RS485 Modbus RTU is built in on the RS485 versions. Set address, baud rate and parity/stop bits from the front setup menu or holding registers 40021, 40029 and 40019.

Byte order & addressing

  • All values, including settings, are 32-bit floats (ABCD).
  • Odd register counts are rejected.
  • Power factor sign shows current direction, not leading/lagging.

Network setup

  • Defaults: address 1, 9600 baud, no parity, 1 stop bit.
  • Baud 2400-38400.
  • Terminate both bus ends with 120 ohm; up to 32 nodes and 1200 m per segment.

Watch out for

  • CT and PT ratios (40063 / 40065) need the password first and are not settable on MID versions.
  • The meter does not answer broadcasts (address 0).

Notes on this map

  • Hosted by Eastron (Metering) Europe, Eastron's European site.
  • Word order: the document says each value is an IEEE-754 float sent most significant register first by default (ABCD). It mentions a 'Register Order' holding register that can change this, but that register is not in the table, so it is not listed.
  • Read and write an even number of registers; odd counts return an exception. A request is limited to 30 values (60 registers) per the overview, while the input-register section says 40 parameters; keep requests at 30 values or fewer.
  • Each input value is marked available or not per wiring system (3P4W, 3P3W, 1P2W); unavailable values read zero. The descriptions say where a value is missing.
  • Left out: 30255 'Total system power factor' because the table gives its unit as Degrees, which clashes with 30063.
  • Left out: CT2 and PT2 rows (hex 0034 / 0030), which have no register number in the table; and the serial number (464513), an unsigned 32-bit integer with no stated word order.
  • Demand note: the power-sum demand is described as calculated for import minus export; check on a live meter if the sign matters.
  • Total kWh / kVArh (30343 / 30345) are import plus export, not net.
  • CT type (1 A / 5 A) and DIN-rail mounting are from the SDM630MCT series user manual on eastrongroup.com (https://www.eastrongroup.com/eastrongroup/2024/08/21/eastronsdm630mctseriesusermanual.pdf).
  • The password default is printed as 1000 in the holding-register table but as 0000 in the password section; try both.
  • The reset register (461457) is a single 2-byte register although the overview says requests must use an even register count; the document does not resolve this.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Eastron SDM630MCT

What Modbus registers does the Eastron SDM630MCT have?

This map lists 109 registers: 93 input registers, 16 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Eastron SDM630MCT Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed Modicon style (30001 / 40001, and six-digit 46xxxx for high addresses) next to the hex start address actually sent. Wire address = printed number minus 30001 or 40001 (or 400001): 30001 is 0x0000, 30007 is 0x0006 (the document's own example), 461457 is 0xF010.

What byte order does the Eastron SDM630MCT use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Eastron SDM630MCT?

Start with IR 0 Phase 1 line to neutral volts (Phase 1 voltage); IR 6 Phase 1 current (Phase 1 current); IR 52 Total system power (Total system power); IR 62 Total system power factor (Total power factor); IR 70 Frequency of supply voltages (Frequency); IR 72 Total import kWh (Total import kWh); IR 74 Total export kWh (Total export kWh); HR 62 CT ratio (CT ratio check).

How do I enable Modbus control of the Eastron SDM630MCT?

RS485 Modbus RTU is built in on the RS485 versions. Set address, baud rate and parity/stop bits from the front setup menu or holding registers 40021, 40029 and 40019.

Where is the official Eastron SDM630MCT Modbus documentation?
