Short answer

Swegon's REACT dampers for demand-controlled ventilation can be fitted with a Modbus RTU actuator. All points are holding registers read with function 03 and written one at a time with 06: set point, override and command, actuator type, relative and absolute position and flow, an optional analog output, flow limits, bus-failure action, set point source mode, Modbus address and flow unit.

This page lists 18 Modbus registers for the Swegon REACT damper / VAV actuator (Modbus RTU, 2018 sheet) — 12 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Swegon’s own free documentation (linked below) and checked against it.

Integration notes: Swegon REACT damper / VAV actuator (Modbus RTU, 2018 sheet)

Integration in brief

Set register 122 to 1 (or 2) so the set point comes from Modbus, then write the set point to register 0 and read relative position (4) and flow (6/7).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Register 122 Mode: 1 = set point via Modbus register 0 (0 = analog input, then register 0 is read-only).

Communication loss & watchdog

Bus fail position (108): 1 closes, 2 opens the damper when no bus traffic for 120 s; 0 disables monitoring.

Byte order & addressing

  • Set point, relative position and relative flow use 0-10000 for 0-100 %.
  • 65535 in position registers means the function is not supported.

Network setup

  • Default serial setting depends on the actuator (19200 8E1 for 227VM, 38400 8N1 for 309C); 120 ohm termination is external.
  • A response delay can be set in 3 ms steps for slow masters.

Watch out for

  • Flow units (l/s or m³/h) follow register 201.

Notes on this map

  • This is the REACT sheet for the actuators named above; the REACT Parasol Zenith with Belimo actuator has its own map in the library.
  • Factory communication setting differs by actuator: page 1 and footnote 4 give setting 14 (19200 baud, 8 data bits, even parity, 1 stop bit) for the 227VM-024-**-MB/SWE, while footnote 1 marks setting 24 (38400 baud, no parity, 1 stop bit) as the default for the 309C-024-150-MB/SL8/ST15/SWE. Settings 1-24 are listed in the sheet. Default slave address is not stated.
  • Only function codes 03 and 06 are implemented. The sheet notes settings 1-3 and 19 limit a read to 8 registers.
  • Command values 0, 2 and 3 and Device ID 0 are printed as '- - -' (unused).
  • All values are 16-bit WORD; the protocol line mentions floats but none are listed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Swegon REACT damper / VAV actuator (Modbus RTU, 2018 sheet)

What Modbus registers does the Swegon REACT damper / VAV actuator (Modbus RTU, 2018 sheet) have?

This map lists 18 registers: 18 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Swegon REACT damper / VAV actuator (Modbus RTU, 2018 sheet) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The sheet prints a decimal 'Address' starting at 0 (Set point). Use the printed number as the wire address.

What are the minimum Modbus registers to integrate the Swegon REACT damper / VAV actuator (Modbus RTU, 2018 sheet)?

Start with HR 0 Set point (Set point); HR 4 Relative position (Relative position); HR 6 Relative flow (Relative flow); HR 7 Absolute flow (Absolute flow); HR 122 Mode signal set point analog output (Set point source mode); HR 108 Bus fail position (Bus fail position).

How do I enable Modbus control of the Swegon REACT damper / VAV actuator (Modbus RTU, 2018 sheet)?

Register 122 Mode: 1 = set point via Modbus register 0 (0 = analog input, then register 0 is read-only).

What happens when the Swegon REACT damper / VAV actuator (Modbus RTU, 2018 sheet) loses Modbus communication?

Bus fail position (108): 1 closes, 2 opens the damper when no bus traffic for 120 s; 0 disables monitoring.
