Short answer

This Intesis gateway plugs into the CN105 connector of a Mitsubishi Electric Ecodan air-to-water heat pump and makes it a Modbus RTU server (or a BACnet MS/TP device, chosen by DIP switch). All points are single 16-bit holding registers: system on/off, heat/cool mode, Zone 1 and Zone 2 setpoints and control type, DHW setpoint, eco and boost, water temperatures, compressor and pump status, run hours, flow and energy counters, plus error codes.

Integration notes: Intesis (HMS Networks) IN485MIT001A000 Mitsubishi Electric Ecodan air-to-water to Modbus RTU / BACnet MS/TP gateway

Integration in brief

Plug the supplied cable into CN105 on the Ecodan board, set SW1 position 5 ON for Modbus RTU, pick the baud on SW1 6-8 and the address on SW2 1-6, reboot, then read holding registers with function 03 (max 50 per request) and write one register at a time with 06.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

SW1 position 5 ON selects Modbus RTU (factory default is BACnet MS/TP). Keep register 119 (Modbus control lock) at 0 or BMS commands are ignored.

Byte order & addressing

  • Function 16 is accepted only with a quantity of one register.
  • At most 50 registers per read.
  • Factory serial setting is 2400 baud, 8-N-2; 8-N-1 is detected automatically.
  • Temperature scale and unit change with SW2 positions 7 and 8.

Network setup

  • SW1 5 = protocol (ON = Modbus RTU); SW1 6-8 = baud (all OFF = 2400 for Modbus).
  • SW2 1-6 = Modbus address 1-63 (binary, position 1 = least significant); SW2 7 = x1/x10; SW2 8 = °C/°F.
  • SW3 1 ON = 120 ohm termination; SW3 2-3 ON = bus biasing.
  • Wire B-, A+ and SG; the gateway is powered from the Ecodan via the 1.5 m CN105 cable, which should not be lengthened.
  • DIP changes take effect only after a gateway reboot (or write 1 to register 463).

Watch out for

  • Writing 1 to register 118 locks out the Ecodan's own remote control.
  • Writing a room temperature to 181/256 switches on virtual temperature; the unit then follows the BMS value.
  • In cooling, only control type 0 (flow temperature) is allowed, and only one zone may use room temperature control.

Notes on this map

  • Temperatures follow DIP switch SW2: position 7 OFF = whole degrees (x1, factory default), ON = tenths (x10, 19.2 = 192); position 8 OFF = °C (default), ON = °F. Units and scale here are for the defaults; use scale 0.1 if you set x10.
  • Every register starts at 0x8000 (-32768) until the gateway has read the unit; the manual writes this value as negative, so temperatures are typed signed 16-bit.
  • An invalid write resets a temperature register to 0x8000; other registers keep their old value.
  • Zone 2 custom, unit and applied limit registers (241-252) mirror Zone 1's (161-172) and are left out to keep the map short; so are the Zone 1 unit limits (165-168), DHW applied limits (281-282) and the gateway-only registers not needed for control.
  • Error code (108) is the code shown on Mitsubishi centralised controllers and sub code (109) the Ecodan screen code, both as hex digits in a 16-bit value (e.g. 0x0601 reads 1537 in decimal); the conversion table is in section 10 of the manual.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options.
