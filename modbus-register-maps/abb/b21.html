ABB EQ meter B21 (Modbus RTU) Modbus register map

Updated 16 October 2026

Short answer

The B21 is ABB's single-phase EQ DIN-rail kWh meter. Versions with the RS485 port talk Modbus RTU using the same hex-addressed holding-register map as the rest of the EQ family. This map keeps the values that make sense on a single-phase meter: total, tariff, L1 and resettable energy, L1 voltage, current, power, angles and power factor, identification, clock status, conversion factors and resets.

This page lists 95 Modbus registers for the ABB EQ meter B21 (Modbus RTU) — 19 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ABB’s own free documentation (linked below) and checked against it.

Integration notes: ABB EQ meter B21 (Modbus RTU)

Integration in brief

Switch the RS485 port to Modbus in the meter menu, then poll holding registers with function 3 at their hex addresses. Energy is 64-bit (4 registers) with 0.01 resolution, high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the meter menu, open the RS485 communication settings and set the protocol to Modbus (not EQ-Bus), then set baud rate, address and parity.

Byte order & addressing

  • Hex wire addresses, no 40001 offset.
  • Readable range 0x1000-0x8EFF, up to 125 registers per request.
  • Missing quantities return FFFF / 7FFF... rather than an exception.

Network setup

  • Address range 1-247.
  • Modbus baud rates: 1200 to 115200; parity None, Odd or Even.

Watch out for

  • Modbus is carried on the RS485 port; M-Bus variants use M-Bus instead.
  • Writes to unsupported registers are not rejected; read back to confirm.

Notes on this map

  • Addresses are printed in hexadecimal exactly as sent on the bus (the manual says not to subtract 40000 or 1). All data is in holding registers, read with function 3 and written with function 6 or 16.
  • Multi-register values are big-endian: the most significant byte is the high byte of the lowest register, so 32-bit and 64-bit values are ABCD (high word first).
  • Unsupported quantities still answer, but with an 'invalid' marker: FFFF in every register for unsigned values, and the largest positive value (7FFF, 7FFFFFFF ...) for signed values.
  • Instantaneous power registers are signed 32-bit with 2 decimals, which caps them near +/-21 MW; for larger systems the manual points to the DMTME-compatible block, which reports whole watts.
  • Built from the current manual revision. The 2013 Revision A also listed input states/counters, error/warning/alarm flag words, load-profile and log resets; the current revision no longer lists them, so they are left out.
  • Left out: the DMTME-block energy registers (103E, 1040) whose unit is printed as 'Wh*100' / 'VArh*100', which does not make the scaling direction unambiguous.
  • Left out: event-log, alarm-configuration, pulse-output and tariff-configuration register groups, which work through selector/header registers or OBIS-coded multi-register fields rather than simple point reads.
  • The B21 manual reprints the full EQ mapping, including L2/L3, line-to-line and 3-phase quantities; those are left out here because a single-phase meter returns the 'invalid' marker for them.
  • Outputs 1 and 2 (6300, 6301) are the only Modbus I/O registers listed. The reset table still lists input counter / stored-state resets for inputs 1-4 (8F0B-8F16), but no input registers are mapped, so those resets are left out.
  • Left out: date/time (8A00) and power outage time (8A39), which pack bytes across three registers rather than a standard data type.
  • Resettable reactive energy import/export (5534, 5538): the manual's Unit column prints 'kWh' for these two rows, while the quantity name is reactive energy. Size (4 registers), resolution (0,01) and data type (Unsigned) are printed unambiguously and match the other reactive registers, so they are kept and listed as kvarh; the unit is the only misprint.

Questions about the ABB EQ meter B21 (Modbus RTU)

What Modbus registers does the ABB EQ meter B21 (Modbus RTU) have?

This map lists 95 registers: 95 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB EQ meter B21 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Start registers are printed in hex exactly as sent on the bus (5000 = 0x5000); the manual says not to subtract 40000 or 1. Function 3 reads, 6/16 write.

What byte order does the ABB EQ meter B21 (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ABB EQ meter B21 (Modbus RTU)?

Start with HR 20480 Active import energy (Total active import energy); HR 20484 Active export energy (Total active export energy); HR 23296 Voltage L1-N (Voltage L1-N); HR 23308 Current L1 (Current L1); HR 23316 Active power Total (Total active power); HR 23340 Frequency (Frequency); HR 35072 Serial number (Serial number).

How do I enable Modbus control of the ABB EQ meter B21 (Modbus RTU)?

In the meter menu, open the RS485 communication settings and set the protocol to Modbus (not EQ-Bus), then set baud rate, address and parity.

Where is the official ABB EQ meter B21 (Modbus RTU) Modbus documentation?
