Integration notes: Schneider Electric Altivar Machine ATV320 (embedded Modbus RTU)

Integration in brief

Set Add (6001) to 1-247 and power-cycle, set FR1 = Modbus and keep CHCF = SIM, then write CMD (8501) = 0006h, then 000Fh with a non-zero LFR (8502, 0.1 Hz) or LFRD (8602, rpm) to run. Poll ETA (3201), RFR (3202), LCR (3204) and LFT (7121).

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set [Modbus Address] Add (COM- menu; logical 6001) to 1-247 - the factory value is OFF, so the drive does not answer at all until this is set. Speed and format default to 19200, 8-E-1 (tbr 6003, tFO 6004). Communication changes apply after a power cycle. For combined CiA402 control set [Ref Freq 1 Config] FR1 = [Modbus] Mdb with [Control Mode] CHCF = [Not separ.] SIM (factory). For separate mode use CHCF = SEP and Cd1 = Mdb; for the I/O profile use CHCF = IO and Cd1 = Mdb, then CMD bit 0 is run forward.

Communication loss & watchdog

[Modbus Timeout] ttO (6005), 0.1-30 s, factory 10 s: once the Modbus channel is being monitored, a Modbus communication interruption longer than this raises SLF1. [Modbus fault mgt] SLL (7010) sets the reaction: freewheel (factory), ramp, fast stop, DC injection, ignore, per Stt, fallback speed LFF (7080) or maintain speed. A channel is only monitored once it has written a command or reference.

Byte order & addressing

  • Addresses are decimal logical numbers sent as-is (3201 = 0x0C81); do not subtract 1 or add 40001.
  • CiA402 sequence: write 0006h (shutdown) to reach Ready to switch on, then 000Fh (enable operation) to run; 0007h stops, 0000h disables voltage, 0080h rising edge resets a fault. 000Fh alone is enough from Ready to switch on.
  • Both CMD and the reference must be written at least once before the drive will go from Switched on to Operation enabled.
  • Mask ETA with 006Fh to read the state: 0040h switch on disabled, 0021h ready, 0023h switched on, 0027h operation enabled, 0007h quick stop, 0008h-0028h fault.
  • CMD bit 11 is reverse direction by default ([Reverse Assign] rrS = C111).
  • Supported functions: 03 (up to 63 words), 06, 16 (up to 61 words), 23 read/write (20+20 words), 43/14 identification and 08 diagnostics.
  • Function 23 with the communication scanner (NC1-NC8 at 12761+, NM1-NM8 at 12741+) gives CMD/LFRD write and ETA/RFRD read in one frame by default.

Network setup

  • RJ45 Modbus port: pin 4 = D1, pin 5 = D0, pin 8 = common, pin 7 = 10 V supply for converters/remote keypad.
  • 2-wire RS-485 trunk up to 1000 m at 19200 bps, up to 31 drives per segment without repeater.
  • Fit a line terminator (120 ohm in series with 1 nF) at each end of the bus; polarization (650 ohm pull-up/down) belongs at the master.
  • Set Add, tbr, tFO in the [COMMUNICATION] COM- menu, then switch the drive off and on.
  • The keypad [COMMUNICATION MAP] menu shows frame and CRC counters (M1Ct 6011, M1EC 6010) and COM1 link status for troubleshooting.

Watch out for

  • Factory Add = OFF: a new drive never answers until an address is entered.
  • SLL = Ignore disables communication-loss protection; use it only during commissioning.
  • CMI bit 1 saves to EEPROM (about 100,000 write cycles); do not set it cyclically.
  • Writing CMI bit 9 changes the unit of LFR and RFR for every reader.
  • R/WS parameters (CHCF, FR1, Cd1, motor data, Modbus settings) are refused while the motor is running.

Notes on this map

  • Second source: Altivar Machine ATV320 Modbus Serial Link Manual NVE41308 rev 01 (04/2016), https://download.schneider-electric.com/files?p_Doc_Ref=NVE41308 - used for addressing, function codes, the Add/tbr/tFO/ttO settings, the CiA402 sequence and SLL behaviour.
  • Every register is a single 16-bit word; the map has no 32-bit values.
  • M1EC (6010) and M1CT (6011) are not in the parameter file; their logical addresses come from the Modbus manual p. 74.
  • LFR (8502) and RFR (3202) are 0.1 Hz only while CMI bit 9 = 0 (power-up default); with bit 9 = 1 they become a signed value where 32767 = tFr.
  • APH, RTH and PTH have no fixed unit: read UNT (3234) after them to learn whether each is in Wh/kWh/MWh or s/min/h.
  • ACC/DEC are raw values; their resolution follows INR (9020): 0 = 0.01 s, 1 = 0.1 s (factory), 2 = 1 s.
  • LFT and DP0-DP3 use the full LFT list (61 codes) from the parameter file Enumerations sheet.
  • FR1 and CD1 value lists show the channel choices relevant to network control; the full PSA list also includes analog and function sources.
  • Left out: ERRD (CiA402 error code, 8606) because the file types it as a bit string but gives a code list; CCS (8421) values because they come from a long assignable-input list; option-card (CANopen, Ethernet, EtherCAT) parameters; Safety-function and function-block registers.
  • Registers marked RW that the source lists as R/WS can only be written while the drive is not running (not in Operation enabled or Quick stop active).

Questions about the Schneider Electric Altivar Machine ATV320 (embedded Modbus RTU)

What Modbus registers does the Schneider Electric Altivar Machine ATV320 (embedded Modbus RTU) have?

This map lists 68 registers: 68 holding registers. 31 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Schneider Electric Altivar Machine ATV320 (embedded Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Logical addresses are decimal (the parameter file also shows hex as 16#....) and go into the request unchanged. The Modbus manual's read example asks for W3102-W3105 by sending starting address 0C1E hex (= 3102), and its write example writes W9001 at 2329 hex. So ETA 3201 is requested at address 3201 (0x0C81), with no 40001 offset and no minus 1.

What are the minimum Modbus registers to integrate the Schneider Electric Altivar Machine ATV320 (embedded Modbus RTU)?
