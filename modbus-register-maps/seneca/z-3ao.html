Short answer

The Z-3AO drives three analog outputs (voltage or current, chosen per channel by DIP switch) from normalized values written over RS-485 Modbus RTU. All registers are single 16-bit holding registers; a bus-timeout fault mode can force preset output values.

This page lists 26 Modbus registers for the Seneca Z-3AO 3-channel analog output module — 22 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Seneca’s own free documentation (linked below) and checked against it.

Integration notes: Seneca Z-3AO 3-channel analog output module

Integration in brief

Write normalized values to 40005-40007 (wire 4-6): 0-10000 maps to the electrical start/end scale of each output.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the baud rate with DIP switches 1-2 and the address with switches 3-8, or set switches 3-8 OFF to use the EEPROM values in 40002/40004.

Communication loss & watchdog

With 40004 bit 7 set, if no bus traffic arrives for the time in 40003 (0.1 s units, default 20 s) the module sets 40008 bit 2 and copies 40069-40071 to the outputs.

Byte order & addressing

  • 40002 packs baud code and address into one register.
  • Output type follows the per-channel DIP switch.

Network setup

  • Write 0xBAB0 to 40009 to store settings in EEPROM.

Watch out for

  • Bit 12 of 40004 selects old or new Z-3AO behaviour.

Notes on this map

  • All registers are single 16-bit words; there are no 32-bit values.
  • Address 1 and 38400 baud are the EEPROM defaults, used when the address DIP switches select memory mode.
  • Command values for 40009 are listed in decimal in 'values' with the hex code in the text.
  • The output scaling registers are signed for mV (-11000..11000) and unsigned for µA (0..22000), following the ranges in the table.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Seneca Z-3AO 3-channel analog output module

What Modbus registers does the Seneca Z-3AO 3-channel analog output module have?

This map lists 26 registers: 26 holding registers. 22 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seneca Z-3AO 3-channel analog output module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register table prints 4xxxx numbers (40001 = first holding register), so 40005 is wire address 4.

What are the minimum Modbus registers to integrate the Seneca Z-3AO 3-channel analog output module?

Start with HR 4 OUT1 normalized value (OUT1 setpoint); HR 5 OUT2 normalized value (OUT2 setpoint); HR 6 OUT3 normalized value (OUT3 setpoint); HR 7 Errors (Error bits); HR 2 Communication timeout (Bus timeout).

How do I enable Modbus control of the Seneca Z-3AO 3-channel analog output module?

Set the baud rate with DIP switches 1-2 and the address with switches 3-8, or set switches 3-8 OFF to use the EEPROM values in 40002/40004.

What happens when the Seneca Z-3AO 3-channel analog output module loses Modbus communication?

With 40004 bit 7 set, if no bus traffic arrives for the time in 40003 (0.1 s units, default 20 s) the module sets 40008 bit 2 and copies 40069-40071 to the outputs.

Where is the official Seneca Z-3AO 3-channel analog output module Modbus documentation?

The source is Z-3AO User Manual (MI00260-2-EN), published free by Seneca at https://www.seneca.it/media/1340/mi00260-2-en.pdf.
