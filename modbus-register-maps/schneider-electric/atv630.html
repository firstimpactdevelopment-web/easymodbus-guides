Short answer

Schneider Electric's process/pump variable frequency drive family with Modbus RTU on an RJ45 port and a Modbus TCP server on the embedded Ethernet port. Both use the same decimal logical addresses, sent unchanged as holding-register addresses. This map covers the CiA402 command/status words (CMD/ETA), frequency and speed references, the main monitors (motor frequency, current, voltages, DC bus, thermal states, power), energy counters, fault/warning codes, I/O states and the Modbus, Ethernet and channel settings.

Integration notes: Schneider Electric Altivar Process ATV630 / ATV600 family (Modbus serial and Modbus TCP)

Integration in brief

Give the drive a Modbus address (serial) or an IP address (Ethernet), set FR1 to Modbus (164) or Embedded Ethernet (171) with CHCF = SIM, then write CMD (8501) = 0006h followed by 000Fh with a non-zero LFR (8502, 0.1 Hz). Poll ETA (3201), RFR (3202), LCR (3204), HMIS (3240) and LFT (7121).

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Serial: set [Modbus Address] Add ([Communication] COM- / [Comm parameters] CMP- / [Modbus SL] MSL-; logical 6001) to 1-247 and restart the drive - the factory value is OFF. Baud and format default to 19200, 8-E-1. Ethernet: [IP mode Eth Embd] IM00 defaults to DHCP; enter a fixed IP (IC01-IC04, mask, gateway) or use BOOTP/DHCP, effective at next power-up. For combined CiA402 control set [Ref.1 channel] Fr1 = Modbus (Mdb) or Embedded Ethernet (ETH) with [Profile] CHCF = [Not separ.] SIM (factory); for separate mode CHCF = SEP and Cd1 = the network channel; for the I/O profile CHCF = IO and Cd1 = the network channel.

Communication loss & watchdog

Serial: [Modbus Time Out] ttO (6005), 0.1-30 s, factory 10 s, raises SLF1; reaction set by [Modbus Error Resp] SLL (7010). Ethernet: [Ethernet Timeout] ttOb (64415), 0.1-30 s, factory 10 s, raises ETHF; reaction set by [Eth Error Response] EtHL (7021). Both offer freewheel (factory), ramp, fast stop, DC injection, ignore, per Stt, fallback speed LFF (7080) or maintain speed. A channel is only monitored once it has written a command or reference.

Byte order & addressing

  • Addresses are decimal logical numbers sent as-is (3201 = 0x0C81); do not subtract 1 or add 40001.
  • Modbus TCP: unit ID 0 or 248 addresses the drive; 255 addresses the I/O scanner. Function 06 is only accepted on unit IDs 0-248.
  • CiA402 sequence: 0006h (shutdown) to Ready to switch on, then 000Fh to run; 0007h stops, 0000h disables voltage, 0080h rising edge resets a fault.
  • Both CMD and the reference must be written at least once before the drive enters Operation enabled.
  • Mask ETA with 006Fh: 0040h switch on disabled, 0021h ready, 0023h switched on, 0027h operation enabled, 0007h quick stop.
  • Serial functions: 03 (63 words), 06, 16 (61 words), 23 (20+20 words), 43/14, 08. Ethernet: 03 and 16 up to 63 words, 23 up to 32+32 words.
  • CMD bit 11 is reverse direction by default ([Reverse assign.] rrS = C111).

Network setup

  • Modbus serial RJ45 behind the front cover: pin 4 = D1, pin 5 = D0, pin 8 = common, pin 7 = 10 V for converters.
  • 2-wire RS-485 up to 1000 m at 19200 bps, up to 31 drives per segment without repeater; terminate both ends with 120 ohm in series with 1 nF.
  • Restart the drive after setting Add - the manual says the address only takes effect after a restart.
  • Ethernet IP settings live under [Communication] COM- / [Comm parameters] CMP- / [Ethernet Embd] EtE-; a manually entered IP other than 0.0.0.0 disables BOOTP/DHCP.
  • Keypad counters M1CT (6011) and M1EC (6010) show received frames and CRC errors on the serial line.

Watch out for

  • Factory Add = OFF: the drive ignores serial requests until an address is set and the drive restarted.
  • Factory IP mode is DHCP: without a DHCP server or a fixed address the Ethernet port has no IP.
  • Read LCR knowing the drive rating: the same raw number means 0.01 A, 0.1 A or 1 A depending on power size.
  • Ignore (NO) in SLL/EtHL turns off communication-loss protection; commissioning only.
  • CMI bit 1 saves to EEPROM (about 100,000 write cycles); do not set it cyclically.

Notes on this map

  • Further sources: ATV600 Modbus Serial Link Manual EAV64325 rev 01, https://download.schneider-electric.com/files?p_Doc_Ref=EAV64325 ; ATV600 Embedded Ethernet Manual EAV64327 rev 03, https://download.schneider-electric.com/files?p_Doc_Ref=EAV64327 ; ATV600 Programming Manual EAV64318.14 (05/2026), https://download.schneider-electric.com/files?p_Doc_Ref=EAV64318 .
  • LCR (3204) is left unscaled: the parameter file defers to the programming manual, which gives a 0.01 A step for drives up to 15 kW, 0.1 A from 18 to 160 kW and 1 A above.
  • LFR (8502) and RFR (3202) are 0.1 Hz only while CMI bit 9 = 0 (power-up default); with bit 9 = 1 they become a signed value where 32767 = tFr.
  • ACC/DEC are raw values; their resolution follows INR (9020): 0 = 0.01 s, 1 = 0.1 s (factory), 2 = 1 s.
  • Left out: all 32-bit values (RTH/PTH run and power-on time 3244/3246, energy saved, fan time, today/yesterday kWh) because none of the documents states the word order; NCR and ITH (current step depends on rating); EPRW, OPRW, IPRW, ILN, AI physical values, PID reference/feedback and pump sensor values (unit 'refer to programming manual' or set by configurable system units).
  • OC0-OC4 and IC0-IC4 are R/WS in the parameter file (writable only when stopped, e.g. to reset). Energy is split into 16-bit 0-999 registers per decade: total motor energy = OC4 TWh + OC3 GWh + OC2 MWh + OC1 kWh + OC0 Wh, input energy likewise with IC0-IC4.
  • Registers marked RW that the source lists as R/WS can only be written while the drive is not running.
  • LFT and DP0-DP3 use the full LFT list (135 codes) and LALR the full ALR list (112 codes) from the parameter file Enumerations sheet.
  • Left out: IPR (3218, input power estimate) because the parameter file types it as signed 16-bit but gives an unsigned 0-65535 % range.
  • None of the sources states the Modbus TCP port number, so tcp_port is left null (502 is the usual Modbus TCP port but is not confirmed here).

Questions about the Schneider Electric Altivar Process ATV630 / ATV600 family (Modbus serial and Modbus TCP)

What Modbus registers does the Schneider Electric Altivar Process ATV630 / ATV600 family (Modbus serial and Modbus TCP) have?

This map lists 73 registers: 73 holding registers. 41 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Schneider Electric Altivar Process ATV630 / ATV600 family (Modbus serial and Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Logical addresses are decimal (the parameter file also shows hex as 16#....) and go into the request unchanged. The Modbus serial manual's read example asks for W3102-W3105 by sending starting address 0C1E hex (= 3102) and writes W9001 at 2329 hex. All drive data are holding registers. On Modbus TCP use unit ID 0 or 248 for the drive; unit ID 255 reaches the Ethernet I/O scanner instead.

What are the minimum Modbus registers to integrate the Schneider Electric Altivar Process ATV630 / ATV600 family (Modbus serial and Modbus TCP)?

Start with HR 8501 CMD - Command word (CMD: CiA402 run/stop/reset); HR 8502 LFR - Frequency reference (LFR: frequency reference, 0.1 Hz); HR 3201 ETA - Status word (ETA: CiA402 status word); HR 3202 RFR - Motor frequency (RFR: motor frequency, 0.1 Hz); HR 3204 LCR - Motor current (LCR: motor current (rating-dependent step)); HR 3240 HMIS - Device state (HMIS: device state code); HR 7121 LFT - Last error (LFT: last error code); HR 3209 THD - Drive thermal state (THD: drive thermal state); HR 3243 VBUS - DC bus voltage (VBUS: DC bus voltage).

How do I enable Modbus control of the Schneider Electric Altivar Process ATV630 / ATV600 family (Modbus serial and Modbus TCP)?

Serial: set [Modbus Address] Add ([Communication] COM- / [Comm parameters] CMP- / [Modbus SL] MSL-; logical 6001) to 1-247 and restart the drive - the factory value is OFF. Baud and format default to 19200, 8-E-1. Ethernet: [IP mode Eth Embd] IM00 defaults to DHCP; enter a fixed IP (IC01-IC04, mask, gateway) or use BOOTP/DHCP, effective at next power-up. For combined CiA402 control set [Ref.1 channel] Fr1 = Modbus (Mdb) or Embedded Ethernet (ETH) with [Profile] CHCF = [Not separ.] SIM (factory); for separate mode CHCF = SEP and Cd1 = the network channel; for the I/O profile CHCF = IO and Cd1 = the network channel.

What happens when the Schneider Electric Altivar Process ATV630 / ATV600 family (Modbus serial and Modbus TCP) loses Modbus communication?

Serial: [Modbus Time Out] ttO (6005), 0.1-30 s, factory 10 s, raises SLF1; reaction set by [Modbus Error Resp] SLL (7010). Ethernet: [Ethernet Timeout] ttOb (64415), 0.1-30 s, factory 10 s, raises ETHF; reaction set by [Eth Error Response] EtHL (7021). Both offer freewheel (factory), ramp, fast stop, DC injection, ignore, per Stt, fallback speed LFF (7080) or maintain speed. A channel is only monitored once it has written a command or reference.
