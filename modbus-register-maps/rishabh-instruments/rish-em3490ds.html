Updated 19 November 2026

Short answer

The RISH EM 3490 DS is a three-phase panel energy meter that keeps separate energy, run-hour and interruption counts for utility and generator supply. It has an RS-485 Modbus RTU port. Every measured value and every setting is an IEEE 32-bit float spread over two registers: readings are input registers (FC04) from 30001, settings are holding registers (FC03 read, FC16 write) from 40005. This map covers the full measured-value table including the utility/generator counters, the setup registers and the word-order switch.

This page lists 78 Modbus registers for the Rishabh Instruments RISH EM 3490 DS dual-source (utility/generator) energy meter — 14 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Rishabh Instruments’s own free documentation (linked below) and checked against it.

Integration notes: Rishabh Instruments RISH EM 3490 DS dual-source (utility/generator) energy meter

Integration in brief

Read 30001-30082 with FC04 in one or two requests (max 20 floats each) and decode each pair as a big-endian float. Settings live in 40005-40071 and are written with FC16 as floats.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set node address, baud/parity (RS485 set-up code) and energy unit from the front panel or via 40019/40021/40005.

Byte order & addressing

  • Settings are floats too: system type 3 reads back as 40 40 00 00, and writing 2 (3-phase 3-wire) sends 40 00 00 00.
  • Reading or writing only part of a float returns exception 02 (illegal data address).
  • 40041 switches the float word order for every register; write 2141.0 in the order you want to use.

Network setup

  • RS485 set-up code (40019) packs baud, parity and stop bits; see the value list.
  • If a password is set, write it to 40071 before changing any 4X register.

Watch out for

  • The energy unit (Wh/kWh/MWh) is a setting, so scale energy values according to 40005.

Notes on this map

  • All registers are IEEE 754 32-bit floats in two consecutive registers, most significant byte first (stated in the data-format table). The read example for Volts 3 returns 43 5B 41 21 (219.25 V), most significant word first, so ABCD is the default; 40041 can switch the meter to reversed order.
  • The register table has no unit column, so units are left blank. The manual notes active energy reads in Wh and apparent energy in VAh, while 40005 lets you change the energy unit to kWh or MWh.
  • Rows marked '3-phase 4-wire only' are not available on a meter set to 3-phase 3-wire.
  • Up to 20 parameters (40 registers) per read; larger requests return an exception.
  • Left out: the 20 user-assignable registers (30513-30551, mapped through 40513-40534), which mirror any 3X value; see the manual's Tables 9 and 10.
  • Serial defaults are not printed in the manual; baud is selectable 2400-19200 bps (40019 or front panel).
  • 30225 (parameter 113) has no name in the table and is left out. Run/on hour units are not printed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Rishabh Instruments RISH EM 3490 DS dual-source (utility/generator) energy meter

What Modbus registers does the Rishabh Instruments RISH EM 3490 DS dual-source (utility/generator) energy meter have?

This map lists 78 registers: 61 input registers, 17 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Rishabh Instruments RISH EM 3490 DS dual-source (utility/generator) energy meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints 30001/40001-style register numbers next to the hex start address that goes on the wire (30001 = 00 00, 40011 = 00 0A). Wire address = printed number - 30001 or - 40001; every row was checked against the printed hex.

What byte order does the Rishabh Instruments RISH EM 3490 DS dual-source (utility/generator) energy meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Rishabh Instruments RISH EM 3490 DS dual-source (utility/generator) energy meter?

Start with IR 0 Volts 1 (Voltage phase 1); IR 6 Current 1 (Current phase 1); IR 52 Watts sum (Total active power); IR 62 PF average (Average power factor); IR 70 Frequency (Frequency); IR 72 Wh (utility) (Active energy).

How do I enable Modbus control of the Rishabh Instruments RISH EM 3490 DS dual-source (utility/generator) energy meter?

Set node address, baud/parity (RS485 set-up code) and energy unit from the front panel or via 40019/40021/40005.
