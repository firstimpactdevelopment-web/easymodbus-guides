Short answer

The HV600 Bypass wraps an HV600 HVAC drive with a bypass contactor board that carries its own RS-485 port. In Modbus mode it exposes the drive command and monitor registers plus bypass-only registers: a bypass command word (drive/bypass select, emergency override, Motor AND/OR), network control of the bypass digital inputs and outputs, and status bits for bypass run and bypass faults.

Integration notes: Yaskawa HV600 Narrow and Enclosed Bypass (MEMOBUS/Modbus RTU)

Integration in brief

Set H5-08 = 0 (Modbus), H5-01/H5-02/H5-03 for the line, then reload (power cycle or H5-20 = 1). Set b1-01 = 2 and b1-02 = 2 for comms control, write the frequency to 0002H and run with 0001H bit 0; use 8400H to select drive or bypass and for emergency override, and poll 0020H, 0021H and 004BH.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Select Modbus with H5-08 = 0 and give the bypass a node address (H5-01 not 0). Set b1-01 = 2 and b1-02 = 2 (or 8 for AUTO command + serial run). Set Z3-12 = 1 to let Modbus drive the digital inputs. Communication parameters take effect after a power cycle or H5-20 = 1.

Communication loss & watchdog

H5-05 = 1 enables CE detection after H5-09 (default 2.0 s) without messages; H5-04 sets the action (ramp, coast, fast stop, alarm only, or run at H5-34).

Byte order & addressing

  • There is no function 06H; write single registers with 10H.
  • Parameter writes need an Enter command (write 0 to 0900H or 0910H) unless H5-11 says otherwise; command registers do not.
  • With H5-04 = 0 (ramp to stop), a motor running in bypass mode coasts to stop instead.

Network setup

  • RS-485 on bypass terminal TB3 (2 TXRX+, 3 TXRX-, 1 IG5); up to 31 bypasses per line.
  • 8 data bits and 1 stop bit are fixed; speeds 1.2-115.2 kbps; parity none, even or odd.
  • Turn DIP switch S1 on the bypass control board ON only at the end of the line (termination).

Watch out for

  • Bypass faults (FBxx) are not cleared by the drive fault reset; the manual resets all faults through a bypass digital input set to Z2-0x = 34 (8400H bit 13 is also labelled fault reset).

Notes on this map

  • All registers are 16-bit; signed values are noted per register.
  • Frequency registers 0002H, 0023H and 0024H use the units chosen in o1-03, so they are left unscaled.
  • Left out: 0025H output voltage (unit switched by H5-10), 0026H/0027H output current and power (resolution or unit not fixed in the table), 00ABH/00FBH currents (unit depends on drive model), 003EH/003FH speed values, the fault-trace blocks from 0080H and the long fault/minor-fault description words from 00C0H.
  • Date/time registers 3004H-3030H, emergency-override references 3A93H-3A96H and bypass clock monitors 8440H-8442H are not listed.
  • Supported function codes are 03H, 08H, 10H, 5AH and 67H; there is no 06H, so use 10H even for one register. A 03H read returns at most 16 registers.
  • H5-08 defaults to 3 (BACnet) on the bypass, so select Modbus (0) first.
  • 0001H bits 0 and 1 are printed with two meanings each (forward run / run, and reverse run / reverse direction) without saying which applies, so bit 1 is left out; bit 0 = 1 runs the motor either way.

Questions about the Yaskawa HV600 Narrow and Enclosed Bypass (MEMOBUS/Modbus RTU)

What Modbus registers does the Yaskawa HV600 Narrow and Enclosed Bypass (MEMOBUS/Modbus RTU) have?

This map lists 38 registers: 38 holding registers. 22 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yaskawa HV600 Narrow and Enclosed Bypass (MEMOBUS/Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are hex and are sent unchanged: the manual's read example asks for starting register 0020H as 00 20. Parameters use the hex number printed under each parameter (H5-01 = 0425H).

What are the minimum Modbus registers to integrate the Yaskawa HV600 Narrow and Enclosed Bypass (MEMOBUS/Modbus RTU)?

Start with HR 1 Run command / drive MFDI command (Run command); HR 2 Frequency reference (Frequency reference); HR 33792 Bypass command word (Bypass command word 8400H); HR 32 Drive status 1 (Drive/bypass status 0020H); HR 33 Fault description 1 (Fault description 1); HR 36 U1-02 output frequency (Output frequency); HR 75 U1-12 drive status (U1-12 drive status (HAND/AUTO)); HR 49 U1-07 DC bus voltage (DC bus voltage).

How do I enable Modbus control of the Yaskawa HV600 Narrow and Enclosed Bypass (MEMOBUS/Modbus RTU)?

Select Modbus with H5-08 = 0 and give the bypass a node address (H5-01 not 0). Set b1-01 = 2 and b1-02 = 2 (or 8 for AUTO command + serial run). Set Z3-12 = 1 to let Modbus drive the digital inputs. Communication parameters take effect after a power cycle or H5-20 = 1.

What happens when the Yaskawa HV600 Narrow and Enclosed Bypass (MEMOBUS/Modbus RTU) loses Modbus communication?

H5-05 = 1 enables CE detection after H5-09 (default 2.0 s) without messages; H5-04 sets the action (ramp, coast, fast stop, alarm only, or run at H5-34).
