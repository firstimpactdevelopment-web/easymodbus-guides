Short answer

The InRow SC (ACSC 100 series) is a self-contained DX in-row cooling unit. It answers Modbus RTU and Modbus TCP with all data in holding registers, readable with function 03 or 04. This map covers unit start/stop, setpoints, air and refrigerant temperatures and pressures, fan speeds, run hours, group settings and the one-register fault flags.

This page lists 119 Modbus registers for the APC (Schneider Electric) InRow ACSC 100 Series self-contained DX cooling unit — 32 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from APC (Schneider Electric)’s own free documentation (linked below) and checked against it.

Integration notes: APC (Schneider Electric) InRow ACSC 100 Series self-contained DX cooling unit

Integration in brief

Poll holding registers with function 03 or 04: OVERALL_STATUS and OPERATE_MODE at 0 and 87, then the 32-bit temperatures from 88 upward in tenths of a degree F, and the fault flags from 256 to 299. Write UNIT_CTRL at 7 to start or stop the unit.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

The register map does not describe how to enable Modbus or set the network parameters.

Byte order & addressing

  • 32-bit values are high word first (ABCD).
  • Temperatures are tenths of a degree Fahrenheit.
  • OVERALL_STATUS uses 0, 2, 4 and 8 rather than 0-3.

Network setup

  • Modbus RTU and Modbus TCP are supported; serial settings and unit ID are not in this map.

Watch out for

  • Reading an item before the controller has data for it returns an invalid-address error, so retry later.
  • Large block reads may take 2 seconds or more.

Notes on this map

  • Word order: note 2 says 32-bit values keep the most significant word at n+0 (ABCD). The table labels them LONG; they are listed here as signed 32-bit, since note 5 says signed values are two's complement and temperatures can go below zero.
  • Scale comes from the units column: '(Tenths)' is 0.1 and '(Hundredths)' is 0.01. Temperatures are in tenths of a degree Fahrenheit.
  • Function codes 3 and 4 read the same registers; writes use function 16, or function 6 for one-register items.
  • Left out: the rows at 132 and 134, which repeat the name CONDENSER_FAN_RUNHOUR of the row at 130 so their meaning is not stated; the reserved blocks; and the APC serial diagnostic counters at 0xFFEE-0xFFFE.
  • The source prints the bias enum as '3 = Slightly Neg4 = Negative'; it is split here into 3 = Slightly Negative and 4 = Negative.
  • Data points that a unit does not support read as 0 rather than raising an error.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the APC (Schneider Electric) InRow ACSC 100 Series self-contained DX cooling unit

What Modbus registers does the APC (Schneider Electric) InRow ACSC 100 Series self-contained DX cooling unit have?

This map lists 119 registers: 119 holding registers. 32 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the APC (Schneider Electric) InRow ACSC 100 Series self-contained DX cooling unit Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table gives absolute addresses in hex and decimal. Note 11 says absolute address 0 equals Modicon register 40001 and is address zero on the wire, so the decimal column is the wire address as printed.

What byte order does the APC (Schneider Electric) InRow ACSC 100 Series self-contained DX cooling unit use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the APC (Schneider Electric) InRow ACSC 100 Series self-contained DX cooling unit?

Start with HR 0 Overall status (Overall alarm severity); HR 87 Operate mode (Unit operating mode); HR 7 Unit ctrl (Unit on / standby command); HR 1 Cool setpoint (Cooling setpoint); HR 92 Rack inlet temp (Rack inlet temperature); HR 94 Supply temp (Supply air temperature); HR 96 Return temp (Return air temperature); HR 259 Cool fail (Cooling failure alarm); HR 272 Water detected (Water detected alarm).
