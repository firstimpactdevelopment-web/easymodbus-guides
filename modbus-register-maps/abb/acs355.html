ABB ACS355 machinery drive (embedded Modbus RTU) Modbus register map

Updated 25 October 2026

Short answer

ABB's compact machinery variable frequency drive. Its embedded Modbus RTU slave is reached through the plug-in FMBA-01 RS-485 adapter (or point-to-point RS-232 on the panel connector) and maps the control word, two references, the status word and up to eight selectable actual values into 40001-40012, a 32-bit DCU-profile control/status pair into 40031-40034, and every drive parameter NNNN into register 4NNNN. This map covers the control block, group 01 operating data, fault and alarm words, fault history and the comm settings; all values are 16-bit.

This page lists 55 Modbus registers for the ABB ACS355 machinery drive (embedded Modbus RTU) — 15 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ABB’s own free documentation (linked below) and checked against it.

Integration notes: ABB ACS355 machinery drive (embedded Modbus RTU)

Integration in brief

Fit the FMBA-01 adapter, set 9802 = STD MODBUS and the group 53 link settings, then cycle power. Set 5305 = ABB DRV FULL, point 1001 EXT1 COMMANDS and 1103 REF1 SELECT at COMM, write the control word and REF1 at 40001/40002 and poll the status word plus the default actual values (output frequency, current) at 40004-40006.

Enable Modbus control & writes

Set 9802 COMM PROT SEL = STD MODBUS (EIA-485 through FMBA-01 on X3) or MODBUS RS232 (panel connector, max 3 m). Set 5302 station ID, 5303 baud, 5304 parity and 5305 profile; new settings apply at the next power-up or after clearing and re-entering 5302. For control set 1001 EXT1 COMMANDS = COMM (1002 for EXT2), 1103 REF1 SELECT = COMM, and optionally 1102 EXT1/EXT2 SEL, 1601 RUN ENABLE and 1604 FAULT RESET SEL = COMM. Save fieldbus parameter writes with 1607 PARAM SAVE.

Communication loss & watchdog

3018 COMM FAULT FUNC (NOT SEL default / FAULT / CONST SP 7 / LAST SPEED) after the delay in 3019 COMM FAULT TIME (default 3.0 s, 0.1 s steps). FAULT trips SERIAL 1 ERR (0028) and coasts; the other two raise alarm IO COMM (2005) and keep running. The supervision is inactive for 60 s after start-up.

Byte order & addressing

  • Register 4xxxx is wire address xxxx - 1 (40001 = 0); parameter NNNN is register 4NNNN.
  • Everything is 16-bit; there is no word-order setting to worry about.
  • Start per the ABB Drives state diagram with ABB DRV FULL: write 0x0476 (1142) to 40001, then 0x0477 (1143) once status bit 0 is 1, then 0x047F (1151) to run. Bit 10 (REMOTE_CMD) and bit 4 are marked ABB DRV FULL only; with FULL and bit 10 = 0 the drive keeps the last control word and reference unless both are 0. Fault reset is a 0->1 edge on bit 7 with 1604 = COMM.
  • Control word bit 3 needs the run enable signal (1601); with 1601 = COMM the bit itself provides it.
  • Only function codes 03, 06, 08, 16 (10h) and 23 (17h) are supported; there are no coils, discrete inputs or input registers.

Network setup

  • The EIA-485 port is the optional FMBA-01 module plugged into drive terminal X3; its wiring and termination are in the FMBA-01 user's manual (3AFE68586704).
  • The RS-232 option uses the control panel connector and is point-to-point, cable length at most 3 m.
  • Parameter-list defaults: station 1, 9.6 kbit/s, 8 data bits, no parity, 1 stop bit, ABB DRV LIM profile; 1.2-115.2 kbit/s selectable.
  • 5306 EFB OK MESSAGES should keep rising during polling; a rising 5307 EFB CRC ERRORS points to noise or a CRC/baud mismatch.

Watch out for

  • Embedded Modbus does nothing until 9802 is set; the default is NOT SEL.
  • Parameter writes over Modbus are volatile until 1607 PARAM SAVE is written.
  • Exception 03 covers out-of-range values, read-only parameters, too-long messages and writes refused while the drive is started. 5318 is documented both as the last exception code and as a response delay, so it is not listed here and should not be relied on as a diagnostic.
  • The AC500 Modbus application macro changes the comm defaults (station 2, 19.2 kbit/s, ABB DRV FULL), so a drive set up with that macro will not answer at the parameter-list defaults.

Notes on this map

  • There are no 32-bit registers: the manual states all values read or written are limited to 16 bits. Signals that can be negative (0101, 0105, 0106, 0110, 0111, 0112, 0404, 0405, 0408) are listed as INT16.
  • Scaling is the manual's FbEq column (fieldbus integer per unit, e.g. '1 = 0.1 Hz' -> scale 0.1).
  • 40001 and 40004 work only with 5305 = ABB DRV LIM or ABB DRV FULL; 40031-40034 work only with 5305 = DCU PROFILE. ABB DRV LIM (the default) ignores control word bits 4 (RAMP_OUT_ZERO) and 10 (REMOTE_CMD).
  • Actual values 40005-40012 follow 5310-5317 (defaults: 40005 = 0103, 40006 = 0104, 40007-40012 unassigned). Their scaling is that of the chosen signal, so they are left unscaled here; 40007-40012 are not listed.
  • Reference scaling (ABB Drives profile): REF1 20000 = 1105 REF1 MAX (speed or frequency); REF2 10000 = 1108 REF2 MAX (speed, frequency, torque or PID). 1104/1107 minimums do not affect the scaling.
  • Defaults conflict inside the manual: group 53 lists 5302 = 1, 5303 = 9.6 kbit/s, 5304 = 8 NONE 1 and 9802 = NOT SEL, while the AC500 Modbus macro sets station 2, 19.2 kbit/s, 5304 = 1 (which the parameter list calls 8 NONE 2), ABB DRV FULL and STD MODBUS. The text of that macro also mislabels 5302 as 5303. The macro also sets 3018 = FAULT and re-points 5310-5312 to 0101, 0303 and 0305, so 40005-40007 then read speed & dir, DCU status word LSW and fault word 1. Check the drive.
  • 0111 External ref 1 is in 0.1 Hz or 1 rpm depending on 9904 Motor ctrl mode, so it is left unscaled.
  • Left out: 0120-0139 analog I/O, PID and process-variable signals (units depend on configuration), 0160/0414 DI status (panel and binary encodings differ), 0402/0403 fault time stamps, 0409 status at fault, and all motor/application parameters.
  • The group 03 fault and alarm words are documented as read-only actual signals, but the alarm word text says an alarm can be reset by writing zero to the word; they are marked R here.
  • 5318 EFB PAR 18 is left out: the group 53 parameter list describes it as an extra response delay in ms, while the exception-code section says it holds the most recent exception code, so its meaning cannot be pinned down from the manual.

Questions about the ABB ACS355 machinery drive (embedded Modbus RTU)

What Modbus registers does the ABB ACS355 machinery drive (embedded Modbus RTU) have?

This map lists 55 registers: 55 holding registers. 15 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB ACS355 machinery drive (embedded Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists 4xxxx holding registers and states that register 4xxxx is sent as xxxx - 1 in the Modbus message (its example: 40002 is addressed as 0001), so 40001 = wire address 0. Drive parameter NNNN sits at register 4NNNN (e.g. 0103 -> 40103, wire 102; 3018 -> 43018, wire 3017). Registers that do not correspond to a parameter return an exception.

What are the minimum Modbus registers to integrate the ABB ACS355 machinery drive (embedded Modbus RTU)?

Start with HR 0 Control word (ABB Drives) (Control word: start/stop/reset); HR 1 Reference 1 (REF1) (REF1 speed/frequency setpoint (20000 = 1105)); HR 3 Status word (ABB Drives) (Status word: ready/running/fault/remote); HR 102 0103 Output freq (0103 Output frequency, 0.1 Hz); HR 103 0104 Current (0104 Motor current, 0.1 A); HR 106 0107 DC bus voltage (0107 DC bus voltage); HR 400 0401 Last fault (0401 Last fault code); HR 304 0305 Fault word 1 (0305 Fault word 1).
