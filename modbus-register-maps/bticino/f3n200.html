Short answer

The F3N200 is a BTicino PM multifunction meter with an RS-485 Modbus RTU port. Integration notes: BTicino PM multifunction meter F3N200 (Modbus RTU)

Integration in brief

Read holding registers with function 03 from 51280: the 16-bit block gives voltages, currents, frequency, power, power factor and energy without any word-order question. The 32-bit block at 50512 is more precise but its word order is not documented, so test it on a live meter before using it.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus address (1-247), baud rate, parity and stop bits are programmable; the table does not say where. To change setup over Modbus, write the registers, write 0xA1 to 57856 (E200) to store, then 0xB2 to reboot.

Byte order & addressing

  • Values are read with function 03 even though the table calls them input registers.

Network setup

  • RS-485 two-wire, RTU mode, 8 data bits; baud 2400-38400, parity none/odd/even and 1 or 2 stop bits are programmable.
  • The table does not state factory defaults for address, baud or parity.

Watch out for

  • Setup changes are not applied until 0xA1 (store) and 0xB2 (reboot) are written to 57856.
  • Reset codes at 1024 can be OR-ed together; 0x1000 resets all parameters.

Notes on this map

  • The document states only the byte order ('Big Endian, most significant byte first') and never which word of a 2-register value comes first, so every 32-bit register is left out. The 16-bit copies of the live values (51280 block) are listed instead.
  • The table groups these values under 'INPUT REGISTERS' but gives function code 3 for reading them, and the worked example uses function 03, so they are listed as holding registers.
  • The worked example requests 2 registers for V1 but shows a 2-byte reply (08FC = 2300 x 0.01 = 230 V); it confirms the address and scale, not the word order.
  • Unavailable values read 0xFFFFFFFF (unsigned) or 0x7FFFFFFF (signed); 16-bit copies use 0xFFFF / 0x7FFF.
  • The 51280 block holds 16-bit values that the table says are not affected by the CT/VT ratios; the 50512 block includes them.
  • Left out: the customisation and TC-correction block at 4096, whose data types are not given; alarm min/max values and alarm duration (no data type); alarm type, thresholds and hysteresis (36363-36367), because the alarm-type code list repeats codes 5-9 and thresholds have no units; and setup registers 36355/36356, whose rows run together so the 'Reserved' register and the current-averaging period can't be told apart; and the hour-meter trigger threshold (36362), whose unit is printed as A/V.
  • The setup and network registers have no data type column; they are single-word values listed here as UINT16.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the BTicino PM multifunction meter F3N200 (Modbus RTU)

What Modbus registers does the BTicino PM multifunction meter F3N200 (Modbus RTU) have?

This map lists 60 registers: 60 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the BTicino PM multifunction meter F3N200 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table prints three columns: a 'Register Number' (address + 1) and the 'Register Address' in decimal and hex. The register address is the wire address: the worked example reads V1 with request 05 03 C558 0002, so 50520 (C558) goes on the wire unchanged.

What are the minimum Modbus registers to integrate the BTicino PM multifunction meter F3N200 (Modbus RTU)?

Start with HR 51284 Voltage V1 (16-bit) (Phase 1 voltage); HR 51288 Current I1 (16-bit) (Phase 1 current); HR 51292 Total active power P (16-bit) (Total active power); HR 51295 Total power factor (16-bit) (Total power factor); HR 51287 Frequency (16-bit) (Frequency); HR 51311 Total positive active energy Ea+ (not resettable) (Imported active energy).

How do I enable Modbus control of the BTicino PM multifunction meter F3N200 (Modbus RTU)?

Modbus address (1-247), baud rate, parity and stop bits are programmable; the table does not say where. To change setup over Modbus, write the registers, write 0xA1 to 57856 (E200) to store, then 0xB2 to reboot.
