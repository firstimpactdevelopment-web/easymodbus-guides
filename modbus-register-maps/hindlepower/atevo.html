HindlePower ATevo battery charger (Modbus communications adapter) Modbus register map

Updated 17 November 2026

Short answer

HindlePower's ATevo industrial battery charger supports Modbus RTU on its serial communications adapter and Modbus TCP on the Ethernet adapter. Charger options are coils, about 60 alarm and status flags are discrete inputs, measurements (DC and AC voltages and currents, ground-fault data) are input registers and all setpoints are holding registers, with fixed multipliers. This map covers the published Modbus register set apart from a few values whose sign or units are not stated.

This page lists 114 Modbus registers for the HindlePower ATevo battery charger (Modbus communications adapter) — 32 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from HindlePower’s own free documentation (linked below) and checked against it.

Integration notes: HindlePower ATevo battery charger (Modbus communications adapter)

Integration in brief

Assign Modbus to the serial port (or enable Modbus on the Ethernet adapter) and set the Modbus address in MENU > COMMUNICATION, then poll 30006/30007 for DC output voltage and current, the discrete inputs for alarms, and write setpoints to 40001-40021.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Serial: MENU > COMMUNICATION > select the port > Protocol = Modbus, then set Address (1-247), Baud rate, Parity, Stop bits and Handshake (set none). Ethernet: MENU > COMMUNICATION > Ethernet setup > Modbus enabled, Port (default 502) and Address.

Byte order & addressing

  • Values are scaled integers; divide by the multiplier.
  • 32-bit timestamps are low word first.

Network setup

  • Handshaking should be set to none; it is never used on RS-485.
  • HindlePower recommends leaving the Modbus TCP port at 502.

Watch out for

  • Some values are reported only with the matching optional hardware; discrete input 10051 shows whether the AC meter option is installed.

Notes on this map

  • This is HindlePower's own manual, published on the manula.com documentation platform (each section is a separate page).
  • Scaling: divide the raw value by the Multiplier column (10 for XXX.X values, 100 for XXX.XX). Scale = 1 / multiplier.
  • 32-bit timestamps are split into a 'Low' and a 'High' register with the low word in the lower address (CDAB): 30018/30019 battery open test time and 40022/40023 date/time, both seconds since 1 January 2000.
  • Left out: 30002 Modbus firmware revision (format 'XXX.xxx.0' cannot be decoded from one register), 30009 (not used), 30010 battery temperature, 30011 rectifier temperature, 30020 ambient temperature, 30029/30030 battery current (the manual does not say whether negative values are sent as signed integers).
  • 30013/30014 (positive/negative terminal to ground) are listed without units because the manual gives none.
  • Some entries are only reported when the matching optional hardware is installed (e.g. AC meter option for 30022-30028).
  • Valid ranges of many setpoints depend on the charger rating; see HindlePower supplement JA5124-02. Writing outside the range returns an exception.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the HindlePower ATevo battery charger (Modbus communications adapter)

What Modbus registers does the HindlePower ATevo battery charger (Modbus communications adapter) have?

This map lists 114 registers: 10 coils, 59 discrete inputs, 23 input registers, 22 holding registers. 32 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the HindlePower ATevo battery charger (Modbus communications adapter) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables use Modicon references (00001 coils, 10001 discrete inputs, 30001 input registers, 40001 holding registers) and the implementation follows the Modicon PI-MBUS-300 guide, so 30001 is input register 0 on the wire and 40001 holding register 0.

What byte order does the HindlePower ATevo battery charger (Modbus communications adapter) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the HindlePower ATevo battery charger (Modbus communications adapter)?

Start with IR 5 Charger DC output voltage (DC output voltage, 0.1 V); IR 6 Charger DC output current (DC output current, 0.1 A); DI 6 Common alarm relay (CAR) alarm (Common alarm); DI 3 No AC input alarm (No AC input alarm); DI 2 DC output failure alarm (DC output failure); HR 0 Float voltage setpoint (Float voltage setpoint); HR 13 Charger mode setting (Charger mode).

How do I enable Modbus control of the HindlePower ATevo battery charger (Modbus communications adapter)?

Serial: MENU > COMMUNICATION > select the port > Protocol = Modbus, then set Address (1-247), Baud rate, Parity, Stop bits and Handshake (set none). Ethernet: MENU > COMMUNICATION > Ethernet setup > Modbus enabled, Port (default 502) and Address.
