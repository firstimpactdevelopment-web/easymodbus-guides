Daikin EKRHH Daikin HomeHub (Modbus TCP/RTU for Daikin Altherma and air-to-air heat pumps) Modbus register map

Updated 19 November 2026

Short answer

The Daikin HomeHub (EKRHH) connects to a Daikin Altherma system and offers a Modbus TCP (port 502, or 802 with TLS) or Modbus RTU slave. Holding registers set leaving-water and room setpoints, operation mode, on/off, quiet mode, hot-water reheat and booster, weather-dependent mode and the smart-grid mode with power limits; input registers return error state and code, pump/compressor/heater/defrost states, water, outdoor and refrigerant temperatures, flow, power use and setpoint limits. For air-to-air units only the smart-grid mode and demand-control power limit are offered.

Integration notes: Daikin EKRHH Daikin HomeHub (Modbus TCP/RTU for Daikin Altherma and air-to-air heat pumps)

Integration in brief

Enable Modbus in the ONECTA app, then read input registers 21-53 for state and temperatures and write holding registers 1-13 and 53-58 for setpoints, modes and smart-grid control. Refresh written values periodically because the HomeHub only forwards changes.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus (RTU or TCP/IP) is configured in the ONECTA app settings for the HomeHub (installer reference guide section 13.1.1).

Byte order & addressing

  • Modbus writes are change based: the HomeHub only updates the unit when it sees a change, so values lost during an outage are not resent. Refresh the state from the client periodically.
  • After the compressor starts, power-limit writes can be overruled for 15 minutes with max(4.5 kW, register value).
  • The error code (input 22) is two ASCII characters packed high byte first.

Network setup

  • RTU: 3-wire RS-485 on the HomeHub's X8A connector, 9600 baud, no parity, 8 data bits, 1 stop bit, slave address 1-247.
  • TCP: port 502 without encryption or 802 with TLS, at the HomeHub's IP address.

Watch out for

  • Room buffering during smart-grid requests needs unit control method [C-07]=2 (room thermostat control); tank buffering needs field settings [E-05]=1 and [E-06]=1.
  • The DHW reheat setpoint only takes effect when the tank is enabled, heat pump mode is reheat only and the setpoint mode is fixed.

Notes on this map

  • Data types are Daikin's: Temp16 and Pow16 are signed 16-bit values divided by 100 (°C and kW); Int16 is a signed 16-bit value with no scaling; Text16 is two ASCII characters. The holding-register setpoints are printed as Int16, so they are whole degrees.
  • Holding offsets 59 and 61 (thermostat inputs): with external room thermostat control ([C-07]=1) they are only valid when thermostat type [C-05]=0 (SW contact), otherwise they read 0 (off). Not available on Daikin Altherma 3 R / 3 M units with Micon ID 20002203.
  • Offsets 1001 and 1002 belong to use case 4 (air-to-air heat pumps) and are the only registers supported there. The type of 1001 is not printed; it is listed as INT16 with the same codes as offset 56.
  • Special return values: 32767 = register unsupported, 32766 = register unavailable in this configuration, 32765 = value not loaded yet (also returned while the HomeHub synchronises).
  • Writes to setpoint registers outside the configured range are clamped to the nearest limit; out-of-range writes to other registers are ignored.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Daikin EKRHH Daikin HomeHub (Modbus TCP/RTU for Daikin Altherma and air-to-air heat pumps)

What Modbus registers does the Daikin EKRHH Daikin HomeHub (Modbus TCP/RTU for Daikin Altherma and air-to-air heat pumps) have?

This map lists 61 registers: 36 input registers, 25 holding registers. 25 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Daikin EKRHH Daikin HomeHub (Modbus TCP/RTU for Daikin Altherma and air-to-air heat pumps) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide lists register offsets 1-based and says PDU addressing is 0-based: register 1 is requested at PDU address 0. Every wire address here is the printed offset minus one.

What are the minimum Modbus registers to integrate the Daikin EKRHH Daikin HomeHub (Modbus TCP/RTU for Daikin Altherma and air-to-air heat pumps)?

Start with HR 3 Space heating/cooling ON/OFF (Space heating/cooling on/off); HR 2 Operation mode (Operation mode); HR 0 Leaving water Main Heating setpoint (Leaving water heating setpoint); HR 55 Smart Grid operation mode (Smart grid mode); HR 57 General power limit (General power limit); IR 20 Unit abnormality (Unit abnormality); IR 21 Unit abnormality code (Error code); IR 30 Compressor run (Compressor running); IR 43 Outside air temperature (Outside air temperature); IR 50 Heat pump power consumption (Power consumption).
