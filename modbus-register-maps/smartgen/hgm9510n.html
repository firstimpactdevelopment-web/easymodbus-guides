SmartGen HGM9510N / HGM9520N / HGM9530N Modbus register map

Updated 16 October 2026

Short answer

SmartGen's HGM9510N, HGM9520N and HGM9530N are genset paralleling controllers; the HGM9520N variant also commands a mains breaker. Two RS485 ports speak Modbus RTU and the RJ45 port speaks Modbus TCP, all with the same register tables. Status, alarms and measurements are holding registers read with FC03; remote keys are FC05 coil writes; the clock and two load-share setpoints are FC06 writes. This map covers status words, voltages, currents, powers, engine values, breaker and genset state codes, counters and the remote command coils.

This page lists 134 Modbus registers for the SmartGen HGM9510N / HGM9520N / HGM9530N — 30 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from SmartGen’s own free documentation (linked below) and checked against it.

Integration notes: SmartGen HGM9510N / HGM9520N / HGM9530N

Integration in brief

Poll register 0000 for mode and common alarm flags, 0260 for genset state, 0264/0268 for breaker states, and the measurement block 0120-0259. To start: send Remote Manual (coil 4), confirm bit 10 of register 0, send Remote Start (coil 0), then follow Generator Status until Normal Running.

Enable Modbus control & writes

Set the controller address in the parameter menu (Controller Parameter Setting, default password 0318); the setting applies once saved. Each controller on a network needs a unique address.

Byte order & addressing

  • Status bits are packed into FC03 registers (word.bit notation); FC01/FC02 are not listed as supported function codes.
  • 32-bit values are low word first (CDAB).
  • Remote key coils accept FF00 only and act once per write, like a key press. Remote outputs and Remote Lock are latched: FF00 sets, 0000 clears.
  • Read at most 120 registers per request.

Network setup

  • RS485: address default 1 (1-245 per the data-format list; 1-254 per the address table), 9600 bps, 8 data bits, parity none/odd/even (default none), 1 or 2 stop bits; at least 200 ms timeout; up to 32 units per segment.
  • The TR terminal has a built-in 120 Ω resistor; link terminals 35 and 36 to enable it at the bus ends.
  • Ethernet: Modbus TCP on port 502, 10/100 Mbit, CAT5e or better, max 100 m per segment. The built-in switch supports ring redundancy.

Watch out for

  • These controllers start engines and close breakers onto a live bus or the mains. Make sure the site is safe and the operators know before sending start, close or mode commands.
  • The document's start sequence needs Manual mode first: a Remote Start in Auto is not part of the documented procedure. Check bit 10 of register 0 before starting.
  • On the HGM9520N, coils 5/6 are close/open keys and the document does not say how the controller chooses between closing and opening; read the breaker state (0264/0268) first so a repeated write does not drop the load.
  • Remote Stop switches the controller to Stop mode, which takes it out of Auto; send Remote Auto afterwards to re-arm automatic operation.
  • The load-share setpoints 4368/4370 only act when the controller is in gen control (constant power) mode.

Notes on this map

  • 32-bit values put the low 16 bits at the lower address: the document's example reads A-phase active power at 0174-0175 as E240h, 0001h and combines them to 0001E240h (123456). That is CDAB word order; it is applied to every 4-byte value in the table.
  • The alarm area 0001-0105 is seven 15-word fields (shutdown, trip-and-stop, trip, safety trip-and-stop, safety trip, block, warning). Each field uses the same bit layout from the alarm data table; only the first word of the shutdown and warning fields is mapped here. Bits of later words are in the document (pp. 36-41).
  • Engine temperature (0220) has no signedness printed but its range starts at -50, so it is listed as signed 16-bit.
  • Left out: ROCOF (0136), Negative/Zero phase angle (0202-0203) and Aux. sensor values (0226, 0228) because no scale or unit is printed; Unbalanced Current (0204) because it is marked both 0-65535 and signed; Multi-unit Total Reactive Power (0285) because its unit is printed as kvarh; expansion module (AIN24/AIN8) values, per-breaker A/B counters (0341-0352), J1939 DM1/DM2 fault lists and the ECU aftertreatment/indicator block 0533-0625.
  • A reading of 32766 means no valid data.
  • FC06 is only accepted at 0296-0302 (clock) and at the two load-share setpoints 4368 and 4370; all other registers are read-only.
  • Generator status codes 14 and 15 are After Stop and Stop Failure in this document (the order is reversed compared with the HGM6100N document).
  • Left out: the per-phase, average and mains power factors (0198-0201, 0259). They are 2-byte registers with ratio 0.001, but the printed range -100.000 to 100.000 does not fit a 16-bit value at that ratio, so the scale is contradictory.
  • Left out: the delay values that follow each state code (0261, 0263, 0265, 0267, 0269); no unit or ratio is printed for them.
  • The RS485 data-format list gives the communication address as 1-245, while the address-assignment table elsewhere in the document says 1-254.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the SmartGen HGM9510N / HGM9520N / HGM9530N

What Modbus registers does the SmartGen HGM9510N / HGM9520N / HGM9530N have?

This map lists 134 registers: 21 coils, 113 holding registers. 30 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the SmartGen HGM9510N / HGM9520N / HGM9530N Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print a decimal 'Modbus Address' (used here as the wire address) and a 1-based 'PLC Address' (40001 style). The document's examples confirm it: address 0174 is requested as 0x00AE and the load-share setpoint 4368 as 0x1110. Bit flags are printed as word.bit, e.g. 0000.10 = bit 10 of register 0.

What byte order does the SmartGen HGM9510N / HGM9520N / HGM9530N use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the SmartGen HGM9510N / HGM9520N / HGM9530N?

Start with HR 0 Summary Status Word (Mode and common alarm flags); HR 260 Generator Status (Genset running state); HR 264 Gen Breaker (ATS) Status (Generator breaker state); HR 146 Gen UA (Generator phase A voltage (32-bit)); HR 166 A Phase Current (Phase A current); HR 180 Total Active Power (Total active power (32-bit)); HR 212 Engine Speed (Engine speed); CO 0 Remote Start Key (STARTS ENGINE) (Remote start command).

How do I enable Modbus control of the SmartGen HGM9510N / HGM9520N / HGM9530N?

Set the controller address in the parameter menu (Controller Parameter Setting, default password 0318); the setting applies once saved. Each controller on a network needs a unique address.
