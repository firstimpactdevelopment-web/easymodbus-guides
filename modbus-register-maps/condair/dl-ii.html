Integration notes: Condair DL II hybrid humidifier (Integrated Controller, Modbus RTU/TCP)

Integration in brief

Read input registers 2000-2019 (UInt16 states) and 2025-2050 (floats). To control over Modbus, write the demand or humidity value to holding 3004 at least once per signal timeout and enable via 3005.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Controls > Signal Settings: set Source = Modbus (and Remote Enable = Modbus to use register 43006). The demand register 43005 only works when Source is not Analog.

Communication loss & watchdog

When the demand or humidity signal comes from Modbus, it must be rewritten within 'Signal Timeout' (1-300 s, default 300 s); otherwise warning W35 is raised and the unit stops humidifying.

Byte order & addressing

  • The address column is the wire address; 32001 is address 2000.
  • Floats are two registers, MSR first by default.

Network setup

  • Menu > password 8808 > Network > Modbus Settings: set protocol (Modbus/RTU or Modbus/TCP), address, parity, baud rate and register sequence; the controller restarts after a protocol change.
  • For Modbus TCP set the IP parameters under Network > IP Settings (factory setting DHCP).

Watch out for

  • With Modbus as signal source, do not also wire a hard demand signal to the driver board.
  • Remote enable via 43006 needs software 1.4.0 or later.

Notes on this map

  • Input registers are read with function 04; holding registers with 03 and written with 06 or 16.
  • Floats use 'Register Sequence': MSR first (high register first, ABCD) is the factory setting; LSR first (CDAB) is the option. The map assumes the factory setting.
  • Factory serial settings: Modbus RTU, address 10, 19200 baud, even parity, 8 data bits, 1 stop bit. Modbus TCP uses port 502 and unit ID 255 (per the TCP technical data).
  • Units marked metric/imperial follow the controller's Metric/Imperial setting; the listed unit is the metric one.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Condair DL II hybrid humidifier (Integrated Controller, Modbus RTU/TCP)

What Modbus registers does the Condair DL II hybrid humidifier (Integrated Controller, Modbus RTU/TCP) have?

This map lists 40 registers: 32 input registers, 8 holding registers. 8 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Condair DL II hybrid humidifier (Integrated Controller, Modbus RTU/TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print the 5-digit register (32001 = input register, 43001 = holding register) and the 0-based address beside it (2000 / 3000). The address column is what goes on the wire; the manual's own example: register 43004 = address 3003.

What byte order does the Condair DL II hybrid humidifier (Integrated Controller, Modbus RTU/TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Condair DL II hybrid humidifier (Integrated Controller, Modbus RTU/TCP)?

Start with IR 2001 Device Status (Device status); IR 2002 Maintenance and Error Status (Maintenance and error status); IR 2003 Error or Warning Code (Error/warning code); IR 2027 Actual Humidification Capacity (Actual capacity); IR 2029 Actual Humidity or Demand (Actual humidity or demand); HR 3004 Actual Humidity or Demand via Modbus (Demand/humidity via Modbus); HR 3005 Remote Enable (Remote enable).

How do I enable Modbus control of the Condair DL II hybrid humidifier (Integrated Controller, Modbus RTU/TCP)?

Controls > Signal Settings: set Source = Modbus (and Remote Enable = Modbus to use register 43006). The demand register 43005 only works when Source is not Analog.

What happens when the Condair DL II hybrid humidifier (Integrated Controller, Modbus RTU/TCP) loses Modbus communication?

When the demand or humidity signal comes from Modbus, it must be rewritten within 'Signal Timeout' (1-300 s, default 300 s); otherwise warning W35 is raised and the unit stops humidifying.

Where is the official Condair DL II hybrid humidifier (Integrated Controller, Modbus RTU/TCP) Modbus documentation?

The source is Modbus addendum manual for DL II, ME II, RS II, RO-E and Vita (Integrated Controller) (2603326-G EN 2607), published free by Condair at https://www.condair.com/m/0/2603326-e-modbus-for-dl-series-addendum.pdf.
