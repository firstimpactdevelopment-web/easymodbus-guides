Siemens SINAMICS V20 inverter (Modbus RTU) Modbus register map

Updated 24 October 2026

Short answer

Siemens' compact general-purpose inverter, with an RS485 port on the control terminals that runs USS by default and Modbus RTU when P2023 = 2. The drive exposes two holding-register blocks: a MICROMASTER-style block from 40001 with individual run/fault/direction bits and scaled measurements, and a block from 40100 with the raw control word, setpoint, status word and actual value plus scaled measurements, fault history and PID settings. This map covers both blocks except the generic parameter-access window.

Integration notes: Siemens SINAMICS V20 inverter (Modbus RTU)

Integration in brief

Run connection macro Cn011 (or set P0700 = 5, P1000 = 5, P2023 = 2 and power-cycle), then write the control word to 40100 and the setpoint to 40101 and poll 40110/40111 for status and actual value. 40024-40033 / 40340-40348 give scaled frequency, current, power and voltage.

Enable Modbus control & writes

Connection macro Cn011 sets P0700 = 5 (command source RS485), P1000 = 5 (setpoint RS485), P2023 = 2 (Modbus), P2010 = 6 (9600 bps), P2021 = 1, P2022 = 1000 ms, P2014 = 100 ms, P2034 = 2 (even parity) and P2035 = 1 stop bit. Power-cycle after changing P2023, waiting until the display goes blank. Baud choices P2010: 6 = 9600, 7 = 19200, 8 = 38400, 9 = 57600, 10 = 76800, 11 = 93750, 12 = 115200.

Communication loss & watchdog

P2014[0] USS/MODBUS telegram off time (factory 2000 ms, 100 ms with Cn011; 0 disables). F72 trips if P2014 is non-zero, process data has been received since power-up and the gap between two process-data telegrams exceeds P2014.

Byte order & addressing

  • Only FC03, FC06 and FC16; up to 125 registers per read and 123 per write.
  • Subtract 40001 from the printed register: 40100 goes on the wire as 99.
  • With P0700 = 5 the first process-data word must be the control word and, with P1000 = 5, the second the main setpoint (r2018 note).
  • With FC16, writes the inverter can't perform return an exception while the other registers in the same request are still written.
  • Failed parameter accesses answer exception 04; the detail is in 40499.

Network setup

  • RS485 on control terminals P+ and N-, with 0 V as reference; screened twisted pair recommended.
  • Terminate one bus end with 120 ohm across P+/N- and the other end with a bias network (1.5 k from 10 V to P+, 120 ohm P+ to N-, 470 ohm N- to 0 V).
  • P2021 sets the Modbus address (1-247), P2034 parity (0 none, 1 odd, 2 even), P2035 stop bits (1 or 2).
  • P2022 Modbus reply timeout (0-10000 ms, default 1000): replies that would take longer are dropped.
  • r2024-r2031 count good and rejected telegrams for diagnostics.

Watch out for

  • The RS485 port runs USS (P2023 = 1) out of the box; nothing answers Modbus until P2023 = 2 and a power cycle.
  • If P2023 is changed over the bus, save to EEPROM with P0971 before power-cycling or the change is lost.
  • P2010, P2021 and P2023 keep their values through a factory reset.
  • Before fitting the SINAMICS V20 Smart Access module to a drive that uses RS485, set P2010[1] = 12 from the BOP.

Notes on this map

  • All values are single 16-bit registers; there are no 32-bit values in the map. Scaled values are sent as the engineering value multiplied by the table's scaling factor (e.g. 100 for 0.01 resolution), so the scale here is 1 / factor.
  • Signed/unsigned is not printed per register; registers with a negative range in the table are INT16, the rest UINT16. Ramp times and P2000 reach raw values above 32767 (650.0 s x 100, 550.00 Hz x 100), which only fits as unsigned.
  • Left out: 40002 Watchdog action (the manual gives no action codes), 40035 Stop/run (its on/off text order contradicts the status bit it mirrors), 40349 Hand/auto (r0807 only reports whether an external client has master control; the HAND/AUTO text is not tied to a bit value), 40013 (reserved), and the parameter-access window 40550-40559 (parameter number, index, upper/lower word) because the access procedure is not described.
  • 40003 and 40044 are the setpoint and actual value in % (factor 100); 40101 and 40111 are the same process data unscaled, where 4000 hex = 100 % of P2000.
  • Writing a BICO register (e.g. 40014/40200 digital output, 40009/40500 PID enable) fixes that BICO input to a static 0 or 1 and drops its previous connection; reading returns the BICO output.
  • This is the 11/2016 edition; a newer 05/2022 edition exists on the Siemens support site but its direct PDF link refused automated download, so it was not used.

Questions about the Siemens SINAMICS V20 inverter (Modbus RTU)

What Modbus registers does the Siemens SINAMICS V20 inverter (Modbus RTU) have?

This map lists 107 registers: 107 holding registers. 38 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Siemens SINAMICS V20 inverter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The mapping table prints each register twice: an 'Inverter' number starting at 0 and a 'MODBUS' number starting at 40001 (e.g. 0 = 40001, 99 = 40100). The inverter number is the value that goes into the request, so subtract 40001 from the Modicon number: control word 40100 is wire address 99.

What are the minimum Modbus registers to integrate the Siemens SINAMICS V20 inverter (Modbus RTU)?

Start with HR 99 STW (control word 1) (Control word: ON/OFF1, enables, fault acknowledge); HR 100 HSW (main setpoint) (Main setpoint, 4000 hex = P2000); HR 109 ZSW (status word 1) (Status word: ready, running, fault, warning); HR 110 HIW (main actual value) (Main actual value); HR 341 Frequency output (Output frequency in 0.01 Hz); HR 344 Current (Output current in 0.01 A); HR 346 Actual power (Actual power in 0.01 kW); HR 399 Fault 1 (Latest fault number).

How do I enable Modbus control of the Siemens SINAMICS V20 inverter (Modbus RTU)?

Connection macro Cn011 sets P0700 = 5 (command source RS485), P1000 = 5 (setpoint RS485), P2023 = 2 (Modbus), P2010 = 6 (9600 bps), P2021 = 1, P2022 = 1000 ms, P2014 = 100 ms, P2034 = 2 (even parity) and P2035 = 1 stop bit. Power-cycle after changing P2023, waiting until the display goes blank. Baud choices P2010: 6 = 9600, 7 = 19200, 8 = 38400, 9 = 57600, 10 = 76800, 11 = 93750, 12 = 115200.

What happens when the Siemens SINAMICS V20 inverter (Modbus RTU) loses Modbus communication?

P2014[0] USS/MODBUS telegram off time (factory 2000 ms, 100 ms with Cn011; 0 disables). F72 trips if P2014 is non-zero, process data has been received since power-up and the gap between two process-data telegrams exceeds P2014.
