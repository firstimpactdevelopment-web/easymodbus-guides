Integration notes: Intesis (HMS Networks) INMBSPAN001I100 Panasonic Etherea (domestic) AC to Modbus RTU gateway

Integration in brief

Write 0-4 for on/off, mode, fan, vane and setpoint; poll 5, 10, 11, 66 and the energy pairs 72-77. Set the date registers 78-80 if you want daily energy to roll over correctly.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step; register 7 = 1 disables the gateway.

Byte order & addressing

  • Temperature scale depends on SW4.
  • Energy pairs are high word first.
  • Writing an external temperature to 22 hands the setpoint to the gateway's virtual-temperature logic and the Panasonic remote can no longer change it.

Network setup

  • 9600 baud 8N2 by default (8N1 auto-detected); baud on SW3/SW4.
  • Slave address 1..63 on SW3 (default 1).
  • 120 ohm terminator on SW4.

Watch out for

  • Power, current and energy reflect the whole AC system.
  • Several registers exist only on 2013 (PKE) and later models.

Notes on this map

  • All registers are 16-bit unsigned holding registers; the 'no value' marker printed -32768 is raw 0x8000 (32768).
  • Energy counters are given as MSW/LSW register pairs with the most significant word at the lower address (72/73, 74/75, 76/77), so they are mapped as UINT32 high word first (ABCD). The manual's text '0..65535 (hours)' on those rows is a copy slip; the unit is stated as watt-hours.
  • Temperatures follow SW4: x1 °C, x10 °C or °F. The register footnote calls x10 the default but the DIP-switch table marks x1 and Celsius as factory setting, so scale 1 / °C is used; with x10 set use 0.1.
  • FC16 is accepted only with a length of 1, so the two words of Total energy (76/77) must be written one at a time.
  • Left out: machine threshold and custom setpoint-limit registers 1151-1156, because the manual does not say whether they follow the SW4 x1/x10 setting.
  • Error code list not reproduced; see manual section 7.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious.
