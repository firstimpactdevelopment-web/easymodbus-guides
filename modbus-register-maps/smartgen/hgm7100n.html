SmartGen HGM7100N Series Modbus register map

Updated 16 October 2026

Short answer

SmartGen's HGM7100N controllers run a single genset (HGM7110N) or a genset with automatic mains failure transfer (HGM7120N). The RS485 port is a Modbus RTU slave: alarms, modes and I/O are packed bit words, measurements and counters are 16-bit holding registers (FC03), and front-panel keys are mirrored as FC05 coils. This map covers the status and alarm words, frequencies, currents, power factor, battery voltage, state codes, counters, clock and the remote command coils; values without a printed scale and all 32-bit values are left out (see notes).

This page lists 81 Modbus registers for the SmartGen HGM7100N Series — 33 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from SmartGen’s own free documentation (linked below) and checked against it.

Integration notes: SmartGen HGM7100N Series

Integration in brief

Poll holding registers 0000-0045 for alarms, modes and I/O, 0064-0143 for measurements and 0189-0213 for states and counters with FC03. Remote keys are single FC05 writes of FF00 to coils 0000-0015.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Give each controller a unique slave address (the protocol allows 1-255) in the controller parameters before networking several units; the document does not state the default address.

Byte order & addressing

  • Only FC03, FC05 and FC06 are supported; status bits are read from holding registers, not with FC01/FC02.
  • Read at most 125 registers per request.
  • Coil writes accept FF00 (on) or 0000 (off); any other value is ignored. The command coils are named after the front-panel keys.
  • Frames with a CRC error get no reply at all; other request errors return exception codes 01 (function), 02 (address) or 03 (value).

Network setup

  • 9600 bps, 8 data bits, no parity, 1 stop bit (2 stop bits can be set).
  • Up to 32 slaves per RS485 line in master-slave mode.

Watch out for

  • This controller starts a real engine and switches load between mains and generator. Make sure the genset and switchgear are safe to operate before sending start, transfer or mode commands.
  • Remote Stop acts like pressing the panel Stop key. Check the mode bits in register 0000 afterwards and send Remote Auto if the set must stay ready for a mains failure.
  • Writing the run-time or start counters (0199-0210) overwrites service history; only do it deliberately.

Notes on this map

  • The document prints no units at all. Units are kept only where the document prints a multiplier ((*10) or (*100)) and the quantity name fixes the unit: frequency (Hz), phase current (A), battery and charger voltage (V); plus registers whose name states hour, minute or second. (*10) means the raw value is ten times the real value (scale 0.1), (*100) means scale 0.01.
  • Left out because no scale or unit is printed: mains and gen phase and line voltages (0055-0060, 0075-0080), voltage phase angles (0061-0063, 0081-0083), load percentage (0140), engine speed (0141), the analog sensor values and resistances (0148-0157), the ECU-only J1939 values (0162-0170) and the state delay values (0190, 0192, 0194, 0196).
  • Left out: all 4-byte values (per-phase and total kW, kvar and kVA at 0103-0126, current energy, average and historical power at 0134-0139, total fuel at 0171-0172, total kWh/kvarh/kVAh at 0203-0208 and the MCU ID). The document never states which register of a pair holds the high word, so the word order cannot be established from it.
  • Bit words list bit 0 (LSB) first; reserved bits are omitted from the bit lists.
  • FC06 is accepted only at 0199-0210 (run-time, start and energy counters) and 0225-0231 (clock); every other register is read-only. Of the writable counters only the 16-bit ones are mapped.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the SmartGen HGM7100N Series

What Modbus registers does the SmartGen HGM7100N Series have?

This map lists 81 registers: 22 coils, 59 holding registers. 33 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the SmartGen HGM7100N Series Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The appendix prints decimal addresses 0000-0284 and they are used as the wire address. Two examples confirm it: the FC05 example writes coil 0000 (Remote Start) at 0x0000, and the FC06 example writes 00E3H (= 227, Controller Time day) inside the FC06-writable range 0225-0231.

What are the minimum Modbus registers to integrate the SmartGen HGM7100N Series?

Start with HR 0 Common Status Word (Common alarm and mode flags); HR 189 Generator Status (Genset running state); HR 193 Switch Status (Transfer switch state); HR 34 Mains / Gen Indications (Mains/gen normal and on-load flags); HR 84 Gen Frequency (Generator frequency); HR 95 A-Phase Current (Phase A current); HR 142 Battery Voltage (Battery voltage); CO 0 Remote Start Key (STARTS ENGINE) (Remote start key).

How do I enable Modbus control of the SmartGen HGM7100N Series?

Give each controller a unique slave address (the protocol allows 1-255) in the controller parameters before networking several units; the document does not state the default address.

Where is the official SmartGen HGM7100N Series Modbus documentation?

The source is HGM7100N Genset Controller Communication Protocol, revision 2025-06-21 (v1.3), published free by SmartGen at https://www.smartgen.cn/yun/data/download/HGM7100N_Protocol_en.pdf.
