Updated 25 October 2026

Short answer

ABB's industrial variable frequency drive family. The control unit's XD2D RS-485 terminal can be switched from the drive-to-drive link to Modbus RTU, which puts a 16-bit control word, two references, a status word and two actual values in the first six holding registers and exposes every drive parameter as a holding register derived from its group and index. This map covers that cyclic block, the EFB error registers, key group 01/04/05/06 monitoring signals, the EFB diagnostics and comm-loss settings, and the main 32-bit actual values.

This page lists 64 Modbus registers for the ABB ACS880 industrial drive, primary control program (embedded Modbus RTU) — 7 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ABB’s own free documentation (linked below) and checked against it.

Integration notes: ABB ACS880 industrial drive, primary control program (embedded Modbus RTU)

Integration in brief

Set 58.01 = Modbus RTU, set node, baud and parity, apply with 58.06 = Refresh settings, then point 20.01 Ext1 commands and the speed or frequency reference source at the embedded fieldbus. Write the ABB Drives control word and Reference 1 at 400001/400002, poll the status word and actual values at 400004-400006, and read other signals straight from their parameter registers.

Enable Modbus control & writes

Set 58.01 Protocol enable = Modbus RTU (this disables the drive-to-drive link on XD2D and cannot be changed while the drive runs), then 58.03 node address, 58.04 baud rate and 58.05 parity, and validate with 58.06 Communication control = Refresh settings or reboot the control unit. For control set 20.01 Ext1 commands (and 20.06 for EXT2) = Embedded fieldbus and the reference source, e.g. 22.11 Speed ref1 source or 28.11 Frequency ref1 source = EFB ref1. Fieldbus parameter writes are made permanent with 96.07 Parameter save manually = Save.

Communication loss & watchdog

58.14 Communication loss action (No / Fault / Last speed / Speed ref safe / Fault always / Warning) with 58.16 Communication loss time (default 3.0 s) and 58.15 Communication loss mode (any message, or only control word/reference writes, resets the timer). A loss trips 6681 EFB comm loss or warns A7CE; Speed ref safe runs at 22.41 (28.41 for frequency). Apart from Fault always, it only acts when the EFB is the active control source or 58.36 forces supervision. Monitoring is held off for 30 s after power-up.

Byte order & addressing

  • Addresses are 6-digit Modicon references: 400001 = wire 0. 32-bit parameter registers start at 420000 and cannot be reached with 5-digit (4xxxx) addressing.
  • 32-bit values in this map are listed CDAB, which assumes 58.34 Word order = LO-HI (the default: low word first). If 58.34 is set to HI-LO, read them as ABCD. Bytes within each register are always high byte first.
  • References and actual values are signed 16-bit scaled to the group 46 values, not engineering units; 58.26-58.29 pick the type (Ref2 and Act2 default to Torque).
  • Start per the ABB Drives state diagram: write 0x0476 (1142) to 400001; once status bit 0 (RDY_ON) is 1, write 0x0477 (1143) and then 0x047F (1151) to run. Clearing bit 0 (0x047E) gives an OFF1 ramp stop; a 0->1 edge on bit 7 resets a fault. Bit 10 (REMOTE_CMD) must be 1 for the fieldbus to have control.
  • Control word bit 3 (run) only works when the run enable signal is present, unless run enable is itself taken from the fieldbus.

Network setup

  • Wire the RS-485 bus to terminal XD2D on the control unit; termination and chaining are in the drive's hardware manual (terminate only the two bus ends).
  • Defaults: node 1, 19.2 kbit/s, 8 data bits, even parity, 1 stop bit (58.03-58.05); 4.8-115.2 kbit/s selectable.
  • Changes to group 58 take effect only after 58.06 = Refresh settings or a control-unit reboot.
  • 58.07 Communication diagnostics flags wiring (A/B swap), parity, baud and noise/addressing errors; 58.08-58.12 count packets, UART errors and CRC errors.

Watch out for

  • If a start command is ignored, read 06.18 Start inhibit status word (e.g. missing run or start enable, STO, or a changed control location).
  • The drive processes 10 registers per 10 ms, so a 20-register read takes about 22 ms before the reply starts.
  • Exception 04h means the drive rejected the value; read 400092 Error code for the reason. Exception 03h means too many registers were requested, not an out-of-range value.
  • Supported function codes are 01, 02, 03, 05, 06, 08, 0Bh, 0Fh, 10h, 16h, 17h and 2Bh/0Eh; there are no input registers (function 04 is not supported).

Notes on this map

  • Registers 400001-400006 are the factory defaults of 58.101-58.106 Data I/O 1-6 and can be re-pointed; 400007-400024 (Data I/O 7-24) are user-selected and not listed.
  • Control and status word bits are for 58.25 Control profile = ABB Drives (default). With Transparent the control word is passed unconverted (visible in 6.05) and the status word comes from the source chosen in 58.30.
  • References and actual values are signed 16-bit. For speed/frequency 20000 equals 46.01 Speed scaling or 46.02 Frequency scaling (torque 46.03, power 46.04), so their engineering value depends on drive settings and they are left unscaled here. 58.27 and 58.29 default to Torque, not Auto.
  • EFB status word bit 12 = EXT_RUN_ENABLE is confirmed three ways in the manual: the EFB status word table, the ABB Drives state diagram (SW bit 12 = 1 is the run-enable condition for OPERATION ENABLED) and 6.31 MSW bit 12 sel, whose default is Ext run enable. It is a user-selectable bit: the coil/discrete-input table calls status bits 11-14 User-defined (0)-(3), so a changed 6.31 changes its meaning. The bit 11 row of the status word table carries a stray '12 USER_1' fragment in its text; bit 11 is shown here only as a user-defined bit.
  • 16-bit scaling is the manual's FbEq 16b column (FbEq is defined as the integer used in communication, e.g. '10 = 1 V' -> scale 0.1). Signals whose 16-bit scaling is 'See par. 46.xx' (01.01 speed, 01.06 frequency, 01.07 current, 01.10 torque, 01.14 power, 01.72-01.74 phase currents) are listed only in 32-bit form, which has a fixed FbEq 32b scaling.
  • 01.14, 01.17, 01.30, 01.31 and 01.65 follow 96.16 Unit selection (kW or hp, Nm or lb·ft, °C or °F); the units shown assume metric.
  • Left out: 01.35-01.37 resettable energy balance, 05.22 Diagnostic word 3 (only two fan bits in use), the ACS800-compatible fault words 4.21/4.22 (bit meanings depend on 4.120), the supply-unit signals 01.102-01.164 (visible only with IGBT supply control), and all configuration parameters other than the EFB diagnostics and comm-loss settings.
  • Coils (control word bits at 00001-00032 plus 10.99 RO/DIO bits) and discrete inputs (status word bits at 10001-10032 plus 10.02 DI bits) also exist but are omitted, matching the ABB sibling maps; the manual does not spell out how those references map to wire addresses.
  • Comm-loss defaults agree between the EFB setup table and the parameter list: 58.14 = Fault, 58.15 = Cw / Ref1 / Ref2, 58.16 = 3.0 s. 58.16 is 1 = 1 s in 16-bit form and 10 = 1 s in 32-bit form.

Questions about the ABB ACS880 industrial drive, primary control program (embedded Modbus RTU)

What Modbus registers does the ABB ACS880 industrial drive, primary control program (embedded Modbus RTU) have?

This map lists 64 registers: 64 holding registers. 7 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB ACS880 industrial drive, primary control program (embedded Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual writes holding registers as 6-digit references 400001-465536 covering the full 16-bit address field, so 400001 = wire address 0. Masters limited to 5 digits can reach 400001-409999 as 40001-49999, but nothing from 410000 up (which includes every 32-bit parameter register). With 58.33 Addressing mode = Mode 0 (default) a 16-bit parameter gg.ii sits at 400000 + 100*gg + ii (e.g. 01.11 -> 400111, wire 110) and its 32-bit form at 420000 + 200*gg + 2*ii (e.g. 01.07 -> 420214, wire 20213). Mode 1 uses 400000 + 256*gg + ii and Mode 2 uses 400000 + 512*gg + 2*ii; this map assumes Mode 0. 32-bit registers are listed CDAB because 58.34 Word order defaults to LO-HI (low word in the first register).

What byte order does the ABB ACS880 industrial drive, primary control program (embedded Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.
