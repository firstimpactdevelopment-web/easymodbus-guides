Yokogawa UTAdvanced UP55A program controller Modbus register map

Updated 19 November 2026

Short answer

The UP55A is the UTAdvanced program (ramp/soak) controller with up to 30 patterns and two loops. Its D registers map one-to-one onto Modbus holding registers over RS-485 (Modbus RTU/ASCII) or Modbus/TCP on Ethernet models. This map covers process data, program status and events, the current PID group and the program operation commands.

This page lists 51 Modbus registers for the Yokogawa UTAdvanced UP55A program controller — 21 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Yokogawa’s own free documentation (linked below) and checked against it.

Integration notes: Yokogawa UTAdvanced UP55A program controller

Integration in brief

Select a pattern with D2322 and start it with D2316 = 1 (PROG); stop with 0 (RESET). Poll D2003-D2008 for PV, SP, output and mode, D2015-D2017 for pattern, segment and remaining time, and D2040/D2041 for time events.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the communication setup parameters (protocol MBRTU or MBASC, baud, parity, stop bits, data length, address) on the keypad. Ethernet models use Modbus/TCP on port 502 by default.

Byte order & addressing

  • Address D register n at wire address n-1.
  • Write values without the decimal point (50.0 with one decimal place = 500).

Network setup

  • Factory defaults: Modbus RTU, 19200 bps, even parity, 1 stop bit, 8 data bits, address 1.

Watch out for

  • HOLD (D2317) and ADV (D2318) are program-operation items: write them while a program is running.

Notes on this map

  • All registers are 16-bit. Values are sent without their decimal point: PV/SP-type values follow the input's decimal point setting, percentages carry one decimal (scale 0.1).
  • Only registers whose UP55A column shows R or R/W are listed. D2001-D2100 are read-only.
  • D2045-D2047 (pattern repeat counters) are left out because the source gives two of them the same description.
  • Program pattern data (D8001-D9000), the GREEN-series compatible area (D0001-D2000) and setup parameters (D2501 onward) are not included.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Yokogawa UTAdvanced UP55A program controller

What Modbus registers does the Yokogawa UTAdvanced UP55A program controller have?

This map lists 51 registers: 51 holding registers. 21 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yokogawa UTAdvanced UP55A program controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists D register numbers (D2003). The Modbus reference number replaces the D with 4 (42003) and the wire address is that minus 40001, printed in the table's H No. column (D2003 = 07D2H).

What are the minimum Modbus registers to integrate the Yokogawa UTAdvanced UP55A program controller?

Start with HR 2002 PV_L1 loop-1 measured value (Loop-1 PV (D2003)); HR 2003 CSP_L1 loop-1 control setpoint (Loop-1 SP (D2004)); HR 2007 MOD_L1 loop-1 operation mode status (UP55A) (Operation mode status (D2008)); HR 2015 SEG.N current segment number (Current segment (D2016)); HR 2010 ALM_L1 loop-1 alarm 1-8 status (Alarm status (D2011)); HR 2315 MODE program operation mode (Program MODE (D2316)); HR 2321 PTNO. program pattern number selection (Pattern number (D2322)).

How do I enable Modbus control of the Yokogawa UTAdvanced UP55A program controller?

Set the communication setup parameters (protocol MBRTU or MBASC, baud, parity, stop bits, data length, address) on the keypad. Ethernet models use Modbus/TCP on port 502 by default.

Where is the official Yokogawa UTAdvanced UP55A program controller Modbus documentation?

The source is UTAdvanced Series Communication Interface (RS-485, Ethernet) User's Manual (IM 05P07A01-01EN 13th Edition), revision 2026-03, published free by Yokogawa at https://web-material3.yokogawa.com/IM05P07A01-01EN.pdf.
