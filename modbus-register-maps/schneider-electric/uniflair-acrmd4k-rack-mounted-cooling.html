Short answer

The Uniflair ACRMD4K is a rack-mounted split DX cooling unit (indoor unit plus outdoor unit). Its controller is a Modbus RTU / TCP slave. This map covers the unit on/off coil, alarm and output status bits (including outdoor-unit compressor and inverter faults), return and outlet air temperatures, return humidity, pressures, compressor frequency, coil temperatures, operating mode and the writable temperature, humidity, alarm and fan-speed settings.

This page lists 86 Modbus registers for the Schneider Electric Uniflair Rack Mounted Room Cooling ACRMD4K — 14 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Schneider Electric’s own free documentation (linked below) and checked against it.

Integration notes: Schneider Electric Uniflair Rack Mounted Room Cooling ACRMD4K

Integration in brief

Write coil 00001 (wire 0) to switch the unit on or off and holding 40121 / 40122 for the return / outlet air setpoints in tenths of °C. Poll input registers 30002-30003 for air temperatures, 30176 for operating mode and input status 10002-10003 for the serious / common alarm outputs.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Not described in the register map. The unit's Modbus address and baud rate are themselves writable at holding 40216 / 40217.

Byte order & addressing

  • Use the decimal absolute register as the wire address (Modicon number minus the 0/1/3/4 prefix and minus 1).
  • Two separate settings share holding 40183 as bits 10 and 11.

Network setup

  • Baud rate choices per holding 40217: 2400, 4800, 9600 or 19200. Parity, stop bits and the default address are not stated in the map.

Watch out for

  • The humidity and pressure input registers are printed with a temperature unit in the map; check them against the unit display.

Notes on this map

  • Per the map's notes, 16-bit values are big-endian and signed values are two's complement; all points here are single registers or bits.
  • Scale: the map's 'Units' column holds the resolution (e.g. 0.1 °C, 0.1 %) and the row text says values are 'magnified 10 times' (219 = 21.9). The map's 'Scale' column actually holds the raw setting range; ranges are given in the descriptions.
  • Air return humidity (30014) and the discharge/suction pressures (30037, 30038) are printed with the unit '0.1 °C', which looks copied from the temperature rows. We keep the 0.1 scale but leave the unit blank because the map does not give the real unit.
  • Holding register 40183 (wire 182) carries two settings as bits: bit 10 = PTC heater function, bit 11 = condensation pump function (0 = yes, 1 = no).
  • Reads use function code 3 or 4; writes use function code 16, or 6 for single registers. The general notes name only these function codes, but the tables also list one coil and input-status points.
  • The map prints no revision or date; 2022-02 is the PDF's own creation date (2022-02-10).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Schneider Electric Uniflair Rack Mounted Room Cooling ACRMD4K

What Modbus registers does the Schneider Electric Uniflair Rack Mounted Room Cooling ACRMD4K have?

This map lists 86 registers: 1 coil, 57 discrete inputs, 15 input registers, 13 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Schneider Electric Uniflair Rack Mounted Room Cooling ACRMD4K Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row shows a Modicon number (00001 / 10002 / 30002 / 40101 style), a hex and a decimal absolute register. The notes say absolute register 0 is Modicon 40001 and address zero on the wire, so the decimal column is the wire address; e.g. holding 40121 is wire 120 and input status 10002 is wire 1.

What are the minimum Modbus registers to integrate the Schneider Electric Uniflair Rack Mounted Room Cooling ACRMD4K?

Start with CO 0 ON/OFF UNIT (Unit on/off); IR 1 Air return temperature (Air return temperature); IR 2 Air outlet temperature (Air outlet temperature); IR 175 Operation mode (Operation mode); DI 1 Serious alarm output (Serious alarm output); DI 2 Common alarm output (Common alarm output); HR 120 Air return temperature setting (Air return temperature setpoint); HR 121 Air outlet temperature setting (Air outlet temperature setpoint).

How do I enable Modbus control of the Schneider Electric Uniflair Rack Mounted Room Cooling ACRMD4K?

Not described in the register map. The unit's Modbus address and baud rate are themselves writable at holding 40216 / 40217.
