Short answer

The TriStar TS-45/TS-60 is a PWM controller that runs as a solar charger, a load controller or a diversion regulator. Its RS-232 port speaks Modbus RTU: RAM registers carry battery, array/load voltage and currents, temperatures, Ah counters, control mode/state, alarm and fault bitfields and PWM duty; EEPROM registers hold setpoints, and coils trigger equalize, disconnect, resets and counter clears.

Integration notes: Morningstar TriStar TS-45 / TS-60 PWM charge, load and diversion controller (Modbus RTU)

Integration in brief

Connect to the RS-232 port at 9600 8N2, ID 1, and read 0x0008-0x001D in one request. Convert voltages with 96.667/32768 (battery) or 139.15/32768 (array/load). Check control mode 0x001A before interpreting control state 0x001B.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is available on the RS-232 port at the factory settings (address 1); no enable step is described.

Byte order & addressing

  • Each analog channel has its own scaling constant; check which applies before converting.
  • EEPROM values that need updating are written once every 24 hours; use coil 0x0016 to force it.
  • Clearing faults does not clear those that need a power cycle (e.g. DIP switch change).

Network setup

  • Serial: 9600 baud, 8 data bits, no parity, 2 stop bits, no flow control, RS-232 only.

Watch out for

  • The spec describes Modbus on the RS-232 port only; an RS-485 network needs a converter.

Notes on this map

  • Scaling: formulas n x 96.667 x 2^-15 (battery voltages), n x 139.15 x 2^-15 (array/load voltage), n x 66.667 x 2^-15 (charging current) and n x 316.67 x 2^-15 (load current) are converted to single multipliers. Example from the spec: 0x1007 = 4103 x 96.667 / 32768 = 12.1 V.
  • Word order: the RAM table names each pair HI word first (Ah_r_HI 0x0011, Ah_r_LO 0x0012), so these are ABCD. The EEPROM Ah copies are printed LO first (EAh_r_LO 0xE028), so they are CDAB.
  • The alarm bitfield is split: bits 0-15 at 0x0017 and bits 16-23 at 0x001D, so it is listed as two 16-bit registers.
  • Control state codes mean different things in charge/diversion and in load/lighting mode; both meanings are given in the values.
  • Left out: EEPROM kWh 0xE02C (no scaling or unit printed), lighting-mode and diversion EEPROM settings, calibration values and the 0x8000-0x85DF data logger. Registers 0x0000-0x0007 are internal use.
  • Both FC 0x03 and FC 0x04 are supported for reading; EEPROM is written with Write Single Register (0x06).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Morningstar TriStar TS-45 / TS-60 PWM charge, load and diversion controller (Modbus RTU)

What Modbus registers does the Morningstar TriStar TS-45 / TS-60 PWM charge, load and diversion controller (Modbus RTU) have?

This map lists 45 registers: 11 coils, 34 holding registers. 22 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Morningstar TriStar TS-45 / TS-60 PWM charge, load and diversion controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Morningstar lists a hex PDU address (used on the wire unchanged) and a logical address one higher. The spec says all listed addresses are request-PDU addresses; its scaling example reads battery voltage at PDU 0x0008.

What byte order does the Morningstar TriStar TS-45 / TS-60 PWM charge, load and diversion controller (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)) and CDAB (low word first (word-swapped)). Each register's order is in the Order column.

What are the minimum Modbus registers to integrate the Morningstar TriStar TS-45 / TS-60 PWM charge, load and diversion controller (Modbus RTU)?

Start with HR 8 adc_vb_f - battery voltage (Battery voltage); HR 10 adc_vx_f - array / load voltage (Array or load voltage); HR 11 adc_ipv_f - charging current (Charging current); HR 26 Control mode (Control mode); HR 27 Control state (Control state); HR 24 Fault bitfield (Fault bitfield); CO 1 Disconnect (Remote disconnect).

How do I enable Modbus control of the Morningstar TriStar TS-45 / TS-60 PWM charge, load and diversion controller (Modbus RTU)?

Modbus is available on the RS-232 port at the factory settings (address 1); no enable step is described.
