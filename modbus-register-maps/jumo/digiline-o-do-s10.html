Integration notes: JUMO digiLine O-DO S10 optical oxygen sensor (Modbus RTU)

Integration in brief

Read 9728-9729 (oxygen) and 9760-9761 (temperature) as floats in the format set by register 775, plus the status word at 9792.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is available directly on the sensor RS-485 line; set address and format with JUMO DSM software or registers 768-775.

Byte order & addressing

  • Float byte order follows register 775; standard Modbus format is low word first (CDAB).
  • Function 03 and 04 both read; writes use 06/16.

Network setup

  • Baud 9600/19200/38400 and data format are set in registers 769-770.

Watch out for

  • Treat values near 1E37-9E37 as error codes, not readings.
  • The sensor origin text (638) is managed by digiLine masters and must not be written.

Notes on this map

  • Copy hosted by the Australian distributor Onetemp; JUMO does not offer a public direct link to this document. The file is the unaltered JUMO interface description.
  • Float order is selectable in register 775. In "Standard Modbus format" (0) the low word comes first (CDAB): the guide says bytes 1-2 and 3-4 are swapped and its temperature example returns 00 00 41 A2 = 20.25 °C. The guide does not state which setting is the factory default, so read 775 first.
  • Invalid float readings are replaced by error codes: 1.0E37 underrange, 2.0E37 overrange, 3.0E37 invalid input, 4.0E37 division by zero, 5.0E37 math error, 6.0E37 invalid compensation temperature, 7.0E37 probe short circuit, 8.0E37 probe break, 9.0E37 timeout.
  • Write cyclic compensation values only to the RAM registers (9648-9653); the flash values (9600-9603) must not be written cyclically.
  • Left out: operating hours and other Uint32 counters (no stated word order), date/time and text fields, the analog output warning/error enable flags (char booleans) and the out-of-range temperature output value.
  • Default serial settings are not stated in the document.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the JUMO digiLine O-DO S10 optical oxygen sensor (Modbus RTU)

What Modbus registers does the JUMO digiLine O-DO S10 optical oxygen sensor (Modbus RTU) have?

This map lists 29 registers: 29 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the JUMO digiLine O-DO S10 optical oxygen sensor (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables give the Modbus PDU address in decimal and hex; it is sent unchanged (the example reads temperature at 0x2620).

What byte order does the JUMO digiLine O-DO S10 optical oxygen sensor (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the JUMO digiLine O-DO S10 optical oxygen sensor (Modbus RTU)?

Start with HR 9728 Measured oxygen value (Oxygen value); HR 9760 Measured temperature (Temperature); HR 9792 Status word (Status / warnings); HR 775 Float value format (Float format in use); HR 9520 Oxygen measurement unit (Oxygen unit).

How do I enable Modbus control of the JUMO digiLine O-DO S10 optical oxygen sensor (Modbus RTU)?

Modbus RTU is available directly on the sensor RS-485 line; set address and format with JUMO DSM software or registers 768-775.
