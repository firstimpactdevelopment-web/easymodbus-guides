Integration notes: Trane CenTraVac simplex centrifugal chiller (Symbio 800)

Integration in brief

Read the analog inputs as pairs of input registers (float, high word first) and the binary/multi-state points as single registers. Write the BAS setpoints and command points in the 4xxxx holding range.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

On the Symbio 800 web interface go to Installation > Identification and Communications > Protocol Configuration and select Modbus RTU or Modbus TCP (per Trane's Symbio 800 integration guides).

Byte order & addressing

  • Analog values are 32-bit floats in two consecutive registers, high word first.
  • 0xFFFF in a binary or multi-state register and NaN in an analog register mean the value is invalid or not present.

Network setup

  • The Modbus RTU address comes from the controller's rotary dials (1-247); address 000 disables Modbus RTU.
  • Serial defaults are 19200 bps, even parity, 1 stop bit (set in the web interface's Protocol Configuration tab); wire RS-485 to the P1 link.
  • Modbus TCP uses Ethernet port 1 (port 2 is reserved for the touch screen) and the IP address set on the IP Configuration tab; the rotary address is ignored for TCP and the Wi-Fi module is not supported for Modbus TCP.

Watch out for

  • Points not supported by the unit's configuration are absent; confirm the configuration dependencies before mapping.

Notes on this map

  • Register format table: analog points are 32-bit floats sent high word / high byte first (NaN = invalid); binary and multi-state points are unsigned 16-bit integers (0xFFFF = invalid).
  • Values are sent in the unit system ordered from the factory (I-P is the usual default, SI optional); the list names only the quantity, so temperature/pressure/flow units are left blank here.
  • Not every point exists on every unit: the controller builds its point set from the unit's configuration. Descriptions name the configuration a point depends on.
  • Register numbers are printed in 5-digit Modicon form (3xxxx input registers, 4xxxx holding registers) and converted here to wire addresses (30011 = input register 10).
  • Controller setup, serial defaults and the I-P/SI units statement come from the list's named reference document, Trane's Symbio 800 BACnet and Modbus integration guide BAS-SVP083B-EN (15 Nov 2024, https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Integration/BAS-SVP083B-EN_11152024.pdf).
  • The document carries separate Simplex and Duplex tables that reuse the same register numbers for different points; do not mix them.
  • The 'Diagnostic Codes' pages (code number to text for the Last Diagnostic Code points) are not reproduced.
  • Binary input 33018 is printed with the name 'Evaporator Leaving Water Temperature' and the states 'Not Limited / Limited'; copied as printed (it reports a capacity limit, not a temperature).
  • Diagnostic input 34008 is also printed with the name 'Evaporator Leaving Water Temperature' (an alarm flag, 0 = Normal / 1 = In Alarm, TR200 AFD option); copied as printed.
  • Duplex (two-compressor) CenTraVacs on Symbio 800 use the Duplex tables of the same list (see centravac-duplex-symbio-800); UC800 duplex units use a different map (centravac-duplex-uc800).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Trane CenTraVac simplex centrifugal chiller (Symbio 800)

What Modbus registers does the Trane CenTraVac simplex centrifugal chiller (Symbio 800) have?

This map lists 546 registers: 531 input registers, 15 holding registers. 15 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Trane CenTraVac simplex centrifugal chiller (Symbio 800) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The list prints Modicon register numbers: 3xxxx are input registers and 4xxxx holding registers, so 30011 is input register address 10 and 42011 is holding register address 2010.

What byte order does the Trane CenTraVac simplex centrifugal chiller (Symbio 800) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

How do I enable Modbus control of the Trane CenTraVac simplex centrifugal chiller (Symbio 800)?

On the Symbio 800 web interface go to Installation > Identification and Communications > Protocol Configuration and select Modbus RTU or Modbus TCP (per Trane's Symbio 800 integration guides).

Where is the official Trane CenTraVac simplex centrifugal chiller (Symbio 800) Modbus documentation?

The source is Symbio 800 Integration Points List, BACnet/Modbus, CenTraVac (BAS-PTS009C-EN), revision 2025-12-12, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Points%20List/BAS-PTS009C-EN_12122025.pdf.
