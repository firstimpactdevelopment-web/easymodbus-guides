Invertek Drives Optidrive Elevator Core (built-in Modbus RTU) Modbus register map

Updated 19 November 2026

Short answer

The Elevator Core is Invertek's drive for lift (elevator) motors, geared or gearless, open or closed loop. Modbus RTU is built in on the RJ45 port. Register 1 runs the drive forward or reverse and resets faults, register 2 sets the speed in the drive's active unit, and registers 5-48 report status, speed, current, torque, power, faults and run time. Parameters sit at their group-and-number register, and group 0 monitor values at 10000 + number.

This page lists 46 Modbus registers for the Invertek Drives Optidrive Elevator Core (built-in Modbus RTU) — 9 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Invertek Drives’s own free documentation (linked below) and checked against it.

Integration notes: Invertek Drives Optidrive Elevator Core (built-in Modbus RTU)

Integration in brief

Set P1-01 = 1, close both STO inputs, write the speed to register 2 and then write register 1 = 1 (up/forward) or 2 (reverse). Poll register 6 for status, 7-10 for speed, current, torque and power, and 18 for the fault code.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set P1-01 = 1 (Modbus RTU). Set the address in P2-01, baud in P2-02 and data format in P2-03. STO1 and STO2 must both be closed (24 V present); no digital input is needed to run.

Communication loss & watchdog

P2-04 sets the Modbus loss timeout (0.0-5.0 s, default 1.0 s) and P2-05 the reaction: 0 trip (default), 1 ramp to stop then trip, 2 ramp to stop only, 3 run at inspection speed P8-08.

Byte order & addressing

  • Register numbers are 1-based; subtract 1 for the wire address.
  • Setting both run bits (value 3) stops the drive or keeps it from starting.
  • Group 0 monitor parameters are read at 10000 + number, and their sub-indexes at 11000 + number x 10 + index.

Network setup

  • RS-485 on the RJ45 port; always connect the 0 V pin.
  • Factory settings: address 1, 115200 bps, no parity, 1 stop bit. Up to 247 drives per network.
  • A 120 ohm terminating resistor at the end of the line helps with dropped telegrams.

Watch out for

  • The drive rejects a speed reference outside the range of P8-01, and ramps still follow the group 8 and 9 S-ramp parameters under Modbus control.
  • Leaving out the 0 V connection can damage the port.

Notes on this map

  • Source is Invertek's official online user guide (HTML), spread over the topics named in the source pages field.
  • Fault reset: the bit tables put reset on control-word bit 2, while one troubleshooting line says bit 3; this map follows the bit tables (bit 2, also shown in P2-50). The reset only acts on a 0 to 1 change.
  • A troubleshooting line says the fault code is in the upper byte of register 6, but the status-word topic defines all 16 bits of register 6 and puts the fault code in P2-56 (register 256) and register 18. This map follows the status-word topic.
  • P2-56 low-byte status bits are left as a plain value: the register-details topic and the group 2 topic give different bit layouts.
  • Speed registers (2, 5, 7, 22) use the drive's active unit, set by P4-06 and P3-08: Hz (0.1), rpm (1), ft/s (0.01) or m/s (0.01). They are kept raw. Signedness is not printed; speeds are typed INT16 because the drive runs in both directions.
  • Registers 3, 4, 12, 32, 33 and 40-47 are reserved. The CANopen interface and the full parameter list are not covered here.
  • Supported functions: 03, 06 and 16.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Invertek Drives Optidrive Elevator Core (built-in Modbus RTU)

What Modbus registers does the Invertek Drives Optidrive Elevator Core (built-in Modbus RTU) have?

This map lists 46 registers: 46 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Invertek Drives Optidrive Elevator Core (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are numbered from 1. The guide's worked telegrams settle it: the control-word write is broken down as physical address 0x0000 = logical register 1, and the status-word read uses physical 0x0005 for register 6. Parameters use group and number (P1-01 = register 101 = wire address 100); group 0 is read at 10000 + parameter number.

What are the minimum Modbus registers to integrate the Invertek Drives Optidrive Elevator Core (built-in Modbus RTU)?

Start with HR 0 Command control word (Control word: run forward/reverse, reset); HR 1 Commanded speed reference (Speed reference); HR 5 Status word (Status word); HR 6 Output speed (Output speed); HR 7 Output current (Output current, 0.1 A); HR 17 Active fault code (Active fault code); HR 100 P1-01 Primary command source (P1-01 command source).

How do I enable Modbus control of the Invertek Drives Optidrive Elevator Core (built-in Modbus RTU)?

Set P1-01 = 1 (Modbus RTU). Set the address in P2-01, baud in P2-02 and data format in P2-03. STO1 and STO2 must both be closed (24 V present); no digital input is needed to run.

What happens when the Invertek Drives Optidrive Elevator Core (built-in Modbus RTU) loses Modbus communication?

P2-04 sets the Modbus loss timeout (0.0-5.0 s, default 1.0 s) and P2-05 the reaction: 0 trip (default), 1 ramp to stop then trip, 2 ramp to stop only, 3 run at inspection speed P8-08.
