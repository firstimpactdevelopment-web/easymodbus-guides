Short answer

The MAG 6000 electromagnetic flow transmitter gets a Modbus RTU slave by fitting the USM II RS-485 add-on module. Data is held in holding registers and coils only. This map covers volume flow and totalizers (float and double), driver and identity registers, basic, totalizer, output, input, sensor and display settings, system status and the totalizer/batch/zero-adjust coils.

This page lists 119 Modbus registers for the Siemens SITRANS F M MAG 6000 with USM II Modbus RTU module — 72 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Siemens’s own free documentation (linked below) and checked against it.

Integration notes: Siemens SITRANS F M MAG 6000 with USM II Modbus RTU module

Integration in brief

Read holding registers (FC 03) from address 3002 for volume flow and 3014/3018 for the double totalizers; values are big-endian IEEE, high word first. Use coils 9-12 to reset or hold the totalizers.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the USM II Modbus RTU add-on module in the transmitter. The module adds a 'MODBUS RTU module' menu (between Reset mode and Service mode) for address, baud, parity/framing, timeouts and TAG; the same settings are writable at addresses 528-530.

Byte order & addressing

  • Use the address column (0-based); 4:03003 is address 3002.
  • Max 26 registers per read and 25 per write.
  • No input registers or discrete inputs: everything is holding registers and coils.

Network setup

  • Factory settings: address 1, 19200 baud, even parity, 1 stop bit; response delay 0, interframe space 3.5 characters.
  • Baud 1200-115200; framing 8E1, 8O1, 8N2 or 8N1.
  • RS-485 2-wire on screw terminals; up to 31 devices per segment without repeaters.
  • Modbus settings live in the module; after swapping the module they must be written again from the master.

Watch out for

  • The module does not react to broadcasts that need an answer; broadcast writes get no reply.
  • If the reply is not ready within the response timeout the module returns exception 6 (busy); repeat the request.

Notes on this map

  • Word order: the manual states the module is big-endian, most significant byte first, and its float table and example frame (4:03001 read as 40 C3 52 93 = 6.10383 kg/s) put the high word in register N. Floats, doubles and double words are therefore listed as ABCD.
  • 'Byte' values sit in the low byte of one register and are listed as UINT16 (0-255).
  • Units of the process values and totalizers follow the unit registers (2904-2917, ID tables in Appendix B.1/B.2). The 'point' registers set the number of decimals (0-6) shown on the display.
  • Adding 10000 to the address of a writable register returns its minimum allowed value, adding 20000 returns its maximum (these mirror registers are not listed).
  • Values printed as (1/100%) are fractions where 1.0 = 100 % (the manual's example: 0.02 = 2 %).
  • Left out: capability bits (603, 3-byte array) and the 54-byte error pending / error log lists (2702, 2729); their record layout is in Appendix B.4.
  • Error numbers are listed in the SITRANS F M / F C transmitter operating instructions, not in this manual.
  • MAG 6000 has no mass, density or temperature values; 3000 and 3004-3012 are MASS 6000 only.
  • Volume flow (3002) and totalizers are in the customer units set at 2906, 2912 and 2914 (defaults m3/s and m3); Q max and other settings are always in m3/s / m3.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Siemens SITRANS F M MAG 6000 with USM II Modbus RTU module

What Modbus registers does the Siemens SITRANS F M MAG 6000 with USM II Modbus RTU module have?

This map lists 119 registers: 8 coils, 111 holding registers. 72 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Siemens SITRANS F M MAG 6000 with USM II Modbus RTU module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every row prints both the Modbus register (4:0xxxx / 0:0xxxx, 1-based) and the Modbus address (0-based) sent on the wire; this map uses the address column. The manual's own example reads absolute massflow 4:03001 with query address 0x0BB8 (3000).

What byte order does the Siemens SITRANS F M MAG 6000 with USM II Modbus RTU module use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Siemens SITRANS F M MAG 6000 with USM II Modbus RTU module?

Start with HR 3002 Absolute Volumeflow (Volume flow); HR 3014 Totalizer 1 (Totalizer 1 (double)); HR 3018 Totalizer 2/Batch (Totalizer 2 / batch (double)); HR 3200 System status (System status bits); HR 3201 Error pending 1 (First pending error); HR 2906 Volumeflow unit (Volume flow unit ID).

How do I enable Modbus control of the Siemens SITRANS F M MAG 6000 with USM II Modbus RTU module?

Fit the USM II Modbus RTU add-on module in the transmitter. The module adds a 'MODBUS RTU module' menu (between Reset mode and Service mode) for address, baud, parity/framing, timeouts and TAG; the same settings are writable at addresses 528-530.

Where is the official Siemens SITRANS F M MAG 6000 with USM II Modbus RTU module Modbus documentation?

The source is SITRANS F Modbus RTU RS 485 (USM II) communication module, Operating Instructions (A5E00753974-AB), revision 2021-03, published free by Siemens at https://cache.industry.siemens.com/dl/files/906/44880906/att_70364/v1/A5E00753974-ABen_USMII_MODBUS_AOM_OI_en-US.pdf.
