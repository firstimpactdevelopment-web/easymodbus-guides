Short answer

The M7000CBNCU03 is BTicino's automatic transfer (changeover) controller for two supply lines. With the RS485 expansion module, or the front optical USB/WiFi interface, it speaks Modbus RTU or ASCII. This map covers both lines' voltages and frequencies, battery voltage, run-time and switching counters, the alarm word, keypad, input, line, breaker and output-function status words and the global status double word.

Integration notes: BTicino M7000CBNCU03 automatic transfer switch controller (Modbus)

Integration in brief

Read input registers (function 04) at table address minus 1: 0x0001 for line 1 L1-N voltage, 0x003F for the alarm double word and 0x220F for the global status flags.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the M7000CBNRS485 module, then in the Settings menu open M08 Communication for COM1 or COM2 and set node address, baud, data format, stop bits and protocol. The front IR-USB/IR-WiFi interfaces need no setup.

Byte order & addressing

  • Table addresses minus 1 on the wire.
  • Voltages are whole volts; frequency and battery voltage in tenths.

Network setup

  • Address 1-247 (248-255 internal).
  • Baud 1200-115200; 7-bit formats only for Modbus ASCII.

Watch out for

  • Writes with function 06 are accepted only above 1000 hex.
  • Up to 80 registers per request.

Notes on this map

  • The source is in Italian; names here are our English translations.
  • Word order: the manual's example answers 00 00 00 07 for 7 alarms, so 2-word values are high word first (ABCD).
  • Measurements are read with function 04 (input registers) or 03; the manual also lists 06, 07, 16 and 17. Function 06 works only on addresses above 1000 hex.
  • Defaults of the COM parameters (P08.n.01-05) as printed: node address 05, 19200 baud, 8 bits even parity, 1 stop bit, Modbus RTU.
  • Left out: line 2 voltage/breaker status, printed at 2176/2177 hex while the line 1 rows are 2074/2075 (probably 2076/2077, but not certain); the input-functions status at 2078 (listed as 2 words of 'unsigned integer'); display-message and LED status words; the generic counters CNT1-4 and limits LIM1-4; and all command registers (2F00-2FF0, 4F00), whose wiring into this map would need the full parameter manual.
  • Left out: the digital-outputs status word. The status table puts it at 2140 hex, but the bit table below it reads the outputs at 2072 hex, so the address is uncertain.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the BTicino M7000CBNCU03 automatic transfer switch controller (Modbus)

What Modbus registers does the BTicino M7000CBNCU03 automatic transfer switch controller (Modbus) have?

This map lists 43 registers: 43 input registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the BTicino M7000CBNCU03 automatic transfer switch controller (Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Table addresses are hex and one higher than the wire address. The manual says the request address is the table address minus 1, and its example reads breaker-1 switching alarms (table 3A hex) with the frame 01 04 00 39 00 02.

What byte order does the BTicino M7000CBNCU03 automatic transfer switch controller (Modbus) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the BTicino M7000CBNCU03 automatic transfer switch controller (Modbus)?

Start with IR 1 Line 1 voltage L1-N (Line 1 voltage L1-N); IR 13 Line 2 voltage L1-N (Line 2 voltage L1-N); IR 25 Line 1 frequency (Line 1 frequency); IR 63 Alarms (Alarm flags); IR 8719 Global device status (Global status (mode, which line feeds the load)); IR 8315 Controller general status (Controller mode and error).

How do I enable Modbus control of the BTicino M7000CBNCU03 automatic transfer switch controller (Modbus)?

Fit the M7000CBNRS485 module, then in the Settings menu open M08 Communication for COM1 or COM2 and set node address, baud, data format, stop bits and protocol. The front IR-USB/IR-WiFi interfaces need no setup.
