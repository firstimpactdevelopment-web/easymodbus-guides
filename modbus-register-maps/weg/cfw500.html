WEG CFW500 frequency inverter (Modbus RTU) Modbus register map

Short answer

WEG's general-purpose variable frequency drive. Over Modbus RTU every drive parameter is a 16-bit holding register whose address equals the parameter number, so P0680 status word is register 680 and P0682/P0683 control word and speed reference are 682/683. This map covers the read-only monitoring parameters, the status/control words, the command-source and serial-port setup parameters, and the network-driven digital/analog outputs.

Integration notes: WEG CFW500 frequency inverter (Modbus RTU)

Integration in brief

Leave P0312 = 2 (Modbus RTU on the standard RS-485), match P0308/P0310/P0311 to the master, then point the remote command sources at Serial/USB (P0220, P0222 = 9, P0226, P0227 = 2). Write the P0682 control word (e.g. 0x0017 = run + general enable + forward + remote; 0x0016 = ramp stop) and P0683 in the 8192 = rated-frequency scale, and poll P0680, P0005, P0003 and P0049.

Enable Modbus control & writes

P0312 selects the serial protocol (2 = Modbus RTU slave on serial 1, 7 = on the second port of a CRS485/CUSB/CRS232 module). Set P0308 address, P0310 baud and P0311 byte format. For network control set P0220 = 1 (always Remote) or 6 (Local/Remote switched by P0682 bit 4), P0222 = 9 (reference from P0683), P0226 = 5 or 6 (direction from P0682 bit 2) and P0227 = 2 (run/stop from P0682). Use P0221/P0223/P0224 instead if the drive runs in Local.

Communication loss & watchdog

P0314 Serial Watchdog (0.0-999.0 s, 0 = off by default) raises alarm A0128 when no valid telegram arrives in time; P0313 picks the reaction (0 none, 1 ramp stop default, 2 coast/general disable, 3 go to Local, 4 Local keeping the network commands, 5 fault F0228). Timing starts at the first valid telegram after power-up. P0316 shows 2 while the watchdog error is active.

Byte order & addressing

  • Register address = parameter number, no offset: P0680 is address 680 (40681 in 4x-style masters).
  • Everything is a 16-bit integer with the decimal point dropped; check the programming manual for each parameter's decimals.
  • P0683 speed reference is not in Hz: 8192 = motor rated frequency (P0403). For 30 Hz on a 60 Hz motor write 4096.
  • Negative P0683 reverses the reference, and P0682 bit 2 also flips direction; both together cancel out.
  • P0682 and P0683 show as read-only on the keypad but are writable over the network.
  • Supported functions: 01, 02, 03, 04, 05, 06, 15, 16 and 43 (device identification).

Network setup

  • RS-485 on the plug-in module terminals: the standard CFW500-IOS module carries A(-), B(+) and GND; check the terminal label of the fitted module (the Modbus guide and programming manual print different terminal numbers).
  • Baud 9600, 19200 (default) or 38400; byte format 8N1, 8E1 (default), 8O1, 8N2, 8E2 or 8O2.
  • Fit 120 ohm termination only at the two ends of the trunk; up to 32 devices per segment, 1000 m max.
  • P0027 shows which plug-in module the drive detected.
  • Most command-source parameters (P0220-P0228, P0312) are 'cfg' and can only be changed with the motor stopped.

Watch out for

  • If a password is set in P0200, parameter writes are refused until the password is written to P0000; access resets at power-down.
  • P0220 factory setting is 2 (HMI key, starting in Local), so network run commands are ignored until Remote is selected.
  • Factory P0227 = 1 (digital inputs): network run/stop is ignored until it is set to 2.
  • When the drive uses the RS-485 port for a remote keypad (P0312 = 0), Modbus is off on that port; use a two-port module and P0312 = 6 for keypad plus Modbus.
  • With P0229 = 1 (coast stop), P0682 bit 0 behaves like bit 1 and the motor coasts.

Notes on this map

  • Scaling and the P0001-P0070 monitoring parameters come from the WEG CFW500 Programming Manual V2.2X, doc 10002296099 rev 07 (09/2024), https://static.weg.net/medias/downloadcenter/h69/h0f/WEG-CFW500-programming-manual-10002296099-en.pdf. Newer firmware (V3.x/V4.x) manuals were not available in English from WEG's server, so check P0023 on site; parameter numbers for these core points are the same in the R04 Modbus guide.
  • P0001 and P0002 are left unscaled: they use the user scale from P0208 (full-scale value), P0209 (unit) and P0210 (decimal point). With the factory defaults the scale is Hz with one decimal.
  • P0681 and P0683 use WEG's 13-bit scale: 8192 equals the motor rated frequency P0403, so Hz = value x P0403 / 8192, saturating at +/-32767 (4x rated).
  • Left out: P0040/P0041 PID process variable and setpoint (decimal places depend on P0529), fault-history currents/voltages for the second and third faults (P0061-P0074, same format as P0051-P0055), and P0684/P0685 (fieldbus-card control word and reference, not used over the serial port).
  • The R04 Modbus guide shows P0680 bit 0 as STO and bit 2 as Fire Mode, and P0682 bits 13/14 as internal/external PID manual select; the V2.2X programming manual marks those bits reserved. Older firmware will leave them at 0.
  • The Modbus guide lists P0308 as 0-255; the programming manual lists 1-247. Use 1-247.
  • Fault and alarm numbers are the F/A codes without the letter (P0049 = 228 means F0228 serial timeout).
  • P0312 options 1, 3, 8, 9, 14 and 15 (SymbiNet and BACnet) come from the R04 Modbus guide; the V2.2X programming manual lists them as Reserved, so they need newer firmware.

Questions about the WEG CFW500 frequency inverter (Modbus RTU)

What Modbus registers does the WEG CFW500 frequency inverter (Modbus RTU) have?

This map lists 62 registers: 62 holding registers. 30 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the WEG CFW500 frequency inverter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The Modbus guide says parameters are mapped with offset zero: the parameter number is the holding register address (P0100 = address 100 = 0064h), and it lists P0680 at holding register address 680. So P0680 is requested as address 680; a master that numbers holding registers from 40001 needs 40681. Values travel as plain integers with no decimal point; the guide says the number of decimal places comes from the programming manual, so scale here follows the decimals in each parameter's range there (e.g. P0003 0.0-200.0 A -> 0.1 A).

What are the minimum Modbus registers to integrate the WEG CFW500 frequency inverter (Modbus RTU)?

Start with HR 682 Serial/USB control word (Control word: run, enable, direction, fault reset); HR 683 Serial/USB speed reference (Speed reference, 8192 = P0403); HR 680 Logical status (status word) (Status word: running, remote, fault); HR 5 Output frequency (Output frequency (0.1 Hz)); HR 3 Motor current (Motor current (0.1 A)); HR 4 DC link voltage (Ud) (DC link voltage); HR 49 Present fault (Present fault number); HR 48 Present alarm (Present alarm number).

How do I enable Modbus control of the WEG CFW500 frequency inverter (Modbus RTU)?

P0312 selects the serial protocol (2 = Modbus RTU slave on serial 1, 7 = on the second port of a CRS485/CUSB/CRS232 module). Set P0308 address, P0310 baud and P0311 byte format. For network control set P0220 = 1 (always Remote) or 6 (Local/Remote switched by P0682 bit 4), P0222 = 9 (reference from P0683), P0226 = 5 or 6 (direction from P0682 bit 2) and P0227 = 2 (run/stop from P0682). Use P0221/P0223/P0224 instead if the drive runs in Local.

What happens when the WEG CFW500 frequency inverter (Modbus RTU) loses Modbus communication?

P0314 Serial Watchdog (0.0-999.0 s, 0 = off by default) raises alarm A0128 when no valid telegram arrives in time; P0313 picks the reaction (0 none, 1 ramp stop default, 2 coast/general disable, 3 go to Local, 4 Local keeping the network commands, 5 fault F0228). Timing starts at the first valid telegram after power-up. P0316 shows 2 while the watchdog error is active.
