Inovance MD200 series compact AC drive Modbus register map

Updated 19 November 2026

Short answer

Inovance's compact general-purpose drive for small machines, fans and pumps. Its RS-485 port speaks Modbus RTU. Speed is written as a signed percentage to 1000H, run commands go to 2000H, status and fault sit at 3000H and 8000H, and every parameter (F/A groups at FxxxH/AxxxH, U0 monitors at 70xxH) has its own hex address. This map covers the control registers, the main U0 monitors and the FD communication parameters.

This page lists 46 Modbus registers for the Inovance MD200 series compact AC drive — 16 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Inovance’s own free documentation (linked below) and checked against it.

Integration notes: Inovance MD200 series compact AC drive

Integration in brief

Set F0-02 = 2 and F0-03 = 9, then write the speed as a signed percentage of F0-10 to 1000H (10000 = 100.00 %) and a run code to 2000H. Poll 3000H for run state, 8000H for faults and 7000H-7006H for frequency, voltage, current, power and torque.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

F0-02 = 2 (communication) accepts run commands from 2000H; F0-03 = 9 (communication) makes 1000H the main frequency. FD-00..FD-02 set baud, format and address; FD-05 = 1 selects standard Modbus.

Communication loss & watchdog

FD-04 sets a communication timeout (0.0 s = off); when exceeded the drive reports a communication error (Err16).

Byte order & addressing

  • 1000H is a percentage, not Hz: 10000 = +100.00 % of F0-10, negative values reverse.
  • Output current resolution over Modbus is 0.01 A by default, 0.1 A when FD-06 = 1.
  • Default serial format is 8-N-2 (FD-01 = 0), not 8-N-1.

Network setup

  • FD-02 address (default 1), FD-00 ones digit = baud (default 5 = 9600 bit/s), FD-01 = data format.
  • Restore factory settings over Modbus by writing the user password to 1F00H, then 1 to 1F01H.

Watch out for

  • Repeated parameter writes to FxxxH go to EEPROM; use the 0xxxH RAM alias for values that change often.

Notes on this map

  • All registers are single 16-bit words. Scales follow the decimals printed in each parameter's range; the guide's read example returns 13 88 (5000) for F0-10 = 50.00 Hz.
  • To write F-group parameters without storing them in EEPROM, replace the leading F with 0 (F0-16 -> 0010H); A-group parameters use 4x instead of Ax.
  • Left out: U0-14 and U0-19 (decimal places set by F7-12), U0-61 (drive state code, no value table), U0-69 (printed Int16 with a 0.00-655.35 Hz range), single-phase-only monitors (U0-12, U0-13, U0-24, U0-35, U0-65, U0-78) and reserved rows.
  • Fault code 6 is printed with the same text as code 3 ('Overcurrent during deceleration'), so its real meaning is unclear. Reserved fault codes are omitted.
  • 2000H, 2001H, 2002H and 1000H are write-only; 2001H bits other than relay 1 are reserved on MD200.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Inovance MD200 series compact AC drive

What Modbus registers does the Inovance MD200 series compact AC drive have?

This map lists 46 registers: 46 holding registers. 16 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Inovance MD200 series compact AC drive Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are hex and go on the wire unchanged: the guide reads F0-10 with 01 03 F0 0A ..., writes AC-16 with 01 06 4C 10 ... and sets the frequency with 01 06 10 00 .... A parameter's address is its group code (F0H-FFH, A0H-AFH, 70H-7FH for U0-UF) followed by its number in hex.

What are the minimum Modbus registers to integrate the Inovance MD200 series compact AC drive?

Start with HR 8192 Control command (Run / stop / reset command); HR 4096 Communication setting (Speed reference as % of max frequency); HR 12288 AC drive running status (Forward / reverse / stopped); HR 32768 AC drive fault code (Fault code); HR 28672 U0-00 Running frequency (Running frequency); HR 28676 U0-04 Output current (Output current); HR 28674 U0-02 Bus voltage (DC bus voltage).

How do I enable Modbus control of the Inovance MD200 series compact AC drive?

F0-02 = 2 (communication) accepts run commands from 2000H; F0-03 = 9 (communication) makes 1000H the main frequency. FD-00..FD-02 set baud, format and address; FD-05 = 1 selects standard Modbus.

What happens when the Inovance MD200 series compact AC drive loses Modbus communication?

FD-04 sets a communication timeout (0.0 s = off); when exceeded the drive reports a communication error (Err16).
