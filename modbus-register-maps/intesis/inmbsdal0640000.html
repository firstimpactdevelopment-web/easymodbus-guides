Updated 17 November 2026

Short answer

Gateway that exposes DALI / DALI-2 control gear on one or two DALI lines as Modbus holding registers. Addresses follow fixed formulas: per ballast short address (100 registers each), per DALI group (from 6400) and broadcast (from 6800), plus a 7000 offset for the second line. Signals cover levels, on/off, step, scenes, fade and limit settings, status and failure bits.

Integration notes: Intesis (HMS Networks) INMBSDAL0640000 / INMBSDAL1280000 DALI-2 to Modbus RTU / TCP server

Integration in brief

Configure the gateway in Intesis MAPS with fixed Modbus addresses, then write arc power level (sa x 100 + 15) or the group/broadcast level registers and read actual level (sa x 100 + 6) and ballast status (+5).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

All settings (Modbus RTU/TCP parameters, slave number, IP, Fixed address mode) are made in the Intesis MAPS configuration tool.

Byte order & addressing

  • The two-channel model (1280000) is Modbus TCP only.
  • Writes use FC06 or FC16; reads FC03 or FC04.

Network setup

  • RTU: 1200..115200 baud, parity and stop bits selectable, EIA-485 or EIA-232.
  • TCP: port 502 by default, plus keep-alive and IP settings in MAPS.

Watch out for

  • Status registers only refresh after an update; write 1 to register 4 to trigger a full ECG status update.

Notes on this map

  • HMS does not appear to host this manual revision publicly any more (newer IN703DAL / INMBSDAL0640200 products have their own manuals); this copy is an unaltered HMS document on an integrator's site (Chipkin).
  • The manual says every register is a 16-bit signed integer, big endian; levels are whole percent.
  • The map applies only when the 'Modbus Addresses' parameter in Intesis MAPS is set to Fixed.
  • For other gear add 100 per short address (sa 0..63), 20 per group (0..15) and 7000 for DALI channel 2 (two-channel model only).
  • Device-type-specific registers for emergency lighting (type 1, from +42) and LED gear (type 6) exist but are not listed; see the manual.
  • Addresses 0..20000 that are not in the map are read-only and return 0; an invalid address returns a Modbus exception.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Intesis (HMS Networks) INMBSDAL0640000 / INMBSDAL1280000 DALI-2 to Modbus RTU / TCP server

What Modbus registers does the Intesis (HMS Networks) INMBSDAL0640000 / INMBSDAL1280000 DALI-2 to Modbus RTU / TCP server have?

This map lists 38 registers: 38 holding registers. 23 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Intesis (HMS Networks) INMBSDAL0640000 / INMBSDAL1280000 DALI-2 to Modbus RTU / TCP server Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers derived from parameter numbers. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Address = 7000 x channel + 100 x short address + signal (ballasts), 7000 x line + 20 x group + 6400..6415 (groups), 7000 x line + 6800..6815 (broadcast). The manual states the result is in link-layer format with the first register at 0, so it is the wire address. Only short address 0, group 0 and two broadcast signals of channel 0 are listed.

What are the minimum Modbus registers to integrate the Intesis (HMS Networks) INMBSDAL0640000 / INMBSDAL1280000 DALI-2 to Modbus RTU / TCP server?

Start with HR 15 Arc power level (sa 0) (Set level of short address 0); HR 6 Actual level (sa 0) (Actual level of short address 0); HR 5 Ballast status (sa 0) (Ballast status); HR 0 Ballast / lamp failure bit field (ECG15-ECG0) (Failure bits for sa 0-15); HR 6400 Group 0: Arc power level (Group 0 level); HR 6800 Broadcast: arc power level (Broadcast level).

How do I enable Modbus control of the Intesis (HMS Networks) INMBSDAL0640000 / INMBSDAL1280000 DALI-2 to Modbus RTU / TCP server?

All settings (Modbus RTU/TCP parameters, slave number, IP, Fixed address mode) are made in the Intesis MAPS configuration tool.
