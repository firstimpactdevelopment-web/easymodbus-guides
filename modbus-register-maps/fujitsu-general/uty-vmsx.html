Short answer

The UTY-VMSX connects a single Fujitsu indoor unit to an RS-485 Modbus RTU network as a slave. Input registers report mode, on/off, setpoint, room temperature, fan, louvres, errors and lockouts; holding registers send commands, where 0 always means 'no change'. All values are single 16-bit registers.

This page lists 43 Modbus registers for the Fujitsu General UTY-VMSX Modbus converter (one indoor unit) — 16 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Fujitsu General’s own free documentation (linked below) and checked against it.

Integration notes: Fujitsu General UTY-VMSX Modbus converter (one indoor unit)

Integration in brief

Poll input registers 53-58 (30054-30059) with FC04 for mode, on/off, setpoint, fan, room temperature and error. Control with FC06 to holding registers 1-4 (40002-40005); 0 in any command register means no change.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step is described; the converter answers as soon as its address and speed are set.

Byte order & addressing

  • Address rule: frame address = (register mod 10000) - 1.
  • Setpoint writes need bit 0 set: (°C x 4) x 2 + 1.
  • Most status values start at 1 (filter sign and the human-detection flags start at 0); command registers add 0 = no change.

Network setup

  • One UTY-VMSX per indoor unit; up to 31 converters per BMS line without a repeater, 247 with.
  • 3-wire RS-485, max 1000 m.

Watch out for

  • An FC04 read of a function the indoor unit does not have returns 0, not an exception.

Notes on this map

  • Function codes: 03 and 04 read, 06 and 16 write. If the indoor unit lacks a function or cannot report a value, an FC04 read returns 0.
  • Serial settings per the spec: 9600 or 19200 bps, 8 data bits, parity even/odd/none, 2 stop bits with no parity or 1 with parity. No factory default address or speed is printed; they are set on the converter.
  • Temperatures in input registers are x4 (0.25 °C steps). Temperature commands use bit 0 as a 'change' flag and bits 1-8 as the value x4, so 20 °C is written as 161; the spec prints a table for 18-30 °C.
  • The setpoint limit registers 30066-30068 pack two values (upper in bits 0-7, lower in bits 8-15) so they are listed raw.
  • Write all six limit registers 40012-40017 together with FC16 when switching between 'no limit' and 'limit', and keep each lower limit below its upper limit.
  • Model name (30003) and software version (30007) are packed character codes; the spec does not give a character table, so they are listed raw.
  • Not listed: holding registers 40018-40022 (external thermo-off and human-detection settings), whose rows are hard to align reliably in the printed table.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Fujitsu General UTY-VMSX Modbus converter (one indoor unit)

What Modbus registers does the Fujitsu General UTY-VMSX Modbus converter (one indoor unit) have?

This map lists 43 registers: 27 input registers, 16 holding registers. 16 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Fujitsu General UTY-VMSX Modbus converter (one indoor unit) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The specification states the rule: the frame address is the remainder of the register number divided by 10000, minus 1. Its example sends 35555 as 5554. So 30054 is input register 53 and 40002 is holding register 1.

What are the minimum Modbus registers to integrate the Fujitsu General UTY-VMSX Modbus converter (one indoor unit)?

Start with IR 53 Operation mode status (Operation mode); IR 54 On/Off status (On/off status); IR 55 Set temperature (Setpoint); IR 57 Indoor (room) temperature (Room temperature); IR 58 Indoor unit error (Indoor unit error); HR 2 On/Off command (On/off command); HR 3 Set temperature command (Setpoint command).

How do I enable Modbus control of the Fujitsu General UTY-VMSX Modbus converter (one indoor unit)?

No enable step is described; the converter answers as soon as its address and speed are set.
