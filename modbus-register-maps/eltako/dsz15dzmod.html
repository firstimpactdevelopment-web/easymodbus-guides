Short answer

The DSZ15DZMOD is Eltako's MID-approved bidirectional three-phase energy meter for direct connection up to 80 A, with an RS485 Modbus RTU interface. Values are 32-bit integers sent high word first: voltages, currents, power factors and import/export energy (total and partial) with fixed decimals.

Integration notes: Eltako DSZ15DZMOD-3x80A MID three-phase energy meter (Modbus RTU)

Integration in brief

Read input registers (function 04) at 0x0000-0x0063 for voltages, currents, power factors and energy; each value is 2 registers, high word first. Total import energy is at 0x0048 in 0.01 kWh.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The spec does not describe enabling Modbus. Change the Modbus address by writing register 0x0014 with function 16 (the spec's example sets 0x2A).

Byte order & addressing

  • Hex start addresses are wire addresses.
  • Power-factor registers are signed with 3 decimals; other values unsigned with 2 decimals.

Network setup

  • 9600 baud, 8 data bits, no parity, 1 stop bit.
  • Address range 1-250.

Watch out for

  • There is no published power resolution; use energy deltas if you need power.
  • Partial energy registers are separate from the totals; do not mix them up.

Notes on this map

  • Word order: the spec says multi-register data runs from the lower to the higher register address with each register high byte first, and its energy example answers 00 00 01 CD 00 00 01 70 for 4.61 kWh import and 3.68 kWh export, so 32-bit values are ABCD.
  • Scaling (remark 1): all values except power and power factor are unsigned with 2 decimals; power factor is signed with 3 decimals.
  • Left out: L1/L2/L3 and total active power (0x000C-0x0010, 0x0034). The remark says power is signed 'without decimal' while the unit column says kW, which would mean whole kilowatts; the resolution is too unclear to publish.
  • Left out: the serial number at 0xFC00 (BCD).
  • Measured values are read with function 04, parameters with function 03 and written with function 16. The spec's examples also use slave address 00 in place of the meter address.
  • The parameter table marks the baud-rate and stop-bit rows read only; only the Modbus address is listed as read/write.
  • The parameter rows are typed only as 'int' with no sign stated; they are listed as INT32, and all documented values are small positive numbers.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Eltako DSZ15DZMOD-3x80A MID three-phase energy meter (Modbus RTU)

What Modbus registers does the Eltako DSZ15DZMOD-3x80A MID three-phase energy meter (Modbus RTU) have?

This map lists 19 registers: 14 input registers, 5 holding registers. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Eltako DSZ15DZMOD-3x80A MID three-phase energy meter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row gives a 3xxxx/4xxxx reference and a hex start address; the hex value is the wire address (30073 = 0x0048). The manual's example frame CC 04 00 48 00 04 reads total import and export energy at 0x0048.

What byte order does the Eltako DSZ15DZMOD-3x80A MID three-phase energy meter (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Eltako DSZ15DZMOD-3x80A MID three-phase energy meter (Modbus RTU)?

Start with IR 72 Total import active energy (Total import active energy (0.01 kWh)); IR 74 Total export active energy (Total export active energy); IR 0 Voltage L1-N (Voltage L1-N); IR 6 Current L1 (Current L1); IR 62 Total power factor (Total power factor).

How do I enable Modbus control of the Eltako DSZ15DZMOD-3x80A MID three-phase energy meter (Modbus RTU)?

The spec does not describe enabling Modbus. Change the Modbus address by writing register 0x0014 with function 16 (the spec's example sets 0x2A).
