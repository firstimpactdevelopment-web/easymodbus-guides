Short answer

Yaskawa's compact vector drive with a built-in RS-422/RS-485 MEMOBUS/Modbus RTU port on terminals R+/R-/S+/S-. Commands are written to hex registers 0001H-000FH, status, fault and alarm words and key monitors are read from 0020H upwards, and every parameter has its own hex register in the parameter table. This map covers the command block, status/fault/alarm words, the main monitors with fixed units, fault and alarm codes, and the b1/H5 setup parameters.

Integration notes: Yaskawa V1000 AC drive (MEMOBUS/Modbus RTU)

Integration in brief

Set H5-01..H5-03 at the keypad and power-cycle, set b1-01 = 2 and b1-02 = 2 so the frequency reference and Run command come from Modbus, then write 0001H (run bits) and 0002H (frequency reference) together with function 10H and poll 0020H-002CH for status, faults and alarms.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set H5-01 slave address (default 1F hex = 31, range 0-20 hex), H5-02 speed (default 3 = 9600 bps) and H5-03 parity (default 0 = none), then cycle power. For control set b1-01 = 2 and b1-02 = 2 (b1-15/b1-16 for external reference 2). H5-12 decides whether 0001H bits 0/1 mean FWD/REV run or Run + direction. Network inputs are ORed with terminals S1-S7.

Communication loss & watchdog

H5-05 = 1 (default) enables CE detection, H5-09 CE Detection Time (0.0-10.0 s, default 2.0 s) sets the timeout, and H5-04 selects the reaction: 0 ramp to stop, 1 coast, 2 fast stop (C1-09), 3 alarm only and keep running (default). Drive Status 2 (002CH) bit F shows a communication timeout.

Byte order & addressing

  • Registers are hex and 0-based: 0020H is sent as 00 20.
  • Only function codes 03H, 08H and 10H are supported; there is no 06H single-register write, so use 10H even for one register.
  • Reads and writes are limited to 16 registers per message.
  • H5-11 defaults to 1 on V1000 (parameter changes apply immediately, V7 style). With H5-11 = 0 (F7/G7 style) parameter writes only apply after writing 0 to 0900H (RAM + EEPROM) or 0910H (RAM only). Reference and broadcast data never need Enter. 0900H/0910H are write-only; reading them returns error 02H.
  • Minimum gap before the next message: 5 ms after commands/reads, 50 ms (H5-11 = 0) or 200 ms (H5-11 = 1) after a parameter write, 200 ms-2 s after an Enter command.

Network setup

  • Terminals R+, R-, S+, S- and IG on the control terminal block; for 2-wire RS-485 jumper S+ to R+ and S- to R-. Up to 31 drives per line.
  • Set DIP switch S2 ON (120 ohm termination) only on the drive at the end of the line.
  • H5-07 = 1 (RTS switched, default) for RS-485 or multi-drop RS-422; 0 for point-to-point RS-422.
  • Data is 8 bits, 1 stop bit, RTU only; speeds 1.2-115.2 kbps; parity none/even/odd.
  • H5-06 Drive Transmit Wait Time (default 5 ms) delays the reply if the master overruns.

Watch out for

  • H5-01 = 0 stops the drive from answering at all, and the V1000 address range only goes to 20 hex (32).
  • H5-01..H5-03 changes need a power cycle; wait until the operator display is fully off before re-powering.
  • The Enter command to EEPROM (0900H) wears the EEPROM (about 100,000 writes); use 0910H for frequent changes, and wait about 5 s after an Enter before removing power.
  • With a communication option card fitted, the option takes priority for ComRef/ComCtrl.
  • Self-test: set H1-06 = 67, loop the comm terminals back as the manual shows and power up; the operator shows PASS when the port is healthy.

Notes on this map

  • Frequency registers (0002H reference, 0023H/0040H U1-01, 0024H/0041H U1-02) use the units chosen in o1-03 (0 = Hz in 0.01 Hz steps, the default; 1 = % of E1-04; 2 = r/min; 3 = user units), so they are left unscaled; with o1-03 = 0 divide by 100 for Hz.
  • 0042H U1-03 output current is scaled 8192 = 100% of drive rated output current (U-monitor footnote); the map converts it to % of rated current.
  • Left out: 0025H output voltage (unit switched by H5-10; use 0045H), 0026H and 00FBH output current (0.01 A on BA0001-BA0018, 2A0001-2A0040, 4A0001-4A0023 but 0.1 A on 2A0056-2A0069, 4A0031-4A0038, so no single scale), 0027H/0047H output power (unit not printed in the data table), 0028H/0032H torque (sign not stated), 002FH frequency reference bias and 0068H U4-08 heatsink temperature (sign not stated), 003EH/003FH and 00ACH-00B8H speed/frequency in r/min and % (sign not stated), 004EH/004FH analog input levels (sign not stated), 0007H AM analog output (10 V = 4000H, sign not stated), 00ABH drive rated current (model-dependent units), U4-10/U4-11 kWh, and the 0082H-008FH fault-trace snapshot values.
  • 0022H Data Link Status: bit 1 is reserved and bit 2 has no printed meaning, so only bits 0, 3, 4 and 5 are listed.
  • Values for 0080H/0081H/0090H (U2-01, U2-02, U3-01) and 007FH are the fault and alarm codes of Tables C.4 and C.5 converted from hex to decimal (e.g. 0021H CE = 33). U3-02 onward continue at 0091H in the U-monitor list.
  • Appendix C says a master can read and write parameters over MEMOBUS/Modbus regardless of parameter settings 'except H5-oo', and its setup steps have H5-01..H5-12 entered at the LED operator, so the H5 registers are listed read-only and should be set at the operator (reading them is not explicitly confirmed either).
  • H5-02: the Appendix C table prints the range as '0 to 5' but lists settings up to 8 (115200 bps), and the parameter table gives 0 to 8; this map follows 0-8.
  • Broadcast (slave address 0) accepts only 0001H, with its own bit layout (bit 0 run, bit 1 direction, bit 4 external fault, bit 5 fault reset, bits C-E terminals S5-S7), and 0002H (30000 = 100%); slaves do not reply.

Questions about the Yaskawa V1000 AC drive (MEMOBUS/Modbus RTU)

What Modbus registers does the Yaskawa V1000 AC drive (MEMOBUS/Modbus RTU) have?

This map lists 63 registers: 63 holding registers. 11 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yaskawa V1000 AC drive (MEMOBUS/Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are printed in hex and go into the request unchanged: the manual's read example asks for starting register 0020H by sending 00 20, and its write example starts at 0001H (00 01). Parameters use the hex address in the parameter table (H5-01 = 425 -> 0425H, b1-01 = 180 -> 0180H).

What are the minimum Modbus registers to integrate the Yaskawa V1000 AC drive (MEMOBUS/Modbus RTU)?

Start with HR 1 Operation commands / multi-function inputs (Run/stop, direction, fault reset); HR 2 Frequency reference (Frequency reference (o1-03 units)); HR 32 Drive Status 1 (Drive Status 1: run/ready/fault); HR 33 Fault Contents 1 (Fault Contents 1); HR 36 Output frequency (Output frequency); HR 44 Drive Status 2 (Drive Status 2 incl. comm timeout bit); HR 49 DC bus voltage (DC bus voltage); HR 128 U2-01 Current Fault (U2-01 current fault code).

How do I enable Modbus control of the Yaskawa V1000 AC drive (MEMOBUS/Modbus RTU)?

Set H5-01 slave address (default 1F hex = 31, range 0-20 hex), H5-02 speed (default 3 = 9600 bps) and H5-03 parity (default 0 = none), then cycle power. For control set b1-01 = 2 and b1-02 = 2 (b1-15/b1-16 for external reference 2). H5-12 decides whether 0001H bits 0/1 mean FWD/REV run or Run + direction. Network inputs are ORed with terminals S1-S7.

What happens when the Yaskawa V1000 AC drive (MEMOBUS/Modbus RTU) loses Modbus communication?

H5-05 = 1 (default) enables CE detection, H5-09 CE Detection Time (0.0-10.0 s, default 2.0 s) sets the timeout, and H5-04 selects the reaction: 0 ramp to stop, 1 coast, 2 fast stop (C1-09), 3 alarm only and keep running (default). Drive Status 2 (002CH) bit F shows a communication timeout.
