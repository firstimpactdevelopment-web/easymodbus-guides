Short answer

The InRow RD is an in-row direct-expansion cooling unit for data-centre rows and contained aisles. Its controller serves Modbus RTU and Modbus TCP with everything in holding registers. This page covers the single-register points: group configuration and fan-speed settings, unit operating mode and type, compressor and I/O states, and about 50 alarm flags.

Integration notes: APC (Schneider Electric) InRow RD direct-expansion cooling unit (Modbus register map 990-3576B)

Integration in brief

Read OPERATE_MODE (141), UNIT_TYPE (142) and OVERALL_STATUS (64) for the unit state, then the individual alarm flags from 256 up. Group settings such as fan speed preference (7) can be written with function code 6.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Not described in the register map.

Byte order & addressing

  • The decimal absolute register number is the wire address; Modicon numbering adds 40001.
  • Points shown on unsupported units read as 0 rather than returning an error.

Network setup

  • Modbus RTU (serial) and Modbus TCP are both supported per the map; serial settings and unit ID are not given in this document.

Watch out for

  • A large block read can take 2 s or more; read fewer registers or raise the timeout if requests time out.
  • Reading before the controller has data returns an invalid-address error.

Notes on this map

  • The download is a ZIP holding JBOR-7NZSGZ_R2_EN.pdf (and an identical _SRC copy).
  • All two-register points (setpoints, deadband, temperatures, cooling output and demand, airflow, fan speed, pressures, PID terms, run hours, thresholds and the Modbus diagnostic counters) are typed "LONG" in the map, a type its own data-type list does not define, so they are left out here: signedness for LONG is not stated. The baud-rate register at 65534 is typed "INTEGER", also undefined, and is left out too.
  • Every point kept here is ENUM, which the map defines as an unsigned 16-bit value with a list of states.
  • Reads use function code 3 or 4; writes use function code 16, or 6 for single-register points.
  • Text registers (unit name, location, model, serial number, firmware and hardware revision, date of manufacture at 65-140) are left out; reserved rows are left out.
  • Some alarm names are cut off in the printed cells (0x0124, 0x0133 and 0x0131); 0x0124 and 0x0133 are completed here as PERSISTENT_HIGH_DISCHARGE_PRESSURE and ACTIVE_FLOW_CONTROLLER_SENSOR_FAULT. 0x0131 shows NUM_OF_ACTIVE_FLOW_CONTROLLERS (the end of the name is hidden) with Clear/Alarm values, kept as printed.
  • Single-register reads of reserved or undefined registers return an exception; a block read starting on a valid register returns zeros for undefined ones.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the APC (Schneider Electric) InRow RD direct-expansion cooling unit (Modbus register map 990-3576B)

What Modbus registers does the APC (Schneider Electric) InRow RD direct-expansion cooling unit (Modbus register map 990-3576B) have?

This map lists 72 registers: 72 holding registers. 16 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the APC (Schneider Electric) InRow RD direct-expansion cooling unit (Modbus register map 990-3576B) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map prints the 'Absolute Starting Register Number' in hex and in decimal. Note 11 says absolute register 0 equals Modicon 40001 and is address zero on the wire, so the decimal number is the wire address (e.g. SUPPLY_TEMP 149 = 0x0095 = Modicon 40150).

What are the minimum Modbus registers to integrate the APC (Schneider Electric) InRow RD direct-expansion cooling unit (Modbus register map 990-3576B)?

Start with HR 141 OPERATE_MODE (Operating mode); HR 64 OVERALL_STATUS (Overall alarm status); HR 142 UNIT_TYPE (Unit type); HR 211 COMPRESSOR_STATE (Compressor on/off); HR 259 COOL_FAIL (Cooling failure alarm); HR 278 WATER_DETECTED (Water detected alarm); HR 7 FAN_SPEED_PREFERENCE (Group fan speed preference); HR 6 CONFIGURATION_TYPE (Group configuration type).
