Neptronic CMU compact make-up air unit (Modbus communication module) Modbus register map

Updated 19 November 2026

Short answer

The Neptronic CMU is a compact make-up air unit with an ECM fan, electric heater, damper, sensor inputs and an exhaust-fan output. Its Modbus RTU module exposes holding registers only: input voltages and temperatures, room temperature, RH, CO2, VOC and light from the TDF room sensor, supply and outdoor air readings, static pressure and airflow, set points and loop tuning, input/output configuration, occupancy and alarm flags.

This page lists 98 Modbus registers for the Neptronic CMU compact make-up air unit (Modbus communication module) — 60 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Neptronic’s own free documentation (linked below) and checked against it.

Integration notes: Neptronic CMU compact make-up air unit (Modbus communication module)

Integration in brief

Read supply air temperature (23), duct static pressure (27), fan speed (30) and alarm status (104). Command occupancy with register 85 and set occupied / unoccupied airflow with 35 / 36.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Modbus communication module and set the address in the device menu or register 0.

Communication loss & watchdog

Modbus timeout (67, 15-1800 s) and number of synchronisation timeouts (68) are provided; the guide does not describe the fallback action.

Byte order & addressing

  • All points are holding registers (FC03/06/16).
  • Auto baud detection is the default; 9600-76800 baud supported.

Network setup

  • RS-485 two-wire, RTU mode.

Watch out for

  • Input and output modes (87-99) change what the analog/binary I/O registers mean.

Notes on this map

  • Only function codes 03, 06 and 16 are supported; every point is a 16-bit holding register.
  • 'Scale N' with 'Value x N' means raw = engineering value x N; this map stores the multiplier 1/N. Units follow the °C/°F setting.
  • Left out: register 0 (product type / address; the byte description is garbled); network / TDF / anti-freeze temperature set points 32-34 and set point min/max 44-45 (Scale 100 but 'Value x 1'); static pressure offset 58 (Scale 10 but example 2 Pa = 200); System alarm host 105 (bits up to B31 printed for a 16-bit register).
  • Alarm status (104) is printed with 'B8 to B31 = Reserved'; only bits 0-7 carry meanings and are listed.
  • Both 22 and 23 rows read 'Binary output 1 state' in the guide; 23 is presumably binary output 2 but is copied as printed.
  • Serial framing defaults are not given; the guide lists 9600-76800 baud with auto-baud detection as the default.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Neptronic CMU compact make-up air unit (Modbus communication module)

What Modbus registers does the Neptronic CMU compact make-up air unit (Modbus communication module) have?

This map lists 98 registers: 98 holding registers. 60 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Neptronic CMU compact make-up air unit (Modbus communication module) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints the protocol-base (0-based) address and the holding register (base 40001) side by side, e.g. 23 / 40024. The protocol-base number is the wire address.

What are the minimum Modbus registers to integrate the Neptronic CMU compact make-up air unit (Modbus communication module)?

Start with HR 23 Supply air temperature (Supply air temperature); HR 27 Duct static pressure (Duct static pressure); HR 30 CMU ECM fan speed feedback value (Fan speed feedback); HR 31 Heater vernier stage duty cycle (Heater duty cycle); HR 85 CMU occupancy state (Occupancy state); HR 104 Alarm status (Alarm status); HR 35 Occupied airflow setpoint in percent of maximum capacity (Occupied airflow set point).

How do I enable Modbus control of the Neptronic CMU compact make-up air unit (Modbus communication module)?

Fit the Modbus communication module and set the address in the device menu or register 0.

What happens when the Neptronic CMU compact make-up air unit (Modbus communication module) loses Modbus communication?

Modbus timeout (67, 15-1800 s) and number of synchronisation timeouts (68) are provided; the guide does not describe the fallback action.
