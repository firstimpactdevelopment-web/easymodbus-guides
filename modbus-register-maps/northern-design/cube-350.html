Northern Design Cube 350 panel power meter (Modbus RTU option) Modbus register map

Updated 17 November 2026

Short answer

The Cube 350 is a three-phase panel multifunction meter. With the Modbus option fitted it is an RS-485 Modbus RTU slave. Readings are integers: energy is a 32-bit copy of the display counter, and instantaneous values are signed 16-bit counts with power-of-ten scale registers. This map covers energy, instantaneous values, demand, THD and the setup registers.

This page lists 86 Modbus registers for the Northern Design Cube 350 panel power meter (Modbus RTU option) — 35 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Northern Design’s own free documentation (linked below) and checked against it.

Integration notes: Northern Design Cube 350 panel power meter (Modbus RTU option)

Integration in brief

Read the scale registers 2837-2840 and eScale (513) once after commissioning, then poll 2816-2836 and the energy block 514-529 with function 03 in requests of 20 words or fewer. Apply 10^(K-3) to instantaneous values and 10^(eScale-6) to energy.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is a fitted option. Two extra steps in the front-panel programming menu set the baud rate and the unique Modbus address.

Byte order & addressing

  • Scale factors are exponents offset by 3 (value x 10^(K-3)), not plain SunSpec-style exponents.
  • Maximum 20 words per request; split larger block reads.
  • Allow at least 10 ms after each reply before the next request; replies can take up to 250 ms.

Network setup

  • RS-485 half duplex, two wires plus 0 V. Baud 4800, 9600 or 19200; address 1-247, both set on the front panel.
  • Fit 120 ohm terminators at the host and at the farthest meter; ground the cable shield at the host only.

Watch out for

  • Energy, hours-run and peak registers are writable; a careless write resets a billing counter.
  • A non-zero Security PIN (3595) locks front-panel programming.

Notes on this map

  • Northern Design does not host this manual publicly; the link is an unaltered copy on a distributor's file host.
  • 32-bit values are a high word at the lower address followed by the low word (LONG = 65536 x high + low), so ABCD.
  • Energy registers hold the display digits without a decimal point. kWh = raw x 10^(eScale-6) and Wh = raw x 10^(eScale-3), with eScale read from register 513 (40514). The manual's formula names register 40513, which is the eScale high word; the worked example shows it means the energy count.
  • Instantaneous values are signed counts with no fixed scale: real value = raw x 10^(K-3), where K is Ki (2837), Kvp (2838), Kvl (2839) or Kp (2840). The K values follow the CT/PT programming and stay fixed once the meter is set up. These registers are listed with scale 1 and no unit, so the map shows raw counts.
  • Export kWh reads 0 on meters without export metering.
  • Left out: the amalgamated block 7680-7737 (copies of the main values; one row is an unqualified 'Kvarh'), the V/I harmonic tables 7936-9229 and the custom table 19200-19487, which only repeats registers you choose.
  • Supported functions: 03, 04, 06, 08 (loop-back only) and 16. A request returns at most 20 words.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Northern Design Cube 350 panel power meter (Modbus RTU option)

What Modbus registers does the Northern Design Cube 350 panel power meter (Modbus RTU option) have?

This map lists 86 registers: 86 holding registers. 35 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Northern Design Cube 350 panel power meter (Modbus RTU option) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each table prints a 0-based data address next to its Modicon register number (512 = 40513). This map records the Modicon number; the data address is what goes on the wire, so request 512 to read 40513.

What byte order does the Northern Design Cube 350 panel power meter (Modbus RTU option) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Northern Design Cube 350 panel power meter (Modbus RTU option)?

Start with HR 2840 Power scale Kp (Power scale Kp); HR 2816 System kW (System kW (raw)); HR 2821 Phase 1 volts (Phase 1 volts (raw)); HR 2822 Phase 1 amps (Phase 1 amps (raw)); HR 2820 Frequency (Frequency); HR 2819 System PF (System power factor); HR 513 eScale (Energy exponent eScale); HR 514 kWh (import) (Import kWh counter).

How do I enable Modbus control of the Northern Design Cube 350 panel power meter (Modbus RTU option)?

Modbus is a fitted option. Two extra steps in the front-panel programming menu set the baud rate and the unique Modbus address.
