Integration notes: Intesis (HMS Networks) IN770AIR***O000 700 Series Air Gateway, Mitsubishi Electric City Multi application (Modbus)

Integration in brief

Pick the Mitsubishi Electric City Multi application and the Modbus interface in Intesis MAPS, discover or add the units, send the project, then read and write each unit's block.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The gateway must be configured with Intesis MAPS (City Multi project, Modbus selected) and the project sent to it; the manual points to the Signals tab of the MAPS configuration guide for the address formulas.

Byte order & addressing

  • Writes accept FC06 (single register) only.
  • Trigger (T) registers act when 1 is written and are not meant to be read.

Network setup

  • All Modbus settings (RTU or TCP, slave address, baud, parity) are made with the Intesis MAPS tool; the manual gives no factory serial settings.
  • On first power-up DHCP is tried for 30 seconds, then the gateway falls back to 192.168.100.246.
  • Modbus RTU uses the EIA-485 port (A+, B-); bias and 120 ohm termination are on DIP switch block SW A.

Watch out for

  • Most centralised controllers need the PC-Monitoring (SW-Mon) software licence from Mitsubishi Electric before their XML interface, which the gateway uses, is active.

Notes on this map

  • Group g on controller c: add ((c-1) x 50 + g - 1) x 100 to the listed group addresses. Controller 2 signals: add 30.
  • Setpoint-restriction registers (+21..+26) and outdoor temperature (+35) are left out: their ranges are printed without the x10 marker the other temperatures carry.
  • Mode, fan and setpoint registers change meaning for Lossnay and ATW / HWHP groups. Lossnay mode: 0 LC Auto, 1 Heat Recovery, 2 Bypass. ATW mode: 0 Hot water, 1 Heating, 2 Heating eco, 3 Anti-freeze, 4 Cooling.
  • Per-unit alarm code registers (controller x 1000 + 20000 + M-NET address) are off by default and enabled per controller in MAPS; not listed.
  • Available registers depend on the gateway configuration and unit type.
  • One manual covers the three licence sizes of the same hardware: IN770AIRXXSO000 (up to 15 groups, 1 centralised controller), IN770AIR00SO000 (50 groups, 1 controller) and IN770AIR00MO000 (100 groups, 2 controllers). The brand application is chosen in Intesis MAPS.
  • The manual gives no data type for the registers; values whose printed range goes below zero are listed as INT16, the rest as UINT16.
  • The consumption registers (yesterday / today / total, also per heat and cool) are left out: each takes two addresses, but the manual gives neither the word order nor a fixed unit (Wh or kWh is chosen in MAPS).
  • Reads use FC03 or FC04; writes use FC06 only. 'T' (trigger) registers act when 1 is written.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious.
