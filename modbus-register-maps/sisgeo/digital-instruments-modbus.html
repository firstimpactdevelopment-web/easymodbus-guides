Short answer

Common Modbus RTU register set of SISGEO's digital geotechnical instruments (in-place inclinometers, tiltmeters, piezometers, extensometers). Input registers give update counters, physical readings as IEEE-754 floats and fixed-point integers, electrical readings, supply voltage and internal temperature/humidity; holding registers hold version, address, baud rate, timed-mode options and power-down.

Integration notes: SISGEO SISGEO digital instruments, RS-485 Modbus (firmware 3.x normal mode)

Integration in brief

Read IR_PHYSICAL_COUNT plus the physical float channels in one FC04 request from 0x0200, decode the floats high word first, and use the count to detect new readings.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Instruments ship in always-on mode (except DEX/DEX-S) at address and baud set in the user configuration; no enable step.

Byte order & addressing

  • Input and holding registers share address numbers but are different data; use FC04 for readings and FC03 for configuration.
  • Floats and 32-bit integers are high word first; the configuration Scale pair is low word first.

Network setup

  • 9600 baud, 8N1 by default; baud stored in 0x0142 as baud/100.
  • Address 1..247 in 0x0103.
  • In timed mode units come online after initial + address x incremental delay seconds.

Watch out for

  • Writing 0xFF to HR_RESET switches the unit off until power is cycled.
  • The moving average needs about two IR_PHYSICAL_CHANGE increments to settle after the input changes.

Notes on this map

  • Word order: the manual shows the float's sign/exponent bits in the first register (e.g. 0x202) and the rest in the second, and states for integer and fixed-point pairs that the most significant word comes first. All listed 32-bit values are ABCD.
  • The channel-configuration 'Scale' pair is the exception: the manual says it is stored least significant word first. Those configuration registers (0x0148 onward) are not listed.
  • What each physical channel holds (tilt, pressure, temperature, etc.) depends on the instrument; see its own datasheet and user manual.
  • Only physical channels 0-14 (float), fixed-point channels 0-7 and electrical channels 0-7 are listed; fixed-point and electrical blocks run to channel 14 at the same 2-register spacing.
  • Raw ADC registers (0x260+) are left out: the manual's table repeats addresses 0x260-0x26E for channels 7-14, so the layout cannot be trusted. Legacy-mode registers (0x0100-0x012B input) are also left out.
  • IR_PHYSICAL_COUNT changes when a new averaged reading is ready; the manual advises waiting for two increments of IR_PHYSICAL_CHANGE after an input change before trusting the value.
  • IR_TEMPERATURE is listed as signed (INT16); the manual gives it in tenths of a degree Celsius but does not state the sign convention.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the SISGEO SISGEO digital instruments, RS-485 Modbus (firmware 3.x normal mode)

What Modbus registers does the SISGEO SISGEO digital instruments, RS-485 Modbus (firmware 3.x normal mode) have?

This map lists 52 registers: 43 input registers, 9 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the SISGEO SISGEO digital instruments, RS-485 Modbus (firmware 3.x normal mode) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as hexadecimal addresses. The manual lists a holding register at 0x0000 (HR_VERSION_FW, 'read Holding Register 0x0000'), which only exists in 0-based protocol addressing, so the printed hex values are the wire addresses. The input-register tables print short forms such as 0x202; 'documented' keeps the form used in each table.

What byte order does the SISGEO SISGEO digital instruments, RS-485 Modbus (firmware 3.x normal mode) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the SISGEO SISGEO digital instruments, RS-485 Modbus (firmware 3.x normal mode)?

Start with IR 512 IR_PHYSICAL_COUNT (New-reading counter); IR 514 IR_PHYSICAL_CHANNEL_0 (Physical channel 0); IR 516 IR_PHYSICAL_CHANNEL_1 (Physical channel 1); IR 518 IR_PHYSICAL_CHANNEL_2 (Physical channel 2); IR 1025 IR_SUPPLY (Supply voltage); IR 1032 IR_TEMPERATURE (Board temperature).

How do I enable Modbus control of the SISGEO SISGEO digital instruments, RS-485 Modbus (firmware 3.x normal mode)?

Instruments ship in always-on mode (except DEX/DEX-S) at address and baud set in the user configuration; no enable step.
