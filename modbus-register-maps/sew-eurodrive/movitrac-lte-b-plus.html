Integration notes: SEW-EURODRIVE MOVITRAC LTE-B+ frequency inverter (built-in Modbus RTU)

Integration in brief

Set P-14 = 101, P-12 = 5 (or 6 to send ramp times in register 3) and P-15 per the fieldbus table, then write register 1 = 0x0006 with register 2 = speed (16384 = P-01). Poll register 6 for status, 7 for actual speed and 8 for current.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set P-14 = 101 for extended parameter access, P-12 = 5 (Modbus RTU, internal ramps P-03/P-04) or 6 (ramps from PO3), and P-15 as the manual's Modbus table shows. P-36 level 1 sets the address (1-63, factory 1) and level 2 the Modbus baud rate (0 = 9.6, 1 = 115.2 (factory), 2 = 19.2, 3 = 38.4, 4 = 57.6, 5 = 76.8 kbit/s). The digital inputs must still be wired so the inverter is enabled.

Communication loss & watchdog

P-36 level 3 sets the reaction to a communication failure: 0 = keep the last setpoint (no fault), 1-4 = coast to a stop after 30/100/1000/3000 ms, 5-8 = rapid stop on P-24 after 30/100/1000/3000 ms. The fault list has fault 50 for a Modbus communication error (0x2B in the PI1 high byte).

Byte order & addressing

  • Register numbers are 1-based: subtract 1 for the wire address.
  • Control word logic is inverted against most drives: bit 0 = 1 inhibits the output stage; 0x0006 runs, 0x0000 rapid-stops, 0x0001 coasts.
  • Speed is a signed relative value: 16384 = +100 % of P-01, -16384 = -100 % (CCW).

Network setup

  • Wire RS485- (Modbus) to RJ45 pin 7 and RS485+ to pin 8; pins 4/5 are the engineering port.
  • Up to 32 stations; 1200 m at 115200 bit/s with 0.5 mm2 cable.
  • Framing is fixed at 8 data bits, no parity, 1 stop bit.

Watch out for

  • Parameters above P-15 are only reachable after P-14 = 101 (or the code set in P-37).
  • With P-36 level 3 = 0 the inverter keeps running on the last setpoint if the master disappears.

Notes on this map

  • PO2/PI2 speed and PI3 current are relative values (16384 = 100 % of P-01 or of P-08), so they are kept raw; multiply by P-01/16384 or P-08/16384 in the master.
  • Left out: PI4 motor torque (register 9) because no scaling is given; P00-03 speed setpoint (22/40) because its unit switches between Hz and rpm with P-10 and the resolution is not stated; P00-07 motor voltage (43), the kWh/MWh counters (32/33, resolution not stated) and the hours/minutes counters (25/26, 28) because the register format is not described.
  • Parameter registers follow 128 + parameter number (P-01 = 129 ... P-60 = 188), but the manual does not give the Modbus scaling for most of them; only P-07 (confirmed by the frame example) and P-12 are listed. P-36 (address, baud, timeout) has three levels behind one register number and is left out.
  • The manual's own example reads P-08 (register 136) as 0x2B = 43 % of the nominal inverter current, i.e. not in amperes; it is left out because the scaling is only shown by that one example.
  • The PI1 high byte holds the 'fault code status word' column of the fault list (e.g. 0x2B = fault 50 Modbus communication error) when bit 5 = 1.
  • Only function codes 03 (read holding registers) and 06 (write single register) are named in the Modbus chapter.

Questions about the SEW-EURODRIVE MOVITRAC LTE-B+ frequency inverter (built-in Modbus RTU)

What Modbus registers does the SEW-EURODRIVE MOVITRAC LTE-B+ frequency inverter (built-in Modbus RTU) have?

This map lists 14 registers: 14 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the SEW-EURODRIVE MOVITRAC LTE-B+ frequency inverter (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual's register numbers start at 1 and it warns that zero-based masters must subtract 1. Its frame examples confirm this: reading registers 135/136 (P-07/P-08) sends start address 0x0086 = 134, and writing register 2 (setpoint speed) sends start address 0x0001.

What are the minimum Modbus registers to integrate the SEW-EURODRIVE MOVITRAC LTE-B+ frequency inverter (built-in Modbus RTU)?
