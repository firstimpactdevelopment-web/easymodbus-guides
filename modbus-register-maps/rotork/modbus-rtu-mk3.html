Short answer

The Mk3 Modbus module puts a Rotork electric valve actuator on an RS-485 Modbus RTU highway (single, dual or repeater versions). Open, close, stop, ESD and partial stroke can be sent as coils or as one register value, and position control uses a 0-100.0 % set-point register. Status bits, torque and valve position can be read as discrete inputs, input registers or holding registers, and holding registers 7-31 hold the positioner, comms-loss and network settings.

This page lists 98 Modbus registers for the Rotork Modbus RTU Mk3 option card (IQ3, SI3/SI4, CK, CVA, CMA, K-range) — 36 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Rotork’s own free documentation (linked below) and checked against it.

Integration notes: Rotork Modbus RTU Mk3 option card (IQ3, SI3/SI4, CK, CVA, CMA, K-range)

Integration in brief

Read input registers 0-4 (status bits, torque, position) with function 04 or 03. Command the valve by writing register 5 (0 stop, 1 close, 2 open, 3 ESD) or send a position in 0.1 % to register 6. The actuator selector must be in Remote.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the module address (register 22, default 247), baud (23) and parity (24) with a Modbus tool or the Rotork setting tool over IR/Bluetooth. Turn the actuator's local/remote selector to Remote. Keep register 80 at 0.

Communication loss & watchdog

If no network traffic is seen for the comms fault timer (register 21, default 10 s), the actuator does what register 7 says: nothing (default), open, close, stop, or move to the comms lost position in register 13.

Byte order & addressing

  • Addresses are already 0-based: holding register 5 is 40006 in 1-based host software.
  • Writing 0 % or 100 % to the position register runs to the tight shut-off or full open limit unless limited-range positioning is set.
  • Only register 5 values 0 (stop) and 3 (ESD), and coils 0 and 3, accept broadcast (address 0).

Network setup

  • RS-485 two-wire half duplex, 300 to 115200 baud, 8 data bits, odd/even/none parity, 1 or 2 stop bits.
  • Switch on module termination (register 25) only on the last device of a segment; use network biasing somewhere on the highway.
  • Replies can take up to 190 ms; a segment takes up to 32 nodes, more with repeaters.

Watch out for

  • Every new module ships at address 247, which the manual says should never stay in use on a live system; readdress each actuator before adding the next.
  • Dual-channel modules share one baud/parity setting; leave an 11-byte idle gap on port 1 so port 2 messages are answered.
  • Setting the deadband below the hysteresis forces the hysteresis to 0.1 %.

Notes on this map

  • Only two 32-bit values exist (motor start counts); the manual labels the low order word at the lower register and the high order word at the next one, so they are CDAB.
  • Holding registers 0-4 and input registers 0-4 carry the same data; registers 0 and 1 pack the same bits as discrete inputs 0-29 (bit 0/15 excepted, see below).
  • Ranges are printed in hex: torque 0-0x78 (0-120 %), position 0-0x3E8 (0.0-100.0 %).
  • Data logger registers 32-59 update a short time after the actuator stops in Remote and can lag by up to two minutes. On ELB units registers 32-49 hold pressure and alarm data instead; the ELB-only tables are not included here.
  • The comms fault timer (register 21) is given as 0-255 s in the table but 0-65 s in the text, and the Comms Lost Position text refers to 'Fault Mode (Register 1)' where the table uses register 7. Check on site.
  • Not every actuator range supports every location (e.g. DO-5 to DO-8 are IQ3 only); see the manual's database summary table.
  • Also supported: function 07 (exception status byte), 08 (loopback, sub-codes 00 and 02) and 17 (report slave ID: name, software version and tag).
  • Status bit 0/15 (discrete input 15) is left out: the data tables call it EEPROM checksum failure, but the database summary and the signal descriptions call it Watchdog Recovery.
  • Register 80 is marked read-only in the data logger table but writable (06) in the configuration register table; it is kept as RW.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Rotork Modbus RTU Mk3 option card (IQ3, SI3/SI4, CK, CVA, CMA, K-range)

What Modbus registers does the Rotork Modbus RTU Mk3 option card (IQ3, SI3/SI4, CK, CVA, CMA, K-range) have?

This map lists 98 registers: 13 coils, 26 discrete inputs, 5 input registers, 54 holding registers. 36 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Rotork Modbus RTU Mk3 option card (IQ3, SI3/SI4, CK, CVA, CMA, K-range) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual says every coil, discrete and register location is numbered from 0 with no offset, exactly as sent on the wire. Hosts that use 1/10001/30001/40001 numbering must add those offsets themselves.

What byte order does the Rotork Modbus RTU Mk3 option card (IQ3, SI3/SI4, CK, CVA, CMA, K-range) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Rotork Modbus RTU Mk3 option card (IQ3, SI3/SI4, CK, CVA, CMA, K-range)?

Start with IR 0 Status word 1 (Status: limits, moving, remote/local, alarms); IR 1 Status word 2 (Status: interlocks, DIs, general alarm); IR 3 Valve position (Valve position, 0.1 %); IR 2 Actuator instantaneous torque (Instantaneous torque, %); HR 5 Actuator digital control (Digital control command); HR 6 Actuator position DV (desired value) (Position set-point, 0.1 %); HR 7 Action on loss of comms (Action on loss of comms).

How do I enable Modbus control of the Rotork Modbus RTU Mk3 option card (IQ3, SI3/SI4, CK, CVA, CMA, K-range)?

Set the module address (register 22, default 247), baud (23) and parity (24) with a Modbus tool or the Rotork setting tool over IR/Bluetooth. Turn the actuator's local/remote selector to Remote. Keep register 80 at 0.

What happens when the Rotork Modbus RTU Mk3 option card (IQ3, SI3/SI4, CK, CVA, CMA, K-range) loses Modbus communication?

If no network traffic is seen for the comms fault timer (register 21, default 10 s), the actuator does what register 7 says: nothing (default), open, close, stop, or move to the comms lost position in register 13.
