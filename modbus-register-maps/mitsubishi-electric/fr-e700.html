Integration notes: Mitsubishi Electric FR-E700 compact inverter (PU connector, Modbus RTU)

Integration in brief

Set Pr.549 = 1, Pr.117 to 1-247 and Pr.122 to 9999 (or a real interval), reset, then switch to NET mode by writing H0014 to 40010. Write the frequency to 40014 (0.01 Hz) and run bits to 40009; poll 40009, 40201, 40202 and 40501.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Pr.549 = 1 selects Modbus RTU on the PU connector; set Pr.117 (station), Pr.118 (speed) and Pr.120 (parity) and reset. The PU connector must be the NET command source (Pr.550 = 2, or 9999 with no communication option fitted). Operation and frequency commands need NET mode (write H0014 to 40010; allowed depending on Pr.79/Pr.340).

Communication loss & watchdog

Pr.122 is the communication check interval (0.1-999.8 s) with Pr.502 choosing coast or decelerate on E.PUE. Initial value 0 trips E.PUE as soon as the drive enters NET mode, so set 9999 or an interval before switching.

Byte order & addressing

  • Request address = register - 40001.
  • Station 0 is broadcast and never replies; the initial Pr.117 is 0.
  • 40009 means control input when written and inverter status when read.

Network setup

  • Pr.118 initial 192 = 19200 bps; Pr.120 initial 2 = even parity, 1 stop bit.
  • With Pr.549 = 1 and Pr.118 = 384, the FR-PU04/FR-PU07 parameter unit stops working; use the built-in panel.
  • Modbus RTU cannot be used in PU operation mode.

Watch out for

  • Pr.122 = 0 (initial) makes the drive trip E.PUE the moment it goes to NET mode.

Notes on this map

  • All registers are single 16-bit words.
  • Modbus RTU runs on the PU connector (RJ45-type RS-485 port), configured with the PU communication parameters Pr.117-Pr.122, not on separate terminals.
  • Frequency registers use 0.01 Hz; with Pr.37 (speed display) set they switch to 1 r/min. The 0.01 Hz unit for 40014/40015 is from the same manual's computer-link set-frequency description (H0000-HFFFF in 0.01 Hz increments).
  • Fault history registers hold the fault code in the low byte; the values listed are the manual's fault code list.
  • Parameters with a 9999 (function off) setting, such as the communication check interval, are listed with their normal increment; the manual does not say how the 9999 setting itself is encoded on the wire, so read the parameter back after setting it from the panel.
  • Parameters 0-999 sit at 41000 + Pr. number; calibration parameters C2-C25 have their own registers and are not listed. Pr.7/Pr.8 are left out (increment depends on Pr.21 / capacity).
  • Left out because the sign is not stated: motor torque 40207 and PID deviation 40254. Option terminal monitors 40258-40260 (FR-A7AX/A7AY E kit) are not listed.

Questions about the Mitsubishi Electric FR-E700 compact inverter (PU connector, Modbus RTU)

What Modbus registers does the Mitsubishi Electric FR-E700 compact inverter (PU connector, Modbus RTU) have?

This map lists 51 registers: 51 holding registers. 22 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Mitsubishi Electric FR-E700 compact inverter (PU connector, Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints Modicon-style register numbers (40002, 41004) and states: starting address = register number - 40001. Its example reads 41004 (Pr.4) with start address H03EB (1003).

What are the minimum Modbus registers to integrate the Mitsubishi Electric FR-E700 compact inverter (PU connector, Modbus RTU)?

Start with HR 8 Inverter status / control input instruction (Run/stop command and inverter status); HR 9 Operation mode / inverter setting (Operation mode (write H0014 for NET)); HR 13 Running frequency (RAM) (Frequency command (RAM)); HR 200 Output frequency / speed (Output frequency); HR 201 Output current (Output current); HR 500 Fault record 1 (Latest fault code).
