Circutor Computer SMART III FAST Modbus register map

Updated 19 November 2026

Short answer

The Computer SMART III FAST is a power factor regulator that switches capacitor stages with static (thyristor) outputs and measures the network like an analyzer. Its RS-485 port speaks Modbus RTU; measurements are 32-bit integer register pairs read with function 04 and the setup block at 0x1071-0x1190 is read with 04 and written with 0x10. This map covers currents, reactive and apparent power, frequency, leakage current, energies, stage and output status, and the main setup registers.

This page lists 89 Modbus registers for the Circutor Computer SMART III FAST — 37 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Circutor’s own free documentation (linked below) and checked against it.

Integration notes: Circutor Computer SMART III FAST

Integration in brief

Read the measurement block from 0x0000 with function 04, keeping each frame at or under 80 bytes (at most 37 registers per read). Values are 32-bit integers, high word first; currents are in mA.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the peripheral number, speed, parity and stop bits in the RS-485 communications setup screen or with registers 0x1071-0x1075.

Byte order & addressing

  • Frames longer than 80 bytes in either direction are rejected, so split large reads.
  • Energies are a whole-unit register plus a remainder register; combine both.
  • Digital output bits in the output status word read 1 when the output is OFF.

Network setup

  • Defaults: peripheral 1, 19200 baud, no parity, 8 data bits, 1 stop bit.
  • Only 9600 and 19200 baud are offered on the RS-485 Modbus port.

Watch out for

  • Writing the stage status registers (0x1110-0x111B) forces capacitor stages on or off; return them to Auto (0) afterwards.

Notes on this map

  • Word order: the function 04 example returns 0000 then 084D for one 2-register value, so 32-bit values are high word first (ABCD).
  • Left out: all voltage registers. The table prints the unit V/100 but the worked example decodes the same register as V x10 (212.5 V), so the scaling is contradictory.
  • Left out: active power, the signed reactive power rows, power factor and cos phi. The manual pairs PF and cos phi with separate kW/kvar sign registers but gives no type or scale for them and does not say whether the power values carry a sign.
  • Left out: THD (unit printed as % with no scale), temperature (signedness not stated), harmonics, the 32-bit alarm word at 605-606 (its bit numbering is printed inconsistently), alarm thresholds, the deleting-parameters commands (the value is printed only as FF with no function code) and identification registers.
  • Left out: registers 98-99 and 9A-9B. The table labels them active energy consumed (kWh and Wh), the same label as 88-89 and 8A-8B, although they sit in the generated-energy block; the manual does not say which they are.
  • Currents and leakage current are printed in mA; they are given here in A with scale 0.001.
  • The kW/kvar sign registers are typed INT32 because their documented values are +1 and -1.
  • The 12Vdc version has its own manual (M100B01-03-21A) whose tables are numbered differently; it was not checked register by register, so it is not covered here.
  • Setup registers are read with function 04 and written with function 0x10; they are listed as holding registers. Frames longer than 80 bytes are rejected.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Circutor Computer SMART III FAST

What Modbus registers does the Circutor Computer SMART III FAST have?

This map lists 89 registers: 52 input registers, 37 holding registers. 37 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Circutor Computer SMART III FAST Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. All Modbus tables print hexadecimal wire addresses. The manual's example reads initial log 0000 with function 04 and gets 0000 084D back for L1 phase voltage, which confirms that table addresses go on the wire unchanged.

What byte order does the Circutor Computer SMART III FAST use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Circutor Computer SMART III FAST?

Start with IR 80 Three-phase current (Three-phase current); IR 90 Three-phase apparent power (Three-phase apparent power); IR 92 Three-phase reactive power consumed (Three-phase reactive power consumed); IR 104 Frequency (Frequency (Hz x10)); IR 136 Active energy consumed (Active energy consumed (kWh)); IR 1536 Relay variable (Which capacitor stages are switched in); IR 114 Leakage current (Leakage current).

How do I enable Modbus control of the Circutor Computer SMART III FAST?

Set the peripheral number, speed, parity and stop bits in the RS-485 communications setup screen or with registers 0x1071-0x1075.

Where is the official Circutor Computer SMART III FAST Modbus documentation?
