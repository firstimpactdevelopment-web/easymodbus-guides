Updated 28 October 2026

Short answer

Schneider's Conext CL is a three-phase grid-tie string inverter with two MPPT inputs and Modbus RTU on RS-485 plus Modbus TCP. All data are holding registers in a vendor map that also embeds SunSpec models 1, 103 and 160 from 0x9C40. This map covers identity strings, lifetime energy, operating state, temperatures, grid voltages, currents, power and frequency, PV input values, the alarm code, the remote on/off command and the active-power limit.

Integration notes: Schneider Electric Conext CL three-phase PV inverter 18/20/25 kVA

Integration in brief

Read 0x1700 for the operating state, 0x1828 for the alarm, 0x17FE for output power and 0x0802 for lifetime energy with function 3. Limit export by writing 0xFA19 (kW x10) or 0xFAF1 (%), and switch the inverter off or on line by writing 0x6B43 / 0x6B44 to 0xEFFE.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step is described; the RS-485 port answers at the configured address (default 10). Modbus TCP needs the IP address, port 502 and slave address.

Byte order & addressing

  • Supported functions: 03, 06, 16 and 43 (read device identification).
  • Addresses are 0-based hex; do not add 40001.
  • Broadcast writes (slave 0) work on RTU only and are meant for Schneider monitoring devices.
  • Writing 0x6B42 (reset) to 0xEFFE gets no reply because the inverter restarts.

Network setup

  • Serial default: 9600 baud, 8 data bits, no parity, 1 stop bit; 19200-115200, even/odd parity and 2 stop bits can be selected.
  • A new slave address (0x8003) only takes effect after a power cycle; a new baud rate (0x8010) may need one too.

Watch out for

  • Unused register locations read 0xFF instead of raising an exception, so a wrong address looks like data.
  • 0xEFFE reads 0000 again after the inverter reboots; re-check the state in 0x1700 rather than trusting the last command written.

Notes on this map

  • Scaling: the map writes units as 'kW/X10', 'Vrms/X10', 'C/X10' and so on, meaning the raw value is ten times the real value (scale 0.1).
  • Lifetime energy 0x0802-0x0803 is the only 32-bit value whose high and low words the map labels (H word first), so it is listed as ABCD. The other 32-bit registers (daily energy 0x0804-0x0811, operating hours 0x081E, event codes, the UTC clock at 0x1920 and the SunSpec acc32 energy at 0x9C9E) carry no word-order statement and are left out.
  • 0x1700 and the SunSpec vendor status 0x9CAD state their codes in hex: 15h = 21, 16h = 22, 17h = 23 decimal.
  • Remote command 0xEFFE and inverter mode 0xFA90 take the hex command words 6B42-6B45; they are listed in decimal under values (0x6B42 = 27458).
  • Section 4 of the map lists the alarm codes reported in 0x1828 (e.g. 2450 No-Grid, 2616 PV insulation, 4003 Replace fan); they are not repeated here.
  • Not listed: software part/build/checksum strings, event logs with time stamps (0x1900-0x193F), the rest of the SunSpec blocks and the reactive-power, LVRT and multifunction-relay settings. Several reactive power and LVRT registers are marked 'Not available' in this revision.
  • Unused addresses return 0xFF bytes rather than an exception.

Questions about the Schneider Electric Conext CL three-phase PV inverter 18/20/25 kVA

What Modbus registers does the Schneider Electric Conext CL three-phase PV inverter 18/20/25 kVA have?

This map lists 51 registers: 51 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Schneider Electric Conext CL three-phase PV inverter 18/20/25 kVA Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map prints addresses in hex and says they are 0-based ('on the wire') addresses, not 1-based. So 0x17FE (active power) is requested as 6142 decimal with no offset.

What byte order does the Schneider Electric Conext CL three-phase PV inverter 18/20/25 kVA use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Schneider Electric Conext CL three-phase PV inverter 18/20/25 kVA?

Start with HR 5888 Operational mode state (Operating state); HR 6184 Inverter alarm code (Active alarm code); HR 6142 Active power (AC output power); HR 2050 Energy produced (lifetime) (Lifetime energy); HR 6146 Grid frequency (Grid frequency); HR 6139 Grid current L1 (Phase L1 current); HR 64241 User active power percentage (Active power limit %); HR 61438 Remote disable/enable (Remote on/off command).

How do I enable Modbus control of the Schneider Electric Conext CL three-phase PV inverter 18/20/25 kVA?
