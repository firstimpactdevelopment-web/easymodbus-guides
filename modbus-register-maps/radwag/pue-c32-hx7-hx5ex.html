Short answer

Radwag's PUE C32, HX7 and HX5.EX indicators act as Modbus slaves over RS-232, RS-485 (not on the C32) or Ethernet. Input registers give mass, tare, unit, status and thresholds per platform; holding registers take zero/tare/print commands and parameter writes such as a tare value, thresholds, outputs and product codes.

This page lists 36 Modbus registers for the Radwag PUE C32 / PUE HX7 / PUE HX5.EX weighing indicators — 15 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Radwag’s own free documentation (linked below) and checked against it.

Integration notes: Radwag PUE C32 / PUE HX7 / PUE HX5.EX weighing indicators

Integration in brief

Read input registers (FC04) from offset 0: platform 1 mass is a big-endian float at offset 0 and its status bits at offset 5. To zero or tare, write the matching bit to the Command register at offset 500, then clear it before the next use.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Turn Modbus on in the indicator menu under SETUP / Peripherals / Modbus; settings are described in the indicator software manual.

Byte order & addressing

  • Commands act on the rising edge of a bit: write 0 before writing the same bit again.
  • Parameter commands: write the value register(s) and the 'Command with parameter' bit, using FC16.

Network setup

  • Modbus communication is configured under SETUP / Peripherals / Modbus; the indicator software manual covers the individual settings.
  • RS-485 is not available on the PUE C32.

Watch out for

  • Platform 2 registers only answer on the PUE HX7.
  • The manual's write examples mix two numbering styles (40000 + offset and Modicon); go by the offset column.

Notes on this map

  • Floats and the lot number are two registers with the first register holding the high bytes (ABCD); the manual's worked example 0x3E68 / 0x72B0 = 0.227 confirms it.
  • Mass, MIN and MAX are in the currently displayed unit; tare and LO threshold use the adjustment (calibration) unit.
  • The worked write examples on pp. 9-10 label registers as 40000 + offset for the tare value (40503/40504 = offsets 503-504) and the output mask (40507 = offset 507), which agrees with the offset column, but label 'command with parameter' as 40502, which is the table's Modicon number for offset 501. This map follows the table's offset column for every wire address.
  • The manual gives no default serial settings or unit ID; they are set in the indicator menu.
  • The table types the lot number as 'long' (signed 32-bit); it is mapped as INT32, high word first as the manual states.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Radwag PUE C32 / PUE HX7 / PUE HX5.EX weighing indicators

What Modbus registers does the Radwag PUE C32 / PUE HX7 / PUE HX5.EX weighing indicators have?

This map lists 36 registers: 21 input registers, 15 holding registers. 15 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Radwag PUE C32 / PUE HX7 / PUE HX5.EX weighing indicators Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each table gives both a 0-based Offset and a Modbus address (30001/40001 style); the offset is what goes on the wire, e.g. platform 1 mass is offset 0 = 30001 and Command is offset 500 = 40501. The 'documented' field holds the Modbus address column.

What byte order does the Radwag PUE C32 / PUE HX7 / PUE HX5.EX weighing indicators use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Radwag PUE C32 / PUE HX7 / PUE HX5.EX weighing indicators?

Start with IR 0 Platform 1 mass (Platform 1 mass); IR 5 Platform 1 status (Platform 1 status (stable, zero, errors)); IR 4 Platform 1 unit (Displayed unit); IR 2 Platform 1 tare (Platform 1 tare); HR 500 Command (Zero / tare / print command bits).

How do I enable Modbus control of the Radwag PUE C32 / PUE HX7 / PUE HX5.EX weighing indicators?

Turn Modbus on in the indicator menu under SETUP / Peripherals / Modbus; settings are described in the indicator software manual.
