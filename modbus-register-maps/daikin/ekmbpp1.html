Short answer

The EKMBPP1(A) connects to the P1P2 remote-controller bus of Daikin Sky Air and VRV indoor units and is a Modbus RTU slave on RS-485. Holding registers set the group's setpoint, fan speed, mode, louvre, on/off, update/lock behaviour, limits, VAM ventilation and Smart Grid mode; input registers give group and per-unit status, errors and temperatures.

Integration notes: Daikin EKMBPP1 / EKMBPP1A Modbus adapter (Sky Air / VRV P1P2)

Integration in brief

Read I0020-I0035 for the group state and the unit blocks from I0120 for each indoor unit. Write H0001-H0005 to control the group; choose an update mode (H0010-H0015) so remote controllers are locked or left free as needed.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the Modbus address (0-63) on the DIP switch; the protocol is fixed at 9600 baud, no parity, 1 stop bit. DIP switches also select the optional 120 s master timeout. Terminate the RS-485 line with slide switches SS1-SS3 (0, 100 or 120 ohm).

Communication loss & watchdog

Optional (DIP switch): if no holding register is written for 120 seconds all units switch on with their current settings and, depending on the setting, remote controllers are unlocked. A Forced off Smart Grid request is never overruled.

Byte order & addressing

  • Up to 10 registers per read or write.
  • In update mode Central the value is written to the unit repeatedly and the remote buttons are locked; LastTouch requires writing only on change.
  • Smart Grid does not work with update mode Local.

Network setup

  • 3-wire RS-485, Modbus RTU slave, 9600 baud, no parity, 1 stop bit.

Watch out for

  • Only one Modbus master is allowed; a Smart Grid controller and a BMS cannot share the adapter.
  • Coil temperatures are only available when the adapter is in P1P2 Main mode.

Notes on this map

  • All registers are 16-bit. Temperatures are degrees C x 100 as signed values (above 32767 is negative).
  • Per-unit input registers: unit n uses n x 100 + 20 to n x 100 + 32 (unit 1 = I0120-I0132, unit 16 = I1620-I1632).
  • Error codes hold two ASCII characters (high and low byte) forming the Daikin error code; 0 = waiting for data, 255 = no error, 14384 = group timeout (80), 14388 = unit missing (84).
  • Inhibit registers are sums of the listed inhibit values (1, 2, 4, 8 ...), shown here as bits.
  • The setpoint registers print a range of 16-32 with no unit.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Daikin EKMBPP1 / EKMBPP1A Modbus adapter (Sky Air / VRV P1P2)

What Modbus registers does the Daikin EKMBPP1 / EKMBPP1A Modbus adapter (Sky Air / VRV P1P2) have?

This map lists 158 registers: 139 input registers, 19 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Daikin EKMBPP1 / EKMBPP1A Modbus adapter (Sky Air / VRV P1P2) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual states register base 0 and writes registers as H0001 / I0020 with the matching Modicon number beside them (H0001 = 40002, I0020 = 30021). The H/I number is the wire address.

What are the minimum Modbus registers to integrate the Daikin EKMBPP1 / EKMBPP1A Modbus adapter (Sky Air / VRV P1P2)?

Start with HR 5 On/off (On/off); HR 3 Operation mode (Operation mode); HR 1 Setpoint (Setpoint); IR 20 Unit count (Unit count); IR 21 Group error (Group error); IR 23 Return air average (Average return air temperature); IR 123 Unit 1 return air temperature (Unit 1 return air temperature).

How do I enable Modbus control of the Daikin EKMBPP1 / EKMBPP1A Modbus adapter (Sky Air / VRV P1P2)?

Set the Modbus address (0-63) on the DIP switch; the protocol is fixed at 9600 baud, no parity, 1 stop bit. DIP switches also select the optional 120 s master timeout. Terminate the RS-485 line with slide switches SS1-SS3 (0, 100 or 120 ohm).

What happens when the Daikin EKMBPP1 / EKMBPP1A Modbus adapter (Sky Air / VRV P1P2) loses Modbus communication?

Optional (DIP switch): if no holding register is written for 120 seconds all units switch on with their current settings and, depending on the setting, remote controllers are unlocked. A Forced off Smart Grid request is never overruled.
