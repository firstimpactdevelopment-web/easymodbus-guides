Short answer

The S811+ is Eaton's larger soft starter with full motor protection, metering and a configurable I/O block. Through the C441 Ethernet module it is reachable over Modbus TCP and RS-485 Modbus RTU. This map covers the adapter I/O registers, status, fault and warning words, single-word current, power and frequency monitors, the network control words (500/501) and the main protection and comm-loss settings.

This page lists 88 Modbus registers for the Eaton S811+ soft starter (via C441 Ethernet module) — 61 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Eaton’s own free documentation (linked below) and checked against it.

Integration notes: Eaton S811+ soft starter (via C441 Ethernet module)

Integration in brief

Poll 300 for running/faulted/bypass state, 304/305 for fault and warning bits, 340 for average line current (0.1 A) and 361 for kW. Control the motor with register 500 (permissive bit 2 plus run bit 0) or 501 in two-wire mode, and set 684 for comm-loss behaviour.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Network control needs 623 = 0 (local-only off); 687 selects three-wire (500, which also needs permissive bit 2 set) or two-wire (501) control. Modbus TCP is served by the C441 module (IP via DHCP, NV memory or DIP switches).

Communication loss & watchdog

684 sets the motor's comm-loss action (auto stop, run, hold or all-stop fault); 686 is the comm idle timeout that raises a device-missing fault; 110/159 set adapter-level Modbus timeouts.

Byte order & addressing

  • Register numbers are 1-based; subtract 1 on the wire.
  • Run1 in register 500 is edge-sensitive, but in 501 it is level-sensitive.

Network setup

  • S811+ Modbus settings 503 (baud) and 505 (parity) take effect only after a power cycle; the node address 504 is read from the DIP switches at power-up.

Watch out for

  • Writing 101 (adapter relay outputs) can change the relay states.

Notes on this map

  • Source is a distributor copy (precision-elec.com) of Eaton manual MN04200002E dated August 2012. Eaton lists a later edition (January 2016) at eaton.com, which could not be downloaded from this machine; check it for changes.
  • Only registers that are clearly one 16-bit word are listed. Items printed with a gap after them (fault/fault lists 301, 318, 370; mains voltage 308; starts 311; RMS line and pole current blocks 328-357 apart from the averages; pole temperature 362) have no stated length or word order and are left out, as is the float FLA at 600.
  • Torque, ramp, stop and start-delay settings without printed units (609-613, 615-622, 641, 681-683) and several trip thresholds without units in the table (652, 655, 657, 673, 674) are left out.
  • Registers 503-507 are the S811+'s own Modbus port settings (baud default 19200, RTU default). With a C441U/C441V that port is the link to the adapter, so integrators reach this map over Modbus TCP; the adapter's serial settings are 159-163.
  • Signedness is not stated in the manual; values are typed unsigned.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Eaton S811+ soft starter (via C441 Ethernet module)

What Modbus registers does the Eaton S811+ soft starter (via C441 Ethernet module) have?

This map lists 88 registers: 88 holding registers. 61 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Eaton S811+ soft starter (via C441 Ethernet module) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print register numbers starting at 1; the manual states that the Modbus register address is the register number minus 1 (field inputs, register 1, is address 0). The manual itself calls the control words 'Modbus reg #500' and '#501'.

What are the minimum Modbus registers to integrate the Eaton S811+ soft starter (via C441 Ethernet module)?

Start with HR 299 Motor control status (Status word); HR 303 Motor control faults (Fault bits); HR 304 Motor control warnings (Warning bits); HR 339 Average line current (0.1 A) (Average line current); HR 360 Average 3-phase real power (Real power); HR 306 Thermal pile used (Thermal pile); HR 499 Modbus motor control word (Network control word).

How do I enable Modbus control of the Eaton S811+ soft starter (via C441 Ethernet module)?

Network control needs 623 = 0 (local-only off); 687 selects three-wire (500, which also needs permissive bit 2 set) or two-wire (501) control. Modbus TCP is served by the C441 module (IP via DHCP, NV memory or DIP switches).

What happens when the Eaton S811+ soft starter (via C441 Ethernet module) loses Modbus communication?

684 sets the motor's comm-loss action (auto stop, run, hold or all-stop fault); 686 is the comm idle timeout that raises a device-missing fault; 110/159 set adapter-level Modbus timeouts.

Where is the official Eaton S811+ soft starter (via C441 Ethernet module) Modbus documentation?

The source is C441 Ethernet Module User Manual (C441R, C441T, C441U, C441V) (MN04200002E), revision 2012-08. Eaton doesn't publish it on its own website, so this map was re-typed from a free copy at https://www.precision-elec.com/wp-content/uploads/2021/01/C441-Ethernet-Module-User-Manual-C441R-C441T-C441U-C441V.pdf. It may be an older revision, so check it against the live unit.
