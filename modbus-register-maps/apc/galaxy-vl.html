Short answer

The Galaxy VL is a 200-500 kW three-phase UPS. It serves Modbus TCP and Modbus RTU, with all data read from holding registers using function 03 only. This map covers the status and alarm bit words, identification strings, input, bypass and output measurements, battery and charger values, operating modes, parallel-system totals and the configuration settings (as read-only values).

Integration notes: APC (Schneider Electric) Galaxy VL 200-500 kW three-phase UPS

Integration in brief

Read holding registers with function 03. Poll the UPS status word at 1 and the alarm words 2-23, the UPS operation mode at 5892, and the output, input and battery measurements in the 0x1300, 0x1400 and 0x1600 blocks, applying the 0.1 or 0.01 multipliers.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus settings are made on the UPS display; the register map refers to the display for detailed configuration.

Byte order & addressing

  • Only function 03 is supported.
  • 32-bit values are high word first (ABCD).
  • Status bits are consistent only within one register.

Network setup

  • Serial RTU and TCP are both supported; set address, serial settings and IP from the UPS display.

Watch out for

  • A single-register read of a reserved address returns an error; block reads return zeros for gaps.
  • The register map applies from firmware 7.23.

Notes on this map

  • Word order: note 2 says INT32/UINT32 keep the most significant word at n+0, so 32-bit values are ABCD.
  • Scale is the 'Multiply reading by' column (for example 0.1, matching 'Divide by 10'). Every numeric register kept here has both columns filled and they agree.
  • Left out: the statistics timers 4208-4224 (UINT32 in minutes, no multiply/divide entry), the settings 8194, 8199, 8200 and 8218, which give a unit but no multiplier, and battery current 5642, which the map types as UINT16 while saying negative values mean discharging.
  • Note 3: only function code 3 is supported, so everything is listed as read-only, configuration rows included.
  • Note 13: the factors for 4867-4869, 5123-5125, 5379-5381 and 6144-6153 differ from the Galaxy VS and Galaxy PX maps; do not reuse those maps' factors.
  • Bit words: bit 0 is the least significant bit and 1 means the condition is active. Reserved bits are omitted.
  • Strings are two characters per register, high byte first, padded with nulls.
  • Phase registers are listed L1, L2, L3 in that order, from the '(phase1)'-'(phase3)' suffixes in the source.

Are the APC (Schneider Electric) Galaxy VL 200-500 kW three-phase UPS Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row lists a Modicon number plus the absolute address in hex and decimal. Note 12 says absolute address 0 is register 40001 and address zero on the wire, so 44865 (0x1300) is wire address 4864.

What byte order does the APC (Schneider Electric) Galaxy VL 200-500 kW three-phase UPS use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.
