Short answer

Indigo510 and Indigo520 are Vaisala transmitters that host one or two smart probes (humidity, CO2, dew point, H2O2 and others) and expose them over Modbus TCP, analog outputs and relays. This map covers the transmitter itself at unit ID 240: optional barometer and analog input, analog output and relay configuration, network and clock settings.

This page lists 65 Modbus registers for the Vaisala Indigo510 / Indigo520 transmitters (Modbus TCP) — 49 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Vaisala’s own free documentation (linked below) and checked against it.

Integration notes: Vaisala Indigo510 / Indigo520 transmitters (Modbus TCP)

Integration in brief

Enable Modbus TCP read (and write if needed) on the transmitter, then poll unit ID 240 for these registers and 241/242 for the connected probes.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Turn on Modbus TCP/IP read and, if needed, write in the touchscreen or web interface (both are off by default).

Byte order & addressing

  • Floats are low word first (CDAB); pick "word-swapped" float in masters that default to high word first.
  • Read or write each 32-bit value in one transaction.

Network setup

  • Unit ID 240 = transmitter, 241 = probe on terminal 1, 242 = probe on terminal 2; Modbus TCP port 502.
  • Set DHCP or a static IP with registers 1537-1561 (write 1 to 1578 to apply) or on the touchscreen/web interface.

Watch out for

  • Use only one Modbus TCP client at a time and one transaction at a time; nested requests are not handled reliably.
  • Response time is about 2 s; raise the client timeout if requests time out.
  • Vaisala warns not to leave Modbus write enabled on an open network; turn it off when not needed.

Notes on this map

  • Transmitter registers are holding registers on unit ID 240: read with function 03, write with function 16.
  • 32-bit floats put the least significant word at the listed register (CDAB). The guide states this, and its worked example (30.56 %RH read from a probe at unit ID 241) confirms it.
  • Unavailable data reads as quiet NaN (float) or 0x8000 (16-bit integer) rather than an exception.
  • Probe readings are not in this map: read the probe on unit ID 241 (terminal 1) or 242 (terminal 2) using that probe's own register map.
  • Modbus TCP read and write access are both disabled by default and must be enabled on the touchscreen or web interface.
  • Indigo510 has 2 analog outputs; Indigo520 has 4 analog outputs, an analog input and 2 relays (the analog input, outputs and relays are not available on PoE-powered Indigo520 units). Registers for hardware a unit lacks are not useful on it.
  • Left out: analog output clipping limits, NTP address and DNS server strings, the time-zone enum (91 values) and the test registers.
  • Network strings occupy 8 registers for up to 15 characters.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Vaisala Indigo510 / Indigo520 transmitters (Modbus TCP)

What Modbus registers does the Vaisala Indigo510 / Indigo520 transmitters (Modbus TCP) have?

This map lists 65 registers: 65 holding registers. 49 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vaisala Indigo510 / Indigo520 transmitters (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide numbers registers in decimal starting at 1 and also prints the 0-based hex address used in the request; register number 1 is address 0x0000 on the wire.

What byte order does the Vaisala Indigo510 / Indigo520 transmitters (Modbus TCP) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Vaisala Indigo510 / Indigo520 transmitters (Modbus TCP)?

Start with HR 42 Barometric pressure (Barometric pressure (if fitted)); HR 54 Analog input level (validated) (Validated analog input); HR 1808 AOUT1 output level (AOUT1 output level); HR 3081 Relay 1 output state (Relay 1 state); HR 514 Barometer error flags (Barometer errors).

How do I enable Modbus control of the Vaisala Indigo510 / Indigo520 transmitters (Modbus TCP)?

Turn on Modbus TCP/IP read and, if needed, write in the touchscreen or web interface (both are off by default).

Where is the official Vaisala Indigo510 / Indigo520 transmitters (Modbus TCP) Modbus documentation?

The source is Indigo510, Indigo520 User Guide (M212287EN-AJ), revision 2026-10, published free by Vaisala at https://docs.vaisala.com/r/M212287EN-AJ/en-US.
