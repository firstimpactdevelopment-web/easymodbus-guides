Short answer

Wall-mounted room panel with LCD, touch buttons, temperature and humidity sensors (plus occupancy on the 801/802 and CO2 on the 802) that works as a Modbus RTU slave for a LOYTEC controller or any master. Everything is in holding registers: button and flag words, sensor readings, display values pushed by the master, set points with limits, offsets and configuration.

Integration notes: LOYTEC L-STAT network thermostat / room operating unit (Modbus RTU)

Integration in brief

Read the sensor block 48-54 with FC03 and the button/flag words 0-5; write display values (64+) and read back set points (384+) that the user adjusts. Clear latched flags by writing 1 to the bit.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step; the panel answers as a slave at address 1 out of the box. Change address/baud/parity in EDIT mode on the panel or in modbus_parameter (176), then reboot.

Byte order & addressing

  • Only FC03 and FC06: no FC16 multi-register writes.
  • Temperatures follow the Modbus unit flag (K, °C or °F) in config_flags, not the display unit.
  • Latched press and change flags stay set until the master writes 1 to them.

Network setup

  • Factory default: address 1, 57600 baud, no parity, 2 stop bits.
  • Built-in 120 ohm terminator: switch it on only at the last device on the bus.
  • Up to 16 L-STATs per LOYTEC controller; each needs a unique address.

Watch out for

  • The device has no clock battery: the master must set system time after every reboot.
  • Display range is -999..9999; larger values are shown shifted.

Notes on this map

  • The download link is named 3.2.4 but the document inside is printed as version 3.2.8.
  • Only function codes 03 (read holding registers) and 06 (write single register) are supported, so multi-register values and strings must be read with FC03 and written one register at a time.
  • Sensor scaling comes from the manual's value-scaling table: temperatures x0.1 in the configured Modbus unit system (factory default °C; K uses a -2740 offset, °F also x0.1), humidity raw x 0.005 %RH, CO2 1 ppm, voltage x0.1 V.
  • Set points, set point min/max, display values and offsets are listed raw (scale 1) because their scale depends on the unit chosen in each value's configuration register (addresses 256-351); apply the manual's scaling table for that unit (e.g. °C x0.1, l/s x0.1, inWC x0.001).
  • Only set_point_0..3, display_value_0..3 and offset_value_0 are listed; the full blocks are set_point 384-399, max 416-431, min 448-463, display values 64-79, offsets 480-488.
  • Left out: system_time (112-113), Modbus statistics (128+) and firmware/bootloader dates, because the manual does not say which of the two 16-bit halves is the high word; CPU temperature/voltage (55-56), whose scaling is not given.
  • Configuration and device-setting registers are stored in flash with limited write cycles; do not write them cyclically.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the LOYTEC L-STAT network thermostat / room operating unit (Modbus RTU)

What Modbus registers does the LOYTEC L-STAT network thermostat / room operating unit (Modbus RTU) have?

This map lists 28 registers: 28 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the LOYTEC L-STAT network thermostat / room operating unit (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each register is printed with its decimal address and hex equivalent (e.g. 48 / 0x0030). The table starts at register address 0 (present_state, 0x0000), which only exists in 0-based protocol addressing, so these are the wire addresses. 'documented' keeps both forms.

What are the minimum Modbus registers to integrate the LOYTEC L-STAT network thermostat / room operating unit (Modbus RTU)?

Start with HR 48 sensor_value_0 internal temperature (Room temperature); HR 50 sensor_value_2 relative humidity (Relative humidity); HR 53 sensor_value_5 amount CO2 (CO2 (802 only)); HR 384 set_point_0 (Main set point); HR 3 change_flags_set_points (Which set points the user changed); HR 1 short_pressed (Button presses / occupancy).

How do I enable Modbus control of the LOYTEC L-STAT network thermostat / room operating unit (Modbus RTU)?

No enable step; the panel answers as a slave at address 1 out of the box. Change address/baud/parity in EDIT mode on the panel or in modbus_parameter (176), then reboot.
