Updated 19 November 2026

Short answer

The P1000 Bypass pairs the drive with a bypass controller board that has its own RS-485 port. Over Modbus RTU the bypass passes through the drive command and monitor registers and adds a bypass command word (run, AUTO select, BYPASS select, smoke purge, Motor AND/OR, fault reset), a bypass frequency reference, network control of the bypass inputs and outputs, and UB bypass monitors.

This page lists 36 Modbus registers for the Yaskawa P1000 Bypass for industrial fans and pumps (MEMOBUS/Modbus RTU) — 16 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Yaskawa’s own free documentation (linked below) and checked against it.

Integration notes: Yaskawa P1000 Bypass for industrial fans and pumps (MEMOBUS/Modbus RTU)

Integration in brief

Set Z3-01 = 0 (Modbus), Z3-02 address, Z3-03/Z3-04 line settings and restart. Set Z1-07 = 2 and Z1-08 = 2 to take speed and run from the bypass serial port, then write 8401H (frequency) and 8400H (run bit 0, AUTO select bit 10, BYPASS select bit 12); poll 0020H, 0021H, 0024H and UB-09 (8788H).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set Z3-01 = 0, then Z1-07 = 2 [Bypass Serial] for the speed reference and Z1-08 = 2 [Bypass Serial] for the AUTO run command. Set Z3-12 = 1 if the bypass digital inputs are to be driven from 8402H.

Communication loss & watchdog

Z3-11 enables comm-fault detection and Z3-06 sets the timeout (default 2.0 s); Z3-05 sets the action (see notes).

Byte order & addressing

  • 8400H bits are OR-ed with the physical bypass inputs; clear them to release a command.
  • There is no function 06H; write single registers with 10H.

Network setup

  • Z3-02 node address 0-127 (default 1); Z3-03 baud 0-8 (default 3 = 9600); Z3-04 parity (default none). Z3-07 adds a reply delay.

Watch out for

  • Z3-05 = 3 opens the bypass contactor on a comm fault as well as faulting the drive.

Notes on this map

  • All registers are 16-bit; signed values are noted per register.
  • Frequency registers 8401H, 0023H and 0024H use the units chosen in drive parameter o1-03, so they are left unscaled.
  • Bypass status and fault words UB-02 to UB-08 (8781H-8787H) are left out because the source shows their bits as display digits without a stated bit order.
  • Left out: 0025H-0027H output voltage, current and power (unit switches or depends on model), 00ABH rated current, speed monitors in r/min, fault-trace blocks from 0080H and the fault/alarm description words from 00C0H.
  • Function codes are 03H (read up to 16 registers), 08H (loopback) and 10H (write); there is no 06H.
  • Z3-01 defaults to 3 (BACnet); select 0 for Modbus. Changes to the Z3 settings take effect after restarting.
  • UB-17 contactor voltage is left out: the monitor table prints it at 878FH (the same number as UB-16) while the BACnet table puts it at 8790H.
  • Z3-05 (comm fault action) is left out: its detail page gives range 0-3 but the parameter list adds setting 4 (run at Z3-10).
  • 8400H bits 9 and 11 are left out: the register table's row order gives HAND select and DRIVE select, but the BACnet object table in the same manual maps bit 9 to 'Drive Select' and bit 11 to 'Not Used'. The other 8400H bit numbers come from that BACnet table and agree with the row order.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Yaskawa P1000 Bypass for industrial fans and pumps (MEMOBUS/Modbus RTU)

What Modbus registers does the Yaskawa P1000 Bypass for industrial fans and pumps (MEMOBUS/Modbus RTU) have?

This map lists 36 registers: 36 holding registers. 16 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yaskawa P1000 Bypass for industrial fans and pumps (MEMOBUS/Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are hex and are sent unchanged: the manual's read example asks for starting register 0020H as 00 20. Bypass parameters and monitors use the hex number printed under each one (Z3-01 = 8500H, UB-09 = 8788H).

What are the minimum Modbus registers to integrate the Yaskawa P1000 Bypass for industrial fans and pumps (MEMOBUS/Modbus RTU)?

Start with HR 33792 Bypass command (BYP Command) (Bypass command 8400H); HR 33793 Bypass frequency reference (Bypass frequency reference 8401H); HR 32 Drive status 1 (Drive status 1); HR 33 Fault contents 1 (Fault contents 1); HR 36 Output frequency (Output frequency); HR 34696 UB-09 bypass current fault (Bypass current fault UB-09); HR 49 DC bus voltage (DC bus voltage).

How do I enable Modbus control of the Yaskawa P1000 Bypass for industrial fans and pumps (MEMOBUS/Modbus RTU)?

Set Z3-01 = 0, then Z1-07 = 2 [Bypass Serial] for the speed reference and Z1-08 = 2 [Bypass Serial] for the AUTO run command. Set Z3-12 = 1 if the bypass digital inputs are to be driven from 8402H.

What happens when the Yaskawa P1000 Bypass for industrial fans and pumps (MEMOBUS/Modbus RTU) loses Modbus communication?

Z3-11 enables comm-fault detection and Z3-06 sets the timeout (default 2.0 s); Z3-05 sets the action (see notes).
