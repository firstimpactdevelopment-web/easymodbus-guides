KOSTAL KOSTAL Smart Energy Meter (KSEM G1 / G2) Modbus register map

Updated 17 November 2026

Short answer

The KSEM is a three-phase energy meter and energy manager. As a Modbus RTU slave (RS485 A/B) or Modbus TCP slave (port 502, TLS on 802) it exposes OBIS-coded power and energy registers, a plug-and-play identification block and a SunSpec meter block. This map covers the internal instantaneous values (0-145), the 64-bit energy counters (512-791) and the identification block (8192-8249).

This page lists 69 Modbus registers for the KOSTAL KOSTAL Smart Energy Meter (KSEM G1 / G2) — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from KOSTAL’s own free documentation (linked below) and checked against it.

Integration notes: KOSTAL KOSTAL Smart Energy Meter (KSEM G1 / G2)

Integration in brief

Turn on the Modbus TCP slave in the KSEM web UI and poll the listed blocks of holding registers 0-145 for live values and 512-791 for 64-bit energy counters, high word first, splitting reads at the gaps. Net grid power is Active power+ minus Active power-.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the KSEM web interface open the Modbus settings and activate the TCP slave (and optionally TLS), or set RS485 A or B to Modbus RTU slave; save the settings before polling.

Byte order & addressing

  • Values are unsigned with separate + and - registers instead of one signed value, except power factor (int32).
  • With TLS enabled the slave only answers on port 802, not 502.
  • 64-bit energy counters must be read as all four registers in one request.

Network setup

  • Default TCP port 502; encrypted Modbus on port 802.
  • A self-signed TLS client certificate must be accepted in the KSEM certificate list before reads are allowed.

Watch out for

  • Reading across a gap between listed registers returns exception 0x02, so split polls at the gaps (e.g. 0-7, 16-27, 40-47).

Notes on this map

  • Word order is stated in section 2.2: in a multi-register value the lower address holds the most significant bits, and the worked examples combine register 0 x 2^16 + register 1 and registers 512-515 most significant first.
  • Each import/export quantity is split into a '+' and a '-' register, both unsigned; net power = (+) minus (-).
  • The SunSpec block at 40000-40177, the static/dynamic E-mobility and energy-flow areas, group registers and sensor registers are not included in this file.
  • Register 146 ('Minimum active power+ * 3', no OBIS code) and the MAC address at 8250-8252 (outside the stated PnP range) are left out.
  • Reading an address not listed in the tables returns exception 0x02 (illegal data address); request each multi-register value in a single read.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the KOSTAL KOSTAL Smart Energy Meter (KSEM G1 / G2)

What Modbus registers does the KOSTAL KOSTAL Smart Energy Meter (KSEM G1 / G2) have?

This map lists 69 registers: 69 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the KOSTAL KOSTAL Smart Energy Meter (KSEM G1 / G2) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register tables give decimal and hex addresses that are used directly on the wire: the manual's own example reads active power+ from holding registers 0 and 1 and energy from registers 512-515.

What byte order does the KOSTAL KOSTAL Smart Energy Meter (KSEM G1 / G2) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the KOSTAL KOSTAL Smart Energy Meter (KSEM G1 / G2)?

Start with HR 0 Active power+ (Active power import (0.1 W)); HR 2 Active power- (Active power export (0.1 W)); HR 26 Supply frequency (Grid frequency); HR 62 Voltage (L1) (Voltage L1); HR 60 Current (L1) (Current L1); HR 512 Active energy+ (Imported active energy (0.1 Wh)); HR 516 Active energy- (Exported active energy (0.1 Wh)); HR 8228 SerialNumber (Serial number for identification).

How do I enable Modbus control of the KOSTAL KOSTAL Smart Energy Meter (KSEM G1 / G2)?

In the KSEM web interface open the Modbus settings and activate the TCP slave (and optionally TLS), or set RS485 A or B to Modbus RTU slave; save the settings before polling.
