Woodward easYgen-3000XT Series Modbus register map

Updated 24 October 2026

Short answer

The easYgen-3000XT is Woodward's genset controller for standby, AMF, peak-shaving and mains-parallel plants. It is a Modbus RTU slave on RS-485 and a Modbus TCP server on Ethernet. Measurements, status and alarm flags are read from a fixed telegram (protocol 5010) starting at address 50000; remote start/stop, acknowledge and interface setpoints are written to parameter addresses 503-511. This page covers generator, mains and engine values, the main status and alarm words, and the remote-control words.

This page lists 90 Modbus registers for the Woodward easYgen-3000XT Series — 8 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Woodward’s own free documentation (linked below) and checked against it.

Integration notes: Woodward easYgen-3000XT Series

Integration in brief

Block-read holding registers from 50000 (up to 128 per request) for status and alarms, and the 32-bit generator and mains values at 50322-50411. To start or stop the set, write parameter 503 with 0 and then the start (bit 0) or stop (bit 1) bit; acknowledge alarms by pulsing bit 4 twice.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

RS-485: set Modbus slave ID (parameter 3188, default 1; 0 disables Modbus) and baud/parity/stop bits (3170-3172). Ethernet: set Modbus/TCP slave ID (7485) and the Ethernet A IP settings, then turn on the matching 'Set IP address' parameter. Protocol number 3184 must stay 5010 for this map; a change needs a reboot. For a remote start, the LogicsManager start request must include 04.13 Remote request.

Communication loss & watchdog

No Modbus communication timeout is documented. Bits 2 and 3 of parameter 503 must always be 0; the manual reserves them for a watchdog. A remote start request (04.13) stays set until a stop bit arrives or power is lost.

Byte order & addressing

  • Start, stop and acknowledge act on rising edges: write 0, then the bit. Writing the same value again does nothing.
  • Acknowledge needs two rising edges of bit 4: the first silences the horn, the second resets alarms that are no longer active.
  • Status-word bit numbers here follow the manual's masks: mask 8000h = bit 15.
  • Reads use function 03; parameters are written with 06 or 16. Parameters are accessed one at a time, with a length that matches their data type.
  • Some PC tools need the address shifted by one (e.g. 504 instead of 503); the manual says to try both.
  • Each parameter ID has its own address, and a 32-bit parameter is read or written as 2 registers starting at that address (high word first). So 507 (INT32) is sent as 507+508 in one request, yet 508 alone is the separate PF setpoint; likewise 510 and 511. Never block-read or block-write across 503-511; send one request per parameter with the length of its data type.

Network setup

  • RS-485 defaults: 19.2 kBd, no parity, one stop bit, full-duplex mode (parameter 3173). Select half-duplex for a two-wire bus and set a reply delay (3189) if the master needs it.
  • Modbus/TCP: up to 5 sockets. An idle socket closes after about 2.2 s and opening one takes about 200 ms, so poll continuously or expect reconnects.
  • The manual recommends a 10 ms pause after each response; RTU replies can take up to 2-3 s on display / plastic-housing units.

Watch out for

  • This controller starts engines and closes breakers. Make sure the site is safe and the operators know before writing parameter 503.
  • Bit 9 of parameter 503 sets 03.40 Remote Shutdown. One chapter says it shuts the engine down at once, but the configuration chapters route 03.40 through a LogicsManager flag and a free alarm with a shutdown class. Check how your unit is set up before relying on it.
  • Writing setpoints 507-511 changes nothing until the AnalogManager setpoint source points at the interface value.
  • Password protection for Modbus RS-485 (9128) and Ethernet (9129) defaults to On. The manual says the remote-control words and interface setpoints need no password; parameter changes do.

Notes on this map

  • The manual states Modbus registers are big-endian; 32-bit values are read high word first (ABCD). LogicsManager composite parameters are the exception (little-endian) and are not on this page.
  • Left out: the 16-bit power, voltage and current values at 50010-50021 and 50031-50040. Their scale depends on exponents published at 50001-50003 and the manual does not give the formula clearly enough; use the 32-bit values from 50322, which have fixed scaling.
  • Left out: 50028/50029 (setpoint frequency / PF, printed with a multiplier of 1 that does not fit their units), the 'active (reserved)' alarm words, and rows the table marks for the easYgen-3400XT/3500XT only (busbar L2-L3/L3-L1, LSx values, GGB bits, analog inputs 4-12, relays 13-22).
  • The status message at 50100 is an index into the manual's status message list; the index-to-text mapping is not tabulated, so no enum is given.
  • 'Latched' alarm words hold an alarm until it is acknowledged. The controller also offers alarm telegrams (protocols 5011/5017) that are not covered here.
  • Interface setpoints only take effect when the matching AnalogManager source (05.56, 05.12, 05.53, 05.59, 05.83) is selected. Parameters 507-511 are described with CANopen object data types; their Modbus addresses follow the parameter rule on p. 921.
  • The easYgen-3400XT/3500XT use the same 5010 telegram but are documented in their own manual, which was not checked for this page.
  • The parameter list gives Ethernet A a default IP of 10.31.140.0 with mask 255.255.240.0. The TCP port is not stated in the manual.

Questions about the Woodward easYgen-3000XT Series

What Modbus registers does the Woodward easYgen-3000XT Series have?

This map lists 90 registers: 90 holding registers. 8 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Woodward easYgen-3000XT Series Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The protocol 5010 table in the appendix prints wire addresses (Protocol ID at 50000). The Modbus chapter shows the same block Modicon-style from 450001 and says 450001 can become bus address 50000. Parameters (remote control, setpoints) use Modicon address = 40000 + (parameter ID + 1), so parameter 503 is 40504 and wire address 503. The manual warns some PC tools need a shift of one (e.g. 504); if a write has no effect, try the neighbour.

What byte order does the Woodward easYgen-3000XT Series use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Woodward easYgen-3000XT Series?

How do I enable Modbus control of the Woodward easYgen-3000XT Series?

RS-485: set Modbus slave ID (parameter 3188, default 1; 0 disables Modbus) and baud/parity/stop bits (3170-3172). Ethernet: set Modbus/TCP slave ID (7485) and the Ethernet A IP settings, then turn on the matching 'Set IP address' parameter. Protocol number 3184 must stay 5010 for this map; a change needs a reboot. For a remote start, the LogicsManager start request must include 04.13 Remote request.

What happens when the Woodward easYgen-3000XT Series loses Modbus communication?

No Modbus communication timeout is documented. Bits 2 and 3 of parameter 503 must always be 0; the manual reserves them for a watchdog. A remote start request (04.13) stays set until a stop bit arrives or power is lost.
