Updated 17 November 2026

Short answer

The GTW-08 is a small gateway that sits on the appliance's L-Bus and answers Modbus RTU for a BMS. Through it the BMS can read flow, return, flue and outside temperatures, water pressure, status codes and errors, set system power or temperature demands, run heating zones manually, configure cascades and define a fallback demand. This map covers the 16-bit registers of the English section.

This page lists 109 Modbus registers for the Remeha GTW-08 Modbus gateway for Remeha / De Dietrich appliances — 35 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Remeha’s own free documentation (linked below) and checked against it.

Integration notes: Remeha GTW-08 Modbus gateway for Remeha / De Dietrich appliances

Integration in brief

Set the gateway's rotary address and DIP baud/parity, then read 400/401/409/411 for temperatures, pressure and status. To control, write 258 (algorithm type), 256 power and/or 257 temperature, and 259 heat demand type (7 heating, 8 cooling).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Connect the GTW-08 to the appliance L-Bus. Rotary knob 0-F sets the Modbus address 100-115 (default 100). DIP switches 1-2 set the baud rate (9600 default, 19200, 38400, 57600) and switches 3-4 the parity (none default, odd, even).

Communication loss & watchdog

Registers 21020-21025 define a fallback heat demand (keep, adjust or cancel) used when communication between the gateway and the BMS is lost, with a period in minutes in 21022.

Byte order & addressing

  • Reads use function 03; writes use 06 or 16. 8-bit values must still be read and written as whole registers.
  • Exception code 0x0B means the gateway has not yet read that value from the appliance; retry.

Network setup

  • Use the use-case tables (p. 15) to combine 256/257/258/259: e.g. 258 = 0, 256 = 60, 257 = 5000, 259 = 7 heats to 50 °C without exceeding 60 % power.
  • A zone is put in manual by writing 649 = 1 and a setpoint in 648 or 664.

Watch out for

  • The status LED blinks orange on a Modbus error; fixed red means no Modbus communication.

Notes on this map

  • UINT8 and ENUM8 values sit in the low byte of a 16-bit register (data-type table p. 8); they are listed as UINT16 here.
  • Left out: every UINT32/INT32 register (energy counters 419-451, power 460, zone pump counters 1115/1117, cascade 7151/7160/7162, serial 7228, service starts 516). The manual says 32-bit values take two registers but never says which word comes first.
  • Also left out because the manual contradicts itself or gives an impossible scale: 272 system power (1 % in one table, 0.01 % in another), 415 (labelled starts but scaled 0.1 µA), 514/515 (resolution printed as '2 hours'), 7166/7167 (UINT8 at 0.1 % over 0-100 %), 7203/7205 (no unit or scale).
  • Zone registers are listed for zone 1. In the manual's per-zone tables most zone registers step by 512 per zone (641, 1153, 1665 ...), but the activity, mode and pump registers jump after zone 6 (zone 7 1107-type at 5121, not 4179); use the manual's zone tables (pp. 16-21) for zones 2-12.
  • Cascade member registers 7111-7146 (power output, flow temperature, status, special request per member) are left out: the manual gives their addresses but no data type, scale or coding.
  • Register 411 main status uses table 16 of the manual; cascade state 7159 and producer status 7209 use table 47, which has the same codes plus 14 (custom load test). Sub status 412 has a long code list in table 17 of the manual.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Remeha GTW-08 Modbus gateway for Remeha / De Dietrich appliances

What Modbus registers does the Remeha GTW-08 Modbus gateway for Remeha / De Dietrich appliances have?

This map lists 109 registers: 109 holding registers. 35 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Remeha GTW-08 Modbus gateway for Remeha / De Dietrich appliances Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual's read example sends start register 0x0020 and calls it register 32, so the decimal register numbers in the tables go on the wire unchanged.

What are the minimum Modbus registers to integrate the Remeha GTW-08 Modbus gateway for Remeha / De Dietrich appliances?

Start with HR 400 Flow temperature (AM016) (Flow temperature); HR 401 Return temperature (AM018) (Return temperature); HR 409 Primary circuit water pressure (AM019) (Water pressure); HR 411 Appliance main status (AM012) (Main status); HR 531 Current error present (Any error present); HR 258 Algorithm type (Control mode (monitor / power / temperature)); HR 257 System temperature request (Temperature request); HR 259 Heat demand type (Heat demand type).

How do I enable Modbus control of the Remeha GTW-08 Modbus gateway for Remeha / De Dietrich appliances?

Connect the GTW-08 to the appliance L-Bus. Rotary knob 0-F sets the Modbus address 100-115 (default 100). DIP switches 1-2 set the baud rate (9600 default, 19200, 38400, 57600) and switches 3-4 the parity (none default, odd, even).

What happens when the Remeha GTW-08 Modbus gateway for Remeha / De Dietrich appliances loses Modbus communication?

Registers 21020-21025 define a fallback heat demand (keep, adjust or cancel) used when communication between the gateway and the BMS is lost, with a period in minutes in 21022.
