Integration notes: IME Nemo D4-Le with Rogowski coil input (KRNEMOD4)

Integration in brief

Read holding registers (function 03) from 0x1000 for voltages and currents in mV/mA, and from 0x1500 (or 0x1700) for signed powers and energies in fixed units. Double words are high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the address, baud rate and parity on the meter (both are programmable). Only functions 03 and 0x10 are used. Setup writes need the unlock key 0x5AA5 written to 0x2700 first.

Byte order & addressing

  • Only functions 03 and 0x10 are supported (no function 04).
  • A single request may ask for at most 240 bytes of data.
  • Voltages and currents are in mV and mA.

Network setup

  • Baud rate and parity are programmable on the device; 8 data bits and 1 stop bit.

Watch out for

  • Power registers in the 0x10xx block change scale with the CT/VT ratio; prefer the 0x15xx block.

Notes on this map

  • Double-word values (UD_WORD/SD_WORD) are sent most significant word first; the protocol notes the meter can be set to big endian, little endian or swapped words, so check that setting if values look wrong.
  • Left out: power and energy registers whose unit is footnote (3) or (4); their scale depends on the CT x VT ratio (for example W/100 below a ratio product of 5000). The 0x15xx/0x17xx blocks give the same quantities in fixed units (W, var, Wh plus MWh).
  • Left out: setup parameters, device configuration words, the per-slot data areas, and any row whose printed unit does not fit the quantity (for example apparent power printed in W).
  • Energy in fixed units is split in two double words: a low part in Wh (varh) and a high part in MWh (Mvarh); total = high x 1,000,000 + low.
  • Left out: the printed last-harmonic addresses 0x72E4 and 0x7364 for phase 2 and 3 current, because they break the two-word step used everywhere else in the harmonic tables (0x72E2/0x7362 would be expected).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the IME Nemo D4-Le with Rogowski coil input (KRNEMOD4)

What Modbus registers does the IME Nemo D4-Le with Rogowski coil input (KRNEMOD4) have?

This map lists 149 registers: 149 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the IME Nemo D4-Le with Rogowski coil input (KRNEMOD4) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are the hex word addresses sent as 'first WORD address' in the function 03 request, so they go on the wire unchanged.

What byte order does the IME Nemo D4-Le with Rogowski coil input (KRNEMOD4) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the IME Nemo D4-Le with Rogowski coil input (KRNEMOD4)?

Start with HR 4096 Phase 1: phase voltage (Phase 1 voltage); HR 4102 Phase 1: current (Phase 1 current); HR 4134 Frequency (Frequency); HR 4132 3-phase: power factor (3-phase power factor); HR 5400 Signed 3-ph Active Power (Signed 3-phase active power); HR 5376 Positive Active Energy - Low (Positive active energy (Wh part)); HR 5378 Positive Active Energy - High (Positive active energy (MWh part)).

How do I enable Modbus control of the IME Nemo D4-Le with Rogowski coil input (KRNEMOD4)?

Set the address, baud rate and parity on the meter (both are programmable). Only functions 03 and 0x10 are used. Setup writes need the unlock key 0x5AA5 written to 0x2700 first.
