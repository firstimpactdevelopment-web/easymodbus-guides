What every map gives you

  • The address on the wire. Every register is listed by its 0-based protocol address, with the manual’s own 40001-style number beside it when the two differ — the off-by-one is settled for you.
  • Data type and word order. 16-bit, 32-bit, float or text, and for 32-bit values whether the high word comes first (ABCD) or second (CDAB).
  • Scale, units and access. The multiplier that turns the raw number into an engineering value, the units, and which registers are writable.
  • The source. A link to the manufacturer’s free public document, so you can check any row yourself, plus CSV and JSON downloads.

Before you connect

  • Get onto the same network as the equipment. Controls gear is usually on its own VLAN, and guest Wi-Fi will not reach it.
  • Modbus TCP is port 502. 503 and 5020 are both seen.
  • Finding equipment means sweeping the subnet, because Modbus devices never announce themselves. On a monitored network that looks like a port scan, so tell whoever runs it.
  • Reading is harmless. Writing has no undo — no priorities, no timeout, no release. Read the writing guide before changing anything on live equipment.
