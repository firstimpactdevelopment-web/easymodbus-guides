Shinko Technos WCL-13A 2-channel digital indicating controller (C5 option) Modbus register map

Updated 17 November 2026

Short answer

The WCL-13A is a two-channel PID temperature controller (one unit, two loops); CH1 also has a heat/cool OUT2. With the C5 option it speaks Shinko protocol, Modbus ASCII or Modbus RTU on RS485, and all items are signed 16-bit holding registers. The map covers both channels' SV, PID, alarm and output settings, shared timer and transmission settings, and each channel's PV, MV, SV, heater current and status words.

This page lists 146 Modbus registers for the Shinko Technos WCL-13A 2-channel digital indicating controller (C5 option) — 130 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Shinko Technos’s own free documentation (linked below) and checked against it.

Integration notes: Shinko Technos WCL-13A 2-channel digital indicating controller (C5 option)

Integration in brief

Select Modbus RTU with an 8-bit format on the keypad and set an instrument number. Poll 0080H-0083H for CH1 and 0090H-0093H for CH2 (PV, MV, SV, status); write SVs at 0001H and 0051H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Requires the C5 option. Set Communication protocol to Modbus RTU and an 8-bit data bit/parity choice on the keypad, then the instrument number and speed.

Byte order & addressing

  • Factory data format is 7 bits/Even; RTU needs an 8-bit choice.
  • SV temporary storage (002BH/007BH) is lost at power off; use SV (0001H/0051H) for permanent changes.

Network setup

  • Factory defaults: Shinko protocol, instrument 0, 9600 bps, 7 bits/Even, 1 stop bit.
  • Speeds 9600, 19200, 38400 bps.

Watch out for

  • Non-volatile memory is rated about 1,000,000 writes; use the temporary SV for frequent setpoint changes.

Notes on this map

  • CH2 items sit 50H above the matching CH1 items (SV 0001H vs 0051H); CH1-only OUT2 items have no CH2 twin. Read-only blocks start at 0080H (CH1) and 0090H (CH2); alarm 2-4 blocks at 00D0H (CH1) and 00E0H (CH2).
  • All data are 16-bit two's complement. Values with a decimal point are sent as whole numbers; apply each channel's decimal point place.
  • Input type codes differ between the multi-range and infrared thermocouple input versions, so value names are not listed.
  • PV may carry a difference or addition value when that block function is enabled in the console software.
  • Instrument number and speed can only be set on the keypad.

Questions about the Shinko Technos WCL-13A 2-channel digital indicating controller (C5 option)

What Modbus registers does the Shinko Technos WCL-13A 2-channel digital indicating controller (C5 option) have?

This map lists 146 registers: 146 holding registers. 130 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos WCL-13A 2-channel digital indicating controller (C5 option) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are listed as hex data items (0001H) that go into the request unchanged. The manual's RTU example reads CH1 SV with data item 0001H, and its CRC (D5CAH) confirms 0001H is the wire address.

What are the minimum Modbus registers to integrate the Shinko Technos WCL-13A 2-channel digital indicating controller (C5 option)?

Start with HR 128 CH1 PV (CH1 PV); HR 131 CH1 Status flag (CH1 status); HR 144 CH2 PV (CH2 PV); HR 147 CH2 Status flag (CH2 status); HR 1 CH1 SV (CH1 SV); HR 81 CH2 SV (CH2 SV).

How do I enable Modbus control of the Shinko Technos WCL-13A 2-channel digital indicating controller (C5 option)?

Requires the C5 option. Set Communication protocol to Modbus RTU and an 8-bit data bit/parity choice on the keypad, then the instrument number and speed.
