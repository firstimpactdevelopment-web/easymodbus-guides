Short answer

TriVibe is a triaxial vibration and temperature sensor that talks Modbus RTU on RS-485 at 115200 baud. Overall acceleration, velocity and displacement per axis are 32-bit floats, high word first. This map covers system status, run time, temperature, overall vibration values from the external and internal accelerometers, alarm states and the four configurable alarm channels.

Integration notes: Machine Saver TriVibe vibration and temperature sensor (Modbus RTU)

Integration in brief

Poll at 115200 8N1 using the slave ID from the serial number label. Read FC03 block 172-189 for overall vibration and 226-229 for alarm states; write with FC16 only.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is always on. Configuration and alarm registers are locked until the matching unlock command is written to SYSTEM_CONTROL (register 1), and must be saved with the matching save command.

Byte order & addressing

  • Only FC03 and FC16 are supported; write single registers with FC16 and a length of 1.
  • Floats are high word first (ABCD).
  • Default slave ID is not 1: it is the last two digits of the serial number.

Network setup

  • Serial: 115200 baud, no parity, 8 data bits, 1 stop bit, no handshake.
  • Each sensor on a multi-drop bus needs a unique slave ID.

Watch out for

  • Writing the wrong SYSTEM_CONTROL value can reset the sensor or erase its EEPROM.

Notes on this map

  • 32-bit values are listed as a HIGH_ register followed by a LOW_ register, and the page says the sensor is big-endian, so the high word is at the lower address (ABCD).
  • The default slave ID is the last two digits of the sensor's serial number (white label on the side).
  • Left out: the dynamic data clip registers (49-171), DDR/capture engine controls, detonation and impact alert counters, unique ID words and sensitivity calibration registers - they are for waveform capture or factory use.
  • TEMPERATURE (31) is divided by 10; the page does not give the unit.
  • Units for alarm levels follow the alarm type (velocity, acceleration, displacement or temperature) chosen in ALARMn_TYPE.
  • Alarm configuration writes need the alarm registers unlocked (SYSTEM_CONTROL = 42074) and saved afterwards (42075).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Machine Saver TriVibe vibration and temperature sensor (Modbus RTU)

What Modbus registers does the Machine Saver TriVibe vibration and temperature sensor (Modbus RTU) have?

This map lists 78 registers: 78 holding registers. 27 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Machine Saver TriVibe vibration and temperature sensor (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The page states the listed registers are 0-indexed; use the number unchanged on the wire.

What byte order does the Machine Saver TriVibe vibration and temperature sensor (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Machine Saver TriVibe vibration and temperature sensor (Modbus RTU)?

Start with HR 178 Axis 1 velocity (Axis 1 velocity); HR 180 Axis 2 velocity (Axis 2 velocity); HR 182 Axis 3 velocity (Axis 3 velocity); HR 172 Axis 1 acceleration (Axis 1 acceleration); HR 31 TEMPERATURE (Temperature); HR 226 ALARM_1_STATE (Alarm 1 state); HR 4 SYSTEM_STATE2 (System state flags).

How do I enable Modbus control of the Machine Saver TriVibe vibration and temperature sensor (Modbus RTU)?

Modbus RTU is always on. Configuration and alarm registers are locked until the matching unlock command is written to SYSTEM_CONTROL (register 1), and must be saved with the matching save command.
