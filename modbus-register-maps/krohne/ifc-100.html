Short answer

This map covers flow, temperature, conductivity and diagnosis floats, the two double-float totalisers, counter and filter settings, calibration values, serial parameters and the control coils.

Integration notes: KROHNE IFC 100 electromagnetic flow converter (Modbus RTU)

Integration in brief

Read input registers 30000-30027 (function 04) in one block for flow speed, volume and mass flow, temperature and the two double-float counters. Use coils (function 05) for counter start/stop/reset and error reset.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the Modbus slave address, baud rate, parity, data format and stop bits in converter menu C5.8 (or holding registers 50000-50004).

Byte order & addressing

  • Addresses are protocol addresses sent as printed (30000 is sent as 30000).
  • Low mirror addresses exist for masters limited to 9999.
  • Counters are 64-bit doubles.

Network setup

  • Defaults 19200 baud, even parity, 1 stop bit, address 1.
  • Terminate both bus ends with 120 Ohm and bias the line at one point.

Watch out for

  • New calibration values take effect only after a warm start (coil 1001), which takes up to 5 s.
  • Write the conductivity target to both 43034 and 43036.

Notes on this map

  • Data format is selectable (C5.8.4 or holding 50004): Big Endian, which the manual defines as MSB first for the data bytes, is the default, so 32-bit floats and 64-bit doubles are listed ABCD. With Little Endian (LSB first) selected the whole value is byte-reversed. The manual gives no worked byte example.
  • Input registers 30000-30034 can also be read at 0-34, and holding registers 40000-49998 at 0-9998; only the primary addresses are listed.
  • Left out: long status sensor/device (30032 / 30034, byte[4]) because the bit meanings are not given in this document; 'no function' and 'not used' registers.
  • Factory serial settings: address 1, 19200 baud, even parity, 1 stop bit, Big Endian, 0 ms response delay.
  • byte and word types in the holding tables each occupy one register and are listed as UINT16.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the KROHNE IFC 100 electromagnetic flow converter (Modbus RTU)

What Modbus registers does the KROHNE IFC 100 electromagnetic flow converter (Modbus RTU) have?

This map lists 63 registers: 10 coils, 12 input registers, 41 holding registers. 51 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the KROHNE IFC 100 electromagnetic flow converter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists protocol addresses and says they go into the request unchanged: input register 30006 is requested as start address 30006 (0x7536). The same registers are mirrored lower for masters that cannot use high addresses (30000-38998 -> 0-8998, 20000-20998 -> 9000-9998, 40000-49998 -> 0-9998).

What byte order does the KROHNE IFC 100 electromagnetic flow converter (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the KROHNE IFC 100 electromagnetic flow converter (Modbus RTU)?

Start with IR 30002 Volume flow (Volume flow); IR 30004 Mass flow (Mass flow); IR 30000 Flow speed (Flow speed); IR 30020 Counter 1 (Counter 1); IR 30024 Counter 2 (Counter 2); IR 30006 Coil temperature (Coil temperature).

How do I enable Modbus control of the KROHNE IFC 100 electromagnetic flow converter (Modbus RTU)?

Set the Modbus slave address, baud rate, parity, data format and stop bits in converter menu C5.8 (or holding registers 50000-50004).

Where is the official KROHNE IFC 100 electromagnetic flow converter (Modbus RTU) Modbus documentation?

The source is IFC 100 Supplementary instructions - Description of Modbus interface (4001410101 R01), revision 2014-08, published free by KROHNE at https://cdn.krohne.com/archive/AD_IFC100_Modbus_en_140728_4001410101_R01.pdf.
