Short answer

The JCL-33A is a digital indicating temperature controller; with the C5 option it talks Shinko protocol, Modbus ASCII or Modbus RTU over RS485. Every value is a signed 16-bit holding register. This map covers the set value, PID and alarm settings, input type, run/stop, program steps, PV, MV and the status flags.

Integration notes: Shinko Technos JCL-33A digital indicating controller (C5 option)

Integration in brief

Pick Modbus RTU in Auxiliary function setting mode 1, give each unit a non-zero instrument number, then read PV at 0080H and status at 0085H with function 03; write SV1 at 0001H with function 06.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Requires the C5 communication option. Set Communication protocol to Modbus RTU (not the Block Read/Write variant) in Auxiliary function setting mode 1, then instrument number, speed, parity and stop bit.

Byte order & addressing

  • Instrument number 0 is the factory default but is the Modbus broadcast address, so set 1-95 before polling.
  • Writable registers accept writes even when the keypad set value lock is on.
  • ON/OFF register 0037H: 0 = ON (STOP), 1 = OFF (RUN).

Network setup

  • Factory defaults: Shinko protocol, instrument 0, 9600 bps, even parity, 1 stop bit.
  • Modbus RTU uses 8 data bits; parity and stop bit are selectable.
  • Up to 31 units per RS485 line, 1.2 km maximum.

Watch out for

  • Settings are stored in non-volatile memory rated for about 1,000,000 writes; don't write SV cyclically.
  • Undefined data items may return random data or errors; use only listed items.

Notes on this map

  • This map is for the plain 'Modbus RTU mode' / 'Modbus ASCII mode' protocol setting. The 'Block Read/Write available' protocol settings use a different register layout (section 7.2 of the manual) and are not covered here.
  • All data are 16-bit; negatives are two's complement. Values with a decimal point are sent as whole numbers, so apply the decimal point place (001AH) or the input type range.
  • Units of PID times, cycles and MV are not printed in the command table; they match the keypad settings described in the main instruction manual.
  • Protocol, instrument number, speed, parity and stop bit can only be set from the keypad, not over Modbus.
  • Writes during keypad setting mode return exception 18 (12H); writes the unit cannot accept now (e.g. during AT) return exception 17 (11H).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Shinko Technos JCL-33A digital indicating controller (C5 option)

What Modbus registers does the Shinko Technos JCL-33A digital indicating controller (C5 option) have?

This map lists 61 registers: 61 holding registers. 54 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos JCL-33A digital indicating controller (C5 option) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are listed as hex data items (0001H) that go into the request unchanged. The manual adds that the matching Modicon holding-register number is the item in decimal plus 40001 (0001H = 40002).

What are the minimum Modbus registers to integrate the Shinko Technos JCL-33A digital indicating controller (C5 option)?

Start with HR 128 PV (Process value); HR 1 SV1 (Set value SV1); HR 129 OUT1 MV (OUT1 manipulated value); HR 133 Status flag (Output/alarm/error status bits); HR 55 ON/OFF (RUN/STOP) (Control on/off (run/stop)); HR 26 Decimal point place (Decimal point for scaling).

How do I enable Modbus control of the Shinko Technos JCL-33A digital indicating controller (C5 option)?

Requires the C5 communication option. Set Communication protocol to Modbus RTU (not the Block Read/Write variant) in Auxiliary function setting mode 1, then instrument number, speed, parity and stop bit.

Where is the official Shinko Technos JCL-33A digital indicating controller (C5 option) Modbus documentation?
