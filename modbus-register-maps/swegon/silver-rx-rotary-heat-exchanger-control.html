Short answer

SILVER C RX air handling units use a separate controller to drive the rotary heat recovery wheel. It is a Modbus RTU slave with coils for start/stop, alarm reset and settings, discrete inputs for rotor-guard and drive alarms, input registers for output, motor and rotor speed, current, power, temperature and versions, and holding registers for the speed set point, speed limits, ramps and alternative communication settings.

This page lists 57 Modbus registers for the Swegon SILVER C / SILVER RX rotary heat exchanger controller (Modbus RTU) — 25 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Swegon’s own free documentation (linked below) and checked against it.

Integration notes: Swegon SILVER C / SILVER RX rotary heat exchanger controller (Modbus RTU)

Integration in brief

Set coil 7 (Control mode) to 0 for Modbus, write the speed set point to holding 0 and start with coil 0. Read input registers 2 (output %), 16 (rotor speed) and the discrete-input alarms 0-15.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Coil 7 Control mode: 0 = Modbus, 1 = 0-10 V (factory 1). Communication settings are changed over Modbus with a tool.

Byte order & addressing

  • Write coils with 0xFF00 for ON (function 05).
  • With Autodetect communication on (coil 9, default), the controller keeps answering on ID 79 / 38400 / no parity even after switching to the alternative settings.

Network setup

  • Default ID 79, 38400 baud, no parity, 1 stop bit.
  • Alternative ID, baud, parity and stop bits are in holding 13-16 and take effect when coil 8 is set.

Watch out for

  • This is the rotor drive controller only, not the AHU's main controller.

Notes on this map

  • Coil and discrete-input tables print the address in decimal and the register reference with a 0x/1x prefix in decimal (e.g. 0x0010 = address 9); input and holding tables print the address in hex.
  • The last coil is printed with register '0xx17' and address 17; the address column is used.
  • Page 2 has a second communication table (address 54, even parity, 2 stop bits); the 'Modbus addressing' section and the footnote on p. 3 both give ID 79, 38400 baud, no parity, 1 stop bit, which are used as defaults here.
  • Intern Temp (range -50.00 to 150.00 °C) is typed INT16; the sheet does not state signedness.
  • Footnote 4 on I Ripple is not printed in the sheet.
  • All values are 16-bit; there are no 32-bit registers.
  • Input registers printed 3x0020-3x0029 (MOC Boot SW, motor/rotor/user-data config variant and version, V DC Bus peak, V Motor peak) are left out: from that row on the sheet's hex Address column equals the register number instead of one lower (3x0020 is printed with 0x0014), so the wire address cannot be settled.
  • Speed registers are listed at 0.01 rpm, which applies with coil 14 High speed resolution = 1 (factory setting); with coil 14 = 0 the resolution is 0.1 rpm.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Swegon SILVER C / SILVER RX rotary heat exchanger controller (Modbus RTU)

What Modbus registers does the Swegon SILVER C / SILVER RX rotary heat exchanger controller (Modbus RTU) have?

This map lists 57 registers: 11 coils, 16 discrete inputs, 16 input registers, 14 holding registers. 25 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Swegon SILVER C / SILVER RX rotary heat exchanger controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each table prints a register reference (0x0001, 1x0001, 3x0001, 4x0001) and an Address column one lower (0, or 0x0000 in hex). The Address column is the wire address: 4x0001 Setpoint is holding address 0.

What are the minimum Modbus registers to integrate the Swegon SILVER C / SILVER RX rotary heat exchanger controller (Modbus RTU)?

Start with CO 0 Motor ON/OFF (Motor on/off); CO 7 Control mode (Control mode Modbus / 0-10 V); HR 0 Setpoint / PrcSet (Speed set point); IR 2 PrcOut (Output %); IR 16 Rotor Speed Out (Rotor speed); DI 0 Rotorguard Alarm (Rotor guard alarm); DI 10 Internal Stop (Rotor blocked); CO 1 Reset Alarms (Reset alarms).

How do I enable Modbus control of the Swegon SILVER C / SILVER RX rotary heat exchanger controller (Modbus RTU)?

Coil 7 Control mode: 0 = Modbus, 1 = 0-10 V (factory 1). Communication settings are changed over Modbus with a tool.
