Updated 17 November 2026

Short answer

ABB's ACS310 is a compact drive for pumps and fans with Modbus RTU built in on its I/O terminals. Every value is a 16-bit holding register: 40001-40006 carry the ABB Drives control word, two references, status word and two selectable actual values, 40031-40034 the DCU profile words, and each parameter NNNN sits at register 4NNNN. This map covers the control block, the main actual signals, fault and alarm words, fault history and the communication set-up parameters.

Integration notes: ABB ACS310 pump and fan drive (embedded Modbus RTU)

Integration in brief

Set 9802 = STD MODBUS and the group 53 link settings, then 5305 = ABB DRV FULL, point 1001 EXT1 COMMANDS and 1103 REF1 SELECT at COMM, write the control word and REF1 at 40001/40002 and poll the status word plus 0103/0104 at 40103/40104.

Enable Modbus control & writes

Set 1611 PARAMETER VIEW = LONG VIEW, then 9802 COMM PROT SEL = STD MODBUS (EIA-485 on terminals 23-26) or MODBUS RS232 (panel connector). Set 5302 station ID, 5303 baud, 5304 parity and 5305 profile. For control set 1001 EXT1 COMMANDS = COMM (1002 for EXT2), 1103 REF1 SELECT = COMM, and optionally 1102, 1601 RUN ENABLE and 1604 FAULT RESET SEL = COMM. Save fieldbus parameter writes with 1607 PARAM SAVE.

Communication loss & watchdog

3018 COMM FAULT FUNC (NOT SEL default / FAULT / CONST SP 7 / LAST SPEED) after the delay in 3019 COMM FAULT TIME (default 3.0 s, 0.1 s steps). FAULT trips SERIAL 1 ERR and coasts; the other two raise alarm IO COMM and keep running.

Byte order & addressing

  • Register 4xxxx is wire address xxxx - 1 (40001 = 0); parameter NNNN is register 4NNNN.
  • Everything is 16-bit; there is no word order to worry about.
  • Start per the state diagram (p. 306): write 0x0476 (ready to switch on), then 0x0477 once status bit 0 is 1 (ready to operate), then 0x047F to run; bits 4 and 10 in these values only matter with ABB DRV FULL. Control word bit 3 also needs the run enable (1601). Fault reset is a 0->1 edge on bit 7 with 1604 = COMM.
  • Parameter writes over Modbus are volatile until 1607 PARAM SAVE is used.

Network setup

  • Parameter-list defaults: station 1, 9.6 kbit/s, 8 data bits, no parity, 1 stop bit.
  • The RS-232 option uses the control panel connector.

Watch out for

  • Reading or writing a register that is not a parameter returns exception 02; writing a read-only parameter, an out-of-range value, or a parameter while started returns exception 03.
  • With the default ABB DRV LIM profile, control word bits 4 and 10 are ignored.

Notes on this map

  • There are no 32-bit registers: the manual states all values read or written are limited to 16 bits (-32768...32767). Signals that can be negative are listed as INT16.
  • Scaling is the manual's FbEq column (fieldbus integer per unit, e.g. '1 = 0.1 Hz' -> scale 0.1).
  • 40001 and 40004 work only with 5305 = ABB DRV LIM or ABB DRV FULL; 40031-40034 only with 5305 = DCU PROFILE. Control word bits 4 and 10 work only with ABB DRV FULL.
  • Actual values 40005-40012 follow 5310-5317 (all default 0 in the parameter list). Their scaling is that of the chosen signal, so they are left unscaled; 40007-40012 are not listed.
  • Reference scaling (ABB Drives profile): REF1 20000 = 1105 REF1 MAX, REF2 10000 = 1108 REF2 MAX; final references are limited by 1104/1105 and 1107/1108.
  • Group 03 fault and alarm words are listed read-only, but the manual says an alarm can be cleared by writing zero to the whole alarm word.
  • Left out: analog I/O, PID and process-variable signals (0116-0139, units depend on configuration), 0402/0403 fault time stamps, 0409 status at fault, energy-saving counters, 40080-40089 Modbus data OUT, and all motor/application parameters.
  • Coils (control-word bits 1-16, relay outputs from 33), discrete inputs and two input registers (analog inputs) are mentioned in the function code table but not listed here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ABB ACS310 pump and fan drive (embedded Modbus RTU)

What Modbus registers does the ABB ACS310 pump and fan drive (embedded Modbus RTU) have?

This map lists 57 registers: 57 holding registers. 15 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB ACS310 pump and fan drive (embedded Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists 4xxxx holding registers and states that register 4xxxx is sent as xxxx - 1 in the Modbus message (its example: 40002 is addressed as 0001), so 40001 = wire address 0. Parameter NNNN sits at register 4NNNN (e.g. 0103 -> 40103, wire 102; 3018 -> 43018, wire 3017).

What are the minimum Modbus registers to integrate the ABB ACS310 pump and fan drive (embedded Modbus RTU)?

Start with HR 0 Control word (ABB Drives) (Control word: start/stop/reset); HR 1 Reference 1 (REF1) (REF1 frequency setpoint (20000 = 1105)); HR 3 Status word (ABB Drives) (Status word: ready/running/fault/remote); HR 102 0103 Output freq (0103 Output frequency, 0.1 Hz); HR 103 0104 Current (0104 Motor current, 0.1 A); HR 106 0107 DC bus voltage (0107 DC bus voltage); HR 400 0401 Last fault (0401 Last fault code); HR 304 0305 Fault word 1 (0305 Fault word 1).
