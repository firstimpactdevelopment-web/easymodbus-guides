Short answer

ABB's older industrial AC drive family. Modbus RTU is added with the RMBA-01 adapter module, which the firmware calls the Standard Modbus Link. The drive exposes two three-word data sets in each direction: control word, two references and three auxiliary references from the master, and status word plus five actual values back. This map covers those twelve holding registers with the ABB Drives control and status word bits.

Integration notes: ABB ACS800 drive, Standard Control Program 7.x (RMBA-01 Standard Modbus Link)

Integration in brief

Fit the RMBA-01, set 98.02 = STD MODBUS and 98.07 = ABB DRIVES, then set station, baud and parity in group 52. Write the control word and REF1 at 40001/40002 and poll the status word and actual values at 40004-40006; pick what the actuals carry with parameters 92.02-92.06.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Install the RMBA-01 in slot 1 or 2. Set 98.02 Comm. module link = STD MODBUS (this activates group 52) and 98.07 = ABB DRIVES. Set 52.01 station number (1-247), 52.02 baud rate (600-19200) and 52.03 parity. For fieldbus control set the control-location parameters (10.01/10.02 = COMM.CW) and the reference selection (11.03 = COMM.REF1, 11.06 = COMM.REF2). Parameter writes are saved to permanent memory with 16.07 = SAVE.

Communication loss & watchdog

30.18 COMM FAULT FUNC picks the action when the main or auxiliary reference data set stops arriving: FAULT (trip, coast), NO, CONST SP 15 (warning, run at par. 12.16) or LAST SPEED (warning, hold 10 s average speed). 30.19 sets the main data set delay (0.1-60 s), 30.21 the auxiliary data set delay, and 30.20 decides whether fieldbus-driven relay and analogue outputs go to zero or hold their last value.

Byte order & addressing

  • Only twelve words exist on the Standard Modbus Link: 40001-40003 and 40007-40009 are written by the master, 40004-40006 and 40010-40012 are read from the drive.
  • References and actual values are scaled integers, not engineering units: 20000 equals the maximum set in group 11 for speed/frequency references.
  • Status word bits 10, 13 and 14 are user-assignable through parameters 92.07-92.09.

Network setup

  • Modbus RTU only; the RMBA-01 does not do Modbus TCP.
  • Set 52.01 station number, 52.02 baud and 52.03 parity (NONE1STOPBIT, NONE2STOPBIT, ODD, EVEN) to match the master.
  • With 98.02 = CUSTOMISED, 90.04 = 81 and 90.05 = 83 select the Standard Modbus data sets as the main and auxiliary reference sources.

Watch out for

  • Bit 10 REMOTE_CMD must be 1 for the fieldbus to command the drive; with it at 0 and a non-zero control word or reference, the drive keeps the last values.
  • Starting follows the ABB Drives state machine: first a word with bit 10 set and bits 1-2 set but bit 0 clear (ready to switch on), then bit 0, then bit 3, then bits 4-6 to reach OPERATING.
  • REF3 bits 13-15 can drive relay outputs RO1-RO3 (14.01-14.03 = COM.REF3), and REF4/REF5 can drive AO1/AO2 (15.01 = COMM.REF4, 15.06 = COMM.REF5, 20000 = 20 mA).

Notes on this map

  • Only the twelve data-set words that the manual maps to Modicon addresses are listed. The manual gives no Modbus address rule for reaching other drive parameters through the RMBA-01, so none are listed.
  • Actual values 1-5 and the destinations of references 3-5 are user-selected through parameters 92.02-92.06 and 90.01-90.03 (format xxyy = group and index), so their meaning and scaling depend on the drive setup and they are left unscaled.
  • Control and status word bits are for parameter 98.07 = ABB DRIVES. With the Generic Drive profile the manual says only Rxxx adapters are supported, and with CSA 2.8/3.0 a different word layout applies (not listed).
  • REF1/REF2 scaling is the ABB Drives profile scaling: for speed or frequency 20000 corresponds to parameter 11.05 (REF1) or 11.08 (REF2); for torque and PID references the manual gives other end points per macro (10000 or 20000 = par. 11.08).
  • Station number, baud rate and parity are set in parameters 52.01-52.03; the manual does not print their factory values, so the defaults are left empty.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ABB ACS800 drive, Standard Control Program 7.x (RMBA-01 Standard Modbus Link)

What Modbus registers does the ABB ACS800 drive, Standard Control Program 7.x (RMBA-01 Standard Modbus Link) have?

This map lists 12 registers: 12 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB ACS800 drive, Standard Control Program 7.x (RMBA-01 Standard Modbus Link) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual places the data words at Modicon references 40001-40012, so 40001 (control word) is wire address 0 and 40004 (status word) is wire address 3.

What are the minimum Modbus registers to integrate the ABB ACS800 drive, Standard Control Program 7.x (RMBA-01 Standard Modbus Link)?

Start with HR 0 Control Word (Control word: start/stop/reset); HR 1 Reference 1 (Reference 1 (20000 = par. 11.05 for speed/frequency)); HR 3 Status Word (Status word: ready/running/fault/remote); HR 4 Actual 1 (Actual 1 (selected by 92.02)); HR 5 Actual 2 (Actual 2 (selected by 92.03)).
