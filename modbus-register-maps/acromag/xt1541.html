Integration notes: Acromag BusWorks XT1541-000 8-channel voltage output + 4 digital I/O (Modbus TCP)

Integration in brief

Write holding registers 1-8 with normalized counts (30000 = full scale of the selected range) to set the eight voltage outputs; drive digital outputs with coils 0-3 or holding register 0 depending on the configured mode.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP needs no enabling; set the IP address (default static 192.168.1.100), output ranges and coil-versus-holding mode with the USB configuration software.

Communication loss & watchdog

Each digital I/O channel has a watchdog time (1-65534 s, 0 or 65535 = off) and watchdog state (on/off) set in the USB software; with no read/write activity for that time the output goes to its watchdog state. The manual describes no watchdog for the analog outputs.

Byte order & addressing

  • Digital outputs are off (40001 reads 0) after reset.
  • Coil access and holding-register access to the digital outputs are mutually exclusive.

Network setup

  • Digital outputs need excitation on EXC to work.

Watch out for

  • If a digital output is on, the paired input reads high; turn the output off to monitor a field signal on that channel.

Notes on this map

  • Analog outputs are normalized counts: -30000 to +30000 = -100 % to +100 % of the selected ±10 V or ±5 V range (±20000 with legacy support). A 0-10 V signal on the ±10 V range is 0 to 30000.
  • Digital outputs are either coils 00001-00004 (coil option enabled) or bits 0-3 of holding register 40001 (coil option disabled), never both. With 40001, read the current states first and mask, because all four outputs are written at once.
  • The digital output register 40001 reads 0 after reset (outputs off) and is not kept in non-volatile memory.
  • The map prints the Modicon reference and a 0-based address column; the address column is sent on the wire.
  • There are no configuration registers: ranges, IP settings, coil-versus-holding mode and DIO watchdogs are set only with the USB configuration software.
  • The Unit ID is ignored and echoed back in Modbus TCP.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Acromag BusWorks XT1541-000 8-channel voltage output + 4 digital I/O (Modbus TCP)

What Modbus registers does the Acromag BusWorks XT1541-000 8-channel voltage output + 4 digital I/O (Modbus TCP) have?

This map lists 19 registers: 4 coils, 4 discrete inputs, 2 input registers, 9 holding registers. 13 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Acromag BusWorks XT1541-000 8-channel voltage output + 4 digital I/O (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register map prints both the reference (00001, 10001, 30001, 40001) and the 0-based address column; the address column is what goes on the wire.

What are the minimum Modbus registers to integrate the Acromag BusWorks XT1541-000 8-channel voltage output + 4 digital I/O (Modbus TCP)?

Start with HR 1 Set AO CH00 value (AO channel 0); HR 2 Set AO CH01 value (AO channel 1); HR 8 Set AO CH07 value (AO channel 7); HR 0 Set DO state CH0-3 (Digital outputs (holding mode)); IR 1 Heart beat (Heartbeat).

How do I enable Modbus control of the Acromag BusWorks XT1541-000 8-channel voltage output + 4 digital I/O (Modbus TCP)?

Modbus TCP needs no enabling; set the IP address (default static 192.168.1.100), output ranges and coil-versus-holding mode with the USB configuration software.

What happens when the Acromag BusWorks XT1541-000 8-channel voltage output + 4 digital I/O (Modbus TCP) loses Modbus communication?

Each digital I/O channel has a watchdog time (1-65534 s, 0 or 65535 = off) and watchdog state (on/off) set in the USB software; with no read/write activity for that time the output goes to its watchdog state. The manual describes no watchdog for the analog outputs.
