Short answer

The WM14 Advanced panel analyzer and the CPT-DIN Advanced DIN-rail transducer are older Carlo Gavazzi meters with an optional RS485 Modbus RTU port. Measurements are IEEE 754 floats sent low word first. This map covers voltages, currents, powers, PF, frequency, asymmetry, demand, max/min and THD values, the model code, alarm outputs, CT/VT ratio, integration times, serial settings and the reset command.

This page lists 84 Modbus registers for the Carlo Gavazzi WM14 Advanced / CPT-DIN Advanced power analyzer (legacy) — 9 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Carlo Gavazzi’s own free documentation (linked below) and checked against it.

Integration notes: Carlo Gavazzi WM14 Advanced / CPT-DIN Advanced power analyzer (legacy)

Integration in brief

Read input registers 0000h-003Fh in chunks of up to 12 registers and decode IEEE 754 floats low word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Needs the optional RS485 (S1) serial module; set the address (01A1h) and baud rate (01A2h) or use the front keys.

Byte order & addressing

  • Floats are CDAB.
  • Max 12 registers per request on RS485.
  • Some printed Modicon numbers are wrong; trust the hex address.

Network setup

  • 8 data bits, no parity, 1 stop bit; baud 4800-38400.

Watch out for

  • Energy counters are not in this map; see the notes.

Notes on this map

  • Float word order: the protocol lists the frame bytes as bits 15-8, 7-0, 31-24, 23-16 of the IEEE 754 value, i.e. low word first (CDAB).
  • Left out: the UINT32 energy counters and hour counter (0056h-005Fh). The word-order sentence covers only UINT16 and UINT64 integers, so the order of these 32-bit integers is not stated.
  • Left out: filter settings, system type (its value list is garbled in the source), output control and digital output/alarm blocks, analogue output setup and virtual alarm words.
  • Up to 12 registers per read on the RS485 port (28 on the CPT-DIN RS232 port).
  • Reads use function 03 or 04; writes use function 06.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Carlo Gavazzi WM14 Advanced / CPT-DIN Advanced power analyzer (legacy)

What Modbus registers does the Carlo Gavazzi WM14 Advanced / CPT-DIN Advanced power analyzer (legacy) have?

This map lists 84 registers: 75 input registers, 9 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Carlo Gavazzi WM14 Advanced / CPT-DIN Advanced power analyzer (legacy) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Rows give a 6-digit Modicon number (3xxxxx) and the hex physical address; the hex address goes in the frame, so 300001 / 0000h is wire address 0. A few printed Modicon numbers do not match their hex address (0058h is printed 300099, 01A8h is printed 300417); the hex value is used.

What byte order does the Carlo Gavazzi WM14 Advanced / CPT-DIN Advanced power analyzer (legacy) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Carlo Gavazzi WM14 Advanced / CPT-DIN Advanced power analyzer (legacy)?

Start with IR 0 V L1-N (V L1-N); IR 12 A L1 (A L1); IR 50 W system (W system); IR 56 PF system (PF system); IR 58 Frequency (Frequency); IR 211 Carlo Gavazzi identification code (Model code).

How do I enable Modbus control of the Carlo Gavazzi WM14 Advanced / CPT-DIN Advanced power analyzer (legacy)?

Needs the optional RS485 (S1) serial module; set the address (01A1h) and baud rate (01A2h) or use the front keys.

Where is the official Carlo Gavazzi WM14 Advanced / CPT-DIN Advanced power analyzer (legacy) Modbus documentation?
