Short answer

KELLER X-Line digital pressure transmitters (Series 30 and 40) speak both the KELLER bus protocol and Modbus RTU on the same RS-485 line. This map covers the Modbus process values (pressure P1/P2, temperatures and the calculated CH0 channel) as floats, x100 integers and 32-bit integers, the conductivity values of 5.21 devices, and the main configuration and status registers.

Integration notes: KELLER X-Line digital pressure transmitters, Series 30 / 40 (Modbus RTU)

Integration in brief

Read 4 registers from 0x0100 (function 03) for P1 and its temperature as ABCD floats, or 0x0002-0x000B for all process values. Use the x100 integers at 0x0010 if your master has no float support.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is always active alongside the KELLER protocol; no initialisation command is needed.

Byte order & addressing

  • Modbus CRC is sent low byte first; the KELLER protocol sends it high byte first.
  • Address 250 reaches any device regardless of its address (point-to-point use only).
  • Older firmware limits a read to 2 or 4 registers per request.

Network setup

  • Defaults: address 1, 9600 baud, 8N1. 115200 baud, parity and 2 stop bits are set in register 0x0200.

Watch out for

  • Single-register writes (function 06) are refused in the 0x03xx and 0xFFxx ranges and on float registers; use function 16.

Notes on this map

  • Floats and 32-bit integers are high word first (ABCD): the register map labels the first register HWord, the float chapter puts the exponent byte in register 0, and the worked P1 read returns 3F 75 F0 7B = 0.9607 bar.
  • Each channel must be read in one request starting on an even address; an odd start returns exception 2.
  • Inactive channels read NaN (float), 32767 (16-bit) or 2147483647 (32-bit); over/underflow reads +/- infinity in the float range.
  • Which ranges exist depends on firmware: 32-bit integers need 5.20-12.28 or later; 16-bit integers work on 5.20-5.50 and on 5.20-12.28 or later but not on 5.20-10.40; the 0x0100 block and the 0x02xx configuration range need 5.20-10.40 or later.
  • Left out: the coefficient ranges (0x03xx, 0x3xxx, 0x40xx), command registers above 0xFF00, conductivity range/compensation settings and the ASCII serial number.
  • The KELLER bus protocol (functions 30-100) runs on the same line; this map covers only the Modbus functions 3, 6, 8 and 16.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the KELLER X-Line digital pressure transmitters, Series 30 / 40 (Modbus RTU)

What Modbus registers does the KELLER X-Line digital pressure transmitters, Series 30 / 40 (Modbus RTU) have?

This map lists 40 registers: 40 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the KELLER X-Line digital pressure transmitters, Series 30 / 40 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The document gives the start address (StAdd) in hex exactly as it goes into the request; its example reads P1 with start address 0x0002.

What byte order does the KELLER X-Line digital pressure transmitters, Series 30 / 40 (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the KELLER X-Line digital pressure transmitters, Series 30 / 40 (Modbus RTU)?

Start with HR 2 P1 pressure (Pressure P1 (bar)); HR 8 TOB1 sensor 1 temperature (Sensor temperature); HR 256 P1 pressure (block 2) (P1 + TOB1 in one read); HR 524 Device status (Channel error bits); HR 17 P1 (integer x100) (P1 as x100 integer).

How do I enable Modbus control of the KELLER X-Line digital pressure transmitters, Series 30 / 40 (Modbus RTU)?

Modbus is always active alongside the KELLER protocol; no initialisation command is needed.
