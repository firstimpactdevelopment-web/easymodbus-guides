Buderus SSB condensing boilers (built-in Modbus RTU) Modbus register map

Updated 29 October 2026

Short answer

Buderus SSB floor-standing condensing boilers have a Modbus RTU slave on their own controller. Everything is a 16-bit holding register: burner state, status and error code, pump outputs, supply/return/DHW/flue temperatures, firing rate, counters, lockout and blocking history, cascade dependents, and the CH, DHW and outdoor-reset setpoints. Writes need a write-enable bit set just before each write.

This page lists 50 Modbus registers for the Buderus SSB condensing boilers (built-in Modbus RTU) — 10 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Buderus’s own free documentation (linked below) and checked against it.

Integration notes: Buderus SSB condensing boilers (built-in Modbus RTU)

Integration in brief

Wire Modbus + and - to the MOD BUS terminals of the boiler's terminal strip, set the master to 9600 8-N-2 and read holding registers 100-142 with function 03. To change a setpoint, first write register 99 = 1 (Write Enable), then write the value x10 within 4 seconds.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Writes are refused unless register 99 bit 0 (Write Enable) is set. The bit clears itself after each write sequence or after 4 seconds, so set it again before every write.

Communication loss & watchdog

If no Modbus read or write arrives for more than 4 seconds the control register 99 is cleared. No other comm-loss behaviour is documented.

Byte order & addressing

  • Only functions 03, 06 and 16 are supported - no input registers or coils.
  • Setting any undefined bit in register 99 clears the whole register.
  • Lockout reset (99 bit 14) works only while the boiler is in lockout.

Network setup

  • Slave address (default 1) and stop bits (1 or 2, default 2) are set with the 894PB tool or LabVision software.
  • Baud is fixed at 9600, 8 data bits, no parity.
  • RS-485 two-wire, ground optional: Modbus + and - go to the MOD BUS pair on the boiler terminal strip (terminals 3-4).

Watch out for

  • Do not leave Write Enable set when you are not writing; the document warns that registers can be corrupted.
  • Changing register 98 changes the units of every temperature you read and write.

Notes on this map

  • Scaling follows the document's data-type table: temperatures, pressures, voltages, flame current and percentages are sent x10 (one decimal). Registers marked 'automatic conversion' use it; state, status and error codes and the counters do not.
  • Temperatures follow the unit chosen in register 98 (°C or °F) for both reads and writes; the document does not say which bit value means which unit or what the default is, so check a known reading first.
  • The document never says whether values are signed. Outside temperature (125) and the outdoor reset-curve points (506 Outdoor Mild Weather, 507 Outdoor Design) can be below zero, so they are left out rather than guessed; the other temperatures are typed unsigned.
  • Left out: successful ignition counter 200 (printed with 'resolution 16', meaning not explained); CH mode 500 and DHW mode 501 (range '0..x' with no value list).
  • Only the first slot of the lockout and blocking histories is listed; slots 2-16 follow at consecutive addresses (lockouts 221-235, blockings 261-275). The history is not in order of occurrence.
  • Dependent registers 300-339 report the cascade dependents (01-07) in the same state/error code tables; the document leaves their access column blank, so they are listed read-only.
  • Left out: the 'time after lockout' (236-251) and 'time after blocking' (276-291) hour stamps. They are marked 'automatic conversion' yet hours are not one of the x10 data types in the document's data-type table, so their scaling is unclear; the burn-hour counters 203-204 carry no such mark.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Buderus SSB condensing boilers (built-in Modbus RTU)

What Modbus registers does the Buderus SSB condensing boilers (built-in Modbus RTU) have?

This map lists 50 registers: 50 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Buderus SSB condensing boilers (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The document prints decimal register numbers with their hex form (98 = 0x0062) and says to use them as printed when the master counts from 0x0000, and to add 1 only if the master counts from 0x0001. So register 100 is wire address 100.

What are the minimum Modbus registers to integrate the Buderus SSB condensing boilers (built-in Modbus RTU)?

Start with HR 101 Status (Boiler status); HR 102 Error code (Error code); HR 120 Supply temperature (Supply temperature); HR 121 Return temperature (Return temperature); HR 140 Firing rate (Firing rate); HR 502 CH set-point (CH setpoint); HR 503 DHW set-point (DHW setpoint); HR 99 Control register (Write enable / lockout reset).

How do I enable Modbus control of the Buderus SSB condensing boilers (built-in Modbus RTU)?

Writes are refused unless register 99 bit 0 (Write Enable) is set. The bit clears itself after each write sequence or after 4 seconds, so set it again before every write.

What happens when the Buderus SSB condensing boilers (built-in Modbus RTU) loses Modbus communication?

If no Modbus read or write arrives for more than 4 seconds the control register 99 is cleared. No other comm-loss behaviour is documented.

Where is the official Buderus SSB condensing boilers (built-in Modbus RTU) Modbus documentation?
