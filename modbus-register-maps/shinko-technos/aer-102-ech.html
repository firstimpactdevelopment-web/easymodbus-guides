Shinko Technos AER-102-ECH conductivity indicating controller (C5 option) Modbus register map

Updated 17 November 2026

Short answer

The AER-102-ECH measures electrical conductivity (or salinity/TDS) and temperature, and drives up to four event outputs and two transmission outputs. With the C5 option it speaks Shinko protocol or Modbus ASCII/RTU; every item is a signed 16-bit holding register. The map covers sensor and range setup, EVT1-EVT4 settings, temperature compensation, transmission outputs, calibration modes, user save area and the measured conductivity, temperature and status words.

Integration notes: Shinko Technos AER-102-ECH conductivity indicating controller (C5 option)

Integration in brief

Select MODBUS RTU in the Basic Function Group and give the unit a non-zero instrument number; then read conductivity 0080H, temperature 0090H and the status words 0081H and 0091H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Requires the C5 option. In the Basic Function Group choose Communication protocol = MODBUS RTU (or ASCII), then instrument number, speed, data bit/parity and stop bit; these are keypad-only.

Byte order & addressing

  • Instrument number 0 is the Modbus broadcast address; give each unit 1-95.
  • Use Lock 3 for frequently written values so non-volatile memory is not worn out (about one million writes).

Network setup

  • Factory defaults: Shinko protocol, instrument number 0, 9600 bps, 7 bits/even parity, 1 stop bit.
  • For Modbus RTU choose an 8-bit data format.
  • Do not fit a terminator; each unit has built-in pull-up/pull-down resistors.

Watch out for

  • Changing any EVT type resets all four EVT values to 0; write types first.
  • Writing transmission output 2 adjustment mode without the TA2 option returns exception 17 (11H).

Notes on this map

  • Function 03 reads and 06 writes; the manual's function column shows no multi-register write (10H).
  • All data are 16-bit two's complement and are sent without the decimal point.
  • Measurement range codes (0004H) are not listed: the list changes with sensor cell constant and unit.
  • The status bit values in 0081H bits 12-13 and 0091H bits 4-7/12-13 are two-bit fields; only the codes listed in the manual are shown as single bits.
  • EVT3/EVT4 and transmission output 2 items need their options; without them writes return exception 3 (some transmission output 2 items return exception 17).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Shinko Technos AER-102-ECH conductivity indicating controller (C5 option)

What Modbus registers does the Shinko Technos AER-102-ECH conductivity indicating controller (C5 option) have?

This map lists 164 registers: 164 holding registers. 156 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos AER-102-ECH conductivity indicating controller (C5 option) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are listed as hex data items (0001H) that go into the request unchanged. The manual adds that the matching Modicon holding-register number is the item in decimal plus 40001 (0001H = 40002). The manual's RTU example reads conductivity with data item 0080H (CRC 85E2H checked).

What are the minimum Modbus registers to integrate the Shinko Technos AER-102-ECH conductivity indicating controller (C5 option)?

Start with HR 128 Conductivity (Conductivity / salinity / TDS value); HR 144 Temperature (Temperature); HR 129 Status flag 1 (Sensor and range errors); HR 145 Status flag 2 (EVT output states); HR 4 Measurement range (Measurement range (sets decimal point)); HR 3 Measurement unit (Measurement unit).

How do I enable Modbus control of the Shinko Technos AER-102-ECH conductivity indicating controller (C5 option)?

Requires the C5 option. In the Basic Function Group choose Communication protocol = MODBUS RTU (or ASCII), then instrument number, speed, data bit/parity and stop bit; these are keypad-only.
