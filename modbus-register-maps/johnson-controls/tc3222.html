Integration notes: Johnson Controls PENN TC3222 refrigeration temperature controller (Modbus RTU)

Integration in brief

Set the LA (address) and Lb (baud) parameters, then poll holding registers with function 03: Probe 1 at 0x0201 (tenths), relay bits at 0x0181 and alarm bits at 0x0301. Write On/Standby (0x0501), the setpoint SP (0x0601, tenths) and trigger defrosts through 0x28B0.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is built in; set the Modbus address (LA) and baud rate (Lb) parameters at the controller.

Byte order & addressing

  • Use the hex Base 0 column as the wire address; the HR: column is 1-based.
  • Temperatures are in tenths; their printed ranges go below zero, so read them as signed (the guide does not state signedness).
  • Defrost command register takes 0Dh to start and 0Ch to stop a defrost.

Network setup

  • Address LA 1-247; baud Lb 0 = 2400, 1 = 4800, 2 = 9600, 3 = 19200.

Watch out for

  • Parameter register numbers differ between the TC3221, TC3222, TC3223 and TC3224 versions; use the map for the exact model.

Notes on this map

  • Source is Johnson Controls' own documentation portal (PENN Controls); a PDF of the guide is attached there.
  • '(0.1 resolution)' is taken as raw = value x 10 (scale 0.1); '1/10 sec', '10sec', '10 Minutes' and '100h' units are applied as multipliers 0.1 s, 10 s, 10 min and 100 h.
  • Signedness is not stated. Temperatures and probe readings, and parameters whose range goes negative, are typed INT16; others UINT16.
  • Temperatures follow parameter P2 (0 = °C, 1 = °F); units are shown as printed (°C).
  • The guide's Maximum and Minimum columns are swapped in places; ranges here are written low to high.
  • Bit points are grouped into one BITMAP16 per register (digital inputs, relay outputs, alarm flags, status flags). The status-flag registers mix read-only and read/write bits.
  • Left out: Defrost phase (HR:1368 bits 8-11, a multi-bit field), Time to next defrost (HR:1370, 0.25 resolution but no unit) and Time to defrost end (HR:1371, no unit), the four-register real-time clock, the UI password, and the firmware revision/variation byte fields.
  • Serial parity, stop bits and the factory address/baud are not stated; address (LA, 1-247) and baud (Lb, 2400-19200) are parameters in the list.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Johnson Controls PENN TC3222 refrigeration temperature controller (Modbus RTU)

What Modbus registers does the Johnson Controls PENN TC3222 refrigeration temperature controller (Modbus RTU) have?

This map lists 108 registers: 108 holding registers. 100 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Johnson Controls PENN TC3222 refrigeration temperature controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints every point twice: a hex 'Base 0' address (0201h) and a decimal 'Base 1' holding-register number (HR:514). The wire address is the Base 0 value (0x0201 = 513 = HR:514 - 1). Bit points are given as register.BitN.

What are the minimum Modbus registers to integrate the Johnson Controls PENN TC3222 refrigeration temperature controller (Modbus RTU)?

Start with HR 513 Probe 1 (Cabinet probe temperature); HR 1537 Setpoint (SP) (Control setpoint); HR 1281 On or standby (Run / standby command); HR 385 Digital outputs (Relay output states); HR 769 Alarm flags (Alarm and probe-failure flags); HR 10416 Defrost command (Start/stop a defrost (0Dh/0Ch)); HR 1544 Celsius or Fahrenheit (P2) (Temperature unit).

How do I enable Modbus control of the Johnson Controls PENN TC3222 refrigeration temperature controller (Modbus RTU)?

Modbus RTU is built in; set the Modbus address (LA) and baud rate (Lb) parameters at the controller.
