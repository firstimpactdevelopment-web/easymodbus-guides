Short answer

Armstrong's Design Envelope in-line pumps carry an integrated drive and pump controller that speaks Modbus RTU on RS-485 or Modbus TCP over Ethernet. The register map gives speed, voltage, run status and I/O, the engineering units in use, control mode, hand/off/auto, speed limits, a BMS speed command and start/stop. Power, flow, head, current, counters and alarm words are 32-bit in the manual and are left out here because their word order is not documented.

Integration notes: Armstrong Fluid Technology Design Envelope 4300 / 4380 with DEPM IVS / DE IVS drive (map v2)

Integration in brief

Select Modbus RTU or TCP/IP on the controller (touchscreen or web server) and set address, baud and parity/stop bits. Control is through HOA State (start address 301), BMS Set Speed (306) and Start/Stop (308); read actual speed (100/101), status (122) and control mode (300). Make sure the controller is set to BMS map version 2.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

From the touchscreen or the web server (firmware v1.36), choose Modbus RTU or Modbus TCP/IP and enter the Modbus address, baud rate and parity/stop bits. In the web server's Remote mode setting, pick BMS map version 2 to match this register list.

Byte order & addressing

  • The manual lists a 0-based start address next to a 1-based register number; use the start address on the wire.
  • Many values are in the units chosen on the Pump Control Module; read the unit registers (start 250-254) before interpreting them.
  • 32-bit values are not in this map because their word order is undocumented.

Network setup

  • RS-485: connect the BMS cable to the controller board RS-485 port (A = +, B = -, G = ground); set the terminating-resistor switch to Enabled only on the first and last device of the daisy chain.
  • Ethernet: connect the RJ-45 cable to the controller board.
  • Select the protocol and enter address, baud and parity/stop bits on the touchscreen or web server.

Watch out for

  • Check controller firmware first: the register map changed at v1.17.
  • Control Mode (300) is read-only over Modbus in map version 2.
  • The web server can switch the BMS register map between version 1 and version 2; the addresses here are version 2 only.

Notes on this map

  • Only function codes 03 (read) and 06 (write single) are listed in the map.
  • Left out because the manual does not state the 32-bit word order: Motor Power, Motor Input Current, Sensorless Head/Flow, Total Flow/Power, Max Sensorless Flow/Head, Analog In 1/2, the running-hour and kWh counters, the Alarms/Warnings/Acknowledge Warnings bit fields, the mode parameter sets (500-523) and Control Setpoint (539). All are 2-register UINT32 values in the manual; add them only once the word order is confirmed.
  • Firmware v1.16 and older use a different register map (version 1, manual p. 24-25); it is not covered here.
  • Hand Mode Speed and BMS Set Speed have 0.1 resolution in the unit configured on the controller; the Speed Units register (254) reports whether that is rpm or %. Minimum/Maximum Speed Limit are plain rpm.
  • Strings: Pump Name occupies 8 registers and Serial Number 7 registers of ASCII; byte order within each register is not stated.

Questions about the Armstrong Fluid Technology Design Envelope 4300 / 4380 with DEPM IVS / DE IVS drive (map v2)

What Modbus registers does the Armstrong Fluid Technology Design Envelope 4300 / 4380 with DEPM IVS / DE IVS drive (map v2) have?

This map lists 28 registers: 28 holding registers. 7 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Armstrong Fluid Technology Design Envelope 4300 / 4380 with DEPM IVS / DE IVS drive (map v2) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints both a 0-based 'start address' and a 1-based 'Modbus register' for every entry (e.g. Actual Speed start address 100, Modbus register 101). The register number is kept as 'documented'; the start address is the wire address.

What are the minimum Modbus registers to integrate the Armstrong Fluid Technology Design Envelope 4300 / 4380 with DEPM IVS / DE IVS drive (map v2)?

Start with HR 308 Start/Stop (Start/stop); HR 306 BMS Set Speed (BMS speed command); HR 301 HOA State (Hand/Off/Auto); HR 100 Actual Speed (rpm) (Actual speed (rpm)); HR 122 Status (Run status); HR 300 Control Mode (Control mode).

How do I enable Modbus control of the Armstrong Fluid Technology Design Envelope 4300 / 4380 with DEPM IVS / DE IVS drive (map v2)?

From the touchscreen or the web server (firmware v1.36), choose Modbus RTU or Modbus TCP/IP and enter the Modbus address, baud rate and parity/stop bits. In the web server's Remote mode setting, pick BMS map version 2 to match this register list.
