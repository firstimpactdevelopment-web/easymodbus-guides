Short answer

NURO is the boiler controller used on Patterson-Kelley (Harsco Industrial) commercial boilers, with an RS-485 Modbus RTU port for a building management system. All values are unsigned integers in holding registers. This map covers the boiler temperatures, analog I/O, digital I/O bit maps, active setpoints, demand source and status, boiler state, flame signal, firing rate and error code.

Integration notes: Patterson-Kelley NURO boiler controller (Modbus BMS port)

Integration in brief

Set MODBUS BMS BAUD RATE and MODBUS BMS SLAVE ADDRESS in the NURO menu, wire RS-485 at 8N2, and read holding registers 100-154 with FC 03. Temperatures are °C x10.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set MODBUS BMS BAUD RATE (9600, 19200 or 38400) and MODBUS BMS SLAVE ADDRESS under All Parameters > Boiler Parameters > General Boiler Settings.

Byte order & addressing

  • 0-based addresses; 40001 + register in 4xxxx tools.
  • Firing rate 0-200 = 0-100 %.
  • Fixed format 8 data bits, no parity, 2 stop bits.

Network setup

  • RS-485 two-wire.
  • With several NUROs on one bus, wait 20 ms when switching between slave addresses.

Watch out for

  • Temperature registers return 32768-34048 when a sensor is shorted, open or out of range.

Notes on this map

  • Source host: an unaltered extract of the Patterson-Kelley guide hosted by Contemporary Controls; we did not find a public manufacturer copy.
  • Word order: the guide says 32-bit values are sent in two registers and the total is first register x 65536 + second register, so high word first (ABCD).
  • All data is sent as unsigned integers; temperatures are always °C x10 regardless of display units. Sensor fault codes replace the temperature value (see descriptions).
  • Fan speed (134) is left out because the guide gives only 'fan speed type' without unit or scaling. The BMS control registers 171-193 (CH/DHW boiler control and BMS setpoints) are left out because the extracted table does not show their access or precision clearly.
  • Reading a reserved address returns an illegal-address exception.
  • Supported functions: FC 03 read holding registers and FC 06 write single register.
  • Left out: burner cycle count (151-152) and run hours (153-154). The table prints a precision of 0.1 for both, which conflicts with the 0-999,999 count range and the plain-integer example in Note 6, so the scaling is unclear.
  • Firing rate (135) is printed with precision 0.1, but Note 5 defines it as 0-200 = 0-100 % (50 % sent as 100), so scale 0.5 is used.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Patterson-Kelley NURO boiler controller (Modbus BMS port)

What Modbus registers does the Patterson-Kelley NURO boiler controller (Modbus BMS port) have?

This map lists 22 registers: 22 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Patterson-Kelley NURO boiler controller (Modbus BMS port) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide says register addresses start at 0 per the Modbus specification and that 40001 is added for traditional numbering, so register 100 (outlet temperature) is wire address 100 (40101).

What byte order does the Patterson-Kelley NURO boiler controller (Modbus BMS port) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Patterson-Kelley NURO boiler controller (Modbus BMS port)?

Start with HR 100 Outlet temperature (Outlet temperature); HR 101 Inlet temperature (Inlet temperature); HR 132 Boiler state (Boiler state); HR 135 Firing rate (Firing rate); HR 136 Error code (Error code); HR 130 Demand source (Demand source).

How do I enable Modbus control of the Patterson-Kelley NURO boiler controller (Modbus BMS port)?

Set MODBUS BMS BAUD RATE (9600, 19200 or 38400) and MODBUS BMS SLAVE ADDRESS under All Parameters > Boiler Parameters > General Boiler Settings.

Where is the official Patterson-Kelley NURO boiler controller (Modbus BMS port) Modbus documentation?

The source is NURO Advanced Users Guide - Appendix A: Modbus Configuration. Patterson-Kelley doesn't publish it on its own website, so this map was re-typed from a free copy at https://www.ccontrols.com/support/dp/NURO%20Advanced%20Users%20Guide.pdf. It may be an older revision, so check it against the live unit.
