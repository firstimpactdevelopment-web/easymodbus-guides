Updated 28 October 2026

Short answer

The UMG 604-PRO is Janitza's DIN-rail power quality analyser with Ethernet and RS-485. It serves its measurements as big-endian 32-bit floats; the 'frequently required readings' block at 19000-19120 holds volts, amps, power, CosPhi, frequency, energy and THD and is the same block other Janitza meters use. This map covers that block plus the fourth channel, consumed energy total, digital I/O, energy resets, transformer settings and identity/network values.

This page lists 76 Modbus registers for the Janitza UMG 604-PRO power analyser (Modbus RTU / Modbus TCP) — 4 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Janitza’s own free documentation (linked below) and checked against it.

Integration notes: Janitza UMG 604-PRO power analyser (Modbus RTU / Modbus TCP)

Integration in brief

Read holding registers (function 03) from 19000: 60 registers give volts, amps, power, CosPhi, frequency and per-phase energy as big-endian floats; 19060-19077 adds the three-phase and delivered energy totals in Wh. Over Ethernet use Modbus TCP; over RS-485 use RTU at the device's address.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The 604-PRO answers Modbus on Ethernet and, as a slave, on RS-485. Set the Modbus address, baud rate and IP settings on the device or in GridVis (see the device manual).

Byte order & addressing

  • Addresses are used as printed (0-based).
  • Floats are ABCD (high word first). Add 32768 to an address for little-endian.
  • Energy is in Wh and varh, not kWh.
  • Rotation field (19052) is a float: 1, 0 or -1.

Network setup

  • RS-485: 8 data bits, no parity, 2 stop bits on the device's own port; baud 9.6, 19.2, 38.4, 57.6, 115.2 or 921.6 kbps.
  • Set CT/VT ratios first so the floats read in primary units.
  • Writing 1 to 9997 clears real/apparent energy; 9998 clears reactive energy.

Watch out for

  • The 'rate 1' consumed row in the 19000 block (19068) is tariff 1 only; use 9851 for the full consumed total.
  • Short-format values elsewhere in the list skip the transformer ratios; do not mix them with the float values.

Notes on this map

  • Byte order: the list says its addresses return data big-endian (high byte first, high word in the lower register = ABCD). Adding 32768 to an address returns the same value little-endian; that mirror block is not listed.
  • Data types in the list: short = signed 16-bit, int = signed 32-bit, uint = unsigned 32-bit, float = IEEE 754 32-bit, long64 = signed 64-bit.
  • Float and integer values include the CT/VT ratios; short values do not. Only float and int/uint rows are used here, apart from the 16-bit status and command rows.
  • Left out: 19068 (consumed L1-L3, tariff 1 only - not the consumed total). The consumed total is at 9851 (_WH_V[4]).
  • Left out: harmonics, min/max/mean blocks, event and transient settings, logging, tariff 3/4 and month peaks, to keep the map short.
  • Left out: baud rate (10184), RS-485 mode (10182) and DHCP mode (10196) because the list gives no value coding for them.
  • The list has no read/write column. Only rows the list marks as writable (digital outputs 'r/w', delete commands '=1') are given write access here; CT/VT and network rows are listed read-only although they are device settings.
  • String length: 10072 _DEV_NAME is printed as 64 and the next row starts 32 registers later, so string sizes are in characters; _RELEASE (16) is taken as 8 registers.
  • Measured values refresh every 200 ms.
  • Defaults and ports come from the UMG 604-PRO user manual (doc. 1.033.059.7.a, 02/2026, https://assets.janitza.com/ce18jq9ih0x6/15504e85f82efabc79f178/d1dfe38c6041322ca16c055682b88072/janitza-bhb-umg604pro-en.pdf): device address default 1, RS-485 baud default 115200 (setting 4), Modbus/TCP on port 502 and Modbus RTU over Ethernet on port 8000. The address list itself only gives the serial framing.

Questions about the Janitza UMG 604-PRO power analyser (Modbus RTU / Modbus TCP)

What Modbus registers does the Janitza UMG 604-PRO power analyser (Modbus RTU / Modbus TCP) have?

This map lists 76 registers: 76 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Janitza UMG 604-PRO power analyser (Modbus RTU / Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed as the protocol address and sent unchanged: 19000 is requested as 19000. The list starts at address 0 (system time), which only fits a 0-based numbering. In a 1-based or Modicon tool enter 19001 / 419001.

What byte order does the Janitza UMG 604-PRO power analyser (Modbus RTU / Modbus TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Janitza UMG 604-PRO power analyser (Modbus RTU / Modbus TCP)?

Start with HR 19000 Voltage L1-N (Voltage L1-N); HR 19012 Current L1 (Current L1); HR 19026 Real power total L1-L3 (Total real power); HR 19034 Apparent power total L1-L3 (Total apparent power); HR 1373 Power factor total L1-L3 (Total power factor); HR 19050 Frequency (Frequency); HR 9851 Real energy L1-L3, consumed (Consumed energy total); HR 19076 Real energy L1-L3, delivered (Delivered energy total).

How do I enable Modbus control of the Janitza UMG 604-PRO power analyser (Modbus RTU / Modbus TCP)?

The 604-PRO answers Modbus on Ethernet and, as a slave, on RS-485. Set the Modbus address, baud rate and IP settings on the device or in GridVis (see the device manual).
