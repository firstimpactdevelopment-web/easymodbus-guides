Short answer

TempTrac is PVI's electronic operating control for its water heaters. It is a Modbus RTU slave on 2-wire RS-485 at a fixed 9600 8N1 and uses only holding registers (FC03/06/16, up to 5 registers per request). This map covers the registers PVI lists for typical BMS use: probe temperatures, set point, modulation rate, burner hours, relay status, alarms and the on/off command.

Integration notes: PVI Industries TempTrac water heater electronic controller (Modbus RTU)

Integration in brief

Poll 9600 8N1 with FC03, no more than 5 registers per request. Read probe 1 (40257), relay status (42050) and alarms (43329); write the set point at 40769 and turn the heater on/off by writing 257/1 to 41281.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is available through the XJ485 serial interface (TTL to RS-485) connected to the TempTrac's programming port.

Byte order & addressing

  • Maximum 5 registers per read or write.
  • Register numbers are Modicon-style; subtract 40001.
  • 41281 is write-only; reading it returns invalid data.

Network setup

  • Fixed serial settings: 9600 baud, 8 data bits, no parity, 1 stop bit (not adjustable).
  • Set the slave address (1-247) on the keypad; each unit on the bus needs its own address.
  • Leave at least 500 ms before a retry. The controller has no bias resistors; bias the line at the master.

Watch out for

  • Reading probe 2 or 3 returns an exception when that probe is disabled.
  • In OFF the display shows OFF and outputs are open, but temperatures can still be read.

Notes on this map

  • PVI does not host this manual publicly that we could find; this copy is served by a controls distributor and is the unaltered PVI document (PVI Industries footer, document number on every page).
  • Only the registers in section 4.2 'Typical parameters' and the clearly readable status/alarm rows are included; the long parameter list in Table 2 (pp. 10-14) did not extract cleanly and is left out.
  • Temperatures are whole degrees F per section 4.2. The display resolution option (rES) applies only to Celsius; its effect on Modbus values is not documented, so Celsius operation is not covered here.
  • Alarm bits follow the decimal values and bit numbers in the manual (bit 0 = 1). The manual's hex values for Alarm 2 (0x1000) and Alarm 3 (0x0800) disagree with their decimal values (2048, 4096); the decimal/bit numbers are used.
  • Register 41281 also accepts keypad lock/unlock and buzzer-silence codes; PVI notes that only the on/off command is normally needed.
  • Table 2 gives a hex base-0 address next to each register number (e.g. St1 0x300 = 40769), which confirms the 40001 = address 0 rule.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the PVI Industries TempTrac water heater electronic controller (Modbus RTU)

What Modbus registers does the PVI Industries TempTrac water heater electronic controller (Modbus RTU) have?

This map lists 10 registers: 10 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the PVI Industries TempTrac water heater electronic controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual uses register numbers: holding register 40001 is address 0 on the wire, so subtract 40001 (40769 -> 768). Coils are numbered from 00001 the same way, so coil 513 is wire address 512.

What are the minimum Modbus registers to integrate the PVI Industries TempTrac water heater electronic controller (Modbus RTU)?

Start with HR 256 Probe 1 temperature (TP1) (Probe 1 temperature); HR 768 Set point 1 (St1) (Set point 1); HR 2049 Relay status (Relay / burner status); HR 3328 Alarm register (Alarm flags); HR 1280 Control command (on/off) (On/off command); HR 848 Working hours relay 1 (ou1) (Burner hours).

How do I enable Modbus control of the PVI Industries TempTrac water heater electronic controller (Modbus RTU)?

Modbus RTU is available through the XJ485 serial interface (TTL to RS-485) connected to the TempTrac's programming port.

Where is the official PVI Industries TempTrac water heater electronic controller (Modbus RTU) Modbus documentation?

The source is MODBUS-RTU Applied to the TempTrac Control (PV500-42 06/2014), revision 2014-06. PVI Industries doesn't publish it on its own website, so this map was re-typed from a free copy at https://www.ccontrols.com/support/dp/PV500-42.pdf. It may be an older revision, so check it against the live unit.
