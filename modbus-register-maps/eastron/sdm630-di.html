Eastron SDM630-DI Modbus register map

Updated 16 October 2026

Short answer

The SDM630-DI is a three-phase, direct-connected (up to 100 A) DIN-rail energy meter with two digital inputs and an RS485 Modbus RTU port. Live readings and energy totals are IEEE-754 floats in input registers (function 04); configuration is held as floats in holding registers (function 03 read, 16 write). This map covers per-phase and total electrical values, demand, THD, import/export energy per phase, and the RS485/demand/system settings.

This page lists 101 Modbus registers for the Eastron SDM630-DI — 9 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Eastron’s own free documentation (linked below) and checked against it.

Integration notes: Eastron SDM630-DI

Integration in brief

Read floats with function 04 starting at 0x0000 (two registers per value, high word first). Total power is at 0x0034, import/export kWh at 0x0048/0x004A. Settings are floats in holding registers and need the password written to the KPPA register first for key parameters.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is always active on the RS485 terminals. To change key settings over Modbus, first write the meter password (default 1000) as a float to 40015 (KPPA); reading 40015 returns 1 when authorized.

Byte order & addressing

  • Every setting, including enumerations like baud rate, is a 32-bit float spanning two registers; write both registers with function 16.
  • Some holding registers use six-digit Modicon numbers (461457, 464515...) that map to hex 0xF010, 0xFC02 and so on.
  • Power factor carries a sign for current direction: positive for forward current, negative for reverse.

Network setup

  • Default RS485 settings: address 1, 9600 bps, 8 data bits, no parity, 1 stop bit.
  • Address, baud, parity and stop bits can be set from the front-panel setup menu or the holding registers listed here.
  • Set the system type (1P2W / 3P3W / 3P4W) to match the wiring; the table shows which values each system provides.

Watch out for

  • The Int32 and Int64 copies of the readings (310021 onwards) are not mapped because their word order is not documented; use the float registers.
  • Max demand and DI counters are cleared with the Reset register (0xF010) codes 0 and 6.

Notes on this map

  • Word order: the manual states that Eastron sends floats big-endian with the first register holding the high 16 bits, and its worked example returns 42 70 00 00 for 60.0. All floats here are ABCD.
  • The register table marks each input value as available or not for each wiring system (3P4W, 3P3W, 1P2W); the per-register descriptions repeat this where a value is not available on every system.
  • Left out: the Int32 (0.1 V, 0.001 A, 0.1 W ...) and Int64 (Wh, VArh) mirror blocks from 310021 onwards. The manual states big-endian order only for floats, not for these integer types, so their word order is not confirmed by the document.
  • Left out: 30255 'Total system power factor' because the table gives its unit as Degrees, which conflicts with 30063 (total power factor) and is likely an error in the source.
  • Left out: DI-1/DI-2 counters (40770/40772) and the serial number (464513), which are unsigned 32-bit integers with no stated word order; and the CO2 rate setting (40071), whose 'hex' data format is not defined.
  • The int64 CO2 at 310311 is omitted for the same reason; the float CO2 at 310315 is kept.
  • Left out: DI filter time (40769). The register table gives its range in milliseconds while the setup-menu section gives the same 0-255 range in minutes, so the unit is ambiguous.
  • Demand footnote: the manual says the power-sum demand is calculated for 'import – export' (en dash) without saying whether that means net import minus export or both directions combined; check on a live meter if the sign matters.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Eastron SDM630-DI

What Modbus registers does the Eastron SDM630-DI have?

This map lists 101 registers: 88 input registers, 13 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Eastron SDM630-DI Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed Modicon style (30001 / 40001, and six-digit 3xxxxx / 4xxxxx for high addresses) next to the hex start address actually sent. Wire address = printed number minus 30001 or 40001 (or 300001 / 400001); e.g. 30001 is 0x0000 and 461457 is 0xF010.

What byte order does the Eastron SDM630-DI use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Eastron SDM630-DI?

Start with IR 0 L1 voltage (L-N) (L1 voltage); IR 6 L1 current (L1 current); IR 52 Total active power (Total active power); IR 62 Total power factor (Total power factor); IR 70 Frequency (Frequency); IR 72 Import active energy (Import kWh); IR 74 Export active energy (Export kWh).

How do I enable Modbus control of the Eastron SDM630-DI?

Modbus RTU is always active on the RS485 terminals. To change key settings over Modbus, first write the meter password (default 1000) as a float to 40015 (KPPA); reading 40015 returns 1 when authorized.
