Short answer

SEW-EURODRIVE's standard inverter with Modbus RTU on the RJ45 communication socket. Registers 1-4 carry the process output words and 6-9 the process input words; words 2-4 and 7-9 are freely assignable in parameter group P5. Other parameters sit at register = parameter number (101 = P1-01), except the P0 monitoring group, which has its own register numbers.

Integration notes: SEW-EURODRIVE MOVITRAC LTP-B standard inverter (built-in Modbus RTU)

Integration in brief

Set P1-14 = 201, P1-12 = 7 and P1-15 per the manual, then write register 1 = 0x0006 with register 2 = speed (16384 = P1-01). Poll registers 6-9 for status, speed, current and power.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set P1-14 = 201 (extended menu), P1-12 = 7 (Modbus RTU or fieldbus) and P1-15 as given in the manual's fieldbus table. P5-01 sets the address (factory 1), P5-03 the baud rate (factory 115200) and P5-04 the format (factory no parity, 1 stop bit). The enable inputs must still be wired.

Communication loss & watchdog

P5-06 sets the communication-failure time (0.0-5.0 s, factory 1.0 s; 0.0 keeps running). P5-05 sets the reaction: 0 fault and coast, 1 stop ramp and fault, 2 stop ramp without fault (factory), 3 run at fixed setpoint speed 8.

Byte order & addressing

  • Register numbers are 1-based: subtract 1 for the wire address.
  • Control word bit 0 = 1 inhibits the output stage; 0x0006 runs, 0x0000 is a rapid stop.
  • Process words 2-4 and 7-9 are reassignable: always check P5-09 to P5-14 before trusting a scale.

Network setup

  • Wire RS485- (Modbus) to RJ45 pin 7 and RS485+ to pin 8.
  • Up to 32 nodes; 1200 m at 115200 bit/s with 0.5 mm2 cable.

Watch out for

  • Fitting a fieldbus or encoder option card disables Modbus on the RJ45 port.
  • The P0 monitoring group does not follow the register = parameter number rule.

Notes on this map

  • Registers 2-4 and 7-9 change meaning with P5-09 to P5-14; the scaling given is for the factory assignment. Each option's scaling is listed in the P5-09 to P5-14 value lists.
  • Speed values are relative (16384 = 100 % of P1-01) and are kept raw.
  • Left out: P0 monitor registers whose layout in the manual's table could not be read unambiguously (speed setpoint 22, torque 41, DC link 23, heat sink 24, kWh/MWh counters 30-33); P5-06 communication timeout (register scaling not stated); most P1-P4 parameters because the Modbus scaling of each is not given.
  • The manual's example reads P1-08 (register 108) as 0x2B = 43, a percentage of the inverter current, so P1-08 is not in amperes; it is left out.
  • Function code 16 (write multiple) works for the PO words; 03 and 06 work on all registers.
  • Modbus is not available once a communication option or an encoder card is fitted in the option slot.

Questions about the SEW-EURODRIVE MOVITRAC LTP-B standard inverter (built-in Modbus RTU)

What Modbus registers does the SEW-EURODRIVE MOVITRAC LTP-B standard inverter (built-in Modbus RTU) have?

This map lists 24 registers: 24 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the SEW-EURODRIVE MOVITRAC LTP-B standard inverter (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual's register numbers start at 1 and it warns that zero-based masters must subtract 1. Its frame example reads registers 107/108 (P1-07/P1-08) with start address 0x006A = 106. Parameters use register = parameter number (P5-03 = 503 = wire address 502).

What are the minimum Modbus registers to integrate the SEW-EURODRIVE MOVITRAC LTP-B standard inverter (built-in Modbus RTU)?

Start with HR 0 PO1 Control word (PO1 control word); HR 1 PO2 (default: speed setpoint %) (PO2 speed setpoint (16384 = P1-01)); HR 5 PI1 Status word (PI1 status word); HR 6 PI2 (default: actual speed %) (PI2 actual speed); HR 7 PI3 (default: actual current) (PI3 current, 0.1 %); HR 8 PI4 (default: power) (PI4 power, 0.1 %); HR 111 P1-12 Control signal source (P1-12 control signal source).

How do I enable Modbus control of the SEW-EURODRIVE MOVITRAC LTP-B standard inverter (built-in Modbus RTU)?

Set P1-14 = 201 (extended menu), P1-12 = 7 (Modbus RTU or fieldbus) and P1-15 as given in the manual's fieldbus table. P5-01 sets the address (factory 1), P5-03 the baud rate (factory 115200) and P5-04 the format (factory no parity, 1 stop bit). The enable inputs must still be wired.

What happens when the SEW-EURODRIVE MOVITRAC LTP-B standard inverter (built-in Modbus RTU) loses Modbus communication?

P5-06 sets the communication-failure time (0.0-5.0 s, factory 1.0 s; 0.0 keeps running). P5-05 sets the reaction: 0 fault and coast, 1 stop ramp and fault, 2 stop ramp without fault (factory), 3 run at fixed setpoint speed 8.
