Short answer

The PRO380-Mod is inepro's MID-certified three-phase DIN-rail energy meter (direct connection up to 100 A, or a CT version) with an RS485 Modbus RTU port. Every measurement is an IEEE 754 float sent high word first and read with function 03 from hex address blocks 4000h (setup), 5000h (live values) and 6000h (energy). This map covers phase voltages, currents, powers, power factor, frequency, total/tariff/per-phase energy and the writable address, baud, parity, tariff, S0 and combination-code settings.

This page lists 75 Modbus registers for the inepro Metering PRO380-Mod three-phase energy meter — 8 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from inepro Metering’s own free documentation (linked below) and checked against it.

Integration notes: inepro Metering PRO380-Mod three-phase energy meter

Integration in brief

Wire RS485 to terminals 22/23, poll unit 1 at 9600 baud 8E1 with function 03, and decode each value as a high-word-first float. Live values sit at 5002h-5031h, energy at 6000h-6047h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The manual describes no enable step for Modbus on the -Mod variant. Set the address in display Program mode 2, and baud/parity in Program mode 3 (4-digit password, default 0000), with the inepro IR software, or over Modbus at 4003h/4004h/4011h.

Byte order & addressing

  • Addresses are hex: 5012h is decimal 20498 on the wire.
  • Floats are ABCD (high word first).
  • Power is in kW/kvar/kVA, not W.
  • Default parity is even (8E1), not 8N1.
  • Total active energy (6000h) follows the combination code; read forward (600Ch) and reverse (6018h) for import and export.

Network setup

  • RS485 on terminals 22 and 23; defaults Modbus ID 1, 9600 baud, 8 data bits, even parity, 1 stop bit.
  • Parity can be changed to none or odd; data and stop bits are fixed.
  • Fit a 120 ohm / 0.25 W resistor across terminals 22 and 23 at the meter when testing through an RS485 converter.
  • The RS485 specification allows up to 60 meters (devices) on one bus; fewer at higher baud rates, depending on the converter.

Watch out for

  • Combination code 10 can only be set once; a meter on C-10 cannot be switched to another mode.
  • Program mode 3 settings (baud, parity, S0, combination code) need the display password (default 0000).
  • On CT versions the CT ratio is set once at first power-up and cannot be changed afterwards.

Notes on this map

  • The PDF is the user manual linked from the official PRO380-Mod product page (ineprometering.com/product/pro380-mod-electricity-meter, documentation tab).
  • 'Float ABCD' in the map = IEEE 754 32-bit float, high word first. 'Signed' rows are 16-bit integers.
  • Units are as printed: power in kW, kvar and kVA (not W), energy in kWh and kvarh.
  • Left out: Voltage (5000h), Current (500Ah) and Error code (4015h) - the map marks them 'PRO1 only'.
  • Left out: serial number (4000h), meter code (4002h), CT ratio (400Ch), LCD cycle time (4010h), checksum (401Bh) and active status word (401Dh). They are typed only as 'HEX' with no encoding given; the LCD-time example writes 0025 for 25 s, which suggests BCD. Current direction (4012h-4014h, 'ASCII') and CT mode (401Fh) are left out because their values are not described.
  • S0 output rate (400Dh) accepts 10000, 2000, 1000, 100, 10, 1, 0.1 or 0.01 imp/kWh.
  • The manual says the older V1.14 register map still works; it is not covered here.
  • Baud rates differ between sections: the RS485 spec lists 1200-9600, the Modbus appendix and display menu also list 300 and 600 (and 2400). 9600, 4800 and 1200 appear in every list.
  • The day-counter write row prints a register length of 1, but its example frame writes 2 registers (4 zero bytes) with function 16; it is listed here as a 2-register float.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the inepro Metering PRO380-Mod three-phase energy meter

What Modbus registers does the inepro Metering PRO380-Mod three-phase energy meter have?

This map lists 75 registers: 75 holding registers. 8 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the inepro Metering PRO380-Mod three-phase energy meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map prints addresses in hex and they go into the request unchanged: the manual's example frames are 01 06 4003 000A (set Modbus ID) and 01 06 6048 0002 (set tariff). So 4003h is wire address 16387 and 5012h (total active power) is 20498. Do not enter the hex numbers as decimal.

What byte order does the inepro Metering PRO380-Mod three-phase energy meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the inepro Metering PRO380-Mod three-phase energy meter?

Start with HR 20482 L1 voltage (L1 voltage); HR 20492 L1 current (L1 current); HR 20498 Total active power (Total active power (kW)); HR 20522 Power factor (Power factor); HR 20488 Grid frequency (Grid frequency); HR 24588 Forward active energy (Forward (import) active energy); HR 24600 Reverse active energy (Reverse (export) active energy).

How do I enable Modbus control of the inepro Metering PRO380-Mod three-phase energy meter?

The manual describes no enable step for Modbus on the -Mod variant. Set the address in display Program mode 2, and baud/parity in Program mode 3 (4-digit password, default 0000), with the inepro IR software, or over Modbus at 4003h/4004h/4011h.
