Short answer

The InRow ACRC30x is a 300 mm wide chilled-water cooling unit that sits between server racks. Its controller answers Modbus RTU and Modbus TCP, with every value in holding registers that can also be read with function 04. This map covers the group values (cooling output, setpoints, airflow), the unit readings (temperatures, fan speed, chilled water valve, flow, power and energy, run hours), configuration items and the full list of one-register alarm flags.

Integration notes: APC (Schneider Electric) InRow ACRC30x chilled-water cooling unit (300 mm)

Integration in brief

Poll holding registers from address 0 with function 03 or 04. Read OVERALL_STATUS and OPERATING_MODE first, then the 32-bit temperatures and cooling output in tenths, and scan the alarm block at 384-456 for active flags.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The register map does not describe how to enable Modbus or set the network parameters.

Byte order & addressing

  • 32-bit values are high word first (ABCD).
  • Temperatures are tenths of a degree Fahrenheit; the map has no Celsius registers.
  • A single-register read of a reserved address fails, while block reads across gaps return zeros.

Network setup

  • Modbus RTU and Modbus TCP are both supported; serial settings and unit ID are not in this map.

Watch out for

  • Large reads can take 2 seconds or more; shorten blocks or raise the response timeout if requests time out.
  • Reading an item before the controller has data for it returns an invalid-address error, so retry later.
  • Alarm flags are only consistent within one register; do not combine bits across registers.

Notes on this map

  • Word order: note 2 says INT32 and UINT32 keep the most significant word at n+0, so 32-bit values are ABCD (big-endian). Note 5: signed values are two's complement.
  • Scale comes from the units column: '(Tenths)' is 0.1 and '(Hundredths)' is 0.01. Temperatures are in tenths of a degree Fahrenheit only; the map has no Celsius registers.
  • Function codes 3 and 4 both read the same registers. Writes use function 16, or function 6 for one-register items.
  • Strings hold two characters per register, high byte first; a null terminator must be included when writing.
  • The last four alarm rows (decimal 453-456) all print Modicon 40454 in the source. Their hex and decimal columns run 453, 454, 455, 456, and those are used here.
  • In revision B the column headed hexadecimal actually prints the decimal value (for example 40017 shows 16, not 0010); the decimal column is used for the wire address.
  • Reserved rows are left out. Reading an undefined register on its own returns an error; a block read that starts on a valid register returns zeros for gaps.
  • The register map does not give serial settings, a unit ID or a TCP port.
  • An older edition, 990-4742A, is also published by Schneider; it lacks the rows added in revision B (for example OPERATE_MODE is named OPERATING_MODE in B).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the APC (Schneider Electric) InRow ACRC30x chilled-water cooling unit (300 mm)

What Modbus registers does the APC (Schneider Electric) InRow ACRC30x chilled-water cooling unit (300 mm) have?

This map lists 163 registers: 163 holding registers. 27 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the APC (Schneider Electric) InRow ACRC30x chilled-water cooling unit (300 mm) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row gives a Modicon number (40001 style) plus the absolute address in hex and decimal. Note 11 says absolute address 0 equals register 40001 and is address zero on the wire, so the decimal column is the wire address.

What byte order does the APC (Schneider Electric) InRow ACRC30x chilled-water cooling unit (300 mm) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.
