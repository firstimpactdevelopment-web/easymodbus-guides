Integration notes: GE Multilin Multilin PQMII power quality meter

Integration in brief

Read 0240h-0245h for currents, 0280h-0290h for voltages (32-bit), 02F0h-030Bh for power and PF, 03D0h-03D9h for energy and 0440h for frequency. Use the command registers to clear energy or min/max values.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the slave address, baud rate and parity in the PQMII setpoints for the COM port in use; Modbus RTU is the native protocol.

Byte order & addressing

  • Hex addresses are wire addresses.
  • 32-bit values are high register first; signed values (F4) are two's complement across both registers.

Network setup

  • Address 0 is broadcast (setpoint stores and commands only); give each meter its own address.

Watch out for

  • Voltages are whole volts in 32-bit registers; power is in 0.01 kW units, not watts.

Notes on this map

  • Word order: the manual says long integers occupy two registers, high-order register first, and its worked example (02F0 = 004Fh, 02F1 = 35D1h -> 51911.21 kW) confirms ABCD.
  • Data formats: F1 unsigned 16-bit, F2 signed 16-bit, F3 unsigned 32-bit, F4 signed 32-bit. Scales are copied from the Units and Scale column (0.01 x kW, 0.1 x %, 0.01 x Hz).
  • Up to 125 registers can be read in one request; up to 60 written.
  • Phase B current THD (0479h) is left out because its units/scale cell is blank in the table. Min/max time stamps, tariff energies/costs, per-harmonic data and setpoints are left out.
  • The user-definable area (index 0180h-01F7h, data 0100h-0177h) can gather scattered registers into one block.
  • Communication defaults are not listed: the RS-485 setpoint rows (e.g. baud rate at 1018h) give codes whose meaning is not readable in this copy of the table.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the GE Multilin Multilin PQMII power quality meter

What Modbus registers does the GE Multilin Multilin PQMII power quality meter have?

This map lists 59 registers: 57 input registers, 2 holding registers. 2 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the GE Multilin Multilin PQMII power quality meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The memory map prints addresses in hex, and the manual's examples send that hex value on the wire (e.g. a read of 3 registers starting at 006B). Actual values are input registers, setpoints and commands holding registers; function 03 and 04 both read either area.

What byte order does the GE Multilin Multilin PQMII power quality meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the GE Multilin Multilin PQMII power quality meter?

Start with IR 576 Phase A current (Phase A current); IR 648 Voltage Vab (Voltage Vab); IR 752 3-phase real power (3-phase real power); IR 758 3-phase power factor (3-phase power factor); IR 1088 Frequency (Frequency); IR 976 3-phase positive real energy (Imported real energy).

How do I enable Modbus control of the GE Multilin Multilin PQMII power quality meter?

Set the slave address, baud rate and parity in the PQMII setpoints for the COM port in use; Modbus RTU is the native protocol.

Where is the official GE Multilin Multilin PQMII power quality meter Modbus documentation?

The source is PQMII Power Quality Meter Communications Guide (GEK-113532 (manual P/N 1601-9090-A1)), published free by GE Multilin at https://www.gevernova.com/grid-solutions/sites/default/files/resources/products/manuals/pqmii/gek-113532-GEV.pdf.
