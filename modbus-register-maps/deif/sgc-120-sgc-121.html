DEIF SGC 120 / SGC 121 Single Genset Controller Modbus register map

Updated 19 November 2026

Short answer

The SGC 120 and SGC 121 are DEIF's small auto-start and AMF genset controllers. They act as a Modbus RTU server on one RS-485 port, and every value is a holding register read with function 03. This map covers the 16-bit generator, mains and load readings, engine values, start and trip counters, the packed alarm-state, I/O and genset-status words, and the mode-change command.

This page lists 66 Modbus registers for the DEIF SGC 120 / SGC 121 Single Genset Controller — 1 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from DEIF’s own free documentation (linked below) and checked against it.

Integration notes: DEIF SGC 120 / SGC 121 Single Genset Controller

Integration in brief

Poll holding registers 1-59 with function 03 for live values and 78 for genset status. To start or stop remotely, write 2 (START) or 1 (STOP) to register 0 with function 16; write 4 to go to AUTO.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set Communication mode to Modbus in the RS485 COMM menu, then set the server ID (1-247), baud rate and parity.

Byte order & addressing

  • Only functions 03 and 16 are supported.
  • Register 0 reads back the protocol revision but accepts mode-key writes.

Network setup

  • Baud 1200-115200 selectable; parity None/Even/Odd; stop bits 1 or 2.
  • RS-485 is on terminals 15 (B) and 16 (A); the port has a built-in 120 ohm termination resistor.
  • Up to 255 registers per request; the manual gives a 250 ms no-response timeout.

Watch out for

  • Phase frequencies are labelled R, Y, B (L1, L2, L3).

Notes on this map

  • Left out: the 32-bit energy counters (39-50) and engine run hours (60-61). The tables give each as a two-register range with no word order, so they cannot be decoded with certainty.
  • Scaling is a multiplier: 0.1 means the raw value is in tenths.
  • Alarm words 65-76 each pack four alarms as 4-bit fields. The table numbers bits 1-16 and puts the first-listed alarm in bits 13-16, the next in 9-12, then 5-8 and 1-4. It does not say whether bit 1 is the least significant bit, so the fields are not split here. Each field holds 0 = disabled, 1 = not active, 2 = warning, 3 = shutdown, 4 = electrical trip, 5 = notification.
  • Word 77 packs digital inputs A-I (table bits 16 down to 8) and outputs A-F (bits 7 down to 2). Word 78 packs, from table bit 16 down: SGC mode, mains healthy, operation mode (bits 14-12: 110 scheduler, 101 auto, 100 manual), load on mains, load on DG, DG running/stopped, stopped normally, stopped with fault, fail to start, gen available, common shutdown, common electric trip, common warning, common notification. The same bit-numbering caveat applies.
  • Registers 79-81 hold the time stamp as packed hex bytes (minute/second, weekday/hour, month/day) and are not listed; 82 holds the year.
  • Mode-change writes use function 16 to register 0 with one key code at a time.
  • RS-485 settings come from the SGC 120 user manual 4189341340B (https://deif-cdn-umbraco.azureedge.net/media/1ajpbyvp/sgc-120-user-manual-4189341340-uk.pdf).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the DEIF SGC 120 / SGC 121 Single Genset Controller

What Modbus registers does the DEIF SGC 120 / SGC 121 Single Genset Controller have?

This map lists 66 registers: 66 holding registers. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the DEIF SGC 120 / SGC 121 Single Genset Controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables print plain register numbers starting at 0, and the user manual's frame layouts put the register address from the map straight into the request. Read generator L1-N voltage at 1, not 40002.

What are the minimum Modbus registers to integrate the DEIF SGC 120 / SGC 121 Single Genset Controller?

Start with HR 1 Generator L1-N voltage (Generator L1-N voltage); HR 7 Generator R frequency (Generator frequency); HR 23 Load L1 current (Load L1 current); HR 29 Load total active power (Total kW); HR 56 Battery voltage (Battery voltage); HR 78 DG status word (Genset status flags); HR 0 Protocol revision (read) / DG mode command (write) (Mode-change command).

How do I enable Modbus control of the DEIF SGC 120 / SGC 121 Single Genset Controller?

Set Communication mode to Modbus in the RS485 COMM menu, then set the server ID (1-247), baud rate and parity.

Where is the official DEIF SGC 120 / SGC 121 Single Genset Controller Modbus documentation?

The source is SGC 120 and SGC 121 Modbus tables (4189341357), published free by DEIF at https://deif-cdn-umbraco.azureedge.net/media/pawhllhf/sgc-120-sgc-121-modbus-tables-4189341357.xlsx.
