Lumel ND20LITE network parameter meter Modbus register map

Updated 17 November 2026

Short answer

The ND20LITE is a 96x96 panel meter for 3- and 1-phase networks with an RS-485 Modbus RTU port. Measured values are floats offered in several register areas; this map uses the 7000 area (two registers per value, high word first) for per-phase and total values, THD and energies, plus the 4000 area for comms settings, 32-bit energy counters and the status word.

This page lists 69 Modbus registers for the Lumel ND20LITE network parameter meter — 4 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lumel’s own free documentation (linked below) and checked against it.

Integration notes: Lumel ND20LITE network parameter meter

Integration in brief

Read holding registers (function 03 or 04) from 7000 for per-phase values, 7042-7064 for 3-phase totals and frequency, and 7100-7118 or 4038-4047 for energy. Floats are high word first in the 7000 area.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is always on; set address, mode and baud from the menu or registers 4030-4032, then write 1 to 4033.

Byte order & addressing

  • The 6000 area is low word first and the 7000 area high word first.
  • At most 41 32-bit or 82 16-bit registers per request.
  • Powers are in W, var and VA.

Network setup

  • Factory settings: address 1, 9600 baud, RTU 8N2.
  • Maximum response time is 600 ms.

Watch out for

  • ND20, ND20CT and ND20LITE use different register maps.

Notes on this map

  • Byte order: the area table gives 7000-7319 as bytes 3-2-1-0 and 6000-6319 as 1-0-3-2; example 2 returns 41 20 00 00 (10.0) from 7000 and example 3 returns 00 00 41 20 from 6000, so the 7000 area is high word first (ABCD).
  • Energy counters 4038-4047 follow the manual's formula (high x 65536 + low) / 10.
  • Left out: the min/max area from 7140, 7054 (labelled a phase L1 value inside the 3-phase block), 4057 (its value list prints 3Ph/4W twice), 7120-7138 (reserved, time and 'utilized ordered power' printed with unit V), 7086/7543 which the table skips, the alarm and display setup registers, and 4061 status 2.
  • Table 10 shows which values exist in 3Ph/4W, 3Ph/3W and 1Ph/2W modes; per-phase values are not valid in 3-wire mode.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lumel ND20LITE network parameter meter

What Modbus registers does the Lumel ND20LITE network parameter meter have?

This map lists 69 registers: 69 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lumel ND20LITE network parameter meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are used as printed: the example frames read 4000 as 0x0FA0, 7000 as 0x1B58 and 6000 as 0x1770. The 'documented' field of float registers shows the table's 6xxx/7xxx pair; this map uses the 7xxx address.

What byte order does the Lumel ND20LITE network parameter meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lumel ND20LITE network parameter meter?

Start with HR 7000 Voltage of phase L1 (Voltage L1); HR 7002 Current in phase L1 (Current L1); HR 7046 3-phase active power (P1+P2+P3) (3-phase active power); HR 7052 Mean power factor (PF) (Mean power factor); HR 7056 Frequency (Frequency); HR 4038 Imported active energy (counter) (Imported active energy counter); HR 4050 Status register (Status bits).

How do I enable Modbus control of the Lumel ND20LITE network parameter meter?

Modbus RTU is always on; set address, mode and baud from the menu or registers 4030-4032, then write 1 to 4033.

Where is the official Lumel ND20LITE network parameter meter Modbus documentation?

The source is ND20LITE Meter of network parameters - User's manual, published free by Lumel at https://www.lumel.com.pl/resources/Pliki%20do%20pobrania/ND20LITE/ND20LITE_user_manual.pdf.
