Short answer

The BCx2 series are PID temperature controllers sharing one command set. With the C5/C5W option they talk Shinko protocol, Modbus ASCII or Modbus RTU on RS485; every item is a 16-bit holding register. This map covers the setup and PID settings, SV memories, event outputs, heater burnout and loop break alarms, run modes, PV, MV, current SV, heater current and the status words.

Integration notes: Shinko Technos BCS2 / BCR2 / BCD2 digital indicating controller (C5, C5W options)

Integration in brief

In Engineering mode 1 choose MODBUS RTU, an 8-bit data format and a non-zero instrument number. Then poll PV 0100H, OUT1 MV 0101H and status flags 010DH/010EH; write SV1 at 0001H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Requires the C5 or C5W option. Hold the up and down keys for 3 s in RUN mode to enter Engineering mode 1, then set Communication protocol to MODBUS RTU (not the JC command allocated variant), instrument number, speed, data bit/parity and stop bit.

Byte order & addressing

  • Factory data format is 7 bits/Even; Modbus RTU needs one of the 8-bit choices.
  • Instrument number defaults to 0, the Modbus broadcast address; set 1-95.
  • Response delay time (default 10 ms) adds to every reply.

Network setup

  • Factory defaults: Shinko protocol, instrument 0, 9600 bps, 7 bits/Even, 1 stop bit, response delay 10 ms.
  • Speeds 9600, 19200 or 38400 bps.

Watch out for

  • Writing 1234H to 00FEH returns every setting to factory default.
  • Settings are stored in non-volatile memory; avoid cyclic writes.

Notes on this map

  • This map is for the standard 'MODBUS RTU' / 'MODBUS ASCII' protocol settings. The 'JC command allocated' protocol settings switch the unit to the older JC-series layout (section 7.2) and are not covered.
  • All data are 16-bit; negatives are two's complement. Items marked 'decimal point ignored' are sent as whole numbers; apply the decimal point place (0005H).
  • Read-only items from 0100H can be read with function 03 or 04.
  • 00E2H means control output ON/OFF, auto/manual, or program STOP/RUN depending on the OUT/OFF key function in 00E0H; in each case 0 is the first state (output ON / automatic / STOP) and 1 the second (output OFF / manual / RUN).
  • The table lists SV1 at both 0001H and 000EH (followed by SV2-SV4 at 000FH-0011H).
  • Left out: program-pattern settings (005EH-0077H), unit model and error status words, and section 8 SV digital transmission.
  • Units of PID times, cycles and MV are not printed in the command table.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Shinko Technos BCS2 / BCR2 / BCD2 digital indicating controller (C5, C5W options)

What Modbus registers does the Shinko Technos BCS2 / BCR2 / BCD2 digital indicating controller (C5, C5W options) have?

This map lists 91 registers: 91 holding registers. 78 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos BCS2 / BCR2 / BCD2 digital indicating controller (C5, C5W options) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are listed as hex data items (0001H) that go into the request unchanged. The manual adds that the matching Modicon holding-register number is the item in decimal plus 40001 (0001H = 40002).

What are the minimum Modbus registers to integrate the Shinko Technos BCS2 / BCR2 / BCD2 digital indicating controller (C5, C5W options)?

Start with HR 256 PV (Process value); HR 1 SV1 (Set value SV1); HR 257 OUT1 MV (OUT1 manipulated value); HR 269 Status flag 1 (Output and alarm status); HR 270 Status flag 2 (Run mode status); HR 5 Decimal point place (Decimal point for scaling).

How do I enable Modbus control of the Shinko Technos BCS2 / BCR2 / BCD2 digital indicating controller (C5, C5W options)?

Requires the C5 or C5W option. Hold the up and down keys for 3 s in RUN mode to enter Engineering mode 1, then set Communication protocol to MODBUS RTU (not the JC command allocated variant), instrument number, speed, data bit/parity and stop bit.

Where is the official Shinko Technos BCS2 / BCR2 / BCD2 digital indicating controller (C5, C5W options) Modbus documentation?
