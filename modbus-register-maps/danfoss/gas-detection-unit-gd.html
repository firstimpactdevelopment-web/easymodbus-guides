This map covers the per-sensor block (gas type, range, divisor, current and average value, error, alarm and relay bits, thresholds) and the operating-data block (production data, maintenance counters, extremes), plus the address-change register.

Integration notes: Danfoss Gas Detection Units GD Basic / Premium / Heavy Duty (Modbus RTU)

Integration in brief

Read the sensor block at 40 (12 registers per sensor, up to 48 in one request) and divide the current value by the divisor register. Alarm and relay states are bit fields in the same block.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The RS-485 Modbus port (Bus A / Bus B terminals) is always a slave at 19200 baud, 8 data bits, even parity, 1 stop bit. The slave address can be changed by writing the new address to register 333 with function 16.

Byte order & addressing

  • Only function 03 reads are supported; nothing can be written with function 06, and function 16 is accepted only for the address-change register 333.
  • The compact block (not listed here) must be read as exactly 10 words starting at address 0.

Network setup

  • Poll each unit no faster than every 100 ms; with poll intervals under 550 ms, add at least one pause longer than 550 ms per polling cycle.

Watch out for

  • Changing the address with register 333 readdresses every device sharing the old address, so only one device with that address may be on the bus.

Notes on this map

  • Gas values are scaled per sensor: the divisor register (42/54/66) says what to divide the current value, average value and thresholds by (e.g. divisor 10 -> 1301 = 130.1). It depends on the measuring range, so it is read rather than fixed; scale is left at 1 here.
  • The guide also offers a compact block: exactly 10 words read from address 0 (current and average value of sensors 1-3, then type + range words and a temperature word). It is left out because the guide does not say whether those words are signed or how the type, range and temperature words are encoded. Its gas values use a dynamic resolution: range under 10 -> value x 1000, 10-99 -> x 100, 100-999 -> x 10, 1000 and up -> x 1.
  • On Heavy Duty units only sensor 1 is populated; the other sensor slots read 0. The sensor 2 operating-data block (218-235) is for Premium units; the guide also lists a third block (236-253), included here for completeness.
  • The units of the gas reading follow the gas type code (ppm, %LEL, %Vol, °C, %rH, mbar...); the code table in the guide is printed in a layout that does not line codes up with gases reliably, so it is not transcribed.
  • Error words are bit coded and can combine, e.g. 0x8001 sensor element error, 0x8002 ADC error, 0x8004 supply voltage, 0x8040 over-temperature, 0x8100 under-range, 0x8200 over-range, 0x0080 maintenance due.
  • Units of the operating-data concentration and temperature extremes are not stated in the guide.
  • Part 1 of the same guide (the Gas Detection Controller's X-bus map with blocks 1001-1096, 2001-2032 etc.) is a different device and is not in this file.
  • Each sensor block can also be read as registers 40-51 from the next slave address up (unit address + 1 for sensor 2, + 2 for sensor 3); this map uses the single-address layout 40-75.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Danfoss Gas Detection Units GD Basic / Premium / Heavy Duty (Modbus RTU)

What Modbus registers does the Danfoss Gas Detection Units GD Basic / Premium / Heavy Duty (Modbus RTU) have?

This map lists 88 registers: 88 holding registers. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Danfoss Gas Detection Units GD Basic / Premium / Heavy Duty (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide gives start addresses as they go in the request: the compact block is read from address 0 (impossible in 1-based numbering), the sensor block from 40 (shown as 28h) and operating data from 200. So register 43 is requested at address 43.

What are the minimum Modbus registers to integrate the Danfoss Gas Detection Units GD Basic / Premium / Heavy Duty (Modbus RTU)?

Start with HR 40 Gas type, sensor 1 (Gas type of sensor 1); HR 42 Divisor, sensor 1 (Divisor needed to scale sensor 1 values); HR 43 Current value, sensor 1 (Sensor 1 current gas value); HR 45 Error, sensor 1 (Sensor 1 error word); HR 46 Alarm status, sensor 1 (Sensor 1 alarm 1-4 bits); HR 47 Relays and digital inputs (sensor 1 block) (Relay and digital input states).

How do I enable Modbus control of the Danfoss Gas Detection Units GD Basic / Premium / Heavy Duty (Modbus RTU)?

The RS-485 Modbus port (Bus A / Bus B terminals) is always a slave at 19200 baud, 8 data bits, even parity, 1 stop bit. The slave address can be changed by writing the new address to register 333 with function 16.
