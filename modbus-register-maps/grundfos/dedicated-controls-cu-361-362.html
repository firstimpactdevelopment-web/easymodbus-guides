Short answer

Grundfos Dedicated Controls runs wastewater lift stations with up to six pumps, a mixer, level sensors or float switches. A CIM module in the CU 36X makes it a Modbus slave with blocks for pit control, pit status, pit data and one 50-register block per pump. This map covers pit commands and level setpoints, operating mode and per-pump state bits, pit level, flows, energy and overflow counters, and the main per-pump data (run hours, starts, current, power, frequency).

Integration notes: Grundfos Dedicated Controls (CU 361 / CU 362) with CIM 200 / CIM 260 / CIM 500 (Modbus)

Integration in brief

Poll 00203 (operating mode), 00206/00209 (pumps running / in alarm) and 00301 (pit level) for the station overview, and each pump block for run hours, starts and current. Use PitControl 00101 to reset alarms, interlock the pit or return it to Auto, and 00103-00108 to force pumps on or off.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the CIM module in the CU 36X; set the address and speed on its switches (CIM 200). Remote control needs write access: if SCADA PIN protection is on, write the PIN to 00109 first and check PitStatus bit 5.

Byte order & addressing

  • Control bits act on a rising edge; with AutoAckControlBits = 1 (default) the CIM clears them itself.
  • InterlockPit (00101 bit 3) stops all pumps for the time in SetInterlockTimeout (00111, minutes); the pit then returns to Auto by itself.

Network setup

  • CIM 200 default: 19200 baud, even parity, 1 stop bit; SW3 selects no parity with 2 stop bits.
  • CIM 500: select Modbus TCP on the rotary switch; port 502.

Watch out for

  • A changed RegisterOffset (00002) moves every register above 00100.
  • Most flow, energy and overflow values need the matching sensor (flow meter, MP 204, level sensor) or read 0xFFFF.

Notes on this map

  • The manual states that 32-bit values are split into registers ending HI and LO and recombined as HI x 65536 + LO, so they are ABCD.
  • All registers can be read with function 03 or 04; they are listed as holding registers. 0xFFFF means not available (missing sensor or option).
  • Pumps 2-6 repeat the pump 1 layout at +50 registers each (00451, 00501, 00551, 00601, 00651); this was checked against the printed pump 2-6 tables.
  • Left out: per-pump alarm/warning words (004x23-004x28, 004x41-004x42), sensor presence and setpoint-select fields, the pit sensor-presence and float-switch 5 registers (00223-00240), most user-defined counters, the real-time clock split registers, the hour log, event log and data log blocks, and the name string. Bit meanings of PitAlarms/PitWarnings are in section 11.11 of the manual and are not decoded here.
  • Level and set-level registers are in 0.01 m; writing the Set...Level registers (00121-00137) changes the controller's configured levels.
  • Left out: GrinderReverseCounter (00389-00390), because the pit status table also prints 00389 for PitWarnings5, so the number is not unambiguous in this edition.
  • Pumps 2-6 print the current asymmetry register as PumpNAsym, while pump 1 uses Pump1iAsym; the names are kept as printed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Grundfos Dedicated Controls (CU 361 / CU 362) with CIM 200 / CIM 260 / CIM 500 (Modbus)

What Modbus registers does the Grundfos Dedicated Controls (CU 361 / CU 362) with CIM 200 / CIM 260 / CIM 500 (Modbus) have?

This map lists 318 registers: 318 holding registers. 31 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Grundfos Dedicated Controls (CU 361 / CU 362) with CIM 200 / CIM 260 / CIM 500 (Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as 5-digit register numbers; this manual states that register X is addressed as X - 1 in the telegram (e.g. 00301 PitWaterLevel is wire address 300). Pump n's block starts at 00401 + 50 x (n-1).

What byte order does the Grundfos Dedicated Controls (CU 361 / CU 362) with CIM 200 / CIM 260 / CIM 500 (Modbus) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Grundfos Dedicated Controls (CU 361 / CU 362) with CIM 200 / CIM 260 / CIM 500 (Modbus)?

Start with HR 202 OperatingMode (Pit operating mode); HR 205 PitPumpsRunning (Pumps running bits); HR 208 PitPumpsAlarm (Pumps in alarm bits); HR 300 PitWaterLevel (Pit water level); HR 100 PitControl (Reset / interlock / auto commands); HR 102 PitPump1Control (Pump 1 manual control); HR 417 Pump1Current (Pump 1 motor current); HR 403 Pump1OperatingTime (Pump 1 operating hours).

How do I enable Modbus control of the Grundfos Dedicated Controls (CU 361 / CU 362) with CIM 200 / CIM 260 / CIM 500 (Modbus)?

Fit the CIM module in the CU 36X; set the address and speed on its switches (CIM 200). Remote control needs write access: if SCADA PIN protection is on, write the PIN to 00109 first and check PitStatus bit 5.
