Eaton Power Xpert Meter 1000 Series (PXM 1000/1100/1200/1300) Modbus register map

Updated 16 October 2026

Short answer

The PXM 1000 series are compact multifunction power and energy meters with a built-in RS-485 port running Modbus RTU (DNP3.0 selectable) and optional plug-in I/O and communication modules. Live readings are IEEE floats in holding registers from 4000H, energy counters are 32-bit integers, and setup values are 16-bit words from 0FFDH. This map covers the comm and CT settings, status, voltages, currents, powers, power factor, demand, energy, THD, phase angles and the first I/O module's inputs and relays.

Integration notes: Eaton Power Xpert Meter 1000 Series (PXM 1000/1100/1200/1300)

Integration in brief

Over RS-485 at the default 19200 baud, 8N1, address 1, read holding registers 4000H-403BH with function 03 to get frequency, voltages, currents, powers and power factor as big-endian floats; read 4048H-4059H for energy. Set Basic Parameter Mode 101DH to 1 first so the readings come back in primary units.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is the default protocol on the built-in RS-485 port (0FFEH = 0). Settings are written with function 16 (10H); one write may only touch registers inside a single settings region. To get primary-unit readings, write 1 to Basic Parameter Mode (101DH). This write is refused while the meter is sealed.

Byte order & addressing

  • Addresses are printed in hex and are the wire addresses (4000H = 16384 decimal).
  • 32-bit floats and Dwords are high word first.
  • By default the 4000H measurement block returns secondary-side values; switch 101DH to Primary or multiply by the PT and CT ratios.
  • If Energy Display Mode (1019H) is switched to Secondary, the energy registers hold secondary-side energy in 0.001 steps instead of primary energy in 0.1 steps.
  • Function 16 writes must stay inside one settings region (for example system parameters 0FFDH-101DH).

Network setup

  • Set the address (S01), baud rate and parity on the meter's System Settings pages or via registers 1001H, 1002H and 0FFFH.
  • Built-in port defaults: address 1, 19200 baud, no parity with one stop bit (NON1).
  • Parity options are Even, Odd, NON2 (no parity, two stop bits) and NON1 (no parity, one stop bit).
  • If an Ethernet or PROFIBUS module is used on the second port, the manual requires 38400 baud and NON1 for that port.

Watch out for

  • When the meter's Seal is closed (101FH = 0x0A), setup registers such as wiring, CT, 1019H, 101DH and the energy presets are blocked over Modbus, and 101EH bits 0/1 can also lock the communication settings.
  • Clear commands only act on the documented magic value: 1 for demand, run time and energy, 0x0A for max/min.

Notes on this map

  • IMPORTANT - primary vs secondary: the 4000H measurement block (voltages, currents, powers and power demand) holds real primary values only when Basic Parameter Mode (101DH) = 1. The manual's default is 0 = Secondary, where voltages must be multiplied by PT1/PT2, currents by CT1/CT2 and powers by both (use CT2 = 5 only for a 5 A CT secondary, otherwise 1). Every affected register says so; scale 1 and the units here assume Primary mode. Frequency, power factor and unbalance are not affected.
  • Word order: the manual defines Dword as high word first, and its function-03 example returns frequency 4000H-4001H as 42 48 00 00 (50.00 Hz) with the high word in the first register. Its function-16 energy example writes 0A9D then 4089. All 32-bit values here are ABCD.
  • Left out: current demand 4600H-4605H. Its table gives only the secondary formula with format code F1 and does not say whether Basic Parameter Mode (101DH) applies, so its scaling is ambiguous.
  • Energy registers 4048H-4059H: scale 0.1 kWh / kvarh / kVAh applies to primary energy (format codes F4-F6), which is the default Energy Display Mode (1019H = 0). If 1019H is set to 1 (Secondary) the same registers hold secondary energy in 0.001 units (F7-F9). The manual prints the apparent energy unit as kVA; kVAh is used here.
  • The system-parameter table prints address 0ffdH twice (Frequency and First Communication Protocol). The manual's notes and its sealed-parameter table both put the protocol at 0FFEH, so Frequency is kept at 0FFDH and the protocol at 0FFEH.
  • Left out: PT1 (1005H, printed as a 32-bit 'Unit 32' with a one-decimal range but no stated scaling) and PT2 (1007H, a word with a one-decimal default of 220.0 but no stated scaling). The PT ratio still matters when Basic Parameter Mode is Secondary.
  • Left out: password (1000H), the 100 ms refresh block 3000H (always secondary values, duplicates 4000H), the standard-register block 2000H (duplicates), the load-characteristic register 4040H (an ASCII code stored in a float), individual harmonics, max/min records with timestamps, sequence components, alarm, SOE and data-log blocks, per-phase energy (4620H-463DH), pulse counters and analog I/O.
  • Digital inputs DI7-DI28 and relays 5-8 follow the same pattern on further I/O modules (see manual Tables 76-77); only the first modules' points are listed.

Questions about the Eaton Power Xpert Meter 1000 Series (PXM 1000/1100/1200/1300)

What Modbus registers does the Eaton Power Xpert Meter 1000 Series (PXM 1000/1100/1200/1300) have?

This map lists 92 registers: 4 coils, 6 discrete inputs, 82 holding registers. 34 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Eaton Power Xpert Meter 1000 Series (PXM 1000/1100/1200/1300) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints register addresses in hex (4000H, 1001H). They go on the wire unchanged: its read example for frequency at 4000H sends start address bytes 40 00. Relays and digital inputs start at 0000H.

What byte order does the Eaton Power Xpert Meter 1000 Series (PXM 1000/1100/1200/1300) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Eaton Power Xpert Meter 1000 Series (PXM 1000/1100/1200/1300)?

Start with HR 16384 Frequency (Frequency (4000H)); HR 16386 Phase Voltage V1 (Phase voltage V1 (4002H)); HR 16402 Current I1 (Current I1 (4012H)); HR 16418 System Power Psum (Total active power (4022H)); HR 16442 System Power Factor PFsum (System power factor (403AH)); HR 16456 Energy IMP (Imported active energy (4048H)); HR 4125 Basic Parameter Mode (Basic Parameter Mode, set to 1 for primary values (101DH)).

How do I enable Modbus control of the Eaton Power Xpert Meter 1000 Series (PXM 1000/1100/1200/1300)?

Modbus RTU is the default protocol on the built-in RS-485 port (0FFEH = 0). Settings are written with function 16 (10H); one write may only touch registers inside a single settings region. To get primary-unit readings, write 1 to Basic Parameter Mode (101DH). This write is refused while the meter is sealed.
