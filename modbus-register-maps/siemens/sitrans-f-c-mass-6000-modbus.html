Short answer

The MASS 6000 Coriolis transmitter gets a Modbus RTU slave by fitting the USM II RS-485 add-on module. Data is held in holding registers and coils only. This map covers mass and volume flow, density, sensor temperature, fractions, totalizers, driver and identity registers, the MASS 6000 settings tables, sensor diagnostics, system status and the control coils.

Integration notes: Siemens SITRANS F C MASS 6000 with USM II Modbus RTU module

Integration in brief

Read holding registers (FC 03) from address 3000: seven floats give mass flow, volume flow, density, temperature and fractions, followed by the double totalizers at 3014 and 3018. All values are big-endian, high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the USM II Modbus RTU add-on module in the transmitter. The module adds a 'MODBUS RTU module' menu (between Reset mode and Service mode) for address, baud, parity/framing, timeouts and TAG; the same settings are writable at addresses 528-530.

Byte order & addressing

  • Use the address column (0-based); 4:03001 is address 3000, as the manual's example frame shows.
  • Max 26 registers per read and 25 per write.
  • No input registers or discrete inputs: everything is holding registers and coils.
  • 3099 picks the process-data update rate set (2 Hz up to 30 Hz mass flow); the manual prints the five sets as a numbered list without stating the register value of each, so no value table is given.

Network setup

  • Factory settings: address 1, 19200 baud, even parity, 1 stop bit; response delay 0, interframe space 3.5 characters.
  • Baud 1200-115200; framing 8E1, 8O1, 8N2 or 8N1.
  • RS-485 2-wire on screw terminals; up to 31 devices per segment without repeaters.
  • Modbus settings live in the module; after swapping the module they must be written again from the master.

Watch out for

  • Zero adjust progress (3211) is a float 0-100 % on MASS 6000 but a byte state on MAG 6000.
  • If the reply is not ready within the response timeout the module returns exception 6 (busy); repeat the request.

Notes on this map

  • Word order: the manual states the module is big-endian, most significant byte first, and its float table and example frame (4:03001 read as 40 C3 52 93 = 6.10383 kg/s) put the high word in register N. Floats, doubles and double words are therefore listed as ABCD.
  • 'Byte' values sit in the low byte of one register and are listed as UINT16 (0-255).
  • Units of the process values and totalizers follow the unit registers (2904-2917, ID tables in Appendix B.1/B.2). The 'point' registers set the number of decimals (0-6) shown on the display.
  • Adding 10000 to the address of a writable register returns its minimum allowed value, adding 20000 returns its maximum (these mirror registers are not listed).
  • Values printed as (1/100%) are fractions where 1.0 = 100 % (the manual's example: 0.02 = 2 %).
  • Left out: capability bits (603, 3-byte array) and the 54-byte error pending / error log lists (2702, 2729); their record layout is in Appendix B.4.
  • Error numbers are listed in the SITRANS F M / F C transmitter operating instructions, not in this manual.
  • Process values 3000-3012 are in fixed SI units (kg/s, m3/s, kg/m3, °C) as printed; the totalizers are kg or m3 depending on the totalizer selection.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Siemens SITRANS F C MASS 6000 with USM II Modbus RTU module

What Modbus registers does the Siemens SITRANS F C MASS 6000 with USM II Modbus RTU module have?

This map lists 163 registers: 8 coils, 155 holding registers. 104 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Siemens SITRANS F C MASS 6000 with USM II Modbus RTU module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every row prints both the Modbus register (4:0xxxx / 0:0xxxx, 1-based) and the Modbus address (0-based) sent on the wire; this map uses the address column. The manual's own example reads absolute massflow 4:03001 with query address 0x0BB8 (3000).

What byte order does the Siemens SITRANS F C MASS 6000 with USM II Modbus RTU module use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Siemens SITRANS F C MASS 6000 with USM II Modbus RTU module?

Start with HR 3000 Absolute Massflow (Mass flow); HR 3002 Absolute Volumeflow (Volume flow); HR 3004 Absolute Density (Density); HR 3006 Sensor temperature (Sensor temperature); HR 3014 Totalizer 1 (Totalizer 1 (double)); HR 3200 System status (System status bits).

How do I enable Modbus control of the Siemens SITRANS F C MASS 6000 with USM II Modbus RTU module?

Fit the USM II Modbus RTU add-on module in the transmitter. The module adds a 'MODBUS RTU module' menu (between Reset mode and Service mode) for address, baud, parity/framing, timeouts and TAG; the same settings are writable at addresses 528-530.
