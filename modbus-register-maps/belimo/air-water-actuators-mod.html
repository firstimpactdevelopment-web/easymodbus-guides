Belimo Air/water actuators with Modbus RTU (..24A-MOD) Modbus register map

Updated 28 October 2026

Short answer

Belimo's standard damper and valve actuators in the -MOD version speak Modbus RTU on RS-485 directly. The map is small and flat: a position setpoint, an override, position feedback and an optional sensor input in registers 1-13, then identity, fault flags, Min/Max limits, the bus watchdog and the setpoint source from register 100 up. Everything is a 16-bit unsigned value.

This page lists 22 Modbus registers for the Belimo Air/water actuators with Modbus RTU (..24A-MOD) — 11 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Belimo’s own free documentation (linked below) and checked against it.

Integration notes: Belimo Air/water actuators with Modbus RTU (..24A-MOD)

Integration in brief

Wire to the RS-485 terminals, set address and frame with the Belimo Assistant app (or the Address button quick-addressing), then write the position in 0.01 % to register 1 (wire address 0) and poll registers 5 and 105. Leave Setpoint source (No. 119) at Bus, its default.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is active out of the box on -MOD actuators; Setpoint source (No. 119) defaults to Bus. Address (1-247), baud rate and frame are set with the Belimo Assistant 2 app or tool, and the address can also be set with the Address and Adaption buttons (see the product datasheet).

Communication loss & watchdog

Not monitored by default. Set Bus fail position (No. 109) and Timeout for bus watchdog (No. 110, 0-3600 s; 0 = off, 120 s default once a fail position is set). If neither No. 1 nor No. 2 is written within the timeout, the actuator goes to the fail position and bit 10 of No. 105 is set. In hybrid mode (Setpoint source = Analog) bus monitoring is not active.

Byte order & addressing

  • The No. column is 1-based; subtract 1 for the wire address (setpoint = address 0).
  • Min and Max must stay at least 20 % apart (Min <= Max - 20 %, Max >= Min + 20 %).
  • Registers that a device or its settings don't support read 65535.

Network setup

  • Factory frame is 38400 baud, 8 data bits, no parity, 2 stop bits (1-8-N-2), address 1.
  • Supported frames: 1-8-N-2, 1-8-N-1, 1-8-E-1, 1-8-O-1; baud 9600-115200.
  • Up to 32 nodes per segment without a repeater; terminate the bus ends with 120 ohm.

Watch out for

  • Don't write the persistent registers (No. 101 and up) on every poll cycle - they live in non-volatile memory.
  • Fast open / Fast close overrides add mechanical wear; Belimo suggests keeping them for events like frost protection.

Notes on this map

  • Belimo states that all register values are unsigned 16-bit integers; a register that does not apply to the device or its settings reads 65535.
  • Sensor 1 value (No. 9) changes meaning with Sensor 1 type (No. 108): mV for Active, ohms for the passive types, 0/1 for Switch (scale 1), and 0.1 °C or 0.1 °F for the PT1000/NI1000/NTC10K2 types. It is listed raw (scale 1); multiply by 0.1 yourself for the temperature types.
  • Writable registers above No. 100 are stored in non-volatile memory; Belimo says not to write them on a regular basis.
  • No. 190/191 exist only on electronic fail-safe actuators; other types return 65535.
  • Registers 7, 8, 10-12 and 111-118 are unused in this actuator range and are not listed.
  • Read Discrete Inputs (FC 2) can also read the bits of No. 105: start bit address = 104 x 16 = 1664.

Questions about the Belimo Air/water actuators with Modbus RTU (..24A-MOD)

What Modbus registers does the Belimo Air/water actuators with Modbus RTU (..24A-MOD) have?

This map lists 22 registers: 22 holding registers. 11 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Belimo Air/water actuators with Modbus RTU (..24A-MOD) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Belimo prints each register twice: 'No.' counts from 1 and 'Address' from 0, and the documented value here is the No. column. Register No. 1 (setpoint) is wire address 0. Every value sits in one flat table, so holding-register reads (FC 3) and writes (FC 6/16) reach everything; FC 4 input-register reads of the same addresses also work.

What are the minimum Modbus registers to integrate the Belimo Air/water actuators with Modbus RTU (..24A-MOD)?

Start with HR 0 Setpoint (Position setpoint, 0.01 %); HR 1 Override control (Override (open/close/min/mid/max)); HR 4 Relative position (Relative position feedback); HR 104 Malfunction and service information (Fault and service flags); HR 118 Setpoint source (Setpoint source must be Bus); HR 108 Bus fail position (Bus fail position); HR 109 Timeout for bus watchdog (Bus watchdog timeout).

How do I enable Modbus control of the Belimo Air/water actuators with Modbus RTU (..24A-MOD)?

Modbus is active out of the box on -MOD actuators; Setpoint source (No. 119) defaults to Bus. Address (1-247), baud rate and frame are set with the Belimo Assistant 2 app or tool, and the address can also be set with the Address and Adaption buttons (see the product datasheet).

What happens when the Belimo Air/water actuators with Modbus RTU (..24A-MOD) loses Modbus communication?

Not monitored by default. Set Bus fail position (No. 109) and Timeout for bus watchdog (No. 110, 0-3600 s; 0 = off, 120 s default once a fail position is set). If neither No. 1 nor No. 2 is written within the timeout, the actuator goes to the fail position and bit 10 of No. 105 is set. In hybrid mode (Setpoint source = Analog) bus monitoring is not active.
