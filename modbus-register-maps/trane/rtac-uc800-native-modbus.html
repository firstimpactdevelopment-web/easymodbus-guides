Short answer

Trane's RTAC is an air-cooled helical-rotary (screw) chiller. On the Tracer UC800 controller it offers a compact native Modbus map in which every point is one 16-bit register with a fixed SI scaling per register type (temperatures in 0.01 °C, pressures in 0.1 kPa absolute, percent in 0.005 % steps). The map covers BAS commands, water and refrigerant temperatures and pressures, oil values, starter currents and voltages, AFD values and status flags.

Integration notes: Trane RTAC air-cooled helical-rotary chiller (UC800 native Modbus profile)

Integration in brief

Write 40001 (auto/stop), 40002 (mode) and 40003 (chilled-water setpoint, 0.01 °C) and poll the 3xxxx input registers with function 04. Every value is a single register; apply the per-type scale from the object-format table.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The points list does not describe setup; it names BAS-SVP083*-EN as its reference integration guide for selecting Modbus on the controller.

Byte order & addressing

  • Percent registers count in 0.005 % steps (20,000 = 100 %).
  • Temperatures are signed hundredths of a degree Celsius; pressures are tenths of a kPa absolute (subtract atmospheric pressure, also published at 30014, for gauge).

Network setup

  • Unit address, baud and TCP settings are set in the controller's protocol configuration; the list gives no defaults.

Watch out for

  • Mode command 40002 accepts only 0 = Cool and 2 = Ice on this chiller.

Notes on this map

  • The object-format table gives one encoding per register type: Binary/Enumeration/Current/Voltage/Power/Frequency/Pressure are unsigned 16-bit; Percent, Percent_1, Power Factor, Differential Pressure and Temperature are signed 16-bit. Scales: Temperature 0.01 °C, Pressure 0.1 kPa absolute, Percent 0.005 % (20,000 = 100 %), Percent_1 1 %, Frequency 0.1 Hz, Power kW, Current A, Voltage V. Rows typed 'Temp' are read as Temperature.
  • Values are always SI in this native map; there is no I-P switch in the list.
  • Left out: compressor starts and run time (30015-30030), typed Count (u32) and Time (u32) over two registers; the list does not state the word order.
  • Left out: Number of Circuits / Compressors (30071-30073), typed Count (u32) but printed as single registers, and Chiller Design Capacity (30074), typed 'Number', which the format table does not define.
  • This RTAC also appears in the library under its Symbio 800 points list (rtac-symbio-800, BAS-PTS023A-EN); that list uses 32-bit float registers and different numbers. Use this map only for the UC800 native Modbus profile.
  • The points list does not name the Modbus transport (RTU or TCP); it refers to BAS-SVP083*-EN for protocol setup, so confirm the transport in the controller configuration.
  • Software Type and Software Revision (30001, 30002) are typed 'NA', which the format table does not list; they are shown as plain unsigned 16-bit values (the table's 'None' type).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Trane RTAC air-cooled helical-rotary chiller (UC800 native Modbus profile)

What Modbus registers does the Trane RTAC air-cooled helical-rotary chiller (UC800 native Modbus profile) have?

This map lists 87 registers: 82 input registers, 5 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Trane RTAC air-cooled helical-rotary chiller (UC800 native Modbus profile) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The list prints Modicon register numbers: 4xxxx are holding registers and 3xxxx input registers, so 40001 is holding register address 0 and 30034 is input register address 33.

What are the minimum Modbus registers to integrate the Trane RTAC air-cooled helical-rotary chiller (UC800 native Modbus profile)?

Start with IR 85 Chiller Running Indicator (Chiller running indicator); IR 96 Chiller Running Status (Chiller running status); IR 33 Evaporator Leaving Water Temp (Evaporator leaving water temperature); IR 2 Active Chilled Water Setpoint (Active chilled water setpoint); IR 4 Actual Running Capacity (Actual running capacity); IR 93 Alarm Present (Alarm present); HR 0 BAS Chiller Auto Stop Command (Chiller auto/stop command); HR 1 BAS Chiller Mode Command (Chiller mode command); HR 2 Chilled Water Setpoint (Chilled water setpoint (BAS)); HR 7 Remote Diagnostic Reset Command (Diagnostic reset).
