Daikin EKMBDXB Modbus Interface DIII Modbus register map

Updated 17 November 2026

Short answer

The EKMBDXB connects to the Daikin DIII-net and presents up to 64 indoor groups (DIII addresses 1-00 to 4-15) to a BMS as Modbus RTU registers. Each group has capability, status, setpoint, room temperature, water setpoint, error and lock registers. This map lists the gateway status words and the full register set of group 1-00 plus the formula for the other groups.

This page lists 34 Modbus registers for the Daikin EKMBDXB Modbus Interface DIII — 9 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Daikin’s own free documentation (linked below) and checked against it.

Integration notes: Daikin EKMBDXB Modbus Interface DIII

Integration in brief

Wait for 30001 bit 0 = ready, read 30002-30005 to find connected groups, then poll each group's 32001-32005 status block. To command, copy the current status bits into 42001/42002 first, change only what you need, and write setpoints to 42003 in 0.1 °C.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set baud rate, parity/stop bits and the Modbus address (1-15) on dip switches DS1/DS2 of the interface; the DIII units are discovered automatically after power-up.

Byte order & addressing

  • Holding registers only take the unit's values at discovery; the BMS must copy the related input-register bits into a holding register before changing one field, or it will overwrite the others.
  • Write the fan control flag (42001 bits 4-7) as 6 when commanding fan speed or direction, 0 if the unit has no fan control.
  • Do not write the same register more often than every 0.5 s. Each indoor unit accepts at most 7000 control commands per year.

Network setup

  • Modbus address 1-15 on DS2; baud 9600 or 19200 and Even/Odd/None parity on DS1.
  • Set termination with the SS switches at the end of the RS485 line.

Watch out for

  • Central forced off (41001) and the button locks (42801+) only work when no other DIII central controller (e.g. iTM) is on the same DIII-net.
  • After a power cut of the interface, forced off and locks must be written again once the units are rediscovered.

Notes on this map

  • Only DIII group 1-00 is listed. Register of another group = base register + ((upper address - 1) x 16 + lower address) x step. Steps: 31001/42001 blocks step 3, 31401/32801/42401 step 4, 32001 step 6, 33601 step 2, 42801 step 1. Example: 4-15 capability = 31190.
  • Status 1 (32001): bits 12-14 fan speed 0-7 (meaning depends on the fan-speed step capability; 3-step: 0 auto, 1 L, 3 M, 5 H), bits 8-10 fan direction (0-4 P0-P4, 6 stop, 7 swing). Status 2 (32002): bits 0-3 operation mode (0 fan, 1 heat, 2 cool, 3 auto, 4 ventilation, 7 dry), bits 4-7 filter sign (0 off, 1-15 on), bits 8-11 actual operation (0 fan, 1 heat, 2 cool), bits 14-15 cool/heat master (0 undecided, 1 slave, 2 master).
  • Control 1 (42001): bit 0 on/off, bits 4-7 fan control flag (6 = fan control, 0 = none), bits 8-10 fan direction, bits 12-14 fan speed. Control 2 (42002): bits 0-3 mode (0 fan, 1 heat, 2 cool, 3 auto, 4 ventilation, 6 setpoint/dependent, 7 dry), bits 4-7 filter sign reset (15 = reset, then write 0 again).
  • Setpoint range fields are signed 8-bit values in 1 °C packed into a 16-bit word; they are listed as UINT16 because the schema has no 8-bit type. The storage (hot water) setpoint byte in 32803/42403 is described both as 'unity 1 °C' and as 'value multiplied by 10', so its scale is not given here.
  • Error code 33601: high byte and low byte are the two ASCII characters of the Daikin code (e.g. 'C7'); '00' means no error. 33602 holds unit number (bits 12-15), warning/alarm/error flags (bits 10/9/8) and sub-code (bits 0-5).
  • Room setpoint, water setpoints and temperatures are signed 16-bit in 0.1 °C. Out-of-range setpoints are clamped by the unit; read the input register for the result.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Daikin EKMBDXB Modbus Interface DIII

What Modbus registers does the Daikin EKMBDXB Modbus Interface DIII have?

This map lists 34 registers: 25 input registers, 9 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Daikin EKMBDXB Modbus Interface DIII Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints 30001/40001-style registers and says the request address starts at zero: 30001 is sent as 0 and 40001 as 0. Its example frames agree (31001 is requested as 0x03E8, 42002 as 0x07D1).

What are the minimum Modbus registers to integrate the Daikin EKMBDXB Modbus Interface DIII?

Start with IR 0 Interface status (Interface ready); IR 1 DIII units 1-00..1-15 connected (Groups 1-00..1-15 connected); IR 2000 1-00 status 1 (1-00 on/off, fan, thermo); IR 2001 1-00 status 2 (1-00 mode, filter, defrost); IR 2004 1-00 room temperature (1-00 room temperature); IR 3600 1-00 error code (1-00 error code); HR 2000 1-00 control 1 (1-00 on/off and fan command); HR 2002 1-00 room setpoint command (1-00 setpoint command).

How do I enable Modbus control of the Daikin EKMBDXB Modbus Interface DIII?

Set baud rate, parity/stop bits and the Modbus address (1-15) on dip switches DS1/DS2 of the interface; the DIII units are discovered automatically after power-up.
