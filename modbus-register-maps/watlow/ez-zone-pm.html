Short answer

The EZ-ZONE PM is Watlow's panel-mount PID and limit controller family. With the Modbus RTU option every parameter has a fixed register: floats take two registers and enumerated settings use Watlow's numeric codes (for example 106 = Yes). This map covers the operations values an integrator needs: input process values and errors, loop set points, control mode, PID terms, output power, autotune, event and limit states, alarm 1 set points and status, and the basic communications settings. The full parameter list is in the manual.

Integration notes: Watlow EZ-ZONE PM PID / limit / integrated controller (Modbus RTU)

Integration in brief

Read the process value as a low-word-first float at 360-361 and the closed-loop set point at 2160-2161; write the set point with function 16. Control mode is at 1880 and output power at 1908.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set Protocol to Modbus RTU and set the Modbus address, baud rate and parity in the Communications menu of the Setup Page on the front panel.

Byte order & addressing

  • Floats are low word first by default (CDAB).
  • Watlow uses numeric codes for enumerations (106 = Yes, 59 = No).
  • Temperature unit for the comms channel is set separately (2490).

Network setup

  • Defaults per the manual footnote: 8 data bits, no parity, 1 stop bit; Modbus address 1 (range 1-247).

Watch out for

  • Settings written over the network are not saved to EEPROM by default; the Nonvolatile Memory Save parameter changes this. The EEPROM is rated for about 1,000,000 writes, so avoid continuous writes in a loop.
  • Some parameters exist only on some model configurations (PID, limit, integrated).

Notes on this map

  • Watlow does not appear to host this communications manual publicly; the copy linked is a distributor (Instrumart) copy of the unaltered Watlow manual, Rev. B from 2007.
  • Floats are IEEE 754 in two registers with the low word first by default (CDAB): register 360 holds the low word and 361 the high word, as the manual's example shows. The order can be changed to high-low in the Communications menu; this map assumes the default.
  • Integers are unsigned 16-bit. Enumerated parameters use Watlow codes, e.g. 59 = No, 106 = Yes, 62 = Off.
  • Temperatures follow the display units chosen for the communications port (°F by default).
  • Only a subset is listed (operations-page values, alarm 1 and comms basics); alarms 2-4 follow the same pattern at other registers given in the manual, as do setup and profile parameters.
  • Left out: the word-order and non-volatile-save registers, which the manual prints with the same address (2494); the baud-rate register, whose value codes are not printed. The manual gives the default serial format as 9,600 baud in its footnotes but lists 38,400 as the baud-rate default, so the default baud is left blank.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Watlow EZ-ZONE PM PID / limit / integrated controller (Modbus RTU)

What Modbus registers does the Watlow EZ-ZONE PM PID / limit / integrated controller (Modbus RTU) have?

This map lists 45 registers: 45 holding registers. 26 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Watlow EZ-ZONE PM PID / limit / integrated controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists 'relative' Modbus registers (less the 40,001 offset) and sends them unchanged: the worked read of analog input 1 sends 360 as hex 01 68. In a Modicon-style tool, 360 is 40361.

What byte order does the Watlow EZ-ZONE PM PID / limit / integrated controller (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Watlow EZ-ZONE PM PID / limit / integrated controller (Modbus RTU)?

Start with HR 360 Analog input 1 process value (Analog input 1 process value); HR 362 Analog input 1 error status (Input 1 error status); HR 2160 Closed loop set point (Closed loop set point); HR 1880 Control mode (Control mode); HR 1908 Control loop output power (Output power); HR 1928 Loop error status (Loop error status).

How do I enable Modbus control of the Watlow EZ-ZONE PM PID / limit / integrated controller (Modbus RTU)?

Set Protocol to Modbus RTU and set the Modbus address, baud rate and parity in the Communications menu of the Setup Page on the front panel.
