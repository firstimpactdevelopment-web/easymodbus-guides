Short answer

The PR223DS trip unit on Tmax moulded-case breakers has a built-in Modbus RTU interface. Measurements, status, alarms and trip data are input registers; open, close and reset commands are single holding registers set to 1. 32-bit power and energy values are sent low word first.

Integration notes: ABB SACE Tmax PR223DS trip unit (Modbus RTU)

Integration in brief

Read input registers 30101-30156 with function 4 for currents, voltages, power and energy, and 30034-30036 for status, alarms and trips. Write 1 to 40001 / 40003 to open or close.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is built into the trip unit; address, baud, parity and addressing type are set locally with the ABB Test Unit. Remote commands need the trip unit in Remote mode (LOCAL/REMOTE button); CB open/close also fails if the motor operator selector is on MANUAL or the motor command is faulty.

Byte order & addressing

  • 32-bit values are low word first.
  • Measurements use function 4 (input registers).
  • Event bits in 30033 clear after reading.

Network setup

  • Defaults: address 247, 19200 baud, even parity; 9600 baud and odd/no parity also allowed.

Watch out for

  • Factory address is 247.
  • Only one command is processed at a time; a second pending command is refused.

Notes on this map

  • The manual says double words are little-endian by word (least significant word first) and big-endian within each word, so 32-bit registers here are CDAB.
  • Default communication parameters (address 247, 19200 baud, even parity, Standard addressing) apply until set with the Test Unit; they can only be changed locally.
  • Currents read in amps once the nominal current is set; if 'Nominal current unknown' (status bit 13) is set they read as a percentage of In (150 = 1.5 In).
  • Voltages, power, energy and frequency need the VM210 voltage module; without it they read 0.
  • Commands run only in remote operating mode and one at a time. The remote signalling contact commands are left out because their hex addresses (0029h, 002Ah) do not match the absolute addresses 40041/40043.
  • Read the currents as a 5-register block, not one at a time, as the manual asks.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ABB SACE Tmax PR223DS trip unit (Modbus RTU)

What Modbus registers does the ABB SACE Tmax PR223DS trip unit (Modbus RTU) have?

This map lists 47 registers: 41 input registers, 6 holding registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB SACE Tmax PR223DS trip unit (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each register row gives the absolute address (30001/40001 style) and a 'Relative Address - 1 (HEX)' column that goes in the Modbus message (30101 = 0064h, 40001 = 0000h). This applies with the default 'Standard' addressing type.

What byte order does the ABB SACE Tmax PR223DS trip unit (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ABB SACE Tmax PR223DS trip unit (Modbus RTU)?

Start with IR 33 Status (CB open/closed/tripped, local/remote); IR 35 Trips (Which protection tripped); IR 100 RMS current phase 1 (Phase 1 current); IR 119 Total active power (Total active power); IR 145 Positive active energy (Active energy); HR 0 CB open command (Open command).

How do I enable Modbus control of the ABB SACE Tmax PR223DS trip unit (Modbus RTU)?

Modbus is built into the trip unit; address, baud, parity and addressing type are set locally with the ABB Test Unit. Remote commands need the trip unit in Remote mode (LOCAL/REMOTE button); CB open/close also fails if the motor operator selector is on MANUAL or the motor command is faulty.
