Fuji Electric PXR micro controller X (RS-485 Modbus option) Modbus register map

Updated 17 November 2026

Short answer

The PXR is a Fuji Electric PID temperature controller. With the RS-485 option it is a Modbus RTU slave whose data appear twice: once as internal percentage values (3xxxx/4xxxx) and once in engineering units at the same numbers plus 1000. This map uses the engineering-unit block: PV, SV, MV and status in the input registers, control, alarm and ramp/soak settings in the holding registers, plus alarm bits.

This page lists 103 Modbus registers for the Fuji Electric PXR micro controller X (RS-485 Modbus option) — 82 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Fuji Electric’s own free documentation (linked below) and checked against it.

Integration notes: Fuji Electric PXR micro controller X (RS-485 Modbus option)

Integration in brief

Set CoM parity and a station number on the keypad, then read input registers 31001-31010 (PV, current SV, DV, MV, status) in one request and write the setpoint to 41003.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Order the RS-485 option. On the keypad set STno (1-255; 0 stops communication), CoM (parity) and PCoL = 1 (Modbus) where shown.

Byte order & addressing

  • Speed is fixed at 9600 bps with 8 data bits and 1 stop bit; only parity is selectable (0 odd, 1 even, 2 none).
  • Monitor SV at 31002, not 41003: the face-panel SV differs while SV-1 or ramp/soak is active.
  • When changing the decimal point over the bus, rewrite the input scale limits as well.

Network setup

  • Factory defaults: station 1, odd parity, 9600 bps, 8 data bits, 1 stop bit.

Watch out for

  • Every write is saved to EEPROM automatically (about 100,000 writes); avoid cyclic writes and wait a few seconds after writing before removing power.

Notes on this map

  • Only the engineering-unit block (31001+, 41001+) is listed. The internal-value block at 30001/40001 holds the same items as 0.00-100.00 % of the input range for range-dependent data.
  • Values carry no decimal point. PV/SV-type values use the P-dP decimal point (41020); P, D, filter and heater current have one decimal; MV, output limits, dead band and output convergence have two.
  • On over/under-range or open input the PV reads 105 % or -5 % of the range; check 31008.
  • Reserved/'do not use' registers and the display-mask items (41101-41113) are omitted; DI and alarm option codes are not reproduced.
  • Writes are accepted beyond the setting range without error; keep values in range.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Fuji Electric PXR micro controller X (RS-485 Modbus option)

What Modbus registers does the Fuji Electric PXR micro controller X (RS-485 Modbus option) have?

This map lists 103 registers: 1 coil, 7 discrete inputs, 14 input registers, 81 holding registers. 82 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Fuji Electric PXR micro controller X (RS-485 Modbus option) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are printed Modicon-style with the relative (wire) address beside them; the manual says the wire address is the lower four digits minus 1 (41001 = 03E8H).

What are the minimum Modbus registers to integrate the Fuji Electric PXR micro controller X (RS-485 Modbus option)?

Start with IR 1000 PV (PV (31001)); IR 1001 Current SV (Current SV (31002)); IR 1003 MV output 1 (Output 1 MV (31004)); IR 1006 Alarm status (Alarm status (31007)); IR 1007 Input/unit abnormal status (Input error status (31008)); HR 1002 Face panel SV (Face panel SV (41003)); HR 1003 Control RUN/standby (RUN/standby (41004)); HR 1019 Decimal point place (Decimal point (41020)).

How do I enable Modbus control of the Fuji Electric PXR micro controller X (RS-485 Modbus option)?

Order the RS-485 option. On the keypad set STno (1-255; 0 stops communication), CoM (parity) and PCoL = 1 (Modbus) where shown.
