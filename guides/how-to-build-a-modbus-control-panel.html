How do I build a control panel for several Modbus devices in Easy Modbus?

Updated 30 September 2026

Short answer

On the main screen tap Control Panel Builder · Beta (or ⋮ menu → Control panels (beta)), then Create a Panel. Pick the first device and name the panel; it opens in Edit mode. Add more devices from ⋮ → Devices… → Add a device (up to 32 per panel), then Add Control, choose which device each control is for, pick a reading and a control type, and arrange the tiles. Tap Done to run it. The free version keeps one panel on one device; the one-time unlock gives unlimited panels of up to 32 devices each.

Beta. The Control Panel Builder is new. It uses the same controls and safety rules as custom remotes, but test a panel on non-critical equipment before you rely on it.

What a control panel is

A custom remote is one screen for one device. A control panel is one screen for a whole set of equipment — the four energy meters behind one gateway, a row of VFDs, a boiler and its pumps. Each control on the panel carries its own target device, so one tap reads all of them and every write goes to the device that control belongs to. A device here is exactly what it is everywhere else in Easy Modbus: a host (IP address or name), a port, a unit ID and a framing (Modbus TCP, or RTU over TCP for a serial gateway). Two meters behind one gateway are two devices with the same IP and different unit IDs.

Before you start

  • Add each device to your device list (Find Devices, Add by IP Address, or Find unit IDs on a gateway) and save the readings you want on the panel. You can also add devices and readings while building.
  • Readings you save on a device are reused by the panel, with their data type, word order, multiplier, units, named states and write limits.

Step 1 — Create the panel

  1. Main screen → Control Panel Builder · Beta.
  2. Tap Create a Panel (or + in the top bar once you have one).
  3. Choose the device to start with — this becomes the panel's primary device — and give the panel a name.

The new panel opens in Edit mode. Nothing is sent to any device while you edit.

Step 2 — Add the other devices

  1. ⋮ menu → Devices…. The title shows how many of the 32 you are using.
  2. Tap Add a device and pick one of your saved devices, or Enter a device by hand (IP address or hostname, port, unit ID, framing, optional name). A device entered by hand is also added to your device list, so you can build readings for it.
  3. To take a device off the panel, tap it in the list. Its controls move to the primary device — the app tells you how many first. The primary itself stays.

Step 3 — Add controls

  1. Tap Add Control and choose which device the control is for.
  2. Choose Pick from this device’s readings or Enter an address by hand.
  3. Pick the control type: Readout, Setpoint, Toggle, Button, Multi-state or Put back (the same six as a remote — see the custom remote guide for what each does).

Tap a tile for its options. Panels add Change device, which points a control at another device on the panel while keeping its register and scaling — the quick way to repeat “kW” for meter 2, 3 and 4. With more than one device, the options title shows which device the control talks to, so give controls clear names (“M2 kW”, not just “kW”).

Step 4 — Lay it out

  • ⋮ → Grid width sets 2 to 6 columns (a wide panel for a tablet, a narrow one for a phone in your pocket).
  • Drag tiles to arrange them; tap for Width, Colour, Card style and Large value text.
  • ⋮ → Rename panel or Delete panel.

Step 5 — Run it

Tap Done. The panel reads each device's controls in as few requests as that device allows, one device after another, and skips a device for the rest of the pass once it stops answering — so one dead meter does not hold up the other thirty-one. The status line shows how many devices the panel drives, or how many controls failed. Writing works exactly as it does everywhere else: turn on Write mode from the main screen first, every write is read back and logged, and a toggle will not write until a value has been read.

Share or move a panel

  • Export: on the Control Panels list, long-press a panel and choose where to save it. It is saved as a .empanel file (plain JSON: the layout, each device's host, port, unit ID and framing, and each control's register and scaling).
  • Import: ⋮ → Import panel and pick the file. An import always becomes a new panel. Devices you do not have on this phone are reached using the addresses saved in the file.
  • Panels are stored on the phone only and excluded from cloud backup; the export file is the way to move one.

A .empanel file contains IP addresses and unit IDs of a customer's equipment. Treat it like the register map it is.
