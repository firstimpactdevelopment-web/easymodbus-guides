Neptronic SKVF evaporative cooler / humidifier (Modbus communication module) Modbus register map

Updated 19 November 2026

Short answer

The Neptronic SKVF is an evaporative cooler that can run humidification or cooling control profiles. Its Modbus RTU module exposes holding registers only: signal voltages, room and supply RH and temperature readings, demand and output, humidity and cooling set points with PID terms, water supply, drain and drying settings, inputs and relays as 0/1 registers, and state, alarm, request and control-profile codes.

This page lists 143 Modbus registers for the Neptronic SKVF evaporative cooler / humidifier (Modbus communication module) — 95 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Neptronic’s own free documentation (linked below) and checked against it.

Integration notes: Neptronic SKVF evaporative cooler / humidifier (Modbus communication module)

Integration in brief

Read Room RH (6008), Room Temperature (6012), Power Output (6028), State (15009) and System Alarm (15010). For BAS control choose a network Control Profile (15016) and Control Demand Source (15027 = Network) and write Control Network Demand (6112).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Modbus communication module, set the address in the device menu (or register 0) and choose the control profile (15016) and sources (15019-15028) if the BAS supplies readings or demand.

Communication loss & watchdog

A Network Timeout exists but it is printed as a two-register value without word order (6117-6118), so it is not listed; Network Control State (12000) flags a network fault.

Byte order & addressing

  • All points, binary ones included, are holding registers (FC03/06/16 only).
  • Default framing is no parity with 2 stop bits.

Network setup

  • RS-485 two-wire, RTU; 9600-57600 baud or auto baud detection.
  • Parity/stop bits via register 2 or the Modbus Comport Config menu item.

Watch out for

  • Control Profile chooses humidification (Hum) or cooling (Cool) logic; network profiles need the matching network registers written.

Notes on this map

  • Only function codes 03, 06 and 16 are supported, so binary points (inputs, relays, flags) are 16-bit holding registers holding 0 or 1.
  • 'Scale N' with 'Value x N' means the raw value is the engineering value times N; this map stores the multiplier 1/N.
  • Temperature and capacity units follow Modbus Server Units (415001): 0 metric, 1 imperial.
  • The guide text calls automatic baud detection the default, while register 1 lists 19200 as its default value; the baud default is left blank here.
  • Default unit address is not stated; it is set from the device menu or register 0.
  • Left out: product name ASCII registers 3-6; 2001 (a second 'Control Signal' row) and 15003/15004 (two rows both named 'Control Signal Type'), where it is unclear which is which; ECM Fan Signal 4001, RH and temperature Supply High Limit Proportional Band 6101/6111 (scale and example disagree); the temperature-control block 6004-6007 (names repeat Control Input/Min/Max/Bias and the example is in %); Room RH Bias 6011 and Room Temperature Network Reading 6082 (typed unsigned with negative ranges); Alarm LED / Power LED 11005/11006 (holding numbers 411004/411005 clash with the protocol column).
  • Several values are printed as two- or four-register entries marked (0)...(3) - Demand, run/on/service time counters, Room Temperature Setpoint, Room RH and Room Temperature Demand Proportional Band/Gain, Water Supply Duty Cycle/Period, Water Treatment Service Interval, Keep Alive, Demand Low Dead Band and Network Timeout. No word order is given, so they are left out.
  • System Power State (15000) is printed read-only in this guide.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Neptronic SKVF evaporative cooler / humidifier (Modbus communication module)

What Modbus registers does the Neptronic SKVF evaporative cooler / humidifier (Modbus communication module) have?

This map lists 143 registers: 143 holding registers. 95 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Neptronic SKVF evaporative cooler / humidifier (Modbus communication module) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints a protocol-base (0-based) address and a six-digit holding register (base 400001) side by side, e.g. 6005 / 406006. The protocol-base number is the wire address.

What are the minimum Modbus registers to integrate the Neptronic SKVF evaporative cooler / humidifier (Modbus communication module)?

Start with HR 6008 Room RH (Room RH); HR 6012 Room Temperature (Room temperature); HR 6028 Power Output (Power output); HR 6073 Room RH Setpoint (Room RH set point); HR 15009 State (Unit state); HR 15010 System Alarm (System alarm); HR 15016 Control Profile (Control profile); HR 6112 Control Network Demand (Network demand).

How do I enable Modbus control of the Neptronic SKVF evaporative cooler / humidifier (Modbus communication module)?

Fit the Modbus communication module, set the address in the device menu (or register 0) and choose the control profile (15016) and sources (15019-15028) if the BAS supplies readings or demand.

What happens when the Neptronic SKVF evaporative cooler / humidifier (Modbus communication module) loses Modbus communication?

A Network Timeout exists but it is printed as a two-register value without word order (6117-6118), so it is not listed; Network Control State (12000) flags a network fault.
