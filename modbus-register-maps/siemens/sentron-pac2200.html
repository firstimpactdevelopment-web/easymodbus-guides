Short answer

Integration notes: Siemens SENTRON PAC2200

Integration in brief

On TCP variants, give the meter an address (DHCP is on by default) and poll port 502; on RTU variants use address 126 at 19200 8N2 unless changed. Read floats from offset 1 and energy doubles from offset 801, high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is the device's built-in interface. Set the MODBUS TCP or MODBUS RTU parameters in the device settings menu. Write access over the bus can be blocked by password protection, the IP filter or hardware write protection, which is toggled only with the SW key.

Byte order & addressing

  • Offsets are wire addresses: offset 1 is requested as address 1 (40002 in 1-based tools).
  • Floats and doubles are big-endian, high word first.
  • Energy counters are 64-bit IEEE doubles in Wh/varh/VAh.

Network setup

  • RS485 factory settings: address 126, 19200 baud, 8N2, response time 0 ms.
  • Ethernet factory settings: DHCP ON, Modbus port 502 (0...65534 configurable), IP filter OFF, HTTP port 80.
  • With the IP filter on, write requests from outside the meter's subnet are rejected.

Watch out for

  • Exception code F0 means write protection is active.
  • Latched diagnostic bits in offset 205 stay set until acknowledged through offset 60007.
  • Enabling or disabling password protection must be confirmed with the SW key on the device within 15 minutes.

Notes on this map

  • The register tables do not name a word order. We record ABCD (high word first) on PAC2200-specific evidence from its own manual: the Modbus FC 0x64 example frames (Appendix A.1, pp. 125-127) transmit unsigned longs (stated as big endian), floats and doubles most-significant byte first, e.g. a Wh double as 41 41 B4 EB 44 67 2E 00, and the FC 0x03 status structure at offset 205 puts byte 0 at mask 0x01000000. The FC 0x03 register order itself is not printed, so confirm with a known reading on site. The same order is confirmed for the PAC3200 by Siemens examples 40614428.
  • Addressing sources (PAC3200 examples): https://cache.industry.siemens.com/dl/files/428/40614428/att_923701/v2/40614428_Set22_DOC_v14_en.pdf ; https://cache.industry.siemens.com/dl/files/762/109779762/att_1028292/v1/109779762_LOGO_ModbusTCP_DOC_en.pdf ; S7-1200 library description: https://cache.industry.siemens.com/dl/files/428/40614428/att_15029/v1/40614428_librarydescription_s7-1200_modbustcp_v1d0_en.pdf
  • Factory settings: RTU variants use address 126, 19200 baud, 8N2, response time 0 ms; TCP variants ship with DHCP on and Modbus port 502.
  • Measured variables answer to FC 0x03 and FC 0x04 and are listed as holding registers. Commands 60001-60009 use FC 0x06; register 65290 uses FC 0x10.
  • Bits of the 32-bit status words use the bit number of the whole value (bit 0 = mask 0x00000001, bit 24 = mask 0x01000000).
  • The float copies of the energy counters (2801-2883) are omitted: several rows print units that contradict the name (active energy in varh, reactive in Wh).
  • Offset 593 is omitted: it is named active energy but printed with unit varh.
  • Offsets 545 and 799 (Unix time stamps), 60010 (format and length disagree), the FC 0x14 aggregation file block (30001+) and the FC 0x64 log readout are omitted.
  • Discrete input 129 is printed twice with two names (device/firmware update); it is left out. The manual marks discrete inputs 108-112 as RW, but FC 0x02 is read-only, so they are listed as read-only.
  • Register 60000 (reset to factory settings) exists but is deliberately not listed.
  • Registers 50011/50013 are writable only on 5 A devices; on 65 A devices they are read-only.
  • Offset 60008 (switching outputs) is omitted: its printed range (0FFh...1FFh) contradicts its byte description (byte 0 = 0 for output 0.0), so the command word cannot be built with certainty.
  • Offset 50147 (digital output timeout) is omitted: the two settings tables give different ranges (1...18000 s and 0.1...18000), which leaves its scaling uncertain. The function exists: an output switched over Modbus resets after the timeout; 0 disables it.
  • Registers 62991 (DHCP) and 63009 (password protection) are listed with range 0/1 only; the register table does not map the values to ON/OFF.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Siemens SENTRON PAC2200

What Modbus registers does the Siemens SENTRON PAC2200 have?

This map lists 146 registers: 16 discrete inputs, 130 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Siemens SENTRON PAC2200 Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Siemens lists every value by its register 'offset', which is the 0-based address sent in the request. Offset 1 (voltage L1-N) is requested as address 1, which a 1-based tool shows as 40002. The PAC2200 manual does not state this itself; it uses the same offset scheme and the same measured-value offsets as the PAC3200, for which two official Siemens application examples confirm it: entry 40614428 (Set 22, Table 3-12: offset 65 read at S7 MB_CLIENT address 40001 + 65) and entry 109779762 (LOGO! example, p. 13: offset 1 entered as LOGO! register 2).

What byte order does the Siemens SENTRON PAC2200 use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Siemens SENTRON PAC2200?

Start with HR 1 Voltage UL1-N (Voltage L1-N); HR 13 Current L1 (Current L1); HR 55 Frequency (Frequency); HR 65 Total active power (Total active power); HR 801 Active energy import tariff 1 (Active energy import tariff 1 (double)); HR 205 Device diagnostics and device status (Device diagnostics and status).

How do I enable Modbus control of the Siemens SENTRON PAC2200?

Modbus is the device's built-in interface. Set the MODBUS TCP or MODBUS RTU parameters in the device settings menu. Write access over the bus can be blocked by password protection, the IP filter or hardware write protection, which is toggled only with the SW key.
