Integration notes: Lenze SCF Series drive with Modbus module (basic network control)

Integration in brief

Set P14 = 01 and P43 = address, write 0 (or the password) to 40049 once after power-up, then write 0008h to 40002 to start and the speed in 0.1 Hz to 40041 (with P05 = 01). Read 40027 for the run status.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

P14 = 01 enables serial communication; P43 sets the address (1-247); P15 sets data format and watchdog.

Communication loss & watchdog

Fixed 10 s: if enabled via P15 and the master stops communicating while the drive is under network control, the drive stops.

Byte order & addressing

  • Use FC06, or FC16 with a length of 1, for every write.
  • The local STOP circuit stays active: input 1 (TB1 to TB2) must be asserted to start.

Network setup

  • Master at 9600 baud with the data format matching P15.

Watch out for

  • Lenze advises not to leave the slave at address 1 to avoid duplicates.

Notes on this map

  • Host: copy hosted by Precision Electric (a Lenze AC Tech distributor); no current copy was found on lenze.com.
  • This is a quick-start map only. The full register list is in the SCF ModBus Reference Guide RG-SFMOD, which was not available; other parameters follow 'Modbus register = parameter + 51' with scaling from the SCF manual.
  • Only 9600 baud is supported. Data format is chosen with P15: 02/03 = 8N2, 04/05 = 8E1, 06/07 = 8O1 (even numbers enable the 10 s watchdog).
  • Only one command bit per write to the control register.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lenze SCF Series drive with Modbus module (basic network control)

What Modbus registers does the Lenze SCF Series drive with Modbus module (basic network control) have?

This map lists 6 registers: 6 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lenze SCF Series drive with Modbus module (basic network control) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The note gives 4xxxx Modbus register numbers, which are AC Tech register + 1 (control register 1 = 40002). Wire address = Modbus register - 40001, so the control register is address 1. SCF parameter Pn is Modbus register n + 51 (P19 -> 40070).

What are the minimum Modbus registers to integrate the Lenze SCF Series drive with Modbus module (basic network control)?

Start with HR 48 Unlock (AC Tech register 48) (Unlock); HR 1 Drive control (AC Tech register 1) (Start / stop / direction); HR 40 Keypad speed command (AC Tech register 40) (Speed command); HR 26 Run status (AC Tech register 26, low byte) (Run status).

How do I enable Modbus control of the Lenze SCF Series drive with Modbus module (basic network control)?

P14 = 01 enables serial communication; P43 sets the address (1-247); P15 sets data format and watchdog.

What happens when the Lenze SCF Series drive with Modbus module (basic network control) loses Modbus communication?

Fixed 10 s: if enabled via P15 and the master stops communicating while the drive is under network control, the drive stops.

Where is the official Lenze SCF Series drive with Modbus module (basic network control) Modbus documentation?

The source is Application Note: Basic Network Control of the SCF Drive using ModBus Communications (AN0028/A1), revision 2008-01.
