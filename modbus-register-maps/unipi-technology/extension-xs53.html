Integration notes: Unipi Technology Unipi Extension xS53 analog input module

Integration in brief

Read the 8 analog inputs as CDAB floats from register 2 onward; set the type of each at registers 1017-1024.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is the native interface; nothing needs enabling. Factory settings are address 15, 19200 bps, 8N1.

Communication loss & watchdog

Master watchdog (MWD): enable it with the MWD Enable bit of the MWD status register and set the timeout in register 1008 (default 5000 ms). A watchdog reboot is flagged by the MWD Reboot Detected bit and coil 1000; the map does not describe the timeout behaviour further.

Byte order & addressing

  • 32-bit values (floats, counters and the PCB serial number) are low word first (CDAB).
  • Changes to RS-485 settings and other configuration need the Save configuration coil to survive a power cycle.

Network setup

  • Set the address register (1026) and the packed RS-485 configuration register (1025), then write 1 to the save coil (1003) so the settings are used on startup.

Notes on this map

  • Word order: the description sheet states 16-bit values are big endian (AB) and 32-bit values are mid-little endian (CDAB, low word first).
  • Registers marked Reserved - Do Not Use are left out.
  • Baud codes for the RS-485 configuration register: 11 = 2400, 12 = 4800, 13 = 9600, 14 = 19200, 15 = 38400, 4097 = 57600, 4098 = 115200 bps.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Unipi Technology Unipi Extension xS53 analog input module

What Modbus registers does the Unipi Technology Unipi Extension xS53 analog input module have?

This map lists 58 registers: 15 coils, 43 holding registers. 38 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Unipi Technology Unipi Extension xS53 analog input module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map lists each register in decimal and hex starting at 0; the number is the wire address.

What byte order does the Unipi Technology Unipi Extension xS53 analog input module use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Unipi Technology Unipi Extension xS53 analog input module?

Start with HR 0 Digital Inputs (Digital input states); HR 1 Relay Outputs (Relay output states); HR 2 Analog Input 1 (Analog input 1); CO 0 Relay Output 1 (Relay 1); HR 1017 Configuration(U/I) of Analog Input 1 (AI 1 type).

How do I enable Modbus control of the Unipi Technology Unipi Extension xS53 analog input module?

Modbus RTU is the native interface; nothing needs enabling. Factory settings are address 15, 19200 bps, 8N1.

What happens when the Unipi Technology Unipi Extension xS53 analog input module loses Modbus communication?

Master watchdog (MWD): enable it with the MWD Enable bit of the MWD status register and set the timeout in register 1008 (default 5000 ms). A watchdog reboot is flagged by the MWD Reboot Detected bit and coil 1000; the map does not describe the timeout behaviour further.
