Neptronic AROB series universal room controller (Modbus communication module) Modbus register map

Updated 19 November 2026

Short answer

The AROB is a wall-mounted universal room controller with temperature and optional humidity, CO2 and VOC sensors, two analog and two binary outputs. Its Modbus RTU module exposes the sensor readings, calibrations, output values and their configuration, cooling, heating, humidity, CO2 and VOC setpoints with limits, PI bands and demands, the system and fan modes, and occupancy / filter / airflow input states, all as holding registers.

This page lists 151 Modbus registers for the Neptronic AROB series universal room controller (Modbus communication module) — 120 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Neptronic’s own free documentation (linked below) and checked against it.

Integration notes: Neptronic AROB series universal room controller (Modbus communication module)

Integration in brief

Read temperature (13), CO2 (11) and VOC (12) and the cooling / heating demands (2074, 2083). Set Main system mode (2116) and Temperature system mode (2117), then write the cooling and heating setpoints (2075, 2084; x10).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Modbus communication module and set the address from the device menu or register 0.

Byte order & addressing

  • Printed register numbers start at 40000 for address 0.
  • Auto baud detection is the default; supported rates 9600-76800 per the text (the register row lists up to 57600).

Network setup

  • RS-485 two-wire, RTU mode.
  • Device address 1-246.

Watch out for

  • OAT lockouts work only when analog input 1 mode (42000) is set to OAT sensor.
  • Unoccupied setpoints need an input (42000/42001) set to occupancy.

Notes on this map

  • Only function codes 03, 06 and 16 are supported; everything is a holding register.
  • 'Scale N' with 'Value x N' means raw = engineering value x N; the multiplier here is 1/N.
  • Temperatures and enthalpy follow the network units register (40034): 0 metric, 1 imperial.
  • Left out: product name ASCII registers 40003-40006; alarm status 40009/40010 (all bits reserved); enthalpy 40016 (its example value lies outside its printed range).
  • 40029 and 40030 are both printed 'Binary Output 1 value'; both are listed as printed.
  • Several output and lockout registers apply only when an App Profile (42123) is selected, or need the matching sensor; this is noted per register.
  • The display and lock option bit tables (40031, 40035) are printed in two interleaved columns; only the bit names are given here (1 = yes / on).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Neptronic AROB series universal room controller (Modbus communication module)

What Modbus registers does the Neptronic AROB series universal room controller (Modbus communication module) have?

This map lists 151 registers: 151 holding registers. 120 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Neptronic AROB series universal room controller (Modbus communication module) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed from 40000. The intro puts the device address at holding register index 0, auto baud at index 1 and the port settings at index 2, which are the rows printed 40000-40002, so the wire address is the printed number minus 40000 (42075 cooling setpoint = address 2075). Same layout as Neptronic's TUXB guide.

What are the minimum Modbus registers to integrate the Neptronic AROB series universal room controller (Modbus communication module)?

Start with HR 13 Temperature Level (Room temperature); HR 11 CO2 Level (CO2); HR 2116 Main system mode (Main system on/off); HR 2117 Temperature system mode (Temperature mode); HR 2075 Cooling Setpoint (Cooling setpoint); HR 2084 Heating Setpoint (Heating setpoint); HR 2074 Cooling Demand (Cooling demand); HR 2083 Heating Demand (Heating demand).

How do I enable Modbus control of the Neptronic AROB series universal room controller (Modbus communication module)?

Fit the Modbus communication module and set the address from the device menu or register 0.
