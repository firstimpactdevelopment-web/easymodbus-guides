Flexit Nordic residential air handling unit (Flexit GO, built-in Modbus) Modbus register map

Updated 24 October 2026

Short answer

Flexit Nordic units are residential balanced-ventilation air handlers with heat recovery. The controller exposes a Modbus RTU slave on RS-485: measurements and outputs are 32-bit IEEE floats over two registers (high word first), while modes, digital inputs and alarm states are single 16-bit registers. This map covers temperatures, fan speeds, ventilation mode commands, home/away set points, filter timer and the A/B alarm handling.

This page lists 59 Modbus registers for the Flexit Nordic residential air handling unit (Flexit GO, built-in Modbus) — 14 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Flexit’s own free documentation (linked below) and checked against it.

Integration notes: Flexit Nordic residential air handling unit (Flexit GO, built-in Modbus)

Integration in brief

Wire RS-485 to terminals 16 (D+), 17 (D-) and 18 (G0) through harness 116405, poll at 9600 8E1 address 1, and check 4x9001 = 0 first. Read temperatures and fan outputs as ABCD floats; set the ventilation mode with 4x2013 after writing 4x2040 = 1.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is built into the Nordic controller; connect a master with cable harness 116405. 4x2013 Room operating mode works only while 4x2040 Comfort button = 1, and a mode selected on a digital input overrides it.

Byte order & addressing

  • Addresses are 0-based: use the number after 3x/4x unchanged on the wire.
  • Floats and 32-bit unsigned values occupy two registers with the high word in the lower address (ABCD); write them with FC 16 only.
  • Many float registers sit at odd addresses (3x0001, 3x0005); read each as a 2-register block starting at the listed address.
  • Several 16-bit enums start at 1, not 0 (ventilation state, alarm indication/state, the trigger and acknowledge registers).

Network setup

  • Defaults: address 1 (1-247), 9600 baud (9600/19200), 8 data bits, even parity (none/even/odd), 1 stop bit (1/2).
  • Nordic terminals: 16 = D+, 17 = D-, 18 = Ref (G0). Cable length 30 m maximum.
  • Supported function codes: 03, 04, 06 and 16; up to 125 registers per read and 123 per write.

Watch out for

  • If 4x9001 reads 2 (configuration mode) the other registers do not answer.
  • A write that is out of range is clamped: the controller replies with the value actually stored, so read back after writing.
  • A bulk read across a gap between defined registers fails with exception 02; read separate blocks.
  • Temporary High and fireplace modes are started by writing 2 to 4x3006/4x3007, not by 4x2013.

Notes on this map

  • Connection, serial defaults, function codes and data-type encoding come from the companion instruction 'Flexit GO - External Modbus communication', 117989-01, 2020-01 (English section pp. 12-15): https://flexitwebsiteprodstorage.blob.core.windows.net/product-documents/2881 . It defines 32-bit values as dd cc at register x and bb aa at x+1, i.e. most significant word first (ABCD); the sheet header also says big-endian byte order.
  • Both documents are listed on Flexit's FlexitGO product page (Documentation tab).
  • Register 4x9001 System Status gates the rest: the sheet says the Modbus registers are only reachable while it reads 0 (Operation mode).
  • Left out: 'Frost protection temp. for heating coil' (3x0033), because the sheet gives it units Pa and a -3000 to 3000 range, which cannot be right for a temperature.
  • Left out: smoke/fire fan operation and CO detector inputs (3x3016-3x3020), fire damper command 4x2043 and cooling pump command 4x2004 - option-only points; read them from the sheet if your unit has them.
  • Output registers 4x0001-4x0025 and 4x2001/4x2007 are holding registers but marked read-only (R) in the sheet; they report what the controller is driving and cannot be overridden.
  • Alarm code values (3x1021 etc.) are numbers whose meanings are in the unit's alarm list, which this sheet does not reproduce.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Flexit Nordic residential air handling unit (Flexit GO, built-in Modbus)

What Modbus registers does the Flexit Nordic residential air handling unit (Flexit GO, built-in Modbus) have?

This map lists 59 registers: 36 input registers, 23 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Flexit Nordic residential air handling unit (Flexit GO, built-in Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register sheet's address column is headed 'Modbus address (Base 0)' and prints references with a table prefix (3x = input register, FC 04; 4x = holding register, FC 03/06/16). The number after the prefix is the wire address unchanged: 3x0001 -> input register 1, 4x2013 -> holding register 2013.

What byte order does the Flexit Nordic residential air handling unit (Flexit GO, built-in Modbus) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Flexit Nordic residential air handling unit (Flexit GO, built-in Modbus)?

Start with HR 9001 System status (System status (must be operation mode)); IR 5 Supply air temperature (Supply air temperature); IR 1 Outside air temperature (Outside air temperature); IR 9 Extract air temperature (Extract air temperature); IR 3034 Heat recovery ventilation state (Current ventilation mode); HR 2013 Room operating mode (Ventilation mode command); HR 2040 Comfort button (Comfort button (enables 4x2013)); HR 1155 Setpoint temperature when home (Home temperature set point); IR 3001 A-alarm indication (A-alarm indication); HR 1271 Operating time filter (Filter operating hours).

How do I enable Modbus control of the Flexit Nordic residential air handling unit (Flexit GO, built-in Modbus)?

Modbus is built into the Nordic controller; connect a master with cable harness 116405. 4x2013 Room operating mode works only while 4x2040 Comfort button = 1, and a mode selected on a digital input overrides it.
