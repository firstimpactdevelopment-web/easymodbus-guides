Short answer

Liebert DS, CW, HPM, PeX and Challenger units are perimeter computer-room air conditioners (DX and chilled water). With a Liebert IntelliSlot Modbus card in the iCOM controller they appear as a Modbus RTU or Modbus TCP slave. This map covers the unit on/off coil, operating state and status, return/supply air temperatures and humidity, temperature and humidity setpoints and bands, alarm thresholds, fan/cooling/reheat/humidifier utilisation, run hours, remote sensors and the full list of event bits.

Integration notes: Vertiv Liebert DS / CW / HPM / PeX / Challenger with iCOM v4 (IntelliSlot Modbus)

Integration in brief

Poll input registers 30100-30134 for state, temperatures and humidity, and the 1xxxx discrete inputs for events. Write coil 25 to start/stop the unit and holding registers 40023 / 40027 for the temperature (tenths of deg C) and humidity setpoints.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Liebert IntelliSlot card the guide lists for the unit's controller (for iCOM v4 units: IS-485L for Modbus 485, IS-IPBML for Modbus IP / BACnet IP) and set its Modbus address and line speed on the card.

Communication loss & watchdog

Holding register 40045 'BMS Timeout Period' (minutes) sets how long the unit waits for BMS traffic before raising a BMS timeout; what the unit does on timeout is not described in this guide.

Byte order & addressing

  • Modicon numbering: subtract 40001 / 30001 / 10001 for the wire address; coil 25 is wire address 24.
  • Temperatures in tenths of deg C have a separate deg F twin register (not listed here); do not mix them up.
  • Which points exist depends on the iCOM application firmware (iCOM_PA35, PA70, PA151, PA203 in the guide's Extra Notes).

Network setup

  • RS-485 (2-wire) RTU settings for the IntelliSlot 485 card: 9600, 19200 or 38400 baud, 8 data bits, no parity, 1 stop bit.
  • Each unit needs a unique Modbus slave address on the RS-485 line.
  • For Modbus IP, use the IntelliSlot Modbus IP / BACnet IP card listed for the unit's controller in the guide's compatibility table.

Watch out for

  • Supply/return air temperature setpoints at 40020 and 40263 are printed without a scale (whole degrees), while 40023 'Air Temperature Set Point' is in tenths.

Notes on this map

  • Source: Emerson Network Power / Liebert reference guide SL-28170 (Rev 9). Vertiv does not host this guide publicly; the linked copy is the unaltered PDF on the Contemporary Controls support site.
  • Scale column: 'x / 10' means the raw value is tenths (scale 0.1); '-' or blank means no scaling. Some temperature setpoints are printed without a scale while similar points use x / 10; they are transcribed exactly as printed.
  • Most temperatures exist twice: once in deg C and once in deg F at a different register. Only the deg C registers are listed here.
  • Points that the guide lists with both an input register (3xxxx) and a holding register (4xxxx) are the writable settings; we list the holding register (read/write). The same value can also be read at the matching 3xxxx input register (same offset).
  • Signedness is not stated in the guide. Temperature values are listed as INT16 (they can be below zero); everything else as UINT16.
  • Points that take two registers (date/time and schedule start/stop times, 32-bit values) are left out because the guide does not state their word order.
  • Event/alarm discrete inputs read 1 while the event is active ('Active on Alarm').
  • The guide marks each point with the iCOM application software that supports it (PA35, PA70, PA151, PA203). Not every unit has every point.
  • Registers 30745, 40733 and 40754 are left out: they sit in the deg F block but the guide labels them deg C, so their unit is unclear.
  • The glossary (Table 8) explains each point; descriptions here are kept short.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Vertiv Liebert DS / CW / HPM / PeX / Challenger with iCOM v4 (IntelliSlot Modbus)

What Modbus registers does the Vertiv Liebert DS / CW / HPM / PeX / Challenger with iCOM v4 (IntelliSlot Modbus) have?

This map lists 408 registers: 4 coils, 160 discrete inputs, 71 input registers, 173 holding registers. 177 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vertiv Liebert DS / CW / HPM / PeX / Challenger with iCOM v4 (IntelliSlot Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints Modicon-style numbers: discrete inputs 1xxxx, input registers 3xxxx, holding registers 4xxxx. Its RTU example asks for holding register 40051 with start offset 50 (0x0032), so subtract 10001 / 30001 / 40001 to get the wire address. Coils are printed as plain numbers on the same scale as the discrete inputs (coil 25 sits beside status 10025), so coil n is wire address n-1.

What are the minimum Modbus registers to integrate the Vertiv Liebert DS / CW / HPM / PeX / Challenger with iCOM v4 (IntelliSlot Modbus)?

Start with CO 24 System On/Off Control (System on/off control); IR 99 System Operating State (System operating state); IR 101 System Status (System status); IR 109 Return Air Temperature (Return air temperature); IR 111 Supply Air Temperature (Supply air temperature); IR 129 Return Humidity (Return humidity); HR 22 Air Temperature Set Point (Air temperature setpoint); HR 26 Humidity Set Point (Humidity setpoint); IR 102 Fan Speed (Fan speed); HR 380 System Event Acknowledge/Reset (Acknowledge / reset events).

How do I enable Modbus control of the Vertiv Liebert DS / CW / HPM / PeX / Challenger with iCOM v4 (IntelliSlot Modbus)?

Fit the Liebert IntelliSlot card the guide lists for the unit's controller (for iCOM v4 units: IS-485L for Modbus 485, IS-IPBML for Modbus IP / BACnet IP) and set its Modbus address and line speed on the card.

What happens when the Vertiv Liebert DS / CW / HPM / PeX / Challenger with iCOM v4 (IntelliSlot Modbus) loses Modbus communication?

Holding register 40045 'BMS Timeout Period' (minutes) sets how long the unit waits for BMS traffic before raising a BMS timeout; what the unit does on timeout is not described in this guide.

Where is the official Vertiv Liebert DS / CW / HPM / PeX / Challenger with iCOM v4 (IntelliSlot Modbus) Modbus documentation?

The source is Liebert IntelliSlot Modbus 485, Modbus IP and BACnet IP Reference Guide (SL-28170 Rev 9), revision 10-12 (printed as SL-28170_REV9_10-12). Vertiv doesn't publish it on its own website, so this map was re-typed from a free copy at https://ccontrols.com/support/dp/Liebert.pdf. It may be an older revision, so check it against the live unit.
