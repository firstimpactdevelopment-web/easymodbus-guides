Short answer

Yaskawa's compact general-purpose variable frequency drive with a built-in RS-485 MEMOBUS/Modbus RTU port. Run/stop, frequency reference and other commands are written to hex registers 0001H-000FH, drive status, faults and key monitors are read from 0020H onwards, and every parameter has its own hex register shown in the parameter list. This map covers the command block, status/fault words, the main monitors with fixed units, and the b1/H5 communication parameters.

Integration notes: Yaskawa GA500 AC drive (MEMOBUS/Modbus RTU)

Integration in brief

Set H5-01..H5-03 for the network, set b1-01 = 2 and b1-02 = 2 so frequency reference and Run command come from Modbus, then write 0001H (run bits) and 0002H (frequency reference) with function 10H and poll 0020H-0021H for status and faults.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set H5-01 node address (default 1FH), H5-02 speed (default 3 = 9600 bps) and H5-03 parity (default 0 = none), then power-cycle or set H5-20 = 1. For control set b1-01 = 2 [Memobus/Modbus Communications] and b1-02 = 2 (b1-15/b1-16 for external reference 2). H5-12 decides whether 0001H bits 0/1 mean FWD/REV run or Run + direction. Network inputs are ORed with terminals S1-S7.

Communication loss & watchdog

H5-05 = 1 enables CE [Modbus Communication Error] detection, H5-09 CE Detection Time (0.0-25.0 s, default 2.0 s) sets the timeout, and H5-04 selects the reaction: 0 ramp to stop, 1 coast, 2 fast stop (C1-09), 3 alarm only (default). Drive Status 2 (002CH) bit F shows a communications timeout.

Byte order & addressing

  • Registers are hex and 0-based: 0020H is sent as 00 20.
  • Only function codes 03H, 08H, 10H, 5AH and 67H are supported; there is no 06H single-register write, so use 10H even for one register.
  • Reads and writes are limited to 16 registers per message (03H/10H).
  • With H5-11 = 0 parameter writes only take effect after writing 0 to 0900H (EEPROM) or 0910H (RAM); command registers 0001H-000FH never need Enter. 0900H/0910H are write-only and reading them returns error 02H.
  • Minimum gap before the next message: about 5 ms after commands/reads, 50 ms after a parameter write, 3-5 s after an Enter command.

Network setup

  • RS-485 2-wire on terminal TB4 (D+, D-, AC common); up to 31 drives per segment.
  • Turn DIP switch S2 ON at the last drive on the line to enable its termination resistor; OFF on the others.
  • Data is 8 bits with 1 stop bit; speeds 1.2-115.2 kbps; parity none/even/odd.
  • H5-06 Drive Transmit Wait Time (default 5 ms) adds delay before the drive answers if the master overruns.
  • Self-test: set H1-06 = 67, jumper S6-SN and power up; the keypad shows PASS when the port is healthy.

Watch out for

  • H5-01 = 0 stops the drive from answering at all.
  • Changes to H5-01..H5-03 need a power cycle or H5-20 = 1 before they apply.
  • The Enter command to EEPROM (0900H) wears the EEPROM (about 100,000 writes); use 0910H for frequent changes.
  • With a communication option card fitted, the option takes priority for ComRef/ComCtrl.

Notes on this map

  • Frequency registers (0002H reference, 0023H U1-01, 0024H U1-02) use the units chosen in o1-03 (0 = 0.01 Hz, 1 = 0.01% of E1-04, 2 = RPM, 3 = user units); o1-03's default depends on A1-02, so they are left unscaled here.
  • Left out: 0025H U1-06 output voltage (unit switched by H5-10), 0026H U1-03 output current (Table 6.16 prints 0.1 A, but the U1-03 monitor list says its units change with drive model - 0.01 A for B001-B018, 2001-2042, 4001-4023 and 0.1 A for 2056-2082, 4031-4060 - and does not say whether 0026H follows that rule, so no single scale is safe), 0027H U1-08 output power (units differ by drive model), 0028H/0032H torque reference (sign not stated), 002FH frequency reference bias and 0068H U4-08 heatsink temperature (sign not stated; both may go negative), 003EH/003FH output frequency in r/min and % (sign not stated), 00ABH rated current and 0042H U1-03 (8192 = rated current, model-dependent units), U4-10/U4-11 kWh (resolution of the lower-digit register is unclear), 0080H-0097H fault trace/history.
  • U4-01 cumulative operation time is available as 004CH (10 h units) or split over 0098H (value / 10) and 0099H (last digit).
  • 0040H-004AH, 004CH-007EH and 0080H-0097H carry the U1/U4/U2/U3 monitors at the hex numbers in the U-monitor list.
  • The table example in the manual for function 67H labels 0024H as U1-01; Table 6.16 assigns U1-01 to 0023H and U1-02 to 0024H, which this map follows.

Questions about the Yaskawa GA500 AC drive (MEMOBUS/Modbus RTU)

What Modbus registers does the Yaskawa GA500 AC drive (MEMOBUS/Modbus RTU) have?

This map lists 48 registers: 48 holding registers. 21 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yaskawa GA500 AC drive (MEMOBUS/Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are printed in hex and go into the request unchanged: the manual's read example asks for starting register 0020H by sending 00 20, and its write example writes 0001H/0002H directly. Parameters use the hex number printed under each parameter in the parameter list (e.g. H5-04 = 0428H).

What are the minimum Modbus registers to integrate the Yaskawa GA500 AC drive (MEMOBUS/Modbus RTU)?

Start with HR 1 Run command / MFDI command (Run/stop, direction, fault reset); HR 2 Frequency reference (Frequency reference (o1-03 units)); HR 32 Drive Status 1 (Drive Status 1: run/ready/fault); HR 33 Fault Description 1 (Fault Description 1); HR 36 U1-02 Output Frequency (U1-02 Output frequency); HR 49 U1-07 DC Bus Voltage (U1-07 DC bus voltage); HR 44 Drive Status 2 (Drive Status 2 incl. comm timeout bit).
