Fronius Fronius Smart Meter via Datamanager (SunSpec meter model int+SF) Modbus register map

Updated 17 November 2026

Short answer

When a Fronius Smart Meter is connected to the Datamanager's RS485 port, the Datamanager republishes its readings as a SunSpec device at Modbus unit ID 240 (meter address 1) to 244. With the int+SF data type the meter appears as SunSpec model 201, 202 or 203 after the common block. This map covers the common block, the 16-bit current, voltage, frequency, power and power-factor values with their scale factors, and the end block.

This page lists 48 Modbus registers for the Fronius Fronius Smart Meter via Datamanager (SunSpec meter model int+SF) — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Fronius’s own free documentation (linked below) and checked against it.

Integration notes: Fronius Fronius Smart Meter via Datamanager (SunSpec meter model int+SF)

Integration in brief

Enable Modbus TCP on the Datamanager with SunSpec Model Type int+SF, then poll unit ID 240 (Smart Meter address 1) on port 502. Read 40072-40107 (wire 40071-40106) in one request and apply each _SF register as a power of ten.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the Datamanager web interface open Settings > Modbus, set data output to tcp, and choose SunSpec Model Type int+SF. The meter must already be configured under Settings > Meter.

Byte order & addressing

  • Scale factors are signed int16 exponents: value = raw x 10^SF.
  • The meter is a separate Modbus device (unit ID 240-244) with its own common block starting again at 40001, not part of the inverter's unit ID.
  • The model ID at 40070 tells you which layout is active: 201-203 = int+SF, 211-213 = float (different addresses).

Network setup

  • Fronius Smart Meter address 1 maps to Modbus unit ID 240, address 5 to 244.
  • If a Modbus meter is configured on the Datamanager, the rtu output setting cannot be used; read the meter over TCP.

Watch out for

  • Power sign flips with the configured meter location (grid vs load); check the location before trusting import/export direction.
  • Energy counters are 32-bit and not included here because Fronius does not document their word order.

Notes on this map

  • Register table comes from Fronius' official 'Meter_Register_Map_Int&SF_v1.0.xlsx' in the Modbus SunSpec maps ZIP published next to the PDF; behaviour and device IDs come from the PDF.
  • Addresses assume SunSpec Model Type = int+SF. With the default float setting the meter shows model 211/212/213 and the register layout is different.
  • Word order: neither the PDF nor the XLSX states the order of 32-bit values, so the 32-bit SID (40001-40002), all acc32 energy counters (TotWhExp 40108, TotWhImp 40116, TotVAhExp 40125, TotVAhImp 40133 and the per-phase/VArh counters, most of which the XLSX marks unsupported) and the 32-bit event field (40175) are left out, together with their energy scale-factor registers.
  • Phase B/C values are only meaningful on a three-phase meter (model 203).
  • The sign of W and the meaning of the import/export energy counters depend on the meter location set in the Datamanager (0 grid, 1 load, 3 external generator, 256-511 sub-load); see the location table in the PDF.
  • The PDF says unsupported int16 values read 0x8000 and unsupported scale factors read 0x8000.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Fronius Fronius Smart Meter via Datamanager (SunSpec meter model int+SF)

What Modbus registers does the Fronius Fronius Smart Meter via Datamanager (SunSpec meter model int+SF) have?

This map lists 48 registers: 48 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Fronius Fronius Smart Meter via Datamanager (SunSpec meter model int+SF) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Fronius numbers registers from 1 (SunSpec base register 40001) and tells you to request the register number minus one, so register 40072 is read at wire address 40071. The manual's RTU example reads register 40005 with address bytes 9C 44 (40004).

What are the minimum Modbus registers to integrate the Fronius Fronius Smart Meter via Datamanager (SunSpec meter model int+SF)?

Start with HR 40069 ID (meter model) (Model ID (203 = three-phase) confirms the int+SF layout); HR 40087 W (Total active power); HR 40091 W_SF (Power scale factor); HR 40071 A (Total current); HR 40075 A_SF (Current scale factor); HR 40077 PhVphA (Phase A voltage); HR 40084 V_SF (Voltage scale factor); HR 40085 Hz (Frequency).

How do I enable Modbus control of the Fronius Fronius Smart Meter via Datamanager (SunSpec meter model int+SF)?

In the Datamanager web interface open Settings > Modbus, set data output to tcp, and choose SunSpec Model Type int+SF. The meter must already be configured under Settings > Meter.
