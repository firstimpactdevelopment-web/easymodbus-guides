Short answer

The Telaire T3400 is an OEM thermal-conductivity refrigerant sensor for A2L leak detection systems in HVAC equipment, with an RS-485 Modbus RTU interface. All data are 16-bit holding registers: operating mode, leak flag, error bits, gas concentration in %LFL, temperature and humidity, plus address, leak threshold and identity registers. This map covers the published register set except the device marking string.

Integration notes: Amphenol Telaire T3400 series refrigerant (A2L) leak sensor

Integration in brief

Talk to the sensor at 2400 baud, 8N2, address 1 by default; wait for operating mode 1 (measuring), then poll 0x0111 leak signal, 0x0112 errors and 0x0113 concentration.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is the only interface; change the address by writing 0x0120 and then reset (write 1 to 0x0101) or power-cycle.

Byte order & addressing

  • Default line settings are 2400 baud, 8 data bits, no parity, 2 stop bits.
  • Concentration is in %LFL x 10, not ppm.

Network setup

  • Wiring: pin 1 +5 Vdc (red), pin 2 ground (black), pin 3 B- (blue), pin 4 A+ (yellow).

Watch out for

  • No measurements are available while the operating mode reads 0 (startup).

Notes on this map

  • The document is marked PROVISIONAL; check for a newer revision before deployment.
  • Supported function codes: 03 (read), 06 (write single), 16 (write multiple). Registers are 16-bit, high byte first.
  • Left out: 0x0140 device marking (String[20], 10 registers): the character order within registers is not stated.
  • Error register bit 2 is not defined in the table.
  • The printed address of the lifetime counter is '0x14E' (same as 0x014E).

Questions about the Amphenol Telaire T3400 series refrigerant (A2L) leak sensor

What Modbus registers does the Amphenol Telaire T3400 series refrigerant (A2L) leak sensor have?

This map lists 13 registers: 13 holding registers. 3 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Amphenol Telaire T3400 series refrigerant (A2L) leak sensor Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register addresses are printed in hex and the frame description defines the register address as the starting position in the table, sent as one word, so 0x0113 (gas concentration) is requested as 275 decimal.

What are the minimum Modbus registers to integrate the Amphenol Telaire T3400 series refrigerant (A2L) leak sensor?

Start with HR 272 Operating mode (Operating mode (startup/measuring)); HR 273 Leak signal (Leak signal); HR 274 Errors (Error flags); HR 275 Gas concentration (Gas concentration %LFL); HR 332 Gas type (Configured gas type).

How do I enable Modbus control of the Amphenol Telaire T3400 series refrigerant (A2L) leak sensor?

Modbus RTU is the only interface; change the address by writing 0x0120 and then reset (write 1 to 0x0101) or power-cycle.
