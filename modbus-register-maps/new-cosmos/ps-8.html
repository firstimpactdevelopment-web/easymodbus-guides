New Cosmos Electric PS-8 series extractive gas detector (Modbus TCP) Modbus register map

Updated 17 November 2026

Short answer

The PS-8 is a New Cosmos pump-sampling gas detector for semiconductor process and flammable gases, holding up to 16 sensor units. Its Ethernet port is a Modbus TCP server with all data in holding registers. This map covers the integer gas readings, decimal points and flow for all 16 channels, relay states, heartbeat, alarm reset, clock, and the channel 1 settings block (other channels repeat every 101 registers).

This page lists 117 Modbus registers for the New Cosmos Electric PS-8 series extractive gas detector (Modbus TCP) — 34 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from New Cosmos Electric’s own free documentation (linked below) and checked against it.

Integration notes: New Cosmos Electric PS-8 series extractive gas detector (Modbus TCP)

Integration in brief

Connect over Ethernet to 192.168.0.101 port 502 and read holding registers 0-111 (seven words per sensor) with function 03; use the integer concentration and decimal registers for each channel.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Menu > Device Information > Modbus: select TCP/IP. Set IP and subnet (or DHCP) under Device Information.

Byte order & addressing

  • Register 400xx minus 40001 = wire address.
  • Reading starting at a reserved register gives an illegal-address error; reserved registers inside a longer read return 0.
  • Date/time must be read or written as all three words together.

Network setup

  • Factory IP 192.168.0.101, port 502 fixed.
  • No proxy; the built-in web page at the IP shows live channel data for a quick check.

Watch out for

  • Maintenance mode masks the alarm and fault bits of the status words.
  • Settings marked change notification set a bit in 40124; clear it by writing 0.

Notes on this map

  • All 32-bit items are left out: the status and fault-detail DWords (40001-40004 per channel), and every IEEE-754 float (40126-40249 block, float settings). The manual gives float examples as "upper word" / "lower word" without saying which register address each sits at, so the word order cannot be settled from the source.
  • Character strings (serial number, tag and gas names) are also left out: the manual puts the 2nd character in the upper byte and the 1st in the lower byte, an order the string type here cannot express.
  • Gas readings are integers: real value = raw / 10^decimal (decimal register 0-3). Example from the source: 20.9 vol% = 209 with decimal 1.
  • The channel 1 settings block (40301-40397) repeats for channels 2-16 at +101 registers per channel (channel 2 starts at 40402). Grouped arrays for all 16 channels also exist at 42301-42984; only the concentration and unit arrays are listed here.
  • Factory IP address is 192.168.0.101; the specification table allows at most 2 connected units. Writing to reserved or read-only registers is ignored; reading reserved registers returns 0.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the New Cosmos Electric PS-8 series extractive gas detector (Modbus TCP)

What Modbus registers does the New Cosmos Electric PS-8 series extractive gas detector (Modbus TCP) have?

This map lists 117 registers: 117 holding registers. 34 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the New Cosmos Electric PS-8 series extractive gas detector (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as 40001-42984 with a relative (wire) address column; 40005 = relative address 4, confirmed by the function 03 example frame that reads 40005 with start address 0x0004.

What are the minimum Modbus registers to integrate the New Cosmos Electric PS-8 series extractive gas detector (Modbus TCP)?

Start with HR 4 Sensor 1 concentration (integer) (Sensor 1 concentration); HR 5 Sensor 1 decimal point (Sensor 1 decimal point); HR 6 Sensor 1 flow rate (Sensor 1 flow); HR 112 Heartbeat (Heartbeat); HR 113 Relay output monitor sensors 1/2 (Relay states sensors 1/2); HR 318 Sensor 1 unit (Sensor 1 unit).

How do I enable Modbus control of the New Cosmos Electric PS-8 series extractive gas detector (Modbus TCP)?

Menu > Device Information > Modbus: select TCP/IP. Set IP and subnet (or DHCP) under Device Information.
