Short answer

The Liebert XDP takes building chilled water and pumps refrigerant to Liebert XD cooling modules. With a Liebert IntelliSlot Modbus card its iCOM controller exposes pump states, supply refrigerant and chilled-water temperatures, chilled-water valve position, dew point, system on/off and status, per-XD-system fan states, capacity and remote sensor values, and alarm bits.

Integration notes: Vertiv Liebert XDP pumping unit for XD systems with iCOM v4 (IntelliSlot Modbus)

Integration in brief

Read 30385-30421 for pumps, refrigerant and chilled-water temperatures and status; write 40422 to switch the XDP on/off. Per-XD-system data starts at 30444 / 40445 for system 1.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Liebert IntelliSlot card the guide lists for the unit's controller (for iCOM v4 units: IS-485L for Modbus 485, IS-IPBML for Modbus IP / BACnet IP) and set its Modbus address and line speed on the card.

Byte order & addressing

  • Modicon numbering: subtract 40001 / 30001 / 10001 for the wire address.
  • The guide prints the XD-system event/fan blocks for systems 1, 2 and 20, and remote sensors 1, 2 and 4 for every system; unprinted blocks are not listed here.

Network setup

  • RS-485 (2-wire) RTU settings for the IntelliSlot 485 card: 9600, 19200 or 38400 baud, 8 data bits, no parity, 1 stop bit.
  • Each unit needs a unique Modbus slave address on the RS-485 line.
  • For Modbus IP, use the IntelliSlot Modbus IP / BACnet IP card listed for the unit's controller in the guide's compatibility table.

Watch out for

  • In the guide, the 'XD System 1 Temperature Sensor 2' heading repeats the secondary-fan points 31032 / 41033 instead of a sensor register, so system 1 has no sensor-2 entry here; 31032 / 41033 are listed as system 1 secondary fan points.
  • Hot/cold aisle thresholds (40459-40465 etc.) are printed without a scale.

  • Source: Emerson Network Power / Liebert reference guide SL-28170 (Rev 9). Vertiv does not host this guide publicly; the linked copy is the unaltered PDF on the Contemporary Controls support site.
  • Scale column: 'x / 10' means the raw value is tenths (scale 0.1); '-' or blank means no scaling. Some temperature setpoints are printed without a scale while similar points use x / 10; they are transcribed exactly as printed.
  • Most temperatures exist twice: once in deg C and once in deg F at a different register. Only the deg C registers are listed here.
  • Points that the guide lists with both an input register (3xxxx) and a holding register (4xxxx) are the writable settings; we list the holding register (read/write). The same value can also be read at the matching 3xxxx input register (same offset).
  • Signedness is not stated in the guide. Temperature values are listed as INT16 (they can be below zero); everything else as UINT16.
  • Points that take two registers (date/time and schedule start/stop times, 32-bit values) are left out because the guide does not state their word order.
  • Event/alarm discrete inputs read 1 while the event is active ('Active on Alarm').
  • The 'SFA' rows in the guide (reserved/special-function points) are left out.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Vertiv Liebert XDP pumping unit for XD systems with iCOM v4 (IntelliSlot Modbus)

What Modbus registers does the Vertiv Liebert XDP pumping unit for XD systems with iCOM v4 (IntelliSlot Modbus) have?

This map lists 242 registers: 55 discrete inputs, 110 input registers, 77 holding registers. 77 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vertiv Liebert XDP pumping unit for XD systems with iCOM v4 (IntelliSlot Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints Modicon-style numbers: discrete inputs 1xxxx, input registers 3xxxx, holding registers 4xxxx. Its RTU example asks for holding register 40051 with start offset 50 (0x0032), so subtract 10001 / 30001 / 40001 to get the wire address. Coils are printed as plain numbers on the same scale as the discrete inputs (coil 25 sits beside status 10025), so coil n is wire address n-1.

What are the minimum Modbus registers to integrate the Vertiv Liebert XDP pumping unit for XD systems with iCOM v4 (IntelliSlot Modbus)?

Start with HR 421 System Information: System On/Off Control (System on/off control); IR 391 System Information: System Operating State (System operating state); IR 390 System Information: System Status (System status); IR 386 Supply Refrigerant Temperature (Supply refrigerant temperature); IR 388 Supply Chilled Water Temperature (Supply chilled water temperature); IR 384 Pump 1 State (Pump 1 state); IR 1709 Chilled Water Valve Open Position (Chilled water valve open position); IR 448 XD System 1: Cooling Capacity (XD system 1 cooling capacity).

How do I enable Modbus control of the Vertiv Liebert XDP pumping unit for XD systems with iCOM v4 (IntelliSlot Modbus)?

Fit the Liebert IntelliSlot card the guide lists for the unit's controller (for iCOM v4 units: IS-485L for Modbus 485, IS-IPBML for Modbus IP / BACnet IP) and set its Modbus address and line speed on the card.

Where is the official Vertiv Liebert XDP pumping unit for XD systems with iCOM v4 (IntelliSlot Modbus) Modbus documentation?

Vertiv doesn't publish it on its own website, so this map was re-typed from a free copy at https://ccontrols.com/support/dp/Liebert.pdf.
