Updated 19 November 2026

Short answer

The SRV is a DIN-rail modular controller whose TIO modules each run two heat or heat/cool PID loops; extension modules share the bus of a basic module. With DIP switch 6 set to Modbus, each module answers Modbus RTU on RS-485 with channel 1 data at 0000H and channel 2 data at 1000H. This map covers measured values, events, setpoints, PID, manual output, module DI/DO and the key input setup items.

Integration notes: RKC Instrument SRV module type controller, TIO temperature control module (Modbus RTU)

Integration in brief

Set DIP switch 6 ON (Modbus) and the rotary address, then read 0000H-0006H for CH1 PV, event state, outputs and SV monitor (1000H onward for CH2). Write the setpoint to 0010H/1010H and start control with 0030H = 1.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The protocol is set when ordering but can be changed with DIP switch 6 (ON = Modbus). Speed is set by DIP switches 1-2, data/parity by 3-5; changes apply after power-up or a RUN/STOP change.

Byte order & addressing

  • The Modbus slave address is the rotary switch setting plus 1 (switch 00 = slave 1).
  • Each module (slave address) carries at most two channels.
  • With a data error part-way through a multi-write, the values before the error still take effect.

Network setup

  • Factory DIP settings for Modbus: 38400 bps, 8 data bits, no parity, 1 stop bit (fixed). Speeds 2400-38400 bps.
  • Give the basic TIO module the lowest address when extension modules share its bus. DIP switches 7 and 8 stay OFF.

Watch out for

  • Wait 30 bit times after a response before the next request.
  • Do not write to addresses not in the data map; items for functions that are not fitted return no error response.

Notes on this map

  • RKC's own download center does not offer this manual publicly; the linked copy is the unaltered RKC manual hosted by a US distributor (a distributor stamp on the cover only).
  • All registers are 16-bit; FFFFH is -1. Values are sent without a decimal point: PV/SV-type items follow the input range (temperature ranges with or without one decimal, or the 0873H setting for voltage/current inputs); other items have the fixed decimals shown (scale).
  • Items marked (module) exist once per module (channel 1 address only); all others repeat for channel 2 at +1000H.
  • DI/DO function settings, input error actions, AT bias, differential gaps and event action bits are left out.
  • Initial-setting items (0870H onward) can only be written in initial setting mode (0860H = 1), which needs control stopped (0030H = 0).

Questions about the RKC Instrument SRV module type controller, TIO temperature control module (Modbus RTU)

What Modbus registers does the RKC Instrument SRV module type controller, TIO temperature control module (Modbus RTU) have?

This map lists 98 registers: 98 holding registers. 72 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the RKC Instrument SRV module type controller, TIO temperature control module (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The data map prints each register in hex and decimal; the value is the address sent on the wire. The manual's read example asks for 0000H-0002H, so 0000H is a real register (CH1 measured value).

What are the minimum Modbus registers to integrate the RKC Instrument SRV module type controller, TIO temperature control module (Modbus RTU)?

Start with HR 0 Measured value (PV) (CH1) (CH1 measured value); HR 1 Comprehensive event state (CH1) (CH1 event state); HR 2 Heat-side manipulated output value (CH1) (CH1 heat-side output); HR 16 Set value (SV) (CH1) (CH1 set value); HR 48 Control RUN/STOP transfer (module) (Control RUN/STOP); HR 4096 Measured value (PV) (CH2) (CH2 measured value); HR 4112 Set value (SV) (CH2) (CH2 set value).

How do I enable Modbus control of the RKC Instrument SRV module type controller, TIO temperature control module (Modbus RTU)?

The protocol is set when ordering but can be changed with DIP switch 6 (ON = Modbus). Speed is set by DIP switches 1-2, data/parity by 3-5; changes apply after power-up or a RUN/STOP change.
