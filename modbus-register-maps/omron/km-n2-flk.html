Short answer

The KM-N2-FLK is a compact power monitor that meters up to four 1-phase 2-wire circuits (or two 1P3W/3P3W circuits), each circuit answering on its own Modbus RTU address. Every value is a 32-bit integer in two holding registers, high word first, with fixed scaling (voltage x10, current x1000, power x10). The map covers the measured values, energy counters, key settings and the command register.

Integration notes: Omron KM-N2-FLK multi-circuit power monitor

Integration in brief

Read holding registers from 0x0000 with FC03 (even counts): voltage, current, PF, frequency and power as high-word-first 32-bit integers, then energy from 0x0200. Address each circuit by its own slave address.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is the default protocol (MENU 00 = MODBS). Set circuit A's communication address on the rotary switch; circuits B-D follow in order.

Byte order & addressing

  • All values are 32-bit: two registers, high word first.
  • Settings need a mode-change command to address FFFF before access.
  • Commands use FC06; FC16 is for writing settings.

Network setup

  • Defaults: 9.6 kbps, 8 data bits (fixed for Modbus), even parity, 1 stop bit (stop bits follow parity in Modbus).
  • Every circuit on the RS-485 line needs a unique address 1-99; leave room for circuits B-D after circuit A's address.

Watch out for

  • Phase/wire type changes what voltage 1-3 and current 1-3 mean; check the table in section 6.4.

Notes on this map

  • Word order: the read example returns 0000 then 0960 for voltage 1 (2400 = 240.0 V), so the high word comes first (ABCD). Negative values are two's complement.
  • Scaling per the address map: voltage x10, current x1000, power factor x100, frequency x10, active and reactive power x10; energy counters are x1 in the unit named.
  • Each circuit of the unit is its own Modbus slave. Circuit A's address is set on the rotary switch; circuits B-D automatically take the next addresses in order, and any address above 99 is invalid. The registers here repeat for every circuit.
  • Settings in the 2000-2210 range can only be read or written after the 'move to setting mode' command (0x0700 to address FFFF); send 'move to measuring mode' (0x0400) afterwards. Measured values can be read in either mode.
  • Read requests are limited to 2-50 registers and only over consecutive addresses.
  • Left out: pulse output, voltage selection, data length, conversion factor/unit, LCD, alarm, tariff, model and status registers (2010-2012, 2204, 220C, 2210-240A).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Omron KM-N2-FLK multi-circuit power monitor

What Modbus registers does the Omron KM-N2-FLK multi-circuit power monitor have?

This map lists 62 registers: 62 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Omron KM-N2-FLK multi-circuit power monitor Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The address map prints Modbus addresses in hex and they go on the wire unchanged; the manual's example reads voltage 1 with start address 0000 and 2 registers. Each value takes two registers, so read an even count.

What byte order does the Omron KM-N2-FLK multi-circuit power monitor use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Omron KM-N2-FLK multi-circuit power monitor?

Start with HR 0 Voltage 1 (Voltage 1 (x0.1 V)); HR 6 Current 1 (Current 1 (x0.001 A)); HR 16 Active power (Active power (x0.1 W)); HR 12 Power factor (Power factor); HR 14 Frequency (Frequency); HR 544 Active energy import (not resettable) (Active energy import, kWh).

How do I enable Modbus control of the Omron KM-N2-FLK multi-circuit power monitor?

Modbus is the default protocol (MENU 00 = MODBS). Set circuit A's communication address on the rotary switch; circuits B-D follow in order.
