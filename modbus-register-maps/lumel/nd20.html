Lumel ND20 network parameter meter Modbus register map

Updated 17 November 2026

Short answer

The ND20 is a 96x96 panel meter for 3- and 1-phase networks with an RS-485 Modbus RTU port. Each measured value is offered as a float in several register areas; this map uses the 7000 area (two 16-bit registers per value, high word first) plus the 4000 area of 16-bit settings, 32-bit energy counters and the status word.

This page lists 74 Modbus registers for the Lumel ND20 network parameter meter — 9 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lumel’s own free documentation (linked below) and checked against it.

Integration notes: Lumel ND20 network parameter meter

Integration in brief

Read holding registers (FC03 or FC04) from 7000: 3 x 7 per-phase floats then 3-phase totals and frequency, high word first. Energy totals are the float pairs at 7096-7110 or the 32-bit counters at 4038-4045 (divide by 10).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The manual describes no separate Modbus enable; address, transmission mode and baud are set from the front menu or registers 4030-4032, then write 1 to 4033 to apply.

Byte order & addressing

  • The 6000 area is low word first, the 7000 area high word first: pick one and stick to it.
  • Read at most 41 32-bit or 82 16-bit registers per request.
  • Powers are in W, var and VA, not kW.

Network setup

  • Factory settings: address 1, 9600 baud, 8N2.
  • Maximum response time is 600 ms.

Watch out for

  • The 7096-7110 energies come as an overflow count (100 MWh) plus a counter that rolls at 99999.9 kWh.

Notes on this map

  • Source is Conrad's copy of the unaltered Lumel manual; Lumel's own site did not turn up a public copy of the full manual in two searches, though its quick-start guides point to lumel.com.pl.
  • Float areas: 7000-7319 is two 16-bit registers per value with bytes 3-2-1-0 (ABCD), confirmed by the example frame that returns 41 20 00 00 = 10.0. The 6000 area holds the same values with bytes 1-0-3-2 (CDAB) and 7500 the same values as single 32-bit registers; only the 7000 area is listed here.
  • Energy in the 4000 area is (high register x 65536 + low register) / 10 in kWh or kvarh, per the manual's formulas.
  • Left out: 7054 (labelled 'Mean Tg factor of phase L1', which does not fit a 3-phase mean), the min/max area from 7128 on, harmonic energy overflow pairs 7112-7118, time registers 7120-7124, the averaged power archive 1000-1077, alarm and analog output setup 4001-4002 and 4012-4029, display configuration 4054-4056, and 4057 (its value list prints 3Ph/4W twice).
  • Which quantities are valid depends on the connection (3Ph/4W, 3Ph/3W, 1Ph/2W); Table 12 marks phase values that are not available in 3-wire mode.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lumel ND20 network parameter meter

What Modbus registers does the Lumel ND20 network parameter meter have?

This map lists 74 registers: 74 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lumel ND20 network parameter meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are used as printed: the manual's example frames read 4000 as 0x0FA0, 7000 as 0x1B58 and 7500 as 0x1D4C. For the float area the 'documented' field shows the table's '6xxx/7xxx' pair; this map uses the 7xxx address.

What byte order does the Lumel ND20 network parameter meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lumel ND20 network parameter meter?

Start with HR 7000 Voltage L1 (Voltage L1); HR 7002 Current L1 (Current L1); HR 7046 3-phase active power (3-phase active power); HR 7052 Mean power factor (Mean power factor); HR 7056 Frequency (Frequency); HR 4038 Imported active energy (Imported active energy); HR 4050 Status register (Status / error bits).

How do I enable Modbus control of the Lumel ND20 network parameter meter?

The manual describes no separate Modbus enable; address, transmission mode and baud are set from the front menu or registers 4030-4032, then write 1 to 4033 to apply.
