Short answer

The original Yaskawa iQpump is a pump-application drive based on the P7 platform with an embedded Modbus RTU slave on terminals R+/R-/S+/S-. Commands go to hex registers 0001H-000FH, status and fault words are read from 0020H upward, and parameters have their own hex Modbus addresses in Appendix A. This map covers the command block, status/fault words, PI levels, pump monitors, fault history codes and the b1/H5 setup parameters.

This page lists 44 Modbus registers for the Yaskawa iQpump drive (P7U-based, legacy) - Modbus RTU — 19 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Yaskawa’s own free documentation (linked below) and checked against it.

Integration notes: Yaskawa iQpump drive (P7U-based, legacy) - Modbus RTU

Integration in brief

Set H5-01..H5-03 at the keypad and power-cycle, set b1-01 = 2 and b1-02 = 2 for Modbus reference and run, then write 0001H and 0002H with function 10H and poll 0020H-002DH for status and faults.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set H5-01 address (default 1F hex), H5-02 baud (default 3 = 9600) and H5-03 parity (default none), then cycle power. b1-01 = 2 and b1-02 = 2 hand the frequency reference and run command to Modbus. Status reads, parameter access, fault reset and multi-function inputs work regardless of b1-01/b1-02.

Communication loss & watchdog

H5-05 = 1 (default) enables CE detection after H5-09 seconds (default 2.0 s) without messages; H5-04 sets the reaction: 0 ramp, 1 coast, 2 fast-stop, 3 alarm only (default). 002CH bit F shows a comm time-out.

Byte order & addressing

  • Registers are hex and 0-based.
  • Function codes 03H, 06H, 08H and 10H are supported; 1 to 16 registers per message.
  • Parameter writes go to a temporary area until 0 is written to 0900H (EEPROM + RAM) or 0910H (RAM only); EEPROM write life is 100,000 cycles.
  • Network multi-function inputs are ORed with terminals S3-S7.
  • Write 0 to unused bits and never write reserved registers.

Network setup

  • Terminals S+, S-, R+, R-; for RS-485 jumper S+ to R+ and S- to R-. Up to 31 drives.
  • Termination: DIP S1-1 ON (110 ohm) only at the end of the line.
  • 8 data bits, 1 stop bit; 1200-19200 baud; parity none/even/odd.
  • Power-cycle after changing H5-01..H5-03.

Watch out for

  • Frequency and pump setpoint registers follow the system units in P1-02/o1-03, so check those before scaling.
  • Parameters cannot be written while running (error 22H) or during undervoltage (23H).

Notes on this map

  • Monitor registers 0023H/0024H and U1 monitors are listed raw where the manual gives no resolution or unit for them (only U1-90/U1-91 state 0.1 resolution and the PI levels state 10 = 1 %).
  • Left out because the manual prints no units or resolution: 0025H output voltage, 0026H output current, 0027H output power, 0028H torque reference, 0031H DC bus voltage, and the 0040H-0067H U1 monitor block and U2 snapshot values.
  • Fault code numbers for U2/U3 registers are not tabulated in this manual's Modbus appendix, so no value list is given.
  • H5-08 (protocol select: Modbus, APOGEE FLN, Metasys N2) is referenced in the H5 table but its Modbus address is not printed there; it is not listed.
  • Broadcast (address 0) accepts only 0001H with its own bit layout (bit 0 run, bit 1 reverse, bit 4 external error, bit 5 fault reset, bits C-E S5-S7) and 0002H (30000 = 100 %).
  • U3-07 is printed as 009BH in the fault history table, which breaks the 0094H-0097H sequence; the elapsed-time registers are not included.

Questions about the Yaskawa iQpump drive (P7U-based, legacy) - Modbus RTU

What Modbus registers does the Yaskawa iQpump drive (P7U-based, legacy) - Modbus RTU have?

This map lists 44 registers: 44 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yaskawa iQpump drive (P7U-based, legacy) - Modbus RTU Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are hex and are sent unchanged: the 03H example reads from start address 00 20 (drive status), and the 10H example writes 0001H (run forward) and 0002H (0258H = 600 for 60.0 Hz) starting at 00 01. Parameters use the hex Modbus address in Appendix A (b1-01 = 0180H, H5-01 = 0425H).

What are the minimum Modbus registers to integrate the Yaskawa iQpump drive (P7U-based, legacy) - Modbus RTU?

Start with HR 1 Operation command (Run/stop and fault reset); HR 2 Frequency reference (Frequency reference); HR 32 Drive status (Drive status); HR 33 Fault details (Fault details); HR 36 Output frequency (U1-02) (Output frequency); HR 44 Drive status 2 (Drive status 2 incl. comm timeout); HR 1825 Pump feedback (U1-91) (Pump feedback); HR 128 Current fault (U2-01) (Current fault code).

How do I enable Modbus control of the Yaskawa iQpump drive (P7U-based, legacy) - Modbus RTU?

Set H5-01 address (default 1F hex), H5-02 baud (default 3 = 9600) and H5-03 parity (default none), then cycle power. b1-01 = 2 and b1-02 = 2 hand the frequency reference and run command to Modbus. Status reads, parameter access, fault reset and multi-function inputs work regardless of b1-01/b1-02.

What happens when the Yaskawa iQpump drive (P7U-based, legacy) - Modbus RTU loses Modbus communication?

H5-05 = 1 (default) enables CE detection after H5-09 seconds (default 2.0 s) without messages; H5-04 sets the reaction: 0 ramp, 1 coast, 2 fast-stop, 3 alarm only (default). 002CH bit F shows a comm time-out.
