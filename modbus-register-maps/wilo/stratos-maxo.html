Wilo Stratos MAXO with CIF module Modbus RTU Modbus register map

Updated 25 October 2026

Short answer

The Wilo Stratos MAXO is a smart wet-rotor circulator for heating, cooling and domestic hot water. Modbus RTU comes from a plug-in CIF module on RS-485. A master picks the setpoint source and control mode, writes a relative duty point in 0.5 % steps and switches the pump on, off or to MIN/MAX overrides; a bus command timer can lock the local menu and load fallback values if the bus goes quiet. Readings cover head, calculated flow, power, energy, speed, run hours, fluid temperatures, the heat/cold meter, status flags and the Wilo error code.

This page lists 56 Modbus registers for the Wilo Stratos MAXO with CIF module Modbus RTU — 11 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Wilo’s own free documentation (linked below) and checked against it.

Integration notes: Wilo Stratos MAXO with CIF module Modbus RTU

Integration in brief

Set the Modbus address, baud and frame in the pump menu, then write H 300 = 5 (MANUAL), H 401 = 1 (bus setpoint), H 42 = control mode, H 1 = duty point (200 = 100 %) and H 40 = 9 (on, with the required bit 3), as in Wilo's basic example. Check I 211 (parameter set 1 = normal), I 210, I 10, I 200 and I 402, then poll I 404, I 940, I 1, I 2, I 4 and I 7.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the pump menu go to Settings > External interfaces and set up the Modbus RTU interface (address, baud rate, data frame); OFF for the bus address deactivates it. Over the bus, write H 401 = 1 so the setpoint comes from the CIF module. On module 3.01+, H 416 picks the parameter set; if I 211 does not read 1 (normal set), the normal registers are not the ones in effect. Wilo's basic example then writes H 300 = 5 (MANUAL) so both the local menu and the bus are allowed, last write wins. By factory setting the local menu and control input IN2 are locked while a CIF module is fitted.

Communication loss & watchdog

Bus command timer: write H 300 = 2 (SET) or 6 (SET_PRESET) and repeat the write before the timeout in H 400 elapses (minimum 20 s; Wilo describes 300 s as the default or fixed value). If the writes stop, the local menu is released and, with SET_PRESET, the pump runs on the preset values in H 402-405; the pump may show E50 (bus timeout). I 504 shows the seconds remaining. The activation survives a power cycle; write H 300 = 1 (OFF) to return to factory behaviour.

Byte order & addressing

  • Register numbers are wire addresses (0-based). Wilo's own test: read input register 700 and expect a value of 256 or more; if that fails, try 699/701 to find your master's offset.
  • Every write to H 40 must have bit 3 set (value 9 = on, 8 = off); bit 3 is a static 1 kept for compatibility.
  • Duty point is in 0.5 % steps: 200 = 100 % of the mode's reference, which is published as a float in I 206 with its unit code in I 208.
  • Values are forwarded to the pump only when they change. If a write seems ignored, write a different value and then the one you want.
  • Several sources (HMI, app, bus) can write the same settings; normally the last write wins. Read the active registers (I 10, I 200, I 210, I 402) to see what is really in effect.
  • 32-bit floats (I 206, I 300-314) are high word first; read both registers in one request.
  • Function codes 03, 04, 06 and 16 are supported.

Network setup

  • Bus terminals on the CIF module: A(-), B(+) and GND, two sets for incoming and outgoing lines. Some masters label A and B the other way round; swap if nothing answers.
  • Switch on the built-in 120 ohm terminator (both switches S1/S2 ON) only at the module that ends the line; factory setting is off.
  • Use shielded cable with the EMC cable gland and earth the shield at both ends; daisy-chain only, no stubs, stars or loops.
  • Baud codes (Parameter A): 0=300, 1=600, 2=1200, 3=2400, 4=4800, 5=9600, 6=19200, 7=38400, 9=115200, 10=76800. Frame codes (Parameter C): 2=8N1, 3=8N2, 6=8E1, 10=8O1.
  • Twin-head pumps: fit the CIF module in the master pump; control writes act on the pump system as a whole.

Watch out for

  • Temperatures are in kelvin x 10, not °C.
  • Calculated flow (I 2) is an estimate; Wilo says not to use it for closed-loop control.
  • Writes below the minimum duty point (I 204) are limited to it, and modes the pump does not support are silently ignored - always read back I 10 and I 200.
  • With the timer in OFF the local menu stays locked permanently; MANUAL keeps both local and bus control.

Notes on this map

  • Source is Wilo's public HTML document for all CIF modules, which marks every register and every enum/bit value with the pumps that support it. Only registers and values listed as supported by the Stratos MAXO are kept. Second, related Wilo document: Wilo-CIF-Module installation and operating instructions 2193854 Ed.02/2020-11, https://cms.media.wilo.com/cdndoc/wilo182202/5025204/wilo182202.pdf (wiring and terminators; no datapoint list). Facts are re-keyed in our own words and the documents are linked, not re-hosted.
  • 32-bit values (REAL and UDINT) are high word first (ABCD): Wilo puts the most significant 16 bits at the base address.
  • Scale: physical value = raw x scale as in Wilo's list (pressure raw x 10 = cm H2O, operation time raw x 10 = h, flow raw x 0.1 = m³/h, duty point raw x 0.5 = %, temperatures raw x 0.1 = K).
  • Temperatures are in kelvin, not °C: 2931 means 293.1 K = 20.0 °C.
  • Error values: Wilo marks an unavailable or invalid reading with the largest positive value of the data type (e.g. 65535 for UINT, 32767 for INT).
  • controlFunction lists every mode Wilo marks as supported on a Stratos MAXO; which modes a given pump accepts depends on its firmware and CPU variant (Wilo lists CPU_F4 and CPU_H5), and unsupported values are ignored. Values 69 and 70 are marked reserved and are left out.
  • warning/errorMessage (I 940) lists only the codes Wilo marks as supported on the Stratos MAXO. The user trouble code (I 901, 74 Stratos MAXO codes) and the second error register I 950 are left out.
  • Left out: aux parameter set H 412-415 and its readbacks I 222-262; PID tuning H 408-410; flow limits H 420-427 / I 270-281; temperature references H 302/H 304 and sensor signal H 306; analog input readings I 324-332; heat-meter start times I 306/I 310 (REAL seconds since 1970); system time I 502; identification I 700-718 (BCD-coded firmware, vendor/UUID words); double-pump total run time I 9; legacy Stratos registers H 44-47 and the partner-pump block I 65-102 (not marked for Stratos MAXO).
  • Bits shown for the bit-field registers are those Wilo marks as supported on Stratos MAXO; bits not listed are static 0 (or unused) on this pump.
  • Left out: I 212. Wilo names it 'pressure max-pres-value' (REAL, bar, module 5.01+) but describes it as the live pressure, so it is unclear whether it is the actual or the maximum pressure.
  • Flow (I 2): for module versions up to 6.00 Wilo gives 9999 as its error value, not 65535.

Questions about the Wilo Stratos MAXO with CIF module Modbus RTU

What Modbus registers does the Wilo Stratos MAXO with CIF module Modbus RTU have?

This map lists 56 registers: 45 input registers, 11 holding registers. 11 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Wilo Stratos MAXO with CIF module Modbus RTU Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Wilo states that all register addresses are raw addresses as sent on the bus, so input register 700 is requested at address 700. Its example frame confirms it: 01 04 02 BC 00 01 reads input register 0x02BC = 700. Masters that number registers from 1 must use 701 (or 30701).

What byte order does the Wilo Stratos MAXO with CIF module Modbus RTU use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Wilo Stratos MAXO with CIF module Modbus RTU?
