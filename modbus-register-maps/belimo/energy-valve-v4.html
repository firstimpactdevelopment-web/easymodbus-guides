Belimo Energy Valve DN 15-50 (Version 4) Modbus RTU / TCP Modbus register map

Updated 28 October 2026

Short answer

Belimo's Energy Valve combines a pressure-independent control valve, a flow sensor and two temperature sensors, so it reports flow, delta T, heating/cooling power and energy totals. Version 4 offers Modbus RTU on RS-485 and Modbus TCP on its Ethernet port. Most values are given three times - in SI, imperial and a user-selected unit - and large values use two registers, low word first.

This page lists 80 Modbus registers for the Belimo Energy Valve DN 15-50 (Version 4) Modbus RTU / TCP — 30 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Belimo’s own free documentation (linked below) and checked against it.

Integration notes: Belimo Energy Valve DN 15-50 (Version 4) Modbus RTU / TCP

Integration in brief

Pick RTU (RS-485, 38400 8N2, address 1) or TCP (port 502), keep Setpoint source = Bus, choose Control mode (No. 117), then write the setpoint to No. 1 (address 0) and poll flow, temperatures, power and energy. Read each 32-bit value as a two-register pair, low word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU and TCP are configured with the Belimo Assistant app or the valve's built-in web server (address, baud, frame, IP). Setpoint source (No. 119) defaults to Bus.

Communication loss & watchdog

Bus fail setpoint is No. 109 and the timeout No. 110 (0-3600 s, 0 = off, default 120 s once a fail setpoint is set): if neither No. 1 nor No. 2 is renewed in time the valve goes to the fail setpoint. Belimo marks No. 110 as not functional in this edition, so test it before relying on it.

Byte order & addressing

  • Register No. is 1-based; subtract 1 for the wire address.
  • 32-bit pairs are low word first (CDAB) and must be written with a single FC 16 to just those two registers.
  • Each quantity appears in SI, imperial and 'selected unit' registers; the selected-unit registers follow No. 148-151.

Network setup

  • RTU default frame 1-8-N-2 at 38400 baud, address 1; 9600-115200 baud supported.
  • TCP default port 502 over the Ethernet socket.
  • Max. 32 RTU nodes per segment without a repeater; terminate with 120 ohm.

Watch out for

  • Unsupported values read 65535 - treat it as 'not available', not as a real reading.
  • Temperatures are signed; read them as INT16.

Notes on this map

  • 32-bit values occupy two registers with the low word first (Belimo's worked example: No. 10 = 14551, No. 11 = 19 gives 19 x 65536 + 14551 = 1,259,735), so they are UINT32 with CDAB word order. Write a 32-bit pair with one FC 16 request covering only those two registers.
  • Values are unsigned unless Belimo marks them signed (**): the sensor-1 and Temperature 1/2 registers (No. 14, 15, 20-23) are signed two's complement and typed INT16 here.
  • Unsupported registers read 65535. Writable registers from No. 101 up are persistent; don't write them cyclically.
  • The description table prints Sensor 1 °C/°F (No. 123/124) with addresses 124/125, which does not match the No.-minus-1 rule used everywhere else, so those two are left out. No. 13 (raw sensor value, scale depends on sensor type) is also left out.
  • No. 136/137 (Vmax in selected unit) is left out: its scaling is printed as '0.001-' and is unclear. No. 201-204 (sensor serial number / production order and sequence numbers) are left out because the document does not say whether each pair is one 32-bit value.
  • No. 9 (flow gpm) has no access letter in the description table; it is read-only like its neighbours. No. 151 has no access letter either and is listed as read-only to be safe, although the other unit selections are R/W.
  • Belimo lists Communication watchdog (No. 110) as 'not functional, reserved for future' in this edition, so don't rely on it.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Belimo Energy Valve DN 15-50 (Version 4) Modbus RTU / TCP

What Modbus registers does the Belimo Energy Valve DN 15-50 (Version 4) Modbus RTU / TCP have?

This map lists 80 registers: 80 holding registers. 30 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Belimo Energy Valve DN 15-50 (Version 4) Modbus RTU / TCP Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Belimo prints each register twice: 'No.' counts from 1 and 'Address' from 0, and the documented value here is the No. column. Register No. 1 (setpoint) is wire address 0. Every value sits in one flat table, so holding-register reads (FC 3) and writes (FC 6/16) reach everything; FC 4 input-register reads of the same addresses also work.

What byte order does the Belimo Energy Valve DN 15-50 (Version 4) Modbus RTU / TCP use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Belimo Energy Valve DN 15-50 (Version 4) Modbus RTU / TCP?

Start with HR 0 Setpoint (Setpoint, 0.01 %); HR 116 Control mode (Control mode: position / flow / power); HR 7 Absolute volumetric flow (l/s) (Flow l/s); HR 19 Temperature 1 external (°C) (Temperature 1 (external) °C); HR 21 Temperature 2 integrated (°C) (Temperature 2 (integrated) °C); HR 27 Cooling power (kW) (Cooling power kW); HR 33 Heating power (kW) (Heating power kW); HR 65 Cooling energy (kWh) (Cooling energy kWh); HR 71 Heating energy (kWh) (Heating energy kWh); HR 104 Malfunction and service information (Fault flags).

How do I enable Modbus control of the Belimo Energy Valve DN 15-50 (Version 4) Modbus RTU / TCP?

Modbus RTU and TCP are configured with the Belimo Assistant app or the valve's built-in web server (address, baud, frame, IP). Setpoint source (No. 119) defaults to Bus.

What happens when the Belimo Energy Valve DN 15-50 (Version 4) Modbus RTU / TCP loses Modbus communication?

Bus fail setpoint is No. 109 and the timeout No. 110 (0-3600 s, 0 = off, default 120 s once a fail setpoint is set): if neither No. 1 nor No. 2 is renewed in time the valve goes to the fail setpoint. Belimo marks No. 110 as not functional in this edition, so test it before relying on it.
