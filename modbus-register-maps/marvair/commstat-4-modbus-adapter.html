Short answer

The CommStat 4 is a Marvair HVAC controller for equipment shelters; a master controller and an optional slave controller each run two HVAC units in lead/lag. A separate Marvair adapter plugs into a CommStat 4 master communications port and acts as a Modbus TCP and Modbus RTU slave. The map gives the controller settings, inputs, unit outputs, lockouts and stage, plus a second register block used to push new settings.

This page lists 107 Modbus registers for the Marvair CommStat 4 lead/lag controller via Modbus Interface Adapter — 43 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Marvair’s own free documentation (linked below) and checked against it.

Integration notes: Marvair CommStat 4 lead/lag controller via Modbus Interface Adapter

Integration in brief

Poll 40001-40068 over TCP port 502 (or RTU 9600 8N1): 40057 temperature, 40056 stage, 40055/40068 lockouts, 40044 alarms and 40047/40048 unit outputs. Change settings only through the 40101 handshake.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Install the Marvair Modbus Interface Adapter and plug its RJ11 cable into one of the master communication ports on the CommStat 4 board. Set the adapter IP through its web page.

Byte order & addressing

  • Writes go to a separate block (40101 up) and only take effect after the 40101 handshake.
  • Current temperature 240 means sensor fault; slave sensor value 0 means sensor fault.

Network setup

  • Default IP 192.168.1.19 (static); browse to it to set DHCP or a new static address, then the adapter reboots in about 60 s.
  • A reset button on the adapter board restores the default IP.
  • RTU terminal: RS-485 A/B, 9600 N 8 1.
  • The adapter needs 24-60 V DC and must be mounted inside the shelter.

Watch out for

  • Only CommStat 4 protocol version 3+ with software revision 67+ is supported.
  • In a two-controller shelter one master port may already carry the master/slave link.

Notes on this map

  • All values are single registers. The bit notes only define bits 0-7.
  • The adapter guide gives no units or scaling for the set points and differentials; it only says to see the CommStat 4 manual. They are listed here as raw values. Only the slave sensor readings 40063-40065 are labelled °F.
  • Registers 40051-40054 (saved output values) are marked internal use and are left out.
  • Write procedure: write 1 to 40101 so the adapter stops refreshing the new-value block, write the new values to 40102-40143, then write 2 to 40101. The adapter shows 3 while waiting and returns to 0 when the CommStat 4 has taken the values.
  • The guide does not list the function-code values for 40143 or the value meanings of settings #10 and #16.
  • The guide states a default Modbus RTU setting of 9600 N 8 1 but no RTU slave address.
  • The guide does not name the read function code; by the usual Modicon convention, 4xxxx numbers are holding registers (function 03).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Marvair CommStat 4 lead/lag controller via Modbus Interface Adapter

What Modbus registers does the Marvair CommStat 4 lead/lag controller via Modbus Interface Adapter have?

This map lists 107 registers: 107 holding registers. 43 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Marvair CommStat 4 lead/lag controller via Modbus Interface Adapter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as 40001-40068 (read) and 40101-40143 (write), Modicon holding-register style. Request 40001 as wire address 0 and 40101 as wire address 100.

What are the minimum Modbus registers to integrate the Marvair CommStat 4 lead/lag controller via Modbus Interface Adapter?

Start with HR 56 Current temperature (Current temperature); HR 55 Current stage (Current heating/cooling stage); HR 54 Master controller lockout status (Master lockout flags); HR 43 Master controller inputs (Smoke / hydrogen / generator alarms); HR 46 Master unit #1 outputs (Master unit 1 outputs); HR 40 Lead unit (Lead unit); HR 100 Write control (Write handshake).

How do I enable Modbus control of the Marvair CommStat 4 lead/lag controller via Modbus Interface Adapter?

Install the Marvair Modbus Interface Adapter and plug its RJ11 cable into one of the master communication ports on the CommStat 4 board. Set the adapter IP through its web page.
