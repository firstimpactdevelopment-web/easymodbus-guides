Yokogawa UTAdvanced UT75A digital indicating controller Modbus register map

Updated 19 November 2026

Short answer

The UT75A is the high-end UTAdvanced PID controller with up to two loops, 20 SP groups and a simple program function. Its data live in D registers that map one-to-one onto Modbus holding registers over RS-485 (Modbus RTU/ASCII) or Modbus/TCP on Ethernet models. This map covers the process data block, the current SP/PID group for both loops and the operation-mode switches.

This page lists 66 Modbus registers for the Yokogawa UTAdvanced UT75A digital indicating controller — 35 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Yokogawa’s own free documentation (linked below) and checked against it.

Integration notes: Yokogawa UTAdvanced UT75A digital indicating controller

Integration in brief

Read D2001-D2013 in one block for errors, PV, SP, output and alarms; write the target setpoint to D2101 (loop 2: D2151) and switch AUTO/MAN, RUN/STOP and REMOTE/LOCAL with D2301, D2304 and D2306.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the communication setup parameters (protocol MBRTU or MBASC, baud, parity, stop bits, data length, address) on the keypad. Ethernet models use Modbus/TCP on port 502 by default.

Byte order & addressing

  • Address D register n at wire address n-1 (D2101 = 0834H).
  • Write values without the decimal point (50.0 with one decimal place = 500).
  • To take the setpoint from communication, put the loop in REMOTE (D2306 = 1) with the remote source set to communication, then write D2331.

Network setup

  • Factory defaults: Modbus RTU, 19200 bps, even parity, 1 stop bit, 8 data bits, address 1.

Watch out for

  • Available registers depend on the suffix code (single/dual loop, options) and parameter settings; blank addresses must not be read or written.

Notes on this map

  • All registers are 16-bit. Values are sent without their decimal point: PV/SP-type values follow the input's decimal point setting, percentages carry one decimal (scale 0.1).
  • D2001-D2100 are read-only. D2101-D2112 / D2151-D2163 act on the SP group in use (1-20); D2114-D2135 / D2164-D2185 on the PID group in use (1-16 or R).
  • Program-operation registers (D2031, D2327-D2329, pattern area D7701-D7900), ramp-rate registers D2112/D2113 and the GREEN-series compatible area (D0001-D2000) are not included.
  • Only part of the D-register space is listed; alarm setpoints 5-8, cooling-side PID terms, SP/PID groups 9-20 (D9001 onward) and the setup parameter areas (D2501 onward) are left out.
  • Modbus/TCP applies only to units with the Ethernet communication option.

Questions about the Yokogawa UTAdvanced UT75A digital indicating controller

What Modbus registers does the Yokogawa UTAdvanced UT75A digital indicating controller have?

This map lists 66 registers: 66 holding registers. 35 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yokogawa UTAdvanced UT75A digital indicating controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists D register numbers (D2003). The Modbus reference number replaces the D with 4 (42003) and the wire address is that minus 40001, printed in the table's H No. column (D2003 = 07D2H).

What are the minimum Modbus registers to integrate the Yokogawa UTAdvanced UT75A digital indicating controller?

Start with HR 2002 PV_L1 loop-1 measured value (Loop-1 PV (D2003)); HR 2003 CSP_L1 loop-1 control setpoint (Loop-1 control setpoint (D2004)); HR 2004 OUT_L1 loop-1 control output (Loop-1 output (D2005)); HR 2007 MOD_L1 loop-1 operation mode status (Operation mode status (D2008)); HR 2010 ALM_L1 loop-1 alarm 1-8 status (Loop-1 alarm status (D2011)); HR 2100 SP_L1 loop-1 target setpoint (Loop-1 target setpoint (D2101)); HR 2300 A.M_L1 loop-1 AUTO/MAN switch (AUTO/MAN (D2301)); HR 2303 S.R_L1 loop-1 STOP/RUN switch (RUN/STOP (D2304)).

How do I enable Modbus control of the Yokogawa UTAdvanced UT75A digital indicating controller?

Set the communication setup parameters (protocol MBRTU or MBASC, baud, parity, stop bits, data length, address) on the keypad. Ethernet models use Modbus/TCP on port 502 by default.
