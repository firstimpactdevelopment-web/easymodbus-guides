Radwag MW-01-A / MW-01-A7 mass converter Modbus register map

Updated 17 November 2026

Short answer

The MW-01-A mass converter serves Modbus RTU on RS-485 and Modbus TCP (and RTU over TCP) on Ethernet. Input registers return mass, tare, unit, status, thresholds and dosing/adjustment state; holding registers take zero, tare, dosing and calibration commands plus threshold writes. Floats here are low word first, unlike Radwag's PUE indicators.

This page lists 20 Modbus registers for the Radwag MW-01-A / MW-01-A7 mass converter — 9 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Radwag’s own free documentation (linked below) and checked against it.

Integration notes: Radwag MW-01-A / MW-01-A7 mass converter

Integration in brief

Read input registers (FC04) from offset 0: mass is a low-word-first float at offset 0 and the status bits at offset 5. Write bit 0 or 1 of the Command register (offset 256) to zero or tare, clearing it before repeating.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Configure communication with the MwManager PC software under Parameters / Set Communication.

Byte order & addressing

  • Floats are CDAB (low word first).
  • Commands act on a bit being set; write 0 first to repeat the same command.

Network setup

  • Use MwManager to set the RS-485 or Ethernet parameters.

Watch out for

  • Do not reuse a PUE indicator template: the MW-01-A float word order and holding addresses differ.

Notes on this map

  • Floats are two registers with the low word first (CDAB): the manual's example has 30001 = 0x72B0 and 30002 = 0x3E68 giving 0.227, and its tare write example puts 0x0000 in the first register and 0x3F80 in the second.
  • Left out: 'Precise dosing threshold' (input offset 40, holding offset 270) and 'Adjustment weight mass' (holding offset 272), because the table lists them as float with a length of 1 register, which cannot both be right.
  • The manual's write examples label registers as 40000 + offset (40257 = 'command with parameter' at offset 257, tare at 40259/40260 = offsets 259-260), so they agree with the offset column on the wire; the output-mask example (40502/40507) is copied from another product and does not fit this map. This map follows the table's offset column.
  • Settings (address, baud, IP) are made with Radwag's MwManager PC software; the Modbus manual gives no defaults.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Radwag MW-01-A / MW-01-A7 mass converter

What Modbus registers does the Radwag MW-01-A / MW-01-A7 mass converter have?

This map lists 20 registers: 11 input registers, 9 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Radwag MW-01-A / MW-01-A7 mass converter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables list a 0-based Offset next to a 30001/40001-style Modbus address; the offset goes on the wire (mass = offset 0 = 30001, Command = offset 256 = 40257).

What byte order does the Radwag MW-01-A / MW-01-A7 mass converter use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Radwag MW-01-A / MW-01-A7 mass converter?

Start with IR 0 Mass (Mass); IR 5 Status (Status (stable, zero, errors)); IR 4 Unit (Displayed unit); IR 32 Dosing status (Dosing status); HR 256 Command (Zero / tare / dosing commands).

How do I enable Modbus control of the Radwag MW-01-A / MW-01-A7 mass converter?

Configure communication with the MwManager PC software under Parameters / Set Communication.

Where is the official Radwag MW-01-A / MW-01-A7 mass converter Modbus documentation?
