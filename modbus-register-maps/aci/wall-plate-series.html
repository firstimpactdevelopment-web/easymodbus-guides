Integration notes: ACI (Automation Components Inc.) Wall Plate Series BACnet/Modbus temperature/RH sensor

Integration in brief

Switch the sensor to Modbus with SW4 DIP 4, give it a non-zero address and a fixed baud rate, then read input registers 2 (temperature, tenths) and 3 (RH) with function 04. Check input registers 9000/9001 once to confirm your master decodes unsigned and signed values correctly.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

SW4 DIP 4 ON selects Modbus RTU; address on switches 1-7 (must not be 0); baud on switches 8-10; power-cycle or press reset after any switch change.

Byte order & addressing

  • Temperature unit is set by holding register 0, not fixed; values are tenths of that unit.
  • Test mode (coil 1000) substitutes HR1000/HR1001 values into the live registers and is cleared by reset or power cycle.
  • String registers: test string and user text are null terminated, serial number and firmware are not.

Network setup

  • Set SW4 DIP 4 ON to select Modbus (factory default is BACnet MS/TP), then power-cycle or press reset.
  • Set the address on switches 1-7 (binary, 1-127). Address 0 is the factory default and cannot be used with Modbus.
  • Set the baud rate on switches 8-10 (9600-115200); auto-baud does not work in Modbus mode.
  • SW4 PAR 2 / PAR 1 DIP switches (1 = ON) set framing: 0/0 8-E-1, 0/1 8-O-1, 1/0 8-N-2, 1/1 8-N-1.
  • Move the EOL jumper to EN on the last device of the RS-485 trunk (default DIS).

Watch out for

  • The factory default is BACnet MS/TP with auto-baud; a sensor left at defaults will not answer Modbus.
  • Address 0 is invalid for Modbus.
  • 8-None-1 framing is labelled non-standard by ACI.

Notes on this map

  • The map prints a 1-based Reference column and a 0-based Address column side by side (e.g. Reference 3 = Address 2 for the temperature value); this map uses the Address column.
  • RH values and RH range registers are described only as tenths of %RH without a sign statement; they are listed as unsigned since RH cannot be negative. The RH offset is explicitly allowed to be negative (example -16 = -1.6 %RH) so it is INT16.
  • Temperature registers carry no fixed unit: the unit follows holding register 0 (62 °C, 63 K, 64 °F).
  • Temperature-only models have no RH element and RH-only models no temperature element; input register 0 shows which is fitted.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ACI (Automation Components Inc.) Wall Plate Series BACnet/Modbus temperature/RH sensor

What Modbus registers does the ACI (Automation Components Inc.) Wall Plate Series BACnet/Modbus temperature/RH sensor have?

This map lists 21 registers: 1 coil, 12 input registers, 8 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ACI (Automation Components Inc.) Wall Plate Series BACnet/Modbus temperature/RH sensor Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row gives a Reference (1-based, e.g. 3) and an Address (0-based, e.g. 2). The documented field here holds the Reference; the address field holds the Address column, which is what goes on the wire.

What are the minimum Modbus registers to integrate the ACI (Automation Components Inc.) Wall Plate Series BACnet/Modbus temperature/RH sensor?

Start with IR 2 Temperature sensor value (Temperature value); IR 3 RH sensor value (Relative humidity); HR 0 Temperature units (Temperature unit); IR 0 Sensors present (Which sensors are fitted); IR 9000 Unsigned test value (Decoding check 12345); IR 9001 Signed test value (Signed decoding check -12345).

How do I enable Modbus control of the ACI (Automation Components Inc.) Wall Plate Series BACnet/Modbus temperature/RH sensor?

SW4 DIP 4 ON selects Modbus RTU; address on switches 1-7 (must not be 0); baud on switches 8-10; power-cycle or press reset after any switch change.
