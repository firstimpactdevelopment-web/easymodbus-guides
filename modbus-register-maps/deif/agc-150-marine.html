DEIF AGC 150 Generator Marine controller Modbus register map

Updated 19 November 2026

Short answer

The AGC 150 Marine is DEIF's marine genset controller for single or paralleled ship generators. It is a Modbus server on Ethernet (Modbus TCP) and on its RS-485 ports (Modbus RTU). This map lists the GEN-M-type AC measurements, energy and hour counters, DC supply, mode and status flags, and the control command words used for remote start, stop, breaker and mode commands.

This page lists 164 Modbus registers for the DEIF AGC 150 Generator Marine controller — 19 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from DEIF’s own free documentation (linked below) and checked against it.

Integration notes: DEIF AGC 150 Generator Marine controller

Integration in brief

Read input registers 501-538 with function 04 for generator values and 1019 for the active mode. Write holding register 5 or 6 with bit 0 set plus the command bit to start, stop, open/close breakers or change mode.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

RS-485: set ID (7511/7521) and speed (7512/7522) under Communication > RS485. Ethernet: set the IP under Settings > Communication > Ethernet setup or in the utility software.

Communication loss & watchdog

RS-485 communication error: enable with 7516/7526, timer 7513/7523 (1-100 s, default 10 s), fail class 7517/7527 (default Warning).

Byte order & addressing

  • A command word is ignored unless bit 0 is 1 in the same write.
  • Function 04 addresses 0-499 are a user-configurable copy area.

Network setup

  • RS-485 default ID 3 and 9600 baud; 9600, 19200, 38400 or 115200 baud selectable.

Watch out for

  • AC voltages, currents and powers are whole units (scale 1); frequency and power factor use 0.01, and DC supply voltage uses 0.1.

Notes on this map

  • The source is an Excel workbook. Each row has a scaling exponent x; the value is raw x 10^-x, so x=2 means scale 0.01. Units are as printed.
  • 32-bit values are ABCD: the manual (section 3.4) puts the high 16 bits at the lower address.
  • Data formats, RS-485 settings and the communication-error timer come from the AGC 150 Modbus server user manual 4189341435-B (https://deif-cdn-umbraco.azureedge.net/media/w25puznj/agc-150-modbus-server-user-manual-4189341435-uk.pdf).
  • Only rows marked for the GEN-M controller type are listed; the ENG-M (engine drive) type reuses addresses.
  • Left out: configurable area 0-499, analogue/multi-inputs and CIO values, alarm bits, EIC engine data (including 26000 upward), DAVR, power-management, the ASCII controller-name words 770-775, the command-flag coils, and input 767 (reactive power load printed with unit kW).
  • Parameters are read and written at an address-area start plus the parameter's USW address (for example 12 + 6000 = 6012 for alarm acknowledge of over-voltage 1).
  • The active-alarm list is at input registers 28000-28099 (each holds the USW address of an active alarm); not listed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the DEIF AGC 150 Generator Marine controller

What Modbus registers does the DEIF AGC 150 Generator Marine controller have?

This map lists 164 registers: 20 discrete inputs, 125 input registers, 19 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the DEIF AGC 150 Generator Marine controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The 'Modbus address' column is the address in the request. The tables also print a 6-digit PLC address one higher (input 501 = PLC 300502).

What byte order does the DEIF AGC 150 Generator Marine controller use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the DEIF AGC 150 Generator Marine controller?

Start with IR 501 Generator voltage L1-L2 (Generator voltage L1-L2); IR 507 Generator frequency L1 (Generator frequency); IR 513 Generator current L1 (Generator current L1); IR 519 Generator power (Generator active power); IR 554 Absolute running hours (Running hours); IR 1019 Mode flags word 1019 (Active mode); HR 5 Control command word 5 (Remote start/stop and breaker commands).

How do I enable Modbus control of the DEIF AGC 150 Generator Marine controller?

RS-485: set ID (7511/7521) and speed (7512/7522) under Communication > RS485. Ethernet: set the IP under Settings > Communication > Ethernet setup or in the utility software.

What happens when the DEIF AGC 150 Generator Marine controller loses Modbus communication?

RS-485 communication error: enable with 7516/7526, timer 7513/7523 (1-100 s, default 10 s), fail class 7517/7527 (default Warning).

Where is the official DEIF AGC 150 Generator Marine controller Modbus documentation?

The source is AGC 150 Marine Modbus server tables (4189341453 rev. E), published free by DEIF at https://deif-cdn-umbraco.azureedge.net/media/zvzb4yfx/agc-150-marine-modbus-server-tables-4189341453-uk.xlsx.
