Short answer

The PXH is a Fuji Electric digital process controller. Every Modbus value is a 32-bit integer spread over two registers, low word first. This map covers the read-only monitoring block: control mode, PV, SV, deviation, MV, input error, alarm and relay states, ramp/soak position, extra inputs/outputs and DI/DO status.

Integration notes: Fuji Electric PXH digital controller (Modbus RTU, monitoring map)

Integration in brief

Read input registers 30257-30269 with function 04 (control mode, PV, SV, DV, MV, input error) as 32-bit values with the low word first, two registers per value.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set SPD4 (speed), BIT4 (parity) and STN4 (station 0-255; 0 stops communication) for the RS-485 channel on the front keys, then cycle power.

Byte order & addressing

  • 32-bit values are low word first; a single-register write (06) only changes the lower word.
  • The PC-loader port always uses station 1.

Network setup

  • Factory defaults (RS-485): 38400 bps, 8 data bits, 1 stop bit, odd parity, station 1.
  • Turn power off and on after changing the communication settings.

Watch out for

  • After changing the input range over the bus, a FIX command and a power cycle or reset are needed before the new range applies.

Notes on this map

  • All PXH data are two registers per value; the manual's read and write examples put the lower word first (CDAB). Read both registers in one request.
  • Function 04 reads at most 15 registers per request; 03 reads up to 32.
  • Holding-register parameters (40001-45001) are not included: their decimal-point table could not be tied to each register with certainty.
  • Values carry no decimal point; PV-type values follow the input range decimal point setting.
  • Heating/cooling MV (30625-30643), totalizer and timer monitors are omitted.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Fuji Electric PXH digital controller (Modbus RTU, monitoring map)

What Modbus registers does the Fuji Electric PXH digital controller (Modbus RTU, monitoring map) have?

This map lists 35 registers: 35 input registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Fuji Electric PXH digital controller (Modbus RTU, monitoring map) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are printed Modicon-style (30259) with the relative wire address beside them (0102H = 30259 - 30001).

What byte order does the Fuji Electric PXH digital controller (Modbus RTU, monitoring map) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Fuji Electric PXH digital controller (Modbus RTU, monitoring map)?

Start with IR 258 PV1 control PV (PV1 (30259)); IR 260 SV1 current setpoint (SV1 (30261)); IR 264 MV1 manipulated value (MV1 (30265)); IR 268 FAULT1 input error status (Input error (30269)); IR 256 PID MODE1 current control mode (Control mode bits (30257)); IR 832 ALM1 status (Alarm 1 status (30833)).

How do I enable Modbus control of the Fuji Electric PXH digital controller (Modbus RTU, monitoring map)?

Set SPD4 (speed), BIT4 (parity) and STN4 (station 0-255; 0 stops communication) for the RS-485 channel on the front keys, then cycle power.
