Shinko Technos PCA1 programmable controller (C/C5 option) Modbus register map

Updated 17 November 2026

Short answer

The PCA1 is a ramp/soak controller with 16 patterns of 16 steps that draw their PID, wait, alarm, output and time-signal settings from numbered blocks. On RS-485 it speaks Shinko protocol or Modbus ASCII/RTU; every item is a signed 16-bit holding register. The map covers general settings, run/hold/advance commands, monitor values, every block table and the per-pattern repeat/link items; step items are listed for pattern 0, step 0 with the rule for the rest.

Integration notes: Shinko Technos PCA1 programmable controller (C/C5 option)

Integration in brief

Select MODBUS RTU in the Communication Parameter Setting Group and give the unit a non-zero instrument number; then poll PV 0080H, current step SV 0083H, pattern/step 0085H and status 0086H-0088H, and run/stop the program with 0042H.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Requires the C or C5 option. In the Communication Parameter Setting Group set Communication protocol to MODBUS RTU (or ASCII), then instrument number, speed, data bit/parity and stop bit; these are keypad-only.

Byte order & addressing

  • The manual's Modicon example writes 1000H as 41001, treating the hex digits as decimal; its example frames send 1000H itself as the PDU address (CRCs check), so use the hex data item directly.
  • Instrument number 0 is the Modbus broadcast address; give each unit 1-95.
  • Serial communication and the USB console cable cannot be used at the same time.

Network setup

  • Factory defaults: Shinko protocol, instrument number 0, 9600 bps, 7 bits/even parity, 1 stop bit, 10 ms response delay.
  • For Modbus RTU choose an 8-bit data format.

Watch out for

  • HOLD, ADVANCE and PREVIOUS STEP return exception 17 (11H) in program standby.
  • Multi-register writes to non-existent or out-of-range items are acknowledged but discarded; check by reading back.

Notes on this map

  • Step items: address = 1000H + pattern x 100H + step x 10H + item, pattern and step 0-F, item 0 (SV) to D (output block). Only pattern 0, step 0 is listed here; all 256 steps use the same item layout.
  • Block items: PID 2k00H-2k04H, wait 3k00H, alarm 4k00H-4k03H, output 5k00H-5k04H (k = block 0-9), time signal 6k00H-6k01H (k = 0-F), repetitions/link 7p00H-7p01H (p = pattern 0-F).
  • All data are 16-bit two's complement; values with a decimal point are sent as whole numbers.
  • Units of PID times, limits and MV are not printed in the command table.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Shinko Technos PCA1 programmable controller (C/C5 option)

What Modbus registers does the Shinko Technos PCA1 programmable controller (C/C5 option) have?

This map lists 328 registers: 328 holding registers. 318 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Shinko Technos PCA1 programmable controller (C/C5 option) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Data items are hex (0080H, 1000H) and are sent unchanged as the Modbus holding-register address. The manual says the Modicon number is the data item plus 40001. The RTU examples read PV at 0080H and pattern 0 step 0 SV at 1000H (CRCs 85E2H and 80CAH checked).

What are the minimum Modbus registers to integrate the Shinko Technos PCA1 programmable controller (C/C5 option)?

Start with HR 128 PV (Process value); HR 131 Current step SV (Current step SV); HR 133 Current pattern and step (Running pattern and step); HR 136 Current unit status (Run/hold/wait status); HR 134 Status flag 1 (Output, alarm and error flags); HR 66 Program control Run/Stop (Program Run/Stop); HR 63 Pattern number for operation (Pattern to run); HR 46 Decimal point place (Decimal point for scaling).

How do I enable Modbus control of the Shinko Technos PCA1 programmable controller (C/C5 option)?

Requires the C or C5 option. In the Communication Parameter Setting Group set Communication protocol to MODBUS RTU (or ASCII), then instrument number, speed, data bit/parity and stop bit; these are keypad-only.

Where is the official Shinko Technos PCA1 programmable controller (C/C5 option) Modbus documentation?

The source is Communication Instruction Manual PCA1 (C, C5) (No. PCA1CE3), revision 2019-12, published free by Shinko Technos at https://shinko-technos.co.jp/e/manual/english/PCA1CE3.pdf.
