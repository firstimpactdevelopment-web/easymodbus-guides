Updated 17 November 2026

Short answer

Modular electronic controller for HVAC and refrigeration: up to three sensor inputs drive up to ten relay or analog outputs. The C450CRN-1 control module is a Modbus RTU subordinate that exposes one holding-register image: module info, sensor types, offsets and live values (IEEE floats), sensor failure flags, output types and statuses, and a 13-register setup block per output (referenced sensor, on/off or setpoint/end point, delays, integration, failure mode).

Integration notes: Johnson Controls PENN System 450 with C450CRN-1 Modbus communications control module

Integration in brief

Set address, baud, parity and stop bits on the C450CRN-1 Communications Setup screens, set the EOL switch on the end device, then read 40100-40110 to learn which outputs exist and poll sensor values (40301-40318) and output statuses (40201-40210). Change setpoints by writing SENS/ON/OFF (or SP/EP) and then any value to the output's Validate register.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Use a C450CRN-1 control module (the only System 450 module with Modbus). In the module UI go to Communications Setup (COMM) and set Addr, bAUd, PAR and STOP.

Byte order & addressing

  • Register numbers are 4xxxx: subtract 40001 for the PDU address.
  • Floats span two registers, high word first.
  • Setpoint writes are only validated when the Validate register (41n07) is written or all five setpoint registers have been written; invalid ON/OFF or SP/EP pairs (range or minimum differential) are rejected.
  • Supported function codes: 3, 6 and 16 only.

Network setup

  • Device address 1-247; baud 9600, 19200 or 38400; parity 0 none, 1 odd, 2 even; 1 or 2 stop bits (2 only with no parity).
  • RS-485 terminals A'+, B'- and C' REF with shielded cable; set the EOL switch On only at the ends of the trunk.

Watch out for

  • Outputs that report type 0 are not physically present; their setup registers have no effect.
  • If a relay output references a binary-input sensor, its ON/OFF values are ignored.
  • Changing a sensor type changes ranges and default setup values of the outputs that reference it.

Notes on this map

  • Source is Johnson Controls' own documentation portal; the same bulletin is offered there as a PDF attachment (LIT-12011826 .pdf).
  • Float word order: the bulletin says floats are stored most significant byte first and that the Niagara Modbus driver calls this Order3210, i.e. fully big-endian: high word in the lower register (ABCD).
  • 'Integer 16' is defined as a signed 16-bit integer, so all single registers are INT16.
  • Sensor values, ON/OFF and SP/EP floats are in the units of the referenced sensor's Sensor Type (Table 21 in the bulletin); the Sn-x Units string registers give the units text.
  • Output setup registers 41n01-41n13 (n = output number, output 10 uses 42001-42013) mean different things for relay and analog outputs; both meanings are given in each name. The bulletin lists the analog SNF in 41n13 and the analog dead band in 41n12.
  • Serial defaults are not stated: address 1-247, baud 9600/19200/38400, parity none/odd/even and 1 or 2 stop bits (2 only with no parity) are set in the module UI.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Johnson Controls PENN System 450 with C450CRN-1 Modbus communications control module

What Modbus registers does the Johnson Controls PENN System 450 with C450CRN-1 Modbus communications control module have?

This map lists 159 registers: 159 holding registers. 106 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Johnson Controls PENN System 450 with C450CRN-1 Modbus communications control module Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The bulletin lists 4xxxx holding registers and says the address in the request frame is the register address minus 40001 (40001 -> 0).

What byte order does the Johnson Controls PENN System 450 with C450CRN-1 Modbus communications control module use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Johnson Controls PENN System 450 with C450CRN-1 Modbus communications control module?

Start with HR 0 Model ID (Model ID check (24 = C450CRN)); HR 99 Number of System Outputs (Number of outputs); HR 300 Sn-1 Value (Sn-1 sensed value (float)); HR 302 Sn-1 Failure State (Sn-1 failure state); HR 200 Output 1 Status (Output 1 status); HR 1102 Output 1 ON value (relay) / SP setpoint (analog) (Output 1 ON / setpoint); HR 1104 Output 1 OFF value (relay) / EP end point (analog) (Output 1 OFF / end point); HR 1106 Output 1 Validate setpoints (Output 1 validate setpoint write).

How do I enable Modbus control of the Johnson Controls PENN System 450 with C450CRN-1 Modbus communications control module?

Use a C450CRN-1 control module (the only System 450 module with Modbus). In the module UI go to Communications Setup (COMM) and set Addr, bAUd, PAR and STOP.
