Short answer

The Neptronic SKS4 is a steam-to-steam humidifier with a modulating steam valve. Its Modbus RTU module exposes holding registers only: signal voltages, scaled room and supply RH, water and board temperatures, demand and steam-valve output, set points and PID terms, binary inputs and relays as 0/1 registers, and enumerated profile, source, boiler-state and alarm codes.

Integration notes: Neptronic SKS4 steam-to-steam humidifier (Modbus communication module)

Integration in brief

Read Room RH (6005), Humidity Demand (6047), System Power Output (6048), Boiler State (15015) and Boiler Alarm (15017). For BAS control set Control Profile (15004) and Humidity Control Demand Source (15011) to the network options and write Humidity Control Network Demand (6045) within the Network Timeout.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Modbus communication module, set the address in the device menu (or register 0) and pick network profile and sources (15004-15012) if the BAS supplies readings or demand.

Communication loss & watchdog

Network Timeout (6084, 1-900 s, default 900 s): network-supplied values must be refreshed within this time; Network Control State (12008) shows a fault.

Byte order & addressing

  • All points, binary ones included, are holding registers (FC03/06/16 only).
  • Default framing is no parity with 2 stop bits.

Network setup

  • RS-485 two-wire, RTU; 9600-57600 baud or auto baud detection.
  • Parity/stop bits via register 2 or the Modbus Comport Config menu item.

Watch out for

  • Several register numbers differ from the SKE4 guide even where names match; use the SKS4 list.

Notes on this map

  • Only function codes 03, 06 and 16 are supported, so binary points (inputs, relays, flags) are 16-bit holding registers holding 0 or 1.
  • 'Scale N' with 'Value x N' means the raw value is the engineering value times N; this map stores the multiplier 1/N.
  • Temperature and capacity units follow Modbus Server Units (415001): 0 metric, 1 imperial.
  • The guide text calls automatic baud detection the default, while register 1 lists 19200 as its default value; the baud default is left blank here.
  • Default unit address is not stated; it is set from the device menu or register 0.
  • Left out: product name ASCII registers 3-6; protocol addresses 6008 and 6035, which each appear twice in the table with different holding numbers and names (Room RH Bias / Supply High Limit RH, Room Demand Proportional Gain / Integral Time); Water Temperature Bias 6018 and Cabinet Temperature 6019 (typed unsigned with negative ranges); Boiler Drain Volume 6071, Boiler Max Steam Output 6072 and Boiler Idle Temperature Setpoint 6074 (scale and example disagree); the run/on/service time and calibration counters (6053-6068, 6087-6090), which span four registers with no stated word order.
  • System Power State (15021) has its writable flag printed inside the value column; it is listed as writable here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Neptronic SKS4 steam-to-steam humidifier (Modbus communication module)

What Modbus registers does the Neptronic SKS4 steam-to-steam humidifier (Modbus communication module) have?

This map lists 147 registers: 147 holding registers. 69 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Neptronic SKS4 steam-to-steam humidifier (Modbus communication module) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide prints a protocol-base (0-based) address and a six-digit holding register (base 400001) side by side, e.g. 6005 / 406006. The protocol-base number is the wire address.

What are the minimum Modbus registers to integrate the Neptronic SKS4 steam-to-steam humidifier (Modbus communication module)?

Start with HR 6005 Room RH (Room RH); HR 6032 Room RH Setpoint (Room RH set point); HR 6047 Humidity Demand (Humidity demand); HR 6048 System Power Output (System power output); HR 15015 Boiler State (Boiler state); HR 15017 Boiler Alarm (Boiler alarm); HR 15021 System Power State (System on/off); HR 6045 Humidity Control Network Demand (Network demand).

How do I enable Modbus control of the Neptronic SKS4 steam-to-steam humidifier (Modbus communication module)?

Fit the Modbus communication module, set the address in the device menu (or register 0) and pick network profile and sources (15004-15012) if the BAS supplies readings or demand.

What happens when the Neptronic SKS4 steam-to-steam humidifier (Modbus communication module) loses Modbus communication?

Network Timeout (6084, 1-900 s, default 900 s): network-supplied values must be refreshed within this time; Network Control State (12008) shows a fault.
