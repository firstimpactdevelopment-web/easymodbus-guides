Integration notes: Johnson Controls GS3000 indoor Modbus carbon monoxide transmitter

Integration in brief

Set a unique address on the 8-way DIP switch, wire A-/B+/shield, and poll holding registers 0-1 at 9600 8N1: status then CO in ppm.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

RegisterNameTypeWhyAccess
HR 1CO ConcentrationUINT16CO level in ppmRead
HR 0CO Sensor StatusUINT16Sensor status (abnormal = fault)Read

Enable Modbus control & writes

Modbus is always on; set the address (1-255) with the DIP switch before connecting to the network.

Byte order & addressing

  • Address is binary on DIP switches weighted 128-64-32-16-8-4-2-1.
  • Baud, parity and stop bits are fixed (9600, none, 1).

Network setup

  • Fit the PCB EOL jumper (121 ohm) only on the devices at each end of the segment.
  • Use 22 AWG shielded twisted pair; ground the shield at one end; max 4000 ft per segment.

Watch out for

  • Half-wave power supply: keep the same circuit ground on all devices and the controller.
  • Allow 30 min warm-up before calibrating.

Notes on this map

  • Both registers are unsigned 16-bit words and read-only. Figure 11 shows both being read with function 03 (Read Holding Registers), one register per request; exception codes 01, 02 and 03 are returned for bad requests.

Questions about the Johnson Controls GS3000 indoor Modbus carbon monoxide transmitter

What Modbus registers does the Johnson Controls GS3000 indoor Modbus carbon monoxide transmitter have?

This map lists 2 registers: 2 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Johnson Controls GS3000 indoor Modbus carbon monoxide transmitter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Table 4 lists Modbus address 40001 with offset +0 and 40002 with offset +1, and the example query frames (Figure 11) send start address 0x0000 for status and 0x0001 for CO, so the wire addresses are 0 and 1.

What are the minimum Modbus registers to integrate the Johnson Controls GS3000 indoor Modbus carbon monoxide transmitter?

Start with HR 1 CO Concentration (CO level in ppm); HR 0 CO Sensor Status (Sensor status (abnormal = fault)).

How do I enable Modbus control of the Johnson Controls GS3000 indoor Modbus carbon monoxide transmitter?

Modbus is always on; set the address (1-255) with the DIP switch before connecting to the network.
