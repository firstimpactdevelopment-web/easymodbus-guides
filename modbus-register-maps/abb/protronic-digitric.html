Short answer

ABB's Protronic and Digitric panel controllers expose their internal variables to a Modbus RTU master through an interface module. Global variables (analog inputs and outputs and the per-loop controller values) are 32-bit IEEE floats in pairs of holding registers starting at register 0; online parameters and binary I/O have their own ranges. This map covers the basic and slot-1 analog I/O plus the main setpoint, process value, deviation and output values of control loops 1-4.

This page lists 38 Modbus registers for the ABB Protronic 100/500/550 and Digitric 500 process controllers (Modbus RTU) — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ABB’s own free documentation (linked below) and checked against it.

Integration notes: ABB Protronic 100/500/550 and Digitric 500 process controllers (Modbus RTU)

Integration in brief

Read the loop values with function 03 as CDAB floats: process value at 164 (loop 1), active setpoint at 238, controller output at 184; add 150 per further loop. Analog inputs start at register 0.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the RS-485 (or RS-232) interface module and set the station address and line settings on the controller; addresses 1-255 are allowed, 0 is broadcast.

Byte order & addressing

  • REAL values are low word first (even register = low word).
  • Always read or write both registers of a REAL together.
  • Function 04 behaves like 03 and 02 like 01.

Network setup

  • RS-485: up to 32 stations, cable under 1200 m, stubs under 0.3 m, electrically isolated; RS-232 for a single PC up to 10 m.

Watch out for

  • Gaps in the register table (e.g. 60-69, 78-79) are unassigned.

Notes on this map

  • Word order: with the pair-of-registers method the even register carries the low word and the next (odd) register the high word of the IEEE-754 REAL, so floats are CDAB.
  • The same variables can also be read in a mantissa/exponent format by adding 2000 to the register number (FW 1.149 and later); that format is not listed.
  • Values are in the engineering units configured in the controller, so no units are given.
  • Loop variables repeat every 150 registers (loop 1 from 150, loop 2 from 300, loop 3 from 450, loop 4 from 600). Many more loop variables (constants, limits, PID parts, free variables) and analog I/O of slots 2-7 follow the same table and are not all listed.
  • Online parameters sit at 10000-20000 (10000 + loop x 1000 + 2 x parameter number, e.g. loop 1 Kp = 11002). Register 900 accepts key-press codes for remote keyboard operation. Binary inputs/outputs are read as coils (e.g. BE01 from 151). These are not listed.
  • The table does not mark which global variables are writable; all are listed read-only here. Writes use function 06 (two telegrams for a REAL) or 16.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ABB Protronic 100/500/550 and Digitric 500 process controllers (Modbus RTU)

What Modbus registers does the ABB Protronic 100/500/550 and Digitric 500 process controllers (Modbus RTU) have?

This map lists 38 registers: 38 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB Protronic 100/500/550 and Digitric 500 process controllers (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register numbers are printed in decimal starting at 0 and go on the wire unchanged: the manual's example reads analog input AE01 from registers 0 and 1 with start address 00 00. Function 03 is preferred; function 04 returns the same data.

What byte order does the ABB Protronic 100/500/550 and Digitric 500 process controllers (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ABB Protronic 100/500/550 and Digitric 500 process controllers (Modbus RTU)?

Start with HR 164 Loop 1 process value (digital display) (.L1_XDIGI) (Loop 1 process value); HR 238 Loop 1 active setpoint (.L1_WW) (Loop 1 active setpoint); HR 184 Loop 1 PID output (.L1_PID_Y_OUT) (Loop 1 PID output); HR 170 Loop 1 control deviation (.L1_XW) (Loop 1 control deviation); HR 0 Basic device analog input 1 (.AE01) (Analog input 1).

How do I enable Modbus control of the ABB Protronic 100/500/550 and Digitric 500 process controllers (Modbus RTU)?

Fit the RS-485 (or RS-232) interface module and set the station address and line settings on the controller; addresses 1-255 are allowed, 0 is broadcast.
