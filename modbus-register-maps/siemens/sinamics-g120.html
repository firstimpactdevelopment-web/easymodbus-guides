Siemens SINAMICS G120 / G120C (Modbus RTU) Modbus register map

Updated 24 October 2026

Short answer

Siemens' modular drive family (Control Unit plus Power Module) and its compact G120C variant. Control Units with an RS485 port run Modbus RTU as a slave when p2030 = 2. Holding registers 40100-40111 carry the PROFIdrive control word, main setpoint, status word and actual value; 40200-40522 map I/O, drive data, measurements, fault numbers and technology (PID) controller settings. This map covers that whole table except two registers: one with an inconsistent scaling entry and one with no stated bit polarity.

This page lists 56 Modbus registers for the Siemens SINAMICS G120 / G120C (Modbus RTU) — 18 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Siemens’s own free documentation (linked below) and checked against it.

Integration notes: Siemens SINAMICS G120 / G120C (Modbus RTU)

Integration in brief

Set p0015 = 21 (USS fieldbus macro), then p2030 = 2 (Modbus), the address and baud rate. Write 047E hex to 40100, then 047F hex (bit 0 going 0 to 1 = ON) to start, the speed setpoint to 40101 (4000 hex = p2000), and poll 40110/40111 plus 40342-40347 for frequency, current and power.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

p0015 = 21 'USS fieldbus' (CU230P-2 HVAC/BT can instead use macro 109 'BT Mac 9: Modbus RTU Fieldbus'), then p2030 = 2 for Modbus, p2020 for baud rate (factory 7 = 19200 bit/s, range 4800-187500), and the address via the Control Unit's address switches or p2021. With STARTER, save the settings afterwards.

Communication loss & watchdog

p2040 fieldbus monitoring time (factory 100 ms, 0 disables): if no process data (40100, 40101, 40110, 40111) is accessed within this time, the drive trips with F01910 'setpoint timeout'. Accessing only parameter registers 40200-40522 does not keep it alive.

Byte order & addressing

  • Only FC03 (read, up to 125 registers) and FC06 (single write); there is no FC16.
  • Valid registers are 40001-40065 and 40100-40522; anything else returns exception 02. Reading a reserved or write-only register returns zeros.
  • Writing a read-only or reserved register returns exception 04; the reason is in 40499.
  • The manual states the Control Unit runs Modbus RTU with even parity; no parity parameter is described.
  • The unit switchover function must not be used with Modbus.

Network setup

  • RS485 on connector X128 (CU) pins 2 = RS485P, 3 = RS485N, 1 = 0 V, 4 = shield; G110M uses M12 X03/X04.
  • Switch on the bus terminating resistor at the first and last node; both must be powered.
  • Address 1-247: DIP switches set 1-127 and override p2021; set all switches to 0 to use p2021 (needed for 128-247). Power-cycle until all LEDs go dark after changing the address.
  • p2024[0..2] set slave response time, character delay and inter-telegram gap; p2024[1] and [2] are 0 from the factory, which lets the drive derive them from the baud rate.
  • Maximum cable length 100 m; r2029 shows receive error statistics.

Watch out for

  • The factory protocol on the RS485 port is USS; nothing answers Modbus until p2030 = 2.
  • If the address switches hold a valid address, p2021 cannot be changed and is ignored.
  • With p2040 > 0 a master that only polls 40200+ will still trip F01910; include the process-data registers in the poll.

Notes on this map

  • All values are single 16-bit registers. The table's 'scaling factor' is what the engineering value is multiplied by before transmission (e.g. 100 for 0.01 Hz), so the scale here is 1 / factor.
  • Signed/unsigned is not printed per register; registers with a negative range are INT16, the rest UINT16. Ramp times (650.0 s x 100) exceed 32767 raw, which only fits as unsigned.
  • Control and status word bits are the PROFIdrive STW1/ZSW1 layout ('all other telegrams' column of the PROFIdrive section), which assumes the default interconnection of the received/sent process data; they change if that interconnection is altered (e.g. free telegram configuration via p0922/p2079 = 999 or BICO changes).
  • Left out: 40301 Converter firmware (scaling factor 0.0001 contradicts its printed range 0.00-327.67) and 40349 Control priority (HAND/AUTO text without a stated bit polarity).
  • Table 5-11 labels 40401-40407 as 'Failure number, index 1..6' with index 2 printed twice; the parameter column (r0947[1]..r0947[7]) is used here.
  • 40001-40065 (MICROMASTER MM436 compatible range) is mentioned but not mapped in this manual, so it is not included.
  • SINAMICS G120X is not covered by this manual; do not use this map for it without its own documentation.

Questions about the Siemens SINAMICS G120 / G120C (Modbus RTU)

What Modbus registers does the Siemens SINAMICS G120 / G120C (Modbus RTU) have?

This map lists 56 registers: 56 holding registers. 18 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Siemens SINAMICS G120 / G120C (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as 40100-40522. The manual's request examples send 00 6D for register 40110 and 00 63 for 40100, so the wire address is the printed number minus 40001 (control word 40100 = address 99).

What are the minimum Modbus registers to integrate the Siemens SINAMICS G120 / G120C (Modbus RTU)?

Start with HR 99 Control word (Control word STW1); HR 100 Main setpoint (Main setpoint, 4000 hex = p2000); HR 109 Status word (Status word ZSW1); HR 110 Main actual value (Main actual value); HR 341 Output frequency (Output frequency in 0.01 Hz); HR 344 Actual current value (Output current in 0.01 A); HR 346 Actual active power (Active power in 0.01 kW); HR 399 Failure number r0947[0] (Latest fault number).

How do I enable Modbus control of the Siemens SINAMICS G120 / G120C (Modbus RTU)?

p0015 = 21 'USS fieldbus' (CU230P-2 HVAC/BT can instead use macro 109 'BT Mac 9: Modbus RTU Fieldbus'), then p2030 = 2 for Modbus, p2020 for baud rate (factory 7 = 19200 bit/s, range 4800-187500), and the address via the Control Unit's address switches or p2021. With STARTER, save the settings afterwards.

What happens when the Siemens SINAMICS G120 / G120C (Modbus RTU) loses Modbus communication?

p2040 fieldbus monitoring time (factory 100 ms, 0 disables): if no process data (40100, 40101, 40110, 40111) is accessed within this time, the drive trips with F01910 'setpoint timeout'. Accessing only parameter registers 40200-40522 does not keep it alive.
