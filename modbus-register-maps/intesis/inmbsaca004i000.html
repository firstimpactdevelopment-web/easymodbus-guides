Short answer

Modbus RTU slave on the XYE bus of XYE-bus (VRF / commercial line) indoor units. Each of up to 4, 8 or 32 index slots maps to an indoor unit address and has a 20-register block for on/off, mode, fan, vane, setpoint, room temperature, alarm, error and remote lock; registers 0..8 send commands to all units.

Integration notes: Intesis (HMS Networks) INMBSACA004I000 / 008I000 / 032I000 XYE-bus air conditioner to Modbus RTU interface (4 to 32 units)

Integration in brief

Address the indoor units 0..63 in the AC system, write each unit's address into its slot (1000 + 20n + 9), then read and write the 20-register slot blocks.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Write the AC-system address of each indoor unit into its slot's assignment register (1000 + 20n + 9); the slot index n is not the unit's address.

Byte order & addressing

  • All registers are unsigned 16-bit holding registers.
  • Error code 65535 (-1 signed) means the interface cannot reach that unit.

Network setup

  • Slave address and baud rate are set on DIP switches SW3/SW4 (factory: address 1, 9600 bps) and can be read back over Modbus.
  • The interface detects 8N2 or 8N1 framing by itself.
  • Changes to DIP switches need a power cycle.
  • Connect X / Y of the indoor unit's XYE bus to the interface (E is not used); the bus may be up to 1200 m.
  • SW1 (unit features) is not used on the multi-unit models; leave it at default.

Watch out for

  • Registers 0..8 are write-only broadcasts to every unit.

Notes on this map

  • Every register is a 16-bit unsigned holding register per the manual. Temperature rows print an initialisation value of -32678 (some rows -32768, which is raw 0x8000 = 32768); -32678 looks like a typo for -32768 but the manual does not confirm it, so no marker value is given for those rows.
  • Temperatures follow DIP switch SW4: whole °C, decidegrees (x10) or °F. The register footnotes call x10 the default, but the SW4 table marks Celsius degrees as the factory setting, so scale 1 / °C is used here; with x10 selected use 0.1.
  • The baud-rate registers are left out: the manual lists the available rates but not the number that stands for each one.
  • Only index n = 0 is listed. For index n add 20 x n (n = 1 on/off = 1020).
  • The index n is not the unit's address in the AC system: write the unit's address (0..63) into 1000 + 20 x n + 9 first.
  • Error code list not reproduced; see the manual's error-code section.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious.
