Short answer

The Gree Modbus Gateway (Mini) sits on the CAN bus of a GMV multi VRF system and serves up to 16 outdoor systems and 128 indoor units to a BMS over Modbus RTU. Holding registers carry per-indoor-unit on/off, mode, setpoint, fan speed and temperatures plus per-system outdoor data; coils carry feature flags, shields, locks and fault bits. Every indoor unit and system has an identical block, so this map lists indoor unit 1 and system 1 and gives the address rule for the rest.

This page lists 65 Modbus registers for the Gree Modbus Gateway (Mini) ME30-24/E6(M) for GMV multi VRF systems — 38 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Gree’s own free documentation (linked below) and checked against it.

Integration notes: Gree Modbus Gateway (Mini) ME30-24/E6(M) for GMV multi VRF systems

Integration in brief

Set the gateway address on DIP switches S1/S2, wire RS485 at 9600 8N1, then read coils from 120 to see which indoor units exist. Control each unit with its on/off, mode, setpoint and fan words (102-105 for unit 1) using function 0x10, and read fault coils 318-319 and system coils 8488-8495.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No software enable: set the Modbus address (1-255) on DIP switches S1 and S2 inside the gateway, and S3 switch 4 for the CAN2 terminating resistor, before use.

Byte order & addressing

  • Power on/off uses 0xAA (on) and 0x55 (off), not 1/0.
  • Exception code 0x04 means the gateway has no contact with the air-conditioning units; it is also returned after power-up until valid data has been collected.
  • A read of more than 127 words is refused with exception 0x03.
  • Writes that conflict with the outdoor unit capability, the master indoor unit mode or active energy-saving limits are ignored; read back to confirm.

Network setup

  • RS485, 9600 baud, 8 data bits, no parity, 1 stop bit (fixed in the protocol).
  • Gateway address 1-255 on DIP switches S1/S2; address 0 is broadcast (writes only, no reply).
  • One gateway serves up to 16 outdoor systems and 128 indoor units; beyond 128 indoor units use a second gateway (starting unit 129).
  • S3 switch 2 sets the first indoor unit the gateway serves: engineering code 1 (units 1-128) or 129 (units 129-255); word 101 reports the setting.
  • S3 switch 3 switches in the gateway's own RS485 terminating resistor; normally the BMS master end carries it and the gateway is left without.
  • If the gateway is at either end of the CAN2 bus, set S3 switch 4 to 0 to switch in the terminating resistor.

Watch out for

  • Re-commission the gateway whenever the unit engineering data (addresses, number of units) changes.
  • Keep communication wiring at least 15 cm from power cabling.

Notes on this map

  • Gree does not host this protocol publicly; the link is a copy on a Lithuanian distributor's site (Asami) and appears to be the unaltered Gree document.
  • Only indoor unit 1 and outdoor system 1 are listed. The source prints identical blocks for indoor units 2-128 (words +25 per unit, coils +64 per unit), systems 2-16 (words +10, coils +48) and the 'subway' on/off blocks (coils +8 per unit or system).
  • Left out: indoor ambient temperature (word 116) and outdoor ambient temperature (word 3307). Both are sent as x10 with negative ranges, but word 116 is typed 'floating-point' and word 3307 has no data type at all, so the 16-bit encoding is not settled.
  • Words the source skips with '...' (for example 109-114 and 120-122) are not printed there and are not listed.
  • Mode and fan words use one set of codes for writing and another for reading; the values list shows both.
  • The fresh air unit sections (words 4200-13159, bits 11200-27583) are not included in this map.
  • The protocol lists function codes 0x01, 0x03, 0x0F and 0x10 only; single writes (0x05/0x06) are not listed.
  • The ME30-24/E6(M) part number comes from the distributor's product listing; the protocol document itself only calls the device 'Modbus Gateway(Mini)'.

Questions about the Gree Modbus Gateway (Mini) ME30-24/E6(M) for GMV multi VRF systems

What Modbus registers does the Gree Modbus Gateway (Mini) ME30-24/E6(M) for GMV multi VRF systems have?

This map lists 65 registers: 43 coils, 22 holding registers. 38 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Gree Modbus Gateway (Mini) ME30-24/E6(M) for GMV multi VRF systems Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The protocol numbers words from 0 and coils (bits) from 0, and its example frames send the printed number unchanged (read word 1 sends 00 01, read coil 5 sends 00 05). Word n and Bit n are wire address n. Indoor unit n uses words from 102+25*(n-1) and coils from 288+64*(n-1); system m uses words from 3302+10*(m-1) and coils from 8488+48*(m-1).

What are the minimum Modbus registers to integrate the Gree Modbus Gateway (Mini) ME30-24/E6(M) for GMV multi VRF systems?

Start with HR 102 IDU 1 power on/off (IDU 1 on/off); HR 103 IDU 1 operation mode (IDU 1 mode); HR 104 IDU 1 temperature setpoint (IDU 1 setpoint); HR 105 IDU 1 fan speed (IDU 1 fan speed); CO 120 IDU 1 present (IDU 1 present); CO 319 IDU 1 general error (IDU 1 general error); CO 8495 System 1 general outdoor unit error (System 1 outdoor error); CO 8494 System 1 compressor operation status (System 1 compressor running).

How do I enable Modbus control of the Gree Modbus Gateway (Mini) ME30-24/E6(M) for GMV multi VRF systems?

No software enable: set the Modbus address (1-255) on DIP switches S1 and S2 inside the gateway, and S3 switch 4 for the CAN2 terminating resistor, before use.
