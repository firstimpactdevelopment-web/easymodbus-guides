Short answer

The THERMA V monobloc can be run by a third-party controller over Modbus RTU wired to terminal block 3 (26 = A, 27 = B) on the indoor PCB, with no LG gateway. Coils switch space heating/cooling, hot water, silent mode and emergency functions; discrete inputs report pump, compressor, defrost, heater and error states; holding registers carry the operating mode, control method, setpoints and the smart-grid energy state; input registers give the error code, outdoor-unit cycle, flow rate and product type.

Integration notes: LG THERMA V R32 Monobloc air-to-water heat pump (built-in Modbus RTU)

Integration in brief

Wire RS-485 to terminals 26 (A) and 27 (B), set the unit's Modbus address, then read discrete inputs 10001-10017 and input registers 30001-30012 for status and write coils 00001/00002 plus holding registers 40001-40010 for control.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Turn DIP switch No.1 of option switch 1 ON (Modbus function as slave for a 3rd-party controller), then set the Modbus address under Installer setting > Modbus Address on the LG controller.

Byte order & addressing

  • Operation mode codes are 0 = cooling, 3 = auto, 4 = heating (not 0/1/2).
  • Product group and product info sit at the top of the input-register range (39998/39999 = wire 9997/9998).

Network setup

  • Serial settings are 9600 bps, no parity, 1 stop bit.
  • The bus connects to terminal block 3 (26 = A, 27 = B); check the CN_MODBUS harness is fully seated in CN_COM on the indoor PCB. The LG meter interface uses the same terminals.

Watch out for

  • While a 3rd-party Modbus controller is in use, the LG controller cannot run the unit at the same time.

Notes on this map

  • This file follows the North American Rev.02 edition, where holding registers (function 0x03) are numbered 40001- and input registers (0x04) 30001-.
  • Left out: every measured temperature (input registers 30003-30008, 30010, 30011 and 30013: water inlet/outlet, backup heater outlet, DHW tank, solar collector, room air and outdoor air) and the auto-mode shift values 40005 and 40008, because the manual gives a x10 scale but never says whether these values are signed, and they can be negative.
  • Setpoints 40003, 40004, 40006, 40007 and 40009 are listed as UINT16: the map prints only the x10 scale and no signedness, but these targets are always positive in the manual's setting ranges (for example leaving water 15-65 °C heating, 5-27 °C cooling), so signed and unsigned reads agree.
  • The map skips coil 00004 and discrete input 10007; they are not listed in this edition.
  • The error-code register returns LG's numeric error code; the code list is not part of this map.

Questions about the LG THERMA V R32 Monobloc air-to-water heat pump (built-in Modbus RTU)

What Modbus registers does the LG THERMA V R32 Monobloc air-to-water heat pump (built-in Modbus RTU) have?

This map lists 35 registers: 5 coils, 16 discrete inputs, 6 input registers, 8 holding registers. 13 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the LG THERMA V R32 Monobloc air-to-water heat pump (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The memory map prints Modicon numbers: coils 00001-, discrete inputs 10001-, input registers 30001-, holding registers 40001-. Drop the leading table digit and subtract one to get the wire address (40001 = holding register 0, 30009 = input register 8, 39999 = input register 9998).

What are the minimum Modbus registers to integrate the LG THERMA V R32 Monobloc air-to-water heat pump (built-in Modbus RTU)?

Start with CO 0 Enable/Disable (Heating/Cooling) (Space heating/cooling on/off); CO 1 Enable/Disable (DHW) (Hot water on/off); HR 0 Operation mode (Operation mode); HR 2 Target temp (heating/cooling) circuit 1 (Circuit 1 water setpoint); HR 8 DHW target temp. (DHW setpoint); DI 3 Compressor status (Compressor running); DI 13 Error status (Error flag); IR 0 Error code (Error code).

How do I enable Modbus control of the LG THERMA V R32 Monobloc air-to-water heat pump (built-in Modbus RTU)?

Turn DIP switch No.1 of option switch 1 ON (Modbus function as slave for a 3rd-party controller), then set the Modbus address under Installer setting > Modbus Address on the LG controller.
