Teledyne Detcon Model X40 integrated alarm and control system (Modbus slave port) Modbus register map

Updated 17 November 2026

Short answer

The X40 is a Teledyne Detcon gas detection controller that collects up to 32 wired or wireless sensors (CXT sensors, alarm stations, repeaters) and drives alarms. A Modbus RTU slave port lets a BMS or PLC read every channel: one register with the gas reading and one with alarm, fault, calibration, battery, decimal-point and device-type bits. This map lists all 64 registers.

Integration notes: Teledyne Detcon Model X40 integrated alarm and control system (Modbus slave port)

Integration in brief

Give each X40 its own slave address, poll at 9600 8N1 no faster than once per second, and read registers 0-63 (reading/status pairs per channel).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The manual describes no separate enable step for the slave port; give each X40 its own device address when several share one network.

Byte order & addressing

  • Read the status register with every reading to get the decimal point.
  • Minimum inter-poll delay 150 ms; response timeout at least 2000 ms; poll at most once per second.

Network setup

  • 9600 baud, 8 data bits, no parity, 1 stop bit.

Watch out for

  • A channel with type bits 000 is disabled; ignore its reading.

Notes on this map

  • Readings carry no fixed scale: status bits 7-6 give the decimal point (00 = none, 01 = divide by 10, 10 = divide by 100, 11 = undefined, treat as none).
  • Status bits 15-13 give the device type on that channel: 000 disabled, 001 CXT sensor, 010 alarm station, 011 SmartHMI, 100 repeater, 101 sensor, 110/111 undefined (sensor).
  • Bits 4, 6 and 7 are only active for sensor devices. Bit 11 is not used.
  • The manual does not name the function code; the 4xxxx register numbers indicate holding registers (function 03).
  • The slave address is set in the controller menu; no default is stated in this section.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Teledyne Detcon Model X40 integrated alarm and control system (Modbus slave port)

What Modbus registers does the Teledyne Detcon Model X40 integrated alarm and control system (Modbus slave port) have?

This map lists 64 registers: 64 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Teledyne Detcon Model X40 integrated alarm and control system (Modbus slave port) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Table 4 numbers the registers from 40000 (channel 1 reading), so the digits after the leading 4 are the wire address: channel n reading = 2(n-1), status = 2(n-1)+1.

What are the minimum Modbus registers to integrate the Teledyne Detcon Model X40 integrated alarm and control system (Modbus slave port)?

Start with HR 0 Channel 1 reading (Channel 1 reading); HR 1 Channel 1 status (Channel 1 status (alarms, fault, decimals)); HR 2 Channel 2 reading (Channel 2 reading); HR 3 Channel 2 status (Channel 2 status).

How do I enable Modbus control of the Teledyne Detcon Model X40 integrated alarm and control system (Modbus slave port)?

The manual describes no separate enable step for the slave port; give each X40 its own device address when several share one network.

Where is the official Teledyne Detcon Model X40 integrated alarm and control system (Modbus slave port) Modbus documentation?

The source is X40 Instruction Manual (Document #3672, Rev. 3.8), revision 2023-01-18, published free by Teledyne Detcon at https://www.teledynegasandflamedetection.com/en-us/Products/docs/controllers-x40-usermanual-english.pdf.
