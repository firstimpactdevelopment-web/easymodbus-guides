Short answer

Gree U-Match units answer Modbus RTU from the indoor controller, so no gateway is needed. Holding registers carry on/off, mode, fan, setpoint, louvres, sleep, clean function and energy-saving limits plus indoor, return-air, display-board and outdoor temperatures; coils carry feature flags, locks, component status and indoor, outdoor and inverter-drive fault bits. Up to 255 units can share a BMS line.

Integration notes: Gree U-Match all-DC-inverter duct / cassette / floor-ceiling units (built-in Modbus)

Integration in brief

Poll words 2-36 for on/off, mode, fan, setpoint and louvres and words 4, 49 and 82 for temperatures; read coils 8-215 for status and faults. Write word 2 (0xAA on / 0x55 off), 17, 19 and 20 to control the unit.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The Modbus interface is built into the unit controller; set each unit's address (1-255 in PC address mode) and power-cycle after changing the outdoor chip or DIP switches.

Byte order & addressing

  • On/off uses 0xAA and 0x55, not 1 and 0.
  • Energy-saving bits 32 and 33 must be written together.
  • Exception code 04 means the interface has lost contact with the air conditioner.

Network setup

  • RS485, 9600 baud, 8 data bits, no parity, 1 stop bit.
  • Twisted pair at least 15 cm from power cables; use repeaters on long lines; A to A, B to B.

Watch out for

  • Setpoints outside an active energy-saving limit are ignored; read back after writing.
  • With a central controller connected the address range is only 1-16.

Notes on this map

  • Gree does not host this protocol publicly. The link is the unaltered Gree PDF in the open document archive of Gree's Ukrainian distributor (the same file is also posted on the Wiren Board support forum). The date comes from the file name.
  • Registers are read with function 03 and written with 16; coils are read with 01 and written with 15.
  • Only named points are listed; reserved words and bits, and bits 216-247 (no name in the table), are left out.
  • Bits 18, 155 and 196 have no English name in the table; their names are translated from the Chinese column.
  • Many fault bits print the English legend '1: yes 0: on'; the Chinese column reads 1 = yes, 0 = no, so 0 is listed as normal.
  • Mode and swing values are printed in binary (for example 001 = cooling); they are given here as decimal. Left/right value 1100 (12) is printed only as '15 position' and is kept as printed.
  • The outdoor-ambient range is printed as -100 to 155 in whole degrees, signed.

Questions about the Gree U-Match all-DC-inverter duct / cassette / floor-ceiling units (built-in Modbus)

What Modbus registers does the Gree U-Match all-DC-inverter duct / cassette / floor-ceiling units (built-in Modbus) have?

This map lists 121 registers: 103 coils, 18 holding registers. 31 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Gree U-Match all-DC-inverter duct / cassette / floor-ceiling units (built-in Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are words numbered from 0 and coils are bits numbered from 0 (Bit0 = Byte0.0). Word n is wire address n and Bit n is coil n; the protocol's example frames read coils from start address 00 05 for coil 5 and words from 00 01 for word 1.

What are the minimum Modbus registers to integrate the Gree U-Match all-DC-inverter duct / cassette / floor-ceiling units (built-in Modbus)?

Start with HR 2 Unit On/Off (On/off); HR 17 Set mode (Mode); HR 19 Set fan speed (Fan speed); HR 20 Set temperature (Setpoint); HR 4 Ambient temperature (Room temperature); HR 49 Outdoor ambient temperature (Outdoor temperature); CO 151 Compressor status (Compressor running); CO 95 Error output status (Error output).

How do I enable Modbus control of the Gree U-Match all-DC-inverter duct / cassette / floor-ceiling units (built-in Modbus)?

The Modbus interface is built into the unit controller; set each unit's address (1-255 in PC address mode) and power-cycle after changing the outdoor chip or DIP switches.
