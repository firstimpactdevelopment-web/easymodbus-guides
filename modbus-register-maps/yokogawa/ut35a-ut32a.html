Yokogawa UTAdvanced UT35A / UT32A digital indicating controller Modbus register map

Updated 17 November 2026

Short answer

The UT35A and UT32A are single-loop PID controllers in Yokogawa's UTAdvanced family. Their data live in D registers that map one-to-one onto Modbus holding registers, reachable over RS-485 (Modbus RTU/ASCII) or, on Ethernet models, Modbus/TCP. This map covers the process data block (PV, setpoint, outputs, status words), the current SP/PID group and the operation-mode switches.

This page lists 52 Modbus registers for the Yokogawa UTAdvanced UT35A / UT32A digital indicating controller — 29 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Yokogawa’s own free documentation (linked below) and checked against it.

Integration notes: Yokogawa UTAdvanced UT35A / UT32A digital indicating controller

Integration in brief

Set protocol MBRTU (factory default) and an address, then read D2001-D2012 in one block for status, PV, SP and output, write the target setpoint to D2101 and switch AUTO/MAN and RUN/STOP with D2301 and D2304.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the communication setup parameters PSL (protocol, MBRTU or MBASC), BPS, PRI, STP, DLN and ADR on the keypad. Ethernet models use Modbus/TCP on port 502 by default.

Byte order & addressing

  • Address D register n at wire address n-1 (D2101 = 0834H).
  • Writing values with a decimal point: send the integer without it (50.0 with one decimal place = 500).

Network setup

  • Factory defaults: Modbus RTU, 19200 bps, even parity, 1 stop bit, 8 data bits, address 1. Speeds 600-38400 bps (38400 only on suffix types that allow it).

Watch out for

  • Available registers depend on the suffix code and parameter settings; check the model before writing.

Notes on this map

  • All registers are 16-bit. Values are sent without their decimal point: PV/SP-type values follow the input's decimal point setting, percentages carry one decimal (scale 0.1).
  • D2001-D2100 are read-only; registers marked as group items (D2101-D2135) act on the SP/PID group currently in use.
  • UT32A-D loop-2, UP35A/UP32A program-pattern and GREEN-series compatible (D0001-D2000) registers are not included.
  • Only part of the D-register space is listed; setup and operation parameter areas (D2501 onward) are left out.
  • Up to 100 registers per read and 50 per multi-register write; blank (undefined) addresses must not be read or written.
  • Modbus/TCP applies only to UT35A units with the Ethernet option; the UT32A is serial only.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Yokogawa UTAdvanced UT35A / UT32A digital indicating controller

What Modbus registers does the Yokogawa UTAdvanced UT35A / UT32A digital indicating controller have?

This map lists 52 registers: 52 holding registers. 29 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yokogawa UTAdvanced UT35A / UT32A digital indicating controller Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual lists D register numbers (D2003). The Modbus reference number replaces the D with 4 (42003) and the wire address is that minus 40001, printed in the table's H No. column (D2003 = 07D2H).

What are the minimum Modbus registers to integrate the Yokogawa UTAdvanced UT35A / UT32A digital indicating controller?

Start with HR 2002 PV_L1 measured value (PV (D2003)); HR 2003 CSP_L1 control setpoint (Control setpoint (D2004)); HR 2004 OUT_L1 control output (Control output (D2005)); HR 2007 MOD_L1 operation mode status (Operation mode status (D2008)); HR 2010 ALM_L1 alarm status (Alarm status (D2011)); HR 2100 SP_L1 target setpoint (Target setpoint (D2101)); HR 2300 A.M AUTO/MAN switch (AUTO/MAN (D2301)); HR 2303 S.R STOP/RUN switch (RUN/STOP (D2304)).

How do I enable Modbus control of the Yokogawa UTAdvanced UT35A / UT32A digital indicating controller?

Set the communication setup parameters PSL (protocol, MBRTU or MBASC), BPS, PRI, STP, DLN and ADR on the keypad. Ethernet models use Modbus/TCP on port 502 by default.
