Updated 17 November 2026

Short answer

eCharge Hardy Barth AC charging stations with the Salia controller run a Modbus TCP server on port 502 for EMS and SCADA control. Telemetry is in input registers, identity, configuration and control points in holding registers; floats and 32-bit values are big-endian with the high word first and need no scaling. Charging is controlled with a current target and a pause/allow register, with an optional heartbeat failsafe.

This page lists 77 Modbus registers for the eCharge Hardy Barth eCharge EVCS (cPH2 / Salia controller), Modbus TCP map 2.3.0 — 10 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from eCharge Hardy Barth’s own free documentation (linked below) and checked against it.

Integration notes: eCharge Hardy Barth eCharge EVCS (cPH2 / Salia controller), Modbus TCP map 2.3.0

Integration in brief

Connect to port 502 at Unit ID 1. Set ChargeMode (40107) to MANUAL, then write the current target and Start_Stop_Charging together in one FC16 frame (40202-40203); poll EVCS_State, ErrorCode and the meter block from 30001/31001.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The Modbus TCP server listens on port 502 by default. An installer may set an IP allow-list in the station's web configuration; ask for your EMS address to be added.

Communication loss & watchdog

Failsafe_Timeout (40204, 0 = off or 10-3600 s). If no accepted write to 40202, 40203, 40208 or 40209 arrives within the timeout, the station applies Failsafe_Current_Target (40206), sets Failsafe_Active (30027) and ErrorCode 7. Write Heartbeat (40208) at least every timeout/2.

Byte order & addressing

  • Start (40203 = 1) is rejected with exception 03 while the current target is 0; write both in one FC16 frame.
  • While 40203 = 0 the charger is offered 0 A whatever 40202 says.
  • Temperature (30025) is a u32 integer, not a float.
  • A change of charge mode resets the station's limit to its maximum and overrides the Modbus current target.
  • Unit IDs 0 and 255 are refused with exception 0B.

Network setup

  • Static IP or DHCP (default) on the station's Ethernet port; Modbus TCP port 502, Unit ID 1.
  • Up to 32 connections total and 4 per source IP; 50 requests/s per IP (burst 100).
  • Idle connections close after 5 minutes.

Watch out for

  • Before an EMS stops controlling the station, write a current with 40203 = 1 and set 40204 = 0, or the station can stay limited to 0 A.
  • Read-only integrations should keep the failsafe off (40204 = 0); stations updated from MapVersion 2.0.0 often keep a saved 20 s / 0 A failsafe.
  • A phase switch (40209) only runs during an active session; confirm it at ActualPhase (30303).

Notes on this map

  • Official documentation from eCharge's own docs site (markdown page).
  • Word order: the manual states big-endian word order (high word at the lower address) and big-endian bytes for all multi-register values; values are already in engineering units (scale 1).
  • Left out: Mains/Battery block 30501-30527 (the manual says this firmware does not populate it), StatusWord 30003 (reserved, always 0), ChargingInfo 30005 (free text, not for parsing), PhaseSwitchDelay/Duration 30305/30306 (the manual says they are unreliable), meter identity strings 41001-41024, and the accepted-but-ignored control registers 40201, 40205, 40207 and 40210-40225.
  • Unused addresses read 0 without an exception, so a wrong function code or an off-by-one address returns zeros; read MapVersion (40001) first to check addressing.
  • Other Unit IDs on the same IP: 2-4 forward to linked slave stations, and 100 (if enabled) is a Fronius-style SunSpec meter emulation starting with 'SunS' at 40001.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the eCharge Hardy Barth eCharge EVCS (cPH2 / Salia controller), Modbus TCP map 2.3.0

What Modbus registers does the eCharge Hardy Barth eCharge EVCS (cPH2 / Salia controller), Modbus TCP map 2.3.0 have?

This map lists 77 registers: 55 input registers, 22 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the eCharge Hardy Barth eCharge EVCS (cPH2 / Salia controller), Modbus TCP map 2.3.0 Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row gives the 3xxxx/4xxxx number and the zero-based PDU address; PDU = register - 30001 (input) or - 40001 (holding). The manual's example frame 06 00 C9 00 10 writes 16 A to 40202 at PDU 201.

What byte order does the eCharge Hardy Barth eCharge EVCS (cPH2 / Salia controller), Modbus TCP map 2.3.0 use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.
