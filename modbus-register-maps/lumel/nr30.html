Lumel NR30 DIN-rail power network meter Modbus register map

Updated 17 November 2026

Short answer

The NR30 is a DIN-rail 3-phase power network meter with RS-485 Modbus RTU and, in Ethernet versions, Modbus TCP. Its fixed measurement list is offered as floats in several areas; this map uses the 8000 area (two registers per value, high word first), plus comms settings, the status word and 32-bit energy counters.

This page lists 65 Modbus registers for the Lumel NR30 DIN-rail power network meter — 3 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lumel’s own free documentation (linked below) and checked against it.

Integration notes: Lumel NR30 DIN-rail power network meter

Integration in brief

Read holding registers from 8000: per-phase values, then 3-phase totals at 8054-8066, frequency at 8072 and energies from 8090. Floats are high word first in the 8000 area.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is always on; set address and baud from the menu or registers 4100-4102, then write 1 to 4104.

Byte order & addressing

  • The 6000 area is low word first and the 8000 area high word first.
  • Powers are in W, var and VA.

Network setup

  • Factory settings: address 1, 9600 baud, RTU 8N2.
  • Modbus TCP: unit address in 4146 (default 1), port in 4147 (default 502), idle close time 4145 (60 s), up to 4 connections (4144).

Watch out for

  • 7000-7118 returns whatever was programmed in 4200-4259, not a fixed list.

Notes on this map

  • Byte order: the area table gives 8000-8970 as bytes 3-2-1-0 and 6000-6970 as 1-0-3-2; example 2 returns 41 20 00 00 (10.0) for a 3-2-1-0 area and example 3 returns 00 00 41 20 for the 6000 area, so the 8000 area is high word first (ABCD).
  • The 7000/7200/7400 areas are a user-programmable group (set in 4200-4259) and are not listed.
  • Energy counters 4426-4435 follow the manual's formula (high x 65536 + low) / 100.
  • Left out: 4101 transmission mode (its row could not be read cleanly), time/date and status floats 8110-8128, the min/max area from 8136, and the alarm, MQTT and display setup registers.
  • Frequency (8072) is printed with unit 'f'; it is listed in Hz.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lumel NR30 DIN-rail power network meter

What Modbus registers does the Lumel NR30 DIN-rail power network meter have?

This map lists 65 registers: 65 holding registers. 3 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lumel NR30 DIN-rail power network meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are used as printed: the example frames read 7000 as 0x1B58 and 6000 as 0x1770. Float registers show the table's 6xxx/8xxx pair in 'documented'; this map uses the 8xxx address.

What byte order does the Lumel NR30 DIN-rail power network meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lumel NR30 DIN-rail power network meter?

Start with HR 8000 Voltage of L1 phase (L1 voltage); HR 8002 Current of L1 phase (L1 current); HR 8058 3-phase active power (P1+P2+P3) (3-phase active power); HR 8064 3-phase power factor (P/S) (3-phase power factor); HR 8072 Frequency (Frequency); HR 4426 Active import energy (counter) (Active import energy counter); HR 4415 Status register 1 (Status 1).

How do I enable Modbus control of the Lumel NR30 DIN-rail power network meter?

Modbus RTU is always on; set address and baud from the menu or registers 4100-4102, then write 1 to 4104.

Where is the official Lumel NR30 DIN-rail power network meter Modbus documentation?

The source is NR30 Rail mounted power network meter - User's manual (NR30-09E_R1), published free by Lumel at https://www.lumel.com.pl/resources/Pliki%20do%20pobrania/NR30/NR30_service_manual.pdf.
