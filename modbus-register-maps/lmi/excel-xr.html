Short answer

The Excel XR is a stepper-driven chemical metering pump from LMI (Milton Roy). Its Modbus RTU version exposes coils for on/off, prime and mode selection, holding registers for flow setpoints and I/O configuration, input registers for live flow, analog I/O and totalizers, and discrete inputs for status and alarms. This map covers the control, live-value and alarm points plus the main mode settings.

Integration notes: LMI Excel XR series electronic metering pump (Modbus RTU)

Integration in brief

Set slave address, bit rate, parity and stop bits on the pump's Communication Settings screen. Read input register 3 for live flow and discrete inputs 1 and 101 for running and global alarm; set the flow with holding register 1 and start/stop with coil 1.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus settings are on the pump display under Settings > Communication Settings: slave address 1-125, bit rate 9600/19200/38400/115200 or Auto, parity none/even/odd, 1 or 2 stop bits, internal line termination on/off.

Byte order & addressing

  • Coil 1 toggles on/off rather than setting a state; read discrete input 1 to know the result.
  • Flow values are four-digit integers with two implied decimals (1234 = 12.34).

Network setup

  • With Auto bit rate the pump hunts for the speed, so the first messages may fail; set the rate explicitly when known.
  • Enable internal termination on the last device on the bus. Connection is an M12 5-pin B-coded connector (pin 2 D0, pin 4 D1, pin 3 DGND).

Watch out for

  • Function code 07 (read exception status) and 17 (report server ID) are also supported.

Notes on this map

  • LMI does not host this manual publicly as far as we could find; the linked copy is the unaltered LMI manual hosted by a distributor (Pumpworld).
  • Multi-register values: the manual states the first register holds the high-order value, so 32- and 64-bit counters are high word first (ABCD).
  • Pulse mode volume (13-14) and batch mode volume (17-18) are left out: the manual gives a decimal range for a two-register integer but no scale.
  • Timed event, RTC, password and stay-prime registers are left out; stay-prime remaining time and weekly event time have no stated units or length conflicts.
  • Flow values are in GPH or L/h and volumes in gallons or litres depending on the units setting (coil 13 / discrete input 14).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the LMI Excel XR series electronic metering pump (Modbus RTU)

What Modbus registers does the LMI Excel XR series electronic metering pump (Modbus RTU) have?

This map lists 104 registers: 15 coils, 34 discrete inputs, 20 input registers, 35 holding registers. 50 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the LMI Excel XR series electronic metering pump (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every table says PLC addressing (base 1) is used and lists each point as decimal and hex (holding register 1 = 0x0001). Request address n-1 on the wire: manual flow rate (1) is wire address 0.

What byte order does the LMI Excel XR series electronic metering pump (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the LMI Excel XR series electronic metering pump (Modbus RTU)?

Start with IR 2 Current flow rate (Current flow rate); IR 3 Flow percentage (Flow percentage); DI 0 Running status (Running status); DI 100 Global alarm (Global alarm); HR 0 Flow rate for manual mode (Manual mode flow setpoint); CO 0 On/Off (On/off toggle); CO 5 Manual operation mode (Select manual mode).

How do I enable Modbus control of the LMI Excel XR series electronic metering pump (Modbus RTU)?

Modbus settings are on the pump display under Settings > Communication Settings: slave address 1-125, bit rate 9600/19200/38400/115200 or Auto, parity none/even/odd, 1 or 2 stop bits, internal line termination on/off.

Where is the official LMI Excel XR series electronic metering pump (Modbus RTU) Modbus documentation?

The source is Excel XR Series Electronic Metering Pump Modbus RTU Manual (55312 Rev 04), revision 2020-03. LMI doesn't publish it on its own website, so this map was re-typed from a free copy at https://www.pumpworld.com/assets/lmi-excel-xr-chemical-pump-modbus-manual.pdf. It may be an older revision, so check it against the live unit.
