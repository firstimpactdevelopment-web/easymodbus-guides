Short answer

The SAB RVU board in Vasco D150 Compact and Energy Plus heat recovery units speaks Modbus RTU on its RS485 port (connector M19), using holding registers only. The map covers identification, the live machine state (temperatures, fan speeds, pressures, CO2, RH, alarms, run hours), the main parameters and the command block for on/off, mode, speed and external RH/CO2 values.

Integration notes: Vasco SAB RVU ventilation unit controller (D150 Compact, Energy Plus)

Integration in brief

Read 0x0100-0x0114 for temperatures, state, fan speeds, alarms, CO2 and RH. Switch with 0x0300, pick the mode with 0x0307 and the manual speed with 0x0309; a BMS humidity or CO2 sensor can be fed through 0x030A/0x030B.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the Modbus address (1-60) on the ADDRESS DIP switches (DIP 2); on residential 0x52xx controllers DIP 1 switch 10 selects 9600 (off) or 38400 baud (on).

Byte order & addressing

  • Only holding registers (FC 03, 06, 16) are supported.
  • A multi-register write is refused unless every register in the range is writable.
  • Writing the Manual Speed parameter (0x0212) switches the unit to manual speed mode.

Network setup

  • RS485 on connector M19, 8 data bits, no parity, 1 stop bit.

Watch out for

  • The Options/info register is printed as '0x0111F' in the manual; it is the register between 0x011E and 0x0120.

Notes on this map

  • 32-bit values use two registers with the most significant 16 bits first (data type table), so the hours counter is ABCD.
  • Left out: the four float registers Rho 1-4 (0x0115-0x011B), because the type table states the word order only for 32-bit integers; the four weekly timer programs (blocks 4-7, 0x0400-0x0737) and block 8 time/date.
  • Byte-type registers (0x0108-0x010A) carry their 8 bits in the most significant byte of the register.
  • Out-of-range parameter writes are accepted but clipped to the allowed range.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Vasco SAB RVU ventilation unit controller (D150 Compact, Energy Plus)

What Modbus registers does the Vasco SAB RVU ventilation unit controller (D150 Compact, Energy Plus) have?

This map lists 96 registers: 96 holding registers. 66 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vasco SAB RVU ventilation unit controller (D150 Compact, Energy Plus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints hexadecimal register addresses and the first block starts at 0x0000 (serial number), which only fits addresses sent as printed. Use the hex value directly: 0x0110 = register 272 on the wire.

What byte order does the Vasco SAB RVU ventilation unit controller (D150 Compact, Energy Plus) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Vasco SAB RVU ventilation unit controller (D150 Compact, Energy Plus)?

Start with HR 256 Temperature probe T1 (T1 temperature); HR 261 Machine state and mode (Machine state and mode); HR 272 Alarms (Alarms); HR 267 Fan1 Speed (Fan 1 speed); HR 768 ON-OFF Command (On/off command); HR 775 Mode Selection (Mode selection); HR 777 Manual speed (Manual speed); HR 784 Reset Filter Counter (Filter counter reset).

How do I enable Modbus control of the Vasco SAB RVU ventilation unit controller (D150 Compact, Energy Plus)?

Set the Modbus address (1-60) on the ADDRESS DIP switches (DIP 2); on residential 0x52xx controllers DIP 1 switch 10 selects 9600 (off) or 38400 baud (on).
