Updated 19 November 2026

Short answer

The M-7088 is an RS-485 remote I/O module with eight PWM outputs and eight digital inputs that also count pulses. Over Modbus RTU the PWM duty cycle, frequency and burst settings are holding registers, PWM start/stop and modes are coils, and the 32-bit input counts are input registers stored low word first.

This page lists 80 Modbus registers for the ICP DAS M-7088 8-channel PWM output / counter input module (Modbus RTU) — 63 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ICP DAS’s own free documentation (linked below) and checked against it.

Integration notes: ICP DAS M-7088 8-channel PWM output / counter input module (Modbus RTU)

Integration in brief

Set a channel's frequency (40737+, 32-bit low word first) and duty cycle (40705+, 0.1 % steps), then start it with its PWM status coil (00001+). Read input registers 0-15 for the eight 32-bit pulse counts.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The module must run the Modbus RTU protocol (coil 00257 = 1, factory default 1).

Communication loss & watchdog

Host watchdog: enable with coil 00261, timeout in 40489 (0.1 s steps, factory 25.5 s); coil 00270 shows and clears a timeout.

Byte order & addressing

  • 32-bit values are low word first (CDAB).
  • Duty cycle is in 0.1 % steps (500 = 50.0 %).

Network setup

  • Module address in 40485 (1-247); baud and parity code in 40486.

Watch out for

  • Coil 00260 picks the host watchdog mode: in the new mode an AO or DO command also clears the watchdog timeout status.

Notes on this map

  • The table states low word then high word for the DI counts, maximum counts and PWM frequency, so these are CDAB.
  • Preset values (40097-40112) are left out: the table's example pairs 40097 with 40104, which contradicts the low/high pattern.
  • Defaults come from the table: address 1 (40485) and baud/parity code 6 = 9600 bps, no parity, 1 stop bit (40486).
  • PWM trigger, synchronisation, burst count readback, LED and EEPROM-save items are left out.

Questions about the ICP DAS M-7088 8-channel PWM output / counter input module (Modbus RTU)

What Modbus registers does the ICP DAS M-7088 8-channel PWM output / counter input module (Modbus RTU) have?

This map lists 80 registers: 27 coils, 9 discrete inputs, 8 input registers, 36 holding registers. 63 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ICP DAS M-7088 8-channel PWM output / counter input module (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table is titled 'M-7000 Address Mapping (Base 1)': 00001 coils, 10001 discrete inputs, 30001 input registers, 40001 holding registers. Subtract the table base for the wire address (40001 = holding register 0).

What byte order does the ICP DAS M-7088 8-channel PWM output / counter input module (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ICP DAS M-7088 8-channel PWM output / counter input module (Modbus RTU)?

Start with HR 704 PWM duty cycle channel 0 (PWM duty channel 0); HR 736 PWM frequency channel 0 (PWM frequency channel 0); CO 0 PWM status channel 0 (PWM start/stop channel 0); CO 864 PWM mode channel 0 (PWM burst/continuous channel 0); IR 0 DI count channel 0 (DI count channel 0); DI 32 DI status channel 0 (DI status channel 0).

How do I enable Modbus control of the ICP DAS M-7088 8-channel PWM output / counter input module (Modbus RTU)?

The module must run the Modbus RTU protocol (coil 00257 = 1, factory default 1).

What happens when the ICP DAS M-7088 8-channel PWM output / counter input module (Modbus RTU) loses Modbus communication?

Host watchdog: enable with coil 00261, timeout in 40489 (0.1 s steps, factory 25.5 s); coil 00270 shows and clears a timeout.
