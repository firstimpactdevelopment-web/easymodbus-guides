Lochinvar Crest / Crest with Hellcat boilers (ModBus communication board) Modbus register map

Updated 16 October 2026

Short answer

Lochinvar's Crest condensing boilers expose Modbus RTU through the RS-485 communication board. A BAS writes a configuration word plus enable, rate/setpoint and remote temperature values; read-only data covers outlet/inlet/flue temperatures, firing rate, pump speeds, cascade power, status/blocking/lockout codes and lockout codes for up to eight cascade units. Some discrete inputs exist only on FB/OF1501-6001 or on FCB1000-6000.

This page lists 62 Modbus registers for the Lochinvar Crest / Crest with Hellcat boilers (ModBus communication board) — 9 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Lochinvar’s own free documentation (linked below) and checked against it.

Integration notes: Lochinvar Crest / Crest with Hellcat boilers (ModBus communication board)

Integration in brief

Set address, baud and parity on the board DIP switches, set the Demand Configuration in MAIN MENU > SETUP > BMS, then write 40001 (configuration) followed by the commands, using the exact values from the manual for the chosen configuration: enable only is 40001 = 0x0001 with 40002 = 0x0001; enable + BMS is 40001 = 0x0005 with 40002 = 0x0010 and the rate/setpoint in 40003. Monitor 30009-30016.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Choose the Demand Configuration (enable only, enable + BMS rate/setpoint, or BMS only) in MAIN MENU > SETUP > BMS; set the BMS type to rate or setpoint for 40003. Re-send 40001 before issuing commands.

Communication loss & watchdog

Crest: BAS timeout adjustable 5-120 s in MAIN MENU > SETUP > BAS; BAS-supplied temperatures must be refreshed within it or the boiler reverts to its own sensors. Other commands must be refreshed at least every 4 minutes. Hellcat: timeout fixed at 300 s.

Byte order & addressing

  • Modicon addressing: 30009 is input register 8 on the wire.
  • Temperatures are degrees C x 10.
  • A setpoint command through 40003 is the 0-10 V equivalent percentage, interpolated from the BMS low/high setpoint parameters, not degrees.
  • Only read the lockout code when the status code is 40.

Network setup

  • DIP switches 1-7: Modbus address (1-127).
  • DIP switch 8: OFF = Celsius, ON = Fahrenheit.
  • DIP switch 9: OFF = 9600 baud, ON = 19200 baud.
  • DIP switch 10: OFF = no parity with 2 stop bits, ON = even parity with 1 stop bit.
  • RTU only; terminate both ends of the RS-485 bus.

Watch out for

  • Some discrete inputs are footnoted as FB/OF1501-6001 only or FCB1000-6000 only; do not expect them on other sizes.
  • Board LED D7: 1.5 s on / 0.5 s off = no Modbus traffic; 0.5 s on / 1.5 s off = no burner-control communication.

Notes on this map

  • Temperatures: the manual's conversion section says the appliance passes temperatures in degrees C multiplied by 10 (worked examples: outdoor 26.7 C sent as 267; outlet 683 read as 68.3 C). Scale 0.1 is applied to every temperature register.
  • Removed: System/Cascade Setpoint (30004), Outlet Setpoint (30008) and Tank Setpoint (40004). The memory map gives these a 0.5 C resolution while the conversion section says all temperature data is degrees C x 10, and the worked examples only cover other registers (outdoor temperature and outlet temperature). Because the scaling of these three is not settled by the document, they are left out.
  • Signed types: registers whose published minimum is negative (inlet, flue, tank, outdoor, supply/return temperatures) are listed as INT16; the manual itself only says '16-bit word'.
  • Dip switch 8 on the communication board selects degrees C (OFF) or F (ON) for the display/data; units here assume C (switch OFF), matching the manual's tables and conversion examples.
  • Holding register 40002 'Coils' has no bit list: for the Crest, the enable-only table writes 0x0001 to enable the unit, the enable + BMS table writes 0x0010 for the same purpose, and the DHW table writes 0x0010 for the tank thermostat. Prefer the Boiler Enable coil (00001) and confirm on site.
  • Input registers 30001-30003 are packed copies of the discrete inputs; the bit-to-input order is not stated, so they are listed as UINT16. Use the discrete inputs instead.
  • Left out: FCB1000-6000 combustion registers 30019-30025 and 30036-30038 (air/gas damper angle, fan speed target, O2 status, trim factor, barometer, flame, O2 reading) because the manual gives no units or scaling for them.
  • The full Crest lockout-code list (input register 30016) is long; see pp. 43 onward in the manual.
  • The Regent water heater map in the same manual uses different input-register numbers and is not included.

Questions about the Lochinvar Crest / Crest with Hellcat boilers (ModBus communication board)

What Modbus registers does the Lochinvar Crest / Crest with Hellcat boilers (ModBus communication board) have?

This map lists 62 registers: 2 coils, 30 discrete inputs, 23 input registers, 7 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lochinvar Crest / Crest with Hellcat boilers (ModBus communication board) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed Modicon-style (00001, 10001, 30001, 40001). Subtract the table base and 1 for the wire address; the manual's exception-code text confirms PDU addresses start at 0.

What are the minimum Modbus registers to integrate the Lochinvar Crest / Crest with Hellcat boilers (ModBus communication board)?

Start with HR 0 Configuration (Configuration bits); CO 0 Boiler Enable (Boiler enable); HR 2 0-10 Volt Input / Rate Command / Setpoint Command (Rate (%) or setpoint command); IR 8 Outlet Temperature (Outlet temperature); IR 11 Firing Rate (Firing rate); IR 13 Boiler Status Code (Status code); IR 14 Boiler Blocking Code (Blocking code); IR 15 Boiler Lockout Code (Lockout code).

How do I enable Modbus control of the Lochinvar Crest / Crest with Hellcat boilers (ModBus communication board)?

What happens when the Lochinvar Crest / Crest with Hellcat boilers (ModBus communication board) loses Modbus communication?
