Short answer

The Cube300 is a panel kWh meter; the Modbus option adds an RS-485 Modbus RTU port. It exposes a small set of holding registers: a 32-bit kWh count (plus a second-tariff count), instantaneous kW as a signed count, decimal-exponent scale registers and the meter setup values.

This page lists 15 Modbus registers for the Northern Design Cube 300 panel kWh meter (Modbus RTU option) — 8 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Northern Design’s own free documentation (linked below) and checked against it.

Integration notes: Northern Design Cube 300 panel kWh meter (Modbus RTU option)

Integration in brief

Read eScale (513) and pScale (2817) once after commissioning, then poll kWh at 514-515 and instantaneous kW at 2816 with function 03. Apply 10^(eScale-6) to the energy count and 10^(pScale-6) to the power count to get kWh and kW.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is a fitted option. Two extra steps in the front-panel programming menu set the baud rate and the unique Modbus address.

Byte order & addressing

  • Scale registers are exponents offset by 3 or 6 (raw x 10^(eScale-6) for kWh), not plain power-of-ten multipliers.
  • Maximum 20 words per request.
  • Allow at least 10 ms after each reply before the next request; replies can take up to 250 ms.

Network setup

  • RS-485 half duplex, two wires plus 0 V. Baud 4800, 9600 or 19200; address 1-247, both set on the front panel or over Modbus.
  • Fit 120 ohm terminators at the host and at the farthest meter; loop in and out of the meter terminals rather than using spurs.
  • Ground the cable shield at the host only and do not use it as the 0 V conductor.

Watch out for

  • The kWh registers are writable; a careless write changes the billing count.
  • The copied data table (7680 onward) is read-only; functions 06 and 16 are refused there.

Notes on this map

  • Northern Design does not host this manual publicly; the link is a copy on a distributor's file host (the same host used for the Cube 350 and multicube manuals).
  • 32-bit values are a high word at the lower address followed by the low word (LONG = 65536 x high + low), so ABCD.
  • Energy registers hold the displayed digits without a decimal point. kWh = raw x 10^(eScale-6) and Wh = raw x 10^(eScale-3), with eScale read from 513 (40514). The manual's formula and worked example both name 40513 (the eScale high word) as the energy value, but the paragraph before them puts the energy count at 40515-40516, so the formula is applied to 514-515.
  • Instantaneous kW is a signed count of the displayed digits: kW = raw x 10^(pScale-6), W = raw x 10^(pScale-3), with pScale at 2817. Both are listed with scale 1 and no unit.
  • Left out: the read-only copied data table 7680-7699, which repeats the registers above in one block so they can be read with a single function 03 request.
  • Supported functions: 03, 04, 06, 08 (sub-function 00 loop-back only) and 16. A request returns at most 20 words.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Northern Design Cube 300 panel kWh meter (Modbus RTU option)

What Modbus registers does the Northern Design Cube 300 panel kWh meter (Modbus RTU option) have?

This map lists 15 registers: 15 holding registers. 8 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Northern Design Cube 300 panel kWh meter (Modbus RTU option) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each table prints a 0-based data address next to the Modicon register number (512 = 40513). The data address is what goes on the wire: request 512 to read 40513.

What byte order does the Northern Design Cube 300 panel kWh meter (Modbus RTU option) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Northern Design Cube 300 panel kWh meter (Modbus RTU option)?

Start with HR 513 eScale (Energy exponent eScale); HR 514 kWh (kWh counter); HR 2816 Instantaneous kW (Instantaneous kW (raw)); HR 2817 pScale (Power exponent pScale); HR 3584 CT Primary (CT primary); HR 3590 Meter Model (Meter model check (300)).

How do I enable Modbus control of the Northern Design Cube 300 panel kWh meter (Modbus RTU option)?

Modbus is a fitted option. Two extra steps in the front-panel programming menu set the baud rate and the unique Modbus address.
