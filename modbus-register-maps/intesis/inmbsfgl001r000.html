Integration notes: Intesis (HMS Networks) INMBSFGL001R000 Fujitsu AC to Modbus RTU gateway

Integration in brief

Set SW1 for the BWR-bus role (master by default, slave if a Fujitsu wired remote is present) and the machine type, set address and baud on SW3/SW4, power-cycle, then poll holding registers 0-11 with function 03 and write with 06.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step; register 7 (gateway disablement) must be 0 for commands to reach the unit.

Byte order & addressing

  • Temperature scale depends on DIP SW4 and the manual is inconsistent about the factory default.
  • Vane pulse registers 27 and 34 are write-only steps, not positions.
  • 8-N-2 by default; 8-N-1 is auto-detected.
  • Function 16 is accepted only with a quantity of one register; at most 100 registers per read.

Network setup

  • SW1: BWR-bus master (default, no Fujitsu remote) or slave (with a Fujitsu wired remote as master); machine-type switch.
  • SW3: slave address; SW3/SW4: baud (9600 default).
  • SW4: x1/x10, °C/°F and 120 Ω termination.
  • DIP changes need a power cycle. BWR bus max 500 m, not polarity sensitive.

Watch out for

  • Set the SW1 machine-type switch to match the Fujitsu range: default covers RAC inverter G series and VRF J-II / V-II / VR-II; the other position covers RAC inverter / non-inverter and VRF V, S and J.
  • Register 22 (external temperature) only works if the indoor unit is set to use the remote-controller thermostat (Fujitsu function 42 = 1, set by an installer) and has no effect on RAC/domestic splits that need an extra comms accessory.

Notes on this map

  • Every register is documented as a 16-bit unsigned holding register and no temperature range in the manual goes below zero, so temperatures are UINT16. The 'no value' marker the manual writes as -32768 is raw 0x8000 (32768) and is listed as an enum entry. A value of 0 in the setpoint / reference registers means 'undetermined'.
  • Temperature registers depend on DIP SW4: x1 °C, x10 °C (decidegrees) or °F (no °F x10). The register-table footnote calls x10 the default, but the SW4 table and the quick-start page (all other switches off) give x1 °C as the factory setting, so scale 1 / °C is used. Read SW4 position 1-2 on site: if x10 is set use scale 0.1; if °F is set the values are whole °F.
  • Error code enum (Fujitsu codes) not reproduced; see manual section 7.
  • Unlike sibling Intesis gateways, this one passes the external temperature (reg 22) straight to the unit as its thermostat sensor rather than using a virtual-temperature setpoint offset.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. What Modbus registers does the Intesis (HMS Networks) INMBSFGL001R000 Fujitsu AC to Modbus RTU gateway have?

This map lists 32 registers: 32 holding registers. 16 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Intesis (HMS Networks) INMBSFGL001R000 Fujitsu AC to Modbus RTU gateway Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables give a 'protocol address' (base 0) and a 'PLC address' (base 1); the protocol address is the wire address and is used for 'documented'.
