Short answer

The Condair Vita is a high-pressure nebulising humidification system serving up to 50 areas. Its Integrated Controller is a Modbus RTU slave or Modbus TCP server. This map covers system, RO, deionisation and HP-line states, error flag, code and category, per-area state and humidity, and the per-area humidity setpoints.

Integration notes: Condair Vita high-pressure humidification system (Integrated Controller, Modbus RTU/TCP)

Integration in brief

Read input registers 2000-2009 for system and error state and 2500-2549 for area states; write area setpoints to holding 3500-3549.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Network > Modbus Settings on the controller.

Byte order & addressing

  • The address column is the wire address; 32001 is address 2000.
  • Floats are two registers, MSR first by default.

Network setup

  • Menu > password 8808 > Network > Modbus Settings: set protocol (Modbus/RTU or Modbus/TCP), address, parity, baud rate and register sequence; the controller restarts after a protocol change.
  • For Modbus TCP set the IP parameters under Network > IP Settings (factory setting DHCP).

Watch out for

  • Read the error category (2006) together with the error flag; the manual warns that ignoring the category causes needless warning messages.
  • Wrong setpoints or sensor values can cause water damage; the operator must monitor them.

Notes on this map

  • Input registers are read with function 04; holding registers with 03 and written with 06 or 16.
  • Floats use 'Register Sequence': MSR first (high register first, ABCD) is the factory setting; LSR first (CDAB) is the option. The map assumes the factory setting.
  • Factory serial settings: Modbus RTU, address 10, 19200 baud, even parity, 8 data bits, 1 stop bit. Modbus TCP uses port 502 and unit ID 255 (per the TCP technical data).
  • Units marked metric/imperial follow the controller's Metric/Imperial setting; the listed unit is the metric one.
  • Left out: UInt32 values (serial number, replacement and error timestamps) because the manual gives the register sequence for floats only.
  • Left out: area actual temperatures; the range is printed 32651-32751 / 2650-2750 (101 registers) for 50 floats, so the end of the block is unclear.
  • Area humidity floats are listed two registers per area from 2550, matching the printed 2550-2649 range.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Condair Vita high-pressure humidification system (Integrated Controller, Modbus RTU/TCP)

What Modbus registers does the Condair Vita high-pressure humidification system (Integrated Controller, Modbus RTU/TCP) have?

This map lists 159 registers: 109 input registers, 50 holding registers. 50 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Condair Vita high-pressure humidification system (Integrated Controller, Modbus RTU/TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print the 5-digit register (32001 = input register, 43001 = holding register) and the 0-based address beside it (2000 / 3000). The address column is what goes on the wire; the manual's own example: register 43004 = address 3003.

What byte order does the Condair Vita high-pressure humidification system (Integrated Controller, Modbus RTU/TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Condair Vita high-pressure humidification system (Integrated Controller, Modbus RTU/TCP)?

Start with IR 2000 Number of Areas (Number of areas); IR 2007 Error Flag (Error flag); IR 2006 Error Category (Error category); IR 2900 Reverse Osmosis State (RO state); IR 2500 Area 1 state (Area 1 state); HR 3500 Area 1 setpoint (Area 1 setpoint).

How do I enable Modbus control of the Condair Vita high-pressure humidification system (Integrated Controller, Modbus RTU/TCP)?
