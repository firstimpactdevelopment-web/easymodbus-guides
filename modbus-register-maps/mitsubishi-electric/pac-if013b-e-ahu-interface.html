Updated 19 November 2026

Short answer

Interface board that lets a third-party air handling unit controller run a Mitsubishi Electric outdoor unit on a DX coil. Its RS-485 port is a Modbus RTU slave: in manual step mode the AHU controller sends a capacity step (off, 1-11 or auto) and the mode; in auto step mode it sends on/off, mode and a setpoint. Thermistor temperatures, error code, output status and step status can be read back.

Integration notes: Mitsubishi Electric PAC-IF013B-E / PAC-SIF013B-E air handling unit interface (Modbus RTU)

Integration in brief

Pick manual or auto step mode on the DIP switches, then write either the capacity step (40001) or on/off and setpoint (00001 / 40004, 40003) together with the mode (40002). Poll the step status, error code and temperatures every 10 seconds or so.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set DIP SW1-1 to 1-3 and SW6 for 'Modbus' (manual step) or 'No input' (auto step mode), as listed in the manual's system table.

Communication loss & watchdog

Send a query or command at least every 10 minutes (10 seconds recommended). After more than 10 minutes without a query, on/off control is handed back to the remote controller.

Byte order & addressing

  • Leave at least 1 minute between operation commands, whatever the baud rate.
  • The slave answers about 50 ms after a request.
  • Broadcast is accepted for coil writes and for FC06/16 holding writes.

Network setup

  • Slave address 1-31 on DIP SW4-1 to 4-5 (all off = 1); the manual does not state a factory setting.
  • Baud 1200-57600 on SW3-6 to 3-8; parity odd/even/none on SW4-6/4-7; stop bits on SW4-8.
  • Wire the Modbus master to TB63 (A, B, SG); earth the shield at one end only.
  • No termination resistor is fitted on the board: add 120 ohm if the interface is at a line end.

Watch out for

  • With multiple outdoor unit control, send the capacity step and mode to the main interface only; sub interfaces read back 12 (auto) in 40001.
  • LED4 lit means a communication error, blinking means traffic.

Notes on this map

  • The manual lists seven system layouts. Systems 1-4 write in manual step mode (capacity request 40001 and drive mode 40002 only; do not send setpoint or on/off) and system 5 writes in auto step mode (coil 00001 / 40004 on/off, 40002 mode, 40003 setpoint; do not send a capacity request). Systems 6 (manual step via analog or remote-switch input) and 7 (auto step, no input) use Modbus for monitoring only. The register tables mark availability per column 1-4,6 and 5,7.
  • Manual step mode by Modbus needs DIP SW1-1, 1-2, 1-3 ON and SW6-1, 6-2 OFF; auto step mode by Modbus needs SW1-1 OFF, SW1-2 and 1-3 ON, SW6-1 and 6-2 OFF.
  • Input address 5 (Modicon 30006) is not listed in the manual and is left out.
  • Temperatures are sent as degrees x 10 in two's complement (0xFFFF = -0.1 °C, 0xFC19 = -99.9 °C), so they are listed as INT16 with scale 0.1. A setpoint value that is not a whole degree is rounded down.
  • Modbus error codes and the matching remote-controller codes: 5101 P1, 5102 P2, 1503 P6 (freezing), 1504 P6 (overheating), 5103 P9, 6831/6834 E0 or E4, 6201 E1, 6202 E2, 6832/6833 E3 or E5, 6840/6843 E6, 6842 E7, 0404 Fb, 1514 PL, 5111 PU, 7130 EE.
  • Writes with any value outside the listed codes are discarded by the interface.

What Modbus registers does the Mitsubishi Electric PAC-IF013B-E / PAC-SIF013B-E air handling unit interface (Modbus RTU) have?

This map lists 20 registers: 1 coil, 10 input registers, 9 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Mitsubishi Electric PAC-IF013B-E / PAC-SIF013B-E air handling unit interface (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every table prints the 0-based 'Address' next to the Modicon address (coil 00001 = 0, input 30001 = 0, holding 40001 = 0). The 0-based address is sent on the wire.

What are the minimum Modbus registers to integrate the Mitsubishi Electric PAC-IF013B-E / PAC-SIF013B-E air handling unit interface (Modbus RTU)?

Start with HR 0 Capacity request (Capacity step (manual step mode)); HR 1 Drive mode (Operating mode); HR 3 Drive ON/OFF (On/off (auto step mode)); HR 2 Temperature setpoint (Setpoint x10 (auto step mode)); HR 6 Step status (Running capacity step); HR 5 Error code (decimal) (Error code (8000 = none)); IR 0 TH11 heat exchanger inlet air temperature (AHU coil inlet air temperature).
