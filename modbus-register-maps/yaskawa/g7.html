Updated 17 November 2026

Short answer

The G7 is Yaskawa's legacy high-performance vector drive with built-in Modbus RTU. Commands are written to hex registers 0001h-000Fh, detailed fault/alarm words are read from 0010h-001Bh, status from 0020h-002Dh, U1/U2/U3 monitors from 0031h upward, and every parameter has its own hex address. This map covers the command block, all status/fault words, monitors with their published units, decoded fault history, and the b1/H5 parameters.

Integration notes: Yaskawa G7 drive (CIMR-G7U, legacy) - Modbus RTU

Integration in brief

Set H5-01..H5-03 at the keypad and power-cycle, set b1-01 = 2 and b1-02 = 2, then write 0001h and 0002h with function 10h and poll 0020h-002Dh and 0040h-0046h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

H5-01 node address (default 1Fh, 0h-20h), H5-02 baud (default 3 = 9600), H5-03 parity (default none); cycle power. b1-01 = 2 and b1-02 = 2 select Modbus for reference and run (or set 0001h bits 4/5).

Communication loss & watchdog

H5-05 = 1 (default) enables CE detection; H5-04 selects the response: 0 ramp, 1 coast, 2 fast-stop, 3 alarm only (default). 002Ch bit F shows a comm timeout.

Byte order & addressing

  • Registers and the node address are hex.
  • Read 1-8 registers per 03h message.
  • Command registers (0000h-00FFh) act immediately; parameter writes (0100h-07FFh) wait in an off-line area until 0 is written to 0910h (ACCEPT) or 0900h (ENTER, about 100,000 writes). Unconfirmed writes cause 'Busy Write Protected' on the keypad.
  • Network digital inputs are ORed with the physical terminals.

Network setup

  • RS-422/485 on control terminals R+, R-, S+, S- (see the G7 user manual for 2-wire wiring).
  • Node address 1-20h; 0 is broadcast and is not valid for reads.
  • 8 data bits, 1 stop bit; 1200-19200 baud.

Watch out for

  • Two output-current registers use different resolutions (0026h 0.01 A, 0042h 0.1 A).

  • Left out because the sign is not stated: output power (0027h, 0033h, 0047h), torque reference (0028h, 0048h), Iq/Id (0032h, 0051h, 0052h), PID levels and PID input/output (0038h-003Ah, 0063h-0065h), ASR and ACR monitors. 0025h output voltage reference is omitted because its unit switches with H5-10.
  • Fault values for U2-01/U2-02/U3-xx are the decimal codes of Table 4.17 (e.g. 33 = CE).
  • The command registers here differ from those of the CM090 Modbus TCP/IP option card, which is not covered.
  • Broadcast (slave 0) uses 0001h and 0002h only; see the manual's Table 4.2.
  • 8 data bits and 1 stop bit for RS-422/485 come from the free G7 user manual TM.G7.01 (https://www.yaskawa.com/delegate/getAttachment?documentId=TM.G7.01&cmd=documents&documentName=TM.G7.01.pdf); TM.G7.11 states them only for the RS-232 port.

Questions about the Yaskawa G7 drive (CIMR-G7U, legacy) - Modbus RTU

What Modbus registers does the Yaskawa G7 drive (CIMR-G7U, legacy) - Modbus RTU have?

This map lists 76 registers: 76 holding registers. 19 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Yaskawa G7 drive (CIMR-G7U, legacy) - Modbus RTU Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. All addresses are hex and sent unchanged: the manual's read example uses starting register 00h 20h to read 0020h-0023h. Parameter addresses are the hex values in the parameter tables (b1-01 = 0180h, H5-01 = 0425h); ENTER/ACCEPT are printed as 900/910 (0900h/0910h).

What are the minimum Modbus registers to integrate the Yaskawa G7 drive (CIMR-G7U, legacy) - Modbus RTU?

Start with HR 1 Digital input command (Run/stop, direction, reset); HR 2 Frequency reference setpoint (Frequency reference); HR 32 Inverter status (0020h) (Run/fault status); HR 33 Fault contents (Fault summary); HR 44 Inverter status (002Ch) (Status incl. comm timeout); HR 65 Output frequency (U1-02) (Output frequency); HR 66 Output current (U1-03) (Output current); HR 128 Current fault (U2-01) (Current fault code).

How do I enable Modbus control of the Yaskawa G7 drive (CIMR-G7U, legacy) - Modbus RTU?

H5-01 node address (default 1Fh, 0h-20h), H5-02 baud (default 3 = 9600), H5-03 parity (default none); cycle power. b1-01 = 2 and b1-02 = 2 select Modbus for reference and run (or set 0001h bits 4/5).

What happens when the Yaskawa G7 drive (CIMR-G7U, legacy) - Modbus RTU loses Modbus communication?

H5-05 = 1 (default) enables CE detection; H5-04 selects the response: 0 ramp, 1 coast, 2 fast-stop, 3 alarm only (default). 002Ch bit F shows a comm timeout.
