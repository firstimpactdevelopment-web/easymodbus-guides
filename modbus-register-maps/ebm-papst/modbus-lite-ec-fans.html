Short answer

ebm-papst EC fans with MODBUS Lite electronics expose a common Modbus RTU parameter set on RS485. Live values (speed, status and warning bits, DC-link voltage/current, temperatures, power) are input registers from D000; settings such as set-value source, set value, control mode, address and serial format are holding registers. Speed, voltage, current and power are scaled against per-fan reference registers, so read those first.

This page lists 33 Modbus registers for the ebm-papst EC fans with MODBUS Lite (series 84/112/150/200 Lite) — 12 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ebm-papst’s own free documentation (linked below) and checked against it.

Integration notes: ebm-papst EC fans with MODBUS Lite (series 84/112/150/200 Lite)

Integration in brief

Read D119 (nMax) and D1A0/D1A1 once, then poll input registers D010-D021 with function 04. To run the fan from Modbus set D101 = 1 and write the set value to holding register D001.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Write Source set value D101 = 1 (RS485) so the fan follows Default set value D001 instead of the 0-10 V input.

Communication loss & watchdog

A fail-safe function can apply a separate set value and running direction when the Modbus connection breaks (sections 2.35-2.38 of the source); it is not mapped here.

Byte order & addressing

  • Do not enable Save set value (D103) if D001 is written often; the EEPROM allows about 100,000 writes.
  • The 4 least significant bits of the set value are ignored.
  • New baud/parity settings only apply after 'Adopt parameters' (D000 bit 1), a reset or power cycle.

Network setup

  • Recommended/standard serial format: 19200 baud, 8E1. Changing D149/D14A needs at least customer-level password.
  • Emergency function: after 10 bad telegrams the fan falls back to 19200 8E1, after 10 more to 2400 8E1, which helps find an unknown setting.
  • Fan address is set in D100 (1-247).

Watch out for

  • Input and holding registers overlap in address (both from D000); use function 04 for live values and 03 for settings.
  • Selecting 8N1 breaks the 11-bit frame rule of the Modbus serial specification; prefer 8E1 or 8N2.

Notes on this map

  • Encoding: the document states parameters are big endian (high byte first). All registers listed here are single 16-bit values.
  • Speed values use 64000 = Maximum speed (D119); DC-link voltage and current use reference values D1A0 (20 mV steps) and D1A1 (2 mA steps); power uses both. Those registers carry raw values with scale 1 and the formula in the description.
  • Bit positions in Motor status (D011), Warning (D012) and Reset (D000) were read from the column layout of the encoding tables (MSB = bits 15-8, LSB = bits 7-0).
  • Left out: module temperature (D015) because the document gives no signed/unsigned format for it, unlike the motor and electronics temperatures; P/I factors, modulation limits, potentiometer curve, fail-safe, derating, error history, password, sensor scaling and production data.
  • Many holding registers need a password at a given authorisation level (write it to D002-D004); this map lists the customer-level settings an integrator normally touches.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ebm-papst EC fans with MODBUS Lite (series 84/112/150/200 Lite)

What Modbus registers does the ebm-papst EC fans with MODBUS Lite (series 84/112/150/200 Lite) have?

This map lists 33 registers: 17 input registers, 16 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ebm-papst EC fans with MODBUS Lite (series 84/112/150/200 Lite) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed in hex and are the register address sent in the frame; the manual's own example telegrams write D149 as bytes D1 49 and trigger Adopt parameters with 06 D0 00. Input and holding registers both start at D000 but are separate tables.

What are the minimum Modbus registers to integrate the ebm-papst EC fans with MODBUS Lite (series 84/112/150/200 Lite)?

Start with IR 53264 Actual speed (Actual speed (scaled by nMax)); IR 53265 Motor status (Motor status / error bits); IR 53266 Warning (Warning bits); IR 53281 Current power (Current power); HR 53249 Default set value (Set value from Modbus); HR 53505 Source set value (Set value source (1 = RS485)); HR 53529 Maximum speed (nMax) (Maximum speed reference).

How do I enable Modbus control of the ebm-papst EC fans with MODBUS Lite (series 84/112/150/200 Lite)?

Write Source set value D101 = 1 (RS485) so the fan follows Default set value D001 instead of the 0-10 V input.

What happens when the ebm-papst EC fans with MODBUS Lite (series 84/112/150/200 Lite) loses Modbus communication?

A fail-safe function can apply a separate set value and running direction when the Modbus connection breaks (sections 2.35-2.38 of the source); it is not mapped here.
