Siemens SENTRON PAC3200 Modbus register map

Updated 16 October 2026

Short answer

Panel-mount 96 x 96 mm three-phase power monitoring device with a built-in Ethernet port. Modbus TCP is available once the Ethernet protocol is switched from SEAbus TCP; Modbus RTU needs the PAC RS485 expansion module. Live values are IEEE floats, energy counters are IEEE doubles. This map covers instantaneous, maximum and minimum values, status words, demand, tariff energy counters, the main transformer settings, communication settings and command registers.

Integration notes: Siemens SENTRON PAC3200

Integration in brief

Set the IP address, subnet and gateway on the device, switch the Ethernet protocol to MODBUS TCP and restart. Then read floats from offset 1 upward with FC 0x03 or 0x04, two registers per value, high word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

On the device: SETTINGS > COMMUNICATION. Enter IP address, subnet and gateway, change PROTOCOL from SEAbus TCP to MODBUS TCP and confirm the restart prompt. For RS485, fit the PAC RS485 expansion module and set its protocol to MODBUS RTU.

Byte order & addressing

  • Offsets are wire addresses: offset 1 is requested as address 1 (40002 in 1-based tools).
  • Floats and doubles are big-endian, high word first.
  • Energy counters are 64-bit IEEE doubles in Wh/varh/VAh, not scaled integers.
  • A read that starts on the second register of a value is rejected with an exception.

Network setup

  • TCP port 502 is fixed for Modbus TCP on this model.
  • Ethernet changes written over Modbus (63001-63015) take effect after writing 0 to offset 65300.
  • RS485 module: address 1...247, baud 4800-38400, framing 8N2/8E1/8O1/8N1 in offsets 63019-63023.
  • RS485 module factory settings: address 126, 19200 baud, 8N2, MODBUS RTU, response time 0 ms.

Watch out for

  • The factory protocol is SEAbus TCP, so a new meter does not answer Modbus until the protocol is changed.
  • Latched diagnostic bits in offset 205 stay set until acknowledged through offset 60007.

Notes on this map

  • The PAC3200 manual does not name a word order. We record ABCD (high word first) because two official Siemens examples for this exact model map the registers straight into big-endian S7 types with no word swap: the S7-1200 library description for entry 40614428 (v1.0, 2010, pp. 12-15) receives PAC3200 floats directly into an Array of REAL / DB1.DBD0, and the Set 22 example (entry 40614428, V14 06/2017, p. 26) overlays the two-register buffer as REAL and UDInt. The manual's own status tables also put byte 0 at mask 0x01000000 (most significant byte first).
  • Sources for addressing and word order: https://cache.industry.siemens.com/dl/files/428/40614428/att_923701/v2/40614428_Set22_DOC_v14_en.pdf ; https://cache.industry.siemens.com/dl/files/428/40614428/att_15029/v1/40614428_librarydescription_s7-1200_modbustcp_v1d0_en.pdf ; https://cache.industry.siemens.com/dl/files/762/109779762/att_1028292/v1/109779762_LOGO_ModbusTCP_DOC_en.pdf
  • All measured variables answer to both FC 0x03 and FC 0x04; they are listed here as holding registers. Settings use FC 0x03/0x04/0x10; command registers (60002-60009, 65300) use FC 0x06.
  • Read and write multi-register values from their first register only; starting a read or write in the middle of a value returns an exception.
  • The 32-bit status words (offsets 203-209) are listed with bit numbers of the whole 32-bit value (bit 0 = mask 0x00000001, bit 24 = mask 0x01000000).
  • Offset 221 (Counter Limit Violations) is omitted: the manual gives no format for it.
  • Offset 201 (Minimum Total Power Factor) is printed with the unit 'var' in the manual; a power factor is unitless, so the unit is left empty.
  • Omitted: the six limit-value blocks (50063-50145), digital I/O and display settings (50025-50061), bootloader version (63007, packed characters) and the I&M data blocks (64001+).
  • RS485 defaults (address 126, 19200 baud, 8N2, MODBUS RTU, response time 0 ms) are those of the optional PAC RS485 expansion module, listed in the manual's RS485 MODULE settings (p. 150). Modbus TCP itself has no unit-ID setting in the manual.

Questions about the Siemens SENTRON PAC3200

What Modbus registers does the Siemens SENTRON PAC3200 have?

This map lists 179 registers: 20 discrete inputs, 159 holding registers. 40 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Siemens SENTRON PAC3200 Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Siemens lists every value by its register 'offset', which is the 0-based address sent in the request. Offset 1 (voltage L1-N) is requested as address 1, which a 1-based tool shows as 40002. Two official Siemens application examples for this model confirm it: entry 40614428 (Set 22, Table 3-12) reads offset 65 at S7 MB_CLIENT address 40001 + 65, and entry 109779762 (LOGO! example, p. 13) enters offset 1 as LOGO! register 2.

What byte order does the Siemens SENTRON PAC3200 use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Siemens SENTRON PAC3200?

Start with HR 1 Voltage Va-n (Voltage L1-N); HR 13 Current a (Current L1); HR 55 Frequency (Frequency); HR 65 Total Active Power (Total active power); HR 69 Total Power Factor (Total power factor); HR 801 Active Energy Import Tariff 1 (Active energy import tariff 1 (double)); HR 205 Device Diagnostics and Device Status (Device diagnostics and status).

How do I enable Modbus control of the Siemens SENTRON PAC3200?

On the device: SETTINGS > COMMUNICATION. Enter IP address, subnet and gateway, change PROTOCOL from SEAbus TCP to MODBUS TCP and confirm the restart prompt. For RS485, fit the PAC RS485 expansion module and set its protocol to MODBUS RTU.
