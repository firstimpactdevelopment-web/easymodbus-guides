Short answer

The M-7005 is an RS-485 module with eight thermistor inputs and six digital outputs. In Modbus RTU mode it gives each channel temperature as a 16-bit value (0.01-degree steps in engineering data format), an over/under-range or open-wire flag per channel, and the six digital outputs as coils.

Integration notes: ICP DAS M-7005 8-channel thermistor input module (Modbus RTU)

Integration in brief

Read input registers 0-7 with function 04 for the eight temperatures (x0.01 in engineering format) and discrete inputs 128-135 with function 02 for over/under range or open wire. Drive the six outputs with coils 0-5 (functions 01, 05, 15).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Select Modbus RTU with function 70 sub-function 06 (mode 1), or with the DCON configuration procedure in the manual. The new protocol and baud rate take effect after the next power-on.

Byte order & addressing

  • Serial format is 8 data bits, no parity, 1 stop bit per section 3.

Network setup

  • Baud 1200-115200, set with function 70 sub-function 06; module address 1-247 with sub-function 04; type code with sub-function 08.

Watch out for

  • -32768 / +32767 mean under range / over range or an open thermistor.
  • Function 02 starts at channel address 0x80 (128), not 0.

Notes on this map

  • Temperatures read as 0.01-degree steps only when the module data format is engineering units (manual section 3.8; e.g. type 60 spans -3000 to 24000 for -30.00 to +240.00). The format is set with the DCON configuration command or, per the address table, coil 00269; other formats (section 1.10) scale differently.
  • Left out: the configuration coils in the address table (safe and power-on DO values 00097+, protocol 00257, host watchdog 00260/00261/00270, temperature scale 00267, data format 00269, alarm coils 00289-00352). The function descriptions for 01, 05 and 15 only accept channels 0-5, which contradicts the table, so these addresses are not certain to work.
  • Left out: all 4xxxx holding registers (temperature copies, alarm limits, type codes, offsets, module address, baud, watchdog timeout, channel enable). The manual lists only functions 01, 02, 04, 05, 15 and 70, so there is no documented way to read or write them; settings are made with function 70 or DCON commands.
  • Left out: the two-register resistance values 30865-30880 (word order not stated) and the duplicate 00129-00136 listing of the range flags.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ICP DAS M-7005 8-channel thermistor input module (Modbus RTU)

What Modbus registers does the ICP DAS M-7005 8-channel thermistor input module (Modbus RTU) have?

This map lists 22 registers: 6 coils, 8 discrete inputs, 8 input registers. 6 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ICP DAS M-7005 8-channel thermistor input module (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Section 3.7 is titled 'Address Mappings, Base 1': 00001 coils, 10001 discrete inputs, 30001 input and 40001 holding registers. Subtract the table base: 30001 is input register 0, 40225 is holding register 224.

What are the minimum Modbus registers to integrate the ICP DAS M-7005 8-channel thermistor input module (Modbus RTU)?

Start with IR 0 Temperature ch0 (Channel 0 temperature); IR 1 Temperature ch1 (Channel 1 temperature); DI 128 Over/under range status ch0 (Channel 0 over/under range or open wire); DI 129 Over/under range status ch1 (Channel 1 over/under range or open wire); CO 0 DO0 output (Digital output 0).

How do I enable Modbus control of the ICP DAS M-7005 8-channel thermistor input module (Modbus RTU)?

Select Modbus RTU with function 70 sub-function 06 (mode 1), or with the DCON configuration procedure in the manual. The new protocol and baud rate take effect after the next power-on.
