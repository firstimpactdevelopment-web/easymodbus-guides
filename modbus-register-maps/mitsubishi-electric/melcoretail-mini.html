Short answer

Small Procon controller that plugs into one Mitsubishi Electric split indoor unit and adds retail-style local I/O (status relays, force/lock inputs, analogue mode, fan, setpoint and occupancy inputs) plus a Modbus RTU slave on RS-485. Over Modbus it exposes mode, setpoint, fan, vane, on/off, room temperature and fault code, occupancy-based setpoints, setpoint limits, deadband settings and relay overrides.

Integration notes: Mitsubishi Electric Procon MelcoRETAIL MINI controller for Air-To-Air split units

Integration in brief

Set DIP 1-7 ON (Modbus RTU), pick the slave ID on DIP 1-1 to 1-5 and use DIP 1-6 ON for 9600 / no parity. Then write mode, setpoint, fan and on/off at holding 0-3 and 7 and poll room temperature (8) and fault code (12).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

DIP CONFIG 1-7 ON selects Modbus RTU (OFF is reserved). Power-cycle after any DIP change.

Byte order & addressing

  • Slave ID from DIP 1-1 to 1-5 (1-30); all ON means the ID comes from holding 4; all OFF is invalid.
  • DIP 1-6 ON fixes 9600 baud, no parity; OFF uses holding 5 and 6. Data bits 8 and stop bits 1 are fixed.
  • Writing 0 to the BMS room temperature (15/16) turns the setpoint offset feature off.

Network setup

  • Plug the flying lead into CN105/CN92 on the indoor unit PCB; the unit is powered from there.
  • RS-485 needs A, B and GND, shielded cable, daisy chain only; shield to GND at one end.
  • Cannot be used together with a MAC-397IF / MAC-333IF interface (same connector).

Watch out for

  • Relay manual override (51) times out after 20 minutes.
  • Setpoint limits and deadband settings depend on the matching DIP features (2-2 setpoint limiting, 2-1 deadband).

Notes on this map

  • Input and coil values are mirrored as holding registers (marked read only) for BMSs that only read holding registers.
  • The four analogue input readings (inputs 11-18) are 32-bit values split over two registers; the manual labels the lower address 'least significant register' and the higher 'most significant register', so they are listed as UINT32 low word first (CDAB). Signedness is not stated; the values are mV (0-10 V inputs) or ohm, so they never reach the sign bit.
  • Rows that the manual describes as 'temperature value in °C multiplied by 10' use scale 0.1; rows described as 'temperature in °C' (virtual setpoint, deadband, limits, occupancy setpoints, relay offsets) are whole degrees.
  • Holding 44/45 repeat the names of 18/19 (deadband cooling / heating setpoint) with the same defaults; both are listed as printed.
  • Discrete input 9 is printed with Modicon number 10000; it sits between 10009 and 10011, so it is listed at address 9.
  • Holding 20-31 and 47-50 are not printed. Inputs 2, 4, 6 and 7 are not printed; input 9 is printed as 'Unused' and left out.
  • Fault codes other than 8000 / 0x8000 and 6999 / 0x6999 are the indoor unit's own codes.
  • Discrete input 8 (DIP 1-6): the register table gives 0 = fixed 9600 / no parity and 1 = software settings, the opposite of the DIP switch section (OFF = software, ON = 9600). Only the switch position (0 = OFF, 1 = ON) is listed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Mitsubishi Electric Procon MelcoRETAIL MINI controller for Air-To-Air split units

What Modbus registers does the Mitsubishi Electric Procon MelcoRETAIL MINI controller for Air-To-Air split units have?

This map lists 70 registers: 1 coil, 15 discrete inputs, 10 input registers, 44 holding registers. 38 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Mitsubishi Electric Procon MelcoRETAIL MINI controller for Air-To-Air split units Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every table prints a 0-based 'Address' next to the Modicon address (40001 = holding 0, 30001 = input 0, 10001 = discrete input 0, 00001 = coil 0). The 0-based address is the wire address.

What byte order does the Mitsubishi Electric Procon MelcoRETAIL MINI controller for Air-To-Air split units use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Mitsubishi Electric Procon MelcoRETAIL MINI controller for Air-To-Air split units?

How do I enable Modbus control of the Mitsubishi Electric Procon MelcoRETAIL MINI controller for Air-To-Air split units?
