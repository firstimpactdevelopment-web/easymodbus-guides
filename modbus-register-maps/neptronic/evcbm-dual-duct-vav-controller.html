Neptronic EVCBM dual-duct VAV controller (Modbus communication module) Modbus register map

Updated 19 November 2026

Short answer

The EVCBM is Neptronic's VAV box controller with built-in actuator; the dual-duct version runs a master and a slave airflow loop. Its Modbus RTU module exposes holding registers for room, supply and external temperatures, humidity and CO2 from the TRL wall sensor, setpoints, PI bands, airflow readings and setpoints for both ducts, minimum/maximum airflows, K-factors, balancing modes, motor positions and overrides, TRIAC and analog output setup and the occupancy / mode commands.

This page lists 106 Modbus registers for the Neptronic EVCBM dual-duct VAV controller (Modbus communication module) — 78 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Neptronic’s own free documentation (linked below) and checked against it.

Integration notes: Neptronic EVCBM dual-duct VAV controller (Modbus communication module)

Integration in brief

Read supply and control temperatures (19, 20), airflow 1 and 2 (60, 90) with their setpoints (61, 91) and motor position (74). Command occupancy with register 105 and the user mode with 108; change setpoints at 25-29 (x10).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit the Modbus communication module and set the address from the device menu or register 0.

Communication loss & watchdog

Network fallback timeout (40096, 0-60 min).

Byte order & addressing

  • Printed register numbers start at 40000 for address 0, not 40001.
  • Auto baud detection is the default; the device steps to the next rate after two or more bad frames in one second.

Network setup

  • RS-485 two-wire, RTU mode, 9600-57600 baud or auto.
  • Device address 1-246.

Watch out for

  • Airflow balancing writes only take effect in the right balancing mode (40131 / 40132).

Notes on this map

  • Only function codes 03, 06 and 16 are supported; everything is a holding register.
  • 'Scale N' with 'Value x N' means raw = engineering value x N; the multiplier here is 1/N.
  • The guide's examples are in °C; System Option 1 has a temperature-units bit (Celsius / Fahrenheit), so temperatures are marked °C / °F.
  • 'Master' rows belong to the first (master) airflow loop and 'Slave' rows to the second duct.
  • Left out: product name ASCII registers 40003-40006; System Option 1 and 2 (40100/40101), whose bit lists are scrambled across columns in the PDF; System Command Status 40103 (mixed command codes and bit states); System Options 4 (40159, all reserved); CL_HT SwitchTimerCount 40146 (range 0-4,294,967,295 s in a single register); Cfg_MixAirDeadBand 40162 (range given only as a reference to other settings, no units).
  • Heating ramp 2 demand (40043) is printed writable while the cooling counterpart (40040) is read only; kept as printed.
  • Port configuration codes start at 1 in this guide (1 = no parity / 2 stop bits), unlike Neptronic's newer guides.
  • Left out by the verifier: CO2 value 40018 (Value x 100, but the range runs up to the CO2 sensor maximum of 5000 ppm, which cannot fit one 16-bit register at x100) and Analog Input 2 value 40017 (0-1000 at Value x 100 with an mV example, unclear whether the range is raw or scaled).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Neptronic EVCBM dual-duct VAV controller (Modbus communication module)

What Modbus registers does the Neptronic EVCBM dual-duct VAV controller (Modbus communication module) have?

This map lists 106 registers: 106 holding registers. 78 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Neptronic EVCBM dual-duct VAV controller (Modbus communication module) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table prints a 'Register Index' from 40000. The intro says the device address is at holding register index 0, the auto-baud setting at index 1 and the port setting at index 2, and those are the rows printed 40000, 40001 and 40002, so the wire address is the printed number minus 40000 (e.g. 40019 supply temperature = address 19). Same layout as Neptronic's TUXB guide.

What are the minimum Modbus registers to integrate the Neptronic EVCBM dual-duct VAV controller (Modbus communication module)?

Start with HR 20 Control temperature (Control (room) temperature); HR 25 Occupied temperature setpoint (Occupied setpoint); HR 60 Actual airflow 1 (Airflow 1); HR 90 Actual airflow 2 (Airflow 2); HR 74 Motor 1 position (Motor 1 position); HR 105 Occupancy / night setback command (Occupancy command); HR 108 User system control mode (System mode); HR 113 Zone occupancy status (Occupancy status).

How do I enable Modbus control of the Neptronic EVCBM dual-duct VAV controller (Modbus communication module)?

Fit the Modbus communication module and set the address from the device menu or register 0.

What happens when the Neptronic EVCBM dual-duct VAV controller (Modbus communication module) loses Modbus communication?

Network fallback timeout (40096, 0-60 min).

Where is the official Neptronic EVCBM dual-duct VAV controller (Modbus communication module) Modbus documentation?
