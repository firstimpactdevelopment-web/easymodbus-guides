Updated 19 November 2026

Short answer

The VF-AS3 inverter's RS485 ports speak either the Toshiba protocol or Modbus RTU. In Modbus every parameter and monitor is addressed by its hexadecimal communication number: FA codes are commands (run word, frequency), FD/FE codes are monitors and trip-held values, and 08xx codes are the RS485 settings. This map covers control, the main monitors, trip history and the port 1 settings.

Integration notes: Toshiba TOSVERT VF-AS3 inverter (RS485 Modbus RTU)

Integration in brief

Set F807 = 1 (MODBUS), F802 to a non-zero address and F800/F801 for the line, then power-cycle. Write FA01 with the frequency and FA00 = 8400h (bit 15 run priority + bit 10 run) to run forward, adding bit 14 (C400h) when the frequency also comes from comms; read FD00, FD01, FD03 and FC90 for status.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set F807 (port 1) or F827 (port 2) to 1: MODBUS and reset the drive. Commands from FA00/FA01 are accepted regardless of CMOd/FMOd once FA00 bit 15 (run priority) and/or bit 14 (frequency priority) are set; that priority stays until cleared, power-off or reset.

Communication loss & watchdog

F803 sets the RS485 time-out (0.0 = off, 0.1-100.0 s); F804 picks continue, trip, or trip after deceleration stop; F808 sets when the time-out is checked. The manual says the time-out should be set so the drive stops on comm loss.

Byte order & addressing

  • Addresses are the hexadecimal communication numbers (FA00, FD00 ...), not 4xxxx numbers.
  • A plain 03 read returns one word; multi-word direct reads are limited to 8 words and skip numbers that do not exist unless F830 = 1. Missing numbers read as 8000H.
  • Manual examples: 8400H = run forward with run priority; 8600H / C600H = run reverse (C600H also takes frequency priority).

Network setup

  • F800 baud: 0 = 9600, 1 = 19200 (default), 2 = 38400; F801 parity default even; both take effect after reset. With F809 (operation panel connection) at its default 1 = connector 1, port 1 is fixed at 19200 bps / even parity whatever F800/F801 say (likewise F820/F821 for port 2 when F809 = 2).
  • F802 inverter number defaults to 0 (broadcast): set 1-247 for Modbus.
  • Inverter-to-inverter communication (F806/F826) does not work in Modbus mode.

Watch out for

  • Emergency off (bit 12) and PID-off bits in FA00 act even without the priority bits set.
  • Changing F809 (operation panel connection priority) can lock out the LCD panel until it is rewritten over comms.
  • F806/F826 inverter-to-inverter settings are disabled on the connector chosen in F809.

Notes on this map

  • Toshiba's own download host refused automated access (HTTP 403), so the link is the copy on AutomationDirect, a Toshiba drive distributor; it appears to be the unaltered Toshiba manual.
  • Every value is a single 16-bit word; negative values are two's complement.
  • FE versions of the FD monitors (FE00-FE07, FE15 ...) hold the value captured just before the last trip; only a few are listed.
  • Output current and voltages are in % of the drive rating (0.01 % steps); convert with FE70/FE71.
  • Input and output cumulative power (FE76/FE77) are left out because their unit depends on parameter F749.
  • The Modbus implementation is partial: function 03 reads one word, an indirect block (F875-F879) or up to 8 consecutive numbers; 06 and 10 write one word; 10 also writes the F870/F871 block and 17 combines block write and read.

Questions about the Toshiba TOSVERT VF-AS3 inverter (RS485 Modbus RTU)

What Modbus registers does the Toshiba TOSVERT VF-AS3 inverter (RS485 Modbus RTU) have?

This map lists 57 registers: 57 holding registers. 18 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Toshiba TOSVERT VF-AS3 inverter (RS485 Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The register address is the parameter's hexadecimal communication number sent unchanged: the manual's example reads output frequency FD00 with the frame 01 03 FD 00 00 01. Parameter F800 has communication number 0800 (wire 0x0800).

What are the minimum Modbus registers to integrate the Toshiba TOSVERT VF-AS3 inverter (RS485 Modbus RTU)?

Start with HR 64000 RS485 (1) command 1 (Command word FA00); HR 64001 RS485 (1) frequency command (Frequency command FA01); HR 64768 Output frequency (Output frequency FD00); HR 64769 Status information 1 (Status word FD01); HR 64771 Output current (Output current FD03); HR 64656 Current trip (Current trip FC90).

How do I enable Modbus control of the Toshiba TOSVERT VF-AS3 inverter (RS485 Modbus RTU)?

Set F807 (port 1) or F827 (port 2) to 1: MODBUS and reset the drive. Commands from FA00/FA01 are accepted regardless of CMOd/FMOd once FA00 bit 15 (run priority) and/or bit 14 (frequency priority) are set; that priority stays until cleared, power-off or reset.

What happens when the Toshiba TOSVERT VF-AS3 inverter (RS485 Modbus RTU) loses Modbus communication?

F803 sets the RS485 time-out (0.0 = off, 0.1-100.0 s); F804 picks continue, trip, or trip after deceleration stop; F808 sets when the time-out is checked. The manual says the time-out should be set so the drive stops on comm loss.
