Carlo Gavazzi WM50 power analyzer with TCD branch channels Modbus register map

Updated 29 October 2026

Short answer

The WM50 is a modular Carlo Gavazzi power analyzer for a main feeder plus up to 96 single-phase TCD branch channels (grouped into 2/3-phase loads). Live values are IEEE-754 floats and energies are 64-bit Wh/varh counters, both sent low word first. This map covers the main feeder's voltage, current, power, PF, frequency, energy and tariff values, identification, status and alarm words, reset and remote-output commands, and channel 1 / load 1 of the branch blocks as a pattern.

This page lists 81 Modbus registers for the Carlo Gavazzi WM50 power analyzer with TCD branch channels — 15 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Carlo Gavazzi’s own free documentation (linked below) and checked against it.

Integration notes: Carlo Gavazzi WM50 power analyzer with TCD branch channels

Integration in brief

Read input registers (function 04, or 03) from 0050h as low-word-first floats for main-feeder values and 0500h-051Fh as UINT64 Wh/varh counters (least significant word first). Branch circuits start at C200h, 14 registers per channel.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Fit a communication module (the status word at 4002h shows MC485232 or MCETH as present) and set its communication parameters on the instrument as described in the WM50 instruction manual; this document does not list them.

Byte order & addressing

  • Floats are low word first (CDAB).
  • 64-bit energy counters are least significant word first and in Wh/varh.
  • Functions 03 and 04 are equivalent; up to 125 registers per read.
  • Input port status bits are inverted: 0 = closed.

Network setup

  • Terminate the last instrument and the host on RS485; above 1000 m use a line amplifier.
  • Assign each TCD channel to a phase; register C100h + (channel - 1) shows the assignment.

Watch out for

  • Wait at least 1 s after a function 10h reset before the next query.
  • Check register 4007h after installation: any bit set means a wiring error to correct.

Notes on this map

  • Float word order: the data-format page lists frame bytes as float bits 15-8, 7-0, 31-24, 23-16, i.e. low word first with MSB-first bytes (CDAB).
  • Integer word order: UINT16/UINT64 are MSB-first inside a word and LSW first across words (p. 28). Under this library's 64-bit convention CDAB means least significant word first with all four words reversed, which is what the document describes.
  • Functions 03 and 04 return the same data; reads are limited to 125 registers. Measured values are listed as input registers, commands and the default tariff as holding registers (written with 06 or 10h).
  • After a reset sent with function 10h, wait at least 1 second before the next request.
  • Float units are not printed in a separate column; the variable names (V, A, W, VA, var, Hz, %) give the engineering units, so no scaling is applied. Energy counters are in Wh / varh, not kWh.
  • Source quirk: the A system row (009Ah) is printed with Modicon 300153, the same number as the row above it; the physical address is used here.
  • Left out: the main-unit THD and TDD floats (00A0h-00DAh), which have no unit or scaling stated (precedent from the WM20/30/40 map); temperature and analogue input (0096h/0098h, optional module, unit not printed); the hour counter (0520h, packed hours x100 plus minutes); totalizers C-1..C-3 (0584h-058Ch, 'values multiplied by 1000' without a base unit); max/min/demand blocks; harmonics; clock; and alarm/latch reset commands.
  • Left out: the TCD channel and load energy counters (Wh+, UINT32) and the min/max/demand timestamps (UINT32). The data-format page states the word order only for UINT16 and UINT64, not for UINT32.
  • TCD blocks: only channel 1 and load 1 are listed. Channels repeat every 14 registers from C200h (channel 96 at C732h); loads 1-48 repeat every 24 registers from C760h (load 48 at CBC8h). The channel voltage references are one register per channel from C100h to C15Fh.
  • RS485/Ethernet communication settings are not in this document; set them on the instrument (see the WM50 instruction manual).
  • This document shows only RTU frames (with CRC); TCP is listed because the MCETH module is the Ethernet option, which this document does not describe further.

Questions about the Carlo Gavazzi WM50 power analyzer with TCD branch channels

What Modbus registers does the Carlo Gavazzi WM50 power analyzer with TCD branch channels have?

This map lists 81 registers: 66 input registers, 15 holding registers. 15 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Carlo Gavazzi WM50 power analyzer with TCD branch channels Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row shows a 6-digit Modicon number for function 04 (3xxxxx; replace the first digit with 4 for function 03) beside the hex 'physical address' that the document says goes in the frame. Wire address = physical address: 300081 / 0050h is requested as 0x0050.

What byte order does the Carlo Gavazzi WM50 power analyzer with TCD branch channels use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Carlo Gavazzi WM50 power analyzer with TCD branch channels?

Start with IR 80 V L1-N (V L1-N (float)); IR 96 A L1 (A L1 (float)); IR 110 W system (W system (float)); IR 134 PF system (PF system); IR 136 Frequency (Frequency); IR 1280 Total kWh+ (Total kWh+ in Wh); IR 11 Carlo Gavazzi identification code (Model ID (99 = WM50)); IR 49666 Channel 1 active power (Branch channel 1 active power).

How do I enable Modbus control of the Carlo Gavazzi WM50 power analyzer with TCD branch channels?

Fit a communication module (the status word at 4002h shows MC485232 or MCETH as present) and set its communication parameters on the instrument as described in the WM50 instruction manual; this document does not list them.
