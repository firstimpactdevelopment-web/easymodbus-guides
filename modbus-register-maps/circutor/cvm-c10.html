Circutor CVM-C10 Modbus register map

Updated 17 November 2026

Short answer

The CVM-C10 is a 96x96 mm panel power analyzer from Circutor with an RS-485 port that speaks Modbus RTU or BACnet MS/TP. Measurements are 32-bit integers in register pairs with fixed scaling (V x10, mA, W, Hz x100) read with function 03 or 04. Energies come as a kWh register plus a Wh remainder per tariff. This map covers voltages, currents, reactive and apparent power, THD, demand, total energy, status words, the main setup registers and the reset commands.

This page lists 103 Modbus registers for the Circutor CVM-C10 — 20 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Circutor’s own free documentation (linked below) and checked against it.

Integration notes: Circutor CVM-C10

Integration in brief

Read the instantaneous block from 0x0000 with function 04 (up to 20 variables = 40 registers per frame). Each value is a 32-bit integer, high word first, with the scale shown in the table.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set Protocol (0x2742) to Modbus (factory default), then peripheral number, speed and framing either from the front panel or via the 0x2743-0x2747 registers. Reset the device for changes to apply.

Byte order & addressing

  • A frame may carry at most 20 variables (40 registers).
  • Energy is split into a whole-unit register (kWh) and a remainder register (Wh); combine both for full resolution.
  • Reset commands use function 05 (write coil) with FF00.

Network setup

  • Defaults: peripheral number 1, 9600 baud, no parity, 8 data bits, 1 stop bit.
  • Only 9600 and 19200 baud are available.
  • Program voltage and current transformer ratios together; voltage ratio x current ratio must stay below 600000.

Watch out for

  • The one RS-485 port runs either Modbus or BACnet, chosen by the Protocol setting (0x2742).

Notes on this map

  • Word order: the manual's function 04 example returns register 1 = 0000 and register 2 = 084D for 212.5 V, so 32-bit values are high word first (ABCD).
  • Left out: active power (per phase and three-phase), power factor and cos phi, plus their max/min and the kW maximum demand. The manual shows generated power as negative on the display but does not say whether the Modbus value is signed, so the data type cannot be fixed from the document.
  • Voltages, currents, reactive/apparent powers, frequency, THD and energies are non-negative quantities and are typed UINT32.
  • Left out: minimum values, per-tariff energies, harmonics tables, CO2/cost, alarm/pulse programming, BACnet and password registers, to keep the map to what integrators normally poll. All are in the manual's tables 19-38.
  • Left out: 'Generated apparent energy (VAh)' total because its address is printed FE-EF (a misprint for FE-FF).
  • Configuration registers: the manual lists function 0x04 for reading them and 0x10 for writing; changes take effect only after the device is reset, and out-of-range values silently revert to the default.
  • Reset commands are written with function 05 and value FF00. The manual's 0x05 example labels register 0834 as deleting max/min values, but its deleting-parameters table lists 834 as delete energies and 838 as delete max/min; the table is followed here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Circutor CVM-C10

What Modbus registers does the Circutor CVM-C10 have?

This map lists 103 registers: 6 coils, 83 input registers, 14 holding registers. 20 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Circutor CVM-C10 Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. All Modbus map addresses in the manual are hexadecimal wire addresses. The manual's example reads L1 voltage at initial register 0000 and receives 0000 084D (= 2125, 212.5 V), confirming the offset and scaling.

What byte order does the Circutor CVM-C10 use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Circutor CVM-C10?

Start with IR 0 L1 Phase voltage (L1 phase voltage (V x10)); IR 2 L1 Current (L1 current (mA)); IR 54 Apparent three-phase power (Three-phase apparent power); IR 60 L1 Frequency (Frequency (Hz x100)); IR 220 Total consumed active energy (kWh) (Total consumed active energy kWh); IR 2001 Power status (Power status (consumed/generated quadrant)).

How do I enable Modbus control of the Circutor CVM-C10?

Set Protocol (0x2742) to Modbus (factory default), then peripheral number, speed and framing either from the front panel or via the 0x2743-0x2747 registers. Reset the device for changes to apply.

Where is the official Circutor CVM-C10 Modbus documentation?

The source is CVM-C10 Power analyzer Instruction Manual (M001B01-03-23A), published free by Circutor at https://docs.circutor.com/docs/M001B01-03.pdf.
