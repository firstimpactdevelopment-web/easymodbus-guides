Short answer

The EM24 E1 is the Ethernet version of Carlo Gavazzi's EM24-DIN three-phase energy analyzer, with Modbus TCP on an RJ45 port. Measurements are 32-bit integers sent low word first with fixed weights and can be read with function 03 or 04, up to 125 registers per request. This map covers voltages, currents, powers, PF, frequency, demand, total/partial/phase/tariff energy, hour meter, identification, measurement setup, tariff, TCP/IP settings and reset commands.

Integration notes: Carlo Gavazzi EM24-DIN Ethernet (E1)

Integration in brief

Connect with Modbus TCP on port 502 (default IP 192.168.1.10, DHCP off) and read input registers 0000h-007Bh with function 04 or 03. Decode INT32 values low word first and apply the fixed weights.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The E1 versions answer Modbus TCP on the RJ45 port. To change IP settings, write the stored IP/mask/gateway/port/DHCP registers (2100h-210Dh) and then write 1 to 210Eh to apply them.

Byte order & addressing

  • INT32 values are low word first (CDAB).
  • The identification code at 000Bh must be read with a length of 1.
  • New TCP/IP settings do nothing until 210Eh is written.
  • With DHCP on, the stored IP settings are ignored; read 2120h-2123h for the address actually in use.

Network setup

  • Default IP 192.168.1.10, mask 255.255.255.0, gateway 192.168.1.1, port 502, DHCP off.
  • Only functions 03, 04 and 06 are supported.

Watch out for

  • Measuring system, CT/VT and total/all resets are refused while the front selector is in LOCK.
  • If CT x VT exceeds the limit, the write is rejected; lower one before raising the other.

Notes on this map

  • Word order: the document states INT32/UINT32/UINT64 values are LSW first with bytes MSB first, so 32-bit values are CDAB; CT and VT rows also say 'LSW:MSW'.
  • This map is not the same as the RS485 EM24-DIN map: tariff kvarh, DMD VA and DMD A max sit at different addresses, and frequency is UINT16 here.
  • The by-phase duplicate table (00FEh-017Fh) is not repeated here.
  • Left out: display page selectors (A001h-A004h), user ID codes (A005h-A007h), MAC address, actual subnet/gateway (2124h-212Bh), measurement firmware CRC (0350h) and the ASCII serial-number letters.
  • Tariff write format here is high byte 5Ah, low byte tariff (0-4); the RS485 EM24 protocol documents the bytes the other way round, so do not reuse code between the two.
  • Changing the active tariff resets all demand values.

Questions about the Carlo Gavazzi EM24-DIN Ethernet (E1)

What Modbus registers does the Carlo Gavazzi EM24-DIN Ethernet (E1) have?

This map lists 89 registers: 56 input registers, 33 holding registers. 29 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Carlo Gavazzi EM24-DIN Ethernet (E1) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as a 6-digit Modicon number for function 04 (3xxxxx; 4xxxxx for function 03) beside the hex physical address placed in the request. Wire address = physical address (300001 / 0000h is address 0). Setup rows are written with function 06 and are listed as holding registers.

What byte order does the Carlo Gavazzi EM24-DIN Ethernet (E1) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Carlo Gavazzi EM24-DIN Ethernet (E1)?

Start with IR 0 V L1-N (V L1-N); IR 12 A L1 (A L1); IR 40 W system (W system); IR 49 PF system (PF system); IR 51 Frequency (Frequency); IR 52 kWh(+) total (kWh(+) total); IR 78 kWh(-) total (kWh(-) total).

How do I enable Modbus control of the Carlo Gavazzi EM24-DIN Ethernet (E1)?

The E1 versions answer Modbus TCP on the RJ45 port. To change IP settings, write the stored IP/mask/gateway/port/DHCP registers (2100h-210Dh) and then write 1 to 210Eh to apply them.
