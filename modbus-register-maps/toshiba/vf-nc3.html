Integration notes: Toshiba TOSVERT VF-nC3 compact inverter (Modbus RTU)

Integration in brief

Set f829 = 1 (Modbus RTU) and f802 to a non-zero address, then power-cycle. Write FA00 = C400H (command and frequency priority + run forward) and the speed in FA01 (0.01 Hz), and poll FD00/FD01/FC90 for speed, status and trip.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set f829 (communication protocol) to 1 = MODBUS-RTU; the factory setting is 0 (Toshiba protocol). Baud f800, parity f801 and the protocol take effect only after a reset or power cycle. Comms run/frequency control is taken by setting FA00 bits 15 and 14, independent of cmod/fmod.

Communication loss & watchdog

f803 sets a communication time-out (0.0 = off, 0.1-100.0 s); f804 picks alarm only, trip with coast stop or trip with slowdown stop (trip shows err5); f808 sets when it is checked (always, during comms mode, or comms mode and running).

Byte order & addressing

  • The inverter number factory value is 0, which Modbus treats as broadcast with no reply; set 1-247 first.
  • FA00 bit 13 (fault reset) gets no reply from the drive.
  • Missing communication numbers inside a multi-word read come back as 8000H.
  • An input terminal set to function 48/49 (forced local) overrides comms commands and frequency.
  • Function 03 reads at most 8 consecutive words in one request (direct block read); a plain read is one word.

Network setup

  • f800 baud: 3 = 9600, 4 = 19200 (default), 5 = 38400.
  • f801 parity: 0 none, 1 even (default), 2 odd.
  • f802 address 1-247.
  • f805 adds reply delay for slow RS-485 converters (CPU1 v108 and later).
  • Power-cycle after changing f800, f801 or f829.

Watch out for

  • Do not write EEPROM-backed parameters cyclically; the manual rates the EEPROM at about 10,000 writes.
  • Comms do not answer for about one second after power-up.
  • f700 = 2 blocks parameter writes over RS-485 (error code 04).

Notes on this map

  • Every register here is a single 16-bit word; the manual has no 32-bit values.
  • FD.. registers give live values; the matching FE.. numbers (FE00-FE49) hold the same item frozen at the last trip. Only the live set is listed, plus the FE-only items.
  • Left out: torque (FD18) and torque current (FD20), because the manual does not say whether these words are signed; FB05 capacity code (needs the Appendix 3 lookup); LED/keypad registers FA10/FA11/FA65-FA80; block-communication parameters f870-f879.
  • Output current, output voltage and DC voltage are percentages of the drive rating, not amps or volts.
  • Section 7.2 names the VI monitor FE35, while the block-read list calls it FE36; the monitor table on p. 61 says FE35, which is used here.
  • The frequency command FA01 and command words FA00/FA20 are RAM only and reset at power-off, fault reset or factory reset.
  • Other drive parameters follow the same rule (f### = communication number 0###); scale = the minimum setting unit in the drive's parameter list.

Questions about the Toshiba TOSVERT VF-nC3 compact inverter (Modbus RTU)

What Modbus registers does the Toshiba TOSVERT VF-nC3 compact inverter (Modbus RTU) have?

This map lists 52 registers: 52 holding registers. 15 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Toshiba TOSVERT VF-nC3 compact inverter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Communication numbers are hex and go on the wire unchanged: the manual's read example sends 01 03 FD 00 00 01 for output frequency FD00, and the direct block-read example sends 01 03 01 30 for parameter f130 (communication number 0130). Parameters f### use communication number 0###.

What are the minimum Modbus registers to integrate the Toshiba TOSVERT VF-nC3 compact inverter (Modbus RTU)?

Start with HR 64000 Command 1 (Run/stop and comms priority bits); HR 64001 Frequency command (Speed reference, 0.01 Hz); HR 64768 Output frequency (Output frequency); HR 64769 Inverter status 1 (Running / tripped / alarm status); HR 64771 Output current (Output current, % of rating); HR 64656 Trip code (Present trip code); HR 64657 Alarm information 1 (Pre-alarm bits).

How do I enable Modbus control of the Toshiba TOSVERT VF-nC3 compact inverter (Modbus RTU)?

Set f829 (communication protocol) to 1 = MODBUS-RTU; the factory setting is 0 (Toshiba protocol). Baud f800, parity f801 and the protocol take effect only after a reset or power cycle. Comms run/frequency control is taken by setting FA00 bits 15 and 14, independent of cmod/fmod.

What happens when the Toshiba TOSVERT VF-nC3 compact inverter (Modbus RTU) loses Modbus communication?

f803 sets a communication time-out (0.0 = off, 0.1-100.0 s); f804 picks alarm only, trip with coast stop or trip with slowdown stop (trip shows err5); f808 sets when it is checked (always, during comms mode, or comms mode and running).
