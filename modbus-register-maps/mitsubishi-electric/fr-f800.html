Integration notes: Mitsubishi Electric FR-F800 fan and pump inverter (RS-485 terminals, Modbus RTU)

Integration in brief

Set Pr.549 = 1, give the drive a station number in Pr.331 (the initial 0 means broadcast, so it never answers) and reset. Put the drive in NET mode by writing H0014 to 40010, write the frequency to 40014 (0.01 Hz) and the run bits to 40009, then poll 40009, 40201 and 40224.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Pr.549 = 1 selects Modbus RTU on the RS-485 terminals; set Pr.331 (1-247), Pr.332 speed and Pr.334 parity, then reset or power-cycle. Run and frequency commands are taken in NET operation mode (write H0014 to 40010, or use Pr.79/Pr.340 so the drive starts in NET mode). If a communication option is installed and Pr.550 = 9999, commands via the RS-485 terminals are ignored.

Communication loss & watchdog

Pr.539 sets the Modbus communication check interval (0.1-999.8 s, same behaviour as Pr.122); 9999 (initial) disables the check, 0 lets Modbus run but shuts the output off in NET mode.

Byte order & addressing

  • Request address = register - 40001 (Pr.4 at 41004 is read at H03EB).
  • Station 0 is broadcast: no reply, and some functions are disabled.
  • Register 40009 means input command when written and inverter status when read.

Network setup

  • Pr.331 initial value 0 is broadcast: set 1-247 first.
  • Pr.332 initial 96 = 9600 bps; Pr.334 initial 2 = even parity, 1 stop bit; data length is fixed at 8 bits under Modbus.
  • Modbus RTU cannot be used in PU operation mode.

Watch out for

  • Current, power and energy monitors change resolution with drive size, so check the capacity before scaling them.
  • Setting Pr.37/Pr.144 for rpm display also changes the frequency registers to rpm.

Notes on this map

  • All registers are single 16-bit words. The manual notes that a 32-bit parameter or monitor whose value exceeds HFFFF reads back as HFFFF.
  • Left out because the increment depends on inverter capacity (0.01 unit up to FR-F820-02330/FR-F840-01160, 0.1 unit above): output current 40202, output current peak 40211, input power 40213, output power 40214, motor excitation current 40218, cumulative energy 40225, motor output 40234 and the 32-bit cumulative energy halves 40279/40280. Motor load factor 40224 (% of rated current) gives a size-independent current reading.
  • Left out because sign handling is unclear (one footnote says Modbus cannot show a minus sign, another says Pr.1018 enables signed monitors): motor torque 40207, PID deviation 40254, PID manipulated amounts 40291/40296, second PID deviation 40294, remote output values 40287-40290, BACnet AM output 40286 and control circuit temperature 40298 (all carry the negative-indication mark). Output frequency 40201 and operation speed 40206 are kept as unsigned: they only become signed when Pr.1018 Monitor with sign selection is set.
  • Output frequency, set frequency and the frequency command use 0.01 Hz by default; with Pr.37 = 1-9998 or Pr.144 = 2-12/102-112 the increment becomes 1 (speed display). The 0.01 Hz unit for 40014/40015 comes from the same manual's computer-link frequency command description (H0000-HE678 = 0-590.00 Hz).
  • Fault history registers hold the error code in the low byte (high byte H00); code meanings are in the manual's fault chapter (around p. 600).
  • Parameters 0-999 sit at 41000 + Pr. number and 1000-1999 at 44000 + Pr. number (45000-45999). Calibration parameters C2-C45 have their own registers (41902-43935) and are not listed.
  • Parameters with a 9999 (function off) setting, such as the communication check interval, are listed with their normal increment; the manual does not say how the 9999 setting itself is encoded on the wire, so read the parameter back after setting it from the panel.
  • Pr.7/Pr.8 acceleration/deceleration times are left out: their increment changes with Pr.21.

Questions about the Mitsubishi Electric FR-F800 fan and pump inverter (RS-485 terminals, Modbus RTU)

What Modbus registers does the Mitsubishi Electric FR-F800 fan and pump inverter (RS-485 terminals, Modbus RTU) have?

This map lists 50 registers: 50 holding registers. 21 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Mitsubishi Electric FR-F800 fan and pump inverter (RS-485 terminals, Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints Modicon-style register numbers (40002, 41004). Its rule: starting address = register number - 40001, e.g. reading 41004 (Pr.4) sends start address H03EB (1003).

What are the minimum Modbus registers to integrate the Mitsubishi Electric FR-F800 fan and pump inverter (RS-485 terminals, Modbus RTU)?

Start with HR 8 Inverter status / control input command (Run/stop command and inverter status); HR 9 Operation mode / inverter setting (Operation mode (write H0014 for NET)); HR 13 Running frequency (RAM) (Frequency command (RAM)); HR 200 Output frequency (Output frequency); HR 223 Motor load factor (Motor load factor (% of rated current)); HR 207 Converter output voltage (DC bus voltage); HR 500 Fault record 1 (Latest fault code).
