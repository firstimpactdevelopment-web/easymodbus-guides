Short answer

Lochinvar's Lectrus KEB electric boilers expose Modbus RTU through an RS-485 communication board. The BAS writes a configuration word, an enable word, a rate or setpoint command and optional remote temperatures; it reads safety-switch and pump states, outlet/inlet temperatures, modulation rate, pump speeds, cascade power and status/blocking/lockout codes.

Integration notes: Lochinvar Lectrus KEB electric boilers / water heaters 0015-0150 (Modbus communication board)

Integration in brief

Set address, baud and parity on the board DIP switches, set the control mode in the installer menu (code 5309, CONTROL MODES), then write 40001 and the commands: enable only = 40001 0x0001 + 40002 0x0001; enable + rate = 40001 0x0005 + 40002 0x0001 + 40003; rate only = 40001 0x0004 + 40003. Monitor 30009-30016.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Installer menu (hold LEFT SELECT [MENU] 5 s, code 5309) > CONTROL MODES: set BMS to ACTIVE for rate/setpoint control or BMS TSTAT to ACTIVE for remote DHW, and choose BMS TYPE (POWER or SETPOINT). Re-send 40001 before each command.

Communication loss & watchdog

MODBUS T/O in CONTROL MODES, 5-120 s (default 10 s): BAS-supplied temperatures/0-10 V values must be refreshed within it. Other commands must be refreshed at least every 4 minutes or the boiler reverts to its own inputs.

Byte order & addressing

  • Modicon addressing: 30009 is input register 8 on the wire.
  • Temperatures are degrees C x 10 with DIP switch 8 OFF.
  • A setpoint sent through 40003 is the 0-10 V equivalent percentage interpolated from the BMS low/high setpoint parameters, not degrees.
  • Read the lockout code only when the status code is 40.

Network setup

  • DIP switches 1-7: Modbus address (maximum 127).
  • DIP switch 8: OFF = Celsius, ON = Fahrenheit.
  • DIP switch 9: 0 = 9600 baud, 1 = 19200 baud.
  • DIP switch 10: 0 = no parity with 2 stop bits, 1 = even parity with 1 stop bit.
  • RTU only; check 120 ohm termination.

Watch out for

  • Board LED D7: 1 s bright / 1 s dim = normal; 1.5 s on / 0.5 s off = no Modbus traffic; 0.5 s on / 1.5 s off = no burner-control communication.

Notes on this map

  • Temperatures: the conversion section says the boiler passes temperatures in degrees C and the value must be divided by 10 (examples: 26.7 C sent as 267; outlet 683 = 68.3 C). Scale 0.1 is applied to the registers with 0.1 resolution in the map, assuming DIP switch 8 is OFF (Celsius).
  • DIP switch 8 selects Celsius (OFF) or Fahrenheit (ON). The map shows Fahrenheit rows only for the setpoints; the manual does not say how the 0.1-resolution temperatures change with the switch ON, so keep it OFF when using this map.
  • Left out: System/Cascade Setpoint (30004), Outlet Setpoint (30008) and Tank Setpoint (40004). They have 0.5 C (or 1.0/1.5 F) resolution in the map while the conversion text says C x 10, so their scaling is not settled.
  • Signed types: inlet and BAS-supplied temperatures have negative minimums in the map and are listed as INT16; the manual itself only says 16-bit word.
  • Input registers 30001-30003 are packed copies of the discrete inputs; the bit order is not stated, so they are UINT16. Use the discrete inputs instead.
  • The manual repeats its unit-operation section twice (Control Modes 1-4 and Demand Configurations) with the same register values; the integration steps follow both.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. What Modbus registers does the Lochinvar Lectrus KEB electric boilers / water heaters 0015-0150 (Modbus communication board) have?

This map lists 36 registers: 2 coils, 14 discrete inputs, 13 input registers, 7 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lochinvar Lectrus KEB electric boilers / water heaters 0015-0150 (Modbus communication board) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed Modicon-style (00001, 10001, 30001, 40001). Subtract the table base and 1 for the wire address; the manual's exception-code text confirms PDU addresses start at 0.
