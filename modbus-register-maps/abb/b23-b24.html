ABB EQ meter B23 / B24 (Modbus RTU) Modbus register map

Updated 16 October 2026

Short answer

The B23 and B24 are three-phase DIN-rail kWh meters from ABB's EQ family. Variants with the RS485 port speak Modbus RTU; every value is a holding register addressed in hex as sent on the wire. This map covers total, tariff, per-phase and resettable energy, instantaneous voltages, currents, powers, angles and power factor, I/O, identification, CT and tariff settings and the reset commands.

This page lists 149 Modbus registers for the ABB EQ meter B23 / B24 (Modbus RTU) — 17 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ABB’s own free documentation (linked below) and checked against it.

Integration notes: ABB EQ meter B23 / B24 (Modbus RTU)

Integration in brief

Set the RS485 port to Modbus on the meter's front panel, then read holding registers with function 3 using the hex addresses directly (0x5000 for total active import). All multi-register values are high word first; energy is 64-bit with 2 decimals.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the meter menu, open the RS485 communication settings and select the Modbus protocol (the alternative is ABB's EQ-Bus). Then set baud rate, address and parity on the following menu pages.

Byte order & addressing

  • Addresses are hex wire addresses; do not apply a 40001 offset.
  • Energy values are 4 registers (64-bit) with resolution 0.01; net energies are signed.
  • Readable range is 0x1000-0x8EFF; reading outside it gives exception 2. Up to 125 registers per read.
  • Unsupported quantities return FFFF (unsigned) or 7FFF... (signed) instead of an exception.
  • A write to a register that the meter does not support is silently ignored, so read back to confirm.

Network setup

  • Address range 1-247.
  • Baud rates offered for Modbus: 1200, 2400, 4800, 9600, 19200, 38400, 57600, 115200.
  • Parity: None, Odd or Even.
  • Function codes supported: 3, 6 and 16; broadcast works for 6 and 16.

Watch out for

  • Modbus runs over the RS485 port; meters fitted with the M-Bus interface talk M-Bus instead.
  • Powers above about 21 MW overflow the 0.01 W registers; use the DMTME block (whole watts) instead.

Notes on this map

  • Addresses are printed in hexadecimal exactly as sent on the bus (the manual says not to subtract 40000 or 1). All data is in holding registers, read with function 3 and written with function 6 or 16.
  • Multi-register values are big-endian: the most significant byte is the high byte of the lowest register, so 32-bit and 64-bit values are ABCD (high word first).
  • Unsupported quantities still answer, but with an 'invalid' marker: FFFF in every register for unsigned values, and the largest positive value (7FFF, 7FFFFFFF ...) for signed values.
  • Instantaneous power registers are signed 32-bit with 2 decimals, which caps them near +/-21 MW; for larger systems the manual points to the DMTME-compatible block, which reports whole watts.
  • Built from the current manual revision. The 2013 Revision A also listed input states/counters, error/warning/alarm flag words, load-profile and log resets; the current revision no longer lists them, so they are left out.
  • Left out: the DMTME-block energy registers (103E, 1040) whose unit is printed as 'Wh*100' / 'VArh*100', which does not make the scaling direction unambiguous.
  • Left out: event-log, alarm-configuration, pulse-output and tariff-configuration register groups, which work through selector/header registers or OBIS-coded multi-register fields rather than simple point reads.
  • Resettable reactive energy import/export (5534, 5538): the manual's Unit column prints 'kWh' for these two rows, while the quantity name is reactive energy. Size (4 registers), resolution (0,01) and data type (Unsigned) are printed unambiguously and match the other reactive registers, so they are kept and listed as kvarh; the unit is the only misprint.
  • The CO2 (5024) and currency (5034) rows show 'kVAh' in the manual's Details column; their Unit column gives kg and currency, which is what is used here.
  • Only outputs 1 and 2 (6300, 6301) are listed as Modbus I/O registers; whether they physically exist depends on the article (2 inputs/2 outputs, 1 output, or none). The input counter and stored-state reset commands (8F0B-8F14) are still listed in the manual and are kept.
  • The B24 is transformer connected; energy and power values are reported on the primary side using the CT ratio set in 8C04/8C08.

Questions about the ABB EQ meter B23 / B24 (Modbus RTU)

What Modbus registers does the ABB EQ meter B23 / B24 (Modbus RTU) have?

This map lists 149 registers: 149 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB EQ meter B23 / B24 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints each start register in hex as it goes on the wire (e.g. 5000 = 0x5000 = 20480 decimal) and explicitly says not to subtract 40000 or 1. Its example frame reads 0x5000 with function 3.

What byte order does the ABB EQ meter B23 / B24 (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ABB EQ meter B23 / B24 (Modbus RTU)?

Start with HR 20480 Active import energy (Total active import energy (kWh, 0.01)); HR 20484 Active export energy (Total active export energy); HR 23296 Voltage L1-N (Voltage L1-N); HR 23308 Current L1 (Current L1); HR 23316 Active power Total (Total active power (signed, 0.01 W)); HR 23340 Frequency (Frequency); HR 23354 Power factor Total (Total power factor); HR 35072 Serial number (Serial number, a quick comms check).

How do I enable Modbus control of the ABB EQ meter B23 / B24 (Modbus RTU)?
