APC Smart-UPS / Smart-UPS VT / MGE Galaxy 3500 (NMC Modbus map 990-5702) Modbus register map

Updated 17 November 2026

Short answer

APC's older Smart-UPS family, plus the three-phase Smart-UPS VT and MGE Galaxy 3500, publish a compact Modbus map through the Network Management Card. Everything is a single 16-bit holding register: status words with per-bit flags, battery charge and runtime, input/output voltages and frequency, per-phase currents and load, transfer settings and an 8-character UPS ID. Modbus TCP is on AP9630/AP9631/AP9635 cards; RTU only on AP9635.

This page lists 73 Modbus registers for the APC Smart-UPS / Smart-UPS VT / MGE Galaxy 3500 (NMC Modbus map 990-5702) — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from APC’s own free documentation (linked below) and checked against it.

Integration notes: APC Smart-UPS / Smart-UPS VT / MGE Galaxy 3500 (NMC Modbus map 990-5702)

Integration in brief

Read holding registers 0-77 with function 03; a block read that starts on a valid register returns zeros for reserved ones. Status Word 3 (0x0003) gives on-line/on-battery/overload/low-battery/replace-battery at a glance.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Enable Modbus on the Network Management Card (TCP on AP9630/AP9631/AP9635, serial RTU on AP9635).

Byte order & addressing

  • Line quality (0x0004) reads 0x00FF when acceptable and 0 when not.
  • Sensitivity (0x0021) returns an ASCII letter H, M or L (0 = not supported).

Network setup

  • Serial and TCP parameters are set in the Network Management Card configuration; the map itself gives no defaults.

Watch out for

  • SMT, SMX, SURTD and SRT Smart-UPS models use a different map and are not covered here.

Notes on this map

  • Source host: the PDF is the APC/Schneider document served from Schneider Electric's product-data CDN for distributors; the apc.com download link refuses automated requests.
  • All registers are one word, transmitted MSB first; signed values are two's complement. Strings are one character per register.
  • Single-register reads of reserved/undefined addresses return an error; block reads starting on a valid register return zeros for undefined ones. Addresses 0x0050 and above are invalid.
  • Left out: 40054 'Output Current Phase A' because the table prints its unit as V while the matching phase B/C registers are in A; and Status Words 6-7, which are reserved for future use.
  • Many registers are marked as not supported on all UPS models.
  • Status bits are only consistent within one register, not across registers.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the APC Smart-UPS / Smart-UPS VT / MGE Galaxy 3500 (NMC Modbus map 990-5702)

What Modbus registers does the APC Smart-UPS / Smart-UPS VT / MGE Galaxy 3500 (NMC Modbus map 990-5702) have?

This map lists 73 registers: 73 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the APC Smart-UPS / Smart-UPS VT / MGE Galaxy 3500 (NMC Modbus map 990-5702) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map prints the Modicon number (40001...) next to the absolute address in hex and decimal; note 10 states that absolute address 0 equals register 40001 and is address zero on the wire.

What are the minimum Modbus registers to integrate the APC Smart-UPS / Smart-UPS VT / MGE Galaxy 3500 (NMC Modbus map 990-5702)?

Start with HR 3 Status Word 3 (Status word 3: on line / on battery / low battery); HR 5 % Battery State of Charge (0-100) (Battery state of charge); HR 6 Runtime Remaining (Runtime remaining (minutes)); HR 12 % Power drawn by load (Load percent); HR 17 Input Voltage (Input voltage); HR 14 Actual Output Voltage (Output voltage); HR 8 UPS Internal Temperature (Internal temperature).

How do I enable Modbus control of the APC Smart-UPS / Smart-UPS VT / MGE Galaxy 3500 (NMC Modbus map 990-5702)?

Enable Modbus on the Network Management Card (TCP on AP9630/AP9631/AP9635, serial RTU on AP9635).
