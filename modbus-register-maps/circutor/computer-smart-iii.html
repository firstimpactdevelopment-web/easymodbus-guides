Circutor Computer SMART III Modbus register map

Updated 17 November 2026

Short answer

The Computer SMART III is Circutor's power factor (capacitor bank) regulator with a built-in three-phase network analyzer and an RS-485 Modbus RTU port. Measurements are 32-bit integers in register pairs read with function 04. This map covers currents, reactive power split into consumed/generated and inductive/capacitive parts, apparent power, frequency, THD, energy counters and the quadrant sign registers.

This page lists 49 Modbus registers for the Circutor Computer SMART III — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Circutor’s own free documentation (linked below) and checked against it.

Integration notes: Circutor Computer SMART III

Integration in brief

Read with function 04 in register pairs (high word first). Use the kW and kvar sign registers to tell consumed from generated and inductive from capacitive operation.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is available on the RS-485 port; peripheral number and serial settings are set in the setup menu.

Byte order & addressing

  • Frames of more than 80 bytes are not accepted (sent or received); size reads so the reply stays within 80 bytes.
  • Energy is split into a whole-unit register (kWh) and a remainder register (Wh).

Network setup

  • Defaults: peripheral number 1, 19200 baud, no parity, 8 data bits, 1 stop bit; 9600 or 19200 can be chosen in the setup menu.

Watch out for

  • Do not apply the CVM-series x10 voltage scaling blindly; this manual's voltage scaling is inconsistent, so verify voltages against the display.

Notes on this map

  • Word order: the manual's function 04 example returns 0000 then 084D (high word first), so 32-bit values are ABCD.
  • Left out: all voltage registers. The table gives the unit as V/100 but the worked example decodes the same register as V x10 (212.5 V), so the scaling is contradictory.
  • Left out: active power, signed reactive power, power factor and cos phi. The manual pairs PF/cos phi with separate kW/kvar sign registers but does not state the type or scaling of the PF values or whether the power values are signed.
  • Left out: THD (unit printed as % with no scaling factor), temperature (signedness not stated), harmonics, relay/alarm/output words and the configuration registers.
  • The kW/kvar sign registers are typed INT32 because the documented values are +1 and -1.
  • Communication defaults come from the programming-variables table (Table 17): peripheral number 1, speed code 1 = 19200, parity 0 = none, 8 data bits, 1 stop bit. Frames longer than 80 bytes are rejected.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Circutor Computer SMART III

What Modbus registers does the Circutor Computer SMART III have?

This map lists 49 registers: 49 input registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Circutor Computer SMART III Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. All addresses in the memory map are hexadecimal wire addresses; the manual's query example reads two registers from 0000 for L1 voltage.

What byte order does the Circutor Computer SMART III use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Circutor Computer SMART III?

Start with IR 80 Three-phase current (Three-phase current (mA)); IR 90 Three-phase apparent power (Three-phase apparent power); IR 100 Three-phase kW sign (Three-phase kW sign); IR 102 Three-phase kvar sign (Three-phase kvar sign); IR 104 Frequency (Frequency (Hz/10)); IR 136 Active energy consumed kWh (Active energy consumed kWh).

How do I enable Modbus control of the Circutor Computer SMART III?

Modbus RTU is available on the RS-485 port; peripheral number and serial settings are set in the setup menu.

Where is the official Circutor Computer SMART III Modbus documentation?

The source is Computer SMART III Instruction Manual (M015B01-03-25B), published free by Circutor at https://docs.circutor.com/docs/M015B01-03.pdf.
