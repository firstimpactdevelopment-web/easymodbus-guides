Danfoss VLT AutomationDrive FC 301/302 (Modbus RTU) Modbus register map

Updated 24 October 2026

Short answer

Danfoss's general-purpose industrial variable frequency drive family (FC 301, and FC 302 which adds flux control modes), with a built-in RS-485 port that can speak Modbus RTU. Control word, bus reference, status word and main actual value sit at fixed holding registers 50000-50210, and every parameter is a holding register at ten times its parameter number. This map covers the control block, the communication and comm-loss parameters and the main 15-xx/16-xx readouts, including the FC 302 high-resolution torque readouts.

This page lists 62 Modbus registers for the Danfoss VLT AutomationDrive FC 301/302 (Modbus RTU) — 22 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Danfoss’s own free documentation (linked below) and checked against it.

Integration notes: Danfoss VLT AutomationDrive FC 301/302 (Modbus RTU)

Integration in brief

Set 8-30 to Modbus RTU and power-cycle, make sure 8-02 points at the FC port and the drive is not in local/Hand control, then write the control word to 50000 and the reference to 50010 and poll 50200/50210. Read readouts from the 16-xx registers at parameter number x 10 (minus 1 on the wire).

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set 8-30 Protocol = [2] Modbus RTU (effective only after the drive is powered off and on), 8-31 Address (1-247, default 1), 8-32 FC Port Baud Rate and 8-33 Parity/Stop Bits. 8-02 Control Word Source must be [1] FC RS485; 8-01 Control Site picks digital inputs and/or control word; 8-50, 8-53, 8-55 and 8-56 default to Logic OR, which decides how bus bits combine with terminals. STW bit 9 must read 1 (not local) and CTW bit 10 (data valid) must be 1 for the control word to act.

Communication loss & watchdog

8-03 Control Word Timeout Time (0.1-18000 s, 0.1 s units) and 8-04 Control Word Timeout Function (Off, Freeze output, Stop, Jogging, Max. speed, Stop and trip, set-up switching; Qstop and trip on software 48.xx; Trip with MCO 302). A valid control word restarts the timer. 8-05 End-of-Timeout Function (default Resume set-up) and 8-06 Reset Control Word Timeout handle recovery after a set-up-switching timeout.

Byte order & addressing

  • Parameter register = parameter number x 10, request address = that minus 1 (16-13 -> 16130 -> address 16129).
  • 32-bit values are high word first (ABCD).
  • REF/MAV use 4000h = 100% of the 3-02..3-03 reference range, negative values in two's complement.
  • CTW bit 10 must be 1 or the whole control word is ignored. Derived from the bit table (no ready-made words are printed): bits 2, 3, 4, 5, 6 and 10 set = 047Ch runs on the ramp; clearing bit 6 (043Ch) ramps to stop; bit 7 resets on its rising edge.
  • Uint8 parameters still occupy a full 16-bit register.

Network setup

  • RS-485 on control-card terminals 68/69 (the built-in FC port); set the Modbus address 1-247 in 8-31 (default 1).
  • 8-33 defaults to even parity, 1 stop bit; baud is chosen in 8-32 (2400-115200).
  • 8-35 Minimum Response Delay (1-10000 ms, default 10 ms) can be raised for slow masters or RS-485 converters.
  • Array parameters need the index written to holding register 9 before the read or write.

Watch out for

  • Parameter writes go to RAM only unless coil 65 is set to 1; RAM-only changes are lost at power-down.
  • If a fieldbus option is fitted in slot A the drive sets 8-02 to Option A at first power-up, and Modbus control words on the FC port are then ignored.
  • Pressing [Stop/Reset] on the keypad or setting 3-13 Reference Site to Local blocks bus control (STW bit 9 = 0); a Local setting survives power-down.
  • Torque readout 16-16 is only 16 bits on FC 301/302; use 16-25 for drives whose torque can exceed 3000 Nm.

Notes on this map

  • Programming data source: VLT AutomationDrive FC 301/FC 302 Programming Guide, software 9.5x and 48.96, AU275636650261en-003201 (2024.09), https://assets.danfoss.com/documents/431896/AU275636650261en-003201.pdf. Each parameter's conversion index gives the scale: -1 = x0.1, -2 = x0.01, -3 = x0.001, 0 = x1, 1 = x10.
  • Indices 67, 74, 75 and 100 have no factor in the current guide or in the design guide's conversion table; the FC 301/302 Programming Guide MG33MP02 (software 8.23/48.33, AU275636650261en-001101, Table 5.2, printed p. 262, https://assets.danfoss.com/documents/271654/AU275636650261en-001101.pdf) gives them 1/60, 3600, 3600000 and 1 relative to SI units, so the transferred integer is already in RPM, hours, kWh and degC (scale 1).
  • Word order: the design guide says 32-bit parameters use 2 registers but prints no 32-bit example. Danfoss's Modbus RTU Operating Instructions MG92B102 (https://assets.danfoss.com/documents/latest/271338/AQ361181101347en-000101.pdf), written for the Danfoss FC series as a whole and using the same register scheme as this drive's design guide, maps an Int32/Uint32 as bytes 3-2 in the first register and bytes 1-0 in the second (printed p. 17) and its read example for 3-03 at registers 3030/3031 returns 0016E360h = 1500000 (printed p. 22): high word first (ABCD).
  • 16-16 Torque [Nm] is Int16 on FC 301/302 (range -3000..3000 Nm, index -1), unlike FC 102/FC 202 where it is Int32; for larger drives read 16-25 Torque [Nm] High (Int32). The MG33MP02 parameter list agrees.
  • 16-10 Power [kW] has conversion index 1 and the guide states its fieldbus value is in 10 W steps with W as the base unit, so raw x 0.01 = kW.
  • REF and MAV are signed 16-bit values where 16384 (4000h) = 100%; with 3-00 = [0] Min - Max the range runs from 3-02 (0%) to 3-03 (100%), with [1] -Max - +Max it runs from -3-03 to +3-03. Coils 17-32 carry the same reference (0x0-0xFFFF = -200%..~200%).
  • 8-bit parameters (Uint8, e.g. 8-31, 16-18, 16-34) are read and written as one 16-bit register.
  • 16-62/16-64 analog inputs are in volts or milliamps depending on the terminal mode; the guide prints no unit for the readout.
  • Left out: 16-05 Main Actual Value [%] and 16-15 Frequency [%] (normalised N2 type); 16-23 Motor Shaft Power (index 1, base unit not stated); 16-20 Motor Angle (raw encoder units); 16-50 External Reference (no unit printed); 15-30..15-33 alarm log arrays (need IND); text parameters; MCO/positioning (software 48.xx) groups.
  • Alarm/warning/extended status words (16-90..16-95) are listed as raw UINT32; their bit meanings are in the programming guide's troubleshooting tables.
  • Coils 1-16 / 17-32 / 33-48 / 49-64 mirror CTW, REF, STW and MAV (output frequency in open loop, feedback in closed loop); only coil 65 (parameter write control) is listed separately.
  • The design guide's 3-14 example prints registers 3410/3411 and '11300 = 1113.00'; by the x10 rule 3-14 is 3140/3141, so treat that example as a typo.
  • The Modbus mapping comes from the MG33BF02 (2013-12-20) edition of the design guide; the parameter numbers, types and conversion indices it relies on were re-checked in the 9.5x programming guide.
  • FC 301 and FC 302 share the programming guide; options marked 'FC 302 only' or 'software 48.xx' are noted in the value lists.

Questions about the Danfoss VLT AutomationDrive FC 301/302 (Modbus RTU)

What Modbus registers does the Danfoss VLT AutomationDrive FC 301/302 (Modbus RTU) have?

This map lists 62 registers: 1 coil, 61 holding registers. 22 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Danfoss VLT AutomationDrive FC 301/302 (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers derived from parameter numbers. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed 1-based (the design guide's own rule: register 40001 is address 0, coil 1 is address 0). A parameter's register number is 10 x its parameter number (3-03 -> 3030, 16-13 -> 16130) and the request carries that number minus 1 (16-13 is read at address 16129). The fixed process registers CTW 50000, REF 50010, STW 50200 and MAV 50210 follow the same minus-1 rule (CTW = address 49999). Coil 65 is address 64.

What byte order does the Danfoss VLT AutomationDrive FC 301/302 (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Danfoss VLT AutomationDrive FC 301/302 (Modbus RTU)?

Start with HR 49999 Control word (CTW) (CTW: start/stop/reset); HR 50009 Bus reference (REF) (REF: speed reference, 4000h = 100%); HR 50199 Status word (STW) (STW: ready/running/trip/warning); HR 16129 16-13 Frequency (16-13 Frequency, 0.1 Hz); HR 16139 16-14 Motor current (16-14 Motor current, 0.01 A); HR 16169 16-17 Speed [RPM] (16-17 Speed, RPM); HR 16099 16-10 Power [kW] (16-10 Power, 10 W steps (0.01 kW)); HR 16899 16-90 Alarm Word (16-90 Alarm word); HR 15019 15-02 kWh Counter (15-02 kWh counter).
