Short answer

The TeSys T LTMR protects and controls a motor and talks Modbus RTU on its network port. Registers are grouped by number: monitoring at 450-539 (trips, status, alarms, currents, voltage and power), configuration at 540-699 and commands at 704-705. Most values are 16-bit; phase currents are 32-bit with a selectable word order.

This page lists 50 Modbus registers for the Schneider Electric TeSys T LTMR motor management controller (Modbus RTU) — 8 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Schneider Electric’s own free documentation (linked below) and checked against it.

Integration notes: Schneider Electric TeSys T LTMR motor management controller (Modbus RTU)

Integration in brief

Read 450-515 for trips, status, alarms and measurements, and write bits in 704 to run, reverse or reset. Register 455 bit 14 shows whether the controller is in remote (network) control.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the network port address (696), baud (695) and parity (694) via the HMI or SoMove with the TeSys T DTM before communicating. Write run, reverse and reset bits in 704; 455 bit 14 shows whether the controller is in remote control. The guide warns that switching to network control can restart the motor from the last PLC command.

Communication loss & watchdog

Network port comm loss timeout (693, 0.01 s units) with the fallback action set in 682 (hold, run, outputs off/on).

Byte order & addressing

  • Printed register numbers are wire addresses (numbering starts at 0).
  • Word order of 32-bit currents depends on register 602 bit 10.
  • Some bit writes are silently ignored outside configuration mode.

Network setup

  • Address 1-247 (1 = undefined at the factory).
  • Autodetection tries 19200 baud, even parity first.
  • Check the PLC Comm (yellow) and Fallback (red) LEDs.

Watch out for

  • Broadcast writes can change configuration; avoid broadcast.
  • A reserved register written with a non-zero value returns exception 03.

Notes on this map

  • 32-bit values (UDInt) follow the 'Network port endian setting' (bit 10 of register 602): 1 = most significant word first (factory setting), 0 = least significant word first. The map assumes the factory setting.
  • Registers marked note 1 (voltage, power, power factor, voltage trip/alarm bits, extra I/O) exist only with the LTMEV40 expansion module. Frequency (474) is always present but reads 0 without it.
  • Factory network settings: address 1 (treated as undefined), baud and parity on autodetection (19200 and even tried first). Parity none uses 2 stop bits, even/odd use 1.
  • Left out: identification and statistics blocks (0-449), trip history, the full configuration area, user map 800-999 and custom logic registers.
  • At most 100 registers per request; functions 03, 06, 16 and 43 are supported.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Schneider Electric TeSys T LTMR motor management controller (Modbus RTU)

What Modbus registers does the Schneider Electric TeSys T LTMR motor management controller (Modbus RTU) have?

This map lists 50 registers: 50 holding registers. 8 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Schneider Electric TeSys T LTMR motor management controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide numbers registers from 0 (identification block 0-99), calls each number an 'address', and its PLC examples read 'address 455' and write 'address 704' directly, so the printed number is the wire address.

What byte order does the Schneider Electric TeSys T LTMR motor management controller (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Schneider Electric TeSys T LTMR motor management controller (Modbus RTU)?

Start with HR 455 System status register 1 (Ready / on / trip / remote status); HR 451 Trip code (Trip code); HR 465 Thermal capacity level (Thermal capacity used); HR 500 Average current (Average current); HR 704 Control register 1 (Run / reverse / reset commands); HR 460 Alarm code (Alarm code).

How do I enable Modbus control of the Schneider Electric TeSys T LTMR motor management controller (Modbus RTU)?

Set the network port address (696), baud (695) and parity (694) via the HMI or SoMove with the TeSys T DTM before communicating. Write run, reverse and reset bits in 704; 455 bit 14 shows whether the controller is in remote control. The guide warns that switching to network control can restart the motor from the last PLC command.

What happens when the Schneider Electric TeSys T LTMR motor management controller (Modbus RTU) loses Modbus communication?

Network port comm loss timeout (693, 0.01 s units) with the fallback action set in 682 (hold, run, outputs off/on).

Where is the official Schneider Electric TeSys T LTMR motor management controller (Modbus RTU) Modbus documentation?

The source is TeSys T LTMR Motor Management Controller Modbus Communication Guide (DOCA0130EN-03), revision 2024-02, published free by Schneider Electric at https://download.se.com/files?p_Doc_Ref=DOCA0130EN.
