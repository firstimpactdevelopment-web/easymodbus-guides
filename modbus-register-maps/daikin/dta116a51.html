Updated 17 November 2026

Short answer

The DTA116A51 connects a Daikin VRV system's D-III NET bus to a Modbus RTU master. Input registers report adaptor readiness, which indoor units are connected, each unit's capabilities, on/off, mode, setpoint, room temperature and error state; holding registers send on/off, mode, fan and setpoint commands. Most per-unit registers pack several small fields into one word, so this map gives the single-bit flags directly and describes the multi-bit fields.

This page lists 196 Modbus registers for the Daikin DTA116A51 D-NET / Modbus communication adaptor (VRV) — 49 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Daikin’s own free documentation (linked below) and checked against it.

Integration notes: Daikin DTA116A51 D-NET / Modbus communication adaptor (VRV)

Integration in brief

Wait for 30001 = 1, read 30002 to see which indoor units exist, then poll each unit's six status registers from 32001 with function 04 (up to 32 registers per read). Before commanding a unit, copy its current state into its three holding registers; the adaptor sends a command whenever a holding register value changes.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the Modbus slave address (1-15, 0 = Modbus off) on DIP switch DS2 and baud, stop bits and parity on DS1. Holding register 40001 sets whether the adaptor is D-NET master; set it to slave (bit 8 = 0) when another central controller is on the VRV system.

Byte order & addressing

  • Function 03 is not supported: read input registers with 04, write holding registers with 06 or 16 (up to 30 registers).
  • Reads are limited to 32 registers per request.
  • Holding registers are not refreshed from the units; if they are not kept in step with the input registers, a command can be skipped or undo a change made at a remote controller.

Network setup

  • DS1-2: 9600 (off) or 19200 (on) baud. DS1-3 off = 1 stop bit with parity, on = 2 stop bits, no parity. DS1-4 parity even (off) or odd (on).
  • Leave a silent interval (5 ms at 9600, 2.5 ms at 19200) plus 20 ms between a reply and the next query.

Watch out for

  • Daikin limits commands to about 7,000 per indoor unit per year; avoid writing values that did not change.
  • With an RQCEQ-PY1 outdoor unit, synchronise the operation mode register with the unit's actual mode before writing a setpoint.

Notes on this map

  • Daikin does not appear to host this specification publicly; the link is the unaltered Daikin Industries document as mirrored by the integrator TapHome.
  • Per-unit blocks repeat: capabilities every 3 registers from 31001, status every 6 from 32001, control every 3 from 42001, for D-NET addresses 1-00 to 1-15.
  • Packed fields (from the spec's bit diagrams): capability word bits 8-10 fan direction level (1 fix, 2-5 = 2-5 step), bit 11 fan direction available, bits 12-14 fan volume steps (1 fix, 2 two-step, 3 three-step), bit 15 fan volume available. Status 1 bits 8-10 fan direction (0-4 = P0-P4, 7 = swing), bits 12-14 fan volume (1 L, 3 M, 5 H). Status 2 bits 0-3 operation mode, 4-7 filter sign (0 off, 1-15 on), 8-11 actual operation (0 fan, 1 heat, 2 cool), 14-15 cool/heat master (0 undecided, 1 slave, 2 master).
  • Control 1 (42001+3n): bit 0 on/off, bits 4-7 fan control flag that must be 6, bits 8-10 fan direction (0-4 P0-P4, 6 stop, 7 swing), bits 12-14 fan volume (1 L, 3 M, 5 H; 0 if the unit has no fan volume capability). Control 2: bits 0-3 mode (0 fan, 1 heat, 2 cool, 3 auto, 6 setpoint, 7 dry), bits 4-7 filter sign reset (15 = reset, then write 0 again), bits 8-11 heat/cool setpoint selection in auto (1 heat, 2 cool).
  • Setpoint limit registers hold two signed 8-bit values (°C) in one word; they are listed as UINT16 because the schema has no 8-bit type.
  • Left out: the error code mapping table (section 6), which converts the two mapping values into Daikin error codes.

Questions about the Daikin DTA116A51 D-NET / Modbus communication adaptor (VRV)

What Modbus registers does the Daikin DTA116A51 D-NET / Modbus communication adaptor (VRV) have?

This map lists 196 registers: 147 input registers, 49 holding registers. 49 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Daikin DTA116A51 D-NET / Modbus communication adaptor (VRV) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The spec lists 30001/40001-style registers and states that the request addresses them from zero (30001 is sent as 0, 40001 as 0). Its example frames confirm it: register 31001 is requested as 0x03E8 and 42002 as 0x07D1.

What are the minimum Modbus registers to integrate the Daikin DTA116A51 D-NET / Modbus communication adaptor (VRV)?

Start with IR 0 Adaptor status (Adaptor ready); IR 1 Indoor unit connection status (Which indoor units are connected); IR 5 Indoor unit communication status (Indoor unit communication errors); IR 2000 IU 1-00 status 1 (Unit 1-00 on/off and fan); IR 2002 IU 1-00 setpoint (Unit 1-00 setpoint); IR 2004 IU 1-00 room temperature (Unit 1-00 room temperature); HR 2000 IU 1-00 control 1 (Unit 1-00 on/off and fan command); HR 2002 IU 1-00 setpoint command (Unit 1-00 setpoint command).

How do I enable Modbus control of the Daikin DTA116A51 D-NET / Modbus communication adaptor (VRV)?

Set the Modbus slave address (1-15, 0 = Modbus off) on DIP switch DS2 and baud, stop bits and parity on DS1. Holding register 40001 sets whether the adaptor is D-NET master; set it to slave (bit 8 = 0) when another central controller is on the VRV system.
