Short answer

The Spyglass SG50-F is a family of optical flame detectors (multi-IR, UV/IR and hydrogen-flame types, some with HD video). Its RS-485 port speaks Modbus RTU: input registers carry alarm, fault, built-in-test flags and the detector type, and holding registers set sensitivity, delays, latching, heater, video and the clock. This map covers every register the manual defines except the 32-bit and IP fields.

Integration notes: Teledyne Gas and Flame Detection Spyglass SG50-F flame detector (Modbus RTU)

Integration in brief

Set a unique address per detector, wire RS-485 at 9600 8N1 and poll input registers 0-2 (alarm, fault, BIT flags) with function 04.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is available on the RS-485 terminals of all SG50-F detectors; the address is register 0x0020 (1-247).

Byte order & addressing

  • Addresses are printed in hex and are the wire addresses.
  • Clock registers pack two fields per register (high byte, low byte).

Network setup

  • 9600 baud, 8N1, half duplex 2-wire, no echo.
  • Terminate the line with 120 ohm.

Watch out for

  • Video and analog-video registers only work on HD models.

Notes on this map

  • Left out: 0-20 mA output value (input 0x0004-0x0005), Ethernet IP address (0x0006-0x0007, HD only) and detector serial ID (u32 at 0x0019-0x001A): the manual does not give their word order or encoding.
  • Input registers and holding registers are separate tables, so input 0x0001 (fault relay) and holding 0x0001 (sensitivity) are different values.
  • The factory default Modbus address is not stated in this manual.
  • Up to 32 detectors per segment; up to 247 with repeaters. 120 ohm end-of-line resistor required.

Questions about the Teledyne Gas and Flame Detection Spyglass SG50-F flame detector (Modbus RTU)

What Modbus registers does the Teledyne Gas and Flame Detection Spyglass SG50-F flame detector (Modbus RTU) have?

This map lists 19 registers: 5 input registers, 14 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Teledyne Gas and Flame Detection Spyglass SG50-F flame detector (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints register addresses in hex starting at 0x0000 (alarm relay), so the hex value is the wire address: 0x0010 = address 16.

Start with IR 0 Alarm relay (Fire alarm); IR 1 Fault relay (Fault); IR 2 BIT status (Maintenance flags); IR 27 Detector type (Detector type); HR 1 Sensitivity (Sensitivity); HR 32 Detector Modbus address (Modbus address).

How do I enable Modbus control of the Teledyne Gas and Flame Detection Spyglass SG50-F flame detector (Modbus RTU)?

Modbus RTU is available on the RS-485 terminals of all SG50-F detectors; the address is register 0x0020 (1-247).
