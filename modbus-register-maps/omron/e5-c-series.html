Short answer

Omron's E5_C temperature controllers speak CompoWay/F or Modbus RTU on their RS-485 option. The variable area can be read in 4-byte mode (two registers per value) or 2-byte mode (one register per value, addresses from 0x2000); this map uses 2-byte mode for PV, set points, MV, heater current, alarms and status, plus the operation-command register for RUN/STOP, auto/manual and auto-tune.

Integration notes: Omron E5CC / E5EC / E5AC / E5DC digital temperature controllers (E5_C series)

Integration in brief

Read 0x2000-0x2005 with FC03 for PV, status, internal SP, heater current and MV; read 0x2410 once for the decimal point. To change the set point, first write 0x0001 to 0xFFFF (communications writing ON), then write 0x2103.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set Protocol Setting (psel) to Modbus in the communications setting level, set unit number and baud, then cycle power. Writes need 'communications writing ON' via the operation command.

Byte order & addressing

  • Values carry no decimal point; check 2410.
  • Use 2-byte mode addresses (0x2000+) for 16-bit tools; 4-byte mode needs even addresses and even counts.
  • Reading in setup area 1 freezes or clears some status bits.

Network setup

  • Protocol (psel), unit no. (u-no, default 1), baud (bps), parity (prty) and send data wait (sdwt, default 20 ms) are set on the front panel in the communications setting level; reset the controller to apply changes.
  • Up to 106 registers per read in 2-byte mode.

Watch out for

  • In backup mode every communications write of an operation/adjustment parameter is also saved to non-volatile memory; RAM write mode (0x0401) skips that until backup mode or 'save RAM data'.

Notes on this map

  • Values are sent without the decimal point (105.0 is sent as 1050). PV, set points and alarm values use the decimal places reported by 2410; MV (x0.1 %) and heater current (x0.1 A) have fixed scaling per the setting ranges.
  • In 2-byte mode 2001 and 2406 return the low 16 bits of the 32-bit status and 2407 the high 16 bits; bit meanings come from the status table on pp. 3-23 to 3-25.
  • Before any write, send operation command 'communications writing ON' (0x0001 to address FFFF). FC06 single writes work only in 2-byte mode; FC16 works in both.
  • The manual states a default unit number of 1 and a default send data wait of 20 ms; default baud rate and parity are only shown as highlighted cells, so they are not listed. With Modbus the data length is fixed at 8 bits, with 1 stop bit for even/odd parity or 2 for none.
  • Left out: the rest of the adjustment, initial-setting and advanced levels (PID, scaling, input type and so on), alarm 3/4 values, valve opening, and program/SP ramp parameters.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Omron E5CC / E5EC / E5AC / E5DC digital temperature controllers (E5_C series)

What Modbus registers does the Omron E5CC / E5EC / E5AC / E5DC digital temperature controllers (E5_C series) have?

This map lists 20 registers: 20 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Omron E5CC / E5EC / E5AC / E5DC digital temperature controllers (E5_C series) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed in hex and sent as-is: the manual's 2-byte example reads PV with 01 03 20 00 00 01. 4-byte mode addresses (0000, 0002, ...) hold the same data as two registers each; only 2-byte mode addresses are listed here.

What are the minimum Modbus registers to integrate the Omron E5CC / E5EC / E5AC / E5DC digital temperature controllers (E5_C series)?

Start with HR 8192 PV (PV); HR 8193 Status (low word) (Status low word (alarms, errors, outputs)); HR 8196 MV monitor (heating) (Heating MV); HR 8451 Set point (Set point); HR 9223 Status (high word) (Status high word (run/stop, auto/manual)); HR 9232 Decimal point monitor (Decimal point); HR 65535 Operation command (Operation command (write enable, RUN/STOP)).

How do I enable Modbus control of the Omron E5CC / E5EC / E5AC / E5DC digital temperature controllers (E5_C series)?

Set Protocol Setting (psel) to Modbus in the communications setting level, set unit number and baud, then cycle power. Writes need 'communications writing ON' via the operation command.
