ABB PSTX softstarter (built-in Modbus RTU) Modbus register map

Updated 17 November 2026

Short answer

ABB's PSTX softstarters have a built-in Modbus RTU slave on their Com3 terminals. Status is read as 16 coils or one status word, ten programmable analog inputs carry measurements such as phase currents, and the motor is started and stopped either through coils or two control words. Parameters are read and written through a 'fieldbus task' handshake register. This map covers every published register.

This page lists 60 Modbus registers for the ABB PSTX softstarter (built-in Modbus RTU) — 32 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ABB’s own free documentation (linked below) and checked against it.

Integration notes: ABB PSTX softstarter (built-in Modbus RTU)

Integration in brief

Set 12.1 Com3 function = Modbus RTU slave and 12.2 FB interface connector = Modbus RTU, then write control word 1 (02FEh) with bit 3 auto mode plus bit 1 stop-permit and bit 0 start, and read the status word (01FFh) and analog inputs 0201h-020Ah with function 04.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set 12.2 FB interface connector = Modbus RTU, 12.3 Fieldbus control = On (Off for monitoring only), 12.9 baud (9600-115200), 12.10 parity, 12.11 stop bits, 12.4 Fieldbus address (1-247) and 12.1 Com3 function = Modbus RTU slave. Power-cycle, or set 12.2 to None and back to Modbus RTU, for changes to apply.

Communication loss & watchdog

If no message passes for longer than the fieldbus failure timeout (19.12) the softstarter trips on fieldbus communication failure (P1E00) and by default stops the motor. Set 19.4 Fieldbus failure op = Off if the master does not poll continuously.

Byte order & addressing

  • Addresses are hex protocol addresses with the Modicon number alongside; use the hex value on the wire.
  • Stop is active-low: bit 1 / coil 0101h must stay set for the motor to keep running.
  • Fault reset, FBT toggle, switch to remote and K4-K6 relay commands work even when auto mode is off.

Network setup

  • Com3 shares terminals 23 and 24 with the DX111/DX112 expansion I/O module, so both cannot be used at once.
  • Supported baud rates: 9600, 19200, 38400, 57600, 76800 and 115200.

Watch out for

  • The motor may start unexpectedly when switching between fieldbus and hardwired control, or after Reset all settings, if a start signal is present.
  • The local/remote switch on the HMI and the 'Fieldbus disable' digital input also decide whether auto mode (Modbus control) is active.

Notes on this map

  • This map follows Rev F (2021), which includes the external relay coils 0118h-011Bh, the 'Refresh parameters' coil 011Ch and the matching control word 2 bits 8-12. Input data is updated every 20 ms.
  • All values are 16-bit; there are no 32-bit registers.
  • The digital input telegram (protocol 0000h-000Fh) is read with function 01 (Read Coil Status), so it is listed as read-only coils; the same bits are in the status word at 01FFh. The analog input block (01FFh-020Ah) can be read with function 03 or 04 and is listed as input registers.
  • The ten analog inputs are programmable (parameters Fieldbus AI 1-10) and are left unscaled. Scaling per function from the manual: phase currents, mains voltage, motor current: 1000 = 100 A or 100 V (0.1); active power 1000 = 10 kW (0.01); power factor 100 = 1; mains frequency 1000 = 100 Hz (0.1); motor voltage and percentages 100 = 100 % (1); active energy 1000 = 10 kWh (0.01); 'high range' variants 100 = 100 A/kW (1).
  • Start/stop can come from coils 0100h/0101h (with auto mode on coil 0103h) or from bits 0/1 of control word 1 (with auto mode in bit 3). If auto mode is set in both places the device ignores start/stop as a configuration error.
  • Parameters are reached only through fieldbus tasks: put the task ID (1 read low word, 2 change value, 3 set clock, 4 read high word) and parameter number in 0300h, any value in 0301h/0302h, then toggle the FBT Toggle Bit; the result is in 0200h once the input toggle bit matches. Error codes: 0 illegal parameter, 1 cannot change, 3 limit violated, 4 invalid argument, 5 no error, 6 invalid task.
  • No factory defaults for address, baud or parity are given in this document; they are in the Installation and commissioning manual 1SFC132081M0201.

Questions about the ABB PSTX softstarter (built-in Modbus RTU)

What Modbus registers does the ABB PSTX softstarter (built-in Modbus RTU) have?

This map lists 60 registers: 43 coils, 12 input registers, 5 holding registers. 32 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB PSTX softstarter (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each table gives both the protocol address in hex (sent on the wire) and the Modicon address: protocol 01FFh = Modicon 30512, 02FEh = 40767, coil 0100h = 00257. The manual explains the translation itself (Modicon 40002 -> protocol 0001), and its example frames send 0000h, 0100h, 0201h and 0300h directly.

What are the minimum Modbus registers to integrate the ABB PSTX softstarter (built-in Modbus RTU)?

Start with HR 766 Control word 1 (Control word 1: start/stop/reset/auto mode); IR 511 Status word (Status word: auto mode, event, ready to start); IR 513 Programmable analog input 1 (Analog input 1 (default phase L1 current)); IR 514 Programmable analog input 2 (Analog input 2 (default phase L2 current)); CO 1 Event status (Event status (fault/warning/protection)); HR 768 FBT Control Word (FBT control word for parameter access).

How do I enable Modbus control of the ABB PSTX softstarter (built-in Modbus RTU)?

Set 12.2 FB interface connector = Modbus RTU, 12.3 Fieldbus control = On (Off for monitoring only), 12.9 baud (9600-115200), 12.10 parity, 12.11 stop bits, 12.4 Fieldbus address (1-247) and 12.1 Com3 function = Modbus RTU slave. Power-cycle, or set 12.2 to None and back to Modbus RTU, for changes to apply.

What happens when the ABB PSTX softstarter (built-in Modbus RTU) loses Modbus communication?

If no message passes for longer than the fieldbus failure timeout (19.12) the softstarter trips on fieldbus communication failure (P1E00) and by default stops the motor. Set 19.4 Fieldbus failure op = Off if the master does not poll continuously.
