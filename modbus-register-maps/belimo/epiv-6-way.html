Belimo 6-way EPIV Modbus RTU (EP..R-R6+BAC) Modbus register map

Updated 28 October 2026

Short answer

Belimo's 6-way EPIV serves two circuits (sequence 1 and sequence 2) through one valve and controls the flow in each with its own flow sensor. Over Modbus RTU one setpoint register covers both sequences (0-33 % and 67-100 %, with a closed dead band in between); the map also gives position, flow in three units, the active sequence, Vmax per sequence and fault flags.

This page lists 25 Modbus registers for the Belimo 6-way EPIV Modbus RTU (EP..R-R6+BAC) — 7 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Belimo’s own free documentation (linked below) and checked against it.

Integration notes: Belimo 6-way EPIV Modbus RTU (EP..R-R6+BAC)

Integration in brief

Set the address (factory 10) and frame with the Belimo Assistant app, write Setpoint source No. 119 = 1 (Bus), then write No. 1: 0-33 % runs sequence 1, 67-100 % sequence 2, 34-66 % closes. Poll No. 17 (active sequence), No. 7/10 (flow) and No. 105 (faults).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Configure address and frame with the Belimo Assistant app, then write No. 119 = 1 so the valve follows the bus setpoint (factory setting is Analog).

Byte order & addressing

  • Register No. is 1-based; subtract 1 for the wire address.
  • Factory slave address is 10.
  • One setpoint drives both sequences; 33 % and 67 % are both zero flow.

Network setup

  • Default frame 1-8-N-2 at 38400 baud.
  • No built-in terminator: fit an external 120 ohm resistor at the bus ends.

Watch out for

  • While air bubbles are detected the valve stays in position control whatever Control mode says (bit 5 of No. 105).

Notes on this map

  • 32-bit values occupy two registers with the low word first (Belimo's worked example: No. 10 = 14551, No. 11 = 19 gives 19 x 65536 + 14551 = 1,259,735), so they are UINT32 with CDAB word order. Write a 32-bit pair with one FC 16 request covering only those two registers.
  • Belimo states all values are unsigned 16-bit integers; unsupported registers read 65535. Writable registers from No. 101 up are persistent.
  • The factory Modbus address of this valve is 10, not 1.
  • The flow-setpoint pair (No. 14/15) is read-only in the description table even though the overview's access column is hard to read; it is listed as read-only.
  • This edition has no bus watchdog or bus-fail registers, and the bus terminator must be fitted externally (120 ohm).
  • Registers 3, 108-110 are unused and not listed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Belimo 6-way EPIV Modbus RTU (EP..R-R6+BAC)

What Modbus registers does the Belimo 6-way EPIV Modbus RTU (EP..R-R6+BAC) have?

This map lists 25 registers: 25 holding registers. 7 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Belimo 6-way EPIV Modbus RTU (EP..R-R6+BAC) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Belimo prints each register twice: 'No.' counts from 1 and 'Address' from 0, and the documented value here is the No. column. Register No. 1 (setpoint) is wire address 0. Every value sits in one flat table, so holding-register reads (FC 3) and writes (FC 6/16) reach everything; FC 4 input-register reads of the same addresses also work.

What byte order does the Belimo 6-way EPIV Modbus RTU (EP..R-R6+BAC) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Belimo 6-way EPIV Modbus RTU (EP..R-R6+BAC)?

Start with HR 118 Setpoint source (Setpoint source = Bus (default Analog)); HR 0 Setpoint (Setpoint across both sequences); HR 16 Active sequence (Active sequence); HR 9 Absolute volumetric flow (l/h) (Flow l/h); HR 4 Relative position (Relative position); HR 104 Malfunction and service information (Fault flags).

How do I enable Modbus control of the Belimo 6-way EPIV Modbus RTU (EP..R-R6+BAC)?

Configure address and frame with the Belimo Assistant app, then write No. 119 = 1 so the valve follows the bus setpoint (factory setting is Analog).
