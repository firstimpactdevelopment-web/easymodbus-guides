Updated 17 November 2026

Short answer

The KNSLM is the boiler control named in this Mestek register list for the KN2, KN4 and rAy series; one connected (master) boiler can report on up to 15 member boilers. Over Modbus a BMS sets heat demand, system and outdoor-reset setpoints and the clock through holding registers, and reads header, supply, return and outdoor temperatures plus per-boiler status flags, runtimes, cycle counts and modulation through input registers.

This page lists 192 Modbus registers for the Mestek KNSLM boiler control (KN2 / KN4 / rAy series) — 17 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Mestek’s own free documentation (linked below) and checked against it.

Integration notes: Mestek KNSLM boiler control (KN2 / KN4 / rAy series)

Integration in brief

Write the system setpoint (40003) and heat demand (40001), and keep reloading the setpoint timer (40002) so the boiler does not fall back to its local setpoint. Poll input registers 30001-30006 for system temperatures and the boiler status blocks for alarms.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Not described in this register list; set up Modbus in the boiler control as per the boiler manual.

Communication loss & watchdog

Setpoint timer 40002: if it counts down to zero the control assumes the BMS has failed and reloads its saved local setpoint. Writing any read/write register reloads it to 60 s if it is below 60 (firmware 2.70+; older firmware only on a setpoint write).

Byte order & addressing

  • Writing the clock is a two-step operation: load 40010-40016, then write 1 to 40017.

Watch out for

  • Temperatures are in °F with 0.01 resolution for the system sensors but whole °F for setpoints and DHW values.

Notes on this map

  • The register list is a Mestek, Inc. document; it names no other brand. No public copy on a Mestek site was found; the link is an unaltered copy hosted by a gateway supplier.
  • Runtime and cycle counters are two 16-bit registers, high word first: value = high x 65536 + low (ABCD).
  • Several registers hold 8-bit or 1-bit values in a 16-bit register; they are listed as UINT16.
  • Unsigned 8-bit values (setpoints, clock fields) are listed as UINT16; the list does not say which byte of the register holds them.
  • Left out: the system modulation at 30002 (listed as 8-bit with scale 0.01 but range 0-100 %, which do not agree) and the low outdoor air temperature setpoint 40009 (8-bit signed; how it sits in the 16-bit register is not stated).
  • Boiler 01 is the master (connected) boiler; boilers 02-16 are cascade members 01-15.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Mestek KNSLM boiler control (KN2 / KN4 / rAy series)

What Modbus registers does the Mestek KNSLM boiler control (KN2 / KN4 / rAy series) have?

This map lists 192 registers: 175 input registers, 17 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Mestek KNSLM boiler control (KN2 / KN4 / rAy series) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are listed in Modicon form (40001 holding, 30001 input). Request 40001 as holding address 0 and 30001 as input address 0.

What byte order does the Mestek KNSLM boiler control (KN2 / KN4 / rAy series) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Mestek KNSLM boiler control (KN2 / KN4 / rAy series)?

Start with HR 0 Heat demand (Heat demand); HR 1 Setpoint timer (Setpoint failsafe timer); HR 2 System setpoint (System setpoint); IR 2 Header / system temperature (Header temperature); IR 3 Supply temperature (Supply temperature); IR 4 Return temperature (Return temperature); IR 16 Boiler 01 status 2 (Master boiler status 2 (alarm / failed / running)); IR 239 Operating setpoint (Active operating setpoint).

How do I enable Modbus control of the Mestek KNSLM boiler control (KN2 / KN4 / rAy series)?

Not described in this register list; set up Modbus in the boiler control as per the boiler manual.

What happens when the Mestek KNSLM boiler control (KN2 / KN4 / rAy series) loses Modbus communication?

Setpoint timer 40002: if it counts down to zero the control assumes the BMS has failed and reloads its saved local setpoint. Writing any read/write register reloads it to 60 s if it is below 60 (firmware 2.70+; older firmware only on a setpoint write).

Where is the official Mestek KNSLM boiler control (KN2 / KN4 / rAy series) Modbus documentation?

The source is KNSLM (KN2/KN4/rAy) Series Boiler - Modbus Registers (V1.10). Mestek doesn't publish it on its own website, so this map was re-typed from a free copy at https://www.ccontrols.com/support/dp/KNSLM.pdf. It may be an older revision, so check it against the live unit.
