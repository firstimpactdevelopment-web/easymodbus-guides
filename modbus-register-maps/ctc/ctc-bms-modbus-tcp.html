CTC CTC heat pumps and controllers via BMS (Modbus TCP) Modbus register map

Updated 19 November 2026

Short answer

CTC's heat pumps and system controllers expose a BMS register list over Modbus TCP from the display's Ethernet port. Everything is a 16-bit holding register: a 1000-block of control values the BMS must refresh, settings from 61500 (hot water, heating circuits 1-4, curves, cooling, pool, solar, add-on heat), and read-only values from 62000 (temperatures, heat pump status, pressures, compressor speed, energy and smart-grid state). Each setting has companion registers holding its max, min and step.

This page lists 340 Modbus registers for the CTC CTC heat pumps and controllers via BMS (Modbus TCP) — 208 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from CTC’s own free documentation (linked below) and checked against it.

Integration notes: CTC CTC heat pumps and controllers via BMS (Modbus TCP)

Integration in brief

Define 'Modbus TCP' under Installer/Define/Remote control on a three-port display, then read 62000-62365 with function 3 and write the 1000-block (refreshed at least every 5 minutes) with function 16. Use the 615xx settings sparingly.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

In the display menu Installer > Define > Remote control, define 'Modbus TCP' (connection through the display's Ethernet port). Only displays with three connection ports support BMS over TCP/IP.

Communication loss & watchdog

The 1000-block control registers must be rewritten within 5 minutes or they are reset; they are also reset on restart.

Byte order & addressing

  • Base address must be set to 0 in the master; registers are above 49999.
  • Read with function 3, write with function 16; at most 100 registers per transfer.
  • Read 65133 before reading alarm/info buffers, because the read fills them.

Network setup

  • Connect the BMS to the display's Ethernet port; the document recommends testing with QModMaster.

Watch out for

  • The 615xx-617xx settings are stored with a limited number of write cycles; frequent writes can damage the controller. Use the 1000-block for values that change often.
  • SmartGrid priority is remote control (BMS/contact) first, then myUplink, week schedule, then the setting.

Notes on this map

  • Data type follows the 'Signed' column: 1 = INT16, 0 = UINT16. Scale is the 'Factor' column. Units are not printed in the list; °C is given here only where the row text names a temperature or °C, and other units only where the row text names them.
  • The 1000-block (p. 23) has no factor or signed column. Only rows with printed codes are included (1005, 1007, 1015-1019, 1022, 1100). The setpoint, RPS and immersion-heater limit rows (1000-1004, 1006, 1008-1014, 1020, 1021, 1023-1033) are left out because their scaling is not stated; 1003/1004 are also printed with upper and lower tank swapped between the table and the text on p. 16.
  • Cascades of up to 10 heat pumps (A1-A10) repeat each heat pump value in consecutive registers. Only heat pump A1 is listed: for A2-A10 add 1-9 to the A1 register (e.g. A1 status 62017, A2 62018 ... A10 62026; blocked flags 61521-61530; max RPS 61572-61581). The same holds for the compressor 32-bit counters, which step by 2 (62214, 62216 ... 62232 and 62341, 62343 ... 62359).
  • 32-bit counters are printed as two rows, the LSB word first and the MSB word ('<< 16') in the next register, so they are listed as UINT32 with low word first (CDAB). The immersion heater kWh counter is split differently: low word 62191, high word 62329.
  • Each 615xx-617xx setting has read-only companion registers in the 600xx range holding its max, min and step (quoted in the description), and a visibility bit (column 'Visible' register and 'Bit') showing whether the parameter is active for the installed product.
  • Which product supports each row is marked per model in the source table; check it before relying on a register. Rows with no function text (61627, 61628, 62285-62287) are left out.
  • Alarm and information texts: read 65133 first (high byte = number of info texts, low byte = number of alarms), then 65010-65059 (alarm pairs: HP flag, alarm code) and 65060-65069 (info pairs). These buffer registers are described but not listed here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the CTC CTC heat pumps and controllers via BMS (Modbus TCP)

What Modbus registers does the CTC CTC heat pumps and controllers via BMS (Modbus TCP) have?

This map lists 340 registers: 340 holding registers. 208 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the CTC CTC heat pumps and controllers via BMS (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The document says the base address is always 0 ('Offset: 0'), so the printed register number is the wire address: 61502 is requested as 61502 and 1000 as 1000. All registers are above standard Modbus numbering (larger than 49999) except the 1000/1100 control block.

What byte order does the CTC CTC heat pumps and controllers via BMS (Modbus TCP) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the CTC CTC heat pumps and controllers via BMS (Modbus TCP)?

Start with HR 62000 Outdoor temperature (Outdoor temperature); HR 62003 Hot water temperature (Hot water temperature); HR 62005 Status (System status); HR 62017 Heat pump 1 (A1): Status (Heat pump A1 status); HR 62011 Heating system 1: Primary flow temperature (Heating circuit 1 flow temperature); HR 62193 Heat pump 1 (A1): Current RPS (Compressor speed A1); HR 62301 SGMode (Smart-grid mode); HR 1015 Zone mode HC1 (Zone mode HC1); HR 1100 Virtual digital in (Virtual digital inputs (SmartGrid)); HR 61509 Heating system 1: setting room temp (Room setpoint HC1).

How do I enable Modbus control of the CTC CTC heat pumps and controllers via BMS (Modbus TCP)?

In the display menu Installer > Define > Remote control, define 'Modbus TCP' (connection through the display's Ethernet port). Only displays with three connection ports support BMS over TCP/IP.

What happens when the CTC CTC heat pumps and controllers via BMS (Modbus TCP) loses Modbus communication?

The 1000-block control registers must be rewritten within 5 minutes or they are reset; they are also reset on restart.
