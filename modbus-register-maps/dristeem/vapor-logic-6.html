DriSteem Vapor-logic 6 humidifier controller (Modbus RTU) Modbus register map

Short answer

Vapor-logic 6 is the DriSteem controller used on its steam humidifiers (electric, GTS gas, XT electrode, STS/LTS steam-to-steam), HPS/LMH high-pressure systems and WM wetted-media units. Modbus RTU is standard on terminal P7. The map gives 16-bit input registers for humidity, dew point, demand, output and temperatures, holding registers for run mode, set points, fieldbus demand and PID, discrete inputs for safety switches, and coils for every alarm and message flag.

This page lists 136 Modbus registers for the DriSteem Vapor-logic 6 humidifier controller (Modbus RTU) — 83 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from DriSteem’s own free documentation (linked below) and checked against it.

Integration notes: DriSteem Vapor-logic 6 humidifier controller (Modbus RTU)

Integration in brief

Enable Modbus in the Communications setup, wire RS-485 to P7, and poll input registers 0-10 for humidity, demand and output. To command the unit, set Control via Modbus and write RunMode (40001) and either a set point (40002) or fieldbus demand (40006).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Setup menu > Communications > Modbus: Modbus enabled = Yes, set address (default 99) and baud rate (default 9600). For demand over Modbus, Setup > Demand signal > Control via Modbus = Yes.

Byte order & addressing

  • Printed numbers are Modicon-style (30001, 40001, 10001, coil 1): subtract one for the wire address.
  • Units switch between I-P and SI with the unit setting; there are no decimal places.

Network setup

  • Connect RS-485 to terminal P7 on the Vapor-logic board (+ to +, - to -).
  • Set the Modbus address and baud rate in Setup > Communications, then cycle power.

Watch out for

  • Several point numbers mean different things on GTS, XT, HPS, LMH and WM units; check which family you have.
  • Numbers are not continuous (no IR 12-22 or 24, no HR 11-13 or 16); DV-65, DV-67, DI-8, DI-9 and DI-15 are on the last table page.

Notes on this map

  • The PDF sits on the CloudFront host that holds DriSteem public documents (path public-documents/docs/iom/vapor-logic); the document itself is the DriSteem IOM (Research Products Corporation copyright).
  • Note 1 of the table says all input and holding registers are 16-bit and all discrete inputs and coils single bits; no scale factor is printed, so values are whole numbers in the units shown, except WaterUntilADS / WaterUntilService where the table gives 100 lbs (or kg) per Modbus count.
  • Units follow the controller's I-P or SI setting (°F/°C, lbs/hr / kg/h, psi/bar). Temperatures are typed INT16 because the ranges go below zero; the manual does not state signedness.
  • Mass values (steam demand/output, up to 100,000) are listed as single 16-bit registers in the source; readings above 65,535 cannot be represented.
  • WaterUntilADS and WaterUntilService are input registers but the table marks them RW; input registers cannot be written over Modbus, so they are listed read-only here.
  • RunMode (40001) and MTRunMode (40014) have separate read and write meanings; reads of RunMode can also return 5 (Test outputs) and 6 (Test run).
  • Many points apply only to one product family, marked in brackets: GTS (gas), XT (electrode), HPS/LMH (high-pressure), WM (wetted media), XV/STS (steam-to-steam). Shared numbers carry different meanings per family.
  • Alarm and message coils are marked RW in the source; alarm meanings are in the manual's Alarms menu tables (pp. 49-50) and messages in the Diagnostics menu table (p. 46).
  • Serial framing (parity, data and stop bits) is not stated in the manual.
  • Note 1 of the table gives DI1-DI7 and DV1-DV69 as the ranges, but the table itself also lists DI-8 to DI-17 and DV-70; those rows are included as printed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the DriSteem Vapor-logic 6 humidifier controller (Modbus RTU)

What Modbus registers does the DriSteem Vapor-logic 6 humidifier controller (Modbus RTU) have?

This map lists 136 registers: 70 coils, 17 discrete inputs, 32 input registers, 17 holding registers. 83 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the DriSteem Vapor-logic 6 humidifier controller (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table prints each point twice, e.g. IR-1 / 30001, HR-1 / 40001, DI-1 / 10001 and coil DV-1 / 1. These are one-based Modicon numbers: input register 30001 is wire address 0 and coil 1 is wire address 0.

What are the minimum Modbus registers to integrate the DriSteem Vapor-logic 6 humidifier controller (Modbus RTU)?

Start with IR 0 SpaceRH (Space RH); IR 8 SteamOutputPercent (Steam output %); IR 4 SteamDemandPercent (Steam demand %); HR 0 RunMode (Run mode); HR 1 SpaceRHSetPoint (Space RH set point); HR 5 FieldbusDemandPcnt (Fieldbus demand %); CO 2 ActiveManualClearAlarmsExist (Manual-clear alarm exists); CO 3 ClearAllActiveAlarms (Clear all alarms).

How do I enable Modbus control of the DriSteem Vapor-logic 6 humidifier controller (Modbus RTU)?

Setup menu > Communications > Modbus: Modbus enabled = Yes, set address (default 99) and baud rate (default 9600). For demand over Modbus, Setup > Demand signal > Control via Modbus = Yes.
