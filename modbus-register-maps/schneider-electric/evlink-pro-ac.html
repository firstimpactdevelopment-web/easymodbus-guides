Integration notes: Schneider Electric EVlink Pro AC charging station (Modbus TCP)

Integration in brief

Connect over Modbus TCP to unit ID 255. Write the current limit in amps to 4004 and keep the lifebit at 4000 cycling so the charger knows the master is alive; read 1 and 150 for state and 4012 for session energy.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The degraded (fallback) setpoints are configured with the eSetup tool. The guide does not say how Modbus is switched on or where the communication timeout is set.

Communication loss & watchdog

With the lifebit active (charger writes 1, master resets it to 0), Modbus counts as lost if the master does not refresh it within the configured communication timeout; the charger then limits to the fallback current in 4005 (single-phase) or 4006 (three-phase). Writing 2 to 4000 deactivates the lifebit.

Byte order & addressing

  • 4004 reads 99 until a Modbus master has written a setpoint since start-up.
  • A setpoint change can take up to 15 s to take effect.

Network setup

  • Use unit (server) ID 255.
  • Addresses are 0-based (the table is on base 0).

Watch out for

  • Firmware older than software 1.2.1 (guide revision 02) has addresses 1211-1213 and 4003-4011 one lower.
  • The lifetime energy counters (3203/3219) are int64 with an unstated word layout, so they are not in this map.

Notes on this map

  • Word order: the guide's data-format table defines UINT32 as U32-4321 (high word in the first register), so the uint32 registers are mapped high word first (ABCD).
  • Left out: the per-phase float32 measurements at 2999-3109 (currents, voltages, active/reactive/apparent power, power factor, frequency). The format table defines both IEEEFloat (F32-4321, high word first) and SwappedFloat (F32-2143) but never says which one the register table's float32 means, so the word order is not stated.
  • Left out: Energy Active TOT (3203, Wh) and Energy Reactive TOT (3219, kVARh). They are typed int64, and the format table defines two 64-bit layouts (S64-87-21 and S64-21-87) without saying which one int64 means.
  • The guide's text says the fallback currents are set by writing 4005 and 4006, but the register table marks both read-only and says they are configured in eSetup. They are kept read-only here.
  • Revision 02 of the guide (March 2023, software 1.2.1) moved addresses 1211-1213 and 4003-4011 up by one; older firmware may still use the old numbers.
  • The register page says reading an address not in the table returns Illegal data address, while the revision history (revision 04) says reads inside the reserved ranges 2999-3222 and 4000-4079 return 0xFFFF.
  • Error codes 1.1 to 19.0 and their OCPP equivalents are listed on printed pp. 15-16; the bitfields at 4020/4022 flag the active ones (bit assignment not given).
  • All values are refreshed once per second.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Schneider Electric EVlink Pro AC charging station (Modbus TCP)

What Modbus registers does the Schneider Electric EVlink Pro AC charging station (Modbus TCP) have?

This map lists 32 registers: 32 holding registers. 3 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Schneider Electric EVlink Pro AC charging station (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide says the register table is on base 0, so the printed address goes on the wire unchanged: the current setpoint at 4004 is requested at address 4004.

What byte order does the Schneider Electric EVlink Pro AC charging station (Modbus TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Schneider Electric EVlink Pro AC charging station (Modbus TCP)?

Start with HR 4004 Set Point (Charging current setpoint); HR 4000 Lifebit (Lifebit heartbeat); HR 1 EV state (Pilot (EV) state); HR 150 OCPP status (OCPP status); HR 4012 Session energy (Session energy); HR 4001 Set command (Remote commands (stop, suspend, restart)).

How do I enable Modbus control of the Schneider Electric EVlink Pro AC charging station (Modbus TCP)?

The degraded (fallback) setpoints are configured with the eSetup tool. The guide does not say how Modbus is switched on or where the communication timeout is set.

What happens when the Schneider Electric EVlink Pro AC charging station (Modbus TCP) loses Modbus communication?

With the lifebit active (charger writes 1, master resets it to 0), Modbus counts as lost if the master does not refresh it within the configured communication timeout; the charger then limits to the fallback current in 4005 (single-phase) or 4006 (three-phase). Writing 2 to 4000 deactivates the lifebit.
