Short answer

NORD's SK 540E/545E inverters answer Modbus RTU on the same RS485 interface as USS, switching protocol automatically. Every parameter is reached at (parameter number x 64 + array index), so the hidden process-data arrays P050 (control word and setpoints) and P051 (status word and actual values) give the cyclic control block. This map covers that process data and the bus setup parameters.

Integration notes: NORD Drivesystems SK 540E / SK 545E frequency inverter (built-in Modbus RTU)

Integration in brief

Set P509 = 2 and P510[-01] = 2, P512 to 1 or 3-30, P511 to 38400 or less, then write 0x047E and next 0x047F to P050[-01] (0x0C80) with setpoint 1 at 0x0C81 (16384 = P105). Poll 0x0CC0-0x0CC3 for status word and actual values.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set P509 = 2 (USS control word; Modbus is detected automatically on SK 540E+) and P510[-01] = 2 for the setpoint. Set P512 to 1 or 3-30 (factory 0 is the broadcast address, and address 2 must not be used: it stops the automatic switch to Modbus) and P511 baud (Modbus max 38400). The format is fixed at 8 data bits, even parity, 1 stop bit.

Communication loss & watchdog

P513 telegram downtime: monitoring starts with the first valid telegram; if no new telegram arrives in time the inverter trips with E010 (error 10.0 Bus Time Out). 0.0 = off (factory); -0.1 = no error even if communication is lost.

Byte order & addressing

  • Addresses are parameter x 64 + index, not the parameter number: P509 = 32576.
  • Control word follows the USS/PROFIdrive pattern: 0x047E = ready for switch-on, then set bit 0 (0x047F) to run; bit 10 must be 1 or the process data is ignored.
  • Address 2 disables Modbus (the port stays USS).

Network setup

  • Connect RS485 on terminals X7:73/74 (SK 520E and above) or the RJ12 socket X11; switch on the termination with DIP 1 at the bus ends.
  • Up to 32 devices per RS485 segment; RS232 only for point-to-point.

Watch out for

  • Baud rates above 38400 exist in P511 but are not valid for Modbus.
  • If a digital input is set for fault acknowledge, do not hold control-word bit 7 at 1 from the bus, or the edge detection stops working.

Notes on this map

  • This manual offers Modbus RTU only on SK 540E and SK 545E; the other series it covers (SK 300E, rest of SK 500E, SK 700E/750E) use USS on this interface.
  • Each 16-bit parameter is one address; read normally takes one parameter per request, except P050/P051 whose four elements can be read or written together. 32-bit parameters must be written with function 16; the manual's example writes P613 = 0x00123456 as 00 12 then 34 56, i.e. high word first.
  • Setpoints and actual values are relative: 16384 (0x4000) = 100 %, 0xC000 = -100 %, range about +/-200 %; setpoint 100 % = P105 maximum frequency of the active parameter set. They are kept raw.
  • Bus I/O coils 0x0000-0x0007 (Bus IO In 1-8, R/W) and 0x0008-0x000F (Bus IO Out 1-8, R) work only when P480/P481 assign them and P509/P510 are set to control terminals; they are not listed.
  • Left out: P513 telegram timeout (the manual gives 0.1 s steps on the keypad but no bus scaling), P543-P548 function lists, and fault parameters P700/P701 (array format not described in this manual).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the NORD Drivesystems SK 540E / SK 545E frequency inverter (built-in Modbus RTU)

What Modbus registers does the NORD Drivesystems SK 540E / SK 545E frequency inverter (built-in Modbus RTU) have?

This map lists 12 registers: 12 holding registers. 8 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the NORD Drivesystems SK 540E / SK 545E frequency inverter (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The start address is the parameter number in bits 6-15 and the array index (or parameter set) in bits 0-5, sent as-is: P102 parameter set 1 = 0x1980, set 2 = 0x1981; P510 array element 2 = 0x7F81. The manual's examples read P051 from 0x0CC0 (status word + 3 actual values) and write setpoints 1-3 from 0x0C81. Registers here use index 0 (first element / parameter set 1).

What are the minimum Modbus registers to integrate the NORD Drivesystems SK 540E / SK 545E frequency inverter (built-in Modbus RTU)?

Start with HR 3200 Process data IN: control word (STW) (Control word STW); HR 3201 Process data IN: setpoint 1 (Setpoint 1 (16384 = 100 %)); HR 3264 Process data OUT: status word (ZSW) (Status word ZSW); HR 3265 Process data OUT: actual value 1 (Actual value 1 (frequency %)); HR 32576 P509 Control word source (P509 control word source); HR 32768 P512 USS / Modbus address (P512 bus address).
