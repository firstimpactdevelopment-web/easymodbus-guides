Short answer

The PRO380-Eichrecht is inepro's German calibration-law (Eichrecht) version of the PRO380, built into AC EV chargers. It has two RS485 Modbus RTU ports: RS485-1 for full access and RS485-2 as a read-only secondary. All registers are holding registers at hex addresses; live values are FLOAT32 in V, A, W, var and VA, and energy counters are INT32 in Wh by default. This map has its own register set and differs from the PRO380-Mod map.

This page lists 149 Modbus registers for the inepro Metering PRO380-Eichrecht three-phase energy meter — 17 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from inepro Metering’s own free documentation (linked below) and checked against it.

Integration notes: inepro Metering PRO380-Eichrecht three-phase energy meter

Integration in brief

Connect to RS485-1 (terminals 22/23), poll unit 1 at 9600 baud, even parity with function 03. Read live values as ABCD floats from 5000h and energy as big-endian INT32 Wh from 6000h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step is described. Settings (ID, baud, parity, energy data type, combination code) can be written over Modbus or with inepro's EichrechtMeterConfig tool.

Byte order & addressing

  • Addresses are hex: 0x5012 is decimal 20498.
  • Power is in W/var/VA here, unlike the PRO380-Mod which reports kW.
  • Energy is INT32 Wh by default; setting 4026h = 0 switches to FLOAT32 kWh, which keeps only about 6 significant digits.
  • Baud rate is written as a code (6 = 9600), not as the number.

Network setup

  • RS485-1 A/B on terminals 22/23 is the primary port; RS485-2 on 24/25 is read-only.
  • Defaults: Modbus ID 1, 9600 baud, even parity.
  • The optical port uses fixed settings: 4800 baud, even parity, ID 1.

Watch out for

  • Forward and reverse counters are always positive; the combination code only affects the total counters, not power.

Notes on this map

  • Energy data type (configurator section): default INT32, big-endian 32-bit integers in 1 Wh units over two holding registers; the alternative FLOAT32 is 'float ABCD' in kWh. Switch with 4026h (0 = FLOAT32, 1 = INT32). The energy rows here assume the default INT32.
  • Word order for the FLOAT32 live values is taken from the manual's description of its FLOAT32 type as 'float ABCD' (high word first).
  • The map prints the unit 'var' for reactive energy counters 6024h-6046h; they are energy counters and are listed here as varh, as on the quadrant rows (6063h on).
  • Left out: serial number and product id (packed BCD), meter code (marked TODO in the manual), phase direction (ASCII), CT ratio and S0 output rate (marked not used), checksums and active status word, LCD custom fields, the waveform sample buffer (47FDh-4800h) and the blocking 'update wait' register 4081h.
  • Two power-peak registers (5064h and 5066h) are both named 'Previous Forward Active Power Peak' in the source; 5066h is most likely the reverse one, but the name is copied as printed.
  • The RS485 spec lists baud rates 1200-115200, address range 0-247 and up to 31 meters per bus.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the inepro Metering PRO380-Eichrecht three-phase energy meter

What Modbus registers does the inepro Metering PRO380-Eichrecht three-phase energy meter have?

This map lists 149 registers: 149 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the inepro Metering PRO380-Eichrecht three-phase energy meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map is headed 'Holding register address (hex)'. The hex value goes on the wire unchanged, so 0x5012 (total active power) is decimal 20498, read with function 03.

What byte order does the inepro Metering PRO380-Eichrecht three-phase energy meter use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the inepro Metering PRO380-Eichrecht three-phase energy meter?

Start with HR 20482 Voltage L1 (Voltage L1); HR 20492 Current L1 (Current L1); HR 20498 Total Active Power (Total active power (W)); HR 20522 Power Factor (Power factor); HR 20488 Grid Frequency (Grid frequency); HR 24588 Forward Active Energy (Forward (import) active energy); HR 24600 Reverse Active Energy (Reverse (export) active energy); HR 16405 Error code (Error bitfield).

How do I enable Modbus control of the inepro Metering PRO380-Eichrecht three-phase energy meter?

No enable step is described. Settings (ID, baud, parity, energy data type, combination code) can be written over Modbus or with inepro's EichrechtMeterConfig tool.
