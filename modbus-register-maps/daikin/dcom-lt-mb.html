Daikin DCOM-LT/MB Modbus interface for Daikin Altherma LT heat pumps Modbus register map

Updated 29 October 2026

Short answer

The DCOM-LT/MB is a small DIN-rail interface that sits on the Altherma P1P2 user-interface bus and exposes the heat pump as a Modbus RTU slave. Holding registers carry the commands and setpoints (on/off, mode, leaving water and room setpoints, domestic hot water, quiet mode, weather-curve offsets); input registers report the error state, running flags, temperatures and flow. Every register is one signed 16-bit word, with sensor temperatures in hundredths of a degree.

This page lists 32 Modbus registers for the Daikin DCOM-LT/MB Modbus interface for Daikin Altherma LT heat pumps — 13 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Daikin’s own free documentation (linked below) and checked against it.

Integration notes: Daikin DCOM-LT/MB Modbus interface for Daikin Altherma LT heat pumps

Integration in brief

Wire P1P2 to the Altherma user interface and RS-485 to the master, set the slave address on DIP switches SW1.3-SW1.8, wait for the green status LED, then poll input registers 21-50 with function 04 and write setpoints with function 06 or 16.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No software enable. Choose the operating mode on SW1.1-SW1.2 and the address on SW1.3-SW1.8; the DCOM answers as a Modbus slave once it has synchronised with the Altherma master.

Communication loss & watchdog

If P1P2 communication with the Altherma master fails for 60 seconds the DCOM falls back to waiting for the master; after 3 more minutes it reports Timeout (unit error 1, error code U8). No Modbus-side watchdog is documented.

Byte order & addressing

  • Reads are limited to 64 registers; function 06 for single writes, function 16 for up to 64.
  • Setpoint writes outside the configured range are clamped to the nearest limit; other out-of-range writes are ignored.
  • Sensor temperatures are signed and divided by 100; setpoints are whole degrees.

Network setup

  • Power: regulated 15-24 VDC, at least 80 mA (polarity independent).
  • RS-485 is fixed at 9600 baud, 8 data bits, no parity, 1 stop bit.
  • Connect the RS-485 common terminal C to the other devices' common; termination is not needed at 9600 baud, and if you add it you must add failsafe bias too.
  • Up to 32 devices per segment, bus topology, under 1000 m.

Watch out for

  • With Altherma 2 and EKRUCBL / EKRUHML user interfaces the DCOM works only if no LAN adapter is connected.
  • Values read 32765 until synchronisation finishes; do not treat that as a temperature.

Notes on this map

  • Three special values can come back from any register when read as 16-bit: 32767 = register unsupported, 32766 = not available in the current configuration, 32765 = value not loaded yet. Expect 32765 everywhere while the DCOM synchronises with the Altherma (up to 8 minutes after power-up).
  • The manual types the setpoints and offsets as plain int16 with no scaling, so they are whole degrees; only the sensor temperatures (temp16) are in hundredths.
  • The DCOM can also run in Sequencer mode (used with the DCOM-LT/IO variant) and Smart Grid mode, chosen with DIP switches SW1.1-SW1.2 (SW1.1-SW1.4 in Smart Grid mode). Sequencer mode moves several input registers (for example outside air to 133); those alternative registers are not listed here.
  • Which functions actually work depends on the Altherma model and its user interface; unsupported ones return 32767 or 32766.
  • The unit error code is two ASCII characters packed into one register: high byte = first character, low byte = second (for example 14152 = '7H'). The sub code is a separate number.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the Daikin DCOM-LT/MB Modbus interface for Daikin Altherma LT heat pumps

What Modbus registers does the Daikin DCOM-LT/MB Modbus interface for Daikin Altherma LT heat pumps have?

This map lists 32 registers: 19 input registers, 13 holding registers. 13 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Daikin DCOM-LT/MB Modbus interface for Daikin Altherma LT heat pumps Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual numbers registers by offset with 'Register Base 0', so the printed offset is the wire address. Its own example: holding register 1 = Modicon 40002, input register 20 = Modicon 30021.
