Short answer

The REACT version of the Parasol Zenith comfort module uses a Belimo actuator with a Modbus RTU interface. Over the bus a BMS can set the damper or flow setpoint, force open/close/min/max, run adaption or test, and read position, relative and absolute airflow, sensor input, service flags and the bus-watchdog settings.

This page lists 27 Modbus registers for the Swegon REACT Parasol Zenith with Belimo actuator (Modbus RTU) — 11 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Swegon’s own free documentation (linked below) and checked against it.

Integration notes: Swegon REACT Parasol Zenith with Belimo actuator (Modbus RTU)

Integration in brief

Write the setpoint in 0.01 % to address 0 (with Setpoint Source = Bus) and read relative position (address 4) and relative or absolute flow (addresses 6-7). Use Override Control (address 1) to force open/close and the bus watchdog (addresses 108-109) for a safe position on comms loss.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Setpoint Source (address 118) must be Bus for Modbus setpoints. Bus termination is set with the actuator configuration tools.

Communication loss & watchdog

Bus Fail Position (address 108) and Timeout for Bus Watchdog (address 109, 0-3600 s; 0 = off). If neither setpoint nor override is rewritten within the timeout, the actuator goes to the fail position and sets bit 10 in address 104.

Byte order & addressing

  • Register numbers in the sheet start at 1; send Address = No. - 1.
  • 32-bit flows are low word first.

Network setup

  • External 120 ohm termination at the line ends; No. 100 shows whether the built-in terminator is active.
  • Max 32 nodes without a repeater.

Watch out for

  • Vmax must stay above 20 % and at or above Vmin.

Notes on this map

  • The two 32-bit flow values are split as LowWord (lower 16 bits) at the first register and HighWord at the next, so they are CDAB; scale 0.001 in the unit chosen in No. 118.
  • Registers No. 10, 112, 115 and 116 are unused (dash) and not listed.
  • Absolute position (No. 6) is in degrees or mm depending on the actuator type.
  • Default communication setting 14: 19200 baud, 8 data bits, even parity, 1 stop bit, 0 ms delay; also selectable 9600-115200 baud and 8N2, 8N1, 8E1, 8O1.
  • Bus termination (No. 100) is read-only in the register overview but marked R/W in the description table, which also says it is set with the configuration tools; it is listed here as read-only.
  • The Swedish column on page 5 places the LW/HW labels one row higher than the English text; the English description (No. 113 = lower 16 bits, No. 114 = upper 16 bits) and the overview table are followed here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Swegon REACT Parasol Zenith with Belimo actuator (Modbus RTU)

What Modbus registers does the Swegon REACT Parasol Zenith with Belimo actuator (Modbus RTU) have?

This map lists 27 registers: 27 holding registers. 11 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Swegon REACT Parasol Zenith with Belimo actuator (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Every table gives both a register number (No.) and the protocol Address, with Address = No. - 1 (No. 1 = address 0). The Address column is used here; the 'documented' field shows both.

What byte order does the Swegon REACT Parasol Zenith with Belimo actuator (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Swegon REACT Parasol Zenith with Belimo actuator (Modbus RTU)?

Start with HR 0 Setpoint (Setpoint %); HR 1 Override Control (Override control); HR 4 Relative Position (Relative position); HR 6 Relative volumetric flow (Relative flow); HR 7 Absolute volumetric flow (Absolute flow m³/h); HR 104 Malfunction and Service Information (Malfunction flags); HR 118 Setpoint Source (Setpoint source).

How do I enable Modbus control of the Swegon REACT Parasol Zenith with Belimo actuator (Modbus RTU)?

Setpoint Source (address 118) must be Bus for Modbus setpoints. Bus termination is set with the actuator configuration tools.

What happens when the Swegon REACT Parasol Zenith with Belimo actuator (Modbus RTU) loses Modbus communication?

Bus Fail Position (address 108) and Timeout for Bus Watchdog (address 109, 0-3600 s; 0 = off). If neither setpoint nor override is rewritten within the timeout, the actuator goes to the fail position and sets bit 10 in address 104.
