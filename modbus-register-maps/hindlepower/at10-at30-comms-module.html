Short answer

HindlePower's AT10.1 and AT30 industrial float battery chargers can carry a communications module that speaks Modbus RTU or ASCII (or DNP3) over RS-232/RS-485, with optional Ethernet. Charger modes are coils, alarms are discrete inputs, measurements are input registers and setpoints are holding registers, all 16-bit with a fixed multiplier. This map covers the full published Modbus register set.

Integration notes: HindlePower AT10.1 / AT30 series battery charger with communications module (Modbus)

Integration in brief

Set DIP S1-3 off (Modbus), S1-4 off for RTU (on = ASCII), S1-5 on for RS-485, S1-7 for the baud rate and S2 for the address, press RESET on the A12 board, then poll 30006/30007 for output voltage and current and 10001-10012 for alarms.

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

DIP S1-3 OFF selects Modbus (ON = DNP3); S1-4 OFF = RTU, ON = ASCII; S1-5 ON = RS-485, OFF = RS-232; S1-7 ON = 19200, OFF = 9600; S1-8 enables Ethernet; S1-2 OFF uses factory-default configuration values; S2-1...S2-8 set the address bits b7...b0. Changes take effect after pressing RESET (SW10) on the A12 board or cycling both charger breakers.

Byte order & addressing

  • Values are scaled integers: divide by the multiplier (10 for volts and amps, 100 for revisions).
  • For telephone-modem links the manual recommends Modbus ASCII because RTU timing is tighter.

Network setup

  • Up to 32 chargers per RS-485 segment; 2-wire half-duplex.
  • Advanced settings (DNP3, Ethernet, Modbus TCP) need the setup program over RS-232 at 9600 8N1 with S1-1 ON.

Watch out for

  • Chargers built before 2003 may need a new or reprogrammed main control board (software 3.00+) before the module works.

Notes on this map

  • Scaling: each register has a multiplier; the raw value is divided by it (manual's example: 30006 = 1300 means 130.0 V). Scale = 1 / multiplier.
  • Left out: 30010 Battery temperature (°C, multiplier 1): the manual does not say whether below-zero temperatures are sent as signed values.
  • Modbus RTU settings: 8 data bits with none/even/odd parity (1 or 2 stop bits with no parity); ASCII uses 7 data bits. Baud is 9600 or 19200 (DIP S1-7). The Modbus address is set in binary on DIP S2. The setup program's factory defaults are no parity and 1 stop bit.
  • Modbus over TCP/IP is available with the Ethernet option; it is disabled by default (setup program item 'Enable Modbus over TCP/IP') and its default port is 502. Port 20000 is the default for DNP3 over TCP, not Modbus.
  • Only one equalize method coil can be active; switching one on turns the other two off, and the method cannot be switched off.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the HindlePower AT10.1 / AT30 series battery charger with communications module (Modbus)

What Modbus registers does the HindlePower AT10.1 / AT30 series battery charger with communications module (Modbus) have?

This map lists 33 registers: 6 coils, 12 discrete inputs, 9 input registers, 6 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the HindlePower AT10.1 / AT30 series battery charger with communications module (Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed with Modicon prefixes (00001 coils, 10001 discrete inputs, 30001 input registers, 40001 holding registers) and the implementation follows the Modicon PI-MBUS-300 guide, so 30001 is input register 0 on the wire, 40001 holding register 0, and so on.

What are the minimum Modbus registers to integrate the HindlePower AT10.1 / AT30 series battery charger with communications module (Modbus)?

Start with IR 5 Output voltage (Output voltage, 0.1 V); IR 6 Output current (Output current, 0.1 A); DI 6 CAR (common alarm relay) (Common alarm); DI 3 AC input failure (AC input failure); DI 2 DC output failure (DC output failure); HR 0 Float voltage setpoint (Float voltage setpoint); CO 0 Equalize mode (Equalize / float mode).

How do I enable Modbus control of the HindlePower AT10.1 / AT30 series battery charger with communications module (Modbus)?

DIP S1-3 OFF selects Modbus (ON = DNP3); S1-4 OFF = RTU, ON = ASCII; S1-5 ON = RS-485, OFF = RS-232; S1-7 ON = 19200, OFF = 9600; S1-8 enables Ethernet; S1-2 OFF uses factory-default configuration values; S2-1...S2-8 set the address bits b7...b0. Changes take effect after pressing RESET (SW10) on the A12 board or cycling both charger breakers.
