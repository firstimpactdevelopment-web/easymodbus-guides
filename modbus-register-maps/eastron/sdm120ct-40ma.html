Eastron SDM120CT-40mA Modbus register map

Updated 16 October 2026

Short answer

The SDM120CT-40mA is a single-phase two-wire DIN-rail meter that measures through external current transformers and reports over RS485 Modbus RTU. Readings are IEEE floats in input registers (function 04) covering voltage, current, powers, power factor, frequency, demand and import/export energy. Holding registers (function 03/16) hold the RS485 settings, CT primary, pulse outputs and demand period.

This page lists 31 Modbus registers for the Eastron SDM120CT-40mA — 10 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Eastron’s own free documentation (linked below) and checked against it.

Integration notes: Eastron SDM120CT-40mA

Integration in brief

Read two-register floats with function 04 from 0x0000 (voltage) through 0x0158; import/export kWh are at 0x0048/0x004A. Set the CT primary (40051) to match the installed CTs before trusting current, power and energy.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is always active on the RS485 port. Settings are written with function 16; the front-panel setup mode also sets the address and CT1.

Byte order & addressing

  • Most settings, including baud code and address, are floats spanning two registers; the pulse constant and reset registers are 16-bit hex values.
  • Six-digit register numbers (461457, 463761) map to wire addresses 0xF010 and 0xF910.

Network setup

  • Defaults: address 1, 9600 bps, no parity, 1 stop bit (data bits are not stated in the manual).
  • Baud options are 1200, 2400, 4800 and 9600 bps only.
  • Enter the CT primary current (5-9999 A) in 40051.

Watch out for

  • Current, power and energy are only correct once the CT primary in 40051 matches the installed CTs; this variant takes CTs with a 40 mA secondary.

Notes on this map

  • Word order: the manual states floats are sent big-endian with the high 16 bits in the first register, and its example decodes 43 66 00 00 as 230 V. All floats here are ABCD.
  • Left out: metering mode (printed 463779 but with hex start address F9 20, which corresponds to 463777). The printed number and the hex address disagree, so the register is omitted until confirmed.
  • Left out: scroll display time (463745), stored as BCD, which this schema cannot represent.
  • Left out: serial number (464513), an unsigned 32-bit value with no stated word order.
  • This map is for the SDM120CT-40mA only. The SDM120-M (direct connect) user manual on eastrongroup.com has no register table, so it is not covered here.
  • The front-panel CT1 menu offers fixed primaries (5 to 600 A) while register 40051 accepts 5 to 9999; values outside the menu list have not been checked on a meter.

Questions about the Eastron SDM120CT-40mA

What Modbus registers does the Eastron SDM120CT-40mA have?

This map lists 31 registers: 21 input registers, 10 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Eastron SDM120CT-40mA Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print Modicon numbers (30001, 40003, six-digit 461457...) beside the hex start address used on the wire. Wire address = printed number minus 30001 / 40001 / 400001; the manual's example reads 30001 at start address 0x0000.

What byte order does the Eastron SDM120CT-40mA use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Eastron SDM120CT-40mA?

Start with IR 0 Voltage (Voltage); IR 6 Current (Current); IR 12 Active power (Active power); IR 72 Import active energy (Import kWh); IR 74 Export active energy (Export kWh); HR 50 CT1 (CT primary setting).

How do I enable Modbus control of the Eastron SDM120CT-40mA?

Modbus RTU is always active on the RS485 port. Settings are written with function 16; the front-panel setup mode also sets the address and CT1.
