SmartGen HGM4010N / HGM4020N Modbus register map

Updated 25 October 2026

Short answer

SmartGen's HGM4000N family are compact single-genset controllers: the HGM4010N starts and stops on a remote signal, the HGM4020N adds mains monitoring and automatic transfer (AMF). One RS485 port is a Modbus RTU slave with fixed tables: alarm and status bits as coils (FC01), measurements and counters as holding registers (FC03), and remote keys as single-coil writes (FC05). This map covers the status and alarm coils, mains and generator voltages, currents, powers, engine values, sequence states, counters and the remote start/stop/mode/breaker commands.

This page lists 150 Modbus registers for the SmartGen HGM4010N / HGM4020N — 7 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from SmartGen’s own free documentation (linked below) and checked against it.

Integration notes: SmartGen HGM4010N / HGM4020N

Integration in brief

Wire to RS485 A/B, set the Controller Address, then poll holding registers 0000-0081 with FC03 and coils 0000-0084 with FC01. Remote commands are single FC05 writes of FF00 to coils 0000-0006, the same addresses that read back as status bits.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set a unique Controller Address (1-254, default 1) from the front panel: menu, Parameter Setting, password (default 0318), Controller Address. The setting applies once saved. Parity is none, odd or even (default none); the document gives 9600 bps as the only baud rate.

Byte order & addressing

  • Remote command coils are written with FF00 and each command is sent once only; they act as one-shot key presses, not latched states.
  • Coils 0-6 mean different things for read (FC01) and write (FC05).
  • Only FC01, FC03 and FC05 are supported (no FC06 or FC16); Modbus ASCII is not supported. Read at most 120 registers per request.
  • The one 32-bit value (fuel total at 0068-0069) is low word first (CDAB).

Network setup

  • Default: address 1, 9600 bps, 8 data bits, no parity, 1 stop bit; allow a response timeout of more than 200 ms.
  • Use 120 Ω shielded twisted pair, shield grounded at one end (host side) only; fit 120 Ω terminators at the two ends of the bus.
  • Up to 32 controllers per RS485 segment, about 1000 m at 9600 bps.

Watch out for

  • This controller starts a real engine. Confirm the genset is safe to run and local staff are informed before writing coils 0-6; a write to coil 0 is a start command even though the same address reads as Common Alarm.
  • HGM4020N coils 5/6 are close/open keys and the document does not say how the controller chooses between closing and opening; a write while the breaker is closed may open it and drop the load. Read Gen On-load (coil 7) and Mains On-load (coil 6) first.
  • After a remote stop, check the mode coils 40-43 and send Remote Auto (coil 3) if the set must stay ready for automatic operation.

Notes on this map

  • Coil addresses 0-6 are shared: FC01 reads return status bits, while an FC05 write of FF00 to the same address issues a remote command (start, stop, test, auto, manual, breaker). Each entry names both meanings; the write meaning is in capitals.
  • HGM4010N and HGM4020N differ at command coils 5 and 6: on the HGM4020N they are gen and mains close/open keys, on the HGM4010N gen open and gen close keys.
  • The only 32-bit value (Accum. Fuel Consump., 0068-0069) is low word first: the document's example reads E240h at 0068 and 0001h at 0069 and combines them to 0001E240h (123456). Its result table labels the rows 0103/0104, but the request frame uses start address 0x0044 (68).
  • Left out: mains and gen frequency (0006, 0013). The table prints ratio 0.1 Hz, but the note explaining ratios uses frequency with ratio 0.01 Hz as its worked example, so the scale is contradictory.
  • Left out: oil pressure value (0019), fuel level value (0021), aux. sensor value and resistance (0030-0031) and coolant level (0058), because no ratio is printed for them; the delay values at 0037 and 0039 because neither ratio nor unit is printed; Load Output Percentage (0055) because its range is -100 to 100 but it is marked unsigned; HW version (0051) because no format is given.
  • Run hours, start count and energy are each split into an MSB register (0-9000) and an LSB register (0-9999). The document does not say how the two parts combine, so they are listed separately.
  • Water and ECU temperatures and the powers are documented as unsigned, so negative values cannot be represented as documented.
  • A reading of 32766 means the sensor is open (controller shows ++++); 32767 means the ECU sent no data (####).
  • The controller running status table stops at 14 (Stop Failure); no 'After Stop' state is listed in this document.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Questions about the SmartGen HGM4010N / HGM4020N

What Modbus registers does the SmartGen HGM4010N / HGM4020N have?

This map lists 150 registers: 83 coils, 67 holding registers. 7 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the SmartGen HGM4010N / HGM4020N Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Tables print a decimal 'Modbus Address' (used here as the wire address) next to a 1-based 'PLC Address' (coils 0001.., holding registers 40001..). The document's examples confirm the Modbus Address column is the PDU address: Accum. Fuel Consump. at 0068 is requested with start address 0x0044, and Remote Manual at 0004 is written to coil 0x0004.

What byte order does the SmartGen HGM4010N / HGM4020N use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the SmartGen HGM4010N / HGM4020N?

Start with CO 0 Common Alarm (read) / WRITE = REMOTE START (Common alarm (read) / remote start (write)); CO 41 Auto Mode (Auto mode active); HR 34 Controller Running Status (Genset running state); HR 7 Gen UA (Generator phase A voltage); HR 14 A Phase Current (Phase A current); HR 26 Active Power (Total active power); HR 23 Speed (Engine speed); HR 24 Battery Voltage (Battery voltage).

How do I enable Modbus control of the SmartGen HGM4010N / HGM4020N?

Set a unique Controller Address (1-254, default 1) from the front panel: menu, Parameter Setting, password (default 0318), Controller Address. The setting applies once saved. Parity is none, odd or even (default none); the document gives 9600 bps as the only baud rate.

Where is the official SmartGen HGM4010N / HGM4020N Modbus documentation?

The source is HGM4000N Genset Controller Communication Protocol, revision 2023-04-20 (v1.2), published free by SmartGen at https://www.smartgen.cn/yun/data/download/HGM4000N_Protocol_en.pdf.
