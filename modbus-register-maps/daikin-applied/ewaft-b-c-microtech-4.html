Short answer

Daikin Applied Europe's EWA(F)T-B/C air-cooled inverter chillers run a Microtech 4 controller that acts as a Modbus RTU slave over RS-485, either through a POL902 plug-in module or a licensed on-board software option. Every point is a 16-bit holding register: unit and circuit status, water and refrigerant temperatures and pressures, setpoints, compressor and pump states, free-cooling status and individual alarm flags.

Integration notes: Daikin Applied EWAT-B / EWAFT-B / EWAT-C / EWAFT-C air-cooled inverter chillers (Microtech 4, ARES software)

Integration in brief

Read holding registers from wire address 0: Unit Status (col 15), leaving water temperature (col 17) and capacity (col 13). Enable the unit with col 9 and send the cooling setpoint to col 35 (tenths of °C).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Either fit a POL902 module and set address/parity/stop bits/baud under Main menu > Commissioning > Modbus (service password), or switch on software option #1 'Modbus Slave MSTP' under Commissioning > Configuration > Software Options with its unlock password, then set the parameters under Commissioning > SW Modbus MSTP.

Byte order & addressing

  • Addresses are Modicon-style: subtract 1 from the guide's column value.
  • Gains of 0.1 apply to temperatures, pressures and percentages.

Network setup

  • POL902 module defaults: address 1, no parity, 2 stop bits, 19200 baud, 5 ms response delay; port T2 passive.
  • Software-option defaults: 19200 baud, no parity, 1 stop bit (2StopBits = No), 100 ms delay and response timeout; address varies.

Watch out for

  • Stop-bit defaults differ between the POL902 module (2) and the software option (1).
  • The software option needs an unlock password from Daikin.

Notes on this map

  • Addressing: the guide says every point is a holding register addressed as 4xxxx plus the number in its Address column, i.e. Modicon references (1 = 40001). On the wire that is the column value minus 1. Registers are listed here with that wire address; the documented field keeps the guide's column value.
  • Values are 16-bit words; 'Gain' is the multiplier (0.1 means tenths of a unit). Temperatures and pressures are shown in metric units; the 'Measurement unit setpoint' register (column 316) switches the unit system between English and Metric.
  • The Read/Write column only uses R and W; W points are taken as writable (and readable) and listed as RW. Points marked 'Prio 8' are commanded at priority 8 per the guide.
  • Left out: every 'UNSIGNED DOUBLE' (32-bit) point (74-75 Circ 1 Compressor 1 - Number of Running Hours (32-bit); 87-88 Circ 1 Compressor 2 - Number of Running Hours (32-bit); 100-102 Circ 1 Compressor 3 - Number of Running Hours (32-bit); 113-114 Circ 2 Compressor 1 - Number of Running Hours (32-bit); 126-127 Circ 2 Compressor 2 - Number of Running Hours (32-bit); 139-140 Circ 2 Compressor 3 - Number of Running Hours (32-bit); 165-166 Circ 1 Compressor 4 - Number of Running Hours (32-bit); 204-205 Circ 2 Compressor 4 - Number of Running Hours (32-bit); 260-261 Performance - Unit Thermal Capacity (32-bit); 262-263 Performance - Unit Power Input (32-bit); 266-267 Performance - Unit Thermal Energy (32-bit); 268-268 Performance - Unit Electrical Energy (32-bit); 303-304 Evaporator Pump 1 - Number of Running Hours (32-bit); 306-307 Evaporator Pump 2 - Number of Running Hours (32-bit); 1900-1901 Unit - Active Energy (32-bit)). The guide does not say which word is high, and some address spans are misprinted, so they cannot be decoded safely from this document.
  • Left out: the alarm code/index table in section 5.1; the Warning/Problem/Fault Index and Code registers are listed, but their meanings need that table.
  • Free-cooling registers (columns 250-254) only apply to EWAFT (free-cooling) units.

Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Daikin Applied EWAT-B / EWAFT-B / EWAT-C / EWAFT-C air-cooled inverter chillers (Microtech 4, ARES software)

What Modbus registers does the Daikin Applied EWAT-B / EWAFT-B / EWAT-C / EWAFT-C air-cooled inverter chillers (Microtech 4, ARES software) have?

This map lists 190 registers: 190 holding registers. 31 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Daikin Applied EWAT-B / EWAFT-B / EWAT-C / EWAFT-C air-cooled inverter chillers (Microtech 4, ARES software) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide says each holding register address is 4xxxx plus the Address column value, so column 1 = 40001 = wire address 0. Subtract 1 from the column value for the PDU address; in a Modicon-style tool enter 40000 + column.

What are the minimum Modbus registers to integrate the Daikin Applied EWAT-B / EWAFT-B / EWAT-C / EWAFT-C air-cooled inverter chillers (Microtech 4, ARES software)?
