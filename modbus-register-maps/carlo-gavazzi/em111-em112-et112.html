Carlo Gavazzi EM100 / ET100 series (EM111, EM112, ET112) Modbus register map

Updated 16 October 2026

Short answer

The EM111/EM112 are Carlo Gavazzi's single-phase DIN-rail energy meters, and the ET112 is the bidirectional version for PV and storage. The S1 versions have an RS485 Modbus RTU port; values are 32-bit integers sent low word first with fixed weights, readable with function 03 or 04. This map covers voltage, current, powers, demand, PF, frequency, total/partial/tariff energy, high-resolution energy totals, hour counter, identification, setup, serial settings and resets.

This page lists 48 Modbus registers for the Carlo Gavazzi EM100 / ET100 series (EM111, EM112, ET112) — 18 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Carlo Gavazzi’s own free documentation (linked below) and checked against it.

Integration notes: Carlo Gavazzi EM100 / ET100 series (EM111, EM112, ET112)

Integration in brief

Read input registers 0000h-0023h with function 04 (or 03) in one request; decode INT32 values low word first and apply the fixed weights (V and W x10, A and PF x1000, energy x10).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

S1 versions carry the RS485 Modbus RTU port. Address, baud rate, parity and stop bits are in registers 2000h-2003h (or the instrument's own setup menu, see its manual).

Byte order & addressing

  • INT32 values are low word first (CDAB).
  • Function 06 only for writes; broadcast to address 0 is supported.
  • Measurement mode (1103h) can only be written on non-MID X versions.

Network setup

  • Defaults: address 1, 9600 baud, no parity, 1 stop bit.
  • Terminate the master end with 120 ohm and the last meter by bridging A- to T.
  • Use a repeater for runs longer than 1000 m or more than 160 instruments on one bus.

Watch out for

  • Total energy reset (4001h) is documented for non-MID X versions only.

Notes on this map

  • Word order: the protocol states INT32/UINT32/UINT64 are LSW first with bytes MSB first, so 32-bit values are CDAB.
  • Functions 03 and 04 are equivalent; up to 50 registers per request.
  • Table 2.4-4 (0100h-0189h) mirrors the same values, with PF as INT32; it is not duplicated here.
  • The integer/decimal split totalizers (0400h-040Fh) exist only on EM111/EM112 from firmware b.10, in units made from 1 January 2020 (serial YR2020 001xxxU onward).
  • Registers marked 'not available, value = 0' (tariffs 3-4, negative partials, kVAh, THD) are left out.
  • Left out: the INT64 energy block at 0500h (no value weight given), kWh-per-pulse settings (1020h/1022h, no weight), the ASCII serial-number letters (5000h-5006h), and kWh(-) total integer part (0408h), whose Notes cell is empty in the document, so its weight is not stated (its decimal-part partner 040Ah is printed with a weight and is kept).
  • In measurement mode A (and PFA models) energy always counts as imported; mode B (PFB, ET112) separates kWh(+) and kWh(-) and current/power go negative when exporting.

Questions about the Carlo Gavazzi EM100 / ET100 series (EM111, EM112, ET112)

What Modbus registers does the Carlo Gavazzi EM100 / ET100 series (EM111, EM112, ET112) have?

This map lists 48 registers: 28 input registers, 20 holding registers. 18 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Carlo Gavazzi EM100 / ET100 series (EM111, EM112, ET112) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed as a 6-digit Modicon number for function 04 (3xxxxx; use 4xxxxx for function 03) and as the hex physical address placed in the frame. Wire address = physical address (300001 / 0000h is address 0). Setup rows are written with function 06 and are listed as holding registers; 1010h/1012h are printed with the hex address only.

What byte order does the Carlo Gavazzi EM100 / ET100 series (EM111, EM112, ET112) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Carlo Gavazzi EM100 / ET100 series (EM111, EM112, ET112)?

Start with IR 0 V L-N (Voltage); IR 2 A (Current); IR 4 W (Active power); IR 14 PF (Power factor); IR 16 kWh(+) total (Imported energy); IR 32 kWh(-) total (Exported energy).

How do I enable Modbus control of the Carlo Gavazzi EM100 / ET100 series (EM111, EM112, ET112)?

S1 versions carry the RS485 Modbus RTU port. Address, baud rate, parity and stop bits are in registers 2000h-2003h (or the instrument's own setup menu, see its manual).

Where is the official Carlo Gavazzi EM100 / ET100 series (EM111, EM112, ET112) Modbus documentation?

The source is EM100 Series and ET100 Series Communication Protocol (Version 2 Revision 14), published free by Carlo Gavazzi at https://www.gavazziautomation.com/fileadmin/images/PIM/OTHERSTUFF/COMPRO/EM111_EM112_ET112_CP.pdf.
