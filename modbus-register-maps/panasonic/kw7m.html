Panasonic KW7M Eco-POWER METER Modbus register map

Updated 17 November 2026

Short answer

The KW7M is a small DIN-rail energy meter for single-phase or three-phase three-wire circuits using dedicated or 5 A CTs, with an RS485 port that speaks MEWTOCOL or Modbus RTU. Its Modbus table is short: two phase currents, two line voltages, active power and the metering and alarm settings, all as holding registers.

This page lists 15 Modbus registers for the Panasonic KW7M Eco-POWER METER — 10 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Panasonic’s own free documentation (linked below) and checked against it.

Integration notes: Panasonic KW7M Eco-POWER METER

Integration in brief

Select MODBUS(RTU) in Mode 2 on the front panel, then poll 00B0H (kW x0.01), 006BH/006DH (A x0.1) and 00AAH/00ACH (V x0.1) with function 03. 32-bit values are low word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Protocol defaults to MEWTOCOL. In Mode 2 change Protocol to MODBUS(RTU), then set station number, speed, format and response time.

Byte order & addressing

  • Only 8-bit transmission formats work with Modbus RTU (8bit-o, 8bit-n, 8bit-E); the default 8bit-o is odd parity.
  • Writes outside the allowed range are acknowledged but not applied.

Network setup

  • Defaults: station 1, 19200 bps, 8bit-o, response time 5 ms.
  • Speeds available: 2400, 4800, 9600, 19200, 38400 bps.
  • Broadcast address 0 is accepted but gets no reply.

Watch out for

  • AKW7111B and AKW7111 are not interchangeable; only AKW4x0xB CTs can be used with the AKW7111B.
  • Settings written over Modbus are stored in EEPROM; don't write them in a loop.

Notes on this map

  • Word order: 32-bit rows are printed as two registers marked <LSB> (lower address) and <MSB> (higher address), so the low word comes first (CDAB).
  • Integral active energy (0064H/0065H, 0.01 kWh, read/write, writing 0 resets it) is left out: that row has no LSB/MSB mark, so the manual does not state its word order.
  • Pulse-output unit codes 999, 777 and 333 turn the output into a power, current or stand-by alarm instead of an energy pulse.
  • Registers not listed read 0. Phase/wire system and the communication settings are not in the Modbus table; set them on the front panel.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Panasonic KW7M Eco-POWER METER

What Modbus registers does the Panasonic KW7M Eco-POWER METER have?

This map lists 15 registers: 15 holding registers. 10 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Panasonic KW7M Eco-POWER METER Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are printed in hex (0064H) and go into the request unchanged; the manual's Modbus example resets energy by writing 2 words at data item 0064H. The MEWTOCOL DT number in decimal equals the hex Modbus address.

What byte order does the Panasonic KW7M Eco-POWER METER use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Panasonic KW7M Eco-POWER METER?

Start with HR 176 Instantaneous active power (Instantaneous active power); HR 107 L1 (CT1) phase current (L1 current); HR 109 L2 (CT2) phase current (L2 current); HR 170 Voltage between 1 and 2 (Voltage 1-2); HR 172 Voltage between 2 and 3 (Voltage 2-3).

How do I enable Modbus control of the Panasonic KW7M Eco-POWER METER?

Protocol defaults to MEWTOCOL. In Mode 2 change Protocol to MODBUS(RTU), then set station number, speed, format and response time.

Where is the official Panasonic KW7M Eco-POWER METER Modbus documentation?
