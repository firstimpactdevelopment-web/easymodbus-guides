Short answer

The WIND-series WebMaster is an older Walchem water treatment controller. Its Modbus TCP/IP option serves holding registers on port 502. This map covers the live dynamic values: direct sensor readings and temperatures, 4-20 mA analog inputs and totals, analog outputs and the calculated RSI/LSI indices, all as word-swapped 32-bit floats.

Integration notes: Walchem WebMaster WIND series Modbus TCP/IP option (s825)

Integration in brief

Connect to port 502 with unit ID 1 and read holding registers with FC3, decoding each value as a CDAB float pair. Data refreshes every 4 seconds; do not poll faster than that.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The Modbus TCP/IP option must be fitted; set point writes need software s825v008 or higher.

Byte order & addressing

  • Addresses are 1-based: subtract 1.
  • Floats are word-swapped (CDAB).

Network setup

  • Network settings are configured through the WebMaster browser interface.
  • Read up to 125 registers per request.

Watch out for

  • The controller refreshes Modbus data every 4 seconds; polling faster only returns the same values.
  • An idle TCP connection is closed after 1 minute; up to 10 connections are accepted.

Notes on this map

  • Floats use the 'float inverse' format: the manual shows 0x12345678 transmitted as 0x56 0x78 0x12 0x34, i.e. low word first (CDAB).
  • Left out: digital input states, which the manual describes both as single bits and as 0 = open / 256 = closed, so the encoding is unclear; also relay interlock and volume values on pp. 28-31, whose table layout could not be read reliably.
  • Left out: status, alarm and header/custom-name registers, and all set point writes (pp. 32-80). The write addresses depend on how each input is configured.
  • This is the older WIND-series manual; WebMaster ONE / WM1 uses manual 180422 and has a different analog output layout (3681 = % output there).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Walchem WebMaster WIND series Modbus TCP/IP option (s825)

What Modbus registers does the Walchem WebMaster WIND series Modbus TCP/IP option (s825) have?

This map lists 62 registers: 62 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Walchem WebMaster WIND series Modbus TCP/IP option (s825) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Section 4.5.1 says the published addresses are 1-based and the packet is 0-based; subtract 1 on the wire (sensor 1 current reading 3001 / 43001 is wire address 3000).

What byte order does the Walchem WebMaster WIND series Modbus TCP/IP option (s825) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Walchem WebMaster WIND series Modbus TCP/IP option (s825)?

Start with HR 3000 Sensor 1 current reading (Sensor 1 current reading); HR 3048 Sensor 1 temperature reading (Sensor 1 temperature); HR 3002 Sensor 2 current reading (Sensor 2 current reading); HR 3096 Analog input 1 measured value (Analog input 1 measured value); HR 3712 Analog output 1 percent (Analog output 1 percent); HR 3728 RSI (RSI).

How do I enable Modbus control of the Walchem WebMaster WIND series Modbus TCP/IP option (s825)?

The Modbus TCP/IP option must be fitted; set point writes need software s825v008 or higher.

Where is the official Walchem WebMaster WIND series Modbus TCP/IP option (s825) Modbus documentation?

The source is WebMaster Modbus TCP/IP Option Instruction Manual (WIND series) (180413 Rev A1), published free by Walchem at https://walchem.com/literature/Controllers/WM/180413_WIND%20Modbus%20Manual_V08-10.pdf.
