Integration notes: Brainboxes ED-516 Ethernet digital I/O (Modbus TCP)

Integration in brief

Switch the module to Modbus TCP on its web page, then read the packed input or output register for a whole-module snapshot, or use the per-channel coils and discrete inputs. All values are single 16-bit registers or bits, so there is no word-order question.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

RegisterNameTypeWhyAccess
IR 32Digital inputs (packed)UINT16All digital input states in one readRead
DI 0Digital input 0BITFirst digital inputRead
IR 0DI 0 counterUINT16First input's pulse counterRead
CO 512Clear DI 0 counterBITClear the first counterWrite

Enable Modbus control & writes

Open the module's web page (http://<ip>/#/protocol) and change Current Protocol from ASCII to Modbus TCP. The factory IP is 192.168.127.254 unless DHCP assigned one.

Byte order & addressing

  • Inputs appear three ways (coils from 0x0020, discrete inputs from 0x0000, packed input register 0x0020); they carry the same states.
  • Counters can be read as input registers or holding registers at the same addresses.

Network setup

  • TCP port defaults to 502, idle timeout 0 (never drop), up to 8 simultaneous connections; all set on the protocol web page.

Watch out for

  • The module answers ASCII, not Modbus, until the protocol is changed on the web page.
  • An idle timeout other than 0 closes quiet connections; poll faster than the timeout or leave it at 0.

Notes on this map

  • The product table gives every object twice: as a logical (wire) address in hex and as a 984-style address (logical + 1 with a 0/1/3/4 prefix). The two columns agree, so the hex logical address is used here.
  • Channel numbers in register names count from 0, matching the order of the logical addresses (channel 0 = first address of each block).
  • The manual does not state the counter width; each counter occupies one 16-bit register in the table, so it is listed as UINT16.
  • Brainboxes' own Node-RED guide (docs.brainboxes.com, 'Using Modbus TCP with Node-RED', ED-588) writes coil address 0 for output 0 and reads input registers from address 0 for inputs 0-7, which matches the product table. The manual's section 10 worked example (ED-527 only) instead puts the outputs at 0x0001-0x0010; that example also labels a 0xFF00 write as 'low', so it is treated as an error here.
  • The same objects can also be reached with IEC 61131 %M/%MW addresses in some PLCs; those are listed in the manual and not repeated here.
  • The manual does not say which bit of a packed register belongs to which channel, so no bit list is given; check against the per-channel objects on site.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Brainboxes ED-516 Ethernet digital I/O (Modbus TCP)

What Modbus registers does the Brainboxes ED-516 Ethernet digital I/O (Modbus TCP) have?

This map lists 81 registers: 32 coils, 16 discrete inputs, 17 input registers, 16 holding registers. 16 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Brainboxes ED-516 Ethernet digital I/O (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table prints logical (on-the-wire) addresses in hex next to 984-style numbers. Use the hex value directly: input register 0x0020 is requested at address 32 and corresponds to 30033.

What are the minimum Modbus registers to integrate the Brainboxes ED-516 Ethernet digital I/O (Modbus TCP)?

Start with IR 32 Digital inputs (packed) (All digital input states in one read); DI 0 Digital input 0 (First digital input); IR 0 DI 0 counter (First input's pulse counter); CO 512 Clear DI 0 counter (Clear the first counter).

How do I enable Modbus control of the Brainboxes ED-516 Ethernet digital I/O (Modbus TCP)?

Open the module's web page (http://<ip>/#/protocol) and change Current Protocol from ASCII to Modbus TCP. The factory IP is 192.168.127.254 unless DHCP assigned one.

Where is the official Brainboxes ED-516 Ethernet digital I/O (Modbus TCP) Modbus documentation?

The source is Using Modbus TCP with Brainboxes products, published free by Brainboxes at https://www.brainboxes.com/files/catalog/product/ED/ED-516/documents/Brainboxes%20Modbus%20TCP%20Manual.pdf.
