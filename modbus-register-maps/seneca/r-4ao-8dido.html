Short answer

The R-4AO-8DIDO is a Seneca R-series remote I/O with four voltage/current analog outputs and eight digital channels that can each be an input or an output, plus eight 32-bit counters. It serves Modbus TCP on a two-port Ethernet switch and Modbus RTU on RS-485. This map covers integer output setpoints, status, digital I/O, counters, period/frequency and the command register.

Integration notes: Seneca R-4AO-8DIDO Ethernet I/O (4 analog outputs, 8 digital I/O)

Integration in brief

Write the signed 16-bit engineering setpoint for each output to 79-82 (scaled by the output's engineering start/stop settings). Read 20 for under/over-scale and watchdog flags and 21 for the digital channels.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus TCP server and RTU slave are on by default. Network and serial settings are changed in the web server or Seneca Discovery Device; DIP switches 1-2 select normal, factory reset or web-server-off.

Communication loss & watchdog

Per the web-server chapter, each analog output and each digital output has an optional watchdog (default disabled) with a timeout in seconds and a fail value or state.

Byte order & addressing

  • Offset is the wire address.
  • Counters, period and frequency are MSW first; the float setpoints have no stated word order.

Network setup

  • Factory IP is 192.168.90.101; never put two factory-fresh units on the same network.
  • Disable the web server with the DIP switches once commissioning is done.

Watch out for

  • Channel direction (input or output) is set per channel in the configuration.

Notes on this map

  • The protocol page lists function codes 01, 03, 05, 06, 15 and 16; the tables also give the digital inputs as 1x input status read with function 02. Modbus RTU runs on RS-485 and Modbus TCP serves up to 8 clients.
  • Counters, period and frequency rows are printed MSW at the lower address (ABCD). The float analog output setpoints (40072-40079) carry no MSW/LSW marks and the manual has no general word-order rule (a sibling model in the same manual is LSW first), so they are left out; use the signed 16-bit setpoints at 40080-40083 instead.
  • Factory settings from the manual: static IP 192.168.90.101/24, gateway 192.168.90.1, Modbus TCP port 502, station address 1; RS-485 38400 baud, 8 data bits, no parity, 1 stop bit, address 1.
  • RW* registers are stored in flash and survive about 10,000 writes.
  • Analog output values are in engineering units set by the configured scale (default mV or uA); the manual does not give a fixed scale.
  • Left out: the auxiliary command registers 40013-40016, whose codes are not described, and reserved registers.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Seneca R-4AO-8DIDO Ethernet I/O (4 analog outputs, 8 digital I/O)

What Modbus registers does the Seneca R-4AO-8DIDO Ethernet I/O (4 analog outputs, 8 digital I/O) have?

This map lists 54 registers: 8 coils, 8 discrete inputs, 38 holding registers. 22 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Seneca R-4AO-8DIDO Ethernet I/O (4 analog outputs, 8 digital I/O) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Holding-register tables print the 4x number (40001) and the 0-based offset (0); coils print 1 / offset 0 and discrete inputs 10001 / offset 0. The offset is the wire address.

What byte order does the Seneca R-4AO-8DIDO Ethernet I/O (4 analog outputs, 8 digital I/O) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Seneca R-4AO-8DIDO Ethernet I/O (4 analog outputs, 8 digital I/O)?

Start with HR 79 AO1 engineering value (integer) (AO1 setpoint (integer)); HR 80 AO2 engineering value (integer) (AO2 setpoint (integer)); HR 81 AO3 engineering value (integer) (AO3 setpoint (integer)); HR 82 AO4 engineering value (integer) (AO4 setpoint (integer)); HR 20 Analog output status (Output status flags); HR 21 Digital I/O value (Digital I/O word); HR 23 Counter 1 (Counter 1).

How do I enable Modbus control of the Seneca R-4AO-8DIDO Ethernet I/O (4 analog outputs, 8 digital I/O)?

Modbus TCP server and RTU slave are on by default. Network and serial settings are changed in the web server or Seneca Discovery Device; DIP switches 1-2 select normal, factory reset or web-server-off.

What happens when the Seneca R-4AO-8DIDO Ethernet I/O (4 analog outputs, 8 digital I/O) loses Modbus communication?

Per the web-server chapter, each analog output and each digital output has an optional watchdog (default disabled) with a timeout in seconds and a fail value or state.
