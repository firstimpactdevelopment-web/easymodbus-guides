ABB CMS-700 circuit monitoring system control unit (Modbus RTU / TCP) Modbus register map

Updated 19 November 2026

Short answer

The CMS-700 control unit measures mains voltage, current, power and energy and collects up to 96 open-core or solid-core branch current sensors. It serves everything over Modbus RTU (RS-485) and Modbus TCP on port 8001. Branch currents are 16-bit values in 0.01 A; mains values and branch power/energy are 32-bit, high word first.

This page lists 59 Modbus registers for the ABB CMS-700 circuit monitoring system control unit (Modbus RTU / TCP) — 5 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from ABB’s own free documentation (linked below) and checked against it.

Integration notes: ABB CMS-700 circuit monitoring system control unit (Modbus RTU / TCP)

Integration in brief

Read 0000h-005Fh for all branch TRMS currents in one block (0.01 A) and 9002h-90C4h for the mains. Branch power and energy come from 2200h and 2300h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set Modbus ID, baud rate and parity in the web UI (Settings > Communication / Modbus). Modbus TCP can be switched on or off there and its port changed; the standard port is 8001.

Byte order & addressing

  • Modbus TCP uses port 8001 by default, not 502.
  • Reads use function 03 and single writes use 06; the manual says not to use other functions (the table also lists 10 for names and polarity).
  • 16-bit branch values use 7FF0h-7FFFh as status codes.

Network setup

  • Default 19200 baud, even parity.
  • Add a 120 ohm terminator on units with serial number after 700K1820000 if needed.

Watch out for

  • Below about 60 mA CT secondary current the mains current reads 0 and power factor reads 1.
  • The FAQ gives 429,496 kWh as the maximum energy value for the mains and each branch.

Notes on this map

  • The manual says multi-register data has the most significant part in the lowest address (high word first).
  • Per-sensor blocks repeat for sensors 1-96: TRMS 0000h-005Fh, AC 0100h-015Fh, DC 0200h-025Fh, min 0400h+, max 0800h+, hold 0C00h+, polarity 2000h+, power factor 7300h+ (one register each); branch power 2200h+ and energy 2300h+ (two registers each). Only the first entries are listed.
  • Special values: 7FF0h = data pending, 7FFCh = sensor not reachable, 7FFDh = data type disabled, 7FFEh = overload, 7FFFh = no such sensor (FFFF7FFxh for 32-bit values).
  • The table has a few misprints in its summary rows (the last AC sensor row shows 005F for 351; the group 2 energy row repeats 9'472); this map lists only rows whose hex and decimal agree.
  • The frame description lists 1 stop bit; parity can be even (default), odd or none. Data bits are not stated.
  • Left out: sensor serial/version blocks (1000h+), branch and group names, phase/group assignment registers and the threshold alarm block (8100h+).
  • Group energy (2500h+, 100 Wh steps) is left out because the table prints the same decimal address (9'472) for groups 1 and 2.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ABB CMS-700 circuit monitoring system control unit (Modbus RTU / TCP)

What Modbus registers does the ABB CMS-700 circuit monitoring system control unit (Modbus RTU / TCP) have?

This map lists 59 registers: 59 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB CMS-700 circuit monitoring system control unit (Modbus RTU / TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The mapping table prints each address in hex (with the decimal beside it), and sensor 1 sits at 0000h, so the printed value is the request address with no offset. The manual has no example frame.

What byte order does the ABB CMS-700 circuit monitoring system control unit (Modbus RTU / TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ABB CMS-700 circuit monitoring system control unit (Modbus RTU / TCP)?

Start with HR 0 TRMS current, sensor 1 (Branch 1 TRMS current); HR 36866 Voltage L1-N (Mains voltage L1-N); HR 36880 Line current L1 (Mains current L1); HR 36910 Total active power (Mains total active power); HR 37044 Total active energy (100 Wh steps) (Mains active energy (100 Wh)); HR 8960 Active energy, sensor 1 (Branch 1 energy).

How do I enable Modbus control of the ABB CMS-700 circuit monitoring system control unit (Modbus RTU / TCP)?

Set Modbus ID, baud rate and parity in the web UI (Settings > Communication / Modbus). Modbus TCP can be switched on or off there and its port changed; the standard port is 8001.
