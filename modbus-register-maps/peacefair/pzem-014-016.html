Peacefair PZEM-014 / PZEM-016 Modbus register map

Updated 17 November 2026

Short answer

Peacefair's PZEM-014/016 are display-less single-phase AC measuring modules that report voltage, current, power, energy, frequency and power factor over RS485 Modbus RTU. Ten input registers hold the readings, with current, power and energy as 32-bit values whose low word comes first. Two holding registers set the over-power alarm threshold and the slave address, and a custom function 0x42 resets energy.

This page lists 9 Modbus registers for the Peacefair PZEM-014 / PZEM-016 — 2 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Peacefair’s own free documentation (linked below) and checked against it.

Integration notes: Peacefair PZEM-014 / PZEM-016

Integration in brief

Read 10 input registers from 0x0000 with function 04 in one request; combine current, power and energy pairs low word first.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step; the module answers Modbus RTU as soon as it is powered from the measured AC line.

Byte order & addressing

  • Energy reset uses non-standard function code 0x42 with no data.
  • 32-bit values are low word first (CDAB).

Network setup

  • Fixed 9600 baud, 8 data bits, no parity, 1 stop bit.
  • Change the slave address by writing holding register 0x0002 (1-247) with function 06.

Watch out for

  • Address 0xF8 only works with a single slave on the bus; give each module a unique address before wiring several together.
  • The PZEM-014/016 take their supply from the measured AC voltage (datasheet section 5.1).

Notes on this map

  • Source host: Peacefair does not host this datasheet publicly; the copy used is the manufacturer datasheet published by distributor RCS Components. The PZEM-004T V3.0 datasheet (innovatorsguru.com copy) has the same register table and example.
  • Word order: the table lists 'low 16 bits' at the lower address and 'high 16 bits' at the next, and the example decodes current 03 E8 00 00 as 0x000003E8 = 1.000 A, so 32-bit values are CDAB.
  • Measurements are read with function 04, parameters with 03 and written with 06. Function 0x42 (no data) resets the energy counter; 0x41 is factory calibration on general address 0xF8.
  • Address 0xF8 is a general address for single-slave setups; 0x00 is broadcast (no reply).
  • The PZEM-004T is a TTL UART module, not RS485; it uses the same Modbus RTU frames at 9600 8N1.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Peacefair PZEM-014 / PZEM-016

What Modbus registers does the Peacefair PZEM-014 / PZEM-016 have?

This map lists 9 registers: 7 input registers, 2 holding registers. 2 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Peacefair PZEM-014 / PZEM-016 Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register addresses are given in hex and sent as-is; the datasheet's example reads 10 registers starting at 0x0000 and decodes voltage from the first register.

What byte order does the Peacefair PZEM-014 / PZEM-016 use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Peacefair PZEM-014 / PZEM-016?

Start with IR 0 Voltage (Voltage); IR 1 Current (Current); IR 3 Active power (Active power); IR 5 Active energy (Energy (Wh)); IR 8 Power factor (Power factor).

How do I enable Modbus control of the Peacefair PZEM-014 / PZEM-016?

No enable step; the module answers Modbus RTU as soon as it is powered from the measured AC line.

Where is the official Peacefair PZEM-014 / PZEM-016 Modbus documentation?

The source is PZEM-014/016 AC communication module. Peacefair doesn't publish it on its own website, so this map was re-typed from a free copy at https://rcscomponents.kiev.ua/datasheets/pzem-014_16.pdf. It may be an older revision, so check it against the live unit.
