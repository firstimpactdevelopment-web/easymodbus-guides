Huawei SDongleA smart dongle (Modbus TCP) Modbus register map

Updated 17 November 2026

Short answer

The SDongleA is Huawei's smart dongle. It acts as a Modbus TCP server for itself (logical device ID 100) and for the inverters, power meter and other devices it manages (IDs 1-247). This map covers the dongle's own registers: identity, network and traffic status, plant-level input, load, grid and battery power, time settings, management-server and NTP settings, and the reset and device-search commands.

This page lists 46 Modbus registers for the Huawei SDongleA smart dongle (Modbus TCP) — 23 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Huawei’s own free documentation (linked below) and checked against it.

Integration notes: Huawei SDongleA smart dongle (Modbus TCP)

Integration in brief

Connect over Modbus TCP and use logical device ID 100 for the dongle; read plant power at 37498-37517. IDs 1-247 reach the inverters and other devices the dongle manages.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The document does not describe an enable step.

Byte order & addressing

  • Logical device ID 100 addresses the dongle; 1-247 address devices behind it.
  • Powers are in kW with gain 1000.
  • Grid power is positive when buying, negative when selling.

Network setup

  • Read with function 03, write with 06 or 16; function 2B reads device identifiers.

Watch out for

  • Several registers are marked as supported only on the 4G dongle.
  • Writing 0 to 40205 sends the reset command.

Notes on this map

  • Huawei publishes this document only behind a support-site login; the copy linked is a forum upload of the unaltered Huawei PDF.
  • Data encoding is big-endian for addresses and data, with the leftmost byte sent first, so 32-bit values are read high word first (ABCD).
  • Gain is a divisor: power has gain 1000 in kW (so 1 count = 1 W) and traffic gain 100 in MB.
  • The read example's text names register 32306 but its frame bytes request 0x89C0 (35264); the frame bytes were used to settle the numbering.
  • Left out: Device operation (47402, 11 registers mixing an SN string with a command word), whose layout is better taken from the source directly.
  • The TCP port is not stated in this document.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Huawei SDongleA smart dongle (Modbus TCP)

What Modbus registers does the Huawei SDongleA smart dongle (Modbus TCP) have?

This map lists 46 registers: 46 holding registers. 23 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Huawei SDongleA smart dongle (Modbus TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Register addresses are sent as printed. The read example puts 0x89C0 (35264, the mobile signal-strength register) in the request, so 35264 goes on the wire unchanged.

What byte order does the Huawei SDongleA smart dongle (Modbus TCP) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Huawei SDongleA smart dongle (Modbus TCP)?

Start with HR 37498 Total input power (Total PV input power); HR 37500 Load power (Load power); HR 37502 Grid power (Grid import/export power); HR 37504 Total battery power (Battery power); HR 37516 Total active power (Total active power); HR 37410 Dongle type (Dongle type).

How do I enable Modbus control of the Huawei SDongleA smart dongle (Modbus TCP)?
