Short answer

The PRO3 is a MID-certified three-phase 100 A DIN-rail energy meter from inepro's 2026 PRO line; the -Mod versions add an RS485 Modbus RTU port. Live values are IEEE 754 floats (high word first) in input registers from hex 5000h, energy counters sit from 6000h and settings from 4000h. This map covers the default register map: instantaneous values, THD, demand peaks, energy totals and tariff registers (as floats) and the main communication and display settings.

Integration notes: inepro Metering PRO3 three-phase energy meter (2026 PRO line)

Integration in brief

Wire RS485 to terminals 12 (A) and 13 (B), poll unit 1 at 9600 baud 8E1 with function 04 and decode live values as high-word-first floats from 5000h. Write 2 to 4026h once (function 06) so the 6000h energy registers come back as floats.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is only on the -Mod and -Mod-Ba versions. Set ID, baud and parity on the display, with inepro's configuration software, or over Modbus at 4003h/4004h/4011h.

Byte order & addressing

  • Addresses are hex: 5012h is decimal 20498 on the wire.
  • Live values are input registers (function 04), not holding registers.
  • Power is in kW/kvar/kVA, not W.
  • Energy registers default to INT32; set 4026h = 2 for floats.
  • Baud rate is written as a code (6 = 9600 ... 10 = 115200), not as the number.

Network setup

  • Defaults: Modbus ID 1, 9600 baud, even parity, 1 stop bit.
  • Parity codes at 4011h: 1 = even, 2 = none, 3 = odd; use 2 stop bits with no parity.
  • Up to 60 devices per RS485 bus, 1200 m range, fewer at higher baud rates.

Watch out for

  • Total active energy (6000h) depends on the combination code at 400Fh; read forward (600Ch) and reverse (6018h) for import and export.
  • RTC tariff registers read 0 unless the meter is a -Mod-Ba.
  • Combination code E (value 5, net forward - reverse) locks permanently once programmed.

Notes on this map

  • This file covers only the 'Default' register map. The manual also prints an 'Extensive' map (from 0000h, W/var units) and a 'YTL' map (scaled integers and UINT64 counters). The display has a 'Modbus Mapping' setting (0/1/2, default 2) but the manual does not say which number selects which map, so check that the meter answers at 5000h before relying on this file.
  • Energy registers are typed 'UINT32/Float ABCD' (or INT32/Float) with units 'Wh/kWh'. Register 4026h selects the format: 1 = INT32 (default), 2 = FLOAT. They are listed here as FLOAT32 in kWh/kvarh/kVAh, valid only after writing 2 to 4026h. The INT32 mode is not covered because the manual never states its scale explicitly.
  • The INT32/FLOAT pairing with Wh/kWh follows the order printed in the type and unit columns ('UINT32/Float', 'Wh/kWh'); the same manual's Extensive map also gives float energy in kWh.
  • Registers marked 'Only for Ba version with RTC' (RTC tariff and some quadrant energies) read 0 on meters without the RTC; the manual says unsupported registers stay readable and return 0.
  • Left out: serial number, meter code and CRC (BCD/HEX/ASCII with no decoding given), RTC time and tariff tables (BCD blocks), current direction (ASCII), S0 output rate (typed UINT16 length 1 in the read map but FLOAT length 2 in the write table), CT ratio, tariff mode 6048h (listed twice with different meanings), LCD password and the resettable day counter (INT32 without a stated word order).
  • Quadrant labels on the DS-T1/DS-T2 rows are copied as printed; some pair import/export with Q2/Q3 differently from the totals rows.
  • Baud rates per the manual: 9600, 19200, 38400, 57600 and 115200 (the spec table on p. 9 prints 76800 instead of 57600). Stop bits: 1 with even/odd parity, 2 with no parity.
  • This 2026 PRO line uses a different template from the older PRO1-Mod/PRO2-Mod (V3.x) and PRO380-Mod maps; do not mix them.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the inepro Metering PRO3 three-phase energy meter (2026 PRO line)

What Modbus registers does the inepro Metering PRO3 three-phase energy meter (2026 PRO line) have?

This map lists 159 registers: 150 input registers, 9 holding registers. 9 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the inepro Metering PRO3 three-phase energy meter (2026 PRO line) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The map prints hex addresses that go into the request unchanged; the manual's example frames are 01 06 4003 000A (set Modbus ID) and 01 10 5060 0002 ... (reset demand peak). So 5012h is wire address 20498. Rows typed 'input' are read with function 04; rows typed 'input /holding' are listed here as holding registers (read 03, write 06/16).

What byte order does the inepro Metering PRO3 three-phase energy meter (2026 PRO line) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the inepro Metering PRO3 three-phase energy meter (2026 PRO line)?

Start with IR 20482 Voltage L1 (Voltage L1); IR 20492 Current L1 (Current L1); IR 20498 Total Active Power (Total active power (kW)); IR 20522 Total Power Factor (Total power factor); IR 20488 Grid Frequency (Grid frequency); IR 24588 Total Forward Active Energy (Total forward (import) active energy); IR 24600 Total Reverse Active Energy (Total reverse (export) active energy); HR 16422 Data format setting (Switch energy registers to float).

How do I enable Modbus control of the inepro Metering PRO3 three-phase energy meter (2026 PRO line)?

Modbus is only on the -Mod and -Mod-Ba versions. Set ID, baud and parity on the display, with inepro's configuration software, or over Modbus at 4003h/4004h/4011h.
