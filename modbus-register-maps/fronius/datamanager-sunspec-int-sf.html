Short answer

The Fronius Datamanager publishes each connected inverter as a SunSpec device (unit ID = inverter number) over Modbus TCP, and over RTU on Datamanager 2.0. With the int+SF model type the inverter model is 101/102/103 followed by nameplate, settings, status, immediate controls, multiple-MPPT and storage models. This map covers the 16-bit measurements, state, ratings and every writable control register.

Integration notes: Fronius Symo / Primo / Galvo / Symo Hybrid via Datamanager (SunSpec int+SF)

Integration in brief

Enable 'Data output via Modbus' = tcp in the Datamanager web UI, choose SunSpec Model Type int+SF, and poll unit ID = inverter number (inverter 00 = 100) on port 502. Read registers 40070-40109 (wire addresses 40069-40108) in one request and scale each value with its _SF register.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Datamanager web interface > Settings > Modbus: set 'Data output via Modbus' to tcp (or rtu on Datamanager 2.0, factory default rtu there), pick SunSpec Model Type int+SF, and tick 'Inverter control via Modbus' to allow writes to models 123/124. 'Limit control' can restrict write access to listed IP addresses. Turning Modbus output off cancels any active Modbus control commands.

Communication loss & watchdog

Each control in model 123 has a *_RvrtTms fallback timer (0-28800 s) that restarts with every Modbus message received; when it expires the control ends and the next-priority control (e.g. dynamic power reduction) takes over. RvrtTms = 0 (default) means the setting stays until disabled.

Byte order & addressing

  • Off-by-one: tables print SunSpec register numbers from 40001; request number minus one (40001 -> 40000).
  • Changing int+SF/float (web UI or F_ModelType 216) shifts every model after the inverter model by 10 registers; F_ModelType needs the value 6 written immediately after, or it reverts.
  • Scale factors are not fixed even if a value is listed - read them; they can change with firmware.
  • Writes to read-only or unsupported registers are silently ignored (no exception); invalid values return exception 3.
  • Power factor sign follows EEI: negative when over-excited (Q1), positive when under-excited (Q4).

Network setup

  • Unit ID = inverter number set on the inverter display; inverter number 00 maps to unit ID 100. String Controls start at the String Control offset (default 101); Smart Meters at 240-244; Sensor Cards at 245-247.
  • TCP port defaults to 502 (port 80 not allowed).
  • RTU is only on Datamanager 2.0 and cannot be used when a Modbus energy meter is configured; baud and parity are set in the web UI. The Datamanager has no bias resistors.
  • Demo mode in the web UI returns fixed data for commissioning a master without live inverters.

Watch out for

  • Use a response timeout of at least 10 s with several inverters on Solar Net, query sequentially, and keep to 6 inverters per Datamanager.
  • To change an active power limit, write the new WMaxLimPct and then re-write WMaxLim_Ena = 1; all five registers 40233-40237 may be written in one FC16 request.
  • Event flags can stay latched; write 0xFFFF to F_Reset_All_Event_Flags (215) to clear them.

Notes on this map

  • Register table comes from Fronius' official XLSX in the 'Modbus Sunspec Maps, State Codes and Events' ZIP (same download page as the PDF); behaviour and settings come from the PDF.
  • All addresses here assume SunSpec Model Type = int+SF. With the default float setting the inverter model is 111-113 and every later model starts 10 registers higher (e.g. nameplate 40131 instead of 40121).
  • Fronius warns the map is dynamic: the correct method is to walk the SunSpec model chain from 40001 (ID, L) and use offsets. The fixed addresses below are the published layout for a single inverter.
  • Word order: neither the PDF nor the XLSX states the order of 32/64-bit values, so every 32/64-bit register is left out: SID 40001-40002, WH lifetime energy 40094-40095, Evt1/Evt2/EvtVnd1-4 40110-40121, ActWh 40187-40190, StActCtl 40217-40218, Tms 40223-40224, model 160 Evt/DCWH/Tms, and site totals F_Site_Power/Energy 500-513. The SID is documented as 0x53756E53 'SunS', which suggests high word first, but this is not stated.
  • Registers marked 'Not supported' in the XLSX are left out (temperatures, VMax/VMin, quadrant 2/3 ratings, ride-through, Ris, StorAval, InBatV, and similar).
  • Unsupported values read as: int16 0x8000, uint16/enum16/bitfield16 0xFFFF, sunssf 0x8000. Some 'supported' points also return these, e.g. phase B/C on single-phase inverters, DCA/DCV on multi-input inverters (use model 160).
  • The XLSX notes that WH (lifetime energy) may be imprecise; ActWh in model 122 is the alternative (both 32/64-bit, omitted here).
  • Access is taken from the XLSX R/W column. VAMax (40157) and WMaxLimPct_RmpTms (40236) are marked RW but list only function code 0x03; the PDF says writes to unsupported RmpTms are ignored (ramp supported from Datamanager 3.13.3-2 / Hybridmanager 1.11.3-2).
  • Model 124 (storage) is only meaningful on Fronius Symo Hybrid with battery.
  • The PDF describes PVConn bit 1 as 'responsive'; the XLSX calls it 'Available'. The XLSX wording is used.
  • Energy meters (Fronius Smart Meter) are published at unit ID 240-244 with their own common block and meter model 201-203 starting again at 40001; they are not part of this inverter map.

Questions about the Fronius Symo / Primo / Galvo / Symo Hybrid via Datamanager (SunSpec int+SF)

What Modbus registers does the Fronius Symo / Primo / Galvo / Symo Hybrid via Datamanager (SunSpec int+SF) have?

This map lists 152 registers: 152 holding registers. 31 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Fronius Symo / Primo / Galvo / Symo Hybrid via Datamanager (SunSpec int+SF) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Fronius numbers registers from 1 (SunSpec base register 40001) and says to send the register number minus one: register 40001 is requested at address 40000 (0x9C40). The manual's RTU example reads register 40005 with address bytes 9C 44. Fronius registers 212-217 follow the same rule (212 -> 211).

What are the minimum Modbus registers to integrate the Fronius Symo / Primo / Galvo / Symo Hybrid via Datamanager (SunSpec int+SF)?

Start with HR 40069 Inverter ID (Inverter model ID (101/102/103) - confirms int+SF layout); HR 40083 W (AC power); HR 40084 W_SF (AC power scale factor); HR 40107 St (Operating state); HR 40232 WMaxLimPct (Active power limit %); HR 40236 WMaxLim_Ena (Enable/disable the power limit); HR 40250 WMaxLimPct_SF (Power limit scale factor).

How do I enable Modbus control of the Fronius Symo / Primo / Galvo / Symo Hybrid via Datamanager (SunSpec int+SF)?

'Limit control' can restrict write access to listed IP addresses. Turning Modbus output off cancels any active Modbus control commands.

What happens when the Fronius Symo / Primo / Galvo / Symo Hybrid via Datamanager (SunSpec int+SF) loses Modbus communication?

Each control in model 123 has a *_RvrtTms fallback timer (0-28800 s) that restarts with every Modbus message received; when it expires the control ends and the next-priority control (e.g. dynamic power reduction) takes over. RvrtTms = 0 (default) means the setting stays until disabled.
