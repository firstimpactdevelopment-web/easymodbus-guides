Victron Energy GX device Modbus-TCP (Cerbo GX, Venus GX, Color Control GX) Modbus register map

Updated 24 October 2026

Short answer

A Victron GX device is a Modbus-TCP gateway: one IP address on port 502, with the unit ID choosing which connected product you talk to (unit ID 100 for whole-system totals and ESS settings, other IDs for each Multi/Quattro, battery monitor or MPPT). Every register in this map is a single 16-bit integer whose raw value is divided by Victron's scale factor. The map covers system power flows and battery summary, VE.Bus AC/DC measurements, state, alarms and ESS mode 3 control, battery monitor/BMS values and alarms, solar charger readings, and the ESS mode 2 settings.

This page lists 128 Modbus registers for the Victron Energy GX device Modbus-TCP (Cerbo GX, Venus GX, Color Control GX) — 21 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Victron Energy’s own free documentation (linked below) and checked against it.

Integration notes: Victron Energy GX device Modbus-TCP (Cerbo GX, Venus GX, Color Control GX)

Integration in brief

Enable the Modbus-TCP service on the GX, read the 'Available services' list to get each device's unit ID, then poll unit ID 100 (registers 817-866) for the system picture and the VE.Bus unit ID (registers 3-36) for the inverter/charger. All listed values are one 16-bit register each: apply the scale, and treat INT16 rows as signed.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus-TCP is off by default. On the GX, enable it under Settings > Services > Modbus TCP (newer Venus OS: Settings > Integrations > Modbus TCP server). The same menu lists 'Available services' with each device's unit ID and shows the last Modbus error. ESS mode 3 control needs ESS mode set to external control (register 2902 = 3, or the GUI).

Communication loss & watchdog

ESS mode 3: the VE.Bus power setpoints (37, 40, 41) must be rewritten at least every 60 seconds or the Multi drops to passthru. No general Modbus timeout is documented for other writes.

Byte order & addressing

  • The unit ID picks the device, not the register: the same register number means different things on different unit IDs, and a register read on the wrong unit ID returns exception 02.
  • Unit ID 100 and unit ID 0 both reach the system service and the ESS settings; use 100 because many clients reject 0.
  • Since Venus OS 2.60 unit IDs are assigned dynamically and generally equal the device instance (up to 247). The 'Unit ID mapping' sheet keeps the old preferred IDs: 246 = CCGX VE.Bus port, 242 = Venus GX VE.Bus port, 227 = Cerbo GX VE.Bus port, 225 = CAN-bus BMS, 223/224/226 = Cerbo GX VE.Direct ports. Always confirm on the GX's Available services page.
  • Scale factors are divisors in Victron's sheet; several power registers have scalefactor 0.1 or 0.01, meaning the raw value must be MULTIPLIED (by 10 or 100).
  • Function 3 and 4 return the same data.
  • A block read must not include any register the device lacks (Victron's example: reading 1-100 on the VE.Bus unit fails because 1 and 2 do not exist).

Network setup

  • Give the GX a fixed IP (or DHCP reservation); Modbus-TCP listens on port 502.
  • No serial settings: RS485 is not used for this interface.
  • Unit IDs do not change after a reboot or power loss, per the GX Modbus-TCP manual.

Watch out for

  • Parallel or three-phase VE.Bus systems cannot be addressed unit by unit; read the per-phase registers instead.
  • Inverter/charger configuration (absorption voltage etc.) cannot be changed over Modbus-TCP.
  • Exception 0A means the unit ID is known but no device answers on that port; 0B means the unit ID is not in the mapping list.
  • Battery history registers (284, 303 and similar) are not available from CAN-bus BMS batteries.
  • For ESS mode 2 grid setpoints on Venus 3.50 and later, Victron recommends the 32-bit register 2716 to avoid flash wear; it is not listed here because the word order is not documented, so 2700/2703 remain the documented 16-bit option.

Notes on this map

  • Scale: Victron's 'Scalefactor' column is a divisor (engineering value = raw / scalefactor). It is converted here to a multiplier: scalefactor 10 -> scale 0.1, 100 -> 0.01, 0.1 -> 10, 0.01 -> 100, -10 -> -0.1 (consumed Ah is published as a positive raw number that means a negative Ah figure).
  • Left out on purpose: every 32-bit and 64-bit register (int32/uint32/uint64, e.g. system 868-918, VE.Bus energy counters 74-93 and ESS setpoints 96-101, battery 256 and 330, solar charger 792 and 3728, ESS 2716/2720/2722). Neither the register list nor Victron's GX Modbus-TCP manual or data communication whitepaper states the word order of multi-register values, so they are not listed. Each has a 16-bit equivalent listed here except the VE.Bus energy counters.
  • Left out: 2704 (ESS max inverter power). The register list gives scalefactor 0.1 (raw x 10 W) while Victron's ESS mode 2 and 3 guide describes the value as plain watts; the scale cannot be settled from the sources.
  • Left out: deprecated registers whose value is always 0 (267, 276-277, 297-300, 781), the deprecated ESS percentage switches 2701/2702, and the microgrid block 200-246 (213-222 are marked unsupported).
  • Not every product fills every register. A register that the selected device does not provide returns Modbus exception 02 (illegal data address); a block read that includes one fails as a whole.
  • ESS details (setpoint sign, 60-second rewrite rule in mode 3, inverted logic of 2708, 100 W units of 2706, -1 for no limit) come from Victron's 'ESS mode 2 and 3' guide, https://www.victronenergy.com/live/ess:ess_mode_2_and_3 (last modified 2024-10-14). Function codes, unit ID 0/100 and the error codes come from the 'GX Modbus-TCP Manual', https://www.victronenergy.com/live/ccgx:modbustcp_faq. Port 502 is stated in 'Data communication with Victron Energy products' (whitepaper on victronenergy.com).
  • Enum meanings are copied from the register list's dbus-unit column; VE.Bus error 32 and solar charger error 788 list only the codes the register list defines.

Questions about the Victron Energy GX device Modbus-TCP (Cerbo GX, Venus GX, Color Control GX)

What Modbus registers does the Victron Energy GX device Modbus-TCP (Cerbo GX, Venus GX, Color Control GX) have?

This map lists 128 registers: 128 holding registers. 21 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Victron Energy GX device Modbus-TCP (Cerbo GX, Venus GX, Color Control GX) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The 'Address' column of Victron's register list goes into the request as-is. Victron's GX Modbus-TCP manual reads VE.Bus input voltage (register 3) by setting the first request register to 3, so the listed number is the wire address. Clients that add or subtract one (Modicon 4xxxx entry) will be off by one register. Function codes 3 and 4 return identical data; all registers are listed here as holding registers, and writes use 6 or 16.

What are the minimum Modbus registers to integrate the Victron Energy GX device Modbus-TCP (Cerbo GX, Venus GX, Color Control GX)?

Start with HR 843 Battery state of charge (system) [unit ID 100] (System battery state of charge (unit ID 100)); HR 842 Battery power (system) [unit ID 100] (System battery power, + charging / - discharging (unit ID 100)); HR 820 Grid power L1 [unit ID 100] (Grid power L1 (unit ID 100)); HR 817 AC consumption L1 [unit ID 100] (AC consumption L1 (unit ID 100)); HR 850 DC-coupled PV power [unit ID 100] (Total DC-coupled PV power (unit ID 100)); HR 31 VE.Bus state [VE.Bus unit ID] (VE.Bus state (VE.Bus unit ID)); HR 32 VE.Bus error [VE.Bus unit ID] (VE.Bus error (VE.Bus unit ID)); HR 33 Switch position (mode) [VE.Bus unit ID] (Switch position: remote on/off/charger-only (VE.Bus unit ID)); HR 22 Active input current limit [VE.Bus unit ID] (AC input current limit (VE.Bus unit ID)).

How do I enable Modbus control of the Victron Energy GX device Modbus-TCP (Cerbo GX, Venus GX, Color Control GX)?

Modbus-TCP is off by default. On the GX, enable it under Settings > Services > Modbus TCP (newer Venus OS: Settings > Integrations > Modbus TCP server). The same menu lists 'Available services' with each device's unit ID and shows the last Modbus error. ESS mode 3 control needs ESS mode set to external control (register 2902 = 3, or the GUI).

What happens when the Victron Energy GX device Modbus-TCP (Cerbo GX, Venus GX, Color Control GX) loses Modbus communication?
