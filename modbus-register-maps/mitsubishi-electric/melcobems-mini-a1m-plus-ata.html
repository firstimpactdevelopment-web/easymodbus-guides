Short answer

Small Procon protocol converter that plugs into the CN105 connector of one Mitsubishi Electric split indoor unit and serves Modbus RTU (RS-485) or Modbus TCP. For air-to-air units it exposes mode, setpoint, fan, vane and on/off, room temperature and fault code, plus a BMS room-sensor offset feature and an optional deadband auto-changeover.

Integration notes: Mitsubishi Electric MelcoBEMS MINI (A1M+) gateway for Air-To-Air split units (M, S and P series)

Integration in brief

Set DIP 7 on for Modbus RTU, pick the slave address on DIP 1-5 and DIP 6 on for 9600 / no parity, then use holding registers 0-3 and 7 for mode, setpoint, fan, vane and on/off, and poll 8-9 for room temperature and fault.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

DIP switch 7 on selects Modbus RTU on RS-485 (off = BACnet MS/TP and BACnet IP). Modbus TCP on the Ethernet port came with firmware 4.1.0; the manual says the Ethernet protocol follows the DIP switch setting and needs application mode (DIP switches not all off).

Byte order & addressing

  • Fault code 0x8000 (decimal register: 8000) means no fault; 0x6999 / 6999 means the gateway cannot talk to the indoor unit.
  • Fan speed codes skip 1 and 4: 0 Auto, 2 Quiet, 3 Weak, 5 Strong, 6 Very strong.
  • The i-see mode codes 9-11 are read-only.

Network setup

  • RS-485 A, B and GND must all be connected; shielded cable, daisy chain only.
  • Factory IP 192.168.92.114, Modbus TCP port 502.
  • Node address 1..30 on DIP 1-5 (binary); all off = 1.

Watch out for

  • The gateway detects ATA vs ATW by itself; check register 13 reads 0 before trusting the ATA map.

Notes on this map

  • This file covers only the Air-To-Air tables (section 10). The same device has separate Air-To-Water and Lossnay tables; the ATW map is a separate file in this library.
  • Registers are 16-bit unsigned except BMS room temperature (signed) at 40016, which the manual gives as signed °C x 10 with an unsigned twin at 40017.
  • All input registers and the coil are mirrored as read-only holding registers for BMSs that read only holding registers.
  • Deadband heating/cooling setpoints (40019/40020) are printed in whole °C, unlike the x10 setpoint and temperature registers.
  • With the BMS room temperature and virtual setpoint written, the gateway shifts the unit's setpoint by the difference between the BMS sensor and the unit's return-air reading.
  • DIP switches: 1-5 slave address (all off = 1, all on = use register 40005), 6 on = 9600 no parity (off = registers 40006/40007), 7 on = Modbus RTU (off = BACnet), 8 = deadband mode. Data bits 8 and stop bits 1 are fixed.
  • Unit ID, baud rate and parity are chosen with the unit's DIP/rotary switches; the manual does not give factory defaults for them.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious.
