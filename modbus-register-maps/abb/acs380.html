Short answer

ABB's ACS380 machinery drive speaks Modbus RTU on the RS-485 terminal of its BMIO-01 extension module (the same embedded fieldbus can also run CANopen with a different module). The first six holding registers carry the control word, two references, status word and two actual values; every parameter is also a holding register derived from its group and index. This map covers the cyclic block, key 01/04/05 monitoring parameters, the comm-loss settings and the main 32-bit actual values.

Integration notes: ABB ACS380 machinery drive (embedded Modbus RTU)

Integration in brief

Pick the Modbus RTU control macro (or set 58.01 = Modbus RTU and point 20.01 and 22.11/28.11 at the embedded fieldbus), then write the ABB Drives control word and Reference 1 at 400001/400002 and poll the status word and actual values at 400004-400006. Read further monitoring values from their parameter registers (400000 + 100*group + index).

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Selecting the Modbus RTU control macro sets 20.01 Ext1 commands = Embedded fieldbus, 22.11 and 28.11 = EFB ref1 and 58.01 = Modbus RTU (and puts fault reset on DI1). Otherwise set them by hand, plus 58.03 node address, 58.04 baud and 58.05 parity, and apply with 58.06 Communication control = Refresh settings.

Communication loss & watchdog

58.14 Communication loss action (default Fault; also No action / Last speed / Speed ref safe / Fault always / Warning) with 58.16 Communication loss time (default 3.0 s) and 58.15 Communication loss mode (default: only control word/reference writes reset the timer). A loss trips 6681 EFB comm loss or warns A7CE.

Byte order & addressing

  • Addresses are 6-digit Modicon references: 400001 = wire 0. 32-bit parameter registers start at 420000 and cannot be reached with 5-digit (4xxxx) addressing.
  • 32-bit values in this map are listed CDAB, which assumes 58.34 Word order = LO-HI (default). If 58.34 is set to HI-LO, read them as ABCD.
  • References and actual values are signed 16-bit with 20000 = the 46.01/46.02 scaling value, not engineering units.
  • Start (manual's sequence): write 0x476; when status bit 0 is 1 write 0x477 (ready/stopped), then 0x47F to run. Stop: 0x477 stops per 21.03 Stop mode; 0x47E is an OFF1 ramp stop. Fault reset: rising edge of control-word bit 7.

Network setup

  • Defaults: node 1, 19.2 kbit/s, 8 data bits, even parity, 1 stop bit (58.03-58.05).
  • Changes to group 58 take effect only after 58.06 = Refresh settings or a control-unit reboot.
  • Termination must be on at both ends of the bus and bias on at one device, preferably at the end.

Watch out for

  • The default comm-loss action is Fault with a 3 s timeout, so a stopped poll trips the drive.
  • Exception 04h means the drive rejected the request (for example a limit was exceeded).

Notes on this map

  • Modbus RTU needs the BMIO-01 module (EIA-485 terminal) fitted on the control unit.
  • Registers 400001-400006 are the factory defaults of Data I/O 1-6 (58.101-58.106) and can be re-pointed; 400007-400014 are user-selectable via 58.107-58.114 and are not listed. The register table on p. 570 says 400003 and 400004 are re-pointed with 58.102; by the parameter list they belong to 58.103 and 58.104.
  • Control and status word bits are shown for the ABB Drives profile (58.25 = 0, default). In this manual 58.25 also offers 2 = Transparent and 3 = DCU Profile, whose words are passed through with a different bit layout.
  • Reference/actual registers are signed 16-bit; 20000 corresponds to the value of 46.01 Speed scaling or 46.02 Frequency scaling (46.03 torque), so their engineering value depends on drive settings and is left unscaled here.
  • 32-bit registers follow 58.34 Word order; the default LO-HI sends the low word first (CDAB). With HI-LO the order becomes ABCD. Within each register the high byte is sent first.
  • 16-bit scaling is the manual's FbEq16 column; 32-bit scaling is the FbEq32 column in the Additional parameter data chapter. Parameters whose 16-bit scaling is 'See par. 46.xx' (01.01, 01.03, 01.06, 01.07, 01.10, 01.14) are listed only in their 32-bit form. 01.72-01.74 phase currents are left out because even their 32-bit scaling refers to 46.05.
  • Left out: the error code registers 400090-400095. The heading of that table says 400090-400100 but its reference column numbers the rows 89-94, so the exact register of each row is not stated unambiguously in this manual.
  • 58.16 Communication loss time (default 3.0 s, 0.0-6000.0 s) is left out: its 16-bit scaling is printed only as '1 = 1', so the unit of the integer is unclear.
  • Left out: 06.xx control/status words, 05.10 control board temperature (unit depends on a setting), 01.50-01.53 hour/day kWh logs and configuration parameters other than the comm-loss settings. Coils and discrete inputs also exist but are omitted.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the ABB ACS380 machinery drive (embedded Modbus RTU)

What Modbus registers does the ABB ACS380 machinery drive (embedded Modbus RTU) have?

This map lists 43 registers: 43 holding registers. 5 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the ABB ACS380 machinery drive (embedded Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual uses 6-digit references 400001-465536 for the 65536 holding registers, so 400001 = wire address 0. Masters limited to 5 digits can use 40001-49999 for 400001-409999; 32-bit parameter registers (420000+) need 6-digit or raw addressing. With 58.33 Addressing mode = Mode 0 (default) a 16-bit parameter gg.ii sits at 400000 + 100*gg + ii (e.g. 01.11 -> 400111, wire 110) and a 32-bit copy at 420000 + 200*gg + 2*ii (e.g. 01.07 -> 420214, wire 20213). Mode 1 uses 400000 + 256*gg + ii and Mode 2 uses 400000 + 512*gg + 2*ii; this map assumes Mode 0. 32-bit registers are listed CDAB, which assumes 58.34 Word order = LO-HI, the default.

What byte order does the ABB ACS380 machinery drive (embedded Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the ABB ACS380 machinery drive (embedded Modbus RTU)?

Start with HR 0 Control word (EFB CW) (Control word: start/stop/reset); HR 1 Reference 1 (EFB Ref1) (Reference 1 (speed/frequency setpoint, 20000 = 46.01/46.02)); HR 3 Status word (EFB SW) (Status word: ready/running/fault/remote); HR 4 Actual value 1 (EFB Act1) (Actual value 1 (speed/frequency feedback)); HR 110 01.11 DC voltage (01.11 DC voltage); HR 400 04.01 Tripping fault (04.01 Tripping fault code); HR 20211 01.06 Output frequency (32-bit) (01.06 Output frequency, 0.01 Hz (32-bit)); HR 20213 01.07 Motor current (32-bit) (01.07 Motor current, 0.01 A (32-bit)).

How do I enable Modbus control of the ABB ACS380 machinery drive (embedded Modbus RTU)?

Selecting the Modbus RTU control macro sets 20.01 Ext1 commands = Embedded fieldbus, 22.11 and 28.11 = EFB ref1 and 58.01 = Modbus RTU (and puts fault reset on DI1). Otherwise set them by hand, plus 58.03 node address, 58.04 baud and 58.05 parity, and apply with 58.06 Communication control = Refresh settings.
