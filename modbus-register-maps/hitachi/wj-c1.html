Short answer

The WJ-C1 compact inverter has an RS485 port that speaks Modbus RTU. Coils give run/stop, direction, reset and the intelligent input and output signals; holding registers give status words, the frequency command, all d-group monitors, trip history and every parameter. This map covers control, the main monitors, the latest trip record and the communication parameters.

Integration notes: Hitachi WJ-C1 series inverter (Modbus RTU)

Integration in brief

Set C096 to Modbus-RTU and the C07x serial settings, then set A001 = 03 and A002 = 03 so the frequency and run command come from Modbus. Write the frequency to 0001h/0002h, start and stop with coil 0001h, and poll 0003h-0005h plus the d-group monitors from 1001h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set RS485 communication mode [C096] to Modbus-RTU, then A001 = 03 (frequency from Modbus) and A002 = 03 (run command from Modbus). Coils 0001h/0002h only act when A002 = 03.

Communication loss & watchdog

C077 sets a communication timeout (0.00 = off, up to 99.99 s); C076 selects the action on a comm error: trip, trip after deceleration, ignore (default), free run or deceleration stop.

Byte order & addressing

  • Wire address is the printed hex number minus 1.
  • F001 is a two-register value (0001h high, 0002h low). Reading or writing only the low word 0002h is allowed; accessing only the high word is rejected with exception 27h.
  • Byte order of the data field follows [P400]; keep it at 00 Big endian unless the master needs otherwise.
  • Parameter writes over Modbus are not stored in EEPROM unless 0900h is written with 1 (or the EEPROM write mode is set).

Network setup

  • C071 baud (default 05 = 9600), C072 node address 1-247 (default 1), C074 parity (default none), C075 stop bits (default 1).
  • Turn on the built-in 120 ohm termination switch on the inverter at the end of the line.
  • Connect SP/SN for the RS485 pair and L as signal ground.

Watch out for

  • The intelligent input coils are OR-ed with the physical terminals; the [d005] monitor shows only the physical terminals, not the Modbus-driven state.
  • Communication error coils (004Ah-004Eh) latch until an error reset.

Notes on this map

  • Two-register values are printed as (High) then (Low) register. With Endian selection [P400] = 00 Big endian (default) a two-register value 01020304h is sent as 01 02 03 04, which is ABCD. Little endian (01) and special endian (02) change the byte order; trip history registers 0012h-004Eh always read big endian.
  • Only a working subset is listed: control coils, status words, main d-group monitors, trip monitor 1, F001-F004, A001/A002 and the C07x communication settings. Trip monitors 2-6 follow at 001Ch, 0026h, 0030h, 003Ah and 0044h with the same layout as trip monitor 1. The full parameter list is in chapter 18.
  • Accumulated input power [d015] is in units of 1 kWh multiplied by the [b079] gain, so no fixed unit is given here.
  • Inverter state A (0003h) has no code 1 in the source.
  • Coils 0010h-0058h can also be read as packed words at 1E01h-1E05h, and coils 0001h-000Fh written via 1F01h; not listed separately.
  • The rotation direction monitor [d003] is printed with keypad symbols only (F / o / r for 0-2); the exact code-to-symbol order is not stated, so no value list is given.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Hitachi WJ-C1 series inverter (Modbus RTU)

What Modbus registers does the Hitachi WJ-C1 series inverter (Modbus RTU) have?

This map lists 75 registers: 28 coils, 47 holding registers. 26 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Hitachi WJ-C1 series inverter (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual prints coil and register numbers in hex starting at 0001h and says the start number in the frame is the register number minus 1 (its coil read example asks for coil 0007h with 0006h). So wire address = printed number - 1: register 1001h is wire 0x1000.

What byte order does the Hitachi WJ-C1 series inverter (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Hitachi WJ-C1 series inverter (Modbus RTU)?

Start with HR 0 Output frequency setting / monitor [F001] (Frequency command F001); CO 0 RUN command (Run/stop); CO 3 Reset (RS) (Fault reset); HR 2 Inverter state A (Inverter state A); HR 4096 Output frequency monitor [d001] (Output frequency); HR 4098 Output current monitor [d002] (Output current); HR 17 Trip monitor 1: trip code [d081] (Latest trip code); HR 4133 DC bus voltage monitor [d102] (DC bus voltage).

How do I enable Modbus control of the Hitachi WJ-C1 series inverter (Modbus RTU)?

Set RS485 communication mode [C096] to Modbus-RTU, then A001 = 03 (frequency from Modbus) and A002 = 03 (run command from Modbus). Coils 0001h/0002h only act when A002 = 03.

What happens when the Hitachi WJ-C1 series inverter (Modbus RTU) loses Modbus communication?

C077 sets a communication timeout (0.00 = off, up to 99.99 s); C076 selects the action on a comm error: trip, trip after deceleration, ignore (default), free run or deceleration stop.
