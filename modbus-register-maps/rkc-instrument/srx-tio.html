RKC Instrument SRX module type controller, TIO temperature control module (Modbus RTU) Modbus register map

Short answer

The SRX is a DIN-rail modular controller: each TIO module runs two PID loops, and extension, DI and DO modules share the bus of a basic TIO module. With DIP switch 6 set to Modbus, each TIO module answers Modbus RTU on RS-485 with channel 1 data at 0000H and channel 2 data at 1000H. This map covers measured values, events, setpoints, PID, manual output, program run control and the key input setup items.

Integration notes: RKC Instrument SRX module type controller, TIO temperature control module (Modbus RTU)

Integration in brief

Set DIP switch 6 ON (Modbus) and the rotary address, then read 0000H-0003H for CH1 PV, event state, output and SV monitor (1000H-1003H for CH2). Write the setpoint to 0010H/1010H and start control with 0030H = 1.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is chosen with DIP switch 6 (ON = Modbus; factory setting is RKC protocol). Speed is set by DIP switches 1-2, data/parity by 3-5. Power off before changing switches.

Byte order & addressing

  • The Modbus slave address is the rotary switch setting plus 1 (switch 00 = slave 1).
  • Each module (slave address) carries at most two channels.
  • Writes to undefined addresses are not allowed; with a data error part-way through a multi-write, the values before the error still take effect.

Network setup

  • Factory DIP settings: 9600 bps, 8 data bits, no parity, 1 stop bit (fixed). Speeds 2400-38400 bps.
  • Give the basic TIO module the lowest address when extension modules share its bus; terminate the internal data bus at both ends (DIP 8).

Watch out for

  • Wait 30 bit times after a response before the next request; the response takes up to 5 ms (200 ms after initial-setting writes).
  • Some items read 0 when the matching function is not fitted or not in use (no error is returned).

Notes on this map

  • RKC's own download center does not offer this manual publicly; the linked copy is the unaltered RKC manual hosted by a US distributor (a distributor stamp on the cover only).
  • All registers are 16-bit; FFFFH is -1. Values are sent without a decimal point: PV/SV-type items follow the input range decimal point (0873H), integral/derivative time follows 085CH, others have the fixed decimals shown (scale).
  • Items marked (module) exist once per module (channel 1 address only); all others repeat for channel 2 at +1000H.
  • The decimal-handling list prints Manual output value twice and does not name the manipulated output (0002H); its scale 0.1 rests on its printed -5.0 to +105.0 % range.
  • Level PID tables, program pattern/segment tables, digital input assignments and the DI/DO module maps are left out.
  • Writing input range, scale, decimal point, unit or event type can take up to 200 ms to answer; stop control (0030H) before changing initial-setting items.

Questions about the RKC Instrument SRX module type controller, TIO temperature control module (Modbus RTU)

What Modbus registers does the RKC Instrument SRX module type controller, TIO temperature control module (Modbus RTU) have?

This map lists 99 registers: 99 holding registers. 68 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the RKC Instrument SRX module type controller, TIO temperature control module (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The data map prints each register in hex and decimal; the value is the address sent on the wire. The manual's read example asks for 0000H-0002H and gets back PV, event state and output, so 0000H is a real register (CH1 measured value).

What are the minimum Modbus registers to integrate the RKC Instrument SRX module type controller, TIO temperature control module (Modbus RTU)?

Start with HR 0 Measured value (PV) (CH1) (CH1 measured value); HR 1 Comprehensive event state (CH1) (CH1 event state); HR 2 Manipulated output value (CH1) (CH1 output); HR 16 Set value (SV) (CH1) (CH1 set value); HR 48 Control RUN/STOP transfer (module) (Control RUN/STOP); HR 4096 Measured value (PV) (CH2) (CH2 measured value); HR 4112 Set value (SV) (CH2) (CH2 set value).

How do I enable Modbus control of the RKC Instrument SRX module type controller, TIO temperature control module (Modbus RTU)?

Modbus is chosen with DIP switch 6 (ON = Modbus; factory setting is RKC protocol). Speed is set by DIP switches 1-2, data/parity by 3-5. Power off before changing switches.
