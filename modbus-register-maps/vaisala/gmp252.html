Integration notes: Vaisala GMP252 CARBOCAP carbon dioxide probe (Modbus RTU)

Integration in brief

Read holding registers 1-6 in one request (function 03) for CO2 and temperature as CDAB floats. Write compensation values to the volatile registers 521-528 if they change often.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU over RS-485 is one of the probe's output modes, chosen at order or later by configuration. From Vaisala Industrial Protocol, switch with the serial command smode modbus. If pin 5 is tied to GND (pin 3) the probe is locked in analog mode and Modbus is not available.

Byte order & addressing

  • Float word order is low word first (CDAB); use "word-swapped" in masters that expect high word first.
  • Read each 32-bit value in a single transaction.

Network setup

  • Defaults: address 240, 19200 baud, no parity, 8 data bits, 2 stop bits.
  • Change address and serial settings with registers 769-772, or in Vaisala Insight PC software.

Watch out for

  • Register 258 must be multiplied by 10.
  • Relative humidity compensation only works with temperature and pressure compensation also enabled.

Notes on this map

  • All values are holding registers read with function 03 and written with function 16.
  • 32-bit floats and the 32-bit error code put the least significant word at the listed register (CDAB); the guide confirms this with a worked read frame (bytes D4 7A 43 E8 = 465.66 ppm).
  • Missing data returns quiet NaN (float) or 0x8000 (integer) instead of an exception.
  • Power-up compensation registers are stored in EEPROM (about 30000 writes); write the volatile registers for frequent updates.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Vaisala GMP252 CARBOCAP carbon dioxide probe (Modbus RTU)

What Modbus registers does the Vaisala GMP252 CARBOCAP carbon dioxide probe (Modbus RTU) have?

This map lists 25 registers: 25 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Vaisala GMP252 CARBOCAP carbon dioxide probe (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide numbers registers in decimal starting at 1 and also prints the 0-based hex address used in the request; register number 1 is address 0x0000 on the wire.

What byte order does the Vaisala GMP252 CARBOCAP carbon dioxide probe (Modbus RTU) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Vaisala GMP252 CARBOCAP carbon dioxide probe (Modbus RTU)?

Start with HR 0 Measured CO2 (CO2 concentration); HR 4 Measured T (Probe temperature); HR 2048 Device status (Device status); HR 2051 Error code (Active error bits); HR 520 Volatile pressure compensation (Live pressure compensation).

How do I enable Modbus control of the Vaisala GMP252 CARBOCAP carbon dioxide probe (Modbus RTU)?

Modbus RTU over RS-485 is one of the probe's output modes, chosen at order or later by configuration. From Vaisala Industrial Protocol, switch with the serial command smode modbus. If pin 5 is tied to GND (pin 3) the probe is locked in analog mode and Modbus is not available.

Where is the official Vaisala GMP252 CARBOCAP carbon dioxide probe (Modbus RTU) Modbus documentation?

The source is GMP252 User Guide (M211897EN-G), revision 2026-11, published free by Vaisala at https://docs.vaisala.com/r/M211897EN-G/en-US.
