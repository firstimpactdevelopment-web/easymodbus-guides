Integration notes: First Co. WSHP series DDC controller CB900 (water-source heat pump, Modbus RTU/TCP)

Integration in brief

Read holding registers 3 (op code) and 5 (machine mode) for status and fault, and coils 0-10 for pressure switches, condensate, reversing valve, call signals and compressor state.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

On the controller (or the CB1000 HMI tool) set the communication mode to 'BacIp&ModRtu' for Modbus RTU; Modbus IP is always available. Modbus RTU and BACnet MS/TP cannot run together.

Byte order & addressing

  • Temperatures have no published Modbus format, so they are not in this map.

Network setup

  • Modbus RTU page: baud 9600-115200 (default 38400), device address 1-247 (default 9), parity default None, stop bits default 1.
  • A soft restart is needed after changing communication settings.
  • Communication menus need password level 2 or 3.

Watch out for

  • BACnet MS/TP mode turns Modbus RTU off.
  • Test mode shortens all wait times and turns itself off after 15 minutes.

Notes on this map

  • Left out: exit water coil temperature (index 0), air coil temperature (1), supply air temperature (2) and the lockout retry count (4). The manual types them as analog values (BACnet AV) with no Modbus data type or scale, so the raw format is not known.
  • Fan mode and machine enable are multi-state values whose state numbers the manual does not list.
  • The coil points are status values; the manual does not say whether any of them can be written.
  • Op code value 17 and mode value 6 are not listed in the manual. Mode values 4 and 5 are both printed as 'Cool'.
  • Software revision and program number are also exposed as BACnet state-text objects that have no Modbus index.
  • For the LP status coil the manual prints "1-high pressure"; read 1 as the low-pressure switch tripped.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the First Co. WSHP series DDC controller CB900 (water-source heat pump, Modbus RTU/TCP)

What Modbus registers does the First Co. WSHP series DDC controller CB900 (water-source heat pump, Modbus RTU/TCP) have?

This map lists 21 registers: 9 coils, 12 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the First Co. WSHP series DDC controller CB900 (water-source heat pump, Modbus RTU/TCP) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table gives a 'Modbus Index' starting at 0 for both coils and holding registers (HP status is coil index 0). The index is used as the wire address.

What are the minimum Modbus registers to integrate the First Co. WSHP series DDC controller CB900 (water-source heat pump, Modbus RTU/TCP)?

Start with HR 3 Op code (Operating / fault code); HR 5 Mode of machine (Machine mode); CO 0 HP status (High-pressure switch); CO 1 LP status (Low-pressure switch); CO 2 Condensate status (Condensate); CO 10 Compressor status (Compressor status).

How do I enable Modbus control of the First Co. WSHP series DDC controller CB900 (water-source heat pump, Modbus RTU/TCP)?

On the controller (or the CB1000 HMI tool) set the communication mode to 'BacIp&ModRtu' for Modbus RTU; Modbus IP is always available. Modbus RTU and BACnet MS/TP cannot run together.

Where is the official First Co. WSHP series DDC controller CB900 (water-source heat pump, Modbus RTU/TCP) Modbus documentation?

The source is WSHP Series DDC Controller Installation, Operation and Maintenance Manual (no hot-gas reheat) (IOM8083D02 Rev. A), revision 2026-03, published free by First Co. at https://firstco.com/files/IOM/IOM8083D02-Water-Source-DDC-Controller-no-HGRH.pdf.
