Short answer

The Wilo-Control EC-WP is a switchgear for level- or pressure-dependent control of up to two fixed-speed pumps (float switch, electrodes, pressure switch or sensor). It has an RS485 ModBus RTU slave port. The holding registers cover pump enable, per-pump modes, pressure actual value and setpoints, general and float-switch status and the alarm history.

This page lists 17 Modbus registers for the Wilo Wilo-Control EC-WP switchgear (ModBus RTU) — 7 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Wilo’s own free documentation (linked below) and checked against it.

Integration notes: Wilo Wilo-Control EC-WP switchgear (ModBus RTU)

Integration in brief

Turn ModBus on in Menu 2.01, wire RS485 and poll unit 10 at 19200 baud, even parity. Read the actual pressure (40026), general status (40062) and float-switch status (40198); enable the pumps with Drives on/off (40015).

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Menu 2.01 switches the ModBus RTU interface on (factory setting on). Baud in 2.02, address in 2.03, parity in 2.04, stop bits in 2.05.

Byte order & addressing

  • Pressure values are INT16/UINT16 in 0.1 bar.
  • Factory address is 10, not 1.

Network setup

  • RS485 interface on the terminal strip; see the terminal diagram on the cover.
  • Baud rate 9600, 19200 (default), 38400 or 76800; parity none, even (default) or odd; 1 (default) or 2 stop bits.
  • The switchgear is terminated at the factory; remove jumper J2 if it is not at the end of the bus. Fit J3 and J4 if the bus needs polarisation.

Watch out for

  • A 'Fault status' block (40139-40140) exists but is not in this map; read General status (40062) for the collective fault bit.

Notes on this map

  • The same parameter table is published as an HTML appendix page: https://cms.media.wilo.com/dcianimpfinder/wilo718556/9646785/en-GB/2228099211.html.
  • BOOL registers are listed as UINT16 with 0/1; the manual treats any value above zero as true. ENUM registers are UINT16.
  • Left out: Fault status 40139-40140 (BITMAP32 over two registers, bits 0-20) because the manual does not say which register holds the low bits.
  • The data-type table describes BITMAP32 with the same 16-bit wording as BITMAP; this is a source wording issue.
  • The scaling column prints 0.1 for 'Fault number alarm history'; it is copied as printed.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Wilo Wilo-Control EC-WP switchgear (ModBus RTU)

What Modbus registers does the Wilo Wilo-Control EC-WP switchgear (ModBus RTU) have?

This map lists 17 registers: 17 holding registers. 7 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Wilo Wilo-Control EC-WP switchgear (ModBus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The parameter table prints each holding register as 4xxxx with the protocol address in brackets, e.g. 40026 (25). The bracketed number goes on the wire.

What are the minimum Modbus registers to integrate the Wilo Wilo-Control EC-WP switchgear (ModBus RTU)?

Start with HR 25 Actual value (Actual pressure); HR 26 Current setpoint (Current setpoint); HR 61 General status (Run and fault signals); HR 14 Drives on/off (Pumps on/off); HR 67 Setpoint 1 (Pressure setpoint); HR 197 Status of float switch (Float switch status).

How do I enable Modbus control of the Wilo Wilo-Control EC-WP switchgear (ModBus RTU)?

Menu 2.01 switches the ModBus RTU interface on (factory setting on). Baud in 2.02, address in 2.03, parity in 2.04, stop bits in 2.05.
