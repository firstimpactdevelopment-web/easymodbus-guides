Invertek Drives Optidrive Coolvert compressor drive (built-in Modbus RTU) Modbus register map

Updated 19 November 2026

Short answer

The Optidrive Coolvert is Invertek's variable speed drive for refrigeration and HVAC compressors (BLDC, PM, induction and synchronous reluctance). Modbus RTU is built in on control terminals 1-3 and the RJ45 port. Registers 1-5 take the control word, speed set point in rps and ramp time; registers 7-45 report speed, current, power, trip codes, energy and run time. Every parameter also has its own register (P1-11 = 111).

This page lists 46 Modbus registers for the Invertek Drives Optidrive Coolvert compressor drive (built-in Modbus RTU) — 14 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Invertek Drives’s own free documentation (linked below) and checked against it.

Integration notes: Invertek Drives Optidrive Coolvert compressor drive (built-in Modbus RTU)

Integration in brief

Set P1-11 = 0, close the STO circuit, then write register 1 = 1 to run and register 2 with the speed in 0.1 rps. Poll registers 7, 8, 10 and 9 for speed, current, power and the trip code.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set P1-11 = 0 (Modbus mode). The STO inputs (terminals 8 and 9) must be energised for the drive to run. Set the drive address in P6-01 (or a separate Modbus address in P6-08), the baud rate in P6-02 and parity in P6-03. Set P6-06 = 1 to take ramp times from register 4.

Communication loss & watchdog

P6-04 sets the communication-loss time (0-60 s, default 5 s). P6-05 picks the reaction: 0 trip (default), 1 ramp to stop then trip, 2 ramp to stop without a trip, 3 run at the signal-loss speed P3-11. A comms loss trip shows as code 50 (SC-F01).

Byte order & addressing

  • Register numbers are 1-based: subtract 1 for the wire address.
  • Speeds are in revolutions per second (rps), not Hz or rpm; the IDL-format registers are the exception.
  • The fault-reset bit in the control word must be returned to 0 after the reset or the drive will reset again unexpectedly.

Network setup

  • RS-485 on control terminals 1 (0 V), 2 (+) and 3 (-), or RJ45 pins 3 (0 V), 8 (+) and 7 (-).
  • Factory settings: address 1, 115.2 kbps, no parity, 1 stop bit.
  • Connect 0 V common to every device; terminate the shield at the controller only, not at the drive.

Watch out for

  • The RJ45 port is not Ethernet; do not plug it into a network switch.
  • Class B trips on frame 3-5 drives cannot be reset for two minutes, and ten trips of one kind before a power cycle cause a lockout that only a power cycle clears.

Notes on this map

  • Left out: register 6 (drive status). The guide describes it both as a 16-bit status word with bits 0-15 defined and as a single byte holding the last fault code, so its layout cannot be settled. Use register 9 for the trip code.
  • Register 3 is not listed. Function 16 (write multiple) is accepted for registers 1-4 only; 03 and 06 work on the others.
  • The guide states no signedness for most registers. Speed and analogue values that can go negative are typed INT16, counters and ratings UINT16.
  • Registers 5, 40 and 42 use an 'IDL format' where 3000 = 50 Hz; they are kept raw.
  • P6-02 (baud rate) is left out because the guide shows it in kbps (default 115) next to a 0-5 option list, so the stored value is unclear.
  • Only the parameters an integrator needs for Modbus control are listed; every other parameter is reachable at its group-and-number register (for example 107 for P1-07).
  • Trip codes listed are the A-class table; frame 3-5 drives with EN/UL 60730 certification also have class B trips.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Invertek Drives Optidrive Coolvert compressor drive (built-in Modbus RTU)

What Modbus registers does the Invertek Drives Optidrive Coolvert compressor drive (built-in Modbus RTU) have?

This map lists 46 registers: 46 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Invertek Drives Optidrive Coolvert compressor drive (built-in Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The guide numbers registers from 1 and tells masters that start at register 0 to subtract 1, so control word register 1 is wire address 0. Parameters use their group and number as the register (P6-04 = register 604 = wire address 603).

What are the minimum Modbus registers to integrate the Invertek Drives Optidrive Coolvert compressor drive (built-in Modbus RTU)?

Start with HR 0 Drive control word (Control word: run, coast stop, reset); HR 1 Speed set point (Speed set point, 0.1 rps); HR 6 Output frequency (compressor speed) (Compressor speed, 0.1 rps); HR 7 Output current (Output current, 0.1 A); HR 8 Trip code (Trip code); HR 9 Output power (Output power, 0.01 kW); HR 110 P1-11 Primary command source (P1-11 command source).

How do I enable Modbus control of the Invertek Drives Optidrive Coolvert compressor drive (built-in Modbus RTU)?

Set P1-11 = 0 (Modbus mode). The STO inputs (terminals 8 and 9) must be energised for the drive to run. Set the drive address in P6-01 (or a separate Modbus address in P6-08), the baud rate in P6-02 and parity in P6-03. Set P6-06 = 1 to take ramp times from register 4.

What happens when the Invertek Drives Optidrive Coolvert compressor drive (built-in Modbus RTU) loses Modbus communication?

P6-04 sets the communication-loss time (0-60 s, default 5 s). P6-05 picks the reaction: 0 trip (default), 1 ramp to stop then trip, 2 ramp to stop without a trip, 3 run at the signal-loss speed P3-11. A comms loss trip shows as code 50 (SC-F01).
