Short answer

The Trafag 8775 sensor and 879x hybrid monitor measure the density of a specified gas or gas mixture with a pair of quartz oscillators, and report it over Modbus RTU. This map is the manual's 'Legacy' configuration: scaled 16-bit density, pressure and temperature, identification, serial settings and a sensor-status discrete input.

Integration notes: Trafag 8775 gas density sensor / 879x hybrid gas density monitor (legacy Modbus map)

Integration in brief

Read input registers 0-3 (function 04) for density, pressure and temperature as scaled integers, and discrete input 0 (function 02) for sensor status.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus RTU is always active. Server ID, baud rate and parity are holding registers 2-5; register 8 shows which of them are write-protected.

Byte order & addressing

  • 0xFFFF in a measurement register means its range was exceeded.
  • Temperature is in kelvin (x 0.1).

Network setup

  • Terminate both bus ends with 120 Ohm (jumper J4 on hybrid units) and use 560 Ohm line polarisation.

Watch out for

  • Confirm the unit runs the Legacy map; the Standard map puts floats at the same addresses.

Notes on this map

  • The manual describes two Modbus configurations, 'Legacy' and 'Standard', with different maps at the same addresses. This file is the Legacy map only; it does not say which units ship with which.
  • Left out: the Standard map (float density/pressure/temperature at 0-48, hour meter, status flag words, serial number U64), because the manual gives no word order for its floats and 32/64-bit values.
  • 32-bit values in the Legacy map are marked big-endian; the serial-number example (0x075BCD15 split as 0x075B, 0xCD15) shows high word first.
  • Left out: 'Quartz frequency difference' (address 8), a fixed dummy value of 1000 from firmware V2.0, and 'Mode' (holding 6), marked non-functional.
  • Parity choice also fixes stop bits: none = 2 stop bits, odd/even = 1 stop bit.
  • Holding registers are stored in EEPROM; the manual warns that excessive writing can wear it out.
  • Server ID can also be changed by broadcast using the serial number (section 5.4).

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Trafag 8775 gas density sensor / 879x hybrid gas density monitor (legacy Modbus map)

What Modbus registers does the Trafag 8775 gas density sensor / 879x hybrid gas density monitor (legacy Modbus map) have?

This map lists 13 registers: 1 discrete input, 7 input registers, 5 holding registers. 4 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Trafag 8775 gas density sensor / 879x hybrid gas density monitor (legacy Modbus map) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Addresses are protocol addresses. The manual's example reads density (address 0) with start address 0x0000 and the serial number (address 5) with 0x0005.

What byte order does the Trafag 8775 gas density sensor / 879x hybrid gas density monitor (legacy Modbus map) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Trafag 8775 gas density sensor / 879x hybrid gas density monitor (legacy Modbus map)?

Start with IR 0 Gas density (Gas density, kg/m3 x 0.01); IR 1 Gas pressure (abs, @20°C) (Pressure @20°C, kPa x 0.1); IR 2 Gas temperature (Gas temperature, K x 0.1); DI 0 Sensor status (Sensor error flag).

How do I enable Modbus control of the Trafag 8775 gas density sensor / 879x hybrid gas density monitor (legacy Modbus map)?

Modbus RTU is always active. Server ID, baud rate and parity are holding registers 2-5; register 8 shows which of them are write-protected.
