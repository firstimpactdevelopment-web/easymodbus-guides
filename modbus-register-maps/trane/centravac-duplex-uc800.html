Short answer

Trane's Duplex CenTraVac is a two-circuit water-cooled centrifugal chiller. Its Tracer UC800 controller has a native Modbus map in which every point is one 16-bit register with a fixed SI scaling per register type (temperatures in 0.01 °C, pressures in 0.1 kPa, percent in 0.005 % steps). This map covers the BAS command registers and the input registers for water and refrigerant temperatures, pressures, starter and AFD values, bearing and winding temperatures and status enums.

This page lists 192 Modbus registers for the Trane CenTraVac CTV-Duplex water-cooled centrifugal chiller (UC800 native Modbus) — 12 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Trane’s own free documentation (linked below) and checked against it.

Integration notes: Trane CenTraVac CTV-Duplex water-cooled centrifugal chiller (UC800 native Modbus)

Integration in brief

Write 40001 (auto/stop), 40002 (mode) and 40003 (chilled-water setpoint, 0.01 °C) and poll the 3xxxx input registers with function 04. Every value is a single register; apply the per-type scale from the object-format table.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

The points list does not describe setup; it names BAS-SVP083*-EN as its reference integration guide for enabling Modbus on the controller.

Byte order & addressing

  • Percent registers count in 0.005 % steps (20,000 = 100 %), not 0.1 %.
  • Temperatures are signed hundredths of a degree Celsius; pressures are tenths of a kPa.

Network setup

  • Unit address, baud and TCP settings are set in the controller's protocol configuration; the list itself gives no defaults.

Watch out for

  • Points not supported by the unit's configuration are absent or invalid; the list applies to Duplex (two-compressor) machines.

Notes on this map

  • The object-format table gives one fixed encoding per register type: Binary/Enumeration/Current/Voltage/Power/Concentration/Frequency/Flow/Pressure are unsigned 16-bit; Percent, Power Factor, Differential Pressure and Temperature are signed 16-bit. Scales: Temperature 0.01 °C, Pressure and Differential Pressure 0.1 kPa (printed as absolute for both), Percent 0.005 % (20,000 = 100 %), Power Factor 0.005, Frequency 0.1 Hz, Flow water L/min, Flow air L/s, Power kW, Current A, Voltage V.
  • Values are always SI in this native map; there is no I-P switch in the list.
  • Left out: all Time Interval points (purge timers, pumpout counters, refrigeration life, compressor running time). They are 32-bit (u32) over two registers and the list does not state the word order.
  • Left out: Compressor Starts Ckt1/Ckt2 (30086, 30142). Their type 'Count' is not defined in the object-format table and they span two registers.
  • Left out: Circuit Available Ckt1/Ckt2 (30217, 30218), printed with no register type.
  • Differential refrigerant pressure and oil differential pressure appear twice: 30058/30061 (Ckt1) and 30114/30117 (Ckt2) use the Pressure type, and 30187-30190 repeat them with the signed Differential Pressure type.
  • Last Diagnostic Code (30025) points to the diagnostic list in the BACnet part of the document; codes are not reproduced.
  • BAS-PTS029A-EN (CTV-Simplex UC800) carries a Modbus section that is essentially the same Duplex table (Software Type 458 = CTVD), so no separate Simplex map is made from it.
  • The points list does not name the Modbus transport (RTU or TCP); it refers to BAS-SVP083*-EN for protocol setup, so confirm the transport in the controller configuration.
  • 30181 and 30182 are both printed as 'AFD Input Current L2 Ckt2'; the names are kept as printed.

Questions about the Trane CenTraVac CTV-Duplex water-cooled centrifugal chiller (UC800 native Modbus)

What Modbus registers does the Trane CenTraVac CTV-Duplex water-cooled centrifugal chiller (UC800 native Modbus) have?

This map lists 192 registers: 180 input registers, 12 holding registers. 12 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Trane CenTraVac CTV-Duplex water-cooled centrifugal chiller (UC800 native Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The list prints Modicon register numbers: 4xxxx are holding registers and 3xxxx input registers, so 40001 is holding register address 0 and 30010 is input register address 9.
