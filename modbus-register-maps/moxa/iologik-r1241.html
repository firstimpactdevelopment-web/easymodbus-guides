Short answer

The ioLogik R1241 is a Moxa RS-485 Modbus RTU remote I/O module with 4 analog outputs (0-10 V, 0-20 mA, 4-20 mA). It supports a repeater or dual RS-485 mode and a Modbus host-connection watchdog with safe-mode output states. This map covers the shared system registers (model, watchdog, serial settings) and the analog output raw values, power-on and safe values, range.

This page lists 32 Modbus registers for the Moxa ioLogik R1241 RS-485 remote I/O — 27 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Moxa’s own free documentation (linked below) and checked against it.

Integration notes: Moxa ioLogik R1241 RS-485 remote I/O

Integration in brief

Poll the I/O block with the function code shown for each register (01/02 for bits, 03/04 for words). Enable the Modbus watchdog (0x7564, timeout 0x7565) so outputs and counters fall back to their safe-mode settings if the master stops polling.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the device ID (1-99) on the two rotary dials. Put the Initial/Run switch on Initial to configure the unit at 9600 baud, no parity, 8 data bits, 1 stop bit (with ioSearch or the SYS_port* registers), then switch back to Run.

Communication loss & watchdog

SYS_modbusWatchdogFuntion (0x7564) enables the host-connection watchdog, SYS_modbusWatchdogTimeout (0x7565) sets the timeout in seconds (factory default 10 s), SYS_modbusWatchdogStatus (0x7566) shows a timeout. It is disabled by default; safe-status settings only act when it is enabled.

Byte order & addressing

  • System registers sit at 0x7530 and up (six-digit references 330001/430002).
  • Write 404 to SYS_restartDevice or SYS_loadFactoryDefault to trigger them.

Network setup

  • Device ID 1-99 on the rotary dials (x1 and x10).
  • The Dual/Rep switch selects two separate RS-485 ports or repeater mode; SYS_rs485PortMode reports which is active.
  • Baud rate codes: 1=1200 ... 4=9600, 5=19200 ... 9=921600.

Watch out for

  • Factory defaults (reset button held 5 s, ioSearch, or SYS_loadFactoryDefault) return the serial settings to 9600 n 8 1 and disable the watchdog.

Notes on this map

  • Moxa does not appear to offer this manual on a public URL found in this pass; the link is an unaltered copy of the Moxa user's manual on a reseller's file host.
  • Each table row gives the hex wire address, the 1-based decimal reference (e.g. 0x0000 = 40001; system registers use six digits, 0x7530 = 330001), access, size and function code.
  • Left out: system strings and multi-word values whose format is not described (firmware version and release date, serial number, server name/location, password, vendor name).
  • Raw AO values are listed without scaling; the table does not give the raw-to-engineering range.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Moxa ioLogik R1241 RS-485 remote I/O

What Modbus registers does the Moxa ioLogik R1241 RS-485 remote I/O have?

This map lists 32 registers: 5 input registers, 27 holding registers. 27 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Moxa ioLogik R1241 RS-485 remote I/O Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers hexadecimal, 0-based. Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Each row prints the hex protocol address and a 1-based reference number (0x0000 = 00001/10001/30001/40001). The hex address is sent on the wire; the table (coil, discrete input, input or holding) is set by the function code column.

What are the minimum Modbus registers to integrate the Moxa ioLogik R1241 RS-485 remote I/O?

Start with IR 30000 SYS_modelID (Model ID check); HR 30052 SYS_modbusWatchdogFuntion (Enable communication watchdog); HR 30053 SYS_modbusWatchdogTimeout (Watchdog timeout); HR 1184 AO-00_rawValue (First analog output raw value); HR 1280 AO-00_mode (First analog output range).

How do I enable Modbus control of the Moxa ioLogik R1241 RS-485 remote I/O?

Set the device ID (1-99) on the two rotary dials. Put the Initial/Run switch on Initial to configure the unit at 9600 baud, no parity, 8 data bits, 1 stop bit (with ioSearch or the SYS_port* registers), then switch back to Run.

What happens when the Moxa ioLogik R1241 RS-485 remote I/O loses Modbus communication?

SYS_modbusWatchdogFuntion (0x7564) enables the host-connection watchdog, SYS_modbusWatchdogTimeout (0x7565) sets the timeout in seconds (factory default 10 s), SYS_modbusWatchdogStatus (0x7566) shows a timeout. It is disabled by default; safe-status settings only act when it is enabled.

Where is the official Moxa ioLogik R1241 RS-485 remote I/O Modbus documentation?
