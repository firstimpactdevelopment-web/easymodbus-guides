Short answer

The Veris Enercept H8035/H8036 is a three-phase power transducer with integral split-core CTs and an RS-485 Modbus RTU port, addressed by DIP switches (1-63). Every data point is offered twice: as a scaled integer from 40001 and as an IEEE 754 float from 40257. This map lists the float block, which needs no model-dependent multiplier; the H8035 provides energy and real power only.

This page lists 26 Modbus registers for the Veris Enercept H8035 / H8036 networked power transducer (Modbus RTU) — 0 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from Veris’s own free documentation (linked below) and checked against it.

Integration notes: Veris Enercept H8035 / H8036 networked power transducer (Modbus RTU)

Integration in brief

Set a unique address 1-63 on the DIP switches, wire RS-485 (+, -, shield) and read the float block from 40257 with function 03 as high-word-first floats.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

No enable step; set the Modbus address on the DIP switches before connecting to the bus.

Byte order & addressing

  • Use the float block (40257 on); the integer block needs CT-size multipliers.
  • Floats are ABCD (MSW at the lower address).

Network setup

  • Only addresses 1 to 63 can be set on the DIP switches.
  • Daisy-chain the bus with a 120 ohm terminator at the first and last device; shielded twisted pair such as Belden 1120A.
  • Do not ground the shield inside the electrical panel.

Watch out for

  • The meter is powered from its voltage leads; connect them on the line side so it stays online when the load is switched off.
  • Colour-match each CT to its voltage lead; the status LED blinks red slowly on wrong wiring or PF below 0.5.

Notes on this map

  • Veris does not host this installation guide publicly at a reachable URL (veris.com refuses automated requests); the linked copy on distributor Stromquist's literature server is the unaltered Veris document Z201686-0K.
  • Floats: the guide states 32-bit IEEE 754 values with the most significant word in the lower address of each register pair (ABCD).
  • Left out: the integer block 40001-40027. Each integer needs a multiplier that depends on the CT size (100 A to 2400 A tables on pp. 8-9), and energy is split over an LSW/MSW pair with separate multipliers.
  • 40259/40260 repeat Energy Consumption (same as 40257/40258) and are not listed separately.
  • Supported function codes: 3 (read holding), 6 (preset single register) and 17 (report slave ID). The guide gives no baud or parity defaults; those are in the separate Veris Modbus protocol specification.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Veris Enercept H8035 / H8036 networked power transducer (Modbus RTU)

What Modbus registers does the Veris Enercept H8035 / H8036 networked power transducer (Modbus RTU) have?

This map lists 26 registers: 26 holding registers. 0 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Veris Enercept H8035 / H8036 networked power transducer (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The table prints Modicon 4xxxx holding registers read with function 03; the guide says the address actually sent is the printed value minus 40001, so 40257 is wire address 256.

What byte order does the Veris Enercept H8035 / H8036 networked power transducer (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Veris Enercept H8035 / H8036 networked power transducer (Modbus RTU)?

Start with HR 256 Energy Consumption (Energy consumption (kWh)); HR 260 Real Power (Total real power (kW)); HR 266 Power Factor (Power factor); HR 272 Current (Average current); HR 268 Voltage, line to line (Voltage line to line).

How do I enable Modbus control of the Veris Enercept H8035 / H8036 networked power transducer (Modbus RTU)?

No enable step; set the Modbus address on the DIP switches before connecting to the bus.

Where is the official Veris Enercept H8035 / H8036 networked power transducer (Modbus RTU) Modbus documentation?
