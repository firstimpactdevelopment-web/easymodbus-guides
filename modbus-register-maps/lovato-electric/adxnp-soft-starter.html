Short answer

The Lovato ADXN is a compact soft starter with built-in bypass for pumps, fans, compressors and conveyors. Only the advanced ADXNP version talks Modbus RTU, through the CX04 RS-485 module clipped to its optical port. This map covers voltage, phase currents and powers, frequency, torque, thermal status, thyristor temperature, input and output status, and the start/stop command.

Integration notes: Lovato Electric ADXNP soft starters with CX04 RS-485 module (Modbus RTU)

Integration in brief

Fit the CX04 module, then read currents (08h-0Dh), total power (3Ah), thermal status (FB0h) and thyristor temperature (FB2h) with function 04, subtracting one from each table address. Start or stop with 1 or 0 written to 1002h.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the communication menu (M06) on the ADXNP with the LOVATO NFC app or Xpress software while the CX04 is unplugged, then clip the CX04 onto the optical port and wire RS-485 (SG, A, B) plus 24 V AC/DC to the module.

Byte order & addressing

  • Table addresses are one above the wire address.
  • 32-bit values are high word first.

Network setup

  • Defaults: node 1, 9600 baud, 8 data bits, no parity, 1 stop bit.
  • For Modbus start/stop set P04.04 = ON and keep the ST input closed; opening ST stops the motor and Modbus commands are ignored.

Watch out for

  • The manual describes Modbus only for the ADXNP (advanced) version with the CX04 module.

Notes on this map

  • Measures are read with function 03 or 04 and are listed as input registers; up to 100 consecutive registers per read. The start/stop command uses function 06.
  • Word order: the example answer 00 00 01 10 decodes to 272 = 27.2 °C, so 32-bit values are high word first (ABCD).
  • Scales are the divisors printed in the unit column (V/100, A/10000, kW/100000, Hz/1000, %/10, °C/10).
  • Left out: the status register F94h, because it is printed as 2 words with format 'Unsigned integer', so its width is unclear. The printed status values are 0 no power line, 1 ready, 2 start delay, 3 acceleration ramp, 4 current limit, 5 run, 6 bypass closed, 7 deceleration ramp, 8 alarm.
  • Parameter setting over Modbus is described only by reference to the ADXL protocol document (I454), so it is not repeated here.
  • Up to 31 ADXNP with CX04 can share one RS-485 line.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Lovato Electric ADXNP soft starters with CX04 RS-485 module (Modbus RTU)

What Modbus registers does the Lovato Electric ADXNP soft starters with CX04 RS-485 module (Modbus RTU) have?

This map lists 19 registers: 18 input registers, 1 holding register. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Lovato Electric ADXNP soft starters with CX04 RS-485 module (Modbus RTU) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The address table prints hex addresses one above the request address; the manual's example reads thyristor temperature (table 0FB2h) by sending 0F B1, 'decreased by one'. Addresses here are already reduced by one.

What byte order does the Lovato Electric ADXNP soft starters with CX04 RS-485 module (Modbus RTU) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Lovato Electric ADXNP soft starters with CX04 RS-485 module (Modbus RTU)?

Start with IR 7 L1 current (L1 current); IR 57 Total active power (Total active power); IR 4015 Motor thermal status (Motor thermal status); IR 4017 Thyristor temperature (Thyristor temperature); HR 4097 Start/stop command (Start/stop command).

How do I enable Modbus control of the Lovato Electric ADXNP soft starters with CX04 RS-485 module (Modbus RTU)?

Set the communication menu (M06) on the ADXNP with the LOVATO NFC app or Xpress software while the CX04 is unplugged, then clip the CX04 onto the optical port and wire RS-485 (SG, A, B) plus 24 V AC/DC to the module.
