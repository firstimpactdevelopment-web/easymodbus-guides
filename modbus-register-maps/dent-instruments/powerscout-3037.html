DENT Instruments PowerScout 3037 Power Meter Modbus register map

Updated 25 October 2026

Short answer

The PowerScout 3037 is a compact three-phase submeter with CT inputs, an RS-485 port (Modbus RTU or BACnet MS/TP) and an optional Ethernet port. In Modbus mode everything is a holding register read with function 03. Readings are 16-bit unsigned integers whose scaling depends on a user-set data scalar (44602). This map covers identification, the main system and per-phase readings, line frequency, and the CT, scaling, wiring, pulse-output and comms settings.

This page lists 53 Modbus registers for the DENT Instruments PowerScout 3037 Power Meter — 17 writable — with the table, 0-based wire address, data type, word order, scale, units and access of each, re-typed from DENT Instruments’s own free documentation (linked below) and checked against it.

Integration notes: DENT Instruments PowerScout 3037 Power Meter

Integration in brief

Read 44602 first to learn the data scalar, then poll the system block from 44001 (wire 4000) with function 03 and apply the matching factor per quantity. Writes use function 06 (single register) only.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Modbus is the factory protocol on RS-485. To return from BACnet to Modbus, write 375 to BACnet object 10190 in ViewPoint, or power up with the address switches at FF, set LSB = 1 (Modbus) and MSB to the baud code within 10 seconds. Switches at 00 force Modbus at 9600 8N1. Writing 1833 to 44612 changes the meter to BACnet.

Byte order & addressing

  • Wire address = printed register - 40001 (the printed Offset column).
  • Integer readings 44001-44061 need the data-scalar factor from 44602; amps and volts use different factors from power and energy.
  • Two-register integers are LSW first (CDAB).
  • Only function codes 03, 06 and 11 (Report Slave ID) are supported; there is no multi-register write.
  • Report Slave ID returns a text string including the serial number, firmware and the current scalar.

Network setup

  • Set the Modbus address on the two hex rotary switches (MSB, LSB); the switch value is hexadecimal, e.g. 6 and 4 = address 100. Factory setting is 01; 00 and FF are reserved.
  • Serial defaults in Modbus mode are 9600 baud, 8 data bits, no parity, 1 stop bit; 9600 to 115200 baud are supported. Baud, parity and stop bits are coded into 44606.
  • Ethernet units ship with static IP 192.168.1.10. The guide does not state the Modbus TCP port; ViewPoint lets you enter it.
  • Set CT type and rating (44525, 44600/44601) and the service type (44607, wye or delta) before trusting readings.
  • Choose a data scalar large enough that the biggest expected value stays under 65535 counts; the guide's selection table suggests scalars 1 to 3 depending on CT size and voltage.

Watch out for

  • When the Ethernet cable is connected the RS-485 port is disabled; power-cycle with Ethernet unplugged to use RS-485.
  • USB always talks Modbus, even when the meter is set to BACnet on RS-485.
  • Too small a data scalar makes large readings wrap past 65535 and read wrong; too large a scalar drops decimal places.
  • Demand registers show a default value until one full demand window has elapsed after a reset.

Notes on this map

  • Scaling: the guide's scalar table (p. 34, Table 7) applies to registers 44001-44061. Those integer readings are listed here raw (scale 1, no unit); multiply by the factor for the current Data Scalar (44602, values 0-6, see its value list) in the column named in each register's description: kW/kWh/Demand, kVAR/kVARh, kVA/kVAh, Amps or Volts. Power factor is x0.01 at every scalar, so the PF registers carry that fixed scale.
  • Two-register integers (energy, time since reset) put the LSW at the lower register and the MSW at the next one; the guide's worked example (p. 36) computes MSW x 65536 + LSW, then applies the scalar. They are listed as UINT32 with CDAB word order.
  • The guide says every register is a 16-bit unsigned value (p. 81), yet its positive/negative PF register descriptions refer to the system and phase PF values in 44014/44015/44050-44055 being negative. How a negative PF is encoded there is not stated; they are listed as unsigned here.
  • Left out: the positive (46xxx), negative (47xxx) and NET (44150-44157, 46150-46157, 47150-47157) power and energy blocks. The guide's scalar table names only registers 44001-44061 and does not say which factor applies to these blocks. The exception is 46022, which the guide documents as 10 x Hz.
  • Left out: the Veris H8035/H8036 floating-point block 40257-40310 (Table 27). The guide labels each value MSW/LSW but never states the float format, gives units only by name, and does not say whether the block answers when 44526 is not set to 1 (Veris identity).
  • Left out: the Veris integer block 40001-40027. Its multipliers depend on the CT rating band (Table 26) rather than a fixed scale.
  • Left out: 44022 Line Frequency (the absolute block gives no scale); use 46022.
  • Left out: per-CT settings 50100-50399, the CT phase-shift registers, the snap-to-zero thresholds and the synchronize register 40129, as their encodings are not fully stated.
  • Left out for size: the per-phase energy, kVAR, kVA and displacement-PF registers and the extra demand registers 44080-44084 (see pp. 67-70).
  • DENT's one-page 'Interpreting the PowerScout Registers - Data Scaling' sheet (https://www.dentinstruments.com/wp-content/uploads/2022/09/Interpreting_PowerScout_Registers_Data_Scaling.pdf) gives the same scalar table, but its worked examples name registers 44302 and 44064 as the scalar register; in the guide 44064 is the Data Tick Counter. The guide's 44602 is followed here.

Questions about the DENT Instruments PowerScout 3037 Power Meter

What Modbus registers does the DENT Instruments PowerScout 3037 Power Meter have?

This map lists 53 registers: 53 holding registers. 17 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the DENT Instruments PowerScout 3037 Power Meter Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers Modicon 3xxxx/4xxxx (drop the prefix, subtract 1). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The tables print 4xxxx register numbers next to an 'Offset' column, and the guide states the offset is relative to 40001 and that the address sent on the wire is the register minus 40001 (its examples: 40025 is sent as 0024, 44062 as 4061). So wire address = printed register - 40001, which equals the printed offset.

What byte order does the DENT Instruments PowerScout 3037 Power Meter use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the DENT Instruments PowerScout 3037 Power Meter?

Start with HR 4601 Data Scalar (Data scalar that sets the integer scaling); HR 4000 kWh System (System kWh (raw, LSW first)); HR 4002 kW System (System kW (raw)); HR 4014 Apparent PF System (System apparent power factor); HR 4055 Amps L1 (Phase 1 current (raw)); HR 4058 Volts L1 to Neutral (Phase 1-N voltage (raw)).

How do I enable Modbus control of the DENT Instruments PowerScout 3037 Power Meter?

Modbus is the factory protocol on RS-485. To return from BACnet to Modbus, write 375 to BACnet object 10190 in ViewPoint, or power up with the address switches at FF, set LSB = 1 (Modbus) and MSB to the baud code within 10 seconds. Switches at 00 force Modbus at 9600 8N1. Writing 1833 to 44612 changes the meter to BACnet.
