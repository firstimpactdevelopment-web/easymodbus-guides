Integration notes: SMA Sunny WebBox Modbus profile - common addresses of SMA devices (unit IDs 3-247)

Integration in brief

Look up the device's unit ID in the WebBox gateway table, then read 30775 (AC power), 30529/30513 (energy) and 30769-30773 (DC input) on that unit ID.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Enable Modbus on the WebBox (Settings > Network > Use Modbus = Yes) and make sure the device has a unit ID other than 255.

Byte order & addressing

  • Read 64-bit counters as one 4-register block.
  • NaN values (0x80000000 / 0xFFFFFFFF) mean the device does not supply that value.

Network setup

  • Modbus TCP to the WebBox IP, port 502, unit ID = the device's assigned ID.

Watch out for

  • Sunny Central families typically take 8-10 s for a value change to show at the WebBox Modbus interface; polling faster gains nothing.

Notes on this map

  • Word order: the manual's data-type figures put bits 31..16 in the first register and bits 15..0 in the second (64-bit: bits 63..48 first), and data are sent big-endian, so 32/64-bit values are high word first (ABCD).
  • Format to scale: FIX0 = x1, FIX1 = x0.1, FIX2 = x0.01, FIX3 = x0.001, TEMP = one decimal (x0.1), DT = UTC seconds since 1970-01-01, Duration = seconds.
  • NaN (no value): U16 0xFFFF, S16 0x8000, U32 0xFFFFFFFF, S32 0x80000000, U64 0xFFFFFFFFFFFFFFFF.
  • Multi-register values must be read in one request. SMA recommends at least 10 s between data requests and no more than 30 registers per transfer.
  • Each device family (Sunny Central, Sunny Island/Backup, STP nn000TL-10, string monitors, Meteo Station, Sensorbox) adds its own registers in sections 5.4.4-5.4.15 of the manual; only the common set is listed here.
  • The manual states this common table does not apply to the SB n000US and SB nn000TL-US-12 families, which have separate tables.
  • Find each device's unit ID in the WebBox gateway table (unit ID 1, from register 42109; see the Sunny WebBox map). The default unit_id of 3 here is just the first device slot.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the SMA Sunny WebBox Modbus profile - common addresses of SMA devices (unit IDs 3-247)

What Modbus registers does the SMA Sunny WebBox Modbus profile - common addresses of SMA devices (unit IDs 3-247) have?

This map lists 30 registers: 29 input registers, 1 holding register. 1 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the SMA Sunny WebBox Modbus profile - common addresses of SMA devices (unit IDs 3-247) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 0-based (the number printed is the address on the wire). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The assignment tables give 'ADR (DEC)', the decimal Modbus register address, which is sent unchanged in the request (the manual's gateway example reads device 1 at 42109). 30xxx entries are read-only values, 40xxx entries are writable parameters; the WebBox accepts FC03 and FC04 for reads.

What byte order does the SMA Sunny WebBox Modbus profile - common addresses of SMA devices (unit IDs 3-247) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the SMA Sunny WebBox Modbus profile - common addresses of SMA devices (unit IDs 3-247)?

Start with IR 30775 AC active power, all phases [Pac] (AC power); IR 30513 Total yield [E-Total] (Total energy); IR 30517 Day yield [E-heute] (Day energy); IR 30773 DC power input [Ppv] (DC power); IR 30803 Power frequency [Fac] (Grid frequency); IR 30197 Current event ID [ErrNo] (Active event number).

How do I enable Modbus control of the SMA Sunny WebBox Modbus profile - common addresses of SMA devices (unit IDs 3-247)?

Enable Modbus on the WebBox (Settings > Network > Use Modbus = Yes) and make sure the device has a unit ID other than 255.

The source is SUNNY WEBBOX Modbus Interface - Technical Description (WEBBOX_MODBUS-TB-US-EN-19, version 1.9), published free by SMA at https://files.sma.de/downloads/WEBBOX-MODBUS-TB-US-en-19.pdf.
