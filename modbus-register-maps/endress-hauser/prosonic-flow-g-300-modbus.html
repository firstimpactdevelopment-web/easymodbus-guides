Integration notes: Endress+Hauser Proline Prosonic Flow G 300 ultrasonic gas flowmeter (Modbus RS485)

Integration in brief

Read the process value floats (CDAB at the factory byte order) with function 03 or 04 and check Actual diagnostics (2732). Read the unit registers once so you know the engineering unit of each value.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

The Modbus RS485 option must be ordered. Bus address, baud rate, parity and byte order are under Expert > Communication > Modbus configuration (registers 4910-4917).

Byte order & addressing

  • Factory byte order 1-0-3-2 gives CDAB floats; adjust the device Byte order (4915) rather than the PLC if needed.
  • Function 03 and 04 both read the same registers; write with 06 or 16.

Network setup

  • Check the factory bus address, baud rate and parity on the device before connecting; change them in the Modbus configuration menu.

Watch out for

  • Avoid cyclic writes to non-volatile parameters; the EEPROM write count is limited.

Notes on this map

  • Integrator subset of a parameter manual that gives a register for every menu item; display, I/O-module, sensor adjustment, web server and service parameters are left out.
  • Float word order follows the Byte order parameter (register 4915). The factory setting 1-0-3-2 sends byte 1, byte 0, byte 3, byte 2, where byte 3 holds sign and exponent, so floats are CDAB. Changing Byte order changes every float.
  • Integer parameters are 2 bytes and listed as UINT16; at 1-0-3-2 integers go out MSB first.
  • Unit picklists (volume, mass, temperature and so on) are long code lists; read the unit register and look the code up in the manual.
  • Totalizer control registers are left out because the extracted option list does not line up cleanly in the source table.
  • Parity codes conflict inside the manual: the parameter description lists 2 = None/1 stop bit and 3 = None/2 stop bits, while the register table lists them the other way round. The enum is left out; set parity on the device display or check by reading back.
  • The device also supports Modbus ASCII (Data transfer mode, register 4913); the factory setting is RTU.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Endress+Hauser Proline Prosonic Flow G 300 ultrasonic gas flowmeter (Modbus RS485)

What Modbus registers does the Endress+Hauser Proline Prosonic Flow G 300 ultrasonic gas flowmeter (Modbus RS485) have?

This map lists 44 registers: 44 holding registers. 14 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Endress+Hauser Proline Prosonic Flow G 300 ultrasonic gas flowmeter (Modbus RS485) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. Registers are printed in the Modbus Application Protocol form, which the manual equates with Modicon 3XXXX/4XXXX numbers (its example: mass flow 2007 = 32007), and the scan list calls register addresses 1-based. Subtract 1 on the wire.

What byte order does the Endress+Hauser Proline Prosonic Flow G 300 ultrasonic gas flowmeter (Modbus RS485) use for 32-bit values?

Multi-register values in this map use CDAB (low word first (word-swapped)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Endress+Hauser Proline Prosonic Flow G 300 ultrasonic gas flowmeter (Modbus RS485)?

Start with HR 2006 Volume flow (Volume flow); HR 2082 Corrected volume flow (Corrected volume flow); HR 2008 Mass flow (Mass flow); HR 2014 Flow velocity (Flow velocity); HR 2731 Actual diagnostics (Actual diagnostics).

How do I enable Modbus control of the Endress+Hauser Proline Prosonic Flow G 300 ultrasonic gas flowmeter (Modbus RS485)?

The Modbus RS485 option must be ordered. Bus address, baud rate, parity and byte order are under Expert > Communication > Modbus configuration (registers 4910-4917).
