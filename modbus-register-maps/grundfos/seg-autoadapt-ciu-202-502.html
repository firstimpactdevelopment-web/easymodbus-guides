Short answer

SEG AUTOADAPT grinder pumps carry their own level sensing and control; a CIU box links up to four of them to a Modbus master. The map covers the pit commands and start/stop levels for single-pit and multi-pit operation, pit state and alarm bits, pit energy and run-time counters, and a 50-register block per pump with temperatures, voltage, current, power, energy, starts, level and alarm/warning bits.

Integration notes: Grundfos SEG AUTOADAPT grinder pumps with CIU 202 / CIU 262 / CIU 502 (Modbus)

Integration in brief

Read 00230-00235 for pump presence, running, alarm and the pit main status, 00301 for the pit level, and each pump block for current, power and alarm bits. Force pumps with 00122-00125 or use the PumpDown bits of PitControl 00101.

Minimum registers to map

Addresses are 0-based wire addresses. Enough to monitor and run the unit; map more as the job needs.

Enable Modbus control & writes

Set the CIU 202 address with the hex rotary switches and the speed and parity with the DIP switches; no setting is needed in the pumps. Write the pit levels only in the mode selected by PitMode (00203).

Byte order & addressing

  • Control bits are rising-edge commands; with AutoAckControlBits = 1 (default) the CIU clears them.
  • Single-pit and multi-pit level registers are separate; the unused set is ignored.

Network setup

  • CIU 202 default 19200 baud, even parity, 1 stop bit.
  • CIU 502: Modbus TCP on port 502.

Watch out for

  • A changed RegisterOffset (00002) shifts all addresses above 00100.

Notes on this map

  • 32-bit values are HI/LO register pairs with the HI part at the lower address, so they are ABCD.
  • All registers can be read with function 03 or 04 and are listed as holding registers. 0xFFFF means not available.
  • Pumps 2-4 repeat the pump 1 layout at +50 (00451, 00501, 00551); checked against the printed pump 2-4 tables.
  • Left out: register 00202, because its bit names (bit 0 AlarmInPumpOrPit, bit 1 WarningInPumpOrPit) contradict their descriptions; 00235 carries the same main status consistently and is listed instead. Also left out: the acknowledge register 00201, CIU 262-only cellular registers (RTC, 00236-00239) and user registers.
  • Motor and electronics temperatures are printed in 0.01 K; no 273.15 offset is applied here.

Check it against the live device. A register map tells you what the controller can expose; the unit in front of you may differ by firmware or options. Read a few registers and compare them with the unit’s own display; for a 32-bit value the float and byte-order decoder shows all four word orders at once, so a wrong word order or scale is obvious. Questions about the Grundfos SEG AUTOADAPT grinder pumps with CIU 202 / CIU 262 / CIU 502 (Modbus)

What Modbus registers does the Grundfos SEG AUTOADAPT grinder pumps with CIU 202 / CIU 262 / CIU 502 (Modbus) have?

This map lists 169 registers: 169 holding registers. 28 of them can be written. Registers vary with firmware, options and configuration, so confirm against the device.

Are the Grundfos SEG AUTOADAPT grinder pumps with CIU 202 / CIU 262 / CIU 502 (Modbus) Modbus addresses 0-based or 1-based?

The manufacturer's document numbers registers 1-based (subtract 1 for the wire address). Every address on this page is the 0-based wire address you put in the request; the documented number is shown under it where it differs. The manual says registers numbered X are addressed in telegrams as X - 1 (00104 is sent as 103). Pump n's block starts at 00401 + 50 x (n-1).

What byte order does the Grundfos SEG AUTOADAPT grinder pumps with CIU 202 / CIU 262 / CIU 502 (Modbus) use for 32-bit values?

Multi-register values in this map use ABCD (high word first (big-endian)). Set your client to this order for every 32/64-bit value in the table.

What are the minimum Modbus registers to integrate the Grundfos SEG AUTOADAPT grinder pumps with CIU 202 / CIU 262 / CIU 502 (Modbus)?

Start with HR 230 PitPumpsRunning (Pumps running bits); HR 231 PitPumpsAlarm (Pumps in alarm bits); HR 234 MainStatus (Warning / alarm / manual summary); HR 300 WaterLevel (Pit water level); HR 100 PitControl (Reset and pump-down commands); HR 403 Pump1.AverageLineCurrent (Pump 1 current); HR 427 Pump1.Alarms (Pump 1 alarm bits).

How do I enable Modbus control of the Grundfos SEG AUTOADAPT grinder pumps with CIU 202 / CIU 262 / CIU 502 (Modbus)?

Set the CIU 202 address with the hex rotary switches and the speed and parity with the DIP switches; no setting is needed in the pumps. Write the pit levels only in the mode selected by PitMode (00203).
